# Isotropic Vector　`def.isotropic-vector`
English entry · root `../`
[in graph](../#n=def.isotropic-vector)　·　[Chinese page (authoritative)](./def.isotropic-vector.md)

Let $\beta$ be a symmetric bilinear form on $V$ (or the corresponding quadratic form $q$). One says that $v \ne 0$ is **isotropic** if

$\beta(v, v) = 0$ (that is, $q(v) = 0$)

Such a $v$ is orthogonal to itself. If $\beta$ is nondegenerate and an isotropic vector exists, $\beta$ is called **isotropic**; if there is no nonzero isotropic vector it is called **anisotropic**.

**Example**: on $\mathbb{R}^{2}$, for $\beta(x,y) = x_{1}y_{1} - x_{2}y_{2}$, both $(1,1)$ and $(1,-1)$ are isotropic; the standard inner product has no isotropic vectors.
