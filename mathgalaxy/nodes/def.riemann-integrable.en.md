## Statement · **draft**
Let $f$ be bounded on $[a, b]$. We say $f$ is **Riemann integrable** if and only if there exists a real number $I$ such that

$$\forall \varepsilon > 0,\ \exists \delta > 0 :\ \|P\| < \delta \implies \bigl| S(f, P, \xi) - I \bigr| < \varepsilon$$
