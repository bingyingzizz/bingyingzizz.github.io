陈述

设 KKK 是单纯复形，记 KpK_{p}Kp​ 为它全体 ppp-单纯形之集（有限集）。ppp-链群 Cp(K)C_{p}(K)Cp​(K) 是以 KpK_{p}Kp​ 为基的自由阿贝尔群，它的具体构造是

Cp(K):={ n:Kp→Z },C_{p}(K) := \{\, n : K_{p} \to \mathbb{Z} \,\},Cp​(K):={n:Kp​→Z},

其中 n(σ)=0n(\sigma) = 0n(σ)=0 除有限多个 σ\sigmaσ 之外（这就是「有限形式和」的意思）。

加法逐点（n+mn + mn+m 表示 (n+m)(σ)=n(σ)+m(σ)(n + m)(\sigma) = n(\sigma) + m(\sigma)(n+m)(σ)=n(σ)+m(σ)）。元素写成有限形式和

c=∑σ∈Kpnσ σ,nσ∈Z,c = \sum_{\sigma \in K_{p}} n_{\sigma}\,\sigma,\qquad n_{\sigma} \in \mathbb{Z},c=σ∈Kp​∑​nσ​σ,nσ​∈Z,

nσn_{\sigma}nσ​ 叫 σ\sigmaσ 在 ccc 里的重数。约定 p<0p < 0p<0 或 p>dim⁡Kp > \dim Kp>dimK 时 Cp(K):=0C_{p}(K) := 0Cp​(K):=0。 Cp(K)C_{p}(K)Cp​(K) 是自由阿贝尔群，秩等于 KKK 的 ppp-单纯形个数 αp\alpha_{p}αp​。

说明

为什么是自由阿贝尔群：我们要「带符号地相加」一条链里的单纯形——把 σ\sigmaσ 加三次就是 3σ3\sigma3σ，把它和它的反向抵消就是 000，而且不允许任何别的等式成立。自由阿贝尔群正是「基上随心所欲相加、不加额外关系」的最小结构。

⚠️ 自由度恰好够用：因为群同态只要在基上规定就唯一确定了，所以之后定义边缘算子时只需对单个单纯形写出公式、再线性延拓，不必验证任何相容性。这是「自由」这个词的全部用处。

系数换了也要一套理论：系数取 Q\mathbb{Q}Q 或 R\mathbb{R}R 时得到 Betti 数（看不见挠部），取 Z/2\mathbb{Z}/2Z/2 时符号 (−1)i(-1)^{i}(−1)i 全部消失（不必担心定向）。本团固定系数 Z\mathbb{Z}Z。

💡 直观：Cp(K)C_{p}(K)Cp​(K) 就是「ppp 维碎片的整系数账本」。同调要做的事是问：这些账目里，哪些是真正的「洞」，哪些只是某个更高维东西的影子（见 def.simplicial-homology）。

    两次秩-零化度，边缘群的维数在交错和里相消

    设 KKK 有限，αp=dim⁡QCp\alpha_{p} = \dim_{\mathbb{Q}} C_{p}αp​=dimQ​Cp​（即 ppp-单纯形个数），zp=rank⁡Zpz_{p} = \operatorname{rank} Z_{p}zp​=rankZp​、bp=rank⁡Bp=rank⁡∂p+1b_{p} = \operatorname{rank} B_{p} = \operatorname{rank}\partial_{p+1}bp​=rankBp​=rank∂p+1​、hp=rank⁡Hph_{p} = \operatorname{rank} H_{p}hp​=rankHp​。这些数都有限（Z\mathbb{Z}Z 是主理想整环，子模自由）。

    第一次秩-零化度（对 ∂p:Cp→Cp−1\partial_{p} : C_{p} \to C_{p-1}∂p​:Cp​→Cp−1​）：

    αp=dim⁡ker⁡∂p+rank⁡∂p=zp+bp−1.\alpha_{p} = \dim\ker\partial_{p} + \operatorname{rank}\partial_{p} = z_{p} + b_{p-1}.αp​=dimker∂p​+rank∂p​=zp​+bp−1​.

    第二次（用在 0→Zp→Cp→Bp−1→00 \to Z_{p} \to C_{p} \to B_{p-1} \to 00→Zp​→Cp​→Bp−1​→0 之后，或直接看商）：因为 Hp=Zp/BpH_{p} = Z_{p}/B_{p}Hp​=Zp​/Bp​，

    zp=bp+hp.z_{p} = b_{p} + h_{p}.zp​=bp​+hp​.

    ∑p(−1)pαp=∑p(−1)php+S1−S2,\sum_{p} (-1)^{p}\alpha_{p} = \sum_{p} (-1)^{p} h_{p} + S_{1} - S_{2},p∑​(−1)pαp​=p∑​(−1)php​+S1​−S2​,
