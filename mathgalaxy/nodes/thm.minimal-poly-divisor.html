陈述

设 dim⁡V=n<∞\dim V = n < \inftydimV=n<∞，T:V→VT : V \to VT:V→V。则

  • μT∣χT\mu_T \mid \chi_TμT​∣χT​（极小多项式整除特征多项式）；特别地 deg⁡μT≤n\deg \mu_T \le ndegμT​≤n；
  • μT\mu_TμT​ 与 χT\chi_TχT​ 在 KKK 的代数闭包中有完全相同的根（即相同的特征值集合）；
  • 因此 TTT 可对角化（在代数闭包上看）  ⟺  \iff⟺ μT\mu_TμT​ 无重根。

说明

⭐ 三条里的第一条是 Cayley–Hamilton + 理想性的直接后果：χT∈IT=(μT)\chi_T \in I_T = (\mu_T)χT​∈IT​=(μT​)。

⭐ 第二条（同根）的证明值得记住：若 λ\lambdaλ 是特征值、vvv 是特征向量，则 μT(T)v=μT(λ)v\mu_T(T)v = \mu_T(\lambda) vμT​(T)v=μT​(λ)v，而 μT(T)=0\mu_T(T) = 0μT​(T)=0、v≠0v \ne 0v=0，故 μT(λ)=0\mu_T(\lambda) = 0μT​(λ)=0；反向由 μT∣χT\mu_T \mid \chi_TμT​∣χT​ 得到。

⚠ 第三个断言的「在代数闭包上看」不能省：μT\mu_TμT​ 是否无重根要到扩域里判（R\mathbb{R}R 上的旋转：μT=x2+1\mu_T = x^{2} + 1μT​=x2+1 无重根，在 C\mathbb{C}C 上可对角化，在 R\mathbb{R}R 上不能）。

  • Cayley–Hamilton 定理、极小多项式 ⟹ 本页推出
    Cayley–Hamilton   ⟹  μT∣χT\implies \mu_T \mid \chi_T⟹μT​∣χT​ 且同根
    1. 整除：由 Cayley–Hamilton，χT(T)=0\chi_T(T) = 0χT​(T)=0，即 χT∈IT=(μT)\chi_T \in I_T = (\mu_T)χT​∈IT​=(μT​)，故 μT∣χT\mu_T \mid \chi_TμT​∣χT​。由此 deg⁡μT≤deg⁡χT=n\deg \mu_T \le \deg \chi_T = ndegμT​≤degχT​=n。
    2. χT\chi_TχT​ 的根都是 μT\mu_TμT​ 的根：由第 1 步与「μT\mu_TμT​ 非零」得 μT∣χT\mu_T \mid \chi_TμT​∣χT​，故 χT\chi_TχT​ 的每个根也是 μT\mu_TμT​ 的根。
    3. μT\mu_TμT​ 的根都是 χT\chi_TχT​ 的根：设 μT(λ)=0\mu_T(\lambda) = 0μT​(λ)=0。由 μT≠0\mu_T \ne 0μT​=0 且 μT∣χT\mu_T \mid \chi_TμT​∣χT​，把 μT\mu_TμT​ 在 KKK 的代数闭包中分解为 ∏(x−λj)ej\prod (x - \lambda_j)^{e_j}∏(x−λj​)ej​；对每个 jjj 取非零向量 vj∈ker⁡(T−λjI)ejv_j \in \ker(T - \lambda_j I)^{e_j}vj​∈ker(T−λj​I)ej​（由第 4 步非零），则 v:=vjv := v_jv:=vj​ 满足 μT(T)v=0\mu_T(T) v = 0μT​(T)v=0。若 λj\lambda_jλj​ 不是特征值，则 T−λjIT - \lambda_j IT−λj​I 可逆，于是 (T−λjI)ej(T - \lambda_j I)^{e_j}(T−λj​I)ej​ 可逆，ker⁡={0}\ker = \{0\}ker={0}，矛盾。故每个 λj\lambda_jλj​ 都是特征值，即 χT(λj)=0\chi_T(\lambda_j) = 0χT​(λj​)=0。
    4. 每个 ker⁡(T−λjI)ej≠{0}\ker (T - \lambda_j I)^{e_j} \ne \{0\}ker(T−λj​I)ej​={0}：若全为零，则 μT\mu_TμT​ 的每个因子都可逆、乘积可逆，而 μT(T)=0\mu_T(T) = 0μT​(T)=0 与可逆性矛盾（n≥1n \ge 1n≥1 时 V≠0V \ne 0V=0）。

    于是两者的根集合相同。∎

    第 3、4 步合起来是一个双向夹逼：既要说明 μT\mu_TμT​ 的根一定是特征值，也要先证明那些核非零 —— 后者看起来显然，其实是「μT(T)=0\mu_T(T) = 0μT​(T)=0 而 TTT 非平凡」的推论。
