# category of vector spaces　`def.category-of-vector-spaces`
English entry · root `../`
[in graph](../#n=def.category-of-vector-spaces)　·　[Chinese page (authoritative)](./def.category-of-vector-spaces.md)

**Forgetting structure**: the forgetful functor $\mathbf{Vect}_K\to\mathbf{Set}$ forgets addition and scalar multiplication, retaining only the underlying sets and functions; it is faithful but not full (not every function is linear).

**Relation to additive categories**: each Hom-set is itself a vector space and composition is bilinear; finite direct sums coincide with finite products, so it is an additive category, hence a preabelian category (kernels and cokernels are taken pointwise).
