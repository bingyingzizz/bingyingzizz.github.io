# One-Point Compactification　`def.one-point-compactification`
English entry · root `../`
[in graph](../#n=def.one-point-compactification)　·　[Chinese page (authoritative)](./def.one-point-compactification.md)

- **$X^{*}$ is compact: no hypothesis is needed.** Take any open cover of $X^{*}$; some member contains $\infty$ (call it $U\cup\{\infty\}$), so $X\setminus U$ is compact; it is covered by the remaining open sets, and compactness gives a finite subcover, which together with $U\cup\{\infty\}$ itself gives a finite subcover. The whole argument uses only "an open cover of a compact set has a finite subcover", **not Hausdorff, not local compactness**.
- **$X^{*}$ is Hausdorff $\iff$ $X$ is locally compact Hausdorff**: both directions cost something.
