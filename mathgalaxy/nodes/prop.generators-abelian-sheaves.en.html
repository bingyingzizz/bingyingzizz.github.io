Statement

Let T\mathcal{T}T be a topos and SSS a set of generators for it. Then

{ Z⋅X : X∈S }\bigl\{\ \mathbb{Z}\cdot X \ :\ X \in S\ \bigr\}{ Z⋅X : X∈S }

is a set of generators for T(Ab)\mathcal{T}(\mathbf{Ab})T(Ab).

Notes

Proof. By the universal property of free objects, Hom⁡Z(Z⋅X,M)=M(X)=Hom⁡(X,M)\operatorname{Hom}_{\mathbb{Z}}(\mathbb{Z}\cdot X, M) = M(X) = \operatorname{Hom}(X, M)HomZ​(Z⋅X,M)=M(X)=Hom(X,M) ✓ — hence "detecting morphisms using Z⋅X\mathbb{Z}\cdot XZ⋅X" and "detecting morphisms using XXX" are the same thing ✓.

That SSS generates T\mathcal{T}T shows the latter is sufficient, so the former is sufficient too ✓.
