# six functor formalism　`def.six-functors`
English entry · root `../`
[in graph](../#n=def.six-functors)　·　[Chinese page (authoritative)](./def.six-functors.md)

That is six functors: $\otimes,\ \operatorname{Hom},\ f^*,\ f_*,\ f_!,\ f^!$. They should satisfy:

**(i)** $f$ proper $\implies f_! = f_*$; **(ii)** $f$ étale $\implies f^! = f^*$;

**(iii) Verdier duality**: $f_* \operatorname{Hom}_X(A, f^!B) \cong \operatorname{Hom}_Y(f_!A, B)$;

**(iv) projection formula**: $f_!(A \otimes_X f^*B) \cong f_!A \otimes_Y B$;

**(v) proper base change**: in a pullback square $g^* f_! \cong f'_! g'^*$;

**(vi) Poincaré duality**: for smooth $f$ the map $f^!\mathbf{1}_Y \otimes_X f^*B \to f^!B$ is an isomorphism and $f^!\mathbf{1}_Y$ is invertible.
