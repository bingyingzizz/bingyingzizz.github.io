## 陈述（续）
- **面映射** $\delta^{i} : [n-1] \to [n]$：跳过 $i$（$i = 0, \ldots, n$），不取 $i$ 的保序单射；
- **退化映射** $\sigma^{i} : [n+1] \to [n]$：把 $i$ 与 $i+1$ 撞在一起（$i = 0, \ldots, n$），保序满射。
