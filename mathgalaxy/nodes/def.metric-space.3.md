## English abstract · reviewed by bingyingzizz (2026-10-16) · Chinese is authoritative（续）
A metric space is a pair $(X, d)$ with $d : X \times X \to [0, +\infty)$ satisfying $d(x,y) = 0 \iff x = y$, symmetry and the triangle inequality; open balls $B(x,r) = \{y : d(x,y) < r\}$ generate a topology, and they form a base for it. The point of the definition here is the split that follows: compactness and closedness use only the open sets, while completeness and total boundedness use $d$. Completeness is genuinely not topological — $\mathbb{R}$ and $(0,1)$ are homeomorphic but only the first is complete.
