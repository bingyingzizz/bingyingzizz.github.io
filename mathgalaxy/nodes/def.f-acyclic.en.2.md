## Notes · **draft**
**Why it matters**: $F$-acyclic objects **may be used for resolutions** — when computing $RF$ one need not use only injective objects; acyclic objects are legitimate (this is what the next Leray acyclicity statement says).

**Examples**: injective objects are of course acyclic ($RF$ is defined using them); flat modules are acyclic for $M \otimes_{A} -$; **condensed abelian groups on a Stonean space** are acyclic for the section functor — that is exactly the beginning of §8.
