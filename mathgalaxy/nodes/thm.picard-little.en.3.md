# little Picard theorem　`thm.picard-little`
English entry · root `../`
[in graph](../#n=thm.picard-little)　·　[Chinese page (authoritative)](./thm.picard-little.md)

if $1$ is omitted, then $e^{P} - 1$ has no zeros $\implies$ it also has a factorization $\implies$; comparing growth orders successively forces $P$ to be constant, contradicting that $f$ is nonconstant.

⚠️ **The general case requires Bloch's theorem or the modular function $\lambda$** (the universal cover from the upper half-plane onto $\mathbb{C}\setminus\{0,1\}$); this graph has neither, so it is recorded as an **external input**. This is stated honestly in the node; it does not pretend to be a complete proof.
