整环 AAA 叫 Bézout 整环，若每个有限生成理想都是主理想 —— 等价地：任意 a,b∈Aa, b \in Aa,b∈A 存在 d,u,vd, u, vd,u,v 使

ua+vb=d=gcd⁡(a,b).u a + v b = d = \gcd(a, b) .ua+vb=d=gcd(a,b).

说明

PID   ⟹  \implies⟹ Bézout（所有理想都是主理想，当然包括有限生成的），反之不然：Bézout 整环未必 Noether，可能有非有限生成的理想。

Z[x]\mathbb{Z}[x]Z[x] 不是 Bézout：gcd⁡(2,x)=1\gcd(2, x) = 1gcd(2,x)=1，但 2u+xv=12u + xv = 12u+xv=1 无解（代 x=0x = 0x=0 得 2u(0)=12u(0) = 12u(0)=1）—— 所以「Bézout 性质」强于 gcd 整环。

Bézout 整环里「不可约 = 素」（因为 gcd⁡\gcdgcd 由线性组合给出，Euclid 引理的证明可以直接搬过来）。
