陈述

设 MMM 是 RRR-模，另有两条短正合列

0→K→P→ π M→0,0→K1→P1→ π1 M→0,0 \to K \to P \xrightarrow{\ \pi\ } M \to 0, \qquad 0 \to K_{1} \to P_{1} \xrightarrow{\ \pi_{1}\ } M \to 0,0→K→P π ​M→0,0→K1​→P1​ π1​ ​M→0,

其中 P,P1P, P_{1}P,P1​ 都投射。则

P1⊕K  ≅  P⊕K1.P_{1} \oplus K \;\cong\; P \oplus K_{1} .P1​⊕K≅P⊕K1​.

也就是说：两条「MMM 的投射预覆盖」各自的核，可以互相补偿成同一个模。

说明

证明（纤维积一次搞定）。 令 XXX 是 π\piπ 与 π1\pi_{1}π1​ 的纤维积（拉回）

X:={ (x,x1)∈P⊕P1:π(x)=π1(x1) }.X := \{\, (x, x_{1}) \in P \oplus P_{1} : \pi(x) = \pi_{1}(x_{1}) \,\}.X:={(x,x1​)∈P⊕P1​:π(x)=π1​(x1​)}.

两个投影给出交换图，而 π1\pi_{1}π1​ 满、π\piπ 满分别是「X→PX \to PX→P 满」与「X→P1X \to P_{1}X→P1​ 满」的原因 ✓。逐条读核：

  • ker⁡(X→P1)={ (x,0):π(x)=0 }=K\ker(X \to P_{1}) = \{\, (x, 0) : \pi(x) = 0 \,\} = Kker(X→P1​)={(x,0):π(x)=0}=K ✓；
  • ker⁡(X→P)={ (0,x1):π1(x1)=0 }=K1\ker(X \to P) = \{\, (0, x_{1}) : \pi_{1}(x_{1}) = 0 \,\} = K_{1}ker(X→P)={(0,x1​):π1​(x1​)=0}=K1​ ✓。

于是得到两条短正合列 0→K→X→P1→00 \to K \to X \to P_{1} \to 00→K→X→P1​→0 与 0→K1→X→P→00 \to K_{1} \to X \to P \to 00→K1​→X→P→0。第一条分裂：P1P_{1}P1​ 投射，故 X→P1X \to P_{1}X→P1​ 有截面，于是 X≅P1⊕KX \cong P_{1}\oplus KX≅P1​⊕K ✓。第二条也分裂（PPP 投射），于是 X≅P⊕K1X \cong P\oplus K_{1}X≅P⊕K1​ ✓。两者一比即得 P1⊕K≅P⊕K1P_{1}\oplus K \cong P\oplus K_{1}P1​⊕K≅P⊕K1​ ✓。∎

⭐ 它说的是「合冲只差一个投射直和项」，而且两条预覆盖的中间项都必须是投射的才有这个结论 —— 这也是为什么「投射」在合冲的整套叙述里反复出现：它是唯一让「分裂」生效的假设。

⚠️ 结论是直和同构，不是同构：KKK 与 K1K_{1}K1​ 一般不同构。要「取掉」这个自由度，就得在稳定范畴里工作 —— 把相差投射直和项的对象等同起来。

名字：这叫 Schanuel 引理，最早出现在 Schanuel 的讲义里（未发表），经 Rotman、Cartan–Eilenberg 等书传播。
