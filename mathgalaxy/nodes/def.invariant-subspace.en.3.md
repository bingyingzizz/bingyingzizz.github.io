# invariant subspace　`def.invariant-subspace`
English entry · root `../`
[in graph](../#n=def.invariant-subspace)　·　[Chinese page (authoritative)](./def.invariant-subspace.md)

⚠ Note that $T$-invariance is not the same as "the image of $T$": invariance only requires $T(U) \subseteq U$, not equality.

Every subspace with $\ker T \subseteq U$ — that is, every such $U$ — is automatically invariant.
