# 像与原像　`def.preimage`
像与原像（Image / Preimage）
layer 6 · 定义 · 关系与函数 · 集合论+分析学
[在星图里打开](../#n=def.preimage)　·　[节点索引](../index.md)

设 $f : X \to Y$ 是映射。

- 对 $A \subseteq X$，$A$ 的**像**是 $f(A) := \{\, f(x) : x \in A \,\} \subseteq Y$；
- 对 $B \subseteq Y$，$B$ 的**原像**是 $f^{-1}(B) := \{\, x \in X : f(x) \in B \,\} \subseteq X$。
