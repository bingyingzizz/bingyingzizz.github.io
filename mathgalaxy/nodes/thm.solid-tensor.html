thm.solid-tensor · 定理 · 固态 · 张量积

又称固态张量积

陈述

(i) Solid\mathbf{Solid}Solid 上有唯一的对称幺半张量积 ⊗■\otimes^{\blacksquare}⊗■，使固态化函子 M↦M■M \mapsto M^{\blacksquare}M↦M■ 对称幺半；具体地

M⊗■N:=(M⊗N)■.M \otimes^{\blacksquare} N := (M \otimes N)^{\blacksquare}.M⊗■N:=(M⊗N)■.

(ii) D(Solid)D(\mathbf{Solid})D(Solid) 上有唯一的对称幺半结构 ⊗L■\otimes^{L\blacksquare}⊗L■，使 C↦CL■C \mapsto C^{L\blacksquare}C↦CL■ 对称幺半；它是 ⊗■\otimes^{\blacksquare}⊗■ 的左导出。

说明

⭐ 这是整套理论要造的那个东西：一个能和「补全」相容的张量积。对照：经典的 Zp⊗^R\mathbb{Z}_p \hat\otimes \mathbb{R}Zp​⊗^​R 没有好定义，而 Zp⊗L■R=0\mathbb{Z}_p \otimes^{L\blacksquare} \mathbb{R} = 0Zp​⊗L■R=0（见 ex.solid-tensor-computations）。

⚠ 唯一性来自「保余极限的函子由自由对象上的值决定」；存在性要验证 (M⊗N)■→(M■⊗N■)■(M \otimes N)^{\blacksquare} \to (M^{\blacksquare} \otimes N^{\blacksquare})^{\blacksquare}(M⊗N)■→(M■⊗N■)■ 是同构，归约到 M=Z[S]M = \mathbb{Z}[S]M=Z[S]、N=Z[T]N = \mathbb{Z}[T]N=Z[T] 后用 cor.solid-compact-generators 的 (iv) 型计算。

    把 M′M'M′、N′N'N′ 分别写成 C(S,Z)C(S,\mathbb{Z})C(S,Z)、C(T,Z)C(T,\mathbb{Z})C(T,Z) 的收缩（thm.csz-free），归约到 M′=C(S,Z)M' = C(S,\mathbb{Z})M′=C(S,Z)、N′=C(T,Z)N' = C(T,\mathbb{Z})N′=C(T,Z)。此时 M′⊗N′=C(S×T,Z)M' \otimes N' = C(S \times T,\mathbb{Z})M′⊗N′=C(S×T,Z)，命题变成

    Z[S]■⊗L■Z[T]■≅Z[S×T]■,Z[S]^{\blacksquare} \otimes^{L\blacksquare} Z[T]^{\blacksquare} \cong Z[S \times T]^{\blacksquare},Z[S]■⊗L■Z[T]■≅Z[S×T]■,

    即 thm.solid-tensor 的幺半性。■\blacksquare■

    紧投射对象上的计算   ⟹  \implies⟹ 对称幺半张量积

    唯一性。 保余极限的函子由紧投射生成元上的值决定，所以 ⊗■\otimes^{\blacksquare}⊗■ 若存在必唯一。

    存在性（对象层）。 定义 M⊗■N:=(M⊗N)■M \otimes^{\blacksquare} N := (M \otimes N)^{\blacksquare}M⊗■N:=(M⊗N)■。要证 M↦M■M \mapsto M^{\blacksquare}M↦M■ 对称幺半，即

    (M⊗N)■⟶(M■⊗N■)■(M \otimes N)^{\blacksquare} \longrightarrow (M^{\blacksquare} \otimes N^{\blacksquare})^{\blacksquare}(M⊗N)■⟶(M■⊗N■)■

    是同构。两边都保余极限，归约到 M=Z[S]M = \mathbb{Z}[S]M=Z[S]、N=Z[T]N = \mathbb{Z}[T]N=Z[T]；再用 cor.solid-compact-generators (iv) 的对偶计算，把两边分别算成 Z[S×T]■Z[S \times T]^{\blacksquare}Z[S×T]■。

    导出层。 同样的论证给出 ⊗L■\otimes^{L\blacksquare}⊗L■；它是左导出，因为两个紧投射对象的张量仍集中在度 000（Z[S]■⊗L■Z[T]■=Z[S×T]■Z[S]^{\blacksquare} \otimes^{L\blacksquare} Z[T]^{\blacksquare} = Z[S \times T]^{\blacksquare}Z[S]■⊗L■Z[T]■=Z[S×T]■）。■\blacksquare■
