陈述

在做什么：Rn\mathbb{R}^{n}Rn 上的 d\mathrm{d}d 是按坐标公式写的，搬到流形上必须回答一句「换一张图卡算出来的 dω\mathrm{d}\omegadω 是不是同一个」。这一条把它钉死，于是 d\mathrm{d}d 可以整体地写在流形上。

设 MMM 是光滑流形。存在唯一的一族算子 d:Ωk(M)→Ωk+1(M)\mathrm{d} : \Omega^{k}(M)\to\Omega^{k+1}(M)d:Ωk(M)→Ωk+1(M)（k≥0k\ge 0k≥0）使

  1. df\mathrm{d}fdf 就是 fff 的微分：dfp(v)=v(f)\mathrm{d}f_{p}(v) = v(f)dfp​(v)=v(f) 对 v∈TpMv\in T_{p}Mv∈Tp​M；
  2. d\mathrm{d}d 是 R\mathbb{R}R-线性的；
  3. 反导子：ω\omegaω 是 kkk-形式时 d(ω∧τ)=dω∧τ+(−1)kω∧dτ\mathrm{d}(\omega\wedge\tau) = \mathrm{d}\omega\wedge\tau + (-1)^{k}\omega\wedge\mathrm{d}\taud(ω∧τ)=dω∧τ+(−1)kω∧dτ；
  4. d2=0\mathrm{d}^{2} = 0d2=0。

并且它在任意图卡 (U,x)(U,x)(U,x) 上就等于坐标公式

d(∑IaI dxI)=∑IdaI∧dxI,\mathrm{d}\Bigl(\sum_{I}a_{I}\,\mathrm{d}x^{I}\Bigr) = \sum_{I}\mathrm{d}a_{I}\wedge\mathrm{d}x^{I},d(I∑​aI​dxI)=I∑​daI​∧dxI,

其中 dxI:=dxi1∧⋯∧dxik\mathrm{d}x^{I} := \mathrm{d}x^{i_{1}}\wedge\cdots\wedge\mathrm{d}x^{i_{k}}dxI:=dxi1​∧⋯∧dxik​，而 daI\mathrm{d}a_{I}daI​ 是函数 aIa_{I}aI​ 的微分。于是「d\mathrm{d}d 与图卡无关」不是额外假设，而是这条命题的结论。

说明

证明的两半：存在性 = 「图卡上按公式定义 + 重叠处一致 + 用单位分解拼成整体」；唯一性 = 「局部公式 + 反导子公理 + d2=0\mathrm{d}^{2}=0d2=0」。骨架在边上，⚠️ 收尾那一步（单位分解的拼接为什么只有有限项、为什么拼出来的东西仍满足 (3)(4)）只给到提纲。

这是 Tu 的处理顺序：先有开集上的坐标公式（def.exterior-derivative），再用「与拉回交换」（prop.pullback-forms 的第 3 条）证明图卡无关。也可以反过来把「与拉回交换」当公理（一堆教材这么做），但那样就得另证存在性，且难以看出 d\mathrm{d}d 为什么长这样。

⭐ 有了这一条，def.de-rham-complex 里那串 Ωk(M)→ d Ωk+1(M)\Omega^{k}(M)\xrightarrow{\ \mathrm{d}\ }\Omega^{k+1}(M)Ωk(M) d ​Ωk+1(M) 才真的是一串映射 —— 在这条之前，那串东西只是记号。

⚠️ 顺带钉住一个常见误解：d\mathrm{d}d 不依赖度量，也不依赖联络。它是光滑结构本身给出的算子；联络（def.affine-connection）与它无关，两者能凑出公式纯属巧合之外的对称性。

Statement reviewed

What it does: the operator d\mathrm{d}d on Rn\mathbb{R}^{n}Rn is written by a coordinate formula; carried to a manifold it must answer one question — is dω\mathrm{d}\omegadω computed in one chart the same object as in another? This proposition settles it, and then d\mathrm{d}d can be written globally on a manifold.

Let MMM be a smooth manifold. There is a unique family of operators d:Ωk(M)→Ωk+1(M)\mathrm{d} : \Omega^{k}(M)\to\Omega^{k+1}(M)d:Ωk(M)→Ωk+1(M) for k≥0k\ge 0k≥0 such that

  1. df\mathrm{d}fdf is the differential of fff: dfp(v)=v(f)\mathrm{d}f_{p}(v) = v(f)dfp​(v)=v(f) for v∈TpMv\in T_{p}Mv∈Tp​M;
  2. d\mathrm{d}d is R\mathbb{R}R-linear;
  3. anti-derivation: for a kkk-form ω\omegaω, d(ω∧τ)=dω∧τ+(−1)kω∧dτ\mathrm{d}(\omega\wedge\tau) = \mathrm{d}\omega\wedge\tau + (-1)^{k}\omega\wedge\mathrm{d}\taud(ω∧τ)=dω∧τ+(−1)kω∧dτ;
  4. d2=0\mathrm{d}^{2} = 0d2=0.

Moreover, in any chart (U,x)(U,x)(U,x) it equals the coordinate formula

d(∑IaI dxI)=∑IdaI∧dxI,\mathrm{d}\Bigl(\sum_{I}a_{I}\,\mathrm{d}x^{I}\Bigr) = \sum_{I}\mathrm{d}a_{I}\wedge\mathrm{d}x^{I},d(I∑​aI​dxI)=I∑​daI​∧dxI,

where dxI:=dxi1∧⋯∧dxik\mathrm{d}x^{I} := \mathrm{d}x^{i_{1}}\wedge\cdots\wedge\mathrm{d}x^{i_{k}}dxI:=dxi1​∧⋯∧dxik​ and daI\mathrm{d}a_{I}daI​ is the differential of the function aIa_{I}aI​. Hence "d\mathrm{d}d does not depend on the chart" is not an extra assumption, but the conclusion of this proposition.
