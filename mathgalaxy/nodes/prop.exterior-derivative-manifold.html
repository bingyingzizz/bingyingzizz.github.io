陈述

在做什么：Rn\mathbb{R}^{n}Rn 上的 d\mathrm{d}d 是按坐标公式写的，搬到流形上必须回答一句「换一张图卡算出来的 dω\mathrm{d}\omegadω 是不是同一个」。这一条把它钉死，于是 d\mathrm{d}d 可以整体地写在流形上。

设 MMM 是光滑流形。存在唯一的一族算子 d:Ωk(M)→Ωk+1(M)\mathrm{d} : \Omega^{k}(M)\to\Omega^{k+1}(M)d:Ωk(M)→Ωk+1(M)（k≥0k\ge 0k≥0）使

  1. 在函数上 df\mathrm{d}fdf 就是 fff 的微分：dfp(v)=v(f)\mathrm{d}f_{p}(v) = v(f)dfp​(v)=v(f) 对 v∈TpMv\in T_{p}Mv∈Tp​M；
  2. d\mathrm{d}d 是 R\mathbb{R}R-线性的；
  3. 反导子：ω\omegaω 是 kkk-形式时 d(ω∧τ)=dω∧τ+(−1)kω∧dτ\mathrm{d}(\omega\wedge\tau) = \mathrm{d}\omega\wedge\tau + (-1)^{k}\omega\wedge\mathrm{d}\taud(ω∧τ)=dω∧τ+(−1)kω∧dτ；
  4. d2=0\mathrm{d}^{2} = 0d2=0。

并且它在任意图卡 (U,x)(U,x)(U,x) 上就等于坐标公式

d(∑IaI dxI)=∑IdaI∧dxI,\mathrm{d}\Bigl(\sum_{I}a_{I}\,\mathrm{d}x^{I}\Bigr) = \sum_{I}\mathrm{d}a_{I}\wedge\mathrm{d}x^{I},d(I∑​aI​dxI)=I∑​daI​∧dxI,

其中 dxI:=dxi1∧⋯∧dxik\mathrm{d}x^{I} := \mathrm{d}x^{i_{1}}\wedge\cdots\wedge\mathrm{d}x^{i_{k}}dxI:=dxi1​∧⋯∧dxik​，而 daI\mathrm{d}a_{I}daI​ 是函数 aIa_{I}aI​ 的微分。于是「d\mathrm{d}d 与图卡无关」不是额外假设，而是这条命题的结论。

说明

证明策略：先在一个图卡内证明「坐标公式满足四条公理」，再证明「满足四条公理的算子被坐标公式唯一决定」；最后由「图卡重叠处两个公式都是满足公理的算子」推出它们一致，把局部公式拼成整体。关键点：不需要单位分解 —— 单位分解是给「局部数据在重叠处不一致」的场合用的，这里局部公式在重叠处自动一致。

引理 A（图卡内唯一性）：设 U⊆RnU \subseteq \mathbb{R}^{n}U⊆Rn 是开集，DDD 是 Ω∙(U)\Omega^{\bullet}(U)Ω∙(U) 上满足 (1)–(4) 的算子。则对 ω=∑IaI dxI\omega = \sum_{I} a_{I}\,\mathrm{d}x^{I}ω=∑I​aI​dxI 有 Dω=∑IdaI∧dxID\omega = \sum_{I}\mathrm{d}a_{I}\wedge\mathrm{d}x^{I}Dω=∑I​daI​∧dxI。证明：000-形式由 (1) 直接给出。看单项 a dxIa\,\mathrm{d}x^{I}adxI，I=(i1<⋯<ik)I = (i_{1} < \cdots < i_{k})I=(i1​<⋯<ik​)：dxi=d(xi)\mathrm{d}x^{i} = \mathrm{d}(x^{i})dxi=d(xi)（对坐标函数用 (1)），由 (4) 得 D(dxi)=D2(xi)=0D(\mathrm{d}x^{i}) = D^{2}(x^{i}) = 0D(dxi)=D2(xi)=0；再由 (3) 归纳得 D(dxI)=0D(\mathrm{d}x^{I}) = 0D(dxI)=0。于是 D(a dxI)=da∧dxI+a D(dxI)=da∧dxID(a\,\mathrm{d}x^{I}) = \mathrm{d}a\wedge\mathrm{d}x^{I} + a\,D(\mathrm{d}x^{I}) = \mathrm{d}a\wedge\mathrm{d}x^{I}D(adxI)=da∧dxI+aD(dxI)=da∧dxI；由 (2) 线性拼起来即得。□\square□

引理 B（坐标公式满足公理）：在 UUU 上定义 D(∑IaI dxI):=∑IdaI∧dxID(\sum_{I} a_{I}\,\mathrm{d}x^{I}) := \sum_{I}\mathrm{d}a_{I}\wedge\mathrm{d}x^{I}D(∑I​aI​dxI):=∑I​daI​∧dxI。证明：(2) 显然。(1)：Df=∑i∂if dxiDf = \sum_{i}\partial_{i}f\,\mathrm{d}x^{i}Df=∑i​∂i​fdxi，这正是 fff 的微分（dfp(v)=v(f)\mathrm{d}f_{p}(v) = v(f)dfp​(v)=v(f)）。(3)：只需对单项 a dxIa\,\mathrm{d}x^{I}adxI 与 b dxJb\,\mathrm{d}x^{J}bdxJ 验，D(ab dxI∧dxJ)=(b da+a db)∧dxI∧dxJ=(da∧dxI)∧(b dxJ)+(−1)ka dxI∧(db∧dxJ),D(ab\,\mathrm{d}x^{I}\wedge\mathrm{d}x^{J}) = (b\,\mathrm{d}a + a\,\mathrm{d}b)\wedge\mathrm{d}x^{I}\wedge\mathrm{d}x^{J} = (\mathrm{d}a\wedge\mathrm{d}x^{I})\wedge(b\,\mathrm{d}x^{J}) + (-1)^{k}a\,\mathrm{d}x^{I}\wedge(\mathrm{d}b\wedge\mathrm{d}x^{J}),D(abdxI∧dxJ)=(bda+adb)∧dxI∧dxJ=(da∧dxI)∧(bdxJ)+(−1)kadxI∧(db∧dxJ), 中间用了 dxI∧db=(−1)kdb∧dxI\mathrm{d}x^{I}\wedge\mathrm{d}b = (-1)^{k}\mathrm{d}b\wedge\mathrm{d}x^{I}dxI∧db=(−1)kdb∧dxI。(4)：先看函数，D2f=∑iD(∂if)∧dxi=∑i,j∂j∂if dxj∧dxi=0D^{2}f = \sum_{i}D(\partial_{i}f)\wedge\mathrm{d}x^{i} = \sum_{i,j}\partial_{j}\partial_{i}f\,\mathrm{d}x^{j}\wedge\mathrm{d}x^{i} = 0D2f=∑i​D(∂i​f)∧dxi=∑i,j​∂j​∂i​fdxj∧dxi=0，因为 dxj∧dxi=−dxi∧dxj\mathrm{d}x^{j}\wedge\mathrm{d}x^{i} = -\mathrm{d}x^{i}\wedge\mathrm{d}x^{j}dxj∧dxi=−dxi∧dxj，而混合偏导 ∂j∂if=∂i∂jf\partial_{j}\partial_{i}f = \partial_{i}\partial_{j}f∂j​∂i​f=∂i​∂j​f（Clairaut）。再看单项 a dxIa\,\mathrm{d}x^{I}adxI：由 (3) 与已证的 D(dxI)=0D(\mathrm{d}x^{I}) = 0D(dxI)=0，D2(a dxI)=D(da∧dxI)=D2a∧dxI=0D^{2}(a\,\mathrm{d}x^{I}) = D(\mathrm{d}a\wedge\mathrm{d}x^{I}) = D^{2}a\wedge\mathrm{d}x^{I} = 0D2(adxI)=D(da∧dxI)=D2a∧dxI=0。□\square□

整体构造（存在性）：取 MMM 的图卡覆盖 {(Uα,xα)}\{(U_{\alpha}, x_{\alpha})\}{(Uα​,xα​)}。在每张图卡上用引理 B 定义算子 DαD_{\alpha}Dα​。若 Uα∩Uβ≠∅U_{\alpha}\cap U_{\beta}\ne\emptysetUα​∩Uβ​=∅，在重叠开集上 DαD_{\alpha}Dα​ 与 DβD_{\beta}Dβ​ 都满足 (1)–(4)；由引理 A（在 xαx_{\alpha}xα​ 坐标下）Dβ=DαD_{\beta} = D_{\alpha}Dβ​=Dα​。故所有 DαD_{\alpha}Dα​ 拼成一个整体算子 d\mathrm{d}d：对 ω∈Ωk(M)\omega\in\Omega^{k}(M)ω∈Ωk(M)，dω\mathrm{d}\omegadω 在 UαU_{\alpha}Uα​ 上定义为 Dα(ω∣Uα)D_{\alpha}(\omega|_{U_{\alpha}})Dα​(ω∣Uα​​)；重叠处一致，故良定义。(1)–(4) 都是局部性质，已逐图卡验证，故整体成立。

唯一性：设 d′\mathrm{d}^{\prime}d′ 是满足 (1)–(4) 的另一族算子。对任意图卡 (U,x)(U,x)(U,x)，d′\mathrm{d}^{\prime}d′ 限制在 UUU 上满足 (1)–(4)，由引理 A 它等于坐标公式，即等于 d\mathrm{d}d。UUU 任意，故 d′=d\mathrm{d}^{\prime} = \mathrm{d}d′=d。∎

「与图卡无关」到底指什么：第 4 步说明换图卡算出的两个公式在重叠处相等 —— 因为它们都是满足公理的算子，而引理 A 说这样的算子只有一个。真正把 d\mathrm{d}d 钉死的是 (3)+(4)：(1) 给函数上的值，(3) 让 d\mathrm{d}d 穿过楔积，(4) 杀掉 dxI\mathrm{d}x^{I}dxI 的导数。

与 Tu 的路线对照：Tu 先用 拉回（开集间） 的第 3 条（与拉回交换）证图卡无关；这里改用「公理唯一性」证。两条路线都对，且都不需要单位分解 —— 这也说明光滑单位分解在本条里不是必需品。

⭐ 有了这一条，de Rham 上同调 里那串 Ωk(M)→ d Ωk+1(M)\Omega^{k}(M)\xrightarrow{\ \mathrm{d}\ }\Omega^{k+1}(M)Ωk(M) d ​Ωk+1(M) 才真的是一串映射 —— 在这条之前，那串东西只是记号。

⚠️ 顺带钉住一个常见误解：d\mathrm{d}d 不依赖度量，也不依赖联络。它是光滑结构本身给出的算子；联络（仿射联络）与它无关，两者能凑出公式纯属巧合之外的对称性。

⚠️ 本图缺的节点：d2=0\mathrm{d}^{2}=0d2=0 的函数情形用到了 Clairaut 定理（混合偏导对称），本图没有这个节点，故在此直接以经典微积分事实使用。

Statement reviewed

What it does: the operator d\mathrm{d}d on Rn\mathbb{R}^{n}Rn is written by a coordinate formula; carried to a manifold it must answer one question — is dω\mathrm{d}\omegadω computed in one chart the same object as in another? This proposition settles it, and then d\mathrm{d}d can be written globally on a manifold.

Let MMM be a smooth manifold. There is a unique family of operators d:Ωk(M)→Ωk+1(M)\mathrm{d} : \Omega^{k}(M)\to\Omega^{k+1}(M)d:Ωk(M)→Ωk+1(M) for k≥0k\ge 0k≥0 such that

  1. on functions df\mathrm{d}fdf is the differential of fff: dfp(v)=v(f)\mathrm{d}f_{p}(v) = v(f)dfp​(v)=v(f) for v∈TpMv\in T_{p}Mv∈Tp​M;
  2. d\mathrm{d}d is R\mathbb{R}R-linear;
  3. anti-derivation: for a kkk-form ω\omegaω, d(ω∧τ)=dω∧τ+(−1)kω∧dτ\mathrm{d}(\omega\wedge\tau) = \mathrm{d}\omega\wedge\tau + (-1)^{k}\omega\wedge\mathrm{d}\taud(ω∧τ)=dω∧τ+(−1)kω∧dτ;
  4. d2=0\mathrm{d}^{2} = 0d2=0.

Moreover, in any chart (U,x)(U,x)(U,x) it equals the coordinate formula

d(∑IaI dxI)=∑IdaI∧dxI,\mathrm{d}\Bigl(\sum_{I}a_{I}\,\mathrm{d}x^{I}\Bigr) = \sum_{I}\mathrm{d}a_{I}\wedge\mathrm{d}x^{I},d(I∑​aI​dxI)=I∑​daI​∧dxI,

where dxI:=dxi1∧⋯∧dxik\mathrm{d}x^{I} := \mathrm{d}x^{i_{1}}\wedge\cdots\wedge\mathrm{d}x^{i_{k}}dxI:=dxi1​∧⋯∧dxik​ and daI\mathrm{d}a_{I}daI​ is the differential of the function aIa_{I}aI​. Hence "d\mathrm{d}d does not depend on the chart" is not an extra assumption, but the conclusion of this proposition.
