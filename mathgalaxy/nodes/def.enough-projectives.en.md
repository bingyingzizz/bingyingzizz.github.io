## Statement · **draft**
A category $\mathcal{C}$ **has enough projectives** if for every $X \in \mathcal{C}$ there exist a projective object $P$ and an **epimorphism**

$$P \twoheadrightarrow X.$$

Dually: it **has enough injectives** if every $X$ embeds **monically** into some injective object $X \hookrightarrow I$.
