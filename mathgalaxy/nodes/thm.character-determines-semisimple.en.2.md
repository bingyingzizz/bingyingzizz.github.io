## Notes · **draft**
Write $W=\oplus n_iV_i$ with pairwise non-isomorphic irreducibles $V_i$. The partition-of-unity elements $a_i$ give $\chi_W(a_i)=n_i\dim V_i$, so the multiplicities $n_i$ are recovered from $\chi_W$; $\operatorname{char}F=0$ allows division by $\dim V_i$. Semisimplicity is essential: over $F[x]$ the identity and a Jordan block can have the same character without being isomorphic.
