# connected　`def.connected`
English entry · root `../`
[in graph](../#n=def.connected)　·　[Chinese page (authoritative)](./def.connected.md)

- connected $\iff$ **not expressible as the union of two disjoint non-empty open sets**: this is the definition.
- connected $\iff$ **no non-trivial clopen subsets**: $(\implies)$ use $V = X \setminus U$, which is closed; $(\Leftarrow)$ one line. **This step uses only the duality of open and closed sets**.
- connected $\iff$ **every continuous map $X \to \{0,1\}$ (discrete two points) is constant**: $(\implies)$ the image is connected and $\{0,1\}$ is not; $(\Leftarrow)$ apply the previous item to a characteristic function. This turns connectedness into "there is no surjection onto two points", the standard form in the internal language.
