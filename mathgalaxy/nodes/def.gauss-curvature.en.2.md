# Gaussian Curvature　`def.gauss-curvature`
English entry · root `../`
[in graph](../#n=def.gauss-curvature)　·　[Chinese page (authoritative)](./def.gauss-curvature.md)

$$K(p) = \frac{\langle R(\partial_{1},\partial_{2})\partial_{2},\partial_{1}\rangle}{\det(g_{ij})} = \frac{R_{1221}}{g_{11}g_{22}-g_{12}^{2}},$$

($1,2$ are local coordinate indices). In an orthonormal frame $e_{1},e_{2}$ it reduces to

$$K = \langle R(e_{1},e_{2})e_{2},e_{1}\rangle .$$

On the other hand, if $h_{ij}$ is the matrix of coefficients of the second fundamental form in the same frame, then $K = \det(h_{ij}) = k_{1}k_{2}$.
