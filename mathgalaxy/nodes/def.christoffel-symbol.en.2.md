# Christoffel Symbols　`def.christoffel-symbol`
English entry · root `../`
[in graph](../#n=def.christoffel-symbol)　·　[Chinese page (authoritative)](./def.christoffel-symbol.md)

Everything uses only the metric coefficients $g_{ij}$ and their first derivatives — so this is the first **intrinsic** object to appear.

Let $(x^{1},x^{2})$ be local coordinates on a surface $S$, let $g_{ij} = \langle \partial_{i},\partial_{j}\rangle$, and let $(g^{ij})$ be the inverse matrix of $(g_{ij})$. The **Christoffel symbols** are defined by

$$\Gamma^{k}_{ij} = \frac{1}{2}g^{k\ell}\left(\partial_{i}g_{j\ell}+\partial_{j}g_{i\ell}-\partial_{\ell}g_{ij}\right).$$
