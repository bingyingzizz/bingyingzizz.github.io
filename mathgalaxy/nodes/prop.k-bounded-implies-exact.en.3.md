# K-Bounded Exactness Implies Exactness　`prop.k-bounded-implies-exact`
English entry · root `../`
[in graph](../#n=prop.k-bounded-implies-exact)　·　[Chinese page (authoritative)](./prop.k-bounded-implies-exact.md)

**Proof (two steps).** At $M^{n}$, bounded exactness with bound $K$ gives, for each $\varepsilon > 0$, an element $s' \in M^{n+1}$ such that $\|s - d^{n+1}s'\| \le K\|d^{n}s\| + \varepsilon = \varepsilon$ (the last step uses $d^{n}s = 0$). Since $\varepsilon$ is arbitrary, $s$ lies in the **closure** of $\operatorname{im} d^{n+1}$.
