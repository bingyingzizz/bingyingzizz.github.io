# Terminal and Initial Objects　`def.final-initial`
English entry · root `../`
[in graph](../#n=def.final-initial)　·　[Chinese page (authoritative)](./def.final-initial.md)

$$\operatorname{Hom}_{\mathcal{C}}(X, \mathbf{1}_{\mathcal{C}}) = \{*\}, \qquad \operatorname{Hom}_{\mathcal{C}}(\mathbf{0}_{\mathcal{C}}, X) = \{*\}$$

(for every object $X$ there is exactly one morphism). When both exist and are isomorphic, the object is called a **zero object**.

## Notes · **draft**
Examples: in $\mathbf{Set}$, $\mathbf{0} = \emptyset$ (the only map into $X$ is the empty map) and $\mathbf{1} = \{\emptyset\}$ (the map into a singleton is unique). The same holds in $\mathbf{Top}$. In $\mathbf{Ab}$ both are $\{0\}$.
