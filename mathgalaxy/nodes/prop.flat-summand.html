平坦模的直和项平坦，直和平坦当且仅当每个平坦

prop.flat-summand · 命题 · 同调代数 · 平坦 · 直和 · 直和项

陈述

若 FFF 平坦且 MMM 是 FFF 的直和项（F≅M⊕M2F \cong M \oplus M_{2}F≅M⊕M2​），则 MMM 平坦。特别地：

  • 投射模平坦（投射 = 自由模的直和项，配合 prop.free-flat）；
  • 一族模的直和 ⨁iMi\bigoplus_{i} M_{i}⨁i​Mi​ 平坦，当且仅当每个 MiM_{i}Mi​ 平坦。

说明

证明：由「与直和交换」（prop.tensor-functor-properties），对每个 AAA 有自然同构

A⊗RF  ≅  (A⊗RM)⊕(A⊗RM2).A \otimes_{R} F \;\cong\; (A \otimes_{R} M) \oplus (A \otimes_{R} M_{2}).A⊗R​F≅(A⊗R​M)⊕(A⊗R​M2​).

若 MMM 与 M2M_{2}M2​ 平坦，右边正合，故左边正合 ✓。

反向：设 (−)⊗F(-) \otimes F(−)⊗F 正合，对 f:A→A1f : A \to A_{1}f:A→A1​ 看 f⊗Ff \otimes Ff⊗F 的对角块形式（两个块分别是 f⊗Mf \otimes Mf⊗M 与 f⊗M2f \otimes M_{2}f⊗M2​）。单射性逐分量判定，故 f⊗Mf \otimes Mf⊗M 单 ✓，MMM 平坦。

直和情形同理：(−)⊗⨁iMi≅⨁i((−)⊗Mi)(-) \otimes \bigoplus_{i} M_{i} \cong \bigoplus_{i} ((-) \otimes M_{i})(−)⊗⨁i​Mi​≅⨁i​((−)⊗Mi​) 正合当且仅当每个分量正合 ✓。∎

📌 注意方向：结论只对直和成立。直积没有「逐分量判定」这种便利 —— 张量不保积，所以平坦性对直积并不自动封闭（相干环才保证「平坦模的积仍平坦」）。

推出 1

  • 自由模平坦、分裂短正合列 ⟹ 本页推出
    直和的正合性   ⟹  \implies⟹ 直和项继承平坦

    设 F=M⊕M2F = M \oplus M_{2}F=M⊕M2​ 平坦。由「与直和交换」，对每个 AAA 有自然同构

    A⊗RF  ≅  (A⊗RM)⊕(A⊗RM2).A \otimes_{R} F \;\cong\; (A \otimes_{R} M) \oplus (A \otimes_{R} M_{2}).A⊗R​F≅(A⊗R​M)⊕(A⊗R​M2​).

    （⇐\Leftarrow⇐） 若 MMM 与 M2M_{2}M2​ 平坦，右边正合，故 (−)⊗F(-) \otimes F(−)⊗F 正合 ✓。

    （  ⟹  \implies⟹） 设 (−)⊗F(-) \otimes F(−)⊗F 正合。对任意 f:A→A1f : A \to A_{1}f:A→A1​，f⊗Ff \otimes Ff⊗F 在分解下是对角块 diag(f⊗M, f⊗M2)\mathrm{diag}(f \otimes M,\ f \otimes M_{2})diag(f⊗M, f⊗M2​)。若 x=(x1,x2)x = (x_{1}, x_{2})x=(x1​,x2​) 被送到零，则两块分别把 x1x_{1}x1​、x2x_{2}x2​ 送到零；单射性逐分量判定，故 f⊗Mf \otimes Mf⊗M 单 ✓，MMM 平坦。

    直和情形：(−)⊗⨁iMi≅⨁i((−)⊗Mi)(-) \otimes \bigoplus_{i} M_{i} \cong \bigoplus_{i} ((-) \otimes M_{i})(−)⊗⨁i​Mi​≅⨁i​((−)⊗Mi​) 正合当且仅当每个分量正合 ✓。∎

    投射模平坦由这条加上 prop.free-flat 立刻得到：投射模是自由模的直和项。

    ⚠️ 只对直和成立。直积没有「逐分量判定」这种便利（张量不保积），所以平坦性对直积并不自动封闭。
