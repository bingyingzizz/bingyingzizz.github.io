设 $\mathcal{A}$ 是阿贝尔范畴，$D = \bigoplus D^{p,q}$、$E = \bigoplus E^{p,q}$ 是双分次对象。一个**正合偶**是三元组 $(D, E, i, j, k)$，由下面的「三角形」组成：

$$D \xrightarrow{\ i\ } D \xrightarrow{\ j\ } E \xrightarrow{\ k\ } D ,$$

其中 $i, j, k$ 是双齐次态射，且在每个位置都正合：
