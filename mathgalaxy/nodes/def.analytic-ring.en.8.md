# analytic ring　`def.analytic-ring`
English entry · root `../`
[in graph](../#n=def.analytic-ring)　·　[Chinese page (authoritative)](./def.analytic-ring.md)

**Hypotheses used in each direction** (analyticity is a derived test on a whole class of complexes):
- Analytic $\iff$ the comparison maps for all the listed complexes and for extremally disconnected $S$ are quasi-isomorphisms: this is the definition unfolded, with the pre-analytic ring already given.
- The canonical map $A[S]\to\mathcal A[S]$ $\implies$ the contravariant derived Hom comparison: uses functoriality of precomposition, and does not presuppose analyticity.
- Testing only the ordinary Hom in degree zero $\implies$ the derived comparison need not be an isomorphism; ordinary Hom sees no higher Ext and cannot replace the condition on complexes.
