# 极化恒等式　`thm.polarization`
极化恒等式：内积由范数恢复
layer 16 · 定理 · Hilbert 空间 · 泛函分析
[在星图里打开](../#n=thm.polarization)　·　[节点索引](../index.md)

在实内积空间：

$$\langle x, y\rangle = \tfrac{1}{4}\bigl( \|x + y\|^2 - \|x - y\|^2 \bigr) .$$

在复内积空间：

$$\langle x, y\rangle = \tfrac{1}{4}\sum_{k=0}^{3} i^k \,\| x + i^k y \|^2 .$$
