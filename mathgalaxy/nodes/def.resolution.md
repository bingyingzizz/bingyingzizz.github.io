# 消解　`def.resolution`
定义：左/右消解、投射/内射消解
layer 19 · 定义 · 同调与正合列 · 同调代数
[在星图里打开](../#n=def.resolution)　·　[节点索引](../index.md)

设 $f : K^{\bullet} \to L^{\bullet}$ 是复形之间的**拟同构**，就说 $L^{\bullet}$ 是 $K^{\bullet}$ 的一个**右消解**（right resolution，也叫 replacement）；若每个 $L^{n}$ 都是**内射**对象，就叫**内射消解**。
