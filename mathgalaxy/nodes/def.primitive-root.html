陈述

设 gcd⁡(g,n)=1\gcd(g, n) = 1gcd(g,n)=1。若

ord⁡n(g)=φ(n),\operatorname{ord}_{n}(g) = \varphi(n) ,ordn​(g)=φ(n),

即 ggg 在 (Z/nZ)×(\mathbb{Z}/n\mathbb{Z})^{\times}(Z/nZ)× 里的阶等于群的阶，称 ggg 是模 nnn 的原根。

等价说法：{[g]0,[g]1,⋯ ,[g]φ(n)−1}\{[g]^{0}, [g]^{1}, \cdots, [g]^{\varphi(n)-1}\}{[g]0,[g]1,⋯,[g]φ(n)−1} 遍历整个单位群；即 (Z/nZ)×(\mathbb{Z}/n\mathbb{Z})^{\times}(Z/nZ)× 是循环群、ggg 是它的生成元。

说明

不是每个 nnn 都有原根：n=1,2,4,pk,2pkn = 1, 2, 4, p^{k}, 2p^{k}n=1,2,4,pk,2pk（ppp 为奇素数）恰好这些有，其余没有。n=8n = 8n=8 就没有：单位群 {1,3,5,7}\{1,3,5,7\}{1,3,5,7} 里每个元素的平方都是 111，是 Klein 四元群，不循环。

模素数时原根一定存在（thm.primitive-root-exists），这是最关键的情形：Fp×\mathbb{F}_{p}^{\times}Fp×​ 循环。它让「离散对数」有意义，也支撑了「Fp\mathbb{F}_{p}Fp​ 的乘法结构 = 循环群」这一整套图像。
