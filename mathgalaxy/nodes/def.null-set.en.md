## Statement · **draft**
Let $(X, \mathcal{M}, \mu )$ be a measure space, $E \in \mathcal{M}$.

If $\mu(E) = 0$, then $E$ is called a **$\mu$-null set** ($\mu -null set$).

If **every subset of a null set is measurable**:

$$\forall E \in \mathcal{M}, \forall F \subseteq E : \mu(E) = 0 \implies F \in \mathcal{M}$$

then $\mu$ (or the measure space) is called **complete**.
