# power set　`def.power-set`
English entry · root `../`
[in graph](../#n=def.power-set)　·　[Chinese page (authoritative)](./def.power-set.md)

In the finite case the number of elements is given by $\#X = n \implies \#\mathcal{P}(X) = 2^{n}$ (each element is either taken or not).

## Notes · **draft**
The power set is the step that **turns a property into an object**: to speak about "all subsets of $X$" as a thing in itself (rather than one subset at a time) one needs the power set.

$\mathcal{P}(X)$ is also the stage for several important constructions:
- Outer measures are defined on **all subsets**: $\mu^* : \mathcal{P}(X) \to [0, +\infty]$;

- Rings, $\sigma$-algebras and monotone classes are each a family of subsets of $X$, i.e. a subfamily of $\mathcal{P}(X)$;
