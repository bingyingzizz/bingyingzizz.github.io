# abelian groups in a topos form a Grothendieck category　`thm.topos-abelian-grothendieck`

[in graph](../#n=thm.topos-abelian-grothendieck)　·　[Chinese page (authoritative)](./thm.topos-abelian-grothendieck.md)


- **Small set of generators**: if $S$ is a small set of generators of $\mathcal{T}$, then $\{\mathbb{Z}\cdot X : X \in S\}$ generates $\mathcal{T}(\mathbf{Ab})$ — their coproduct is a generator.
