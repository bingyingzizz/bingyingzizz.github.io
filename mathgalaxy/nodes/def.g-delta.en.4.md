# G-delta and F-sigma sets　`def.g-delta`
English entry · root `../`
[in graph](../#n=def.g-delta)　·　[Chinese page (authoritative)](./def.g-delta.md)

⭐ After Baire, "dense $G_\delta$" is the standard way to write "almost every point": for a pointwise limit $f$ of a sequence of continuous functions, the set of continuity points is a dense $G_\delta$ (this is the only unconditional statement of this kind — "set of differentiability points" does not work: for $f = \mathbf{1}_{\mathbb{Q}}$ both the continuity set and the differentiability set are empty); the set of nowhere differentiable functions in $C[0,1]$ is also a dense $G_\delta$.
