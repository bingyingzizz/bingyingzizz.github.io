Statement

Let VVV be a real vector space and C⊆VC \subseteq VC⊆V. Call CCC a convex set if for all x,y∈Cx, y \in Cx,y∈C and t∈[0,1]t \in [0,1]t∈[0,1],

(1−t)x+ty∈C.(1-t)x + ty \in C.(1−t)x+ty∈C.

Equivalently: CCC contains the whole segment between any two of its points.

Notes

⭐ Convexity uses only the affine structure; no norm or inner product is needed. In infinite dimension it is the key hypothesis for "existence of a minimiser" (see 凸闭集的最近点).

⚠ The empty set is convex under this definition (the condition "for any two points" holds vacuously); when non-emptiness is needed it is assumed separately in the theorem (as in the projection theorem).

💡 Convex combinations, convex hulls and separation theorems all start here.

📌 A convex set is star-shaped at each of its points (see 凸集在每一点处星形); for the empty set this universal statement holds vacuously, so there is no conflict with "the empty set is not star-shaped".
