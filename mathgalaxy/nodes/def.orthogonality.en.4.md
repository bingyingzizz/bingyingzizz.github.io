- $u \perp v \iff \langle u,v\rangle = 0$: **this is a definition**, with no content.
- $S \perp T$: **also a definition** (pairwise orthogonality).
- **Orthonormal set** $\iff$ $\langle v_{i},v_{j}\rangle = \delta_{ij}$: **still a definition**, but note that it includes the case $i = j$, that is, every vector has **unit length**; saying only "pairwise orthogonal" is not enough (that is an **orthogonal set**, whose lengths may differ from $1$).
