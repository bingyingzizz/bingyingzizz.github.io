沿用上面的记号。称 {fn}\{f_n\}{fn​} 一致收敛到 fff，当且仅当

∀ε>0, ∃N, ∀n≥N, ∀x∈X: ∣fn(x)−f(x)∣<ε\forall \varepsilon > 0,\ \exists N,\ \forall n \ge N,\ \forall x \in X :\ |f_n(x) - f(x)| < \varepsilon∀ε>0, ∃N, ∀n≥N, ∀x∈X: ∣fn​(x)−f(x)∣<ε

记 fn⇉ff_n \rightrightarrows ffn​⇉f。等价说法（用上确界）：

sup⁡x∈X∣fn(x)−f(x)∣→  n→∞  0\sup_{x \in X} |f_n(x) - f(x)| \xrightarrow{\;n \to \infty\;} 0x∈Xsup​∣fn​(x)−f(x)∣n→∞​0

说明

⭐ 与逐点收敛的唯一差别是量词顺序：这里 ∃N\exists N∃N 出现在 ∀x\forall x∀x 之前 —— 一个 NNN 通吃整个定义域。

⭐ 上确界形式是最常用的判据：一致收敛就是「误差函数的上确界趋于零」，也就是在 sup 范数下收敛。

这也解释了它为什么是「函数空间里的收敛」而不是「点集上的收敛」。

⚠ 一致收敛   ⟹  \implies⟹ 逐点收敛，反之不然（fn(x)=xnf_n(x) = x^{n}fn​(x)=xn 在 [0,1][0, 1][0,1] 上）。

⭐ 这一包的三大交换定理（保连续、保积分、保导数）全都只需要一致收敛 —— 而 fn(x)=xnf_n(x) = x^{n}fn​(x)=xn 那种「漏掉一个点」的收敛恰好把连续性弄丢了。

Statement draft

With the notation above, {fn}\{f_n\}{fn​} converges uniformly to fff if and only if

∀ε>0, ∃N, ∀n≥N, ∀x∈X: ∣fn(x)−f(x)∣<ε\forall \varepsilon > 0,\ \exists N,\ \forall n \ge N,\ \forall x \in X :\ |f_n(x) - f(x)| < \varepsilon∀ε>0, ∃N, ∀n≥N, ∀x∈X: ∣fn​(x)−f(x)∣<ε

Write fn⇉ff_n \rightrightarrows ffn​⇉f. An equivalent formulation (in terms of the supremum):

sup⁡x∈X∣fn(x)−f(x)∣→  n→∞  0\sup_{x \in X} |f_n(x) - f(x)| \xrightarrow{\;n \to \infty\;} 0x∈Xsup​∣fn​(x)−f(x)∣n→∞​0

Notes draft

⭐ The only difference from pointwise convergence is the order of quantifiers: here ∃N\exists N∃N comes before ∀x\forall x∀x — a single NNN works for the whole domain.

⭐ The supremum form is the most-used criterion: uniform convergence says "the supremum of the error function tends to zero", that is, convergence in the sup norm.

This also explains why it is "convergence in a function space" rather than "convergence on a set of points".

⚠ Uniform convergence   ⟹  \implies⟹ pointwise convergence, but not conversely (fn(x)=xnf_n(x) = x^{n}fn​(x)=xn on [0,1][0, 1][0,1]).

⭐ The three exchange theorems in this pack (preserving continuity, integrals, derivatives) all need only uniform convergence — and convergence of the kind fn(x)=xnf_n(x) = x^{n}fn​(x)=xn that "misses one point" is exactly what destroys continuity.
