# CHaus 是预拓扑斯　`def.chaus-pretopos`
$\mathbf{CHaus}$ 是预拓扑斯
layer 16 · 定理 · 凝聚态集 · 范畴论+拓扑学

在 $\mathbf{CHaus}$ 中：

1. 所有极限与余极限存在；
2. 有限余积**不交**且**万有**；
3. 等价关系**有效**且**万有**；
4. 满态射**正则**且**万有**。

因此 $\mathbf{CHaus}$ 是**预拓扑斯**。
