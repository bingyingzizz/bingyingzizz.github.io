设 $f : X \to Y$ 是**映射**。若它的取值落在**数集**里 —— 即 $Y \subseteq \mathbb{R}$ 或 $Y \subseteq \mathbb{C}$ —— 就叫 $f$ 是一个**函数**。

按中学课本的说法是「数集到数集的映射」；本图把**定义域**那一边放宽：$X$ 可以是任意集合（测度空间、拓扑空间、甚至另一个函数空间）。
