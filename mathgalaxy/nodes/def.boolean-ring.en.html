Statement

A Boolean ring is a ring BBB in which every element is idempotent:

∀x∈B,x2=x.\forall x \in B,\qquad x^{2} = x.∀x∈B,x2=x.

Notes

Idempotence pins rings down tightly. Expanding (x+y)2=x+y(x + y)^{2} = x + y(x+y)2=x+y gives xy+yx=0xy + yx = 0xy+yx=0; from (x+x)2=x+x(x+x)^{2} = x+x(x+x)2=x+x one gets 2x=02x = 02x=0. Together: a Boolean ring is automatically commutative, and has characteristic 222. So a Boolean ring contains no "real" numbers, only the algebra of "yes / no".

It is the same thing as a Boolean algebra (a complemented distributive lattice). The lattice operations translate into ring operations:

  • a∧b=aba \wedge b = aba∧b=ab (meet = multiplication);
  • a∨b=a+b+aba \vee b = a + b + aba∨b=a+b+ab (join = addition plus the overlap);
  • ¬a=1+a\neg a = 1 + a¬a=1+a (complement = sum with the unit).

Conversely, a △ b=a+ba \,\triangle\, b = a + ba△b=a+b: ring addition is symmetric difference.

Smallest example: F2={ 0,1 }\mathbb{F}_{2} = \{\, 0, 1 \,\}F2​={0,1}. Most general example: for a set III, its power set P(I)\mathcal{P}(I)P(I), with symmetric difference as addition and intersection as multiplication.
