# 余连续函子　`def.cocontinuous-functor`
余连续函子
layer 16 · 定义 · 拓扑斯 · 范畴论
[在星图里打开](../#n=def.cocontinuous-functor)　·　[节点索引](../index.md)

设 $g : \mathcal{C}' \to \mathcal{C}$ 是两个景之间的函子。叫**余连续的**，如果函子 $g^{\sharp}$（把预层沿 $g$ 推出、再层化）**把层送到层**。
