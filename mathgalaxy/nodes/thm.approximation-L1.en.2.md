# approximation in L1　`thm.approximation-L1`
English entry · root `../`
[in graph](../#n=thm.approximation-L1)　·　[Chinese page (authoritative)](./thm.approximation-L1.md)

Moreover, if $\mu$ is a **Lebesgue–Stieltjes measure on $\mathbb{R}$**, one can require the $E_{j}$ to be finite unions of open intervals; one can even take a **continuous function** $g$ (vanishing outside some bounded interval) such that

$$\int |f - g| d\mu < \varepsilon$$

## Notes · **draft**
Meaning: **simple functions and continuous functions are dense in $L^{1}$**. Hence many statements need only be checked on these two classes, then one passes to the limit.
