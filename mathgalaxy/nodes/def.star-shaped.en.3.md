# star-shaped set　`def.star-shaped`
English entry · root `../`
[in graph](../#n=def.star-shaped)　·　[Chinese page (authoritative)](./def.star-shaped.md)

📌 A convex set is star-shaped at each of its points (@@thm.convex-star-shaped-every-point@@); but the empty set is convex and not star-shaped — a star-shaped set requires a star centre, so "nonempty" cannot be dropped.
