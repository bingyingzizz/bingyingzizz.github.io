Statement

A topological space (X,T)(X, \mathcal{T})(X,T) is called metrizable if there is a distance ddd on XXX such that the topology induced by ddd is exactly T\mathcal{T}T:

Td=T,Td:={ U⊆X:∀x∈U ∃r>0, Bd(x,r)⊆U }.\mathcal{T}_{d} = \mathcal{T},\qquad \mathcal{T}_{d} := \{\, U \subseteq X : \forall x \in U\ \exists r > 0,\ B_{d}(x, r) \subseteq U \,\}.Td​=T,Td​:={U⊆X:∀x∈U ∃r>0, Bd​(x,r)⊆U}.

Equivalently, XXX is homeomorphic to some metric space, i.e. there is a metric compatible with T\mathcal{T}T.

Notes

"There exists a metric", not "a metric is specified": the same topology can carry many metrics (ddd and min⁡(d,1)\min(d, 1)min(d,1) induce the same topology), so metrizability is a purely topological property, invariant under homeomorphism. "Complete", "bounded" and "uniformly continuous" are not topological properties — they change when the metric is replaced.

⭐ This is a dividing line for theorems: a metrizable space automatically acquires Hausdorff, first countability, normality and paracompactness (propositions in this cluster), so every tool available on metric spaces applies. Conversely, second countability +++ regularity suffices (Urysohn's theorem), and a weaker sufficient condition is a σ\sigmaσ-locally finite base (Nagata–Smirnov).

⚠️ Not every topological space is metrizable: an uncountable discrete space is metrizable (discrete metric) yet not second countable, while the Sorgenfrey line (lower-limit topology) is normal, separable and first countable but not second countable, hence not metrizable.
