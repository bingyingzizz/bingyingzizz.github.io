又称Proposition 1.1.4·Prop 1.1.4·同构的截面唯一

陈述

若 f:X→Yf : X \to Yf:X→Y 是同构，则它的截面与收缩都存在且唯一，而且两者相等，都等于 f−1f^{-1}f−1。

说明

证明。 设 f:X→Yf : X \to Yf:X→Y 是同构，记 g:=f−1g := f^{-1}g:=f−1。

  • 存在：gf=1Xg f = 1_{X}gf=1X​ 且 fg=1Yf g = 1_{Y}fg=1Y​，故 ggg 既是 fff 的截面（fg=1Yf g = 1_{Y}fg=1Y​）又是收缩（gf=1Xg f = 1_{X}gf=1X​）✓。
  • 截面唯一：设 s:Y→Xs : Y\to Xs:Y→X 满足 fs=1Yf s = 1_{Y}fs=1Y​，则 s=1X s=(gf) s=g (fs)=g 1Y=gs = 1_{X}\,s = (g f)\,s = g\,(f s) = g\,1_{Y} = gs=1X​s=(gf)s=g(fs)=g1Y​=g ✓。
  • 收缩唯一：设 r:X→Yr : X \to Yr:X→Y 满足 rf=1Xr f = 1_{X}rf=1X​，则 r=r 1X=r (fg)=(rf) g=1X g=gr = r\,1_{X} = r\,(f g) = (r f)\,g = 1_{X}\,g = gr=r1X​=r(fg)=(rf)g=1X​g=g ✓。

两件事并起来：截面与收缩都存在、都唯一，且都等于 f−1f^{-1}f−1 ✓。∎
