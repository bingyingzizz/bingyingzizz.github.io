# Montel's theorem　`thm.montel`
English entry · root `../`
[in graph](../#n=thm.montel)　·　[Chinese page (authoritative)](./thm.montel.md)

⚠️ "Locally uniformly bounded" cannot be weakened to "pointwise bounded": $f_{n}(z) = n z$ is pointwise bounded on $\mathbb{C}$ (constant at each point) but not uniformly bounded on any compact set, and has no locally uniformly convergent subsequence.
