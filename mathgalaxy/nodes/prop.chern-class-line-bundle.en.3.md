## Notes · **draft**
**Why rank $1$ is especially simple**: $\mathfrak{gl}(1,\mathbb{C}) = \mathbb{C}$ is commutative, so the "conjugation-invariance" condition is automatic — every polynomial is invariant, nothing to choose. Hence a line bundle has only one characteristic class ($c_{1}$), and all the rest vanish.
