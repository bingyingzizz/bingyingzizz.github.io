又称因式定理与根

陈述

设 f∈K[x]f \in K[x]f∈K[x]、a∈Ka \in Ka∈K。则

f(a)=0  ⟺  (x−a) divides f  in K[x]f(a) = 0 \iff (x - a) \text{ divides } f \ \text{ in } K[x]f(a)=0⟺(x−a) divides f  in K[x]

即：存在 h∈K[x]h \in K[x]h∈K[x] 使 f=(x−a) hf = (x - a)\,hf=(x−a)h。此时称 aaa 是 fff 的根（零点）。

说明

⭐ 证明只有两行：把 fff 除以 (x−a)(x - a)(x−a)（x−ax - ax−a 首一，带余除法可用），余式 rrr 的次数 <1< 1<1，即 rrr 是常数；把 x=ax = ax=a 代进去得 f(a)=rf(a) = rf(a)=r。所以「余式」就是「函数值」。

⭐ 由此立刻得到根的个数不超过次数（见下一条），以及「一次多项式一定有根」。

⚠ aaa 必须是 KKK 中的元素：x2+1x^{2} + 1x2+1 在 R\mathbb{R}R 上没有根，但它当然不被 (x−a)(x - a)(x−a) 整除（a∈Ra \in \mathbb{R}a∈R）。根的存在性与 KKK 有关 —— 那正是代数基本定理要管的事。

  • 带余除法 ⟹ 本页推出
    带余除法   ⟹  \implies⟹ 因式定理

    设 a∈Ka \in Ka∈K。把 fff 除以 x−ax - ax−a（首一，故带余除法适用）：

    f=q (x−a)+r,deg⁡r<1f = q\,(x - a) + r, \qquad \deg r < 1f=q(x−a)+r,degr<1

    即 r∈Kr \in Kr∈K 是常数。把 x=ax = ax=a 代入两边：f(a)=q(a)⋅0+r=rf(a) = q(a) \cdot 0 + r = rf(a)=q(a)⋅0+r=r。

    于是 f(a)=0  ⟺  r=0  ⟺  (x−a)∣ff(a) = 0 \iff r = 0 \iff (x - a) \mid ff(a)=0⟺r=0⟺(x−a)∣f。∎

    这条证明只有一行实质内容，但它给出了一个额外收获：余式就是函数值 —— 这也是多项式作为「函数」与作为「形式对象」之间的桥。
