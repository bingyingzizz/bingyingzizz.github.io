# module　`def.module`
English entry · root `../`
[in graph](../#n=def.module)　·　[Chinese page (authoritative)](./def.module.md)

- an **abelian category** (it has kernels and cokernels, and all monomorphisms and epimorphisms are strict);

- **with enough injective objects** (every module embeds into an injective module);

- **with enough projective objects** (free modules are projective);

- a **Grothendieck category** (it has a generator, $A$ itself, and filtered colimits are exact).

So "what can be done in $A\text{-}\mathbf{Mod}$" is exactly what homological algebra wants to generalize to arbitrary categories. **Everything other categories can do is measured against it.**
