# Lie Bracket　`def.lie-bracket`
English entry · root `../`
[in graph](../#n=def.lie-bracket)　·　[Chinese page (authoritative)](./def.lie-bracket.md)

1. **Antisymmetry**: $[X,Y] = -[Y,X]$, in particular $[X,X] = 0$;
2. $\mathbb{R}$-bilinearity;
3. **Jacobi identity**: $[X,[Y,Z]] + [Y,[Z,X]] + [Z,[X,Y]] = 0$;
4. **Leibniz rule**: $[X, fY] = (Xf)\,Y + f\,[X,Y]$, and $[fX, gY] = fg\,[X,Y] + f(Xg)\,Y - g(Yf)\,X$.

## Notes · **draft**
**Why the result is still a vector field**: $X(Yf)$ and $Y(Xf)$ each contain second derivatives of $f$, in a chart terms such as $X^{j}\partial_{j}\bigl(Y^{i}\partial_{i}f\bigr)$;
