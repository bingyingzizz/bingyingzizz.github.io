# 圆周率 π　`def.pi`
常数 $\pi$（由余弦的最小正零点定义）
layer 17 · 定义 · 函数列、幂级数与初等函数 · 数学分析
[在星图里打开](../#n=def.pi)　·　[节点索引](../index.md)

由 $\cos$ 的幂级数可以证明：$\cos$ 在 $(0, 2)$ 内**恰有一个**零点。把它记为 $\pi / 2$，即

$$\pi := 2 \cdot \min \{ x > 0 : \cos x = 0 \}$$

于是 $\cos(\pi/2) = 0$、$\sin(\pi/2) = 1$，而且 $\cos$ 与 $\sin$ 都以 $2\pi$ 为周期。
