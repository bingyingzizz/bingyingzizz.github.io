陈述

设 KKK 是单纯复形，(C∗(K),∂)(C_{*}(K), \partial)(C∗​(K),∂) 是它的链复形。由 ∂2=0\partial^{2} = 0∂2=0 得 Bp⊆ZpB_{p} \subseteq Z_{p}Bp​⊆Zp​，而 Cp(K)C_{p}(K)Cp​(K) 是阿贝尔群，所以子群都是正规的，可以取商。ppp 维单纯同调群定义为商群

Hp(K):=Zp(K) / Bp(K)  =  ker⁡∂p / im⁡∂p+1.H_{p}(K) := Z_{p}(K)\, \big/\, B_{p}(K) \;=\; \ker\partial_{p}\, \big/\, \operatorname{im}\partial_{p+1}.Hp​(K):=Zp​(K)/Bp​(K)=ker∂p​/im∂p+1​.

它的元素叫同调类，记 [z][z][z]（z∈Zpz \in Z_{p}z∈Zp​ 是代表闭链）。

[z]=0  ⟺  z∈Bp,[z] = 0 \iff z \in B_{p},[z]=0⟺z∈Bp​,

即：一个闭链在同调里是零，当且仅当它是某个 (p+1)(p+1)(p+1)-链的边界。

说明

它在量什么：HpH_{p}Hp​ 量的是「ppp 维的闭链里，有多少不是边缘」。H1H_{1}H1​ 数一维的洞（S1S^{1}S1：H1=ZH_{1} = \mathbb{Z}H1​=Z），H2H_{2}H2​ 数空腔（S2S^{2}S2：H2=ZH_{2} = \mathbb{Z}H2​=Z），H0H_{0}H0​ 数连通分支（prop.h0-components）。

⚠️ HpH_{p}Hp​ 是商群，不是子群。单看「闭链」什么也看不出——任何空间都有大量闭链；信息全在「哪些闭链是别人影子」这一步。把 BpB_{p}Bp​ 除掉，剩下的才是「真的堵住了」。

为什么必须除掉 BpB_{p}Bp​ 而不是别的：如果只除掉 000，那 ZpZ_{p}Zp​ 里会塞满「薄薄一层壳」（例如球面上任何小圆都是闭链），洞与洞之间的差别被无穷多无用信息淹没。除到 BpB_{p}Bp​ 恰好留下「拓扑」信息。

有限复形时 HpH_{p}Hp​ 是有限生成的：Z\mathbb{Z}Z 是主理想整环，自由模的子模仍自由，所以 Hp≅Zβp⊕(挠部)H_{p} \cong \mathbb{Z}^{\beta_{p}} \oplus (\text{挠部})Hp​≅Zβp​⊕(挠部)，βp\beta_{p}βp​ 叫 Betti 数。挠部（如 Z/2\mathbb{Z}/2Z/2）是「扭了一下」的洞，R\mathbb{R}R 系数的同调看不见它。

💡 与 π1\pi_{1}π1​ 的分工：π1\pi_{1}π1​ 非阿贝尔、难算、只管一维；HpH_{p}Hp​ 是阿贝尔群、对每个维数都有、而且有长正合列这类强工具。两者通过 Hurewicz 同态联系（H1H_{1}H1​ 是 π1\pi_{1}π1​ 的阿贝尔化，见 def.singular-homology 的弱边）。

    两次秩-零化度，边缘群的维数在交错和里相消

    设 KKK 有限，αp=dim⁡QCp\alpha_{p} = \dim_{\mathbb{Q}} C_{p}αp​=dimQ​Cp​（即 ppp-单纯形个数），zp=rank⁡Zpz_{p} = \operatorname{rank} Z_{p}zp​=rankZp​、bp=rank⁡Bp=rank⁡∂p+1b_{p} = \operatorname{rank} B_{p} = \operatorname{rank}\partial_{p+1}bp​=rankBp​=rank∂p+1​、hp=rank⁡Hph_{p} = \operatorname{rank} H_{p}hp​=rankHp​。这些数都有限（Z\mathbb{Z}Z 是主理想整环，子模自由）。

    第一次秩-零化度（对 ∂p:Cp→Cp−1\partial_{p} : C_{p} \to C_{p-1}∂p​:Cp​→Cp−1​）：

    αp=dim⁡ker⁡∂p+rank⁡∂p=zp+bp−1.\alpha_{p} = \dim\ker\partial_{p} + \operatorname{rank}\partial_{p} = z_{p} + b_{p-1}.αp​=dimker∂p​+rank∂p​=zp​+bp−1​.

    第二次（用在 0→Zp→Cp→Bp−1→00 \to Z_{p} \to C_{p} \to B_{p-1} \to 00→Zp​→Cp​→Bp−1​→0 之后，或直接看商）：因为 Hp=Zp/BpH_{p} = Z_{p}/B_{p}Hp​=Zp​/Bp​，

    zp=bp+hp.z_{p} = b_{p} + h_{p}.zp​=bp​+hp​.

    代入，得 αp=bp+hp+bp−1\alpha_{p} = b_{p} + h_{p} + b_{p-1}αp​=bp​+hp​+bp−1​。交错求和：

    ∑p(−1)pαp=∑p(−1)php+S1−S2,\sum_{p} (-1)^{p}\alpha_{p} = \sum_{p} (-1)^{p} h_{p} + S_{1} - S_{2},p∑​(−1)pαp​=p∑​(−1)php​+S1​−S2​,

    「相消」是这条定理的全部内容：边缘群 bpb_{p}bp​ 在相邻两项里符号相反，数得再多也看不见。
