陈述

张量积是一个双函子 ⊗R:Mod-R×R-Mod→Ab\otimes_{R} : \mathbf{Mod}\text{-}R \times R\text{-}\mathbf{Mod} \to \mathbf{Ab}⊗R​:Mod-R×R-Mod→Ab，并且：

  1. 加法性：对 f:M→M1f : M \to M_{1}f:M→M1​、g:N→N1g : N \to N_{1}g:N→N1​，有 f⊗gf \otimes gf⊗g；固定一个变元时是加法函子。
  2. 与直和交换：(⨁iMi)⊗RN≅⨁i(Mi⊗RN)(\bigoplus_{i} M_{i}) \otimes_{R} N \cong \bigoplus_{i} (M_{i} \otimes_{R} N)(⨁i​Mi​)⊗R​N≅⨁i​(Mi​⊗R​N)，M⊗R(⨁jNj)≅⨁j(M⊗RNj)M \otimes_{R} (\bigoplus_{j} N_{j}) \cong \bigoplus_{j} (M \otimes_{R} N_{j})M⊗R​(⨁j​Nj​)≅⨁j​(M⊗R​Nj​)，且同构自然。
  3. 单位：R⊗RN≅NR \otimes_{R} N \cong NR⊗R​N≅N（r⊗n↦rnr \otimes n \mapsto r nr⊗n↦rn）；一般地 R(I)⊗RN≅N(I)R^{(I)} \otimes_{R} N \cong N^{(I)}R(I)⊗R​N≅N(I)。
  4. 结合：若 MMM 是 (S,R)(S, R)(S,R)-双模、NNN 是 (R,T)(R, T)(R,T)-双模、PPP 是左 TTT-模，则
(M⊗RN)⊗TP  ≅  M⊗R(N⊗TP).(M \otimes_{R} N) \otimes_{T} P \;\cong\; M \otimes_{R} (N \otimes_{T} P).(M⊗R​N)⊗T​P≅M⊗R​(N⊗T​P).
  1. 对称（RRR 交换）：τ:M⊗RN→N⊗RM\tau : M \otimes_{R} N \to N \otimes_{R} Mτ:M⊗R​N→N⊗R​M、m⊗n↦n⊗mm \otimes n \mapsto n \otimes mm⊗n↦n⊗m，且 τ∘τ=id\tau \circ \tau = \mathrm{id}τ∘τ=id。

说明

⭐ 由 2、3 立刻得到：(−)⊗RN(-) \otimes_{R} N(−)⊗R​N 保余极限（直和、余核、滤过余极限）。这一条同时解释了「右正合」（保余核）与「保直和」，是后面 prop.tensor-right-exact 与 prop.free-flat 的共同根。

⚠️ 一般不保极限：⊗\otimes⊗ 不保核。0→Z→  2  Z0 \to \mathbb{Z} \xrightarrow{\;2\;} \mathbb{Z}0→Z2​Z 是正合列，取 N=QN = \mathbb{Q}N=Q 张量后仍正合（乘 222 在 Q\mathbb{Q}Q 上仍然单），但取 N=Z/2N = \mathbb{Z}/2N=Z/2 张量后乘 222 变成零映射，核冒出来了（见 prop.tensor-right-exact）。它也不保无限积。

📌 结合律 4 在交换环上的常见样子：(M⊗RN)⊗RP≅M⊗RN⊗RP(M \otimes_{R} N) \otimes_{R} P \cong M \otimes_{R} N \otimes_{R} P(M⊗R​N)⊗R​P≅M⊗R​N⊗R​P，于是可以不加括号地写多重张量积。

它指向谁（出边）

推出 1

  • 本页 ⟹ 自由模平坦推出
    与直和交换 + 单位   ⟹  \implies⟹ 自由模平坦

    由「单位」R⊗RN≅NR \otimes_{R} N \cong NR⊗R​N≅N 与「与直和交换」，对每个 AAA 有自然同构

    A⊗RR(I)  ≅  A⊗R⨁i∈IR  ≅  ⨁i∈I(A⊗RR)  ≅  A(I).A \otimes_{R} R^{(I)} \;\cong\; A \otimes_{R} \bigoplus_{i \in I} R \;\cong\; \bigoplus_{i \in I} (A \otimes_{R} R) \;\cong\; A^{(I)} .A⊗R​R(I)≅A⊗R​i∈I⨁​R≅i∈I⨁​(A⊗R​R)≅A(I).

    所以 (−)⊗RR(I)≅⨁i∈I(−)(-) \otimes_{R} R^{(I)} \cong \bigoplus_{i \in I} (-)(−)⊗R​R(I)≅⨁i∈I​(−) 就是「取 III 重直和」这个函子。

    一族函子的直和正合：f:A→A1f : A \to A_{1}f:A→A1​ 单射   ⟺  \iff⟺ 每个分量 fff 单射，而 (f)(I)(f)^{(I)}(f)(I) 就是 fff 的 III 重直和、单射性逐分量判定 ✓。故自由模平坦。

    投射模平坦：投射模是某自由模的直和项，由 prop.flat-summand 继承平坦性 ✓。∎

    这条让「投射消解也是平坦消解」成立，于是 Tor⁡\operatorname{Tor}Tor 可以用更短的平坦消解来算。

谁指向它（入边）

推出 1

  • 模的张量积 ⟹ 本页推出
    万有性质   ⟹  \implies⟹ 双函子性、结合、对称与保直和

    五个性质全都由同一个办法得到：要造 M⊗N→PM \otimes N \to PM⊗N→P，只需给出一个平衡双加性映射 M×N→PM \times N \to PM×N→P；要证两个张量积之间的映射互逆，在一组生成元（纯张量）上验证即可。

    双函子：给定 f:M→M1f : M \to M_{1}f:M→M1​、g:N→N1g : N \to N_{1}g:N→N1​，(m,n)↦f(m)⊗g(n)(m, n) \mapsto f(m) \otimes g(n)(m,n)↦f(m)⊗g(n) 平衡双加性，唯一给出 f⊗gf \otimes gf⊗g；加法性由 ⊗\otimes⊗ 的双加性直接得到 ✓。

    与直和交换：投影 ⨁iMi→Mi0\bigoplus_{i} M_{i} \to M_{i_{0}}⨁i​Mi​→Mi0​​ 给出 φ:(⨁iMi)⊗N→⨁i(Mi⊗N)\varphi : (\bigoplus_{i} M_{i}) \otimes N \to \bigoplus_{i}(M_{i} \otimes N)φ:(⨁i​Mi​)⊗N→⨁i​(Mi​⊗N)；含入 Mi⊗N→(⨁iMi)⊗NM_{i} \otimes N \to (\bigoplus_{i} M_{i}) \otimes NMi​⊗N→(⨁i​Mi​)⊗N 给出反向的 ψ\psiψ。两者在纯张量上互逆，故互为逆同构 ✓。

    单位：r⊗n↦rnr \otimes n \mapsto r nr⊗n↦rn 有反向 n↦1⊗nn \mapsto 1 \otimes nn↦1⊗n，且 r⊗n=(1⋅r)⊗n=1⊗rnr \otimes n = (1 \cdot r) \otimes n = 1 \otimes r nr⊗n=(1⋅r)⊗n=1⊗rn 由平衡关系成立，故 R⊗RN≅NR \otimes_{R} N \cong NR⊗R​N≅N ✓。

    结合：(m⊗n)⊗p↦m⊗(n⊗p)(m \otimes n) \otimes p \mapsto m \otimes (n \otimes p)(m⊗n)⊗p↦m⊗(n⊗p) 与反向都由三重平衡映射给出，互逆 ✓。

    对称（RRR 交换）：τ(m⊗n)=n⊗m\tau(m \otimes n) = n \otimes mτ(m⊗n)=n⊗m 良定义（交换性保证 τ(mr⊗n)=τ(m⊗rn)\tau(m r \otimes n) = \tau(m \otimes r n)τ(mr⊗n)=τ(m⊗rn)），且 τ2=id\tau^{2} = \mathrm{id}τ2=id ✓。∎

    由「与直和交换」+「单位」两条合成，得到后面反复要用的那句：(−)⊗RN(-) \otimes_{R} N(−)⊗R​N 保余极限。
