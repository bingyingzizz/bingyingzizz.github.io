# rotation　`prop.triangle-rotation`
English entry · root `../`
[in graph](../#n=prop.triangle-rotation)　·　[Chinese page (authoritative)](./prop.triangle-rotation.md)

1. $K \xrightarrow{\ 1\ } K \to 0 \to K[1]$ is a distinguished triangle;
2. **Rotation**: $K \xrightarrow{\ f\ } L \xrightarrow{\ g\ } M \xrightarrow{\ h\ } K[1]$ is distinguished $\iff$ the rotated $L \xrightarrow{\ g\ } M \xrightarrow{\ h\ } K[1] \xrightarrow{\ -f[1]\ } L[1]$ is distinguished;
3. every $f : K \to L$ embeds (**non-uniquely**) into a distinguished triangle;
4. morphisms between distinguished triangles extend (**non-uniquely**).
