# category of algebras　`def.category-of-algebras`

[in graph](../#n=def.category-of-algebras)　·　[Chinese page (authoritative)](./def.category-of-algebras.md)

**Commutative case**: the coproduct of commutative $R$-algebras is $\otimes_R$; no separate entry is given for the category of commutative algebras, so this is noted here.

**Convention on zero algebras**: if zero algebras were disallowed, the category would have no terminal object; here they are allowed, so that a terminal object exists, as recorded in this note.
