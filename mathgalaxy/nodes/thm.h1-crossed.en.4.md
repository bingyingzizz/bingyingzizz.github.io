# First Cohomology and Crossed Homomorphisms　`thm.h1-crossed`
English entry · root `../`
[in graph](../#n=thm.h1-crossed)　·　[Chinese page (authoritative)](./thm.h1-crossed.md)

**Two immediate consequences**:
- When the action is **trivial**, $Z^{1} = \operatorname{Hom}(G, M)$ and $B^{1} = 0$, so $H^{1}(G, M) = \operatorname{Hom}(G, M)$.
- If $G$ is **finite**, $M$ is torsion-free, and the action is trivial, then $\implies H^{1}(G, M) = 0$ (there is no nontrivial homomorphism from a finite group to a torsion-free group).

**Why "crossed"**: $d(g_{1}g_{2}) = d(g_{1}) + g_{1}d(g_{2})$ is exactly the Leibniz formula for "twisting by $g_{1}$ when moving $g_{1}$ out" — the same formula as for a derivation, only with coefficients in a module.
