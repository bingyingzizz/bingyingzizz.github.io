又称过滤复形给出正合偶

陈述

设 KKK 是带递降过滤 FpKF^{p}KFpK 的复形（ddd 保过滤，即 d(FpKn)⊆FpKn+1d(F^{p}K^{n}) \subseteq F^{p}K^{n+1}d(FpKn)⊆FpKn+1）。对每个 ppp 有复形的短正合列

0⟶Fp+1K⟶FpK⟶Gr⁡pK⟶0.0 \longrightarrow F^{p+1}K \longrightarrow F^{p}K \longrightarrow \operatorname{Gr}^{p}K \longrightarrow 0 .0⟶Fp+1K⟶FpK⟶GrpK⟶0.

把它们的长正合列在一切 ppp 上并排，得到正合偶

D1p,q:=Hp+q(FpK),E1p,q:=Hp+q(Gr⁡pK),D_{1}^{p,q} := H^{p+q}\bigl(F^{p}K\bigr), \qquad E_{1}^{p,q} := H^{p+q}\bigl(\operatorname{Gr}^{p}K\bigr),D1p,q​:=Hp+q(FpK),E1p,q​:=Hp+q(GrpK),

其中 iii 由含入 Fp+1K↪FpKF^{p+1}K \hookrightarrow F^{p}KFp+1K↪FpK 诱导、jjj 由商映射诱导、kkk 是长正合列的连接同态。它给出的谱序列满足

Erp,q=Zrp,q/Brp,q,Zrp,q:=FpKp+q∩d−1(Fp+rKp+q+1),Brp,q:=FpKp+q∩d(Fp−r+1Kp+q−1),E_{r}^{p,q} = Z_{r}^{p,q} \big/ B_{r}^{p,q}, \qquad Z_{r}^{p,q} := F^{p}K^{p+q} \cap d^{-1}\bigl(F^{p+r}K^{p+q+1}\bigr), \qquad B_{r}^{p,q} := F^{p}K^{p+q} \cap d\bigl(F^{p-r+1}K^{p+q-1}\bigr),Erp,q​=Zrp,q​/Brp,q​,Zrp,q​:=FpKp+q∩d−1(Fp+rKp+q+1),Brp,q​:=FpKp+q∩d(Fp−r+1Kp+q−1),

即与直接构造给出同一个谱序列；过滤下有界时收敛到 E∞p,q=Gr⁡pHp+q(K)E_{\infty}^{p,q} = \operatorname{Gr}^{p} H^{p+q}(K)E∞p,q​=GrpHp+q(K)。

说明

这一条是把两条路焊在一起的螺丝。

  • 一条路（图上已有）：直接对过滤复形定义 Zrp,qZ^{p,q}_{r}Zrp,q​、Brp,qB^{p,q}_{r}Brp,q​，验证 Er+1=H(Er,dr)E_{r+1} = H(E_{r}, d_{r})Er+1​=H(Er​,dr​)、收敛到 Gr⁡pHp+q\operatorname{Gr}^{p}H^{p+q}GrpHp+q —— 见 thm.filtered-complex-spectral。
  • 另一条路（这一条）：把长正合列的「三项正合」打包成正合偶，让正合偶的导出机制自动生成谱序列 —— 见 thm.exact-couple-spectral。

两条路为什么是同一个。

① 第一页相同：两边都是 E1p,q=Hp+q(Gr⁡pK)E_{1}^{p,q} = H^{p+q}(\operatorname{Gr}^{p}K)E1p,q​=Hp+q(GrpK)。

② 第一微分相同：导出偶的 d1=jkd_{1} = j kd1​=jk 是

Hp+q(Gr⁡pK)→ k Hp+q+1(Fp+1K)→ j Hp+q+1(Gr⁡p+1K),H^{p+q}\bigl(\operatorname{Gr}^{p}K\bigr) \xrightarrow{\ k\ } H^{p+q+1}\bigl(F^{p+1}K\bigr) \xrightarrow{\ j\ } H^{p+q+1}\bigl(\operatorname{Gr}^{p+1}K\bigr),Hp+q(GrpK) k ​Hp+q+1(Fp+1K) j ​Hp+q+1(Grp+1K),

即「连接同态 + 落到关联分次」，这正是直接构造里 Gr⁡p→Gr⁡p+1\operatorname{Gr}^{p} \to \operatorname{Gr}^{p+1}Grp→Grp+1 的那个微分，其落点 (p+1,q)(p+1, q)(p+1,q) 与 drd_{r}dr​ 的规律 (r,1−r)(r, 1-r)(r,1−r) 在 r=1r = 1r=1 时吻合。

③ 逐叶归纳：把 DrD_{r}Dr​、ErE_{r}Er​ 用 Zr/BrZ_{r}/B_{r}Zr​/Br​ 显式写出（Drp,qD_{r}^{p,q}Drp,q​ 是「FpF^{p}Fp 里 ddd 至少跳 rrr 步仍留在 Fp+r−1F^{p+r-1}Fp+r−1 内的那些类」），代入导出偶的三条公式，得到的就是上面的 Zrp,qZ_{r}^{p,q}Zrp,q​、Brp,qB_{r}^{p,q}Brp,q​。归纳步只用到 d2=0d^{2} = 0d2=0 与核 / 余核的泛性质，没有额外输入。∎

⭐ 实用价值：想算某个谱序列时，挑好算的那条路走。双复形的情形通常用直接构造（两个方向的过滤各给一台，比较 E2E_{2}E2​ 页即可，见 prop.bicomplex-spectral）；而一般正合偶（同伦群、Bockstein、Gysin 那类）只有正合偶这条路 —— 那里根本没有一个复形可以过滤。

⚠️ 收敛仍要下有界（或至少「对每个 (p,q)(p,q)(p,q)，rrr 充分大时 ZrZ_{r}Zr​、BrB_{r}Br​ 稳定」）。无界复形的谱序列可以「不收敛到任何东西」，别默认那个符号一定成立。

  • 正合偶、正合偶给出谱序列 ⟹ 本页推出
    长正合列打包成正合偶   ⟹  \implies⟹ 与直接构造同一个谱序列

    第一步：构造偶。 对每个 ppp 有复形的短正合列 0→Fp+1K→FpK→Gr⁡pK→00 \to F^{p+1}K \to F^{p}K \to \operatorname{Gr}^{p}K \to 00→Fp+1K→FpK→GrpK→0。取长正合列

    ⋯→Hn(Fp+1K)→ i Hn(FpK)→ j Hn(Gr⁡pK)→ k Hn+1(Fp+1K)→⋯\cdots \to H^{n}(F^{p+1}K) \xrightarrow{\ i\ } H^{n}(F^{p}K) \xrightarrow{\ j\ } H^{n}(\operatorname{Gr}^{p}K) \xrightarrow{\ k\ } H^{n+1}(F^{p+1}K) \to \cdots⋯→Hn(Fp+1K) i ​Hn(FpK) j ​Hn(GrpK) k ​Hn+1(Fp+1K)→⋯

    并把 Hp+qH^{p+q}Hp+q 认成双次数 (p,q)(p,q)(p,q) 的分量：D1p,q:=Hp+q(FpK)D_{1}^{p,q} := H^{p+q}(F^{p}K)D1p,q​:=Hp+q(FpK)、E1p,q:=Hp+q(Gr⁡pK)E_{1}^{p,q} := H^{p+q}(\operatorname{Gr}^{p}K)E1p,q​:=Hp+q(GrpK)。于是

    i:D1p,q→D1p−1,q+1 (等价地 D1p+1,q−1→D1p,q),j:D1p,q→E1p,q,k:E1p,q→D1p+1,q.i : D_{1}^{p,q} \to D_{1}^{p-1,q+1} \ (\text{等价地 } D_{1}^{p+1,q-1} \to D_{1}^{p,q}), \qquad j : D_{1}^{p,q} \to E_{1}^{p,q}, \qquad k : E_{1}^{p,q} \to D_{1}^{p+1,q} .i:D1p,q​→D1p−1,q+1​ (等价地 D1p+1,q−1​→D1p,q​),j:D1p,q​→E1p,q​,k:E1p,q​→D1p+1,q​.

    正合性：三角形的三处正合恰好就是长正合列中相邻三项的正合性（im⁡i=ker⁡j\operatorname{im} i = \ker jimi=kerj 是「Fp+1→Fp→Gr⁡pF^{p+1} \to F^{p} \to \operatorname{Gr}^{p}Fp+1→Fp→Grp 处正合」，im⁡j=ker⁡k\operatorname{im} j = \ker kimj=kerk、im⁡k=ker⁡i\operatorname{im} k = \ker iimk=keri 同理）。故这是一个正合偶。∎

    第二步：由定理得谱序列。 由 thm.exact-couple-spectral，它给出谱序列，微分 dr:Erp,q→Erp+r,q−r+1d_{r} : E_{r}^{p,q} \to E_{r}^{p+r,q-r+1}dr​:Erp,q​→Erp+r,q−r+1​。∎

    第三步：与直接构造逐页一致。 对 rrr 归纳证明

    Erp,q=Zrp,q/Brp,q,Zrp,q=FpKp+q∩d−1(Fp+rKp+q+1),Brp,q=FpKp+q∩d(Fp−r+1Kp+q−1).E_{r}^{p,q} = Z_{r}^{p,q}\big/ B_{r}^{p,q}, \qquad Z_{r}^{p,q} = F^{p}K^{p+q} \cap d^{-1}(F^{p+r}K^{p+q+1}), \qquad B_{r}^{p,q} = F^{p}K^{p+q} \cap d(F^{p-r+1}K^{p+q-1}) .Erp,q​=Zrp,q​/Brp,q​,Zrp,q​=FpKp+q∩d−1(Fp+rKp+q+1),Brp,q​=FpKp+q∩d(Fp−r+1Kp+q−1).
    • r=1r = 1r=1：Z1=FpK∩d−1(Fp+1K)Z_{1} = F^{p}K \cap d^{-1}(F^{p+1}K)Z1​=FpK∩d−1(Fp+1K)、B1=FpK∩d(FpK)B_{1} = F^{p}K \cap d(F^{p}K)B1​=FpK∩d(FpK)，商就是 Hp+q(Gr⁡pK)H^{p+q}(\operatorname{Gr}^{p}K)Hp+q(GrpK) —— 与第一步的 E1E_{1}E1​ 相同。✓
    • r=2r = 2r=2：d1=jkd_{1} = jkd1​=jk 就是「连接同态 + 落到 Gr⁡p+1\operatorname{Gr}^{p+1}Grp+1」，其核商掉 d1d_{1}d1​ 的像正好把 Z1Z_{1}Z1​ 放宽到 d−1(Fp+2K)d^{-1}(F^{p+2}K)d−1(Fp+2K) —— 即 Z2/B2Z_{2}/B_{2}Z2​/B2​。✓
    • 归纳步：Zr+1Z_{r+1}Zr+1​ 比 ZrZ_{r}Zr​ 放宽一层（ddd 允许再跳一格）、Br+1B_{r+1}Br+1​ 比 BrB_{r}Br​ 放宽一层（前一步允许再远一格），而导出偶的三条公式代入后给出逐字相同的两个递推。这一步只用到 d2=0d^{2}=0d2=0 与核 / 余核的泛性质，无额外输入。∎

    第四步：收敛。 过滤下有界时每格稳定，由 thm.exact-couple-spectral 得 E∞p,q=D∞p,q/D∞p+1,q−1E_{\infty}^{p,q} = D_{\infty}^{p,q}/D_{\infty}^{p+1,q-1}E∞p,q​=D∞p,q​/D∞p+1,q−1​；而 D∞p,q=⋂rim⁡(Hp+q(Fp+rK)→Hp+q(FpK))=im⁡(Hp+q(FpK)→Hp+q(K))=FpHp+q(K)D_{\infty}^{p,q} = \bigcap_{r} \operatorname{im}\bigl(H^{p+q}(F^{p+r}K) \to H^{p+q}(F^{p}K)\bigr) = \operatorname{im}\bigl(H^{p+q}(F^{p}K) \to H^{p+q}(K)\bigr) = F^{p}H^{p+q}(K)D∞p,q​=⋂r​im(Hp+q(Fp+rK)→Hp+q(FpK))=im(Hp+q(FpK)→Hp+q(K))=FpHp+q(K)（下有界时这个递降链在每格上稳定到一个偏序集里的极限，而 ⋃pFpK=K\bigcup_{p} F^{p}K = K⋃p​FpK=K 让它落在那条映射的像上）。于是 E∞p,q=FpHp+q/Fp+1Hp+q=Gr⁡pHp+q(K)E_{\infty}^{p,q} = F^{p}H^{p+q}/F^{p+1}H^{p+q} = \operatorname{Gr}^{p}H^{p+q}(K)E∞p,q​=FpHp+q/Fp+1Hp+q=GrpHp+q(K)。∎

    两条路的差别只在「Zr/BrZ_{r}/B_{r}Zr​/Br​ 的递推怎么打包」：直接构造把递推写在 ErE_{r}Er​ 上，正合偶把递推交给导出机制；两者给出的 ErE_{r}Er​ 与微分逐页相同。
