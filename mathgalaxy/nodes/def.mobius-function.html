说明

μ\muμ 是积性函数里最简单的一个（也是完全积性以外的第一个「有零值」的积性函数）：由素数幂上的值 μ(p)=−1\mu(p) = -1μ(p)=−1、μ(pe)=0 (e≥2)\mu(p^{e}) = 0\ (e \ge 2)μ(pe)=0 (e≥2) 完全确定。

它出现的原因只有一个：它是「常数函数 111」在狄利克雷卷积下的逆。也就是说，Möbius 反演不是技巧，而是卷积群的逆元。
