Statement

A set is determined uniquely by its elements:

∀A∀B[∀x(x∈A↔x∈B)→A=B]\forall A \forall B [ \forall x ( x \in A \leftrightarrow x \in B ) \to A = B ]∀A∀B[∀x(x∈A↔x∈B)→A=B]

The converse direction (A=B→A = B \toA=B→ the elements are exactly the same) holds automatically in first-order logic with equality, which is why the axiom is often written with ↔\leftrightarrow↔. It guarantees that describing a set by a condition determines it uniquely, so a notation such as {x∈A:φ(x)}\{ x \in A : \varphi (x) \}{x∈A:φ(x)} is never ambiguous.
