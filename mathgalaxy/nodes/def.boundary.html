陈述

在做什么：把同调公式 Hn=Zn/BnH^{n} = Z^{n}/B^{n}Hn=Zn/Bn 里那个分母说清楚。边缘是从上一层打过来的元素 —— 它们是「平凡的闭链」，同调要做的就是把它们除掉。

设 KKK 是加法范畴 C\mathcal{C}C 中的复形，微分 dn:Kn→Kn+1d^{n} : K^{n} \to K^{n+1}dn:Kn→Kn+1。

上链情形：第 nnn 阶上边缘群（coboundaries）是

Bn(K):=im⁡dn−1={ dn−1x:x∈Kn−1 },B^{n}(K) := \operatorname{im} d^{n-1} = \{\, d^{n-1}x : x \in K^{n-1} \,\} ,Bn(K):=imdn−1={dn−1x:x∈Kn−1},

它的元素叫上边缘（coboundary）。

链情形：第 nnn 阶边缘群（boundaries）是

Bn(K):=im⁡dn+1,B_{n}(K) := \operatorname{im} d_{n+1} ,Bn​(K):=imdn+1​,

它的元素叫边缘（boundary）。

为什么 B⊆ZB \subseteq ZB⊆Z：由复形的定义 dn∘dn−1=0d^{n} \circ d^{n-1} = 0dn∘dn−1=0，对 x=dn−1yx = d^{n-1}yx=dn−1y 有 dnx=dndn−1y=0d^{n}x = d^{n}d^{n-1}y = 0dnx=dndn−1y=0，所以每个上边缘都是上闭链。因此商 Zn/BnZ^{n}/B^{n}Zn/Bn 有意义。

说明

⭐ d2=0d^{2} = 0d2=0 的全部内容就是这一条：Bn⊆ZnB^{n} \subseteq Z^{n}Bn⊆Zn。复形的公理（d∘d=0d\circ d = 0d∘d=0）没有别的用处 —— 它存在的唯一理由就是让「闭链 / 边缘」这个商能取。所以复形 = 「一个能让同调有定义的装置」。

⚠️ 「边缘」与拓扑的「边界」撞名：流形的边界 ∂M\partial M∂M、单形复形的边界算子 ∂n\partial_{n}∂n​ 里的「边界」在复形语言里就是这里的边缘（∂n\partial_{n}∂n​ 就是 dnd_{n}dn​）。

但一般范畴里没有「点集边界」这个概念，只有像。

读「边缘」时一律按 im⁡d\operatorname{im} dimd 理解。

⚠️ 记号：BnB^{n}Bn（boundary）、im⁡dn−1\operatorname{im} d^{n-1}imdn−1、d(Kn−1)d(K^{n-1})d(Kn−1) 三种都在用。

BBB 与 ZZZ 一起出现时注意台阶：Bn=im⁡dn−1B^{n} = \operatorname{im} d^{n-1}Bn=imdn−1 比 Zn=ker⁡dnZ^{n} = \ker d^{n}Zn=kerdn 低一阶的微分，这个「错位」是同调代数里所有符号错误的来源。

⭐ de Rham 版：dω=0d\omega = 0dω=0 的叫闭形式（= 闭链），ω=dη\omega = d\etaω=dη 的叫恰当形式（= 边缘）。所以「闭形式恰当」  ⟺  \iff⟺ H1=0H^{1} = 0H1=0 的那部分 —— 这正是 Poincaré 引理的内容。
