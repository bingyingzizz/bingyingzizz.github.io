# category of sets　`def.category-of-sets`
English entry · root `../`
[in graph](../#n=def.category-of-sets)　·　[Chinese page (authoritative)](./def.category-of-sets.md)

**Not an additive category**: $\hom(A,B)$ in general has no group structure, so one cannot add pointwise.

**Relation to the category of topological spaces**: there is a forgetful functor $\mathbf{Top}\to\mathbf{Set}$ preserving limits and colimits, because the topologies are built pointwise from the underlying sets.
