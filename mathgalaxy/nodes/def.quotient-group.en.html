Statement

Let N⊴GN \trianglelefteq GN⊴G. The set of all left cosets { gN:g∈G }\{\, gN : g \in G \,\}{gN:g∈G} is denoted G/NG/NG/N; define on it

(gN)⋅(g′N):=(gg′)N.(g N) \cdot (g' N) := (g g') N.(gN)⋅(g′N):=(gg′)N.

Normality guarantees that this definition is independent of the choice of representatives, so G/NG/NG/N becomes a group, called the quotient group.

The natural map π:G→G/N\pi : G \to G/Nπ:G→G/N, g↦gNg \mapsto gNg↦gN, is a surjective homomorphism.

Notes

The quotient group is the set-theoretic quotient with one more layer: first quotient GGG by the equivalence relation “differ by an element of NNN”, then check that an operation survives on the quotient set.

Universal property (the real use of quotient groups): for any group homomorphism φ:G→G′\varphi : G \to G'φ:G→G′, if N⊆ker⁡φN \subseteq \ker\varphiN⊆kerφ, then φ\varphiφ factors uniquely through π\piπ: there exists a unique φ‾:G/N→G′\overline{\varphi} : G/N \to G'φ​:G/N→G′ with φ‾∘π=φ\overline{\varphi} \circ \pi = \varphiφ​∘π=φ.

⚠️ A quotient group exists only for normal subgroups; the quotient set G/HG/HG/H exists for any subgroup (left cosets still partition GGG), but that quotient set usually carries no group structure.
