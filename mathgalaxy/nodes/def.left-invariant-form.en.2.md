# left-invariant form　`def.left-invariant-form`
English entry · root `../`
[in graph](../#n=def.left-invariant-form)　·　[Chinese page (authoritative)](./def.left-invariant-form.md)

Let $G$ be an $n$-dimensional Lie group, $\mathfrak{g} = T_{e}G$, and $L_{g}$ the left translation. A $k$-form $\omega \in \Omega^{k}(G)$ is **left-invariant** if

$$L_{g}^{\ast}\omega = \omega\qquad (g \in G),$$

equivalently $\omega_{g}(v_{1},\ldots,v_{k}) = \omega_{e}\bigl(\mathrm{d}(L_{g^{-1}})_{g}v_{1},\ldots,\mathrm{d}(L_{g^{-1}})_{g}v_{k}\bigr)$ — that is, the values of $\omega$ on $G$ are uniquely determined by $\omega_{e}$.

Thus the evaluation

$$\omega \longmapsto \omega_{e}$$
