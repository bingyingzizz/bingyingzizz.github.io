又称Frobenius 定理

陈述

白话：一族光滑方向能被拼成薄片，当且仅当这族方向对合 —— 没有别的障碍。这是一阶偏微分方程组可解的几何版本，也是叶状结构的出生证。

设 D\mathcal{D}D 是 nnn 维光滑流形 MMM 上的光滑 kkk 阶切分布。以下四条等价：

  1. D\mathcal{D}D 对合（def.involutive-distribution）；
  2. 平坦坐标存在：每点 ppp 有邻域 UUU 与坐标 (x1,…,xn)(x^{1},\ldots,x^{n})(x1,…,xn)，使 D∣U\mathcal{D}|_{U}D∣U​ 由 ∂1,…,∂k\partial_{1},\ldots,\partial_{k}∂1​,…,∂k​ 生成；
  3. 局部可积：每点 ppp 落在某块 kkk 维积分流形里（def.integral-manifold）；
  4. 叶状结构存在：MMM 被一族互不相交的极大连通积分流形（叶）覆盖，每片叶是浸入子流形。

特别地：对合当且仅当局部总有「把 D\mathcal{D}D 拉直成坐标面」的坐标。k=n−1k = n-1k=n−1 且 D=ker⁡ω\mathcal{D} = \ker\omegaD=kerω（ω\omegaω 处处非零）时，对合等价于

ω∧dω=0,\omega \wedge \mathrm{d}\omega = 0,ω∧dω=0,

这就是经典教材里的 Frobenius 条件；本图只陈述这一支，不展开。

说明

证明的骨架（详细提纲写在两条边上）：(2)  ⟹  \implies⟹(3)  ⟹  \implies⟹(1) 与 (2)  ⟹  \implies⟹(4) 都是一行计算，内容全在 (1)  ⟹  \implies⟹(2) —— 先把一个生成元拉直成 ∂1\partial_{1}∂1​（用局部流 + 流盒定理），再在横截超曲面上降秩归纳。关键技巧是：把其余生成元换成「没有 ∂1\partial_{1}∂1​ 分量」的新生成元，于是它们的括号也落在其余生成元张成的空间里（这一步只在对合时才做得到）；最后沿 ∂1\partial_{1}∂1​ 把坐标平移出去，用一个线性 ODE 的初值问题把「相切」验完。

条件是最优的：反例就是接触分布（def.involutive-distribution 的 notes 里那个）—— 它光滑、秩 222、处处非零，就是不对合，于是任何曲面都装不下它。所以「对合」不是技术假设，是充要条件的一半。

「局部」不能升成「整体」：定理给的是每点附近有叶片坐标，不保证整体上有坐标把 D\mathcal{D}D 拉直成 Rn\mathbb{R}^{n}Rn 的坐标面（那要求叶空间本身是乘积流形）。稠密叶（环面上的无理斜率线）就是反例：局部全是直线，整体却绕回来稠密。

分析版本：Frobenius 等价于「一阶线性偏微分方程组 ∂if=∑jaij∂jf\partial_{i}f = \sum_{j} a^{j}_{i}\partial_{j}f∂i​f=∑j​aij​∂j​f（i>ki > ki>k）局部可解」的相容性条件。相容性条件就是对合，而它恰好是「混合偏导可交换」（d2=0\mathrm{d}^{2} = 0d2=0）的读法 —— 与 def.exterior-derivative 的 notes 里那句「d2=0\mathrm{d}^{2} = 0d2=0 与结构方程同源」是同一件事。

口径：本图用「kkk 维子空间族」的语言；一般教材用「微分理想 I⊆Ω∙(M)I \subseteq \Omega^{\bullet}(M)I⊆Ω∙(M) 的积分流形」，两者等价（取 III 为湮灭 D\mathcal{D}D 的形式生成的理想）。本图不引入理想语言，以免两套记号打架。

⚠️ 定理的 k=nk = nk=n 情形平凡（D=TM\mathcal{D} = TMD=TM 总对合、任意坐标都平坦），k=0k = 0k=0 也平凡；有内容的只有 1≤k≤n−11 \le k \le n-11≤k≤n−1，而 k=1k = 1k=1 又总是对合（见 def.involutive-distribution）。所以真正的例子从「2≤k≤n−12 \le k \le n-12≤k≤n−1」才开始。
