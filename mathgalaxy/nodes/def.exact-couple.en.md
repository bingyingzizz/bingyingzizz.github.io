## Statement · **draft**
Let $\mathcal{A}$ be an abelian category and $D = \bigoplus D^{p,q}$, $E = \bigoplus E^{p,q}$ bigraded objects. An **exact couple** is a triple $(D, E, i, j, k)$ forming the "triangle"

$$D \xrightarrow{\ i\ } D \xrightarrow{\ j\ } E \xrightarrow{\ k\ } D ,$$
