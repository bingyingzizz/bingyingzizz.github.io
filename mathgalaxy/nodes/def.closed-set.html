陈述

设 (X,T)(X, \mathcal{T})(X,T) 是拓扑空间。

  • F⊆XF \subseteq XF⊆X 是闭集：X∖FX \setminus FX∖F 是开集；
  • A⊆XA \subseteq XA⊆X 的闭包 cl⁡A\operatorname{cl} AclA：一切包含 AAA 的闭集之交（最小的那个闭集）；
  • AAA 稠密：cl⁡A=X\operatorname{cl} A = XclA=X；
  • xxx 的邻域：任何含 xxx 的开集（的包含者）。

由 De Morgan 律，开集的三条公理翻译成闭集就是：∅,X\emptyset, X∅,X 闭；任意交闭；有限并闭。

说明

⭐ 开与闭不是互斥的：∅\emptyset∅ 与 XXX 既开又闭；在 R\mathbb{R}R 里 [0,1][0, 1][0,1] 是闭的，[0,1)[0, 1)[0,1) 既不开也不闭。

闭包是「把极限点都收进来」：在距离空间里 cl⁡A\operatorname{cl} AclA 恰好是「AAA 中某个序列的极限」全体。
