陈述

设 (X,T)(X, \mathcal{T})(X,T) 是拓扑空间。

  • F⊆XF \subseteq XF⊆X 是闭集：X∖FX \setminus FX∖F 是开集；
  • A⊆XA \subseteq XA⊆X 的闭包 A‾\overline{A}A：一切包含 AAA 的闭集之交（最小的那个闭集）；
  • AAA 稠密：A‾=X\overline{A} = XA=X；
  • xxx 的邻域：任何含 xxx 的开集（的包含者）。

由 De Morgan 律，开集的三条公理翻译成闭集就是：∅,X\emptyset, X∅,X 闭；任意交闭；有限并闭。

说明

⭐ 开与闭不是互斥的：∅\emptyset∅ 与 XXX 既开又闭；在 R\mathbb{R}R 里 [0,1][0, 1][0,1] 是闭的，[0,1)[0, 1)[0,1) 既不开也不闭。

闭包是「把极限点都收进来」：在距离空间里 A‾\overline{A}A 恰好是「AAA 中某个序列的极限」全体。

Statement draft

Let (X,T)(X, \mathcal{T})(X,T) be a topological space.

  • F⊆XF \subseteq XF⊆X is closed: X∖FX \setminus FX∖F is open;
  • the closure A‾\overline{A}A of A⊆XA \subseteq XA⊆X: the intersection of all closed sets containing AAA (the smallest such closed set);
  • AAA is dense: A‾=X\overline{A} = XA=X;
  • a neighbourhood of xxx: any open set containing xxx (or any set containing such an open set).

By De Morgan's laws, the three axioms for open sets become, for closed sets: ∅,X\emptyset, X∅,X are closed; arbitrary intersections are closed; finite unions are closed.

Notes draft

Open and closed are not opposites: ∅\emptyset∅ and XXX are both open and closed; in R\mathbb{R}R, [0,1][0, 1][0,1] is closed while [0,1)[0, 1)[0,1) is neither open nor closed.

The closure "collects all the limit points": in a metric space, A‾\overline{A}A is exactly the set of limits of sequences in AAA.
