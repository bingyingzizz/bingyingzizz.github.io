# Right Exactness of the Tensor Functor　`prop.tensor-right-exact`
English entry · root `../`
[in graph](../#n=prop.tensor-right-exact)　·　[Chinese page (authoritative)](./prop.tensor-right-exact.md)

$$M_{1} \otimes_{R} N \xrightarrow{\;f \otimes 1\;} M \otimes_{R} N \xrightarrow{\;g \otimes 1\;} M_{2} \otimes_{R} N \longrightarrow 0 .$$

Moreover the following are equivalent: (i) $(-) \otimes_{R} N$ is **exact**; (ii) for every injection $M_{1} \rightarrowtail M$, the map $M_{1} \otimes N \to M \otimes N$ is still injective; (iii) $N$ is **flat**.

(The right-hand $\to 0$ is always exact; only the left $0$ can fail.)
