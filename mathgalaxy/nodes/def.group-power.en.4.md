# group power　`def.group-power`
English entry · root `../`
[in graph](../#n=def.group-power)　·　[Chinese page (authoritative)](./def.group-power.md)

⭐ **Order of an element**: if there is $n \ge 1$ with $x^{n} = e$, the least such $n$ is called the order of $x$; it is exactly the step at which powers return to the identity. The set of all integer powers $\{x^{n} : n \in \mathbb{Z}\}$ forms, inside $G$, the cyclic subgroup $\langle x \rangle$.

⚠ In a nonabelian group $(xy)^{n} \ne x^{n} y^{n}$ (for $n \ge 2$); this holds only when $x, y$ commute. But $x^{m} x^{n} = x^{m+n}$ always holds for the **same** $x$, guaranteed by associativity.
