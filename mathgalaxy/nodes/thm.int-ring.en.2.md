# Z is a commutative integral domain　`thm.int-ring`
English entry · root `../`
[in graph](../#n=thm.int-ring)　·　[Chinese page (authoritative)](./thm.int-ring.md)

**(iv)** $\le$ is a total order compatible with the operations: $x \le y \implies x + z \le y + z$, $x \le y,\ 0 \le z \implies xz \le yz$;

**(v)** $n \mapsto [n, 0]$ is an **injection** from $\mathbb{N}$ to $\mathbb{Z}$, preserving addition, multiplication, and order.

## Notes · **draft**
⭐ Each item is "move to representatives and use the arithmetic laws of $\mathbb{N}$". There is no subtraction in $\mathbb{N}$, so addition in $\mathbb{Z}$ is written $[a,b] + [c,d] = [a+c, b+d]$ — the $+$ inside the representatives is the $+$ of `thm.nat-arith-laws`.
