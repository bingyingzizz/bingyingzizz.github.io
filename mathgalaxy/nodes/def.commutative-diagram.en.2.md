# diagram and commutative diagram　`def.commutative-diagram`
English entry · root `../`
[in graph](../#n=def.commutative-diagram)　·　[Chinese page (authoritative)](./def.commutative-diagram.md)

If between any two objects of $I$ there is **at most one morphism** (such an $I$ is called a **preorder**), then $D$ is called a **commutative diagram** over $I$.

## Notes · **draft**
**Commutativity is a property of the indexing category, not something the functor supplies.** “$I$ is a preorder” holds if and only if “every $I$-shaped diagram commutes”: then two paths in $I$ with the same source and target compose to the **unique** morphism of $\operatorname{Hom}(i, j)$, hence are equal.
