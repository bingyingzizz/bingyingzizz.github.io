# Banach Groups Are Acyclic on Stone Spaces　`prop.banach-stone-acyclic`
English entry · root `../`
[in graph](../#n=prop.banach-stone-acyclic)　·　[Chinese page (authoritative)](./prop.banach-stone-acyclic.md)

**Relation to acyclicity with constant coefficients on Stone spaces.** The constant-coefficient result uses **discrete** abelian groups as coefficients (the extreme case of a discrete topology). This result uses **Banach** abelian groups, with their complete norm structure. The conclusions have the same form, but the proofs differ. Constant coefficients use profinite inverse limits, while Banach coefficients use $K$-boundedness and Čech complexes.
