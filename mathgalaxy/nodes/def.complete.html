{xn} 是Cauchy 列  ⟹  ∃x∈X:xn→x\{x_n\}\text{ 是} Cauchy\text{ 列} \implies \exists x \in X : x_n \to x{xn​} 是Cauchy 列⟹∃x∈X:xn​→x

说明

「收敛   ⟹  Cauchy\implies Cauchy⟹Cauchy」永远成立；「Cauchy  ⟹  Cauchy \impliesCauchy⟹ 收敛」才是完备性的内容。

例子：Rn\mathbb{R}^{n}Rn、Cn\mathbb{C}^{n}Cn、任何 Banach 空间都完备；Q\mathbb{Q}Q 不完备（3, 3.1, 3.14, …, 一个收敛到 2\sqrt 22​ 的 Cauchy 列在 Q\mathbb{Q}Q 中不收敛）。

闭子集继承完备：XXX 完备时，A⊆XA \subseteq XA⊆X 作为子空间完备   ⟺  A\iff A⟺A 在 XXX 中闭。这条在下面「子集的紧性刻画」里要用。

  • 本页 ⟹ 列紧推出
    完备 + 全有界   ⟹  \implies⟹ 列紧（对角线法）

    设 XXX 完备且全有界，{xn}\{x_{n}\}{xn​} 是 XXX 中任一序列。要抽出一个收敛子列。

    ① 抽一个「直径越来越小」的子列。 对 k=1,2,3k = 1, 2, 3k=1,2,3 … 依次操作：由全有界，XXX 能被有限个半径 1/k 的球盖住，于是其中一个球含有当前子列中的无穷多项（抽屉原理：有限个球盖住无穷多项，必有一个球含无穷多项）。把子列限制到这个球里。

    这样得到一串子列

    {xn}⊇{xn(1)}⊇{xn(2)}⊇⋯\{x_n\} \supseteq \{x^{(1)}_n\} \supseteq \{x^{(2)}_n\} \supseteq \cdots{xn​}⊇{xn(1)​}⊇{xn(2)​}⊇⋯

    其中第 kkk 个子列的项全部落在某个半径 1/k 的球内，因此它任意两项的距离 <2/k< 2/k<2/k。

    ② 对角线。 取 yk=x{(k)}ky_{k} = x^\{(k)\}_{k}yk​=x{(k)}k​（第 kkk 个子列的第 kkk 项）。则 {yk}\{y_{k}\}{yk​} 是 {xn}\{x_{n}\}{xn​} 的子列；且对 k,l≥Kk, l \ge Kk,l≥K，yky_{k}yk​ 与 yly_{l}yl​ 都是第 KKK 个子列的项（下标 ≥K\ge K≥K 的项都在里面），故

    d(yk,yl)<2/Kd(y_k, y_l) < 2/Kd(yk​,yl​)<2/K

    于是 {yk}\{y_{k}\}{yk​} 是 Cauchy 列。

    ③ 由 XXX 完备，{yk}\{y_{k}\}{yk​} 收敛。于是 {xn}\{x_{n}\}{xn​} 有收敛子列，XXX 列紧。∎

    ① 里「无穷多项落进某一个球」用到抽屉原理（有限情形，不需要选择）。② 的对角线抽取也不需要选择 —— 所有选取都由「取第 kkk 个子列的第 kkk 项」唯一确定。

    列紧   ⟹  \implies⟹ 完备

    设 XXX 列紧，{xn}\{x_{n}\}{xn​} 是 XXX 中的 Cauchy 列。

    ① 由列紧，{xn}\{x_{n}\}{xn​} 有收敛子列 x{nk}→x∈Xx_\{n_{k}\} \to x \in Xx{​nk​}→x∈X。

    ② Cauchy 列只要有收敛子列，就整体收敛到同一个极限：给定 ε>0\varepsilon > 0ε>0，取 NNN 使 m,n≥Nm, n \ge Nm,n≥N 时 d(xm,xn)<ε/2d(x_{m}, x_{n}) < \varepsilon /2d(xm​,xn​)<ε/2；再取 KKK 使 k≥Kk \ge Kk≥K 时 nk≥Nn_{k} \ge Nnk​≥N 且 d(x{nk},x)<ε/2d(x_\{n_{k}\}, x) < \varepsilon /2d(x{​nk​},x)<ε/2。于是对 n≥Nn \ge Nn≥N，取 k≥Kk \ge Kk≥K 使 nk≥Nn_{k} \ge Nnk​≥N，得
