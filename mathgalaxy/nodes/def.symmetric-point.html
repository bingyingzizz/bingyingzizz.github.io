又称关于圆的对称点

陈述

设圆 CCC 的圆心为 aaa、半径为 RRR。称 zzz 与 z∗z^{*}z∗ 关于 CCC 对称，如果

(z−a)(z∗‾−aˉ)=R2,(z - a)(\overline{z^{*}} - \bar a) = R^{2},(z−a)(z∗−aˉ)=R2,

并且 arg⁡(z−a)=arg⁡(z∗−a)\arg(z - a) = \arg(z^{} - a)arg(z−a)=arg(z∗−a)（即 a,z,z∗a, z, z^{}a,z,z∗ 三点共线且同向）。

（等价地：z∗z^{}z∗ 在射线 a+t(z−a)a + t(z - a)a+t(z−a)（t>0t > 0t>0）上，且 ∣z−a∣ ∣z∗−a∣=R2|z - a|\,|z^{} - a| = R^{2}∣z−a∣∣z∗−a∣=R2。）

关于直线 LLL 的对称就是通常的镜像；把 LLL 看成过 ∞\infty∞ 的圆，两种情形可以合成一句：「z,z∗z, z^{}z,z∗ 关于圆 CCC 对称   ⟺  \iff⟺ 每个过 z,z∗z, z^{}z,z∗ 的圆都与 CCC 正交」。

说明

为什么这样定义：在圆内 ∣z−a∣<R|z - a| < R∣z−a∣<R，对称点落在圆外 —— 这是个反演。它把「圆心」和「无穷远点」互相对应（z=az = az=a 时 z∗=∞z^{*} = \inftyz∗=∞），这正是 prop.mobius-symmetry 能让对称性在分式线性变换下保持的原因。

⭐ 计算式（做题最常用）：

z∗=a+R2z−a‾.z^{*} = a + \frac{R^{2}}{\overline{z - a}}.z∗=a+z−a​R2​.

关于实轴的对称就是 z∗=zˉz^{} = \bar zz∗=zˉ；关于单位圆的对称是 z∗=1/zˉz^{} = 1/\bar zz∗=1/zˉ。

⚠️ 对称点不是「到圆心的距离相等」：那是对径点。对称是反演，距离乘积固定。

  • 本页 ⟹ 分式线性变换保对称点推出
    共形（保角）保持「正交圆」的刻画

    由 def.symmetric-point 的等价刻画：z,z∗z, z^{*}z,z∗ 关于 CCC 对称   ⟺  \iff⟺ 每个过它们的圆正交于 CCC。

    分式线性变换双全纯、导数非零，由 prop.conformal-iff 保角，故「正交」被保持；同时它把「过 z,z∗z, z^{}z,z∗ 的圆」映成「过 Tz,Tz∗Tz, Tz^{}Tz,Tz∗ 的圆」，把 CCC 映成 T(C)T(C)T(C)。于是同一个刻画对 Tz,Tz∗Tz, Tz^{*}Tz,Tz∗ 与 T(C)T(C)T(C) 成立。∎

    造映射时最好用的一条：定几对对称点，变换就被逼出来了。

  • 本页 ⟹ 边界对应定理推出
    内部双全纯 + Jordan 边界   ⟹  \implies⟹ 延拓成闭包上的同胚

    （骨架，完整证明是 Carathéodory–Osgood 定理。）

    第一步：径向极限存在。对每个 ζ∈∂Ω\zeta \in \partial\Omegaζ∈∂Ω，证明 f(rζ)f(r\zeta)f(rζ) 当 r→1−r \to 1^{-}r→1− 时有极限 —— 用「Ω\OmegaΩ 的边界是 Jordan 曲线」把区域夹在两条圆弧之间，再用 Schwarz 引理型的估计控制振荡。

    第二步：极限映射连续且单射。两部分都靠 Jordan 曲线的分离性质：若两个边界点映到同一点，则内部会出现「被挤压」的连通分支，与单叶性矛盾。

    第三步：紧空间上的连续单射 = 同胚。Ω‾\overline{\Omega}Ω 紧、D‾\overline{\mathbb{D}}D Hausdorff，连续单射自动是同胚。∎

    它给 S–C 公式的「xkx_{k}xk​ 对应顶点」提供了合法性。

  • 分式线性变换、保角性 ⟹ 本页推出
    对称点是反演：z∗=a+R2/(z−a)‾z^{*} = a + R^{2}/\overline{(z - a)}z∗=a+R2/(z−a)​

    由 def.mobius，z↦a+R2/(z−a)‾z \mapsto a + R^{2}/\overline{(z - a)}z↦a+R2/(z−a)​ 是「平移 + 反演 + 伸缩」的复合，其中 z↦1/zˉz \mapsto 1/\bar zz↦1/zˉ 是共轭再取倒数，属于反全纯的分式映射。

    保角性的对照：prop.conformal-iff 说全纯 + 导数非零 = 保角且保定向；而反演是反全纯的，保角但反定向。对称点正是在这个反全纯映射下与 zzz 配对，所以「关于圆对称」与「关于直线镜像」是同一件事的两种外观（直线 = 过 ∞\infty∞ 的圆）。

    验算：∣z−a∣ ∣z∗−a∣=∣z−a∣⋅R2/∣z−a∣=R2|z - a|\,|z^{} - a| = |z - a| \cdot R^{2}/|z - a| = R^{2}∣z−a∣∣z∗−a∣=∣z−a∣⋅R2/∣z−a∣=R2，且 z∗−az^{} - az∗−a 与 z−az - az−a 同向（因为取了共轭再取倒数只改模长不改方向）。∎

    对称 ≠\ne= 到圆心等距；对称是反演，距离的乘积固定。
