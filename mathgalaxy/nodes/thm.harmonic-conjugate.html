又称调和函数的共轭

陈述

白话：在单连通区域上，每个调和函数都是某个全纯函数的实部 —— 那个虚部叫它的「共轭调和函数」，只差一个常数。

设 Ω\OmegaΩ 是单连通区域，uuu 在 Ω\OmegaΩ 上调和。则存在 Ω\OmegaΩ 上的全纯函数 fff，使

Re⁡f=u.\operatorname{Re} f = u.Ref=u.

并且 vvv（共轭调和函数，满足 vx=−uyv_x = -u_yvx​=−uy​、vy=uxv_y = u_xvy​=ux​）在相差一个实常数的意义下唯一 —— 等价地，f=u+ivf = u + ivf=u+iv 在相差一个纯虚常数的意义下唯一。

说明

⭐ 证明是「闭 1-形式必恰当」：令 ω=−uy dx+ux dy\omega = -u_y\,\mathrm{d}x + u_x\,\mathrm{d}yω=−uy​dx+ux​dy，则

dω=(uxx+uyy) dx∧dy=0,\mathrm{d}\omega = (u_{xx} + u_{yy})\,\mathrm{d}x \wedge \mathrm{d}y = 0,dω=(uxx​+uyy​)dx∧dy=0,

Ω\OmegaΩ 单连通   ⟹  \implies⟹ 存在 vvv 使 dv=ω\mathrm{d}v = \omegadv=ω，即 vx=−uyv_x = -u_yvx​=−uy​、vy=uxv_y = u_xvy​=ux​；这两式正是 (u,v)(u, v)(u,v) 的 Cauchy–Riemann 方程，故 f=u+ivf = u + ivf=u+iv 全纯。

⭐ 唯一性：若 Re⁡f1=Re⁡f2=u\operatorname{Re} f_1 = \operatorname{Re} f_2 = uRef1​=Ref2​=u，则 g=f1−f2g = f_1 - f_2g=f1​−f2​ 纯虚且全纯；写 g=iyg = iyg=iy（yyy 实值），Cauchy–Riemann 给 yx=yy=0y_x = y_y = 0yx​=yy​=0，故 yyy 是常数。

⚠ 单连通不能去掉：u(z)=ln⁡∣z∣u(z) = \ln|z|u(z)=ln∣z∣ 在 C×\mathbb{C}^{\times}C× 上调和，但它不是任何单值全纯函数的实部 —— 那需要 Log⁡\operatorname{Log}Log 本身，而 Log⁡\operatorname{Log}Log 是多值的。绕原点一圈，∮ω=2π≠0\oint \omega = 2\pi \ne 0∮ω=2π=0。

📌 反方向（全纯   ⟹  \implies⟹ 实部调和）不需要单连通，只要 Cauchy–Riemann 方程。所以「调和」比「全纯的实部」宽一点点，缺的正是拓扑条件。
