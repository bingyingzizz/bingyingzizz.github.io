陈述

环 RRR 的（左）整体维数是全体左模的投射维数的上确界：

gl.dim⁡R:=sup⁡Mpd⁡RM,\operatorname{gl.dim} R := \sup_{M} \operatorname{pd}_{R} M ,gl.dimR:=Msup​pdR​M,

上确界取遍所有左 RRR-模 MMM。等价地

gl.dim⁡R=sup⁡Mid⁡RM,\operatorname{gl.dim} R = \sup_{M} \operatorname{id}_{R} M ,gl.dimR=Msup​idR​M,

也等于使「Ext⁡Rn(−,−)\operatorname{Ext}^{n}_{R}(-,-)ExtRn​(−,−) 对一切 n>dn > dn>d 恒为零」成立的最小 ddd。

相应地还有右整体维数 gl.dim⁡Rop\operatorname{gl.dim} R^{\mathrm{op}}gl.dimRop；两者可以不相等。

说明

为什么这三个上确界相等：由维数消失刻画，「pd⁡RM≤d\operatorname{pd}_{R} M \le dpdR​M≤d 对一切 MMM」「id⁡RN≤d\operatorname{id}_{R} N \le didR​N≤d 对一切 NNN」「Ext⁡Rn(−,−)\operatorname{Ext}^{n}_{R}(-,-)ExtRn​(−,−) 对一切 n>dn > dn>d 恒为零」是同一句话 —— 三条都只是在说「这一整族群在 n>dn > dn>d 处消失」✓。

四个基本例子：

  • gl.dim⁡R=0  ⟺  R\operatorname{gl.dim} R = 0 \iff Rgl.dimR=0⟺R 半单（Wedderburn–Artin：每个模都投射）；域上为 000；
  • gl.dim⁡Z=1\operatorname{gl.dim} \mathbb{Z} = 1gl.dimZ=1（主理想整环，见「主理想整环的整体维数」）；
  • gl.dim⁡k[x1,…,xn]=n\operatorname{gl.dim} k[x_{1}, \ldots, x_{n}] = ngl.dimk[x1​,…,xn​]=n（Hilbert 合冲定理 + Koszul 复形）；
  • gl.dim⁡R=∞\operatorname{gl.dim} R = \inftygl.dimR=∞ 会发生（例如 k[x,y]/(xy)k[x,y]/(xy)k[x,y]/(xy)），此时「没有统一的上界」。

⭐ 它衡量的是「计算 Ext⁡\operatorname{Ext}Ext 需要多少层」：整体维数越小，导出函子的机器越短。000 维就是「什么都不用算」，111 维就是「只需两条正合列互相推」，这也是阿贝尔群那套同调代数如此简单的原因。

⚠️ 左右之分不是学究：非交换环上左、右整体维数可以不相等；交换环上两者相等，于是符号可以只写一个。
