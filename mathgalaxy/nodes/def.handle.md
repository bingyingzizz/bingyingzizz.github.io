# 环柄　`def.handle`
环柄（连通和 $T^{2}$）
layer 22 · 定义 · 曲面的地形 · 拓扑学
[在星图里打开](../#n=def.handle)　·　[节点索引](../index.md)

设 $S$ 是闭曲面。在 $S$ 上挖去两个开圆盘，得到边界为两个圆周的曲面；再把圆柱 $S^{1}\times[0,1]$ 的两端分别粘到这两个边界圆周上，所得闭曲面称为在 $S$ 上**加一个环柄**。等价地，加环柄就是与环面作连通和：$S\mapsto S\#T^{2}$。
