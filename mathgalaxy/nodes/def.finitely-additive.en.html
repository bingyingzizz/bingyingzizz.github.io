Statement

If μ\muμ satisfies only (i) and finite additivity:

A,B∈M, A∩B=∅  ⟹  μ(A∪B)=μ(A)+μ(B)A, B \in \mathcal{M},\ A \cap B = \emptyset \implies \mu(A \cup B) = \mu(A) + \mu(B)A,B∈M, A∩B=∅⟹μ(A∪B)=μ(A)+μ(B)

(by induction this extends to any finite number of disjoint sets),

then μ\muμ is called a finitely additive measure.

Notes

It is even weaker than a premeasure: a premeasure is countably additive (only its domain is a ring), while a finitely additive measure requires only finite additivity.

⚠ Finitely additive ≠\ne= countably additive: on N\mathbb{N}N define μ(E)=0\mu (E) = 0μ(E)=0 (EEE finite), μ(E)=+∞\mu (E) = +\inftyμ(E)=+∞ (EEE infinite); it is finitely additive, yet fails countable additivity for ⋃n{n}=N\bigcup _{n} \{n\} = \mathbb{N}⋃n​{n}=N.

Historically (the Banach–Tarski era) "measures" using only finite additivity were seriously considered; the problem is not constructing length (Lebesgue measure itself is finitely additive, m((a,b])=b−am((a,b]) = b - am((a,b])=b−a being length), but that finite additivity cannot support countable limit theorems (MCT, DCT and Fubini all collapse).
