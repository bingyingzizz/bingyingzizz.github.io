# Christoffel Symbols　`def.christoffel-symbol`
English entry · root `../`
[in graph](../#n=def.christoffel-symbol)　·　[Chinese page (authoritative)](./def.christoffel-symbol.md)

⚠️ $\Gamma^{k}_{ij}$ **is not a tensor**: under a change of coordinates a non-homogeneous second-derivative term appears, so "$\Gamma$ equals some number at $p$" depends on the coordinates. But "there **exist** coordinates with $\Gamma(p) = 0$" is a coordinate-independent fact (normal coordinates); the difference between the two is "a numerical value" versus "existence".

**Why it determines geodesics**: the only external datum in the geodesic equation is $\Gamma$, so "which curves are geodesics" is entirely a matter of $I$ — already the first step of intrinsic geometry.
