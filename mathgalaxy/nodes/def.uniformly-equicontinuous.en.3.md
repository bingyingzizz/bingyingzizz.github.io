# uniform equicontinuity　`def.uniformly-equicontinuous`
English entry · root `../`
[in graph](../#n=def.uniformly-equicontinuous)　·　[Chinese page (authoritative)](./def.uniformly-equicontinuous.md)

⚠️ Without compactness the converse fails: for $K = \mathbb{R}$ and $f_n(x) = x/n$, the family is pointwise equicontinuous (the oscillation near each point is uniformly small), but it is not uniformly equicontinuous on $\mathbb{R}$ ($|f_n(n) - f_n(n+1)| = 1/n$, so $\eta$ would have to depend on $n$).

⭐ The "equicontinuity" in Arzelà–Ascoli is exactly this notion on a compact metric space; `thm.equicontinuous-uniform` is the bridge that upgrades the pointwise version to it.
