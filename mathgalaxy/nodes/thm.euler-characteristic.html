Euler 示性数：数单纯形与数 Betti 数给出同一个数

  • 定理
  • 依赖深度 layer 25
  • 拓扑学

thm.euler-characteristic · 代数拓扑 · Euler 示性数 · Betti 数 · 同调群

又称Euler 示性数·χ·χ(M)·欧拉示性数

陈述

设 KKK 是有限单纯复形，αp\alpha_{p}αp​ 是它的 ppp-单纯形个数，βp:=rank⁡Hp(K)\beta_{p} := \operatorname{rank} H_{p}(K)βp​:=rankHp​(K) 是第 ppp 个 Betti 数（自由部分的秩）。则

χ(K)=∑p(−1)pαp=∑p(−1)pβp.\chi(K) = \sum_{p} (-1)^{p} \alpha_{p} = \sum_{p} (-1)^{p} \beta_{p}.χ(K)=p∑​(−1)pαp​=p∑​(−1)pβp​.

也就是说：左边只是数单纯形的个数，右边只依赖同调群。

说明

两个例子：

  • S2S^{2}S2 的四面体剖分：α=(4,6,4,0)\alpha = (4, 6, 4, 0)α=(4,6,4,0)，χ=4−6+4−0=2\chi = 4 - 6 + 4 - 0 = 2χ=4−6+4−0=2；β=(1,0,1)\beta = (1, 0, 1)β=(1,0,1)，∑=1−0+1=2\sum = 1 - 0 + 1 = 2∑=1−0+1=2 ✓
  • 实射影平面 RP2\mathbb{RP}^{2}RP2 的最小剖分（6 顶点 / 15 棱 / 10 面）：χ=6−15+10=1\chi = 6 - 15 + 10 = 1χ=6−15+10=1；而 H1(RP2)=Z/2H_{1}(\mathbb{RP}^{2}) = \mathbb{Z}/2H1​(RP2)=Z/2 秩为零，所以 ∑(−1)pβp=1−0+0=1\sum(-1)^{p}\beta_{p} = 1 - 0 + 0 = 1∑(−1)pβp​=1−0+0=1 ✓

⚠️ 注意右端用的是秩（Betti 数），不是 #Hp\#H_{p}#Hp​。挠部（如 Z/2\mathbb{Z}/2Z/2）不进交错和；上面 RP2\mathbb{RP}^{2}RP2 那个例子正是靠这一点才对得上。

⭐ 这条定理真正的价值不在等式本身，而在于右端只依赖同调——所以 χ\chiχ 与三角剖分的选法无关（配合 单纯逼近），是拓扑不变量。反过来，计算 χ\chiχ 时只需数单纯形，根本不用算同调。

证明的思路（见边上的完整算式）：两次秩-零化度，一次作用在 ∂p\partial_{p}∂p​ 上，一次作用在 Zp/Bp≅HpZ_{p}/B_{p} \cong H_{p}Zp​/Bp​≅Hp​ 上；边缘群的维数在交错和里成对相消（望远镜式）。

Statement draft

Let KKK be a finite simplicial complex, αp\alpha_{p}αp​ the number of its ppp-simplices, and βp:=rank⁡Hp(K)\beta_{p} := \operatorname{rank} H_{p}(K)βp​:=rankHp​(K) the ppp-th Betti number (the rank of the free part). Then

χ(K)=∑p(−1)pαp=∑p(−1)pβp.\chi(K) = \sum_{p} (-1)^{p} \alpha_{p} = \sum_{p} (-1)^{p} \beta_{p}.χ(K)=p∑​(−1)pαp​=p∑​(−1)pβp​.

That is: the left side merely counts simplices, while the right side depends only on the homology groups.

Notes draft

Two examples:

  • The tetrahedral subdivision of S2S^{2}S2: α=(4,6,4,0)\alpha = (4, 6, 4, 0)α=(4,6,4,0), χ=4−6+4−0=2\chi = 4 - 6 + 4 - 0 = 2χ=4−6+4−0=2; β=(1,0,1)\beta = (1, 0, 1)β=(1,0,1), ∑=1−0+1=2\sum = 1 - 0 + 1 = 2∑=1−0+1=2 ✓
  • The minimal subdivision of the real projective plane RP2\mathbb{RP}^{2}RP2 (6 vertices / 15 edges / 10 faces): χ=6−15+10=1\chi = 6 - 15 + 10 = 1χ=6−15+10=1; while H1(RP2)=Z/2H_{1}(\mathbb{RP}^{2}) = \mathbb{Z}/2H1​(RP2)=Z/2 has rank zero, so ∑(−1)pβp=1−0+0=1\sum(-1)^{p}\beta_{p} = 1 - 0 + 0 = 1∑(−1)pβp​=1−0+0=1 ✓

⚠ Note that the right side uses the rank (Betti number), not #Hp\#H_{p}#Hp​. Torsion (e.g. Z/2\mathbb{Z}/2Z/2) does not enter the alternating sum; the example RP2\mathbb{RP}^{2}RP2 above matches precisely because of this.

⭐ The real value of the theorem is not the identity itself but that the right side depends only on homology — hence χ\chiχ is independent of the triangulation (together with 单纯逼近) and is a topological invariant. Conversely, to compute χ\chiχ one only counts simplices, without computing homology at all.

Idea of the proof (the full computation is on the edge): twice rank–nullity, once on ∂p\partial_{p}∂p​ and once on Zp/Bp≅HpZ_{p}/B_{p} \cong H_{p}Zp​/Bp​≅Hp​; the dimensions of the boundary groups cancel in pairs in the alternating sum (telescoping).

推出 3

  • 本页 ⟹ 闭曲面分类定理推出
    标准形上用 χ\chiχ 区分曲面

    分类定理第三步在标准形上读不变量：可定向性与 χ\chiχ。要断言「χ\chiχ 不同则不同胚」，必须先知道 χ\chiχ 是同胚不变量 —— Euler 示性数 给出 χ(K)=∑p(−1)pαp=∑p(−1)pβp\chi(K)=\sum_{p}(-1)^{p}\alpha_{p}=\sum_{p}(-1)^{p}\beta_{p}χ(K)=∑p​(−1)pαp​=∑p​(−1)pβp​，右端只依赖同调型，于是同伦等价（从而同胚）保持 χ\chiχ。同一等式还让「由三角剖分数出的 χ\chiχ」与「由 Betti 数算出的 χ\chiχ」对接，标准形与任意剖分才可比较。∎

    不同胚性用 χ\chiχ 作不变量（χ\chiχ 在同胚下不变）。这条用定理当原理：Euler 示性数 说「数单纯形 = 数 Betti 数」，正好给出 χ\chiχ 的组合与同调两种算法。

  • 本页 ⟹ Euler 示性数与亏格推出
    χ\chiχ 的两种算法给出 χ=2−2g\chi=2-2gχ=2−2g

    命题先由任一三角剖分数出 χ(S)\chi(S)χ(S)，再由 g=12rank⁡H1(S;Z)g=\tfrac12\operatorname{rank}H_{1}(S;\mathbb{Z})g=21​rankH1​(S;Z) 得 β0=1\beta_{0}=1β0​=1、β1=2g\beta_{1}=2gβ1​=2g、β2=1\beta_{2}=1β2​=1，于是 χ=2−2g\chi=2-2gχ=2−2g。把两种算法接起来靠的正是 Euler 示性数 的 χ=∑p(−1)pαp=∑p(−1)pβp\chi=\sum_{p}(-1)^{p}\alpha_{p}=\sum_{p}(-1)^{p}\beta_{p}χ=∑p​(−1)pαp​=∑p​(−1)pβp​；没有它，组合侧的数与同调侧的 ggg 无法对齐，「与剖分无关」也无从谈起。∎

    χ\chiχ 的两种算法（数单纯形 / 数 Betti 数）相等，正是这条定理的内容。

  • 本页 ⟹ Euler 示性数与不可定向亏格推出
    χ=V−E+F\chi=V-E+Fχ=V−E+F 递推给出 χ=2−k\chi=2-kχ=2−k

    先算 χ(RP2)=6−15+10=1\chi(\mathbb{RP}^{2})=6-15+10=1χ(RP2)=6−15+10=1（正二十面体按对径点粘合），再用连通和公式 χ(Sk)=χ(Sk−1)+χ(RP2)−2\chi(S_{k})=\chi(S_{k-1})+\chi(\mathbb{RP}^{2})-2χ(Sk​)=χ(Sk−1​)+χ(RP2)−2 递推得 χ(Sk)=2−k\chi(S_{k})=2-kχ(Sk​)=2−k。两处用的都是 Euler 示性数 的组合算法 χ=V−E+F\chi=V-E+Fχ=V−E+F；最后「与剖分无关」再用它的同调算法 χ=∑p(−1)pβp\chi=\sum_{p}(-1)^{p}\beta_{p}χ=∑p​(−1)pβp​。∎

    χ\chiχ 的组合算法（V−E+FV - E + FV−E+F）是这一条的另一半。

推出 2

  • 链群、单纯同调群 ⟹ 本页推出
    两次秩-零化度，边缘群的维数在交错和里相消

    设 KKK 有限，αp=dim⁡QCp\alpha_{p} = \dim_{\mathbb{Q}} C_{p}αp​=dimQ​Cp​（即 ppp-单纯形个数），zp=rank⁡Zpz_{p} = \operatorname{rank} Z_{p}zp​=rankZp​、bp=rank⁡Bp=rank⁡∂p+1b_{p} = \operatorname{rank} B_{p} = \operatorname{rank}\partial_{p+1}bp​=rankBp​=rank∂p+1​、hp=rank⁡Hph_{p} = \operatorname{rank} H_{p}hp​=rankHp​。

    这些数都有限（Z\mathbb{Z}Z 是主理想整环，子模自由）。

    第一次秩-零化度（对 ∂p:Cp→Cp−1\partial_{p} : C_{p} \to C_{p-1}∂p​:Cp​→Cp−1​）：

    αp=dim⁡ker⁡∂p+rank⁡∂p=zp+bp−1.\alpha_{p} = \dim\ker\partial_{p} + \operatorname{rank}\partial_{p} = z_{p} + b_{p-1}.αp​=dimker∂p​+rank∂p​=zp​+bp−1​.

    第二次（用在 0→Zp→Cp→Bp−1→00 \to Z_{p} \to C_{p} \to B_{p-1} \to 00→Zp​→Cp​→Bp−1​→0 之后，或直接看商）：因为 Hp=Zp/BpH_{p} = Z_{p}/B_{p}Hp​=Zp​/Bp​，

    zp=bp+hp.z_{p} = b_{p} + h_{p}.zp​=bp​+hp​.

    代入，得 αp=bp+hp+bp−1\alpha_{p} = b_{p} + h_{p} + b_{p-1}αp​=bp​+hp​+bp−1​。交错求和：

    ∑p(−1)pαp=∑p(−1)php+S1−S2,\sum_{p} (-1)^{p}\alpha_{p} = \sum_{p} (-1)^{p} h_{p} + S_{1} - S_{2},p∑​(−1)pαp​=p∑​(−1)php​+S1​−S2​,

    其中 S1:=∑p(−1)pbpS_{1} := \sum_{p} (-1)^{p} b_{p}S1​:=∑p​(−1)pbp​、S2:=∑p(−1)p−1bp−1S_{2} := \sum_{p} (-1)^{p-1} b_{p-1}S2​:=∑p​(−1)p−1bp−1​。这两个是同一个和（只是把下标 p−1p - 1p−1 换成 ppp），故 S1=S2S_{1} = S_{2}S1​=S2​、恰好相消，剩下 ∑p(−1)php\sum_{p}(-1)^{p} h_{p}∑p​(−1)php​。而 hp=βph_{p} = \beta_{p}hp​=βp​ 就是 Betti 数。∎

    「相消」是这条定理的全部内容：边缘群 bpb_{p}bp​ 在相邻两项里符号相反，数得再多也看不见。

  • 单纯逼近 ⟹ 本页推出
    奇异同调 === 单纯同调   ⟹  \implies⟹ χ\chiχ 与三角剖分无关

    设 X=∣K∣=∣K′∣X = |K| = |K'|X=∣K∣=∣K′∣ 是同一个空间的两个有限三角剖分。由 单纯逼近，

    Hp(K)≅Hp(X)≅Hp(K′),H_{p}(K) \cong H_{p}(X) \cong H_{p}(K'),Hp​(K)≅Hp​(X)≅Hp​(K′),

    故两个剖分的 Betti 数 βp\beta_{p}βp​ 完全相同。秩公式（对任一有限链复形）：记 cp=rank⁡Cpc_{p} = \operatorname{rank} C_{p}cp​=rankCp​、bp=rank⁡Bpb_{p} = \operatorname{rank} B_{p}bp​=rankBp​、zp=rank⁡Zpz_{p} = \operatorname{rank} Z_{p}zp​=rankZp​，则 cp=bp+zpc_{p} = b_{p} + z_{p}cp​=bp​+zp​ 且 zp=bp−1+βpz_{p} = b_{p-1} + \beta_{p}zp​=bp−1​+βp​（0→Zp→Bp−1→00 \to Z_{p} \to B_{p-1} \to 00→Zp​→Bp−1​→0 正合），于是 cp=bp+bp−1+βpc_{p} = b_{p} + b_{p-1} + \beta_{p}cp​=bp​+bp−1​+βp​。交错求和时 ∑(−1)p(bp+bp−1)=0\sum (-1)^{p}(b_{p} + b_{p-1}) = 0∑(−1)p(bp​+bp−1​)=0 抵消，故 ∑p(−1)pαp=∑p(−1)pβp\sum_{p} (-1)^{p}\alpha_{p} = \sum_{p} (-1)^{p}\beta_{p}∑p​(−1)pαp​=∑p​(−1)pβp​ —— 这条只用到链复形的秩关系，不依赖要证的结论。

    ∑p(−1)pαp(K)=∑p(−1)pβp,\sum_{p} (-1)^{p}\alpha_{p}(K) = \sum_{p} (-1)^{p}\beta_{p},p∑​(−1)pαp​(K)=p∑​(−1)pβp​,∑p(−1)pαp(K′)=∑p(−1)pβp.\sum_{p} (-1)^{p}\alpha_{p}(K') = \sum_{p} (-1)^{p}\beta_{p}.p∑​(−1)pαp​(K′)=p∑​(−1)pβp​.

    所以 χ\chiχ 只依赖 XXX 本身，可以记作 χ(X)\chi(X)χ(X)。∎

    没有这一条，χ\chiχ 只是「某个三角剖分上数单纯形」的结果，换个剖分就可能有别的值。
