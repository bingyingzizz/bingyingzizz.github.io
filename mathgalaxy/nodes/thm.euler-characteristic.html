又称Euler 示性数

陈述

设 KKK 是有限单纯复形，αp\alpha_{p}αp​ 是它的 ppp-单纯形个数，βp:=rank⁡Hp(K)\beta_{p} := \operatorname{rank} H_{p}(K)βp​:=rankHp​(K) 是第 ppp 个 Betti 数（自由部分的秩）。则

χ(K)=∑p(−1)pαp=∑p(−1)pβp.\chi(K) = \sum_{p} (-1)^{p} \alpha_{p} = \sum_{p} (-1)^{p} \beta_{p}.χ(K)=p∑​(−1)pαp​=p∑​(−1)pβp​.

也就是说：左边只是数单纯形的个数，右边只依赖同调群。

说明

两个例子：

  • S2S^{2}S2 的四面体剖分：α=(4,6,4,0)\alpha = (4, 6, 4, 0)α=(4,6,4,0)，χ=4−6+4−0=2\chi = 4 - 6 + 4 - 0 = 2χ=4−6+4−0=2；β=(1,0,1)\beta = (1, 0, 1)β=(1,0,1)，∑=1−0+1=2\sum = 1 - 0 + 1 = 2∑=1−0+1=2 ✓
  • 实射影平面 RP2\mathbb{RP}^{2}RP2 的最小剖分（6 顶点 / 15 棱 / 10 面）：χ=6−15+10=1\chi = 6 - 15 + 10 = 1χ=6−15+10=1；而 H1(RP2)=Z/2H_{1}(\mathbb{RP}^{2}) = \mathbb{Z}/2H1​(RP2)=Z/2 秩为零，所以 ∑(−1)pβp=1−0+0=1\sum(-1)^{p}\beta_{p} = 1 - 0 + 0 = 1∑(−1)pβp​=1−0+0=1 ✓

⚠️ 注意右端用的是秩（Betti 数），不是 #Hp\#H_{p}#Hp​。挠部（如 Z/2\mathbb{Z}/2Z/2）不进交错和；上面 RP2\mathbb{RP}^{2}RP2 那个例子正是靠这一点才对得上。

⭐ 这条定理真正的价值不在等式本身，而在于右端只依赖同调——所以 χ\chiχ 与三角剖分的选法无关（配合 thm.simplicial-approximation），是拓扑不变量。反过来，计算 χ\chiχ 时只需数单纯形，根本不用算同调。

证明的思路（见边上的完整算式）：两次秩-零化度，一次作用在 ∂p\partial_{p}∂p​ 上，一次作用在 Zp/Bp≅HpZ_{p}/B_{p} \cong H_{p}Zp​/Bp​≅Hp​ 上；边缘群的维数在交错和里成对相消（望远镜式）。

  • 链群、单纯同调群 ⟹ 本页推出
    两次秩-零化度，边缘群的维数在交错和里相消

    设 KKK 有限，αp=dim⁡QCp\alpha_{p} = \dim_{\mathbb{Q}} C_{p}αp​=dimQ​Cp​（即 ppp-单纯形个数），zp=rank⁡Zpz_{p} = \operatorname{rank} Z_{p}zp​=rankZp​、bp=rank⁡Bp=rank⁡∂p+1b_{p} = \operatorname{rank} B_{p} = \operatorname{rank}\partial_{p+1}bp​=rankBp​=rank∂p+1​、hp=rank⁡Hph_{p} = \operatorname{rank} H_{p}hp​=rankHp​。这些数都有限（Z\mathbb{Z}Z 是主理想整环，子模自由）。

    第一次秩-零化度（对 ∂p:Cp→Cp−1\partial_{p} : C_{p} \to C_{p-1}∂p​:Cp​→Cp−1​）：

    αp=dim⁡ker⁡∂p+rank⁡∂p=zp+bp−1.\alpha_{p} = \dim\ker\partial_{p} + \operatorname{rank}\partial_{p} = z_{p} + b_{p-1}.αp​=dimker∂p​+rank∂p​=zp​+bp−1​.

    第二次（用在 0→Zp→Cp→Bp−1→00 \to Z_{p} \to C_{p} \to B_{p-1} \to 00→Zp​→Cp​→Bp−1​→0 之后，或直接看商）：因为 Hp=Zp/BpH_{p} = Z_{p}/B_{p}Hp​=Zp​/Bp​，

    zp=bp+hp.z_{p} = b_{p} + h_{p}.zp​=bp​+hp​.

    代入，得 αp=bp+hp+bp−1\alpha_{p} = b_{p} + h_{p} + b_{p-1}αp​=bp​+hp​+bp−1​。交错求和：

    ∑p(−1)pαp=∑p(−1)php+S1−S2,\sum_{p} (-1)^{p}\alpha_{p} = \sum_{p} (-1)^{p} h_{p} + S_{1} - S_{2},p∑​(−1)pαp​=p∑​(−1)php​+S1​−S2​,

    其中 S1:=∑p(−1)pbpS_{1} := \sum_{p} (-1)^{p} b_{p}S1​:=∑p​(−1)pbp​、S2:=∑p(−1)p−1bp−1S_{2} := \sum_{p} (-1)^{p-1} b_{p-1}S2​:=∑p​(−1)p−1bp−1​。这两个是同一个和（只是把下标 p−1p - 1p−1 换成 ppp），故 S1=S2S_{1} = S_{2}S1​=S2​、恰好相消，剩下 ∑p(−1)php\sum_{p}(-1)^{p} h_{p}∑p​(−1)php​。而 hp=βph_{p} = \beta_{p}hp​=βp​ 就是 Betti 数。∎

    「相消」是这条定理的全部内容：边缘群 bpb_{p}bp​ 在相邻两项里符号相反，数得再多也看不见。

  • 单纯逼近 ⟹ 本页推出
    奇异同调 === 单纯同调   ⟹  \implies⟹ χ\chiχ 与三角剖分无关

    设 X=∣K∣=∣K′∣X = |K| = |K'|X=∣K∣=∣K′∣ 是同一个空间的两个有限三角剖分。由 thm.simplicial-approximation，

    Hp(K)≅Hp(X)≅Hp(K′),H_{p}(K) \cong H_{p}(X) \cong H_{p}(K'),Hp​(K)≅Hp​(X)≅Hp​(K′),

    故两个剖分的 Betti 数 βp\beta_{p}βp​ 完全相同。再由 thm.euler-characteristic 的等式，

    ∑p(−1)pαp(K)=∑p(−1)pβp,\sum_{p} (-1)^{p}\alpha_{p}(K) = \sum_{p} (-1)^{p}\beta_{p},p∑​(−1)pαp​(K)=p∑​(−1)pβp​,∑p(−1)pαp(K′)=∑p(−1)pβp.\sum_{p} (-1)^{p}\alpha_{p}(K') = \sum_{p} (-1)^{p}\beta_{p}.p∑​(−1)pαp​(K′)=p∑​(−1)pβp​.

    所以 χ\chiχ 只依赖 XXX 本身，可以记作 χ(X)\chi(X)χ(X)。∎

    没有这一条，χ\chiχ 只是「某个三角剖分上数单纯形」的结果，换个剖分就可能有别的值。
