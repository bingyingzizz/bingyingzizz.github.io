# entire and meromorphic functions　`def.entire-meromorphic`
English entry · root `../`
[in graph](../#n=def.entire-meromorphic)　·　[Chinese page (authoritative)](./def.entire-meromorphic.md)

**Entire function**: $f$ is holomorphic everywhere on $\mathbb{C}$. By Liouville's theorem, a bounded entire function is constant; a non-constant entire function has a singularity at $\infty$ (a polynomial has a pole there, while $e^{z}$ has an essential singularity).

**Meromorphic function**: let $\Omega$ be a region. If $f$ is holomorphic on $\Omega$ except on an **isolated** set $P$, and every point of $P$ is a pole of $f$, one says that $f$ is **meromorphic** on $\Omega$.
