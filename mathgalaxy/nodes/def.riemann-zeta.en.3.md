# Riemann zeta function　`def.riemann-zeta`
English entry · root `../`
[in graph](../#n=def.riemann-zeta)　·　[Chinese page (authoritative)](./def.riemann-zeta.md)

⭐ **Continuation (statement only)**: $\zeta$ extends to a meromorphic function on $\mathbb{C}$, with a single pole, a simple pole at $s = 1$ with residue $1$; and there is a functional equation $\zeta(s) = 2^{s}\pi^{s-1}\sin(\pi s/2)\,\Gamma(1-s)\,\zeta(1-s)$. ⚠ **This paragraph is a skeleton in this library**: the standard route to the continuation (Euler–Maclaurin, or the Mellin transform of the theta function) has no node here, so it is quoted only as a **known result**, without proof.
