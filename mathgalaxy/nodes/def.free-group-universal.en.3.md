# universal property of free groups　`def.free-group-universal`
English entry · root `../`
[in graph](../#n=def.free-group-universal)　·　[Chinese page (authoritative)](./def.free-group-universal.md)

**Adjunction**: the universal property is exactly the definition of “$F$ is left adjoint to the forgetful functor $U:\mathbf{Grp}\to\mathbf{Set}$” (see `def.adjoint`): the unit $\iota$ gives $\operatorname{Hom}(F(S),G)\cong\operatorname{Hom}(S,U(G))$.

⚠ If one required only “existence” and not “uniqueness”, any group containing $S$ would satisfy it, and the universal property would no longer characterize the free group.
