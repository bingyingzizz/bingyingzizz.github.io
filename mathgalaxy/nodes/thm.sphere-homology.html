  • 同伦不变性 ⟹ 本页推出
    球面同调的归纳要用「可缩   ⟹  \implies⟹ 同调平凡」

    球面的同调 的证明把 SnS^{n}Sn 拆成两个开半球 U=Sn∖{南极 S}U = S^{n} \setminus \{\text{南极 } S\}U=Sn∖{南极 S}、V=Sn∖{北极 N}V = S^{n} \setminus \{\text{北极 } N\}V=Sn∖{北极 N} —— 与节点 球面的同调 的记号一致（两者对称，哪个叫 UUU 都行）；它们各自经球极投影同胚于 Rn\mathbb{R}^{n}Rn，可缩，再用约化 Mayer–Vietoris 与对 H~p(Sn−1)\tilde{H}_{p}(S^{n-1})H~p​(Sn−1) 的归纳。

    缺的那一步：两个开半球各自可缩，因此它们的恒等映射与「常值映射」同伦；由 同伦不变性，恒等诱导的同态等于常值映射诱导的同态，而后者经过 H~k(pt)=0\tilde H_{k}(\text{pt}) = 0H~k​(pt)=0 分解，故 H~k(Dn)=0\tilde H_{k}(D^{n}) = 0H~k​(Dn)=0。

    没有这一条，归纳只能算出「某个群是 0」，却说不出「为什么半球没有同调」。∎

    这条补上了子 agent 交付时自己标注的「最薄弱一环」。
