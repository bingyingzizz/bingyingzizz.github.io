陈述

对 n≥1n \ge 1n≥1：

H0(Sn)=Z,Hn(Sn)=Z,H_{0}(S^{n}) = \mathbb{Z},\qquad H_{n}(S^{n}) = \mathbb{Z},H0​(Sn)=Z,Hn​(Sn)=Z,Hp(Sn)=0(p≠0,n).H_{p}(S^{n}) = 0 \quad (p \ne 0, n).Hp​(Sn)=0(p=0,n).

用约化同调可以对着所有 ppp（含 n=0n = 0n=0）统一写成

H~p(Sn)=Z (p=n),H~p(Sn)=0 (p≠n).\tilde{H}_{p}(S^{n}) = \mathbb{Z} \ (p = n),\qquad \tilde{H}_{p}(S^{n}) = 0 \ (p \ne n).H~p​(Sn)=Z (p=n),H~p​(Sn)=0 (p=n).

说明

n=0n = 0n=0 要单独看清：S0S^{0}S0 是两点，由 prop.h0-components，H0(S0)=Z2H_{0}(S^{0}) = \mathbb{Z}^{2}H0​(S0)=Z2，约化后 H~0(S0)=Z\tilde{H}_{0}(S^{0}) = \mathbb{Z}H~0​(S0)=Z —— 与 p=np = np=n 的约定吻合，所以它是归纳法的基础情形。

⚠️ 证明是骨架，正式证明请查 refs。结构与关键步骤： ① 取两个开集 U:=Sn∖{南极}U := S^{n} \setminus \{\text{南极}\}U:=Sn∖{南极}、V:=Sn∖{北极}V := S^{n} \setminus \{\text{北极}\}V:=Sn∖{北极}，它们都同胚于 Rn\mathbb{R}^{n}Rn，可缩，故所有约化同调为零（同伦不变性：恒等 ≃\simeq≃ 常值，而常值映射在约化同调上是零）； ② U∩V=Sn∖{两极}U \cap V = S^{n} \setminus \{\text{两极}\}U∩V=Sn∖{两极} 沿经线形变收缩到赤道 Sn−1S^{n-1}Sn−1，故 H~p(U∩V)≅H~p(Sn−1)\tilde{H}_{p}(U \cap V) \cong \tilde{H}_{p}(S^{n-1})H~p​(U∩V)≅H~p​(Sn−1)； ③ 代入 Mayer–Vietoris（thm.mv-homology）的约化版，两个可缩块的项为零，得对每个 ppp

H~p(Sn)≅H~p(Sn−1),\tilde{H}_{p}(S^{n}) \cong \tilde{H}_{p}(S^{n-1}),H~p​(Sn)≅H~p​(Sn−1),

④ 从 S0S^{0}S0 出发归纳即得结论。

⚠️ 第 ② 步用到了同调的同伦不变性，而第 ③ 步用到 MV —— 本图里 MV 那条边的证明本身也只是骨架。所以这条定理在图上离「可逐行复现」还有一段距离，如实标注。

⭐ 意义：这是「同调看得见 nnn 维的洞」的精确表述。对比 cor.pi1-sphere（π1(Sn)=1\pi_{1}(S^{n}) = 1π1​(Sn)=1 对 n≥2n \ge 2n≥2）——π1\pi_{1}π1​ 只看见 n=1n = 1n=1 那一层，HnH_{n}Hn​ 看见每一层。当然 πn\pi_{n}πn​ 也看得见（那是另一套理论）。

  • Mayer–Vietoris（同调）、H₀ 与分支 ⟹ 本页推出
    两个可缩开半球 + 交叠形变收缩到赤道   ⟹  \implies⟹ 只剩两个非零

    开覆盖：令 U:=Sn∖{南极 N}U := S^{n} \setminus \{\text{南极 } N\}U:=Sn∖{南极 N}、V:=Sn∖{北极 S}V := S^{n} \setminus \{\text{北极 } S\}V:=Sn∖{北极 S}。两者都是开集且覆盖 SnS^{n}Sn，各自经球极投影同胚于 Rn\mathbb{R}^{n}Rn，因而可缩。

    可缩   ⟹  \implies⟹ 约化同调为零：恒等映射 ≃\simeq≃ 常值映射，同调不变性给出两者诱导相同的映射；而常值映射在约化同调上是零（H~0\tilde{H}_{0}H~0​ 上：ε(1⋅x)=1\varepsilon(1 \cdot x) = 1ε(1⋅x)=1 但约化同调里点类为零；p≥1p \ge 1p≥1 上：链映射经过 S∗(pt)S_{*}(\mathrm{pt})S∗​(pt)，那里没有正维数的链）。故 H~p(U)=H~p(V)=0\tilde{H}_{p}(U) = \tilde{H}_{p}(V) = 0H~p​(U)=H~p​(V)=0 对一切 ppp。

    交叠：U∩V=Sn∖{N,S}U \cap V = S^{n} \setminus \{N, S\}U∩V=Sn∖{N,S} 沿经线把每点推到赤道，给出到 Sn−1S^{n-1}Sn−1 的形变收缩，故 H~p(U∩V)≅H~p(Sn−1)\tilde{H}_{p}(U \cap V) \cong \tilde{H}_{p}(S^{n-1})H~p​(U∩V)≅H~p​(Sn−1)。

    代入 MV（约化版）：序列在每处 ppp 上是

    H~p(U∩V)→0→H~p(Sn)\tilde{H}_{p}(U \cap V) \to 0 \to \tilde{H}_{p}(S^{n})H~p​(U∩V)→0→H~p​(Sn)→H~p−1(U∩V)→0,\to \tilde{H}_{p-1}(U \cap V) \to 0,→H~p−1​(U∩V)→0,

    （这两处 000 是 H~p(U)⊕H~p(V)\tilde{H}_{p}(U) \oplus \tilde{H}_{p}(V)H~p​(U)⊕H~p​(V)，两块都为零。）

    两端为零   ⟹  \implies⟹ 中间的映射被夹成同构：H~p(Sn)≅H~p−1(U∩V)≅H~p−1(Sn−1)\tilde{H}_{p}(S^{n}) \cong \tilde{H}_{p-1}(U \cap V) \cong \tilde{H}_{p-1}(S^{n-1})H~p​(Sn)≅H~p−1​(U∩V)≅H~p−1​(Sn−1)。

    基础情形 n=0n = 0n=0：S0S^{0}S0 是两点，由 prop.h0-components，H0(S0)=Z2H_{0}(S^{0}) = \mathbb{Z}^{2}H0​(S0)=Z2，取约化得 H~0(S0)=Z\tilde{H}_{0}(S^{0}) = \mathbb{Z}H~0​(S0)=Z。

    归纳：反复用上式把维数降下来，得 H~p(Sn)=H~p−(n)(S0)\tilde{H}_{p}(S^{n}) = \tilde{H}_{p-(n)}(S^{0})H~p​(Sn)=H~p−(n)​(S0) 型的平移，故只有 p=np = np=n 处为 Z\mathbb{Z}Z、其余为零。非约化版 H0=ZH_{0} = \mathbb{Z}H0​=Z（n≥1n \ge 1n≥1 连通）与之相容。∎

    这条链子用到了「同伦不变性」（写在 def.singular-homology 的陈述里）与 MV 的骨架证明，如实标注。

  • 同伦不变性 ⟹ 本页推出
    球面同调的归纳要用「可缩   ⟹  \implies⟹ 同调平凡」

    thm.sphere-homology 的证明把 SnS^{n}Sn 拆成两个闭半球 D+n∪D−nD^{n}_{+} \cup D^{n}_{-}D+n​∪D−n​，再用对 (Sn,D+n)(S^{n}, D^{n}_{+})(Sn,D+n​) 的长正合列与归纳。

    缺的那一步：两个半球各自可缩，因此它们的恒等映射与「常值映射」同伦；由 thm.homotopy-invariance，恒等诱导的同态等于常值映射诱导的同态，而后者经过 H~k(pt)=0\tilde H_{k}(\text{pt}) = 0H~k​(pt)=0 分解，故 H~k(Dn)=0\tilde H_{k}(D^{n}) = 0H~k​(Dn)=0。

    没有这一条，归纳只能算出「某个群是 0」，却说不出「为什么半球没有同调」。∎

    这条补上了子 agent 交付时自己标注的「最薄弱一环」。
