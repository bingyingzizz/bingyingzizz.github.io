# Lagrangian Submanifold　`def.lagrangian-submanifold`
English entry · root `../`
[in graph](../#n=def.lagrangian-submanifold)　·　[Chinese page (authoritative)](./def.lagrangian-submanifold.md)

- In $\mathbb{R}^{2n}$, the zero section $\{p = 0\}$ (the position space, with all momenta zero).
- More generally, **the graph associated with any function**, $\{(q, p) : p = dF(q)\}$, is a Lagrangian submanifold because $\omega|_{L} = dq \wedge d(dF) = 0$.

## Notes · **draft**
⭐ **‘$\omega|_L = 0$’ is equivalent to ‘$p\,dq$ is closed on $L$’**: Take $\omega = d(p\,dq)$. On $L$, $p\,dq$ is closed $\iff$ it is locally of the form $dF$ $\iff$ $L$ is locally the graph associated with a function.
