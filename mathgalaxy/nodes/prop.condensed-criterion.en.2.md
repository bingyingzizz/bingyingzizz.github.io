# Criterion for a Presheaf to Be Condensed　`prop.condensed-criterion`
English entry · root `../`
[in graph](../#n=prop.condensed-criterion)　·　[Chinese page (authoritative)](./prop.condensed-criterion.md)

$$X\bigl(\operatorname{coker}(R \rightrightarrows S)\bigr) \;\cong\; \ker\bigl(X(S) \rightrightarrows X(R)\bigr)$$

In particular $X(\emptyset) \cong \{\ast\}$; equivalently, if $S' \to S$ is a surjection, then

$$X(S) \longrightarrow X(S') \rightrightarrows X(S' \times_{S} S')$$

is left exact.
