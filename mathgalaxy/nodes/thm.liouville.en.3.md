# Liouville's Theorem　`thm.liouville`
English entry · root `../`
[in graph](../#n=thm.liouville)　·　[Chinese page (authoritative)](./thm.liouville.md)

⚠ Boundedness cannot be relaxed carelessly: $e^{z}$ is bounded on the **left** half-plane ($|e^{z}| \le 1$), but unbounded on the whole plane.

Conversely, if one only knows $|f(z)| \le C(1 + |z|)^k$, the same argument gives only "$f$ is a polynomial of degree at most $k$".

⭐ Contrast with real analysis: $\sin x$ is bounded and infinitely differentiable on $\mathbb{R}$, yet not constant — because "entire" is far stronger than "$C^\infty$ function".
