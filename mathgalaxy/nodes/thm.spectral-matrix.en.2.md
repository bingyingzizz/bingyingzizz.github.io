# Spectral Theorem (Matrices)　`thm.spectral-matrix`
English entry · root `../`
[in graph](../#n=thm.spectral-matrix)　·　[Chinese page (authoritative)](./thm.spectral-matrix.md)

$A$ is normal $\iff$ there is a unitary matrix $U$ with $U^{*}AU = \operatorname{diag}(\lambda_{1}, \ldots, \lambda_{n})$

that is: **normal $\iff$ there is an orthonormal basis of eigenvectors**. In that case

$$A = U \Lambda U^{*}, \qquad \Lambda = \operatorname{diag}(\lambda_{1}, \ldots, \lambda_{n}) ,$$

called the **spectral decomposition** of $A$ (a sum of orthogonal projections: $A = \sum_i \lambda_i u_i u_i^{*}$).

**Real case**: a real symmetric matrix $\iff$ there is an **orthogonal** matrix $Q$ with $Q^{T}AQ$ real diagonal.
