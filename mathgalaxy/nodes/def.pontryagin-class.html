陈述

在做什么：实丛一般没有「Z\mathbb{Z}Z 系数」的示性类 —— 例外是可定向偶秩的顶维欧拉类 eee（整系数、只在顶维）；wiw_{i}wi​ 是 Z/2\mathbb{Z}/2Z/2 系数的，pip_{i}pi​ 要复化之后才取。取复化 E⊗CE \otimes \mathbb{C}E⊗C 之后就有整系数陈类了 —— 取其中偶次的那几个，就是 Pontryagin 类。

设 E→BE \to BE→B 是秩 kkk 的实向量丛。第 iii 个 Pontryagin 类定义为

pi(E):=(−1)i c2i(E⊗RC)∈H4i(B;Z),i=1,2,…,⌊k2⌋.p_{i}(E) := (-1)^{i}\, c_{2i}\bigl(E \otimes_{\mathbb{R}} \mathbb{C}\bigr) \in H^{4i}(B; \mathbb{Z}) , \qquad i = 1, 2, \ldots , \Bigl\lfloor \frac{k}{2} \Bigr\rfloor .pi​(E):=(−1)ic2i​(E⊗R​C)∈H4i(B;Z),i=1,2,…,⌊2k​⌋.

基本性质：

  1. p0=1p_{0} = 1p0​=1；
  2. 自然性：pi(f∗E)=f∗pi(E)p_{i}(f^{}E) = f^{}p_{i}(E)pi​(f∗E)=f∗pi​(E)；
  3. Whitney 乘积公式（模 222-挠才严格成立）p(E⊕E′)=p(E)⌣p(E′)p(E \oplus E') = p(E) \smile p(E')p(E⊕E′)=p(E)⌣p(E′)；
  4. 复丛的实化：若 E=FRE = F_{\mathbb{R}}E=FR​ 是复丛 FFF 的实化，则 pi(FR)=(−1)i c2i(F⊕F‾)p_{i}(F_{\mathbb{R}}) = (-1)^{i}\, c_{2i}(F \oplus \overline{F})pi​(FR​)=(−1)ic2i​(F⊕F)（一般不是 ci(F)2c_{i}(F)^{2}ci​(F)2；对线丛 FFF 才有 p1=c12p_{1}=c_{1}^{2}p1​=c12​，秩 mmm 复丛的顶类 pm=cm2p_{m}=c_{m}^{2}pm​=cm2​；例：F=O(1)→CP2F = \mathcal{O}(1) \to \mathbb{CP}^{2}F=O(1)→CP2 时 p1=c12=h2p_{1} = c_{1}^{2} = h^{2}p1​=c12​=h2）。ppp 丢掉了 ccc 的奇次信息，这正是「实化丢相位」的表现。

说明

为什么只取偶次：复化 E⊗CE\otimes\mathbb{C}E⊗C 带一个共轭结构（把 iii 变成 −i-i−i），于是 c2i+1(E⊗C)=−c2i+1c_{2i+1}(E\otimes\mathbb{C}) = -c_{2i+1}c2i+1​(E⊗C)=−c2i+1​ 型地成对抵消（在 Z\mathbb{Z}Z 系数下变成 222-挠元）。所以整系数里只剩偶次是真不变量，奇次的信息要用 Z/2\mathbb{Z}/2Z/2 的 wiw_{i}wi​ 去补 —— 这就是 www 与 ppp 的分工。

⚠️ S4S^{4}S4 反而是「p1p_{1}p1​ 为零」的例子：S4S^{4}S4 稳定可平行化（TS4⊕R‾≅R‾5TS^{4} \oplus \underline{\mathbb{R}} \cong \underline{\mathbb{R}}^{5}TS4⊕R​≅R​5），故 p1(TS4)=0p_{1}(TS^{4}) = 0p1​(TS4)=0；它非平凡要靠 Euler 类检出（e(TS4)=χ(S4)=2≠0e(TS^{4}) = \chi(S^{4}) = 2 \ne 0e(TS4)=χ(S4)=2=0）。更著名的是 CP2\mathbb{CP}^{2}CP2 的 p1p_{1}p1​ 与符号差定理（signature theorem）：σ(M)=13∫p1\sigma(M) = \frac{1}{3}\int p_{1}σ(M)=31​∫p1​（四维闭可定向流形），这是 Hirzebruch 指标定理的特例。

⚠️ Whitney 公式的 222-挠警告：p(E⊕E′)=p(E)p(E′)p(E\oplus E') = p(E)p(E')p(E⊕E′)=p(E)p(E′) 在 H∗(B;Z)H^{}(B;\mathbb{Z})H∗(B;Z) 里只对模 222-挠成立（严格版要写到 H∗(B;Z)/挠H^{}(B;\mathbb{Z})/\text{挠}H∗(B;Z)/挠，或用 Z[1/2]\mathbb{Z}[1/2]Z[1/2] 系数）。这一点与陈类形成鲜明对照（陈类的 Whitney 公式是无条件的）—— 因为复化会引入 222-挠。

⚠️ 三种实示性类的角色：wiw_{i}wi​（Z/2\mathbb{Z}/2Z/2，全维数、能测定向与 Spin）、eee（Z\mathbb{Z}Z，只在可定向且偶数秩、顶维）、pip_{i}pi​（Z\mathbb{Z}Z，444 的倍数维、丢奇次信息）。三者不互相包含 —— 判断某个实丛非平凡时，可能要几种一起用。
