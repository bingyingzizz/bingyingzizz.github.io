## Statement · **draft**
Let $\mathcal{M}$ be a $\sigma$-algebra on $X$. A function $\mu : \mathcal{M} \to [0, +\infty]$ is a **measure** if and only if

- **(i)** $\mu(\emptyset) = 0$
- **(ii) countable additivity**: if $\{E_{j}\}$ is a sequence of pairwise disjoint sets in $\mathcal{M}$, then

$$\mu( \bigcup_{j=1}^{\infty} E_j ) = \sum_{j=1}^{\infty} \mu(E_j)$$

$(X, \mathcal{M}, \mu )$ is called a **measure space**.
