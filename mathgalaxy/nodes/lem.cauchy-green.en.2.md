# Cauchy–Green Identity　`lem.cauchy-green`
English entry · root `../`
[in graph](../#n=lem.cauchy-green)　·　[Chinese page (authoritative)](./lem.cauchy-green.md)

Let $\Omega$ be a bounded region whose boundary $\partial\Omega$ is a piecewise smooth simple closed curve, positively oriented (counterclockwise). If $f \in C^1(\overline{\Omega})$, then

$$\int_{\partial\Omega} f(z)\,\mathrm{d}z = 2i \iint_{\Omega} \frac{\partial f}{\partial \bar z}(z)\,\mathrm{d}x\,\mathrm{d}y.$$

In particular, if $f$ is holomorphic (**one need no longer say "$f'$ is continuous"**: the derivative of a holomorphic function is again holomorphic and hence continuous), then the right-hand side is zero, i.e. $\displaystyle\oint_{\partial\Omega} f\,\mathrm{d}z = 0$.
