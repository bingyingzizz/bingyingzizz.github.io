# linear maps and matrices　`thm.matrix-linear-map`
English entry · root `../`
[in graph](../#n=thm.matrix-linear-map)　·　[Chinese page (authoritative)](./thm.matrix-linear-map.md)

Then the map $T \mapsto [T]_{\mathcal{B}}^{\mathcal{C}}$ is an isomorphism of $K$-vector spaces

$$\operatorname{Hom}_K(V, W) \;\cong\; M_{m \times n}(K)$$

and **composition corresponds to multiplication**: if $T : V \to W$, $S : W \to U$, then

$$[S \circ T]_{\mathcal{B}}^{\mathcal{E}} = [S]_{\mathcal{C}}^{\mathcal{E}}\; [T]_{\mathcal{B}}^{\mathcal{C}}$$
