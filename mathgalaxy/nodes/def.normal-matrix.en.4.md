# Normal Matrix　`def.normal-matrix`
English entry · root `../`
[in graph](../#n=def.normal-matrix)　·　[Chinese page (authoritative)](./def.normal-matrix.md)

**Why real normal matrices can only be block-diagonalized**: $\begin{pmatrix} 0 & -1 \\ 1 & 0\end{pmatrix}$ is real normal (it is a rotation by $90^\circ$), but it has no real eigenvector, so it certainly cannot be orthogonally diagonalized. Its two eigenvalues are $\pm i$ — conjugate pairs, the source of those $2\times 2$ blocks.
