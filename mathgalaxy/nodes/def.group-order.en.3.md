# order of a group　`def.group-order`
English entry · root `../`
[in graph](../#n=def.group-order)　·　[Chinese page (authoritative)](./def.group-order.md)

⚠ **The symbol $|G|$ has two meanings in this graph** (same symbol, different contexts): the order of a group is written $|G|$, while the cardinality of a set is written $\#A$. Mathematically these are the same thing (the order of a group is the cardinality of its underlying set), but the spelling is divided by context — check whether the object is a group.

⚠ **Not the same as “the degree of an element”**: in a ring the “nilpotency degree” of $x$ and the “degree” $[F(x):F]$ of a field element are different quantities.

📌 Readings: $|S_{n}| = n!$; $\operatorname{ord}((1\,2\,3)) = 3$; in $\mathbb{Z}/n$, $\operatorname{ord}(\bar{k}) = n/\gcd(n,k)$.
