陈述

设 RRR 是交换含幺环，M,N,PM, N, PM,N,P 是 RRR-模。则存在自然同构

Hom⁡R(M⊗RN, P)  ≅  Hom⁡R(M, Hom⁡R(N,P)),f⟼(m↦(n↦f(m⊗n))),\operatorname{Hom}_{R}\bigl(M \otimes_{R} N,\ P\bigr) \;\cong\; \operatorname{Hom}_{R}\bigl(M,\ \operatorname{Hom}_{R}(N, P)\bigr), \qquad f \longmapsto \bigl(m \mapsto (n \mapsto f(m \otimes n))\bigr),HomR​(M⊗R​N, P)≅HomR​(M, HomR​(N,P)),f⟼(m↦(n↦f(m⊗n))),

即函子 (−)⊗RN(-) \otimes_{R} N(−)⊗R​N 是 Hom⁡R(N,−)\operatorname{Hom}_{R}(N, -)HomR​(N,−) 的左伴随：

(−)⊗RN  ⊣  Hom⁡R(N,−).(-) \otimes_{R} N \;\dashv\; \operatorname{Hom}_{R}(N, -).(−)⊗R​N⊣HomR​(N,−).

说明

证明（显式写映射）：记 Φ(f):=(m↦(n↦f(m⊗n)))\Phi(f) := \bigl(m \mapsto (n \mapsto f(m \otimes n))\bigr)Φ(f):=(m↦(n↦f(m⊗n)))。反向 Ψ(g):=(m⊗n↦g(m)(n))\Psi(g) := \bigl(m \otimes n \mapsto g(m)(n)\bigr)Ψ(g):=(m⊗n↦g(m)(n))：因为 (m,n)↦g(m)(n)(m, n) \mapsto g(m)(n)(m,n)↦g(m)(n) 是平衡双加性的，由 def.tensor-module 的万有性质它唯一地给出 Ψ(g)\Psi(g)Ψ(g)。ΦΨ\Phi \PsiΦΨ 与 ΨΦ\Psi \PhiΨΦ 在纯张量（或 MMM 的生成元）上是恒等，而生成元张成整个模，故互逆。自然性：Φ\PhiΦ 的公式里没有任何选取，只用到 ⊗\otimes⊗ 与复合。∎

⭐ 这就是curry 化：两个变元的东西，与「取值在函数空间里」的一个变元的东西，是同一件事。

两条推论立刻可用：(−)⊗RN(-) \otimes_{R} N(−)⊗R​N 是左伴随，故保余极限（右正合、保直和、保滤过余极限）；Hom⁡R(N,−)\operatorname{Hom}_{R}(N, -)HomR​(N,−) 是右伴随，故保极限（左正合、保积）。

📌 非交换版本：MMM 右 RRR-模、NNN 左 RRR-模、PPP 为阿贝尔群时，同一条同构改写成

Hom⁡Z(M⊗RN, P)  ≅  Hom⁡R(M, Hom⁡Z(N,P)),\operatorname{Hom}_{\mathbb{Z}}(M \otimes_{R} N,\ P) \;\cong\; \operatorname{Hom}_{R}\bigl(M,\ \operatorname{Hom}_{\mathbb{Z}}(N, P)\bigr),HomZ​(M⊗R​N, P)≅HomR​(M, HomZ​(N,P)),

要点只是：Hom⁡Z(N,P)\operatorname{Hom}_{\mathbb{Z}}(N, P)HomZ​(N,P) 天然是右 RRR-模。

推出 2

  • 本页 ⟹ 张量函子右正合推出
    左伴随保余极限   ⟹  \implies⟹ 张量右正合

    由伴随 (−)⊗RN⊣Hom⁡R(N,−)(-) \otimes_{R} N \dashv \operatorname{Hom}_{R}(N, -)(−)⊗R​N⊣HomR​(N,−)，左伴随保所有余极限。

    而余核是两项图的余极限：coker⁡(f)=colim(M1→fM)\operatorname{coker}(f) = \mathrm{colim}\bigl(M_{1} \xrightarrow{f} M\bigr)coker(f)=colim(M1​f​M)。故 (−)⊗N(-) \otimes N(−)⊗N 保余核 ✓。

    对一个加法函子，「保余核」与「把短正合列送成 M1⊗N→M⊗N→M2⊗N→0M_{1} \otimes N \to M \otimes N \to M_{2} \otimes N \to 0M1​⊗N→M⊗N→M2​⊗N→0 正合」是同一句话：ggg 满   ⟺  \iff⟺ coker⁡g=0\operatorname{coker} g = 0cokerg=0   ⟺  \iff⟺ coker⁡(g⊗1)=0\operatorname{coker}(g \otimes 1) = 0coker(g⊗1)=0   ⟺  \iff⟺ g⊗1g \otimes 1g⊗1 满；im⁡(f⊗1)=ker⁡(g⊗1)\operatorname{im}(f \otimes 1) = \ker(g \otimes 1)im(f⊗1)=ker(g⊗1) 由保余核直接给出 ✓。

    左端为什么没有：f⊗1f \otimes 1f⊗1 的单射性不能由伴随得到（左伴随保的是余极限，不是极限）。Z→2Z\mathbb{Z} \xrightarrow{2} \mathbb{Z}Z2​Z 张量 Z/2\mathbb{Z}/2Z/2 就是反例：映射变成零 ✓。∎

    这条把「右正合」与「平坦」切成两半：右正合是伴随白送的，左正合才是要研究的性质。

  • 本页 ⟹ 标量扩张与限制互为伴随推出
    张量–内 Hom 伴随   ⟹  \implies⟹ 标量扩张 ⊣\dashv⊣ 标量限制

    把 SSS 看成 (S,R)(S, R)(S,R)-双模。对左 RRR-模 MMM、左 SSS-模 PPP：

    第一步（SSS-线性 = 特定的 RRR-线性）：S⊗RMS \otimes_{R} MS⊗R​M 由纯张量生成，而 s⊗m=s(1⊗m)s \otimes m = s(1 \otimes m)s⊗m=s(1⊗m)，所以 SSS-线性映射 ggg 被 m↦g(1⊗m)m \mapsto g(1 \otimes m)m↦g(1⊗m) 完全决定 ✓。

    第二步（反向构造）：给定 RRR-线性 φ:M→P\varphi : M \to Pφ:M→P，(s,m)↦sφ(m)(s, m) \mapsto s \varphi(m)(s,m)↦sφ(m) 是平衡双加性的（srs rsr 与 rrr 的搬动用 φ\varphiφ 的 RRR-线性），故由 def.tensor-module 的万有性质唯一给出 SSS-线性映射 S⊗RM→PS \otimes_{R} M \to PS⊗R​M→P ✓。

    第三步（互逆与自然）：两个构造互为逆（在 1⊗m1 \otimes m1⊗m 上显然），公式无选取，故自然。于是

    Hom⁡S(S⊗RM,P)  ≅  Hom⁡R(M,f∗P).\operatorname{Hom}_{S}(S \otimes_{R} M, P) \;\cong\; \operatorname{Hom}_{R}(M, f_{\ast} P) .HomS​(S⊗R​M,P)≅HomR​(M,f∗​P).

    单位与余单位：把 id\mathrm{id}id 沿同构对来对去得 ηM(m)=1⊗m\eta_{M}(m) = 1 \otimes mηM​(m)=1⊗m 与 εP(s⊗p)=sp\varepsilon_{P}(s \otimes p) = s pεP​(s⊗p)=sp；三角恒等式在纯张量与 MMM 的元素上验证，再线性延拓 ✓。∎

    这条与 thm.hom-tensor-adjunction-mod 是同一条 curry 化的两种用法：那里把 NNN 当可变变元，这里把环同态 fff 当参数。

推出 1

  • 张量积对双线性映射万有、模的张量积 ⟹ 本页推出
    平衡双加性的万有性质   ⟹  \implies⟹ 张量–内 Hom 伴随

    万有性质给出一半：Hom⁡R(M⊗RN,P)\operatorname{Hom}_{R}(M \otimes_{R} N, P)HomR​(M⊗R​N,P) 与「平衡双加性映射 M×N→PM \times N \to PM×N→P」的全体一一对应。

    curry 化给出另一半：平衡双加性映射 B:M×N→PB : M \times N \to PB:M×N→P 与「线性映射 M→Hom⁡R(N,P)M \to \operatorname{Hom}_{R}(N, P)M→HomR​(N,P)」一一对应 —— 给定 BBB，m↦B(m,−)m \mapsto B(m, -)m↦B(m,−) 线性；给定 ggg，(m,n)↦g(m)(n)(m, n) \mapsto g(m)(n)(m,n)↦g(m)(n) 平衡双加性。两个方向明显互逆 ✓。

    复合两个双射即得同构。自然性：同构由显式公式 f↦(m↦(n↦f(m⊗n)))f \mapsto \bigl(m \mapsto (n \mapsto f(m \otimes n))\bigr)f↦(m↦(n↦f(m⊗n))) 给出，公式里没有任何选取，故对 MMM 与 PPP 都自然 ✓。∎

    另一条等价的证法：取 MMM 的自由表现 R(J)→R(I)→M→0R^{(J)} \to R^{(I)} \to M \to 0R(J)→R(I)→M→0，先用 M=RM = RM=R 的情形（即「单位」R⊗N≅NR \otimes N \cong NR⊗N≅N）验证，再用五引理把同构推到 MMM 上。

    两个来源缺一不可：prop.module-tensor-universal 给「双线性 = 线性」这半句（在 Z\mathbb{Z}Z 与域上写的），def.tensor-module 给一般 RRR 上平衡关系的形式。
