# Cauchy–Green Identity　`lem.cauchy-green`
English entry · root `../`
[in graph](../#n=lem.cauchy-green)　·　[Chinese page (authoritative)](./lem.cauchy-green.md)

⚠ This lemma is **not free**: Green's formula requires $P, Q$ (hence $f$) to be $C^1$ on the closure $\overline{\Omega}$.

Holomorphic only guarantees that $f$ is differentiable, **not that $f'$ is continuous** — this gap is filled by Goursat's subdivision into triangles.
