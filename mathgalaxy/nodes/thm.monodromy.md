# 单值性定理　`thm.monodromy`
单值性定理：单连通区域内沿同伦路径的延拓结果相同
layer 25 · 定理 · 解析延拓与整函数 · 复变函数
[在星图里打开](../#n=thm.monodromy)　·　[节点索引](../index.md)

设 $\Omega \subset \mathbb{C}$ 是**单连通**区域，$(f, D)$ 是 $\Omega$ 内某点的函数元素，且 $f$ 能沿 $\Omega$ 中每条曲线解析延拓。则存在 $\Omega$ 上的**单值**全纯函数 $F$，它在 $D$ 上与 $f$ 相同。
