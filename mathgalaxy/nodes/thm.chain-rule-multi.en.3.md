# Chain Rule in Several Variables　`thm.chain-rule-multi`
English entry · root `../`
[in graph](../#n=thm.chain-rule-multi)　·　[Chinese page (authoritative)](./thm.chain-rule-multi.md)

Because $f(a + h) - f(a)$ is itself $O(\|h\|)$, the $o(\|k\|)$ of $g$ at $f(a)$ (with $k = f(a+h) - f(a)$) must be explicitly replaced by $o(\|h\|)$; this step uses $\|k\| \le (\|Df(a)\| + 1)\|h\|$ (for small $h$).
