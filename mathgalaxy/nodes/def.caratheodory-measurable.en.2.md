## Notes · **draft**
Since $\mu^{*}$ is only subadditive, one always has $\mu^*(E) \le \mu^*(E \cap A) + \mu^*(E \cap A^c)$. The definition therefore only requires the **reverse inequality**: $A$ “eats” nothing.

At first the definition looks strange (why not use intuitive conditions involving open or closed sets?) — its virtue is that it is **completely intrinsic**: only the single object $\mu^{*}$ is needed, no topology. Hence it works for an arbitrary outer measure.

Intuition: $A$ is a set that can be “cut out freely”.
