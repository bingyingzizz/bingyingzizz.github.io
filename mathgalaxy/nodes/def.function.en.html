Statement

Let fff be a relation from AAA to BBB. Then fff is a map (written f:A→Bf : A \to Bf:A→B) if and only if every input has exactly one output:

∀a∈A,∃!b∈B,(a,b)∈f\forall a \in A, \exists! b \in B, (a, b) \in f∀a∈A,∃!b∈B,(a,b)∈f

Uniqueness is what makes the notation f(a)=bf(a) = bf(a)=b unambiguous; in that case dom⁡f=A\operatorname{dom} f = Adomf=A, and the image of fff is f(A)={f(a):a∈A}f(A) = \{ f(a) : a \in A \}f(A)={f(a):a∈A}.

Injective / surjective / bijective are separate nodes; a map whose values lie in a set of numbers has its own name, a function.
