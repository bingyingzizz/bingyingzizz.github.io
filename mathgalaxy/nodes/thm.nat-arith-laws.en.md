## Statement · **draft**
On $\mathbb{N} = \omega$ take the addition and multiplication defined in `def.nat-arith`. Then for all $m, n, k \in \mathbb{N}$:

$$0 + n = n, \qquad S(m) + n = S(m + n),$$

$$m + n = n + m, \qquad (m + n) + k = m + (n + k),$$

$$m \cdot 0 = 0, \qquad m \cdot n = n \cdot m, \qquad (m n) k = m (n k), \qquad m(n + k) = m n + m k,$$

and the **cancellation law**

$$m + k = n + k \implies m = n.$$
