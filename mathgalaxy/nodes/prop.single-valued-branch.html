陈述

设 D⊂CD \subset \mathbb{C}D⊂C 是区域，FFF 是 DDD 上的多值函数（每点给一个非空值集 F(z)F(z)F(z)）。FFF 的单值支是连续函数 f:D→Cf : D \to \mathbb{C}f:D→C 使 f(z)∈F(z)f(z) \in F(z)f(z)∈F(z) 对一切 z∈Dz \in Dz∈D 成立；若 FFF 来自解析延拓，则单值支自动全纯。

对对数（F(z)={ w:ew=z }F(z) = \{\, w : e^{w} = z \,\}F(z)={w:ew=z}）下列三条等价：

  1. log⁡\loglog 在 DDD 上存在全纯单值支；
  2. 1/z1/z1/z 在 DDD 上有原函数；
  3. 对 DDD 中每条闭曲线 γ\gammaγ 都有 ∮γdzz=0\displaystyle\oint_{\gamma} \frac{\mathrm{d}z}{z} = 0∮γ​zdz​=0。

充分条件：DDD 单连通且 0∉D0 \notin D0∈/D。

说明

证明（1   ⟹  \implies⟹ 3）：若 ef=ze^{f} = zef=z，则 f′=1/zf' = 1/zf′=1/z，于是 ∮γdz/z=∮γf′ dz=0\oint_{\gamma} \mathrm{d}z/z = \oint_{\gamma} f'\,\mathrm{d}z = 0∮γ​dz/z=∮γ​f′dz=0（全纯函数的围道积分在单连通区域内为零，这里用「有原函数」的版本）。

证明（3   ⟹  \implies⟹ 2   ⟹  \implies⟹ 1）：条件 3 说明沿曲线的积分只依赖端点，于是可定义 f(z):=∫z0zdζ/ζf(z) := \int_{z_{0}}^{z} \mathrm{d}\zeta/\zetaf(z):=∫z0​z​dζ/ζ，它满足 f′=1/zf' = 1/zf′=1/z；再验证 (ze−f(z))′=e−f−ze−f/z=0(z e^{-f(z)})' = e^{-f} - z e^{-f}/z = 0(ze−f(z))′=e−f−ze−f/z=0，故 ze−fz e^{-f}ze−f 为常数，调整常数即得 ef=ze^{f} = zef=z。

⭐ 条件 3 就是「绕数全为零」（见 绕数的积分表示）：∮γdz/z=2πi n(γ,0)\oint_{\gamma}\mathrm{d}z/z = 2\pi i\, n(\gamma, 0)∮γ​dz/z=2πin(γ,0)。所以「对数有没有单值支」被翻译成了一句关于曲线绕不绕原点的话 —— 单连通区域里没有闭曲线能绕住外点，故自动成立。

⚠️ 单连通不是必要条件：圆环 {1<∣z∣<2}\{1 < |z| < 2\}{1<∣z∣<2} 上 log⁡\loglog 没有单值支，但去掉两个洞的区域上可能有 —— 判据永远是 3 而不是「形状像不像单连通」。

各方向用到的假设（对数分支判据要求区域避开原点，单连通只是充分条件）：

  • 单值支   ⟺  \iff⟺ 连续选择每点的值：这是定义展开；对数三条件的等价则要求 D⊂C∖{0}D\subset\mathbb C\setminus\{0\}D⊂C∖{0}，否则 1/z1/z1/z 无定义。
  • (1)   ⟹  \implies⟹ (2)   ⟹  \implies⟹ (3)：对 ef=ze^f=zef=z 求导得 f′=1/zf'=1/zf′=1/z，再用原函数的积分基本定理；不要求单连通。
  • (3)   ⟹  \implies⟹ (2)：用区域的道路连通性及闭路积分为零保证路径积分与路径无关，再由被积函数全纯求导。
  • (2)   ⟹  \implies⟹ (1)：ze−fze^{-f}ze−f 导数为零，由连通性为非零常数，调整一个常数即可；这是构造，不是定义展开。
  • 单连通且避开零   ⟹  \implies⟹ (3) 用 Cauchy 积分定理；环域 1<∣z∣<21<|z|<21<∣z∣<2 有积分 2πi2\pi i2πi 的闭路而无对数分支。单连通非必要，例如右半平面删去一点仍可限制主值对数。
