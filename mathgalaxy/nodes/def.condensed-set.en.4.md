# condensed set　`def.condensed-set`
English entry · root `../`
[in graph](../#n=def.condensed-set)　·　[Chinese page (authoritative)](./def.condensed-set.md)

**Example 3. Continuous functions modulo locally constant functions.** There is a unique condensed set $Q$ with $Q(S) = C(S, \mathbb{R}) / C(S, \mathbb{R}^{\mathrm{disc}})$.

What the three examples have in common: **the values are always "some quotient or subset of continuous maps out of compact Hausdorff spaces"**. Condensed sets remember topological information precisely by keeping all these maps.
