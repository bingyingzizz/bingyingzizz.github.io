# limit of a function　`def.function-limit`
English entry · root `../`
[in graph](../#n=def.function-limit)　·　[Chinese page (authoritative)](./def.function-limit.md)

**Heine characterization**: $\lim_{x \to x_0} f(x) = L$ if and only if for every sequence with $x_n \ne x_0$ and $x_n \to x_0$, we have $f(x_n) \to L$.

Replacing $0 < |x - x_0| < \delta$ by other ranges ($x > M$, $x \to x_0^{+}$, $|x| > M$, etc.) yields $x \to \pm\infty$, one-sided limits and various other variants.

## Notes · **draft**
⭐ The only difference from the limit of a **sequence** is this: here the variable approaches continuously, so an extra quantifier $\delta$ is needed to control "how close is close enough".

The whole novelty of the $\varepsilon$-$\delta$ language lies in this two-level quantifier.
