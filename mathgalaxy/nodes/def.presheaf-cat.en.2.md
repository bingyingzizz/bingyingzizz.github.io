# presheaf category　`def.presheaf-cat`
English entry · root `../`
[in graph](../#n=def.presheaf-cat)　·　[Chinese page (authoritative)](./def.presheaf-cat.md)

A few small examples: $\widehat{\emptyset} = \mathbf{1}$ (the unique functor from the empty category to $\mathbf{Set}$); $\widehat{\mathbf{1}} \simeq \mathbf{Set}$ (choose an object and a set);

when $G$ is a monoid, $\widehat{G} \simeq G\text{-}\mathbf{Set}$ (sets with a $G$-action, with maps compatible with translation by every element of $G$).
