# Chern class of a line bundle　`prop.chern-class-line-bundle`
English entry · root `../`
[in graph](../#n=prop.chern-class-line-bundle)　·　[Chinese page (authoritative)](./prop.chern-class-line-bundle.md)

**What this integer is**: $\frac{i}{2\pi}\int_{\Sigma}\Omega$ is the **winding number / first Chern number**, called "quantization of magnetic flux" in physics. On $\Sigma = S^{2}$ it runs over all of $\mathbb{Z}$ — this is the analytic root of the fact that complex line bundles on $S^{2}$ are classified by $\mathbb{Z}$ (the Hopf bundle is a generator, as noted in the notes to @@thm.bundle-classification@@).
