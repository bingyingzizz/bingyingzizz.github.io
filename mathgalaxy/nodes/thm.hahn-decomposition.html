Hahn 分解定理（Hahn Decomposition Theorem）

thm.hahn-decomposition · 定理 · Hahn 分解 · 正集 · 负集

又称Hahn 分解·Hahn decomposition·哈恩分解

陈述

设 ν\nuν 是 (X,M)(X, \mathcal{M})(X,M) 上的符号测度。则存在 P,N∈MP, N \in \mathcal{M}P,N∈M 使

P∪N=X,P∩N=∅,P \cup N = X, \quad P \cap N = \emptyset, P∪N=X,P∩N=∅,

其中 PPP 是正集、NNN 是负集。

若 P′,N′P', N'P′,N′ 是另一对这样的集合，则 P△P′=N△N′P \triangle P' = N \triangle N'P△P′=N△N′ 是 ν\nuν零集。

说明

这就是「把空间按符号一刀切开」：ν\nuν 在 PPP 上非负、在 NNN 上非正。

⚠ 「P△P′P \triangle P'P△P′ 是零集」只是说分解在零集意义下唯一 —— 严格说 Hahn 分解并不唯一（可以把零集在 PPP、NNN 之间随意搬），但一切可测集的 ν\nuν值完全相同。

⭐ 有了它，「符号测度」就完全化归成「两个真测度」—— 这正是下一条 Jordan 分解的内容。
