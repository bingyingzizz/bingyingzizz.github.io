# exact sequence　`def.exact-sequence`
English entry · root `../`
[in graph](../#n=def.exact-sequence)　·　[Chinese page (authoritative)](./def.exact-sequence.md)

$$0 \longrightarrow M' \xrightarrow{\ f\ } M \xrightarrow{\ g\ } M'' \longrightarrow 0$$

means: $f$ is a monomorphism, $g$ is an epimorphism, and $\operatorname{im}(f) = \ker(g)$.

## Notes · **draft**
**In one sentence**: exact = "what comes in is exactly the kernel of what goes out" — no more, no less. $\operatorname{im} \subseteq \ker$ is automatic from the complex condition ($d \circ d = 0$); exactness requires only the **reverse** inclusion.
