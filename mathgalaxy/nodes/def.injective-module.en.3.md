## Notes · **draft**
**Reading**: injective means "extensions can always be made". Note that the extension is **not unique**, so this is not a universal property (unlike the tensor product) but only an existence condition — which makes injectivity hard to characterize pointwise and forces one to use criteria (`thm.baer-criterion`).

**Dual to projective**: reversing all arrows gives the projective objects in `def.projective-object`. In $R\text{-}\mathbf{Mod}$, projective = direct summand of a free module, injective = cannot be embedded as a proper submodule of a larger module (see `prop.injective-splitting`).
