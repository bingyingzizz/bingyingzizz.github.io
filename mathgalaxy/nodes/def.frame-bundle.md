# 帧丛　`def.frame-bundle`
帧丛：把向量丛变成主 $\mathrm{GL}(k)$-丛
layer 27 · 定义 · 流形与向量丛 · 微分几何
[在星图里打开](../#n=def.frame-bundle)　·　[节点索引](../index.md)

**在做什么**：向量丛的纤维是**向量空间**（有加法、有零元），主丛的纤维是**群**（有乘法、没有零元）。帧丛就是两者之间那座桥：把每根纤维里的「一组基」而不是「一个向量」取出来当新纤维。
