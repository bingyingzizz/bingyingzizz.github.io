# Structure Equations　`thm.structure-equations`
English entry · root `../`
[in graph](../#n=thm.structure-equations)　·　[Chinese page (authoritative)](./thm.structure-equations.md)

Let $\omega^{i}$ be the dual coframe ($\mathrm{d}r = \sum_{i}\omega^{i}e_{i}$) and $\omega^{i}_{\ j}$ the connection forms. Then

**First structure equation** (zero torsion)

$$\mathrm{d}\omega^{i} = \sum_{j}\omega^{j}\wedge\omega^{i}_{\ j} ;$$

**Second structure equation** ($\mathbb{R}^{3}$ flat)

$$\mathrm{d}\omega^{i}_{\ j}+\sum_{k}\omega^{i}_{\ k}\wedge\omega^{k}_{\ j} = 0 ,\qquad \mathrm{d}\omega^{i}_{\ j} = \sum_{k}\omega^{k}_{\ j}\wedge\omega^{i}_{\ k}.$$
