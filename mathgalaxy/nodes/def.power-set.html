又称幂集·power set

陈述

设 XXX 是集合。XXX 的幂集是「XXX 的全部子集」装成的集合：

P(X):={A:A⊆X}\mathcal{P}(X) := \{ A : A \subseteq X \}P(X):={A:A⊆X}

于是 A∈P(X)  ⟺  A⊆XA \in \mathcal{P}(X) \iff A \subseteq XA∈P(X)⟺A⊆X，且 P(X)\mathcal{P}(X)P(X) 自己的元素都是集合。

由幂集公理，P(X)\mathcal{P}(X)P(X) 确实是集合；由外延公理它唯一。

有限情形的元素个数：∣X∣=n  ⟹  ∣P(X)∣=2n|X| = n \implies |\mathcal{P}(X)| = 2^{n}∣X∣=n⟹∣P(X)∣=2n（每个元素「取或不取」）。

说明

⭐ 幂集是「把性质变成对象」的那一步：想谈「XXX 的所有子集」这件事本身（而不是逐个谈），就得有幂集。P(X)\mathcal{P}(X)P(X) 同时是几个重要构造的舞台：

  • 外测度定义在全体子集上：μ∗:P(X)→[0,+∞]\mu^* : \mathcal{P}(X) \to [0, +\infty]μ∗:P(X)→[0,+∞]；
  • 环、σ\sigmaσ-代数、单调类都是 P(X)\mathcal{P}(X)P(X) 的某一族子集；
  • 生成的 σ\sigmaσ-代数取的就是「一切包含 E\mathcal{E}E 的 σ\sigmaσ-代数之交」，而 P(X)\mathcal{P}(X)P(X) 保证这个交不空。

⚠ ∅∈P(X)\emptyset \in \mathcal{P}(X)∅∈P(X) 且 X∈P(X)X \in \mathcal{P}(X)X∈P(X) 对一切 XXX 成立 —— 幂集从来不是空的。

    ① ∣A∣≤∣P(A)∣|A| \le |\mathcal{P}(A)|∣A∣≤∣P(A)∣。 映射 a↦{a}a \mapsto \{a\}a↦{a} 是单射：{a}={a′}  ⟹  a=a′\{a\} = \{a'\} \implies a = a'{a}={a′}⟹a=a′。
