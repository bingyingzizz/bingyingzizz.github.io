陈述

在做什么：把最低那一格算出来 —— 000-形式是函数，「闭」就是「局部常」，于是 H0H^{0}H0 精确地数连通分支的个数。

设 MMM 是光滑流形，ccc 是它的连通分支个数。则

HdR0(M)≅Rc.H^{0}_{\mathrm{dR}}(M) \cong \mathbb{R}^{c}.HdR0​(M)≅Rc.

特别地，MMM 连通当且仅当 dim⁡HdR0(M)=1\dim H^{0}_{\mathrm{dR}}(M) = 1dimHdR0​(M)=1（M≠∅M \ne \emptysetM=∅）。

000-形式就是光滑函数，df=0\mathrm{d}f = 0df=0 等价于 fff 在每张连通卡上是常数；而 B0=0B^{0} = 0B0=0，所以 H0=Z0H^{0} = Z^{0}H0=Z0，没有商可做。

说明

为什么是 Rc\mathbb{R}^{c}Rc 而不是 Zc\mathbb{Z}^{c}Zc：系数是实数，H0H^{0}H0 是实向量空间，一组基就是各连通分支的指示函数。所以「H0H^{0}H0 数分支」是在维数上数的，不是数元素个数。

证明的两步：① df=0\mathrm{d}f = 0df=0 当且仅当 fff 在每个连通分支上常值（分支连通，任两点能用一串卡连起来，相邻两张卡的重叠在连通块上、常值相同）；② B0=0B^{0} = 0B0=0，因为没有 −1-1−1-形式，没有东西可商。于是 H0H^{0}H0 同构于「局部常函数构成的空间」，而这个空间的维数恰是分支数。细节在边上。

它是函子性的：F:N→MF : N \to MF:N→M 光滑时 F∗:H0(M)→H0(N)F^{\ast} : H^{0}(M) \to H^{0}(N)F∗:H0(M)→H0(N) 就是「把 MMM 上的局部常函数拉回去」。MMM 连通而 NNN 不连通时，FFF 在每个分支上只能取一个常值 —— 分支结构被这一条完全编码。

与同伦的关系：H0H^{0}H0 是 π0(M)\pi_{0}(M)π0​(M) 上的自由实向量空间，所以它是同伦不变量而非微分不变量。这也是 de Rham 定理在 k=0k = 0k=0 时的样子（0 维奇异上同调同样是每个分支贡献一个 R\mathbb{R}R）。

别拿 Poincaré 引理套 H0H^{0}H0：引理说的是 k≥1k \ge 1k≥1 且区域可缩才有 Hk=0H^{k} = 0Hk=0。H0H^{0}H0 对非空流形永远不为零，因为它数的是「有几个整体」而不是「有没有局部障碍」。

    de Rham 定理的 k=0k=0k=0 情形：上同调数连通分支

    de Rham 定理给 k=0k = 0k=0 的自然同构

    Φ0:HdR0(M)⟶Hsing0(M;R),[ω]⟼([c]↦∫cω).\Phi^{0} : H^{0}_{\mathrm{dR}}(M) \longrightarrow H^{0}_{\mathrm{sing}}(M;\mathbb{R}), \qquad [\omega] \longmapsto \Bigl([c]\mapsto \int_{c}\omega\Bigr).Φ0:HdR0​(M)⟶Hsing0​(M;R),[ω]⟼([c]↦∫c​ω).

    右边直接算。 奇异 000-链是点的形式和，所以 000-上链就是「给每个点一个实数」的函数；对一条道路 σ\sigmaσ，

    δ0f(σ)=f(σ(1))−f(σ(0)).\delta^{0}f(\sigma) = f\bigl(\sigma(1)\bigr) - f\bigl(\sigma(0)\bigr).δ0f(σ)=f(σ(1))−f(σ(0)).

    于是 fff 是上循环当且仅当它在每条道路两端取值相同，即 fff 在道路连通分支上常值；又因为没有 −1-1−1-单形，上边缘群为零。流形局部道路连通，连通与道路连通一致，设连通分支有 ccc 个，则

    Hsing0(M;R)≅Rc,H^{0}_{\mathrm{sing}}(M;\mathbb{R}) \cong \mathbb{R}^{c},Hsing0​(M;R)≅Rc,

    再由 Φ0\Phi^{0}Φ0 得 HdR0(M)≅RcH^{0}_{\mathrm{dR}}(M) \cong \mathbb{R}^{c}HdR0​(M)≅Rc；特别地 M≠∅M \ne \emptysetM=∅ 时 MMM 连通当且仅当 dim⁡HdR0(M)=1\dim H^{0}_{\mathrm{dR}}(M) = 1dimHdR0​(M)=1。■\blacksquare■

    这里没有任何「形式」的计算：H0H^{0}H0 的整条结论都是从 de Rham 定理借来的，k≥1k \ge 1k≥1 才需要 Poincaré 引理那一套。
