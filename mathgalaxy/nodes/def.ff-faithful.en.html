Statement

A functor F:C→C′F : \mathcal{C} \to \mathcal{C}'F:C→C′ assigns to each pair of objects X,YX, YX,Y a map

Hom⁡C(X,Y)⟶Hom⁡C′(F(X),F(Y)),f↦F(f)\operatorname{Hom}_{\mathcal{C}}(X, Y) \longrightarrow \operatorname{Hom}_{\mathcal{C}'}(F(X), F(Y)), \qquad f \mapsto F(f)HomC​(X,Y)⟶HomC′​(F(X),F(Y)),f↦F(f)

The names are given according to the properties of this map:

  • faithful: each such map is injective;
  • full: each such map is surjective;
  • fully faithful: each such map is bijective.

Notes

All three names concern the behaviour of FFF on the morphism level, independently of the object level — a fully faithful functor may send two distinct objects to the same object (which is exactly what is allowed in an equivalence).

Faithfulness guarantees that "morphisms are not merged", fullness that "every morphism in the target comes from the source"; neither implies the other.
