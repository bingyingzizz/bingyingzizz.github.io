又称缩并

陈述

白话：张量上有一个上标和一个下标时，可以把它们「配对吃掉」，得到一个少两阶的张量 —— 这就是缩并；矩阵的取迹是它最熟悉的特例。

设 TTT 是 MMM 上的 (r,s)(r,s)(r,s) 型张量场（def.tensor-field），r,s≥1r, s \ge 1r,s≥1。取定第 iii 个上标（1≤i≤r1 \le i \le r1≤i≤r）与第 jjj 个下标（1≤j≤s1 \le j \le s1≤j≤s），缩并 C jiT\mathrm{C}^{i}_{\ j}TC ji​T 是 (r−1,s−1)(r-1,s-1)(r−1,s−1) 型张量场，逐点定义为

(C jiT)p(α1,…,αi^,…; v1,…,vj^,…):=∑a=1nTp(…,dxa,…; …,∂a,…),\bigl(\mathrm{C}^{i}_{\ j}T\bigr)_{p}\bigl(\alpha^{1},\ldots,\widehat{\alpha^{i}},\ldots;\ v_{1},\ldots,\widehat{v_{j}},\ldots\bigr) := \sum_{a=1}^{n} T_{p}\bigl(\ldots,\mathrm{d}x^{a},\ldots;\ \ldots,\partial_{a},\ldots\bigr),(C ji​T)p​(α1,…,αi,…; v1​,…,vj​​,…):=a=1∑n​Tp​(…,dxa,…; …,∂a​,…),

即把第 iii 个余向量槽与第 jjj 个向量槽用同一组基配对求和（帽子记「去掉这一项」）。在卡里就是

(C jiT)……=∑a=1nT… a …… a …,\bigl(\mathrm{C}^{i}_{\ j}T\bigr)^{\ldots}_{\ldots} = \sum_{a=1}^{n} T^{\ldots\,a\,\ldots}_{\ldots\,a\,\ldots},(C ji​T)……​=a=1∑n​T…a……a…​,

一上一下两个指标同名求和 —— 爱因斯坦求和约定。

说明

为什么必须一上一下：缩并的实质是用配对 dxa(∂b)=δ ba\mathrm{d}x^{a}(\partial_{b}) = \delta^{a}_{\ b}dxa(∂b​)=δ ba​ 吃掉一对指标，而这样的配对只存在于「一个余向量槽、一个向量槽」之间。两个上标想配对，得先借度量把其中一个拉下来（Tab↦gacTcbT^{ab} \mapsto g_{ac}T^{cb}Tab↦gac​Tcb 再缩并，得 T aaT^{a}_{\ a}T aa​）—— 那是用了额外结构的运算，不是张量代数自带的。

(1,1)(1,1)(1,1) 型时就是取迹：C 11T=tr⁡T\mathrm{C}^{1}_{\ 1}T = \operatorname{tr}TC 11​T=trT（把 TTT 看成逐点的线性变换 TpM→TpMT_{p}M \to T_{p}MTp​M→Tp​M）。所以缩并是取迹的推广，def.trace 里那条「tr⁡(AB)=tr⁡(BA)\operatorname{tr}(AB) = \operatorname{tr}(BA)tr(AB)=tr(BA)」在这里读作「缩并的次序可以调换」。

例子：曲率张量是 (1,3)(1,3)(1,3) 型的，缩并一次（上标与第二个下标）得 Ricci 张量（def.ricci-curvature），再缩并一次得标量曲率。Einstein 张量是 Ricci 张量与 ggg 的组合 —— 所以「曲率的三个层次」就是「缩并 0/1/20/1/20/1/2 次」。

与坐标无关：换卡时上标各乘一次 ∂y/∂x\partial y/\partial x∂y/∂x、下标各乘一次 ∂x/∂y\partial x/\partial y∂x/∂y；被缩的那一对恰好一个上标一个下标，两个 Jacobi 矩阵互逆，乘起来是 δ\deltaδ。这一步是「缩并是张量运算」的全部内容（对照 def.tensor-field 的 notes：变化律只含一阶导）。

⚠️ 记号冲突：def.trace 是「矩阵取迹」，这里的缩并是它在张量场上的推广；而 C ji\mathrm{C}^{i}_{\ j}C ji​ 里的 C\mathrm{C}C 不是「连续函数空间」的 CCC。三处同字母，取用时看上下文。

和楔积的关系：楔积是「交错化加张量积」，缩并是「配对吃掉一对指标」。两者生成张量代数上的全部自然运算 —— 这条是古典不变量理论的结论，本图只提不证。

    它就是迹。 把 TTT 在某点的分量写成矩阵 A=(T ji)A = (T^{i}_{\ j})A=(T ji​)（第 iii 行是上标、第 jjj 列是下标），则上式正是 ∑aAaa=tr⁡A\sum_{a} A_{aa} = \operatorname{tr} A∑a​Aaa​=trA。所以「缩并」在 r=s=1r = s = 1r=s=1 这一格上退化成取迹。

    顺带得到 tr⁡(AB)=tr⁡(BA)\operatorname{tr}(AB) = \operatorname{tr}(BA)tr(AB)=tr(BA)。 缩并按哪一个上标与哪一个下标配对来定义；而求和号 ∑aT…a……a…\sum_{a} T^{\ldots a \ldots}_{\ldots a \ldots}∑a​T…a……a…​ 里的哑标可以任意换名 —— 换成另一对上下标就是另一种缩并，在 ABA BAB 上分别算得 tr⁡(AB)\operatorname{tr}(AB)tr(AB) 与 tr⁡(BA)\operatorname{tr}(BA)tr(BA)。两者是同一个张量的同一组求和指标的重排，故相等。■\blacksquare■
