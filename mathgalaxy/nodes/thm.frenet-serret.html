陈述

设 γ\gammaγ 是弧长参数化的 C3C^{3}C3 正则曲线，κ>0\kappa>0κ>0。则

T′=κN,N′=−κT+τB,B′=−τN.T' = \kappa N,\qquad N' = -\kappa T+\tau B,\qquad B' = -\tau N .T′=κN,N′=−κT+τB,B′=−τN.

写成矩阵就是

(T′N′B′)=(0κ0−κ0τ0−τ0)(TNB).\begin{pmatrix} T' \\ N' \\ B' \end{pmatrix} = \begin{pmatrix} 0 & \kappa & 0 \\ -\kappa & 0 & \tau \\ 0 & -\tau & 0 \end{pmatrix}\begin{pmatrix} T \\ N \\ B \end{pmatrix}.​T′N′B′​​=​0−κ0​κ0−τ​0τ0​​​TNB​​.

系数矩阵反称 —— 这正是「标架始终是正交标架」的无穷小写法。

说明

⭐ 为什么只有两个函数：3×33\times33×3 反称矩阵有 333 个自由度，但 T′T'T′ 的方向被 NNN 的定义锁死（⟨T′,T⟩=⟨T′,B⟩=0\langle T',T\rangle = \langle T',B\rangle = 0⟨T′,T⟩=⟨T′,B⟩=0 是恒等式），于是只剩 κ\kappaκ 与 τ\tauτ。

与结构方程是同一件事：把 dT,dN,dB\mathrm{d}T,\mathrm{d}N,\mathrm{d}BdT,dN,dB 按标架展开，系数就是 κ ds\kappa\,\mathrm{d}sκds、τ ds\tau\,\mathrm{d}sτds。曲面的 ω ji\omega^{i}_{\ j}ω ji​（def.connection-form）在曲线情形退化成这三个数乘以 ds\mathrm{d}sds。

反称性的来源：⟨T,T⟩=⟨N,N⟩=⟨B,B⟩=1\langle T,T\rangle = \langle N,N\rangle = \langle B,B\rangle = 1⟨T,T⟩=⟨N,N⟩=⟨B,B⟩=1、⟨T,N⟩=⟨T,B⟩=⟨N,B⟩=0\langle T,N\rangle = \langle T,B\rangle = \langle N,B\rangle = 0⟨T,N⟩=⟨T,B⟩=⟨N,B⟩=0 都是常数，求导即得矩阵反称 —— 与 prop.connection-antisymmetric 的证明逐字相同。

⚠️ 只在 κ>0\kappa>0κ>0 处成立。κ=0\kappa = 0κ=0 的孤立点上 NNN 不存在，公式没有意义（但 κ\kappaκ 本身仍然有定义）。

它的用处：把曲线的几何问题化成一个线性方程组问题 —— 于是「存在性 + 唯一性」可以整块交给 ODE（thm.curve-fundamental-theorem）。

    唯一性。 设 γ1,γ2\gamma_{1},\gamma_{2}γ1​,γ2​ 给出相同的 (κ,τ)(\kappa,\tau)(κ,τ)，对应标架 X1,X2X_{1},X_{2}X1​,X2​。取唯一的刚体运动 ggg 使 g∗(X2(s0))=X1(s0)g_{\ast}\bigl(X_{2}(s_{0})\bigr) = X_{1}(s_{0})g∗​(X2​(s0​))=X1​(s0​) 且 g(γ2(s0))=γ1(s0)g\bigl(\gamma_{2}(s_{0})\bigr) = \gamma_{1}(s_{0})g(γ2​(s0​))=γ1​(s0​)。则 g∘γ2g\circ\gamma_{2}g∘γ2​ 与 γ1\gamma_{1}γ1​ 满足同一个 ODE、有相同初值，由解的唯一性两者标架相等，从而曲线相等。∎

    单位正交   ⟹  \implies⟹ Frenet–Serret 公式

    全程弧长参数，⟨T,T⟩=⟨N,N⟩=⟨B,B⟩=1\langle T,T\rangle = \langle N,N\rangle = \langle B,B\rangle = 1⟨T,T⟩=⟨N,N⟩=⟨B,B⟩=1，两两正交。

    0=⟨B′,T⟩+⟨B,T′⟩=⟨B′,T⟩+κ⟨B,N⟩=⟨B′,T⟩,0 = \langle B',T\rangle+\langle B,T'\rangle = \langle B',T\rangle+\kappa\langle B,N\rangle = \langle B',T\rangle ,0=⟨B′,T⟩+⟨B,T′⟩=⟨B′,T⟩+κ⟨B,N⟩=⟨B′,T⟩,

    故 B′B'B′ 与 TTT 也正交。三维里同时垂直于 TTT 与 BBB 的方向只有 ±N\pm N±N，于是 B′=⟨B′,N⟩N=−τNB' = \langle B',N\rangle N = -\tau NB′=⟨B′,N⟩N=−τN，最后一步是 τ\tauτ 的定义。

    (3) N′=−κT+τBN' = -\kappa T+\tau BN′=−κT+τB。 ⟨N,N⟩=1\langle N,N\rangle = 1⟨N,N⟩=1 给 N′⊥NN'\perp NN′⊥N，所以 N′N'N′ 落在 {T,B}\{T,B\}{T,B} 张成的平面里，只需两个系数：

    ⟨N′,T⟩=−⟨N,T′⟩=−κ⟨N,N⟩=−κ,⟨N′,B⟩=−⟨N,B′⟩=τ⟨N,N⟩=τ.\langle N',T\rangle = -\langle N,T'\rangle = -\kappa\langle N,N\rangle = -\kappa ,\qquad \langle N',B\rangle = -\langle N,B'\rangle = \tau\langle N,N\rangle = \tau .⟨N′,T⟩=−⟨N,T′⟩=−κ⟨N,N⟩=−κ,⟨N′,B⟩=−⟨N,B′⟩=τ⟨N,N⟩=τ.

    于是 N′=−κT+τBN' = -\kappa T+\tau BN′=−κT+τB。∎
