陈述

在 R3\mathbb{R}^{3}R3（标准内积）里取子空间 W={ (x,y,0) }W = \{\, (x, y, 0) \,\}W={(x,y,0)}。到 WWW 的正交投影是

P=(100010000).P = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 0 \end{pmatrix}.P=​100​010​000​​.

说明

三条性质逐条验：P2=PP^{2} = PP2=P（幂等）；P∗=PP^{\ast} = PP∗=P（对称）；ker⁡P=span⁡(e3)\ker P = \operatorname{span}(e_{3})kerP=span(e3​)、im⁡P=W\operatorname{im} P = WimP=W，且 R3=ker⁡P⊕im⁡P\mathbb{R}^{3} = \ker P \oplus \operatorname{im} PR3=kerP⊕imP 正交直和。反过来：幂等 + 对称   ⟹  \implies⟹ 正交投射（只幂等的话是斜投射，像与核不垂直）。

⭐ 它是最小二乘的几何内核：Pb=(b1,b2,0)P b = (b_{1}, b_{2}, 0)Pb=(b1​,b2​,0) 就是「离 bbb 最近的 WWW 中的点」，残差 b−Pb=(0,0,b3)b - Pb = (0, 0, b_{3})b−Pb=(0,0,b3​) 与 WWW 正交 —— 这正是 最小二乘 的法方程的几何内容。一般情形 W=col⁡(A)W = \operatorname{col}(A)W=col(A) 时投影矩阵就是 A(ATA)−1ATA(A^{T}A)^{-1}A^{T}A(ATA)−1AT。

📌 与伪逆的关系：A=PA = PA=P 本身是幂等且对称的，所以 A+=AA^{+} = AA+=A（Penrose 四条直接成立）。这说明「投影」在伪逆的语言里是自伴幂等那一类。

⚠ 别把投影矩阵当成「去掉一个坐标」：换一组非标准正交基，矩阵就不再是对角形 —— 「投影」是几何概念，diag⁡(1,1,0)\operatorname{diag}(1,1,0)diag(1,1,0) 只是它在标准基下的样子。
