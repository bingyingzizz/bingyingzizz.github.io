# Perfectly Normal Space　`def.perfectly-normal-space`
English entry · root `../`
[in graph](../#n=def.perfectly-normal-space)　·　[Chinese page (authoritative)](./def.perfectly-normal-space.md)

⚠️ **Every metric space is perfectly normal**: $d(x, F)$ is continuous, $F = \{\, x : d(x, F) = 0 \,\}$, and $\{\, x : d(x,F) < 1/n \,\}$ is a sequence of open sets — hence a closed set is a countable intersection of open sets ✓. So $T_{6}$ almost always holds automatically in analysis; it is a genuine condition only in general topology.
