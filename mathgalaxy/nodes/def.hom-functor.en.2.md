# Hom functor　`def.hom-functor`
English entry · root `../`
[in graph](../#n=def.hom-functor)　·　[Chinese page (authoritative)](./def.hom-functor.md)

Fix $W$. The **contravariant Hom functor** $\operatorname{Hom}_K(-,W):\mathbf{Vect}_K^{\mathrm{op}}\to\mathbf{Vect}_K$ sends an object to $U\mapsto\operatorname{Hom}_K(U,W)$ and a morphism $T:U_1\to U_2$ to postcomposition $(-)\circ T:\operatorname{Hom}_K(U_2,W)\to\operatorname{Hom}_K(U_1,W)$.

Both Hom-sets become $K$-vector spaces under pointwise addition and pointwise scalar multiplication, and the morphism part of the functor is linear, so the target category is $\mathbf{Vect}_K$, not merely $\mathbf{Set}$.
