陈述

三角函数是周期的，整体上没有反函数；但在单调区间上可以取反函数：

  • arcsin⁡:[−1,1]→[−π/2,π/2]\arcsin : [-1, 1] \to [-\pi/2, \pi/2]arcsin:[−1,1]→[−π/2,π/2] 是 sin⁡\sinsin 限制在 [−π/2,π/2][-\pi/2, \pi/2][−π/2,π/2] 上的反函数；
  • arccos⁡:[−1,1]→[0,π]\arccos : [-1, 1] \to [0, \pi]arccos:[−1,1]→[0,π] 是 cos⁡\coscos 限制在 [0,π][0, \pi][0,π] 上的反函数；
  • arctan⁡:R→(−π/2,π/2)\arctan : \mathbb{R} \to (-\pi/2, \pi/2)arctan:R→(−π/2,π/2) 是 tan⁡\tantan 限制在 (−π/2,π/2)(-\pi/2, \pi/2)(−π/2,π/2) 上的反函数。

即 sin⁡(arcsin⁡x)=x\sin(\arcsin x) = xsin(arcsinx)=x（∣x∣≤1|x| \le 1∣x∣≤1），而 arcsin⁡(sin⁡x)=x\arcsin(\sin x) = xarcsin(sinx)=x 只在 ∣x∣≤π/2|x| \le \pi/2∣x∣≤π/2 时成立。

说明

⚠ 最关键的一条：arcsin⁡(sin⁡x)=x\arcsin(\sin x) = xarcsin(sinx)=x 一般不成立（只在上面的单调区间内成立）；反过来 sin⁡(arcsin⁡x)=x\sin(\arcsin x) = xsin(arcsinx)=x 在定义域内总成立。这个「一侧总成立、另一侧要看区间」是反函数的一般规律。

⭐ 为什么必须挑区间：sin⁡\sinsin 在 [0,π][0, \pi][0,π] 上不单调，所以那里没有单值的反函数；选 [−π/2,π/2][-\pi/2, \pi/2][−π/2,π/2] 是约定（值域对称、含 000、连续），换一个区间就是另一个反函数。

⭐ 导数（都能从反函数求导 + sin⁡2+cos⁡2=1\sin^{2}+\cos^{2}=1sin2+cos2=1 推出）：

(arcsin⁡x)′=11−x2,(arctan⁡x)′=11+x2.(\arcsin x)' = \frac{1}{\sqrt{1 - x^{2}}}, \qquad (\arctan x)' = \frac{1}{1 + x^{2}} .(arcsinx)′=1−x2​1​,(arctanx)′=1+x21​.

⚠ 两个都要注意开区间：arcsin⁡\arcsinarcsin 在 x=±1x = \pm 1x=±1 处导数发散（竖直切线），所以端点的单侧差商 →+∞\to +\infty→+∞ —— 不存在有限的单侧导数。
