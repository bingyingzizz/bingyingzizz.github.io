# Set, Top and Ab are complete　`prop.set-top-ab-complete`
English entry · root `../`
[in graph](../#n=prop.set-top-ab-complete)　·　[Chinese page (authoritative)](./prop.set-top-ab-complete.md)

The forgetful functor preserves limits because both topological and algebraic structure are defined "pointwise" ✓; but the underlying set of $M \oplus N$ is not $M \sqcup N$, so $\mathbf{Ab} \to \mathbf{Set}$ does not preserve coproducts ✓. ∎
