fff 与 ggg 之间的一个链同伦是一族同态 Pn:Cn→Dn+1P_{n} : C_{n} \to D_{n+1}Pn​:Cn​→Dn+1​，满足

∂n+1′Pn+Pn−1∂n=gn−fn.\partial_{n+1}' P_{n} + P_{n-1} \partial_{n} = g_{n} - f_{n}.∂n+1′​Pn​+Pn−1​∂n​=gn​−fn​.

基本事实：若存在这样的 PPP，则 fff 与 ggg 在同调上诱导同一个同态，即 f∗=g∗:Hn(C)→Hn(D)f_{} = g_{} : H_{n}(C) \to H_{n}(D)f∗​=g∗​:Hn​(C)→Hn​(D)。

说明

为什么「链同伦   ⟹  \implies⟹ 同调上相等」：设 z∈Cnz \in C_{n}z∈Cn​ 是闭链（∂z=0\partial z = 0∂z=0）。则

g(z)−f(z)=∂′P(z)+P∂(z)=∂′P(z),g(z) - f(z) = \partial' P(z) + P\partial(z) = \partial' P(z),g(z)−f(z)=∂′P(z)+P∂(z)=∂′P(z),

即 g(z)−f(z)g(z) - f(z)g(z)−f(z) 是 DDD 中的边缘，于是它代表的同调类是 000。也就是说 [g(z)]=[f(z)][g(z)] = [f(z)][g(z)]=[f(z)]，对每个闭链成立 —— 正是 f∗=g∗f_{} = g_{}f∗​=g∗​。∎

⭐ 它是「同伦」在代数侧的翻译：拓扑里的同伦是「两映射之间的一条连续形变」，链复形里没有空间可形变，于是把形变换成一个升一次的同态 PPP。∂P+P∂\partial P + P\partial∂P+P∂ 这个组合恰好是「链复形的同伦」应该有的样子：它与 ∂\partial∂ 反交换，于是把闭链送到边缘。

⚠️ 链同伦不是等价关系：fff 与 ggg 链同伦、ggg 与 hhh 链同伦不能推出 fff 与 hhh 链同伦（P+QP + QP+Q 差一个符号，要对上得调整）。但「存在链同伦」在链映射的集合上确实给出对称的关系，同伦范畴就是把它们形式地变成同构。
