# Sheaf Cohomology Is a Homotopy Invariant　`cor.homotopy-invariant-cohomology`
English entry · root `../`
[in graph](../#n=cor.homotopy-invariant-cohomology)　·　[Chinese page (authoritative)](./cor.homotopy-invariant-cohomology.md)

⭐ **This is the source of the phrase "sheaf cohomology is a topological invariant"** — with constant coefficients, $H^{n}(-, M)$ is homotopy invariant, so it can be used to compute invariants of homotopy classes of spaces (singular cohomology and de Rham cohomology both fall under this statement).
