## Notes · **draft**
⭐ **Why "every closed set is a countable intersection of open sets" deserves its own axiom**: it guarantees a **continuous function whose zero set is exactly the closed set** ($F = f^{-1}(0)$), not merely "$f$ vanishes on $F$". This is crucial in infinite-dimensional analysis ($G_{\delta}$ points in $C^{*}$-algebras, strengthened forms of the Baire category theorem).
