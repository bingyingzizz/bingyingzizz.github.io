陈述

在做什么：把两个「边界」对齐 —— 一个是方块上按坐标编号定出来的代数边界 ∂c\partial c∂c，一个是带边流形上按「外法向在前」定出来的几何边界。它们相差的正是那串符号 (−1)i+α(-1)^{i+\alpha}(−1)i+α。

设 MMM 是定向 nnn 维带边流形，c:In→Mc : I^{n}\to Mc:In→M 是保向的微分同胚，把 InI^{n}In 映到自己的像上（像是一个带边的 nnn 维区域，InI^{n}In 取标准定向）。则对每个面 (i,α)(i,\alpha)(i,α)：把 c(i,α)c_{(i,\alpha)}c(i,α)​ 看成 ∂M\partial M∂M 的像上的参数化，它与 ∂M\partial M∂M 的诱导定向相符，当且仅当 (−1)i+α=+1(-1)^{i+\alpha} = +1(−1)i+α=+1。

换句话说：把所有面按诱导定向重新排一次符号，得到的链就是

∂c=∑i=1n∑α=01(−1)i+α c(i,α).\partial c = \sum_{i=1}^{n}\sum_{\alpha=0}^{1}(-1)^{i+\alpha}\,c_{(i,\alpha)} .∂c=i=1∑n​α=0∑1​(−1)i+αc(i,α)​.

所以「代数边界」与「几何边界」不是两套约定，是同一套：符号已经写在 ∂c\partial c∂c 的系数里了。

说明

为什么这条重要：流形版的 Stokes 定理（thm.stokes）用的是几何边界（诱导定向），链版的 Stokes 定理（thm.stokes-chain）用的是代数边界（∂c\partial c∂c）。两者能写成同一个公式，全靠这个命题。它也是散度定理里那个「外法向 + 诱导定向」符号的真正出处。

n=1n = 1n=1 的验算：I1=[0,1]I^{1} = [0,1]I1=[0,1]，∂c=−c(1,0)+c(1,1)=c(1)−c(0)\partial c = -c_{(1,0)}+c_{(1,1)} = c(1)-c(0)∂c=−c(1,0)​+c(1,1)​=c(1)−c(0)。而 000 维的诱导定向里，x=1x = 1x=1 那端（外法向 +e1+e_{1}+e1​）为正、x=0x = 0x=0 那端为负。逐项相符。

n=2n = 2n=2 的验算：∂c=−c(1,0)+c(1,1)+c(2,0)−c(2,1)\partial c = -c_{(1,0)}+c_{(1,1)}+c_{(2,0)}-c_{(2,1)}∂c=−c(1,0)​+c(1,1)​+c(2,0)​−c(2,1)​。四条边分别是左、右、下、上；右边（α=1\alpha = 1α=1，外法向 +e1+e_{1}+e1​）取 +++，左边（外法向 −e1-e_{1}−e1​）取 −-−，下边（外法向 −e2-e_{2}−e2​）取 +++，上边（外法向 +e2+e_{2}+e2​）取 −-−。按「外法向在前」逐个核对，四条全部相符 —— 而四条边的走向正好构成逆时针一圈。

⚠️ 顺序容易抄错的方向：证明里比较的是「面自身的基在 Rn\mathbb{R}^{n}Rn 里与 NNN 拼起来后的行列式」，不是「面的基与 NNN 的叉积方向」。前者是纯代数、可逐项验算；后者只在三维有直觉。三维以下的直觉可以帮忙记，但不能当证明。

⚠️ 保向性不能丢：若 ccc 反向，则每个面都多一个负号，命题的结论整体差一个号。所以命题的前提写成「ccc 保向」，而不是「ccc 是微分同胚」。
