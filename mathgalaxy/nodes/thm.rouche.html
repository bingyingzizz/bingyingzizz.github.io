白话：如果两个全纯函数在闭曲线的边界上，「扰动项」的模严格小于「主项」的模，那么加上扰动不会改变曲线内部的零点个数。

设 γ\gammaγ 是分段光滑闭曲线，f,gf, gf,g 在 γ\gammaγ 及其内部全纯，且在 γ\gammaγ 上处处

∣g(z)∣<∣f(z)∣.|g(z)| < |f(z)|.∣g(z)∣<∣f(z)∣.

则 fff 与 f+gf + gf+g 在 γ\gammaγ 内部有同样多的零点（都按重数计）。

说明

⭐ 用途：数零点不用解方程，只要在边界上比大小。例：f(z)=−5z3f(z) = -5z^3f(z)=−5z3、g(z)=z7+z−2g(z) = z^7 + z - 2g(z)=z7+z−2，在 ∣z∣=1|z| = 1∣z∣=1 上 ∣g∣≤1+1+2=4<5=∣f∣|g| \le 1 + 1 + 2 = 4 < 5 = |f|∣g∣≤1+1+2=4<5=∣f∣，故 z7−5z3+z−2z^7 - 5z^3 + z - 2z7−5z3+z−2 在 ∣z∣<1|z| < 1∣z∣<1 内恰有 333 个零点（与 −5z3-5z^3−5z3 相同）。

⭐ 代数基本定理的另一条证明：f(z)=anznf(z) = a_n z^nf(z)=an​zn、g(z)=an−1zn−1+⋯+a0g(z) = a_{n-1}z^{n-1} + \cdots + a_0g(z)=an−1​zn−1+⋯+a0​，在 ∣z∣=R|z| = R∣z∣=R 上取 RRR 充分大就有 ∣g∣<∣f∣|g| < |f|∣g∣<∣f∣，于是 ppp 与 anzna_n z^nan​zn 在 ∣z∣<R|z| < R∣z∣<R 内零点数相同，都是 nnn 个。

⚠ 条件必须严格、而且要在整条边界上成立。等号是可以出事的位置：f=zf = zf=z、g=−zg = -zg=−z 在 ∣z∣=1|z| = 1∣z∣=1 上有 ∣g∣=∣f∣|g| = |f|∣g∣=∣f∣，fff 与 f+g=0f + g = 0f+g=0 的零点数完全不同。

📌 「主项」怎么挑：挑边界上模最大的那一项。这与「多项式在远处的行为由最高次项决定」是同一件事。
