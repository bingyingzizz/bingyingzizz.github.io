# closed set and closure　`def.closed-set`
English entry · root `../`
[in graph](../#n=def.closed-set)　·　[Chinese page (authoritative)](./def.closed-set.md)

By De Morgan's laws, the three axioms for open sets become, for closed sets: $\emptyset, X$ are closed; **arbitrary** intersections are closed; **finite** unions are closed.

## Notes · **draft**
Open and closed are not opposites: $\emptyset$ and $X$ are both open and closed; in $\mathbb{R}$, $[0, 1]$ is closed while $[0, 1)$ is neither open nor closed.

The closure "collects all the limit points": in a metric space, $\overline{A}$ is exactly the set of limits of sequences in $A$.
