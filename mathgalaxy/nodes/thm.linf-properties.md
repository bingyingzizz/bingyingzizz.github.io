# L^∞ 的性质　`thm.linf-properties`
定理：$L^\infty$ 的五条基本性质
layer 19 · 定理 · L^p 空间 · 分析学

**(a)** $\|fg\|_\infty \le \|f\|_\infty \|g\|_\infty$。若 $f \in L^1$、$g \in L^\infty$，则

$$\|fg\|_1 = \|f\|_1 \|g\|_\infty \iff |g(x)| = \|g\|_\infty \text{ a.e. on } \{f \ne 0\}$$

**(b)** $\|\cdot\|_\infty$ 是 $L^\infty$ 上的**范数**。
