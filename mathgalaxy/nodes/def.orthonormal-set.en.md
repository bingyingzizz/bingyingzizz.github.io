## Statement · **draft**
Let $\{f_i\}_{i \in I} \subseteq H$.

- **Orthogonal**: $f_i \perp f_j$ ($i \ne j$);
- **Orthonormal**: orthogonal + $\|f_i\| = 1$;
- **Complete**: $\overline{\operatorname{span}\{f_i\}} = H$;
- **Orthonormal basis**: orthonormal + complete.
