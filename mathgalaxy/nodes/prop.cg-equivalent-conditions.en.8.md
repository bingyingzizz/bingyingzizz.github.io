# Equivalent Characterizations of Compact Generation　`prop.cg-equivalent-conditions`
English entry · root `../`
[in graph](../#n=prop.cg-equivalent-conditions)　·　[Chinese page (authoritative)](./prop.cg-equivalent-conditions.md)

⭐ **The test spaces are uniformly taken compact Hausdorff.** The defining item and items (2)(3)(4)(6) here use the same family of test spaces — that is: $X$ compactly generated $\iff$ there is a disjoint union of compact Hausdorff spaces $\coprod S \twoheadrightarrow X$ that is a quotient map $\iff$ there is a locally compact Hausdorff space $Z \twoheadrightarrow X$ that is a quotient map.

**The three descriptions give the same category**; use whichever is easier to compute with.
