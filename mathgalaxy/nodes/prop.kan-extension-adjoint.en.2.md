# Kan Extensions and the Existence of Adjoints　`prop.kan-extension-adjoint`
English entry · root `../`
[in graph](../#n=prop.kan-extension-adjoint)　·　[Chinese page (authoritative)](./prop.kan-extension-adjoint.md)

$$p^{-1} : \operatorname{Hom}(\mathcal{C}', \mathcal{D}) \longrightarrow \operatorname{Hom}(\mathcal{C}, \mathcal{D}), \qquad G \longmapsto G \circ p$$

has a **left adjoint** $p_{!}$ $\iff$ **left Kan extensions along $p$ with values in $\mathcal{D}$ always exist**.

Dually: $p^{-1}$ has a right adjoint $p_{*}$ $\iff$ right Kan extensions always exist.
