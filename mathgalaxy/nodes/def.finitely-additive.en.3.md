# finitely additive　`def.finitely-additive`
English entry · root `../`
[in graph](../#n=def.finitely-additive)　·　[Chinese page (authoritative)](./def.finitely-additive.md)

Historically (the Banach–Tarski era) "measures" using only finite additivity were seriously considered; the problem is not constructing length (Lebesgue measure itself is finitely additive, $m((a,b]) = b - a$ being length), but that finite additivity **cannot support countable limit theorems** (MCT, DCT and Fubini all collapse).
