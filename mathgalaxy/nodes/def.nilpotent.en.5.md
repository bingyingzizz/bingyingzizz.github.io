# Nilpotent Operator　`def.nilpotent`
English entry · root `../`
[in graph](../#n=def.nilpotent)　·　[Chinese page (authoritative)](./def.nilpotent.md)

- definition $T^{k} = 0$ (some $k$) $\iff$ **all eigenvalues are $0$**: $(\implies)$ is obvious ($0$ is the only possible eigenvalue); $(\Leftrightarrow)$ needs the **characteristic polynomial to split** (over $\mathbb{C}$ or an algebraic closure), otherwise the word "eigenvalue" is meaningless.
- **characteristic polynomial $= x^{n}$** $\iff$ all eigenvalues zero + adding algebraic multiplicities: this step uses **Vieta's formulas** and **requires finite dimension**.
- **$T^{n} = 0$** ($n = \dim V$): **this step uses Cayley–Hamilton** (thm.cayley-hamilton). ⚠️ It gives "$k$ can be taken to be $n$", whereas the definition only requires "some $k$" — t
