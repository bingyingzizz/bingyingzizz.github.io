# long exact sequence of a pair　`thm.long-exact-pair`
English entry · root `../`
[in graph](../#n=thm.long-exact-pair)　·　[Chinese page (authoritative)](./thm.long-exact-pair.md)

**(c) $\operatorname{im} \partial_{*} = \ker j_{*}$.** If $[c]$ comes from relative homology, then $j_{*}(\partial_{*}[c]) = [\partial c]$, and $\partial c$ is a boundary in $X$, so its class is $0$. Conversely, if $a \in S_{p-1}(A)$ is a cycle and $j_{*}[a] = 0$, so $a = \partial b$ for some $b \in S_{p}(X)$, then $b$ is a relative cycle ($\partial b = a \in S_{*}(A)$), and $\partial_{*}[b] = [\partial b] = [a]$.
