陈述

单纯形范畴 Δ\DeltaΔ 的对象是正整数

[n]:=n+1:={ 0,1,…,n }(n∈N),[n] := n + 1 := \{\, 0, 1, \ldots, n \,\} \qquad (n \in \mathbb{N}),[n]:=n+1:={0,1,…,n}(n∈N),

态射是保序映射 [m]→[n][m] \to [n][m]→[n]。它由两类基本的态射生成：

  • 面映射 δi:[n−1]→[n]\delta^{i} : [n-1] \to [n]δi:[n−1]→[n]：跳过 iii（i=0,…,ni = 0, \ldots, ni=0,…,n），不取 iii 的保序单射；
  • 退化映射 σi:[n+1]→[n]\sigma^{i} : [n+1] \to [n]σi:[n+1]→[n]：把 iii 与 i+1i+1i+1 撞在一起（i=0,…,ni = 0, \ldots, ni=0,…,n），保序满射。

说明

为什么要它：单纯对象就是 Δop\Delta^{\mathrm{op}}Δop 上的图（见「单纯对象」）。这一条把「一个空间在 nnn 维的骨架」组织成范畴语言 —— [n][n][n] 是 nnn-单形，面映射是「取第 iii 个面」，退化映射是「把单形压扁」。

每个态射都有唯一的单-满分解：单调映射 f:[m]→[n]f : [m] \to [n]f:[m]→[n] 唯一地写成

[m]↠im⁡(f)↪[n],[m] \twoheadrightarrow \operatorname{im}(f) \hookrightarrow [n],[m]↠im(f)↪[n],

即先做满射（在每根纤维里只留一个代表），再做单射。满射段是一串退化映射的复合，单射段是一串面映射的复合 —— 这就是下面「两族生成」的确切含义。

完整单纯恒等式（本图取 δi\delta^{i}δi 跳过 iii、σi\sigma^{i}σi 合并 i,i+1i,i+1i,i+1 的约定）：

  • δjδi=δiδj−1\delta^{j}\delta^{i} = \delta^{i}\delta^{j-1}δjδi=δiδj−1（i<ji < ji<j）；
  • σjσi=σiσj−1\sigma^{j}\sigma^{i} = \sigma^{i}\sigma^{j-1}σjσi=σiσj−1（i<ji < ji<j）；
  • σjδi=δiσj−1\sigma^{j}\delta^{i} = \delta^{i}\sigma^{j-1}σjδi=δiσj−1（i<ji < ji<j）；
  • σjδi=1\sigma^{j}\delta^{i} = 1σjδi=1（i=ji = ji=j 或 i=j+1i = j+1i=j+1）；
  • σjδi=δi−1σj\sigma^{j}\delta^{i} = \delta^{i-1}\sigma^{j}σjδi=δi−1σj（i>j+1i > j+1i>j+1）。

前两族说明「同一类的映射复合时，指标从后往前递减」；后三族说明「面与退化交错时，要么换序、要么相消」。所有关于单纯对象的论证，本质上都只是把这五条恒等式代进去。

为什么就这些：Δ\DeltaΔ 等价于有限非空全序集范畴 Ordfin\mathbf{Ord}_{\mathrm{fin}}Ordfin​ 的骨架 —— 每个有限非空全序集都唯一同构于某个 [n][n][n]，而保序映射就是全体态射。所以「单纯形范畴」不是人为造出来的指标集，而是「有限全序集及其保序映射」这件事的最小表示。

⚠️ 记号在各书里不统一：有的用 [n]={0,…,n}[n] = \{0, \ldots, n\}[n]={0,…,n}（本图取这个），有的用 Δn\Delta^{n}Δn 指标准的几何 nnn-单形（那是几何实现那边的对象，不是这里的指标）。有的书把 δi\delta^{i}δi 定义成「插入」而不是「跳过」iii，恒等式里的指标会整体平移一格 —— 引用恒等式前先核对约定。

类比 1

  • 标准单纯形类比

    标准单纯形 Δp\Delta^{p}Δp 与单纯形范畴的对象 [p][p][p] 是同一组面/退化数据的两个模型：前者是几何实现，后者是组合索引。单纯复形用前者，单纯对象用后者。
