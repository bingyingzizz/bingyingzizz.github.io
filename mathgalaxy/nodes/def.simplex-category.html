陈述

单纯形范畴 Δ\DeltaΔ 的对象是正整数

[n]:=n+1:={ 0,1,…,n }(n∈N),[n] := n + 1 := \{\, 0, 1, \ldots, n \,\} \qquad (n \in \mathbb{N}),[n]:=n+1:={0,1,…,n}(n∈N),

态射是保序映射 [m]→[n][m] \to [n][m]→[n]。它由两类基本的态射生成：

  • 面映射 δi:[n−1]→[n]\delta^{i} : [n-1] \to [n]δi:[n−1]→[n]：跳过 iii（i=0,…,ni = 0, \ldots, ni=0,…,n），不取 iii 的保序单射；
  • 退化映射 σi:[n+1]→[n]\sigma^{i} : [n+1] \to [n]σi:[n+1]→[n]：把 iii 与 i+1i+1i+1 撞在一起（i=0,…,ni = 0, \ldots, ni=0,…,n），保序满射。

说明

为什么要它：单纯对象就是 Δop\Delta^{\mathrm{op}}Δop 上的图（见「单纯对象」）。这一条把「一个空间在 nnn 维的骨架」组织成范畴语言 —— [n][n][n] 是 nnn-单形，面映射是「取第 iii 个面」，退化映射是「把单形压扁」。

Δ\DeltaΔ 的态射全都能写成面映射与退化映射的复合，而且它们满足单纯恒等式（δjδi=δiδj−1\delta^{j}\delta^{i} = \delta^{i}\delta^{j-1}δjδi=δiδj−1 等）。所以定义单纯对象时只要给出这两族映射就够 —— 这正是「单纯集 = 一族集合 + 面 + 退化」那种写法的来源。

⚠️ 记号在各书里不统一：有的用 [n]={0,…,n}[n] = \{0, \ldots, n\}[n]={0,…,n}（本图取这个），有的用 Δn\Delta^{n}Δn 指标准的几何 nnn-单形（那是几何实现那边的对象，不是这里的指标）。
