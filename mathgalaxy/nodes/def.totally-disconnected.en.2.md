# totally disconnected space　`def.totally-disconnected`
English entry · root `../`
[in graph](../#n=def.totally-disconnected)　·　[Chinese page (authoritative)](./def.totally-disconnected.md)

- **totally disconnected** says "shattered until every component is a single point";
- **extremally disconnected** says "the closure of an open set no longer grows" — the latter is stronger.

**The demand side for extremally disconnected is Haskell / set theory / condensed mathematics**: it is the geometric shape of "projective objects" (Gleason's theorem: the projective objects of $\mathbf{CHaus}$ are exactly the Stonean spaces).
