陈述

布尔环是一个环 BBB，其中每个元素都幂等：

∀x∈B,x2=x.\forall x \in B,\qquad x^{2} = x.∀x∈B,x2=x.

说明

幂等性把环逼得很紧。由 (x+y)2=x+y(x + y)^{2} = x + y(x+y)2=x+y 展开得 xy+yx=0xy + yx = 0xy+yx=0；由 (x+x)2=x+x(x+x)^{2} = x+x(x+x)2=x+x 得 2x=02x = 02x=0。合起来：布尔环自动是交换环，而且特征为 222。所以布尔环里没有「真实」的数，只有「是 / 不是」的代数。

与布尔代数（带补分配格）是一回事。格运算翻译成环运算：

  • a∧b=aba \wedge b = aba∧b=ab（交 = 乘法）；
  • a∨b=a+b+aba \vee b = a + b + aba∨b=a+b+ab（并 = 加法加回重叠部分）；
  • ¬a=1+a\neg a = 1 + a¬a=1+a（补 = 与单位元加和）。

反过来，a △ b=a+ba \,\triangle\, b = a + ba△b=a+b：环加法就是对称差。

最小的例子：F2={ 0,1 }\mathbb{F}_{2} = \{\, 0, 1 \,\}F2​={0,1}。最一般的例子：集合 III 的幂集 P(I)\mathcal{P}(I)P(I)，以对称差为加法、以交为乘法。
