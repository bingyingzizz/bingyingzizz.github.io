又称积性·乘性函数

陈述

称 f:N+→Cf : \mathbb{N}^{+} \to \mathbb{C}f:N+→C 是积性函数，若 f(1)=1f(1) = 1f(1)=1 且对互素的 m,nm, nm,n（即 gcd⁡(m,n)=1\gcd(m,n) = 1gcd(m,n)=1）有

f(mn)=f(m) f(n).f(mn) = f(m)\,f(n) .f(mn)=f(m)f(n).

若上式对一切 m,nm, nm,n 都成立（不要求互素），称 fff 是完全积性的。

说明

为什么这个条件自然：由算术基本定理，nnn 唯一分解成素数幂之积，而这些素数幂两两互素 —— 所以积性函数完全由它在素数幂 pep^{e}pe 上的值决定。这就把「nnn 的全体」上的函数压成「每个素数一列」的数据。

完全积性更强：还要求 f(pe)=f(p)ef(p^{e}) = f(p)^{e}f(pe)=f(p)e。μ\muμ、φ\varphiφ、τ\tauτ、σ\sigmaσ 都积性；只有 μ\muμ 与「id\mathrm{id}id」「111」是完全积性，φ\varphiφ、τ\tauτ、σ\sigmaσ 不是（例如 φ(4)=2≠φ(2)2=1\varphi(4) = 2 \ne \varphi(2)^{2} = 1φ(4)=2=φ(2)2=1）。

两个积性函数的狄利克雷卷积仍积性 —— 这是后面 Möbius 反演的代数背景。

    积性函数的积性来自「素数幂两两互素」

    设 fff 积性，n=p1e1⋯prern = p_{1}^{e_{1}}\cdots p_{r}^{e_{r}}n=p1e1​​⋯prer​​。这些素数幂 qi:=pieiq_{i} := p_{i}^{e_{i}}qi​:=piei​​ 两两互素，于是对 rrr 归纳：

    f(n)=f(q1)⋯f(qr).f(n) = f(q_{1})\cdots f(q_{r}) .f(n)=f(q1​)⋯f(qr​).

    反之若两个函数在一个互素的分解上一致，也一致。所以积性函数完全由 (f(pe))p,e(f(p^{e}))_{p,e}(f(pe))p,e​ 这张表决定。
