# change of basepoint　`prop.pi1-basepoint`
English entry · root `../`
[in graph](../#n=prop.pi1-basepoint)　·　[Chinese page (authoritative)](./prop.pi1-basepoint.md)

If $\gamma'$ is another path from $x_{0}$ to $x_{1}$, put $g := [\bar{\gamma}' * \gamma] \in \pi_{1}(X, x_{1})$; then

$$\Pi_{\gamma'} = \operatorname{ad}_{g} \circ \Pi_{\gamma},\qquad \operatorname{ad}_{g}(u) := g\,u\,g^{-1}.$$

That is: the isomorphisms given by different paths **differ by an inner automorphism**.
