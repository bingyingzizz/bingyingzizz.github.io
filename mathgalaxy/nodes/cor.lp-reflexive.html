陈述

设 1<p<∞1 < p < \infty1<p<∞。则

Lp≅(Lp)∗∗L^p \cong (L^p)^{**}Lp≅(Lp)∗∗

即 LpL^pLp 是自反的 Banach 空间。

说明

证明。 设 1<p<∞1 < p < \infty1<p<∞，qqq 是共轭指数（1p+1q=1\frac1p+\frac1q = 1p1​+q1​=1，于是也有 1<q<∞1 < q < \infty1<q<∞）。

  • 由「LpL^{p}Lp 的对偶是 LqL^{q}Lq」（Riesz 表示）：(Lp)∗≅Lq(L^{p})^{*} \cong L^{q}(Lp)∗≅Lq ✓；
  • 把同一条定理用在 qqq 上：(Lq)∗≅Lp(L^{q})^{*} \cong L^{p}(Lq)∗≅Lp ✓；
  • 于是
(Lp)∗∗≅(Lq)∗≅Lp,(L^{p})^{**} \cong (L^{q})^{*} \cong L^{p},(Lp)∗∗≅(Lq)∗≅Lp,

即 LpL^{p}Lp 自反 ✓。∎ ⚠️ p=1p = 1p=1 与 p=∞p = \inftyp=∞ 时不自反：(L1)∗≅L∞(L^{1})^{} \cong L^{\infty}(L1)∗≅L∞，而 (L∞)∗(L^{\infty})^{}(L∞)∗ 严格大于 L1L^{1}L1（有非绝对连续的函数）✓。 ⭐ 自反的价值：自反 Banach 空间里有界序列必有弱收敛子列（Eberlein–Šmulian），这是 LpL^{p}Lp 上变分 / 存在性论证的常用工具。

把对偶定理用两次即可：(Lp)∗≅Lq(L^p)^* \cong L^q(Lp)∗≅Lq，而 qqq 的共轭又回到 ppp，故 (Lp)∗∗≅(Lq)∗≅Lp(L^p)^{**} \cong (L^q)^* \cong L^p(Lp)∗∗≅(Lq)∗≅Lp。

⚠ p=1p = 1p=1 与 p=∞p = \inftyp=∞ 时不自反。

⭐ 自反性的价值：自反 Banach 空间里有界序列必有弱收敛子列（Banach–Alaoglu / Eberlein–Šmulian），这是变分法与 PDE 里取极限的基本工具。
