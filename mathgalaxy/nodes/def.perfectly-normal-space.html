在做什么：链顶端的最后一格。它用「可数」这一条把正规性再拧紧一格 —— 每个闭集都是一列开集之交。

Statement draft

What it does: the last rung at the top of the chain. It tightens normality by one notch using countability: every closed set is a countable intersection of open sets.

First, two notations: a set AAA is a GδG_{\delta}Gδ​ set if it is a countable intersection of open sets; it is an FσF_{\sigma}Fσ​ set if it is a countable union of closed sets.

A topological space XXX is perfectly normal if

  1. XXX is normal (正规空间);
  2. every closed set is a GδG_{\delta}Gδ​ set.

(Equivalently: every open set is an FσF_{\sigma}Fσ​ set, by taking complements.)

Position in the chain: T6  ⟹  T5  ⟹  T4T_{6} \implies T_{5} \implies T_{4}T6​⟹T5​⟹T4​.

Notes draft

⭐ Why "every closed set is a countable intersection of open sets" deserves its own axiom: it guarantees a continuous function whose zero set is exactly the closed set (F=f−1(0)F = f^{-1}(0)F=f−1(0)), not merely "fff vanishes on FFF". This is crucial in infinite-dimensional analysis (GδG_{\delta}Gδ​ points in C∗C^{*}C∗-algebras, strengthened forms of the Baire category theorem).

⚠️ Every metric space is perfectly normal: d(x,F)d(x, F)d(x,F) is continuous, F={ x:d(x,F)=0 }F = \{\, x : d(x, F) = 0 \,\}F={x:d(x,F)=0}, and { x:d(x,F)<1/n }\{\, x : d(x,F) < 1/n \,\}{x:d(x,F)<1/n} is a sequence of open sets — hence a closed set is a countable intersection of open sets ✓. So T6T_{6}T6​ almost always holds automatically in analysis; it is a genuine condition only in general topology.

⚠️ T6  ⟹  T5T_{6} \implies T_{5}T6​⟹T5​ is not free: one must use "countable intersection of open sets" to write the closed set as a zero set (Urysohn's lemma plus a 2−n2^{-n}2−n weighted series), then separate on a subspace by f/(f+g)f/(f+g)f/(f+g) — details are in the edge "perfectly normal   ⟹  \implies⟹ completely normal" in this file.

⚠️ Convention: the definition of perfect normality already includes normality, hence automatically T1T_{1}T1​, and one need not add T1T_{1}T1​.

Hypotheses used in each direction (taking complements is free; the zero-set description needs normality):

  • Perfectly normal   ⟺  \iff⟺ normal and every closed set is a GδG_\deltaGδ​ set: this is the definition unfolded; normality already includes T1T_1T1​.
  • Every closed set is GδG_\deltaGδ​   ⟺  \iff⟺ every open set is FσF_\sigmaFσ​: De Morgan, with no separation axiom needed; when using this to characterize perfect normality, normality must still be kept on both sides.
  • Normal and a closed set FFF is GδG_\deltaGδ​   ⟹  \implies⟹ FFF is a zero set of a continuous function: for the representation F=⋂nUnF=\bigcap_n U_nF=⋂n​Un​ use Urysohn's lemma to separate FFF from X∖UnX\setminus U_nX∖Un​, then weight by 2−n2^{-n}2−n to obtain a uniformly convergent series; the converse follows directly by taking preimages of a continuous function.
  • Normality cannot be replaced by "every closed set is GδG_\deltaGδ​": the two-point Sierpiński space has every closed set open, yet fails the T1T_1T1​ required here; nor is normality automatically perfect — the singleton of the last point of [0,ω1][0,\omega_1][0,ω1​] is not a GδG_\deltaGδ​ set.
