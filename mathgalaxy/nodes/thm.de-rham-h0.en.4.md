# Zeroth de Rham Cohomology　`thm.de-rham-h0`
English entry · root `../`
[in graph](../#n=thm.de-rham-h0)　·　[Chinese page (authoritative)](./thm.de-rham-h0.md)

**It is functorial**: for smooth $F : N \to M$, the map $F^{\ast} : H^{0}(M) \to H^{0}(N)$ is "pull back locally constant functions from $M$". If $M$ is connected and $N$ is not, $F$ can take only one constant value on each component — the component structure is fully encoded by this.

**Relation to homotopy**: $H^{0}$ is the free real vector space on $\pi_{0}(M)$, so it is a **homotopy invariant**, not a differential invariant. This is also what de Rham's theorem looks like for $k = 0$ (singular cohomology in degree 0 likewise contributes one $\mathbb{R}$ per component).
