在做什么：「把方块的一个面取出来」这件事有统一的写法：固定某个坐标为此端或彼端，再乘一个符号，全部加起来就是边界。

插入映射：对 1≤i≤k1\le i\le k1≤i≤k、α∈{0,1}\alpha\in\{0,1\}α∈{0,1} 定义

I(i,α)k:Ik−1⟶Ik,(x1,…,xk−1)⟼(x1,…,xi−1,α,xi,…,xk−1).I^{k}_{(i,\alpha)} : I^{k-1}\longrightarrow I^{k},\qquad (x^{1},\ldots,x^{k-1})\longmapsto(x^{1},\ldots,x^{i-1},\alpha,x^{i},\ldots,x^{k-1}).I(i,α)k​:Ik−1⟶Ik,(x1,…,xk−1)⟼(x1,…,xi−1,α,xi,…,xk−1).

对 kkk-方块 ccc，记 c(i,α):=c∘I(i,α)kc_{(i,\alpha)} := c\circ I^{k}_{(i,\alpha)}c(i,α)​:=c∘I(i,α)k​，它是 (k−1)(k-1)(k−1)-方块，叫 ccc 的第 (i,α)(i,\alpha)(i,α) 面。

边界算子 ∂\partial∂ 先把方块送到「面的带符号和」，再线性延拓到链：

∂c:=∑i=1k∑α=01(−1)i+α c(i,α),∂(∑lnlcl):=∑lnl ∂cl.\partial c := \sum_{i=1}^{k}\sum_{\alpha=0}^{1}(-1)^{i+\alpha}\,c_{(i,\alpha)},\qquad \partial\Bigl(\sum_{l}n_{l}c_{l}\Bigr) := \sum_{l}n_{l}\,\partial c_{l}.∂c:=i=1∑k​α=0∑1​(−1)i+αc(i,α)​,∂(l∑​nl​cl​):=l∑​nl​∂cl​.

约定 k=0k = 0k=0 时 ∂c:=0\partial c := 0∂c:=0（点是零维的，没有面）。于是 ∂:Ck(M)→Ck−1(M)\partial : C_{k}(M)\to C_{k-1}(M)∂:Ck​(M)→Ck−1​(M) 是群同态。

说明

符号 (−1)i+α(-1)^{i+\alpha}(−1)i+α 是谁给的：它不是硬凑的。取外法向为 +∂i+\partial_{i}+∂i​ 的那一端（即 α=1\alpha = 1α=1）与取 (−1)i+1(-1)^{i+1}(−1)i+1，另一端的法向是 −∂i-\partial_{i}−∂i​、符号是 (−1)i(-1)^{i}(−1)i，两端的差别正好就是「把外法向搬到最前面要跨过 i−1i-1i−1 个坐标」的那个置换符号。完整的验算在 prop.boundary-sign-convention 里 —— 结论是这套符号与「外法向在前」的诱导定向逐面相同。

2k2k2k 个面：iii 取 kkk 个值、α\alphaα 取两端，共 2k2k2k 个 (k−1)(k-1)(k−1)-方块。它们不是两两不同的映射，但作为链的项是两两不同的（别处可以重合，作为映射不能）。

平方为零：见 prop.boundary-squared-zero。这是整套记账能用的关键 —— 它保证「边界没有边界」，于是 Stokes 定理两边不会多出一层。

为什么线性延拓而不是逐项定义：链已经是形式和，∂\partial∂ 若不同态就没法算 ∂(c1+c2)\partial(c_{1}+c_{2})∂(c1​+c2​)，而 Stokes 定理要对链成立就必须要这一条。

⚠️ 记号陷阱：∂\partial∂ 同时用来表示半空间的边界（∂Hn\partial\mathbb{H}^{n}∂Hn）、流形的边界（∂M\partial M∂M）与链的边界（∂c\partial c∂c）。三种用法在 prop.boundary-sign-convention 之后统一：对保向方块，链的边界与流形边界逐面一致。
