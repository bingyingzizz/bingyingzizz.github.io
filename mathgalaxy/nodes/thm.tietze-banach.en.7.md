- **Why it is well-defined**: Local finiteness $\implies$ only finitely many $\varphi_{i}$ are nonzero near each point, so the sum is finite. Since $V$ is a **vector space**, convex combinations make sense. Since $\varphi_{i}$ is continuous, so is $G$.
- **Why it is an extension**: If $x \in A$, then for every instance of $\varphi_{i}(x) > 0$ the corresponding $U_{i}$ contains $x$. Each $g_{i}$ equals, on $A \cap U_{i}$, the value $g$, so $G(x) = \sum \varphi_{i}(x) g(x) = g(x)$.
