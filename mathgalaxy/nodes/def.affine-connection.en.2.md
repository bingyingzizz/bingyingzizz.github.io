# Affine Connection　`def.affine-connection`
English entry · root `../`
[in graph](../#n=def.affine-connection)　·　[Chinese page (authoritative)](./def.affine-connection.md)

$$\nabla : \mathfrak{X}(M)\times\mathfrak{X}(M)\longrightarrow\mathfrak{X}(M),\qquad (X,Y)\longmapsto\nabla_{X}Y ,$$

satisfying three conditions:

1. $C^{\infty}(M)$-linear in the first variable: $\nabla_{fX+gY}Z = f\,\nabla_{X}Z+g\,\nabla_{Y}Z$;
2. $\mathbb{R}$-linear in the second variable: $\nabla_{X}(aY+bZ) = a\,\nabla_{X}Y+b\,\nabla_{X}Z$;
3. **Leibniz rule**: $\nabla_{X}(fY) = (Xf)\,Y+f\,\nabla_{X}Y$.
