# Differential Form: Coordinate Model on Euclidean Open Sets　`def.differential-form`
English entry · root `../`
[in graph](../#n=def.differential-form)　·　[Chinese page (authoritative)](./def.differential-form.md)

**On manifolds**: replace $\mathbb{R}^{n}$ by an $n$-dimensional manifold $M$; one writes everything in coordinate differentials on a chart, then uses the smoothness of transition maps to show that "being a $k$-form" is chart-independent — the same argument as "tangent vectors are chart-independent" in `def.tangent-space-manifold`.
