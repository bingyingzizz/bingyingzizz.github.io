## Notes · **draft**
**"Smooth" is the only delicate point**: merely "choose a tangent vector at each point" is a set-theoretic choice and can be extremely pathological. Smoothness pins it down to $n$ smooth functions in local coordinates, so all of calculus carries over — this is also the use of the equivalence "vector field = derivation".

**$\mathfrak{X}(M)$ is a $C^{\infty}(M)$-module**: $X + Y$ and $fX$ (with $f$ smooth) are again vector fields. So vector fields are not objects to be "added pointwise into numbers" but elements of a module — on the same level as "$\mathrm{d}f$ is a $1$-form".
