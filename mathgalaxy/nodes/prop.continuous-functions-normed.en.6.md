# Continuous Functions Form a Normed Banach Group　`prop.continuous-functions-normed`
English entry · root `../`
[in graph](../#n=prop.continuous-functions-normed)　·　[Chinese page (authoritative)](./prop.continuous-functions-normed.md)

On each $S_{r}$, choose any $m_{r}$ such that $S_{r} \subseteq f^{-1}(B(m_{r},\varepsilon/2))$ ✓, and set $g := m_{r}$ on $S_{r}$.

Then $g$ is **locally constant**, that is, continuous as a map into the discrete group $M^{\mathrm{disc}}$ ✓. Pointwise, $\|f - g\| \le \varepsilon/2$ ✓, so $\|f-g\| \le \varepsilon/2 < \varepsilon$ ✓.

Thus $C(S,M^{\mathrm{disc}})$ is dense ✓.

∎
