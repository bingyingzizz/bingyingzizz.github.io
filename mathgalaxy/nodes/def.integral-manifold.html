又称积分流形

陈述

白话：一块 kkk 维薄片，如果它在每点的切空间正好是分布给的那个子空间，它就是这分布的积分流形 —— 「积分」就是把一堆方向积成一整块地。

设 D\mathcal{D}D 是 MMM 上的光滑 kkk 阶切分布。MMM 的 kkk 维浸入子流形（即单浸入 i:Nk→Mi : N^{k} \to Mi:Nk→M 的像：iii 光滑、di\mathrm{d}idi 处处单射）叫 D\mathcal{D}D 的积分流形，如果

dip(TpN)=Di(p)(p∈N).\mathrm{d}i_{p}\bigl(T_{p}N\bigr) = \mathcal{D}_{i(p)}\qquad (p \in N).dip​(Tp​N)=Di(p)​(p∈N).

两边都是 kkk 维，所以「包含」与「相等」等价：条件就是 dip(TpN)⊆Di(p)\mathrm{d}i_{p}(T_{p}N) \subseteq \mathcal{D}_{i(p)}dip​(Tp​N)⊆Di(p)​ 对每点成立。

局部形式（叶片坐标）：若 ppp 附近有坐标 (x1,…,xn)(x^{1},\ldots,x^{n})(x1,…,xn) 使 D\mathcal{D}D 由 ∂1,…,∂k\partial_{1},\ldots,\partial_{k}∂1​,…,∂k​ 生成，则每块叶片

{xk+1=ck+1, …, xn=cn}\{x^{k+1} = c^{k+1},\ \ldots,\ x^{n} = c^{n}\}{xk+1=ck+1, …, xn=cn}

（ck+1,…,cnc^{k+1},\ldots,c^{n}ck+1,…,cn 是常数）都是积分流形。这样的坐标叫平坦坐标，也叫叶片坐标。

整体形式：把 MMM 按「过同一点的积分流形」切开，得到的极大连通积分流形叫叶，全体叶叫 D\mathcal{D}D 的叶状结构（foliation）。

说明

为什么只要求「浸入」不要求「嵌入」：叶常常是稠密的（环面 T2\mathbb{T}^{2}T2 上斜率为无理数的线分布，每条叶都稠密），它作为子集不可能是嵌入子流形（嵌入要求子空间拓扑），但作为浸入子流形完全合法。所以积分流形的正确语言是浸入 —— 这是「叶」与「嵌入子流形」必须分开的地方。

维数必须正好是 kkk：D\mathcal{D}D 里的积分曲线（k=1k = 1k=1 时就是它）是积分流形的例子；但一条躺在 D\mathcal{D}D 里的低维曲线在高秩情形一般不叫积分流形，因为它的切空间只有更低维。本图的定义要求维数相等，正是为了让「di(TN)⊆D\mathrm{d}i(TN) \subseteq \mathcal{D}di(TN)⊆D」能升成等号。

局部唯一性：若 N1,N2N_{1}, N_{2}N1​,N2​ 是过同一点的两块积分流形，则它们在交点附近重合。理由：在平坦坐标里两者都只能沿前 kkk 个坐标方向伸展，而叶片是唯一那样的 kkk 维薄片。这条是「叶把流形分开」的来源，也是把局部叶片拼成整体叶的依据。

与常微分方程的类比：k=1k = 1k=1 时积分流形就是积分曲线（def.flow），存在唯一性由 ODE 给，没有障碍；k≥2k \ge 2k≥2 时方程变成偏微分方程组，于是出现障碍，障碍正是对合（def.involutive-distribution）。这就是 Frobenius 定理的全部内容。

整体存在不是自动的：定理（thm.frobenius）只保证局部有积分流形。整体上「过每点有唯一的极大叶」还要一次把局部叶片粘起来的手续（用 Zorn 引理取极大的连通并，或用局部唯一性证明两个叶要么相等要么不交）。本图只陈述结论。

定义引用 3

  • 浸入 / 淹没 / 嵌入 → 本页定义引用

    积分流形是浸入子流形（di\mathrm{d}idi 处处单射），不是任意子集；「浸入」这个词的出处就是 def.submersion-immersion。

  • 切分布 → 本页定义引用

    「积分流形」永远是「某个分布 D\mathcal{D}D 的积分流形」；定义里 di(TN)=D\mathrm{d}i(TN) = \mathcal{D}di(TN)=D 的右边就是分布。

  • 切映射 → 本页定义引用

    条件写成 dip(TpN)=Di(p)\mathrm{d}i_{p}(T_{p}N) = \mathcal{D}_{i(p)}dip​(Tp​N)=Di(p)​，用的是切映射的像 —— 不写下 di\mathrm{d}idi，就无法把「NNN 的切空间」搬到 MMM 里比较。
