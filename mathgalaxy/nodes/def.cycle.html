又称闭链·上闭链·cycle·cocycle·闭链群·上闭链群·Z^n

陈述

在做什么：把同调公式 Hn=Zn/BnH^{n} = Z^{n}/B^{n}Hn=Zn/Bn 里那个分子说清楚。闭链就是被微分杀掉的元素 —— 整门同调代数都在问「杀掉的里面，有多少是真的来了、有多少是绕了远路」。

设 KKK 是加法范畴 C\mathcal{C}C 中的复形，微分 dn:Kn→Kn+1d^{n} : K^{n} \to K^{n+1}dn:Kn→Kn+1（上链复形）。

上链情形：第 nnn 阶上闭链群（cocycles）是

Zn(K):=ker⁡dn={ x∈Kn:dnx=0 };Z^{n}(K) := \ker d^{n} = \{\, x \in K^{n} : d^{n}x = 0 \,\} ;Zn(K):=kerdn={x∈Kn:dnx=0};

它的元素叫上闭链（cocycle）。

链情形（箭头反向，dn:Kn→Kn−1d_{n} : K_{n} \to K_{n-1}dn​:Kn​→Kn−1​）：第 nnn 阶闭链群（cycles）是

Zn(K):=ker⁡dn,Z_{n}(K) := \ker d_{n} ,Zn​(K):=kerdn​,

它的元素叫闭链（cycle）。

⚠️ 两个名字指的是同一个东西（ddd 的核），只是复形的分次方向不同：上链复形的核记 ZnZ^{n}Zn、链复形的核记 ZnZ_{n}Zn​。

说明

⭐ 「闭」这个字是拓扑来的：单形复形里 ∂z=0\partial z = 0∂z=0 的链是「没有边界的链」—— 直觉上就是一串闭起来的单形（一个圈、一个球面）。de Rham 复形里 dω=0d\omega = 0dω=0 的形式就叫闭形式，完全同一条定义。所以「闭链 / 闭形式 / 上闭链」是一句话的三种说法。

⚠️ 字母 ZZZ 的来源：德语 Zyklus（循环）。BBB 来自 boundary（边缘）—— 见 边缘。老文献里也写 CnC^{n}Cn（cocycle）与 BnB^{n}Bn，读到时对一下记号。

⚠️ ZnZ^{n}Zn 是 KnK^{n}Kn 的子对象（核），但它不是复形的子复形：把 ddd 限制到 ZnZ^{n}Zn 上得零映射，于是 ZZZ 自带一个「处处为零」的复形结构。用它的时侯要分清是在说子对象还是子复形。

⭐ 同调就是量「闭链里有多少不是边缘」：Hn=Zn/BnH^{n} = Z^{n}/B^{n}Hn=Zn/Bn（同调）。所以 Hn=0  ⟺  H^{n} = 0 \iffHn=0⟺ 每个闭链都是边缘   ⟺  \iff⟺ 复形在 nnn 处正合。这是把「同调为 0」翻译成「闭 = 边缘」的唯一桥梁。
