陈述

在做什么：复数可以写成 z=eiθ∣z∣z = e^{i\theta}\lvert z\rvertz=eiθ∣z∣（方向 ×\times× 长度）。矩阵也有同款分解：酉（方向）×\times× 半正定（长度）。

设 A∈Mn(C)A \in M_{n}(\mathbb{C})A∈Mn​(C)。则存在酉矩阵 UUU 与半正定 Hermite 矩阵 PPP 使

A=UP,A = UP ,A=UP,

且 PPP 由 AAA 唯一确定（P=A∗AP = \sqrt{A^{*}A}P=A∗A​）；若 AAA 可逆，则 UUU 也唯一，且 PPP 正定。

另一种次序：同样有 A=P′U′A = P'U'A=P′U′，其中 P′=AA∗P' = \sqrt{AA^{*}}P′=AA∗​ 半正定、U′U'U′ 酉。

与 SVD 的关系：把 PPP 对角化（P=VΣV∗P = V\Sigma V^{}P=VΣV∗）即得 A=(UV)ΣV∗A = (UV)\Sigma V^{}A=(UV)ΣV∗ —— 这正是奇异值分解；Σ\SigmaΣ 的对角元就是奇异值。

说明

为什么 P=A∗AP = \sqrt{A^{*}A}P=A∗A​：就像 ∣z∣=zˉz\lvert z\rvert = \sqrt{\bar z z}∣z∣=zˉz​。

A∗AA^{*}AA∗A 总是半正定 Hermite（正定矩阵 的注），所以能开唯一的半正定平方根。

定义 U:=AP−1U := AP^{-1}U:=AP−1（AAA 可逆时），剩下只需验 UUU 保内积 —— 一行计算：U∗U=P−1A∗AP−1=P−1P2P−1=IU^{}U = P^{-1}A^{}AP^{-1} = P^{-1}P^{2}P^{-1} = IU∗U=P−1A∗AP−1=P−1P2P−1=I。

⭐ 几何读法：任何线性映射都是「先沿一组正交方向各自伸缩（PPP），再整体旋转（UUU）」。伸缩因子就是奇异值。这条对非方阵也成立（用等距代替酉）。

与 SVD 的分工：极分解强调「旋转 ×\times× 拉伸」这个结构，SVD 强调「A=UΣV∗A = U\Sigma V^{*}A=UΣV∗ 这个坐标写法」。两者信息量相同，SVD 多给了两组基底。

⚠️ 唯一性要说清：PPP 永远唯一，但 AAA 奇异时 UUU 可以在 AAA 的核上任意取 —— 所以「极分解唯一」这句话只在可逆时成立。
