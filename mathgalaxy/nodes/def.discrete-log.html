说明

唯一性来自 ggg 是生成元（每个单位恰好对应一个指数）；「kkk 的范围是 0≤k<φ(n)0 \le k < \varphi(n)0≤k<φ(n)」只是取代表元。

它把乘法变成加法：log⁡g(ab)=log⁡ga+log⁡gb(modφ(n))\log_{g}(ab) = \log_{g}a + \log_{g}b \pmod{\varphi(n)}logg​(ab)=logg​a+logg​b(modφ(n)) —— 与实对数同构，把 (Z/n)×(\mathbb{Z}/n)^{\times}(Z/n)× 与 Z/φ(n)\mathbb{Z}/\varphi(n)Z/φ(n) 对齐。

计算上：正向（给定 kkk 算 gkg^{k}gk）是快速幂，O(log⁡k)O(\log k)O(logk)；反向（给定 aaa 求 kkk）没有已知的多项式算法，最好的通用方法是 baby-step giant-step（O(n)O(\sqrt{n})O(n​)）与 index calculus。这个不对称性就是 Diffie–Hellman 与 ElGamal 的基础 —— 也是「离散对数问题」在密码学里被当作困难问题的原因。
