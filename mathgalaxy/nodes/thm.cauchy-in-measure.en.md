## Statement · **draft**
If $\{f_n\}$ is Cauchy in measure, then there is a measurable function $f$ such that

$$f_n \xrightarrow{\ \mu\ } f$$

and there is a **subsequence** $\{f_{n_j}\}$ such that

$$f_{n_j} \to f\quad  \text{a.e.}$$
