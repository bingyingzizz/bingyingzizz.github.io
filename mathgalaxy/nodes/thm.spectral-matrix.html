陈述

在做什么：把两条已有的算子版谱定理（谱定理（实对称） 实对称、谱定理（复正规） 复正规）落到矩阵上，并给出精确的充要条件。

设 A∈Mn(C)A \in M_{n}(\mathbb{C})A∈Mn​(C)。则

AAA 正规   ⟺  \iff⟺ 存在酉矩阵 UUU 使 U∗AU=diag⁡(λ1,…,λn)U^{*}AU = \operatorname{diag}(\lambda_{1}, \ldots, \lambda_{n})U∗AU=diag(λ1​,…,λn​)

即：正规   ⟺  \iff⟺ 有一组标准正交的特征向量基。此时

A=UΛU∗,Λ=diag⁡(λ1,…,λn),A = U \Lambda U^{*}, \qquad \Lambda = \operatorname{diag}(\lambda_{1}, \ldots, \lambda_{n}) ,A=UΛU∗,Λ=diag(λ1​,…,λn​),

这叫 AAA 的谱分解（正交投影之和：A=∑iλiuiui∗A = \sum_i \lambda_i u_i u_i^{*}A=∑i​λi​ui​ui∗​）。

实情形：实对称矩阵   ⟺  \iff⟺ 存在正交矩阵 QQQ 使 QTAQQ^{T}AQQTAQ 为实对角阵。

说明

四个等价说法，任取其一当定义都行：AAA 正规；AAA 有标准正交特征向量基；A=UΛU∗A = U\Lambda U^{*}A=UΛU∗；AAA 的谱测度只取原子值。矩阵语言里第一种最省事，第二种最直观（谱定理（矩阵版） 的全部内容就是「两者等价」）。

谱分解的读法：A=∑iλiPiA = \sum_i \lambda_i P_iA=∑i​λi​Pi​，其中 Pi=uiui∗P_i = u_i u_i^{*}Pi​=ui​ui∗​ 是往特征方向上的正交投影，满足 Pi2=PiP_i^2 = P_iPi2​=Pi​、PiPj=0P_iP_j = 0Pi​Pj​=0（i≠ji \ne ji=j）、∑iPi=I\sum_i P_i = I∑i​Pi​=I。

于是「对角化」= 「把算子拆成一堆互相垂直的方向，各自乘一个数」。

⭐ 与函数演算的连接：有了谱分解，任意函数 fff 都能作用：f(A):=∑if(λi)Pif(A) := \sum_i f(\lambda_i)P_if(A):=∑i​f(λi​)Pi​。A\sqrt{A}A​、etAe^{tA}etA、A1/2A^{1/2}A1/2 全是这一条的特例 —— 这也是为什么「正定矩阵可开方」不需要另外构造。

⚠️ 非正规矩阵也可能可对角化（可对角化判据），但特征向量不正交，相似矩阵 PPP 一般病态。所以「可对角化」与「酉可对角化」是两件事：后者要求正交，强得多。

证明在出边上：完整证明见本团「Schur 三角化 ⟹\Longrightarrow⟹ 谱定理（矩阵版）」这条推论边 —— 正规性在酉相似下保持，上三角正规阵必对角；实对称情形再用「特征值实、特征向量可取实」归纳。

推出 1

  • 本页 ⟹ 极分解推出
    谱定理 ⟹\Longrightarrow⟹ 极分解

    ① 构造 PPP。A∗AA^{}AA∗A 是半正定 Hermite 矩阵，故正规；由谱定理（矩阵版）存在酉 VVV 与实对角 μ=diag⁡(μ1,…,μn)\mu = \operatorname{diag}(\mu_{1}, \ldots, \mu_{n})μ=diag(μ1​,…,μn​) 使 A∗A=VμV∗A^{}A = V\mu V^{}A∗A=VμV∗，且 μi≥0\mu_{i} \ge 0μi​≥0（半正定性：⟨A∗Ax,x⟩=∥Ax∥2≥0\langle A^{}Ax, x\rangle = \|Ax\|^{2} \ge 0⟨A∗Ax,x⟩=∥Ax∥2≥0）。令 P:=Vdiag⁡(μ1,…,μn)V∗P := V\operatorname{diag}(\sqrt{\mu_{1}}, \ldots, \sqrt{\mu_{n}})V^{}P:=Vdiag(μ1​​,…,μn​​)V∗，则 PPP 半正定 Hermite 且 P2=A∗AP^{2} = A^{}AP2=A∗A。

    ② 唯一性。若 QQQ 半正定 Hermite 且 Q2=A∗AQ^{2} = A^{}AQ2=A∗A，把 QQQ 谱分解为 Q=Wdiag⁡(νi)W∗Q = W\operatorname{diag}(\nu_{i})W^{}Q=Wdiag(νi​)W∗（νi≥0\nu_{i} \ge 0νi​≥0），则 Q2=Wdiag⁡(νi2)W∗=A∗AQ^{2} = W\operatorname{diag}(\nu_{i}^{2})W^{} = A^{}AQ2=Wdiag(νi2​)W∗=A∗A。谱分解的谱值唯一，故 νi2=μi\nu_{i}^{2} = \mu_{i}νi2​=μi​、νi=μi\nu_{i} = \sqrt{\mu_{i}}νi​=μi​​；在重特征值上 QQQ 与 A∗AA^{*}AA∗A 可同时对角化，于是 Q=PQ = PQ=P。

    ③ AAA 可逆时。令 U:=AP−1U := AP^{-1}U:=AP−1。则 U∗U=P−1A∗AP−1=P−1P2P−1=IU^{}U = P^{-1}A^{}AP^{-1} = P^{-1}P^{2}P^{-1} = IU∗U=P−1A∗AP−1=P−1P2P−1=I，故 UUU 酉，且 A=UPA = UPA=UP；PPP 正定（AAA 可逆时 A∗AA^{*}AA∗A 正定，μi>0\mu_{i} > 0μi​>0）。

    ④ AAA 奇异时。由 ∥Px∥2=⟨A∗Ax,x⟩=∥Ax∥2\|Px\|^{2} = \langle A^{*}Ax, x\rangle = \|Ax\|^{2}∥Px∥2=⟨A∗Ax,x⟩=∥Ax∥2 得 ker⁡P=ker⁡A\ker P = \ker AkerP=kerA。在 im⁡P\operatorname{im}PimP 上定义 U(Px):=AxU(Px) := AxU(Px):=Ax：若 Px=0Px = 0Px=0 则 Ax=0Ax = 0Ax=0，故良定义；且 ∥U(Px)∥=∥Ax∥=∥Px∥\|U(Px)\| = \|Ax\| = \|Px\|∥U(Px)∥=∥Ax∥=∥Px∥，故 UUU 是 im⁡P→im⁡A\operatorname{im}P \to \operatorname{im}AimP→imA 的等距。把 UUU 延拓为酉映射：取 im⁡P\operatorname{im}PimP 的标准正交基并延拓到全空间，令 UUU 把 (im⁡P)⊥=ker⁡P(\operatorname{im}P)^{\perp} = \ker P(imP)⊥=kerP 等距地送到 (im⁡A)⊥(\operatorname{im}A)^{\perp}(imA)⊥（两边维数都等于 n−rank⁡An - \operatorname{rank}An−rankA）。于是 UUU 酉且 A=UPA = UPA=UP；PPP 仍唯一，UUU 在 ker⁡A\ker AkerA 上不唯一。∎

等价 2

  • 本页 ⟺ 谱定理（实对称）等价
    算子版谱定理   ⟺  \iff⟺ 矩阵版谱定理（实对称）
    算子版 $\implies$ 矩阵版

    设 AAA 实对称，它定义 Rn\mathbb{R}^{n}Rn（标准正交基）上的自伴算子 TTT。谱定理给 TTT 的一组标准正交特征基 u1,…,unu_1,\ldots,u_nu1​,…,un​，以它们为列得正交矩阵 QQQ；由 Tui=λiuiT u_i = \lambda_i u_iTui​=λi​ui​ 得 AQ=QΛAQ = Q\LambdaAQ=QΛ，即 QTAQ=ΛQ^{\mathsf{T}}AQ = \LambdaQTAQ=Λ 为实对角阵。

    矩阵版 $\implies$ 算子版

    设 VVV 有限维实内积空间、TTT 自伴。取标准正交基把 TTT 写成实对称矩阵 AAA；矩阵版给正交 QQQ 使 QTAQ=ΛQ^{\mathsf{T}}AQ = \LambdaQTAQ=Λ。QQQ 的列是 VVV 的一组标准正交基，且 AQ=QΛAQ = Q\LambdaAQ=QΛ 说明第 iii 列是特征值 λi\lambda_iλi​ 的特征向量 —— 这就是谱定理要的特征基，特征值全实由 Λ\LambdaΛ 直接读出。

    两条是同一件事的算子语言与矩阵语言；关键一步「在标准正交基下取矩阵」在两个方向上都可逆。原记 analogy，FIX-065 改 equivalence 并补双向推导。

  • 本页 ⟺ 谱定理（复正规）等价
    正规矩阵可酉对角化   ⟺  \iff⟺ 正规算子可酉对角化
    算子版 $\implies$ 矩阵版

    设 AAA 正规。取 Cn\mathbb{C}^{n}Cn 的标准正交基，AAA 定义的算子 TTT 满足 T∗T=TT∗T^{}T = TT^{}T∗T=TT∗。复谱定理给标准正交特征基，以之为列得酉矩阵 UUU；由 AU=UΛAU = U\LambdaAU=UΛ 得 U∗AU=ΛU^{*}AU = \LambdaU∗AU=Λ 对角。

    矩阵版 $\implies$ 算子版

    设 TTT 是有限维复内积空间上的正规算子。取标准正交基把 TTT 写成 AAA，正规性逐项传递：A∗A=AA∗A^{}A = AA^{}A∗A=AA∗。矩阵版给酉 UUU 使 U∗AU=ΛU^{*}AU = \LambdaU∗AU=Λ；UUU 的列是标准正交基，AU=UΛAU = U\LambdaAU=UΛ 说明第 iii 列是特征值 λi\lambda_iλi​ 的特征向量。

    原记 analogy，FIX-065 改 equivalence：两个方向都归结为「标准正交基下的矩阵 + AU=UΛAU = U\LambdaAU=UΛ」这一条事实。

推出 1

  • Schur 三角化 ⟹ 本页推出
    Schur 三角化 ⟹\Longrightarrow⟹ 谱定理（矩阵版）

    (⟸\Longleftarrow⟸) 若 A=UΛU∗A = U\Lambda U^{}A=UΛU∗，则 AA∗=UΛU∗UΛ∗U∗=UΛΛ∗U∗AA^{} = U\Lambda U^{}U\Lambda^{}U^{} = U\Lambda\Lambda^{}U^{}AA∗=UΛU∗UΛ∗U∗=UΛΛ∗U∗，而 A∗A=UΛ∗ΛU∗A^{}A = U\Lambda^{}\Lambda U^{}A∗A=UΛ∗ΛU∗；对角阵的乘法可交换，ΛΛ∗=Λ∗Λ\Lambda\Lambda^{} = \Lambda^{}\LambdaΛΛ∗=Λ∗Λ，故 AA∗=A∗AAA^{} = A^{}AAA∗=A∗A —— AAA 正规。

    (⟹\Longrightarrow⟹) 设 AAA 正规。由 Schur 三角化，存在酉 UUU 使 T=U∗AUT = U^{}AUT=U∗AU 上三角。正规性在酉相似下保持：T∗T=U∗A∗UU∗AU=U∗A∗AUT^{}T = U^{}A^{}UU^{}AU = U^{}A^{}AUT∗T=U∗A∗UU∗AU=U∗A∗AU，TT∗=U∗AUU∗A∗U=U∗AA∗UTT^{} = U^{}AUU^{}A^{}U = U^{}AA^{*}UTT∗=U∗AUU∗A∗U=U∗AA∗U，两者相等。

    对 TTT 的第 (1,1)(1,1)(1,1) 元比较：(T∗T)11=∑j∣tj1∣2=∣t11∣2(T^{}T)_{11} = \sum_{j}|t_{j1}|^{2} = |t_{11}|^{2}(T∗T)11​=∑j​∣tj1​∣2=∣t11​∣2（第一列只有 t11t_{11}t11​），(TT∗)11=∑j∣t1j∣2(TT^{})_{11} = \sum_{j}|t_{1j}|^{2}(TT∗)11​=∑j​∣t1j​∣2；相等给出 t12=⋯=t1n=0t_{12} = \cdots = t_{1n} = 0t12​=⋯=t1n​=0。于是 T=diag⁡(t11,T1)T = \operatorname{diag}(t_{11}, T_{1})T=diag(t11​,T1​)，T1T_{1}T1​ 仍上三角且正规；对 T1T_{1}T1​ 重复该论证，归纳得 TTT 对角。故 A=UTU∗A = UTU^{*}A=UTU∗ 酉可对角化。

    实情形：实对称矩阵是正规矩阵，故有复谱分解 A=UΛU∗A = U\Lambda U^{*}A=UΛU∗。其特征值全实：若 Ax=λxAx = \lambda xAx=λx、x≠0x \ne 0x=0，则 λ∥x∥2=⟨Ax,x⟩=⟨x,Ax⟩=λ‾∥x∥2\lambda\|x\|^{2} = \langle Ax, x\rangle = \langle x, Ax\rangle = \overline{\lambda}\|x\|^{2}λ∥x∥2=⟨Ax,x⟩=⟨x,Ax⟩=λ∥x∥2，故 λ=λ‾\lambda = \overline{\lambda}λ=λ。对实特征值 λ\lambdaλ，(A−λI)x=0(A - \lambda I)x = 0(A−λI)x=0 是实系数方程组，其解空间有实基，故特征向量可取实；于是 UUU 可取为实正交矩阵 QQQ，QTAQQ^{T}AQQTAQ 为实对角阵。∎
