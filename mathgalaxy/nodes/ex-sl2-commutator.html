陈述

取

E=(0100),F=(0010),H=(100−1),E = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix},\quad F = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix},\quad H = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix},E=(00​10​),F=(01​00​),H=(10​0−1​),

在 [A,B]:=AB−BA[A, B] := AB - BA[A,B]:=AB−BA 下，这三个矩阵张成的三维空间对括号封闭，且

[E,F]=H,[H,E]=2E,[H,F]=−2F.[E, F] = H, \qquad [H, E] = 2E, \qquad [H, F] = -2F.[E,F]=H,[H,E]=2E,[H,F]=−2F.

说明

逐条验：EF=(1000)EF = \begin{pmatrix}1&0\\0&0\end{pmatrix}EF=(10​00​)、FE=(0001)FE = \begin{pmatrix}0&0\\0&1\end{pmatrix}FE=(00​01​)，相减正是 HHH；HE=EHE = EHE=E、EH=−EEH = -EEH=−E   ⟹  \implies⟹ [H,E]=2E[H,E] = 2E[H,E]=2E；同理 [H,F]=−2F[H,F] = -2F[H,F]=−2F。

⭐ 为什么这三个是标准例子：它们就是 sl2\mathfrak{sl}_{2}sl2​ 的标准基 —— 「特征值 2,0,−22, 0, -22,0,−2」的伴随作用让整个表示论可以画在一张图上。本图的 Lie 括号 说「反称 + Jacobi」，这里能直接看到反称（[E,E]=0[E,E] = 0[E,E]=0）与 Jacobi 恒等式在三元组上成立。

📌 括号是「换位子的无穷小版」：对矩阵群，exp⁡(tA)exp⁡(tB)exp⁡(−tA)exp⁡(−tB)=I+t2[A,B]+O(t3)\exp(tA)\exp(tB)\exp(-tA)\exp(-tB) = I + t^{2}[A,B] + O(t^{3})exp(tA)exp(tB)exp(−tA)exp(−tB)=I+t2[A,B]+O(t3) —— 所以交换子测的正是「两个流在多大程度上不交换」。这条式子本图没有节点（Lie 群 的注里提了线性化，没给这条路），这里只作为读法。

⚠ 别把 [A,B][A,B][A,B] 当成矩阵乘法的「另一种写法」：[A,B][A,B][A,B] 与 ABABAB 是完全不同的对象（前者在 A=BA = BA=B 时为零）。Lie 括号也不是结合运算：[A,[B,C]]≠[[A,B],C][A,[B,C]] \ne [[A,B],C][A,[B,C]]=[[A,B],C] 一般而言 —— 代替结合律的是 Jacobi。
