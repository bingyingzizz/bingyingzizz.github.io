# the Carathéodory extension agrees with the premeasure　`prop.caratheodory-extension`
English entry · root `../`
[in graph](../#n=prop.caratheodory-extension)　·　[Chinese page (authoritative)](./prop.caratheodory-extension.md)

Not only $\mathfrak{A}$ itself, but also the sets obtained by countable unions and intersections (and iterating) — $\mathfrak{A}_\sigma$, $\mathfrak{A}_\delta$, $\mathfrak{A}_\sigma \delta$, $\mathfrak{A}_\delta \sigma$ — are all $\mu^{*}$-measurable, because $\mathcal{M}$ is a $\sigma$-algebra and is closed under these operations.
