# Metrizable Space　`def.metrizable`
English entry · root `../`
[in graph](../#n=def.metrizable)　·　[Chinese page (authoritative)](./def.metrizable.md)

⭐ **This is a dividing line for theorems**: a metrizable space automatically acquires Hausdorff, first countability, normality and paracompactness (propositions in this cluster), so every tool available on metric spaces applies. Conversely, second countability $+$ regularity suffices (Urysohn's theorem), and a weaker sufficient condition is a $\sigma$-locally finite base (Nagata–Smirnov).

⚠️ Not every topological space is metrizable: an uncountable discrete space is metrizable (discrete metric) yet not second countable, while the Sorgenfrey line (lower-limit topology) is normal, separable and first countable but not second countable, hence **not** metrizable.
