陈述

设 E,FE, FE,F 是 Banach 空间，u:E→Fu : E \to Fu:E→F 线性。若 uuu 的图像

G(u):={(x,u(x)):x∈E}G(u) := \{(x, u(x)) : x \in E\}G(u):={(x,u(x)):x∈E}

在乘积空间 E×FE \times FE×F 中闭，则 uuu 有界（从而连续）。 把乘积拓扑的收敛展开，判据就是一句话：对任意序列 xn→xx_n \to xxn​→x，若 u(xn)→yu(x_n) \to yu(xn​)→y，则必有 y=u(x)y = u(x)y=u(x)。

说明

证明。 E×FE \times FE×F 完备（两个完备空间的积完备），而 G(u)G(u)G(u) 是它的闭子集，故 G(u)G(u)G(u) 本身是 Banach 空间。两个投影

π1:G(u)→E, (x,u(x))↦x;π2:G(u)→F, (x,u(x))↦u(x)\pi_1 : G(u) \to E,\ (x, u(x)) \mapsto x ; \qquad \pi_2 : G(u) \to F,\ (x, u(x)) \mapsto u(x)π1​:G(u)→E, (x,u(x))↦x;π2​:G(u)→F, (x,u(x))↦u(x)

都是有界线性映射（∥π1∥≤1\|\pi_1\| \le 1∥π1​∥≤1、∥π2∥≤1\|\pi_2\| \le 1∥π2​∥≤1），且 π1\pi_1π1​ 是双射（线性映射的图像与定义域一一对应）。对 π1\pi_1π1​ 用逆算子定理：π1−1:E→G(u)\pi_1^{-1} : E \to G(u)π1−1​:E→G(u) 有界。于是

u=π2∘π1−1u = \pi_2 \circ \pi_1^{-1}u=π2​∘π1−1​

作为两个有界映射的复合有界。□\square□

实用价值在于「闭」比「有界」好验。 要直接证明 uuu 有界，得估计 ∥ux∥\|u x\|∥ux∥；而验证图像闭只需要：任取收敛的 xn→xx_n \to xxn​→x 与 u(xn)→yu(x_n) \to yu(xn​)→y，证明 y=u(x)y = u(x)y=u(x) —— 中间不需要任何范数估计。分布理论里证明微分算子、Fourier 变换这类映射连续，走的就是这条路。

为什么必须线性、必须两端完备。「连续   ⟹  \implies⟹ 图像闭」是初等的（连续映射的图像在乘积空间里当然闭，对任何映射都对），所以容易误以为两者差不多；差别全在逆命题上。

线性。 非线性映射可以有闭图像而不连续：取 u:R→Ru : \mathbb{R} \to \mathbb{R}u:R→R，u(x)=1/xu(x) = 1/xu(x)=1/x（x≠0x \ne 0x=0）、u(0)=0u(0) = 0u(0)=0。它的图像在 R2\mathbb{R}^2R2 中闭（是一条双曲线加原点），但 uuu 在 000 处不连续。

    闭图像定理   ⟹  \implies⟹ Lax–Milgram 的逆有界

    强制性给出 ∥Ax∥≥δ∥x∥\|A x\| \ge \delta \|x\|∥Ax∥≥δ∥x∥；由此 AAA 单射、像闭，再用正交分解证满射，故 AAA 是 Banach 空间之间的有界双射。 考察 A−1A^{-1}A−1 的图像：若 yn→yy_n \to yyn​→y 且 A−1yn→xA^{-1} y_n \to xA−1yn​→x，则 A(A−1yn)=yn→yA(A^{-1} y_n) = y_n \to yA(A−1yn​)=yn​→y，由 AAA 连续得 Ax=yA x = yAx=y，即 x=A−1yx = A^{-1} yx=A−1y。图像闭，由闭图像定理 A−1A^{-1}A−1 有界。

    这里用的是闭图像定理（而不是开映射定理）；两者等价，但闭图像形式在「逆映射」上更直接。

定义引用 2

  • Banach 空间 → 本页定义引用

    两边都必须是 Banach：乘积空间要完备，逆算子定理才能用。

  • 映射 → 本页定义引用

    「映射就是它的图像」是「映射」那条定义的直接后果（映射 = 一种特殊的关系 = 有序对的集合），所以闭图像定理里的 G(u)G(u)G(u) 不是新对象。
