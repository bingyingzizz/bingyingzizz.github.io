# Completely Regular Space　`def.completely-regular-space`
English entry · root `../`
[in graph](../#n=def.completely-regular-space)　·　[Chinese page (authoritative)](./def.completely-regular-space.md)

1. $X$ is **$T_{3.5}$**: a point and a closed set not containing it can be separated by a continuous function (`def.t35-space`);
2. $X$ is **$T_{1}$**.

A space satisfying both is also called a **Tychonoff space**.

**Equivalent form**: $X$ embeds in some cube $[0,1]^{I}$ (that is, "there are enough continuous functions to separate points from closed sets").
