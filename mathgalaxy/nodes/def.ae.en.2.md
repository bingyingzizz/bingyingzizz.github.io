# almost everywhere　`def.ae`
English entry · root `../`
[in graph](../#n=def.ae)　·　[Chinese page (authoritative)](./def.ae.md)

that is, **the set of failure points is contained in some measurable null set** (it need not itself be measurable — a non-Borel subset of the Cantor set in a non-complete space is a counterexample; only after completion are the two formulations equivalent).

Common uses: $f = g$ a.e. (the set $\{f \ne g\}$ is null), $f_n \to f$ a.e. (the points of non-convergence form a null set), $F' = 0$ a.e.
