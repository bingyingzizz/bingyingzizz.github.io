Statement

What it says**: a vector bundle only requires the fiber to be a vector space. Replacing the vector space by an arbitrary manifold FFF** gives a fiber bundle — covering spaces, principal bundles and vector bundles all fall under this one definition.

Let E,B,FE, B, FE,B,F be smooth manifolds and π:E→B\pi : E\to Bπ:E→B a smooth surjection. One calls π\piπ (together with EEE) a fiber bundle with fiber FFF and base BBB if every point b∈Bb\in Bb∈B has an open neighbourhood UUU and a diffeomorphism
