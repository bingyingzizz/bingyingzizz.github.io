# Gauss Equation　`thm.gauss-equation`
English entry · root `../`
[in graph](../#n=thm.gauss-equation)　·　[Chinese page (authoritative)](./thm.gauss-equation.md)

**Coordinate cross-check**: from the commutation of mixed partials of $r_{ij} = \Gamma^{k}_{\ ij}r_{k}+h_{ij}n$ one derives the Gauss equation and writes it as $R_{ijkl} = h_{ik}h_{jl}-h_{il}h_{jk}$, $R_{1212} = LN-M^{2} = K(EG-F^{2})$.

Reading coefficients from $\mathrm{d}\omega^{i}_{\ j}$ is a shorter notation for the same system.

⚠️ **Index order is a convention**: with $R_{ijkl} = \langle R(e_{i}, e_{j})e_{k}, e_{l}\rangle$, the vector form above reads $R_{ijkl} = h_{jk}h_{il}-h_{ik}h_{jl}$, with the opposite sign to the other index order;
