(5) 若 $\mathcal{E}$ 是**基本类**，则「$\mathcal{E}$ 中有限多个两两不交集合之并」全体

$\mathfrak{A} = \{ E_1 \cup \cdots \cup E_n : E_1, \ldots, E_n \in \mathcal{E}$ 两两不交 $\}$

是一个**环**。

（第 (4) 条因为本身是一条定理，单独列在「环 $\implies \sigma$-环 的判据」里。）
