# Legendre symbol　`def.legendre-symbol`
English entry · root `../`
[in graph](../#n=def.legendre-symbol)　·　[Chinese page (authoritative)](./def.legendre-symbol.md)

Additionally set $\left(\frac{a}{p}\right) = 0$ when $p \mid a$.

## Notes · **draft**
It compresses "does a solution exist" into a function taking values $\pm 1$, and multiplicativity is immediate: from $x^{2} \equiv a$, $y^{2} \equiv b$ one gets $(xy)^{2} \equiv ab$, and together with the count "each has exactly $(p-1)/2$ residues" this gives

$$\left(\frac{ab}{p}\right) = \left(\frac{a}{p}\right)\left(\frac{b}{p}\right) .$$
