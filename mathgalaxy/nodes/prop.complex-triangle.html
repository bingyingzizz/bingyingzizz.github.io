白话：和的模不超过模的和；取等号的唯一情形是这些复数「方向一致」。

对任意 z1,⋯ ,zn∈Cz_1, \cdots, z_n \in \mathbb{C}z1​,⋯,zn​∈C，

∣∑k=1nzk∣≤∑k=1n∣zk∣.\left| \sum_{k=1}^{n} z_k \right| \le \sum_{k=1}^{n} |z_k|.​k=1∑n​zk​​≤k=1∑n​∣zk​∣.

等号成立当且仅当：非零的那些 zkz_kzk​ 有相同的辐角。

说明

⭐ 证明的妙处在于不去估和，而是先把和转到实轴上：令 θ\thetaθ 是 ∑kzk\sum_k z_k∑k​zk​ 的一个辐角（和为零时结论显然），则

∣∑kzk∣=e−iθ∑kzk=Re⁡(e−iθ∑kzk)=∑kRe⁡(e−iθzk)≤∑k∣e−iθzk∣=∑k∣zk∣.\left| \sum_k z_k \right| = e^{-i\theta}\sum_k z_k = \operatorname{Re}\left( e^{-i\theta}\sum_k z_k \right) = \sum_k \operatorname{Re}\left( e^{-i\theta} z_k \right) \le \sum_k \left| e^{-i\theta} z_k \right| = \sum_k |z_k|.​k∑​zk​​=e−iθk∑​zk​=Re(e−iθk∑​zk​)=k∑​Re(e−iθzk​)≤k∑​​e−iθzk​​=k∑​∣zk​∣.

第 2 个等号是「非负实数等于自己的实部」，最后一步是 Re⁡w≤∣w∣\operatorname{Re} w \le |w|Rew≤∣w∣。

⭐ 等号条件从中直接读出：每一步都要取等，即每个 e−iθzke^{-i\theta} z_ke−iθzk​ 都是非负实数。

⭐ 两条常用推论：反三角不等式 ∣∣z∣−∣w∣∣≤∣z−w∣\big| |z| - |w| \big| \le |z - w|​∣z∣−∣w∣​≤∣z−w∣；以及积分基本不等式 ∣∫γf dz∣≤∫γ∣f∣ ∣dz∣≤max⁡γ∣f∣⋅L(γ)\left| \int_\gamma f\,\mathrm{d}z \right| \le \int_\gamma |f|\,|\mathrm{d}z| \le \max_\gamma |f| \cdot L(\gamma)​∫γ​fdz​≤∫γ​∣f∣∣dz∣≤maxγ​∣f∣⋅L(γ) —— 后面的 Cauchy 不等式与 Liouville 定理全靠它。

📌 书里同节的另一条是复的 Cauchy–Schwarz 不等式：∣∑jzjwj‾∣2≤(∑j∣zj∣2)(∑j∣wj∣2)\left| \sum_j z_j \overline{w_j} \right|^2 \le \left( \sum_j |z_j|^2 \right)\left( \sum_j |w_j|^2 \right)​∑j​zj​wj​​​2≤(∑j​∣zj​∣2)(∑j​∣wj​∣2)，等号当且仅当两组数相差一个复常数倍。

推出 1

  • 复数 ℂ ⟹ 本页推出
    复数的模与辐角   ⟹  \implies⟹ 模长三角不等式

    设 S=∑k=1nzkS = \sum_{k=1}^{n} z_kS=∑k=1n​zk​。S=0S = 0S=0 时结论即 0≤∑∣zk∣0 \le \sum |z_k|0≤∑∣zk​∣，显然。

    关键一步：把和转到实轴上。 取 θ\thetaθ 为 SSS 的一个辐角（即 S=∣S∣eiθS = |S| e^{i\theta}S=∣S∣eiθ），两边乘 e−iθe^{-i\theta}e−iθ：e−iθS=∣S∣e^{-i\theta} S = |S|e−iθS=∣S∣ 是非负实数，于是

    ∣S∣=e−iθS=Re⁡(e−iθS)=∑k=1nRe⁡(e−iθzk).|S| = e^{-i\theta} S = \operatorname{Re}\left( e^{-i\theta} S \right) = \sum_{k=1}^{n} \operatorname{Re}\left( e^{-i\theta} z_k \right).∣S∣=e−iθS=Re(e−iθS)=k=1∑n​Re(e−iθzk​).

    逐项放缩。 对每个 kkk 有 Re⁡w≤∣w∣\operatorname{Re} w \le |w|Rew≤∣w∣，故

    ∣S∣≤∑k=1n∣e−iθzk∣=∑k=1n∣zk∣,|S| \le \sum_{k=1}^{n} \left| e^{-i\theta} z_k \right| = \sum_{k=1}^{n} |z_k|,∣S∣≤k=1∑n​​e−iθzk​​=k=1∑n​∣zk​∣,

    最后一步用到 ∣e−iθ∣=1|e^{-i\theta}| = 1∣e−iθ∣=1 与模的乘法性 ∣zw∣=∣z∣∣w∣|zw| = |z||w|∣zw∣=∣z∣∣w∣（这是 C\mathbb{C}C 的乘法定义直接给出的）。

    等号条件。 上面只用了两处不等号：Re⁡w≤∣w∣\operatorname{Re} w \le |w|Rew≤∣w∣，以及逐项求和。两处同时取等，当且仅当每个 e−iθzke^{-i\theta} z_ke−iθzk​ 都是非负实数，即全体非零 zkz_kzk​ 的辐角都等于 θ\thetaθ。■\blacksquare■
