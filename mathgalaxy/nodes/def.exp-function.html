说明

⭐ 先有级数，后有 exe^{x}ex：这样定义的原因是它不依赖任何几何直观、对复数同样成立、而且所有性质（函数方程、导数等于自身）都能从级数里算出来。

⭐ 函数方程的证明是卷积：exp⁡(z+w)=∑n(z+w)nn!\exp(z+w) = \sum_n \frac{(z+w)^{n}}{n!}exp(z+w)=∑n​n!(z+w)n​，把 (z+w)n(z+w)^{n}(z+w)n 二项式展开再重排（绝对收敛，重排合法）。

⚠ exp⁡\expexp 从不取零值：exp⁡z⋅exp⁡(−z)=exp⁡0=1\exp z \cdot \exp(-z) = \exp 0 = 1expz⋅exp(−z)=exp0=1。于是它把 C\mathbb{C}C 送进 C∖{0}\mathbb{C} \setminus \{0\}C∖{0}。
