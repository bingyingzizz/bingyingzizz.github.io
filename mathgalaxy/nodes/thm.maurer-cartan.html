又称Maurer–Cartan 方程

陈述

白话：Lie 群上那组「随群一起平移」的 111-形式，其外微分完全由结构常数决定 —— 一条公式把群的乘法（结构常数）和流形的微分（d\mathrm{d}d）扣在一起。

设 GGG 是 nnn 维 Lie 群，g=TeG\mathfrak{g} = T_{e}Gg=Te​G，e1,…,ene_{1},\ldots,e_{n}e1​,…,en​ 是 g\mathfrak{g}g 的基，ω1,…,ωn\omega^{1},\ldots,\omega^{n}ω1,…,ωn 是左不变对偶余标架（def.left-invariant-form），结构常数由

[ej,ek]=∑i=1nc jki ei[e_{j},e_{k}] = \sum_{i=1}^{n} c^{i}_{\ jk}\,e_{i}[ej​,ek​]=i=1∑n​c jki​ei​

定义（等价地用左不变向量场写：[e~j,e~k]=∑ic jkie~i[\tilde e_{j},\tilde e_{k}] = \sum_{i}c^{i}_{\ jk}\tilde e_{i}[e~j​,e~k​]=∑i​c jki​e~i​）。则

dωi=−12∑j,k=1nc jki ωj∧ωk(i=1,…,n).\mathrm{d}\omega^{i} = -\frac{1}{2}\sum_{j,k=1}^{n} c^{i}_{\ jk}\,\omega^{j}\wedge\omega^{k}\qquad (i = 1,\ldots,n).dωi=−21​j,k=1∑n​c jki​ωj∧ωk(i=1,…,n).

把 ω:=∑iωiei∈Ω1(G;g)\omega := \sum_{i}\omega^{i}e_{i} \in \Omega^{1}(G;\mathfrak{g})ω:=∑i​ωiei​∈Ω1(G;g) 看成一个 g\mathfrak{g}g-值 111-形式（Maurer–Cartan 形式），并对 g\mathfrak{g}g-值形式定义分次括号 [α∧β][\alpha\wedge\beta][α∧β]，上式就是 Maurer–Cartan 方程

dω+12[ω∧ω]=0,dω=−12[ω∧ω],\mathrm{d}\omega + \frac{1}{2}[\omega\wedge\omega] = 0,\qquad\mathrm{d}\omega = -\frac{1}{2}[\omega\wedge\omega],dω+21​[ω∧ω]=0,dω=−21​[ω∧ω],

两个 111-形式的约定是：把 [ω∧ω][\omega\wedge\omega][ω∧ω] 放在 (X,Y)(X,Y)(X,Y) 上取值，得 2 [ω(X),ω(Y)]2\,[\omega(X),\omega(Y)]2[ω(X),ω(Y)]。

说明

系数与符号的来历：把 [ω∧ω][\omega\wedge\omega][ω∧ω] 逐项写开时，(j,k)(j,k)(j,k) 与 (k,j)(k,j)(k,j) 两项给出 c jki−c kji=2c jkic^{i}_{\ jk} - c^{i}_{\ kj} = 2c^{i}_{\ jk}c jki​−c kji​=2c jki​，恰好抵掉 12\frac{1}{2}21​；符号来自「dθ(X,Y)=Xθ(Y)−Yθ(X)−θ([X,Y])\mathrm{d}\theta(X,Y) = X\theta(Y) - Y\theta(X) - \theta([X,Y])dθ(X,Y)=Xθ(Y)−Yθ(X)−θ([X,Y])」里的最后一项。所以这条公式没有一处自由度是多余的：有的书把括号归一化成不除 222，系数就跟着变（dω=−12[ω,ω]\mathrm{d}\omega = -\frac{1}{2}[\omega,\omega]dω=−21​[ω,ω] 与 dω+[ω∧ω]=0\mathrm{d}\omega + [\omega\wedge\omega] = 0dω+[ω∧ω]=0 是同一句话的两种写法）。

它就是 Cartan 结构方程的群版本：曲面上的结构方程 dωi=∑jωj∧ω ji\mathrm{d}\omega^{i} = \sum_{j}\omega^{j}\wedge\omega^{i}_{\ j}dωi=∑j​ωj∧ω ji​ 描述「标架怎么转」；这里标架不动、群在动，于是 dωi\mathrm{d}\omega^{i}dωi 只剩结构常数这一项。同一套记账，一个描述空间弯曲，一个描述乘法非交换。

反推 Jacobi：对 MC 方程两边取 d\mathrm{d}d 并用 d2=0\mathrm{d}^{2} = 0d2=0，比较 ωj∧ωk∧ωl\omega^{j}\wedge\omega^{k}\wedge\omega^{l}ωj∧ωk∧ωl 的系数，得到

∑i(c jkic ilm+c klic ijm+c ljic ikm)=0,\sum_{i}\bigl(c^{i}_{\ jk}c^{m}_{\ il} + c^{i}_{\ kl}c^{m}_{\ ij} + c^{i}_{\ lj}c^{m}_{\ ik}\bigr) = 0,i∑​(c jki​c ilm​+c kli​c ijm​+c lji​c ikm​)=0,

这正是 [[ej,ek],el]+[[ek,el],ej]+[[el,ej],ek]=0[[e_{j},e_{k}],e_{l}] + [[e_{k},e_{l}],e_{j}] + [[e_{l},e_{j}],e_{k}] = 0[[ej​,ek​],el​]+[[ek​,el​],ej​]+[[el​,ej​],ek​]=0。于是「g\mathfrak{g}g 是 Lie 代数（Jacobi 成立）」与「ω\omegaω 满足 MC 方程」是同一件事 —— 这就是 MC 方程被称为「平坦性条件」的原因。

与 H1H^{1}H1、平坦联络的接口：dω+12[ω∧ω]=0\mathrm{d}\omega + \frac{1}{2}[\omega\wedge\omega] = 0dω+21​[ω∧ω]=0 是「联络形式零曲率」的方程（把 ω\omegaω 看成平凡主丛上的联络）。所以「结构常数」与「平坦联络的模空间」在这个层次上是同一串数；本图只提这一句，不展开。

⚠️ 上标 iii 是「结果的第几个分量」、下面两个 j,kj,kj,k 是「输入的两个下标」。反称性只发生在下面两个之间（c jki=−c kjic^{i}_{\ jk} = -c^{i}_{\ kj}c jki​=−c kji​），iii 与它们之间没有任何对称性可言 —— 抄公式时把 iii 写到下标位置，就会凭空多出一次反称，符号全错。

    预备公式：对任意 111-形式 θ\thetaθ 与向量场 X,YX, YX,Y，

    dθ(X,Y)=X(θ(Y))−Y(θ(X))−θ([X,Y]).\mathrm{d}\theta(X,Y) = X\bigl(\theta(Y)\bigr) - Y\bigl(\theta(X)\bigr) - \theta\bigl([X,Y]\bigr).dθ(X,Y)=X(θ(Y))−Y(θ(X))−θ([X,Y]).

    这是 d\mathrm{d}d 的坐标无关刻画：在卡里把 θ=∑aidxi\theta = \sum a_{i}\mathrm{d}x^{i}θ=∑ai​dxi 与 X,YX, YX,Y 的分量代入 dθ=∑∂jai dxj∧dxi\mathrm{d}\theta = \sum\partial_{j}a_{i}\,\mathrm{d}x^{j}\wedge\mathrm{d}x^{i}dθ=∑∂j​ai​dxj∧dxi，与上式逐项吻合（def.exterior-derivative 的定义式加 Leibniz 律）。

    两边都是左不变的 222-形式。 左边：d(Lh∗ωi)=Lh∗dωi\mathrm{d}(L_{h}^{\ast}\omega^{i}) = L_{h}^{\ast}\mathrm{d}\omega^{i}d(Lh∗​ωi)=Lh∗​dωi（拉回与外微分交换，prop.pullback-forms），而 Lh∗ωi=ωiL_{h}^{\ast}\omega^{i} = \omega^{i}Lh∗​ωi=ωi，故 Lh∗dωi=dωiL_{h}^{\ast}\mathrm{d}\omega^{i} = \mathrm{d}\omega^{i}Lh∗​dωi=dωi。右边：ωj∧ωk\omega^{j}\wedge\omega^{k}ωj∧ωk 由左不变形式组成，也左不变。所以只需在一点（或在一组左不变基上）比较。

    右边同一点的值。 由 (ωa∧ωb)(e~j,e~k)=δ jaδ kb−δ kaδ jb(\omega^{a}\wedge\omega^{b})(\tilde e_{j},\tilde e_{k}) = \delta^{a}_{\ j}\delta^{b}_{\ k} - \delta^{a}_{\ k}\delta^{b}_{\ j}(ωa∧ωb)(e~j​,e~k​)=δ ja​δ kb​−δ ka​δ jb​，

定义引用 3

  • 左不变形式 → 本页定义引用

    方程左边是左不变余标架 ωi\omega^{i}ωi 的外微分，右边是结构常数 —— 两样都在左不变形式的定义里。

  • Lie 代数 → 本页定义引用

    结构常数 c jkic^{i}_{\ jk}c jki​ 是 Lie 代数的括号在基下的坐标；MC 方程就是说「这些坐标决定了 dωi\mathrm{d}\omega^{i}dωi」。

  • 外微分 → 本页定义引用

    方程是 d\mathrm{d}d 的等式；证明用的桥是「dθ(X,Y)=Xθ(Y)−Yθ(X)−θ([X,Y])\mathrm{d}\theta(X,Y) = X\theta(Y) - Y\theta(X) - \theta([X,Y])dθ(X,Y)=Xθ(Y)−Yθ(X)−θ([X,Y])」，那是外微分的坐标无关刻画。
