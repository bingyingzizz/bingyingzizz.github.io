陈述

在做什么：在有内积的空间里，⟨v,v⟩=0\langle v,v\rangle = 0⟨v,v⟩=0 只有零解。但一般双线性型没有这个性质 —— 能让「长度为零」的非零向量叫迷向向量，它是这门几何与内积几何分道扬镳的地方。

设 β\betaβ 是 VVV 上的对称双线性型（或对应的二次型 qqq）。称 v≠0v \ne 0v=0 迷向，若

β(v,v)=0\beta(v, v) = 0β(v,v)=0（即 q(v)=0q(v) = 0q(v)=0）

这样的 vvv 自己就与自己正交。若 β\betaβ 非退化且存在迷向向量，就称 β\betaβ 是迷向型（isotropic form）；不存在非零迷向向量时叫非迷向（各向异性，anisotropic）。

例子：R2\mathbb{R}^{2}R2 上 β(x,y)=x1y1−x2y2\beta(x,y) = x_{1}y_{1} - x_{2}y_{2}β(x,y)=x1​y1​−x2​y2​ 中，(1,1)(1,1)(1,1) 与 (1,−1)(1,-1)(1,−1) 都迷向；而标准内积没有迷向向量。

说明

几何直观：把 q(x)=1q(x) = 1q(x)=1 想成「单位球面」。正定型给的是椭球（各向异性）；不定型给的是双曲面，而双曲面穿过原点的那两条直线上的点满足 q=0q = 0q=0 —— 那就是迷向向量。所以「迷向」= 「光锥方向」。

⚠️ 迷向向量的存在与基无关（q(v)=0q(v) = 0q(v)=0 是坐标无关的陈述），但它是否存在取决于型：实对称型由惯性指数决定 —— 只要 qqq 不定（p,qp, qp,q 都非零），就一定有迷向向量；正定或负定则没有。

⭐ 在相对论里这个就是「类光线」：β\betaβ 取 Minkowski 型，迷向向量 = 光速方向。数学上同一条东西叫「零向量 / 迷向向量」，名字不同而已。

⚠️ 别把「迷向」与「零向量」搞混：迷向向量必须非零，只是它的「长度平方」是零。
