Abstract reviewed

The essential supremum is ∥f∥∞:=inf⁡{a≥0:μ({∣f∣>a})=0}\|f\|_\infty := \inf \{a \ge 0 : \mu(\{|f| > a\}) = 0\}∥f∥∞​:=inf{a≥0:μ({∣f∣>a})=0}: the true bound of fff once its values on null sets are ignored. The infimum is attained at a=∥f∥∞a = \|f\|_\inftya=∥f∥∞​ itself, and ∥f∥∞≤M  ⟺  ∣f∣≤M\|f\|_\infty \le M \iff |f| \le M∥f∥∞​≤M⟺∣f∣≤M almost everywhere. Then L∞L^\inftyL∞ consists of the measurable fff with ∥f∥∞<∞\|f\|_\infty < \infty∥f∥∞​<∞. Note the difference from sup⁡∣f∣\sup |f|sup∣f∣, which a single value on a null set can spoil.

Definition

∥f∥∞:=inf⁡{ a≥0:μ({ ∣f∣>a })=0 }\|f\|_\infty := \inf \{\, a \ge 0 : \mu(\{\, |f| > a \,\}) = 0 \,\}∥f∥∞​:=inf{a≥0:μ({∣f∣>a})=0}

Notes reviewed

An equivalent form: ∥f∥∞≤M  ⟺  ∣f(x)∣≤M\|f\|_\infty \le M \iff |f(x)| \le M∥f∥∞​≤M⟺∣f(x)∣≤M holds for a.e. xxx.

What the word "essential" means: bad values on null sets simply do not count. For instance, if f=0f = 0f=0 a.e. but fff takes the value +∞+\infty+∞ on some null set, we still have ∥f∥∞=0\|f\|_\infty = 0∥f∥∞​=0.

⚠ ∥f∥∞\|f\|_\infty∥f∥∞​ differs from "sup⁡∣f∣\sup |f|sup∣f∣": the latter can become large because of a single point on a null set.
