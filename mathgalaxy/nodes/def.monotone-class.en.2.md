## Notes · **draft**
A monotone class only cares about the two limits "increasing union, decreasing intersection"; it does **not** require closure under finite unions, differences, or complements — so it is far weaker than a $\sigma$-algebra.

Its use lies entirely in the monotone class theorem: a $\sigma$-algebra is equivalent to "a ring closed under both limits". To prove "a property holds for all measurable sets", one usually verifies it on a monotone class and then invokes the monotone class theorem.
