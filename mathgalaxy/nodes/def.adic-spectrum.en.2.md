# the adic spectrum　`def.adic-spectrum`
English entry · root `../`
[in graph](../#n=def.adic-spectrum)　·　[Chinese page (authoritative)](./def.adic-spectrum.md)

First, terminology. A **valuation** is a "size-measuring" function $|\cdot| : A \to \Gamma \cup \{0\}$ ($\Gamma$ a totally ordered abelian group written multiplicatively, think $\mathbb{R}_{>0}$) satisfying

$$|0| = 0, \quad |1| = 1, \quad |xy| = |x|\,|y|, \quad |x + y| \le \max(|x|, |y|).$$

Two valuations $|\cdot|, |\cdot|_1$ are **equivalent** if there is an order-preserving group isomorphism with $|x|_1 = \sigma(|x|)$ for all $x$ — that is, "they order the elements of $A$ by size in exactly the same way", only the "ruler" changes.
