Statement

In plain words: f!f^!f! need not be built separately — it is "first pull back by f∗f^*f∗, then multiply by a fixed object f!Rf^!Rf!R". This fixed object is called the dualizing complex (a twist: f∗f^*f∗ is twisted). Thus computing the dual is reduced to computing one complex f!Rf^!Rf!R; the next two nodes compute this complex (regular closed immersion, smooth map).
