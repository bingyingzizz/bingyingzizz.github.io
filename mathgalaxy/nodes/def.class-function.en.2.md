## Notes · **draft**
Class functions form an $F$-vector space of dimension the number of conjugacy classes, $\#\mathrm{CL}(G)$.
When $\operatorname{char}F=0$ (or $\operatorname{char}F\nmid|G|$), characters of pairwise non-isomorphic irreducible representations are linearly independent (orthogonality relations).
A class function is determined by its values on conjugacy classes.
The centralizer of $g$ is its stabilizer under conjugation.
