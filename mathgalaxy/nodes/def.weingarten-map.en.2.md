# Weingarten Map (Shape Operator)　`def.weingarten-map`
English entry · root `../`
[in graph](../#n=def.weingarten-map)　·　[Chinese page (authoritative)](./def.weingarten-map.md)

$$W(e_{j}) = \sum_{i=1}^{2}h_{ij}\,e_{i},\qquad h_{ij} := -c_{ij} = -\omega^{i}_{\ 3}(e_{j}),$$

and $W$ is self-adjoint: $\langle W(v), w\rangle = \langle v, W(w)\rangle$, i.e. $(h_{ij})$ is symmetric.

## Notes · **draft**
**Intuition**: $W$ measures how fast the normal turns, i.e. how strongly the surface bends. The bending in a unit direction $V$ is $\langle W(V), V\rangle$; see `def.normal-curvature`.
