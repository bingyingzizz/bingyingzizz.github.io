陈述

设 VVV 有有序基 B=(v1,…,vn)\mathcal{B} = (v_1, \ldots, v_n)B=(v1​,…,vn​)、WWW 有有序基 C=(w1,…,wm)\mathcal{C} = (w_1, \ldots, w_m)C=(w1​,…,wm​)，都是有限维 KKK-向量空间。称 m×nm \times nm×n 矩阵 [T]BC[T]_{\mathcal{B}}^{\mathcal{C}}[T]BC​ 为 TTT 在这两组基下的矩阵，其中第 jjj 列是 T(vj)T(v_j)T(vj​) 在 C\mathcal{C}C 下的坐标。

于是映射 T↦[T]BCT \mapsto [T]_{\mathcal{B}}^{\mathcal{C}}T↦[T]BC​ 是 KKK-向量空间的同构

Hom⁡K(V,W)  ≅  Mm×n(K)\operatorname{Hom}_K(V, W) \;\cong\; M_{m \times n}(K)HomK​(V,W)≅Mm×n​(K)

并且复合对应乘法：若 T:V→WT : V \to WT:V→W、S:W→US : W \to US:W→U，则

[S∘T]BE=[S]CE  [T]BC[S \circ T]_{\mathcal{B}}^{\mathcal{E}} = [S]_{\mathcal{C}}^{\mathcal{E}}\; [T]_{\mathcal{B}}^{\mathcal{C}}[S∘T]BE​=[S]CE​[T]BC​

说明

⭐ 这就是整套矩阵论的出生证：矩阵不是被定义出来的对象，而是线性映射在选定基下的坐标（与「坐标」那一条完全同一个机制，只是两侧各选一组基）。

⭐ 于是所有矩阵运算都有了意义：加法 = 映射的和、乘法 = 复合、单位矩阵 = 恒等映射、可逆 = 同构。矩阵的每一个公式都可以翻译成映射的语言，反之亦然 —— 这是本图把两者分团又用边连起来的原因。

⚠ 这一切都依赖基的选取：换一组基，矩阵就变了（变成相似的，见「基变换」）。而线性映射本身不变。

  • 本页 ⟹ M_n(K) 是环推出
    矩阵运算的定义   ⟹  \implies⟹ Mn(K)M_n(K)Mn​(K) 是环

    逐条验证。

    1. 加法群：逐分量加法继承 KKK 的加法群结构，零元是零矩阵，−A-A−A 是逐分量取负。
    2. 乘法结合：(AB)C(AB)C(AB)C 与 A(BC)A(BC)A(BC) 的 (i,j)(i,j)(i,j) 元素都是 ∑k,laikbklclj\sum_{k,l} a_{ik} b_{kl} c_{lj}∑k,l​aik​bkl​clj​（两次求和次序可换，因为都是有限和）。
    3. 分配律：(A+B)C(A + B)C(A+B)C 与 AC+BCAC + BCAC+BC 的 (i,j)(i,j)(i,j) 元素都是 ∑k(aik+bik)ckj\sum_k (a_{ik} + b_{ik}) c_{kj}∑k​(aik​+bik​)ckj​。
    4. 单位元：(InA)ij=∑kδikakj=aij(I_n A)_{ij} = \sum_k \delta_{ik} a_{kj} = a_{ij}(In​A)ij​=∑k​δik​akj​=aij​，同理 AIn=AA I_n = AAIn​=A。
    5. KKK-代数：数乘与加法的相容（向量空间公理）逐分量成立，且 c(AB)=(cA)B=A(cB)c(AB) = (cA)B = A(cB)c(AB)=(cA)B=A(cB) 由有限和的线性性得到。

    非交换（n≥2n \ge 2n≥2）：取 A=E12A = E_{12}A=E12​（只有 (1,2)(1,2)(1,2) 位是 111）、B=E21B = E_{21}B=E21​，则 AB=E11AB = E_{11}AB=E11​ 而 BA=E22BA = E_{22}BA=E22​，不等。∎

    （另一条路更短：由「线性映射 ↔\leftrightarrow↔ 矩阵」把加法读成映射的加法、乘法读成复合，于是环公理就是 End⁡(Kn)\operatorname{End}(K^{n})End(Kn) 的环公理，逐条显然。）

    第 5 步「c(AB)=A(cB)c(AB) = A(cB)c(AB)=A(cB)」是 KKK-代数定义里唯一不平凡的一条 —— 它说明数乘可以从任何一个因子里提出来。

  • 本页 ⟹ 基变换与相似推出
    矩阵表示 + 乘法对应复合   ⟹  \implies⟹ 相似

    记 P:=[id]B′BP := [\mathrm{id}]_{\mathcal{B}'}^{\mathcal{B}}P:=[id]B′B​。由矩阵表示对复合的乘性，

    [T]B′=[id∘T∘id]B′B′=[id]BB′ [T]BB [id]B′B=P−1 [T]B P[T]_{\mathcal{B}'} = [\mathrm{id} \circ T \circ \mathrm{id}]_{\mathcal{B}'}^{\mathcal{B}'} = [\mathrm{id}]_{\mathcal{B}}^{\mathcal{B}'}\ [T]_{\mathcal{B}}^{\mathcal{B}}\ [\mathrm{id}]_{\mathcal{B}'}^{\mathcal{B}} = P^{-1}\,[T]_{\mathcal{B}}\,P[T]B′​=[id∘T∘id]B′B′​=[id]BB′​ [T]BB​ [id]B′B​=P−1[T]B​P

    其中 [id]BB′=P−1[\mathrm{id}]_{\mathcal{B}}^{\mathcal{B}'} = P^{-1}[id]BB′​=P−1 是因为两个过渡矩阵互为逆（(P−1P)(P^{-1}P)(P−1P) 是恒等映射在两同一组基下的矩阵，即 InI_nIn​）。

    由「可逆   ⟺  \iff⟺ 双射」一栏的等价，PPP 可逆。

    相似是等价关系：自反（P=IP = IP=I）、对称（A∼B  ⟹  B=P−1AP  ⟹  A=(P−1)−1BP−1A \sim B \implies B = P^{-1}AP \implies A = (P^{-1})^{-1} B P^{-1}A∼B⟹B=P−1AP⟹A=(P−1)−1BP−1）、传递（P−1AP=BP^{-1}AP = BP−1AP=B、Q−1BQ=C  ⟹  (PQ)−1A(PQ)=CQ^{-1}BQ = C \implies (PQ)^{-1}A(PQ) = CQ−1BQ=C⟹(PQ)−1A(PQ)=C）。∎

  • 本页 ⟹ 行秩 = 列秩推出
    矩阵表示   ⟹  \implies⟹ 行秩 = 列秩

    把 AAA 看成映射 T:Kn→KmT : K^{n} \to K^{m}T:Kn→Km、x↦Axx \mapsto Axx↦Ax（取标准基）。

    1. 列秩：AAA 的列向量正是 T(e1),…,T(en)T(e_1), \ldots, T(e_n)T(e1​),…,T(en​)，所以列秩 =dim⁡im⁡T=rank⁡A= \dim \operatorname{im} T = \operatorname{rank} A=dimimT=rankA。
    2. 行秩：AAA 的转置 ATA^{\mathsf{T}}AT 对应的映射 TT:Km→KnT^{\mathsf{T}} : K^{m} \to K^{n}TT:Km→Kn 就是 TTT 的对偶（取标准基，见「对偶基」里的 [T∗]=[T]T[T^{\ast}] = [T]^{\mathsf{T}}[T∗]=[T]T）。AAA 的行向量是 ATA^{\mathsf{T}}AT 的列向量，故行秩 =rank⁡AT= \operatorname{rank} A^{\mathsf{T}}=rankAT。
    3. 只需再证 rank⁡AT=rank⁡A\operatorname{rank} A^{\mathsf{T}} = \operatorname{rank} ArankAT=rankA：由 im⁡TT=(ker⁡T)0\operatorname{im} T^{\mathsf{T}} = (\ker T)^{0}imTT=(kerT)0（零化子）与 dim⁡U0=dim⁡V−dim⁡U\dim U^{0} = \dim V - \dim UdimU0=dimV−dimU，
    rank⁡AT=dim⁡im⁡TT=dim⁡(ker⁡T)0=n−dim⁡ker⁡T=dim⁡im⁡T=rank⁡A\operatorname{rank} A^{\mathsf{T}} = \dim \operatorname{im} T^{\mathsf{T}} = \dim (\ker T)^{0} = n - \dim \ker T = \dim \operatorname{im} T = \operatorname{rank} ArankAT=dimimTT=dim(kerT)0=n−dimkerT=dimimT=rankA

    （最后一步用了秩-零化度定理。）∎

    这条证明把「行秩 = 列秩」化归成对偶那一段的零化子维数公式 —— 也就是说：转置不改变秩，而那是零化子与秩-零化度的共同推论。

  • 坐标、线性映射、矩阵 ⟹ 本页推出
    坐标 + 线性   ⟹  \implies⟹ 线性映射与矩阵一一对应

    记 B=(v1,…,vn)\mathcal{B} = (v_1, \ldots, v_n)B=(v1​,…,vn​)、C=(w1,…,wm)\mathcal{C} = (w_1, \ldots, w_m)C=(w1​,…,wm​)。

    构造：给定 TTT，它在每个基向量上的值 T(vj)∈WT(v_j) \in WT(vj​)∈W 有唯一坐标 (a1j,…,amj)T(a_{1j}, \ldots, a_{mj})^{\mathsf{T}}(a1j​,…,amj​)T，排成矩阵 [T]BC:=(aij)[T]_{\mathcal{B}}^{\mathcal{C}} := (a_{ij})[T]BC​:=(aij​)。

    互逆：两个构造显然互相还原，故 T↦[T]T \mapsto [T]T↦[T] 是双射。

    (S∘T)(vj)=S(∑iaijwi)=∑iaijS(wi)=∑iaij∑kbkiuk=∑k(∑ibkiaij)uk(S \circ T)(v_j) = S\Bigl( \sum_i a_{ij} w_i \Bigr) = \sum_i a_{ij} S(w_i) = \sum_i a_{ij} \sum_k b_{ki} u_k = \sum_k \Bigl( \sum_i b_{ki} a_{ij} \Bigr) u_k(S∘T)(vj​)=S(i∑​aij​wi​)=i∑​aij​S(wi​)=i∑​aij​k∑​bki​uk​=k∑​(i∑​bki​aij​)uk​
