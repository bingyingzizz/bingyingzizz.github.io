# Banach–Alaoglu　`thm.banach-alaoglu`
English entry · root `../`
[in graph](../#n=thm.banach-alaoglu)　·　[Chinese page (authoritative)](./thm.banach-alaoglu.md)

**The image is closed.** Suppose $\Phi(\varphi_\alpha) \to y = (y_x)$ in $P$. Define $\varphi(x) = y_x$. Linearity: $y_{x + z} = \lim \varphi_\alpha(x + z) = \lim(\varphi_\alpha(x) + \varphi_\alpha(z)) = y_x + y_z$, and similarly $y_{tx} = t y_x$. Boundedness: $|y_x| \le \|x\|$, hence $\|\varphi\| \le 1$. Thus $y = \Phi(\varphi) \in \Phi(B_{X^{*}})$, so the image is closed.
