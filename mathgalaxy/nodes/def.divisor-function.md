# 除数函数 τ 与 σ　`def.divisor-function`
除数个数与除数之和
layer 14 · 定义 · 数论函数与素数分布 · 数论
[在星图里打开](../#n=def.divisor-function)　·　[节点索引](../index.md)

对 $n \ge 1$ 定义

$$\tau(n) := \#\{\, d \ge 1 : d \mid n \,\}, \qquad \sigma(n) := \sum_{d \mid n} d .$$

$\tau(n)$ 是 $n$ 的正因数个数，$\sigma(n)$ 是它们之和。
