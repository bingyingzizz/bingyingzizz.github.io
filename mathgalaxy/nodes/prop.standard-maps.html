又称标准共形映射

陈述

常用的一批「把区域搬到标准位置」的映射（H\mathbb{H}H = 上半平面，D\mathbb{D}D = 单位圆盘）：

  1. H→D\mathbb{H} \to \mathbb{D}H→D：z↦z−iz+iz \mapsto \dfrac{z - i}{z + i}z↦z+iz−i​；
  2. 角域 { 0<arg⁡z<α }\{\, 0 < \arg z < \alpha \,\}{0<argz<α} →H\to \mathbb{H}→H：z↦zπ/αz \mapsto z^{\pi/\alpha}z↦zπ/α；
  3. 带域 { 0<Im⁡z<π }\{\, 0 < \operatorname{Im} z < \pi \,\}{0<Imz<π} →H\to \mathbb{H}→H：z↦ezz \mapsto e^{z}z↦ez；
  4. 割平面 C∖(−∞,0]\mathbb{C} \setminus (-\infty, 0]C∖(−∞,0] →H\to \mathbb{H}→H：主值 z\sqrt{z}z​ 或 log⁡z\log zlogz；
  5. D→D\mathbb{D} \to \mathbb{D}D→D 的自同构：z↦eiθz−a1−aˉzz \mapsto e^{i\theta}\dfrac{z - a}{1 - \bar a z}z↦eiθ1−aˉzz−a​，∣a∣<1|a| < 1∣a∣<1。

说明

⭐ 这一张表就是「共形映射」这一章的手册：遇到一个新区域，先想办法用表里的映射（幂、指数、对数、分式线性）把它搬到 H\mathbb{H}H 或 D\mathbb{D}D，再由 thm.riemann-mapping 知道一定能做到 —— 差别只在「能不能写出公式」。

为什么这些映射对：zkz^{k}zk 把角域张开 kkk 倍角（k=π/αk = \pi/\alphak=π/α）；eze^{z}ez 把水平带卷成角域；log⁡\loglog 反过来把割平面摊成带域；分式线性变换保圆（prop.mobius-circle），所以能把半平面/圆盘互换。

⚠️ 每个映射都要指明取哪一支：zπ/αz^{\pi/\alpha}zπ/α 与 log⁡\loglog 都是多值的，上面写的是主值（或约定好的那一支）。

  • 本页 ⟹ Schwarz–Christoffel 公式推出
    f′f'f′ 的形状由「沿边反射」定出来

    指数从哪来：设 fff 把 H\mathbb{H}H 映成多边形。沿第 kkk 段边做 Schwarz 反射（thm.schwarz-reflection），可把 fff 越过实轴解析延拓；在 xkx_{k}xk​ 处两侧的延拓相差一个旋转，转角恰是外角 π−αkπ\pi - \alpha_{k}\piπ−αk​π。

    于是 arg⁡f′\arg f'argf′ 在 xkx_{k}xk​ 有跳变 π(αk−1)\pi(\alpha_{k} - 1)π(αk​−1)，而 f′f'f′ 在 H\mathbb{H}H 内无零点，故 f′f'f′ 只能是 A∏(ζ−xk)αk−1A\prod(\zeta - x_{k})^{\alpha_{k}-1}A∏(ζ−xk​)αk​−1 乘以一个无零点的整函数倍。再证那个因子为常数（增长与有界性），积分即得公式。

    常数：AAA 管大小与旋转、BBB 管平移；三个 xkx_{k}xk​ 可自由指定（分式线性变换自由度）。∎

    S–C 公式 = 反射原理 + 对 f′f'f′ 的局部形状分析。
