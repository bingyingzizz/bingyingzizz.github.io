Statement draft

Assume char⁡F=0\operatorname{char}F=0charF=0. If W1,W2W_1,W_2W1​,W2​ are finite-dimensional semisimple representations of AAA, then W1≅W2W_1\cong W_2W1​≅W2​ if and only if χW1=χW2\chi_{W_1}=\chi_{W_2}χW1​​=χW2​​.

Notes draft

Write W=⊕niViW=\oplus n_iV_iW=⊕ni​Vi​ with pairwise non-isomorphic irreducibles ViV_iVi​. The partition-of-unity elements aia_iai​ give χW(ai)=nidim⁡Vi\chi_W(a_i)=n_i\dim V_iχW​(ai​)=ni​dimVi​, so the multiplicities nin_ini​ are recovered from χW\chi_WχW​; char⁡F=0\operatorname{char}F=0charF=0 allows division by dim⁡Vi\dim V_idimVi​. Semisimplicity is essential: over F[x]F[x]F[x] the identity and a Jordan block can have the same character without being isomorphic. This is the basis of character-table theory; the proof goes through prop.partition-of-unity, which follows from Burnside surjectivity.
