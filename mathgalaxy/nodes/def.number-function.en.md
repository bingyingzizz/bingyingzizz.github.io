## Statement · **reviewed**
Let $X$ be a set and $f : X \to Y$ a **map**. If its values lie in a **set of numbers** — that is, $Y \subseteq \mathbb{R}$ or $Y \subseteq \mathbb{C}$ — then $f$ is called a **function**.
