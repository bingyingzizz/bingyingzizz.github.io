# long exact sequence of a pair　`thm.long-exact-pair`
English entry · root `../`
[in graph](../#n=thm.long-exact-pair)　·　[Chinese page (authoritative)](./thm.long-exact-pair.md)

**(a) $\operatorname{im} j_{*} = \ker q_{*}$.** If $[c] = j_{*}[a]$ (where $a$ is a cycle in $A$), then $q_{*}[c] = [q(a)] = 0$, since $a \in S_{*}(A)$ is $0$ in the quotient complex. Conversely, suppose $q_{*}[c] = 0$, so $q(c) = \partial b$ for some $b \in S_{p+1}(X)$. Then $q(c - \partial b) = 0$, so $c - \partial b \in S_{p}(A)$ and $\partial(c - \partial b) = 0$, hence $[c] = j_{*}[c - \partial b]$.
