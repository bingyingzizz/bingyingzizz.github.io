陈述

A⊆XA \subseteq XA⊆X 叫第一纲集（meager，贫集），若 AAA 可写成可数个无处稠密集之并；不是第一纲的叫第二纲集。称 AAA 剩余（residual），若 AcA^cAc 第一纲。

说明

「纲」是「大小」的第三种口径，既不是基数也不是测度：Q\mathbb{Q}Q 可数、稠密但是第一纲（每个单点无处稠密）；Cantor 集不可数、测度为零但是第一纲（它本身无处稠密）；[0,1]∖Q[0,1] \setminus \mathbb{Q}[0,1]∖Q 是第二纲且剩余。

⚠️ 第二纲 ≠\ne= 稠密：[0,1]∪{2}[0,1] \cup \{2\}[0,1]∪{2} 也是第二纲。

⭐ 用法：想说「几乎所有点都满足 PPP」，就去证 {x:¬P(x)}\{x : \neg P(x)\}{x:¬P(x)} 第一纲。在无穷维里这比测度论更顺手（很多函数空间没有自然测度，但有 Baire 纲）。
