# row rank equals column rank　`thm.rank-row-col`
English entry · root `../`
[in graph](../#n=thm.rank-row-col)　·　[Chinese page (authoritative)](./thm.rank-row-col.md)

⭐ The proof goes through elementary operations: left multiplication by an invertible matrix does not change the row space (it only changes the basis), so one may first reduce $A$ to reduced row echelon form, where the number of nonzero rows is the rank — and the column rank is determined by the same pivots.

⚠ This is the justification for "computing rank by elimination": moving column operations around does not change that number.
