## 陈述（续）
若 $T_F(a) < \infty$（即 $F$ 在 $(-\infty, a]$ 上有界变差），则 $T_F(b) - T_F(a)$ 等于 $F$ 在 $[a, b]$ 上的全变差；一般情形要**直接定义** $\operatorname{Var}_{[a,b]}(F) := \sup\Bigl\{\sum_{j}\lvert F(x_{j}) - F(x_{j-1})\rvert : a = x_{0} < \cdots < x_{n} = b\Bigr\}$，⛔ 不能写差值：$F = \sin$ 时 $T_F(a) = T_F(b) = +\infty$，差值是 $\infty - 
\infty$（无意义），而 $\sin$ 在 $[a,b]$ 上显然有界变差。$[a,b]$ 上有界变差的函数全体记作 $BV([a, b])$。
