说明

Statement draft

A finite-dimensional FFF-algebra AAA is semisimple if and only if J(A)=0J(A)=0J(A)=0.

Notes draft

If AAA is semisimple, the regular module is a direct sum of simple modules; indeed J(A)J(A)J(A) is the intersection of the maximal left ideals, and J(A)J(A)J(A) annihilates every simple module, so J(A)⊆Ann⁡(A)=0J(A)\subseteq\operatorname{Ann}(A)=0J(A)⊆Ann(A)=0. Conversely, if J(A)=0J(A)=0J(A)=0, then A/J(A)=AA/J(A)=AA/J(A)=A is semisimple; more directly, the regular module has a simple submodule, and the radical property splits it off. Finite dimension is used for termination.
