又称谱定理（实对称）

陈述

设 VVV 是有限维实内积空间，T:V→VT : V \to VT:V→V 自伴（即实对称）。则存在 VVV 的标准正交基，使 TTT 在其中是对角阵：

V=Eλ1⊕⋯⊕EλmV = E_{\lambda_1} \oplus \cdots \oplus E_{\lambda_m}V=Eλ1​​⊕⋯⊕Eλm​​

（这些特征子空间两两正交。）

并且所有特征值 λi\lambda_iλi​ 都是实数。矩阵形式：实对称矩阵 AAA 存在正交矩阵 QQQ 使 QTAQ=diag⁡(λ1,…,λn)Q^{\mathsf{T}} A Q = \operatorname{diag}(\lambda_1, \ldots, \lambda_n)QTAQ=diag(λ1​,…,λn​)。

说明

⭐ 与 Jordan 型的区别：Jordan 只保证「相似」，谱定理保证「酉/正交相似」，代价是把条件收紧到自伴（正规）。这是有限维里两个不同的分类问题的答案。

⭐ 证明的两步：① 至少有一个（实）特征值（用最值定理：∣Tv∣|Tv|∣Tv∣ 或 ⟨Tv,v⟩\langle Tv, v\rangle⟨Tv,v⟩ 在单位球面这个紧集上取极值）；② 对特征子空间的正交补归纳（不变性来自自伴：T(U)⊆U  ⟹  T(U⊥)⊆U⊥T(U) \subseteq U \implies T(U^{\perp}) \subseteq U^{\perp}T(U)⊆U⟹T(U⊥)⊆U⊥）。

⭐ 无限维的推广是Hilbert 空间上的谱定理（自伴算子的谱测度 / 投影值测度）—— 那是泛函分析的内容，图上 analysis.lp 那一团的 L2L^{2}L2 就是它的舞台。

  • 本页 ⟹ 谱定理（复正规）推出
    实谱定理 + 复化   ⟹  \implies⟹ 复正规可酉对角化
    1. 自伴的情形：复自伴算子（Hermite）的实谱定理版本：把 VVV 看作实向量空间，TTT 作为实算子是实对称的，由上一条得到实特征值与正交分解；再把实结构复化即得复情形。
    2. 正规的情形：TTT 正规时写 T=A+iBT = A + iBT=A+iB，其中 A:=(T+T∗)/2A := (T + T^{\ast})/2A:=(T+T∗)/2、B:=(T−T∗)/(2i)B := (T - T^{\ast})/(2i)B:=(T−T∗)/(2i) 都自伴；正规性等价于 AB=BAAB = BAAB=BA（直接展开 T∗T=TT∗T^{\ast}T = TT^{\ast}T∗T=TT∗ 即得）。
    3. 由 AB=BAAB = BAAB=BA，它们同时可正交对角化：对 AAA 的每个特征子空间 EλE_\lambdaEλ​，由 AB=BAAB = BAAB=BA 得 B(Eλ)⊆EλB(E_\lambda) \subseteq E_\lambdaB(Eλ​)⊆Eλ​；在 EλE_\lambdaEλ​ 上对 BBB 用实谱定理（同理复化），把所有这样的标准正交基拼起来即得。
    4. 于是 TTT 在同一组标准正交基下对角（对角元 λj+iμj\lambda_j + i\mu_jλj​+iμj​）。
    5. 三条等价：由对角形直接读出 —— T∗=T  ⟺  T^{\ast} = T \iffT∗=T⟺ 所有对角元实；TTT 酉   ⟺  ∣λ∣=1\iff |\lambda|=1⟺∣λ∣=1；投影   ⟺  \iff⟺ 特征值 ∈{0,1}\in\{0,1\}∈{0,1} 且自伴。∎

    第 2 步的「正规   ⟺  \iff⟺ ABABAB 交换」是这条推论的核心：复正规算子 = 一对交换的自伴算子，于是问题化归到实谱定理。

  • 正规算子、可对角化判据、最值定理、正交补 ⟹ 本页推出
    自伴性 + 紧性   ⟹  \implies⟹ 谱定理（实对称）

    设 TTT 是有限维实内积空间上的自伴算子。

    1. 存在实特征值：单位球面 S:={v:∥v∥=1}S := \{v : \|v\| = 1\}S:={v:∥v∥=1} 是紧集，函数 f(v):=⟨Tv,v⟩f(v) := \langle Tv, v\ranglef(v):=⟨Tv,v⟩ 连续，故在某点 v0v_0v0​ 取到最大值 λ\lambdaλ（最值定理）。用 Lagrange 乘子（或直接对 v0v_0v0​ 附近扰动求导）可得 Tv0=λv0Tv_0 = \lambda v_0Tv0​=λv0​：即在约束 ∥v∥2=1\|v\|^{2} = 1∥v∥2=1 下 fff 的极值点满足 ∇f=λ∇(∥v∥2)\nabla f = \lambda \nabla(\|v\|^{2})∇f=λ∇(∥v∥2)，而两个梯度分别是 2Tv02Tv_02Tv0​ 与 2v02v_02v0​。于是 λ\lambdaλ 是特征值，且由 λ=⟨Tv0,v0⟩∈R\lambda = \langle Tv_0, v_0\rangle \in \mathbb{R}λ=⟨Tv0​,v0​⟩∈R 知它是实数。
    2. 特征子空间的不变性：U:=EλU := E_\lambdaU:=Eλ​ 是 TTT-不变的；由自伴性，U⊥U^{\perp}U⊥ 也是 TTT-不变的：若 w⊥Uw \perp Uw⊥U，则对 u∈Uu \in Uu∈U，⟨u,Tw⟩=⟨Tu,w⟩=⟨λu,w⟩=λ⟨u,w⟩=0\langle u, Tw\rangle = \langle Tu, w\rangle = \langle \lambda u, w\rangle = \lambda\langle u, w\rangle = 0⟨u,Tw⟩=⟨Tu,w⟩=⟨λu,w⟩=λ⟨u,w⟩=0，即 Tw⊥UTw \perp UTw⊥U。
    3. 归纳：T∣U⊥T|_{U^{\perp}}T∣U⊥​ 仍自伴，对 dim⁡U⊥<dim⁡V\dim U^{\perp} < \dim VdimU⊥<dimV 用归纳假设，得 U⊥=Eλ2⊕⋯U^{\perp} = E_{\lambda_2}\oplus\cdotsU⊥=Eλ2​​⊕⋯（两两正交）。于是 V=Eλ⊕U⊥V = E_{\lambda} \oplus U^{\perp}V=Eλ​⊕U⊥ 是所有特征子空间的正交直和。
    4. 在每个 EλiE_{\lambda_i}Eλi​​ 里取标准正交基（Gram–Schmidt），拼起来就是 VVV 的标准正交基，TTT 在其中是对角阵。∎

    第 1 步是分析输入（紧集上连续函数取最值），第 2 步是自伴性唯一被用到的地方。这也解释了为什么谱定理在实情形必须要求对称：没有自伴性，U⊥U^{\perp}U⊥ 不必不变，归纳断掉。
