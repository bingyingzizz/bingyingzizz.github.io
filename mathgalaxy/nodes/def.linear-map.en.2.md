# linear map　`def.linear-map`
English entry · root `../`
[in graph](../#n=def.linear-map)　·　[Chinese page (authoritative)](./def.linear-map.md)

$$\operatorname{Hom}_K(V, W) := \{\, T : V \to W \ \text{linear} \,\}$$

A composite $S \circ T$ is again linear.

## Notes · **draft**
⭐ Linear means **preserving the two operations** (addition and scalar multiplication).

Compared with a group homomorphism, which preserves one operation, there is one more requirement, but it comes for free: both $T(0) = 0$ and $T(-v) = -T(v)$ follow from the definition.
