陈述

在做什么：曲率张量除了代数对称性，还必须满足一条微分恒等式 —— 它是「Einstein 张量散度为零」的几何来源，也是广义相对论里能量守恒的对应物。

设 (M,g)(M,g)(M,g) 是黎曼流形，RRR 是曲率算子，∇\nabla∇ 是 Levi-Civita 联络。则

第一比安基恒等式（代数，无挠的推论）

R(X,Y)Z+R(Y,Z)X+R(Z,X)Y=0;R(X,Y)Z+R(Y,Z)X+R(Z,X)Y = 0 ;R(X,Y)Z+R(Y,Z)X+R(Z,X)Y=0;

第二比安基恒等式（微分）

(∇XR)(Y,Z)+(∇YR)(Z,X)+(∇ZR)(X,Y)=0,(\nabla_{X}R)(Y,Z)+(\nabla_{Y}R)(Z,X)+(\nabla_{Z}R)(X,Y) = 0 ,(∇X​R)(Y,Z)+(∇Y​R)(Z,X)+(∇Z​R)(X,Y)=0,

其中 (∇XR)(Y,Z)W:=∇X(R(Y,Z)W)−R(∇XY,Z)W−R(Y,∇XZ)W−R(Y,Z)∇XW(\nabla_{X}R)(Y,Z)W := \nabla_{X}\bigl(R(Y,Z)W\bigr)-R(\nabla_{X}Y,Z)W-R(Y,\nabla_{X}Z)W-R(Y,Z)\nabla_{X}W(∇X​R)(Y,Z)W:=∇X​(R(Y,Z)W)−R(∇X​Y,Z)W−R(Y,∇X​Z)W−R(Y,Z)∇X​W。

缩并形式（两次缩并并整理）：

∇i(Rij−12S gij)=0,\nabla^{i}\Bigl(R_{ij}-\frac{1}{2}S\,g_{ij}\Bigr) = 0 ,∇i(Rij​−21​Sgij​)=0,

即 Einstein 张量 Gij:=Rij−12S gijG_{ij} := R_{ij}-\frac{1}{2}S\,g_{ij}Gij​:=Rij​−21​Sgij​ 的散度为零。

说明

第一 vs 第二：第一是代数恒等式（同一点上四个向量之间），第二是微分恒等式（曲率的导数之间）。第一比安基已在 def.curvature-tensor 里列出，本节点给证明；第二比安基不成立的话 Einstein 方程根本写不出来。

证明的机制：在一点取法坐标（Γijk(p)=0\Gamma^{k}_{ij}(p) = 0Γijk​(p)=0、∂igjk(p)=0\partial_{i}g_{jk}(p) = 0∂i​gjk​(p)=0），则 ∇i=∂i\nabla_{i} = \partial_{i}∇i​=∂i​ 且 RijkℓR_{ijk\ell}Rijkℓ​ 可用 ggg 的二阶导数写出；三条轮流展开后，每个三阶偏导出现两次、符号相反，逐项抵消。两边都是张量等式且在每点都能这样取坐标，故恒成立。

缩并那一步：对第二比安基先用 giℓg^{i\ell}giℓ 缩并、再用 gjmg^{jm}gjm 缩并，用对称性把指标搬正，即得 ∇iGij=0\nabla^{i}G_{ij} = 0∇iGij​=0。这一步是「Einstein 张量为什么恰好是 Rij−12SgijR_{ij}-\frac{1}{2}Sg_{ij}Rij​−21​Sgij​」的全部理由：这个组合是唯一（差常数倍）散度为零的二阶对称张量。

⚠️ 缩并的方向依赖符号约定：本图取 Rij=R kijkR_{ij} = R^{k}_{\ kij}Rij​=R kijk​（见 def.ricci-curvature），于是 Gij=Rij−12SgijG_{ij} = R_{ij}-\frac{1}{2}Sg_{ij}Gij​=Rij​−21​Sgij​ 散度为零。换一套 Ricci 的符号，GGG 里的相对符号也跟着变，但「散度为零」这条内容不变。

⭐ 它管什么用：Einstein 方程 Rij−12Sgij=8πTijR_{ij}-\frac{1}{2}Sg_{ij} = 8\pi T_{ij}Rij​−21​Sgij​=8πTij​ 的左边自动散度为零，于是右边（能量-动量张量）必须守恒 —— 这就是「几何决定守恒律」的那一半。

    ∇iRij−12∇jS=0,\nabla^{i}R_{ij}-\frac{1}{2}\nabla_{j}S = 0 ,∇iRij​−21​∇j​S=0,
