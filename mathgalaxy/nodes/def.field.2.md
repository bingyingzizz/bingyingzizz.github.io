## 陈述（续）
- **加法**：$a + (b + c) = (a + b) + c$，$a + b = b + a$；存在 $0 \in F$ 使 $a + 0 = a$；对每个 $a$ 存在 $-a \in F$ 使 $a + (-a) = 0$；
- **乘法**：$a(bc) = (ab)c$，$ab = ba$；存在 $1 \in F$，$1 \ne 0$，使 $a \cdot 1 = a$；对每个 $a \ne 0$ 存在 $a^{-1} \in F$ 使 $a\, a^{-1} = 1$；
- **分配律**：$a (b + c) = ab + ac$。
一句话：**加减乘除（除以非零元）都封闭，且满足结合、交换、分配律**。
