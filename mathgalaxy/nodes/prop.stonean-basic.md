# 极端不连通的基本性质　`prop.stonean-basic`
极端不连通的性质
layer 17 · 命题 · Stone 与 Stonean · 拓扑学
[在星图里打开](../#n=prop.stonean-basic)　·　[节点索引](../index.md)

**(a)** 若 $X$ 极端不连通，则任意两个不交开集 $U, V$ 的闭包仍不交：$\overline{U} \cap \overline{V} = \emptyset$。

**(b)** 极端不连通的 Hausdorff 空间是**全不连通**的。
