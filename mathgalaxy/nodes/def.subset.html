陈述

设 AAA、BBB 是集合。

  • AAA 是 BBB 的子集（记 A⊆BA \subseteq BA⊆B）：∀x(x∈A→x∈B)\forall x ( x \in A \to x \in B )∀x(x∈A→x∈B)
  • AAA 是 BBB 的真子集（记 A⊂BA \subset BA⊂B）：A⊆BA \subseteq BA⊆B 且 A≠BA \ne BA=B。

基本性质：⊆\subseteq⊆ 自反、传递；并且由外延公理，

A=B  ⟺  A⊆B∧B⊆AA = B \iff A \subseteq B \wedge B \subseteq AA=B⟺A⊆B∧B⊆A

这是证明两个集合相等最常用的套路：两边互包。

说明

∅⊆A\emptyset \subseteq A∅⊆A 对一切 AAA 成立（空泛真）。

它指向谁（出边）
