Notes

⭐ This is a rare three-in-one theorem in analysis: it gives existence, uniqueness, and an algorithm (the iteration) with error estimates.

Most existence theorems only say "there is"; this one says "how to find it and how accurate it is".

⚠ Neither hypothesis can be dropped:

  • drop completeness: (0,1](0,1](0,1] is not complete and T(x)=x/2T(x) = x/2T(x)=x/2 is a contraction, but the fixed point 000 is not in the space;
  • drop q<1q < 1q<1: the map x+1/xx + 1/xx+1/x in 压缩映射 is a counterexample.
