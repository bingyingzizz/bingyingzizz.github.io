设 KKK 是有序域（如 Q\mathbb{Q}Q、R\mathbb{R}R），x,y∈Kx, y \in Kx,y∈K。则

∣x+y∣≤∣x∣+∣y∣|x + y| \le |x| + |y|∣x+y∣≤∣x∣+∣y∣

并且由此得到两个常用的变形：

∣∣x∣−∣y∣∣≤∣x−y∣,∣x1+x2+⋯+xn∣≤∣x1∣+∣x2∣+⋯+∣xn∣\big| |x| - |y| \big| \le |x - y|, \qquad |x_1 + x_2 + \cdots + x_n| \le |x_1| + |x_2| + \cdots + |x_n|​∣x∣−∣y∣​≤∣x−y∣,∣x1​+x2​+⋯+xn​∣≤∣x1​∣+∣x2​∣+⋯+∣xn​∣

（后者由前者对 nnn 归纳。）

说明

⭐ 这是一切估计的起点：Cauchy 列的线性运算、极限的四则运算、级数的比较判别法、距离空间里那条 d(x,z)≤d(x,y)+d(y,z)d(x, z) \le d(x, y) + d(y, z)d(x,z)≤d(x,y)+d(y,z)，归根到底都是它（距离空间那条是把它取作公理）。

⚠ 证明只有分情形，没有任何技巧 —— 但「a≤∣a∣a \le |a|a≤∣a∣ 且 −a≤∣a∣-a \le |a|−a≤∣a∣」这两句是全部的关键：由它得 −(∣x∣+∣y∣)≤x+y≤∣x∣+∣y∣-(|x| + |y|) \le x + y \le |x| + |y|−(∣x∣+∣y∣)≤x+y≤∣x∣+∣y∣，而 ∣t∣≤c  ⟺  −c≤t≤c|t| \le c \iff -c \le t \le c∣t∣≤c⟺−c≤t≤c（c≥0c \ge 0c≥0）。

  • 本页 ⟹ Cauchy 列与零列推出
    三角不等式   ⟹  \implies⟹ 零列关系是等价关系

    自反、对称直接由定义读出；传递要三角不等式：若 (xn)∼(yn)(x_n) \sim (y_n)(xn​)∼(yn​)、(yn)∼(zn)(y_n) \sim (z_n)(yn​)∼(zn​)，则 ∣xn−zn∣≤∣xn−yn∣+∣yn−zn∣|x_n - z_n| \le |x_n - y_n| + |y_n - z_n|∣xn​−zn​∣≤∣xn​−yn​∣+∣yn​−zn​∣，右边两项都是零列，故 (xn)∼(zn)(x_n) \sim (z_n)(xn​)∼(zn​)。没有这一条，R\mathbb{R}R 就没法定义成商集。∎

  • 绝对值 |x| ⟹ 本页推出
    绝对值的定义   ⟹  \implies⟹ 三角不等式

    设 x,y∈Kx, y \in Kx,y∈K。先看两个基本事实（都由 ∣t∣=max⁡{t,−t}|t| = \max\{t, -t\}∣t∣=max{t,−t} 直接读出）：

    • t≤∣t∣t \le |t|t≤∣t∣ 且 −t≤∣t∣-t \le |t|−t≤∣t∣，即 −∣t∣≤t≤∣t∣-|t| \le t \le |t|−∣t∣≤t≤∣t∣。

    于是

    x≤∣x∣,−x≤∣x∣,y≤∣y∣,−y≤∣y∣x \le |x|, \qquad -x \le |x|, \qquad y \le |y|, \qquad -y \le |y|x≤∣x∣,−x≤∣x∣,y≤∣y∣,−y≤∣y∣

    两两相加（序与加法相容）：

    x+y≤∣x∣+∣y∣,−(x+y)≤∣x∣+∣y∣x + y \le |x| + |y|, \qquad -(x + y) \le |x| + |y|x+y≤∣x∣+∣y∣,−(x+y)≤∣x∣+∣y∣

    即 −c≤x+y≤c-c \le x + y \le c−c≤x+y≤c，其中 c:=∣x∣+∣y∣≥0c := |x| + |y| \ge 0c:=∣x∣+∣y∣≥0。而

    −c≤t≤c  ⟺  ∣t∣≤c(c≥0)-c \le t \le c \iff |t| \le c \qquad (c \ge 0)−c≤t≤c⟺∣t∣≤c(c≥0)

    （⟸\Longleftarrow⟸：由 t≤ct \le ct≤c 与 −t≤c-t \le c−t≤c 分别取 max⁡\maxmax；  ⟹  \implies⟹：∣t∣|t|∣t∣ 等于 ttt 或 −t-t−t，两种情形都在 ccc 以下。）取 t=x+yt = x + yt=x+y 得

    ∣x+y∣≤∣x∣+∣y∣■|x + y| \le |x| + |y| \qquad \blacksquare∣x+y∣≤∣x∣+∣y∣■

    变形。 在 ∣x+y∣≤∣x∣+∣y∣|x + y| \le |x| + |y|∣x+y∣≤∣x∣+∣y∣ 中把 xxx 换成 x−yx - yx−y 得 ∣x∣≤∣x−y∣+∣y∣|x| \le |x - y| + |y|∣x∣≤∣x−y∣+∣y∣，即 ∣x∣−∣y∣≤∣x−y∣|x| - |y| \le |x - y|∣x∣−∣y∣≤∣x−y∣；交换 x,yx, yx,y 得另一侧，两者合起来就是 ∣∣x∣−∣y∣∣≤∣x−y∣\big| |x| - |y| \big| \le |x - y|​∣x∣−∣y∣​≤∣x−y∣。nnn 元版本由归纳：∣x1+⋯+xn∣≤∣x1+⋯+xn−1∣+∣xn∣|x_1 + \cdots + x_n| \le |x_1 + \cdots + x_{n-1}| + |x_n|∣x1​+⋯+xn​∣≤∣x1​+⋯+xn−1​∣+∣xn​∣。
