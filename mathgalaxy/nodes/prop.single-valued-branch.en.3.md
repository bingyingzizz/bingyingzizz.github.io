**Proof (1 $\implies$ 3)**: if $e^{f} = z$, then $f' = 1/z$, hence $\oint_{\gamma} \mathrm{d}z/z = \oint_{\gamma} f'\,\mathrm{d}z = 0$ (the contour integral of a holomorphic function in a simply connected region vanishes; here we use the "has a primitive" version).
