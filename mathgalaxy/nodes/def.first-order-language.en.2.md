# first-order logic　`def.first-order-language`
English entry · root `../`
[in graph](../#n=def.first-order-language)　·　[Chinese page (authoritative)](./def.first-order-language.md)

- **logical symbols** (shared by all first-order languages): countably many **variables** $v_{0}, v_{1}, v_{2}, \ldots$; the connectives $\neg, \wedge$ ($\vee, \to$ are abbreviations); the quantifiers $\forall$ ($\exists$ is an abbreviation); equality $=$; parentheses.
- **non-logical symbols** (specific to each language): **constant symbols**, **$n$-ary function symbols**, **$n$-ary relation symbols**, each with a definite arity $n$.
