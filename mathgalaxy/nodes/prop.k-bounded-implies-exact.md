# 相邻两条 K-有界 推出 正合　`prop.k-bounded-implies-exact`
$K$-有界正合（相邻两处）$\implies$ 通常正合

设 $M^{\bullet}$ 是 **Banach** 阿贝尔群复形。若它在 $M^{n-1}$ 与 $M^{n}$ 两处都 $K$-有界正合，则它在 $M^{n}$ 处（通常意义下）**正合**。
