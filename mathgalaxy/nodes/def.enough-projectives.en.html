Statement

A category C\mathcal{C}C has enough projectives if for every X∈CX \in \mathcal{C}X∈C there exist a projective object PPP and an epimorphism

P↠X.P \twoheadrightarrow X.P↠X.

Dually: it has enough injectives if every XXX embeds monically into some injective object X↪IX \hookrightarrow IX↪I.

Notes

⭐ It guarantees that projective resolutions exist: starting from P0↠XP_{0} \twoheadrightarrow XP0​↠X, cover the kernel ker⁡(P0→X)\ker(P_{0} \to X)ker(P0​→X) by another projective object, and so on recursively, obtaining a projective resolution

⋯→P2→P1→P0→X→0,\cdots \to P_{2} \to P_{1} \to P_{0} \to X \to 0,⋯→P2​→P1​→P0​→X→0,

Then one can take left derived functors (Tor⁡\operatorname{Tor}Tor, LnFL^{n}FLnF). Dually, enough injectives gives injective resolutions and right derived functors (Ext⁡n\operatorname{Ext}^{n}Extn, RnFR^{n}FRnF).

Why the condition "enough" is needed: a derived functor replaces an object by a resolution and then takes homology; if some object has no resolution at all, the definition stalls. So homological algebra names categories by "having enough projectives / injectives".

Examples: A-ModA\text{-}\mathbf{Mod}A-Mod has both (free modules are projective, every module embeds into an injective module); CondAb\mathrm{CondAb}CondAb has enough projectives (the finitely presented projective condensed abelian groups generate it); a Grothendieck category automatically has enough injectives.
