Statement draft

Fix a measure space (X,M,μ)(X, \mathcal{M}, \mu )(X,M,μ). Denote by L+L^+L+ the set of all measurable functions with values in the extended nonnegative reals:

L+:={f:X→[0,+∞]:fL^+ := \{ f : X \to [0, +\infty] : fL+:={f:X→[0,+∞]:f measurable }\}}

Notes draft

⚠ Values are allowed to be ∞\infty∞, deliberately: integration is first defined for functions with values in [0,+∞][0, +\infty ][0,+∞], and the convergence theorems (supremum / limits) are closed within all of L+L^{+}L+, so one need not keep asking whether an integral is finite.

“Integrable” (finite integral) is a condition added separately later, see the definition of L1L^{1}L1.
