# 最大公因数　`def.gcd`
最大公因数与它的两个刻画
layer 11 · 定义 · 整除与同余 · 数论
[在星图里打开](../#n=def.gcd)　·　[节点索引](../index.md)

设 $a, b \in \mathbb{Z}$ 不全为零。**最大公因数** $\gcd(a, b)$ 是同时整除 $a$ 与 $b$ 的正整数中最大的那个。

等价刻画（不预设存在性）：$\gcd(a, b)$ 是集合 $\{\, ua + vb : u, v \in \mathbb{Z} \,\}$ 中最小的正整数。
