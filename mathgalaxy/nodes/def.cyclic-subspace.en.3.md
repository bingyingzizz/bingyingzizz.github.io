# Cyclic Subspace and Cyclic Vector　`def.cyclic-subspace`
English entry · root `../`
[in graph](../#n=def.cyclic-subspace)　·　[Chinese page (authoritative)](./def.cyclic-subspace.md)

In finite dimension, $v$ is a cyclic vector if and only if $\deg\mu_v=\dim V$; in that case $\mu_T=\chi_T$. Conversely, if $\mu_T=\chi_T$, a cyclic vector exists (for instance, take the module corresponding to $1,x,\ldots$).

Example: for the companion matrix $C_d$, the vector $e_1$ is cyclic (see @@def.companion-matrix@@); $\operatorname{diag}(C_d,C_d)$ is not cyclic, because its minimal polynomial is still $d$ while the dimension is $2\deg d$.
