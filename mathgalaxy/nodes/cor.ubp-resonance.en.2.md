# the resonance set is a dense G-delta　`cor.ubp-resonance`
English entry · root `../`
[in graph](../#n=cor.ubp-resonance)　·　[Chinese page (authoritative)](./cor.ubp-resonance.md)

$R = \bigcap_k \Omega_k$ is a $G_\delta$.

If some $\Omega_k$ were not dense, there would be a ball $B(x_0, r) \subseteq \Omega_k^c$ on which $M \le k$, and the same translation-and-scaling argument as in the UBP would give $\sup_i\|u_i\| \le 2k/r$, a contradiction.

⭐ Meaning: divergence is not confined to exceptional points, it is **almost everywhere**. Classical application: the partial-sum operators of Fourier series satisfy $\|S_N\| \to \infty$, so there **exists** a continuous function whose Fourier series diverges at some point (du Bois-Reymond, 1876) — and such functions are plentiful.
