又称Cauchy 列

陈述

实数列 {xn}\{x_n\}{xn​} 是 Cauchy 列，当且仅当

∀ε>0, ∃N, ∀m,n≥N: ∣xm−xn∣<ε\forall \varepsilon > 0,\ \exists N,\ \forall m, n \ge N :\ |x_m - x_n| < \varepsilon∀ε>0, ∃N, ∀m,n≥N: ∣xm​−xn​∣<ε

即：只要取得足够靠后，任意两项都互相接近。

说明

⭐ 与「收敛」的差别是信息方向：验证收敛要先有 xxx 才能算 ∣xn−x∣|x_n - x|∣xn​−x∣，而 Cauchy 列只让数列自己人互相比 —— 一个不知道极限是多少的人也能验证它。

⭐ 在 R\mathbb{R}R 里两者等价（Cauchy 收敛准则）；在 Q\mathbb{Q}Q 里不等价（1,1.4,1.41,…1, 1.4, 1.41, \ldots1,1.4,1.41,… 是 Cauchy 列却没有有理极限）。R\mathbb{R}R 之所以要被造出来，正是为了补上这个缺口。

⚠ 别与 def.cauchy-null 混淆：那个是有理 Cauchy 列，是构造 R\mathbb{R}R 用的零件；这一条是 R\mathbb{R}R 造好之后判收敛的工具。
