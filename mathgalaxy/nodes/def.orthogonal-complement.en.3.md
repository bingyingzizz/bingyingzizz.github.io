# orthogonal complement　`def.orthogonal-complement`
English entry · root `../`
[in graph](../#n=def.orthogonal-complement)　·　[Chinese page (authoritative)](./def.orthogonal-complement.md)

⭐ It is paired with the annihilator in duality: $U^{\perp} \subseteq V$, $U^{0} \subseteq V^{\ast}$, and their dimension formulas look the same ($\dim V - \dim U$); under "$V \cong V^{\ast}$" (via the inner product) they translate into each other.

⚠ $V = U \oplus U^{\perp}$ holds in **infinite dimension** only for closed subspaces, not for arbitrary subspaces (this is a genuine theorem of Hilbert space theory).
