def.pair · 定义 · Kuratowski

又称有序对·ordered pair·Kuratowski·库拉托夫斯基

陈述

Kuratowski 定义：

(a,b):={{a},{a,b}}(a, b) := \{ \{a\}, \{a, b\} \}(a,b):={{a},{a,b}}

它由配对公理与幂集公理保证是集合。

特征性质（这才是「有序」的全部含义）：

(a,b)=(c,d)  ⟺  a=c∧b=d(a, b) = (c, d) \iff a = c \wedge b = d(a,b)=(c,d)⟺a=c∧b=d

说明

用集合「编码」有序对之后，关系、函数、序型等等才都能在 ZFC 内部说清楚。

它指向谁（出边）

    集合构造式 Ex={y:(x,y)∈E}E_x = \{ y : (x, y) \in E \}Ex​={y:(x,y)∈E} 里写的就是有序对 (x,y)(x, y)(x,y)。

  • 单射 / 满射 / 双射 用到 本页定义引用

    判断单射时用的是「f(a)=f(b)  ⟹  a=bf(a) = f(b) \implies a = bf(a)=f(b)⟹a=b」，即在有序对层面比较。

  • 关系 用到 本页定义引用

    关系被定义为「有序对的集合」，函数是特殊的关系，因此整个定义都建立在有序对之上。

  • 笛卡尔积存在 用到 本页定义引用

    A×B={(a,b):a∈A,b∈B}A \times B = \{ (a, b) : a \in A, b \in B \}A×B={(a,b):a∈A,b∈B} 中的元素就是有序对。

    四元组 (V,E,s,t)(V, E, s, t)(V,E,s,t) 是嵌套的有序对 —— 有序对是它的载体，先有有序对才写得下四元组。
