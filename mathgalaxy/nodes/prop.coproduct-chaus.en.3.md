# disjoint unions are coproducts of compact Hausdorff spaces　`prop.coproduct-chaus`
English entry · root `../`
[in graph](../#n=prop.coproduct-chaus)　·　[Chinese page (authoritative)](./prop.coproduct-chaus.md)

⚠️ An infinite disjoint union is in general **not** compact, so the coproduct stays in the category only for finite families; this is also why the pretopology below uses finite disjoint unions rather than arbitrary ones.
