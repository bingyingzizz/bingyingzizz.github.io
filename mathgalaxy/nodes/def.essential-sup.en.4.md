# essential supremum　`def.essential-sup`
English entry · root `../`
[in graph](../#n=def.essential-sup)　·　[Chinese page (authoritative)](./def.essential-sup.md)

What the word "essential" means: **bad values on null sets simply do not count**. For instance, if $f = 0$ a.e. but $f$ takes the value $+\infty$ on some null set, we still have $\|f\|_\infty = 0$.

⚠ $\|f\|_\infty$ differs from "$\sup |f|$": the latter can become large because of a single point on a null set.
