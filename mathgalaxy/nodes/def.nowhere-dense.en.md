## Statement · **draft**
Let $A \subseteq X$ be a topological space. Call $A$ **nowhere dense** if $(\overline{A})^\circ = \emptyset$; equivalently, every non-empty open set contains a non-empty open subset disjoint from $A$.

## Notes · **draft**
⚠️ "Nowhere dense" is not "not dense": $(0,1) \cup (1,2)$ is neither dense nor nowhere dense in $\mathbb{R}$ — the definition demands that even the closure has no interior.
