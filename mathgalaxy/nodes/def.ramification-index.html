设 p:Y→Xp : Y \to Xp:Y→X 是紧 Riemann 面之间的非常数全纯映射，q∈Yq \in Yq∈Y、p(q)=rp(q) = rp(q)=r。取 q,rq, rq,r 附近的局部坐标，把 ppp 写成

p(z)−r=(z−q)e u(z),u 在 q 附近全纯且 u(q)≠0.p(z) - r = (z - q)^{e}\, u(z), \qquad u \text{ 在 } q \text{ 附近全纯且 } u(q) \ne 0 .p(z)−r=(z−q)eu(z),u 在 q 附近全纯且 u(q)=0.

这个正整数 e=eqe = e_{q}e=eq​ 叫 ppp 在 qqq 的分歧指数（ramification index）。 eq>1e_{q} > 1eq​>1 时 qqq 叫分歧点、rrr 叫分支点；eq=1e_{q} = 1eq​=1 时 ppp 在 qqq 局部双全纯。

说明

局部形状就是 z↦zez \mapsto z^{e}z↦ze 乘一个不消失的全纯函数 —— 所以「eee 对 111」是唯一的局部模型，没有第二种可能。

⭐ 求和恒等式（RH 里那个求和的意义所在）：对每个 r∈Xr \in Xr∈X，

∑q∈p−1(r)eq=d,\sum_{q \in p^{-1}(r)} e_{q} = d ,q∈p−1(r)∑​eq​=d,

即「按分歧指数计重数的原像个数恒等于次数 ddd」。它保证了 ddd 与 rrr 无关（下面的 RH 公式要用）。

⚠️ eqe_{q}eq​ 就是零点重数：p−rp - rp−r 是 YYY 上的全纯函数（常值 rrr 的拉回），qqq 是它的 eqe_{q}eq​ 重零点。

所以「分歧」不是新现象，就是「p−rp - rp−r 的零点不单重」。

📌 对 ddd 次分支覆盖，∑q(eq−1)\sum_{q}(e_{q} - 1)∑q​(eq​−1) 是一个有限和：只有分歧点贡献（eq=1e_q = 1eq​=1 时贡献 000）。
