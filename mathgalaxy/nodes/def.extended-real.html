又称扩充实数·extended real·广义实数

陈述

在 R\mathbb{R}R 上添两个记号 +∞+\infty+∞、−∞-\infty−∞，得到扩充实数系

R‾:=R∪{−∞,+∞}\overline{\mathbb{R}} := \mathbb{R} \cup \{ -\infty, +\infty \}R:=R∪{−∞,+∞}

规定 −∞<x<+∞-\infty < x < +\infty−∞<x<+∞ 对一切 x∈Rx \in \mathbb{R}x∈R 成立，于是 R‾\overline{\mathbb{R}}R 仍是全序集；并约定

x+(±∞)=±∞,0⋅(±∞)=0x + (\pm\infty) = \pm\infty, \qquad 0 \cdot (\pm\infty) = 0x+(±∞)=±∞,0⋅(±∞)=0

而 ∞−∞\infty - \infty∞−∞ 与 ∞/∞\infty / \infty∞/∞ 不定义。

说明

为什么需要它：测度、积分的取值天然可以是 ∞\infty∞（R\mathbb{R}R 的 Lebesgue 测度就是 ∞\infty∞），把所有量都放进 R‾\overline{\mathbb{R}}R，收敛定理（sup、极限）就不必反复讨论「值是不是有限」。

⚠ 约定 0⋅∞=00 \cdot \infty = 00⋅∞=0 是刻意的：它让「在无穷测度集上取 000 的函数」积分为 000。 ⚠ 它不是域：∞\infty∞ 没有加法逆元。
