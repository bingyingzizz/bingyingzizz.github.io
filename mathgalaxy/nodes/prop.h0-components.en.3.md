# H0 and path components　`prop.h0-components`
English entry · root `../`
[in graph](../#n=prop.h0-components)　·　[Chinese page (authoritative)](./prop.h0-components.md)

**Why the boundary lands on "differences of points in the same component"**: $\partial$ acts only on a singular $1$-simplex (a path), and its image is the difference of the two endpoints; the whole path lies in one path component. So $\partial$ cannot cross components $\implies$ points in different components are linearly independent in $H_{0}$.

💡 This is the first conclusion in this pack that **computes an actual number**: $H_{0}$ is the only homology group whose answer you can write down just by looking at the space.
