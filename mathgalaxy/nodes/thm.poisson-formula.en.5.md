# Poisson integral formula　`thm.poisson-formula`
English entry · root `../`
[in graph](../#n=thm.poisson-formula)　·　[Chinese page (authoritative)](./thm.poisson-formula.md)

📌 From $P_r \ge 0$ and $\int P_r = 1$ one immediately gets: a harmonic function satisfies the **extremal inequality** $|u(z)| \le \max_{|\zeta| = r}|u(\zeta)|$, which is precisely the maximum principle.
