# Orthogonally Similar Matrices　`def.orthogonally-similar`
English entry · root `../`
[in graph](../#n=def.orthogonally-similar)　·　[Chinese page (authoritative)](./def.orthogonally-similar.md)

Let $A, B \in M_{n}(\mathbb{R})$. Call $A$ and $B$ **orthogonally similar** if there exists an **orthogonal** matrix $Q$ such that

$$B = Q^{T} A\, Q = Q^{-1} A\, Q .$$

In the complex case replace $Q$ by a **unitary** matrix $U$, obtaining **unitary similarity** $B = U^{*}AU = U^{-1}AU$.

**Why this cell matters**: orthogonal/unitary matrices satisfy $P^{-1} = P^{T}$ (or $P^{*}$) at the same time, so

orthogonal similarity = similarity + congruence (the differences among the three are explained in the notes of def.orthogonally-similar)
