## 陈述（续）
$$\cdots \to P_{1} \xrightarrow{\ d_{1}\ } P_{0} \xrightarrow{\ \varepsilon\ } M_{1} \to 0, \qquad \cdots \to Q_{1} \xrightarrow{\ e_{1
}\ } Q_{0} \xrightarrow{\ \eta\ } M_{2} \to 0 .$$
则存在 $M$ 的投射消解 $R_{\bullet} \twoheadrightarrow M$，使
1. $R_{n} = P_{n} \oplus Q_{n}$（逐项直和）；
2. 含入与投影拼成复形的短正合列 $0 \to P_{\bullet} \to R_{\bullet} \to Q_{\bullet} \to 0$，
且它**逐项分裂**；
3. 增广 $R_{0} = P_{0}\oplus Q_{0} \to M$ 由 $i\varepsilon$ 与 $\eta$ 的一个提升拼成。
三个消解拼起来的图就是**双复形**：横向是 $M$ 的消解，纵向是两端各自的消解 —— 形状像一只马蹄。
