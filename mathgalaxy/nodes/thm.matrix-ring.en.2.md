# the matrix ring　`thm.matrix-ring`
English entry · root `../`
[in graph](../#n=thm.matrix-ring)　·　[Chinese page (authoritative)](./thm.matrix-ring.md)

- $(M_n(K), +)$ is an abelian group (the zero element is the zero matrix);
- multiplication is associative, distributes over addition on both sides, and has the unit $I_n$ (with $1$ on the diagonal and $0$ elsewhere);
- hence $M_n(K)$ is a **ring**, and moreover a $K$-algebra (addition and scalar multiplication make it a $K$-vector space, and multiplication is compatible with them).

⚠ Multiplication is **not commutative** (when $n \ge 2$), so it is a noncommutative ring.
