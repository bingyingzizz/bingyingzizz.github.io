# L¹ 是向量空间　`prop.L1-vector-space`
命题：可积函数全体是向量空间，$\int$ 线性
layer 19 · 命题 · 积分 · 分析学

$X$ 上可积的（实值）函数全体构成一个**实向量空间**，并且

$$\int (af + bg) = a\int f + b\int g\quad  \forall a, b \in \mathbb{R}$$

即 $f \mapsto \int f$ 是线性的。
