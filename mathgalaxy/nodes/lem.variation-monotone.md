# T_F ± F 递增　`lem.variation-monotone`
引理：实值有界变差函数的 $T_F + F$ 与 $T_F - F$ 都递增

设 $F$ 是**实值**有界变差函数。则 $T_F + F$ 与 $T_F - F$ 都是**递增**函数，即

$$x < y \implies T_F(y)+F(y) \ge T_F(x)+F(x),\qquad T_F(y)-F(y) \ge T_F(x)-F(x) .$$
