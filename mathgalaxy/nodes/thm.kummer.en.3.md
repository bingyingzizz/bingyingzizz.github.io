# Kummer's test　`thm.kummer`
English entry · root `../`
[in graph](../#n=thm.kummer)　·　[Chinese page (authoritative)](./thm.kummer.md)

⚠ The convergence branch requires $\liminf K_n > 0$ (not $\lim K_n$, and not merely some $K_n > 0$).

⚠ The divergence branch has the extra hypothesis "$\sum 1/c_n$ diverges" — for $c_n = 1$ this is $\sum 1$, for $c_n = n$ it is the harmonic series; neither is free.
