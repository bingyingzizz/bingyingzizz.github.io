# 酉算子　`def.unitary-operator`
酉算子与部分等距
layer 14 · 定义 · Hilbert 空间 · 泛函分析
[在星图里打开](../#n=def.unitary-operator)　·　[节点索引](../index.md)

设 $u \in B(H)$。称 $u$ 是**酉算子**（unitary），若

$$u\,u^* = u^*\,u = I .$$

称 $u$ 是**部分等距**（partial isometry），若 $u\,u^*$ 与 $u^*u$ 都是正交投影。
