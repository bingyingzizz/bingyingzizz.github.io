# isomorphism　`def.isomorphism`
English entry · root `../`
[in graph](../#n=def.isomorphism)　·　[Chinese page (authoritative)](./def.isomorphism.md)

- whereas "monomorphism / epimorphism" is **another pair of concepts** — in a general category mono + epi does **not** imply isomorphism (for example, in $\mathbf{Top}$ a continuous bijection need not be a homeomorphism), so it cannot serve as the common name for isomorphism.

⚠ **"Isomorphic" is not "equal"**: isomorphic means "indistinguishable under a structure-preserving map". Almost all statements here hold only up to isomorphism (for example "$V \cong K^{n}$" rather than "$V = K^{n}$").
