# first isomorphism theorem　`thm.first-iso`
English entry · root `../`
[in graph](../#n=thm.first-iso)　·　[Chinese page (authoritative)](./thm.first-iso.md)

⭐ **The set-level prototype**: for any map $f : A \to B$, put $a \sim a' \iff f(a) = f(a')$ on $A$; then $f$ induces a **bijection** $A/{\sim} \;\to\; \operatorname{im} f$ (see "quotient set and equivalence classes"). The group version adds exactly one sentence: **after dividing by the kernel, what remains is a group**. The first two steps (well defined, bijection) are the set-level content; only the third (homomorphism) is new.
