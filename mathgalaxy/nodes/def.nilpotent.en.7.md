# Nilpotent Operator　`def.nilpotent`
English entry · root `../`
[in graph](../#n=def.nilpotent)　·　[Chinese page (authoritative)](./def.nilpotent.md)

⚠️ **Nilpotent $\ne$ rank-deficient**: $\begin{pmatrix}0&0\\0&1\end{pmatrix}$ has rank $1 < 2$ but is not nilpotent (eigenvalue $1$). The criterion is always **all eigenvalues zero**.
⚠️ **In infinite dimension "$T^{n} = 0$" fails**: the shift operator on $\ell^{2}$ has no nonzero power equal to zero (though it can be "locally nilpotent") — so that criterion must explicitly say "finite-dimensional".
