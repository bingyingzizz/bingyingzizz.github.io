陈述

设 ν\nuν 是复测度（或符号测度），∣ν∣|\nu|∣ν∣ 是它的全变差。则

(a) ∣ν(E)∣≤∣ν∣(E)|\nu(E)| \le |\nu|(E)∣ν(E)∣≤∣ν∣(E) 对一切 E∈ME \in \mathcal{M}E∈M 成立；

(b) 若 dν=fdμd\nu = f d\mudν=fdμ（即 ν≪μ\nu \ll \muν≪μ）则 d∣ν∣=∣f∣dμd|\nu| = |f| d\mud∣ν∣=∣f∣dμ，即

∣ν∣(E)=∫E∣f∣dμ|\nu|(E) = \int_E |f| d\mu∣ν∣(E)=∫E​∣f∣dμ

说明

证明。 记 ∣ν∣(E):=sup⁡{∑j∣ν(Ej)∣:E=⨆jEj 可数划分}|\nu|(E) := \sup\bigl\{\sum_{j}|\nu(E_{j})| : E = \bigsqcup_{j} E_{j} \text{ 可数划分} \bigr\}∣ν∣(E):=sup{∑j​∣ν(Ej​)∣:E=⨆j​Ej​ 可数划分}。 (a) 对任意划分，由三角不等式

∣ν(E)∣=∣∑jν(Ej)∣≤∑j∣ν(Ej)∣,|\nu(E)| = \Bigl|\sum_{j}\nu(E_{j})\Bigr| \le \sum_{j}|\nu(E_{j})|,∣ν(E)∣=​j∑​ν(Ej​)​≤j∑​∣ν(Ej​)∣,

对一切划分取上确界得 ∣ν(E)∣≤∣ν∣(E)|\nu(E)| \le |\nu|(E)∣ν(E)∣≤∣ν∣(E) ✓。 (b) 设 dν=f dμd\nu = f\,\mathrm{d}\mudν=fdμ。

  • 上界：对任意划分
∑j∣ν(Ej)∣=∑j∣∫Ejf dμ∣≤∑j∫Ej∣f∣ dμ=∫E∣f∣ dμ,\sum_{j}|\nu(E_{j})| = \sum_{j}\Bigl|\int_{E_{j}} f\,\mathrm{d}\mu\Bigr| \le \sum_{j}\int_{E_{j}}|f|\,\mathrm{d}\mu = \int_{E}|f|\,\mathrm{d}\mu,j∑​∣ν(Ej​)∣=j∑​​∫Ej​​fdμ​≤j∑​∫Ej​​∣f∣dμ=∫E​∣f∣dμ,

取上确界得 ∣ν∣(E)≤∫E∣f∣ dμ|\nu|(E) \le \int_{E}|f|\,\mathrm{d}\mu∣ν∣(E)≤∫E​∣f∣dμ ✓；

  • 下界：取只由 E∩{f≥0}E \cap \{f \ge 0\}E∩{f≥0} 与 E∩{f<0}E \cap \{f < 0\}E∩{f<0} 组成的划分，此时 ∑j∣ν(Ej)∣=∫E∣f∣ dμ\sum_{j}|\nu(E_{j})| = \int_{E}|f|\,\mathrm{d}\mu∑j​∣ν(Ej​)∣=∫E​∣f∣dμ，故上确界 ≥\ge≥ 它 ✓；

两边合起来：∣ν∣(E)=∫E∣f∣ dμ|\nu|(E) = \int_{E}|f|\,\mathrm{d}\mu∣ν∣(E)=∫E​∣f∣dμ，即 d∣ν∣=∣f∣ dμd|\nu| = |f|\,\mathrm{d}\mud∣ν∣=∣f∣dμ ✓。 不同表示的一致性：若同时有 dν=f1dμ1=f2dμ2d\nu = f_{1}d\mu_{1} = f_{2}d\mu_{2}dν=f1​dμ1​=f2​dμ2​，取公共基准 ρ:=∣ν∣+μ1+μ2\rho := |\nu| + \mu_{1} + \mu_{2}ρ:=∣ν∣+μ1​+μ2​，把两边都用链式法则换到 ρ\rhoρ 上，再用上式的上确界论证即得 ∣f1∣dμ1dρ=∣f2∣dμ2dρ|f_{1}|\frac{d\mu_{1}}{d\rho} = |f_{2}|\frac{d\mu_{2}}{d\rho}∣f1​∣dρdμ1​​=∣f2​∣dρdμ2​​ ρ\rhoρ-a.e. ✓。∎

(b) 的证法：先取 ρ=∣ν1∣+∣ν2∣\rho = |\nu_1| + |\nu_2|ρ=∣ν1​∣+∣ν2​∣ 把 ν\nuν 的两个不同表示拉到一个共同的「基准测度」上，再用 Radon–Nikodym 与链式法则把两个密度都换到 ρ\rhoρ 上。于是要证的就是

∣f1∣dμ1dρ=∣f2∣dμ2dρρ−a.e.|f_1| \frac{d\mu_1}{d\rho} = |f_2| \frac{d\mu_2}{d\rho}\quad \rho-\text{a.e.}∣f1​∣dρdμ1​​=∣f2​∣dρdμ2​​ρ−a.e.

从而 ∣f1∣dμ1=∣f2∣dμ2|f_1| d\mu_1 = |f_2| d\mu_2∣f1​∣dμ1​=∣f2​∣dμ2​ —— 说明全变差的密度与「用哪个 μ\muμ 表示 ν\nuν」无关。

由此也得到一个实用的直觉：全变差就是「把质量取绝对值之后再测一遍」。
