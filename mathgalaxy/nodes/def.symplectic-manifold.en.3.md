# Symplectic Manifold　`def.symplectic-manifold`
English entry · root `../`
[in graph](../#n=def.symplectic-manifold)　·　[Chinese page (authoritative)](./def.symplectic-manifold.md)

**Standard example**: On $\mathbb{R}^{2n} = T^{*}\mathbb{R}^{n}$ (the cotangent bundle), take

$$\omega_{0} = \sum_{i=1}^{n} dq_{i} \wedge dp_{i} ,$$

This is the phase space of classical mechanics.
