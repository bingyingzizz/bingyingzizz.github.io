又称不变多项式

陈述

在做什么：示性类要用「曲率矩阵的多项式」来算，而曲率换基会变（F↦g−1FgF \mapsto g^{-1}FgF↦g−1Fg）。所以必须挑出在共轭下不变的那些多项式 —— 它们才是几何量。

设 g=gl(k,K)\mathfrak{g} = \mathfrak{gl}(k, \mathbb{K})g=gl(k,K)（K=R\mathbb{K} = \mathbb{R}K=R 或 C\mathbb{C}C）。一个多项式函数

P:gl(k,K)⟶KP : \mathfrak{gl}(k,\mathbb{K}) \longrightarrow \mathbb{K}P:gl(k,K)⟶K

（取矩阵元的多项式，且齐次：P(λA)=λmP(A)P(\lambda A) = \lambda^{m}P(A)P(λA)=λmP(A)）叫不变多项式，若对一切可逆 ggg 有

P(g−1A g)=P(A).P(g^{-1} A\, g) = P(A) .P(g−1Ag)=P(A).

等价刻画：PPP 可写成矩阵 AAA 的特征值的对称多项式。具体地，记 cj(A)c_{j}(A)cj​(A) 为 det⁡(tI+A)=∑jcj(A) tk−j\det(tI + A) = \sum_{j} c_{j}(A)\,t^{k-j}det(tI+A)=∑j​cj​(A)tk−j 的系数（即初等对称多项式在特征值上的取值），则

P 不变  ⟺  P 是 c1,…,ck 的多项式.P\ \text{不变} \iff P\ \text{是}\ c_{1}, \ldots, c_{k}\ \text{的多项式} .P 不变⟺P 是 c1​,…,ck​ 的多项式.

两个最常用的：P1(A)=tr⁡AP_{1}(A) = \operatorname{tr} AP1​(A)=trA（c1c_{1}c1​）与 Pk(A)=det⁡AP_{k}(A) = \det APk​(A)=detA（ckc_{k}ck​）；中间那些是 tr⁡(Aj)\operatorname{tr}(A^{j})tr(Aj) 的组合。

说明

为什么“不变”是硬要求：曲率形式 FFF 是取值在 gl(k)\mathfrak{gl}(k)gl(k) 里的 2-形式，换局部标架时 F↦g−1FgF \mapsto g^{-1}FgF↦g−1Fg（逐点共轭，见 联络形式）。若 PPP 不变，则 P(F)P(F)P(F) 是标架无关的 2m2m2m-形式 —— 于是可以对它取 d\mathrm{d}d、取上同调类。这是整台装置的入口。

“不变”与“对称”的翻译：gl(k,C)\mathfrak{gl}(k,\mathbb{C})gl(k,C) 里每个矩阵可上三角化（Jordan），于是 PPP 由它在对角情形（特征值）的取值决定；共轭不变就等价于「只依赖特征值、且对置换对称」。这就是它与对称多项式的桥梁（对称多项式基本定理：齐次对称多项式 = 初等对称多项式的多项式）。

⚠️ 只对可逆 ggg 要求不变是不够的？ 不 —— 可逆元在 gl(k)\mathfrak{gl}(k)gl(k) 里稠密，多项式连续，所以对可逆 ggg 成立就自动对一切 ggg 成立。别用“ggg 是 Lie 群元素”这种更强假设。

⚠️ 实情形要注意符号：K=R\mathbb{K} = \mathbb{R}K=R 时特征值可能复，但 cj(A)c_{j}(A)cj​(A) 仍是实多项式（它们是对称多项式的实系数组合），所以不碍事。
