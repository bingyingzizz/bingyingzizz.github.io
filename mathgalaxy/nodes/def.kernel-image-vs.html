设 T:V→WT : V \to WT:V→W 线性。定义

ker⁡T:={ v∈V:T(v)=0 }⊆V,im⁡T:={ T(v):v∈V }⊆W\ker T := \{\, v \in V : T(v) = 0 \,\} \subseteq V, \qquad \operatorname{im} T := \{\, T(v) : v \in V \,\} \subseteq WkerT:={v∈V:T(v)=0}⊆V,imT:={T(v):v∈V}⊆W

分别叫 TTT 的核与像。两者都是子空间，并且

TTT 单射，当且仅当

ker⁡T={0}\ker T = \{0\}kerT={0}

TTT 满射，当且仅当 im⁡T=W\operatorname{im} T = WimT=W。

说明

⭐ 「单射   ⟺  \iff⟺ 核为零」是线性映射最好用的一条：因为 T(u)=T(v)  ⟺  T(u−v)=0T(u) = T(v) \iff T(u - v) = 0T(u)=T(v)⟺T(u−v)=0 —— 线性把「两点相同」换成了「差落在核里」。一般映射没有这个便利。

⭐ 核与像分别是「丢失的信息」与「留下来的信息」：秩-零化度定理说的就是这两块加起来正好是 VVV。

⚠ ker⁡T\ker TkerT 是 VVV 的子空间、im⁡T\operatorname{im} TimT 是 WWW 的子空间 —— 别写反。

  • 本页 ⟹ 第一同构定理（向量空间版）推出
    核 / 像 / 商空间   ⟹  \implies⟹ 第一同构定理

    令 T‾(v+ker⁡T):=T(v)\overline{T}(v + \ker T) := T(v)T(v+kerT):=T(v)。

    1. 良定义：若 v+ker⁡T=v′+ker⁡Tv + \ker T = v' + \ker Tv+kerT=v′+kerT，则 v−v′∈ker⁡Tv - v' \in \ker Tv−v′∈kerT，即 T(v−v′)=0T(v - v') = 0T(v−v′)=0，由线性得 T(v)=T(v′)T(v) = T(v')T(v)=T(v′)。所以 T‾\overline{T}T 只依赖陪集。
    2. 线性：T‾((v+ker⁡T)+c(v′+ker⁡T))=T‾((v+cv′)+ker⁡T)=T(v+cv′)=T(v)+cT(v′)\overline{T}\bigl((v + \ker T) + c(v' + \ker T)\bigr) = \overline{T}\bigl((v + cv') + \ker T\bigr) = T(v + cv') = T(v) + cT(v')T((v+kerT)+c(v′+kerT))=T((v+cv′)+kerT)=T(v+cv′)=T(v)+cT(v′)。
    3. 单射：若 T‾(v+ker⁡T)=0\overline{T}(v + \ker T) = 0T(v+kerT)=0，则 T(v)=0T(v) = 0T(v)=0，即 v∈ker⁡Tv \in \ker Tv∈kerT，于是 v+ker⁡Tv + \ker Tv+kerT 是零陪集。故 ker⁡T‾={0}\ker \overline{T} = \{0\}kerT={0}，T‾\overline{T}T 单。
    4. 满射：im⁡T‾=im⁡T\operatorname{im} \overline{T} = \operatorname{im} TimT=imT 由定义直接得到。

    四步齐备，T‾\overline{T}T 是线性同构，V/ker⁡T≅im⁡TV/\ker T \cong \operatorname{im} TV/kerT≅imT。∎

    四步的顺序值得记住：先良定义、再线性、再单、再满。所有「商掉之后构造映射」的证明都是这个骨架 —— 群、环、模、拓扑空间（商拓扑）一模一样。

  • 本页 ⟹ 线性方程组的解结构推出
    秩-零化度   ⟹  \implies⟹ 线性方程组的解结构

    记 T:Kn→KmT : K^{n} \to K^{m}T:Kn→Km、x↦Axx \mapsto Axx↦Ax。

    有解判据：Ax=bAx = bAx=b 有解   ⟺  \iff⟺ b∈im⁡Tb \in \operatorname{im} Tb∈imT。而 im⁡T\operatorname{im} TimT 就是 AAA 的列空间，其维数是列秩；把 bbb 添成一列不改变列空间的维数当且仅当 bbb 落在其中 —— 即 rank⁡A=rank⁡(A∣b)\operatorname{rank} A = \operatorname{rank}(A \mid b)rankA=rank(A∣b)。

    解的结构：若 x0x_0x0​ 是一个解，则对任意 u∈ker⁡Tu \in \ker Tu∈kerT，A(x0+u)=bA(x_0 + u) = bA(x0​+u)=b，所以 x0+ker⁡T⊆x_0 + \ker T \subseteqx0​+kerT⊆ 解集。反之若 xxx 也是解，则 A(x−x0)=0A(x - x_0) = 0A(x−x0​)=0，即 x−x0∈ker⁡Tx - x_0 \in \ker Tx−x0​∈kerT，故 x∈x0+ker⁡Tx \in x_0 + \ker Tx∈x0​+kerT。两边相等。

    维数：由秩-零化度定理，dim⁡ker⁡T=n−rank⁡A\dim \ker T = n - \operatorname{rank} AdimkerT=n−rankA；平移不改变「维数」（仿射子空间与 ker⁡T\ker TkerT 同维）。

    唯一性：det⁡A≠0\det A \ne 0detA=0 时 ker⁡T={0}\ker T = \{0\}kerT={0}，解集是单点集 {A−1b}\{A^{-1}b\}{A−1b}。∎

    第 2 段是纯集合论的：解集 = 一个特解 + 全体齐次解。它对任何群同态、任何环同态都成立 —— 「非齐次解 = 特解 + 齐次解」是这一招的通用形态。
