# sequence of morphisms　`def.sequence-of-morphisms`
English entry · root `../`
[in graph](../#n=def.sequence-of-morphisms)　·　[Chinese page (authoritative)](./def.sequence-of-morphisms.md)

Example: a sequence in $\mathbf{Ab}$ is a string of group homomorphisms; for $\mathcal{C} = \mathbf{Vect}_{k}$ it is a string of linear maps.

Finite sequences (only finitely many nonzero terms) and one-sided sequences (given only for $n \ge 0$, with values $K^{n}$) are common variants; by default this graph uses two-sided infinite sequences, since complexes in homological algebra are usually indexed in both directions.
