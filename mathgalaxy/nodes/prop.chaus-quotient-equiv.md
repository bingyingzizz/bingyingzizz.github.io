# 紧 Hausdorff 上商映射的四种说法　`prop.chaus-quotient-equiv`
命题：商映射 $\iff$ 正则满 $\iff$ 满态射 $\iff$ 满射
layer 16 · 命题 · 紧 Hausdorff 空间 · 拓扑学
[在星图里打开](../#n=prop.chaus-quotient-equiv)　·　[节点索引](../index.md)

设 $\pi : S \to T$ 是**紧 Hausdorff** 空间之间的连续映射。以下四条等价：

1. $\pi$ 是**商映射**；
2. $\pi$ 是**正则满态射**；
3. $\pi$ 是**满态射**；
4. $\pi$ 是**满射**。
