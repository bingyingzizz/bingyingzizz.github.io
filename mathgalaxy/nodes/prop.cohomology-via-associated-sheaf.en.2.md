# Cohomology via the Associated Sheaf　`prop.cohomology-via-associated-sheaf`
English entry · root `../`
[in graph](../#n=prop.cohomology-via-associated-sheaf)　·　[Chinese page (authoritative)](./prop.cohomology-via-associated-sheaf.md)

$$\mathrm{R}\Gamma\bigl(X,\ M^{\bullet}\bigr) \;=\; \mathrm{R}\Gamma\bigl(\underline{X},\ M^{\bullet}\bigr), \qquad \mathrm{H}^{n}\bigl(\underline{X},\ M^{\bullet}\bigr) = \mathrm{H}^{n}\bigl(X,\ M^{\bullet}\bigr).$$

## Notes · **draft**
**Proof.** For any sheaf $M$, the universal property of the associated sheaf gives $\operatorname{Hom}(\underline{X}, M) = M(X) = \operatorname{Hom}(X, M)$ ✓, that is, $\Gamma(X, M) = \Gamma(\underline{X}, M)$.
