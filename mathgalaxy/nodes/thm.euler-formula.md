# Euler 公式　`thm.euler-formula`
定理：$e^{i\theta} = \cos\theta + i\sin\theta$
layer 17 · 定理 · 函数列、幂级数与初等函数 · 分析学
[在星图里打开](../#n=thm.euler-formula)　·　[节点索引](../index.md)

对一切实数（或复数）$\theta$，

$$\exp(i\theta) = e^{i\theta} = \cos\theta + i\sin\theta$$

特别地 $e^{i\pi} = -1$。
