# 严格凸　`def.strictly-convex`

称赋范空间 $(X, \|\cdot\|)$ **严格凸**（strictly convex），若单位球面不含线段：

$\|x\| = \|y\| = 1,\quad x \ne y \implies \left\|\frac{x + y}{2}\right\| < 1 .$
