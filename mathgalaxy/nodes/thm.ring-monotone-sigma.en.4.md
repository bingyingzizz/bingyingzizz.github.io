# when a ring is a sigma-ring　`thm.ring-monotone-sigma`
English entry · root `../`
[in graph](../#n=thm.ring-monotone-sigma)　·　[Chinese page (authoritative)](./thm.ring-monotone-sigma.md)

This theorem is the technical core of the monotone class theorem: it is precisely what lets one reduce "true for all $\sigma$-algebras" to "first verify it on a ring, then pass to monotone limits".
