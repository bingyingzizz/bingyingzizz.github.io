# One-Point Compactification　`def.one-point-compactification`
English entry · root `../`
[in graph](../#n=def.one-point-compactification)　·　[Chinese page (authoritative)](./def.one-point-compactification.md)

⚠️ **Why neighbourhoods of $\infty$ look like that**: "compact complement" in the second axiom is not arbitrary — if the neighbourhood is $U\cup\{\infty\}$, then points "running to infinity" must eventually lie in $U$, i.e. eventually leave $X\setminus U$; requiring $X\setminus U$ to be compact is exactly what aligns "leaving it" with "compactness", making $X^{*}$ compact.
