## Notes · **draft**
**Well-definedness is the chain rule**: changing the chart $\varphi$ to $\theta$, two curves through $p$ with the same velocity in the $\varphi$-chart have the same velocity in the $\theta$-chart (both equal the same Jacobian matrix times the same vector).

Class is invariant, so $\mathrm{d}F_{p}$ is defined — but **existence** rests entirely on smoothness of transition maps, which is where this node meets the previous two.
