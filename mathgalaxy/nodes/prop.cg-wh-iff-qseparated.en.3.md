# weak Hausdorff iff quasi-separated　`prop.cg-wh-iff-qseparated`

⭐ **What they add up to**: within the compactly generated range, the **topological** condition "weakly Hausdorff" and the **sheaf-theoretic** condition "quasi-separated" say the same thing. So $\mathrm{CGWH}$, the habitat of this whole homotopy theory, acquires a purely sheaf-theoretic name in the condensed world.
