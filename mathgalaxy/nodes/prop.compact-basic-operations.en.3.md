# basic operations on compact spaces　`prop.compact-basic-operations`
English entry · root `../`
[in graph](../#n=prop.compact-basic-operations)　·　[Chinese page (authoritative)](./prop.compact-basic-operations.md)

$A$ is compact, so finitely many cover it, $A$; set $U := \bigcup_{i} U_{a_i}$, then $\overline{U} \cap B = \emptyset$ ✓;

perform the same construction for $B$, then shrink both families of open sets by one step to obtain open sets separating $A, B$ ✓.

∎
