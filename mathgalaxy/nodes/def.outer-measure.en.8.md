# outer measure　`def.outer-measure`
English entry · root `../`
[in graph](../#n=def.outer-measure)　·　[Chinese page (authoritative)](./def.outer-measure.md)

- **An outer measure is defined on $\mathcal{P}(X)$** (all subsets), whereas a measure (`def.measure`) is defined only on a $\sigma$-algebra \u2014 that is the whole point of an outer measure as a **construction device**: first put a crude "size" on all subsets, then single out the subsets on which it is additive.
- **Monotone plus countably subadditive does not say "the value on a countable union is the limit"**: on increasing unions an outer measure only guarantees $\mu^{*}(\bigcup A_{n}) \le \lim \mu^{*}(A_{n})$; equality needs continuity from below, hence measurability \u2014 exactly what the Carath\u00E9odory condition supplies.
