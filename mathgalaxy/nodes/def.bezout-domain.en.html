Statement

A domain AAA is called a Bézout domain if every finitely generated ideal is principal — equivalently: for any a,b∈Aa, b \in Aa,b∈A there exist d,u,vd, u, vd,u,v such that

ua+vb=d=gcd⁡(a,b).u a + v b = d = \gcd(a, b) .ua+vb=d=gcd(a,b).

Notes

PID   ⟹  \implies⟹ Bézout (every ideal is principal, so certainly every finitely generated one is), but not conversely: a Bézout domain need not be Noetherian, and may have ideals that are not finitely generated.

Z[x]\mathbb{Z}[x]Z[x] is not Bézout: gcd⁡(2,x)=1\gcd(2, x) = 1gcd(2,x)=1, but 2u+xv=12u + xv = 12u+xv=1 has no solution (set x=0x = 0x=0 to get 2u(0)=12u(0) = 12u(0)=1) — so the "Bézout property" is stronger than being a gcd domain.

In a Bézout domain "irreducible = prime" (because gcd⁡\gcdgcd is given by a linear combination, so the proof of Euclid's lemma carries over directly).
