## Statement · **draft**
- $X$ is **totally disconnected** if every connected component is a single point;
- $X$ is **extremally disconnected** if the **closure of every open set is again clopen**;
- a **Stone space** = a totally disconnected compact Hausdorff space;
- a **Stonean space** = an extremally disconnected compact Hausdorff space.
