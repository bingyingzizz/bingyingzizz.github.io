# exact functor　`def.exact-functor`
English entry · root `../`
[in graph](../#n=def.exact-functor)　·　[Chinese page (authoritative)](./def.exact-functor.md)

**Better in abelian categories**: $F$ is left exact $\iff$ it preserves kernels ($F(\ker) = \ker$); $F$ is exact $\iff$ it sends short exact sequences to short exact sequences.

⚠️ The name is ambiguous: some books use "exact" for preserving **finite** limits and others for **all** limits. This graph follows the definition above (finite limits/colimits).
