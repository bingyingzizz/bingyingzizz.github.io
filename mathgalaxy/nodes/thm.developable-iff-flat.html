又称可展的判据

陈述

在做什么：给出「直纹面可不可展」的可操作判据 —— 一条行列式恒等式，不必解偏微分方程。

设 X(u,v)=a(u)+v b(u)X(u,v) = a(u) + v\,b(u)X(u,v)=a(u)+vb(u) 是直纹面（直纹面）。则下列等价：

  1. 沿每条母线切平面不变（法向量与 vvv 无关）；
  2. det⁡(a′(u), b(u), b′(u))=0\det\bigl(a'(u),\ b(u),\ b'(u)\bigr) = 0det(a′(u), b(u), b′(u))=0 对一切 uuu；
  3. 高斯曲率恒为零：K≡0K \equiv 0K≡0；
  4. 可展（局部等距于平面，可展曲面）。

用法：把 a,ba, ba,b 代进那个三阶行列式即可。圆柱面 b′=0b' = 0b′=0 故可展；双曲抛物面 X=(u,v,uv)X = (u,v,uv)X=(u,v,uv) 的行列式为 1≠01 \ne 01=0，不可展。

说明

证明骨架：

  • (1) 与 (2)：N∝Xu×Xv=a′×b+v (b′×b)N \propto X_u \times X_v = a'\times b + v\,(b'\times b)N∝Xu​×Xv​=a′×b+v(b′×b)；要求与 vvv 无关，即 b′×bb'\times bb′×b 与 a′×ba'\times ba′×b 平行，等价于 det⁡(a′,b,b′)=0\det(a',b,b') = 0det(a′,b,b′)=0。
  • (2) 与 (3)：由 K=det⁡(hij)/det⁡(gij)K = \det(h_{ij})/\det(g_{ij})K=det(hij​)/det(gij​) 直接算，直纹面上 det⁡(hij)\det(h_{ij})det(hij​) 与 det⁡(a′,b,b′)2\det(a',b,b')^{2}det(a′,b,b′)2 差一个符号（未必是正因子：X=(u,v,uv)X = (u,v,uv)X=(u,v,uv) 给出 det⁡h=−1\det h = -1deth=−1，而 det⁡(a′,b,b′)2>0\det(a',b,b')^{2} > 0det(a′,b,b′)2>0）—— 但「等于零」不受符号影响，故 K≡0K \equiv 0K≡0 仍等价于行列式恒为零。只用第二基本形式的具体计算。
  • (3) 与 (4)：K≡0K \equiv 0K≡0 时由常曲率曲面的局部分类（常 Gauss 曲率曲面 中 K=0K = 0K=0 情形）得局部等距于平面；反向由 Gauss 绝妙定理（KKK 是等距不变量，平面的 KKK 为零）。

⚠️ 含平坦点时第 1 条与第 4 条会脱钩：存在 K≡0K \equiv 0K≡0、含成片平坦点、却写不成「沿母线切平面不变」的曲面。所以第 4 条应读作「局部等距于平面」，它恒成立。

⚠️ 别把「可展」与「极小曲面」搞混：后者是 H=0H = 0H=0（KKK 一般不为零），平面是两者唯一交点。
