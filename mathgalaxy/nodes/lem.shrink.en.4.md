# Shrinking Lemma　`lem.shrink`
English entry · root `../`
[in graph](../#n=lem.shrink)　·　[Chinese page (authoritative)](./lem.shrink.md)

If $x \in U_{k}$ for some $k \ge i$, the point is already covered.

Otherwise, $x \notin U_{k}$ for every $k \ge i$, and the cover $\mathcal{W}_{i}$ gives some $j < i$ such that $x \in U_{j}$.

By **point finiteness** (locally finite $\implies$ point finite), $J := \{\, j < i : x \in U_{j} \,\}$ is finite and nonempty.
