# uniqueness of the Jordan form　`cor.jordan-uniqueness`
English entry · root `../`
[in graph](../#n=cor.jordan-uniqueness)　·　[Chinese page (authoritative)](./cor.jordan-uniqueness.md)

More quantitatively: for each eigenvalue $\lambda$, the **sizes** of the Jordan blocks form a partition $\mu(\lambda)$; two matrices are similar if and only if, for every $\lambda$, $\mu_A(\lambda) = \mu_B(\lambda)$.

## Notes · **draft**
⭐ The practical form of uniqueness: **the number of blocks = geometric multiplicity** ($\dim E_\lambda$), **the largest block size = the multiplicity of $\lambda$ in the minimal polynomial**, **the sum of the sizes = algebraic multiplicity**.

Thus "classification up to similarity" is compressed into a set of integer partitions.
