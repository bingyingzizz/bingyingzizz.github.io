# kernels and cokernels in Hausdorff topological abelian groups　`prop.abhaus-strict-exact`
English entry · root `../`
[in graph](../#n=prop.abhaus-strict-exact)　·　[Chinese page (authoritative)](./prop.abhaus-strict-exact.md)

1. For a continuous homomorphism $f : M \to N$, the kernel is $\ker f = f^{-1}(0)$ (with the subspace topology) and the cokernel is $\operatorname{coker} f = N/\overline{f(M)}$ (with the quotient topology);
2. A continuous homomorphism is a kernel $\iff$ it is a **homeomorphic embedding onto a closed subgroup**, and it is a cokernel $\iff$ it is an **open surjection**;
