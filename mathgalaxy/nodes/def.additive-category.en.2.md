# additive category　`def.additive-category`
English entry · root `../`
[in graph](../#n=def.additive-category)　·　[Chinese page (authoritative)](./def.additive-category.md)

1. it has a **zero object** ($\operatorname{End}(M) = 1$, i.e. an object with $1_{M} = 0_{M}$, see @@def.zero-object@@);
2. any two objects have a **direct sum** $M = M_{1} \oplus M_{2}$: there exist morphisms $p_{k} : M \to M_{k}$, $i_{k} : M_{k} \to M$ such that $p_{1} i_{1} = 1_{M_{1}}$, $p_{2} i_{2} = 1_{M_{2}}$, $i_{1} p_{1} + i_{2} p_{2} = 1_{M}$.

Equivalently: an additive category is a preadditive category in which finite products and finite coproducts exist and coincide (biproducts).
