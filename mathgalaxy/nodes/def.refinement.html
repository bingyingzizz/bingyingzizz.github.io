不要求指标集相同，也不要求单射：多个 VsV_{s}Vs​ 可以落在同一个 UiU_{i}Ui​ 里。若 V\mathcal{V}V 的成员全是开集（闭集），叫开加细（闭加细）；若 V\mathcal{V}V 作为族局部有限（σ\sigmaσ-局部有限、离散），就叫局部有限加细（相应地 σ\sigmaσ-局部有限加细、离散加细）。

说明

「加细」和「局部有限」是两条独立的要求，这才是仿紧不平凡的原因：

  • 想细就能细：{ {x}:x∈X }\{\, \{ x \} : x \in X \,\}{{x}:x∈X} 永远是最细的加细；
  • 想局部有限也不难：{ X }\{\, X \,\}{X} 只有一个成员，当然局部有限；
  • 但要同时又细、又开、又局部有限，就等价于仿紧 —— 仿紧因此是一条真正的结构条件，而不是可以随手满足的技术语。

⚠️ 加细是覆盖之间的关系，不是集合之间的包含：V\mathcal{V}V 加细 U\mathcal{U}U 时，V\mathcal{V}V 完全可以有更多、更小的成员。
