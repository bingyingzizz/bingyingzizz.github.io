# 三角的旋转与延拓　`prop.triangle-rotation`　·　续页（第 2 页）
根 `../`　·　第 1 页 `nodes/prop.triangle-rotation.md`

## 陈述（续）
1. $K \xrightarrow{\ 1\ } K \to 0 \to K[1]$ 是导出三角；
2. **旋转**：$K \xrightarrow{\ f\ } L \xrightarrow{\ g\ } M \xrightarrow{\ h\ } K[1]$ 导出 $\iff$ 旋转后的 $L \xrightarrow{\ g\ } M \xright
arrow{\ h\ } K[1] \xrightarrow{\ -f[1]\ } L[1]$ 导出；
3. 任意 $f : K \to L$ 都能（**不唯一**地）嵌入一个导出三角；
4. 导出三角之间的态射可以（**不唯一**地）延拓。
