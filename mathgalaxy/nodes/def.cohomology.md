# 同调　`def.cohomology`
同调（Cohomology）

[在星图里打开](../#n=def.cohomology)　·　[节点索引](../index.md)

设 $\mathcal{A}$ 是阿贝尔范畴，$K$ 是 $\mathcal{A}$ 中的上链复形。$K$ 的**第 $n$ 阶同调**是

$$H^{n}(K) \;:=\; Z^{n}(K) \big/ B^{n}(K) \;=\; \ker d^{n} \big/ \operatorname{im} d^{n-1}$$

链复形 $K_{n}$ 的第 $n$ 阶同调取它在 $\mathcal{A}^{\mathrm{op}}$ 中的 $(1-n)$ 阶上同调。
