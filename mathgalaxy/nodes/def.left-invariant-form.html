又称左不变形式

陈述

白话：Lie 群上的微分形式如果对左平移「纹丝不动」，它就被单位元处的一个多重线性型完全决定 —— 于是 GGG 上的左不变 kkk-形式与 ⋀kg∗\bigwedge^{k}\mathfrak{g}^{\ast}⋀kg∗ 是同一个东西。

设 GGG 是 nnn 维 Lie 群（def.lie-group），g=TeG\mathfrak{g} = T_{e}Gg=Te​G，LgL_{g}Lg​ 是左平移。kkk-形式 ω∈Ωk(G)\omega \in \Omega^{k}(G)ω∈Ωk(G) 叫左不变，如果

Lg∗ω=ω(g∈G),L_{g}^{\ast}\omega = \omega\qquad (g \in G),Lg∗​ω=ω(g∈G),

等价地 ωg(v1,…,vk)=ωe(d(Lg−1)gv1,…,d(Lg−1)gvk)\omega_{g}(v_{1},\ldots,v_{k}) = \omega_{e}\bigl(\mathrm{d}(L_{g^{-1}})_{g}v_{1},\ldots,\mathrm{d}(L_{g^{-1}})_{g}v_{k}\bigr)ωg​(v1​,…,vk​)=ωe​(d(Lg−1​)g​v1​,…,d(Lg−1​)g​vk​) —— 即 ω\omegaω 在 GGG 上的值由 ωe\omega_{e}ωe​ 唯一决定。于是赋值

ω⟼ωe\omega \longmapsto \omega_{e}ω⟼ωe​

是「左不变 kkk-形式」的空间到 ⋀kg∗\bigwedge^{k}\mathfrak{g}^{\ast}⋀kg∗ 的线性同构，维数为 (nk)\binom{n}{k}(kn​)。

左不变余标架：取 g\mathfrak{g}g 的基 e1,…,ene_{1},\ldots,e_{n}e1​,…,en​ 与对偶基 ωe1,…,ωen\omega^{1}_{e},\ldots,\omega^{n}_{e}ωe1​,…,ωen​（ωei(ej)=δ ji\omega^{i}_{e}(e_{j}) = \delta^{i}_{\ j}ωei​(ej​)=δ ji​），把它们左平移出去：

ωgi:=d(Lg−1)e∗ ωei,ωgi((e~j)g)=δ ji,\omega^{i}_{g} := \mathrm{d}(L_{g^{-1}})^{\ast}_{e}\,\omega^{i}_{e},\qquad \omega^{i}_{g}\bigl((\tilde e_{j})_{g}\bigr) = \delta^{i}_{\ j},ωgi​:=d(Lg−1​)e∗​ωei​,ωgi​((e~j​)g​)=δ ji​,

其中 e~j\tilde e_{j}e~j​ 是 eje_{j}ej​ 对应的左不变向量场（prop.left-invariant-fields）。这组 ω1,…,ωn\omega^{1},\ldots,\omega^{n}ω1,…,ωn 叫左不变余标架，结构常数由 [ej,ek]=∑ic jkiei[e_{j},e_{k}] = \sum_{i}c^{i}_{\ jk}e_{i}[ej​,ek​]=∑i​c jki​ei​ 定义。

说明

为什么赋值是同构：左不变性取 h=eh = eh=e 得 ωg(d(Lg)ew)=ωe(w)\omega_{g}(\mathrm{d}(L_{g})_{e}w) = \omega_{e}(w)ωg​(d(Lg​)e​w)=ωe​(w)，故 ωg=d(Lg−1)∗ωe\omega_{g} = \mathrm{d}(L_{g^{-1}})^{\ast}\omega_{e}ωg​=d(Lg−1​)∗ωe​，即 ω\omegaω 由 ωe\omega_{e}ωe​ 决定（单射）。反向：给定 α∈⋀kg∗\alpha \in \bigwedge^{k}\mathfrak{g}^{\ast}α∈⋀kg∗ 令 ωg:=d(Lg−1)∗α\omega_{g} := \mathrm{d}(L_{g^{-1}})^{\ast}\alphaωg​:=d(Lg−1​)∗α，则 Lh∗ω=ωL_{h}^{\ast}\omega = \omegaLh∗​ω=ω，因为

L(hg)−1=Lg−1∘Lh−1,Lh−1∘Lh=id⁡,L_{(hg)^{-1}} = L_{g^{-1}}\circ L_{h^{-1}},\qquad L_{h^{-1}}\circ L_{h} = \operatorname{id},L(hg)−1​=Lg−1​∘Lh−1​,Lh−1​∘Lh​=id,

两个左平移把 d(Lh)\mathrm{d}(L_{h})d(Lh​) 吃掉，恰好还原。所以 ω↦ωe\omega \mapsto \omega_{e}ω↦ωe​ 是双射，线性显然。

与左不变向量场互为对偶：prop.left-invariant-fields 说左不变向量场与 g\mathfrak{g}g 同构；这里说左不变 kkk-形式与 ⋀kg∗\bigwedge^{k}\mathfrak{g}^{\ast}⋀kg∗ 同构。k=1k = 1k=1 时两组互为对偶基 —— 这正是活动标架法（def.moving-frame）在群上的版本：标架自身不动，动的只是点。

可定向性：k=nk = nk=n 时 ⋀ng∗\bigwedge^{n}\mathfrak{g}^{\ast}⋀ng∗ 一维，取非零元左平移出去得到一个处处非零的 nnn-形式，由 prop.volume-form-orientation 得每个 Lie 群都可定向（S1S^{1}S1、SO⁡(3)\operatorname{SO}(3)SO(3)、GL⁡(n,R)\operatorname{GL}(n,\mathbb{R})GL(n,R) 都如此，而一般流形未必）。

Haar 测度的那一半：ω1∧⋯∧ωn\omega^{1}\wedge\cdots\wedge\omega^{n}ω1∧⋯∧ωn 是左不变的体积形式，它的绝对值给出左不变测度（Haar 测度）。紧群上左不变与右不变只差一个常数（模函数），非紧时未必 —— 本图只用形式这一面。

⚠️ 左不变形式与左不变向量场是两族不同的对象，都记下标 ggg，别混：前者的分量矩阵是 Jacobi 矩阵的逆转置，后者是 Jacobi 矩阵本身。

    两边都是左不变的 222-形式。 左边：d(Lh∗ωi)=Lh∗dωi\mathrm{d}(L_{h}^{\ast}\omega^{i}) = L_{h}^{\ast}\mathrm{d}\omega^{i}d(Lh∗​ωi)=Lh∗​dωi（拉回与外微分交换，prop.pullback-forms），而 Lh∗ωi=ωiL_{h}^{\ast}\omega^{i} = \omega^{i}Lh∗​ωi=ωi，故 Lh∗dωi=dωiL_{h}^{\ast}\mathrm{d}\omega^{i} = \mathrm{d}\omega^{i}Lh∗​dωi=dωi。右边：ωj∧ωk\omega^{j}\wedge\omega^{k}ωj∧ωk 由左不变形式组成，也左不变。所以只需在一点（或在一组左不变基上）比较。

    取左不变向量场比较。 令 X=e~jX = \tilde e_{j}X=e~j​、Y=e~kY = \tilde e_{k}Y=e~k​。ωi(e~l)=δ li\omega^{i}(\tilde e_{l}) = \delta^{i}_{\ l}ωi(e~l​)=δ li​ 是常数，故预备公式前两项为零，

    dωi(e~j,e~k)=−ωi([e~j,e~k])=−ωi(∑lc jkle~l)=−c jki,\mathrm{d}\omega^{i}(\tilde e_{j},\tilde e_{k}) = -\omega^{i}\bigl([\tilde e_{j},\tilde e_{k}]\bigr) = -\omega^{i}\Bigl(\sum_{l}c^{l}_{\ jk}\tilde e_{l}\Bigr) = -c^{i}_{\ jk},dωi(e~j​,e~k​)=−ωi([e~j​,e~k​])=−ωi(l∑​c jkl​e~l​)=−c jki​,

    其中第二个等号用了 [e~j,e~k][\tilde e_{j},\tilde e_{k}][e~j​,e~k​] 左不变（prop.left-invariant-fields 第 2 条），因而可以按 g\mathfrak{g}g 的基展开。

    右边同一点的值。 由 (ωa∧ωb)(e~j,e~k)=δ jaδ kb−δ kaδ jb(\omega^{a}\wedge\omega^{b})(\tilde e_{j},\tilde e_{k}) = \delta^{a}_{\ j}\delta^{b}_{\ k} - \delta^{a}_{\ k}\delta^{b}_{\ j}(ωa∧ωb)(e~j​,e~k​)=δ ja​δ kb​−δ ka​δ jb​，
