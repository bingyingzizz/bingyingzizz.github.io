The **wedge product** is defined pointwise: $(\omega\wedge\eta)_{p} := \omega_{p}\wedge\eta_{p}$, so $\Omega^{\bullet}(U)$ is a graded commutative algebra.

## Notes · **draft**
**Relation to the exterior algebra**: at each point $\omega_{p}\in\bigwedge^{k}(\mathbb{R}^{n})^{\ast}$, so a $k$-form is "a smooth function with values in $\bigwedge^{k}(\mathbb{R}^{n})^{\ast}$".

The exterior algebra supplies the algebraic structure, smoothness the analytic structure;

only together do they allow the definition of $\mathrm{d}$ (`def.exterior-derivative`).
