Statement draft

A function f:G→Ff:G\to Ff:G→F is a class function if f(hgh−1)=f(g)f(hgh^{-1})=f(g)f(hgh−1)=f(g) for all g,h∈Gg,h\in Gg,h∈G; equivalently, fff is constant on conjugacy classes. Group characters are class functions.

Notes draft

Class functions form an FFF-vector space of dimension the number of conjugacy classes, #CL(G)\#\mathrm{CL}(G)#CL(G). When char⁡F=0\operatorname{char}F=0charF=0 (or char⁡F∤∣G∣\operatorname{char}F\nmid|G|charF∤∣G∣), characters of pairwise non-isomorphic irreducible representations are linearly independent (orthogonality relations). A class function is determined by its values on conjugacy classes. The centralizer of ggg is the stabilizer of ggg under conjugation.
