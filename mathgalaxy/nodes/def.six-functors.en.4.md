## Notes · **draft**
⭐ The first four functors $\otimes, \operatorname{Hom}, f^*, f_*$ are usually easy to construct; **all the difficulty is in $f_!$**.

The classical example is $\ell$-adic sheaves $D_{\mathrm{et}}(X, \mathbb{Z}_\ell)$ and condensed/solid sheaves.

⭐ Once $f_!$ exists, $f^!$ is given by adjunction.

Conversely, $f_!$ is determined by "open immersion + proper map + Nagata compactification": for $f = \bar f \circ j$ one has $f_! = \bar f_* j_!$.

So what really must be constructed is only **$j_!$ for open immersions** (see `prop.open-immersion-shriek`).
