# Stokes' Formula on a Single Cube　`lem.single-cube-stokes`
English entry · root `../`
[in graph](../#n=lem.single-cube-stokes)　·　[Chinese page (authoritative)](./lem.single-cube-stokes.md)

**⚠️ Measure-zero sets on the boundary**: The form $\eta$ need only be defined on an open set and continuous up to the boundary. The facewise pullbacks use the values of $\eta$ on each face, and $\partial I^{k}$ has measure zero, so the integrals are independent of the choice of extension.

**Relation to the classical formulas**: When $k = 2$, this is Green's theorem. When $k = 3$, it is the Kelvin–Stokes theorem in circulation form. Both are special cases of this lemma.
