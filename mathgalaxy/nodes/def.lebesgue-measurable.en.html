Statement

For f:R→Cf : \mathbb{R} \to \mathbb{C}f:R→C:

  • if fff is (L,BC)(\mathcal{L}, \mathfrak{B}_\mathbb{C})(L,BC​)-measurable, fff is called Lebesgue measurable (L\mathcal{L}L is the LebesgueσLebesgue \sigmaLebesgueσ-algebra);
  • if fff is (BR,BC)(\mathfrak{B}_\mathbb{R}, \mathfrak{B}_\mathbb{C})(BR​,BC​)-measurable, fff is called Borel measurable.

Notes

⚠ There is a trap here: the composition of two Lebesgue measurable functions need not be Lebesgue measurable.

The reason: making the composition work requires the intermediate σ\sigmaσ-algebra to cooperate, and L\mathcal{L}L is strictly larger than BR\mathfrak{B}_\mathbb{R}BR​.

Take f:R→RLebesguef : \mathbb{R} \to \mathbb{R} Lebesguef:R→RLebesgue and g:R→RLebesgueg : \mathbb{R} \to \mathbb{R} Lebesgueg:R→RLebesgue measurable; then g∘fg\circ fg∘f need not be measurable with respect to L\mathcal{L}L — because g−1g^{-1}g−1 only guarantees pulling sets in BR\mathfrak{B}_\mathbb{R}BR​ back to L\mathcal{L}L, whereas f−1f^{-1}f−1 needs a non-Borel Lebesgue measurable set in R\mathbb{R}R to produce a failure.

The standard fix: make the intermediate function Borel measurable. If ggg is Borel measurable and fff is Lebesgue measurable, then g∘fg\circ fg∘f is Lebesgue measurable.
