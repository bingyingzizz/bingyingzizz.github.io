# Moore-Penrose Pseudoinverse　`def.pseudoinverse`
English entry · root `../`
[in graph](../#n=def.pseudoinverse)　·　[Chinese page (authoritative)](./def.pseudoinverse.md)

where $\Sigma^{+}$ is obtained by taking the reciprocals of the nonzero diagonal entries of $\Sigma$ and then transposing.

**When $A$ is invertible**, $A^{+} = A^{-1}$. If $A$ has full column rank, then $A^{+} = (A^{*}A)^{-1}A^{*}$ (the least-squares solution is $x = A^{+}b$).
