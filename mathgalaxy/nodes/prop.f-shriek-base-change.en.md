## Statement · **draft**
In plain words: **$f^!$ need not be built separately — it is "first pull back by $f^*$, then multiply by a fixed object $f^!R$"**. This fixed object is called the **dualizing complex** (a twist: $f^*$ is twisted). Thus computing the dual is reduced to computing one complex $f^!R$; the next two nodes compute this complex (regular closed immersion, smooth map).
