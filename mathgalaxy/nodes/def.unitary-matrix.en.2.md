# Unitary and Orthogonal Matrices　`def.unitary-matrix`
English entry · root `../`
[in graph](../#n=def.unitary-matrix)　·　[Chinese page (authoritative)](./def.unitary-matrix.md)

⚠️ For finite order **this single equation suffices**: $U^{*}U = I$ already shows that $U$ is injective, and a square matrix that is injective is invertible, so $U^{*} = U^{-1}$; right-multiplying by $U$ gives $UU^{*} = I$ (the same argument with $UU^{*} = I$). Equivalently $U^{-1} = U^{*}$. A real square matrix $Q \in M_{n}(\mathbb{R})$ satisfying $Q^{T}Q = I$ is called an **orthogonal matrix**.

**Equivalent characterizations**: the following three are equivalent — (i) $U$ is unitary; (ii) the **columns** of $U$ form an orthonormal basis; (iii) for all $x, y$, $\langle Ux, Uy\rangle = \langle x, y\rangle$.
