# Lagrange's theorem　`thm.lagrange`
English entry · root `../`
[in graph](../#n=thm.lagrange)　·　[Chinese page (authoritative)](./thm.lagrange.md)

⚠ **The converse fails**: "$d \mid |G|$ $\implies$ has a subgroup of order $d$" is **false**.

Smallest counterexample: $|A_4| = 12$, $6 \mid 12$, yet $A_4$ has no subgroup of order $6$ (a subgroup of order $6$ would have index $2$ and hence be normal, while the only normal subgroups of $A_4$ are $V_4$ and $A_4$).

So divisibility is only a necessary condition — a partial converse requires Sylow's theorem.
