# Connected Locally Compact to Discrete Has Only First Ext　`ex.connected-lc-ext`

**Idea of proof**: a connected locally compact abelian group splits as "compact connected part $\oplus$ real vector space"; for the real vector space part use "real vector spaces $\to$ discrete are all zero", and for the compact connected part use compact-group techniques.

⭐ This is a key component of the "$N$ discrete" branch of the main theorem.
