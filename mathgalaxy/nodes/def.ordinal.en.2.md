# ordinal　`def.ordinal`
English entry · root `../`
[in graph](../#n=def.ordinal)　·　[Chinese page (authoritative)](./def.ordinal.md)

By transitivity, **every element of $\alpha$ is itself an ordinal**. Conventions: $0 := \emptyset$, the **successor ordinal** $\alpha + 1 := \alpha \cup \{ \alpha \}$; a non-zero ordinal with no greatest element is a **limit ordinal**, and $\omega$ is the least limit ordinal. The class of all ordinals is written $\mathrm{On}$.

The first few are $\emptyset,\ \{ \emptyset \},\ \{ \emptyset, \{ \emptyset \} \},\ \ldots$, that is $0, 1, 2, \ldots$;

then come $\omega,\ \omega + 1,\ \omega + 2,\ \ldots,\ \omega + \omega,\ \ldots$
