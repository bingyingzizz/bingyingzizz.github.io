Statement

There exists a set with no elements:

∃B∀x(x∉B)\exists B \forall x ( x \notin B )∃B∀x(x∈/B)

By the Axiom of Extensionality such a BBB is unique; it is written ∅\emptyset∅.

Notes

∅\emptyset∅ is the least element for ∈\in∈ and also for ⊆\subseteq⊆: ∅⊆A\emptyset \subseteq A∅⊆A holds for every AAA.

The point of this theorem is that ∅\emptyset∅ need not be taken as a primitive object: the Axiom Scheme of Separation already produces it (from any set AAA, take {x∈A:x≠x}\{x \in A : x \ne x\}{x∈A:x=x}). So in ZF the empty set is not an extra assumption.
