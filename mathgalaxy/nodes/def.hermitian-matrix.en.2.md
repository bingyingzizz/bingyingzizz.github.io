# Hermitian and Symmetric Matrices　`def.hermitian-matrix`
English entry · root `../`
[in graph](../#n=def.hermitian-matrix)　·　[Chinese page (authoritative)](./def.hermitian-matrix.md)

Let $A \in M_{n}(\mathbb{C})$. Call $A$ a **Hermitian matrix** (self-adjoint matrix) if

$$A^{*} = A .$$

A real square matrix satisfying $A^{T} = A$ is called a **symmetric matrix**.

**Key properties**: (i) the diagonal entries are all real; (ii) the eigenvalues are **all real**; (iii) eigenvectors belonging to distinct eigenvalues are **mutually orthogonal**; (iv) there exists a unitary matrix $U$ such that $U^{*}AU$ is a real diagonal matrix (thm.spectral-matrix).
