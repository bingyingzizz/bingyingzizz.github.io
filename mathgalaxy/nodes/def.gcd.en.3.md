# greatest common divisor　`def.gcd`
English entry · root `../`
[in graph](../#n=def.gcd)　·　[Chinese page (authoritative)](./def.gcd.md)

The "smallest positive element" description requires a **Bézout domain** ($\mathbb{Z}$, $K[x]$), not merely dimension one: $R = K[t^{2}, t^{3}]$ is a one-dimensional domain with $\gcd(t^{2}, t^{3}) = 1$, but $ut^{2} + vt^{3}$ always has zero constant term and never equals $1$. In a general gcd domain $\gcd$ exists but need not be a linear combination.
