# Skyscraper Sheaves Are Injective　`prop.skyscraper-injective`
English entry · root `../`
[in graph](../#n=prop.skyscraper-injective)　·　[Chinese page (authoritative)](./prop.skyscraper-injective.md)

**Why $A$ must be divisible**: in $\mathbf{Ab}$, injective $=$ divisible. For $A = \mathbb{Z}$ the skyscraper sheaf is **not** injective ($\mathbb{Z} \rightarrowtail \mathbb{Q}$ cannot be lifted), so building injective sheaves requires first enlarging each stalk with an injective hull.
