conv⁡(S):=⋂{C:C⊇S, C 凸}.\operatorname{conv}(S) := \bigcap\{ C : C \supseteq S,\ C \text{ 凸} \}.conv(S):=⋂{C:C⊇S, C 凸}.

等价地，conv⁡(S)\operatorname{conv}(S)conv(S) 恰是 SSS 中点的所有有限凸组合之集；S=∅S=\emptysetS=∅ 时为空集。

说明

⭐ 两条等价刻画：交定义（最小凸集）与有限凸组合定义。前者说明「凸包是最小的」，后者说明「凸包里的点长什么样」。
