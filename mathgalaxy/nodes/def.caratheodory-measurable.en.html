Statement

Let μ∗\mu^{*}μ∗ be an outer measure on XXX. A set A⊆XA \subseteq XA⊆X is called μ∗\mu^{*}μ∗-measurable iff AAA splits every set “cleanly into two pieces”:

μ∗(E)=μ∗(E∩A)+μ∗(E∩Ac)∀E⊆X\mu^*(E) = \mu^*(E \cap A) + \mu^*(E \cap A^c)\quad \forall E \subseteq Xμ∗(E)=μ∗(E∩A)+μ∗(E∩Ac)∀E⊆X

Notes

Since μ∗\mu^{*}μ∗ is only subadditive, one always has μ∗(E)≤μ∗(E∩A)+μ∗(E∩Ac)\mu^*(E) \le \mu^*(E \cap A) + \mu^*(E \cap A^c)μ∗(E)≤μ∗(E∩A)+μ∗(E∩Ac). The definition therefore only requires the reverse inequality: AAA “eats” nothing.

At first the definition looks strange (why not use intuitive conditions involving open or closed sets?) — its virtue is that it is completely intrinsic: only the single object μ∗\mu^{*}μ∗ is needed, no topology. Hence it works for an arbitrary outer measure.

Intuition: AAA is a set that can be “cut out freely”.
