- **Second countable $\implies$ first countable**: a countable base itself gives a countable local base at each point. **No extra hypothesis is needed**.
- **Second countable $\implies$ separable**: choose one point from each basic element to obtain a countable dense set. ⚠️ This step **uses countable choice** (skip empty basic elements; usually harmless).
- **Separable $\not\implies$ second countable**: the Sorgenfrey line is a counterexample (separable and first countable, but not second countable).
