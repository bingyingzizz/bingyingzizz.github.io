Hahn–Banach：次线性控制下的线性延拓

又称Hahn–Banach theorem·Hahn-Banach

陈述

设 XXX 是实向量空间，p:X→Rp : X \to \mathbb{R}p:X→R 是次线性的（p(x+y)≤p(x)+p(y)p(x + y) \le p(x) + p(y)p(x+y)≤p(x)+p(y)，且 p(tx)=t p(x)p(tx) = t\,p(x)p(tx)=tp(x) 对 t≥0t \ge 0t≥0），M⊆XM \subseteq XM⊆X 是子空间，f:M→Rf : M \to \mathbb{R}f:M→R 线性且满足 f≤pf \le pf≤p 于 MMM。则存在线性 F:X→RF : X \to \mathbb{R}F:X→R 使 F∣M=fF|_M = fF∣M​=f 且 F≤pF \le pF≤p。

保范延拓（推论）：设 XXX 是赋范空间，M⊆XM \subseteq XM⊆X 子空间，φ∈M∗\varphi \in M^{*}φ∈M∗。则存在 Φ∈X∗\Phi \in X^{*}Φ∈X∗ 使 Φ∣M=φ\Phi|_M = \varphiΦ∣M​=φ 且 ∥Φ∥=∥φ∥\|\Phi\| = \|\varphi\|∥Φ∥=∥φ∥。

说明

第一步：一维延拓引理。 设 x0∉Mx_0 \notin Mx0​∈/M，N=M⊕Rx0N = M \oplus \mathbb{R}x_0N=M⊕Rx0​。要在 NNN 上定义 g(m+tx0)=f(m)+tcg(m + t x_0) = f(m) + t cg(m+tx0​)=f(m)+tc 并保持 g≤pg \le pg≤p，等价于对一切 m∈Mm \in Mm∈M 有

f(m)+c≤p(m+x0),f(m)−c≤p(m−x0).f(m) + c \le p(m + x_0), \qquad f(m) - c \le p(m - x_0).f(m)+c≤p(m+x0​),f(m)−c≤p(m−x0​).

即 ccc 落在区间 [sup⁡m(f(m)−p(m−x0)), inf⁡m(p(m+x0)−f(m))][\sup_m (f(m) - p(m - x_0)),\ \inf_m (p(m + x_0) - f(m))][supm​(f(m)−p(m−x0​)), infm​(p(m+x0​)−f(m))] 里。此区间非空，因为对任意 m1,m2∈Mm_1, m_2 \in Mm1​,m2​∈M，由次线性性

f(m1)+f(m2)=f(m1+m2)≤p(m1+m2)≤p(m1−x0)+p(m2+x0),f(m_1) + f(m_2) = f(m_1 + m_2) \le p(m_1 + m_2) \le p(m_1 - x_0) + p(m_2 + x_0),f(m1​)+f(m2​)=f(m1​+m2​)≤p(m1​+m2​)≤p(m1​−x0​)+p(m2​+x0​),

即 f(m1)−p(m1−x0)≤p(m2+x0)−f(m2)f(m_1) - p(m_1 - x_0) \le p(m_2 + x_0) - f(m_2)f(m1​)−p(m1​−x0​)≤p(m2​+x0​)−f(m2​)。任取 ccc 落在其间，延拓即成立。

第二步：Zorn。 考虑所有「ggg 定义在子空间 N⊇MN \supseteq MN⊇M 上、线性、g∣M=fg|_M = fg∣M​=f、g≤pg \le pg≤p 于 NNN」的对象，按「延拓」排序（g1⪯g2g_1 \preceq g_2g1​⪯g2​ 当 g2g_2g2​ 的定义域更大且在 g1g_1g1​ 上等于 g1g_1g1​）。全序子族的并仍是这种对象（定义域取并、线性与 ≤p\le p≤p 逐点验证），由 Zorn 引理 得极大元 FFF。若 dom⁡F≠X\operatorname{dom} F \ne XdomF=X，取 x0∉dom⁡Fx_0 \notin \operatorname{dom} Fx0​∈/domF 用第一步再延拓，与极大性矛盾。故 FFF 定义在整个 XXX 上。■\blacksquare■

第三步：保范延拓。 取 p(x)=∥φ∥⋅∥x∥p(x) = \|\varphi\| \cdot \|x\|p(x)=∥φ∥⋅∥x∥（次线性），f=φf = \varphif=φ，则 φ≤p\varphi \le pφ≤p 于 MMM。得线性 Φ\PhiΦ 使 Φ∣M=φ\Phi|_M = \varphiΦ∣M​=φ、Φ≤p\Phi \le pΦ≤p 于 XXX。对 xxx 与 −x-x−x 分别用 Φ≤p\Phi \le pΦ≤p 得 ∣Φ(x)∣≤∥φ∥ ∥x∥|\Phi(x)| \le \|\varphi\|\,\|x\|∣Φ(x)∣≤∥φ∥∥x∥，故 ∥Φ∥≤∥φ∥\|\Phi\| \le \|\varphi\|∥Φ∥≤∥φ∥；反向由延拓给出，故相等。■\blacksquare■

复空间的情形：把 φ\varphiφ 看成实线性泛函，延拓后令 ΦC(x)=Ψ(x)−i Ψ(ix)\Phi_{\mathbb C}(x) = \Psi(x) - i\,\Psi(ix)ΦC​(x)=Ψ(x)−iΨ(ix)，可验证它复线性且保范。

📌 本条只证「次线性控制」这一形式；几何形式（点与闭凸集的分离）由它导出，用在 Goldstine 定理 的注里。

Statement draft

Let XXX be a real vector space, p:X→Rp : X \to \mathbb{R}p:X→R sublinear (p(x+y)≤p(x)+p(y)p(x + y) \le p(x) + p(y)p(x+y)≤p(x)+p(y), and p(tx)=t p(x)p(tx) = t\,p(x)p(tx)=tp(x) for t≥0t \ge 0t≥0), M⊆XM \subseteq XM⊆X a subspace, and f:M→Rf : M \to \mathbb{R}f:M→R linear with f≤pf \le pf≤p on MMM. Then there exists a linear F:X→RF : X \to \mathbb{R}F:X→R such that F∣M=fF|_M = fF∣M​=f and F≤pF \le pF≤p.

Norm-preserving extension (corollary): let XXX be a normed space, M⊆XM \subseteq XM⊆X a subspace, φ∈M∗\varphi \in M^{*}φ∈M∗. Then there exists Φ∈X∗\Phi \in X^{*}Φ∈X∗ such that Φ∣M=φ\Phi|_M = \varphiΦ∣M​=φ and ∥Φ∥=∥φ∥\|\Phi\| = \|\varphi\|∥Φ∥=∥φ∥.

Notes draft

Step 1: the one-dimensional extension lemma. Let x0∉Mx_0 \notin Mx0​∈/M, N=M⊕Rx0N = M \oplus \mathbb{R}x_0N=M⊕Rx0​. Defining, on NNN, a map g(m+tx0)=f(m)+tcg(m + t x_0) = f(m) + t cg(m+tx0​)=f(m)+tc that preserves g≤pg \le pg≤p is equivalent to having, for every m∈Mm \in Mm∈M,

f(m)+c≤p(m+x0),f(m)−c≤p(m−x0).f(m) + c \le p(m + x_0), \qquad f(m) - c \le p(m - x_0).f(m)+c≤p(m+x0​),f(m)−c≤p(m−x0​).

i.e. ccc lies in the interval [sup⁡m(f(m)−p(m−x0)), inf⁡m(p(m+x0)−f(m))][\sup_m (f(m) - p(m - x_0)),\ \inf_m (p(m + x_0) - f(m))][supm​(f(m)−p(m−x0​)), infm​(p(m+x0​)−f(m))]. This interval is non-empty, because for any m1,m2∈Mm_1, m_2 \in Mm1​,m2​∈M, sublinearity gives

f(m1)+f(m2)=f(m1+m2)≤p(m1+m2)≤p(m1−x0)+p(m2+x0),f(m_1) + f(m_2) = f(m_1 + m_2) \le p(m_1 + m_2) \le p(m_1 - x_0) + p(m_2 + x_0),f(m1​)+f(m2​)=f(m1​+m2​)≤p(m1​+m2​)≤p(m1​−x0​)+p(m2​+x0​),

i.e. f(m1)−p(m1−x0)≤p(m2+x0)−f(m2)f(m_1) - p(m_1 - x_0) \le p(m_2 + x_0) - f(m_2)f(m1​)−p(m1​−x0​)≤p(m2​+x0​)−f(m2​). Choose any ccc in the interval; the extension then works.

Step 2: Zorn. Consider all objects "ggg defined on a subspace N⊇MN \supseteq MN⊇M, linear, g∣M=fg|_M = fg∣M​=f, and g≤pg \le pg≤p on NNN", ordered by extension (g1⪯g2g_1 \preceq g_2g1​⪯g2​ when g2g_2g2​ has larger domain and agrees on g1g_1g1​ with g1g_1g1​). The union of a totally ordered subfamily is again such an object (domains are unioned; linearity and ≤p\le p≤p are checked pointwise), so Zorn 引理 gives a maximal element FFF. If dom⁡F≠X\operatorname{dom} F \ne XdomF=X, take x0∉dom⁡Fx_0 \notin \operatorname{dom} Fx0​∈/domF and extend again by Step 1, contradicting maximality. Hence FFF is defined on all of XXX. ■\blacksquare■

Step 3: norm-preserving extension. Take p(x)=∥φ∥⋅∥x∥p(x) = \|\varphi\| \cdot \|x\|p(x)=∥φ∥⋅∥x∥ (sublinear) and f=φf = \varphif=φ; then φ≤p\varphi \le pφ≤p on MMM. This gives a linear Φ\PhiΦ with Φ∣M=φ\Phi|_M = \varphiΦ∣M​=φ and Φ≤p\Phi \le pΦ≤p on XXX. Applying Φ≤p\Phi \le pΦ≤p to xxx and to −x-x−x gives ∣Φ(x)∣≤∥φ∥ ∥x∥|\Phi(x)| \le \|\varphi\|\,\|x\|∣Φ(x)∣≤∥φ∥∥x∥, hence ∥Φ∥≤∥φ∥\|\Phi\| \le \|\varphi\|∥Φ∥≤∥φ∥; the reverse inequality comes from the extension, so equality holds. ■\blacksquare■

The complex case: regard φ\varphiφ as a real-linear functional, extend it, then set ΦC(x)=Ψ(x)−i Ψ(ix)\Phi_{\mathbb C}(x) = \Psi(x) - i\,\Psi(ix)ΦC​(x)=Ψ(x)−iΨ(ix); one checks that it is complex-linear and norm-preserving.

📌 This entry proves only the "sublinear domination" form; the geometric form (separation of a point from a closed convex set) is derived from it and used in the notes to Goldstine 定理.
