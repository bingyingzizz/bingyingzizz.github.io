# local inverse of the exponential　`prop.exp-local-inverse`
English entry · root `../`
[in graph](../#n=prop.exp-local-inverse)　·　[Chinese page (authoritative)](./prop.exp-local-inverse.md)

## Notes · **draft**
**Proof**: $\exp' = \exp \ne 0$ holds everywhere, so the inverse function theorem (complex version: if $f'(z_{0}) \ne 0$ then the map is locally biholomorphic and the inverse has derivative $1/f'$) gives local biholomorphy. The explicit inverse is read off from Euler's formula: $e^{x + iy} = w$ gives $x = \log|w|$ and $y = \arg w + 2k\pi$, and taking the branch lying in the prescribed interval gives the formula.
