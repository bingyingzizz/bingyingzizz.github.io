陈述

白话：分式线性变换是复球面上最「刚性」的一类全纯双射 —— 它把圆（含直线）送到圆，并且保持交比不变。

形如

f(z)=az+bcz+d,a,b,c,d∈C, ad−bc≠0f(z) = \frac{az + b}{cz + d}, \qquad a, b, c, d \in \mathbb{C},\ ad - bc \ne 0f(z)=cz+daz+b​,a,b,c,d∈C, ad−bc=0

的映射称为分式线性变换（Möbius 变换）。它延拓成 Riemann 球面 C^=C∪{∞}\hat{\mathbb{C}} = \mathbb{C} \cup \{\infty\}C^=C∪{∞} 到自身的双射：c≠0c \ne 0c=0 时 f(−d/c)=∞f(-d/c) = \inftyf(−d/c)=∞、f(∞)=a/cf(\infty) = a/cf(∞)=a/c；c=0c = 0c=0 时 f(∞)=∞f(\infty) = \inftyf(∞)=∞。逆映射仍是分式线性变换：

f−1(w)=dw−b−cw+a.f^{-1}(w) = \frac{dw - b}{-cw + a}.f−1(w)=−cw+adw−b​.

说明

⭐ ad−bc≠0ad - bc \ne 0ad−bc=0 是「非退化」条件：等于 000 时 fff 退化为常数。它同时保证 f′(z)=(ad−bc)/(cz+d)2≠0f'(z) = (ad - bc)/(cz + d)^2 \ne 0f′(z)=(ad−bc)/(cz+d)2=0，所以 fff 处处共形（保角，见「保角性」那条）。

⭐ 三个基本构件：平移 z↦z+bz \mapsto z + bz↦z+b、伸缩旋转 z↦azz \mapsto azz↦az（a≠0a \ne 0a=0）、反演 z↦1/zz \mapsto 1/zz↦1/z。任何 Möbius 变换都是它们的复合，而 ad−bc≠0ad - bc \ne 0ad−bc=0 保证复合之后不塌成常数。

⭐ 几何性质（书第 13 章）：把圆或直线送到圆或直线（统称「广义圆」，在球面上其实就是「圆」）；并且保持交比不变：

(z1,z2;z3,z4)=(z1−z3)(z2−z4)(z1−z4)(z2−z3).(z_1, z_2; z_3, z_4) = \frac{(z_1 - z_3)(z_2 - z_4)}{(z_1 - z_4)(z_2 - z_3)}.(z1​,z2​;z3​,z4​)=(z1​−z4​)(z2​−z3​)(z1​−z3​)(z2​−z4​)​.

于是 fff 由三个点的像唯一确定 —— 交比是 Möbius 变换的全不变量。

⚠ 球面上的 ∞\infty∞ 不是「很大的数」：它是用球极投影添进来的一个点。只有在球面上，「fff 是双射」这句话才干净 —— 在 C\mathbb{C}C 上它总漏掉一两个点。

  • 本页 ⟹ 交比推出
    分式线性变换给出交比这个不变量

    由 def.mobius，分式线性变换是 z↦(az+b)/(cz+d)z \mapsto (az+b)/(cz+d)z↦(az+b)/(cz+d)。对四个点直接算差：

    Tzi−Tzj=(ad−bc)(zi−zj)(czi+d)(czj+d).Tz_{i} - Tz_{j} = \frac{(ad - bc)(z_{i} - z_{j})}{(cz_{i} + d)(cz_{j} + d)}.Tzi​−Tzj​=(czi​+d)(czj​+d)(ad−bc)(zi​−zj​)​.

    把它代进交比 (Tz1,Tz2;Tz3,Tz4)(Tz_{1}, Tz_{2}; Tz_{3}, Tz_{4})(Tz1​,Tz2​;Tz3​,Tz4​)，分子分母里的 (ad−bc)(ad-bc)(ad−bc) 与四个 (czk+d)(cz_{k} + d)(czk​+d) 逐对抵消，剩下的正是 (z1,z2;z3,z4)(z_{1}, z_{2}; z_{3}, z_{4})(z1​,z2​;z3​,z4​)。∎

    交比之所以值得定义，就是因为它是 PGL⁡(2,C)\operatorname{PGL}(2,\mathbb{C})PGL(2,C) 下唯一的不变量。

  • 本页 ⟹ 关于圆的对称点推出
    对称点是反演：z∗=a+R2/(z−a)‾z^{*} = a + R^{2}/\overline{(z - a)}z∗=a+R2/(z−a)​

    由 def.mobius，z↦a+R2/(z−a)‾z \mapsto a + R^{2}/\overline{(z - a)}z↦a+R2/(z−a)​ 是「平移 + 反演 + 伸缩」的复合，其中 z↦1/zˉz \mapsto 1/\bar zz↦1/zˉ 是共轭再取倒数，属于反全纯的分式映射。

    保角性的对照：prop.conformal-iff 说全纯 + 导数非零 = 保角且保定向；而反演是反全纯的，保角但反定向。对称点正是在这个反全纯映射下与 zzz 配对，所以「关于圆对称」与「关于直线镜像」是同一件事的两种外观（直线 = 过 ∞\infty∞ 的圆）。

    对称 ≠\ne= 到圆心等距；对称是反演，距离的乘积固定。

  • 本页 ⟹ 分式线性变换成群推出
    矩阵乘法 = 复合，纯量倍数 = 同一个变换

    分式线性变换与矩阵 (abcd)\begin{pmatrix} a & b\\ c & d\end{pmatrix}(ac​bd​) 一一对应到纯量倍数：若 (a,b,c,d)=λ(a′,b′,c′,d′)(a,b,c,d) = \lambda(a',b',c',d')(a,b,c,d)=λ(a′,b′,c′,d′)，两边的分式恒等。

    复合对应乘法：直接代入 T1(T2(z))T_{1}(T_{2}(z))T1​(T2​(z)) 得到的分式，其系数矩阵正是两个矩阵之积。逆：逆变换的矩阵是逆矩阵（差一个行列式纯量）。故 PGL⁡(2,C)\operatorname{PGL}(2,\mathbb{C})PGL(2,C) 成群。
