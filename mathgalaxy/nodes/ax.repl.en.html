Statement

If a formula defines a "functional relation", the image of any set is again a set. For every formula φ(x,y,p)\varphi (x, y, p)φ(x,y,p) (in which BBB does not occur):

∀p[∀x∀y∀z(φ(x,y,p)∧φ(x,z,p)→y=z)→∀A∃B∀y(y∈B↔∃x∈A,φ(x,y,p))]\forall p [ \forall x\forall y\forall z ( \varphi(x,y,p) \wedge \varphi(x,z,p) \to y = z ) \to \forall A \exists B \forall y ( y \in B \leftrightarrow \exists x \in A, \varphi(x,y,p) ) ]∀p[∀x∀y∀z(φ(x,y,p)∧φ(x,z,p)→y=z)→∀A∃B∀y(y∈B↔∃x∈A,φ(x,y,p))]

It guarantees that "replacement" never leaves the set-theoretic universe: the image BBB is a set too.
