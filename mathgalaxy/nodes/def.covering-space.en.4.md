# covering space　`def.covering-space`
English entry · root `../`
[in graph](../#n=def.covering-space)　·　[Chinese page (authoritative)](./def.covering-space.md)

**Number of sheets = index**: if $B$ is path connected and locally path connected and the number of sheets is finite, then the index of $\pi_{1}(E)$ in $\pi_{1}(B)$ equals the number of sheets (`prop.covering-index`). This is the source of "count the sheets to compute the fundamental group".

⚠️ A common counterexample: $p : (0, 2) \to S^{1}$, $p(t) = e^{2\pi i t}$ — this is **not** a covering, because every neighbourhood of $1 \in S^{1}$ is covered only halfway ($(0,2)$ does not "continue" at the endpoint). A covering must be even at **every** point, including limit points.
