# Arc Length　`def.arc-length`
English entry · root `../`
[in graph](../#n=def.arc-length)　·　[Chinese page (authoritative)](./def.arc-length.md)

The **arc-length function** measured from $t_{0}\in[a,b]$ is

$$s(t) := \int_{t_{0}}^{t}\lVert\gamma'(u)\rVert\,\mathrm{d}u ,\qquad s'(t) = \lVert\gamma'(t)\rVert .$$

If $\lVert\gamma'(t)\rVert\equiv 1$, one calls $\gamma$ **arc-length parametrized** (unit-speed parametrized); then arc length is just the difference of parameters. A regular curve can always be reparametrized by arc length (the construction is on the edge); from then on one writes $s$ for the parameter and $T := \gamma'(s)$ for the unit tangent vector.
