设 (X,M)(X, \mathcal{M})(X,M) 是可测空间。ν:M→[−∞,+∞]\nu : \mathcal{M} \to [-\infty, +\infty]ν:M→[−∞,+∞] 是符号测度，当且仅当

  • ν(∅)=0\nu(\emptyset) = 0ν(∅)=0；
  • ν\nuν 至多取到 ±∞\pm \infty±∞ 中的一个（不能同时取到 ∞\infty∞ 与 −∞-\infty−∞）；
  • 对两两不交的 {Ej}⊆M\{E_j\} \subseteq \mathcal{M}{Ej​}⊆M：
ν(⨆jEj)=∑jν(Ej), 且右边的级数绝对收敛(当∣ν(⨆Ej)∣<∞ 时)\nu( \bigsqcup_j E_j ) = \sum_j \nu(E_j),\text{ 且右边的级数绝对收敛}(\text{当} |\nu(\bigsqcup E_j)| < \infty\text{ 时})ν(j⨆​Ej​)=j∑​ν(Ej​), 且右边的级数绝对收敛(当∣ν(⨆Ej​)∣<∞ 时)

说明

⚠ 「至多取到一个无穷」这一条是必需的：否则可数可加性会碰上 ∞−∞\infty - \infty∞−∞。

例 1：μ1\mu _{1}μ1​、μ2\mu _{2}μ2​ 是测度，其中至少一个有限   ⟹  \implies⟹ ν=μ1−μ2\nu = \mu_1 - \mu_2ν=μ1​−μ2​ 是符号测度。

例 2：f:X→[−∞,+∞]f : X \to [-\infty, +\infty]f:X→[−∞,+∞] 可测，且 ∫f+dμ\int f^+ d\mu∫f+dμ、∫f−dμ\int f^- d\mu∫f−dμ 中至少一个有限   ⟹  \implies⟹

ν(E):=∫Efdμ\nu(E) := \int_E f d\muν(E):=∫E​fdμ

是符号测度。这样的 fff 叫广义可积函数（extended integrable function）。

    ① 先把 ν\nuν 的无穷值甩掉。 不妨设 ν\nuν 不取 ∞\infty∞（若 ν\nuν 不取 −∞-\infty−∞ 就改证 −ν-\nu−ν）。于是 ν(X)<∞\nu(X) < \inftyν(X)<∞ 中的「上方」是安全的。

    P=⋃jPjP = \bigcup_j P_jP=j⋃​Pj​

    由正集的可数并仍是正集，PPP 是正集；且 ν(P)=m\nu(P) = mν(P)=m（正集的不交化 + 可数可加）。
