又称AB 公理例子·哪些范畴满足 AB

陈述

  • Ab\mathbf{Ab}Ab：AB6 与 AB4\*；
  • AbTop\mathbf{AbTop}AbTop（拓扑阿贝尔群）：只满足 AB1；
  • AbCHaus\mathbf{AbCHaus}AbCHaus（紧 Hausdorff 阿贝尔群）：只满足 AB1（更精确地 AbCHaus≃Abop\mathbf{AbCHaus} \simeq \mathbf{Ab}^{\mathrm{op}}AbCHaus≃Abop，故满足 AB4 与 AB6\*）；
  • AbC\mathbf{Ab}^{\mathcal{C}}AbC（任意范畴 C\mathcal{C}C 上的阿贝尔群预层）：AB6 与 AB4\*；
  • Ab(T)\mathbf{Ab}(\mathcal{T})Ab(T)（拓扑斯 T\mathcal{T}T 上的阿贝尔群）：AB5 与 AB3\*；
  • CondAb\mathrm{CondAb}CondAb：AB6 与 AB4\*。

说明

怎么读这张表：从下往上，公理越往上越强（AB1 < AB2 < AB3 < AB4 < AB5 < AB6）。表里最有意思的两个对照：

  • AbTop\mathbf{AbTop}AbTop 只到 AB1 —— 连 AB2 都不满足。理由是「态射不必严格」（存在单态射不是核的情形），所以它连阿贝尔范畴都不是，做不了同调代数。这正是要把拓扑群搬进凝聚态那侧的理由。- Ab(T)\mathbf{Ab}(\mathcal{T})Ab(T) 停在 AB5，而 CondAb\mathrm{CondAb}CondAb 能上到 AB6 —— 多出来的正是「滤过余极限与积交换」与「积正合」。凝聚态数学在一般拓扑斯之上额外拿到的，就是这两条。

⭐ 表里 AbCHaus≃Abop\mathbf{AbCHaus} \simeq \mathbf{Ab}^{\mathrm{op}}AbCHaus≃Abop 那一行是把 Pontryagin 对偶提升成范畴等价的结果：紧 Hausdorff 阿贝尔群的范畴反等价于离散阿贝尔群的范畴，于是它的公理等级就是 Ab\mathbf{Ab}Ab 的对偶版本。
