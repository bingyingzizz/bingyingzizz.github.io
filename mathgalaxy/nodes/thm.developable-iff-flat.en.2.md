# criterion for developable surfaces　`thm.developable-iff-flat`
English entry · root `../`
[in graph](../#n=thm.developable-iff-flat)　·　[Chinese page (authoritative)](./thm.developable-iff-flat.md)

1. the **tangent plane is constant** along each ruling (the normal vector is independent of $v$);
2. $\det\bigl(a'(u),\ b(u),\ b'(u)\bigr) = 0$ for all $u$;
3. **Gauss curvature vanishes identically**: $K \equiv 0$;
4. **developable** (locally isometric to the plane, `def.developable-surface`).

**How to use it**: substitute $a, b$ into that third-order determinant. For a cylinder $b' = 0$, hence developable; for the hyperbolic paraboloid $X = (u,v,uv)$ the determinant is $1 \ne 0$, so it is **not** developable.
