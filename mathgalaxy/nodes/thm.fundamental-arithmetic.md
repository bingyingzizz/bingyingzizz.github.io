# 算术基本定理　`thm.fundamental-arithmetic`
唯一分解：每个整数拆成素数乘积恰好一种方式
layer 12 · 定理 · 整除与同余 · 数论
[在星图里打开](../#n=thm.fundamental-arithmetic)　·　[节点索引](../index.md)

每个整数 $n > 1$ 都能唯一地写成

$$n = p_{1}^{e_{1}} p_{2}^{e_{2}} \cdots p_{r}^{e_{r}},$$

其中 $p_{1} < p_{2} < \cdots < p_{r}$ 是素数，$e_{i} \ge 1$。
