# Tangent Space　`def.tangent-space-manifold`
English entry · root `../`
[in graph](../#n=def.tangent-space-manifold)　·　[Chinese page (authoritative)](./def.tangent-space-manifold.md)

Two curves $\gamma_{1},\gamma_{2} : (-\varepsilon,\varepsilon)\to M$ through $p$ ($\gamma_{i}(0) = p$) are called **tangent at $p$** if there exists (equivalently: for every) chart $(U,\varphi)$ containing $p$ with

$$(\varphi\circ\gamma_{1})'(0) = (\varphi\circ\gamma_{2})'(0) .$$

"Exists one chart" and "for every chart" are equivalent, because changing charts only introduces a chain-rule factor. Such an equivalence class is a **tangent vector** at $p$, and the set of all of them is $T_{p}M$.

In a chart $(U,\varphi)$, write $x^{i} := \varphi^{i}$, $\partial_{i} := \partial/\partial x^{i}$.
