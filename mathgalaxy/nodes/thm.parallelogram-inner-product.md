# 平行四边形法则　`thm.parallelogram-inner-product`
平行四边形法则 $\iff$ 范数来自内积（Jordan–von Neumann）
layer 21 · 定理 · Hilbert 空间 · 泛函分析
[在星图里打开](../#n=thm.parallelogram-inner-product)　·　[节点索引](../index.md)

赋范空间 $E$ 的范数来自某个内积 $\iff$ 它对一切 $x, y$ 满足**平行四边形法则**

$$\|x + y\|^2 + \|x - y\|^2 = 2\|x\|^2 + 2\|y\|^2 .$$
