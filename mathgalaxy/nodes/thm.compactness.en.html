Statement

Let Γ\GammaΓ be a set of first-order formulas. If **every finite subset** of Γ\GammaΓ has a model, then Γ\GammaΓ itself has a model.

Equivalently: if Γ⊨φ\Gamma \vDash \varphiΓ⊨φ, then there is a **finite** Γ0⊆Γ\Gamma_{0} \subseteq \GammaΓ0​⊆Γ with Γ0⊨φ\Gamma_{0} \vDash \varphiΓ0​⊨φ.

Notes

It is a one-sentence corollary**: by the completeness theorem, having a model   ⟺  \iff⟺ being consistent; and inconsistency is witnessed by a finite** proof, which uses only finitely many formulas of Γ\GammaΓ. So inconsistency is always finitely visible, and taking the contrapositive gives compactness.

**Second proof** (avoiding completeness): use ultraproducts / Łoś's theorem — take the directed family of finite subsets as the index set, choose a model of each finite subset, and the ultraproduct is a model of the whole theory. Ultraproducts are not developed here, so this is only a remark.

It is the reason first-order logic cannot express finiteness**: let Γ\GammaΓ consist of infinitely many sentences saying "field + characteristic 0 + finite". Every finite subset is satisfiable in some finite field, so the whole of Γ\GammaΓ has a model — an infinite** "finite field". Likewise the standard model of the natural numbers cannot be characterised by first-order axioms: non-standard analysis is a direct product of this theorem.

The resemblance to topological compactness (紧) is only in the name**: that one says "every open cover has a finite subcover", this one says "finitely satisfiable   ⟹  \implies⟹ satisfiable". The two are connected only by an analogy edge**, not by a dependence of theorems.
