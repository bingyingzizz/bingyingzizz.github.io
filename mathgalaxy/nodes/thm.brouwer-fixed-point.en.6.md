# Brouwer fixed point theorem　`thm.brouwer-fixed-point`
English entry · root `../`
[in graph](../#n=thm.brouwer-fixed-point)　·　[Chinese page (authoritative)](./thm.brouwer-fixed-point.md)

**An alternative for the holomorphic case (Rouché)**: Suppose $f$ is holomorphic on $\mathbb{D}$, continuous up to the boundary, and $|f| \le 1$. Then on $|z| = 1$, $|f(z) - z| \ge |z| - |f(z)| \ge 0$, with equality only when $f(z) = z$ (already a fixed point). Otherwise $f - z$ has no boundary zeros. By `thm.rouche`, compare $f - z$ with $-z$ ($|-z| = 1 > |f|$). The latter has exactly one zero inside $\mathbb{D}$, so $f - z$ also has exactly one zero. This argument covers only the holomorphic case.
