# structure theorem for locally compact abelian groups　`thm.lc-structure`
English entry · root `../`
[in graph](../#n=thm.lc-structure)　·　[Chinese page (authoritative)](./thm.lc-structure.md)

⭐ **This theorem drives Chapter 8.** It is used to show that higher Ext groups between locally compact abelian groups vanish. Since every object is built by extensions from three classes (discrete, finite-dimensional real Banach, and compact connected), it suffices to verify Ext vanishing for pairs from those classes. This reduces infinitely many kinds of groups to $3 \times 3$ cases.
