# multilinear form　`def.multilinear-form`
English entry · root `../`
[in graph](../#n=def.multilinear-form)　·　[Chinese page (authoritative)](./def.multilinear-form.md)

The set of all $n$-linear forms is denoted $\operatorname{Mult}_n(V; K)$; with pointwise operations it becomes a $K$-vector space.

When $n = 2$ it is called a **bilinear form**; after fixing a basis, $n$-linear forms correspond one-to-one with "$n$-dimensional arrays $(f(e_{i_1}, \ldots, e_{i_n}))$".

## Notes · **draft**
⭐ The order of the caveats matters: "linear in each argument separately" and "linear as a whole" **do not imply each other** — $f(x, y) = xy$ is linear in each argument, yet it is not a linear map $\mathbb{R}^{2} \to \mathbb{R}$ (in general $f(x + x', y + y') \ne f(x,y) + f(x',y')$).
