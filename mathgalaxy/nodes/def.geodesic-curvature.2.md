## 陈述（续）
$$\vec\kappa_{g} = \nabla_{\dot\gamma}\dot\gamma = (\ddot\gamma)^{\top},\qquad k_{g} = \langle \vec\kappa_{g},\,n\times\dot\gamma\rangle = \langle \ddot\gamma,\,n
\times\dot\gamma\rangle,$$
其中 $(\cdot)^{\top}$ 表示投到切平面，$n\times\dot\gamma$ 是切平面内与 $\dot\gamma$ 正交的单位向量（Darboux 标架 $(T,n,u)$ 里的 $u$，$T = \dot\gamma$）。于是「$k
_{g}$ 恒等于零」正好就是测地线的判据：
$$k_{g}(\gamma)\equiv 0 \iff \nabla_{\dot\gamma}\dot\gamma\equiv 0 .$$
