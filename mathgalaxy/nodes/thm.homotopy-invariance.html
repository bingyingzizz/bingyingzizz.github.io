又称同伦不变性

陈述

设 X,YX, YX,Y 是拓扑空间，f,g:X→Yf, g : X \to Yf,g:X→Y 连续且同伦：存在连续 F:X×[0,1]→YF : X \times [0,1] \to YF:X×[0,1]→Y 使 F(⋅,0)=fF(\cdot, 0) = fF(⋅,0)=f、F(⋅,1)=gF(\cdot, 1) = gF(⋅,1)=g。则对每个 nnn，

f∗=g∗:Hn(X)→Hn(Y).f_{*} = g_{*} : H_{n}(X) \to H_{n}(Y).f∗​=g∗​:Hn​(X)→Hn​(Y).

推论：同伦等价的空间有同构的同调群（同调是同伦不变量）。

说明

证明（棱柱算子）：只需造一条链同伦（def.chain-homotopy）Pn:Sn(X)→Sn+1(Y)P_{n} : S_{n}(X) \to S_{n+1}(Y)Pn​:Sn​(X)→Sn+1​(Y)，使 ∂P+P∂=g#−f#\partial P + P\partial = g_{\#} - f_{\#}∂P+P∂=g#​−f#​。

几何图像：一个奇异单形 σ:Δn→X\sigma : \Delta^{n} \to Xσ:Δn→X 与 FFF 一起给出「棱柱」F∘(σ×id):Δn×[0,1]→YF \circ (\sigma \times \mathrm{id}) : \Delta^{n} \times [0,1] \to YF∘(σ×id):Δn×[0,1]→Y。棱柱有 n+2n+2n+2 个面：n+1n+1n+1 个「侧面」加底（f∘σf \circ \sigmaf∘σ）和顶（g∘σg \circ \sigmag∘σ）。把 Δn×[0,1]\Delta^{n} \times [0,1]Δn×[0,1] 三角剖分成 n+1n+1n+1 个 Δn+1\Delta^{n+1}Δn+1，按定向取侧面之和：

Pn(σ):=∑i=0n(−1)i F∘(σ×id)∘τi,P_{n}(\sigma) := \sum_{i=0}^{n} (-1)^{i}\, F \circ (\sigma \times \mathrm{id}) \circ \tau_{i},Pn​(σ):=i=0∑n​(−1)iF∘(σ×id)∘τi​,

其中 τi:=[v0,…,vi,wi,…,wn]\tau_{i} := [v_{0}, \ldots, v_{i}, w_{i}, \ldots, w_{n}]τi​:=[v0​,…,vi​,wi​,…,wn​] 是棱柱剖分出的第 iii 块。

关键计算：对 PPP 取边缘 ∂\partial∂，每个「内部面」被相邻两个三角块各算一次、定向相反   ⟹  \implies⟹ 抵消；剩下「底 + 顶 + 一圈侧面」。而那一圈侧面恰好是 P(∂σ)P(\partial\sigma)P(∂σ)（因为 ∂σ\partial\sigma∂σ 的单形正好对应棱柱的侧面）。于是

∂P(σ)=g∘σ−f∘σ+P(∂σ),\partial P(\sigma) = g \circ \sigma - f \circ \sigma + P(\partial \sigma),∂P(σ)=g∘σ−f∘σ+P(∂σ),

即 ∂P+P∂=g#−f#\partial P + P\partial = g_{\#} - f_{\#}∂P+P∂=g#​−f#​。由 def.chain-homotopy，fff 与 ggg 在同调上诱导同一同态。∎

⭐ 这一步正是整条链缺的那环：thm.sphere-homology 的归纳法（把 SnS^{n}Sn 拆成两个半球）要用「两个半球各自可缩   ⟹  \implies⟹ 它们的恒等映射与常值映射在同调上相同」。没有这条，那个归纳只能算「算出来是 0 和 Z\mathbb{Z}Z」，不能说「所以球面同调就是这样」。

⚠️ 本节点写的是完整构造 + 关键抵消；那一步「内部面两两抵消」在书上是逐个下标验算的，这里给的是可复现的骨架（每个面的定向按 (−1)i(-1)^{i}(−1)i 交替，抵消的机制写清楚了）。

推出 1

  • 本页 ⟹ 球面的同调推出
    球面同调的归纳要用「可缩   ⟹  \implies⟹ 同调平凡」

    thm.sphere-homology 的证明把 SnS^{n}Sn 拆成两个闭半球 D+n∪D−nD^{n}_{+} \cup D^{n}_{-}D+n​∪D−n​，再用对 (Sn,D+n)(S^{n}, D^{n}_{+})(Sn,D+n​) 的长正合列与归纳。

    缺的那一步：两个半球各自可缩，因此它们的恒等映射与「常值映射」同伦；由 thm.homotopy-invariance，恒等诱导的同态等于常值映射诱导的同态，而后者经过 H~k(pt)=0\tilde H_{k}(\text{pt}) = 0H~k​(pt)=0 分解，故 H~k(Dn)=0\tilde H_{k}(D^{n}) = 0H~k​(Dn)=0。

    没有这一条，归纳只能算出「某个群是 0」，却说不出「为什么半球没有同调」。∎

    这条补上了子 agent 交付时自己标注的「最薄弱一环」。

推出 2

  • 奇异同调群 ⟹ 本页推出
    奇异链上造棱柱算子 PnP_{n}Pn​

    设 F:X×[0,1]→YF : X \times [0,1] \to YF:X×[0,1]→Y 给出 f≃gf \simeq gf≃g。对每个奇异 nnn-单形 σ:Δn→X\sigma : \Delta^{n} \to Xσ:Δn→X，构造 Δn×[0,1]\Delta^{n} \times [0,1]Δn×[0,1] 的三角剖分：底顶点 v0,…,vnv_{0}, \ldots, v_{n}v0​,…,vn​、顶顶点 w0,…,wnw_{0}, \ldots, w_{n}w0​,…,wn​，第 iii 块是 [v0,…,vi,wi,…,wn][v_{0}, \ldots, v_{i}, w_{i}, \ldots, w_{n}][v0​,…,vi​,wi​,…,wn​]。

    令 Pn(σ)P_{n}(\sigma)Pn​(σ) 为这 n+1n+1n+1 块在 F∘(σ×id)F \circ (\sigma \times \mathrm{id})F∘(σ×id) 下的像的交替和（系数 (−1)i(-1)^{i}(−1)i），线性延拓到整个链群。

    校验 ∂P+P∂=g#−f#\partial P + P\partial = g_{\#} - f_{\#}∂P+P∂=g#​−f#​：取边缘后，剖分内部的面对被两块共享且定向相反，相消；剩下底面（给 f∘σf \circ \sigmaf∘σ）、顶面（给 g∘σg \circ \sigmag∘σ）与侧面。侧面之和正是 Pn−1(∂σ)P_{n-1}(\partial \sigma)Pn−1​(∂σ)（因为 ∂σ\partial\sigma∂σ 的每个面对应棱柱的一个侧面）。于是恰好得到 g#−f#g_{\#} - f_{\#}g#​−f#​。∎

    棱柱算子把「连续形变」翻译成「链同伦」——这就是同伦不变性的全部内容。

  • 同伦 ⟹ 本页推出
    同伦的定义就是这里要用的那条形变

    由 def.homotopy，f≃gf \simeq gf≃g 指存在连续 F:X×[0,1]→YF : X \times [0,1] \to YF:X×[0,1]→Y 使 F(⋅,0)=fF(\cdot, 0) = fF(⋅,0)=f、F(⋅,1)=gF(\cdot, 1) = gF(⋅,1)=g。

    这条 FFF 同时是「棱柱」的原料：F∘(σ×id)F \circ (\sigma \times \mathrm{id})F∘(σ×id) 把 Δn×[0,1]\Delta^{n} \times [0,1]Δn×[0,1] 送进 YYY，于是任何能把乘积剖分成单形的构造都能用。（这正是为什么同调要比同伦群好算：同伦群没有这种「线性」的搬运。）∎

    同伦给形变，链同伦给代数：FFF 就是那根桥。
