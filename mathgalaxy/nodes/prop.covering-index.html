陈述

设 p:(E,e0)→(B,b0)p : (E, e_{0}) \to (B, b_{0})p:(E,e0​)→(B,b0​) 是覆叠映射，E,BE, BE,B 道路连通且局部道路连通。则

  1. 单射：p∗:π1(E,e0)→π1(B,b0)p_{*} : \pi_{1}(E, e_{0}) \to \pi_{1}(B, b_{0})p∗​:π1​(E,e0​)→π1​(B,b0​) 是单射；
  2. 纤维 = 陪集：存在双射
p−1(b0)  ⟷  π1(B,b0)/p∗π1(E,e0),p^{-1}(b_{0}) \;\longleftrightarrow\; \pi_{1}(B, b_{0}) \big/ p_{*}\pi_{1}(E, e_{0}),p−1(b0​)⟷π1​(B,b0​)/p∗​π1​(E,e0​),

把 e∈p−1(b0)e \in p^{-1}(b_{0})e∈p−1(b0​) 送到「从 e0e_{0}e0​ 走到 eee 的那条道路的投影」所在的右陪集。

因此层数 #p−1(b0)\#p^{-1}(b_{0})#p−1(b0​) 等于指数 [π1(B):p∗π1(E)][\pi_{1}(B) : p_{*}\pi_{1}(E)][π1​(B):p∗​π1​(E)]（两者都有限时）。

说明

⚠️⚠️ 这是集合的双射，不是群同构。陪集集 π1(B)/p∗π1(E)\pi_{1}(B)/p_{*}\pi_{1}(E)π1​(B)/p∗​π1​(E) 一般没有群结构，仅凭这条拿不到 π1(S1)≅Z\pi_{1}(S^{1}) \cong \mathbb{Z}π1​(S1)≅Z 的群信息——只能拿到「π1(S1)\pi_{1}(S^{1})π1​(S1) 与 Z\mathbb{Z}Z 等势」。要得到同构必须另外定义度数并证明它是同态，见 thm.pi1-circle。

⭐ 当覆叠是万有覆叠（EEE 单连通，于是 p∗π1(E)=1p_{*}\pi_{1}(E) = 1p∗​π1​(E)=1）时，结论化简成「纤维 ↔π1(B)\leftrightarrow \pi_{1}(B)↔π1​(B) 集合同构」。p:R→S1p : \mathbb{R} \to S^{1}p:R→S1 正是这种情形。

单射的几何意思：π1(E)\pi_{1}(E)π1​(E) 里非零的东西在 BBB 里也非零——覆叠不会假装「解开」已经很平凡的圈，它只会让一个圈变成更「紧」的圈。

💡 这条命题是「覆叠分类」的入口：BBB 的连通覆叠（差同胚）与 π1(B)\pi_{1}(B)π1​(B) 的共轭类子群一一对应。
