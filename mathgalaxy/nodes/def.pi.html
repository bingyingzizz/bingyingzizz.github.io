陈述

由 cos⁡\coscos 的幂级数可以证明：cos⁡\coscos 在 (0,2)(0, 2)(0,2) 内恰有一个零点。把它记为 π/2\pi / 2π/2，即

π:=2⋅min⁡{x>0:cos⁡x=0}\pi := 2 \cdot \min \{ x > 0 : \cos x = 0 \}π:=2⋅min{x>0:cosx=0}

于是 cos⁡(π/2)=0\cos(\pi/2) = 0cos(π/2)=0、sin⁡(π/2)=1\sin(\pi/2) = 1sin(π/2)=1，而且 cos⁡\coscos 与 sin⁡\sinsin 都以 2π2\pi2π 为周期。

说明

⭐ π\piπ 在这里不是「周长与直径之比」—— 那是几何事实，要靠弧长理论才能证明。分析里的 π\piπ 定义为余弦的最小正零点，于是周期、正交性、Fourier 展开全都从级数里长出来。

⭐ 存在性的关键一步：cos⁡0=1>0\cos 0 = 1 > 0cos0=1>0 而 cos⁡2<0\cos 2 < 0cos2<0（由级数估值：cos⁡2=1−2+1624−⋯\cos 2 = 1 - 2 + \frac{16}{24} - \cdotscos2=1−2+2416​−⋯ 的尾巴被控制住），由介值定理得到零点。唯一性靠 sin⁡>0\sin > 0sin>0 在 (0,2)(0, 2)(0,2) 上（cos⁡′=−sin⁡\cos' = -\sincos′=−sin 且 sin⁡\sinsin 递增为正）。

⚠ 定义里用的是 min⁡\minmin，所以先要证明那个集合非空 —— 这正是上面说的介值定理那一步。
