# Möbius transformations preserve circles　`prop.mobius-circle`
English entry · root `../`
[in graph](../#n=prop.mobius-circle)　·　[Chinese page (authoritative)](./prop.mobius-circle.md)

Corollary: between any two disks (or half-planes) there is a Möbius transformation carrying one to the other; in particular every disk is conformally equivalent to the upper half-plane and to the unit disk.

## Notes · **draft**
**Proof**: by `prop.cross-ratio-real`, four points are concyclic $\iff$ the cross-ratio is real. The cross-ratio is invariant under Möbius transformations, so "concyclic" is preserved — hence the image of a circle (or line) stays in the same class.
