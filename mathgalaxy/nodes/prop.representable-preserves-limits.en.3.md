# representable functors preserve limits　`prop.representable-preserves-limits`
English entry · root `../`
[in graph](../#n=prop.representable-preserves-limits)　·　[Chinese page (authoritative)](./prop.representable-preserves-limits.md)

- The **contravariant** representable functor $\operatorname{Hom}(-, X)$ sends **colimits** to **limits**, by passing to the opposite category.
- The fact that $\operatorname{Hom}(X, -)$ preserves **finite** limits means that $X$ is compatible with all finite limits in this sense.

A functor is **left exact** if it preserves all **finite** limits. It is right exact if it preserves all finite colimits, and exact if it does both.
