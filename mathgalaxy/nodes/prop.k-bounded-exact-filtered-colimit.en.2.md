# K-Bounded Exactness Is Stable under Filtered Colimits　`prop.k-bounded-exact-filtered-colimit`
English entry · root `../`
[in graph](../#n=prop.k-bounded-exact-filtered-colimit)　·　[Chinese page (authoritative)](./prop.k-bounded-exact-filtered-colimit.md)

If each $M^{\bullet}_{k}$ is boundedly exact at $M^{n}_{k}$ with bound $K$, then $M^{\bullet}$ is boundedly exact at $M^{n}$ with bound $K$.

## Notes · **draft**
⭐ Use: the "analytic property with a constant", $K$-bounded exactness, is not lost when passing to larger complexes — so one can check the condition on finite/simple complexes first and then take the colimit.
