# Kan extension　`def.kan-extension`
English entry · root `../`
[in graph](../#n=def.kan-extension)　·　[Chinese page (authoritative)](./def.kan-extension.md)

such that for every $G : \mathcal{C}' \to \mathcal{D}$ and every $\gamma : F \implies G \circ p$ there is a **unique** $\widetilde{\gamma} : p_{!}F \implies G$ with

$$\gamma = (\widetilde{\gamma} \circ p) \circ \alpha$$

Equivalently:

$$\operatorname{Hom}(p_{!}F,\ G) \;\cong\; \operatorname{Hom}(F,\ G \circ p)$$

i.e. $p_{!}$ is the **left adjoint** of the precomposition functor $p^{*} = (-) \circ p$. Reversing arrows gives the **right Kan extension** $p_{*} \dashv p^{*}$.
