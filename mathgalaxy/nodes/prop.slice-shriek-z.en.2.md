# The Slice Left Adjoint on the Constant Sheaf　`prop.slice-shriek-z`
English entry · root `../`
[in graph](../#n=prop.slice-shriek-z)　·　[Chinese page (authoritative)](./prop.slice-shriek-z.md)

$$\operatorname{Hom}_{\mathbb{Z}}\bigl(j_{X!}\mathbb{Z},\ M\bigr) = \operatorname{Hom}_{\mathbb{Z}}\bigl(\mathbb{Z},\ j_{X}^{-1}M\bigr) = \operatorname{Hom}\bigl(\mathbf{1}_{X},\ j_{X}^{-1}M\bigr) = \operatorname{Hom}(X,\ M) ✓$$

The last identity uses "the terminal object over $X$ gives $\operatorname{Hom}(\mathbf{1}_{X}, j_X^{-1}M) = M(X) = \operatorname{Hom}(X,M)$" ✓. Comparing with the universal property of $\mathbb{Z}\cdot X$, Yoneda gives the result ✓. ∎
