# continuous　`def.continuous`
English entry · root `../`
[in graph](../#n=def.continuous)　·　[Chinese page (authoritative)](./def.continuous.md)

$$\forall \varepsilon > 0, \exists \delta > 0 : |x - x_0| < \delta \implies |f(x) - f(x_0)| < \varepsilon$$

Equivalent formulation: $\lim_{x \to x_0} f(x) = f(x_0)$ (the limit exists and equals the value of the function).

$f$ is **continuous** (continuous on $\mathbb{R}$) iff it is continuous at every point.

**Uniform continuity** is a stronger requirement: $\delta$ depends only on $\varepsilon$, not on $x_0$.
