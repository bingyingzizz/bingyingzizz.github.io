Statement

Let MMM be a GGG-module (written additively). A map d:G→Md : G \to Md:G→M is called a crossed homomorphism (that is, a 111-cocycle) if

d(g1g2)=d(g1)+g1 d(g2)(g1,g2∈G).d(g_{1} g_{2}) = d(g_{1}) + g_{1}\, d(g_{2}) \qquad (g_{1}, g_{2} \in G).d(g1​g2​)=d(g1​)+g1​d(g2​)(g1​,g2​∈G).

The class given by a fixed element,

dm(g):=g m−m(m∈M)d_{m}(g) := g\, m - m \qquad (m \in M)dm​(g):=gm−m(m∈M)

is called a principal crossed homomorphism (a 111-coboundary). Write Z1(G,M)Z^{1}(G, M)Z1(G,M) for all crossed homomorphisms and B1(G,M)⊆Z1(G,M)B^{1}(G, M) \subseteq Z^{1}(G, M)B1(G,M)⊆Z1(G,M) for all principal ones. Then

H1(G,M)  ≅  Z1(G,M)/B1(G,M).H^{1}(G, M) \;\cong\; Z^{1}(G, M) \big/ B^{1}(G, M) .H1(G,M)≅Z1(G,M)/B1(G,M).

Notes

Reading: a crossed homomorphism is a homomorphism "up to the action" — when the action is trivial it degenerates to an ordinary group homomorphism G→MG \to MG→M, and the principal ones all collapse to 000.

The proof takes one line: in the standard cochain complex C1(G,M)C^{1}(G, M)C1(G,M) is just the set of all maps G→MG \to MG→M, and

δc(g1,g2)=g1c(g2)−c(g1g2)+c(g1),\delta c(g_{1}, g_{2}) = g_{1} c(g_{2}) - c(g_{1} g_{2}) + c(g_{1}),δc(g1​,g2​)=g1​c(g2​)−c(g1​g2​)+c(g1​),

so δc=0  ⟺  c(g1g2)=c(g1)+g1c(g2)\delta c = 0 \iff c(g_{1}g_{2}) = c(g_{1}) + g_{1}c(g_{2})δc=0⟺c(g1​g2​)=c(g1​)+g1​c(g2​), i.e. Z1Z^{1}Z1 is exactly the crossed homomorphisms.

Also C0=MC^{0} = MC0=M and (δ0m)(g)=gm−m(\delta^{0}m)(g) = g m - m(δ0m)(g)=gm−m, hence im⁡δ0=B1\operatorname{im}\delta^{0} = B^{1}imδ0=B1.

Thus H1=ker⁡δ1/im⁡δ0=Z1/B1H^{1} = \ker\delta^{1}/\operatorname{im}\delta^{0} = Z^{1}/B^{1}H1=kerδ1/imδ0=Z1/B1.

∎

Two immediate consequences:

  • When the action is trivial, Z1=Hom⁡(G,M)Z^{1} = \operatorname{Hom}(G, M)Z1=Hom(G,M) and B1=0B^{1} = 0B1=0, so H1(G,M)=Hom⁡(G,M)H^{1}(G, M) = \operatorname{Hom}(G, M)H1(G,M)=Hom(G,M).
  • If GGG is finite, MMM is torsion-free, and the action is trivial, then   ⟹  H1(G,M)=0\implies H^{1}(G, M) = 0⟹H1(G,M)=0 (there is no nontrivial homomorphism from a finite group to a torsion-free group).

Why "crossed": d(g1g2)=d(g1)+g1d(g2)d(g_{1}g_{2}) = d(g_{1}) + g_{1}d(g_{2})d(g1​g2​)=d(g1​)+g1​d(g2​) is exactly the Leibniz formula for "twisting by g1g_{1}g1​ when moving g1g_{1}g1​ out" — the same formula as for a derivation, only with coefficients in a module.
