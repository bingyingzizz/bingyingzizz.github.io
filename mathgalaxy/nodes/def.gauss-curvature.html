白话：二维曲面上「曲率」其实只有一个数，这个数就是高斯曲率 KKK。这里用曲率张量的一个分量算出它，下一节点（绝妙定理）再说明它和 k1k2k_{1}k_{2}k1​k2​ 是同一个数。

曲面 SSS 在点 ppp 的高斯曲率由曲率张量定义为

K(p)=⟨R(∂1,∂2)∂2,∂1⟩det⁡(gij)=R1221g11g22−g122,K(p) = \frac{\langle R(\partial_{1},\partial_{2})\partial_{2},\partial_{1}\rangle}{\det(g_{ij})} = \frac{R_{1221}}{g_{11}g_{22}-g_{12}^{2}},K(p)=det(gij​)⟨R(∂1​,∂2​)∂2​,∂1​⟩​=g11​g22​−g122​R1221​​,

K=⟨R(e1,e2)e2,e1⟩.K = \langle R(e_{1},e_{2})e_{2},e_{1}\rangle .K=⟨R(e1​,e2​)e2​,e1​⟩.

另一方面，若 hijh_{ij}hij​ 是第二基本形式在同一标架下的系数矩阵，则 K=det⁡(hij)=k1k2K = \det(h_{ij}) = k_{1}k_{2}K=det(hij​)=k1​k2​。

⚠️ 符号与指标顺序（本包全包统一）：Rijkℓ=⟨R(∂i,∂j)∂k,∂ℓ⟩R_{ijk\ell} = \langle R(\partial_{i},\partial_{j})\partial_{k},\partial_{\ell}\rangleRijkℓ​=⟨R(∂i​,∂j​)∂k​,∂ℓ​⟩，于是单位球面（K=1K = 1K=1、gij=δijg_{ij} = \delta_{ij}gij​=δij​）上 R1221=1R_{1221} = 1R1221​=1、R1212=−1R_{1212} = -1R1212​=−1。很多书写成「K=R1212/det⁡gK = R_{1212}/\det gK=R1212​/detg」，那用的是另一种指标顺序（或另一种 RRR 的符号），数学上是同一件事。判断约定对不对的检查只有一条：单位球面必须给出 K=1K = 1K=1。

与缩并写法 12gikgjℓRijkℓ\frac{1}{2}g^{ik}g^{j\ell}R_{ijk\ell}21​gikgjℓRijkℓ​ 的关系：二维只有一个独立分量，把四个指标枚举一遍就得到 K=−12gikgjℓRijkℓK = -\frac{1}{2}g^{ik}g^{j\ell}R_{ijk\ell}K=−21​gikgjℓRijkℓ​（本包约定下的符号）。两个写法给的是同一个数，差别只在指标顺序带来的负号。

两条路都通向它：

  • 内蕴方向：RRR 只含 ggg 及其一、二阶导数（Γ\GammaΓ 一阶、RRR 含 ∂Γ\partial\Gamma∂Γ），所以只要知道 III 就能把 KKK 算出来；
  • 外在方向：K=k1k2=det⁡(hij)K = k_{1}k_{2} = \det(h_{ij})K=k1​k2​=det(hij​)，用的是两个主曲率。

两条路给出同一个数，这就是绝妙定理的内容 —— 在那个节点里给证明。

⚠️ KKK 是一个点上的量，与「曲线的曲率」没有直接大小关系：K=1K = 1K=1 的曲面上可以有曲率为 000 的曲线（测地线），K=0K = 0K=0 的柱面上可以有曲率非零的曲线。
