# order and type of an entire function　`def.entire-order`
English entry · root `../`
[in graph](../#n=def.entire-order)　·　[Chinese page (authoritative)](./def.entire-order.md)

⭐ **The order is an upper bound for the “density of zeros”**: if $f$ has order $\rho$ and zeros $z_{n}$ (counted with multiplicity), then $\sum |z_{n}|^{-\rho - \varepsilon} < \infty$ holds for every $\varepsilon > 0$. This (a direct corollary of Jensen's formula) is the first thread connecting “growth” with “distribution of zeros”.

📌 Notation: $\log^{+}$ rather than $\log$, so that no negative numbers appear when $M(r) < 1$ — the behaviour for small $r$ should not affect the order.
