# 拓扑斯态射的导出函子　`prop.topos-morphism-derived`
$R^{n}f_{*}M$ 是 $X' \mapsto H^{n}(f^{-1}(X'), M)$ 的层化
layer 18 · 命题 · 层上同调 · 同调代数+范畴论
