Notes

⭐ "Almost everywhere convergence" sounds weak, but Egorov says: as long as the space has finite measure, it is in fact almost uniform convergence — the price is only discarding a set of arbitrarily small measure.

⚠ "μ(X)<∞\mu(X) < \inftyμ(X)<∞" cannot be omitted. Counterexample: fn=χ(n,n+1)f_n = \chi_{(n, n+1)}fn​=χ(n,n+1)​ on R\mathbb{R}R, converging a.e. to 0, but after discarding any set of finite measure the remainder still has sup⁡=1\sup = 1sup=1, so there is no uniform convergence.

This is the template for "discard a small set in exchange for a good property" (Lusin's theorem follows the same pattern).
