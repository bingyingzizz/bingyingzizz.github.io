# zero object and biproduct　`def.zero-object`
English entry · root `../`
[in graph](../#n=def.zero-object)　·　[Chinese page (authoritative)](./def.zero-object.md)

⚠️ A zero object may fail to exist when the category is not assumed to have one (e.g. $\mathbf{Set}$: the empty set is initial, but the terminal object is a one-point set, so they differ). In $\mathbf{Ab}$ and $A\text{-}\mathbf{Mod}$ it is of course the same $\{0\}$.
