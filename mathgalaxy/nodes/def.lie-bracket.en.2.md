# Lie Bracket　`def.lie-bracket`
English entry · root `../`
[in graph](../#n=def.lie-bracket)　·　[Chinese page (authoritative)](./def.lie-bracket.md)

$$[X,Y]f := X(Yf) - Y(Xf),\qquad f \in C^{\infty}(M).$$

The right-hand side appears to use second derivatives, but second partial derivatives commute, so $[X,Y]f$ contains only first derivatives of $f$ — hence it is still a vector field. Explicitly in a chart,

$$[X,Y] = \sum_{i=1}^{n}\Bigl(\sum_{j=1}^{n}\bigl(X^{j}\partial_{j}Y^{i} - Y^{j}\partial_{j}X^{i}\bigr)\Bigr)\frac{\partial}{\partial x^{i}} .$$
