# Injective Dimension　`def.injective-dimension`
English entry · root `../`
[in graph](../#n=def.injective-dimension)　·　[Chinese page (authoritative)](./def.injective-dimension.md)

- $\operatorname{id}_{R} M = 0 \iff M$ is injective.

- $\operatorname{id}_{R} M \le n \iff \operatorname{Ext}^{k}_{R}(N, M) = 0$ holds for every $N$ and every $k > n$ (note the **second** variable).

- $\operatorname{id}_{R} M$ is the largest degree for which $\operatorname{Ext}^{n}_{R}(-, M)$ is nonzero on some module, with that degree denoted by $n$.

**Examples (over $\mathbb{Z}$)**: $\mathbb{Q}$ is injective because it is a divisible group, so $\operatorname{id}_{\mathbb{Z}}\mathbb{Q} = 0$.
