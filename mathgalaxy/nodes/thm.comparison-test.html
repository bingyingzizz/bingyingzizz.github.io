又称比较判别法

陈述

设 0≤an≤bn0 \le a_n \le b_n0≤an​≤bn​ 对充分大的 nnn 成立。则

  • ∑bn\sum b_n∑bn​ 收敛   ⟹  \implies⟹ ∑an\sum a_n∑an​ 收敛；
  • ∑an\sum a_n∑an​ 发散   ⟹  \implies⟹ ∑bn\sum b_n∑bn​ 发散。

极限形式：若 an,bn>0a_n, b_n > 0an​,bn​>0 且 anbn→L\dfrac{a_n}{b_n} \to Lbn​an​​→L，则 L∈(0,+∞)L \in (0, +\infty)L∈(0,+∞) 时两者同敛散；L=0L = 0L=0 时由 ∑bn\sum b_n∑bn​ 收敛推出 ∑an\sum a_n∑an​ 收敛。

说明

⭐ 这是所有正项级数判据的地基，而它自己只是「部分和单调有界   ⟹  \implies⟹ 收敛」的直接翻译：∑an\sum a_n∑an​ 的部分和被 ∑bn\sum b_n∑bn​ 的部分和压住。

⚠ 前提是非负（或至少最终非负）：有正有负时部分和不再单调，「压住」什么也不意味着。

⚠ 它不是 Kummer 判别法的推论 —— 方向相反：Kummer 判别法的证明本身就要用到「部分和单调有界」这一套（即比较的思想）。把这条删掉会让整包判据失去落脚点。

  • 级数收敛、单调有界定理 ⟹ 本页推出
    非负项级数 + 单调有界   ⟹  \implies⟹ 比较判别法

    设 0≤an≤bn0 \le a_n \le b_n0≤an​≤bn​ 对 n≥N0n \ge N_0n≥N0​ 成立。记 AN:=∑n≤NanA_N := \sum_{n \le N} a_nAN​:=∑n≤N​an​、BN:=∑n≤NbnB_N := \sum_{n \le N} b_nBN​:=∑n≤N​bn​，两者都（最终）单调递增。

    1. 若 ∑bn\sum b_n∑bn​ 收敛，则 {BN}\{B_N\}{BN​} 有界；由 AN≤BN+constA_N \le B_N + \text{const}AN​≤BN​+const（前 N0N_0N0​ 项之差），{AN}\{A_N\}{AN​} 也有界。
    2. 单调有界   ⟹  \implies⟹ {AN}\{A_N\}{AN​} 收敛，即 ∑an\sum a_n∑an​ 收敛。
    3. 第二条是第一条的逆否命题。

    极限形式：设 an/bn→L∈(0,+∞)a_n / b_n \to L \in (0, +\infty)an​/bn​→L∈(0,+∞)，则存在 N0N_0N0​ 使 n≥N0n \ge N_0n≥N0​ 时 L2bn≤an≤2L bn\frac{L}{2} b_n \le a_n \le 2L\, b_n2L​bn​≤an​≤2Lbn​ —— 两边比较即得同敛散性。L=0L = 0L=0 时只有右半边不等式，故只单向成立。∎

    比较判别法对「非负」的依赖是本质的：bnb_nbn​ 收敛给出 {BN}\{B_N\}{BN​} 有界，而 {AN}\{A_N\}{AN​} 有界只有在它单调（即 an≥0a_n \ge 0an​≥0）时才等价于收敛。
