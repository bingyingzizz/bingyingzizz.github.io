# triangulation of a space　`def.triangulation`
English entry · root `../`
[in graph](../#n=def.triangulation)　·　[Chinese page (authoritative)](./def.triangulation.md)

⚠️ Triangulations are highly nonunique. The same $S^{2}$ admits infinitely many genuinely different triangulations (a tetrahedron, an octahedron, arbitrary subdivisions, and so on).

Any quantity defined using a triangulation therefore requires a proof of **independence from the triangulation**. That is what the result on $\chi$ establishes (`thm.euler-characteristic` together with `thm.simplicial-approximation`).

⭐ One-way implication: The realization of a simplicial complex is always triangulable (take the identity), but **some topological spaces are not triangulable**, as discussed in the next section.
