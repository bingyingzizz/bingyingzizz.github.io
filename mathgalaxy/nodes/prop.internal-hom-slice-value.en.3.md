# Values of the Internal Hom　`prop.internal-hom-slice-value`
English entry · root `../`
[in graph](../#n=prop.internal-hom-slice-value)　·　[Chinese page (authoritative)](./prop.internal-hom-slice-value.md)

$$\underline{\operatorname{Hom}}_{\mathbb{Z}}(M,N)(Z) = \operatorname{Hom}_{\mathbb{Z}}\bigl(M\otimes_{\mathbb{Z}}\mathbb{Z}\cdot Z,\ N\bigr) = \operatorname{Hom}_{\mathbb{Z}}\bigl(j_{Z}^{-1}M,\ j_{Z}^{-1}N\bigr),$$

Since $\mathbb{Z}\cdot Z = j_{Z!}\mathbb{Z}$, we get $M\otimes_{\mathbb{Z}}\mathbb{Z}\cdot Z = j_{Z!}j_{Z}^{-1}M$ (see @@prop.slice-shriek-projection@@), and one more application of $j_{Z!}\dashv j_{Z}^{-1}$ gives the last term.
