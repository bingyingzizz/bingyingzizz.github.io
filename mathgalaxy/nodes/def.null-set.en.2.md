## Notes · **draft**
Completeness says "subsets of null sets are measurable". This does **not** hold automatically: the $Borel \sigma$-algebra with Lebesgue measure is not complete — the Cantor set is Borel with measure 0, and some of its subsets are not Borel.

So the usual procedure is first to **complete** the Borel measure (see the next theorem), obtaining the $Lebesgue \sigma$-algebra.
