# 商表示　`def.quotient-representation`
商表示

若 $W\subseteq V$ 是子表示，商空间 $V/W$ 上有良定义的表示作用 $a(v+W)=av+W$；商映射 $V\to V/W$ 是 $A$-线性的。

## 说明
良定义用 $\theta(a)W\subseteq W$。
商表示的维数是 $\dim V-\dim W$。
对群表示作用为 $\rho(g)(v+W)=\rho(g)v+W$。
半单表示的商仍半单，见后续命题。
