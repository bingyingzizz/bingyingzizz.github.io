# 诱导拓扑　`def.induced-topology`
诱导拓扑（Induced Topology）
layer 17 · 定义 · 拓扑斯 · 范畴论

设 $\mathcal{C}'$ 是 site，$f^{-1} : \mathcal{C} \to \mathcal{C}'$ 是任何函子。$\mathcal{C}$ 上的**诱导拓扑**是使 $f^{-1}$ **连续**的最细拓扑。
