# Stone-Weierstrass theorem　`thm.stone-weierstrass`
English entry · root `../`
[in graph](../#n=thm.stone-weierstrass)　·　[Chinese page (authoritative)](./thm.stone-weierstrass.md)

- **Fix $x$ and, for each $y$, take a finite $\max$**: for each $y$, since $g_{xy}(y) = f(y) < f(y) + \varepsilon$ and by continuity, there is an open neighbourhood $V_{y}$ of $y$ on which $g_{xy} < f + \varepsilon$. Since $K$ is compact, finitely many $V_{y_1}, \ldots, V_{y_n}$ cover $K$; put $h_{x} := \max_{j} g_{xy_j} \in \overline{A}$. Then $h_{x} < f + \varepsilon$ holds everywhere, and $h_{x}(x) = f(x) > f(x) - \varepsilon$.
