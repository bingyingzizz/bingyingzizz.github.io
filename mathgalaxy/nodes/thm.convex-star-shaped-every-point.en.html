Statement

Let VVV be a real vector space and C⊆VC \subseteq VC⊆V a convex set. Then for every x0∈Cx_{0} \in Cx0​∈C, CCC is star-shaped with respect to x0x_{0}x0​.

In particular, a nonempty convex set is star-shaped.

Notes

By the definition of convexity, for any x0∈Cx_{0} \in Cx0​∈C and y∈Cy \in Cy∈C the whole segment (1−t)x0+ty(1-t)x_{0} + t y(1−t)x0​+ty (t∈[0,1]t \in [0,1]t∈[0,1]) lies in CCC, that is, CCC is star-shaped with respect to x0x_{0}x0​; the proof is on the edge @@imp.convex-star-shaped-every-point@@.

⚠ For the empty set, "for every x0∈Cx_{0} \in Cx0​∈C" is a universal statement and holds vacuously; but the empty set itself is not star-shaped (it has no star point), see @@def.star-shaped@@. There is no contradiction: this item says "every point is a star point", not "there exists a star point".

📌 Hence "convex set ⟹\Longrightarrow⟹ star-shaped set" holds for nonempty convex sets; written pointwise, the empty set is no longer a counterexample.
