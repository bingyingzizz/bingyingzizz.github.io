陈述

设 A\mathcal{A}A 是阿贝尔范畴，K∙K^{\bullet}K∙ 是 A\mathcal{A}A 中的上链复形。记 Zk:=ker⁡dkZ^{k} := \ker d^{k}Zk:=kerdk（闭链）、Bk:=im⁡dk−1B^{k} := \operatorname{im} d^{k-1}Bk:=imdk−1（上边缘），于是 Hk=Zk/BkH^{k} = Z^{k}/B^{k}Hk=Zk/Bk。则对每个 kkk 有处处正合的列

0⟶Hk⟶coker⁡(dk−1)⟶Zk+1⟶Hk+1⟶0.0 \longrightarrow H^{k} \longrightarrow \operatorname{coker}\bigl(d^{k-1}\bigr) \longrightarrow Z^{k+1} \longrightarrow H^{k+1} \longrightarrow 0.0⟶Hk⟶coker(dk−1)⟶Zk+1⟶Hk+1⟶0.

说明

证明。 dk∘dk−1=0d^{k}\circ d^{k-1} = 0dk∘dk−1=0 说明 dkd^{k}dk 诱导出一个映射

D:coker⁡(dk−1)=Kk/Bk⟶Zk+1,D : \operatorname{coker}(d^{k-1}) = K^{k}/B^{k} \longrightarrow Z^{k+1},D:coker(dk−1)=Kk/Bk⟶Zk+1,

（良定义：Bk⊆ZkB^{k} \subseteq Z^{k}Bk⊆Zk，因为 dkd^{k}dk 把 BkB^{k}Bk 杀死 ✓）。逐段读这条列：

  • Hk=ker⁡DH^{k} = \ker DHk=kerD：DDD 的核是 Zk/BkZ^{k}/B^{k}Zk/Bk，正是 HkH^{k}Hk ✓，这就是左端的正合性；
  • im⁡D=Bk+1\operatorname{im}D = B^{k+1}imD=Bk+1：DDD 的像就是 dk(Kk)=Bk+1d^{k}(K^{k}) = B^{k+1}dk(Kk)=Bk+1 ✓，这就是中间的正合性；
  • coker⁡D=Zk+1/Bk+1=Hk+1\operatorname{coker}D = Z^{k+1}/B^{k+1} = H^{k+1}cokerD=Zk+1/Bk+1=Hk+1 ✓，即右端的正合性。

三段合起来就是整条列处处正合 ✓。∎ ⭐ 这条列常常写成两条短正合列再拼起来：

0→Hk→Kk/Bk→Bk+1→0,0→Bk+1→Zk+1→Hk+1→0.0 \to H^{k} \to K^{k}/B^{k} \to B^{k+1} \to 0, \qquad 0 \to B^{k+1} \to Z^{k+1} \to H^{k+1} \to 0.0→Hk→Kk/Bk→Bk+1→0,0→Bk+1→Zk+1→Hk+1→0.

后面构造谱序列时用的正是这两条。

⭐ 用途：它把「同调」拆成两条只管闭链与上边缘的短正合列。谱序列的全部技术内容就是在这些短正合列之间做逐步比较。
