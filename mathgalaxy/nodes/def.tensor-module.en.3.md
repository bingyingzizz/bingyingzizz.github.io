# Tensor Product of Modules　`def.tensor-module`
English entry · root `../`
[in graph](../#n=def.tensor-module)　·　[Chinese page (authoritative)](./def.tensor-module.md)

$$\widetilde{B} : M \otimes_{R} N \longrightarrow P, \qquad \widetilde{B}(m \otimes n) = B(m, n).$$

If $R$ is commutative, $r \cdot (m \otimes n) := (m r) \otimes n$ makes $M \otimes_{R} N$ an $R$-module.

## Notes · **draft**
**How to read it**: each of the three relations does one job — the first two say that $\otimes$ is additive in each variable separately, and the third $m r \otimes n = m \otimes r n$ says "the action of $R$ can be moved from one side to the other". Over a commutative ring the third reads $r m \otimes n = m \otimes r n$, which is the most familiar form.
