陈述

设 FFF 是特征 0 的域，f∈F[x]f \in F[x]f∈F[x] 非零，KKK 是 fff 的分裂域。则

fff 的根可以用根式（四则运算与开 nnn 次方）从 FFF 的元素表示出来   ⟺  \iff⟺ Gal⁡(K/F)\operatorname{Gal}(K/F)Gal(K/F) 是可解群。

说明

⚠ 骨架。两个方向各有一条主线，本图只记路线：

  • ⇐\Leftarrow⇐（可解   ⟹  \implies⟹ 根式可解）：把可解列 G=G0⊵G1⊵⋯⊵{e}G = G_{0} \trianglerighteq G_{1} \trianglerighteq \cdots \trianglerighteq \{e\}G=G0​⊵G1​⊵⋯⊵{e} 翻译成域塔 F=E0⊆E1⊆⋯⊆KF = E_{0} \subseteq E_{1} \subseteq \cdots \subseteq KF=E0​⊆E1​⊆⋯⊆K，每一步商群是循环群；循环扩张在 char 0 下可以靠添加单位根 + Kummer 理论用开方实现。
  •   ⟹  \implies⟹（根式可解   ⟹  \implies⟹ 可解）：反过来，把根式塔翻译成群塔，用「循环扩张的伽罗瓦群是循环群」（这一步又靠伽罗瓦对应 + 可解性对子群与商群封闭），拼出可解列。

⭐ 为什么必须 char 0：可解   ⟹  \implies⟹ 根式那一步要用 nnn 次单位根与 Kummer 理论；char ppp 时 xp−x−ax^{p} - x - axp−x−a 这类 Artin–Schreier 扩张取代了纯开方扩张，结论要改写。

📌 这条定理是「五次方程」那条线唯一的入口：它把「有没有根式公式」这个分析/代数混着的问题，换成一个纯群论问题（SnS_{n}Sn​ 可解   ⟺  n≤4\iff n \le 4⟺n≤4，见「对称群的可解性」）。

定义引用 6

  • 伽罗瓦群 → 本页定义引用

    定理的左端是「根式写成」，右端是 Gal⁡(f)\operatorname{Gal}(f)Gal(f) 的可解性 —— 桥就是它。

  • 可解群 → 本页定义引用

    「可解」在这里是群论的可解（有正规列、商群阿贝尔），与「方程可解」不是同一个意思 —— 定理说的正是两者等价。

  • 分裂域 → 本页定义引用

    要谈「fff 的伽罗瓦群」得先有 fff 的分裂域。

  • 可解性对子群与商群封闭 → 本页定义引用

    两个方向都要「可解性对商群/子群封闭」：塔的每一步商群可解   ⟺  \iff⟺ 整个群可解。

  • 单位根 → 本页定义引用

    根式可解   ⟹  \implies⟹ 可解那条路线必须先添加 nnn 次单位根（否则开方写不出来）。

  • 伽罗瓦基本定理 → 本页定义引用

    「根式塔 ↔\leftrightarrow↔ 群塔」的翻译全靠基本定理：每添加一次开方对应一个循环扩张，域塔对应子群链、正规性对应正规子群，于是域的可解性变成群的可解性。
