(a,b)∼(c,d):  ⟺  a+d=b+c(a, b) \sim (c, d) :\iff a + d = b + c(a,b)∼(c,d):⟺a+d=b+c

（直观：(a,b)(a, b)(a,b) 代表 a−ba - ba−b；这条等价关系说的正是「差相同」。）它确实是一个等价关系。令

Z:=(N×N)/∼\mathbb{Z} := (\mathbb{N} \times \mathbb{N}) / \simZ:=(N×N)/∼

Abstract reviewed

The integers as a quotient: on N×N\mathbb{N} \times \mathbb{N}N×N put (a,b)∼(c,d)  ⟺  a+d=b+c(a,b) \sim (c,d) \iff a + d = b + c(a,b)∼(c,d)⟺a+d=b+c (same difference) and set Z:=(N×N)/∼\mathbb{Z} := (\mathbb{N} \times \mathbb{N})/{\sim}Z:=(N×N)/∼, writing [a,b][a,b][a,b] for a−ba - ba−b. Addition, multiplication and order are defined on representatives and must be checked independent of them. Motivation: subtraction fails in N\mathbb{N}N, but the pair 3−53 - 53−5 is meaningful, so the difference itself is taken as the object; [0,0][0,0][0,0] and [b,a][b,a][b,a] supply the missing zero and inverses. N\mathbb{N}N embeds via a↦[a,0]a \mapsto [a,0]a↦[a,0].

Statement reviewed

On N×N\mathbb{N} \times \mathbb{N}N×N define

(a,b)∼(c,d):  ⟺  a+d=b+c(a, b) \sim (c, d) :\iff a + d = b + c(a,b)∼(c,d):⟺a+d=b+c

(intuition: (a,b)(a, b)(a,b) stands for a−ba - ba−b; this equivalence relation says precisely that the differences are equal). It really is an equivalence relation. Put

Z:=(N×N)/∼\mathbb{Z} := (\mathbb{N} \times \mathbb{N}) / \simZ:=(N×N)/∼

Its elements are written [a,b][a, b][a,b] (that is, a−ba - ba−b). The operations and order on Z\mathbb{Z}Z (both must first be checked to be independent of the choice of representatives):

[a,b]+[c,d]:=[a+c, b+d][a, b] + [c, d] := [a + c,\ b + d][a,b]+[c,d]:=[a+c, b+d][a,b]⋅[c,d]:=[ac+bd, ad+bc][a, b] \cdot [c, d] := [ac + bd,\ ad + bc][a,b]⋅[c,d]:=[ac+bd, ad+bc][a,b]≤[c,d]:  ⟺  a+d≤b+c[a, b] \le [c, d] :\iff a + d \le b + c[a,b]≤[c,d]:⟺a+d≤b+c

Here addition and order come from those of N\mathbb{N}N, and the formula for multiplication is copied from (a−b)(c−d)=ac+bd−(ad+bc)(a - b)(c - d) = ac + bd - (ad + bc)(a−b)(c−d)=ac+bd−(ad+bc).

Notes reviewed

⭐ The motivation in one sentence: subtraction does not work inside N\mathbb{N}N (3−53 - 53−5 does not exist), yet the pair "3−53 - 53−5" always makes sense — so one takes the difference itself as a new object.

By-product: Z\mathbb{Z}Z has an additive zero [0,0]=0[0, 0] = 0[0,0]=0 and additive inverses −[a,b]=[b,a]-[a, b] = [b, a]−[a,b]=[b,a] — precisely what N\mathbb{N}N lacks.

⚠ Inside Z\mathbb{Z}Z, the copy of N\mathbb{N}N is embedded via a↦[a,0]a \mapsto [a, 0]a↦[a,0] (injective, and preserving the operations and the order), so writing 3∈Z3 \in \mathbb{Z}3∈Z uses this embedding — that step cannot be skipped.
