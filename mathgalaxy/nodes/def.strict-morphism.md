# 严格态射　`def.strict-morphism`

态射 $f : X \to Y$ 叫**严格的**（strict），如果它在**余像**上的分解 $X \twoheadrightarrow \operatorname{coim} f \to \operatorname{im} f \hookrightarrow Y$ 中间那一步是**同构** —— 即「余像与像之间的自然映射」可逆。
