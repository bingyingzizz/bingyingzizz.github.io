Statement

A standard list of maps that move regions to standard position (H\mathbb{H}H = upper half-plane, D\mathbb{D}D = unit disc):

  1. H→D\mathbb{H} \to \mathbb{D}H→D: z↦z−iz+iz \mapsto \dfrac{z - i}{z + i}z↦z+iz−i​;
  2. angle { 0<arg⁡z<α }\{\, 0 < \arg z < \alpha \,\}{0<argz<α} →H\to \mathbb{H}→H: z↦zπ/αz \mapsto z^{\pi/\alpha}z↦zπ/α;
  3. strip { 0<Im⁡z<π }\{\, 0 < \operatorname{Im} z < \pi \,\}{0<Imz<π} →H\to \mathbb{H}→H: z↦ezz \mapsto e^{z}z↦ez;
  4. slit plane C∖(−∞,0]\mathbb{C} \setminus (-\infty, 0]C∖(−∞,0] →H\to \mathbb{H}→H: the principal branch of z\sqrt{z}z​ or log⁡z\log zlogz;
  5. automorphisms of D→D\mathbb{D} \to \mathbb{D}D→D: z↦eiθz−a1−aˉzz \mapsto e^{i\theta}\dfrac{z - a}{1 - \bar a z}z↦eiθ1−aˉzz−a​, ∣a∣<1|a| < 1∣a∣<1.

Notes

⭐ This table is the handbook of the chapter on conformal maps: when a new region appears, first try to move it to H\mathbb{H}H or D\mathbb{D}D with the maps in the table (power, exponential, logarithm, fractional linear), and then Riemann 映射定理 tells you this is always possible — the only question is whether a formula can be written.

Why these maps are right: zkz^{k}zk opens an angle by a factor kkk (k=π/αk = \pi/\alphak=π/α); eze^{z}ez rolls a horizontal strip into an angle; log⁡\loglog conversely flattens a slit plane into a strip; fractional linear maps preserve circles (保圆性), so they interchange half-planes and discs.

⚠️ Each map must specify which branch is taken: zπ/αz^{\pi/\alpha}zπ/α and log⁡\loglog are multivalued, and the formulas above mean the principal branch (or a fixed branch).
