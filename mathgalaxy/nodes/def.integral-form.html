陈述

在做什么：把「nnn-形式在一个定向区域上积起来」说清楚 —— 它是唯一能自然积分的东西，因为换元时只有最高次外形式的变换因子恰好是行列式（不带绝对值）。

设 U⊆RnU\subseteq\mathbb{R}^{n}U⊆Rn 开，ω=f dx1∧⋯∧dxn\omega = f\,\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}ω=fdx1∧⋯∧dxn 是紧支的 nnn-形式。定义

∫Uω:=∫Uf(x) dx1⋯dxn,\int_{U}\omega := \int_{U}f(x)\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n},∫U​ω:=∫U​f(x)dx1⋯dxn,

右边是通常的（Lebesgue 或 Riemann）积分，dx1⋯dxn\mathrm{d}x^{1}\cdots\mathrm{d}x^{n}dx1⋯dxn 记 Lebesgue 测度。良定性：若 y=ψ(x)y = \psi(x)y=ψ(x) 是保向微分同胚，则

ω=(f∘ψ−1)det⁡(∂x∂y) dy1∧⋯∧dyn,\omega = (f\circ\psi^{-1})\det\Bigl(\frac{\partial x}{\partial y}\Bigr)\,\mathrm{d}y^{1}\wedge\cdots\wedge\mathrm{d}y^{n},ω=(f∘ψ−1)det(∂y∂x​)dy1∧⋯∧dyn,

而换元公式里出现的正是同一个 det⁡\detdet（不是 ∣det⁡∣\lvert\det\rvert∣det∣），所以积分不变。于是在定向流形 MMM 上取保向图册与单位分解 {ρα}\{\rho_{\alpha}\}{ρα​}，可整体定义

∫Mω:=∑α∫Uαρα ω.\int_{M}\omega := \sum_{\alpha}\int_{U_{\alpha}}\rho_{\alpha}\,\omega .∫M​ω:=α∑​∫Uα​​ρα​ω.

说明

为什么偏偏是 nnn-形式：换元时 dx1∧⋯∧dxn\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}dx1∧⋯∧dxn 的系数变换是 det⁡\detdet，与积分换元公式里的 det⁡\detdet 精确匹配（保向时无绝对值）。k<nk<nk<n 的形式要积分，得先选一个 kkk 维子流形把它拉回去 —— 那就是「形式在子流形上的积分」。

定向不可省：把 ψ\psiψ 换成反向的，det⁡\detdet 变号、积分变号。无定向时能积的只有密度 ∣ω∣\lvert\omega\rvert∣ω∣ —— 面积元 dA\mathrm{d}AdA 就是密度（def.area-element）。

与面积元的接口：曲面上 dA=det⁡g du∧dv\mathrm{d}A = \sqrt{\det g}\,\mathrm{d}u\wedge\mathrm{d}vdA=detg​du∧dv，在定向曲面上积分就是面积。这里 det⁡g\sqrt{\det g}detg​ 是「密度」侧的因子、du∧dv\mathrm{d}u\wedge\mathrm{d}vdu∧dv 是「形式」侧的定向，两者都写对符号才不会错。

单位分解为什么够用：ω\omegaω 紧支，只有有限多个 ραω\rho_{\alpha}\omegaρα​ω 非零，每个支在保向卡里，于是化到 Rn\mathbb{R}^{n}Rn 的情形。没有紧支时用「绝对可积」代替，本图不展开。

⚠️ 记号：∫Mω\int_{M}\omega∫M​ω 只依赖 ω\omegaω 与定向，不依赖图册与单位分解（两种不同选取的差可以逐项抵消）。这一点是 Stokes 定理能否写下来的前提。

它指向谁（出边）

推出 2

  • 本页 ⟹ Stokes 定理推出
    一元微积分基本定理   ⟹  \implies⟹ Stokes 定理

    化到半空间。 用单位分解把 ω\omegaω 拆成有限个支在保向卡里的形式，每块化到 Hn={xn≤0}\mathbb{H}^{n} = \{x^{n}\le 0\}Hn={xn≤0} 中的方块 QQQ 上，于是只需证 ∫Qdω=∫∂Qω\int_{Q}\mathrm{d}\omega = \int_{\partial Q}\omega∫Q​dω=∫∂Q​ω。

    写出分量。 记 dxi^\widehat{\mathrm{d}x^{i}}dxi 为「略去该因子」，则任意 (n−1)(n-1)(n−1)-形式可唯一写成

    ω=∑i=1n(−1)i−1fi dx1∧⋯dxi^∧⋯∧dxn,\omega = \sum_{i=1}^{n}(-1)^{i-1}f_{i}\,\mathrm{d}x^{1}\wedge\cdots\widehat{\mathrm{d}x^{i}}\wedge\cdots\wedge\mathrm{d}x^{n},ω=i=1∑n​(−1)i−1fi​dx1∧⋯dxi∧⋯∧dxn,

    于是 dω=∑i∂ifi dx1∧⋯∧dxn\mathrm{d}\omega = \sum_{i}\partial_{i}f_{i}\,\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}dω=∑i​∂i​fi​dx1∧⋯∧dxn。

    逐项积分。 对 i<ni<ni<n，fif_{i}fi​ 在 xix^{i}xi 方向有紧支，由 Fubini 定理与一元微积分基本定理

    ∫Q∂ifi dx1⋯dxn=0.\int_{Q}\partial_{i}f_{i}\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n} = 0 .∫Q​∂i​fi​dx1⋯dxn=0.

    只剩 i=ni = ni=n：∫Q∂nfn dx1⋯dxn=∫fn(x1,…,xn−1,0) dx1⋯dxn−1\int_{Q}\partial_{n}f_{n}\ \mathrm{d}x^{1}\cdots\mathrm{d}x^{n} = \int f_{n}(x^{1},\ldots,x^{n-1},0)\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n-1}∫Q​∂n​fn​ dx1⋯dxn=∫fn​(x1,…,xn−1,0)dx1⋯dxn−1 —— 而这正是 ω\omegaω 限制到边界 {xn=0}\{x^{n} = 0\}{xn=0} 上的积分（诱导定向使两个符号一致）。

    拼回去。 各块相加时，内部边界出现两次、方向相反、互相抵消，剩下恰好是 ∂M\partial M∂M 上的积分。∎

    ⚠️ 符号全部来自「诱导定向 = 外法向在前」这一条约定；约定改一个字，整条公式就差一个负号。

  • 本页 ⟹ 流形上的换元公式推出
    保向不变性 + 单位分解   ⟹  \implies⟹ 流形上的换元公式

    （1）拆到卡里。 设 M,NM,NM,N 各有保向图册，取从属于它们的单位分解 {ρα}\{\rho_{\alpha}\}{ρα​}（在 MMM 上）与 {σβ}\{\sigma_{\beta}\}{σβ​}（在 NNN 上）。把 ω\omegaω 写成 ∑βσβω\sum_{\beta}\sigma_{\beta}\omega∑β​σβ​ω，每一项支在一张保向卡 Vβ⊆NV_{\beta}\subseteq NVβ​⊆N 里；f∗f^{\ast}f∗ 保求和，故只需处理「ω\omegaω 支在一张卡里」的情形。再用 MMM 侧的 {ρα}\{\rho_{\alpha}\}{ρα​} 把 f∗ωf^{\ast}\omegaf∗ω 拆开。有限多项相加，逐项证完即可。

    （2）化到 Rn\mathbb{R}^{n}Rn。 于是只需处理开集之间的微分同胚 g:U→Vg : U\to Vg:U→V（U,V⊆RnU,V\subseteq\mathbb{R}^{n}U,V⊆Rn）与 ω=β dy1∧⋯∧dyn\omega = \beta\,\mathrm{d}y^{1}\wedge\cdots\wedge\mathrm{d}y^{n}ω=βdy1∧⋯∧dyn。拉回给出

    g∗ω=(β∘g) det⁡(∂g∂x) dx1∧⋯∧dxn,g^{\ast}\omega = (\beta\circ g)\,\det\Bigl(\frac{\partial g}{\partial x}\Bigr)\,\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n} ,g∗ω=(β∘g)det(∂x∂g​)dx1∧⋯∧dxn,

    因为 g∗(dy1∧⋯∧dyn)g^{\ast}(\mathrm{d}y^{1}\wedge\cdots\wedge\mathrm{d}y^{n})g∗(dy1∧⋯∧dyn) 是 UUU 上的顶次形式，其唯一系数正是 Jacobi 行列式（顶次外形式在微分同胚下按 det⁡\detdet 变换 —— 这正是 def.integral-form 的良定性所用的那一条）。

    （3）用一次换元公式。

    ∫Ug∗ω=∫U(β∘g) det⁡(∂g∂x)dx=±∫U(β∘g)∣det⁡(∂g∂x)∣dx=±∫Vβ dy,\int_{U}g^{\ast}\omega = \int_{U}(\beta\circ g)\,\det\Bigl(\frac{\partial g}{\partial x}\Bigr)\mathrm{d}x = \pm\int_{U}(\beta\circ g)\Bigl|\det\Bigl(\frac{\partial g}{\partial x}\Bigr)\Bigr|\mathrm{d}x = \pm\int_{V}\beta\,\mathrm{d}y ,∫U​g∗ω=∫U​(β∘g)det(∂x∂g​)dx=±∫U​(β∘g)​det(∂x∂g​)​dx=±∫V​βdy,

    中间的 ±\pm± 只在 det⁡<0\det<0det<0 时出现；最后一步就是 Rn\mathbb{R}^{n}Rn 上的换元公式（它自带 ∣det⁡∣|\det|∣det∣）。ggg 保向等价于 det⁡>0\det>0det>0 处处成立（UUU 连通时），此时取 +++。

    （4）拼回去。 逐项相加，再用单位分解「和为一」把系数约掉，得 ∫Mf∗ω=ε∫Nω\int_{M}f^{\ast}\omega = \varepsilon\int_{N}\omega∫M​f∗ω=ε∫N​ω。∎

    ⭐ 绝对值的有无就是「有没有定向」：nnn-形式自带符号，故换元带 det⁡\detdet；密度不带符号，故换元带 ∣det⁡∣|\det|∣det∣。两条公式的差别全在这里。

定义引用 3

  • Stokes 定理 用到 本页定义引用

    定理两边都是「形式的积分」；没有 ∫Mω\int_{M}\omega∫M​ω 的定义就写不出这条等式。

  • 链上的积分 用到 本页定义引用

    链上的积分最后落在 ∫[0,1]kf\int_{[0,1]^{k}}f∫[0,1]k​f 上，那正是 nnn-形式在开集上积分的那套定义（取 UUU 为包含方块的开集）；换元时 det⁡\detdet 与换元公式的匹配也来自这条。

  • 诱导体积 用到 本页定义引用

    体积是积分 ∫NdAN\int_{N}\mathrm{d}A_{N}∫N​dAN​；「怎么在流形上积」的记账（保向卡 + 单位分解）不重写，直接引用那条定义。

定义引用 2

  • 可定向曲面 → 本页定义引用

    最高次形式要在定向流形上积分；反向的图册会让积分变号。

  • 微分形式 → 本页定义引用

    被积对象是最高次形式；积分的定义逐字用到「kkk-形式 = 交错型 + 光滑系数」。
