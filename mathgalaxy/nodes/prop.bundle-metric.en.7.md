# Fiber Metric on a Vector Bundle　`prop.bundle-metric`
English entry · root `../`
[in graph](../#n=prop.bundle-metric)　·　[Chinese page (authoritative)](./prop.bundle-metric.md)

**A fibre metric is not a Riemannian metric on $E$**: $E$ itself is a manifold and can carry a Riemannian metric, but that measures both fibre and base directions, whereas here only the fibre direction is measured. For $TM$ the Riemannian metric happens to serve both roles, which is the easiest place to confuse them.
