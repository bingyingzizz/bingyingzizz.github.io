# the solution set functor is representable　`prop.solution-functor-representable`

## Notes · **draft**
**Proof.** A $k$-algebra homomorphism $k[t_{1},\ldots,t_{n}]/(f_{1},\ldots,f_{r}) \to A$ is determined entirely by the images of the $t_{i}$, and these images must be chosen so that each $f_{i}$ maps to $0$ ✓ — thus the set of these homomorphisms is precisely $S(A)$ ✓. ∎
