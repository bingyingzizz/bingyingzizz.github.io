# Inverse Function Theorem　`thm.inverse-function`
English entry · root `../`
[in graph](../#n=thm.inverse-function)　·　[Chinese page (authoritative)](./thm.inverse-function.md)

⚠ It belongs to the same family as `thm.regular-value` and `cor.rank-theorem`: the rank theorem says "a constant-rank map locally has only a standard form", and the inverse function theorem is the case $r = n = m$.

The full proof is on the edge (reduce to $Df(a) = I$, build a local inverse of $f$ by the contraction mapping principle, then solve for $Dg$ from $f \circ g = \mathrm{id}$).

> Proofs of the edges are still Chinese only: `proofs/`; the Chinese page remains authoritative.
