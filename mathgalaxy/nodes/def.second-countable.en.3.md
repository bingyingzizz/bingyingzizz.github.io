# second countable space　`def.second-countable`
English entry · root `../`
[in graph](../#n=def.second-countable)　·　[Chinese page (authoritative)](./def.second-countable.md)

**For metrizable spaces the three countability properties coincide**: separable $\iff$ Lindelöf $\iff$ second countable. Hence the Urysohn theorem can also be read as "regular $+$ separable".

**Heredity**: subspaces inherit second countability (intersect basic elements with the subspace; still countable); quotient spaces do not (the quotient map crushes a countable base into a much coarser topology).

⚠️ The converse fails: an uncountable discrete space is first countable and metrizable, but not second countable (it has no countable dense subset).
