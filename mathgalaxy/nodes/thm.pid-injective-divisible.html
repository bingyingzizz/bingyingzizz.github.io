主理想整环上，内射当且仅当可除

陈述

设 RRR 是主理想整环（例如 Z\mathbb{Z}Z 或 k[x]k[x]k[x]），MMM 是 RRR-模。则 MMM 内射，当且仅当 MMM 可除，即

∀a≠0, ∀y∈M, ∃x∈M,ax=y.\forall a \ne 0,\ \forall y \in M,\ \exists x \in M, \qquad a x = y .∀a=0, ∀y∈M, ∃x∈M,ax=y.

特别地：Z\mathbb{Z}Z-模内射当且仅当它是可除群。

说明

可除   ⟹  \implies⟹ 内射（用 Baer 判据）：设 J⊆RJ \subseteq RJ⊆R 是理想，f:J→If : J \to If:J→I。主理想整环里 J=(a)J = (a)J=(a)。若 a=0a = 0a=0 则 J=0J = 0J=0，取 x=0x = 0x=0；若 a≠0a \ne 0a=0，记 y:=f(a)y := f(a)y:=f(a)，由可除性取 x∈Ix \in Ix∈I 使 ax=ya x = yax=y。于是对 ra∈Jr a \in Jra∈J 有 f(ra)=rf(a)=rax=(ra)xf(r a) = r f(a) = r a x = (r a) xf(ra)=rf(a)=rax=(ra)x ✓，即 fff 由「乘 xxx」给出。

内射   ⟹  \implies⟹ 可除：设 a≠0a \ne 0a=0、y∈Iy \in Iy∈I。把 Baer 判据用在理想 (a)(a)(a) 与映射 a↦ya \mapsto ya↦y 上，得 xxx 使 ax=ya x = yax=y ✓。

Z\mathbb{Z}Z 的情形就是 R=ZR = \mathbb{Z}R=Z（主理想整环），此时 RRR-模即阿贝尔群（prop.zmod-is-ab）✓。

⭐ 一句话记住：「除以 aaa」就是「沿 (a)↣R(a) \rightarrowtail R(a)↣R 延拓」。主理想整环上理想结构最简单，Baer 判据就退化成一道除法题。

    Baer 判据 + 主理想   ⟹  \implies⟹ 内射即除

    （可除   ⟹  \implies⟹ 内射） 用 Baer 判据。设 J⊆RJ \subseteq RJ⊆R 是理想，f:J→If : J \to If:J→I。主理想整环里 J=(a)J = (a)J=(a)。

    • a=0a = 0a=0：J=0J = 0J=0，取 x=0x = 0x=0 即可；
    • a≠0a \ne 0a=0：记 y:=f(a)y := f(a)y:=f(a)，由可除性取 x∈Ix \in Ix∈I 使 ax=ya x = yax=y。于是对 ra∈Jr a \in Jra∈J：f(ra)=rf(a)=rax=(ra)xf(r a) = r f(a) = r a x = (r a) xf(ra)=rf(a)=rax=(ra)x ✓，即 fff 就是「乘 xxx」。

    故延拓总存在，III 内射 ✓。

    （内射   ⟹  \implies⟹ 可除） 设 a≠0a \ne 0a=0、y∈Iy \in Iy∈I。把 Baer 判据用在理想 (a)(a)(a) 与映射 a↦ya \mapsto ya↦y 上，得 x∈Ix \in Ix∈I 使 ax=ya x = yax=y ✓。

    Z\mathbb{Z}Z 是主理想整环，而 Z\mathbb{Z}Z-模即阿贝尔群（prop.zmod-is-ab），故「内射『Z\mathbb{Z}Z-模』」与「可除群」是同一件事 ✓。∎
