## Notes · **draft**
**How to read the three axioms**: the first says that $\nabla_{X}Y$ at a point depends only on the value of $X$ at that point (otherwise it would not count as "along a direction"); the third says that it is not tensorial in $Y$ — differentiation must see how $Y$ changes. This asymmetry is exactly the boundary between a "connection" and a "tensor".
