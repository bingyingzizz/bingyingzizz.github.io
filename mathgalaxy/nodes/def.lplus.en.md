## Statement · **draft**
Fix a measure space $(X, \mathcal{M}, \mu )$. Denote by $L^+$ the set of all **measurable** functions with values in the **extended** nonnegative reals:

$L^+ := \{ f : X \to [0, +\infty] : f$ **measurable** $\}$
