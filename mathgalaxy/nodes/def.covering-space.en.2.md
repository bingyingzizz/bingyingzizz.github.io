# covering space　`def.covering-space`
English entry · root `../`
[in graph](../#n=def.covering-space)　·　[Chinese page (authoritative)](./def.covering-space.md)

is a homeomorphism. If every point of $B$ has an evenly covered neighbourhood, then $p$ is a **covering map**, $E$ is a **covering space** of $B$, and $B$ is called the **base space**.

**Constructive examples**:
- $p(t) = e^{2\pi i t}$, $p : \mathbb{R} \to S^{1}$: near the image of each $t$, the preimage $p^{-1}(U)$ consists of $\mathbb{Z}$ copies of the same arc;
- $p(z) = z^{n}$, $p : S^{1} \to S^{1}$: an $n$-sheeted covering;
- if $B$ is path connected and locally path connected, the cardinality of $p^{-1}(b)$ is independent of $b$; this cardinality is called the **number of sheets**.
