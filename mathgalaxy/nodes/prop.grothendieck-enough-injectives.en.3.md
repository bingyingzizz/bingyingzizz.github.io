# enough injectives　`prop.grothendieck-enough-injectives`
English entry · root `../`
[in graph](../#n=prop.grothendieck-enough-injectives)　·　[Chinese page (authoritative)](./prop.grothendieck-enough-injectives.md)

**What "enough" means**: not "there are many injective objects", but "every object embeds into some injective object". This condition is about the **category as a whole** and cannot be checked object by object.

**Where it is used**: $A\text{-}\mathbf{Mod}$, $\operatorname{Ind}(\mathcal{C})$, $\mathbf{Ab}(\mathcal{T})$ on a topos, $\mathrm{CondAb}$ — all are Grothendieck categories, so right derived functors, derived categories, and spectral sequences are all available on them.
