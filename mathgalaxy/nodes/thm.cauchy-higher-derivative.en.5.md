# Cauchy Integral Formula for Derivatives　`thm.cauchy-higher-derivative`
English entry · root `../`
[in graph](../#n=thm.cauchy-higher-derivative)　·　[Chinese page (authoritative)](./thm.cauchy-higher-derivative.md)

⭐ This is the **great watershed** between complex and real analysis: a real function can be once differentiable but not twice (e.g. $x|x|$), whereas a complex function that is once differentiable is infinitely differentiable.

⚠ "Holomorphic" itself does **not** assume that $f'$ is continuous — continuity is **derived** from this formula, not assumed.

This is exactly the value of Goursat's step: first remove the superfluous hypothesis, then earn it back as a conclusion.
