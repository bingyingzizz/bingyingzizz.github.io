又称赋值谱

陈述

白话：把环 AAA 的元素「量大小」的所有方式收集起来，就得到 adic 谱。每个点是一个「绝对值」（valuation，赋值），A+A^+A+ 的作用是筛掉「把某个有界元量成 >1>1>1」的那些点。这是 Spec⁡\operatorname{Spec}Spec 的「带大小」版本 —— Spec⁡\operatorname{Spec}Spec 只记「哪些理想的元素为零」，Spa⁡\operatorname{Spa}Spa 还记「多小」。

先约定术语。赋值是「量大小」的函数 ∣⋅∣:A→Γ∪{0}|\cdot| : A \to \Gamma \cup \{0\}∣⋅∣:A→Γ∪{0}（Γ\GammaΓ 是乘法写法的全序阿贝尔群，想成 R>0\mathbb{R}_{>0}R>0​ 即可），满足

∣0∣=0,∣1∣=1,∣xy∣=∣x∣ ∣y∣,∣x+y∣≤max⁡(∣x∣,∣y∣).|0| = 0, \quad |1| = 1, \quad |xy| = |x|\,|y|, \quad |x + y| \le \max(|x|, |y|).∣0∣=0,∣1∣=1,∣xy∣=∣x∣∣y∣,∣x+y∣≤max(∣x∣,∣y∣).

两个赋值 ∣⋅∣,∣⋅∣1|\cdot|, |\cdot|_1∣⋅∣,∣⋅∣1​ 等价，如果存在保序的群同构使 ∣x∣1=σ(∣x∣)|x|_1 = \sigma(|x|)∣x∣1​=σ(∣x∣) 对一切 xxx —— 也就是「它们给 AAA 排出的大小顺序完全一样」，只是「标尺」换了。Spa⁡\operatorname{Spa}Spa 取的是赋值的等价类（所以同一个点不会因为标尺不同重复计数）。直觉：∣x∣|x|∣x∣ 是「xxx 到 000 的距离」，∣x∣≤1|x| \le 1∣x∣≤1 是「xxx 有界」；ppp-进绝对值 ∣pnu∣=p−n|p^{n}u| = p^{-n}∣pnu∣=p−n（uuu 与 ppp 互素）就是标准例子。

设 (A,A+)(A, A^+)(A,A+) 是离散 Huber pair。adic 谱

Spa⁡(A,A+):={ ∣⋅∣:A→Γ∪{0} ∣ ∣A+∣≤1 }/∼\operatorname{Spa}(A, A^+) := \bigl\{\, |\cdot| : A \to \Gamma \cup \{0\} \ \big|\ |A^+| \le 1 \,\bigr\} \big/ \simSpa(A,A+):={∣⋅∣:A→Γ∪{0} ​ ∣A+∣≤1}/∼

是 AAA 上「在 A+A^+A+ 上 ≤1\le 1≤1」的那些赋值（即 A+A^+A+ 里每个元素都算有界）的等价类全体。拓扑由有理开集给出：对 f,g1,…,gn∈Af, g_1, \ldots, g_n \in Af,g1​,…,gn​∈A，

U ⁣(g1,…,gnf):={ x:∣gi(x)∣≤∣f(x)∣≠0 对一切 i }.U\!\left(\tfrac{g_1, \ldots, g_n}{f}\right) := \bigl\{\, x : |g_i(x)| \le |f(x)| \ne 0 \ \text{对一切 } i \,\bigr\}.U(fg1​,…,gn​​):={x:∣gi​(x)∣≤∣f(x)∣=0 对一切 i}.

这些有理开集构成一组基，Spa⁡(A,A+)\operatorname{Spa}(A,A^+)Spa(A,A+) 是 spectral space（谱空间：同胚于某个环的素谱的拓扑空间；等价刻画是「紧、T0T_0T0​、有紧开集作基」）。

说明

⭐ 赋值满足强三角不等式 ∣x+y∣≤max⁡(∣x∣,∣y∣)|x+y| \le \max(|x|,|y|)∣x+y∣≤max(∣x∣,∣y∣)，这是非阿基米德的标志；换成 ≤∣x∣+∣y∣\le |x| + |y|≤∣x∣+∣y∣ 就是阿基米德的（复几何那一边），那是另一套理论。

⭐ 有理开集是「∣gi∣≤∣f∣|g_i| \le |f|∣gi​∣≤∣f∣」定义的区域 —— 直觉上就是「gi/fg_i/fgi​/f 有界」的 locus。它们既开又紧（quasicompact），这正是 adic 空间比概形好用的地方：仿射开集自带紧性。

⚠ Spa⁡(A,A+)\operatorname{Spa}(A,A^+)Spa(A,A+) 一般不是 Hausdorff 的，它是 spectral（紧、T0T_0T0​、有开集基）。所以不能拿度量空间的直觉套它。
