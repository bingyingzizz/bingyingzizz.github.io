又称酉算子·unitary

陈述

设 u∈B(H)u \in B(H)u∈B(H)。称 uuu 是酉算子（unitary），若

u u∗=u∗ u=I.u\,u^* = u^*\,u = I .uu∗=u∗u=I.

等价地：uuu 是保内积的满射，或 u∗=u−1u^* = u^{-1}u∗=u−1。

说明

酉算子就是「可逆的等距」：⟨ux,uy⟩=⟨x,y⟩\langle ux, uy\rangle = \langle x, y\rangle⟨ux,uy⟩=⟨x,y⟩ 且 uuu 满射。

⚠️ 无穷维里「等距」≠\ne=「酉」：单侧移位 S(x1,x2,…)=(0,x1,x2,…)S(x_1, x_2, \ldots) = (0, x_1, x_2, \ldots)S(x1​,x2​,…)=(0,x1​,x2​,…) 满足 ∥Sx∥=∥x∥\|Sx\| = \|x\|∥Sx∥=∥x∥（等距），但不满；SSS 是部分等距而不是酉算子。部分等距的完整定义与等价条件见 部分等距。

⭐ 极分解 u=V∣u∣u = V|u|u=V∣u∣（VVV 部分等距，∣u∣=u∗u|u| = \sqrt{u^*u}∣u∣=u∗u​）就是部分等距的标准出场方式。有限维版本见 酉矩阵与正交矩阵。

    酉算子   ⟹  \implies⟹ 部分等距

    设 uuu 是酉算子，即 u∗u=u u∗=Iu^u = u\,u^ = Iu∗u=uu∗=I。 III 是正交投影，故按定义 u∗u=Iu^*u = Iu∗u=I 是正交投影，uuu 是部分等距。■\blacksquare■

    部分等距是一般定义；酉算子是满足 u∗u=u u∗=Iu^u = u\,u^ = Iu∗u=uu∗=I 的特例，这条只作逻辑包含、不分层。反向不成立：单侧移位是部分等距但不是酉算子（S S∗S\,S^*SS∗ 不是 III）。
