又称Rolle 中值定理

陈述

设 fff 在闭区间 [a,b][a, b][a,b] 上连续、在开区间 (a,b)(a, b)(a,b) 内可导，且 f(a)=f(b)f(a) = f(b)f(a)=f(b)。则存在 ξ∈(a,b)\xi \in (a, b)ξ∈(a,b) 使

f′(ξ)=0f'(\xi) = 0f′(ξ)=0

说明

⭐ 几何内容：两端等高时，中间必有一个水平切线点。它是中值定理家族里唯一需要紧性的一条（用最值定理找内部极值点），后面几条都是它换一件衣服。

⚠ 两个前提同样不能丢：「[a,b][a, b][a,b] 上连续」保证最值存在（紧性），「(a,b)(a, b)(a,b) 内可导」保证那个极值点是内点、可以用 Fermat 引理。f(a)=f(b)f(a) = f(b)f(a)=f(b) 若换成 f(a)≠f(b)f(a) \ne f(b)f(a)=f(b) 就是 Lagrange 中值定理。

它指向谁（出边）

推出 3

  • 本页 ⟹ Lagrange 中值定理推出
    Rolle 定理   ⟹  \implies⟹ Lagrange 中值定理

    令

    g(x):=f(x)−f(b)−f(a)b−a (x−a)g(x) := f(x) - \frac{f(b) - f(a)}{b - a}\,(x - a)g(x):=f(x)−b−af(b)−f(a)​(x−a)

    即把 fff 减去那条弦。ggg 在 [a,b][a, b][a,b] 上连续、在 (a,b)(a, b)(a,b) 内可导（差一个线性函数），且

    g(a)=f(a),g(b)=f(b)−(f(b)−f(a))=f(a)g(a) = f(a), \qquad g(b) = f(b) - (f(b) - f(a)) = f(a)g(a)=f(a),g(b)=f(b)−(f(b)−f(a))=f(a)

    故 g(a)=g(b)g(a) = g(b)g(a)=g(b)。由 Rolle 定理，存在 ξ∈(a,b)\xi \in (a, b)ξ∈(a,b) 使 g′(ξ)=0g'(\xi) = 0g′(ξ)=0，即

    f′(ξ)=f(b)−f(a)b−af'(\xi) = \frac{f(b) - f(a)}{b - a}f′(ξ)=b−af(b)−f(a)​

    整理即得 f(b)−f(a)=f′(ξ)(b−a)f(b) - f(a) = f'(\xi)(b - a)f(b)−f(a)=f′(ξ)(b−a)。∎

    「减去弦」这个手法（找一个辅助函数让它满足 Rolle 的条件）在中值定理家族里是标准动作，下面 Cauchy 版也是同一招。

  • 本页 ⟹ Cauchy 中值定理推出
    Rolle 定理   ⟹  \implies⟹ Cauchy 中值定理

    先注意 g(b)≠g(a)g(b) \ne g(a)g(b)=g(a)：若 g(b)=g(a)g(b) = g(a)g(b)=g(a)，由 Rolle 定理存在内点使 g′=0g' = 0g′=0，与 g′≠0g' \ne 0g′=0 矛盾。于是下面的分母不为零。

    令

    h(x):=(f(b)−f(a))g(x)−(g(b)−g(a))f(x)h(x) := \bigl( f(b) - f(a) \bigr) g(x) - \bigl( g(b) - g(a) \bigr) f(x)h(x):=(f(b)−f(a))g(x)−(g(b)−g(a))f(x)

    hhh 在 [a,b][a, b][a,b] 上连续、在 (a,b)(a, b)(a,b) 内可导，且

    h(a)=(f(b)−f(a))g(a)−(g(b)−g(a))f(a),h(b)=(f(b)−f(a))g(b)−(g(b)−g(a))f(b)h(a) = (f(b) - f(a)) g(a) - (g(b) - g(a)) f(a), \qquad h(b) = (f(b) - f(a)) g(b) - (g(b) - g(a)) f(b)h(a)=(f(b)−f(a))g(a)−(g(b)−g(a))f(a),h(b)=(f(b)−f(a))g(b)−(g(b)−g(a))f(b)

    两式相减得 h(b)−h(a)=(f(b)−f(a))(g(b)−g(a))−(g(b)−g(a))(f(b)−f(a))=0h(b) - h(a) = (f(b) - f(a))(g(b) - g(a)) - (g(b) - g(a))(f(b) - f(a)) = 0h(b)−h(a)=(f(b)−f(a))(g(b)−g(a))−(g(b)−g(a))(f(b)−f(a))=0。由 Rolle 定理存在 ξ∈(a,b)\xi \in (a, b)ξ∈(a,b) 使 h′(ξ)=0h'(\xi) = 0h′(ξ)=0，即

    (f(b)−f(a))g′(ξ)=(g(b)−g(a))f′(ξ)\bigl( f(b) - f(a) \bigr) g'(\xi) = \bigl( g(b) - g(a) \bigr) f'(\xi)(f(b)−f(a))g′(ξ)=(g(b)−g(a))f′(ξ)

    两边同除 g′(ξ) (g(b)−g(a))g'(\xi)\,(g(b) - g(a))g′(ξ)(g(b)−g(a))（都不为零）即得结论。∎

    辅助函数 hhh 是「弦」的推广：g(x)=xg(x) = xg(x)=x 时 hhh 就是 Lagrange 版里那个 ggg 的常数倍。

推出 1

  • Fermat 引理、最值定理 ⟹ 本页推出
    Fermat 引理 + 最值定理   ⟹  \implies⟹ Rolle 中值定理

    设 fff 在 [a,b][a, b][a,b] 上连续、在 (a,b)(a, b)(a,b) 内可导、f(a)=f(b)f(a) = f(b)f(a)=f(b)。

    1. 由最值定理，fff 在 [a,b][a, b][a,b] 上取到最大值 MMM 与最小值 mmm。
    2. 若 M=mM = mM=m，则 fff 是常数，于是 (a,b)(a, b)(a,b) 内任取 ξ\xiξ 都有 f′(ξ)=0f'(\xi) = 0f′(ξ)=0。
    3. 否则 M>mM > mM>m。因为 f(a)=f(b)f(a) = f(b)f(a)=f(b)，两个数 M,mM, mM,m 中至少有一个不等于 f(a)f(a)f(a)，所以它在 (a,b)(a, b)(a,b) 内的某点 ξ\xiξ 处被取到 —— 这个 ξ\xiξ 是内点极值点。
    4. 由 Fermat 引理，f′(ξ)=0f'(\xi) = 0f′(ξ)=0。∎

    第 3 步是全部技巧所在：「两端相等」保证最值不能在两个端点同时取到，于是必有一个最值被内点取到 —— 紧性（由最值定理提供）与可导性（由 Fermat 引理使用）就在这一点上汇合。
