# Perfectly Normal Space　`def.perfectly-normal-space`
English entry · root `../`
[in graph](../#n=def.perfectly-normal-space)　·　[Chinese page (authoritative)](./def.perfectly-normal-space.md)

A topological space $X$ is **perfectly normal** if

1. $X$ is normal (`def.normal-space`);
2. every closed set is a $G_{\delta}$ set.

(Equivalently: every open set is an $F_{\sigma}$ set, by taking complements.)

**Position in the chain**: $T_{6} \implies T_{5} \implies T_{4}$.
