Statement

Let V,WV, WV,W be vector spaces over a field KKK. A map T:V→WT : V \to WT:V→W is called **KKK-linear** (or a linear map) if and only if

T(u+v)=T(u)+T(v),T(cu)=c T(u)T(u + v) = T(u) + T(v), \qquad T(cu) = c\,T(u)T(u+v)=T(u)+T(v),T(cu)=cT(u)

for all u,v∈Vu, v \in Vu,v∈V and c∈Kc \in Kc∈K. Equivalently, T(cu+v)=c T(u)+T(v)T(cu + v) = c\,T(u) + T(v)T(cu+v)=cT(u)+T(v).

The sum** and scalar multiple** of two linear maps are again linear, so the set of all linear maps is a KKK-vector space, denoted

Hom⁡K(V,W):={ T:V→W linear }\operatorname{Hom}_K(V, W) := \{\, T : V \to W \ \text{linear} \,\}HomK​(V,W):={T:V→W linear}

A composite S∘TS \circ TS∘T is again linear.

Notes

⭐ Linear means **preserving the two operations** (addition and scalar multiplication).

Compared with a group homomorphism, which preserves one operation, there is one more requirement, but it comes for free: both T(0)=0T(0) = 0T(0)=0 and T(−v)=−T(v)T(-v) = -T(v)T(−v)=−T(v) follow from the definition.

⭐ That Hom⁡K(V,W)\operatorname{Hom}_K(V, W)HomK​(V,W) is itself a vector space is special to linear algebra: in a general category the morphism set between two objects has no addition (as in Set\mathbf{Set}Set), whereas the category of vector spaces is an **additive category** — the morphism sets carry an addition of their own, an extra structure absent from general categories.
