## Statement · **draft**
Let $a < b$. A **partition** of the closed interval $[a, b]$ is a finite set of points

$$P = \{ a = x_0 < x_1 < \cdots < x_n = b \}$$

The $i$-th subinterval is denoted $I_i := [x_{i-1}, x_i]$, its length $\Delta x_i := x_i - x_{i-1}$. The **mesh** of the partition is

$$\|P\| := \max_{1 \le i \le n} \Delta x_i$$
