# closed surface　`def.closed-surface`
English entry · root `../`
[in graph](../#n=def.closed-surface)　·　[Chinese page (authoritative)](./def.closed-surface.md)

⭐ Basic examples: the sphere $S^{2}$, the torus $T^{2}$ (genus 1), the projective plane $\mathbb{RP}^{2}$ (nonorientable), and the Klein bottle (nonorientable). ⚠ All four **already have nodes**: `ex.sphere`, `ex.torus`, `ex.projective-plane`, and `ex.klein-bottle`.

📌 The genus in `def.genus` is defined only for **orientable** closed surfaces. The nonorientable case uses a different notion ($\chi = 2 - k$).
