## Statement · **draft**
Let $K$ be an ordered field, $a, b, c, d \in K$. Then

**(i)** $a < b \iff a + c < b + c$;

**(ii)** $a < b$ and $c < d$ $\implies$ $a + c < b + d$;

**(iii)** for $c > 0$, $a < b \implies ac < bc$; for $c < 0$, $a < b \implies ac > bc$;

**(iv)** $0 < a < b \implies 0 < \dfrac{1}{b} < \dfrac{1}{a}$;
