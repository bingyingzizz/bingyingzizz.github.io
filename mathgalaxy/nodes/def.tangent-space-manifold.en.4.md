# Tangent Space　`def.tangent-space-manifold`
English entry · root `../`
[in graph](../#n=def.tangent-space-manifold)　·　[Chinese page (authoritative)](./def.tangent-space-manifold.md)

The tangent bundle $TM := \bigsqcup_{p\in M}T_{p}M$ also carries a smooth manifold structure (dimension $2n$).

## Notes · **draft**
**Why difference quotients do not work**: in $\mathbb{R}^{n}$, a tangent vector is the limit of $(\gamma(t)-\gamma(0))/t$, which needs subtraction; on a manifold there is no subtraction, only "coordinates + chain rule", so the definition must be written in the **transformation-compatible** form "same velocity in some chart".
