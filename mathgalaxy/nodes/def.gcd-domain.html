整环 AAA 叫 gcd 整环，若任意 a,b∈Aa, b \in Aa,b∈A 都有最大公因子：存在 ddd 使

d∣a,d∣b,且任何 c∣a, c∣b 都有 c∣d.d \mid a,\quad d \mid b,\quad \text{且任何 } c \mid a,\ c \mid b \text{ 都有 } c \mid d .d∣a,d∣b,且任何 c∣a, c∣b 都有 c∣d.

注意「最大」是整除意义下的最大下界，不是大小比较 —— 整环上没有全序。

说明

为什么必须这样定义：Z\mathbb{Z}Z 里「最大的公因数」靠 ∣d∣|d|∣d∣ 比较，一般整环没有绝对值。改用「被一切公因子整除」才对：Z\mathbb{Z}Z 里它等价于「绝对值最大」，而 Z[i]\mathbb{Z}[i]Z[i] 里也只有这个说法成立。

层级：UFD   ⟹  \implies⟹ gcd 整环（imp.ring-ufd-gcd），反之不然（Z[−5]\mathbb{Z}[\sqrt{-5}]Z[−5​] 连 gcd⁡(6,2(1+−5))\gcd(6, 2(1+\sqrt{-5}))gcd(6,2(1+−5​)) 都不存在）。Bézout 整环   ⟹  \implies⟹ gcd 整环，因为 gcd⁡\gcdgcd 直接由线性组合给出。

gcd⁡\gcdgcd 可以不存在 —— 这正是「UFD 的分解唯一性」不能用 gcd 替代的原因。

    UFD   ⟹  \implies⟹ gcd 整环：取公共素因子指数的最小值

    设 AAA 是 UFD，a,ba, ba,b 非零。把两者写成不可约元的乘积，按相伴类归并：

    a∼∏ipi mi,b∼∏ipi ni.a \sim \prod_{i} p_{i}^{\,m_{i}}, \qquad b \sim \prod_{i} p_{i}^{\,n_{i}} .a∼i∏​pimi​​,b∼i∏​pini​​.

    （只保留在两者中至少一个里出现的 pip_{i}pi​。）

    令 d:=∏ipi min⁡(mi,ni)d := \prod_{i} p_{i}^{\,\min(m_{i}, n_{i})}d:=∏i​pimin(mi​,ni​)​。则 d∣ad \mid ad∣a 且 d∣bd \mid bd∣b，故 ddd 是公因子。

    反之设 c∣ac \mid ac∣a、c∣bc \mid bc∣b。把 ccc 分解，每个不可约因子 q∣cq \mid cq∣c 都整除 aaa，而 UFD 里不可约即素，故 qqq 与某个 pip_{i}pi​ 相伴，且它在 ccc 里的重数 ≤min⁡(mi,ni)\le \min(m_{i}, n_{i})≤min(mi​,ni​)。于是 c∣dc \mid dc∣d。
