# Mean Value Theorem in Several Variables　`thm.mean-value-multi`
English entry · root `../`
[in graph](../#n=thm.mean-value-multi)　·　[Chinese page (authoritative)](./thm.mean-value-multi.md)

**Mean value inequality**: if $f : U \to \mathbb{R}^{m}$ is differentiable, then

$$\|f(a + h) - f(a)\| \le \Bigl( \sup_{[a, a+h]} \|Df\| \Bigr) \|h\|$$

## Notes · **draft**
⭐ The one-dimensional mean value theorem rests on Rolle, and Rolle on "a continuous function on a closed interval attains its extrema" — and **multivariable calculus has no such thing** (the equality version is **false** for $\mathbb{R}^{m}$-valued functions: $f(t) = (\cos t, \sin t)$ goes once around a circle, $f(2\pi) - f(0) = 0$, yet $Df$ is nowhere zero and $\|Df\| = 1$).
