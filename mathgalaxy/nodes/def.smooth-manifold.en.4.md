# Smooth Manifold　`def.smooth-manifold`

[in graph](../#n=def.smooth-manifold)　·　[Chinese page (authoritative)](./def.smooth-manifold.md)

$$\psi\circ\varphi^{-1} : \varphi(U\cap V)\longrightarrow\psi(U\cap V)$$

is $C^{\infty}$ (it is defined on an open subset of $\mathbb{R}^{n}$, so it is tested by partial derivatives). A family of pairwise compatible charts covering $M$ is an **atlas**; adding to an atlas all charts compatible with it gives a **maximal atlas**, also called a **smooth structure** on $M$. An $n$-dimensional manifold equipped with a smooth structure is an **$n$-dimensional smooth manifold**.

**Smooth functions**: $f : M\to\mathbb{R}$ is smooth if for every chart $(U,\varphi)$, the map $f\circ\varphi^{-1}$ is smooth on $\varphi(U)$.
