# quotient group　`def.quotient-group`
English entry · root `../`
[in graph](../#n=def.quotient-group)　·　[Chinese page (authoritative)](./def.quotient-group.md)

⚠️ A quotient **group** exists only for normal subgroups; the quotient **set** $G/H$ exists for any subgroup (left cosets still partition $G$), but that quotient set usually carries no group structure.
