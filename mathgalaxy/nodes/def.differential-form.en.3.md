# Differential Form: Coordinate Model on Euclidean Open Sets　`def.differential-form`
English entry · root `../`
[in graph](../#n=def.differential-form)　·　[Chinese page (authoritative)](./def.differential-form.md)

$$\omega = \sum_{i_{1}<\cdots<i_{k}}a_{i_{1}\cdots i_{k}}(x)\,\mathrm{d}x^{i_{1}}\wedge\cdots\wedge\mathrm{d}x^{i_{k}} ,\qquad a_{I}\in C^{\infty}(U),$$

where $\mathrm{d}x^{i}(v) := v^{i}$ is the differential of the coordinate function and $\wedge$ is the exterior product ($\mathrm{d}x^{i}\wedge\mathrm{d}x^{j} = -\mathrm{d}x^{j}\wedge\mathrm{d}x^{i}$). The whole space is denoted $\Omega^{k}(U)$.

$\Omega^{0}(U) = C^{\infty}(U)$ (a function is a $0$-form); for $k>n$ one has $\Omega^{k}(U) = 0$; a $k$-form is a combination of $\binom{n}{k}$ smooth functions.
