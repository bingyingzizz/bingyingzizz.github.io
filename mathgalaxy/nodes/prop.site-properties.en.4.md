# Properties of Sheaf Categories over a Site　`prop.site-properties`
English entry · root `../`
[in graph](../#n=prop.site-properties)　·　[Chinese page (authoritative)](./prop.site-properties.md)

- **① Universal colimits**: **automatic in a sheaf category** (sheaves are limits along covers, and limits commute with pullback). No condition on the site is needed, only that $\widehat{\mathcal{C}}$ exists.
- **② Filtered colimits are exact**: **this needs "sheafification commutes with filtered colimits"** — true for a general Grothendieck topology; for **finite** filtered colimits (i.e. over $\mathbf{Ab}$) the site must satisfy an extra condition (for instance "quasi-compact + quasi-separated").
- **③ Epimorphisms are regular and universal**: a sheaf category is a **regular category**, so epi
