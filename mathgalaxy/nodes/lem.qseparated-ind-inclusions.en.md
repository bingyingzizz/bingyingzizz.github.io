## Statement · **draft**
A condensed set $X$ is **quasi-separated** $\iff$ it can be written as

$$X \cong \varinjlim_{i \in I}\ S_{i},$$

where each $S_{i}$ is a compact Hausdorff space and each transition map $S_{i} \hookrightarrow S_{j}$ is an **inclusion**.
