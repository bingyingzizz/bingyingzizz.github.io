陈述

由递增右连续函数 FFF 按上一条定理得到的 Borel 测度 μF\mu_FμF​ 称为 FFF 的 Lebesgue–Stieltjes 测度。

特别地，取 F(x)=xF(x) = xF(x)=x，得到的 μF\mu _FμF​ 就是 R\mathbb{R}R 上的 Lebesgue 测度 mmm：

m((a,b])=b−am( (a, b] ) = b - am((a,b])=b−a

说明

若改用左连续的 FFF 配区间 [a, b)，得到的是同一族测度 —— 只是把「右连续」换成了「左连续」。

μF\mu _FμF​ 的分布函数视角：若 FFF 还满足 F(−∞)=0F(-\infty ) = 0F(−∞)=0、F(+∞)=1F(+\infty ) = 1F(+∞)=1，那 FFF 就是一个概率分布的分布函数，μF\mu _FμF​ 就是对应的概率测度。

这条把「测度」和「函数」这两类对象接了起来：R\mathbb{R}R 上（局部有限的）测度 ↔\leftrightarrow↔ 递增右连续函数（模常数）。后面 Radon–Nikodym 会把「绝对连续」精确地实现为「FFF 是可积函数的积分」。
