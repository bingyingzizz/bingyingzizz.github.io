又称特征类·示性类·characteristic class·Stiefel–Whitney 类·陈类

⚠ 骨架：只看陈述与思路，当不得完整证明

陈述

要解决什么问题：丛的同构类由 Hˇ1(B;GL(k))\check{H}^{1}(B; \mathrm{GL}(k))Hˇ1(B;GL(k)) 分类（丛的分类），但那个集合是非阿贝尔的、没法直接算。示性类把「丛」翻译成「上同调类」—— 上同调是群，能算，于是「两个丛不同构」有了可验证的判据。

设 E→BE \to BE→B 是光滑流形上的秩 kkk 实向量丛。EEE 的示性类（characteristic class）是一族对应

ci(E)∈Hi(B;Λ),c_{i}(E) \in H^{i}(B; \Lambda),ci​(E)∈Hi(B;Λ),

（Λ\LambdaΛ 取 Z\mathbb{Z}Z、Z/2\mathbb{Z}/2Z/2 或 R\mathbb{R}R，看具体类）满足两条公理：

  1. 自然性：对任意光滑映射 f:B′→Bf : B' \to Bf:B′→B 有 ci(f∗E)=f∗ci(E)c_{i}(f^{}E) = f^{}c_{i}(E)ci​(f∗E)=f∗ci​(E)；
  2. 同构不变：E≅E′E \cong E'E≅E′   ⟹  \implies⟹ ci(E)=ci(E′)c_{i}(E) = c_{i}(E')ci​(E)=ci​(E′)。

因此示性类是从「BBB 上的向量丛」到「BBB 的上同调」的自然变换。

两条最基本的：

  • 秩 kkk 实丛的 Stiefel–Whitney 类 wi(E)∈Hi(B;Z/2)w_{i}(E) \in H^{i}(B; \mathbb{Z}/2)wi​(E)∈Hi(B;Z/2)（i=0,…,ki = 0, \ldots, ki=0,…,k），w1(E)≠0w_{1}(E) \ne 0w1​(E)=0 当且仅当 EEE 不可定向；
  • 秩 kkk 复丛的 陈类 ci(E)∈H2i(B;Z)c_{i}(E) \in H^{2i}(B; \mathbb{Z})ci​(E)∈H2i(B;Z)（i=0,…,ki = 0, \ldots, ki=0,…,k），c1c_{1}c1​ 是那个「第一障碍」。

说明

为什么它接在分类定理后面：分类定理把丛变成 Hˇ1(B;G)\check{H}^{1}(B; G)Hˇ1(B;G)（一个只带基点、没有群结构的集合），示性类把它接到 H∙(B)H^{\bullet}(B)H∙(B)（真正的环）。这样做的代价是丢失信息：不同的丛可以有相同的示性类（例如所有平凡丛的示性类都平凡）。所以示性类是必要条件、不是充分条件 —— 它的用处是「证明两个丛不同构」，不是「证明同构」。

和「换结构群」的关系：示性类正是结构群约化的障碍。最典型的一条：w1(E)=0w_{1}(E) = 0w1​(E)=0 等价于 EEE 的结构群可从 GL(k)\mathrm{GL}(k)GL(k) 约化到 SO(k)\mathrm{SO}(k)SO(k)（即可定向，见 可定向流形）；同理 w2=0w_{2} = 0w2​=0 是 Spin\mathrm{Spin}Spin 结构存在的先决条件（还有一条额外的整系数条件）。这与 结构群 的注里说的「能不能约化是障碍理论问题」是同一件事的两面。

怎么算出来：实用算法是 陈–Weil 理论 —— 在丛上取一个联络（联络形式），算它的曲率形式，示性类就是曲率形式的多项式（不变量），并且与联络的选取无关（差一个恰当形式）。本图只到「联络 / 曲率形式」为止，陈–Weil 同态、分裂原理、示性类的公理刻画都未收录。

⚠️ 示性类不是丛的不变量，是「丛的同构类」的不变量：同一个类可以由不同丛给出，所以它给的是 Hˇ1→H∙\check{H}^{1} \to H^{\bullet}Hˇ1→H∙ 的映射，不是同构。若想要「完全」不变量，需要用 KKK 理论或更细的工具。

⚠️ 特征类 / 示性类 / characteristic class 是同一个东西的中英几种叫法；注意别与「域的特征」（域的特征）混淆 —— 那个是 char K\mathrm{char}\,KcharK。

两条公理不够唯一地确定示性类 —— 这是它最容易误解的地方：

  • 自然性：把「丛的拉回」与「上同调的拉回」对齐。这是函子性，不给具体数值。
  • 同构不变：只保证它是丛的同构类的函数。
  • ⚠️ 两条加起来仍有无穷多解（c1c_{1}c1​ 的任何多项式都满足），所以真正的定义要再补规范化（例如 w0=1w_{0} = 1w0​=1、c0=1c_{0} = 1c0​=1，以及“高阶类在被直和分解时的乘性”，或等价的“万有丛上取定生成元”）。本节只给了公理骨架，没有钉死归一化 —— 这是有意为之，规范化的完整陈述属于 陈–Weil 理论。

⚠️ 方向只能“证不同构”：ci(E)≠ci(E′)c_{i}(E) \ne c_{i}(E')ci​(E)=ci​(E′)   ⟹  \implies⟹ E≇E′E \not\cong E'E≅E′；反之不成立（不同丛可以有相同示性类）。所以示性类是必要条件，不构成分类。 ⚠️ 与结构群约化的关系是“障碍”而非“判据”：w1(E)=0w_{1}(E) = 0w1​(E)=0   ⟺  \iff⟺ 可定向（这条是等价）；但 w2=0w_{2} = 0w2​=0 只是 Spin\mathrm{Spin}Spin 结构存在的先决条件，还要一个整系数条件。别把「某类消失」当成分结构存在的充要条件。

各方向用到的假设（自然性定义免费，障碍判据另有定理）：

  • 同构不变的类赋值满足拉回自然性   ⟺  \iff⟺ 它给出丛同构类函子到上同调函子的自然变换，是定义展开；这两条不唯一确定具体示性类，零赋值也满足。
  • 丛同构   ⟹  \implies⟹ 各示性类相同只用同构不变性；类不同   ⟹  \implies⟹ 不同构是其逆否命题。反向不免费，例如 TS2TS^2TS2 与平凡实二平面丛的 Stiefel–Whitney 类全相同，但 Euler 类不同，故不同构。
  • 对实向量丛，w1=0w_1=0w1​=0   ⟺  \iff⟺ 可定向是定向障碍定理；约化到 SO(k)\mathrm{SO}(k)SO(k) 还使用流形上度量的存在，后者可由单位分解构造。
  • 已定向实丛具有 Spin 提升   ⟺  \iff⟺ w2=0w_2=0w2​=0，是双覆盖提升的障碍理论结论；原注所谓还需额外整系数条件不适用于通常 Spin 判据。未定向时须先要求 w1=0w_1=0w1​=0。
