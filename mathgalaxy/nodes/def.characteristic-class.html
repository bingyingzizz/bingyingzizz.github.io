陈述

要解决什么问题：丛的同构类由 Hˇ1(B;GL(k))\check{H}^{1}(B; \mathrm{GL}(k))Hˇ1(B;GL(k)) 分类（丛的分类），但那个集合非阿贝尔、没法直接算。示性类把「丛」翻译成「上同调类」—— 上同调是群，能算，于是「两个丛不同构」有了可验证的判据。

设 E→BE \to BE→B 是光滑流形上的秩 kkk 实向量丛。EEE 的示性类（characteristic class）是一族对应

ci(E)∈Hi(B;Λ),c_{i}(E) \in H^{i}(B; \Lambda),ci​(E)∈Hi(B;Λ),

（Λ\LambdaΛ 取 Z\mathbb{Z}Z、Z/2\mathbb{Z}/2Z/2 或 R\mathbb{R}R，看具体类）满足两条公理：

  1. 自然性：对任意光滑映射 f:B1→B2f : B_{1} \to B_{2}f:B1​→B2​ 有 ci(f∗E)=f∗ci(E)c_{i}(f^{}E) = f^{}c_{i}(E)ci​(f∗E)=f∗ci​(E)；
  2. 同构不变：E≅E1E \cong E_{1}E≅E1​   ⟹  \implies⟹ ci(E)=ci(E1)c_{i}(E) = c_{i}(E_{1})ci​(E)=ci​(E1​)。

因此示性类是从「BBB 上的向量丛」到「BBB 的上同调」的自然变换。

说明

定义的展开：把每个空间 BBB 上的向量丛看成一个范畴（态射是拉回），示性类就是这个范畴到分次环 H∙(B;Λ)H^{\bullet}(B;\Lambda)H∙(B;Λ) 的自然变换。两条公理合起来只说「拉回与上同调拉回相容」，并不指定任何具体数值：零变换也满足它们。所以「示性类」是一族满足公理的对应，具体到 SW 类或陈类，必须再补规范化与 Whitney 公式（上面陈述里已写）。

为什么需要 Whitney 公式：它把丛的直和分解变成类的乘法，从而「线丛的类」决定一切（分裂原理）。例如复线丛 LLL 有 c(L)=1+c1(L)c(L) = 1 + c_{1}(L)c(L)=1+c1​(L)，一般复丛用形式分裂 E≅⨁LiE \cong \bigoplus L_{i}E≅⨁Li​ 定义 c(E)=∏(1+c1(Li))c(E) = \prod (1 + c_{1}(L_{i}))c(E)=∏(1+c1​(Li​))，再证明与分裂无关。实丛用同样的办法，只是系数换成 Z/2\mathbb{Z}/2Z/2。

和结构群约化的关系（障碍，不是判据）：对实丛，w1(E)=0w_{1}(E) = 0w1​(E)=0 当且仅当 EEE 可定向，即结构群可从 GL(k)\mathrm{GL}(k)GL(k) 约化到 SO(k)\mathrm{SO}(k)SO(k)（定向与 w1 消失）；这是等价，不是单向障碍。若 EEE 已定向，则它带有 Spin(k)\mathrm{Spin}(k)Spin(k) 结构当且仅当 w2(E)=0w_{2}(E) = 0w2​(E)=0（双覆盖的提升障碍）。对光滑流形 MMM，旋结构存在当且仅当 w1(TM)=0w_{1}(TM) = 0w1​(TM)=0 且 w2(TM)=0w_{2}(TM) = 0w2​(TM)=0。⚠ 不要把「某个类消失」一般地当成结构群可约化的充要条件：w2=0w_{2} = 0w2​=0 对未定向丛不够，必须先有 w1=0w_{1} = 0w1​=0。

至少一个例子：Möbius 带 MMM 的切丛（或它的 tautological 线丛）不可定向（莫比乌斯带），故 w1(TM)≠0w_{1}(TM) \ne 0w1​(TM)=0；这给出「w1w_{1}w1​ 非零所以不能定向」的具体读数。复线丛方面，CP1\mathbb{CP}^{1}CP1 上的 tautological 线丛 O(−1)\mathcal{O}(-1)O(−1) 满足 ∫CP1c1(O(−1))=−1\int_{\mathbb{CP}^{1}} c_{1}(\mathcal{O}(-1)) = -1∫CP1​c1​(O(−1))=−1（线丛的陈类计算），于是它的任何正整数次幂都给出不同的陈类 —— 这就是「用示性类区分丛」的样板。

怎么算：实用算法是 陈–Weil 理论 —— 在丛上取一个联络（联络形式），算曲率形式，示性类就是曲率形式的多项式（不变量），并且与联络的选取无关（差一个恰当形式）。本图的 陈类 就是陈–Weil 版定义。分裂原理、公理刻画、KKK 理论细化都没有展开。

⚠ 示性类不是完全不变量：不同的丛可以有相同的示性类（所有平凡丛的示性类都平凡；更微妙的例子需要 KKK 理论才能分开）。所以它只能证不同构：ci(E)≠ci(E1)c_{i}(E) \ne c_{i}(E_{1})ci​(E)=ci​(E1​) 推出 E≇E1E \not\cong E_{1}E≅E1​；反过来不成立。

⚠ 名称：示性类、特征类、characteristic class 是同一个东西；别与「域的特征」char K\mathrm{char}\,KcharK（域的特征）混淆。

⚠ Euler 类不是 SW 类：Euler 类 e(E)∈Hk(B;Z)e(E) \in H^{k}(B;\mathbb{Z})e(E)∈Hk(B;Z) 取整数值，wk(E)w_{k}(E)wk​(E) 是 e(E)e(E)e(E) 模 222 的约化；TS2TS^{2}TS2 的 w1=w2=0w_{1} = w_{2} = 0w1​=w2​=0 但 e(TS2)=χ(S2)=2≠0e(TS^{2}) = \chi(S^{2}) = 2 \ne 0e(TS2)=χ(S2)=2=0，这正是「整系数类能看见、Z/2\mathbb{Z}/2Z/2 类看不见」的例子。
