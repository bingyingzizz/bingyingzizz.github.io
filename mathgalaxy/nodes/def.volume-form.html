又称黎曼体积·黎曼

陈述

在说什么：一个处处不为零的 nnn-形式给出「有向体积」；度量的行列式因子乘上坐标体积形式，就是黎曼体积。

设 MMM 是 nnn 维光滑流形。体积形式是处处非零的 nnn-形式 ω∈Ωn(M)\omega \in \Omega^{n}(M)ω∈Ωn(M)（即 ωp≠0\omega_{p} \ne 0ωp​=0 对每个 ppp 成立）。

若 MMM 还带黎曼度量 ggg（def.riemannian-metric）与一个定向，则黎曼体积形式在每张保向卡里写成

dVg:=det⁡(gij) dx1∧⋯∧dxn,gij=g(∂∂xi,∂∂xj).\mathrm{d}V_{g} := \sqrt{\det\bigl(g_{ij}\bigr)}\ \mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n},\qquad g_{ij} = g\Bigl(\frac{\partial}{\partial x^{i}},\frac{\partial}{\partial x^{j}}\Bigr).dVg​:=det(gij​)​ dx1∧⋯∧dxn,gij​=g(∂xi∂​,∂xj∂​).

在保向正交余标架 {θ1,…,θn}\{\theta^{1},\ldots,\theta^{n}\}{θ1,…,θn}（即 g=∑i(θi)2g = \sum_{i}(\theta^{i})^{2}g=∑i​(θi)2）下它化简成没有系数的样子

dVg=θ1∧⋯∧θn.\mathrm{d}V_{g} = \theta^{1}\wedge\cdots\wedge\theta^{n}.dVg​=θ1∧⋯∧θn.

于是可积的函数有体积与积分

vol⁡(M):=∫MdVg,∫Mf dVg,\operatorname{vol}(M) := \int_{M}\mathrm{d}V_{g},\qquad \int_{M}f\,\mathrm{d}V_{g},vol(M):=∫M​dVg​,∫M​fdVg​,

积分按 def.integral-form 的「定向形式积分」定义。

说明

为什么必须是最高次形式：换元公式里 dx1∧⋯∧dxn\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}dx1∧⋯∧dxn 的系数变换恰好是 det⁡\detdet（保向时无绝对值），与积分换元里出现的 det⁡\detdet 精确匹配 —— 这就是「形式能积分」的全部理由。k<nk < nk<n 的形式要积分得先拉回到 kkk 维子流形上。

根号是密度、楔积是定向：det⁡g\sqrt{\det g}detg​ 对反向换卡不变（它带的是 ∣det⁡∣\lvert\det\rvert∣det∣），dx1∧⋯\mathrm{d}x^{1}\wedge\cdotsdx1∧⋯ 反向变号。所以 dVg\mathrm{d}V_{g}dVg​ 必须先取定定向才有定义；无定向时能积的只有密度 ∣dVg∣\lvert\mathrm{d}V_{g}\rvert∣dVg​∣（面积元 dA\mathrm{d}AdA 就是这种，def.area-element）。

二维退化成面积元：dVg=EG−F2 du∧dv\mathrm{d}V_{g} = \sqrt{EG - F^{2}}\,\mathrm{d}u\wedge\mathrm{d}vdVg​=EG−F2​du∧dv，与 def.area-element 的 dA\mathrm{d}AdA 逐字相同，只差「要不要把 du∧dv\mathrm{d}u\wedge\mathrm{d}vdu∧dv 看成带定向的」这一层。

正交余标架为什么省事：g=∑(θi)2g = \sum(\theta^{i})^{2}g=∑(θi)2 时 det⁡(gij)=1\det(g_{ij}) = 1det(gij​)=1，活动标架法（def.moving-frame）里所有体积与曲面积分都用 θ1∧⋯\theta^{1}\wedge\cdotsθ1∧⋯ 写，不再带根号。这也是「曲面上 dA=ω1∧ω2\mathrm{d}A = \omega^{1}\wedge\omega^{2}dA=ω1∧ω2」的来源。

它不是度量的一部分：同一个度量配两个定向，给出两个只差符号的体积形式；同一个定向配不同度量，给出不同的 det⁡g\sqrt{\det g}detg​。体积形式 = 定向 + 度量，两部分都要交代。
