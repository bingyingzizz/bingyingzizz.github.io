# integral domain　`def.int-domain`
English entry · root `../`
[in graph](../#n=def.int-domain)　·　[Chinese page (authoritative)](./def.int-domain.md)

The uses of the three conditions: commutativity $\implies$ lets one speak of the “principal ideal $(a)$”; unity $\implies$ makes the unit group and “invertible” meaningful; no zero divisors $\implies$ allows cancellation and hence the fraction field.
