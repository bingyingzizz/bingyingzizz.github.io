# Riemann Criterion for Integrability　`thm.riemann-criterion`
English entry · root `../`
[in graph](../#n=thm.riemann-criterion)　·　[Chinese page (authoritative)](./thm.riemann-criterion.md)

for **monotonically increasing** functions use equal partitions to make $\sum \omega_i \Delta x_i \le (f(b) - f(a))\|P\|$ (for decreasing functions take absolute values on the right).

⚠ The criterion requires only that **some** partition makes the oscillation sum small, not all partitions — because the oscillation sum is monotone nonincreasing under refinement.
