# singular homology groups　`def.singular-homology`
English entry · root `../`
[in graph](../#n=def.singular-homology)　·　[Chinese page (authoritative)](./def.singular-homology.md)

is called the **$p$-th singular homology group** of $X$.

**Functoriality**: a continuous map $f : X \to Y$ gives a chain map $f_{\#}(\sigma) := f \circ \sigma$, which satisfies $f_{\#}\partial = \partial f_{\#}$ and hence induces $f_{*} : H_{p}(X) \to H_{p}(Y)$; moreover $(1_{X})_{*} = \operatorname{id}$ and $(g \circ f)_{*} = g_{*} \circ f_{*}$.

Homotopic maps induce the same map: $f \simeq g \implies f_{*} = g_{*}$.
