# Orthogonally Similar Matrices　`def.orthogonally-similar`
English entry · root `../`
[in graph](../#n=def.orthogonally-similar)　·　[Chinese page (authoritative)](./def.orthogonally-similar.md)

It preserves both eigenvalues (a property of similarity) and the inner-product structure (a property of congruence) — so it is a **stable** similarity, with condition number $1$.

## Notes · **draft**
⭐ **Which matrices are orthogonally similar to a diagonal matrix**: real symmetric matrices (thm.spectral-matrix); more generally, real normal matrices are orthogonally similar to a **block diagonal** matrix ($1\times1$ and $2\times2$ blocks, because non-real eigenvalues occur in pairs).
