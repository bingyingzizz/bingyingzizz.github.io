# 类函数　`def.class-function`
类函数
layer 15 · 定义 · 群与代数表示 · 抽象代数
[在星图里打开](../#n=def.class-function)　·　[节点索引](../index.md)

函数 $f:G\to F$ 称为类函数，若对所有 $g,h\in G$ 有 $f(hgh^{-1})=f(g)$；等价地，$f$ 在共轭类上为常数。群特征标是类函数。
