陈述

在做什么：在流形上定义「某点的所有方向」。没有外围空间可用，于是改用「过该点的曲线」来抓方向：两条曲线只要在某张卡里速度相同，就规定它们同向。

设 MMM 是 nnn 维光滑流形，p∈Mp\in Mp∈M。两条过 ppp 的曲线 γ1,γ2:(−ε,ε)→M\gamma_{1},\gamma_{2} : (-\varepsilon,\varepsilon)\to Mγ1​,γ2​:(−ε,ε)→M（γi(0)=p\gamma_{i}(0) = pγi​(0)=p）叫在 ppp 处相切，如果存在（等价地：对每张）含 ppp 的卡 (U,φ)(U,\varphi)(U,φ) 有

(φ∘γ1)′(0)=(φ∘γ2)′(0).(\varphi\circ\gamma_{1})'(0) = (\varphi\circ\gamma_{2})'(0) .(φ∘γ1​)′(0)=(φ∘γ2​)′(0).

「存在一张卡」与「对每张卡」等价，因为换卡只差一个链式法则因子。这个等价类叫 ppp 处的一个切向量，全体记 TpMT_{p}MTp​M。

在卡 (U,φ)(U,\varphi)(U,φ) 里记 xi:=φix^{i} := \varphi^{i}xi:=φi、∂i:=∂/∂xi\partial_{i} := \partial/\partial x^{i}∂i​:=∂/∂xi。取曲线 t↦φ−1(φ(p)+t ei)t\mapsto\varphi^{-1}\bigl(\varphi(p)+t\,e_{i}\bigr)t↦φ−1(φ(p)+tei​) 的类，记作 ∂i(p)\partial_{i}(p)∂i​(p)。这 nnn 个切向量两两不同、线性无关，构成 TpMT_{p}MTp​M 的一组基，于是 dim⁡TpM=n\dim T_{p}M = ndimTp​M=n。

导子刻画（等价定义）：TpMT_{p}MTp​M 与「满足 Leibniz 律的线性泛函 D:C∞(M)→RD : C^{\infty}(M)\to\mathbb{R}D:C∞(M)→R，即 D(fg)=f(p) Dg+g(p) DfD(fg) = f(p)\,Dg+g(p)\,DfD(fg)=f(p)Dg+g(p)Df」一一对应，对应关系是 v=[γ]↦(f↦(f∘γ)′(0))v = [\gamma]\mapsto\bigl(f\mapsto (f\circ\gamma)'(0)\bigr)v=[γ]↦(f↦(f∘γ)′(0))。切丛 TM:=⨆p∈MTpMTM := \bigsqcup_{p\in M}T_{p}MTM:=⨆p∈M​Tp​M 也带光滑流形结构（维数 2n2n2n）。

说明

为什么不能用差商：Rn\mathbb{R}^{n}Rn 里切向量是 (γ(t)−γ(0))/t(\gamma(t)-\gamma(0))/t(γ(t)−γ(0))/t 的极限，需要减法；流形上没有减法，能用的只有「坐标 + 链式法则」，所以定义必须写成「在某张卡里速度相同」这种变换相容的样子。

两种定义为什么等价：曲线类给出方向导数（Leibniz 律由乘积求导得到）；反过来，给一个导子 DDD，把它作用在展开式上、用 Leibniz 律杀掉二次以上的项，就得到 D=∑iD(xi) ∂i(p)D = \sum_{i}D(x^{i})\,\partial_{i}(p)D=∑i​D(xi)∂i​(p) —— 正好是某条曲线的方向导数。

坐标变换：∂/∂xi=∑j∂yj∂xi ∂/∂yj\partial/\partial x^{i} = \sum_{j}\frac{\partial y^{j}}{\partial x^{i}}\,\partial/\partial y^{j}∂/∂xi=∑j​∂xi∂yj​∂/∂yj，系数是 Jacobi 矩阵。所以切向量反变（跟着坐标反向走），而 df\mathrm{d}fdf 这类余切向量协变。

⚠️ 记号陷阱：∂i(p)\partial_{i}(p)∂i​(p) 是向量，dxi(p)\mathrm{d}x^{i}(p)dxi(p) 是它的对偶余向量（dxi(∂j)=δ ji\mathrm{d}x^{i}(\partial_{j}) = \delta^{i}_{\ j}dxi(∂j​)=δ ji​）。曲面上这两样就是切平面的基与对偶余标架（def.moving-frame）。

与曲面切平面一致：S⊆R3S\subseteq\mathbb{R}^{3}S⊆R3 的 TpST_{p}STp​S（由 ru,rvr_{u},r_{v}ru​,rv​ 张成）与上面的抽象定义给出同一个空间 —— 取卡 φ=r−1\varphi = r^{-1}φ=r−1 一比就知道，曲线的速度正是 R3\mathbb{R}^{3}R3 里的速度。

定义引用 7

  • 黎曼度量 用到 本页定义引用

    内积住在 TpMT_{p}MTp​M 上，所以必须先有切空间；「光滑变化」是对向量场说的。

  • 仿射联络 用到 本页定义引用

    协变导数作用在向量场上，而向量场逐点取值于 TMTMTM —— 联络是在 TMTMTM 上做微分的规则。

  • 切映射 用到 本页定义引用

    切映射是切空间之间的线性映射，定义域与值域都是切空间；「曲线类相切」这个定义直接给出 dFp([γ]):=[F∘γ]\mathrm{d}F_{p}([\gamma]) := [F \circ \gamma]dFp​([γ]):=[F∘γ]。

  • 切丛 用到 本页定义引用

    切丛是把所有 TpMT_{p}MTp​M 按 ppp 摞起来，纤维就是切空间；「切向量带起点」这件事让 TMTMTM 成为流形而不只是向量空间的并。

  • 向量场 用到 本页定义引用

    每点挑的那个向量住在 TpMT_{p}MTp​M 里；导子视角 Xf:=df(X)Xf := \mathrm{d}f(X)Xf:=df(X) 用的正是切向量作用在函数上这一定义。

  • 左不变向量场 用到 本页定义引用

    g:=TeG\mathfrak{g} := T_{e}Gg:=Te​G —— Lie 代数的载体就是单位元处的切空间，「左不变向量场与它同构」正是命题的第 1 条。

  • 奇异方块 用到 本页定义引用

    「奇异」二字指的是 dcp:Rk→Tc(p)M\mathrm{d}c_{p} : \mathbb{R}^{k}\to T_{c(p)}Mdcp​:Rk→Tc(p)​M 不满秩；「方块的正向 / 反向」也要靠切映射的行列式符号才说得清。切空间是这两件事的共同语言。

    图卡相容   ⟹  \implies⟹ 切向量与卡无关，并给出坐标基
