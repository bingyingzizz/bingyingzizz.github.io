# product sigma-algebra　`def.product-sigma`
English entry · root `../`
[in graph](../#n=def.product-sigma)　·　[Chinese page (authoritative)](./def.product-sigma.md)

$$\otimes _{\alpha \in A} \mathcal{M}_\alpha := \mathcal{M}(\{ \pi _\alpha^{-1}(E_\alpha) : E_\alpha \in \mathcal{M}_\alpha, \alpha \in A \})$$

## Notes · **draft**
That is, the $\sigma$-algebra generated by all **cylinder sets**. A cylinder set $\pi _\alpha ^{-1}(E_\alpha )$ is a set that “imposes conditions only on the $\alpha$-th coordinate”.

⚠ In general it **cannot** be defined as “take all $\prod E_\alpha$ and then the $\sigma$-algebra they generate” — that is equivalent only when the index set is **countable** (see the next item).
