又称良序定理·well-ordering theorem

图外条目Wikipedia ↗

陈述

每个集合都能被赋予一个良序：对任何集合 XXX，都存在 XXX 上的良序关系 ⪯\preceq⪯。

换句话说：任何集合 XXX 都与某个序数等势。

特别地，每个集合都有基数；实数集上存在良序（但这个良序无法被显式写出）。

说明

Zermelo 1904 年为证明「每个集合可良序」而明确提出了选择公理，这也是 AC 第一次登场。

由良序定理可立刻得到基数可比定理：任意两个集合的基数都可比较大小。

在 ZF 中不能证明它；但由它和 ZF 可推出 AC，所以两者等价。

Abstract reviewed

Every set can be well ordered: ∀X ∃⪯\forall X\, \exists \preceq∀X∃⪯ a well-ordering of XXX, equivalently every set is equinumerous with an ordinal. Zermelo introduced the axiom of choice in 1904 precisely to prove this, and over ZF the statement is equivalent to AC. Immediate consequence: any two cardinals are comparable, and R\mathbb{R}R carries a well-ordering that cannot be written down explicitly.

Statement reviewed

Every set can be given a well-ordering: for any set XXX there is a well-ordering relation ⪯\preceq⪯ on XXX.

In other words: every set XXX is equinumerous with some ordinal.

In particular, every set has a cardinality, and the real line admits a well-ordering (though this well-ordering cannot be written down explicitly).

Notes reviewed

Zermelo introduced the axiom of choice explicitly in 1904 in order to prove that every set can be well-ordered; this is where AC first appears.

The well-ordering theorem immediately yields the comparability theorem for cardinals: any two sets have comparable cardinalities.

It cannot be proved in ZF; but ZF together with it proves AC, so the two are equivalent.

推出 1

  • 本页 ⟹ 基数可比定理推出
    良序定理   ⟹  \implies⟹ 任意两个基数可比

    设 AAA、BBB 是任意两个集合。

    ① 良序化。 由良序定理，AAA 上有一个良序 ⪯A\preceq_A⪯A​、BBB 上有一个良序 ⪯B\preceq_B⪯B​。

    ② 换成序数。 每个良序集序同构于唯一的一个序数，记作 α\alphaα、β\betaβ。于是只需比较两个序数。

    ③ 序数可比。 对任意两个序数 α\alphaα、β\betaβ，总有 α∈β\alpha \in \betaα∈β、α=β\alpha = \betaα=β、β∈α\beta \in \alphaβ∈α 三者之一成立（这一步是序数理论的基本事实，用的是良序性）。

    • 若 α⊆β\alpha \subseteq \betaα⊆β：序同构给出单射 A→BA \to BA→B，于是 ∣A∣≤∣B∣|A| \le |B|∣A∣≤∣B∣；
    • 若 β⊆α\beta \subseteq \alphaβ⊆α：同理 ∣B∣≤∣A∣|B| \le |A|∣B∣≤∣A∣。

    所以必有 ∣A∣≤∣B∣|A| \le |B|∣A∣≤∣B∣ 或 ∣B∣≤∣A∣|B| \le |A|∣B∣≤∣A∣。■\blacksquare■

    反过来说：基数可比定理   ⟹  \implies⟹ 良序定理（取 AAA、BBB 中能单射进另一个的那个方向，可以良序化较小的集合，再把良序搬到较大集合上）。所以它与 AC、良序定理、佐恩引理是同一件事。

    选择公理   ⟺  \iff⟺ 良序定理
    选择公理 ⇒ 良序定理（路线 1⟹4）

    设 XXX 是集合。X=∅X = \emptysetX=∅ 时平凡，以下设 X≠∅X \ne \emptysetX=∅。

    1. 由 AC，非空子集族 P(X)∖{∅}\mathcal{P}(X) \setminus \{\emptyset \}P(X)∖{∅} 上有选择函数 φ\varphiφ，即 φ(A)∈A\varphi (A) \in Aφ(A)∈A 对每个非空 A⊆XA \subseteq XA⊆X 成立。
    2. 用超限递归往下取元素：对序数 α\alphaα，只要余集非空就令
    x(α)=φ(X∖{x(β):β<α})x(\alpha) = \varphi( X \setminus \{ x(\beta) : \beta < \alpha \} )x(α)=φ(X∖{x(β):β<α})

    一旦余集为空就停止。

    1. 过程一定会停：取 XXX 的 Hartogs 数 ℵ(X)\aleph (X)ℵ(X)，即最小的不能单射进 XXX 的序数（见「Hartogs 定理」——它在 ZF 里就能证，不需要 AC）。若对一切 α<ℵ(X)\alpha < \aleph (X)α<ℵ(X) 过程都没停，则 α↦x(α)\alpha \mapsto x(\alpha )α↦x(α) 就是 ℵ(X)\aleph (X)ℵ(X) 到 XXX 的单射，与 ℵ(X)\aleph (X)ℵ(X) 的定义矛盾。故存在序数 γ\gammaγ 使 x:γ→Xx : \gamma \to Xx:γ→X 是双射。
    2. 把 γ\gammaγ 上的序经 xxx 搬到 XXX 上：
    a⪯b:  ⟺  x−1(a)≤x−1(b)a \preceq b :\iff x^{-1}(a) \le x^{-1}(b)a⪯b:⟺x−1(a)≤x−1(b)

    因为序数在 ∈\in∈／≤\le≤ 下是良序的，XXX 上这个序也是良序。∎

    良序定理 ⇒ 选择公理（路线 4⟹1）

    设 FFF 是一族非空集合（即 ∅∉F\emptyset \notin F∅∈/F）。

    1. 由良序定理，取 U=⋃FU = \bigcup FU=⋃F 的一个良序 ⪯\preceq⪯。
    2. 对每个 X∈FX \in FX∈F：X≠∅X \ne \emptysetX=∅ 且 X⊆UX \subseteq UX⊆U，所以 XXX 是 UUU 的非空子集，有 ⪯\preceq⪯最小元 m(X)。
    3. 定义 f(X)=m(X)f(X) = m(X)f(X)=m(X)（XXX 唯一确定 m(X)，故这是一个函数）。则 dom⁡f=F\operatorname{dom} f = Fdomf=F 且 f(X)∈Xf(X) \in Xf(X)∈X 对一切 X∈FX \in FX∈F 成立，即 fff 是 FFF 的选择函数。

    由 FFF 的任意性，AC 成立。∎
