又称自然数的运算律

陈述

在 N=ω\mathbb{N} = \omegaN=ω 上取 def.nat-arith 定义的加法与乘法。则对一切 m,n,k∈Nm, n, k \in \mathbb{N}m,n,k∈N：

0+n=n,S(m)+n=S(m+n),0 + n = n, \qquad S(m) + n = S(m + n),0+n=n,S(m)+n=S(m+n),m+n=n+m,(m+n)+k=m+(n+k),m + n = n + m, \qquad (m + n) + k = m + (n + k),m+n=n+m,(m+n)+k=m+(n+k),m⋅0=0,m⋅n=n⋅m,(mn)k=m(nk),m(n+k)=mn+mk,m \cdot 0 = 0, \qquad m \cdot n = n \cdot m, \qquad (m n) k = m (n k), \qquad m(n + k) = m n + m k,m⋅0=0,m⋅n=n⋅m,(mn)k=m(nk),m(n+k)=mn+mk,

以及消去律

m+k=n+k  ⟹  m=n.m + k = n + k \implies m = n.m+k=n+k⟹m=n.

说明

⭐ 这些不是定义的一部分：def.nat-arith 只递归地规定了 m+0m+0m+0 与 m+S(n)m+S(n)m+S(n)，交换律、结合律、分配律全都要另外证。

⭐ 顺序有讲究，不能乱：先证两条辅助等式 0+n=n0+n=n0+n=n 与 S(m)+n=S(m+n)S(m)+n=S(m+n)S(m)+n=S(m+n)（都对 nnn 归纳），再做加法交换律（对 nnn 归纳，归纳步正好用这两条），然后结合律、乘法交换、分配律。后面的每一步都踩在前一步上。

⭐ 有了这些，N\mathbb{N}N 才是一个「半环」（没有加法逆元）；Z\mathbb{Z}Z 的构造（def.int）正是为了补上那个逆元。

    递推定义 + 归纳原理   ⟹  \implies⟹ 运算律
