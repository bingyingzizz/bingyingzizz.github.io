# Projective and Injective Objects　`def.projective-object`
English entry · root `../`
[in graph](../#n=def.projective-object)　·　[Chinese page (authoritative)](./def.projective-object.md)

In $\mathbf{Set}$ **every object is projective**, and this is precisely the axiom of choice: given a surjection $A \twoheadrightarrow B$ and a point of $B$, one can always choose a preimage.
