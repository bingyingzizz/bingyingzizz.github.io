# derivative　`def.derivative`
English entry · root `../`
[in graph](../#n=def.derivative)　·　[Chinese page (authoritative)](./def.derivative.md)

- **Differentiability a.e. does not guarantee** $F(b) - F(a) = \int_a^b F'$ (the Cantor function is continuous everywhere, differentiable a.e., and $F' = 0$ a.e., yet $F(1) - F(0) = 1 \ne 0$; note that it is **not differentiable everywhere**: at $1/3$ the one-sided difference quotients $0$ and $(3/2)^{k} \to \infty$ differ);

Equality requires absolute continuity.
