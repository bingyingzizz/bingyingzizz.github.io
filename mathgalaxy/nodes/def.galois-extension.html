又称伽罗瓦扩张·Galois 扩张

陈述

有限扩张 K/FK/FK/F 叫伽罗瓦扩张，如果它同时是正规的（正规扩张）与可分的（可分扩张）。

等价条件（任一）：

  • ∣Gal⁡(K/F)∣=[K:F]|\operatorname{Gal}(K/F)| = [K:F]∣Gal(K/F)∣=[K:F]；
  • F=KGal⁡(K/F)F = K^{\operatorname{Gal}(K/F)}F=KGal(K/F)（被群固定的元素只有 FFF 自己）；
  • KKK 是某个可分多项式在 FFF 上的分裂域。

说明

⭐ 为什么这三条等价：正规 + 可分保证「根都被送到根、且根互不相同」，于是自同构能把 [K:F][K:F][K:F] 个共轭伸满；反过来，自同构数够多就逼出正规与可分。三条等价的完整证明是这门课的主干，本图不展开。

⭐ 不变量是「不动点」：KG:={ x∈K:σ(x)=x  ∀σ∈G }K^{G} := \{\, x \in K : \sigma(x) = x\ \ \forall \sigma \in G \,\}KG:={x∈K:σ(x)=x  ∀σ∈G} 是 KKK 的子域，自动包含 FFF；伽罗瓦条件说的正是「它恰好等于 FFF，不多」。

⚠ 最常见的误会：以为「分裂域 = 伽罗瓦扩张」。缺的是可分：char ppp 下 xp−tx^{p} - txp−t 的分裂域（Fp(t)\mathbb{F}_{p}(t)Fp​(t) 上）不可分，所以不是伽罗瓦扩张。char 0 下这个区别消失 —— 这也是为什么初学时看不出来。
