# enough projectives　`def.enough-projectives`
English entry · root `../`
[in graph](../#n=def.enough-projectives)　·　[Chinese page (authoritative)](./def.enough-projectives.md)

**Why the condition "enough" is needed**: a derived functor replaces an object by a resolution and then takes homology; if some object has no resolution at all, the definition stalls. So homological algebra names categories by "having enough projectives / injectives".

**Examples**: $A\text{-}\mathbf{Mod}$ has both (free modules are projective, every module embeds into an injective module); $\mathrm{CondAb}$ has enough projectives (the finitely presented projective condensed abelian groups generate it); **a Grothendieck category automatically has enough injectives**.
