# quasi-compact　`def.quasi-compact`
English entry · root `../`
[in graph](../#n=def.quasi-compact)　·　[Chinese page (authoritative)](./def.quasi-compact.md)

In a topos, an equivalent formulation: for every surjection $\coprod_{i \in I} X_{i} \to X$ there is a finite $J \subseteq I$ such that $\coprod_{i \in J} X_{i} \to X$ is still a surjection.

## Notes · **draft**
This is the shape **compactness** keeps after the topology has been stripped away: **every cover has a finite subcover**. Compact Hausdorff spaces are exactly the quasi-compact objects in $\mathrm{Cond}$ — the definition of condensed sets is built on it, so the name is worth remembering.
