陈述

设 C\mathcal{C}C 是范畴，f:X→Yf : X \to Yf:X→Y 是其中的态射。称 fff 是同构，如果存在态射 g:Y→Xg : Y \to Xg:Y→X 使

g∘f=idX,f∘g=idY.g \circ f = \mathrm{id}_{X}, \qquad f \circ g = \mathrm{id}_{Y}.g∘f=idX​,f∘g=idY​.

这样的 ggg 唯一（若 g,g′g, g'g,g′ 都行，则 g=g′fg=g′g = g' f g = g'g=g′fg=g′），记 g=f−1g = f^{-1}g=f−1；此时称 XXX 与 YYY 同构，记 X≅YX \cong YX≅Y。

说明

⭐ 它是各分支里同一个概念的通名（此前全库只有范畴论那个三合一的 单态射 / 满态射 / 同构）：

  • 集合 / Set\mathbf{Set}Set：同构 = 双射；
  • 群、环、模：同构 = 双射的同态；
  • 拓扑 / Top\mathbf{Top}Top：同构 = 同胚（同胚）；
  • 向量空间：同构 = 线性同构（线性同构）；
  • 序集：同构 = 序同构（序同构）；
  • 而「单态射 / 满态射」是另一对概念 —— 一般范畴里单 + 满不蕴含同构（例如 Top\mathbf{Top}Top 里连续双射不必同胚），所以它不能当同构的通名。

⚠ 「同构」不等于「相等」：同构说的是「在保持结构的映射下无法区分」。整张星图里绝大多数结论都只在同构意义下成立（例如「V≅KnV \cong K^{n}V≅Kn」而不是「V=KnV = K^{n}V=Kn」）。

📌 与「等价」的区别：范畴之间的等价（伴随函子 那一族讨论的）只需要「差一个自然同构」，比同构弱；同构是最强的那一档。
