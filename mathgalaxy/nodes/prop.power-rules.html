Statement draft

Let AAA be a commutative ring, a,b∈Aa, b \in Aa,b∈A, m,n∈Zm, n \in \mathbb{Z}m,n∈Z (when negative exponents occur, a,ba, ba,b is required to be invertible). Then

am+n=am an,(am)n=amn,(ab)n=an bn.a^{m+n} = a^{m}\,a^{n}, \qquad (a^{m})^{n} = a^{mn}, \qquad (ab)^{n} = a^{n}\,b^{n}.am+n=aman,(am)n=amn,(ab)n=anbn.

If KKK is an ordered field and a>1a > 1a>1, then for m,n∈Zm, n \in \mathbb{Z}m,n∈Z:

m<n  ⟺  am<an;m < n \iff a^{m} < a^{n};m<n⟺am<an;

while for 0<a<10 < a < 10<a<1 the inequality reverses; for a=1a = 1a=1, an=1a^{n} = 1an=1 holds identically.

Notes draft

⭐ The three exponent laws are all "induction on nnn", with no trick.

What is really useful is monotonicity: for a>1a > 1a>1, n↦ann \mapsto a^{n}n↦an is strictly increasing, so in an Archimedean ordered field (e.g. R\mathbb{R}R), qn→0q^{n} \to 0qn→0 (0<q<10 < q < 10<q<1) can be written as qn≤1/(1+nh)q^{n} \le 1/(1+nh)qn≤1/(1+nh) and squeezed (it fails in a general ordered field: in Q(t)\mathbb{Q}(t)Q(t), ttt is infinite, and powers of q=1/2q = 1/2q=1/2 are never less than 1/t1/t1/t) — the proof that the geometric series converges rests on this.

⚠ The negative-exponent half requires first writing a−na^{-n}a−n as (a−1)n(a^{-1})^{n}(a−1)n, then using the positive-exponent result;

commutativity is essential here ((ab)−1=b−1a−1=a−1b−1(ab)^{-1} = b^{-1}a^{-1} = a^{-1}b^{-1}(ab)−1=b−1a−1=a−1b−1 holds only in the commutative case).
