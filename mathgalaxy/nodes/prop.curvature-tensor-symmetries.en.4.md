# Symmetries of the Curvature Tensor　`prop.curvature-tensor-symmetries`
English entry · root `../`
[in graph](../#n=prop.curvature-tensor-symmetries)　·　[Chinese page (authoritative)](./prop.curvature-tensor-symmetries.md)

1. **Antisymmetric in the first two indices**: $R_{ijk\ell} = -R_{jik\ell}$;
2. **antisymmetric in the last two**: $R_{ijk\ell} = -R_{ij\ell k}$;
3. **the two pairs can be exchanged**: $R_{ijk\ell} = R_{k\ell ij}$;
4. **first Bianchi identity**: $R_{ijk\ell}+R_{jki\ell}+R_{kij\ell} = 0$.

Hence the number of independent components is

$$\dim = \frac{n^{2}\bigl(n^{2}-1\bigr)}{12}:\qquad n = 2:\ 1,\quad n = 3:\ 6,\quad n = 4:\ 20 .$$
