# Gram 矩阵　`def.gram-matrix`
Gram 矩阵：内积的矩阵
layer 20 · 定义 · 多重线性与张量 · 抽象代数
[在星图里打开](../#n=def.gram-matrix)　·　[节点索引](../index.md)

**在做什么**：内积也是双线性型（实情形对称、复情形 Hermite），所以它也有矩阵。这个矩阵总是**半正定**的，且当 $v_{1}, \ldots, v_{k}$ 线性无关时**正定** —— 反过来每个正定矩阵都给出一个内积。
