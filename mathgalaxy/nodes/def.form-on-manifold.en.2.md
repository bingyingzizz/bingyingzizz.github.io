# Differential Form: Intrinsic Definition on Manifolds　`def.form-on-manifold`
English entry · root `../`
[in graph](../#n=def.form-on-manifold)　·　[Chinese page (authoritative)](./def.form-on-manifold.md)

Let $M$ be a smooth $n$-manifold. A **differential $k$-form** $\omega$ on $M$ assigns to each point $p\in M$ an **alternating $k$-linear form**

$$\omega_{p} : T_{p}M\times\cdots\times T_{p}M\longrightarrow\mathbb{R},$$

and it **depends smoothly**: for every chart $(U,x)$ the function $p\mapsto\omega_{p}\bigl(\partial_{i_{1}}\big|_{p},\ldots,\partial_{i_{k}}\big|_{p}\bigr)$ is smooth on $U$. The set of all $k$-forms on $M$ is denoted $\Omega^{k}(M)$.
