## Statement · **draft**
Let $V, W$ be vector spaces over a field $K$. A map $T : V \to W$ is called **$K$-linear** (or a linear map) if and only if

$$T(u + v) = T(u) + T(v), \qquad T(cu) = c\,T(u)$$

for all $u, v \in V$ and $c \in K$. Equivalently, $T(cu + v) = c\,T(u) + T(v)$.
