# Matrix Norm　`def.matrix-norm`
English entry · root `../`
[in graph](../#n=def.matrix-norm)　·　[Chinese page (authoritative)](./def.matrix-norm.md)

⚠️ **The Frobenius norm is not an operator norm** (except in dimension one). It is not induced by a vector norm, as shown by $\lVert I\rVert_{F} = \sqrt{n}$, while every operator norm satisfies $\lVert I\rVert = 1$. This gives the distinguishing test.

⚠️ The spectral norm uses **singular values** rather than eigenvalues: $\lVert A\rVert_2 = \sigma_{\max}$, whereas $\rho(A) = \max\lvert\lambda\rvert$. The two agree only for normal matrices (`def.normal-matrix`).
