# pre-abelian category　`def.pre-abelian-category`
English entry · root `../`
[in graph](../#n=def.pre-abelian-category)　·　[Chinese page (authoritative)](./def.pre-abelian-category.md)

Adding any one of the four equivalent conditions (every monomorphism is regular, images decompose uniquely, $\ker(\operatorname{coker} f) \cong \operatorname{coker}(\ker f)$, etc.) gives an abelian category, see @@def.abelian-category@@.
