陈述

白话：标架自己也会转 —— 沿某个方向走一小步，(e1,e2,e3)(e_{1},e_{2},e_{3})(e1​,e2​,e3​) 就微微转动一点。联络形式就是把这件「转动」记下来的九个 111-形式：喂给它一个方向，它告诉你标架绕哪个轴、转多快。和 Christoffel 符号是一回事，只是换了正交标架来记。

把 dei\mathrm{d}e_{i}dei​ 按标架展开，系数记作 ω ij\omega^{j}_{\ i}ω ij​：

dei=∑j=13ω ij ej,ω ij=⟨dei,ej⟩.\mathrm{d}e_{i} = \sum_{j=1}^{3}\omega^{j}_{\ i}\,e_{j},\qquad \omega^{j}_{\ i} = \langle \mathrm{d}e_{i}, e_{j}\rangle .dei​=j=1∑3​ω ij​ej​,ω ij​=⟨dei​,ej​⟩.

这九个 111-形式叫联络形式（Γ\GammaΓ-形式）。矩阵 (ω ji)(\omega^{i}_{\ j})(ω ji​) 反称（见 prop.connection-antisymmetric），故只有三个独立：ω 21,ω 31,ω 32\omega^{1}_{\ 2}, \omega^{1}_{\ 3}, \omega^{2}_{\ 3}ω 21​,ω 31​,ω 32​。

取 e3=ne_{3} = ne3​=n（法向）后它们分成两类：

  • ω 21\omega^{1}_{\ 2}ω 21​：内蕴部分 —— 曲面的 Levi-Civita 联络，Gauss 曲率由它算出；
  • ω 31,ω 32\omega^{1}_{\ 3}, \omega^{2}_{\ 3}ω 31​,ω 32​：外蕴部分 —— 第二基本形式由它们算出。

说明

名字的来历：ω ij\omega^{j}_{\ i}ω ij​ 描述「沿某个方向走时，标架怎么转」。它不是无端造出来的外形式：每一点上是 R3\mathbb{R}^{3}R3 的一个 3×33\times33×3 反称矩阵（333 个自由度），沿方向取值就成了 111-形式。

⭐ 这一拆分就是曲面论：R3\mathbb{R}^{3}R3 里曲率形式恒为零；限制到曲面上，ω 21\omega^{1}_{\ 2}ω 21​ 那部分由内蕴度量决定（Gauss 方程），剩下的外蕴部分给出 IIIIII 与 Codazzi 方程。整本曲面论都在读这两类形式的系数。

⚠️ ω ji\omega^{i}_{\ j}ω ji​ 与 ω ij\omega^{j}_{\ i}ω ij​ 差一个负号，是全图最容易抄错的地方。判据只有一条：对 ⟨ei,ej⟩=δij\langle e_{i}, e_{j}\rangle = \delta_{ij}⟨ei​,ej​⟩=δij​ 取外微分，不要凭记忆。

与 Christoffel 符号的关系：在不正交的标架 {ru,rv,n}\{r_{u}, r_{v}, n\}{ru​,rv​,n} 上把它写开，系数就是 Γ ijk\Gamma^{k}_{\ ij}Γ ijk​ 与 hijh_{ij}hij​ 的混合体（对照 def.second-fundamental-form 与 def.christoffel-symbol）；只有在正交标架下它才变成干净的反对称矩阵。

    标架联络   ⟹  \implies⟹ 曲面上有一个仿射联络

    设 S⊆R3S\subseteq\mathbb{R}^{3}S⊆R3 是正则曲面，∇ˉ\bar\nabla∇ˉ 是 R3\mathbb{R}^{3}R3 的平坦联络（∇ˉXY=dY(X)\bar\nabla_{X}Y = \mathrm{d}Y(X)∇ˉX​Y=dY(X)，把 YYY 当成 R3\mathbb{R}^{3}R3-值函数）。对切向量场定义（上标 ⊤\top⊤ 表示投影到切平面）

    ∇XY:=(∇ˉXY)⊤.\nabla_{X}Y := \bigl(\bar\nabla_{X}Y\bigr)^{\top}.∇X​Y:=(∇ˉX​Y)⊤.

    三条公理逐条验证：

    • 对 XXX 的 C∞(S)C^{\infty}(S)C∞(S)-线性：来自 ∇ˉ\bar\nabla∇ˉ 的对应性质与投影的线性；
