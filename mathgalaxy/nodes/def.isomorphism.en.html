Statement

Let C\mathcal{C}C be a category and f:X→Yf : X \to Yf:X→Y a morphism in it. We say that fff is an **isomorphism** if there exists a morphism g:Y→Xg : Y \to Xg:Y→X with

g∘f=idX,f∘g=idY.g \circ f = \mathrm{id}_{X}, \qquad f \circ g = \mathrm{id}_{Y}.g∘f=idX​,f∘g=idY​.

Such a ggg is unique (if g,g′g, g'g,g′ both work, then g=g′fg=g′g = g' f g = g'g=g′fg=g′); we write g=f−1g = f^{-1}g=f−1. In this case XXX and YYY are called **isomorphic**, written X≅YX \cong YX≅Y.

Notes

⭐ **It is the common name for one concept across the branches** (previously only the three-in-one 单态射 / 满态射 / 同构 of category theory existed):

  • sets / Set\mathbf{Set}Set: isomorphism = **bijection**;
  • groups, rings, modules: isomorphism = bijective homomorphism;
  • topology / Top\mathbf{Top}Top: isomorphism = **homeomorphism** (同胚);
  • vector spaces: isomorphism = **linear isomorphism** (线性同构);
  • posets: isomorphism = **order isomorphism** (序同构);
  • whereas "monomorphism / epimorphism" is another pair of concepts** — in a general category mono + epi does not** imply isomorphism (for example, in Top\mathbf{Top}Top a continuous bijection need not be a homeomorphism), so it cannot serve as the common name for isomorphism.

⚠ "Isomorphic" is not "equal": isomorphic means "indistinguishable under a structure-preserving map". Almost all statements here hold only up to isomorphism (for example "V≅KnV \cong K^{n}V≅Kn" rather than "V=KnV = K^{n}V=Kn").

📌 Difference from "equivalence": an **equivalence** between categories (discussed in the 伴随函子 family) requires only "isomorphic up to a natural isomorphism" and is weaker than isomorphism; isomorphism is the strongest tier.
