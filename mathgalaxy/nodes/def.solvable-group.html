群 GGG 叫可解的，当且仅当存在正规链

{e}=G0⊴G1⊴⋯⊴Gn=G\{e\} = G_0 \trianglelefteq G_1 \trianglelefteq \cdots \trianglelefteq G_n = G {e}=G0​⊴G1​⊴⋯⊴Gn​=G

使每个商 Gi/Gi−1G_i / G_{i-1}Gi​/Gi−1​ 都是阿贝尔群。

等价刻画：令 G(0):=GG^{(0)} := GG(0):=G、G(k+1):=[G(k),G(k)]G^{(k+1)} := [G^{(k)}, G^{(k)}]G(k+1):=[G(k),G(k)]（换位子子群），得导出列

G=G(0)⊵G(1)⊵G(2)⊵⋯G = G^{(0)} \trianglerighteq G^{(1)} \trianglerighteq G^{(2)} \trianglerighteq \cdotsG=G(0)⊵G(1)⊵G(2)⊵⋯

则 GGG 可解   ⟺  \iff⟺ 存在 nnn 使 G(n)={e}G^{(n)} = \{e\}G(n)={e}。

说明

⭐ 三个等价说法，用哪个都行：

  • 存在阿贝尔商的正规链（定义）；
  • 导出列有限步终止（最好算）；
  • 有合成列且所有合成因子都是素数阶循环群（最好判）。

⭐ 名字的来源与它真正的价值：Galois 理论的主定理把「多项式方程可用根式解」翻译成「它的 Galois 群可解」—— Abel–Ruffini 定理就从这里出来。这条线的另一半（域扩张）在批 7。

⚠ 「可解」不是「阿贝尔」：S3S_3S3​ 与 S4S_4S4​ 都可解但非阿贝尔。「可解」说的是「能被一串阿贝尔商逐层拆开」，即「离阿贝尔群有限步远」。

⭐ 单群 + 可解   ⟹  \implies⟹ 阿贝尔（因为合成列只能是一条 {e}⊴G\{e\} \trianglelefteq G{e}⊴G，因子 GGG 单且必须阿贝尔）。所以非阿贝尔单群一律不可解，A5A_5A5​ 是第一个例子。

⭐ 两类必会：阿贝尔群全部可解（一步链）；ppp-群全部可解（用类方程归纳，中心非平凡   ⟹  \implies⟹ 可对 Z(G)Z(G)Z(G) 与 G/Z(G)G/Z(G)G/Z(G) 归纳）。

  • 本页 ⟹ 可解性对子群与商群封闭推出
    导出列的三条函子性   ⟹  \implies⟹ 封闭性

    先记两个初等事实：若 φ:G→G′\varphi : G \to G'φ:G→G′ 是满同态，则 φ(G(k))=(G′)(k)\varphi(G^{(k)}) = (G')^{(k)}φ(G(k))=(G′)(k)（换位子被送到换位子，且满射保证反向也成立）。

    （a） 设 GGG 可解，G(n)={e}G^{(n)} = \{e\}G(n)={e}。因 H≤GH \le GH≤G 蕴含 H(k)≤G(k)H^{(k)} \le G^{(k)}H(k)≤G(k)（对 kkk 归纳：[H,H]≤[G,G][H,H] \le [G,G][H,H]≤[G,G]，再逐层），故 H(n)≤G(n)={e}H^{(n)} \le G^{(n)} = \{e\}H(n)≤G(n)={e}，即 H(n)={e}H^{(n)} = \{e\}H(n)={e}。

    （b） 设 π:G→G/N\pi : G \to G/Nπ:G→G/N 是自然满同态。由上面的事实

    (G/N)(n)=π(G(n))=π({e})={e},(G/N)^{(n)} = \pi(G^{(n)}) = \pi(\{e\}) = \{e\},(G/N)(n)=π(G(n))=π({e})={e},

    故 G/NG/NG/N 可解。

    （c） 设 NNN 可解、G/NG/NG/N 可解。取 nnn 使 (G/N)(n)={e}(G/N)^{(n)} = \{e\}(G/N)(n)={e}，即 π(G(n))={e}\pi(G^{(n)}) = \{e\}π(G(n))={e}，也就是 G(n)≤NG^{(n)} \le NG(n)≤N。再取 mmm 使 N(m)={e}N^{(m)} = \{e\}N(m)={e}。于是

    G(n+m)=(G(n))(m)≤N(m)={e},G^{(n+m)} = \bigl(G^{(n)}\bigr)^{(m)} \le N^{(m)} = \{e\},G(n+m)=(G(n))(m)≤N(m)={e},

    （第一步用了同样的事实 [H,H][H,H][H,H] 的迭代：G(n+m)=(G(n))(m)G^{(n+m)} = (G^{(n)})^{(m)}G(n+m)=(G(n))(m)，因为导出列就是反复取换位子。）故 GGG 可解。∎

    ⭐ 三条的证明都只用了「H≤G  ⟹  H(k)≤G(k)H \le G \implies H^{(k)} \le G^{(k)}H≤G⟹H(k)≤G(k)」与「满同态把导出列送到导出列」这两句话 —— 导出列是函子式的，所以可解性才这么听话。
