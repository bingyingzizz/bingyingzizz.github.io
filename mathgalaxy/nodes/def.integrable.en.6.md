# integrable　`def.integrable`
English entry · root `../`
[in graph](../#n=def.integrable)　·　[Chinese page (authoritative)](./def.integrable.md)

⚠️ **Necessary hypotheses**: $f$ must be **measurable** (an unmeasurable function has no integral to speak of). The difference from **Riemann integrability**: Riemann requires boundedness plus a null set of discontinuities (`thm.riemann-lebesgue-criterion`), whereas Lebesgue integrability **does not require boundedness** ($1/\sqrt{x}$ is Lebesgue integrable on $(0,1]$); conversely, a bounded Riemann integrable function is Lebesgue integrable (`prop.riemann-implies-lebesgue`).
