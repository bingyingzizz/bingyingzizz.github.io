Statement

There exists an "inductive set" — a set containing ∅\emptyset∅ and closed under the successor operation:

∃I[∅∈I∧∀x(x∈I→x∪{x}∈I)]\exists I [ \emptyset \in I \wedge \forall x ( x \in I \to x \cup \{ x \} \in I ) ]∃I[∅∈I∧∀x(x∈I→x∪{x}∈I)]

The clause ∅∈I\emptyset \in I∅∈I cannot be dropped: I=ω∖{0}I = \omega \setminus \{0\}I=ω∖{0} is non-empty and closed under successor (x≠0  ⟹  S(x)≠0x \ne 0 \implies S(x) \ne 0x=0⟹S(x)=0), yet it does not contain ∅\emptyset∅ — "non-empty + closed under successor" does not force ∅∈I\emptyset \in I∅∈I. (∅\emptyset∅ is a primitive object, see "the empty set"). This axiom asserts the existence of an infinite set, and is the only source from which the set of natural numbers ω\omegaω is built.
