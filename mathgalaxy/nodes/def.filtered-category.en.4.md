# filtered category　`def.filtered-category`
English entry · root `../`
[in graph](../#n=def.filtered-category)　·　[Chinese page (authoritative)](./def.filtered-category.md)

⭐ **Why it is required everywhere**: filtered colimits are **exact** (commute with finite limits) in $\mathbf{Set}$, $A\text{-}\mathbf{Mod}$, $\mathrm{CondAb}$; this is Grothendieck's **AB5** axiom and the key condition when homological algebra selects categories. Colimits along a general category lack this good property.

⚠️ Distinguish from "chain": a chain is a **totally ordered** subset, stronger than filtered; filtered only requires "a common upper bound", and any two elements need not be comparable.
