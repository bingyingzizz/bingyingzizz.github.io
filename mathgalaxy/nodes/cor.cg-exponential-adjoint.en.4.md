# Exponential Adjunction for Compactly Generated Spaces　`cor.cg-exponential-adjoint`
English entry · root `../`
[in graph](../#n=cor.cg-exponential-adjoint)　·　[Chinese page (authoritative)](./cor.cg-exponential-adjoint.md)

**Proof (adjunction = natural bijection).** What must be shown is a **natural** bijection
$$\operatorname{Hom}_{k\mathbf{Top}}\bigl(k(X\times Y),\ Z\bigr) \;\cong\; \operatorname{Hom}_{k\mathbf{Top}}\bigl(X,\ kC(kY, Z)\bigr).$$
- **Left-hand side**: $k$-ification is a coreflection (the inclusion $i$ has a right adjoint $k$), so for compactly generated $Z$ one has $\operatorname{Hom}_{k\mathbf{Top}}(kA, Z) = \operatorname{Hom}_{\mathbf{Top}}(A, Z)$;
