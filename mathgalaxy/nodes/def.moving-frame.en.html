Statement

Let U0⊆SU_{0} \subseteq SU0​⊆S be an open set on the surface. A moving frame is a triple of C1C^{1}C1 vector fields e1,e2,e3e_{1}, e_{2}, e_{3}e1​,e2​,e3​ such that at every point (e1,e2,e3)(e_{1}, e_{2}, e_{3})(e1​,e2​,e3​) is an orthonormal basis of R3\mathbb{R}^{3}R3 (it moves with the point, hence "moving"). The dual coframe is

ωi:=⟨dr, ei⟩,i=1,2,3,\omega^{i} := \langle \mathrm{d}r,\, e_{i}\rangle ,\qquad i = 1,2,3,ωi:=⟨dr,ei​⟩,i=1,2,3,

these are 111-forms on the parameter domain (vvv must first be sent by dr\mathrm{d}rdr to an ambient vector, and only then can it be paired with eie_{i}ei​). ⚠ For a surface, dr\mathrm{d}rdr lies in the tangent plane, so ω3≡0\omega^{3} \equiv 0ω3≡0; and ωi(ej)=δ ji\omega^{i}(e_{j}) = \delta^{i}_{\ j}ωi(ej​)=δ ji​ must be read as "the ωi\omega^{i}ωi on the parameter domain paired with the pullback to the parameter domain of the tangent vector eje_{j}ej​" — ωi\omega^{i}ωi is defined on the parameter domain UUU and eje_{j}ej​ is an ambient vector, so only j=1,2j = 1, 2j=1,2 (the tangential ones) lie in the pairing domain; e3e_{3}e3​ is normal, and ω3(e3)\omega^{3}(e_{3})ω3(e3​) is not defined here. The differential of the position vector expands in the frame as

dr=ω1e1+ω2e2+ω3e3.\mathrm{d}r = \omega^{1}e_{1}+\omega^{2}e_{2}+\omega^{3}e_{3}.dr=ω1e1​+ω2e2​+ω3e3​.

This is called the soldering equation: it translates "how rrr moves" into "how much it moves in each frame component".

Notes

Why change the language at all: the coordinate route requires computing ruu,ruv,rvvr_{uu}, r_{uv}, r_{vv}ruu​,ruv​,rvv​ and the partial derivatives of nnn; the frame route expands dr\mathrm{d}rdr and dei\mathrm{d}e_{i}dei​ once, after which everything is algebra between 111-forms (wedge products, comparing coefficients). This is exactly the point of "using a moving frame in place of a complicated computation".

The standard choice on a surface: e3=ne_{3} = ne3​=n, with e1,e2e_{1}, e_{2}e1​,e2​ unit tangent vector fields orthogonal to nnn. Then ω3=⟨dr,n⟩=0\omega^{3} = \langle \mathrm{d}r, n\rangle = 0ω3=⟨dr,n⟩=0: there is no normal increment on the surface.

⚠ (e1,e2)(e_{1}, e_{2})(e1​,e2​) exists only locally and is not unique (one may rotate it).
