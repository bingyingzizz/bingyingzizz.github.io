# Rado theorem: every compact surface is triangulable　`thm.rado`
English entry · root `../`
[in graph](../#n=thm.rado)　·　[Chinese page (authoritative)](./thm.rado.md)

**Approach B (differential topology).** Existence of a smooth structure (Whitehead: a $C^{1}$ structure suffices, or construct $C^{\infty}$ directly) $\rightarrow$ a Morse function $\rightarrow$ a handle decomposition $\rightarrow$ each handle is a $0/1/2$-handle, giving a CW decomposition in attachment order $\rightarrow$ triangulate each handle and subdivide compatibly $\rightarrow$ obtain a triangulation. Gaps: (iv) existence of a smooth structure, (v) existence of a Morse function (requiring $C^{2}$ approximation), and (vi) compatibility between the handle decomposition and triangulation (treatment of $1$-handles and gluing between handles).
