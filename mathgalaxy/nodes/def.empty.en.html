Statement

The empty set is the set with no elements, written ∅\emptyset∅:

∅:={x:x≠x}\emptyset := \{ x : x \ne x \}∅:={x:x=x}

"x≠xx \ne xx=x" fails for every xxx, so this set has no elements at all. It is a primitive object of the language, on the same level as the Axiom of Extensionality and first-order logic.

Hence for every set AAA: ∅⊆A\emptyset \subseteq A∅⊆A (vacuously true), and ∅\emptyset∅ is the least element under ⊆\subseteq⊆.

The Axiom of Extensionality supplies at most one such set;

the half that says one exists is a separate result — see "the empty set exists".
