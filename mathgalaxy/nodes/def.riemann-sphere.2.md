## 陈述（续）
**球极投影**把单位球面 $S^{2} \subset \mathbb{R}^{3}$ 与 $\widehat{\mathbb{C}}$ 一一对应：从北极 $N = (0,0,1)$ 出发，把球面上除 $N$ 外的点投到赤道平面 $w = 0$ 上。对 $z = u + iv$，
$$(x, y, w) = \left(\frac{2u}{1 + |z|^{2}},\ \frac{2v}{1 + |z|^{2}},\ \frac{|z|^{2} - 1}{1 + |z|^{2}}\right).$$

反过来 $z = \dfrac{x + iy}{1 - w}$。$N$ 对应 $\infty$。
