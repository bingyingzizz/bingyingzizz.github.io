陈述

设 RRR 是含幺环，III 是左 RRR-模。则 III 内射当且仅当：对每个左理想 J⊆RJ \subseteq RJ⊆R 与每个 RRR-线性映射 f:J→If : J \to If:J→I，都存在 x∈Ix \in Ix∈I 使

f(a)=ax(∀a∈J),f(a) = a x \qquad (\forall a \in J),f(a)=ax(∀a∈J),

即 fff 总能延拓成 R→IR \to IR→I、1↦x1 \mapsto x1↦x。

也就是说：检验内射性时，「A↣BA \rightarrowtail BA↣B」可以只取「理想含入 J↣RJ \rightarrowtail RJ↣R」。

说明

必要性：J↣RJ \rightarrowtail RJ↣R 本身就是单射，内射性直接给出延拓 R→IR \to IR→I ✓。

充分性：给定单射 A⊆BA \subseteq BA⊆B 与 f:A→If : A \to If:A→I。考虑所有延拓对 (A1,f1)(A_{1}, f_{1})(A1​,f1​)（A⊆A1⊆BA \subseteq A_{1} \subseteq BA⊆A1​⊆B、f1f_{1}f1​ 在 AAA 上与 fff 一致），按「定义域更大」排序。一条链的并仍是延拓，故由 Zorn 引理 存在极大元 (A1,f1)(A_{1}, f_{1})(A1​,f1​)。

若 A1≠BA_{1} \ne BA1​=B，取 b∈B∖A1b \in B \setminus A_{1}b∈B∖A1​，令

J:={ r∈R:rb∈A1 },h:J→I,h(r):=f1(rb).J := \{\, r \in R : r b \in A_{1} \,\}, \qquad h : J \to I, \quad h(r) := f_{1}(r b).J:={r∈R:rb∈A1​},h:J→I,h(r):=f1​(rb).

JJJ 是左理想、hhh 是 RRR-线性的。由假设，存在 x∈Ix \in Ix∈I 使 h(r)=rxh(r) = r xh(r)=rx（∀r∈J\forall r \in J∀r∈J）。定义 f2(a+rb):=f1(a)+rxf_{2}(a + r b) := f_{1}(a) + r xf2​(a+rb):=f1​(a)+rx。

良定义：若 a+rb=a1+r1ba + r b = a_{1} + r_{1} ba+rb=a1​+r1​b，则 (r−r1)b=a1−a∈A1(r - r_{1}) b = a_{1} - a \in A_{1}(r−r1​)b=a1​−a∈A1​，故 r−r1∈Jr - r_{1} \in Jr−r1​∈J，于是 f1((r−r1)b)=f1(a1−a)f_{1}((r - r_{1})b) = f_{1}(a_{1} - a)f1​((r−r1​)b)=f1​(a1​−a)，即 f1(a)+rx=f1(a1)+r1xf_{1}(a) + r x = f_{1}(a_{1}) + r_{1} xf1​(a)+rx=f1​(a1​)+r1​x ✓。这与极大性矛盾，故 A1=BA_{1} = BA1​=B ✓。∎

⭐ 意义：把「对一切单射检验」压成「对 RRR 的理想检验」，而理想是 RRR 的子集、通常少得多。这一步是把范畴条件翻译成环上条件的关键，后面 thm.pid-injective-divisible 全靠它。

⚠️ 判据里的「理想」不能换成「有限生成理想」：平坦有 Lambek 定理可以只查有限生成理想，内射没有这样的对偶弱化（除非环是 Noether 的）。

  • 本页 ⟹ 内射等价于可除推出
    Baer 判据 + 主理想   ⟹  \implies⟹ 内射即除

    （可除   ⟹  \implies⟹ 内射） 用 Baer 判据。设 J⊆RJ \subseteq RJ⊆R 是理想，f:J→If : J \to If:J→I。主理想整环里 J=(a)J = (a)J=(a)。

    • a=0a = 0a=0：J=0J = 0J=0，取 x=0x = 0x=0 即可；
    • a≠0a \ne 0a=0：记 y:=f(a)y := f(a)y:=f(a)，由可除性取 x∈Ix \in Ix∈I 使 ax=ya x = yax=y。于是对 ra∈Jr a \in Jra∈J：f(ra)=rf(a)=rax=(ra)xf(r a) = r f(a) = r a x = (r a) xf(ra)=rf(a)=rax=(ra)x ✓，即 fff 就是「乘 xxx」。

    故延拓总存在，III 内射 ✓。

    （内射   ⟹  \implies⟹ 可除） 设 a≠0a \ne 0a=0、y∈Iy \in Iy∈I。把 Baer 判据用在理想 (a)(a)(a) 与映射 a↦ya \mapsto ya↦y 上，得 x∈Ix \in Ix∈I 使 ax=ya x = yax=y ✓。

    Z\mathbb{Z}Z 是主理想整环，而 Z\mathbb{Z}Z-模即阿贝尔群（prop.zmod-is-ab），故「内射『Z\mathbb{Z}Z-模』」与「可除群」是同一件事 ✓。∎

    这条把范畴条件彻底翻译成群论条件，是 §「内射模」整条链的落点：从此内射性可以用除法来检查。

  • 本页 ⟹ 足够多内射对象推出
    Q/Z\mathbb{Q}/\mathbb{Z}Q/Z 内射 + 一个伴随   ⟹  \implies⟹ 足够多内射

    （一）Q/Z\mathbb{Q}/\mathbb{Z}Q/Z 是内射 Z\mathbb{Z}Z-模且是余生成元。 内射性由 thm.pid-injective-divisible（可除即内射）给出。余生成元：给定 0≠a∈A0 \ne a \in A0=a∈A，⟨a⟩\langle a \rangle⟨a⟩ 是循环群（≅Z/m\cong \mathbb{Z}/m≅Z/m 或 ≅Z\cong \mathbb{Z}≅Z），它上面存在非零特征标 ⟨a⟩→Q/Z\langle a \rangle \to \mathbb{Q}/\mathbb{Z}⟨a⟩→Q/Z，再用内射性延拓到 AAA ✓。故求值映射 A→A∨∨A \to A^{\vee\vee}A→A∨∨ 单。

    （二）嵌入内射 RRR-模。 m↦(r↦rm)m \mapsto (r \mapsto r m)m↦(r↦rm) 给出单射 M↪Hom⁡Z(R,M)M \hookrightarrow \operatorname{Hom}_{\mathbb{Z}}(R, M)M↪HomZ​(R,M)（取 r=1r = 1r=1 复原 mmm）。由（一）取内射 Z\mathbb{Z}Z-模 E⊇ME \supseteq ME⊇M，则 Hom⁡Z(R,−)\operatorname{Hom}_{\mathbb{Z}}(R, -)HomZ​(R,−) 作用后仍单（它保单射：作为右伴随它保极限，而核是极限），得到 RRR-模单射

    M↪Hom⁡Z(R,M)↪Hom⁡Z(R,E).M \hookrightarrow \operatorname{Hom}_{\mathbb{Z}}(R, M) \hookrightarrow \operatorname{Hom}_{\mathbb{Z}}(R, E).M↪HomZ​(R,M)↪HomZ​(R,E).

    （三）Hom⁡Z(R,E)\operatorname{Hom}_{\mathbb{Z}}(R, E)HomZ​(R,E) 内射。 它等于遗忘函子 UUU 的右伴随作用在内射对象上：

    Hom⁡R(N,Hom⁡Z(R,E))  ≅  Hom⁡Z(UN, E).\operatorname{Hom}_{R}\bigl(N, \operatorname{Hom}_{\mathbb{Z}}(R, E)\bigr) \;\cong\; \operatorname{Hom}_{\mathbb{Z}}(UN,\ E).HomR​(N,HomZ​(R,E))≅HomZ​(UN, E).

    一般事实：伴随 F⊣GF \dashv GF⊣G 中若 FFF 正合，则 GGG 把内射对象送到内射对象（把 Hom⁡(−,GI)\operatorname{Hom}(-, GI)Hom(−,GI) 换成 Hom⁡(F−,I)\operatorname{Hom}(F -, I)Hom(F−,I) 即知）；UUU 显然正合 ✓。

    于是每个模都嵌进内射模，递归造出内射消解 ✓。∎

    三步各用一件现成工具：Q/Z\mathbb{Q}/\mathbb{Z}Q/Z 内射（来自主理想整环那一条）、余生成元性质、遗忘–余自由伴随。比 Grothendieck 范畴的超限迭代短得多，代价是只对模范畴有效。

推出 1

  • 内射模、内射的单射可裂 ⟹ 本页推出
    延拓性质 + Zorn 引理   ⟹  \implies⟹ Baer 判据

    （  ⟹  \implies⟹） J↣RJ \rightarrowtail RJ↣R 本身是单射，内射性直接给出延拓 R→IR \to IR→I，记 1↦x1 \mapsto x1↦x，则 f(a)=axf(a) = a xf(a)=ax ✓。

    （⇐\Leftarrow⇐） 给定单射 A⊆BA \subseteq BA⊆B 与 f:A→If : A \to If:A→I。考虑一切延拓对 (A1,f1)(A_{1}, f_{1})(A1​,f1​)（A⊆A1⊆BA \subseteq A_{1} \subseteq BA⊆A1​⊆B，f1∣A=ff_{1}|_{A} = ff1​∣A​=f），按定义域包含排序。链的并仍是延拓，故由 Zorn 引理存在极大元 (A1,f1)(A_{1}, f_{1})(A1​,f1​) ✓。

    若 A1≠BA_{1} \ne BA1​=B，取 b∈B∖A1b \in B \setminus A_{1}b∈B∖A1​，令 J:={ r∈R:rb∈A1 }J := \{\, r \in R : r b \in A_{1} \,\}J:={r∈R:rb∈A1​}、h(r):=f1(rb)h(r) := f_{1}(r b)h(r):=f1​(rb)。JJJ 是左理想、hhh 线性；由假设存在 x∈Ix \in Ix∈I 使 h(r)=rxh(r) = r xh(r)=rx（∀r∈J\forall r \in J∀r∈J）。

    定义 f2(a+rb):=f1(a)+rxf_{2}(a + r b) := f_{1}(a) + r xf2​(a+rb):=f1​(a)+rx。良定义：若 a+rb=a1+r1ba + r b = a_{1} + r_{1} ba+rb=a1​+r1​b，则 (r−r1)b=a1−a∈A1(r - r_{1}) b = a_{1} - a \in A_{1}(r−r1​)b=a1​−a∈A1​，故 r−r1∈Jr - r_{1} \in Jr−r1​∈J，于是 f1((r−r1)b)=f1(a1−a)f_{1}((r-r_{1})b) = f_{1}(a_{1}-a)f1​((r−r1​)b)=f1​(a1​−a)，两边即 f1(a)+rx=f1(a1)+r1xf_{1}(a) + rx = f_{1}(a_{1}) + r_{1}xf1​(a)+rx=f1​(a1​)+r1​x ✓。这与极大性矛盾，故 A1=BA_{1} = BA1​=B ✓。∎

    整条证明只用了「RRR 是环」与 Zorn 引理，没有任何小性/有限性假设 —— 所以它对任意环都成立，这是它比平坦的 Lambek 判据更「硬」的原因。
