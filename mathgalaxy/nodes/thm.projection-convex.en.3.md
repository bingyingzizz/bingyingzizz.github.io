# nearest point in a closed convex set　`thm.projection-convex`
English entry · root `../`
[in graph](../#n=thm.projection-convex)　·　[Chinese page (authoritative)](./thm.projection-convex.md)

**Hypotheses used in each direction** (existence has a completeness cost; the variational characterization is a local algebraic argument):
- Nearest point $\implies$ variational inequality: first require $y\in C$, use convexity to guarantee $y+t(z-y)\in C$, expand the square and let $t\to0$; this is not a definition unfolding, and needs no completeness.
- Variational inequality $\implies$ nearest point: still requires $y\in C$, and is just a square expansion; this direction does not even need convexity, closedness, or completeness.
- Existence and uniqueness for all $x$: use nonemptiness, convexity, the parallelogram
