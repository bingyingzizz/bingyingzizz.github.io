# power set　`def.power-set`
English entry · root `../`
[in graph](../#n=def.power-set)　·　[Chinese page (authoritative)](./def.power-set.md)

- The generated $\sigma$-algebra is the intersection of all $\sigma$-algebras containing $\mathcal{E}$, and $\mathcal{P}(X)$ guarantees that this intersection is non-empty.

$\emptyset \in \mathcal{P}(X)$ and $X \in \mathcal{P}(X)$ for every $X$ — a power set is never empty.
