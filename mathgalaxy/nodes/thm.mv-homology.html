陈述

设 X=U∪VX = U \cup VX=U∪V，U,V⊆XU, V \subseteq XU,V⊆X 是开集（更一般：U,VU, VU,V 的内部覆盖 XXX）。记 i∗,j∗i_{}, j_{}i∗​,j∗​ 为 U∩V↪U,VU \cap V \hookrightarrow U, VU∩V↪U,V 的包含映射诱导的映射。则存在长正合列

Hp(U∩V)→Hp(U)⊕Hp(V)→Hp(X)H_{p}(U \cap V) \to H_{p}(U) \oplus H_{p}(V) \to H_{p}(X)Hp​(U∩V)→Hp​(U)⊕Hp​(V)→Hp​(X)→ ∂∗ Hp−1(U∩V)\xrightarrow{\ \partial_{*}\ } H_{p-1}(U \cap V) ∂∗​ ​Hp−1​(U∩V)

（两端各再向左右无限延伸成 ⋯\cdots⋯）。其中两个不明显的映射是

Φ[z]:=(i∗[z], −j∗[z]),Ψ[a,b]:=[a+b].\Phi[z] := (i_{*}[z],\ -j_{*}[z]),\qquad \Psi[a, b] := [a + b].Φ[z]:=(i∗​[z], −j∗​[z]),Ψ[a,b]:=[a+b].

把 HHH 换成约化同调 H~\tilde{H}H~，同样的序列照样成立。

说明

⚠️ 本图的证明是骨架。结构与关键的一步： ① 记 S∗(U)+S∗(V)⊆S∗(X)S_{}(U) + S_{}(V) \subseteq S_{}(X)S∗​(U)+S∗​(V)⊆S∗​(X) 为「落在 UUU 里的」与「落在 VVV 里的」奇异单纯形共同生成的子复形；有短正合列 0→S∗(U∩V)→S∗(U)⊕S∗(V)→S∗(U)+S∗(V)→00 \to S_{}(U \cap V) \to S_{}(U) \oplus S_{}(V) \to S_{}(U) + S_{}(V) \to 00→S∗​(U∩V)→S∗​(U)⊕S∗​(V)→S∗​(U)+S∗​(V)→0； ② 由 thm.long-exact-pair 的追图得一条长正合列； ③ 关键一步（本图不展开）：包含 S∗(U)+S∗(V)↪S∗(X)S_{}(U) + S_{}(V) \hookrightarrow S_{}(X)S∗​(U)+S∗​(V)↪S∗​(X) 诱导同调同构。理由是小单纯形引理 / 重心重分：给定奇异 ppp-单纯形 σ:Δp→X\sigma : \Delta^{p} \to Xσ:Δp→X，{σ−1(U),σ−1(V)}\{\sigma^{-1}(U), \sigma^{-1}(V)\}{σ−1(U),σ−1(V)} 是 Δp\Delta^{p}Δp 的开覆盖；取 Lebesgue 数 δ\deltaδ，反复重心重分直到每个小单纯形的直径 <δ< \delta<δ，则每个小单纯形整体落在 UUU 或 VVV 里——于是「重分后的链」落在 S∗(U)+S∗(V)S_{}(U) + S_{*}(V)S∗​(U)+S∗​(V) 里。重分链映射与包含互为链同伦逆； ④ 把 ②③ 接起来即得 MV。

⭐ 全部的力气都在第 ③ 步的重细分上：它把「局部落在 UUU 或 VVV」升级成「整体等价」。这条也是最容易被略过、却最容易出错的地方（符号与链同伦的显式构造）。

⚠️ 与 thm.mayer-vietoris 的区别：那个节点是 de Rham 版（光滑流形、实系数、微分形式复形，def.de-rham-complex）。这里是奇异链版（任意空间、Z\mathbb{Z}Z 系数）。两个序列形状一样，但一个有挠部信息、一个没有 —— 名字相似不等于同一个结论，不要互相引用当证明。

💡 常用法：算 H~∗(Sn)\tilde{H}_{*}(S^{n})H~∗​(Sn)（thm.sphere-homology）、把环面拆成两张柱面、把连通和拆成两块挖掉小球的空间。

推出 1

  • 本页 ⟹ 球面的同调推出
    两个可缩开半球 + 交叠形变收缩到赤道   ⟹  \implies⟹ 只剩两个非零

    开覆盖：令 U:=Sn∖{南极 N}U := S^{n} \setminus \{\text{南极 } N\}U:=Sn∖{南极 N}、V:=Sn∖{北极 S}V := S^{n} \setminus \{\text{北极 } S\}V:=Sn∖{北极 S}。两者都是开集且覆盖 SnS^{n}Sn，各自经球极投影同胚于 Rn\mathbb{R}^{n}Rn，因而可缩。

    可缩   ⟹  \implies⟹ 约化同调为零：恒等映射 ≃\simeq≃ 常值映射，同调不变性给出两者诱导相同的映射；而常值映射在约化同调上是零（H~0\tilde{H}_{0}H~0​ 上：ε(1⋅x)=1\varepsilon(1 \cdot x) = 1ε(1⋅x)=1 但约化同调里点类为零；p≥1p \ge 1p≥1 上：链映射经过 S∗(pt)S_{*}(\mathrm{pt})S∗​(pt)，那里没有正维数的链）。故 H~p(U)=H~p(V)=0\tilde{H}_{p}(U) = \tilde{H}_{p}(V) = 0H~p​(U)=H~p​(V)=0 对一切 ppp。

    交叠：U∩V=Sn∖{N,S}U \cap V = S^{n} \setminus \{N, S\}U∩V=Sn∖{N,S} 沿经线把每点推到赤道，给出到 Sn−1S^{n-1}Sn−1 的形变收缩，故 H~p(U∩V)≅H~p(Sn−1)\tilde{H}_{p}(U \cap V) \cong \tilde{H}_{p}(S^{n-1})H~p​(U∩V)≅H~p​(Sn−1)。

    代入 MV（约化版）：序列在每处 ppp 上是

    H~p(U∩V)→0→H~p(Sn)\tilde{H}_{p}(U \cap V) \to 0 \to \tilde{H}_{p}(S^{n})H~p​(U∩V)→0→H~p​(Sn)→H~p−1(U∩V)→0,\to \tilde{H}_{p-1}(U \cap V) \to 0,→H~p−1​(U∩V)→0,

    （这两处 000 是 H~p(U)⊕H~p(V)\tilde{H}_{p}(U) \oplus \tilde{H}_{p}(V)H~p​(U)⊕H~p​(V)，两块都为零。）

    两端为零   ⟹  \implies⟹ 中间的映射被夹成同构：H~p(Sn)≅H~p−1(U∩V)≅H~p−1(Sn−1)\tilde{H}_{p}(S^{n}) \cong \tilde{H}_{p-1}(U \cap V) \cong \tilde{H}_{p-1}(S^{n-1})H~p​(Sn)≅H~p−1​(U∩V)≅H~p−1​(Sn−1)。

    基础情形 n=0n = 0n=0：S0S^{0}S0 是两点，由 prop.h0-components，H0(S0)=Z2H_{0}(S^{0}) = \mathbb{Z}^{2}H0​(S0)=Z2，取约化得 H~0(S0)=Z\tilde{H}_{0}(S^{0}) = \mathbb{Z}H~0​(S0)=Z。

    归纳：反复用上式把维数降下来，得 H~p(Sn)=H~p−(n)(S0)\tilde{H}_{p}(S^{n}) = \tilde{H}_{p-(n)}(S^{0})H~p​(Sn)=H~p−(n)​(S0) 型的平移，故只有 p=np = np=n 处为 Z\mathbb{Z}Z、其余为零。非约化版 H0=ZH_{0} = \mathbb{Z}H0​=Z（n≥1n \ge 1n≥1 连通）与之相容。∎

    这条链子用到了「同伦不变性」（写在 def.singular-homology 的陈述里）与 MV 的骨架证明，如实标注。

推出 1

  • 对的长正合列 ⟹ 本页推出
    对 (X,U)(X, U)(X,U) 的长正合列 +++ 重心重分   ⟹  \implies⟹ Mayer–Vietoris

    第一步（代数）：设 X=U∪VX = U \cup VX=U∪V。记 S∗(U)+S∗(V)⊆S∗(X)S_{}(U) + S_{}(V) \subseteq S_{*}(X)S∗​(U)+S∗​(V)⊆S∗​(X) 为「落在 UUU 里的」与「落在 VVV 里的」奇异单纯形共同生成的子复形。有

    0→S∗(U∩V)→S∗(U)⊕S∗(V)0 \to S_{*}(U \cap V) \to S_{*}(U) \oplus S_{*}(V)0→S∗​(U∩V)→S∗​(U)⊕S∗​(V)→S∗(U)+S∗(V)→0,\to S_{*}(U) + S_{*}(V) \to 0,→S∗​(U)+S∗​(V)→0,

    其中第一个映射是 a↦(a,−a)a \mapsto (a, -a)a↦(a,−a)，第二个是 (a,b)↦a+b(a, b) \mapsto a + b(a,b)↦a+b。单射性：aaa 在 UUU 与 VVV 里同时为零说明 a=0a = 0a=0；正合性：a+b=0a + b = 0a+b=0 时 a=−ba = -ba=−b 落在两边，故来自 U∩VU \cap VU∩V。再由 thm.long-exact-pair 的追图，得一条三项一片的长正合列：Hp(U∩V)→Hp(U)⊕Hp(V)→Hp(S∗(U)+S∗(V))→∂∗Hp−1(U∩V)H_{p}(U \cap V) \to H_{p}(U) \oplus H_{p}(V) \to H_{p}(S_{}(U) + S_{}(V)) \xrightarrow{\partial_{*}} H_{p-1}(U \cap V)Hp​(U∩V)→Hp​(U)⊕Hp​(V)→Hp​(S∗​(U)+S∗​(V))∂∗​​Hp−1​(U∩V)。

    第二步（几何，本图的骨架所在）：包含 S∗(U)+S∗(V)↪S∗(X)S_{}(U) + S_{}(V) \hookrightarrow S_{}(X)S∗​(U)+S∗​(V)↪S∗​(X) 诱导同调同构。证明靠小单纯形引理 / 重心重分：给定奇异 ppp-单纯形 σ:Δp→X\sigma : \Delta^{p} \to Xσ:Δp→X，{σ−1(U), σ−1(V)}\{\sigma^{-1}(U),\ \sigma^{-1}(V)\}{σ−1(U), σ−1(V)} 是紧空间 Δp\Delta^{p}Δp 的开覆盖；取它的 Lebesgue 数 δ>0\delta > 0δ>0，反复重心重分直到每个小单纯形的直径 <δ< \delta<δ。这时每个小单纯形的像整体落在 UUU 或 VVV 里，于是 σ\sigmaσ 与 S∗(U)+S∗(V)S_{}(U)+S_{}(V)S∗​(U)+S∗​(V) 里的某个链同调。重分链映射 sd⁡:S∗(X)→S∗(U)+S∗(V)\operatorname{sd} : S_{}(X) \to S_{}(U) + S_{}(V)sd:S∗​(X)→S∗​(U)+S∗​(V) 与包含互为链同伦逆，故诱导的映射是双射。

    合起来：把第一步的序列里 Hp(S∗(U)+S∗(V))H_{p}(S_{}(U)+S_{}(V))Hp​(S∗​(U)+S∗​(V)) 换成 Hp(X)H_{p}(X)Hp​(X)，就是 Mayer–Vietoris。∎

    ⭐ 第二步是全部难点：没有重细分，「局部在 UUU 或 VVV」与「整体同调等价」之间没有桥。
