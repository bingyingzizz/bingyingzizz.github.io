# Lagrangian Submanifold　`def.lagrangian-submanifold`

[in graph](../#n=def.lagrangian-submanifold)　·　[Chinese page (authoritative)](./def.lagrangian-submanifold.md)

**Hypotheses used in each direction** (the pointwise definition requires no extra hypotheses, while a generating function requires transversality):
- $\dim L=n$ and $\omega|_L=0$ $\iff$ each tangent space is a Lagrangian subspace. This is the pointwise definition applied to the tangent map of the immersion. It does not require $L$ to be closed, compact, or embedded.
- Isotropic and half-dimensional $\iff$ $T_pL=(T_pL)^\omega$ uses nondegeneracy of the symplectic form and $\dim W+\dim W^\omega=2n$. Isotropy alone is insufficient, as a one-dimensional submanifold when $n>1$ shows.
