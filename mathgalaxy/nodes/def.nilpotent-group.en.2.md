# nilpotent group　`def.nilpotent-group`
English entry · root `../`
[in graph](../#n=def.nilpotent-group)　·　[Chinese page (authoritative)](./def.nilpotent-group.md)

Equivalently, the **upper central series** $Z_0 = \{e\}$, $Z_{i+1}/Z_i := Z(G/Z_i)$ reaches $G$ in finitely many steps.

## Notes · **draft**
⭐ Examples: a nontrivial abelian group has nilpotency class $1$ ($\gamma_1 = \{e\}$), the trivial group has class $0$; $D_8$ has class $2$; every finite $p$-group is nilpotent; $S_3$ is not nilpotent ($\gamma_1 = A_3$, $\gamma_2 = A_3 \ne \{e\}$).

⭐ Nilpotent $\implies$ solvable: inductively $\gamma_i \subseteq G^{(i)}$, so the derived series terminates no later than the lower central series. The converse fails ($S_3$ is solvable but not nilpotent).
