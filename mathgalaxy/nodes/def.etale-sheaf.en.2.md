# Étale Sheaf　`def.etale-sheaf`
English entry · root `../`
[in graph](../#n=def.etale-sheaf)　·　[Chinese page (authoritative)](./def.etale-sheaf.md)

$$\mathcal{F} : \bigl(X_{\text{et}}\bigr)^{\mathrm{op}} \longrightarrow \mathbf{Ab} .$$

It is an **étale sheaf** if for every étale covering $\{U_{i} \to U\}$ the sequence is exact:

$$0 \longrightarrow \mathcal{F}(U) \longrightarrow \prod_{i} \mathcal{F}(U_{i}) \longrightarrow \prod_{i,j} \mathcal{F}\bigl(U_{i} \times_{U} U_{j}\bigr).$$

The category of étale sheaves is written $\mathbf{Sh}(X_{\text{et}}, \mathbf{Ab})$.
