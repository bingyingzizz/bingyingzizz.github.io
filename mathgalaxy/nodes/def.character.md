# 代数的特征标　`def.character`
代数的特征标

设 $(V,\theta)$ 是 $A$ 的有限维表示。其特征标是函数 $\chi_\theta:A\to F$，$\chi_\theta(a)=\operatorname{tr}\theta(a)$。它只依赖 $V$ 的同构类；$\chi_{V\oplus W}=\chi_V+\chi_W$，$\chi_V(1_A)=\dim V$。
