# Countable Increasing Colimits Are Quasi-Separated　`prop.countable-colimit-qseparated`
English entry · root `../`
[in graph](../#n=prop.countable-colimit-qseparated)　·　[Chinese page (authoritative)](./prop.countable-colimit-qseparated.md)

The second is "elements come from finitely many layers": given a compact Hausdorff $T$ and a continuous $f : T \to X$, since $T$ is compact and $\{S_{n}\}$ is an increasing open-cover-like approximation, $f(T)$ lands in some $S_{n}$ ✓ (this is exactly "a compact set can see only finitely many layers"), so $f$ comes from some $T \to S_{n}$ ✓. ∎

⭐ Use: **a locally compact Hausdorff space is exactly such a countable increasing colimit** (take its compact pieces), so their condensed versions are always quasi-separated.
