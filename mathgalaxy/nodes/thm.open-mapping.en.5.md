# open mapping theorem　`thm.open-mapping`
English entry · root `../`
[in graph](../#n=thm.open-mapping)　·　[Chinese page (authoritative)](./thm.open-mapping.md)

⭐ **A more intuitive way to read the theorem**: A nonconstant holomorphic function cannot collapse an open set to a line or a point. The maximum modulus principle, Schwarz's lemma, and the implication univalent $\implies$ biholomorphic are different expressions of this idea.

⚠️ Nonconstancy is essential, since a constant function maps an open set to a point. ⚠️ The theorem requires **holomorphicity**. Continuous real-valued functions lack this property.
