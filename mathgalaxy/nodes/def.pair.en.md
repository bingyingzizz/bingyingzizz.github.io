## Statement · **reviewed**
Kuratowski's definition:

$$(a, b) := \{ \{a\}, \{a, b\} \}$$

The pairing and power-set axioms guarantee that this is a set.

**Characteristic property** (this is all that "ordered" means):

$$(a, b) = (c, d) \iff a = c \wedge  b = d$$

An $n$-tuple is defined recursively: $(a_{1}$ …$a_{n}) = ( (a_{1}$ …$a_{n-1}), a_{n} )$.
