陈述

设 a≥0a \ge 0a≥0，b≥0b \ge 0b≥0，0<λ<10 < \lambda < 10<λ<1。则

aλb1−λ≤λa+(1−λ)ba^{\lambda} b^{1-\lambda} \le \lambda a + (1-\lambda) baλb1−λ≤λa+(1−λ)b

说明

这就是 log⁡\loglog 的凹性（等价于指数函数的凸性）：

log⁡ ⁣(λa+(1−λ)b)≥λlog⁡a+(1−λ)log⁡b\log\!\left( \lambda a + (1-\lambda) b \right) \ge \lambda \log a + (1-\lambda) \log blog(λa+(1−λ)b)≥λloga+(1−λ)logb

两边取指数即得。

引出标准特例：取 λ=1/p\lambda = 1/pλ=1/p、a=∣f∣p/∥f∥ppa = |f|^p / \|f\|_p^pa=∣f∣p/∥f∥pp​、b=∣g∣q/∥g∥qqb = |g|^q / \|g\|_q^qb=∣g∣q/∥g∥qq​，就是 Hölder 不等式 的证明里那一步。

  • 本页 ⟹ Hölder 不等式推出
    Young 不等式   ⟹  \implies⟹ Hölder 不等式

    ① 先设 ∥f∥p=∥g∥q=1\|f\|_p = \|g\|_q = 1∥f∥p​=∥g∥q​=1。 在 Young 不等式里取

    a=∣f(x)∣p,b=∣g(x)∣q,λ=1p,1−λ=1qa = |f(x)|^p, \qquad b = |g(x)|^q, \qquad \lambda = \frac{1}{p}, \qquad 1 - \lambda = \frac{1}{q}a=∣f(x)∣p,b=∣g(x)∣q,λ=p1​,1−λ=q1​

    得逐点不等式

    ∣f(x)g(x)∣≤∣f(x)∣pp+∣g(x)∣qq|f(x)g(x)| \le \frac{|f(x)|^p}{p} + \frac{|g(x)|^q}{q}∣f(x)g(x)∣≤p∣f(x)∣p​+q∣g(x)∣q​

    ② 积分。

    ∫∣fg∣≤1p∫∣f∣p+1q∫∣g∣q=1p+1q=1\int |fg| \le \frac{1}{p} \int |f|^p + \frac{1}{q} \int |g|^q = \frac{1}{p} + \frac{1}{q} = 1∫∣fg∣≤p1​∫∣f∣p+q1​∫∣g∣q=p1​+q1​=1

    ③ 一般情形。 若 ∥f∥p\|f\|_p∥f∥p​、∥g∥q\|g\|_q∥g∥q​ 都非零，把 f/∥f∥pf / \|f\|_pf/∥f∥p​ 与 g/∥g∥qg / \|g\|_qg/∥g∥q​ 代进去再用齐次性。若有一个为零，则 fg=0fg = 0fg=0 a.e.，两边都是 0。∎

    ④ 取等条件。 回看 ②：等号成立要求 ① 里每一步都取等，即 a=ba = ba=b a.e.（Young 不等式的取等条件），也就是

    ∣f∣p=∣g∣qa.e.|f|^p = |g|^q \quad \text{a.e.}∣f∣p=∣g∣qa.e.

    在归一化之后；还原到一般情形就是「∣f∣p|f|^p∣f∣p 与 ∣g∣q|g|^q∣g∣q 成比例 a.e.」。
