又称矩阵范数

陈述

在做什么：给矩阵量「大小」。有两套口径，必须分清：把矩阵当一堆数量（Frobenius），还是当一个算子量（算子范数）。

算子范数（从属范数）：给定 Rn\mathbb{R}^{n}Rn 上的向量范数 ∥⋅∥\lVert\cdot\rVert∥⋅∥，定义

∥A∥:=sup⁡x≠0∥Ax∥∥x∥=sup⁡∥x∥=1∥Ax∥.\lVert A\rVert := \sup_{x \ne 0}\frac{\lVert Ax\rVert}{\lVert x\rVert} = \sup_{\lVert x\rVert = 1}\lVert Ax\rVert .∥A∥:=x=0sup​∥x∥∥Ax∥​=∥x∥=1sup​∥Ax∥.

Frobenius 范数：∥A∥F:=(∑i,j∣aij∣2)1/2\lVert A\rVert_{F} := \bigl(\sum_{i,j}\lvert a_{ij}\rvert^{2}\bigr)^{1/2}∥A∥F​:=(∑i,j​∣aij​∣2)1/2（就是把它当 mnmnmn 维向量量长度）。

基本性质：两者都是范数；都满足 ∥AB∥≤∥A∥ ∥B∥\lVert AB\rVert \le \lVert A\rVert\,\lVert B\rVert∥AB∥≤∥A∥∥B∥（次乘性）；算子范数还额外满足 ∥Ax∥≤∥A∥ ∥x∥\lVert Ax\rVert \le \lVert A\rVert\,\lVert x\rVert∥Ax∥≤∥A∥∥x∥。

与谱的关系：∥A∥2=σmax⁡(A)=λmax⁡(A∗A)\lVert A\rVert_{2} = \sigma_{\max}(A) = \sqrt{\lambda_{\max}(A^{*}A)}∥A∥2​=σmax​(A)=λmax​(A∗A)​（谱范数 = 最大奇异值）；∥A∥F=(∑σi2)1/2\lVert A\rVert_{F} = \bigl(\sum \sigma_{i}^{2}\bigr)^{1/2}∥A∥F​=(∑σi2​)1/2。

说明

两种口径为什么都要：算子范数量的是「最大放大倍数」，直接对应谱半径与收敛性（ρ(A)≤∥A∥\rho(A) \le \lVert A\rVertρ(A)≤∥A∥，谱半径）；Frobenius 范数量的是「一共有多大」，计算容易、且对低秩逼近天然合适（Eckart–Young 用它陈述）。

⚠️ Frobenius 不是算子范数（除了一维情形），它不满足「从某个向量范数诱导」；所以 ∥I∥F=n\lVert I\rVert_{F} = \sqrt{n}∥I∥F​=n​ 而任何算子范数都有 ∥I∥=1\lVert I\rVert = 1∥I∥=1。判据就在这里。

⚠️ 谱范数用奇异值而不是特征值：∥A∥2=σmax⁡\lVert A\rVert_2 = \sigma_{\max}∥A∥2​=σmax​，而 ρ(A)=max⁡∣λ∣\rho(A) = \max\lvert\lambda\rvertρ(A)=max∣λ∣。两者只在正规矩阵上相等（正规矩阵）。

⭐ 为什么 ∥⋅∥\lVert\cdot\rVert∥⋅∥ 常用来估误差：∥x−x0∥≤∥A−1∥ ∥b−Ax0∥\lVert x - x_{0}\rVert \le \lVert A^{-1}\rVert\,\lVert b - Ax_{0}\rVert∥x−x0​∥≤∥A−1∥∥b−Ax0​∥ —— 条件数 κ=∥A∥∥A−1∥\kappa = \lVert A\rVert\lVert A^{-1}\rVertκ=∥A∥∥A−1∥ 就是这么来的（本图不展开数值分析，只记这个接口）。
