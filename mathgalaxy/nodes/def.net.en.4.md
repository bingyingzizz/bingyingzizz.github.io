# Net　`def.net`
English entry · root `../`
[in graph](../#n=def.net)　·　[Chinese page (authoritative)](./def.net.md)

⭐ **Subnet $\ne$ subsequence**: a subnet may use a coarser index set and is therefore far more flexible than a subsequence (a subsequence requires an order-preserving embedding $\mathbb{N} \to \mathbb{N}$, which misses many cases). Hence the net characterisation of compactness must use **subnets**; using “subsequences” is wrong.

⭐ **Nets come from Riemann sums**: Moore–Smith (1922) invented nets precisely to give a rigorous meaning to “$\int f$ is the limit of Riemann sums” — the index set of those sums is the refinement order of partitions, not $\mathbb{N}$. So “nets” are not abstract fussiness; they solve a real problem in analysis.
