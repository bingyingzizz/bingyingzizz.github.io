说明

⭐ 秩定理说「常秩映射局部只有一种形状」：一切常秩 rrr 的映射在局部长得一模一样，唯一的「不变量」就是秩 rrr。这是微积分里的一条分类定理，也是「局部 →\to→ 标准形」这个套路的收官之作。

⭐ 三个推论一次拿到：

  • r=n=mr = n = mr=n=m：ψ∘f∘φ−1=id\psi \circ f \circ \varphi^{-1} = \mathrm{id}ψ∘f∘φ−1=id   ⟹  \implies⟹ 局部同构，即逆映射定理；
  • r=n<mr = n < mr=n<m：x↦(x,0)x \mapsto (x, 0)x↦(x,0)，即浸入标准形；
  • r=m<nr = m < nr=m<n：(x1,…,xn)↦(x1,…,xm)(x_1, \ldots, x_n) \mapsto (x_1, \ldots, x_m)(x1​,…,xn​)↦(x1​,…,xm​)，即淹没（局部投影）标准形。

⚠ 常秩这个前提不能去：f(x)=x2f(x) = x^{2}f(x)=x2（R→R\mathbb{R} \to \mathbb{R}R→R）在 x≠0x \ne 0x=0 处秩 111、在 000 处秩 000，局部形状不是标准形（它是「折叠」）。

证明全文在边上（先对 rrr 造坐标把 fff 的前 rrr 个分量变成坐标，再用隐函数定理把剩下的分量消掉）。
