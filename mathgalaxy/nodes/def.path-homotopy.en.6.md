# path homotopy　`def.path-homotopy`
English entry · root `../`
[in graph](../#n=def.path-homotopy)　·　[Chinese page (authoritative)](./def.path-homotopy.md)

**Homotopy classes are equivalence classes**: the three properties in `def.homotopy-maps` restrict to homotopies that keep the endpoints fixed, so for fixed $x_{0}, x_{1}$ the paths from $x_{0}$ to $x_{1}$ split into homotopy classes.

💡 Intuition: a homotopy class is "a way of walking from $x_{0}$ to $x_{1}$"; two walks count as the same if they can be deformed continuously into each other.
