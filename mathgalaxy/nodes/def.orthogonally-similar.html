陈述

在做什么：填「相似」与「合同」之间的那一格 —— 当变换既保持结构（相似）又保持长度（正交/酉）时，就是它。谱定理说的正是「对称矩阵正交相似于对角阵」。

设 A,B∈Mn(R)A, B \in M_{n}(\mathbb{R})A,B∈Mn​(R)。称 AAA 与 BBB 正交相似，若存在正交矩阵 QQQ 使

B=QTA Q=Q−1A Q.B = Q^{T} A\, Q = Q^{-1} A\, Q .B=QTAQ=Q−1AQ.

复情形把 QQQ 换成酉矩阵 UUU，得到酉相似 B=U∗AU=U−1AUB = U^{*}AU = U^{-1}AUB=U∗AU=U−1AU。

为什么这一格重要：正交/酉矩阵同时满足 P−1=PTP^{-1} = P^{T}P−1=PT（或 P∗P^{*}P∗），所以

正交相似 = 相似 + 合同（三者的区别见 def.orthogonally-similar 的注）

它既保持特征值（相似的性质），又保持内积结构（合同的性质）—— 所以它是稳定的相似，条件数为 111。

说明

⭐ 谁正交相似于对角阵：实对称矩阵（thm.spectral-matrix）；更一般地，实正规矩阵正交相似于分块对角（1×11\times11×1 与 2×22\times22×2 块，因为非实特征值成对出现）。而任意矩阵都酉相似于上三角（thm.schur-triangularization）—— 这就是「正交相似能化简到什么程度」的完整答案。

⚠️ 三个概念的区别要牢牢记住：相似 P−1APP^{-1}APP−1AP（任意可逆 PPP，保持特征值）；合同 PTAPP^{T}APPTAP（任意可逆 PPP，保持惯性）；正交相似 QTAQQ^{T}AQQTAQ 且 Q−1=QTQ^{-1} = Q^{T}Q−1=QT（两者都保持）。只在第三个里「P−1P^{-1}P−1 与 PTP^{T}PT 是同一个东西」。

⚠️ 本图 def.similarity 讲的是最一般的相似。别把「AAA 相似于对角阵」与「AAA 正交相似于对角阵」混起来 —— 前者只要求特征向量够多，后者还要求它们互相垂直（这就是正规，def.normal-matrix）。
