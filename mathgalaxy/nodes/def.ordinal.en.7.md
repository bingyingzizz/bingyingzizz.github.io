# ordinal　`def.ordinal`
English entry · root `../`
[in graph](../#n=def.ordinal)　·　[Chinese page (authoritative)](./def.ordinal.md)

dinal of the same order type: build it by well-founded recursion and collect the image with Replacement; this is not an unfolding of the definition, and it does not need the Choice that well-orders an arbitrary set.
- transitivity cannot be dropped: the members of $\{\{\emptyset\}\}$ are well-ordered by membership as a single point, yet the set is not transitive; the well-order condition cannot be dropped either: $\{0,1,\{1\}\}$ is transitive, but $0$ and $\{1\}$ are incomparable under membership.
