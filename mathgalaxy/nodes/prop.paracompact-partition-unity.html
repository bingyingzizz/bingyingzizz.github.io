陈述

对拓扑空间 XXX：

  1. XXX 是仿紧 Hausdorff 空间   ⟺  \iff⟺ 每个开覆盖都有一族从属于它的单位分解；
  2. XXX 是正规空间   ⟺  \iff⟺ 每个局部有限开覆盖都有一族从属于它的单位分解。

说明

证明（两个方向）。 (⟸)(\Longleftarrow)(⟸) 单位分解给出局部有限的加细。 设 {ρi}\{\rho_{i}\}{ρi​} 是从属于覆盖 {Ui}\{U_{i}\}{Ui​} 的单位分解。由单位分解的定义，supp⁡ρi⊆Ui\operatorname{supp}\rho_{i} \subseteq U_{i}suppρi​⊆Ui​ 且这族支撑是局部有限的 ✓；于是 {ρi−1((0,1])}\{ \rho_{i}^{-1}\bigl((0,1]\bigr) \}{ρi−1​((0,1])} 是 {Ui}\{U_{i}\}{Ui​} 的一个开加细，且仍然局部有限（每个点是有限多个支撑之外的点）✓ —— 这正是仿紧（在 Hausdorff 前提下）要求的「每个开覆盖都有局部有限开加细」。正规的情形同理（局部有限覆盖取局部有限的 {supp⁡ρi}\{\operatorname{supp}\rho_{i}\}{suppρi​}）✓。 (⟹)(\Longrightarrow)(⟹) 用正规性逐步造 ρi\rho_{i}ρi​。

  • 先取一个局部有限的开加细 {Vi}\{V_{i}\}{Vi​}（仿紧的定义；正规的情形直接取自局部有限覆盖本身）✓；
  • 正规性给出：存在开集 WiW_{i}Wi​ 使 Wi‾⊆Vi\overline{W_{i}} \subseteq V_{i}Wi​​⊆Vi​ 且 {Wi}\{W_{i}\}{Wi​} 仍覆盖 XXX（这是正规空间的标准「收缩」引理，由 Urysohn 引理或它的变体得到）✓；
  • 对每对 (Wi‾,X∖Vi)(\overline{W_{i}}, X \setminus V_{i})(Wi​​,X∖Vi​)（不交闭集）用 Urysohn 引理取连续函数 gi:X→[0,1]g_{i} : X \to [0,1]gi​:X→[0,1] 使 gi∣Wi‾=1g_{i}|_{\overline{W_{i}}} = 1gi​∣Wi​​​=1、gi∣X∖Vi=0g_{i}|_{X\setminus V_{i}} = 0gi​∣X∖Vi​​=0 ✓；
  • 令 g:=∑igig := \sum_{i} g_{i}g:=∑i​gi​：局部有限性保证这是局部有限和，故 ggg 连续 ✓，且因为 {Wi}\{W_{i}\}{Wi​} 覆盖 XXX，每点处 g≥1g \ge 1g≥1（至少一项为 1）✓；
  • 取 ρi:=gi/g\rho_{i} := g_{i}/gρi​:=gi​/g ✓：非负、和恒为 1、supp⁡ρi⊆Vi⊆Ui\operatorname{supp}\rho_{i} \subseteq V_{i} \subseteq U_{i}suppρi​⊆Vi​⊆Ui​，且支撑仍局部有限 ✓。

于是得到从属于原覆盖的单位分解 ✓。∎

⭐ 这条是延拓定理的引擎：单位分解把「局部定义的东西」加权求和成整体定义的函数 —— Tietze / Dugundji 型延拓、流形上的积分与 Stokes 定理，用的都是这一招。

⚠️ 局部有限不能省：没有局部有限性，∑ρi=1\sum \rho_{i} = 1∑ρi​=1 只是一个「点态」的断言，逐点求和出来的函数未必连续。

Abstract draft

For a topological space XXX: XXX is paracompact Hausdorff exactly when every open cover has a subordinate partition of unity, and XXX is normal exactly when every locally finite open cover has one. In one direction the supports of the partition give a locally finite open refinement of the cover; in the other, normality produces the functions one at a time. This is the standard bridge from local data to global objects, for instance from local metrics to a Riemannian metric.
