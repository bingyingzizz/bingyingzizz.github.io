又称调和函数

陈述

白话：二阶偏导连续、并且满足 Laplace 方程 Δu=0\Delta u = 0Δu=0 的实值函数。通俗说就是「处处不会比周围更凸也不会更凹」的函数。

设 Ω⊂R2≅C\Omega \subset \mathbb{R}^2 \cong \mathbb{C}Ω⊂R2≅C 是区域，u:Ω→Ru: \Omega \to \mathbb{R}u:Ω→R 属于 C2C^2C2。若

Δu:=∂2u∂x2+∂2u∂y2=0\Delta u := \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0Δu:=∂x2∂2u​+∂y2∂2u​=0

在 Ω\OmegaΩ 上处处成立，称 uuu 是 Ω\OmegaΩ 上的调和函数。

等价的刻画（局部）：uuu 是某个全纯函数的实部（圆盘上总可以，单连通区域上也可以，见「调和函数的共轭」那条）。

说明

⭐ 全纯函数的实部、虚部都调和：由 Cauchy–Riemann 方程 ux=vyu_x = v_yux​=vy​、uy=−vxu_y = -v_xuy​=−vx​，得

Δu=(ux)x+(uy)y=(vy)x+(−vx)y=vxy−vyx=0,\Delta u = (u_x)_x + (u_y)_y = (v_y)_x + (-v_x)_y = v_{xy} - v_{yx} = 0,Δu=(ux​)x​+(uy​)y​=(vy​)x​+(−vx​)y​=vxy​−vyx​=0,

最后一步用了混合偏导相等（vvv 充分光滑）。

⭐ 例子：Re⁡zn\operatorname{Re} z^nRezn、x2−y2x^2 - y^2x2−y2、ln⁡∣z∣\ln|z|ln∣z∣（在 C×\mathbb{C}^{\times}C× 上）、excos⁡ye^{x}\cos yexcosy。

⚠ 反例：∣z∣2=x2+y2|z|^2 = x^2 + y^2∣z∣2=x2+y2 不调和，Δ(x2+y2)=4\Delta(x^2 + y^2) = 4Δ(x2+y2)=4。x3x^3x3 也不调和，Δx3=6x\Delta x^3 = 6xΔx3=6x。

⚠ 定义只要求 C2C^2C2，但调和函数自动是 C∞C^{\infty}C∞ 且实解析 —— 这是「它是全纯函数的实部」的直接后果。

📌 调和函数没有「全纯」那样的刚性：两个调和函数的乘积一般既不调和也不全纯，u+vu + vu+v、cucucu 才是。
