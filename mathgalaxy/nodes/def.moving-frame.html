陈述

设 U0⊆SU_{0} \subseteq SU0​⊆S 是曲面上的开集。活动标架是三个 C1C^{1}C1 向量场 e1,e2,e3e_{1}, e_{2}, e_{3}e1​,e2​,e3​，使每点的 (e1,e2,e3)(e_{1}, e_{2}, e_{3})(e1​,e2​,e3​) 都是 R3\mathbb{R}^{3}R3 的标准正交基（随点移动而变，故名「活动」）。对偶余标架是

ωi(v):=⟨v,ei⟩,i=1,2,3,\omega^{i}(v) := \langle v, e_{i}\rangle ,\qquad i = 1,2,3,ωi(v):=⟨v,ei​⟩,i=1,2,3,

它们是 111-形式，满足 ωi(ej)=δ ji\omega^{i}(e_{j}) = \delta^{i}_{\ j}ωi(ej​)=δ ji​。位置向量的微分按标架展开：

dr=ω1e1+ω2e2+ω3e3.\mathrm{d}r = \omega^{1}e_{1}+\omega^{2}e_{2}+\omega^{3}e_{3}.dr=ω1e1​+ω2e2​+ω3e3​.

这叫焊接方程（soldering）：它把「rrr 怎么动」翻译成「沿标架的各分量动多少」。

说明

为什么值得换一套说法：坐标路线要算 ruu,ruv,rvvr_{uu}, r_{uv}, r_{vv}ruu​,ruv​,rvv​ 以及 nnn 的偏导；标架路线只把 dr\mathrm{d}rdr、dei\mathrm{d}e_{i}dei​ 展开一次，此后全是 111-形式之间的代数（外积、比较系数）。这正是用户要的「用活动标架代替复杂计算」。

曲面上的标准取法：e3=ne_{3} = ne3​=n（法向），e1,e2e_{1}, e_{2}e1​,e2​ 是与 nnn 正交的单位切向量场。这时 ω3=⟨dr,n⟩=0\omega^{3} = \langle \mathrm{d}r, n\rangle = 0ω3=⟨dr,n⟩=0：曲面上没有法向增量。

⚠️ (e1,e2)(e_{1}, e_{2})(e1​,e2​) 只在局部存在，且不唯一（可差一次转动）。凡要写出来的量都要写成与转动无关的形式（如 I=(ω1)2+(ω2)2I = (\omega^{1})^{2}+(\omega^{2})^{2}I=(ω1)2+(ω2)2），否则一换标架就变形。

记号：ωi\omega^{i}ωi 的上标是编号、不是幂；(e1,e2,e3)(e_{1}, e_{2}, e_{3})(e1​,e2​,e3​) 与 (ω1,ω2,ω3)(\omega^{1}, \omega^{2}, \omega^{3})(ω1,ω2,ω3) 互为对偶对，这是活动标架法的全部记账规则。
