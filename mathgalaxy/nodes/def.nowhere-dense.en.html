Statement

Let A⊆XA \subseteq XA⊆X be a topological space. Call AAA nowhere dense if (A‾)∘=∅(\overline{A})^\circ = \emptyset(A)∘=∅; equivalently, every non-empty open set contains a non-empty open subset disjoint from AAA.

Notes

⚠️ "Nowhere dense" is not "not dense": (0,1)∪(1,2)(0,1) \cup (1,2)(0,1)∪(1,2) is neither dense nor nowhere dense in R\mathbb{R}R — the definition demands that even the closure has no interior.

Examples: Z⊆R\mathbb{Z} \subseteq \mathbb{R}Z⊆R, {1/n}\{1/n\}{1/n}, the Cantor set.

⭐ The Cantor set is the most instructive example: it is nowhere dense yet uncountable. So "nowhere dense" and "small cardinality" are two different things.
