# Darboux’s Theorem　`thm.darboux`
English entry · root `../`
[in graph](../#n=thm.darboux)　·　[Chinese page (authoritative)](./thm.darboux.md)

**Step 3: The Moser homotopy and $\theta$**. Set $\eta = \omega - \omega_{0}$. This is a closed 2-form on $U$, and $\eta(p) = 0$. Take $U$ to be a ball centered at $p$ (star-shaped and contractible). By `lem.poincare-lemma` ($k = 2 \ge 1$), there is a 1-form $\theta \in \Omega^{1}(U)$ such that $\eta = d\theta$. For $t \in [0, 1]$, set $\omega_{t} = \omega_{0} + t\eta$. Each $\omega_{t}$ is closed, and by $\eta(p) = 0$, $\omega_{t}(p) = \omega(p)$ is independent of $t$. Nondegeneracy is an open condition and $[0, 1]$ is compact, so we can shrink $U$ further to make **all** $\omega_{t}$ ($t \in [0, 1]$) nondegenerate.
