## Notes · **draft**
⭐ "Solution set = particular solution + homogeneous solutions" is the central picture of linear algebra: **the inhomogeneous system has no structure, the homogeneous one does** (it is a subspace), and the inhomogeneous solution set is just a translate of it (an affine subspace).

⭐ The dimension formula $n - \operatorname{rank} A$ is the rank–nullity theorem in the language of linear systems: the number of variables $n$ = the $\operatorname{rank} A$ constrained away + the $\dim \ker A$ free ones.
