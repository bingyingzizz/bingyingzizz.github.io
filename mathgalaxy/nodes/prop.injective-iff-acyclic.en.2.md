# Injective Objects Are Exactly the Acyclic Ones　`prop.injective-iff-acyclic`
English entry · root `../`
[in graph](../#n=prop.injective-iff-acyclic)　·　[Chinese page (authoritative)](./prop.injective-iff-acyclic.md)

1. $I$ is an **injective** object;
2. $I$ is acyclic with respect to $F : \mathcal{A} \to \mathcal{A}'$ for every **left exact** additive functor (here $F$ is that functor);
3. $I$, for every left exact functor $F = \operatorname{Hom}_{\mathcal{A}}(M, -)$ of that form, is acyclic for $F$.

## Notes · **draft**
**Proof.**
$(1) \implies (2)$: when $I$ is injective, $I$ together with the identity map is itself an **injective resolution of length $0$**, $0 \to I \xrightarrow{\ 1\ } I \to 0$ ✓.
