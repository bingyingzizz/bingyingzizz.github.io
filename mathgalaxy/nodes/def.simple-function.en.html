Statement

A measurable function φ:X→C\varphi : X \to \mathbb{C}φ:X→C is a simple function if and only if it takes only finitely many values. Equivalently, it can be written as

φ=∑j=1najχEj\varphi = \sum_{j=1}^{n} a_j \chi_{E_j}φ=j=1∑n​aj​χEj​​

where aj∈Ca_j \in \mathbb{C}aj​∈C, and the sets Ej=φ−1({aj})∈ME_j = \varphi^{-1}(\{a_j\}) \in \mathcal{M}Ej​=φ−1({aj​})∈M are pairwise disjoint.

Notes

A simple function is the measurable version of a step function — finitely many "steps".

It is the starting point of the whole theory of integration: first define the integral for simple functions (a weighted sum), then extend it to all non-negative measurable functions by "approximating from below by simple functions".
