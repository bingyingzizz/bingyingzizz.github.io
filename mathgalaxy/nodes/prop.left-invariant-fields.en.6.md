# Left-Invariant Vector Fields　`prop.left-invariant-fields`
English entry · root `../`
[in graph](../#n=prop.left-invariant-fields)　·　[Chinese page (authoritative)](./prop.left-invariant-fields.md)

Smoothness: write everything in a chart; $\mathrm{d}(L_{g})$ is smooth in $g$.

**Why the bracket descends**: the key is **naturality** of the Lie bracket,

$$\mathrm{d}F\bigl([X,Y]_{p}\bigr) = \bigl[\mathrm{d}F(X),\mathrm{d}F(Y)\bigr]_{F(p)},$$

where $F$ is a diffeomorphism. Take $F = L_{g}$; left-invariance gives $\mathrm{d}(L_{g})X = X$ and $\mathrm{d}(L_{g})Y = Y$, hence $\mathrm{d}(L_{g})[X,Y] = [X,Y]$, i.e. $[X,Y]$ is left-invariant. So the only substantive input in "a Lie group gives a Lie algebra" is this naturality.
