# topological orientability　`def.topological-orientability`
English entry · root `../`
[in graph](../#n=def.topological-orientability)　·　[Chinese page (authoritative)](./def.topological-orientability.md)

$$\varphi_{\beta}\circ\varphi_{\alpha}^{-1}:\ \varphi_{\alpha}(U_{\alpha}\cap U_{\beta})\longrightarrow \varphi_{\beta}(U_{\alpha}\cap U_{\beta})$$

are all **orientation-preserving** (give $\mathbb{R}^{n}$ its standard orientation; see the notes for a precise definition of orientation preservation). Such an atlas is called an **oriented atlas**. If no oriented atlas exists, $M$ is **nonorientable**.
