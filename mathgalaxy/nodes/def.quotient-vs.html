又称商空间

陈述

设 U⊆VU \subseteq VU⊆V 是子空间。在 VVV 上定义等价关系

v∼v′  ⟺  v−v′∈Uv \sim v' \iff v - v' \in Uv∼v′⟺v−v′∈U

等价类 v+U:={ v+u:u∈U }v + U := \{\, v + u : u \in U \,\}v+U:={v+u:u∈U} 叫 UUU 的陪集。全体陪集记 V/UV / UV/U，在上面定义

(v+U)+(v′+U):=(v+v′)+U,c (v+U):=(cv)+U(v + U) + (v' + U) := (v + v') + U, \qquad c\,(v + U) := (cv) + U(v+U)+(v′+U):=(v+v′)+U,c(v+U):=(cv)+U

这两条与代表元的选取无关（因为 UUU 是子空间），于是 V/UV / UV/U 成为一个 KKK-向量空间，叫商空间。

商映射 π:V→V/U\pi : V \to V/Uπ:V→V/U、v↦v+Uv \mapsto v + Uv↦v+U 是满的线性映射，且 ker⁡π=U\ker \pi = Ukerπ=U。

说明

⭐ 这一条是集合的商集（def.quotient-set）加上结构：先把 VVV 按 UUU 压成集合，再验证运算良定义。良定义的那一步是全部内容 —— 因为运算写在代表元上，而代表元有无数种选法。

⭐ 「每个子空间都是某个线性映射的核」由此得到：取 π\piπ 即可。这与群的情形完全平行（每个正规子群都是某个同态的核）。

⚠ 商的是子空间（不是任意子集）：否则陪集之和不封闭。群那边对应的是「正规子群」，这里所有子空间自动正规（因为 KKK-向量空间都是交换群）。

  • 本页 ⟹ 第一同构定理（向量空间版）推出
    核 / 像 / 商空间   ⟹  \implies⟹ 第一同构定理

    令 T‾(v+ker⁡T):=T(v)\overline{T}(v + \ker T) := T(v)T(v+kerT):=T(v)。

    1. 良定义：若 v+ker⁡T=v′+ker⁡Tv + \ker T = v' + \ker Tv+kerT=v′+kerT，则 v−v′∈ker⁡Tv - v' \in \ker Tv−v′∈kerT，即 T(v−v′)=0T(v - v') = 0T(v−v′)=0，由线性得 T(v)=T(v′)T(v) = T(v')T(v)=T(v′)。所以 T‾\overline{T}T 只依赖陪集。
    2. 线性：T‾((v+ker⁡T)+c(v′+ker⁡T))=T‾((v+cv′)+ker⁡T)=T(v+cv′)=T(v)+cT(v′)\overline{T}\bigl((v + \ker T) + c(v' + \ker T)\bigr) = \overline{T}\bigl((v + cv') + \ker T\bigr) = T(v + cv') = T(v) + cT(v')T((v+kerT)+c(v′+kerT))=T((v+cv′)+kerT)=T(v+cv′)=T(v)+cT(v′)。
    3. 单射：若 T‾(v+ker⁡T)=0\overline{T}(v + \ker T) = 0T(v+kerT)=0，则 T(v)=0T(v) = 0T(v)=0，即 v∈ker⁡Tv \in \ker Tv∈kerT，于是 v+ker⁡Tv + \ker Tv+kerT 是零陪集。故 ker⁡T‾={0}\ker \overline{T} = \{0\}kerT={0}，T‾\overline{T}T 单。
    4. 满射：im⁡T‾=im⁡T\operatorname{im} \overline{T} = \operatorname{im} TimT=imT 由定义直接得到。

    四步齐备，T‾\overline{T}T 是线性同构，V/ker⁡T≅im⁡TV/\ker T \cong \operatorname{im} TV/kerT≅imT。∎

    四步的顺序值得记住：先良定义、再线性、再单、再满。所有「商掉之后构造映射」的证明都是这个骨架 —— 群、环、模、拓扑空间（商拓扑）一模一样。

  • 本页 ⟹ 商空间的万有性质推出
    商映射   ⟹  \implies⟹ 万有性质

    设 T:V→WT : V \to WT:V→W 线性且 U⊆ker⁡TU \subseteq \ker TU⊆kerT。

    存在性：令 T‾(v+U):=T(v)\overline{T}(v + U) := T(v)T(v+U):=T(v)。良定义：若 v−v′∈U⊆ker⁡Tv - v' \in U \subseteq \ker Tv−v′∈U⊆kerT，则 T(v−v′)=0T(v - v') = 0T(v−v′)=0，即 T(v)=T(v′)T(v) = T(v')T(v)=T(v′)。线性同第一同构定理的证明。于是 T‾∘π=T\overline{T} \circ \pi = TT∘π=T 由定义成立。

    唯一性：设 S:V/U→WS : V/U \to WS:V/U→W 也满足 S∘π=TS \circ \pi = TS∘π=T。任取 v+U∈V/Uv + U \in V/Uv+U∈V/U，则

    S(v+U)=S(π(v))=T(v)=T‾(v+U)S(v + U) = S(\pi(v)) = T(v) = \overline{T}(v + U)S(v+U)=S(π(v))=T(v)=T(v+U)

    故 S=T‾S = \overline{T}S=T。∎

    唯一性只用到一个事实：π\piπ 是满射（所以每个陪集都有代表元可用）。这是「万有性质」类定理的共同收尾方式。

  • 本页 ⟹ 张量积的万有性质推出
    张量积的构造   ⟹  \implies⟹ 万有性质

    存在性：给定双线性 B:V×W→UB : V \times W \to UB:V×W→U。先在 V×WV \times WV×W 生成的自由向量空间（形式上取全部 (v,w)(v, w)(v,w) 的形式线性组合）上定义 B^(∑cij(vi,wj)):=∑cijB(vi,wj)\widehat B\bigl( \sum c_{ij}(v_i, w_j) \bigr) := \sum c_{ij} B(v_i, w_j)B(∑cij​(vi​,wj​)):=∑cij​B(vi​,wj​)，这是线性的；再由 BBB 的双线性，B^\widehat BB 在「双线性关系」张成的子空间上取零，于是由商空间的万有性质（thm.quotient-universal-vs）它唯一地下降为 B~:V⊗W→U\widetilde B : V \otimes W \to UB:V⊗W→U。

    唯一性：任何满足 B~(v⊗w)=B(v,w)\widetilde B(v \otimes w) = B(v, w)B(v⊗w)=B(v,w) 的线性映射在可分解张量上取值已定；而可分解张量张成 V⊗WV \otimes WV⊗W，故线性映射被取值唯一确定。

    反向：给定线性 B~\widetilde BB，则 B:=B~∘⊗B := \widetilde B \circ \otimesB:=B∘⊗ 是双线性的（因为 ⊗\otimes⊗ 双线性）。

    两个方向互逆且自然，故 Hom⁡(V⊗W,U)≅Bil⁡(V,W;U)\operatorname{Hom}(V \otimes W, U) \cong \operatorname{Bil}(V, W; U)Hom(V⊗W,U)≅Bil(V,W;U)。∎

    结尾的「自然」两字是伴随的入口：正因为同构对 UUU（以及 V,WV, WV,W）自然，张量积才是一个真正的函子层面的构造，而不仅是「某个具体的商空间」。
