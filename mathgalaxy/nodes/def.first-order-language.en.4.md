## Notes · **draft**
⭐⭐ **This is the only "metamathematical" primitive in the star map**: the ZF axioms, the empty set, and this item all sit at the very bottom, but only this one is not part of the object language — it is **the language in which the axioms are written**, more primitive than ZFC itself.

It therefore sits at the bottom layers together with the ZF axioms and **has no dependency edges upward**: to really draw one, "formula" would first have to be built as a set inside ZFC, which uses the ZFC axioms, but the axiom schemas themselves need formulas — a direct circle.
