# Connection Coefficients in an Orthonormal Frame　`prop.christoffel-frame`
English entry · root `../`
[in graph](../#n=prop.christoffel-frame)　·　[Chinese page (authoritative)](./prop.christoffel-frame.md)

$$\omega^{k}_{j}(e_{i}) = \frac{1}{2}\left(\langle [e_{i},e_{j}],e_{k}\rangle-\langle [e_{j},e_{k}],e_{i}\rangle+\langle [e_{k},e_{i}],e_{j}\rangle\right).$$

② If the frame is the **normalization of orthogonal coordinates**, $e_{1} = \partial_{u}/\sqrt{E}$, $e_{2} = \partial_{v}/\sqrt{G}$ ($F = 0$), then

$$\omega^{1}_{2} = \frac{1}{\sqrt{EG}}\left(\frac{E_{v}}{2}\,\mathrm{d}u-\frac{G_{u}}{2}\,\mathrm{d}v\right) = \frac{(\ln E)_{v}}{2\sqrt{G}}\,\omega^{1}-\frac{(\ln G)_{u}}{2\sqrt{E}}\,\omega^{2},$$
