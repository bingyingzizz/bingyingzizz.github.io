陈述

在做什么：Rayleigh 商只能抓最大与最小特征值。要抓「第 kkk 个」，就得让子空间参与竞争 —— 这就是极小极大。

设 AAA 是 nnn 阶 Hermite 矩阵，特征值按降序排列 λ1≥λ2≥⋯≥λn\lambda_{1} \ge \lambda_{2} \ge \cdots \ge \lambda_{n}λ1​≥λ2​≥⋯≥λn​。则对每个 k=1,…,nk = 1, \ldots, nk=1,…,n，

λk=max⁡dim⁡S=k min⁡0≠x∈SRA(x)=min⁡dim⁡T=n−k+1 max⁡0≠x∈TRA(x),\lambda_{k} = \max_{\dim S = k}\ \min_{0 \ne x \in S} R_{A}(x) = \min_{\dim T = n-k+1}\ \max_{0 \ne x \in T} R_{A}(x) ,λk​=dimS=kmax​ 0=x∈Smin​RA​(x)=dimT=n−k+1min​ 0=x∈Tmax​RA​(x),

其中 S,TS, TS,T 取遍相应维数的子空间，RAR_ARA​ 是 Rayleigh 商。

推论（Weyl 单调性）：若 A≤BA \le BA≤B（即 B−AB - AB−A 半正定），则 λk(A)≤λk(B)\lambda_{k}(A) \le \lambda_{k}(B)λk​(A)≤λk​(B) 对每个 kkk 成立。

说明

证明（谱定理 + 子空间维数计数）。由谱定理，存在 Cn\mathbb{C}^{n}Cn 的标准正交基 u1,…,unu_{1}, \ldots, u_{n}u1​,…,un​ 与实数 λ1≥⋯≥λn\lambda_{1} \ge \cdots \ge \lambda_{n}λ1​≥⋯≥λn​ 使 Aui=λiuiAu_{i} = \lambda_{i}u_{i}Aui​=λi​ui​。对 x=∑iciui≠0x = \sum_{i} c_{i}u_{i} \ne 0x=∑i​ci​ui​=0，

是 λ1,…,λn\lambda_{1}, \ldots, \lambda_{n}λ1​,…,λn​ 的加权平均（权 ∣ci∣2≥0|c_{i}|^{2} \ge 0∣ci​∣2≥0 不全为零）。

⭐ 它为什么重要：把「特征值是方程的根」换成「特征值是某个优化问题的值」，于是特征值有了连续性（子空间族是紧的）与单调性（Weyl）。扰动理论、数值特征值算法、图谱理论全都建立在这条上。

与 SVD 的连接：对 A∗AA^{*}AA∗A 用这条，就得到奇异值的变分刻画 σk=max⁡dim⁡S=kmin⁡x∈S∥Ax∥/∥x∥\sigma_k = \max_{\dim S=k}\min_{x\in S}\lVert Ax\rVert/\lVert x\rVertσk​=maxdimS=k​minx∈S​∥Ax∥/∥x∥ —— 这是「低秩逼近最优」的严格依据（Eckart–Young）。

⚠️ 前提是 Hermite（或实对称）。一般矩阵没有实谱，Rayleigh 商也不是实的，这套不等式不成立；那种情形要用奇异值代替特征值。
