说明

⭐ 这是「微积分 ×\times× 线性代数」在本科阶段最漂亮的一次交汇：判极值 = 判二次型正定，而后者有现成的算法（thm.sylvester-criterion 的顺序主子式，或 thm.spectral-theorem 的特征值符号）。

⚠ 「半定」那一档真的没有结论，两个反例：

  • f=x4+y4f = x^{4} + y^{4}f=x4+y4 在原点 H=0H = 0H=0（半定），但原点是严格极小；
  • f=x4−y4f = x^{4} - y^{4}f=x4−y4 在原点同样 H=0H = 0H=0，但原点是鞍点。

所以判据失效不是「证法不够好」，而是信息真的不足。

⚠ 反过来，正定只给局部极小：f(x)=x2(1+x2)f(x) = x^{2}(1 + x^{2})f(x)=x2(1+x2) 在原点正定但整体有别的极小点。
