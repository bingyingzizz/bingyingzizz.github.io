设 γ:[0,1]→X\gamma : [0, 1] \to Xγ:[0,1]→X 是从 x0x_{0}x0​ 到 x1x_{1}x1​ 的道路，γˉ\bar{\gamma}γˉ​ 是它的反向道路。定义

Πγ:π1(X,x0)⟶π1(X,x1),\Pi_{\gamma} : \pi_{1}(X, x_{0}) \longrightarrow \pi_{1}(X, x_{1}),Πγ​:π1​(X,x0​)⟶π1​(X,x1​),Πγ([α]):=[γˉ∗α∗γ].\Pi_{\gamma}([\alpha]) := [\bar{\gamma} * \alpha * \gamma].Πγ​([α]):=[γˉ​∗α∗γ].

则 Πγ\Pi_{\gamma}Πγ​ 是群同构，且 Πγˉ=Πγ−1\Pi_{\bar{\gamma}} = \Pi_{\gamma}^{-1}Πγˉ​​=Πγ−1​。

若 γ′\gamma'γ′ 是另一条从 x0x_{0}x0​ 到 x1x_{1}x1​ 的道路，令 g:=[γˉ′∗γ]∈π1(X,x1)g := [\bar{\gamma}' * \gamma] \in \pi_{1}(X, x_{1})g:=[γˉ​′∗γ]∈π1​(X,x1​)，则

Πγ′=ad⁡g∘Πγ,ad⁡g(u):=g u g−1.\Pi_{\gamma'} = \operatorname{ad}_{g} \circ \Pi_{\gamma},\qquad \operatorname{ad}_{g}(u) := g\,u\,g^{-1}.Πγ′​=adg​∘Πγ​,adg​(u):=gug−1.

即：不同的道路给出的同构只差一个内自同构。

说明

⭐ 结论：XXX 道路连通时，π1(X,x0)≅π1(X,x1)\pi_{1}(X, x_{0}) \cong \pi_{1}(X, x_{1})π1​(X,x0​)≅π1​(X,x1​)，但这个同构不典范。于是「π1(X)=1\pi_{1}(X) = 1π1​(X)=1」（单连通）是良定义的陈述，而「π1(X)≅Z\pi_{1}(X) \cong \mathbb{Z}π1​(X)≅Z 且生成元是哪一个」不是。

⚠️ 若 π1\pi_{1}π1​ 非阿贝尔，内自同构不一定是恒等，所以「共轭类」才是与基点无关的数据。共轭类空间的另一种读法：π1(X)\pi_{1}(X)π1​(X) 上的共轭作用 ↔\leftrightarrow↔ 空间里以 x0x_{0}x0​ 为基点的闭道路的同伦类在「自由同伦」下的分类。

与 π0\pi_{0}π0​ 的对照：π1\pi_{1}π1​ 靠「路径」连接不同基点；重排一下基点看，这正是为什么道路连通性在这里是必要的（否则 Πγ\Pi_{\gamma}Πγ​ 连定义都写不出）。

💡 实践上：算 π1\pi_{1}π1​ 时先随便挑一个好算的基点，算完再用这条命题说「换基点不变」。

    先验证 Πγ\Pi_{\gamma}Πγ​ 是同态（这是唯一需要动手的地方）。设 α,α′\alpha, \alpha'α,α′ 是以 x0x_{0}x0​ 为基点的闭道路。由 lem.path-product 的结合律、单位律，以及 γ∗γˉ≃pex1\gamma * \bar{\gamma} \simeq_{p} e_{x_{1}}γ∗γˉ​≃p​ex1​​：

    Πγ([α][α′])=[γˉ∗α∗α′∗γ]\Pi_{\gamma}([\alpha][\alpha']) = [\bar{\gamma} * \alpha * \alpha' * \gamma]Πγ​([α][α′])=[γˉ​∗α∗α′∗γ]=[γˉ∗α∗γ] [γˉ∗α′∗γ].= [\bar{\gamma} * \alpha * \gamma]\,[\bar{\gamma} * \alpha' * \gamma].=[γˉ​∗α∗γ][γˉ​∗α′∗γ].

    中间插入的 γ∗γˉ\gamma \bar{\gamma}γ∗γˉ​（或 γˉ∗γ\bar{\gamma} \gammaγˉ​∗γ）由单位律消掉，这正是需要结合律的地方。

    互逆：Πγˉ∘Πγ([α])=[γ∗γˉ∗α∗γ∗γˉ]=[α]\Pi_{\bar{\gamma}} \circ \Pi_{\gamma}([\alpha]) = [\gamma \bar{\gamma} \alpha \gamma \bar{\gamma}] = [\alpha]Πγˉ​​∘Πγ​([α])=[γ∗γˉ​∗α∗γ∗γˉ​]=[α]；另一个方向同理。故 Πγ\Pi_{\gamma}Πγ​ 是双射，从而是同构。

    共轭公式：设 γ′\gamma'γ′ 是另一条从 x0x_{0}x0​ 到 x1x_{1}x1​ 的道路，令 g:=[γˉ′∗γ]∈π1(X,x1)g := [\bar{\gamma}' * \gamma] \in \pi_{1}(X, x_{1})g:=[γˉ​′∗γ]∈π1​(X,x1​)（它是 x1x_{1}x1​ 处的闭道路）。则

    Πγ′([α])=[γˉ′∗α∗γ′]=g [γˉ∗α∗γ] g−1,\Pi_{\gamma'}([\alpha]) = [\bar{\gamma}' * \alpha * \gamma'] = g\,[\bar{\gamma} * \alpha * \gamma]\,g^{-1},Πγ′​([α])=[γˉ​′∗α∗γ′]=g[γˉ​∗α∗γ]g−1,

    因为 [γˉ′∗α∗γ′]=[γˉ′∗γ]∗[γˉ∗α∗γ]∗[γˉ∗γ′][\bar{\gamma}' \alpha \gamma'] = [\bar{\gamma}' \gamma] [\bar{\gamma} \alpha \gamma] [\bar{\gamma} \gamma'][γˉ​′∗α∗γ′]=[γˉ​′∗γ]∗[γˉ​∗α∗γ]∗[γˉ​∗γ′]，而 [γˉ∗γ′]=g−1[\bar{\gamma} * \gamma'] = g^{-1}[γˉ​∗γ′]=g−1。∎

    「只差一个内自同构」就是不典范的精确含义；只有当 π1\pi_{1}π1​ 阿贝尔时它才真的与道路无关。
