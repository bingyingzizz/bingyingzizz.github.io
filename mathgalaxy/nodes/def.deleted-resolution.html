陈述

设 ε:P0→M\varepsilon : P_{0} \to Mε:P0​→M 是 RRR-模 MMM 的一条投射消解的增广，即

⋯→P2→ d2 P1→ d1 P0→ ε M→0\cdots \to P_{2} \xrightarrow{\ d_{2}\ } P_{1} \xrightarrow{\ d_{1}\ } P_{0} \xrightarrow{\ \varepsilon\ } M \to 0⋯→P2​ d2​ ​P1​ d1​ ​P0​ ε ​M→0

处处正合、每项 PnP_{n}Pn​ 投射。删除消解（deleted resolution）是去掉增广留下的链复形

P∙:⋯→P2→ d2 P1→ d1 P0→0.P_{\bullet} : \quad \cdots \to P_{2} \xrightarrow{\ d_{2}\ } P_{1} \xrightarrow{\ d_{1}\ } P_{0} \to 0 .P∙​:⋯→P2​ d2​ ​P1​ d1​ ​P0​→0.

换句话说：把 MMM 支在 −1-1−1 次的那条正合复形，删掉 −1-1−1 次的那一项，其余原样保留。

说明

为什么值得单独命名。 求导时，函子并不是作用在增广上的：真正算的是删除消解上的复形

Ext⁡Rn(M,N)=Hn(Hom⁡R(P∙,N)),Tor⁡nR(M,N)=Hn(P∙⊗RN).\operatorname{Ext}^{n}_{R}(M, N) = H^{n}\bigl(\operatorname{Hom}_{R}(P_{\bullet}, N)\bigr), \qquad \operatorname{Tor}_{n}^{R}(M, N) = H_{n}\bigl(P_{\bullet} \otimes_{R} N\bigr).ExtRn​(M,N)=Hn(HomR​(P∙​,N)),TornR​(M,N)=Hn​(P∙​⊗R​N).

右边两个 HHH 取的都是删除消解本身，而不是带 MMM 的那条。见「扩展群的双边算法」与「挠积」。

两个容易翻的细节。 ① 删除消解不再正合：H0(P∙)=P0/im⁡d1≅MH_{0}(P_{\bullet}) = P_{0}/\operatorname{im} d_{1} \cong MH0​(P∙​)=P0​/imd1​≅M，高次同调全为零 —— 它「只在 000 次与原来不同」；② 也有书把 MMM 留在 −1-1−1 次（叫增广复形），两者只差一项，写公式时必须说清用的是哪一个。

⚠️ 记号陷阱：Hom⁡(P∙,N)\operatorname{Hom}(P_{\bullet}, N)Hom(P∙​,N) 是把 NNN 看成支在 000 次的复形之后取的 Hom 复形，其次数与 P∙P_{\bullet}P∙​ 的上下标方向相反（不上对偶就只得到链复形）；所以那里写 HnH^{n}Hn，这里写 HnH_{n}Hn​。
