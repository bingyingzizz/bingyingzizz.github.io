def.effective-equivalence · 范畴论 · 等价关系 · 商

又称有效等价关系·effective equivalence relation·有效关系

陈述

对象 XXX 上的等价关系是一个图 R⇉XR \rightrightarrows XR⇉X，使得对每个 YYY，Hom⁡(Y,R)→Hom⁡(Y,X)×Hom⁡(Y,X)\operatorname{Hom}(Y, R) \to \operatorname{Hom}(Y, X) \times \operatorname{Hom}(Y, X)Hom(Y,R)→Hom(Y,X)×Hom(Y,X) 是等价关系（在 Set\mathbf{Set}Set 里取）。

它叫有效的，如果

R  ≅  X×X‾X,X‾:=coker⁡(R⇉X)R \;\cong\; X \times_{\overline{X}} X, \qquad \overline{X} := \operatorname{coker}(R \rightrightarrows X)R≅X×X​X,X:=coker(R⇉X)

即 RRR 恰好就是商映射的核对。

说明

「有效」说的是商没有多粘：先取等价关系再取商、然后再看商映射的核对，回到原来的等价关系。

对照集合：任意 f:X→Yf : X \to Yf:X→Y 给出的核对 X×YXX \times_{Y} XX×Y​X 一定是有效的（X‾≅im⁡f\overline{X} \cong \operatorname{im} fX≅imf）；

反过来任意等价关系 R⊆X×XR \subseteq X \times XR⊆X×X 取 X‾=X/R\overline{X} = X/RX=X/R 也总是回到 RRR。

在 Set\mathbf{Set}Set 里人人都有效，但在一般范畴里这是要额外要求的一条。

Statement draft

An equivalence relation on an object XXX is a graph R⇉XR \rightrightarrows XR⇉X such that for every YYY, the map Hom⁡(Y,R)→Hom⁡(Y,X)×Hom⁡(Y,X)\operatorname{Hom}(Y, R) \to \operatorname{Hom}(Y, X) \times \operatorname{Hom}(Y, X)Hom(Y,R)→Hom(Y,X)×Hom(Y,X) is an equivalence relation (taken in Set\mathbf{Set}Set).

It is effective if

R  ≅  X×X‾X,X‾:=coker⁡(R⇉X)R \;\cong\; X \times_{\overline{X}} X, \qquad \overline{X} := \operatorname{coker}(R \rightrightarrows X)R≅X×X​X,X:=coker(R⇉X)

that is, RRR is exactly the kernel pair of the quotient map.

Notes draft

"Effective" says the quotient glues nothing extra: take the equivalence relation, then the quotient, then look at the kernel pair of the quotient map, and one returns to the original equivalence relation.

Compare with sets: for any f:X→Yf : X \to Yf:X→Y the kernel pair X×YXX \times_{Y} XX×Y​X is always effective (X‾≅im⁡f\overline{X} \cong \operatorname{im} fX≅imf); conversely, any equivalence relation R⊆X×XR \subseteq X \times XR⊆X×X with X‾=X/R\overline{X} = X/RX=X/R always returns RRR.

In Set\mathbf{Set}Set everything is effective, but in a general category this has to be required separately.

    设 f:X→Yf : X \to Yf:X→Y。取核对 R:=X×YXR := X \times_{Y} XR:=X×Y​X，它是 XXX 上的等价关系。由预拓扑斯第 3 条，等价关系有效，所以可以取商

    X‾:=X/R=coker⁡(R⇉X)\overline{X} := X/R = \operatorname{coker}(R \rightrightarrows X)X:=X/R=coker(R⇉X)

    两条投影在 fff 下相等，故 fff 穿过商，得到分解

    f:X↠X‾→ l Yf : X \twoheadrightarrow \overline{X} \xrightarrow{\ l\ } Yf:X↠X l ​Y

    V⟶Z↓(g0,h0)↓(g,h)X×XX→ π×π X‾×X‾\begin{array}{ccc} V & \longrightarrow & Z \\ \downarrow\scriptstyle{(g_0,h_0)} & & \downarrow\scriptstyle{(g,h)} \\ X \times_{X} X & \xrightarrow{\ \pi \times \pi\ } & \overline{X} \times \overline{X} \end{array}V↓(g0​,h0​)X×X​X​⟶ π×π ​​Z↓(g,h)X×X​

    由 l∘g=l∘hl \circ g = l \circ hl∘g=l∘h 得 l∘π∘g0=l∘π∘h0l \circ \pi \circ g_{0} = l \circ \pi \circ h_{0}l∘π∘g0​=l∘π∘h0​，即 f∘g0=f∘h0f \circ g_{0} = f \circ h_{0}f∘g0​=f∘h0​。

    唯一性。 若 f=X→ π′ X′→ l′ Yf = X \xrightarrow{\ \pi'\ } X' \xrightarrow{\ l'\ } Yf=X π′ ​X′ l′ ​Y 是另一个满-单分解，则由 l′l'l′ 是单态射得 R=X×X′XR = X \times_{X'} XR=X×X′​X。

    记 π′\pi'π′ 为满态射，由第 4 条它是正则的，即 π′=coker⁡(X×X′X⇉X)\pi' = \operatorname{coker}(X \times_{X'} X \rightrightarrows X)π′=coker(X×X′​X⇉X)；

    把 X×X′X=RX \times_{X'} X = RX×X′​X=R 代进去得 π′\pi'π′ 与 π\piπ 是同一个余等化子。

    于是存在互逆的 X‾⇄X′\overline{X} \rightleftarrows X'X⇄X′，X′≅X‾X' \cong \overline{X}X′≅X。

    ∎

    平衡性。 若 fff 既满又单，则 R=X×YX≅XR = X \times_{Y} X \cong XR=X×Y​X≅X（单态射的等价刻画），故 X‾≅X\overline{X} \cong XX≅X，f≅lf \cong lf≅l 是单态射；又 fff 已是单态射，故 fff 是同构。∎

    严格性。 上面的分解把 im⁡f\operatorname{im} fimf 与 coim⁡f\operatorname{coim} fcoimf 都算成了 X‾\overline{X}X，所以它们同构。∎

  • 本页 ⟹ 层化与等价关系交换推出

    证明。 记层化为 (−)♯(-)^{\sharp}(−)♯：它是到层范畴的反射，故左伴随。

    • 左伴随保余极限 ✓；它同时又左正合（保有限极限，因为拓扑斯都是左正合的）✓。
    • 等价关系的条件都是有限极限条件：R⇉TR \rightrightarrows TR⇉T 是等价关系   ⟺  \iff⟺ 存在 R→T×TR \to T\times TR→T×T 使其为单态射（自反、对称、传递三条用对角、交换与拉回表达）。

    层化保这些有限极限，故 R♯⇉T♯R^{\sharp} \rightrightarrows T^{\sharp}R♯⇉T♯ 仍是等价关系 ✓。

    • 商是余等化子：T/R:=coeq⁡(R⇉T)T/R := \operatorname{coeq}(R \rightrightarrows T)T/R:=coeq(R⇉T)，是余极限，故 (T/R)♯≅coeq⁡(R♯⇉T♯)=T♯/R♯(T/R)^{\sharp} \cong \operatorname{coeq}(R^{\sharp}\rightrightarrows T^{\sharp}) = T^{\sharp}/R^{\sharp}(T/R)♯≅coeq(R♯⇉T♯)=T♯/R♯ ✓。

    两件事合起来就是「先商再层化 === 先层化再商」✓。∎
