陈述

等势把「所有集合」分成一个个类。「集合 AAA 的基数」∣A∣|A|∣A∣ 指的就是 AAA 所在的这个等势类 —— 它衡量 AAA 有多大，而不关心 AAA 的元素是什么。

比较两个基数：

  • ∣A∣≤∣B∣|A| \le |B|∣A∣≤∣B∣：存在单射 A→BA \to BA→B；
  • ∣A∣=∣B∣|A| = |B|∣A∣=∣B∣：存在双射 A→BA \to BA→B（等势）；
  • ∣A∣<∣B∣|A| < |B|∣A∣<∣B∣：∣A∣≤∣B∣|A| \le |B|∣A∣≤∣B∣ 但 ∣A∣≠∣B∣|A| \ne |B|∣A∣=∣B∣。

若 ∣A∣≤∣B∣|A| \le |B|∣A∣≤∣B∣ 且 ∣B∣≤∣A∣|B| \le |A|∣B∣≤∣A∣，则 ∣A∣=∣B∣|A| = |B|∣A∣=∣B∣（Schröder–Bernstein 定理）。

说明

⭐ 记号的用法：∣N∣=ℵ0|\mathbb{N}| = \aleph_0∣N∣=ℵ0​（可数无限），∣R∣=2ℵ0|\mathbb{R}| = 2^{\aleph_0}∣R∣=2ℵ0​，且 ℵ0<2ℵ0\aleph_0 < 2^{\aleph_0}ℵ0​<2ℵ0​。

⚠ 严格说来「等势类」不是集合（它是真类），所以 ZFC 里的通行做法是：先有序数，再用良序定理（  ⟺  \iff⟺ AC）取每个等势类里最小的那个序数作代表，那个序数就叫基数。

本星图只用到「∣A∣≤∣B∣|A| \le |B|∣A∣≤∣B∣ 靠单射、∣A∣=∣B∣|A| = |B|∣A∣=∣B∣ 靠双射」这两件事 —— 它们不需要选代表就能用。

⚠ 任意两个基数不一定可比，这正是基数可比定理（要用 AC）的内容。
