# Hadamard factorization theorem　`thm.hadamard-factorization`
English entry · root `../`
[in graph](../#n=thm.hadamard-factorization)　·　[Chinese page (authoritative)](./thm.hadamard-factorization.md)

⭐ **This is a quantitative version of the Weierstrass product.** Knowing the order of growth lets us use the same $p$ for every factor and reduces the remaining freedom to a polynomial $P$. When $\rho<1$, we have $p=0$ and $\sum|a_{n}|^{-1}<\infty$, but there can still be infinitely many zeros ($\prod(1-z/n^{2})$ has order $1/2$). ⚠️ The finite-order hypothesis is essential. Entire functions of infinite order still admit Weierstrass products, but the exponent need no longer be a polynomial and the conclusion is weaker.
