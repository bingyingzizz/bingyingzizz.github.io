陈述

单纯形范畴 Δ\DeltaΔ 的对象是

[0], [1], [2], …, [n], …[0], \ [1], \ [2], \ \ldots, \ [n], \ \ldots[0], [1], [2], …, [n], …

而 [n]→[m][n] \to [m][n]→[m] 的态射取全体单调映射（不要求 n≤mn \le mn≤m，也不要求严格）。Δ\DeltaΔ 的全体态射由两类生成：

  • 面映射 δi:[n−1]→[n]\delta^{i} : [n-1] \to [n]δi:[n−1]→[n]：跳过第 iii 个点（i=0,…,ni = 0, \ldots, ni=0,…,n）；
  • 退化映射 σi:[n]→[n−1]\sigma^{i} : [n] \to [n-1]σi:[n]→[n−1]：重复第 iii 个点。

只保留面映射的子范畴记 Δinj\Delta_{\mathrm{inj}}Δinj​，只保留退化映射的记 Δsurj\Delta_{\mathrm{surj}}Δsurj​。C\mathcal{C}C 中的单纯对象是图

X:Δop⟶CX : \Delta^{\mathrm{op}} \longrightarrow \mathcal{C}X:Δop⟶C

只保留面映射的图（Δinjop→C\Delta_{\mathrm{inj}}^{\mathrm{op}} \to \mathcal{C}Δinjop​→C）叫半单纯对象。

说明

把 [n][n][n] 画成一个顶点数 n+1n+1n+1 的标准单纯形，面映射就是「贴一个面」，退化映射就是「把一个顶点压扁」。于是 Δ\DeltaΔ 是「所有标准单纯形及其贴合方式」的骨架，Δop→C\Delta^{\mathrm{op}} \to \mathcal{C}Δop→C 的一个图就是把一串层层相套的单纯形安进 C\mathcal{C}C 里 —— 这是把空间编码成代数数据的最省事的办法。

取 C=Set\mathcal{C} = \mathbf{Set}C=Set，X([n])X([n])X([n]) 就是「nnn 维单纯形的集合」，X(δi)X(\delta^i)X(δi) 给出「第 iii 个面」，X(σi)X(\sigma^i)X(σi) 给出「退化」。
