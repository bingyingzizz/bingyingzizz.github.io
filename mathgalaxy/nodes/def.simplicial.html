def.simplicial · 范畴论 · 单纯 · 索引范畴

又称单纯对象·simplicial object·Definition 1.3.2·Def 1.3.2·Exercise 1.25

陈述

单纯形范畴 Δ\DeltaΔ 的对象是

[0], [1], [2], …, [n], …[0], \ [1], \ [2], \ \ldots, \ [n], \ \ldots[0], [1], [2], …, [n], …

而 [n]→[m][n] \to [m][n]→[m] 的态射取全体单调映射（不要求 n≤mn \le mn≤m，也不要求严格）。Δ\DeltaΔ 的全体态射由两类生成：

  • 面映射 δi:[n−1]→[n]\delta^{i} : [n-1] \to [n]δi:[n−1]→[n]：跳过第 iii 个点（i=0,…,ni = 0, \ldots, ni=0,…,n）；
  • 退化映射 σi:[n+1]→[n]\sigma^{i} : [n+1] \to [n]σi:[n+1]→[n]：把 iii 与 i+1i+1i+1 合并（等价地，插入一个重复点）。

只保留面映射的子范畴记 Δinj\Delta_{\mathrm{inj}}Δinj​，只保留退化映射的记 Δsurj\Delta_{\mathrm{surj}}Δsurj​。C\mathcal{C}C 中的单纯对象是图

X:Δop⟶C,X : \Delta^{\mathrm{op}} \longrightarrow \mathcal{C},X:Δop⟶C,

只保留面映射的图（Δinjop→C\Delta_{\mathrm{inj}}^{\mathrm{op}} \to \mathcal{C}Δinjop​→C）叫半单纯对象。

说明

把 [n][n][n] 画成一个顶点数 n+1n+1n+1 的标准单纯形，面映射就是「贴一个面」，退化映射就是「把一个顶点压扁」。

于是 Δ\DeltaΔ 是「所有标准单纯形及其贴合方式」的骨架，Δop→C\Delta^{\mathrm{op}} \to \mathcal{C}Δop→C 的一个图就是把一串层层相套的单纯形安进 C\mathcal{C}C 里 —— 这是把空间编码成代数数据的最省事的办法。

展开写法：记 Xn:=X([n])X_{n} := X([n])Xn​:=X([n])，并把 Δop\Delta^{\mathrm{op}}Δop 里的箭头反向后记为

di:=X(δi):Xn⟶Xn−1,si:=X(σi):Xn⟶Xn+1.d_{i} := X(\delta^{i}) : X_{n} \longrightarrow X_{n-1}, \qquad s_{i} := X(\sigma^{i}) : X_{n} \longrightarrow X_{n+1}.di​:=X(δi):Xn​⟶Xn−1​,si​:=X(σi):Xn​⟶Xn+1​.

它们满足与单纯恒等式对偶的面-退化关系：

  • didj=dj−1did_{i} d_{j} = d_{j-1} d_{i}di​dj​=dj−1​di​（i<ji < ji<j）；
  • sisj=sj−1sis_{i} s_{j} = s_{j-1} s_{i}si​sj​=sj−1​si​（i<ji < ji<j）；
  • disj=sj−1did_{i} s_{j} = s_{j-1} d_{i}di​sj​=sj−1​di​（i<ji < ji<j）；
  • disj=1d_{i} s_{j} = 1di​sj​=1（i=ji = ji=j 或 i=j+1i = j+1i=j+1）；
  • disj=sjdi−1d_{i} s_{j} = s_{j} d_{i-1}di​sj​=sj​di−1​（i>j+1i > j+1i>j+1）。

所以「单纯对象」在纸面上永远是一串对象 X0,X1,…X_{0}, X_{1}, \ldotsX0​,X1​,… 加上面映射 did_{i}di​ 与退化映射 sis_{i}si​ —— 范畴语言只是把这串数据与其相容性一次说清。

例 1（标准单纯形）：X=Hom⁡Δ(−,[n])X = \operatorname{Hom}_{\Delta}(-,[n])X=HomΔ​(−,[n]) 是单纯集，XkX_{k}Xk​ 恰是「[k][k][k] 中的保序嵌入数」，几何实现就是标准的 nnn-单形。

例 2（奇异单纯集）：拓扑空间 TTT 给出 S∙(T):[n]↦Hom⁡Top(Δn,T)S_{\bullet}(T) : [n] \mapsto \operatorname{Hom}_{\mathbf{Top}}(\Delta^{n}, T)S∙​(T):[n]↦HomTop​(Δn,T)，即「TTT 中的 nnn-奇异单形」；它的链群就是奇异链群。所以奇异同调不是另一套理论，而是单纯对象取链复形。

例 3（单纯集 = 预层）：C=Set\mathcal{C} = \mathbf{Set}C=Set 时，单纯对象就是 Δop\Delta^{\mathrm{op}}Δop 上的预层（presheaf）。几何实现是余极限 ∣X∣=lim→⁡[k]→XΔk|X| = \varinjlim_{[k] \to X} \Delta^{k}∣X∣=lim​[k]→X​Δk（把每个 kkk-单形按面关系粘起来）—— 「XXX 在 kkk 维有几个单形、怎么粘」全由 XkX_{k}Xk​ 与 di,sid_{i}, s_{i}di​,si​ 记录。

⚠️ 三个易混：

  • 「单纯集」(simplicial set) 与「单纯复形」(simplicial complex) 不是一回事：前者是 Δop\Delta^{\mathrm{op}}Δop 上的预层（允许一个单形有多个顶点、允许退化单形），后者是一族有限子集并满足闭包条件。
  • 半单纯对象只保留面映射 did_{i}di​，丢掉退化 sis_{i}si​；它足以定义同调（∂=∑(−1)idi\partial = \sum (-1)^{i} d_{i}∂=∑(−1)idi​），但不足以做同伦论。
  • 「余单纯对象」是把 Δ\DeltaΔ 换成 Δop\Delta^{\mathrm{op}}Δop（图 Δ→C\Delta \to \mathcal{C}Δ→C），上同调的指标方向由此而来。

  • 单纯形范畴 → 本页定义引用

    单纯对象是 Δop\Delta^{\mathrm{op}}Δop 上的图，索引范畴正是 单纯形范畴；本节点陈述为了自足把 Δ\DeltaΔ 的骨架重述了一遍，正式定义以那个节点为准。

  • 图与交换图 → 本页定义引用

    单纯对象就是一个图 Δop→C\Delta^{\mathrm{op}} \to \mathcal{C}Δop→C —— 只不过索引范畴换成了单纯形范畴 Δ\DeltaΔ。

  • 映射 → 本页定义引用

    Δ\DeltaΔ 的态射是单调映射 [n]→[m][n] \to [m][n]→[m]，面映射与退化映射是两类基本映射（跳过一点 / 重复一点）。
