Statement

Let RRR be a unital ring and NNN a left RRR-module. The functor (−)⊗RN:Mod-R→Ab(-) \otimes_{R} N : \mathbf{Mod}\text{-}R \to \mathbf{Ab}(−)⊗R​N:Mod-R→Ab is right exact: every short exact sequence

0⟶M1→  f  M→  g  M2⟶00 \longrightarrow M_{1} \xrightarrow{\;f\;} M \xrightarrow{\;g\;} M_{2} \longrightarrow 00⟶M1​f​Mg​M2​⟶0

gives an exact sequence

M1⊗RN→  f⊗1  M⊗RN→  g⊗1  M2⊗RN⟶0.M_{1} \otimes_{R} N \xrightarrow{\;f \otimes 1\;} M \otimes_{R} N \xrightarrow{\;g \otimes 1\;} M_{2} \otimes_{R} N \longrightarrow 0 .M1​⊗R​Nf⊗1​M⊗R​Ng⊗1​M2​⊗R​N⟶0.

Moreover the following are equivalent: (i) (−)⊗RN(-) \otimes_{R} N(−)⊗R​N is exact; (ii) for every injection M1↣MM_{1} \rightarrowtail MM1​↣M, the map M1⊗N→M⊗NM_{1} \otimes N \to M \otimes NM1​⊗N→M⊗N is still injective; (iii) NNN is flat.

(The right-hand →0\to 0→0 is always exact; only the left 000 can fail.)

Notes

Proof (adjunction route, fastest): by 张量与内同态的伴随, (−)⊗RN⊣Hom⁡Z(N,−)(-) \otimes_{R} N \dashv \operatorname{Hom}_{\mathbb{Z}}(N, -)(−)⊗R​N⊣HomZ​(N,−) (the target is Ab\mathbf{Ab}Ab, and the right adjoint takes Z\mathbb{Z}Z-linear homs).

A left adjoint preserves all colimits, and a cokernel is the colimit of a two-term diagram, so (−)⊗N(-) \otimes N(−)⊗N preserves cokernels — for an additive functor "preserves cokernels" is exactly "sends short exact sequences to the exact sequence M1⊗N→M⊗N→M2⊗N→0M_{1} \otimes N \to M \otimes N \to M_{2} \otimes N \to 0M1​⊗N→M⊗N→M2​⊗N→0" ✓.

A direct computation also works: ggg surjective implies g⊗1g \otimes 1g⊗1 surjective (every m2⊗nm_{2} \otimes nm2​⊗n has a preimage m⊗nm \otimes nm⊗n); for the kernel: from ker⁡g=im⁡f\ker g = \operatorname{im} fkerg=imf, if g(m)=0g(m) = 0g(m)=0, then mmm can be written f(m1)f(m_{1})f(m1​), so a pure tensor is m⊗n=(f⊗1)(m1⊗n)m \otimes n = (f \otimes 1)(m_{1} \otimes n)m⊗n=(f⊗1)(m1​⊗n), and a general element is a sum of these, giving ker⁡(g⊗1)⊆im⁡(f⊗1)\ker(g \otimes 1) \subseteq \operatorname{im}(f \otimes 1)ker(g⊗1)⊆im(f⊗1);

the reverse inclusion follows from gf=0g f = 0gf=0 ✓.

⚠️ The left end can be lost: after tensoring 0→Z→  2  Z→Z/2→00 \to \mathbb{Z} \xrightarrow{\;2\;} \mathbb{Z} \to \mathbb{Z}/2 \to 00→Z2​Z→Z/2→0 with N=Z/2N = \mathbb{Z}/2N=Z/2, the map Z⊗Z/2→  2  Z⊗Z/2\mathbb{Z} \otimes \mathbb{Z}/2 \xrightarrow{\;2\;} \mathbb{Z} \otimes \mathbb{Z}/2Z⊗Z/22​Z⊗Z/2 is zero, no longer injective.

⭐ So "right exact" is free, and left exactness is the property — and its name is flatness. The lost left end does not vanish into nothing: it is the image of the connecting map Tor⁡1R(M2,N)→M1⊗N\operatorname{Tor}_{1}^{R}(M_{2}, N) \to M_{1} \otimes NTor1R​(M2​,N)→M1​⊗N (one cannot identify the "lost kernel" with Tor⁡1\operatorname{Tor}_{1}Tor1​ directly: the split sequence 0→Z/2→(Z/2)2→Z/2→00 \to \mathbb{Z}/2 \to (\mathbb{Z}/2)^{2} \to \mathbb{Z}/2 \to 00→Z/2→(Z/2)2→Z/2→0 stays split after tensoring, with zero kernel, while Tor⁡1(Z/2,Z/2)=Z/2\operatorname{Tor}_{1}(\mathbb{Z}/2, \mathbb{Z}/2) = \mathbb{Z}/2Tor1​(Z/2,Z/2)=Z/2).
