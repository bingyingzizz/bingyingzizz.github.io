# 正定矩阵　`def.positive-definite-matrix`

[在星图里打开](../#n=def.positive-definite-matrix)　·　[节点索引](../index.md)

**在做什么**：把「这个二次型处处为正」写成矩阵条件。物理上它是「能量形式」，几何上它是「内积的另一种写法」。

设 $A \in M_{n}(\mathbb{C})$ 是 Hermite 矩阵。称 $A$ **正定**，若对一切 $x \ne 0$

$$x^{*}Ax > 0 ;$$
