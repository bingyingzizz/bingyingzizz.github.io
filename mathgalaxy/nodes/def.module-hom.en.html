Statement

Let AAA be a ring with identity and M,NM, NM,N be AAA-modules. A map f:M→Nf : M \to Nf:M→N is an AAA-module homomorphism if

f(m+m′)=f(m)+f(m′),f(am)=af(m)f(m + m') = f(m) + f(m'), \qquad f(a m) = a f(m)f(m+m′)=f(m)+f(m′),f(am)=af(m)

for all m,m′∈Mm, m' \in Mm,m′∈M and a∈Aa \in Aa∈A.

The set of all AAA-module homomorphisms is denoted Hom⁡A(M,N)\operatorname{Hom}_A(M, N)HomA​(M,N); under pointwise addition it is an abelian group. The kernel ker⁡f\ker fkerf and the image im⁡f\operatorname{im} fimf are both submodules; the map fff is an isomorphism   ⟺  \iff⟺ it is bijective.

Notes

⭐ Examples: for A=ZA = \mathbb{Z}A=Z, module homomorphisms are abelian group homomorphisms; for A=KA = KA=K, they are linear maps.

⚠ In general Hom⁡A(M,N)\operatorname{Hom}_A(M, N)HomA​(M,N) is only an abelian group, not an AAA-module; a natural AAA-module structure exists only when AAA is commutative.

⭐ First isomorphism theorem: M/ker⁡f≅im⁡fM/\ker f \cong \operatorname{im} fM/kerf≅imf (for quotient modules see 商模).
