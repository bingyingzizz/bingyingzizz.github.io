陈述

在做什么：散度在整块流形上积起来，等于流量从边界漏出去的通量。这是 Gauss 公式在任意维数、任意黎曼流形上的样子，也是「散度 = 源密度」这句口号的正式版本。

设 (M,g)(M,g)(M,g) 是紧致、定向、带边的 nnn 维黎曼流形；∂M\partial M∂M 取诱导定向与诱导度量，dV\mathrm{d}VdV 是 MMM 的体积形式，dA\mathrm{d}AdA 是 ∂M\partial M∂M 的体积形式，NNN 是沿 ∂M\partial M∂M 指向外的单位法向量，XXX 是 MMM 上的光滑向量场。则

∫M(div⁡X) dV=∫∂M⟨X,N⟩ dA.\int_{M}(\operatorname{div}X)\,\mathrm{d}V = \int_{\partial M}\langle X,N\rangle\,\mathrm{d}A .∫M​(divX)dV=∫∂M​⟨X,N⟩dA.

∂M=∅\partial M = \emptyset∂M=∅ 时右边为零，等式退化成「无边界则总散度为零」。

n=3n = 3n=3、X=(P,Q,R)X = (P,Q,R)X=(P,Q,R) 在平坦区域上给出经典 Gauss–Ostrogradsky 公式，n=2n = 2n=2 给出 Green 公式的另一种写法。

说明

它不是新定理：证明就是把 thm.stokes 用在 ω=ιXdV\omega = \iota_{X}\mathrm{d}Vω=ιX​dV 上。所以「微积分基本定理 / Stokes / 散度定理 / Green / Kelvin–Stokes」这五条是同一句公式在五种维数与五种形式次数上的读法。

符号的两个来源：NNN 必须朝外，∂M\partial M∂M 必须取诱导定向（外法向在前）。两个约定缺一个，整体就差一个负号 —— 而所有二、三维的特例都仍然「看起来对」，所以这个错误特别难查。约定之间的相容性由 prop.boundary-sign-convention 保证。

Green 第一公式：取 X=∇uX = \nabla uX=∇u（∇\nabla∇ 取 ggg 的梯度），得 ∫MΔu dV=∫∂M∂Nu dA\int_{M}\Delta u\,\mathrm{d}V = \int_{\partial M}\partial_{N}u\,\mathrm{d}A∫M​ΔudV=∫∂M​∂N​udA；再对 u ∇vu\,\nabla vu∇v 用一次并相减，就得到对称的那个版本。

⚠️ 紧致性：不紧时右边必须绝对可积，或对穷竭序列 M1⊂M2⊂⋯M_{1}\subset M_{2}\subset\cdotsM1​⊂M2​⊂⋯ 取极限（此时会多出内部边界项，靠它们两两相消收敛）。本图只陈述紧致情形。

⚠️ 边界为空不等于平凡：闭流形上 ∫Mdiv⁡X dV=0\int_{M}\operatorname{div}X\,\mathrm{d}V = 0∫M​divXdV=0，这条非平凡 —— 它排除了「处处往外冒」的向量场，是 Hodge 理论与调和形式那一支的起点。
