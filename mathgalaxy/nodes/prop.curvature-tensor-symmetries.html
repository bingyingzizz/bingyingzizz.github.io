陈述

在做什么：清点曲率张量到底有几个独立分量 —— 四条对称性把它从 n4n^{4}n4 砍到 n2(n2−1)/12n^{2}(n^{2}-1)/12n2(n2−1)/12。这是「二维曲率只有一个数、四维有两个张量」的算术来源。

设 (M,g)(M,g)(M,g) 是黎曼流形，曲率算子 R(X,Y)Z=∇X∇YZ−∇Y∇XZ−∇[X,Y]ZR(X,Y)Z = \nabla_{X}\nabla_{Y}Z-\nabla_{Y}\nabla_{X}Z-\nabla_{[X,Y]}ZR(X,Y)Z=∇X​∇Y​Z−∇Y​∇X​Z−∇[X,Y]​Z，分量 Rijkℓ=⟨R(∂i,∂j)∂k,∂ℓ⟩R_{ijk\ell} = \langle R(\partial_{i},\partial_{j})\partial_{k},\partial_{\ell}\rangleRijkℓ​=⟨R(∂i​,∂j​)∂k​,∂ℓ​⟩（约定与 def.curvature-tensor、def.gauss-curvature 相同）。则

  1. 对前两个指标反称：Rijkℓ=−RjikℓR_{ijk\ell} = -R_{jik\ell}Rijkℓ​=−Rjikℓ​；
  2. 对后两个指标反称：Rijkℓ=−RijℓkR_{ijk\ell} = -R_{ij\ell k}Rijkℓ​=−Rijℓk​；
  3. 两对指标可交换：Rijkℓ=RkℓijR_{ijk\ell} = R_{k\ell ij}Rijkℓ​=Rkℓij​；
  4. 第一比安基恒等式：Rijkℓ+Rjkiℓ+Rkijℓ=0R_{ijk\ell}+R_{jki\ell}+R_{kij\ell} = 0Rijkℓ​+Rjkiℓ​+Rkijℓ​=0。

于是独立分量数是

dim⁡=n2(n2−1)12:n=2: 1,n=3: 6,n=4: 20.\dim = \frac{n^{2}\bigl(n^{2}-1\bigr)}{12}:\qquad n = 2:\ 1,\quad n = 3:\ 6,\quad n = 4:\ 20 .dim=12n2(n2−1)​:n=2: 1,n=3: 6,n=4: 20.

无指标的说法：R(X,Y,Z,W):=⟨R(X,Y)Z,W⟩R(X,Y,Z,W) := \langle R(X,Y)Z,W\rangleR(X,Y,Z,W):=⟨R(X,Y)Z,W⟩ 是 ⋀2TpM\bigwedge^{2}T_{p}M⋀2Tp​M 上的对称双线性型（前两条给反称、第三条给对称），第四条再削掉 (n3)\binom{n}{3}(3n​) 维。

说明

前两条的来源不同：对 X,YX,YX,Y 的反称是定义里 [∇X,∇Y][\nabla_{X},\nabla_{Y}][∇X​,∇Y​] 的直接结果；对 Z,WZ,WZ,W 的反称要用保度量（∇g=0\nabla g = 0∇g=0）—— 先证 ⟨R(X,Y)Z,Z⟩=0\langle R(X,Y)Z,Z\rangle = 0⟨R(X,Y)Z,Z⟩=0 再极化。

第四条来自无挠：R(X,Y)Z+R(Y,Z)X+R(Z,X)Y=0R(X,Y)Z+R(Y,Z)X+R(Z,X)Y = 0R(X,Y)Z+R(Y,Z)X+R(Z,X)Y=0。等价的漂亮证法：无挠时 ∇2Z(X,Y):=∇X∇YZ−∇∇XYZ\nabla^{2}Z(X,Y) := \nabla_{X}\nabla_{Y}Z-\nabla_{\nabla_{X}Y}Z∇2Z(X,Y):=∇X​∇Y​Z−∇∇X​Y​Z 关于 X,YX,YX,Y 对称，而 R(X,Y)Z=∇2Z(X,Y)−∇2Z(Y,X)R(X,Y)Z = \nabla^{2}Z(X,Y)-\nabla^{2}Z(Y,X)R(X,Y)Z=∇2Z(X,Y)−∇2Z(Y,X)；对三个变元循环求和时两个对称项互换位置、逐项抵消。

第三条是纯代数记账：把第一比安基对四个变元的几种循环取法写出、用前两条把符号搬正再相加，剩下的正是 Rijkℓ−RkℓijR_{ijk\ell}-R_{k\ell ij}Rijkℓ​−Rkℓij​。没有几何内容，本节点不逐项抄。

为什么要数分量：n=2n = 2n=2 时只剩 R1212R_{1212}R1212​ 一个函数，所以二维曲率就是一个数（高斯曲率）；n=3n = 3n=3 时 666 个分量全由 Ricci 决定（外尔张量为零）；n=4n = 4n=4 时 20=10+1020 = 10+1020=10+10，后一半是外尔张量 —— 引力波住在那里。

⚠️ 符号约定：本图取 Rijkℓ=⟨R(∂i,∂j)∂k,∂ℓ⟩R_{ijk\ell} = \langle R(\partial_{i},\partial_{j})\partial_{k},\partial_{\ell}\rangleRijkℓ​=⟨R(∂i​,∂j​)∂k​,∂ℓ​⟩，单位球面给 R1221=+1R_{1221} = +1R1221​=+1、R1212=−1R_{1212} = -1R1212​=−1。换一种指标次序会让第 3、4 条的符号整体挪位，用球面检验最快。

    Rijkℓ=12(∂i∂kgjℓ−∂i∂ℓgjk−∂j∂kgiℓ+∂j∂ℓgik).R_{ijk\ell} = \frac{1}{2}\bigl(\partial_{i}\partial_{k}g_{j\ell}-\partial_{i}\partial_{\ell}g_{jk}-\partial_{j}\partial_{k}g_{i\ell}+\partial_{j}\partial_{\ell}g_{ik}\bigr).Rijkℓ​=21​(∂i​∂k​gjℓ​−∂i​∂ℓ​gjk​−∂j​∂k​giℓ​+∂j​∂ℓ​gik​).

    缩并形式。 对第二比安基先用 giℓg^{i\ell}giℓ 缩并一次、再用 gjmg^{jm}gjm 缩并一次，并用 (3)（两对指标可交换）把指标搬正，得

    ∇iRij−12∇jS=0,\nabla^{i}R_{ij}-\frac{1}{2}\nabla_{j}S = 0 ,∇iRij​−21​∇j​S=0,

    保度量 +++ 无挠   ⟹  \implies⟹ 曲率张量的四条对称性

    (1) 对 X,YX,YX,Y 反称：R(X,Y)=[∇X,∇Y]−∇[X,Y]R(X,Y) = [\nabla_{X},\nabla_{Y}]-\nabla_{[X,Y]}R(X,Y)=[∇X​,∇Y​]−∇[X,Y]​ 中交换 X,YX,YX,Y，每一项都反号。

    (2) 对 Z,WZ,WZ,W 反称（用保度量）。先证 ⟨R(X,Y)Z,Z⟩=0\langle R(X,Y)Z,Z\rangle = 0⟨R(X,Y)Z,Z⟩=0。由 ⟨∇UZ,Z⟩=12U⟨Z,Z⟩\langle\nabla_{U}Z,Z\rangle = \frac{1}{2}U\langle Z,Z\rangle⟨∇U​Z,Z⟩=21​U⟨Z,Z⟩：

    ⟨∇X∇YZ,Z⟩=X⟨∇YZ,Z⟩−⟨∇YZ,∇XZ⟩=12XY⟨Z,Z⟩−⟨∇YZ,∇XZ⟩,\langle\nabla_{X}\nabla_{Y}Z,Z\rangle = X\langle\nabla_{Y}Z,Z\rangle-\langle\nabla_{Y}Z,\nabla_{X}Z\rangle = \frac{1}{2}XY\langle Z,Z\rangle-\langle\nabla_{Y}Z,\nabla_{X}Z\rangle ,⟨∇X​∇Y​Z,Z⟩=X⟨∇Y​Z,Z⟩−⟨∇Y​Z,∇X​Z⟩=21​XY⟨Z,Z⟩−⟨∇Y​Z,∇X​Z⟩,

    同理 ⟨∇Y∇XZ,Z⟩=12YX⟨Z,Z⟩−⟨∇XZ,∇YZ⟩\langle\nabla_{Y}\nabla_{X}Z,Z\rangle = \frac{1}{2}YX\langle Z,Z\rangle-\langle\nabla_{X}Z,\nabla_{Y}Z\rangle⟨∇Y​∇X​Z,Z⟩=21​YX⟨Z,Z⟩−⟨∇X​Z,∇Y​Z⟩，而 ⟨∇[X,Y]Z,Z⟩=12[X,Y]⟨Z,Z⟩\langle\nabla_{[X,Y]}Z,Z\rangle = \frac{1}{2}[X,Y]\langle Z,Z\rangle⟨∇[X,Y]​Z,Z⟩=21​[X,Y]⟨Z,Z⟩。三项相减：二阶项合成 12(XY−YX−[X,Y])⟨Z,Z⟩=0\frac{1}{2}\bigl(XY-YX-[X,Y]\bigr)\langle Z,Z\rangle = 021​(XY−YX−[X,Y])⟨Z,Z⟩=0，两个内积项相消。再把 ⟨R(X,Y)(Z+W),Z+W⟩=0\langle R(X,Y)(Z+W),Z+W\rangle = 0⟨R(X,Y)(Z+W),Z+W⟩=0 展开，即得 ⟨R(X,Y)Z,W⟩=−⟨R(X,Y)W,Z⟩\langle R(X,Y)Z,W\rangle = -\langle R(X,Y)W,Z\rangle⟨R(X,Y)Z,W⟩=−⟨R(X,Y)W,Z⟩。

    (3) 第一比安基（用无挠）。记 ∇2Z(X,Y):=∇X∇YZ−∇∇XYZ\nabla^{2}Z(X,Y) := \nabla_{X}\nabla_{Y}Z-\nabla_{\nabla_{X}Y}Z∇2Z(X,Y):=∇X​∇Y​Z−∇∇X​Y​Z。无挠给 ∇XY−∇YX=[X,Y]\nabla_{X}Y-\nabla_{Y}X = [X,Y]∇X​Y−∇Y​X=[X,Y]，于是

    ∇2Z(X,Y)−∇2Z(Y,X)=∇X∇YZ−∇Y∇XZ−∇[X,Y]Z=R(X,Y)Z,\nabla^{2}Z(X,Y)-\nabla^{2}Z(Y,X) = \nabla_{X}\nabla_{Y}Z-\nabla_{Y}\nabla_{X}Z-\nabla_{[X,Y]}Z = R(X,Y)Z ,∇2Z(X,Y)−∇2Z(Y,X)=∇X​∇Y​Z−∇Y​∇X​Z−∇[X,Y]​Z=R(X,Y)Z,

    而 ∇2Z\nabla^{2}Z∇2Z 关于 X,YX,YX,Y 对称。对三个变元做循环求和时，两个对称项互换位置、逐项抵消，故 R(X,Y)Z+R(Y,Z)X+R(Z,X)Y=0R(X,Y)Z+R(Y,Z)X+R(Z,X)Y = 0R(X,Y)Z+R(Y,Z)X+R(Z,X)Y=0。

    (4) 两对指标可交换：把 (3) 的三种循环取法写出、用 (1)(2) 把符号搬正再相加，剩下的正是 Rijkℓ−RkℓijR_{ijk\ell}-R_{k\ell ij}Rijkℓ​−Rkℓij​（这一条是纯指标记账，不含几何）。

    计数：(1)(2) 说明 RRR 可看成 ⋀2TpM\bigwedge^{2}T_{p}M⋀2Tp​M 上的双线性型，(4) 说明它对称，故有 N(N+1)2\frac{N(N+1)}{2}2N(N+1)​ 个分量（N=(n2)N = \binom{n}{2}N=(2n​)）；再扣掉 (3) 给出的 (n3)\binom{n}{3}(3n​) 个独立关系，得 n2(n2−1)12\frac{n^{2}(n^{2}-1)}{12}12n2(n2−1)​。∎
