# Regular Value Theorem　`thm.regular-value`
English entry · root `../`
[in graph](../#n=thm.regular-value)　·　[Chinese page (authoritative)](./thm.regular-value.md)

If $c$ is a regular value and $f^{-1}(c) \ne \emptyset$, then $f^{-1}(c)$ is a **submanifold** of $\mathbb{R}^{n}$ of dimension $n - m$: near each point it is the **graph of a $C^{1}$ function** (equivalently, near each point $m$ independent equations "solve for" $m$ coordinates). ⚠ Only $f \in C^{1}$ is assumed here, so what results is a **$C^{1}$ submanifold**; if $f$ is $C^{\infty}$, the same argument gives a $C^{\infty}$ submanifold (the usual statement of the regular value theorem silently assumes smoothness).
