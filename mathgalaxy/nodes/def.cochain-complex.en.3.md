# cochain complex　`def.cochain-complex`
English entry · root `../`
[in graph](../#n=def.cochain-complex)　·　[Chinese page (authoritative)](./def.cochain-complex.md)

Example: when $K$ is a (semi)simplicial object, put $d^{n} := \sum_{i} (-1)^{i} d_{i}^{n}$; then $K$ is a chain complex — the sign $(-1)^{i}$ is exactly what makes consecutive composites cancel, in complete agreement with the classical simplicial boundary operator.
