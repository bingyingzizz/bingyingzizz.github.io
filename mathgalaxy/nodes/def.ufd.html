唯一分解整环（UFD）：分解存在且唯一

def.ufd · 代数 · 环论 · 唯一分解

又称唯一分解整环·UFD

陈述

整环 AAA 叫唯一分解整环（UFD），若

  1. 存在性：每个非零非单位元 aaa 都能写成有限多个不可约元的乘积；
  2. 唯一性：两个这样的分解只差次序与相伴（即把因子逐个配对成相伴元）。

说明

Z\mathbb{Z}Z 与 K[x]K[x]K[x] 都是 UFD（后者见 thm.poly-ufd），而 Z[−5]\mathbb{Z}[\sqrt{-5}]Z[−5​] 不是：

6=2⋅3=(1+−5)(1−−5),6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5}),6=2⋅3=(1+−5​)(1−−5​),

四个因子都不可约，且互不相伴 —— 所以分解不唯一。

UFD 的三个判别性质：①「不可约 = 素」（def.irreducible-element）；② 任意两元素有 gcd⁡\gcdgcd（def.gcd-domain）；③ 没有「无限下降的因子链」。三者都等价于唯一分解。

层级（imp.ring-euclid-pid / imp.ring-pid-ufd）：Euclid 整环   ⟹  \implies⟹ PID   ⟹  \implies⟹ UFD   ⟹  \implies⟹ gcd 整环，两个箭头都不可逆（Z[−5]\mathbb{Z}[\sqrt{-5}]Z[−5​] 连 gcd 都没有；存在 UFD 不是 PID，如 K[x,y]K[x, y]K[x,y]）。

  • 本页 ⟹ gcd 整环推出
    UFD   ⟹  \implies⟹ gcd 整环：取公共素因子指数的最小值

    设 AAA 是 UFD，a,ba, ba,b 非零。把两者写成不可约元的乘积，按相伴类归并：

    a∼∏ipi mi,b∼∏ipi ni.a \sim \prod_{i} p_{i}^{\,m_{i}}, \qquad b \sim \prod_{i} p_{i}^{\,n_{i}} .a∼i∏​pimi​​,b∼i∏​pini​​.

    （只保留在两者中至少一个里出现的 pip_{i}pi​。）

    令 d:=∏ipi min⁡(mi,ni)d := \prod_{i} p_{i}^{\,\min(m_{i}, n_{i})}d:=∏i​pimin(mi​,ni​)​。则 d∣ad \mid ad∣a 且 d∣bd \mid bd∣b，故 ddd 是公因子。

    反之设 c∣ac \mid ac∣a、c∣bc \mid bc∣b。把 ccc 分解，每个不可约因子 q∣cq \mid cq∣c 都整除 aaa，而 UFD 里不可约即素，故 qqq 与某个 pip_{i}pi​ 相伴，且它在 ccc 里的重数 ≤min⁡(mi,ni)\le \min(m_{i}, n_{i})≤min(mi​,ni​)。于是 c∣dc \mid dc∣d。

    所以 ddd 是「被一切公因子整除」的那个公因子 —— 即 gcd⁡\gcdgcd。UFD 是 gcd 整环。

推出 1

  • 主理想整环 ⟹ 本页推出
    PID   ⟹  \implies⟹ UFD：升链条件给存在性，不可约=素给唯一性

    存在性（分解不能无限细）：若某个非零非单位元 aaa 写不成有限乘积，则可写 a=a1b1a = a_{1}b_{1}a=a1​b1​ 且两者都非单位，对其一继续拆 —— 得到严格上升的理想链 (a)⊂(a1)⊂(a2)⊂⋯(a) \subset (a_{1}) \subset (a_{2}) \subset \cdots(a)⊂(a1​)⊂(a2​)⊂⋯。其并 I=⋃(ai)I = \bigcup (a_{i})I=⋃(ai​) 是理想，PID 给出 I=(d)I = (d)I=(d)，于是 d∈(an)d \in (a_{n})d∈(an​) 对某个 nnn 成立，链在 nnn 停止 —— 与「能无限拆」矛盾。

    不可约 = 素（PID 里）：设 ppp 不可约且 p∣abp \mid abp∣ab。理想 (p,a)(p, a)(p,a) 是主理想，记作 (d)(d)(d)，则 d∣pd \mid pd∣p；ppp 不可约给出 d∼1d \sim 1d∼1 或 d∼pd \sim pd∼p。若 d∼pd \sim pd∼p，则 p∣ap \mid ap∣a，完事；若 d∼1d \sim 1d∼1，则 (p,a)=A(p, a) = A(p,a)=A，写 1=up+va1 = up + va1=up+va，乘 bbb 得 b=upb+vabb = upb + vabb=upb+vab，而 p∣abp \mid abp∣ab，故 p∣bp \mid bp∣b。

    唯一性：两个分解的素因子逐个用「素元整除乘积必整除某个因子」配对，约掉后归纳即得。所以 PID 是 UFD。
