Statement

A topological space XXX is second countable if its topology has a countable base: there is a countable family B={ Bn }n≥1\mathcal{B} = \{\, B_{n} \,\}_{n \ge 1}B={Bn​}n≥1​ such that every open set is a union of members of B\mathcal{B}B.

Notes

It yields three good properties at once: second countable   ⟹  \implies⟹ separable (choose one point from each nonempty basic element; the result is a countable dense set); second countable   ⟹  \implies⟹ Lindelöf (every open cover has a countable subcover, by filtering basic elements);

second countable   ⟹  \implies⟹ first countable (at each point, filter the countably many basic elements containing it).

With regularity it also yields normality — this is the first step of the Urysohn metrization theorem.

For metrizable spaces the three countability properties coincide: separable   ⟺  \iff⟺ Lindelöf   ⟺  \iff⟺ second countable. Hence the Urysohn theorem can also be read as "regular +++ separable".

Heredity: subspaces inherit second countability (intersect basic elements with the subspace; still countable); quotient spaces do not (the quotient map crushes a countable base into a much coarser topology).

⚠️ The converse fails: an uncountable discrete space is first countable and metrizable, but not second countable (it has no countable dense subset).

The relations with first countability and separability are one-way (this is the group of implications most often reversed):

  • Second countable   ⟹  \implies⟹ first countable: a countable base itself gives a countable local base at each point. No extra hypothesis is needed.
  • Second countable   ⟹  \implies⟹ separable: choose one point from each basic element to obtain a countable dense set. ⚠️ This step uses countable choice (skip empty basic elements; usually harmless).
  • Separable ̸  ⟹  \not\implies⟹ second countable: the Sorgenfrey line is a counterexample (separable and first countable, but not second countable).
  • Separable + metrizable   ⟹  \implies⟹ second countable: this is what makes second countability equivalent to separability in metric spaces; the proof uses metrizability (take a countable dense set and balls of radius 1/n1/n1/n).

⚠️ In one sentence: second countability is "global countability", first countability is "local countability"; in metric spaces both are equivalent to separability, in general topology they are not.
