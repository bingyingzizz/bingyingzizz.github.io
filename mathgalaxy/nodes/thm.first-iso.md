# 第一同构定理（Noether）　`thm.first-iso`
第一同构定理

设 $\varphi : G \to G'$ 是**群同态**。则 $\varphi$ 诱导出同构

$$G \big/ \ker\varphi \;\cong\; \operatorname{im}\varphi, \qquad g \ker\varphi \;\longmapsto\; \varphi(g).$$
