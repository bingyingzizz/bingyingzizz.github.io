# base change for the exceptional inverse image　`prop.f-shriek-base-change`
English entry · root `../`
[in graph](../#n=prop.f-shriek-base-change)　·　[Chinese page (authoritative)](./prop.f-shriek-base-change.md)

Let $f : R \to A$ be a ring map of finite type and finite Tor dimension (base change between Noetherian rings). Then the natural map

$$f^!R \otimes^{L}_{A_\blacksquare} f^* \longrightarrow f^!$$

is an equivalence of functors. If $g : R \to S$ is flat and $f' : S \to B = A \otimes_R S$ is the base change ($g' : A \to B$), then

$$g'^* f^! \;\simeq\; f'^! g^* : D(R_\blacksquare) \longrightarrow D(B_\blacksquare).$$

## Notes · **draft**
⭐ Reading: **$f^!$ is "$f^*$ twisted by $f^!R$"**.

So to compute $f^!$, it suffices to compute $f^!R$ (the dualizing complex).
