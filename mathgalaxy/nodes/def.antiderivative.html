F′(x)=f(x)(∀x∈I).F'(x) = f(x) \qquad (\forall x \in I).F′(x)=f(x)(∀x∈I).

若 FFF 是一个原函数，则 fff 的全部原函数恰好是 {F+C:C∈R}\{ F + C : C \in \mathbb{R} \}{F+C:C∈R}。

说明

⭐ 为什么「全部」只差常数：若 F′=G′=fF' = G' = fF′=G′=f，则 (F−G)′=0(F - G)' = 0(F−G)′=0，由中值定理（Lagrange 中值定理）F−GF - GF−G 是常数。这一步是「不定积分」这个记号 ∫f dx=F+C\int f\,\mathrm{d}x = F + C∫fdx=F+C 的全部依据。

⭐ 存在性不是白给的：fff 连续时一定有原函数 —— 取 F(x)=∫axfF(x) = \int_{a}^{x} fF(x)=∫ax​f，就是变上限积分的导数（变上限积分的导数）。而不连续的函数可能没有原函数（有第一类间断点的导数不存在原函数：导函数不能有跳跃间断）。

⚠ 「原函数」与「定积分」是两件事：原函数是一个函数（差一个常数），定积分是一个数；把它们粘起来的是微积分基本定理。
