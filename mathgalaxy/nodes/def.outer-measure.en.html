Abstract

An outer measure on a non-empty set XXX is a function μ∗:P(X)→[0,+∞]\mu^ : \mathcal{P}(X) \to [0, +\infty]μ∗:P(X)→[0,+∞] with μ∗(∅)=0\mu^(\emptyset) = 0μ∗(∅)=0 that is monotone and countably subadditive. It is defined on every subset, and the price is exactly that subadditivity: it is not a measure. Carathéodory's idea is to single out the sets on which μ∗\mu^μ∗ is additive, and there it becomes a genuine measure. Lebesgue's original construction, μ∗(A)=inf⁡∑(bn−an)\mu^(A) = \inf \sum (b_n - a_n)μ∗(A)=inf∑(bn​−an​) over countable interval covers, is the prototypical example.

Statement

Let XXX be a non-empty set. A function μ∗:P(X)→[0,+∞]\mu^* : \mathcal{P}(X) \to [0, +\infty]μ∗:P(X)→[0,+∞] is an outer measure iff

  • μ∗(∅)=0\mu^*(\emptyset) = 0μ∗(∅)=0
  • Monotone: A⊆B  ⟹  μ∗(A)≤μ∗(B)A \subseteq B \implies \mu^(A) \le \mu^(B)A⊆B⟹μ∗(A)≤μ∗(B)
  • Countably subadditive: μ∗(⋃j=1∞Aj)≤∑j=1∞μ∗(Aj)\mu^( \bigcup_{j=1}^{\infty} A_j ) \le \sum_{j=1}^{\infty} \mu^(A_j)μ∗(⋃j=1∞​Aj​)≤∑j=1∞​μ∗(Aj​)

Notes

An outer measure is defined on all subsets (P(X)\mathcal{P}(X)P(X), not on some σ\sigmaσ-algebra); the price is that it only has subadditivity.

So an outer measure is not a measure — it is too large even to be additive on P(X)\mathcal{P}(X)P(X). Carathéodory's idea is to single out the sets that "behave well" (the next definition); on those the outer measure does become a genuine measure.

What Lebesgue first constructed was an outer measure: μ∗(A)=inf⁡{∑(bn−an):A⊆⋃(an,bn)}\mu^{*}(A) = \inf\{ \sum (b_{n} - a_{n}) : A \subseteq \bigcup (a_{n}, b_{n}) \}μ∗(A)=inf{∑(bn​−an​):A⊆⋃(an​,bn​)}.Which of the three conditions is "hard" (the three are asymmetric — one is normalisation, one is almost free, one is a real condition):

  • μ∗(∅)=0\mu^{}(\emptyset) = 0μ∗(∅)=0: normalisation, there only so that 0≤μ∗0 \le \mu^{}0≤μ∗ below is meaningful (otherwise the constant +∞+\infty+∞ would satisfy the other two).
  • Monotonicity: almost free, but deriving it uses countable subadditivity: B=A∪(B∖A)B = A \cup (B \setminus A)B=A∪(B∖A)   ⟹  \implies⟹ μ∗(B)≤μ∗(A)+μ∗(B∖A)\mu^{}(B) \le \mu^{}(A) + \mu^{*}(B\setminus A)μ∗(B)≤μ∗(A)+μ∗(B∖A); monotonicity is usually listed as an axiom to save that step, and in a concrete construction (Carathéodory) it is verified directly.
  • Countable subadditivity: this is the real condition, the only one with content — it ties "the size of one set" to "countable operations". ⚠ Note that it is an inequality: an outer measure is not additive (additivity on disjoint unions is what makes it a measure, and that is an extra conclusion on Carathéodory-measurable sets).

Two distinctions that must stay separate:

  • An outer measure is defined on P(X)\mathcal{P}(X)P(X) (all subsets), whereas a measure (测度) is defined only on a σ\sigmaσ-algebra — that is the whole point of an outer measure as a construction device: first put a crude "size" on all subsets, then single out the subsets on which it is additive.
  • Monotone plus countably subadditive does not say "the value on a countable union is the limit": on increasing unions an outer measure only guarantees μ∗(⋃An)≤lim⁡μ∗(An)\mu^{}(\bigcup A_{n}) \le \lim \mu^{}(A_{n})μ∗(⋃An​)≤limμ∗(An​); equality needs continuity from below, hence measurability — exactly what the Carathéodory condition supplies.

⚠ Notation: the star in μ∗\mu^{}μ∗ means "defined on P(X)\mathcal{P}(X)P(X)", not "dual of something". Some books write m∗m^{}m∗ or ν∗\nu^{*}ν∗.
