陈述

设 A\mathcal{A}A 是阿贝尔范畴，P∈AP \in \mathcal{A}P∈A 是投射对象，M∈AM \in \mathcal{A}M∈A 任意。则

Ext⁡An(P, M)=0(n>0),Ext⁡A0(P, M)=Hom⁡A(P, M).\operatorname{Ext}^{n}_{\mathcal{A}}(P,\ M) = 0 \qquad (n > 0), \qquad \operatorname{Ext}^{0}_{\mathcal{A}}(P,\ M) = \operatorname{Hom}_{\mathcal{A}}(P,\ M).ExtAn​(P, M)=0(n>0),ExtA0​(P, M)=HomA​(P, M).

注意：这句话不需要 A\mathcal{A}A 有足够多投射对象 —— PPP 投射本身就给出 PPP 的一条长度 000 的投射消解。

说明

证明。 PPP 投射意味着函子 Hom⁡A(P,−)\operatorname{Hom}_{\mathcal{A}}(P, -)HomA​(P,−) 正合 ✓。而 PPP 的投射消解可以取成

⋯→0→0→P→ 1 P→0,\cdots \to 0 \to 0 \to P \xrightarrow{\ 1\ } P \to 0,⋯→0→0→P 1 ​P→0,

即「长度 000 的消解」（PPP 自己就是投射的，不需要再找覆盖）✓。把 Hom⁡(P,−)\operatorname{Hom}(P, -)Hom(P,−) 作用在 MMM 的内射消解 M→I∙M \to I^{\bullet}M→I∙ 上：因为 Hom⁡(P,−)\operatorname{Hom}(P,-)Hom(P,−) 正合、M→I∙M \to I^{\bullet}M→I∙ 正合，复形 Hom⁡(P,I∙)\operatorname{Hom}(P, I^{\bullet})Hom(P,I∙) 只可能在 000 次有上同调 ✓，即

RnHom⁡(P,M)=Ext⁡n(P,M)=0(n>0)✓R^{n}\operatorname{Hom}(P, M) = \operatorname{Ext}^{n}(P, M) = 0 \quad (n > 0) ✓RnHom(P,M)=Extn(P,M)=0(n>0)✓

（也可以直接从 RHom⁡(P,M)=Hom⁡(P,M)\operatorname{RHom}(P, M) = \operatorname{Hom}(P, M)RHom(P,M)=Hom(P,M) 这件事读出来：正合函子的右导出函子就是它自己。）∎

⭐ 对偶地：内射对象没有高次 Ext（Ext⁡n(M,I)=0\operatorname{Ext}^{n}(M, I) = 0Extn(M,I)=0，n>0n>0n>0）—— 这两条合起来就是「投射 / 内射对象可以拿来替代消解里的项」的全部理由。
