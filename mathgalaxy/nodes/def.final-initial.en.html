Statement

In a category C\mathcal{C}C, the terminal object 1C\mathbf{1}_{\mathcal{C}}1C​ is the limit of the empty diagram ∅→C\emptyset \to \mathcal{C}∅→C, and the initial object 0C\mathbf{0}_{\mathcal{C}}0C​ is its colimit. In terms of hom-sets:

Hom⁡C(X,1C)={∗},Hom⁡C(0C,X)={∗}\operatorname{Hom}_{\mathcal{C}}(X, \mathbf{1}_{\mathcal{C}}) = \{*\}, \qquad \operatorname{Hom}_{\mathcal{C}}(\mathbf{0}_{\mathcal{C}}, X) = \{*\}HomC​(X,1C​)={∗},HomC​(0C​,X)={∗}

(for every object XXX there is exactly one morphism). When both exist and are isomorphic, the object is called a zero object.

Notes

Examples: in Set\mathbf{Set}Set, 0=∅\mathbf{0} = \emptyset0=∅ (the only map into XXX is the empty map) and 1={∅}\mathbf{1} = \{\emptyset\}1={∅} (the map into a singleton is unique). The same holds in Top\mathbf{Top}Top. In Ab\mathbf{Ab}Ab both are {0}\{0\}{0}.

At the other end: Z\mathbb{Z}Z is the initial object of the category of rings — every ring has a unique Z→R\mathbb{Z} \to RZ→R. So saying that Z\mathbb{Z}Z is "universal among all rings" is precisely this.
