陈述

设 ∼\sim∼ 是集合 AAA 上的一个等价关系。对 a∈Aa \in Aa∈A，称

[a]:={b∈A:b∼a}[a] := \{ b \in A : b \sim a \}[a]:={b∈A:b∼a}

为 aaa 的等价类；称

A/∼ :={[a]:a∈A}A / \sim\ := \{ [a] : a \in A \}A/∼ :={[a]:a∈A}

为 AAA 关于 ∼\sim∼ 的商集。三条基本事实：

  • a∈[a]a \in [a]a∈[a]；
  • [a]=[b]  ⟺  a∼b[a] = [b] \iff a \sim b[a]=[b]⟺a∼b；
  • 不同的等价类两两不交，且全体之并恰为 AAA —— 也就是说，等价关系把 AAA 划分成一块块。

说明

⭐ 这是数学里「造新对象」最常用的手法：手头只有一类东西，却想得到另一类，就把前者按某个等价关系粘起来。本星图里至少四处用到：

  • Z=(N×N)/∼\mathbb{Z} = (\mathbb{N} \times \mathbb{N})/\simZ=(N×N)/∼、Q=(Z×(Z∖{0}))/∼\mathbb{Q} = (\mathbb{Z} \times (\mathbb{Z}\setminus\{0\}))/\simQ=(Z×(Z∖{0}))/∼、R={\mathbb{R} = \{R={有理 Cauchy 列}/∼\}/\sim}/∼；
  • L1L^1L1、LpL^pLp 的元素其实是函数的等价类（a.e. 相等视为同一个）；
  • RN 导数 dν/dμd\nu/d\mudν/dμ 也是一个等价类，而不是单个函数。

⚠ 等价类的代表元不唯一，所以凡是要在商集上定义的东西（运算、序、范数），都必须先证明「与代表元的选取无关」，也就是良定义。这是商构造最容易漏掉的一步。
