# Riemann's Removable Singularity Theorem　`thm.riemann-removable`
English entry · root `../`
[in graph](../#n=thm.riemann-removable)　·　[Chinese page (authoritative)](./thm.riemann-removable.md)

For example $\sin z / z$ extends at $0$ to $1$, so $\sin z / z$ is entire;

the order of vanishing of $z^k f(z)$, and "a holomorphic function near a zero can be written as $(z - a)^k \psi(z)$", both rely on it.

⚠ Formally this is weaker than "bounded" (it only requires $(z - a)f(z) \to 0$); but for $f$ **holomorphic on a punctured neighbourhood**, the theorem gives "removable $\implies$ locally bounded", so the two conditions are in fact **equivalent**.

What is genuinely non-removable is a rate like $1/(z - a)$ — that is a pole.
