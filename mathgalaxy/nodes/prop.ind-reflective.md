# C 是 Ind(C) 的反射子范畴　`prop.ind-reflective`
$\mathcal{C} \hookrightarrow \operatorname{Ind}(\mathcal{C})$ 是反射
layer 12 · 命题 · 图与极限 · 范畴论

若 $\mathcal{C}$ 有滤过余极限，则 $\mathcal{C}$ 是 $\operatorname{Ind}(\mathcal{C})$ 的**反射子范畴**。
