# natural transformation　`def.natural-transformation`
English entry · root `../`
[in graph](../#n=def.natural-transformation)　·　[Chinese page (authoritative)](./def.natural-transformation.md)

the set of all natural transformations $F \implies G$ is denoted $\operatorname{Nat}(F, G)$.

Example: there are two functors $\mathbf{CRng} \to \mathbf{Grp}$ — $A \mapsto GL_n(A)$ and $A \mapsto A^{*}$. The determinant

$$\det_A : GL_n(A) \to A^{*}$$

assembles into a **natural transformation**: $\det$ "commutes with" ring homomorphisms. This is exactly what "natural" means — not a coincidence verified case by case, but forced by structure.
