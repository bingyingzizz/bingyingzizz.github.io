## Notes · **draft**
The action is well defined because $\otimes$ is bilinear and $\rho(g),\sigma(g)$ are linear. Its dimension is $(\dim V)(\dim W)$. The character satisfies $\chi_{V\otimes W}(g)=\chi_V(g)\chi_W(g)$, see the node on character operations. For a general algebra $A$, $V\otimes W$ is only an $A\otimes A$-module unless $A$ is a bialgebra; the group algebra $F[G]$ is the main case here.
