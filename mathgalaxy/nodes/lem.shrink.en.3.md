Moreover, $x \notin \mathcal{W}_{i^{+}}$ implies $x \notin V_{j}$ ($j < i$) and $x \notin U_{k}$ ($k > i$), so the invariant forces $x$ to lie in $U_{i}$. Hence $A_{i} \subseteq U_{i}$.

Apply normality to the disjoint closed sets $A_{i}$ and $X \setminus U_{i}$ to obtain an open set $V_{i}$ such that $A_{i} \subseteq V_{i}$ and $\overline{V_{i}} \subseteq U_{i}$. This is the standard reformulation of normality: between a closed set and an open set containing it, there is an open set whose closure still lies in the larger open set.

Thus $\mathcal{W}_{i^{+}}$ still covers $X$.
