# Cauchy Integral Formula　`thm.cauchy-integral-formula`
English entry · root `../`
[in graph](../#n=thm.cauchy-integral-formula)　·　[Chinese page (authoritative)](./thm.cauchy-integral-formula.md)

**Split off the main term**: on the right, write the integrand as $\frac{f(\zeta)}{\zeta - z} = \frac{f(z)}{\zeta - z} + \frac{f(\zeta) - f(z)}{\zeta - z}.$. The integral of the first term is computed directly with $\zeta = z + re^{i\theta}$: $\oint_{|\zeta - z| = r} \frac{\mathrm{d}\zeta}{\zeta - z} = \int_{0}^{2\pi} \frac{ire^{i\theta}}{re^{i\theta}}\,\mathrm{d}\theta = 2\pi i$, hence contributes $2\pi i\,f(z)$.
