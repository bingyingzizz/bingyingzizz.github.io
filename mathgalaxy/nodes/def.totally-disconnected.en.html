Statement

A topological space XXX is called totally disconnected if every connected component is a single point.

It is called extremally disconnected if the closure of every open set is again open.

Notes

⚠️ The two names differ by one word, and their strengths are opposite:

  • totally disconnected says "shattered until every component is a single point";
  • extremally disconnected says "the closure of an open set no longer grows" — the latter is stronger.

The demand side for extremally disconnected is Haskell / set theory / condensed mathematics: it is the geometric shape of "projective objects" (Gleason's theorem: the projective objects of CHaus\mathbf{CHaus}CHaus are exactly the Stonean spaces).

⭐ In the compact Hausdorff world the three line up in a chain: extremally disconnected   ⟹  \implies⟹ totally disconnected; totally disconnected + compact Hausdorff   ⟺  \iff⟺ profinite; extremally disconnected + compact Hausdorff   ⟹  \implies⟹ Stonean.

Examples: the Cantor set 2N2^{\mathbb{N}}2N is totally disconnected but not extremally disconnected; βN\beta\mathbb{N}βN (the Stone–Čech compactification of N\mathbb{N}N) is extremally disconnected; βN∖N\beta\mathbb{N} \setminus \mathbb{N}βN∖N is an extreme example of it.
