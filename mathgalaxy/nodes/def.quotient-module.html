Statement draft

Let AAA be a ring with identity, MMM an AAA-module and N⊆MN \subseteq MN⊆M a submodule. On the additive quotient group M/NM/NM/N define

(m+N)+(m′+N):=(m+m′)+N,a(m+N):=am+N.(m + N) + (m' + N) := (m + m') + N, \qquad a(m + N) := a m + N .(m+N)+(m′+N):=(m+m′)+N,a(m+N):=am+N.

These operations are well defined and make M/NM/NM/N an AAA-module, the quotient module; the quotient map π:M→M/N\pi : M \to M/Nπ:M→M/N is a module homomorphism with ker⁡π=N\ker \pi = Nkerπ=N.

Universal property: if f:M→Lf : M \to Lf:M→L is a module homomorphism with f(N)=0f(N) = 0f(N)=0, then there is a unique module homomorphism fˉ:M/N→L\bar f : M/N \to Lfˉ​:M/N→L with fˉ∘π=f\bar f \circ \pi = ffˉ​∘π=f.

Notes draft

⭐ Why a submodule is necessary: for a(m+n)≡am(modN)a(m + n) \equiv a m \pmod Na(m+n)≡am(modN) one needs an∈Na n \in Nan∈N for all a∈Aa \in Aa∈A and n∈Nn \in Nn∈N.

⭐ Examples: the Z\mathbb{Z}Z-module Z/nZ\mathbb{Z}/n\mathbb{Z}Z/nZ; a vector space V/WV/WV/W; A/IA/IA/I as an AAA-module is a quotient module.

⭐ First isomorphism: M/ker⁡f≅im⁡fM/\ker f \cong \operatorname{im} fM/kerf≅imf, see 模同态.
