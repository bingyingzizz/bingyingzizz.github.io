Statement

Let VVV be a finite-dimensional indecomposable representation. Then End⁡A(V)\operatorname{End}_A(V)EndA​(V) is a local ring whose maximal ideal is exactly the set of nilpotent endomorphisms.

Notes

By cor.indecomposable-endomorphism, any fff that is not an automorphism is nilpotent, so the non-units are exactly the nilpotent elements. If fff is nilpotent then id⁡−f\operatorname{id}-fid−f is invertible (inverse given by a finite geometric series); hence the nilpotent elements form a two-sided ideal whose quotient is a division ring, so the ring is local. Conversely, any non-invertible fff is nilpotent, so the maximal ideal is exactly the nilpotent elements.
