## Notes · **draft**
⭐ This “basic fact” is the **cancellation theory** of all finite-dimensional linear algebra: isomorphism classes are determined by dimension alone, so there is only one “$n$-dimensional vector space” up to isomorphism.

Thus studying all finite-dimensional vector spaces amounts to studying all $K^{n}$.
