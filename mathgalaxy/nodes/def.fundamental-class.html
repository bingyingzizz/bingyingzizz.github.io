设 XXX 是集合，A⊆P(X)\mathfrak{A} \subseteq \mathcal{P}(X)A⊆P(X)。A\mathfrak{A}A 是 XXX 上的一个基本类，当且仅当

  • 对交封闭：A,B∈A  ⟹  A∩B∈AA, B \in \mathfrak{A} \implies A \cap B \in \mathfrak{A}A,B∈A⟹A∩B∈A
  • 差可以拆开：A,B∈A  ⟹  A∖BA, B \in \mathfrak{A} \implies A \setminus BA,B∈A⟹A∖B 是 A\mathfrak{A}A 中有限多个两两不交集合之并

说明

它比「环」弱一档：只要求对交封闭（不是并），而差只要求「能拆成不交并」。

基本类的作用是当砖块：把它的元素做成有限不交并，就得到一个环 —— 这正是下面那条性质 (5)。

典型例子：半开区间族 {(a,b]:a<b}\{ (a, b] : a < b \}{(a,b]:a<b} 是 R\mathbb{R}R 上的基本类；由它做有限不交并得到的，正是构造 Lebesgue–Stieltjes 测度时要用的那个环（不是代数：它不含 X=RX = \mathbb{R}X=R，对补集也不封闭 —— 见 F 给出的预测度）。

各方向用到的假设（基本类给出生成环的砖块，而不是环本身）：

  • 基本类   ⟹  \implies⟹ 交封闭、差可拆为有限不交并：只是定义展开，不要求含全集。
  • 基本类   ⟹  \implies⟹ 有限不交并组成一个环：要反复用交封闭及差的有限分解，把两个表示共同细分；不需要选择公理。
  • 环   ⟹  \implies⟹ 基本类：差本身就是一个元素，分解免费；反向不能省去取有限并这一步，半开区间族一般不对并封闭。
