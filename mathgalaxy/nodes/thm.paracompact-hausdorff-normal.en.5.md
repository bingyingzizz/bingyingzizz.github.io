# Paracompact Hausdorff Spaces Are Normal　`thm.paracompact-hausdorff-normal`

Then $\mathcal{A} := \{\, X \setminus A \,\} \cup \{\, O_{x} : x \in A \,\}$ is an open cover. Take a locally finite open refinement $\mathcal{D}$ and set $U := \bigcup \{\, D \in \mathcal{D} : D \cap A \ne \emptyset \,\}$.

As above, $A \subseteq U$, and each such $D$ lies in some $O_{x}$, giving $\overline{D} \cap B = \emptyset$. Therefore $\overline{U} \cap B = \emptyset$.

Thus $U \supseteq A$ and $X \setminus \overline{U} \supseteq B$ are disjoint open sets separating $A, B$.
