又称道路拼接

陈述

设 α\alphaα 是从 x0x_{0}x0​ 到 x1x_{1}x1​ 的道路、β\betaβ 是从 x1x_{1}x1​ 到 x2x_{2}x2​ 的道路。它们的拼接是「先走 α\alphaα，再走 β\betaβ，各用一半时间」：

(α∗β)(t)=α(2t)(0≤t≤12),(\alpha * \beta)(t) = \alpha(2t) \quad (0 \le t \le \tfrac{1}{2}),(α∗β)(t)=α(2t)(0≤t≤21​),(α∗β)(t)=β(2t−1)(12≤t≤1).(\alpha * \beta)(t) = \beta(2t - 1) \quad (\tfrac{1}{2} \le t \le 1).(α∗β)(t)=β(2t−1)(21​≤t≤1).

由粘贴引理，α∗β\alpha * \betaα∗β 连续，是从 x0x_{0}x0​ 到 x2x_{2}x2​ 的道路。此外记 αˉ(t):=α(1−t)\bar{\alpha}(t) := \alpha(1 - t)αˉ(t):=α(1−t)（反向道路），exe_{x}ex​ 表示常值道路 t↦xt \mapsto xt↦x。则有：

  1. 良定义：α≃pα′\alpha \simeq_{p} \alpha'α≃p​α′ 且 β≃pβ′\beta \simeq_{p} \beta'β≃p​β′   ⟹  \implies⟹ α∗β≃pα′∗β′\alpha \beta \simeq_{p} \alpha' \beta'α∗β≃p​α′∗β′；
  2. 结合律：(α∗β)∗γ≃pα∗(β∗γ)(\alpha \beta) \gamma \simeq_{p} \alpha (\beta \gamma)(α∗β)∗γ≃p​α∗(β∗γ)；
  3. 单位：ex0∗α≃pα≃pα∗ex1e_{x_{0}} \alpha \simeq_{p} \alpha \simeq_{p} \alpha e_{x_{1}}ex0​​∗α≃p​α≃p​α∗ex1​​；
  4. 逆：α∗αˉ≃pex0\alpha \bar{\alpha} \simeq_{p} e_{x_{0}}α∗αˉ≃p​ex0​​ 且 αˉ∗α≃pex1\bar{\alpha} \alpha \simeq_{p} e_{x_{1}}αˉ∗α≃p​ex1​​。

于是「以 x0x_{0}x0​ 为基点的闭道路同伦类」带上乘法 [α][β]:=[α∗β][\alpha][\beta] := [\alpha * \beta][α][β]:=[α∗β] 构成一个群。

说明

⚠️ 这四条都不是道路层面的等式。(α∗β)∗γ(\alpha \beta) \gamma(α∗β)∗γ 与 α∗(β∗γ)\alpha (\beta \gamma)α∗(β∗γ) 在 t=1/4,1/2t = 1/4, 1/2t=1/4,1/2 处的值根本不同；它们只是同伦。所以乘法必须定义在同伦类上。

重参数化是全部技巧：若 φ:[0,1]→[0,1]\varphi : [0, 1] \to [0, 1]φ:[0,1]→[0,1] 连续、φ(0)=0\varphi(0) = 0φ(0)=0、φ(1)=1\varphi(1) = 1φ(1)=1，则 α∘φ≃pα\alpha \circ \varphi \simeq_{p} \alphaα∘φ≃p​α，同伦取 F(t,s):=α((1−s) φ(t)+s t)F(t, s) := \alpha((1 - s)\,\varphi(t) + s\,t)F(t,s):=α((1−s)φ(t)+st)。结合律就是把 φ\varphiφ 取成「按 1/4,1/2,1/41/4, 1/2, 1/41/4,1/2,1/4 分段」的那个重参数化。

⭐ 单位律里那个同伦不能取 F(t,s)=ex0∗αF(t, s) = e_{x_{0}} * \alphaF(t,s)=ex0​​∗α 之类「不动」的东西：单位律是真的要形变，不是等式。

💡 一句话：道路层面的乘法不好（不结合、没单位），同伦类层面的乘法很好（是群）——这就是为什么基本群要收「类」而不是「道路」。
