Statement

Let XXX be a topological space, x∈Xx \in Xx∈X, and AAA an abelian group. If AAA is injective in Ab\mathbf{Ab}Ab (i.e. AAA is a divisible group), then the skyscraper sheaf ix,∗Ai_{x,*}Aix,∗​A is injective in the category of abelian sheaves Ab(X)\mathbf{Ab}(X)Ab(X).

Conversely, if ix,∗Ai_{x,*}Aix,∗​A is injective in Ab(X)\mathbf{Ab}(X)Ab(X), then AAA is injective in Ab\mathbf{Ab}Ab.

Notes

Proof (moving injectivity to the stalk). The key is a natural isomorphism: for every sheaf F\mathcal{F}F,

Hom⁡Ab(X)(F, ix,∗A)  ≅  Hom⁡Ab(Fx, A),\operatorname{Hom}_{\mathbf{Ab}(X)}\bigl(\mathcal{F},\ i_{x,*}A\bigr) \;\cong\; \operatorname{Hom}_{\mathbf{Ab}}\bigl(\mathcal{F}_{x},\ A\bigr),HomAb(X)​(F, ix,∗​A)≅HomAb​(Fx​, A),

coming from the adjunction ix−1⊣ix,∗i_{x}^{-1} \dashv i_{x,*}ix−1​⊣ix,∗​ and "ix−1F=Fxi_{x}^{-1}\mathcal{F} = \mathcal{F}_{x}ix−1​F=Fx​".

Injectivity must be tested as: for every injective sheaf map G↣H\mathcal{G} \rightarrowtail \mathcal{H}G↣H, the map Hom⁡(H,ix,∗A)→Hom⁡(G,ix,∗A)\operatorname{Hom}(\mathcal{H}, i_{x,*}A) \to \operatorname{Hom}(\mathcal{G}, i_{x,*}A)Hom(H,ix,∗​A)→Hom(G,ix,∗​A) is surjective.

Using the isomorphism above, this is equivalent to

Hom⁡Ab(Hx, A)⟶Hom⁡Ab(Gx, A)\operatorname{Hom}_{\mathbf{Ab}}(\mathcal{H}_{x},\ A) \longrightarrow \operatorname{Hom}_{\mathbf{Ab}}(\mathcal{G}_{x},\ A)HomAb​(Hx​, A)⟶HomAb​(Gx​, A)

being surjective. Taking stalks is a filtered colimit and exact, so Gx↣Hx\mathcal{G}_{x} \rightarrowtail \mathcal{H}_{x}Gx​↣Hx​ is an injection of abelian groups; AAA is injective, so the displayed map is surjective. ∎

Converse: let B↣CB \rightarrowtail CB↣C be an injection in Ab\mathbf{Ab}Ab together with a map B→AB \to AB→A.

ix,∗i_{x,*}ix,∗​ is exact, so ix,∗B↣ix,∗Ci_{x,*}B \rightarrowtail i_{x,*}Cix,∗​B↣ix,∗​C is an injection of sheaves;

ix,∗Ai_{x,*}Aix,∗​A is injective, so Hom⁡(ix,∗C,ix,∗A)→Hom⁡(ix,∗B,ix,∗A)\operatorname{Hom}(i_{x,*}C, i_{x,*}A) \to \operatorname{Hom}(i_{x,*}B, i_{x,*}A)Hom(ix,∗​C,ix,∗​A)→Hom(ix,∗​B,ix,∗​A) is surjective, and under the same adjunction isomorphism this is precisely the lift of Hom⁡(C,A)→Hom⁡(B,A)\operatorname{Hom}(C, A) \to \operatorname{Hom}(B, A)Hom(C,A)→Hom(B,A) — hence the latter is surjective and AAA is injective.

∎

Why AAA must be divisible: in Ab\mathbf{Ab}Ab, injective === divisible. For A=ZA = \mathbb{Z}A=Z the skyscraper sheaf is not injective (Z↣Q\mathbb{Z} \rightarrowtail \mathbb{Q}Z↣Q cannot be lifted), so building injective sheaves requires first enlarging each stalk with an injective hull.
