陈述

凝聚态集是 CHaus\mathbf{CHaus}CHaus 上的（集合值）层。其范畴记

Cond  :=  CHaus^\mathrm{Cond} \;:=\; \widehat{\mathbf{CHaus}}Cond:=CHaus

这里 CHaus\mathbf{CHaus}CHaus 配的是它的预标准拓扑。

说明

例 1. 拓扑空间给凝聚态集。 任一拓扑空间 XXX 给出凝聚态集 X‾(S):=C(S,X)=Hom⁡Top(S,X)\underline{X}(S) := C(S, X) = \operatorname{Hom}_{\mathbf{Top}}(S, X)X​(S):=C(S,X)=HomTop​(S,X) —— 从 SSS 到 XXX 的连续映射全体。

例 2. 收敛序列。 取 XXX 是拓扑空间，则 X‾(Nˉ)\underline{X}(\bar{\mathbb{N}})X​(Nˉ) 恰好是「收敛序列 (xn)n≥1(x_{n})_{n \ge 1}(xn​)n≥1​ 连同指定的极限 x∞x_{\infty}x∞​」的集合 —— 这里 Nˉ\bar{\mathbb{N}}Nˉ 是 N\mathbb{N}N 的一点紧化，而「收敛序列连同极限」正好就是从 Nˉ\bar{\mathbb{N}}Nˉ 到 XXX 的连续映射：N\mathbb{N}N 上的像给出序列，新添那个点上的像给出极限。

例 3. 连续函数模掉局部常值函数。 存在唯一的凝聚态集 QQQ 使 Q(S)=C(S,R)/C(S,Rdisc)Q(S) = C(S, \mathbb{R}) / C(S, \mathbb{R}^{\mathrm{disc}})Q(S)=C(S,R)/C(S,Rdisc)。

这三个例子的共同点：取值都是「从紧 Hausdorff 空间出发的连续映射的某种商或子集」。凝聚态集之所以能记住拓扑信息，靠的就是把这些映射全留下来。

推出 1

  • 本页 ⟹ Top 与 Cond 的伴随推出
    Top→Cond\mathbf{Top} \to \mathrm{Cond}Top→Cond 忠实、限制到 kTopk\mathbf{Top}kTop 全忠实

    X‾\underline{X}X​ 是凝聚态集。 对任一点集 SSS，X‾(S)=C(S,X)\underline{X}(S) = C(S, X)X​(S)=C(S,X)；C(−,X)C(-, X)C(−,X) 把 CHaus\mathbf{CHaus}CHaus 里的有限不交并变成有限积、把商变成核（连续映射在无交并上与商上都是逐块决定的）。由凝聚态集的两条判据，X‾\underline{X}X​ 是凝聚态集。∎

    伴随。 函子 X↦X‾X \mapsto \underline{X}X↦X​ 与 Z↦Z(⋅)Z \mapsto Z(\cdot)Z↦Z(⋅) 之间要给出

    Hom⁡Cond(X‾,Z)  ≅  Hom⁡Top(X,Z(⋅))\operatorname{Hom}_{\mathrm{Cond}}(\underline{X}, Z) \;\cong\; \operatorname{Hom}_{\mathbf{Top}}\bigl(X, Z(\cdot)\bigr)HomCond​(X​,Z)≅HomTop​(X,Z(⋅))

    而 Hom⁡Cond(X‾,Z)=Nat⁡(C(−,X),Z)\operatorname{Hom}_{\mathrm{Cond}}(\underline{X}, Z) = \operatorname{Nat}(C(-,X), Z)HomCond​(X​,Z)=Nat(C(−,X),Z)，按米田式的计算，它正是「在 S=∗S = \astS=∗ 处的取值」加上自然性 —— 也就是 Z(⋅)=Z(∗)Z(\cdot) = Z(\ast)Z(⋅)=Z(∗) 上的一个元素，并且与所有 X‾(S)=C(S,X)\underline{X}(S) = C(S,X)X​(S)=C(S,X) 相容。这恰恰是「从 XXX 出发的连续映射」，两边一一对应。∎

    忠实。 由上面的伴随式取 Z=Y‾Z = \underline{Y}Z=Y​：

    Hom⁡Cond(X‾,Y‾)  ≅  Hom⁡Top(X,Y‾(⋅))\operatorname{Hom}_{\mathrm{Cond}}(\underline{X}, \underline{Y}) \;\cong\; \operatorname{Hom}_{\mathbf{Top}}\bigl(X, \underline{Y}(\cdot)\bigr)HomCond​(X​,Y​)≅HomTop​(X,Y​(⋅))

    而关键的一步是：Y‾(⋅)≅kY\underline{Y}(\cdot) \cong kYY​(⋅)≅kY（把 YYY 换成它的 kkk-化，拓扑可能变细）。于是

    Hom⁡Cond(X‾,Y‾)  ≅  Hom⁡Top(X,kY)  ≅  Hom⁡kTop(kX,kY)\operatorname{Hom}_{\mathrm{Cond}}(\underline{X}, \underline{Y}) \;\cong\; \operatorname{Hom}_{\mathbf{Top}}(X, kY) \;\cong\; \operatorname{Hom}_{k\mathbf{Top}}(kX, kY)HomCond​(X​,Y​)≅HomTop​(X,kY)≅HomkTop​(kX,kY)

    （最后一个同构因为 kTopk\mathbf{Top}kTop 是余反射子范畴，kkk 是含入的右伴随：kXkXkX 处的映射等同于一切从 XXX 出发射入紧生成空间的映射。）

    当 XXX 本身紧生成时 kX=XkX = XkX=X，上式就是 Hom⁡Cond(X‾,Y‾)≅Hom⁡kTop(X,kY)\operatorname{Hom}_{\mathrm{Cond}}(\underline{X}, \underline{Y}) \cong \operatorname{Hom}_{k\mathbf{Top}}(X, kY)HomCond​(X​,Y​)≅HomkTop​(X,kY)，逐对 X,YX, YX,Y 都是双射 —— 限制到 kTopk\mathbf{Top}kTop 上全忠实。对一般 XXX，X→kXX \to kXX→kX 是同一集合上的恒等映射，所以函子在态射层仍是单射 —— 在 Top\mathbf{Top}Top 上忠实。∎

    一句话记住：「拓扑空间 →\to→ 凝聚态集」这件事丢掉的东西，正好就是 kkk-化丢掉的东西。 所以在 kTopk\mathbf{Top}kTop 上它不丢信息。
