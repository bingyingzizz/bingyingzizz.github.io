thm.cauchy-criterion · 定理 · 完备性

又称Cauchy 收敛准则

陈述

实数列 {xn}\{x_n\}{xn​} 收敛（到某个实数），当且仅当它是 Cauchy 列。

说明

⭐ 两个方向的分量完全不同：「收敛   ⟹  \implies⟹ Cauchy」只用三角不等式，是平凡的；「Cauchy   ⟹  \implies⟹ 收敛」才是完备性本身 —— 它说的是「自己人互相比就够了的数列，一定有极限等着它」。

⭐ 实用价值：判收敛时不必先猜极限。后面幂级数的收敛半径、函数的完备性、Banach 空间的定义（每个 Cauchy 列都收敛）都是这一条的直系后代。

  • 本页 ⟹ ℝ 是完备度量空间推出
    Cauchy 准则   ⟹  \implies⟹ R\mathbb{R}R 完备

    把 Cauchy 准则的结论逐字翻译成距离空间的语言：R\mathbb{R}R 中的 Cauchy 列（即 ∀ε>0,∃N,∀m,n≥N:d(xm,xn)<ε\forall \varepsilon > 0, \exists N, \forall m, n \ge N : d(x_m, x_n) < \varepsilon∀ε>0,∃N,∀m,n≥N:d(xm​,xn​)<ε）都收敛，这恰恰就是「(R,d)(\mathbb{R}, d)(R,d) 完备」的定义。故不需要新的论证。∎

    这条边的作用是把两套语言对上：序那一侧的「确界原理」与度量那一侧的「完备」在 R\mathbb{R}R 上说的是同一件事。

    实数的 Cauchy 准则   ⟹  \implies⟹ 级数的 Cauchy 准则

  • Bolzano–Weierstrass 定理 ⟹ 本页推出
    Bolzano–Weierstrass   ⟹  \implies⟹ Cauchy 收敛准则

    「  ⟹  \implies⟹」：设 xn→xx_n \to xxn​→x。给定 ε>0\varepsilon > 0ε>0，取 NNN 使 n≥Nn \ge Nn≥N 时 ∣xn−x∣<ε/2|x_n - x| < \varepsilon / 2∣xn​−x∣<ε/2。则 m,n≥Nm, n \ge Nm,n≥N 时

    ∣xm−xn∣≤∣xm−x∣+∣xn−x∣<ε|x_m - x_n| \le |x_m - x| + |x_n - x| < \varepsilon∣xm​−xn​∣≤∣xm​−x∣+∣xn​−x∣<ε

    故 {xn}\{x_n\}{xn​} 是 Cauchy 列。

    「⟸\Longleftarrow⟸」：设 {xn}\{x_n\}{xn​} 是 Cauchy 列。

    1. 先证有界：取 ε=1\varepsilon = 1ε=1 得 N0N_0N0​，使 m,n≥N0m, n \ge N_0m,n≥N0​ 时 ∣xm−xn∣<1|x_m - x_n| < 1∣xm​−xn​∣<1。于是 n≥N0n \ge N_0n≥N0​ 时 ∣xn∣≤∣xN0∣+1|x_n| \le |x_{N_0}| + 1∣xn​∣≤∣xN0​​∣+1，而前 N0−1N_0 - 1N0​−1 项有限，故 {xn}\{x_n\}{xn​} 有界。
    2. 由 Bolzano–Weierstrass，存在子列 xnk→xx_{n_k} \to xxnk​​→x。
    3. 证原列也收敛到 xxx：给定 ε>0\varepsilon > 0ε>0，取 N1N_1N1​ 使 m,n≥N1m, n \ge N_1m,n≥N1​ 时 ∣xm−xn∣<ε/2|x_m - x_n| < \varepsilon / 2∣xm​−xn​∣<ε/2（Cauchy 性），再取 kkk 使 nk≥N1n_k \ge N_1nk​≥N1​ 且 ∣xnk−x∣<ε/2|x_{n_k} - x| < \varepsilon / 2∣xnk​​−x∣<ε/2。则 n≥N1n \ge N_1n≥N1​ 时
    ∣xn−x∣≤∣xn−xnk∣+∣xnk−x∣<ε|x_n - x| \le |x_n - x_{n_k}| + |x_{n_k} - x| < \varepsilon∣xn​−x∣≤∣xn​−xnk​​∣+∣xnk​​−x∣<ε

    注意第 3 步里 nk≥N1n_k \ge N_1nk​≥N1​ 是关键 —— 它保证 ∣xn−xnk∣|x_n - x_{n_k}|∣xn​−xnk​​∣ 可以按 Cauchy 性来估。∎
