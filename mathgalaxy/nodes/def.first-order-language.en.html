Statement

A first-order language L\mathcal{L}L is given by a signature, whose symbols fall into two classes:

  • logical symbols (shared by all first-order languages): countably many variables v0,v1,v2,…v_{0}, v_{1}, v_{2}, \ldotsv0​,v1​,v2​,…; the connectives ¬,∧\neg, \wedge¬,∧ (∨,→\vee, \to∨,→ are abbreviations); the quantifiers ∀\forall∀ (∃\exists∃ is an abbreviation); equality ===; parentheses.
  • non-logical symbols (specific to each language): constant symbols, nnn-ary function symbols, nnn-ary relation symbols, each with a definite arity nnn.

From the signature, three syntactic rules generate all terms and formulas:

  1. variables and constants are terms; if fff is an nnn-ary function symbol and t1,…,tnt_{1}, \ldots, t_{n}t1​,…,tn​ are terms, then f(t1,…,tn)f(t_{1}, \ldots, t_{n})f(t1​,…,tn​) is a term;
  2. if RRR is an nnn-ary relation symbol and t1,…,tnt_{1}, \ldots, t_{n}t1​,…,tn​ are terms, then R(t1,…,tn)R(t_{1}, \ldots, t_{n})R(t1​,…,tn​) is an atomic formula;
  3. formulas are built from atomic formulas by repeated application of ¬\neg¬, ∧\wedge∧, ∨\vee∨, →\to→, ∀vi\forall v_{i}∀vi​, ∃vi\exists v_{i}∃vi​.

Example: L={∈}\mathcal{L} = \{ \in \}L={∈} (with ∈\in∈ a binary relation symbol) is the language of set theory — all axioms of ZFC are written in this language.

Notes

⭐⭐ This is the only "metamathematical" primitive in the star map: the ZF axioms, the empty set, and this item all sit at the very bottom, but only this one is not part of the object language — it is the language in which the axioms are written, more primitive than ZFC itself.

It therefore sits at the bottom layers together with the ZF axioms and has no dependency edges upward: to really draw one, "formula" would first have to be built as a set inside ZFC, which uses the ZFC axioms, but the axiom schemas themselves need formulas — a direct circle.

⭐ It can also be formalized inside ZFC: encode symbols as sets and formulas as finite sequences; "φ\varphiφ is a formula" then becomes a property in ZFC. That is further metamathematical work, not developed here. (This direction is exactly the entrance to Gödel's incompleteness theorems.)

⚠ Keep language and structure apart: L={∈}\mathcal{L} = \{ \in \}L={∈} specifies only which symbols exist, not yet where variables range — that is what the satisfaction relation has to say.
