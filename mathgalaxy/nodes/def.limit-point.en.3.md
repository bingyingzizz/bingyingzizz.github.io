# limit point　`def.limit-point`
English entry · root `../`
[in graph](../#n=def.limit-point)　·　[Chinese page (authoritative)](./def.limit-point.md)

⚠ Do not confuse it with the supremum: $\sup S$ is about "upper bounds of $S$", while a limit point is about "which points the elements of $S$ approach arbitrarily closely";

$\sup\{1, 1/2, 1/3, \ldots\} = 1$ is also the unique limit point of that set, whereas $\sup\{1\} = 1$ is not a limit point.
