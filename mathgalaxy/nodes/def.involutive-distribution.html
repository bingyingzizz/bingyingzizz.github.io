又称对合分布

陈述

白话：一族方向「对合」，说的是：沿其中两个方向各走一步、交换次序后的那点偏差，仍然落在这族方向里。这一条就是「能被拼成薄片」的全部障碍。

设 D\mathcal{D}D 是 MMM 上的光滑 kkk 阶切分布（def.tangent-distribution）。称 D\mathcal{D}D 对合（involutive），如果对任意开集 U⊆MU \subseteq MU⊆M 与任意 X,Y∈Γ(D∣U)X, Y \in \Gamma(\mathcal{D}|_{U})X,Y∈Γ(D∣U​)（取值落在 D\mathcal{D}D 里的光滑向量场），都有

[X,Y]∈Γ(D∣U),[X,Y] \in \Gamma(\mathcal{D}|_{U}),[X,Y]∈Γ(D∣U​),

其中 [⋅,⋅][\cdot,\cdot][⋅,⋅] 是向量场的 Lie 括号（def.lie-bracket）。

只需查生成元：设 D\mathcal{D}D 在 UUU 上由 X1,…,XkX_{1},\ldots,X_{k}X1​,…,Xk​ 生成，则 D\mathcal{D}D 在 UUU 上对合，当且仅当每个括号都能写成生成元的 C∞C^{\infty}C∞-线性组合

[Xi,Xj]=∑l=1ka ijl Xl,a ijl∈C∞(U).[X_{i},X_{j}] = \sum_{l=1}^{k} a^{l}_{\ ij}\,X_{l},\qquad a^{l}_{\ ij} \in C^{\infty}(U).[Xi​,Xj​]=l=1∑k​a ijl​Xl​,a ijl​∈C∞(U).

这一条判据是 Frobenius 定理证明里真正动手验的东西。

说明

为什么只需查生成元：Γ(D∣U)\Gamma(\mathcal{D}|_{U})Γ(D∣U​) 是 C∞(U)C^{\infty}(U)C∞(U)-模，任意两个截面写成 fiXif^{i}X_{i}fiXi​、gjXjg^{j}X_{j}gjXj​。由 def.lie-bracket 的第 4 条（Leibniz 律）

[fXi, gXj]=fg [Xi,Xj]+f(Xig) Xj−g(Xjf) Xi,[fX_{i},\,gX_{j}] = fg\,[X_{i},X_{j}] + f(X_{i}g)\,X_{j} - g(X_{j}f)\,X_{i},[fXi​,gXj​]=fg[Xi​,Xj​]+f(Xi​g)Xj​−g(Xj​f)Xi​,

后两项只是生成元的组合，所以「括号落在 D\mathcal{D}D 里」逐点由 [Xi,Xj][X_{i},X_{j}][Xi​,Xj​] 决定。

秩 111 永远对合：局部取处处非零的 XXX 生成 D\mathcal{D}D，任意两个截面是 fXfXfX、gXgXgX，而 [fX,gX]=f(Xg)X−g(Xf)X[fX,gX] = f(Xg)X - g(Xf)X[fX,gX]=f(Xg)X−g(Xf)X 仍是 XXX 的倍数。所以线分布永远可积（thm.frobenius）；可积性是从秩 222 才开始的问题 —— 这与「一个一阶常微分方程总有解、一阶偏微分方程组才有障碍」是同一句话。

为什么对合是「正确」的条件：若有积分流形 NNN（def.integral-manifold），则「X,YX, YX,Y 落在 D\mathcal{D}D 里」等于「X,YX, YX,Y 是 NNN 上的向量场」，于是 [X,Y][X,Y][X,Y] 必落在 TN=DTN = \mathcal{D}TN=D 里 —— 对合是必要条件，而且它只用括号就能验。Frobenius 定理说它也是充分的。

反例（Heisenberg 接触分布）：R3\mathbb{R}^{3}R3 上令 D=ker⁡ω\mathcal{D} = \ker\omegaD=kerω，ω=dz−x dy\omega = \mathrm{d}z - x\,\mathrm{d}yω=dz−xdy。X=∂xX = \partial_{x}X=∂x​ 与 Y=∂y+x ∂zY = \partial_{y} + x\,\partial_{z}Y=∂y​+x∂z​ 满足 ω(X)=0\omega(X) = 0ω(X)=0、ω(Y)=−x+x=0\omega(Y) = -x + x = 0ω(Y)=−x+x=0，所以它们是 D\mathcal{D}D 的生成元；但

[X,Y]=[∂x, ∂y+x ∂z]=∂z,ω(∂z)=1≠0,[X,Y] = [\partial_{x},\ \partial_{y} + x\,\partial_{z}] = \partial_{z},\qquad \omega(\partial_{z}) = 1 \ne 0,[X,Y]=[∂x​, ∂y​+x∂z​]=∂z​,ω(∂z​)=1=0,

故 [X,Y]∉D[X,Y] \notin \mathcal{D}[X,Y]∈/D：这个秩 222 的接触分布不对合，因而不可能有积分曲面。它每点附近都「绕着拧」，任何曲面都装不下 —— 这是 Frobenius 定理最省事的反例。

⚠️ 「对合」是分布的性质，与生成元的选取无关（换生成元只是乘以 GL⁡(k)\operatorname{GL}(k)GL(k)-值函数矩阵，括号的封闭性不变）。所以反例里只验一组生成元就够。

  • 向量场 → 本页定义引用

    对合性说的是「落在 D\mathcal{D}D 里的向量场」这个集合的封闭性；没有向量场就没有 Γ(D)\Gamma(\mathcal{D})Γ(D) 可说。

  • Lie 括号 → 本页定义引用

    判据就是「生成元的括号仍是生成元的组合」；Leibniz 律保证只需查生成元（见边 imp.mf2-frobenius-flat 的证明里那一步）。

    对合是分布的属性：没有「kkk 维子空间族」这个对象，就无从说括号落在哪里。
