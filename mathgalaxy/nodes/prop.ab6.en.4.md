# AB6: Filtered Colimits Commute with Products　`prop.ab6`
English entry · root `../`
[in graph](../#n=prop.ab6)　·　[Chinese page (authoritative)](./prop.ab6.md)

Take $t = (t_{j})_{j}$, where $t_{j}$ is the element of order $p^{j}$: over any single $i$, elements can have order only $\le p^{i}$, so the components $j > i$ cannot be lifted at all — whereas over $\prod_{j} I_{j}$ there is no such problem, and each $j$ can go to a sufficiently high level on its own.

Relation to AB5: AB6 = AB5 + the item above (AB5 governs "filtered colimits are exact", AB6 further governs "they commute with products").
