$$g_{\alpha\alpha} = \mathrm{id}, \qquad g_{\alpha\beta}\, g_{\beta\gamma}\, g_{\gamma\alpha} = \mathrm{id} \quad \text{在}\ U_{\alpha\beta\gamma}\ \text{上} .$$
