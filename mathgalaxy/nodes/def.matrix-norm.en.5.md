# Matrix Norm　`def.matrix-norm`
English entry · root `../`
[in graph](../#n=def.matrix-norm)　·　[Chinese page (authoritative)](./def.matrix-norm.md)

⭐ **Why $\lVert\cdot\rVert$ is often used in error estimates**: $\lVert x - x_{0}\rVert \le \lVert A^{-1}\rVert\,\lVert b - Ax_{0}\rVert$. This gives rise to the condition number $\kappa = \lVert A\rVert\lVert A^{-1}\rVert$ (only this connection is recorded here, without developing the numerical analysis).
