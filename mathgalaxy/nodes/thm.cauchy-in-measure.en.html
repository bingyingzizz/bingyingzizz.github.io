Statement

If {fn}\{f_n\}{fn​} is Cauchy in measure, then there is a measurable function fff such that

fn→ μ ff_n \xrightarrow{\ \mu\ } ffn​ μ ​f

and there is a subsequence {fnj}\{f_{n_j}\}{fnj​​} such that

fnj→fa.e.f_{n_j} \to f\quad \text{a.e.}fnj​​→fa.e.

Notes

⭐ This is the most useful property of “convergence in measure”: convergence itself does not guarantee convergence at any single point, but one can always extract a subsequence converging almost everywhere.

The tool in the proof is a Borel–Cantelli type argument: build a family of “bad sets” with ∑kμ(Ek)<∞\sum_k \mu(E_k) < \infty∑k​μ(Ek​)<∞; then almost every point lies in only finitely many bad sets.

This is also the half of Riesz's theorem stating “convergence in measure   ⟹  \implies⟹ there is a subsequence converging a.e.” (the converse fails: a.e. convergence does not imply convergence in measure unless the space has finite measure).
