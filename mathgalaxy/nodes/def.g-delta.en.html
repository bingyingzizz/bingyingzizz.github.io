Statement

AAA is called a GδG_\deltaGδ​ set if AAA is a countable intersection of open sets; and an FσF_\sigmaFσ​ set if AAA is a countable union of closed sets.

Notes

Two directions must be kept apart. The trivial one: a closed set is a union of one closed set, so ⊆Fσ\subseteq F_\sigma⊆Fσ​; an open set is an intersection of one open set, so ⊆Gδ\subseteq G_\delta⊆Gδ​.
