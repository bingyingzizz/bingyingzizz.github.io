Statement

Let R,SR, SR,S be rings with identity. A map f:R→Sf : R \to Sf:R→S is a ring homomorphism if

f(a+b)=f(a)+f(b),f(ab)=f(a)f(b),f(1R)=1Sf(a+b) = f(a)+f(b), \qquad f(ab) = f(a)f(b), \qquad f(1_R) = 1_Sf(a+b)=f(a)+f(b),f(ab)=f(a)f(b),f(1R​)=1S​

for all a,b∈Ra, b \in Ra,b∈R.

The kernel ker⁡f:={ a∈R:f(a)=0 }\ker f := \{\, a \in R : f(a) = 0 \,\}kerf:={a∈R:f(a)=0} is an ideal of RRR; the image im⁡f\operatorname{im} fimf is a subring of SSS. The map fff is injective if and only if ker⁡f=0\ker f = 0kerf=0; a bijective ring homomorphism is an isomorphism.

Notes

⭐ Examples: Z→Z/nZ\mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}Z→Z/nZ; K[x]→KK[x] \to KK[x]→K, f↦f(a)f \mapsto f(a)f↦f(a) (evaluation); C→C\mathbb{C} \to \mathbb{C}C→C, z↦zˉz \mapsto \bar zz↦zˉ (conjugation, a ring isomorphism but not a C\mathbb{C}C-algebra homomorphism).

⚠ Some texts do not require f(1R)=1Sf(1_R) = 1_Sf(1R​)=1S​; these notes use the convention "rings with identity and homomorphisms preserving 111". Without preserving 111 the kernel is still an ideal, but "R/ker⁡f≅im⁡fR/\ker f \cong \operatorname{im} fR/kerf≅imf" then requires aligning the identity of the image (the 111 of the image).

⭐ First isomorphism theorem: R/ker⁡f≅im⁡fR/\ker f \cong \operatorname{im} fR/kerf≅imf (for quotient rings see 商环).
