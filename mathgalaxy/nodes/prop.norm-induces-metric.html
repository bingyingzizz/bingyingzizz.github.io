陈述

令 d(x,y):=∥x−y∥d(x, y) := \|x - y\|d(x,y):=∥x−y∥。则 ddd 是 EEE 上的距离，并且

  • 平移不变：d(x+z, y+z)=d(x,y)d(x + z,\ y + z) = d(x, y)d(x+z, y+z)=d(x,y)；
  • 齐次：d(λx, λy)=∣λ∣ d(x,y)d(\lambda x,\ \lambda y) = |\lambda|\,d(x, y)d(λx, λy)=∣λ∣d(x,y)；
  • 每个球 B(x,r)B(x, r)B(x,r) 都是凸的。

反过来，若距离满足平移不变与齐次，则 ∥x∥:=d(x,0)\|x\| := d(x, 0)∥x∥:=d(x,0) 是范数，且它诱导回这个距离。

说明

这条说清了「赋范」比「度量」多出来的是什么：平移不变 + 齐次 + 球凸。所以「这个度量是否来自范数」是一个有内容的问题（反例：min⁡(d,1)\min(d, 1)min(d,1) 与 ∑i2−i∣xi−yi∣1+∣xi−yi∣\sum_i 2^{-i}\frac{|x_i - y_i|}{1 + |x_i - y_i|}∑i​2−i1+∣xi​−yi​∣∣xi​−yi​∣​ 都平移不变，缺的是齐次性：前者取 x=1,y=0,λ=2x = 1, y = 0, \lambda = 2x=1,y=0,λ=2 得 1≠21 \ne 21=2）。

⭐ 球凸这一条后面要用两次：凸集上的最近点（Hilbert 的投影定理）、以及「开球的像是否开」（开映射定理）。
