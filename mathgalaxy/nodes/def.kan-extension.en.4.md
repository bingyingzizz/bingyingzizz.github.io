# Kan extension　`def.kan-extension`
English entry · root `../`
[in graph](../#n=def.kan-extension)　·　[Chinese page (authoritative)](./def.kan-extension.md)

| adjunction $L \dashv R$ | $p_{!} \dashv p^{*}$ |
| --- | --- |
| unit $\eta_{A} : A \to R L A$ | $\alpha : F \implies p^{*}(p_{!}F)$ |
| $f : A \to R B$ | $\gamma : F \implies p^{*}(G)$ |
| $g : L A \to B$ | $\widetilde{\gamma} : p_{!}F \implies G$ |
| $f = R(g) \circ \eta_{A}$ | $\gamma = p^{*}(\widetilde{\gamma}) \circ \alpha$ |

So Kan extension is nothing new: it just uses the adjunction formulas in a different direction.
