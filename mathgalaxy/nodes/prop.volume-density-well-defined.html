在做什么：说明「密度」这个词为什么名副其实 —— 换卡时两个绝对值因子恰好抵消，所以它拼得成整体、也不依赖定向；带符号的那版则会被定向拖着变号。

设 (M,g)(M,g)(M,g) 是 nnn 维黎曼流形，两张卡 xxx、yyy 有重叠。则

det⁡(gijy)=det⁡(gijx)  ∣det⁡∂x∂y∣,dy1⋯dyn=∣det⁡∂y∂x∣ dx1⋯dxn,\sqrt{\det(g^{y}_{ij})} = \sqrt{\det(g^{x}_{ij})}\;\Bigl|\det\frac{\partial x}{\partial y}\Bigr|,\qquad \mathrm{d}y^{1}\cdots\mathrm{d}y^{n} = \Bigl|\det\frac{\partial y}{\partial x}\Bigr|\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n},det(gijy​)​=det(gijx​)​​det∂y∂x​​,dy1⋯dyn=​det∂x∂y​​dx1⋯dxn,

两式相乘，∣det⁡∣|\det|∣det∣ 因子等于 111，故

det⁡(gijy)  dy1⋯dyn=det⁡(gijx)  dx1⋯dxn.\sqrt{\det(g^{y}_{ij})}\;\mathrm{d}y^{1}\cdots\mathrm{d}y^{n} = \sqrt{\det(g^{x}_{ij})}\;\mathrm{d}x^{1}\cdots\mathrm{d}x^{n}.det(gijy​)​dy1⋯dyn=det(gijx​)​dx1⋯dxn.

于是 dμg\mathrm{d}\mu_{g}dμg​ 是一个整体良定的密度，拼接后给出 MMM 上唯一的 Radon 测度 μg\mu_{g}μg​，且它不依赖定向。

对照：体积形式 dV\mathrm{d}VdV 的变换因子是 det⁡\detdet（没有绝对值），所以 dV\mathrm{d}VdV 只在保向换卡下不变、反向变号。有定向时 dμg=∣dV∣\mathrm{d}\mu_{g} = |\mathrm{d}V|dμg​=∣dV∣。

说明

绝对值是开方给的：∂yi=∑k(∂xk/∂yi)∂xk\partial_{y^{i}} = \sum_{k}(\partial x^{k}/\partial y^{i})\partial_{x^{k}}∂yi​=∑k​(∂xk/∂yi)∂xk​，故 gy=JTgxJg^{y} = J^{\mathsf T}g^{x}Jgy=JTgxJ（J=∂x/∂yJ = \partial x/\partial yJ=∂x/∂y），取行列式得 det⁡gy=(det⁡J)2det⁡gx\det g^{y} = (\det J)^{2}\det g^{x}detgy=(detJ)2detgx。开方时 det⁡J\det JdetJ 的符号被吃掉，∣det⁡J∣|\det J|∣detJ∣ 留下 —— 再来一个 ∣det⁡J∣−1|\det J|^{-1}∣detJ∣−1 就正好抵消。这一步是整条命题的全部内容。

拼成整体测度：局部密度在重叠处相等，剩下的只是把它加成测度。用从属于卡族的单位分解 {ρα}\{\rho_{\alpha}\}{ρα​}（prop.paracompact-partition-unity）定义 μg(f):=∑α∫Rn(ραf)∘xα−1 det⁡g dx\mu_{g}(f) := \sum_{\alpha}\int_{\mathbb{R}^{n}}(\rho_{\alpha}f)\circ x_{\alpha}^{-1}\,\sqrt{\det g}\ \mathrm{d}xμg​(f):=∑α​∫Rn​(ρα​f)∘xα−1​detg​ dx；每项非负、和有限，正性与可数可加性逐块相加即得。

二维时这条就是 def.area-element 的注记：「面积元是密度、不是形式」—— 换参数化时 det⁡g\sqrt{\det g}detg​ 与 du dv\mathrm{d}u\,\mathrm{d}vdudv 一起变，乘积不变且不变号。nnn 维只是把 2×22\times22×2 的 Gram 行列式换成 n×nn\times nn×n 的。

与 def.riemannian-metric 的关系：那边的定义把 dV\mathrm{d}VdV 记作 det⁡(gij) dx1⋯dxn\sqrt{\det(g_{ij})}\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n}det(gij​)​dx1⋯dxn。严格说这是密度（配 Lebesgue 测度、不带符号）；带符号的形式版是 def.volume-density 里那一个。两处是同一串系数，用法不同。

⚠️ 不可定向流形上照样有体积：面积、体积、质量这类量都不需要定向；丢掉的只是「带符号的积分」。散度定理那类公式则必须先取定定向（否则 dV\mathrm{d}VdV 的符号没有意义）。

    行列式的平方   ⟹  \implies⟹ 密度不依赖定向

    （1）局部变换。 设 yyy 是另一张卡，J:=∂x/∂yJ := \partial x/\partial yJ:=∂x/∂y。由 ∂yi=∑kJki ∂xk\partial_{y^{i}} = \sum_{k}J_{ki}\,\partial_{x^{k}}∂yi​=∑k​Jki​∂xk​ 与度量的双线性得 gy=JTgxJg^{y} = J^{\mathsf T}g^{x}Jgy=JTgxJ，取行列式：det⁡gy=(det⁡J)2det⁡gx\det g^{y} = (\det J)^{2}\det g^{x}detgy=(detJ)2detgx。两边开方（det⁡g>0\det g>0detg>0，因为 ggg 正定），

    det⁡gy=∣det⁡J∣ det⁡gx.\sqrt{\det g^{y}} = |\det J|\,\sqrt{\det g^{x}} .detgy​=∣detJ∣detgx​.

    （2）与体积元配平。 换元公式给出 dy1⋯dyn=∣det⁡(∂y/∂x)∣ dx1⋯dxn=∣det⁡J∣−1dx1⋯dxn\mathrm{d}y^{1}\cdots\mathrm{d}y^{n} = |\det(\partial y/\partial x)|\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n} = |\det J|^{-1}\mathrm{d}x^{1}\cdots\mathrm{d}x^{n}dy1⋯dyn=∣det(∂y/∂x)∣dx1⋯dxn=∣detJ∣−1dx1⋯dxn。两式相乘，∣det⁡J∣|\det J|∣detJ∣ 抵消，故

    det⁡gy dy1⋯dyn=det⁡gx dx1⋯dxn.\sqrt{\det g^{y}}\,\mathrm{d}y^{1}\cdots\mathrm{d}y^{n} = \sqrt{\det g^{x}}\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n} .detgy​dy1⋯dyn=detgx​dx1⋯dxn.

    关键：开方给出 ∣det⁡J∣|\det J|∣detJ∣ 而不是 det⁡J\det JdetJ —— 这一步就是「密度不换号」的全部来源。若换成 nnn-形式版，dx1∧⋯\mathrm{d}x^{1}\wedge\cdotsdx1∧⋯ 的变换因子是 det⁡J\det JdetJ（无绝对值），于是乘积只在保向时不变、反向时变号。

    （3）拼成整体。 局部密度在重叠处相等，故用从属于卡族的单位分解 {ρα}\{\rho_{\alpha}\}{ρα​} 定义 μg(f):=∑α∫Rn(ραf)∘xα−1 det⁡g dx\mu_{g}(f) := \sum_{\alpha}\int_{\mathbb{R}^{n}}(\rho_{\alpha}f)\circ x_{\alpha}^{-1}\,\sqrt{\det g}\ \mathrm{d}xμg​(f):=∑α​∫Rn​(ρα​f)∘xα−1​detg​ dx。每一项非负（f≥0f\ge 0f≥0 时）、和有限，且由 (2) 与卡选取无关；于是 μg\mu_{g}μg​ 是 MMM 上良定、正、可数可加的 Radon 测度。

    （4）与 dV\mathrm{d}VdV 对照。 有定向时 dV=det⁡g dx1∧⋯∧dxn\mathrm{d}V = \sqrt{\det g}\,\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}dV=detg​dx1∧⋯∧dxn 与 dμg\mathrm{d}\mu_{g}dμg​ 逐卡同系数，只差「楔积（带符号）」与「Lebesgue（不带符号）」，故 μg=∣dV∣\mu_{g} = |\mathrm{d}V|μg​=∣dV∣，且紧流形上 ∫MdV=μg(M)=vol⁡g(M)\int_{M}\mathrm{d}V = \mu_{g}(M) = \operatorname{vol}_{g}(M)∫M​dV=μg​(M)=volg​(M)。∎
