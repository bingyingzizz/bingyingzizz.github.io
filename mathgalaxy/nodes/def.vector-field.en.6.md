# Vector Field　`def.vector-field`
English entry · root `../`
[in graph](../#n=def.vector-field)　·　[Chinese page (authoritative)](./def.vector-field.md)

**Coordinate change**: expanding in two local coordinate systems, the components satisfy $X_{y}^{i} = \sum_{j}\frac{\partial y^{i}}{\partial x^{j}}X_{x}^{j}$ — the $X^{i}$ on the two sides belong to **different coordinate systems** and must be written separately (for $y = 2x$ and $X = \partial_{x}$, the $x$ component is $1$ and the $y$ component is $2$, so using one symbol would produce the absurd $1 = 2$). This is the same transformation law as for tangent vectors (contravariant). This is what "$X$ is a tensor field of type $(1,0)$" means (`def.tensor-field`).
