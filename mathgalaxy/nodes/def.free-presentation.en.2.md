## Notes · **draft**
Compare with the set-theoretic picture: for $f : X \to Y$, put $R := X \times_{Y} X = \{(x_{1},x_{2}) : f(x_{1}) = f(x_{2})\}$ ("pairs of points with the same image"); then $X/R \cong \operatorname{im} f$ (**Noether's first isomorphism theorem**);

conversely, given an equivalence relation $R$ on $X$, set $Y := X/R$, and then $R = X \times_{Y} X$.
