## Notes · **draft**
⚠️ **Do not substitute $X$ directly into $\operatorname{Hom}_{\mathbb{Z}}$**: $X$ is assumed only to be an **object of the topos**, not necessarily an abelian group object, so $j_{Z}^{-1}X$ is merely an object of $\mathcal{T}/Z$ and $\operatorname{Hom}_{\mathbb{Z}}(j_{Z}^{-1}X,\cdot)$ is undefined. Example: $\mathcal{T} = \mathbf{Set}$, $X$ the three-element set $\{0,1,2\}$, and $j_{X}^{-1}X$ is still just a set. To use the $X$ version one must additionally assume $X\in\mathrm{Ab}(\mathcal{T})$ (in which case $\mathbb{Z}\cdot X = X$).
