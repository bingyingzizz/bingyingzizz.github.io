# Monotonicity and Estimates for Integrals　`prop.integral-order`

[in graph](../#n=prop.integral-order)　·　[Chinese page (authoritative)](./prop.integral-order.md)

- **Basic estimate**: if $|f(x)| \le M$ holds everywhere, then $\bigl| \int_a^b f \bigr| \le M\,(b - a)$.

## Notes · **draft**
⭐ Order preservation sounds trivial, but it is the source of **all integral inequalities**: to prove $\int f \le \int g$, it suffices to prove $f \le g$ pointwise.

⚠ The **non-strict** inequality obtained from order preservation cannot be upgraded: if $f \le g$ and $f < g$ only at one point, still $\int_a^b f = \int_a^b g$ (changing the value at one point does not change the Riemann integral).
