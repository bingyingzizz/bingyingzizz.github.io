Notes

⭐ "Solution set = particular solution + homogeneous solutions" is the central picture of linear algebra: the inhomogeneous system has no structure, the homogeneous one does (it is a subspace), and the inhomogeneous solution set is just a translate of it (an affine subspace).

⭐ The dimension formula n−rank⁡An - \operatorname{rank} An−rankA is the rank–nullity theorem in the language of linear systems: the number of variables nnn = the rank⁡A\operatorname{rank} ArankA constrained away + the dim⁡ker⁡A\dim \ker AdimkerA free ones.

⚠ The geometric meaning of "solvable   ⟺  \iff⟺ rank⁡A=rank⁡(A∣b)\operatorname{rank} A = \operatorname{rank}(A \mid b)rankA=rank(A∣b)": bbb lies in the column space of AAA.

Do not misremember it as "rank A = m": for a general m × n matrix, rank A = m only says that the rows of A are of full rank, so that every b is solvable; uniqueness needs rank A = n. The two coincide only for square matrices (m = n).

Which of the four items is a "theorem" and which is only a restatement (this group is often presented as four parallel statements, but the last one depends on the first two):

  • Solvability   ⟺  rank⁡A=rank⁡(A∣b)\iff \operatorname{rank}A = \operatorname{rank}(A\mid b)⟺rankA=rank(A∣b): this step has real content, it is equivalent to "b∈col⁡(A)b \in \operatorname{col}(A)b∈col(A)". The proof uses row reduction (Gauss elimination) — a row of the form 0=c≠00 = c \ne 00=c=0 appears exactly when the ranks differ. It only uses that KKK is a field (elimination is free over a field; over Z\mathbb{Z}Z one must pass to the Smith normal form).
  • Solution set = particular solution + homogeneous solutions: this step is purely linear (no field, no finite dimension needed): if Ax0=bAx_{0} = bAx0​=b and Au=0Au = 0Au=0, then A(x0+u)=bA(x_{0}+u) = bA(x0​+u)=b; conversely the difference of two solutions lies in ker⁡A\ker AkerA. An affine subspace need not be a subspace — unless b=0b = 0b=0.
  • dim⁡ker⁡A=n−rank⁡A\dim \ker A = n - \operatorname{rank} AdimkerA=n−rankA: this step uses the rank–nullity theorem (thm.rank-nullity), the only dimensional input; it itself requires the finite-dimensional hypothesis.
  • m=nm=nm=n, det⁡A≠0\det A \ne 0detA=0   ⟹  \implies⟹ a unique solution: this is only a special case of the first two (det⁡≠0  ⟺  rank⁡A=n  ⟺  ker⁡A=0\det \ne 0 \iff \operatorname{rank} A = n \iff \ker A = 0det=0⟺rankA=n⟺kerA=0), with no independent content.

⚠️ Three hypotheses that cannot be dropped:

  • "KKK is a field": over Z\mathbb{Z}Z the equation 2x=12x = 12x=1 has no solution while 2x=22x = 22x=2 has one, and the rank criterion must be replaced by the Smith normal form (or by a gcd condition for existence   ⟺  \iff⟺).
  • "Finite-dimensional": in infinite dimension the equality dim⁡ker⁡A=n−rank⁡A\dim \ker A = n - \operatorname{rank} AdimkerA=n−rankA fails (there is no nnn to subtract), and one must speak of codimension.
  • "det⁡A≠0\det A \ne 0detA=0" is meaningful only when m=nm = nm=n; for m≠nm \ne nm=n do not speak of "det⁡\detdet" — that is the setting of pseudoinverses and least squares (def.pseudoinverse).
