def.algebraic-closure

Machine-drafted and pending author review. The Chinese text is authoritative.

Statement

Let KKK be a field. A field extension Kˉ/K\bar K / KKˉ/K is an algebraic closure of KKK if

  1. Kˉ\bar KKˉ is algebraically closed (every nonconstant polynomial has a root in Kˉ\bar KKˉ, see algebraically closed field);
  2. Kˉ/K\bar K / KKˉ/K is an algebraic extension (every element is a root of some nonzero polynomial over KKK).

By Zorn's lemma every field has an algebraic closure; and any two algebraic closures are KKK-isomorphic (unique up to isomorphism).

Notes

⭐ Examples: C\mathbb{C}C is the algebraic closure of R\mathbb{R}R; Q‾\overline{\mathbb{Q}}Q​ (all algebraic numbers over Q\mathbb{Q}Q) is the algebraic closure of Q\mathbb{Q}Q; the algebraic closure of Fp\mathbb{F}_pFp​ is ⋃nFpn\bigcup_{n} \mathbb{F}_{p^n}⋃n​Fpn​.

⚠ The algebraic closure is not "a unique set" but "unique up to isomorphism"; different constructions give KKK-isomorphic fields.

⭐ Existence uses Zorn, but first one must pass to a set: all algebraic extensions form a proper class and cannot be ordered directly. Give the candidate field a cardinal bound ≤max⁡(∣K∣,ℵ0)\le \max(|K|, \aleph_0)≤max(∣K∣,ℵ0​) first (each algebraic element is a root of some nonzero polynomial in K[x]K[x]K[x], while K[x]K[x]K[x] has only max⁡(∣K∣,ℵ0)\max(|K|,\aleph_0)max(∣K∣,ℵ0​) elements and each polynomial has finitely many roots, so the total number of algebraic elements is at most this bound), keep only algebraic extensions within the bound, and apply Zorn to those; a maximal element must be algebraically closed (otherwise add one more root and extend).
