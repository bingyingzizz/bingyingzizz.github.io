Statement

Let KKK be a field. A field extension Kˉ/K\bar K / KKˉ/K is an algebraic closure of KKK if

  1. Kˉ\bar KKˉ is algebraically closed (every nonconstant polynomial has a root in Kˉ\bar KKˉ, see 代数闭域);
  2. Kˉ/K\bar K / KKˉ/K is an algebraic extension (every element is a root of some nonzero polynomial over KKK).

By Zorn's lemma every field has an algebraic closure; and any two algebraic closures are KKK-isomorphic (unique up to isomorphism).

Notes

⭐ Examples: C\mathbb{C}C is an algebraic closure of R\mathbb{R}R; Q‾\overline{\mathbb{Q}}Q​ (all algebraic numbers over Q\mathbb{Q}Q) is an algebraic closure of Q\mathbb{Q}Q; an algebraic closure of Fp\mathbb{F}_pFp​ is ⋃nFpn\bigcup_{n} \mathbb{F}_{p^n}⋃n​Fpn​.

⚠ An algebraic closure is not "a unique set" but "unique up to isomorphism"; different constructions give KKK-isomorphic fields.

⭐ Existence uses Zorn: take the partially ordered set of all algebraic extensions; a maximal element must be algebraically closed (otherwise adjoin one more root and continue).
