# the adic structure sheaf is a sheaf　`thm.adic-structure-sheaf`
English entry · root `../`
[in graph](../#n=thm.adic-structure-sheaf)　·　[Chinese page (authoritative)](./thm.adic-structure-sheaf.md)

The preimage of a rational open set under $\psi$ is exactly $D(f)$, so $\mathcal{O}_{\operatorname{Spa}(A,A^+)}$ is the **pushforward** of $\mathcal{O}_{\operatorname{Spec} A}$ along $\psi$; pushforwards preserve sheaves.

⭐ (iii) says that $\mathcal{O}^+$ is not extra structure but the part of $\mathcal{O}$ consisting of functions that are pointwise $\le 1$ — the local version of the same statement as `prop.huber-subring-recovery`.
