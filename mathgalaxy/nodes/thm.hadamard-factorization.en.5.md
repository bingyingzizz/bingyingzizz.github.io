# Hadamard factorization theorem　`thm.hadamard-factorization`
English entry · root `../`
[in graph](../#n=thm.hadamard-factorization)　·　[Chinese page (authoritative)](./thm.hadamard-factorization.md)

**Step 2. Convergence of the product.** Write $\mathcal{P}(z):=\prod_{n}E_{p}(z/a_{n})$. For $|w|\le1/2$, we have $\log E_{p}(w)=-\sum_{k>p}w^{k}/k$, hence $|E_{p}(w)-1|\le C_{p}|w|^{p+1}$. Given $R$, there are only finitely many $|a_{n}|\le2R$. For the remaining terms, $|z/a_{n}|\le1/2$, so $\sum_{|a_{n}|>2R}|z/a_{n}|^{p+1}\le R^{p+1}\sum_{n}|a_{n}|^{-(p+1)}<\infty$. Therefore $\mathcal{P}$ converges uniformly on $|z|\le R$ and defines an entire function.
