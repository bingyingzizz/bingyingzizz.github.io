# branched cover of Riemann surfaces　`def.branched-cover`
English entry · root `../`
[in graph](../#n=def.branched-cover)　·　[Chinese page (authoritative)](./def.branched-cover.md)

$$p : \mathbb{P}^{1} \to \mathbb{P}^{1}, \qquad z \mapsto z^{2}$$

This is a branched covering of degree $2$ with branch points $0$ and $\infty$ (at these points it is $2$-to-$1$), and everywhere else it is $2$-to-$1$.

📌 In brief, a branched covering is a finite-sheeted covering $+$ finitely many points where ramification is allowed.
