陈述

设 V,WV, WV,W 是域 KKK 上的向量空间。映射 T:V→WT : V \to WT:V→W 叫 KKK-线性的（或线性映射），当且仅当

T(u+v)=T(u)+T(v),T(cu)=c T(u)T(u + v) = T(u) + T(v), \qquad T(cu) = c\,T(u)T(u+v)=T(u)+T(v),T(cu)=cT(u)

对一切 u,v∈Vu, v \in Vu,v∈V、c∈Kc \in Kc∈K 成立。等价地：T(cu+v)=c T(u)+T(v)T(cu + v) = c\,T(u) + T(v)T(cu+v)=cT(u)+T(v)。

两个线性映射的和与数乘仍是线性映射，于是全体线性映射构成一个 KKK-向量空间，记

Hom⁡K(V,W):={ T:V→W linear }\operatorname{Hom}_K(V, W) := \{\, T : V \to W \ \text{linear} \,\}HomK​(V,W):={T:V→W linear}

复合 S∘TS \circ TS∘T 仍是线性的。

说明

⭐ 线性 = 保持两个运算（加法与数乘）。与群同态（保持一个运算）相比多了一条，但那条数是免费的：T(0)=0T(0) = 0T(0)=0 与 T(−v)=−T(v)T(-v) = -T(v)T(−v)=−T(v) 都能从定义推出。

⭐ 「Hom⁡K(V,W)\operatorname{Hom}_K(V, W)HomK​(V,W) 本身是向量空间」这件事是线性代数特有的：一般范畴里两个对象之间的态射集没有加法（Set\mathbf{Set}Set 里就是如此），而向量空间的范畴是加法范畴 —— 两个对象之间的态射集自带加法，这是它比一般范畴多出来的结构。

⚠ 线性的关键在于只看 KKK 的加法与数乘：平移 v↦v+v0v \mapsto v + v_0v↦v+v0​（v0≠0v_0 \ne 0v0​=0）不是线性的（000 不映到 000），但它「差一个平移就是线性的」—— 那叫仿射映射。
