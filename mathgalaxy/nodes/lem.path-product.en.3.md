# concatenation of paths　`lem.path-product`
English entry · root `../`
[in graph](../#n=lem.path-product)　·　[Chinese page (authoritative)](./lem.path-product.md)

1. **Well defined**: $\alpha \simeq_{p} \alpha'$ and $\beta \simeq_{p} \beta'$ $\implies$ $\alpha * \beta \simeq_{p} \alpha' * \beta'$;
2. **Associativity**: $(\alpha * \beta) * \gamma \simeq_{p} \alpha * (\beta * \gamma)$;
3. **Unit**: $e_{x_{0}} * \alpha \simeq_{p} \alpha \simeq_{p} \alpha * e_{x_{1}}$;
4. **Inverse**: $\alpha * \bar{\alpha} \simeq_{p} e_{x_{0}}$ and $\bar{\alpha} * \alpha \simeq_{p} e_{x_{1}}$.

Thus "homotopy classes of loops based at $x_{0}$" with multiplication $[\alpha][\beta] := [\alpha * \beta]$ form a group.
