# Normal Matrix　`def.normal-matrix`
English entry · root `../`
[in graph](../#n=def.normal-matrix)　·　[Chinese page (authoritative)](./def.normal-matrix.md)

$\{$ unitary $\} \subset \{$ normal $\}$, $\{$ Hermitian $\} \subset \{$ normal $\}$, $\{$ real symmetric $\} \subset \{$ normal $\}$.

**Core result** (thm.spectral-matrix): $A$ normal $\iff$ there exists a unitary matrix $U$ such that $U^{*}AU$ is diagonal.

The real case corresponds to **real normal matrices** ($A^{T}A = AA^{T}$): they are orthogonally diagonalizable, but as a **block** diagonal with $1\times 1$ and $2\times 2$ blocks, not necessarily purely diagonal — because non-real eigenvalues can only occur in conjugate pairs.
