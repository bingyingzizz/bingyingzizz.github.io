又称幂等

陈述

在做什么：「做两次和做一次一样」的算子。它等价于「把空间劈成两块、扔掉其中一块」，所以幂等算子与直和分解是同一件事。

设 T:V→VT : V \to VT:V→V 线性。称 TTT 幂等（idempotent），若

T2=T.T^{2} = T .T2=T.

矩阵情形：A2=AA^{2} = AA2=A。

与直和的对应：TTT 幂等   ⟺  \iff⟺ V=ker⁡T⊕im⁡TV = \ker T \oplus \operatorname{im} TV=kerT⊕imT，且 TTT 就是沿 ker⁡T\ker TkerT 到 im⁡T\operatorname{im} TimT 的投影。

此时 I−TI - TI−T 也幂等，且 ker⁡T=im⁡(I−T)\ker T = \operatorname{im}(I - T)kerT=im(I−T)。

最小多项式：幂等算子的最小多项式整除 x2−x=x(x−1)x^{2} - x = x(x-1)x2−x=x(x−1)，所以它一定可对角化、特征值只能是 000 或 111。

说明

⚠️ 幂等 ≠\ne= 正交投影：一般的幂等算子（投影）只是「沿着某个补空间投出去」，不保证与像垂直。像与核正交的投影才是 正交投影（那要求 T∗=TT^{*} = TT∗=T，即自伴 + 幂等）。把两者混同会得出「投影总是最短距离」这种错误结论。

两种投影的判据对照：幂等   ⟺  T2=T\iff T^{2} = T⟺T2=T；正交投影   ⟺  T2=T\iff T^{2} = T⟺T2=T 且 T∗=TT^{*} = TT∗=T。差的就是自伴那一条。

⭐ 谱分解的积木：谱定理把 AAA 写成 ∑λiPi\sum \lambda_i P_i∑λi​Pi​，其中每个 PiP_iPi​ 都是正交幂等算子，且两两正交、和为 III（谱定理（矩阵版） 的注）。所以幂等元是「把谱切开」的最小单位。

⚠️ 幂等与幂零是两个极端：T2=TT^{2} = TT2=T 停止变化，Tk=0T^{k} = 0Tk=0 最终归零。除了 T=0T = 0T=0（两者都满足）之外没有交集。
