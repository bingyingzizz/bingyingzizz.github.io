短正合列

0⟶M1→  i1  M→  i2  M2⟶00 \longrightarrow M_{1} \xrightarrow{\;i_{1}\;} M \xrightarrow{\;i_{2}\;} M_{2} \longrightarrow 00⟶M1​i1​​Mi2​​M2​⟶0

叫分裂的，如果它同构于

0⟶M1→  pr1  M1⊕M2→  pr2  M2⟶00 \longrightarrow M_{1} \xrightarrow{\;\mathrm{pr}_{1}\;} M_{1} \oplus M_{2} \xrightarrow{\;\mathrm{pr}_{2}\;} M_{2} \longrightarrow 00⟶M1​pr1​​M1​⊕M2​pr2​​M2​⟶0

（即 i1i_{1}i1​ 是到直和第一个分量的含入、i2i_{2}i2​ 是到第二个分量的投影）。

说明

等价判据（在阿贝尔范畴里，三条等价）：

  • i2i_{2}i2​ 有截面 s:M2→Ms : M_{2} \to Ms:M2​→M（i2∘s=idi_{2} \circ s = \mathrm{id}i2​∘s=id）；
  • i1i_{1}i1​ 有收缩 r:M→M1r : M \to M_{1}r:M→M1​（r∘i1=idr \circ i_{1} = \mathrm{id}r∘i1​=id）；
  • M≅M1⊕M2M \cong M_{1} \oplus M_{2}M≅M1​⊕M2​ 与这个列相容。

证明。 记 i:=i1i := i_{1}i:=i1​、p:=i2p := i_{2}p:=i2​，则 iii 单、ppp 满且 im⁡i=ker⁡p\operatorname{im} i = \ker pimi=kerp。

  • 有截面   ⟹  \implies⟹ 分裂：设 ps=1M2p s = 1_{M_{2}}ps=1M2​​。则 p(1M−sp)=p−psp=0p(1_{M} - s p) = p - p s p = 0p(1M​−sp)=p−psp=0，故 1M−sp1_{M} - sp1M​−sp 落在 ker⁡p=im⁡i\ker p = \operatorname{im} ikerp=imi 里，于是存在 r:M→M1r : M \to M_{1}r:M→M1​ 使
ir=1M−sp.i r = 1_{M} - s p.ir=1M​−sp.

由 iii 单：i(ri)=(1M−sp) i=i−s(pi)=ii(r i) = (1_{M} - sp)\,i = i - s(p i) = ii(ri)=(1M​−sp)i=i−s(pi)=i（用了 pi=0p i = 0pi=0），故 ri=1M1r i = 1_{M_{1}}ri=1M1​​ ✓。与 pi=0p i = 0pi=0 合起来，p1:=rp_{1} := rp1​:=r、i1:=ii_{1} := ii1​:=i、p2:=pp_{2} := pp2​:=p、i2:=si_{2} := si2​:=s 满足双积的三条等式（ri=1r i = 1ri=1、ps=1p s = 1ps=1、ir+sp=1Mi r + s p = 1_{M}ir+sp=1M​，见「直和就是积」），即 MMM 就是 M1⊕M2M_{1} \oplus M_{2}M1​⊕M2​，该列分裂 ✓。

  • 分裂   ⟹  \implies⟹ 有截面：分裂时该列同构于 0→M1→ pr1 M1⊕M2→ pr2 M2→00 \to M_{1} \xrightarrow{\ \mathrm{pr}_{1}\ } M_{1} \oplus M_{2} \xrightarrow{\ \mathrm{pr}_{2}\ } M_{2} \to 00→M1​ pr1​ ​M1​⊕M2​ pr2​ ​M2​→0，而 pr2\mathrm{pr}_{2}pr2​ 有显然的截面（到第二个分量的含入），沿同构搬回去就得到 ppp 的截面 ✓。
  • 对偶：把同一论证搬到 Cop\mathcal{C}^{\mathrm{op}}Cop，得「分裂   ⟺  \iff⟺ iii 有收缩」✓。∎

⭐ 这就是「分裂引理」（split lemma）：在加法范畴里，「短正合列分裂」与「有截面」与「是直和」是同一件事。它把列论的问题化成直和的问题 —— 这是同调代数里最常用的一步化简。

⚠️ 短正合列一般不分裂（0→Z→2Z→Z/2→00 \to \mathbb{Z} \xrightarrow{2} \mathbb{Z} \to \mathbb{Z}/2 \to 00→Z2​Z→Z/2→0 就不分裂）—— 分裂是特殊情形，判断它分不分裂正是 Ext⁡1\operatorname{Ext}^{1}Ext1 要回答的问题。
