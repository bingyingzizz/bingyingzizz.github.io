短正合列

0⟶M1→  i1  M→  i2  M2⟶00 \longrightarrow M_{1} \xrightarrow{\;i_{1}\;} M \xrightarrow{\;i_{2}\;} M_{2} \longrightarrow 00⟶M1​i1​​Mi2​​M2​⟶0

叫分裂的，如果它同构于

0⟶M1→  pr1  M1⊕M2→  pr2  M2⟶00 \longrightarrow M_{1} \xrightarrow{\;\mathrm{pr}_{1}\;} M_{1} \oplus M_{2} \xrightarrow{\;\mathrm{pr}_{2}\;} M_{2} \longrightarrow 00⟶M1​pr1​​M1​⊕M2​pr2​​M2​⟶0

（即 i1i_{1}i1​ 是到直和第一个分量的含入、i2i_{2}i2​ 是到第二个分量的投影）。

说明

等价判据（在阿贝尔范畴里，三条等价）：

  • i2i_{2}i2​ 有截面 s:M2→Ms : M_{2} \to Ms:M2​→M（i2∘s=idi_{2} \circ s = \mathrm{id}i2​∘s=id）；
  • i1i_{1}i1​ 有收缩 r:M→M1r : M \to M_{1}r:M→M1​（r∘i1=idr \circ i_{1} = \mathrm{id}r∘i1​=id）；
  • M≅M1⊕M2M \cong M_{1} \oplus M_{2}M≅M1​⊕M2​ 与这个列相容。

证明。 记 i:=i1i := i_{1}i:=i1​、p:=i2p := i_{2}p:=i2​，则 iii 单、ppp 满且 im⁡i=ker⁡p\operatorname{im} i = \ker pimi=kerp。

  • 有截面   ⟹  \implies⟹ 分裂：设 ps=1M2p s = 1_{M_{2}}ps=1M2​​。则 p(1M−sp)=p−psp=0p(1_{M} - s p) = p - p s p = 0p(1M​−sp)=p−psp=0，故 1M−sp1_{M} - sp1M​−sp 落在 ker⁡p=im⁡i\ker p = \operatorname{im} ikerp=imi 里，于是存在 r:M→M1r : M \to M_{1}r:M→M1​ 使
ir=1M−sp.i r = 1_{M} - s p.ir=1M​−sp.

由 iii 单：i(ri)=(1M−sp) i=i−s(pi)=ii(r i) = (1_{M} - sp)\,i = i - s(p i) = ii(ri)=(1M​−sp)i=i−s(pi)=i（用了 pi=0p i = 0pi=0），故 ri=1M1r i = 1_{M_{1}}ri=1M1​​ ✓。与 pi=0p i = 0pi=0 合起来，p1:=rp_{1} := rp1​:=r、i1:=ii_{1} := ii1​:=i、p2:=pp_{2} := pp2​:=p、i2:=si_{2} := si2​:=s 满足双积的三条等式（ri=1r i = 1ri=1、ps=1p s = 1ps=1、ir+sp=1Mi r + s p = 1_{M}ir+sp=1M​，见「直和就是积」），即 MMM 就是 M1⊕M2M_{1} \oplus M_{2}M1​⊕M2​，该列分裂 ✓。

  • 分裂   ⟹  \implies⟹ 有截面：分裂时该列同构于 0→M1→ pr1 M1⊕M2→ pr2 M2→00 \to M_{1} \xrightarrow{\ \mathrm{pr}_{1}\ } M_{1} \oplus M_{2} \xrightarrow{\ \mathrm{pr}_{2}\ } M_{2} \to 00→M1​ pr1​ ​M1​⊕M2​ pr2​ ​M2​→0，而 pr2\mathrm{pr}_{2}pr2​ 有显然的截面（到第二个分量的含入），沿同构搬回去就得到 ppp 的截面 ✓。
  • 对偶：把同一论证搬到 Cop\mathcal{C}^{\mathrm{op}}Cop，得「分裂   ⟺  \iff⟺ iii 有收缩」✓。∎

⭐ 这就是「分裂引理」（split lemma）：在加法范畴里，「短正合列分裂」与「有截面」与「是直和」是同一件事。它把列论的问题化成直和的问题 —— 这是同调代数里最常用的一步化简。

⚠️ 短正合列一般不分裂（0→Z→2Z→Z/2→00 \to \mathbb{Z} \xrightarrow{2} \mathbb{Z} \to \mathbb{Z}/2 \to 00→Z2​Z→Z/2→0 就不分裂）—— 分裂是特殊情形，判断它分不分裂正是 Ext⁡1\operatorname{Ext}^{1}Ext1 要回答的问题。

  • 本页 ⟹ 平坦的直和项推出
    直和的正合性   ⟹  \implies⟹ 直和项继承平坦

    设 F=M⊕M2F = M \oplus M_{2}F=M⊕M2​ 平坦。由「与直和交换」，对每个 AAA 有自然同构

    A⊗RF  ≅  (A⊗RM)⊕(A⊗RM2).A \otimes_{R} F \;\cong\; (A \otimes_{R} M) \oplus (A \otimes_{R} M_{2}).A⊗R​F≅(A⊗R​M)⊕(A⊗R​M2​).

    （⇐\Leftarrow⇐） 若 MMM 与 M2M_{2}M2​ 平坦，右边正合，故 (−)⊗F(-) \otimes F(−)⊗F 正合 ✓。

    （  ⟹  \implies⟹） 设 (−)⊗F(-) \otimes F(−)⊗F 正合。对任意 f:A→A1f : A \to A_{1}f:A→A1​，f⊗Ff \otimes Ff⊗F 在分解下是对角块 diag(f⊗M, f⊗M2)\mathrm{diag}(f \otimes M,\ f \otimes M_{2})diag(f⊗M, f⊗M2​)。若 x=(x1,x2)x = (x_{1}, x_{2})x=(x1​,x2​) 被送到零，则两块分别把 x1x_{1}x1​、x2x_{2}x2​ 送到零；单射性逐分量判定，故 f⊗Mf \otimes Mf⊗M 单 ✓，MMM 平坦。

    直和情形：(−)⊗⨁iMi≅⨁i((−)⊗Mi)(-) \otimes \bigoplus_{i} M_{i} \cong \bigoplus_{i} ((-) \otimes M_{i})(−)⊗⨁i​Mi​≅⨁i​((−)⊗Mi​) 正合当且仅当每个分量正合 ✓。∎

    投射模平坦由这条加上 prop.free-flat 立刻得到：投射模是自由模的直和项。

    ⚠️ 只对直和成立。直积没有「逐分量判定」这种便利（张量不保积），所以平坦性对直积并不自动封闭。

    延拓性质   ⟹  \implies⟹ 单射可裂

    （2 与 3） 由 def.split-exact 的三条等价判据：iii 有收缩   ⟺  \iff⟺ 该短正合列分裂 ✓。∎

  • 直和就是积 ⟹ 本页推出
    「直和就是积」给出分裂短正合列的等价判据

    设 0→M1→ i M→ p M2→00 \to M_{1} \xrightarrow{\ i\ } M \xrightarrow{\ p\ } M_{2} \to 00→M1​ i ​M p ​M2​→0 正合（于是 iii 单、ppp 满、im⁡i=ker⁡p\operatorname{im}i = \ker pimi=kerp）。

    有截面就分裂。 设 ps=1M2p s = 1_{M_{2}}ps=1M2​​。则 p(1M−sp)=p−psp=0p(1_{M}-sp) = p - psp = 0p(1M​−sp)=p−psp=0，故 1M−sp1_{M}-sp1M​−sp 落在 ker⁡p=im⁡i\ker p = \operatorname{im}ikerp=imi 里，取 rrr 使 ir=1M−spi r = 1_{M}-spir=1M​−sp。由 iii 单：

    i(ri)=(1M−sp) i=i−s(pi)=i（用到 pi=0）⟹ri=1M1.i(ri) = (1_{M}-sp)\,i = i - s(pi) = i \quad\text{（用到 } pi = 0\text{）}\Longrightarrow ri = 1_{M_{1}}.i(ri)=(1M​−sp)i=i−s(pi)=i（用到 pi=0）⟹ri=1M1​​.

    于是 {i,p,r,s}\{i, p, r, s\}{i,p,r,s} 满足双积的三条等式 ri=1M1ri = 1_{M_{1}}ri=1M1​​、ps=1M2ps = 1_{M_{2}}ps=1M2​​、ir+sp=1Mir+sp = 1_{M}ir+sp=1M​。由「直和就是积」，这三条等式连同 pi=0pi = 0pi=0 使 MMM 成为 M1M_{1}M1​ 与 M2M_{2}M2​ 的双积：(M,p)(M,p)(M,p) 是积、(M,i)(M,i)(M,i) 是余积，特别地 M≅M1⊕M2M \cong M_{1}\oplus M_{2}M≅M1​⊕M2​ 且该列同构于标准列，即分裂。

    分裂就有截面。 分裂时该列同构于 0→M1→pr⁡1M1⊕M2→pr⁡2M2→00 \to M_{1} \xrightarrow{\operatorname{pr}_{1}} M_{1}\oplus M_{2} \xrightarrow{\operatorname{pr}_{2}} M_{2} \to 00→M1​pr1​​M1​⊕M2​pr2​​M2​→0，而 pr⁡2\operatorname{pr}_{2}pr2​ 有显然的截面 m2↦(0,m2)m_{2}\mapsto (0,m_{2})m2​↦(0,m2​)。

    两条合起来给出分裂短正合列的三条等价判据。■\blacksquare■

    关键的一步是「双积的三条等式」，而那正是「直和就是积」的内容 —— 没有它就只能说「该列分裂」，说不出 MMM 是直和。
