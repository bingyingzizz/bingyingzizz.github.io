## Statement · **draft**
**What it does**: collects unitary matrices, Hermitian matrices, and those matrices for which $A^{*}A$ and $AA^{*}$ do not matter in which order, into a single class — and this class is exactly the set of **unitarily diagonalizable** matrices.

Let $A \in M_{n}(\mathbb{C})$. Call $A$ a **normal matrix** if

$$A^{*}A = AA^{*} .$$
