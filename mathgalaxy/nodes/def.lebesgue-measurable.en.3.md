# Lebesgue measurable set　`def.lebesgue-measurable`
English entry · root `../`
[in graph](../#n=def.lebesgue-measurable)　·　[Chinese page (authoritative)](./def.lebesgue-measurable.md)

Take $f : \mathbb{R} \to \mathbb{R} Lebesgue$ and $g : \mathbb{R} \to \mathbb{R} Lebesgue$ measurable; then $g\circ f$ need not be measurable with respect to $\mathcal{L}$ — because $g^{-1}$ only guarantees pulling sets in $\mathfrak{B}_\mathbb{R}$ back to $\mathcal{L}$, whereas $f^{-1}$ needs a **non-Borel Lebesgue measurable set** in $\mathbb{R}$ to produce a failure.

The standard fix: make the intermediate function Borel measurable. If $g$ is Borel measurable and $f$ is Lebesgue measurable, then $g\circ f$ is Lebesgue measurable.
