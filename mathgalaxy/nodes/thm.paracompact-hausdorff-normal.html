陈述

设 XXX 是仿紧的 Hausdorff 空间。则 XXX 是正规的；证明会先得到更强的中间结论：XXX 已经是正则的。

说明

第 1 步：仿紧 Hausdorff   ⟹  \implies⟹ 正则。 设 x∈Xx \in Xx∈X、F⊆XF \subseteq XF⊆X 闭、x∉Fx \notin Fx∈/F。对每个 y∈Fy \in Fy∈F，Hausdorff 性给出不交开集 O1∋yO_{1} \ni yO1​∋y、O2∋xO_{2} \ni xO2​∋x；取 Gy:=O1G_{y} := O_{1}Gy​:=O1​，由 O1⊆X∖O2O_{1} \subseteq X \setminus O_{2}O1​⊆X∖O2​ 得 cl⁡Gy⊆X∖O2\operatorname{cl} G_{y} \subseteq X \setminus O_{2}clGy​⊆X∖O2​，故 x∉cl⁡Gyx \notin \operatorname{cl} G_{y}x∈/clGy​。于是

A:={ X∖F }∪{ Gy:y∈F }\mathcal{A} := \{\, X \setminus F \,\} \cup \{\, G_{y} : y \in F \,\}A:={X∖F}∪{Gy​:y∈F}

是开覆盖。取它的局部有限开加细 C\mathcal{C}C，令 W:=⋃{ C∈C:C∩F≠∅ }W := \bigcup \{\, C \in \mathcal{C} : C \cap F \ne \emptyset \,\}W:=⋃{C∈C:C∩F=∅}。则 F⊆WF \subseteq WF⊆W：FFF 的点 yyy 落在某个 CCC 里，而 C⊆X∖FC \subseteq X \setminus FC⊆X∖F 不可能（它含 yyy），故 C⊆GyC \subseteq G_{y}C⊆Gy​，于是 CCC 被计入 WWW。另一方面，每个计入 WWW 的 CCC 都落在某个 GyG_{y}Gy​ 里，故 x∉cl⁡Cx \notin \operatorname{cl} Cx∈/clC；由局部有限族的「并的闭包等于闭包之并」，cl⁡W=⋃{ cl⁡C:C∩F≠∅ }\operatorname{cl} W = \bigcup \{\, \operatorname{cl} C : C \cap F \ne \emptyset \,\}clW=⋃{clC:C∩F=∅} 不含 xxx。所以 W∋FW \ni FW∋F 与 X∖cl⁡W∋xX \setminus \operatorname{cl} W \ni xX∖clW∋x 是分开 FFF 与 xxx 的不交开集。 第 2 步：正则 +++ 仿紧   ⟹  \implies⟹ 正规。 设 A,BA, BA,B 是不交闭集。对每个 x∈Ax \in Ax∈A，正则性（x∉Bx \notin Bx∈/B）给出开集 Ox∋xO_{x} \ni xOx​∋x 使 cl⁡Ox∩B=∅\operatorname{cl} O_{x} \cap B = \emptysetclOx​∩B=∅。于是 A:={ X∖A }∪{ Ox:x∈A }\mathcal{A} := \{\, X \setminus A \,\} \cup \{\, O_{x} : x \in A \,\}A:={X∖A}∪{Ox​:x∈A} 是开覆盖，取局部有限开加细 D\mathcal{D}D，令 U:=⋃{ D∈D:D∩A≠∅ }U := \bigcup \{\, D \in \mathcal{D} : D \cap A \ne \emptyset \,\}U:=⋃{D∈D:D∩A=∅}。同上：A⊆UA \subseteq UA⊆U，且每个这样的 DDD 含于某个 OxO_{x}Ox​，给出 cl⁡D∩B=∅\operatorname{cl} D \cap B = \emptysetclD∩B=∅，故 cl⁡U∩B=∅\operatorname{cl} U \cap B = \emptysetclU∩B=∅。于是 U⊇AU \supseteq AU⊇A 与 X∖cl⁡U⊇BX \setminus \operatorname{cl} U \supseteq BX∖clU⊇B 是分开 A,BA, BA,B 的不交开集。∎

⭐ 这条把「仿紧」接进了分离公理的层级：紧 Hausdorff   ⟹  \implies⟹ 仿紧 Hausdorff   ⟹  \implies⟹ 正规   ⟹  \implies⟹ 正则   ⟹  \implies⟹ Hausdorff。40 号包里的正规性与 Urysohn 引理从此有了来处：紧 Hausdorff 空间（[0,1][0,1][0,1]、βI\beta IβI）都是仿紧的。

⚠️ Hausdorff 不能省：只有两个点的 Sierpiński 空间是仿紧的（它的开覆盖都有限，局部有限性自动成立）却不是 T1T_{1}T1​，因而非正规。

⚠️ 反方向也不成立：正规不必仿紧（[0,ω1)[0, \omega_{1})[0,ω1​)）。所以「仿紧」是真的一条新条件，而不是正规的改写。

    先证正则。 设 x∉Fx \notin Fx∈/F、FFF 闭。对每个 y∈Fy \in Fy∈F 取不交开集 O1∋yO_{1} \ni yO1​∋y、O2∋xO_{2} \ni xO2​∋x 并令 Gy:=O1G_{y} := O_{1}Gy​:=O1​：由 O1⊆X∖O2O_{1} \subseteq X \setminus O_{2}O1​⊆X∖O2​ 得 cl⁡Gy∩O2=∅\operatorname{cl} G_{y} \cap O_{2} = \emptysetclGy​∩O2​=∅，故 x∉cl⁡Gyx \notin \operatorname{cl} G_{y}x∈/clGy​。开覆盖 { X∖F }∪{ Gy }\{\, X \setminus F \,\} \cup \{\, G_{y} \,\}{X∖F}∪{Gy​} 由仿紧性有局部有限开加细 C\mathcal{C}C；令 W:=⋃{ C∈C:C∩F≠∅ }W := \bigcup \{\, C \in \mathcal{C} : C \cap F \ne \emptyset \,\}W:=⋃{C∈C:C∩F=∅}。
