# metric space　`def.metric-space`
English entry · root `../`
[in graph](../#n=def.metric-space)　·　[Chinese page (authoritative)](./def.metric-space.md)

\u26A0 **"$d$ takes values in $[0,+\infty)$ rather than $[0,+\infty]$"**: allowing $+\infty$ wrecks the notion of a connected component (the discrete metric $d \equiv +\infty$ misbehaves), so the standard definition takes finite values; if a map between metric spaces needs $+\infty$, say so explicitly.
