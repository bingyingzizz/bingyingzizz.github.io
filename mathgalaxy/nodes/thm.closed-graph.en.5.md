# closed graph theorem　`thm.closed-graph`
English entry · root `../`
[in graph](../#n=thm.closed-graph)　·　[Chinese page (authoritative)](./thm.closed-graph.md)

**Completeness.** Take $E = (C[0,1], \|\cdot\|_1)$ (incomplete) and $F = (C[0,1], \|\cdot\|_\infty)$ (complete), with $u = \mathrm{id}$. If $f_n \to f$ in $\|\cdot\|_1$ and $f_n \to g$ in $\|\cdot\|_\infty$, then convergence in $\|\cdot\|_1$ implies convergence in $L^1$, while convergence in $\|\cdot\|_\infty$ implies convergence in $L^1$, so $f = g$: the graph is closed. But $\|u\| = \sup\|f\|_\infty / \|f\|_1 = \infty$ is infinite, so $u$ is not bounded. Thus **if either the domain or the target is incomplete, the conclusion fails**.
