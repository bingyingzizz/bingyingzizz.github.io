# 模 n 的阶　`def.order-mod-n`
模 $n$ 的阶与循环子群
layer 11 · 定义 · 二次剩余与原根 · 数论
[在星图里打开](../#n=def.order-mod-n)　·　[节点索引](../index.md)

设 $\gcd(a, n) = 1$。使

$$a^{k} \equiv 1 \pmod n$$

成立的最小正整数 $k$ 叫 $a$ 模 $n$ 的**阶**，记 $\operatorname{ord}_{n}(a)$。
