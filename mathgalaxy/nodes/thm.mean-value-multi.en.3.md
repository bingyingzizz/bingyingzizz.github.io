# Mean Value Theorem in Several Variables　`thm.mean-value-multi`

⭐ So what is really useful in several variables is the **inequality version**: it needs only "apply the one-variable mean value theorem along a line segment + estimate the norm", and no existence of extrema.

The contraction mapping principle and the inverse function theorem later use nothing but this.

⚠ In the scalar case ($f$ has values in $\mathbb{R}$) the equality version needs care: the usual proof applies the one-dimensional MVT to $\varphi(t) = f(a + th)$ and yields "there exists $\theta$ with $f(a+h) - f(a) = Df(a + \theta h)(h)$" — here $\theta$ depends on $h$ and cannot be treated as a constant.
