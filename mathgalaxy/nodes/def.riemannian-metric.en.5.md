# Riemannian Metric　`def.riemannian-metric`
English entry · root `../`
[in graph](../#n=def.riemannian-metric)　·　[Chinese page (authoritative)](./def.riemannian-metric.md)

⚠ Not every Riemannian manifold embeds isometrically into a low-dimensional Euclidean space. Nash's theorem says that it always embeds into some sufficiently high-dimensional $\mathbb{R}^{N}$, but even then the "intrinsic" viewpoint is more economical: conclusions should depend only on $g$, not on the embedding.
