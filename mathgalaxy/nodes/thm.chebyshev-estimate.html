  1. 取 N=(2nn)N = \binom{2n}{n}N=(n2n​)。它在 4n2n+1≤N≤4n\dfrac{4^{n}}{2n+1} \le N \le 4^{n}2n+14n​≤N≤4n 之间（中间项最大 + 二项式和为 4n4^{n}4n）。
  1. 把 NNN 分解：n<p≤2nn < p \le 2nn<p≤2n 的素数都整除 NNN（它们在分子里出现、分母里不出现），于是 ∏n<p≤2np≤N≤4n\prod_{n < p \le 2n} p \le N \le 4^{n}∏n<p≤2n​p≤N≤4n —— 取对数得 θ(2n)−θ(n)≤2nlog⁡2\theta(2n) - \theta(n) \le 2n\log 2θ(2n)−θ(n)≤2nlog2。
  1. 反方向用 NNN 的 ppp-进指数：vp(N)=∑k(⌊2n/pk⌋−2⌊n/pk⌋)≤log⁡(2n)/log⁡pv_{p}(N) = \sum_{k}\left(\lfloor 2n/p^{k}\rfloor - 2\lfloor n/p^{k}\rfloor\right) \le \log(2n)/\log pvp​(N)=∑k​(⌊2n/pk⌋−2⌊n/pk⌋)≤log(2n)/logp，累乘得 N≤(2n)π(2n)N \le (2n)^{\pi(2n)}N≤(2n)π(2n)，与下界 N≥4n/(2n+1)N \ge 4^{n}/(2n+1)N≥4n/(2n+1) 合并即得 π(2n)≥c n/log⁡n\pi(2n) \ge c\,n/\log nπ(2n)≥cn/logn。
  1. 从 2n2n2n 过渡到一般的 xxx：用 θ\thetaθ 的单调性与 π\piπ 的分段常数性质夹住。

    要证：对 n>1n > 1n>1 存在素数 p∈(n,2n)p \in (n, 2n)p∈(n,2n)。

    反设没有这样的素数。取 N=(2nn)N = \binom{2n}{n}N=(n2n​)，则 NNN 的每个素因子 p≤np \le np≤n（因为 p>2np > 2np>2n 不可能，n<p<2nn < p < 2nn<p<2n 被假设排除，p=2np = 2np=2n 不是素数）。

    把 p≤np \le np≤n 的贡献拆成两段：

    • p≤2np \le \sqrt{2n}p≤2n​：由 vp(N)≤log⁡(2n)/log⁡pv_{p}(N) \le \log(2n)/\log pvp​(N)≤log(2n)/logp 得总贡献 ≤(2n)π(2n)≤(2n)2n\le (2n)^{\pi(\sqrt{2n})} \le (2n)^{\sqrt{2n}}≤(2n)π(2n​)≤(2n)2n​；

    三段合起来给出 N≤4n/3⋅(多项式因子)N \le 4^{n/3}\cdot(\text{多项式因子})N≤4n/3⋅(多项式因子)，与 N≥4n/(2n+1)N \ge 4^{n}/(2n+1)N≥4n/(2n+1) 矛盾（对充分大的 nnn）；小 nnn 逐个验证（n=2,3,⋯n = 2,3,\cdotsn=2,3,⋯）。
