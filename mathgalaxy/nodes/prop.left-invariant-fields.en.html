Statement

What it does: it differentiates a Lie group at the identity — left translation spreads each tangent vector at the identity into a global vector field, and these fields form a Lie algebra.

Let GGG be a Lie group and g:=TeG\mathfrak{g} := T_{e}Gg:=Te​G (eee the identity). A vector field X∈X(G)X \in \mathfrak{X}(G)X∈X(G) is left-invariant if for all g,h∈Gg, h \in Gg,h∈G

Xgh=d(Lg)h(Xh).X_{gh} = \mathrm{d}(L_{g})_{h}\bigl(X_{h}\bigr).Xgh​=d(Lg​)h​(Xh​).

Then:

  1. Evaluation is an isomorphism: X↦XeX \mapsto X_{e}X↦Xe​ is a linear isomorphism from the space of left-invariant vector fields onto g\mathfrak{g}g (inverse: v↦(g↦d(Lg)e(v))v \mapsto \bigl(g \mapsto \mathrm{d}(L_{g})_{e}(v)\bigr)v↦(g↦d(Lg​)e​(v))), so this space has dimension dim⁡G\dim GdimG;
  2. Closed under the Lie bracket: if X,YX, YX,Y are left-invariant, so is [X,Y][X,Y][X,Y];
  3. Hence g\mathfrak{g}g carries a Lie algebra structure: define [v,w]:=[v~,w~]e[v,w] := [\tilde v,\tilde w]_{e}[v,w]:=[v~,w~]e​ (v~\tilde vv~ the left-invariant field of vvv); then (g,[⋅,⋅])(\mathfrak{g},[\cdot,\cdot])(g,[⋅,⋅]) is a Lie algebra, the Lie algebra of GGG, and dim⁡g=dim⁡G\dim\mathfrak{g} = \dim Gdimg=dimG.

Thus "Lie group →\to→ Lie algebra" is a functor: Lie(G)\mathrm{Lie}(G)Lie(G).

Notes

Why evaluation is a bijection: left-invariance determines the value of XXX at ghghgh uniquely from XhX_{h}Xh​; taking h=eh = eh=e shows XXX is determined by XeX_{e}Xe​ (injectivity). Conversely, given v∈gv \in \mathfrak{g}v∈g, put Xg:=d(Lg)e(v)X_{g} := \mathrm{d}(L_{g})_{e}(v)Xg​:=d(Lg​)e​(v); then Xgh=d(Lgh)e(v)=d(Lg)h(d(Lh)e(v))=d(Lg)h(Xh)X_{gh} = \mathrm{d}(L_{gh})_{e}(v) = \mathrm{d}(L_{g})_{h}\bigl(\mathrm{d}(L_{h})_{e}(v)\bigr) = \mathrm{d}(L_{g})_{h}(X_{h})Xgh​=d(Lgh​)e​(v)=d(Lg​)h​(d(Lh​)e​(v))=d(Lg​)h​(Xh​) (chain rule plus Lgh=Lg∘LhL_{gh} = L_{g} \circ L_{h}Lgh​=Lg​∘Lh​), so it is left-invariant (surjectivity).

Smoothness: write everything in a chart; d(Lg)\mathrm{d}(L_{g})d(Lg​) is smooth in ggg.

Why the bracket descends: the key is naturality of the Lie bracket,

dF([X,Y]p)=[dF(X),dF(Y)]F(p),\mathrm{d}F\bigl([X,Y]_{p}\bigr) = \bigl[\mathrm{d}F(X),\mathrm{d}F(Y)\bigr]_{F(p)},dF([X,Y]p​)=[dF(X),dF(Y)]F(p)​,

where FFF is a diffeomorphism. Take F=LgF = L_{g}F=Lg​; left-invariance gives d(Lg)X=X\mathrm{d}(L_{g})X = Xd(Lg​)X=X and d(Lg)Y=Y\mathrm{d}(L_{g})Y = Yd(Lg​)Y=Y, hence d(Lg)[X,Y]=[X,Y]\mathrm{d}(L_{g})[X,Y] = [X,Y]d(Lg​)[X,Y]=[X,Y], i.e. [X,Y][X,Y][X,Y] is left-invariant. So the only substantive input in "a Lie group gives a Lie algebra" is this naturality.

Example: for G=GL⁡(n,R)G = \operatorname{GL}(n,\mathbb{R})G=GL(n,R) the Lie algebra is gl(n,R)\mathfrak{gl}(n,\mathbb{R})gl(n,R) with the commutator — because LAL_{A}LA​ is linear and d(LA)=A\mathrm{d}(L_{A}) = Ad(LA​)=A itself, left-invariant fields are X(A)=AMX(A) = AMX(A)=AM (MMM fixed), and the bracket computes to [M,N]=MN−NM[M,N] = MN - NM[M,N]=MN−NM.

"The Lie algebra determines the Lie group" is false: S1S^{1}S1 and R\mathbb{R}R both have the one-dimensional abelian Lie algebra, yet they are not isomorphic (compact versus non-compact). So g\mathfrak{g}g does not recover GGG, only the simply connected GGG — this is Lie's third theorem, not developed here.
