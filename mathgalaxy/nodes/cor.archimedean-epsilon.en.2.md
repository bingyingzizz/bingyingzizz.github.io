# the Archimedean property in epsilon form　`cor.archimedean-epsilon`
English entry · root `../`
[in graph](../#n=cor.archimedean-epsilon)　·　[Chinese page (authoritative)](./cor.archimedean-epsilon.md)

**(ii)** For every $x \in K$ there is a **unique** integer $n$ such that

$$n \le x < n + 1.$$

Write $n = \lfloor x \rfloor$, called the **integer part** of $x$ (the floor function); $\{x\} := x - \lfloor x \rfloor \in [0, 1)$ is called the **fractional part**.

## Notes · **draft**
⭐ (i) is the **standard form** in analysis of "take $n$ sufficiently large".

The Archimedean property originally says "$\mathbb{N}$ is unbounded", but in actual proofs one almost always uses (i): given $\varepsilon$, take $n > 1/\varepsilon$.
