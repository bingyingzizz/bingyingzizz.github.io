thm.nagata-smirnov · Nagata · Smirnov

Machine-drafted and pending author review. The Chinese text is authoritative.

Statement

Let XXX be a regular space (including T1T_{1}T1​) whose topology has a σ\sigmaσ-locally finite base (a base expressible as the union of countably many locally finite subfamilies). Then XXX is metrizable.

Conversely, every metrizable space has a σ\sigmaσ-locally finite base, so this is a necessary and sufficient condition.

Notes

Why this is stronger than Urysohn's theorem: A countable base can be split into countably many discrete families by placing each basic open set in a singleton family. Thus second countability is a special case of having a σ\sigmaσ-locally finite base. Here the hypothesis is weakened to σ\sigmaσ-local finiteness, with the same conclusion.

Proof sketch

  • Arrange the σ\sigmaσ-locally finite base in layers. Each layer is a locally finite family, and regularity allows these to be turned into locally finite open covers.
  • The key step (Nagata's systematic neighborhoods) is to construct a countable sequence of locally finite covers Gn\mathcal{G}_{n}Gn​ (n≥1n \ge 1n≥1) such that for every open set UUU and every x∈Ux \in Ux∈U, some member of one cover contains xxx in its interior and is contained in UUU.
  • Use these covers to define a nonnegative symmetric function by summing contributions to separation from each layer. Verify the three metric axioms and check that the induced topology is exactly the original topology.

⚠️ Scope: This node gives a proof outline and a reference. Munkres devotes all of Section 40 to the theorem.

⚠️ Regularity is essential. The base condition alone does not guarantee metrizability. The proof uses the ability to separate a point from a closed set by basic open sets.
