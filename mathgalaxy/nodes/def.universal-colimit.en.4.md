**Hypotheses used in each direction** (the three kinds of terms are different pullback-stability requirements):
- Universal colimits $\iff$ remain the colimit of that diagram after an arbitrary base change: unfolding the definition is free, provided the pullbacks and colimits written exist.
- Universal regular epimorphisms $\iff$ have all pullbacks still regular epi: again unfolding the definition; taking only the identity base change gives only regular epi, which does not conversely imply universal.
