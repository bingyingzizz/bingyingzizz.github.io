Statement

Let an≥0a_n \ge 0an​≥0, and set

α:=lim sup⁡n→∞ann\alpha := \limsup_{n \to \infty} \sqrt[n]{a_n}α:=n→∞limsup​nan​​

Then: if α<1\alpha < 1α<1, ∑an\sum a_n∑an​ converges; if α>1\alpha > 1α>1, ∑an\sum a_n∑an​ diverges; if α=1\alpha = 1α=1, there is no conclusion.

Notes

⭐ The mechanism is "comparison with a geometric series": when α<q<1\alpha < q < 1α<q<1, eventually ann≤q\sqrt[n]{a_n} \le qnan​​≤q, i.e. an≤qna_n \le q^{n}an​≤qn, and the geometric series converges.

⭐ Relation to the ratio test: the root test is stronger.

If lim⁡an+1/an\lim a_{n+1}/a_nliman+1​/an​ exists, then lim⁡ann\lim \sqrt[n]{a_n}limnan​​ also exists and the two are equal;

the converse fails (examples such as an=2−na_n = 2^{-n}an​=2−n and an=2−n−(−1)na_n = 2^{-n - (-1)^n}an​=2−n−(−1)n).

So "what the ratio test cannot decide, the root test may".
