陈述

在做什么：把 kkk-形式沿流形之间的光滑映射搬回去。Rn\mathbb{R}^{n}Rn 开集那版只是它的局部样子。

设 F:M→NF : M\to NF:M→N 是光滑映射，ω∈Ωk(N)\omega\in\Omega^{k}(N)ω∈Ωk(N)。拉回 F∗ω∈Ωk(M)F^{\ast}\omega\in\Omega^{k}(M)F∗ω∈Ωk(M) 逐点定义为

(F∗ω)p(v1,…,vk):=ωF(p)(dFpv1,…,dFpvk)(F^{\ast}\omega)_{p}(v_{1},\ldots,v_{k}) := \omega_{F(p)}\bigl(\mathrm{d}F_{p}v_{1},\ldots,\mathrm{d}F_{p}v_{k}\bigr)(F∗ω)p​(v1​,…,vk​):=ωF(p)​(dFp​v1​,…,dFp​vk​)

其中 vi∈TpMv_{i}\in T_{p}Mvi​∈Tp​M。则 F∗ωF^{\ast}\omegaF∗ω 光滑，且

  1. F∗F^{\ast}F∗ 是 R\mathbb{R}R-线性的；对函数 F∗f=f∘FF^{\ast}f = f\circ FF∗f=f∘F；
  2. 保楔积：F∗(ω∧η)=F∗ω∧F∗ηF^{\ast}(\omega\wedge\eta) = F^{\ast}\omega\wedge F^{\ast}\etaF∗(ω∧η)=F∗ω∧F∗η；
  3. 与 d\mathrm{d}d 交换：d(F∗ω)=F∗(dω)\mathrm{d}(F^{\ast}\omega) = F^{\ast}(\mathrm{d}\omega)d(F∗ω)=F∗(dω)；
  4. 保复合：(G∘F)∗=F∗∘G∗(G\circ F)^{\ast} = F^{\ast}\circ G^{\ast}(G∘F)∗=F∗∘G∗，(id⁡)∗=id⁡(\operatorname{id})^{\ast} = \operatorname{id}(id)∗=id。

于是 F∗:Ω∙(N)→Ω∙(M)F^{\ast} : \Omega^{\bullet}(N)\to\Omega^{\bullet}(M)F∗:Ω∙(N)→Ω∙(M) 是微分分次代数的同态。

说明

证明分四步：先说明 F∗ωF^{\ast}\omegaF∗ω 确实是光滑的 kkk-形式，再逐条验证 (1)–(4)，最后 (2)+(3) 合起来说明它是微分分次代数同态。所有等式都是逐点验证 —— 形式逐点定义，所以「逐点相等」就是「形式相等」。

光滑性：取 MMM 的图卡 (U,x)(U,x)(U,x) 与 NNN 的图卡 (V,y)(V,y)(V,y)，且 F(U)⊆VF(U)\subseteq VF(U)⊆V。在 yyy 坐标下 ω=∑IaI dyI\omega = \sum_{I} a_{I}\,\mathrm{d}y^{I}ω=∑I​aI​dyI，FFF 写成 y=F(x)=(F1(x),…,Fn(x))y = F(x) = (F^{1}(x), \ldots, F^{n}(x))y=F(x)=(F1(x),…,Fn(x))。则 F∗ω=∑I(aI∘F) dFi1∧⋯∧dFik,dFi=∑j∂Fi∂xj dxj.F^{\ast}\omega = \sum_{I}(a_{I}\circ F)\,\mathrm{d}F^{i_{1}}\wedge\cdots\wedge\mathrm{d}F^{i_{k}},\qquad \mathrm{d}F^{i} = \sum_{j}\frac{\partial F^{i}}{\partial x^{j}}\,\mathrm{d}x^{j}.F∗ω=∑I​(aI​∘F)dFi1​∧⋯∧dFik​,dFi=∑j​∂xj∂Fi​dxj. 右端系数是光滑函数的积与和，故 F∗ωF^{\ast}\omegaF∗ω 在 UUU 上光滑；图卡 UUU 覆盖 MMM，故整体光滑。（这里 dF\mathrm{d}FdF 与 切映射 的微分是同一个东西：dFp\mathrm{d}F_{p}dFp​ 是切映。）

逐条验证：(1) R\mathbb{R}R-线性由 ω↦ωF(p)(dFp⋅)\omega\mapsto\omega_{F(p)}(\mathrm{d}F_{p}\cdot)ω↦ωF(p)​(dFp​⋅) 对 ω\omegaω 线性得到；函数的拉回 (F∗f)(p)=f(F(p))=(f∘F)(p)(F^{\ast}f)(p) = f(F(p)) = (f\circ F)(p)(F∗f)(p)=f(F(p))=(f∘F)(p) 就是定义。

(2) 保楔积：固定 ppp，记 L=dFp:TpM→TF(p)NL = \mathrm{d}F_{p} : T_{p}M\to T_{F(p)}NL=dFp​:Tp​M→TF(p)​N。对 v1,…,vk+l∈TpMv_{1},\ldots,v_{k+l}\in T_{p}Mv1​,…,vk+l​∈Tp​M，用楔积的洗牌公式（对 (k,l)(k,l)(k,l)-洗牌 σ\sigmaσ 求和）：(L∗α∧L∗β)(v)=∑σsgn⁡(σ) (L∗α)(vσ(1),…)(L∗β)(vσ(k+1),…)=∑σsgn⁡(σ) α(Lvσ(1),…)β(Lvσ(k+1),…)=(α∧β)(Lv1,…,Lvk+l)=L∗(α∧β)(v).(L^{\ast}\alpha\wedge L^{\ast}\beta)(v) = \sum_{\sigma}\operatorname{sgn}(\sigma)\,(L^{\ast}\alpha)(v_{\sigma(1)},\ldots)(L^{\ast}\beta)(v_{\sigma(k+1)},\ldots) = \sum_{\sigma}\operatorname{sgn}(\sigma)\,\alpha(Lv_{\sigma(1)},\ldots)\beta(Lv_{\sigma(k+1)},\ldots) = (\alpha\wedge\beta)(Lv_{1},\ldots,Lv_{k+l}) = L^{\ast}(\alpha\wedge\beta)(v).(L∗α∧L∗β)(v)=∑σ​sgn(σ)(L∗α)(vσ(1)​,…)(L∗β)(vσ(k+1)​,…)=∑σ​sgn(σ)α(Lvσ(1)​,…)β(Lvσ(k+1)​,…)=(α∧β)(Lv1​,…,Lvk+l​)=L∗(α∧β)(v). 取 α=ωF(p)\alpha = \omega_{F(p)}α=ωF(p)​、β=ηF(p)\beta = \eta_{F(p)}β=ηF(p)​，即得 (2)。

(3) 与 d\mathrm{d}d 交换：两边都逐点定义，用图卡化到 Rn\mathbb{R}^{n}Rn 的开集。由线性只需验单项 ω=a dyI\omega = a\,\mathrm{d}y^{I}ω=adyI。此时 F∗ω=(a∘F) dFIF^{\ast}\omega = (a\circ F)\,\mathrm{d}F^{I}F∗ω=(a∘F)dFI，其中 dFI=dFi1∧⋯∧dFik\mathrm{d}F^{I} = \mathrm{d}F^{i_{1}}\wedge\cdots\wedge\mathrm{d}F^{i_{k}}dFI=dFi1​∧⋯∧dFik​。由反导子与 d2Fi=0\mathrm{d}^{2}F^{i} = 0d2Fi=0（FiF^{i}Fi 是函数）：d(F∗ω)=d(a∘F)∧dFI+(a∘F) d(dFI)=d(a∘F)∧dFI.\mathrm{d}(F^{\ast}\omega) = \mathrm{d}(a\circ F)\wedge\mathrm{d}F^{I} + (a\circ F)\,\mathrm{d}(\mathrm{d}F^{I}) = \mathrm{d}(a\circ F)\wedge\mathrm{d}F^{I}.d(F∗ω)=d(a∘F)∧dFI+(a∘F)d(dFI)=d(a∘F)∧dFI. 链式法则给 d(a∘F)=∑j(∂ja∘F) dFj\mathrm{d}(a\circ F) = \sum_{j}(\partial_{j}a\circ F)\,\mathrm{d}F^{j}d(a∘F)=∑j​(∂j​a∘F)dFj，代回：d(F∗ω)=∑j(∂ja∘F) dFj∧dFI=F∗(∑j∂ja dyj∧dyI)=F∗(da∧dyI)=F∗(dω),\mathrm{d}(F^{\ast}\omega) = \sum_{j}(\partial_{j}a\circ F)\,\mathrm{d}F^{j}\wedge\mathrm{d}F^{I} = F^{\ast}\Bigl(\sum_{j}\partial_{j}a\,\mathrm{d}y^{j}\wedge\mathrm{d}y^{I}\Bigr) = F^{\ast}(\mathrm{d}a\wedge\mathrm{d}y^{I}) = F^{\ast}(\mathrm{d}\omega),d(F∗ω)=∑j​(∂j​a∘F)dFj∧dFI=F∗(∑j​∂j​adyj∧dyI)=F∗(da∧dyI)=F∗(dω), 末步用了 dω=da∧dyI+a d(dyI)=da∧dyI\mathrm{d}\omega = \mathrm{d}a\wedge\mathrm{d}y^{I} + a\,\mathrm{d}(\mathrm{d}y^{I}) = \mathrm{d}a\wedge\mathrm{d}y^{I}dω=da∧dyI+ad(dyI)=da∧dyI。

(4) 保复合：链式法则给 d(G∘F)p=dGF(p)∘dFp\mathrm{d}(G\circ F)_{p} = \mathrm{d}G_{F(p)}\circ\mathrm{d}F_{p}d(G∘F)p​=dGF(p)​∘dFp​，于是 ((G∘F)∗ω)p(v1,…)=ωG(F(p))(dGF(p)dFpv1,…)=(F∗(G∗ω))p(v1,…).((G\circ F)^{\ast}\omega)_{p}(v_{1},\ldots) = \omega_{G(F(p))}\bigl(\mathrm{d}G_{F(p)}\mathrm{d}F_{p}v_{1},\ldots\bigr) = (F^{\ast}(G^{\ast}\omega))_{p}(v_{1},\ldots).((G∘F)∗ω)p​(v1​,…)=ωG(F(p))​(dGF(p)​dFp​v1​,…)=(F∗(G∗ω))p​(v1​,…). (id⁡)∗=id⁡(\operatorname{id})^{\ast} = \operatorname{id}(id)∗=id 显然。∎

小结：(1)+(2) 说 F∗F^{\ast}F∗ 是分次代数同态，(3) 说它与微分交换，(4) 说它保复合 —— 合起来，F∗F^{\ast}F∗ 是微分分次代数之间的（反变）映射。

⭐ 这一条是 de Rham 上同调「是函子」的全部内容：F∗F^{\ast}F∗ 与 d\mathrm{d}d 交换，故把闭形式送到闭形式、把恰当形式送到恰当形式，从而下到商空间 F∗:HdRk(N)→HdRk(M)F^{\ast} : H^{k}_{\mathrm{dR}}(N)\to H^{k}_{\mathrm{dR}}(M)F∗:HdRk​(N)→HdRk​(M)。方向是反的，这正是「上同调反变」的意思。

⚠️ 与向量场的对照：向量场不能沿任意光滑映射拉回（要 FFF 是微分同胚才能前推），形式可以。这个不对称不是技术缺陷，而是「形式是 T∗MT^{\ast}MT∗M 的截面、向量场是 TMTMTM 的截面」的直接后果。

⚠️ 本图缺的节点/边：(3) 里 d(dFI)=0\mathrm{d}(\mathrm{d}F^{I}) = 0d(dFI)=0 用到「d2=0\mathrm{d}^{2} = 0d2=0」（函数情形即 Clairaut 定理），本图没有 Clairaut 节点；洗牌公式也没有独立节点，故在此写全。若日后加这两条，可改为引用。

Statement reviewed

What it does: it carries a kkk-form back along a smooth map between manifolds. The version for open subsets of Rn\mathbb{R}^{n}Rn is only its local appearance.

Let F:M→NF : M\to NF:M→N be a smooth map and ω∈Ωk(N)\omega\in\Omega^{k}(N)ω∈Ωk(N). The pullback F∗ω∈Ωk(M)F^{\ast}\omega\in\Omega^{k}(M)F∗ω∈Ωk(M) is defined pointwise by

(F∗ω)p(v1,…,vk):=ωF(p)(dFpv1,…,dFpvk)(F^{\ast}\omega)_{p}(v_{1},\ldots,v_{k}) := \omega_{F(p)}\bigl(\mathrm{d}F_{p}v_{1},\ldots,\mathrm{d}F_{p}v_{k}\bigr)(F∗ω)p​(v1​,…,vk​):=ωF(p)​(dFp​v1​,…,dFp​vk​)

for vi∈TpMv_{i}\in T_{p}Mvi​∈Tp​M. Then F∗ωF^{\ast}\omegaF∗ω is smooth, and

  1. F∗F^{\ast}F∗ is R\mathbb{R}R-linear; on functions F∗f=f∘FF^{\ast}f = f\circ FF∗f=f∘F;
  2. it preserves the wedge product: F∗(ω∧η)=F∗ω∧F∗ηF^{\ast}(\omega\wedge\eta) = F^{\ast}\omega\wedge F^{\ast}\etaF∗(ω∧η)=F∗ω∧F∗η;
  3. it commutes with d\mathrm{d}d: d(F∗ω)=F∗(dω)\mathrm{d}(F^{\ast}\omega) = F^{\ast}(\mathrm{d}\omega)d(F∗ω)=F∗(dω);
  4. it preserves composition: (G∘F)∗=F∗∘G∗(G\circ F)^{\ast} = F^{\ast}\circ G^{\ast}(G∘F)∗=F∗∘G∗ and (id⁡)∗=id⁡(\operatorname{id})^{\ast} = \operatorname{id}(id)∗=id.

Thus F∗:Ω∙(N)→Ω∙(M)F^{\ast} : \Omega^{\bullet}(N)\to\Omega^{\bullet}(M)F∗:Ω∙(N)→Ω∙(M) is a homomorphism of differential graded algebras.
