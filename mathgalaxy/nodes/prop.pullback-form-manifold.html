陈述

在做什么：把 kkk-形式沿流形之间的光滑映射搬回去。Rn\mathbb{R}^{n}Rn 开集那版只是它的局部样子。

设 F:M→NF : M\to NF:M→N 是光滑映射，ω∈Ωk(N)\omega\in\Omega^{k}(N)ω∈Ωk(N)。拉回 F∗ω∈Ωk(M)F^{\ast}\omega\in\Omega^{k}(M)F∗ω∈Ωk(M) 逐点定义为

(F∗ω)p(v1,…,vk):=ωF(p)(dFpv1,…,dFpvk)(F^{\ast}\omega)_{p}(v_{1},\ldots,v_{k}) := \omega_{F(p)}\bigl(\mathrm{d}F_{p}v_{1},\ldots,\mathrm{d}F_{p}v_{k}\bigr)(F∗ω)p​(v1​,…,vk​):=ωF(p)​(dFp​v1​,…,dFp​vk​)

其中 vi∈TpMv_{i}\in T_{p}Mvi​∈Tp​M。则 F∗ωF^{\ast}\omegaF∗ω 光滑，且

  1. F∗F^{\ast}F∗ 是 R\mathbb{R}R-线性的；对函数 F∗f=f∘FF^{\ast}f = f\circ FF∗f=f∘F；
  2. 保楔积：F∗(ω∧η)=F∗ω∧F∗ηF^{\ast}(\omega\wedge\eta) = F^{\ast}\omega\wedge F^{\ast}\etaF∗(ω∧η)=F∗ω∧F∗η；
  3. 与 d\mathrm{d}d 交换：d(F∗ω)=F∗(dω)\mathrm{d}(F^{\ast}\omega) = F^{\ast}(\mathrm{d}\omega)d(F∗ω)=F∗(dω)；
  4. 保复合：(G∘F)∗=F∗∘G∗(G\circ F)^{\ast} = F^{\ast}\circ G^{\ast}(G∘F)∗=F∗∘G∗，(id⁡)∗=id⁡(\operatorname{id})^{\ast} = \operatorname{id}(id)∗=id。

于是 F∗:Ω∙(N)→Ω∙(M)F^{\ast} : \Omega^{\bullet}(N)\to\Omega^{\bullet}(M)F∗:Ω∙(N)→Ω∙(M) 是微分分次代数的同态。

说明

证明的路线：TpMT_{p}MTp​M 上的交错型在坐标基 dxI\mathrm{d}x^{I}dxI 上线性展开，于是只需在单项 ω=dyI\omega = \mathrm{d}y^{I}ω=dyI 上验 —— 而那正是链式法则加「d2=0\mathrm{d}^{2}=0d2=0」的机械计算，再用上一句的线性拼回去。骨架在边上。

它和「d\mathrm{d}d 良定」互为因果：开集间那条（prop.pullback-forms）已经证过 (3)，流形上用图卡局部化即可；反过来，正因为 d\mathrm{d}d 与拉回交换、而拉回只用链式法则定义，d\mathrm{d}d 才不依赖坐标（prop.exterior-derivative-manifold）。两条一起看，才知道谁也不是循环论证 —— 开集上的 (3) 是初等的。

⭐ 这一条是 de Rham 上同调「是函子」的全部内容：FFF 光滑   ⟹  \implies⟹ F∗F^{\ast}F∗ 与 d\mathrm{d}d 交换   ⟹  \implies⟹ F∗F^{\ast}F∗ 下到商空间，得 F∗:HdRk(N)→HdRk(M)F^{\ast} : H^{k}_{\mathrm{dR}}(N)\to H^{k}_{\mathrm{dR}}(M)F∗:HdRk​(N)→HdRk​(M)。方向是反的，这正是「上同调反变」的意思。

⚠️ 与向量场的对照：向量场不能沿任意光滑映射拉回（要 FFF 是微分同胚才能前推），形式可以。这个不对称不是技术缺陷，而是「形式是 T∗MT^{\ast}MT∗M 的截面、向量场是 TMTMTM 的截面」的直接后果。

Statement reviewed

What it does: it carries a kkk-form back along a smooth map between manifolds. The version for open subsets of Rn\mathbb{R}^{n}Rn is only its local appearance.

Let F:M→NF : M\to NF:M→N be a smooth map and ω∈Ωk(N)\omega\in\Omega^{k}(N)ω∈Ωk(N). The pullback F∗ω∈Ωk(M)F^{\ast}\omega\in\Omega^{k}(M)F∗ω∈Ωk(M) is defined pointwise by

(F∗ω)p(v1,…,vk):=ωF(p)(dFpv1,…,dFpvk)(F^{\ast}\omega)_{p}(v_{1},\ldots,v_{k}) := \omega_{F(p)}\bigl(\mathrm{d}F_{p}v_{1},\ldots,\mathrm{d}F_{p}v_{k}\bigr)(F∗ω)p​(v1​,…,vk​):=ωF(p)​(dFp​v1​,…,dFp​vk​)

for vi∈TpMv_{i}\in T_{p}Mvi​∈Tp​M. Then F∗ωF^{\ast}\omegaF∗ω is smooth, and

  1. F∗F^{\ast}F∗ is R\mathbb{R}R-linear; on functions F∗f=f∘FF^{\ast}f = f\circ FF∗f=f∘F;
  2. it preserves the wedge product: F∗(ω∧η)=F∗ω∧F∗ηF^{\ast}(\omega\wedge\eta) = F^{\ast}\omega\wedge F^{\ast}\etaF∗(ω∧η)=F∗ω∧F∗η;
  3. it commutes with d\mathrm{d}d: d(F∗ω)=F∗(dω)\mathrm{d}(F^{\ast}\omega) = F^{\ast}(\mathrm{d}\omega)d(F∗ω)=F∗(dω);
  4. it preserves composition: (G∘F)∗=F∗∘G∗(G\circ F)^{\ast} = F^{\ast}\circ G^{\ast}(G∘F)∗=F∗∘G∗ and (id⁡)∗=id⁡(\operatorname{id})^{\ast} = \operatorname{id}(id)∗=id.

Thus F∗:Ω∙(N)→Ω∙(M)F^{\ast} : \Omega^{\bullet}(N)\to\Omega^{\bullet}(M)F∗:Ω∙(N)→Ω∙(M) is a homomorphism of differential graded algebras.
