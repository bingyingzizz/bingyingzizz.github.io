# Riemannian Metric　`def.riemannian-metric`
English entry · root `../`
[in graph](../#n=def.riemannian-metric)　·　[Chinese page (authoritative)](./def.riemannian-metric.md)

(bilinear, symmetric, positive definite), and for all smooth vector fields $X,Y$ the function $p\mapsto g_{p}(X_{p},Y_{p})$ is smooth. $(M,g)$ is called a **Riemannian manifold**. In a chart,

$$g = \sum_{i,j=1}^{n}g_{ij}\,\mathrm{d}x^{i}\mathrm{d}x^{j},\qquad g_{ij} = g(\partial_{i},\partial_{j}),$$

where $(g_{ij})$ is symmetric positive definite. This yields length and volume:

$$L(\gamma) = \int_{a}^{b}\sqrt{g_{\gamma(t)}\bigl(\dot\gamma(t),\dot\gamma(t)\bigr)}\,\mathrm{d}t ,\qquad \mathrm{d}V = \sqrt{\det(g_{ij})}\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n}.$$
