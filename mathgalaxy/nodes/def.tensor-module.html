设 RRR 是含幺环，MMM 是右 RRR-模、NNN 是左 RRR-模。取以 M×NM \times NM×N 为基的自由阿贝尔群 F:=Z(M×N)F := \mathbb{Z}^{(M \times N)}F:=Z(M×N)，令 K⊆FK \subseteq FK⊆F 是由形如

M⊗RN:=F/K,m⊗n:=[ (m,n) ].M \otimes_{R} N := F / K, \qquad m \otimes n := [\,(m, n)\,].M⊗R​N:=F/K,m⊗n:=[(m,n)].

它的元素是纯张量 m⊗nm \otimes nm⊗n 的有限和 ∑imi⊗ni\sum_{i} m_{i} \otimes n_{i}∑i​mi​⊗ni​。像满足两条双加性关系与一条平衡关系 mr⊗n=m⊗rnm r \otimes n = m \otimes r nmr⊗n=m⊗rn；并且对每个平衡双加性映射 B:M×N→PB : M \times N \to PB:M×N→P（PPP 是阿贝尔群），存在唯一的群同态

B~:M⊗RN⟶P,B~(m⊗n)=B(m,n).\widetilde{B} : M \otimes_{R} N \longrightarrow P, \qquad \widetilde{B}(m \otimes n) = B(m, n).B:M⊗R​N⟶P,B(m⊗n)=B(m,n).

若 RRR 交换，r⋅(m⊗n):=(mr)⊗nr \cdot (m \otimes n) := (m r) \otimes nr⋅(m⊗n):=(mr)⊗n 使 M⊗RNM \otimes_{R} NM⊗R​N 成为 RRR-模。

说明

读法：三个关系各管一件事 —— 前两条说 ⊗\otimes⊗ 对两个变元分别可加，第三条 mr⊗n=m⊗rnm r \otimes n = m \otimes r nmr⊗n=m⊗rn 说「RRR 的作用可以从一边搬到另一边」。交换环上第三条写成 rm⊗n=m⊗rnr m \otimes n = m \otimes r nrm⊗n=m⊗rn，最眼熟。

元素不是纯张量：一般元素是有限和，所以「∑mi⊗ni\sum m_{i} \otimes n_{i}∑mi​⊗ni​ 是否为零」不能逐项看。纯张量仍可能等于零：Z/2⊗ZZ/3=0\mathbb{Z}/2 \otimes_{\mathbb{Z}} \mathbb{Z}/3 = 0Z/2⊗Z​Z/3=0，因为

1⊗1=(3⋅1)⊗1=1⊗(3⋅1)=1⊗0=0.1 \otimes 1 = (3 \cdot 1) \otimes 1 = 1 \otimes (3 \cdot 1) = 1 \otimes 0 = 0 .1⊗1=(3⋅1)⊗1=1⊗(3⋅1)=1⊗0=0.

⭐ 构造与基无关：万有性质说任何「把双线性换成线性」的对象都同构于它，所以换一种造法（例如先做自由模再取商）得到同一个东西。

📌 与 prop.module-tensor-universal 的关系：那是 Z\mathbb{Z}Z 与域系数下的特例；一般 RRR 上多出来的只有平衡那条关系。

定义引用 2

  • 模 → 本页定义引用

    张量积的原料正是模：MMM 取右模、NNN 取左模，商掉的第三条关系就是两条模作用的对接。

  • 双线性型 → 本页定义引用

    「双线性」在模上变成「平衡双加性」：多出来的那条 B(mr,n)=B(m,rn)B(m r, n) = B(m, r n)B(mr,n)=B(m,rn) 是标量从一边搬到另一边；域上它自动满足，所以向量空间张量积用不到它。
