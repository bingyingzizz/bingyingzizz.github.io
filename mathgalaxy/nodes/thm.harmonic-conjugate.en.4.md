# harmonic conjugate　`thm.harmonic-conjugate`
English entry · root `../`
[in graph](../#n=thm.harmonic-conjugate)　·　[Chinese page (authoritative)](./thm.harmonic-conjugate.md)

⚠ Simple connectivity **cannot be dropped**: $u(z) = \ln|z|$ is harmonic on $\mathbb{C}^{\times}$, but it is not the real part of any single-valued holomorphic function — that would require $\operatorname{Log}$ itself, and $\operatorname{Log}$ is multivalued.

Going once around the origin, $\oint \omega = 2\pi \ne 0$.

📌 The converse direction (holomorphic $\implies$ real part harmonic) **does not** need simple connectivity, only the Cauchy–Riemann equations. So "harmonic" is slightly wider than "real part of a holomorphic function"; what is missing is precisely a topological condition.
