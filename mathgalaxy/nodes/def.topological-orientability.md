# 拓扑可定向性　`def.topological-orientability`
定义：拓扑流形的可定向性（定向图册 / 定向双覆盖）
layer 0 · 定义 · 曲面的地形 · 拓扑学
[在星图里打开](../#n=def.topological-orientability)　·　[节点索引](../index.md)
