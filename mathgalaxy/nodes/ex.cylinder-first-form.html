半径 RRR 的圆柱面用 r(u,v)=(Rcos⁡u, Rsin⁡u, v)r(u, v) = (R\cos u,\ R\sin u,\ v)r(u,v)=(Rcosu, Rsinu, v) 参数化（0≤u<2π0 \le u < 2\pi0≤u<2π、v∈Rv \in \mathbb{R}v∈R）。则

E=⟨ru,ru⟩=R2,F=⟨ru,rv⟩=0,G=⟨rv,rv⟩=1,E = \langle r_{u}, r_{u}\rangle = R^{2},\quad F = \langle r_{u}, r_{v}\rangle = 0,\quad G = \langle r_{v}, r_{v}\rangle = 1,E=⟨ru​,ru​⟩=R2,F=⟨ru​,rv​⟩=0,G=⟨rv​,rv​⟩=1,

即第一基本形式 I=R2 du2+dv2\mathrm{I} = R^{2}\,\mathrm{d}u^{2} + \mathrm{d}v^{2}I=R2du2+dv2，Gauss 曲率 K=0K = 0K=0。

说明

为什么 K=0K = 0K=0：E,F,GE, F, GE,F,G 全是常数   ⟹  \implies⟹ 所有 Christoffel 符号为零   ⟹  \implies⟹ 曲率张量为零。直观上圆柱可以「摊平」成矩形而不改变长度与角度 —— 这就是 K=0K = 0K=0 的意思。

⭐ 它是「内蕴 = 外在」的最干净反例素材：圆柱的 K=0K = 0K=0（内蕴平坦），但它不是平面 ——整块摊平会让 uuu 方向的边粘起来，所以圆柱与平面只局部等距（沿 uuu 绕一圈后回不到原来的点）。「局部等距」与「整体等距」的区别，在这一个例子里就能看清。

📌 第二基本形式不为零：k1=1/Rk_{1} = 1/Rk1​=1/R、k2=0k_{2} = 0k2​=0 —— 圆柱在 R3\mathbb{R}^{3}R3 里是弯的，但两个主曲率一正一「零」使 K=k1k2=0K = k_{1}k_{2} = 0K=k1​k2​=0。这直接说明「外在地弯」与「内在地弯」是两件事。

⚠ 参数化的退化：u=0u = 0u=0 与 u=2πu = 2\piu=2π 是同一条母线，所以 rrr 只是局部参数化（整个圆柱要两张图卡或允许周期性）。这与极坐标在 r=0r = 0r=0 处退化是同一类问题（见 极坐标的 Christoffel 符号）。
