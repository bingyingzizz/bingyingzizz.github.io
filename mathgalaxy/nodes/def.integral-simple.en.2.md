## Notes · **draft**
This is exactly "area $=$ height of each layer $\times$ measure of each layer" — written in the same shape as a Riemann sum, only intervals are replaced by measurable sets.

One must check **well-definedness**: the same $\varphi$ can be written in different standard forms (for instance by splitting some $E_{j}$ further), but finite additivity of $\mu$ gives the same result.

Convention $0 \cdot \infty = 0$: this step is crucial — it makes the integral of "the function equal to 0 on a set of infinite measure" equal to 0, as intuition demands.
