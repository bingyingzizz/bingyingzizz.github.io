# Basic Properties of Weakly Hausdorff Spaces　`prop.weak-hausdorff-basic`
English entry · root `../`
[in graph](../#n=prop.weak-hausdorff-basic)　·　[Chinese page (authoritative)](./prop.weak-hausdorff-basic.md)

- every compact Hausdorff subspace of $X$ is closed;
- $X$ is $T_{1}$ (a point is a compact Hausdorff subspace);
- for every continuous $f : S \to X$ ($S$ compact Hausdorff), $f(S)$ is **compact Hausdorff**;
- the **diagonal** $\Delta_{X} \subseteq X \times X$ is $k$-closed; conversely, if $X$ is compactly generated, then diagonal $k$-closed $\implies$ $X$ weak Hausdorff;
- if moreover $Y$ is weak Hausdorff and $f, g : X \rightrightarrows Y$ continuous, then $\ker(f, g) = \{\, x : f(x) = g(x) \,\} \subseteq X$ is $k$-closed.
