# Jacobian Matrix　`def.jacobian`
English entry · root `../`
[in graph](../#n=def.jacobian)　·　[Chinese page (authoritative)](./def.jacobian.md)

If $f$ is differentiable at $a$, then $J_f(a)$ is exactly the matrix of the linear map $Df(a)$ in the standard bases.

## Notes · **draft**
⭐ The chain rule in matrix form is just **matrix multiplication**: $J_{g \circ f}(a) = J_g(f(a))\, J_f(a)$ (`thm.chain-rule-multi`).

Composition of linear maps corresponds to matrix multiplication — the total differential is exactly the transport of this linear-algebra fact into calculus.
