# 绝对值的运算性质　`prop.abs-properties`
命题：绝对值的运算性质

设 $K$ 是有序域，$x, y \in K$，$c \ge 0$。则

**(i)** $|x| \ge 0$，$|x| = 0 \iff x = 0$，$|-x| = |x|$，$-|x| \le x \le |x|$；

**(ii)** $|xy| = |x|\,|y|$，且 $y \ne 0 \implies \left|\dfrac{x}{y}\right| = \dfrac{|x|}{|y|}$；

**(iii)** $|x|^{2} = x^{2}$；

**(iv)** $|x| \le c \iff -c \le x \le c$；$|x| < c \iff -c < x < c$；
