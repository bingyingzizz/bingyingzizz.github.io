# Frobenius theorem　`thm.frobenius`
English entry · root `../`
[in graph](../#n=thm.frobenius)　·　[Chinese page (authoritative)](./thm.frobenius.md)

**V. The calculation for $k=n-1$ and $\omega\wedge\mathrm{d}\omega=0$.** Suppose $\mathcal{D}=\ker\omega$ and $\omega$ is nowhere zero. For $X,Y\in\ker\omega$,

$$\mathrm{d}\omega(X,Y)=X\omega(Y)-Y\omega(X)-\omega([X,Y])=-\omega([X,Y]).$$

Thus involutivity ($[X,Y]\in\ker\omega$) is equivalent to $\mathrm{d}\omega$ vanishing identically on $\ker\omega\times\ker\omega$. In turn, $\mathrm{d}\omega$ vanishes on $\ker\omega$ if and only if $\mathrm{d}\omega=\omega\wedge\alpha$ (for some $1$-form $\alpha$), which is equivalent to $\omega\wedge\mathrm{d}\omega=0$, as one sees by expanding both sides using the same $\alpha$. $\square$
