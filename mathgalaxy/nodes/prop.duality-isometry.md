# ‖g‖_q = ‖φ_g‖　`prop.duality-isometry`
命题：$\|\varphi_g\| = \|g\|_q$（$\mu$ 半有限时也含 $q = \infty$）
layer 19 · 命题 · L^p 空间 · 分析学

设 $p, q$ 共轭。则

- 若 $1 \le q < \infty$，$g \in L^q$，就有 $\|\varphi_g\| = \|g\|_q$；
- 若 $\mu$ 是**半有限**的，$q = \infty$ 时同样成立。
