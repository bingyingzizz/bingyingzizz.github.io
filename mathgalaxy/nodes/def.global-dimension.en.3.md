# Global Dimension　`def.global-dimension`
English entry · root `../`
[in graph](../#n=def.global-dimension)　·　[Chinese page (authoritative)](./def.global-dimension.md)

**Four basic examples**:

- $\operatorname{gl.dim} R = 0 \iff R$ is semisimple (Wedderburn–Artin: every module is projective). Over a field the global dimension is $0$.

- $\operatorname{gl.dim} \mathbb{Z} = 1$ (a principal ideal domain, see “Global Dimension of a Principal Ideal Domain”).

- $\operatorname{gl.dim} k[x_{1}, \ldots, x_{n}] = n$ (Hilbert’s syzygy theorem and the Koszul complex).

- $\operatorname{gl.dim} R = \infty$ can occur (for example, for $k[x,y]/(xy)$). In this case there is no uniform upper bound.
