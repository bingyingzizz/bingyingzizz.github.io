# L^p 自反　`cor.lp-reflexive`
推论：$1 < p < \infty$ 时 $L^p \cong (L^p)^{**}$
layer 18 · 推论 · L^p 空间 · 分析学

设 $1 < p < \infty$。则

$$L^p \cong (L^p)^{**}$$

即 $L^p$ 是**自反**的 Banach 空间。
