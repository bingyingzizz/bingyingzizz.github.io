Statement

What it does: characterizes those operators that "vanish after being applied repeatedly". It is the protagonist of the structure theorem for nilpotent parts (everything in the Jordan form off the diagonal).

Let T:V→VT : V \to VT:V→V be linear (dim⁡V=n<∞\dim V = n < \inftydimV=n<∞). Call TTT nilpotent if

Tk=0T^{k} = 0Tk=0 (for some k≥1k \ge 1k≥1)

Matrix case: for Ak=0A^{k} = 0Ak=0, one calls AAA a nilpotent matrix.

Equivalent conditions (often used as tests):

  1. all eigenvalues of TTT are 000;
  2. the characteristic polynomial is xnx^{n}xn;
  3. Tn=0T^{n} = 0Tn=0 (n=dim⁡Vn = \dim Vn=dimV suffices — Cayley–Hamilton).

Structure: a nilpotent operator can always be brought to a direct sum of Jordan blocks Jk(0)J_{k}(0)Jk​(0); the order of the largest block equals the nilpotency index of TTT (the least exponent at which Tk=0T^{k} = 0Tk=0 first holds, namely kkk).

Notes

The standard example: the shift operator T(x1,…,xn)=(0,x1,…,xn−1)T(x_{1}, \ldots, x_{n}) = (0, x_{1}, \ldots, x_{n-1})T(x1​,…,xn​)=(0,x1​,…,xn−1​), with Tn=0T^{n} = 0Tn=0 while Tn−1≠0T^{n-1} \ne 0Tn−1=0. Its matrix is the "shift up by one" matrix, namely a single Jn(0)J_{n}(0)Jn​(0).

⭐ Why nilpotent operators matter so much: every operator splits as "diagonalizable part + nilpotent part" T=S+NT = S + NT=S+N (SSS diagonalizable, NNN nilpotent, SN=NSSN = NSSN=NS; this is the Jordan–Chevalley decomposition). So "understanding nilpotent" = "understanding all the difficulty of non-diagonalizability".

⚠️ Nilpotent must not be confused with "rank less than nnn": (0100)\begin{pmatrix} 0 & 1 \\ 0 & 0\end{pmatrix}(00​10​) is nilpotent, but (0001)\begin{pmatrix} 0 & 0 \\ 0 & 1\end{pmatrix}(00​01​) has rank 111 and is not nilpotent (its eigenvalues are 111 and 000).

The criterion is all eigenvalues zero, not rank.

⚠️ A nilpotent matrix has trace and determinant both 000, but the converse fails ((100−1)\begin{pmatrix} 1 & 0 \\ 0 & -1\end{pmatrix}(10​0−1​) has both equal to 000 yet is not nilpotent).

Of the four criteria, "Tn=0T^{n} = 0Tn=0" looks most like a definition but is actually the most expensive:

  • definition Tk=0T^{k} = 0Tk=0 (some kkk)   ⟺  \iff⟺ all eigenvalues are 000: (  ⟹  )(\implies)(⟹) is obvious (000 is the only possible eigenvalue); (⇔)(\Leftrightarrow)(⇔) needs the characteristic polynomial to split (over C\mathbb{C}C or an algebraic closure), otherwise the word "eigenvalue" is meaningless.
  • characteristic polynomial =xn= x^{n}=xn   ⟺  \iff⟺ all eigenvalues zero + adding algebraic multiplicities: this step uses Vieta's formulas and requires finite dimension.
  • Tn=0T^{n} = 0Tn=0 (n=dim⁡Vn = \dim Vn=dimV): this step uses Cayley–Hamilton (thm.cayley-hamilton). ⚠️ It gives "kkk can be taken to be nnn", whereas the definition only requires "some kkk" — this quantifier difference is exactly what Cayley–Hamilton provides.
  • nilpotent   ⟺  \iff⟺ there is a basis in which the matrix is strictly upper triangular (with 000 on the diagonal): this step uses the Jordan form or the splitting of the characteristic polynomial.

⚠️ Nilpotent ≠\ne= rank-deficient: (0001)\begin{pmatrix}0&0\\0&1\end{pmatrix}(00​01​) has rank 1<21 < 21<2 but is not nilpotent (eigenvalue 111). The criterion is always all eigenvalues zero. ⚠️ In infinite dimension "Tn=0T^{n} = 0Tn=0" fails: the shift operator on ℓ2\ell^{2}ℓ2 has no nonzero power equal to zero (though it can be "locally nilpotent") — so that criterion must explicitly say "finite-dimensional".
