# strict morphism　`def.strict-morphism`
English entry · root `../`
[in graph](../#n=def.strict-morphism)　·　[Chinese page (authoritative)](./def.strict-morphism.md)

**In $\mathbf{Set}$ and $\mathbf{Ab}$ every morphism is strict**: there coimage and image both compute concretely as factorizations, and the middle map is the identity.
