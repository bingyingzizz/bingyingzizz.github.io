陈述

在做什么：把形式沿着光滑映射「搬回去」—— 这是形式特有的能力（向量场只能正着推），也是「d\mathrm{d}d 与坐标无关」的正式说法。

设 F:U→VF : U\to VF:U→V 是开集间的 C∞C^{\infty}C∞ 映射，ω\omegaω 是 VVV 上的 kkk-形式。拉回 F∗ωF^{\ast}\omegaF∗ω 是 UUU 上的 kkk-形式，定义为

(F∗ω)p(v1,…,vk):=ωF(p)(dFp(v1),…,dFp(vk)).(F^{\ast}\omega)_{p}(v_{1},\ldots,v_{k}) := \omega_{F(p)}\bigl(\mathrm{d}F_{p}(v_{1}),\ldots,\mathrm{d}F_{p}(v_{k})\bigr).(F∗ω)p​(v1​,…,vk​):=ωF(p)​(dFp​(v1​),…,dFp​(vk​)).

于是 F∗F^{\ast}F∗ 把 Ωk(V)\Omega^{k}(V)Ωk(V) 送到 Ωk(U)\Omega^{k}(U)Ωk(U)，且满足

  1. 线性：F∗(aω+bη)=a F∗ω+b F∗ηF^{\ast}(a\omega+b\eta) = a\,F^{\ast}\omega+b\,F^{\ast}\etaF∗(aω+bη)=aF∗ω+bF∗η；对函数 F∗f=f∘FF^{\ast}f = f\circ FF∗f=f∘F；
  2. 保楔积：F∗(ω∧η)=F∗ω∧F∗ηF^{\ast}(\omega\wedge\eta) = F^{\ast}\omega\wedge F^{\ast}\etaF∗(ω∧η)=F∗ω∧F∗η；
  3. 与 d\mathrm{d}d 交换：F∗(dω)=d(F∗ω)F^{\ast}(\mathrm{d}\omega) = \mathrm{d}(F^{\ast}\omega)F∗(dω)=d(F∗ω)；
  4. 保复合：(G∘F)∗=F∗∘G∗(G\circ F)^{\ast} = F^{\ast}\circ G^{\ast}(G∘F)∗=F∗∘G∗，(id⁡)∗=id⁡(\operatorname{id})^{\ast} = \operatorname{id}(id)∗=id。

前两条说 F∗F^{\ast}F∗ 是分次代数同态，第三条说它还是链映射；合起来：F∗F^{\ast}F∗ 是微分分次代数的同态。

说明

方向：F:U→VF : U\to VF:U→V 给出的是 F∗:Ωk(V)→Ωk(U)F^{\ast} : \Omega^{k}(V)\to\Omega^{k}(U)F∗:Ωk(V)→Ωk(U)，与 FFF 反向。这就是「形式是协变的」的确切含义；也是它能沿任意光滑映射定义，而向量场的前推要求 FFF 是微分同胚的原因。

（3）是核心：它等价于「d\mathrm{d}d 不依赖坐标」。唯一的实质内容是链式法则，剩下的由 (2) 与 d2=0\mathrm{d}^{2}=0d2=0 收尾（证明在边上）。

几何里的用法：曲面参数化 r:U→R3r : U\to\mathbb{R}^{3}r:U→R3 把 R3\mathbb{R}^{3}R3 上的形式拉回 UUU。第一基本形式与面积元都是拉回的样子：I=(ω1)2+(ω2)2I = (\omega^{1})^{2}+(\omega^{2})^{2}I=(ω1)2+(ω2)2、dA=ω1∧ω2\mathrm{d}A = \omega^{1}\wedge\omega^{2}dA=ω1∧ω2。曲面论能用形式写，全靠这一条。

⚠️ 拉回不保积分的方向：∫UF∗ω=∫F(U)ω\int_{U}F^{\ast}\omega = \int_{F(U)}\omega∫U​F∗ω=∫F(U)​ω 只在 FFF 是保向微分同胚、且形式的次数等于维数时成立（换元公式，def.integral-form）。

⚠️ (4) 的次序不能记反：复合 G∘FG\circ FG∘F 的拉回是 F∗∘G∗F^{\ast}\circ G^{\ast}F∗∘G∗，先拉后面那个。

  • 微分形式 ⟹ 本页推出
    逐点交错型   ⟹  \implies⟹ 拉回保楔积

    两边都对系数函数线性，故只需对单项式 ω=a dxI\omega = a\,\mathrm{d}x^{I}ω=adxI、η=b dxJ\eta = b\,\mathrm{d}x^{J}η=bdxJ 验证，并记 F=(F1,…,Fn)F = (F^{1},\ldots,F^{n})F=(F1,…,Fn)。

    先看 111-形式：(F∗dxi)p(v)=dxi(dFp(v))=dFpi(v)(F^{\ast}\mathrm{d}x^{i})_{p}(v) = \mathrm{d}x^{i}\bigl(\mathrm{d}F_{p}(v)\bigr) = \mathrm{d}F^{i}_{p}(v)(F∗dxi)p​(v)=dxi(dFp​(v))=dFpi​(v)，即

    F∗dxi=dFi=∑j∂Fi∂xj dxj.F^{\ast}\mathrm{d}x^{i} = \mathrm{d}F^{i} = \sum_{j}\frac{\partial F^{i}}{\partial x^{j}}\ \mathrm{d}x^{j}.F∗dxi=dFi=j∑​∂xj∂Fi​ dxj.

    保楔积。 每点的 ∧\wedge∧ 就是「张量积再交错化」，而交错化只置换变元、线性映射的拉回 L∗L^{\ast}L∗ 逐变元作用，两者交换；于是对线性映射 LLL 有 L∗(α∧β)=L∗α∧L∗βL^{\ast}(\alpha\wedge\beta) = L^{\ast}\alpha\wedge L^{\ast}\betaL∗(α∧β)=L∗α∧L∗β。取 L=dFpL = \mathrm{d}F_{p}L=dFp​ 并逐点拼接，再用 F∗a=a∘FF^{\ast}a = a\circ FF∗a=a∘F 得

    F∗(a dxI∧b dxJ)=(a∘F)(b∘F) dFi1∧⋯∧dFjk=(F∗ω)∧(F∗η).F^{\ast}\bigl(a\,\mathrm{d}x^{I}\wedge b\,\mathrm{d}x^{J}\bigr) = (a\circ F)(b\circ F)\,\mathrm{d}F^{i_{1}}\wedge\cdots\wedge\mathrm{d}F^{j_{k}} = (F^{\ast}\omega)\wedge(F^{\ast}\eta).F∗(adxI∧bdxJ)=(a∘F)(b∘F)dFi1​∧⋯∧dFjk​=(F∗ω)∧(F∗η).

    线性与复合是定义的直接读法：F∗F^{\ast}F∗ 逐点就是 (dFp)∗(\mathrm{d}F_{p})^{\ast}(dFp​)∗，而 d(G∘F)p=dGF(p)∘dFp\mathrm{d}(G\circ F)_{p} = \mathrm{d}G_{F(p)}\circ\mathrm{d}F_{p}d(G∘F)p​=dGF(p)​∘dFp​ 给出 (G∘F)∗=F∗∘G∗(G\circ F)^{\ast} = F^{\ast}\circ G^{\ast}(G∘F)∗=F∗∘G∗。∎

  • 外微分 ⟹ 本页推出
    链式法则 +++ d2=0\mathrm{d}^{2}=0d2=0   ⟹  \implies⟹ F∗F^{\ast}F∗ 与 d\mathrm{d}d 交换

    只需验证 ω=f dxI\omega = f\,\mathrm{d}x^{I}ω=fdxI，再用线性拼起来。由已证的保楔积与 F∗f=f∘FF^{\ast}f = f\circ FF∗f=f∘F：

    F∗(dω)=F∗(∑j∂jf dxj∧dxI)=∑j(∂jf∘F) dFj∧dFI.F^{\ast}(\mathrm{d}\omega) = F^{\ast}\Bigl(\sum_{j}\partial_{j}f\ \mathrm{d}x^{j}\wedge\mathrm{d}x^{I}\Bigr) = \sum_{j}(\partial_{j}f\circ F)\ \mathrm{d}F^{j}\wedge\mathrm{d}F^{I}.F∗(dω)=F∗(j∑​∂j​f dxj∧dxI)=j∑​(∂j​f∘F) dFj∧dFI.

    另一方面

    d(F∗ω)=d((f∘F) dFI)=d(f∘F)∧dFI+(f∘F) d(dFI).\mathrm{d}(F^{\ast}\omega) = \mathrm{d}\bigl((f\circ F)\,\mathrm{d}F^{I}\bigr) = \mathrm{d}(f\circ F)\wedge\mathrm{d}F^{I}+(f\circ F)\,\mathrm{d}\bigl(\mathrm{d}F^{I}\bigr).d(F∗ω)=d((f∘F)dFI)=d(f∘F)∧dFI+(f∘F)d(dFI).

    第二项为零：每个 dFj\mathrm{d}F^{j}dFj 都是恰当形式（dFj=d(Fj)\mathrm{d}F^{j} = \mathrm{d}(F^{j})dFj=d(Fj)），而 d2=0\mathrm{d}^{2} = 0d2=0，故 d(dFI)=0\mathrm{d}(\mathrm{d}F^{I}) = 0d(dFI)=0。第一项用链式法则

    d(f∘F)=∑j(∂jf∘F) dFj,\mathrm{d}(f\circ F) = \sum_{j}(\partial_{j}f\circ F)\,\mathrm{d}F^{j} ,d(f∘F)=j∑​(∂j​f∘F)dFj,

    代回即与上式相同（注意 dFI=dFi1∧⋯∧dFik\mathrm{d}F^{I} = \mathrm{d}F^{i_{1}}\wedge\cdots\wedge\mathrm{d}F^{i_{k}}dFI=dFi1​∧⋯∧dFik​ 与 F∗dxIF^{\ast}\mathrm{d}x^{I}F∗dxI 是同一个东西）。∎

    ⭐ 唯一的实质内容是链式法则 + d2=0\mathrm{d}^{2}=0d2=0 这两条；所有「d\mathrm{d}d 与坐标无关」的说法最终都归结到这里。
