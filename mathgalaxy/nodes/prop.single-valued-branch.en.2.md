# criterion for a single-valued branch　`prop.single-valued-branch`
English entry · root `../`
[in graph](../#n=prop.single-valued-branch)　·　[Chinese page (authoritative)](./prop.single-valued-branch.md)

For the **logarithm** ($F(z) = \{\, w : e^{w} = z \,\}$) the following three conditions are equivalent:

1. $\log$ has a holomorphic single-valued branch on $D$;
2. $1/z$ has a primitive on $D$;
3. for every closed curve $\gamma$ in $D$, $\displaystyle\oint_{\gamma} \frac{\mathrm{d}z}{z} = 0$.

A sufficient condition: $D$ is simply connected and $0 \notin D$.
