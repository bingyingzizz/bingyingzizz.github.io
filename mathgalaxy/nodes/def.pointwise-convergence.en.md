## Statement · **draft**
Let $f_n : X \to \mathbb{R}$ ($n = 1, 2, \ldots$) and $f : X \to \mathbb{R}$. We say that $\{f_n\}$ **converges pointwise** to $f$ if and only if for **every fixed** $x \in X$,

$$\forall \varepsilon > 0,\ \exists N,\ \forall n \ge N :\ |f_n(x) - f(x)| < \varepsilon$$

We write $f_n \to f$ (pointwise).
