## Notes · **draft**
⭐ a.e. is the **lubricant** of Lebesgue theory: elements of $L^1$, $L^p$ are really **equivalence classes of functions** (equal a.e. counts as the same), and almost every convergence theorem (MCT, Fatou, the a.e. version of DCT, Egorov) requires only a.e. convergence — because values on a null set do not contribute to the integral.

⚠ "Equal a.e." and "equal everywhere" are different relations: $\int |f| = 0 \implies f = 0$ a.e. (not everywhere 0).

⚠ A **subset** of a null set need not be measurable unless the measure space is complete — this is exactly the problem that completion solves.
