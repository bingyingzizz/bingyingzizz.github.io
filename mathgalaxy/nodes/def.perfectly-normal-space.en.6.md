**Hypotheses used in each direction** (taking complements is free; the zero-set description needs normality):
- Perfectly normal $\iff$ normal and every closed set is a $G_\delta$ set: this is the definition unfolded; normality already includes $T_1$.
- Every closed set is $G_\delta$ $\iff$ every open set is $F_\sigma$: De Morgan, with no separation axiom needed; when using this to characterize perfect normality, normality must still be kept on both sides.
