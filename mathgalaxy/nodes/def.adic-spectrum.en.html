Statement

In plain words: collect all ways of "measuring the size" of elements of a ring AAA, and you get the adic spectrum.

Each point is an "absolute value" (valuation), and A+A^+A+ serves to filter out those points that measure some bounded element as >1>1>1.

This is the "with sizes" version of Spec⁡\operatorname{Spec}Spec — Spec⁡\operatorname{Spec}Spec records only "which ideals have elements equal to zero", while Spa⁡\operatorname{Spa}Spa also records "how small".

First, terminology. A valuation is a "size-measuring" function ∣⋅∣:A→Γ∪{0}|\cdot| : A \to \Gamma \cup \{0\}∣⋅∣:A→Γ∪{0} (Γ\GammaΓ a totally ordered abelian group written multiplicatively, think R>0\mathbb{R}_{>0}R>0​) satisfying

∣0∣=0,∣1∣=1,∣xy∣=∣x∣ ∣y∣,∣x+y∣≤max⁡(∣x∣,∣y∣).|0| = 0, \quad |1| = 1, \quad |xy| = |x|\,|y|, \quad |x + y| \le \max(|x|, |y|).∣0∣=0,∣1∣=1,∣xy∣=∣x∣∣y∣,∣x+y∣≤max(∣x∣,∣y∣).

Two valuations ∣⋅∣,∣⋅∣1|\cdot|, |\cdot|_1∣⋅∣,∣⋅∣1​ are equivalent if there is an order-preserving group isomorphism with ∣x∣1=σ(∣x∣)|x|_1 = \sigma(|x|)∣x∣1​=σ(∣x∣) for all xxx — that is, "they order the elements of AAA by size in exactly the same way", only the "ruler" changes.

Spa⁡\operatorname{Spa}Spa takes equivalence classes of valuations (so the same point is not counted twice because of a different ruler).

Intuition: ∣x∣|x|∣x∣ is "the distance from xxx to 000", and ∣x∣≤1|x| \le 1∣x∣≤1 means "xxx is bounded";

the ppp-adic absolute value ∣pnu∣=p−n|p^{n}u| = p^{-n}∣pnu∣=p−n (uuu coprime to ppp) is the standard example.

Let (A,A+)(A, A^+)(A,A+) be a discrete Huber pair. The adic spectrum

Spa⁡(A,A+):={ ∣⋅∣:A→Γ∪{0} ∣ ∣A+∣≤1 }/∼\operatorname{Spa}(A, A^+) := \bigl\{\, |\cdot| : A \to \Gamma \cup \{0\} \ \big|\ |A^+| \le 1 \,\bigr\} \big/ \simSpa(A,A+):={∣⋅∣:A→Γ∪{0} ​ ∣A+∣≤1}/∼

is the set of equivalence classes of valuations on AAA that are bounded on A+A^+A+ — that is, satisfy ≤1\le 1≤1 (every element of A+A^+A+ is bounded). The topology is generated by rational open sets: for f,g1,…,gn∈Af, g_1, \ldots, g_n \in Af,g1​,…,gn​∈A,

U ⁣(g1,…,gnf):={ x:∣gi(x)∣≤∣f(x)∣≠0 ∀i }.U\!\left(\tfrac{g_1, \ldots, g_n}{f}\right) := \bigl\{\, x : |g_i(x)| \le |f(x)| \ne 0\ \forall i\, \bigr\}.U(fg1​,…,gn​​):={x:∣gi​(x)∣≤∣f(x)∣=0 ∀i}.

These rational open sets form a basis, and Spa⁡(A,A+)\operatorname{Spa}(A,A^+)Spa(A,A+) is a spectral space (homeomorphic to the prime spectrum of some ring; equivalently: compact, sober, and compact open sets form a basis).

Notes

⭐ A valuation satisfies the strong triangle inequality ∣x+y∣≤max⁡(∣x∣,∣y∣)|x+y| \le \max(|x|,|y|)∣x+y∣≤max(∣x∣,∣y∣), the hallmark of non-archimedean geometry; replacing it by ≤∣x∣+∣y∣\le |x| + |y|≤∣x∣+∣y∣ gives the archimedean side (complex geometry), a different theory.

⭐ Rational open sets are the regions defined by "∣gi∣≤∣f∣|g_i| \le |f|∣gi​∣≤∣f∣" — intuitively the locus where "gi/fg_i/fgi​/f is bounded".

They are both open and compact (quasicompact), which is exactly what makes adic spaces handier than schemes: affine open sets carry their own compactness.

⚠ Spa⁡(A,A+)\operatorname{Spa}(A,A^+)Spa(A,A+) is in general not Hausdorff; it is spectral (compact, sober, compact open sets form a basis, and compact open sets are closed under finite intersections).

So metric-space intuition does not apply.
