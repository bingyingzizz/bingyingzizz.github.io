# integral over a set　`def.integral-over-set`
English entry · root `../`
[in graph](../#n=def.integral-over-set)　·　[Chinese page (authoritative)](./def.integral-over-set.md)

If $f$ is integrable ($\int |f| < \infty$), define $\int_E f := \int f\mathbf{1}_E$ in the same way, splitting a complex-valued function into real and imaginary parts. When $E = X$ this reduces to the integral over the whole space; when $\mu(E) = 0$, $\int_E f = 0$.

## Notes · **draft**
⚠ $E$ must be measurable, otherwise the indicator $\mathbf{1}_E$ is not measurable. ⭐ This notation is completely synonymous with “integrating $f$ times the indicator”; the nonnegative/complex integral comes first, and integration over a measurable set is its restriction.
