# Flat Module　`def.flat-module`
English entry · root `../`
[in graph](../#n=def.flat-module)　·　[Chinese page (authoritative)](./def.flat-module.md)

⚠️ **Flat and projective are not equivalent**: $\mathbb{Q}$ is flat over $\mathbb{Z}$ ($\mathbb{Q}$ is torsion-free) but **not projective** ($\mathbb{Q}$ is not free, nor a direct summand of a free module). So "flat" is indeed one level weaker than "projective".

⚠️ **Not the same as flatness in a topos**: "flat abelian group" in a category of sheaves is a different definition (a double condition using filtered colimits / exactness of tensoring), see "flat abelian sheaves". This entry refers only to module categories.
