# Wedderburn–Artin 定理　`thm.wedderburn-artin`
Wedderburn–Artin 定理
layer 20 · 定理 · 群与代数表示 · 抽象代数
[在星图里打开](../#n=thm.wedderburn-artin)　·　[节点索引](../index.md)

设 $A$ 是有限维半单 $F$-代数。则 $A\cong\prod_{i=1}^s M_{n_i}(D_i)$，其中 $D_i$ 是除法代数；等价地，每个有限维 $A$-模都是半单的。
