# Pullback: Between Open Sets　`prop.pullback-forms`
English entry · root `../`
[in graph](../#n=prop.pullback-forms)　·　[Chinese page (authoritative)](./prop.pullback-forms.md)

1. **Linearity**: $F^{\ast}(a\omega+b\eta) = a\,F^{\ast}\omega+b\,F^{\ast}\eta$; for functions, $F^{\ast}f = f\circ F$;
2. **Preserves the wedge product**: $F^{\ast}(\omega\wedge\eta) = F^{\ast}\omega\wedge F^{\ast}\eta$;
3. **Commutes with** $\mathrm{d}$: $F^{\ast}(\mathrm{d}\omega) = \mathrm{d}(F^{\ast}\omega)$;
4. **Preserves composition**: $(G\circ F)^{\ast} = F^{\ast}\circ G^{\ast}$, $(\operatorname{id})^{\ast} = \operatorname{id}$.
