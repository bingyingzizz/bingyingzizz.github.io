设 fff 是有限阶 ρ\rhoρ 的整函数，零点为 {an}\{a_{n}\}{an​}（按重数计）。则

f(z)=zmeP(z)∏nEp(zan),f(z) = z^{m} e^{P(z)} \prod_{n} E_{p}\left(\frac{z}{a_{n}}\right),f(z)=zmeP(z)n∏​Ep​(an​z​),

其中 PPP 是次数 ≤ρ\le \rho≤ρ 的多项式，而 p≤ρp \le \rhop≤ρ 是统一取定的整数（不再像 Weierstrass 那样逐个选）。

特别地：阶 ρ<1\rho < 1ρ<1 的整函数没有零点（除非恒为零）—— 因为此时 p=0p = 0p=0 要求∑∣an∣−1<∞\sum |a_{n}|^{-1} < \infty∑∣an​∣−1<∞，而零点再多也只能是有限个。

说明

证明思路（骨架）：

第一步：零点密度。 由 Jensen 公式（prop.jensen）n(R)log⁡2≤log⁡M(2R)+O(1)n(R) \log 2 \le \log M(2R) + O(1)n(R)log2≤logM(2R)+O(1)，而 log⁡M(2R)=O(Rρ+ε)\log M(2R) = O(R^{\rho + \varepsilon})logM(2R)=O(Rρ+ε)，故 n(R)=O(Rρ+ε)n(R) = O(R^{\rho+\varepsilon})n(R)=O(Rρ+ε)，于是 ∑∣an∣−(ρ+ε)<∞\sum |a_{n}|^{-(\rho+\varepsilon)} < \infty∑∣an​∣−(ρ+ε)<∞。这一步说明统一取 p=⌊ρ⌋p = \lfloor \rho \rfloorp=⌊ρ⌋ 就够。

第二步：除掉零点。 令 Φ(z):=f(z)/∏Ep(z/an)\Phi(z) := f(z)\big/\prod E_{p}(z/a_{n})Φ(z):=f(z)/∏Ep​(z/an​)，则 Φ\PhiΦ 无零点、且仍是有限阶（乘积的贡献被初等因子的估计压住）。

第三步：无零点的有限阶整函数 = e多项式e^{\text{多项式}}e多项式。 写 Φ=eh\Phi = e^{h}Φ=eh（单连通，prop.single-valued-branch），则 Re⁡h=log⁡∣Φ∣=O(rρ+ε)\operatorname{Re} h = \log|\Phi| = O(r^{\rho+\varepsilon})Reh=log∣Φ∣=O(rρ+ε)。对 hhh 用 Borel–Carathéodory 不等式，得 hhh 是次数 ≤ρ\le \rho≤ρ 的多项式。∎

⭐ 它是 Weierstrass 乘积的「定量版」：一旦知道增长阶，就能把因子统一化、并把自由度压成一个多项式。Picard 小定理（thm.picard-little）在有限阶情形就靠它证。

⚠️ 「有限阶」不能省。无穷阶整函数照样能分解（Weierstrass），但指数部分不再是多项式，而且没有这么强的结论。
