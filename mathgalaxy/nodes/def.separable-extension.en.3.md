# separable extension　`def.separable-extension`
English entry · root `../`
[in graph](../#n=def.separable-extension)　·　[Chinese page (authoritative)](./def.separable-extension.md)

⭐ **Why Galois theory needs separability**: the correspondence counts automorphisms, and an automorphism can only send a root to a **different** root. With repeated roots there are too few roots, so $|\operatorname{Gal}|$ drops below $[K:F]$ and the correspondence fails.

⚠ Hence the standard definition of Galois extension is finite + normal + separable; in characteristic 0 the third condition is automatic and is often quietly dropped — dropped **under the characteristic 0 hypothesis**, not in general.
