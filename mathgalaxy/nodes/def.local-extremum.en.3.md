# local extremum　`def.local-extremum`
English entry · root `../`
[in graph](../#n=def.local-extremum)　·　[Chinese page (authoritative)](./def.local-extremum.md)

⚠ Endpoints do not count as interior extremum points — this is a hypothesis of Fermat's lemma, because the **one-sided** nature of the derivative at an endpoint destroys the argument.

⚠ A local maximum need not be a global maximum: $f(x) = x^{3} - x$ has a local maximum near $x = -1$, but is unbounded globally.
