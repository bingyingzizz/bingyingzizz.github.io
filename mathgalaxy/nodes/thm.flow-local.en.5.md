# existence of a local flow　`thm.flow-local`
English entry · root `../`
[in graph](../#n=thm.flow-local)　·　[Chinese page (authoritative)](./thm.flow-local.md)

**Why the maximal flow is unique**: two maximal flows have the same initial-value problem at an intersection point, so by uniqueness they agree locally; gluing all local solutions along curves gives the one with maximal domain. The domain $\mathcal{W}$ is open: near each point there is a time interval supplied by existence, and this time can be chosen lower semicontinuous in $p$.
