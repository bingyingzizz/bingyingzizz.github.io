设 XXX 是赋范空间，X∗X^{}X∗ 其连续对偶，BX∗={φ∈X∗:∥φ∥≤1}B_{X^{}} = \{\varphi \in X^{} : \|\varphi\| \le 1\}BX∗​={φ∈X∗:∥φ∥≤1}。则 BX∗B_{X^{}}BX∗​ 在弱拓扑 σ(X∗,X)\sigma(X^{}, X)σ(X∗,X)（由半范数 φ↦∣φ(x)∣\varphi \mapsto |\varphi(x)|φ↦∣φ(x)∣，x∈Xx \in Xx∈X 生成）下紧。

说明

弱拓扑 = 积拓扑的限制。 令 P=∏x∈X[−∥x∥,∥x∥]P = \prod_{x \in X} [-\|x\|, \|x\|]P=∏x∈X​[−∥x∥,∥x∥]，映射 Φ:BX∗→P\Phi : B_{X^{}} \to PΦ:BX∗​→P，Φ(φ)=(φ(x))x∈X\Phi(\varphi) = (\varphi(x))_{x \in X}Φ(φ)=(φ(x))x∈X​。由 ∣φ(x)∣≤∥φ∥ ∥x∥≤∥x∥|\varphi(x)| \le \|\varphi\|\,\|x\| \le \|x\|∣φ(x)∣≤∥φ∥∥x∥≤∥x∥，像落在 PPP 里；Φ\PhiΦ 是单射，且弱拓扑正是 PPP 的积拓扑在 BX∗B_{X^{}}BX∗​ 上拉回的拓扑（每个坐标都是弱*连续的，坐标族又分离点）。

像闭。 设 Φ(φα)→y=(yx)\Phi(\varphi_\alpha) \to y = (y_x)Φ(φα​)→y=(yx​) 于 PPP。定义 φ(x)=yx\varphi(x) = y_xφ(x)=yx​。线性：yx+z=lim⁡φα(x+z)=lim⁡(φα(x)+φα(z))=yx+yzy_{x + z} = \lim \varphi_\alpha(x + z) = \lim(\varphi_\alpha(x) + \varphi_\alpha(z)) = y_x + y_zyx+z​=limφα​(x+z)=lim(φα​(x)+φα​(z))=yx​+yz​，同理 ytx=tyxy_{tx} = t y_xytx​=tyx​。有界：∣yx∣≤∥x∥|y_x| \le \|x\|∣yx​∣≤∥x∥，故 ∥φ∥≤1\|\varphi\| \le 1∥φ∥≤1。于是 y=Φ(φ)∈Φ(BX∗)y = \Phi(\varphi) \in \Phi(B_{X^{*}})y=Φ(φ)∈Φ(BX∗​)，像闭。

紧。 PPP 是紧空间的积（每个 [−∥x∥,∥x∥][-\|x\|,\|x\|][−∥x∥,∥x∥] 紧），由 Tychonoff 定理 紧；闭子集 Φ(BX∗)\Phi(B_{X^{}})Φ(BX∗​) 紧；Φ\PhiΦ 是到其像上的同胚（连续双射、紧 →\to→ Hausdorff），故 BX∗B_{X^{}}BX∗​ 弱*紧。■\blacksquare■

⚠ 弱拓扑不是范数拓扑：BX∗B_{X^{}}BX∗​ 在范数拓扑下一般不紧（XXX 无限维时）。本条的紧性只在弱*意义下成立。

📌 用途：James 定理 的正向（自反   ⟹  \implies⟹ 泛函达到范数）要用「BXB_XBX​ 弱紧」；而「自反   ⟹  \implies⟹ BXB_XBX​ 弱紧」正是把本条用到 X∗∗X^{**}X∗∗ 上、再沿 JXJ_XJX​ 拉回。
