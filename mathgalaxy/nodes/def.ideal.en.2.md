# ideal　`def.ideal`
English entry · root `../`
[in graph](../#n=def.ideal)　·　[Chinese page (authoritative)](./def.ideal.md)

Multiplication $(a + I)(b + I) := ab + I$ on the quotient set $A/I$ (by additive cosets) is well defined, and the resulting ring is called the **quotient ring**.

## Notes · **draft**
**Why ideals are defined this way.** The problem is exactly the same as for normal subgroups: to define multiplication on the quotient set, $(a + I)(b + I)$ must not depend on the representatives. Compute $(a + x)(b + y) = ab + ay + xb + xy$ — the last three terms must all lie in $I$. That $xy \in I$ is **not** guaranteed by "$I$ is a subgroup" and must be **required separately**.
