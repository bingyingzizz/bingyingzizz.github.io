## Notes · **draft**
**What it contains**: an element of $\hat{\mathbb{Z}}$ is a compatible sequence $(a_{n})_{n \ge 1}$ ($a_{n} \in \mathbb{Z}/n$, $a_{m} \equiv a_{n} \pmod n$). Sending an integer $k$ to the constant sequence $(k \bmod n)_{n}$ is a compact embedding $\mathbb{Z} \hookrightarrow \hat{\mathbb{Z}}$, whose image is dense but **not** all of it (the standard example in @@def.profinite@@ of "dense but not surjective").
