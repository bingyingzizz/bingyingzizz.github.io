陈述

在做什么：规定「把一个向量沿某个方向搬运时怎么变」—— 有了这条规则才能对向量场求导，进而谈加速度、测地线与曲率。

设 MMM 是光滑流形，X(M)\mathfrak{X}(M)X(M) 是光滑向量场的集合。仿射联络（线性联络）是一个映射

∇:X(M)×X(M)⟶X(M),(X,Y)⟼∇XY,\nabla : \mathfrak{X}(M)\times\mathfrak{X}(M)\longrightarrow\mathfrak{X}(M),\qquad (X,Y)\longmapsto\nabla_{X}Y ,∇:X(M)×X(M)⟶X(M),(X,Y)⟼∇X​Y,

满足三条：

  1. 对第一个变元 C∞(M)C^{\infty}(M)C∞(M)-线性：∇fX+gYZ=f ∇XZ+g ∇YZ\nabla_{fX+gY}Z = f\,\nabla_{X}Z+g\,\nabla_{Y}Z∇fX+gY​Z=f∇X​Z+g∇Y​Z；
  2. 对第二个变元 R\mathbb{R}R-线性：∇X(aY+bZ)=a ∇XY+b ∇XZ\nabla_{X}(aY+bZ) = a\,\nabla_{X}Y+b\,\nabla_{X}Z∇X​(aY+bZ)=a∇X​Y+b∇X​Z；
  3. Leibniz 律：∇X(fY)=(Xf) Y+f ∇XY\nabla_{X}(fY) = (Xf)\,Y+f\,\nabla_{X}Y∇X​(fY)=(Xf)Y+f∇X​Y。

∇XY\nabla_{X}Y∇X​Y 叫 YYY 沿 XXX 的协变导数。在卡里设 ∇∂i∂j=Γijk∂k\nabla_{\partial_{i}}\partial_{j} = \Gamma^{k}_{ij}\partial_{k}∇∂i​​∂j​=Γijk​∂k​，则

∇XY=∑k(Xj∂jYk+ΓijkXiYj)∂k.\nabla_{X}Y = \sum_{k}\Bigl(X^{j}\partial_{j}Y^{k}+\Gamma^{k}_{ij}X^{i}Y^{j}\Bigr)\partial_{k}.∇X​Y=k∑​(Xj∂j​Yk+Γijk​XiYj)∂k​.

黎曼流形上有唯一无挠（∇XY−∇YX=[X,Y]\nabla_{X}Y-\nabla_{Y}X = [X,Y]∇X​Y−∇Y​X=[X,Y]）且保度量（X g(Y,Z)=g(∇XY,Z)+g(Y,∇XZ)X\,g(Y,Z) = g(\nabla_{X}Y,Z)+g(Y,\nabla_{X}Z)Xg(Y,Z)=g(∇X​Y,Z)+g(Y,∇X​Z)）的联络，叫 Levi-Civita 联络；它的 Γ\GammaΓ 就是 Christoffel 记号。

说明

三条公理的读法：第 1 条说明 ∇XY\nabla_{X}Y∇X​Y 在一点只依赖 XXX 在该点的值（否则不算「沿方向」）；第 3 条说明它对 YYY 不是张量性的 —— 求导必须看见 YYY 的变化。这个不对称正是「联络」与「张量」的分界。

平行移动与测地线：解 ∇γ˙V=0\nabla_{\dot\gamma}V = 0∇γ˙​​V=0 得 VVV 沿 γ\gammaγ 的平行移动；∇γ˙γ˙=0\nabla_{\dot\gamma}\dot\gamma = 0∇γ˙​​γ˙​=0 的解就是测地线（def.geodesic）。两样都只用 ∇\nabla∇，不需要外围空间。

联络不唯一：一般的仿射联络有无穷多（Γ\GammaΓ 的任意非对称部分都能改）。加上「无挠 + 保度量」才唯一 —— 这就是 Levi-Civita 联络的存在唯一性（Koszul 公式）。

曲率是联络的交换子：R(X,Y)=[∇X,∇Y]−∇[X,Y]R(X,Y) = [\nabla_{X},\nabla_{Y}]-\nabla_{[X,Y]}R(X,Y)=[∇X​,∇Y​]−∇[X,Y]​（def.curvature-tensor）。所以一个「联络」同时生出平行移动、测地线与曲率。

⚠️ 指标约定：无挠时 Γijk\Gamma^{k}_{ij}Γijk​ 对两个下标对称；ω jk\omega^{k}_{\ j}ω jk​ 是同一件东西在正交标架下的样子（def.connection-form）。两者换标架时差一个 Jacobi 因子，都不是张量。

  • 联络形式、活动标架 ⟹ 本页推出
    标架联络   ⟹  \implies⟹ 曲面上有一个仿射联络

    设 S⊆R3S\subseteq\mathbb{R}^{3}S⊆R3 是正则曲面，∇ˉ\bar\nabla∇ˉ 是 R3\mathbb{R}^{3}R3 的平坦联络（∇ˉXY=dY(X)\bar\nabla_{X}Y = \mathrm{d}Y(X)∇ˉX​Y=dY(X)，把 YYY 当成 R3\mathbb{R}^{3}R3-值函数）。对切向量场定义（上标 ⊤\top⊤ 表示投影到切平面）

    ∇XY:=(∇ˉXY)⊤.\nabla_{X}Y := \bigl(\bar\nabla_{X}Y\bigr)^{\top}.∇X​Y:=(∇ˉX​Y)⊤.

    三条公理逐条验证：

    • 对 XXX 的 C∞(S)C^{\infty}(S)C∞(S)-线性：来自 ∇ˉ\bar\nabla∇ˉ 的对应性质与投影的线性；
    • 对 YYY 的 R\mathbb{R}R-线性：同上；
    • Leibniz 律：∇ˉX(fY)=(Xf)Y+f∇ˉXY\bar\nabla_{X}(fY) = (Xf)Y+f\bar\nabla_{X}Y∇ˉX​(fY)=(Xf)Y+f∇ˉX​Y，而 (Xf)Y(Xf)Y(Xf)Y 已经切向，投影后等式不变。

    无挠：∇XY−∇YX=([X,Y])⊤=[X,Y]\nabla_{X}Y-\nabla_{Y}X = \bigl([X,Y]\bigr)^{\top} = [X,Y]∇X​Y−∇Y​X=([X,Y])⊤=[X,Y]（[X,Y][X,Y][X,Y] 本来就切于 SSS）。保度量：⟨⋅,⋅⟩\langle\cdot,\cdot\rangle⟨⋅,⋅⟩ 是 R3\mathbb{R}^{3}R3 的常度量、∇ˉ\bar\nabla∇ˉ 保它，而投影不改变两个切向量的内积。所以 ∇\nabla∇ 是 SSS 上的 Levi-Civita 联络。

    与联络形式的关系：取单位正交标架 (e1,e2)(e_{1},e_{2})(e1​,e2​)，则 ∇ˉXej=dej(X)\bar\nabla_{X}e_{j} = \mathrm{d}e_{j}(X)∇ˉX​ej​=dej​(X)，于是

    ∇Xej=(dej(X))⊤=∑k=12ω jk(X) ek,ω jk(X)=⟨dej(X),ek⟩,\nabla_{X}e_{j} = \bigl(\mathrm{d}e_{j}(X)\bigr)^{\top} = \sum_{k=1}^{2}\omega^{k}_{\ j}(X)\,e_{k},\qquad \omega^{k}_{\ j}(X) = \langle \mathrm{d}e_{j}(X),e_{k}\rangle ,∇X​ej​=(dej​(X))⊤=k=1∑2​ω jk​(X)ek​,ω jk​(X)=⟨dej​(X),ek​⟩,

    正是 def.connection-form 的联络形式（上标记分量、下标记被微分的标架向量）。∎
