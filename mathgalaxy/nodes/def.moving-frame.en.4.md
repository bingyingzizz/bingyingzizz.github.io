# Moving Frame　`def.moving-frame`
English entry · root `../`
[in graph](../#n=def.moving-frame)　·　[Chinese page (authoritative)](./def.moving-frame.md)

$$\mathrm{d}r = \omega^{1}e_{1}+\omega^{2}e_{2}+\omega^{3}e_{3}.$$

This is called the **soldering equation**: it translates "how $r$ moves" into "how much it moves in each frame component".

## Notes · **draft**
**Why change the language at all**: the coordinate route requires computing $r_{uu}, r_{uv}, r_{vv}$ and the partial derivatives of $n$; the frame route expands $\mathrm{d}r$ and $\mathrm{d}e_{i}$ **once**, after which everything is algebra between $1$-forms (wedge products, comparing coefficients). This is exactly the point of "using a moving frame in place of a complicated computation".
