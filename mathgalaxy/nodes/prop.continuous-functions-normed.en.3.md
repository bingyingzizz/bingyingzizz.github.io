## Notes · **draft**
**Proof.**
**1.** $\sup$ is finite because a continuous function on a compact space is bounded ($f(S)$ is compact, and norm balls have finite radius) ✓. Verify the three seminorm axioms pointwise using the seminorm on $M$ and then take suprema ✓. $\|f\| = 0 \implies f = 0$ if and only if $M$ is Hausdorff (its seminorm is a norm) ✓.
**Completeness**: Let $(f_{j})$ be a Cauchy sequence for $\|\cdot\|$. At each $x$, the sequence $(f_{j}(x))$ is Cauchy. Since $M$ is complete, it has a limit $f(x)$ ✓;
