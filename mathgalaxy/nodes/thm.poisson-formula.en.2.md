# Poisson integral formula　`thm.poisson-formula`
English entry · root `../`
[in graph](../#n=thm.poisson-formula)　·　[Chinese page (authoritative)](./thm.poisson-formula.md)

$$u(z) = \frac{1}{2\pi}\int_0^{2\pi} \frac{r^2 - |z|^2}{|r e^{i\theta} - z|^2}\, u(r e^{i\theta})\,\mathrm{d}\theta.$$

The weight function

$$P_r(z, \theta) := \frac{r^2 - |z|^2}{|r e^{i\theta} - z|^2}$$

is called the **Poisson kernel**. For fixed $z$ it satisfies $P_r \ge 0$ and $\frac{1}{2\pi}\int_0^{2\pi} P_r\,\mathrm{d}\theta = 1$.
