# convex set　`def.convex-set`
English entry · root `../`
[in graph](../#n=def.convex-set)　·　[Chinese page (authoritative)](./def.convex-set.md)

⚠ The empty set is convex under this definition (the condition "for any two points" holds vacuously); when non-emptiness is needed it is assumed separately in the theorem (as in the projection theorem).

💡 Convex combinations, convex hulls and separation theorems all start here.

📌 **A convex set is star-shaped at each of its points** (see `thm.convex-star-shaped-every-point`); for the empty set this universal statement holds vacuously, so there is no conflict with "the empty set is not star-shaped".
