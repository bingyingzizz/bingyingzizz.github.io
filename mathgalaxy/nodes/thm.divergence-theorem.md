# 散度定理　`thm.divergence-theorem`
散度定理
layer 29 · 定理 · 微分形式、积分与 de Rham · 微分几何
[在星图里打开](../#n=thm.divergence-theorem)　·　[节点索引](../index.md)

**在做什么**：散度在整块流形上积起来，等于流量从边界漏出去的通量。这是 Gauss 公式在任意维数、任意黎曼流形上的样子，也是「散度 = 源密度」这句口号的正式版本。
