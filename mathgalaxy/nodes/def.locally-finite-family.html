∀x∈X, ∃U∋x 开:{ s∈S:U∩As≠∅ } 有限.\forall x \in X,\ \exists U \ni x \text{ 开}:\quad \{\, s \in S : U \cap A_{s} \ne \emptyset \,\} \text{ 有限}.∀x∈X, ∃U∋x 开:{s∈S:U∩As​=∅} 有限.

把「开邻域」换成「点本身」，得到弱一些的点有限族：每个点只属于有限多个 AsA_{s}As​。

说明

为什么要「局部」：一个族整体上可以无穷（R\mathbb{R}R 上的 { (n,n+2) }n∈Z\{\, (n, n+2) \,\}_{n \in \mathbb{Z}}{(n,n+2)}n∈Z​ 有无穷多个成员），但只要每点附近只碰到有限多个，任何逐点求和就自动是局部有限和、任何逐点判断都只需看有限多项。仿紧、单位分解、层论里的细部论证全靠这一条。

三条常用性质（后两条才是它真正被用到的形式）：

  • 局部有限   ⟹  \implies⟹ 点有限：取只碰有限多个成员的邻域 U∋xU \ni xU∋x，含 xxx 的成员只能更少；
  • 并的闭包等于闭包之并：cl⁡⋃sAs=⋃scl⁡As\operatorname{cl}\bigcup_{s} A_{s} = \bigcup_{s} \operatorname{cl} A_{s}cl⋃s​As​=⋃s​clAs​（⊇\supseteq⊇ 恒成立，⊆\subseteq⊆ 那一半用局部有限性）；
  • 若每个 AsA_{s}As​ 都闭，则 ⋃sAs\bigcup_{s} A_{s}⋃s​As​ 也闭（上一条的直接推论）。

⚠️ 局部有限不等于「成员可以很多」，也不等于点有限：R\mathbb{R}R 上的族 { {1/n}:n≥1 }\{\, \{ 1/n \} : n \ge 1 \,\}{{1/n}:n≥1} 点有限（每点至多属于一个成员）却不局部有限（000 的任何邻域都碰到无穷多个成员）。
