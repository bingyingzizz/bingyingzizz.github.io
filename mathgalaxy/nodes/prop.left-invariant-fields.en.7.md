# Left-Invariant Vector Fields　`prop.left-invariant-fields`
English entry · root `../`
[in graph](../#n=prop.left-invariant-fields)　·　[Chinese page (authoritative)](./prop.left-invariant-fields.md)

**Example**: for $G = \operatorname{GL}(n,\mathbb{R})$ the Lie algebra is $\mathfrak{gl}(n,\mathbb{R})$ with the commutator — because $L_{A}$ is linear and $\mathrm{d}(L_{A}) = A$ itself, left-invariant fields are $X(A) = AM$ ($M$ fixed), and the bracket computes to $[M,N] = MN - NM$.

**"The Lie algebra determines the Lie group" is false**: $S^{1}$ and $\mathbb{R}$ both have the one-dimensional abelian Lie algebra, yet they are not isomorphic (compact versus non-compact). So $\mathfrak{g}$ does not recover $G$, only the simply connected $G$ — this is Lie's third theorem, not developed here.
