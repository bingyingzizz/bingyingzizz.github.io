陈述

在做什么：换元公式在流形上的样子 —— 沿微分同胚把形式搬过去，积分不变；搬的方向反了就变号。它其实是「nnn-形式是唯一能自然积分的东西」的另一种说法。

设 f:M→Nf : M\to Nf:M→N 是定向 nnn 维光滑流形之间的微分同胚，ω∈Ωn(N)\omega\in\Omega^{n}(N)ω∈Ωn(N) 可积（NNN 紧，或 ω\omegaω 有紧支）。则

fff 保向时

∫Mf∗ω=∫Nω;\int_{M}f^{\ast}\omega = \int_{N}\omega ;∫M​f∗ω=∫N​ω;

fff 反向时

∫Mf∗ω=−∫Nω.\int_{M}f^{\ast}\omega = -\int_{N}\omega .∫M​f∗ω=−∫N​ω.

两种情形合写成 ∫Mf∗ω=ε∫Nω\int_{M}f^{\ast}\omega = \varepsilon\int_{N}\omega∫M​f∗ω=ε∫N​ω，ε=+1\varepsilon = +1ε=+1 表示保向、−1-1−1 表示反向。

经典换元是它的坐标版：取 M,U⊆RnM,U\subseteq\mathbb{R}^{n}M,U⊆Rn、N=g(U)N = g(U)N=g(U)、ω=F dy1∧⋯∧dyn\omega = F\,\mathrm{d}y^{1}\wedge\cdots\wedge\mathrm{d}y^{n}ω=Fdy1∧⋯∧dyn，则 f∗ω=(F∘g)det⁡(∂g/∂x) dx1∧⋯∧dxnf^{\ast}\omega = (F\circ g)\det(\partial g/\partial x)\,\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}f∗ω=(F∘g)det(∂g/∂x)dx1∧⋯∧dxn，公式变成 ∫g(U)F dy=∫U(F∘g)det⁡(∂g/∂x) dx\int_{g(U)}F\,\mathrm{d}y = \int_{U}(F\circ g)\det(\partial g/\partial x)\,\mathrm{d}x∫g(U)​Fdy=∫U​(F∘g)det(∂g/∂x)dx —— 与微积分课本上的差别只在「有没有绝对值」。

说明

绝对值的有无就是定向的有无：不带定向时能积的只有密度，换元带 ∣det⁡∣|\det|∣det∣（prop.volume-density-well-defined）；带定向时 nnn-形式自带符号，换元带 det⁡\detdet。同一件事的两种记账。

为什么只对 nnn-形式成立：k<nk<nk<n 的形式在微分同胚下按 k×kk\times kk×k 的子式变换，与 nnn 维体积元对不上，所以不存在「kkk-形式在流形上的换元公式」。要积分 kkk-形式，得先挑一个 kkk 维子流形把它拉回去（def.integral-form 开头那句）。

证明的两块拼图：一是「保向微分同胚下积分不变」（def.integral-form 的良定性，就是 Rn\mathbb{R}^{n}Rn 上 det⁡\detdet 与换元公式的匹配），二是单位分解（prop.paracompact-partition-unity）把整体拆到卡里。两块都在别处证过，所以这条定理本身是拼装。

⚠️ 微分同胚不能放宽成「光滑满射」：那样要引入度数与积分重数（∫Mf∗ω=deg⁡(f)∫Nω\int_{M}f^{\ast}\omega = \deg(f)\int_{N}\omega∫M​f∗ω=deg(f)∫N​ω），ε\varepsilonε 就变成整数而不是 ±1\pm1±1。本图只陈述微分同胚情形。

⚠️ 定向的选取：若 MMM 与 NNN 上各取定向，则 ε\varepsilonε 由 fff 相对这两组定向是否保向决定；换掉 NNN 的定向，ε\varepsilonε 与右边同时变号，等式仍成立。所以「保向」这个说法必须相对定好的两组定向。

它指向谁（出边）

推出 1

  • 本页 ⟹ 行列式推出
    流形上的换元公式给出 ∣det⁡A∣|\det A|∣detA∣ 的体积含义

    取 M=U⊆RnM = U \subseteq \mathbb{R}^{n}M=U⊆Rn 有界、N=A(U)N = A(U)N=A(U)，其中 AAA 是可逆线性映射（把它看成 Rn\mathbb{R}^{n}Rn 到自身的微分同胚），ω=dx1∧⋯∧dxn\omega = \mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}ω=dx1∧⋯∧dxn。

    第一步：A∗ω=det⁡(A) ωA^{\ast}\omega = \det(A)\,\omegaA∗ω=det(A)ω。 左边按定义是 ω(Au1,…,Aun)\omega(Au_1,\ldots,Au_n)ω(Au1​,…,Aun​) 给出的 nnn 重交错 nnn 线性型；nnn 维空间上这样的型全体是一维的，而 ω(e1,…,en)=1\omega(e_1,\ldots,e_n) = 1ω(e1​,…,en​)=1，于是由行列式的「交错、多重线性、取单位阵为 111」这三条刻画，

    ω(Au1,…,Aun)=det⁡(A) ω(u1,…,un).\omega(Au_1,\ldots,Au_n) = \det(A)\,\omega(u_1,\ldots,u_n).ω(Au1​,…,Aun​)=det(A)ω(u1​,…,un​).

    第二步：套换元公式。 AAA 保向时 ∫A(U)ω=∫UA∗ω=det⁡(A)∫Uω\int_{A(U)}\omega = \int_{U} A^{\ast}\omega = \det(A)\int_{U}\omega∫A(U)​ω=∫U​A∗ω=det(A)∫U​ω；反向时按公式多一个负号。两种情形合起来是 ∫A(U)ω=∣det⁡A∣∫Uω\int_{A(U)}\omega = |\det A|\int_{U}\omega∫A(U)​ω=∣detA∣∫U​ω，而左边就是 A(U)A(U)A(U) 的体积：

    vol⁡(A(U))=∣det⁡A∣⋅vol⁡(U).\operatorname{vol}\bigl(A(U)\bigr) = |\det A| \cdot \operatorname{vol}(U).vol(A(U))=∣detA∣⋅vol(U).

    取 UUU 是单位立方体，即得「det⁡\detdet 的绝对值是把单位立方体拉成的平行体的体积」，符号则记录 AAA 是否保向。■\blacksquare■

    这条把「行列式的几何读法」从直接的体积公理换成了积分：∣det⁡∣|\det|∣det∣ 之所以是体积缩放因子，是因为 nnn-形式是唯一能自然积分的东西。

  • 形式的积分、仿紧性与单位分解 ⟹ 本页推出
    保向不变性 + 单位分解   ⟹  \implies⟹ 流形上的换元公式

    （1）拆到卡里。 设 M,NM,NM,N 各有保向图册，取从属于它们的单位分解 {ρα}\{\rho_{\alpha}\}{ρα​}（在 MMM 上）与 {σβ}\{\sigma_{\beta}\}{σβ​}（在 NNN 上）。把 ω\omegaω 写成 ∑βσβω\sum_{\beta}\sigma_{\beta}\omega∑β​σβ​ω，每一项支在一张保向卡 Vβ⊆NV_{\beta}\subseteq NVβ​⊆N 里；f∗f^{\ast}f∗ 保求和，故只需处理「ω\omegaω 支在一张卡里」的情形。再用 MMM 侧的 {ρα}\{\rho_{\alpha}\}{ρα​} 把 f∗ωf^{\ast}\omegaf∗ω 拆开。有限多项相加，逐项证完即可。

    （2）化到 Rn\mathbb{R}^{n}Rn。 于是只需处理开集之间的微分同胚 g:U→Vg : U\to Vg:U→V（U,V⊆RnU,V\subseteq\mathbb{R}^{n}U,V⊆Rn）与 ω=β dy1∧⋯∧dyn\omega = \beta\,\mathrm{d}y^{1}\wedge\cdots\wedge\mathrm{d}y^{n}ω=βdy1∧⋯∧dyn。拉回给出

    g∗ω=(β∘g) det⁡(∂g∂x) dx1∧⋯∧dxn,g^{\ast}\omega = (\beta\circ g)\,\det\Bigl(\frac{\partial g}{\partial x}\Bigr)\,\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n} ,g∗ω=(β∘g)det(∂x∂g​)dx1∧⋯∧dxn,

    因为 g∗(dy1∧⋯∧dyn)g^{\ast}(\mathrm{d}y^{1}\wedge\cdots\wedge\mathrm{d}y^{n})g∗(dy1∧⋯∧dyn) 是 UUU 上的顶次形式，其唯一系数正是 Jacobi 行列式（顶次外形式在微分同胚下按 det⁡\detdet 变换 —— 这正是 def.integral-form 的良定性所用的那一条）。

    （3）用一次换元公式。

    ∫Ug∗ω=∫U(β∘g) det⁡(∂g∂x)dx=±∫U(β∘g)∣det⁡(∂g∂x)∣dx=±∫Vβ dy,\int_{U}g^{\ast}\omega = \int_{U}(\beta\circ g)\,\det\Bigl(\frac{\partial g}{\partial x}\Bigr)\mathrm{d}x = \pm\int_{U}(\beta\circ g)\Bigl|\det\Bigl(\frac{\partial g}{\partial x}\Bigr)\Bigr|\mathrm{d}x = \pm\int_{V}\beta\,\mathrm{d}y ,∫U​g∗ω=∫U​(β∘g)det(∂x∂g​)dx=±∫U​(β∘g)​det(∂x∂g​)​dx=±∫V​βdy,

    中间的 ±\pm± 只在 det⁡<0\det<0det<0 时出现；最后一步就是 Rn\mathbb{R}^{n}Rn 上的换元公式（它自带 ∣det⁡∣|\det|∣det∣）。ggg 保向等价于 det⁡>0\det>0det>0 处处成立（UUU 连通时），此时取 +++。

    （4）拼回去。 逐项相加，再用单位分解「和为一」把系数约掉，得 ∫Mf∗ω=ε∫Nω\int_{M}f^{\ast}\omega = \varepsilon\int_{N}\omega∫M​f∗ω=ε∫N​ω。∎

    ⭐ 绝对值的有无就是「有没有定向」：nnn-形式自带符号，故换元带 det⁡\detdet；密度不带符号，故换元带 ∣det⁡∣|\det|∣det∣。两条公式的差别全在这里。

定义引用 2

  • 行列式 → 本页定义引用

    换元因子是 Jacobi 矩阵的行列式 det⁡(∂g/∂x)\det(\partial g/\partial x)det(∂g/∂x)。定向版的公式之所以没有绝对值，正是因为 det⁡\detdet 本身带符号 —— 绝对值是「丢了定向」之后补回来的。

  • 仿紧性与单位分解 → 本页定义引用

    把流形上的积分拆成逐卡的 Rn\mathbb{R}^{n}Rn 积分，靠的是从属于保向图册的单位分解；没有它，定理只能逐卡陈述，拼不成整体。
