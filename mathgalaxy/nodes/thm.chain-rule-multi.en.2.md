# Chain Rule in Several Variables　`thm.chain-rule-multi`
English entry · root `../`
[in graph](../#n=thm.chain-rule-multi)　·　[Chinese page (authoritative)](./thm.chain-rule-multi.md)

$$J_{g \circ f}(a) = J_g\bigl(f(a)\bigr)\, J_f(a)$$

## Notes · **draft**
⭐ The whole theorem is one sentence: **the chain rule for differentials is composition of linear maps**.

The matrix form is merely what it looks like after choosing bases — so "chain rule = matrix multiplication" is not a coincidence but a consequence of the definition.

⚠ There is a real trap in the proof: one cannot simply write $Dg(f(a + h)) = Dg(f(a)) + O(h)$.
