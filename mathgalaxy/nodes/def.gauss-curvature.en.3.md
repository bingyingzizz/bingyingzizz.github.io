## Notes · **draft**
⚠️ **Signs and index order** (uniform throughout this package): $R_{ijk\ell} = \langle R(\partial_{i},\partial_{j})\partial_{k},\partial_{\ell}\rangle$, so on the unit sphere ($K = 1$, $g_{ij} = \delta_{ij}$) one has $R_{1221} = 1$, $R_{1212} = -1$.

Many books write "$K = R_{1212}/\det g$", which uses another index order (or another sign for $R$); mathematically it is the same thing.

**The only check that a convention is right: the unit sphere must give $K = 1$.**
