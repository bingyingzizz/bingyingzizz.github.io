Statement

From any family of non-empty sets one can pick one element from each, "all at once". Written in terms of a choice function:

dom⁡\operatorname{dom}dom is defined only for functions, so the assertion says: "there is a function fff with dom⁡f=F\operatorname{dom} f = Fdomf=F, and f(X)∈Xf(X) \in Xf(X)∈X for every X∈FX \in FX∈F":

∀F[(∀X∈F,X≠∅)→∃f(dom⁡f=F∧∀X∈F,f(X)∈X)]\forall F [ ( \forall X \in F, X \ne \emptyset ) \to \exists f ( \operatorname{dom} f = F \wedge \forall X \in F, f(X) \in X ) ]∀F[(∀X∈F,X=∅)→∃f(domf=F∧∀X∈F,f(X)∈X)] Another common form (pairwise disjoint form): if FFF is a family of pairwise disjoint non-empty sets, then there is a set CCC with #(C∩X)=1\#(C \cap X) = 1#(C∩X)=1 for every X∈FX \in FX∈F.

The choice function fff is the device for "picking all at once"; AC asserts that such a simultaneous choice is always possible.
