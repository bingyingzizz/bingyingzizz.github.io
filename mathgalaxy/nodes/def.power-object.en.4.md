# power object　`def.power-object`
English entry · root `../`
[in graph](../#n=def.power-object)　·　[Chinese page (authoritative)](./def.power-object.md)

📌 **What it looks like in $\mathbf{Set}$**: $Y^{X}$ is just the function set $\operatorname{Hom}_{\mathbf{Set}}(X,Y)$, with $\operatorname{ev}(f, x) = f(x)$ — the power object is the objectification of "collecting functions into a set".
