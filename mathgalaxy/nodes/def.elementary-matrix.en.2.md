# elementary operations and elementary matrices　`def.elementary-matrix`
English entry · root `../`
[in graph](../#n=def.elementary-matrix)　·　[Chinese page (authoritative)](./def.elementary-matrix.md)

The matrix obtained by applying one such operation to the identity matrix $I_n$ is called an **elementary matrix** (written $E$). The key property is: **performing one elementary row operation on $A$ is the same as multiplying on the left by the corresponding elementary matrix**, that is, replacing $A$ by $EA$.

Every elementary matrix is **invertible**, and its inverse is again an elementary matrix of the same type: a swap is its own inverse, multiplying by $c$ has inverse multiplying by $c^{-1}$, and adding $c$ times a row has inverse adding $-c$ times it.
