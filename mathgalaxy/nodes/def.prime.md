# 素数　`def.prime`
素数与合数
layer 11 · 定义 · 整除与同余 · 数论
[在星图里打开](../#n=def.prime)　·　[节点索引](../index.md)

大于 $1$ 的整数 $p$ 叫**素数**，若它的正因数只有 $1$ 与 $p$ 本身。大于 $1$ 且不是素数的整数叫**合数**。
