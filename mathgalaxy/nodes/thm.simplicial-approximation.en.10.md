# simplicial approximation　`thm.simplicial-approximation`
English entry · root `../`
[in graph](../#n=thm.simplicial-approximation)　·　[Chinese page (authoritative)](./thm.simplicial-approximation.md)

For each vertex of $K^{(m)}$, say $v$, the set $\operatorname{st}(v)$ has diameter $\le 2\,\operatorname{mesh}(K^{(m)}) < \delta$, so $f(\operatorname{st}(v)) \subseteq \operatorname{st}_{L}(w)$ for some $w$. Set $g(v) := w$. By Lemma 1, $g$ is simplicial and $|g| \simeq f$. ∎
