# standard conformal maps　`prop.standard-maps`
English entry · root `../`
[in graph](../#n=prop.standard-maps)　·　[Chinese page (authoritative)](./prop.standard-maps.md)

1. $\mathbb{H} \to \mathbb{D}$: $z \mapsto \dfrac{z - i}{z + i}$;
2. angle $\{\, 0 < \arg z < \alpha \,\}$ $\to \mathbb{H}$: $z \mapsto z^{\pi/\alpha}$;
3. strip $\{\, 0 < \operatorname{Im} z < \pi \,\}$ $\to \mathbb{H}$: $z \mapsto e^{z}$;
4. slit plane $\mathbb{C} \setminus (-\infty, 0]$ $\to \mathbb{H}$: the principal branch of $\sqrt{z}$ or $\log z$;
5. automorphisms of $\mathbb{D} \to \mathbb{D}$: $z \mapsto e^{i\theta}\dfrac{z - a}{1 - \bar a z}$, $|a| < 1$.
