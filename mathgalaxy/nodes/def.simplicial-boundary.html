设 σ=[v0,…,vp]\sigma = [v_{0}, \ldots, v_{p}]σ=[v0​,…,vp​] 是有序 ppp-单纯形（v0<⋯<vpv_{0} < \cdots < v_{p}v0​<⋯<vp​）。它的边缘定义为

∂pσ:=∑i=0p(−1)i [v0,…,vi^,…,vp],\partial_{p}\sigma := \sum_{i=0}^{p} (-1)^{i}\,[v_{0}, \ldots, \widehat{v_{i}}, \ldots, v_{p}],∂p​σ:=i=0∑p​(−1)i[v0​,…,vi​​,…,vp​],

其中帽子 vi^\widehat{v_{i}}vi​​ 表示「删掉这个顶点」。因为 Cp(K)C_{p}(K)Cp​(K) 自由，这条公式线性延拓成唯一的群同态

∂p:Cp(K)⟶Cp−1(K).\partial_{p} : C_{p}(K) \longrightarrow C_{p-1}(K).∂p​:Cp​(K)⟶Cp−1​(K).

基本性质：对每个 ppp，

∂p−1∘∂p=0.\partial_{p-1} \circ \partial_{p} = 0.∂p−1​∘∂p​=0.

于是约定 Zp:=ker⁡∂pZ_{p} := \ker\partial_{p}Zp​:=ker∂p​（闭链）、Bp:=im⁡∂p+1B_{p} := \operatorname{im}\partial_{p+1}Bp​:=im∂p+1​（边缘），并且 Bp⊆ZpB_{p} \subseteq Z_{p}Bp​⊆Zp​，即 (C∗,∂)(C_{*}, \partial)(C∗​,∂) 是一个链复形。

说明

∂2=0\partial^{2} = 0∂2=0 的证明骨架：把 ∂∂σ\partial\partial\sigma∂∂σ 写成双重求和，每项对应「删两个顶点 i<ji < ji<j」。这一项在两次展开里出现两次：一次系数是 (−1)i(−1)j−1(-1)^{i}(-1)^{j-1}(−1)i(−1)j−1（先删 jjj 再删 iii），另一次是 (−1)j(−1)i(-1)^{j}(-1)^{i}(−1)j(−1)i（先删 iii 再删 jjj）——两者相差一个符号，恰好相消。用的是面映射恒等式 djdi=didj−1d_{j}d_{i} = d_{i}d_{j-1}dj​di​=di​dj−1​（i<ji < ji<j）。

⭐ 符号 (−1)i(-1)^{i}(−1)i 就是为这件事选的。换别的符号约定也行，只要全篇一致；不一致的后果是 ∂2≠0\partial^{2} \ne 0∂2=0，整台机器立刻失效。

几个小情形：∂0=0\partial_{0} = 0∂0​=0（顶点没有更低维的面）；∂1[v0,v1]=[v1]−[v0]\partial_{1}[v_{0}, v_{1}] = [v_{1}] - [v_{0}]∂1​[v0​,v1​]=[v1​]−[v0​]；∂2[v0,v1,v2]=[v1,v2]−[v0,v2]+[v0,v1]\partial_{2}[v_{0}, v_{1}, v_{2}] = [v_{1}, v_{2}] - [v_{0}, v_{2}] + [v_{0}, v_{1}]∂2​[v0​,v1​,v2​]=[v1​,v2​]−[v0​,v2​]+[v0​,v1​]（三角形三条边，中间那条带负号 —— 定向）。

💡 一句话：∂\partial∂ 与 ∂2=0\partial^{2} = 0∂2=0 这一对，就是整个同调论的全部代数输入；剩下的一切（商群、长正合列、Mayer–Vietoris）都是这两条的推论。

  • 链群 → 本页定义引用

    ∂p:Cp(K)→Cp−1(K)\partial_{p} : C_{p}(K) \to C_{p-1}(K)∂p​:Cp​(K)→Cp−1​(K) 只在基上规定，再线性延拓。这正是自由阿贝尔群的用处：基上的规定自动给出唯一的群同态，不需要任何相容性验证。
