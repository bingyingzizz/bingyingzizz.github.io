def.ring · 代数 · 环 · 交换环

又称环·ring·交换环·含幺环

陈述

设 AAA 是集合，+++ 与 ⋅\cdot⋅ 是 AAA 上的两个二元运算。称 (A,+,⋅)(A, +, \cdot)(A,+,⋅) 是一个环，当且仅当：

  • (A,+)(A, +)(A,+) 是阿贝尔群；
  • (A,⋅)(A, \cdot)(A,⋅) 满足结合律（不要求单位元，也不要求交换）；
  • 分配律 a(b+c)=ab+aca(b + c) = ab + aca(b+c)=ab+ac、(a+b)c=ac+bc(a + b)c = ac + bc(a+b)c=ac+bc 成立。

乘法还交换的环叫交换环；再要求有乘法单位元 1≠01 \ne 01=0 的环叫含幺环。

说明

⭐ 又是「集合 + 运算 + 公理」，而且这一层直接引用了下面的阿贝尔群：加法那一组公理不再重写，一句话带过。

与域对照：域要求每个非零元可逆（(F∖{0},⋅)(F\setminus\{0\}, \cdot)(F∖{0},⋅) 是阿贝尔群），环不要求。所以域是环中的一个特例，Z\mathbb{Z}Z 是环但不是域 —— 这正是「域」那条定义里 Z\mathbb{Z}Z 反例的来源。
