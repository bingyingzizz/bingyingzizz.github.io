Statement

What it does: it specifies "how a vector changes when transported in a given direction" — only with this rule can one differentiate vector fields and then speak of acceleration, geodesics, and curvature.

Let MMM be a smooth manifold and X(M)\mathfrak{X}(M)X(M) the set of smooth vector fields. An affine connection (linear connection) is a map

∇:X(M)×X(M)⟶X(M),(X,Y)⟼∇XY,\nabla : \mathfrak{X}(M)\times\mathfrak{X}(M)\longrightarrow\mathfrak{X}(M),\qquad (X,Y)\longmapsto\nabla_{X}Y ,∇:X(M)×X(M)⟶X(M),(X,Y)⟼∇X​Y,

Notes

How to read the three axioms: the first says that ∇XY\nabla_{X}Y∇X​Y at a point depends only on the value of XXX at that point (otherwise it would not count as "along a direction"); the third says that it is not tensorial in YYY — differentiation must see how YYY changes. This asymmetry is exactly the boundary between a "connection" and a "tensor".

Parallel transport and geodesics: solving ∇γ˙V=0\nabla_{\dot\gamma}V = 0∇γ˙​​V=0 gives the parallel transport of VVV along γ\gammaγ; the solutions of ∇γ˙γ˙=0\nabla_{\dot\gamma}\dot\gamma = 0∇γ˙​​γ˙​=0 are geodesics. Both use only ∇\nabla∇, with no need for an ambient space.

Connections are not unique: a general affine connection has infinitely many choices (any non-symmetric part of Γ\GammaΓ can be changed). Only adding "torsion-free + metric" makes it unique — this is the existence and uniqueness of the Levi-Civita connection (Koszul formula).

Curvature is the commutator of the connection: R(X,Y)=[∇X,∇Y]−∇[X,Y]R(X,Y) = [\nabla_{X},\nabla_{Y}]-\nabla_{[X,Y]}R(X,Y)=[∇X​,∇Y​]−∇[X,Y]​ (Riemann 曲率张量). Thus a single "connection" gives rise to parallel transport, geodesics, and curvature at once.
