# Differential of a Smooth Map　`def.differential-map`
English entry · root `../`
[in graph](../#n=def.differential-map)　·　[Chinese page (authoritative)](./def.differential-map.md)

**Notation clash**: the same $\mathrm{d}$ denotes the tangent map $\mathrm{d}F_{p}$ and the exterior derivative $\mathrm{d}\omega$.

These are not two things: $\mathrm{d}f$ is the tangent map $\mathrm{d}f_{p} : T_{p}M \to \mathbb{R}$, i.e. a $1$-form (`def.exterior-derivative`).
