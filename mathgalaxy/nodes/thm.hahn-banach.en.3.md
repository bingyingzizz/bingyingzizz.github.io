i.e. $c$ lies in the interval $[\sup_m (f(m) - p(m - x_0)),\ \inf_m (p(m + x_0) - f(m))]$. This interval is non-empty, because for any $m_1, m_2 \in M$, sublinearity gives

$f(m_1) + f(m_2) = f(m_1 + m_2) \le p(m_1 + m_2) \le p(m_1 - x_0) + p(m_2 + x_0),$

i.e. $f(m_1) - p(m_1 - x_0) \le p(m_2 + x_0) - f(m_2)$. Choose any $c$ in the interval; the extension then works.
