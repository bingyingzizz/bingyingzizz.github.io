白话：把实意义下的两个偏导数 ∂f/∂x\partial f/\partial x∂f/∂x、∂f/∂y\partial f/\partial y∂f/∂y 重新线性组合，得到「沿 zzz 方向」和「沿 zˉ\bar zzˉ 方向」的两个复数方向导数。

设 f=u+ivf = u + ivf=u+iv 在 z0z_0z0​ 的邻域内实可微（即 u,vu, vu,v 都实可微）。定义

∂f∂z:=12(∂f∂x−i ∂f∂y),∂f∂zˉ:=12(∂f∂x+i ∂f∂y).\frac{\partial f}{\partial z} := \frac{1}{2}\left( \frac{\partial f}{\partial x} - i\,\frac{\partial f}{\partial y} \right), \qquad \frac{\partial f}{\partial \bar z} := \frac{1}{2}\left( \frac{\partial f}{\partial x} + i\,\frac{\partial f}{\partial y} \right).∂z∂f​:=21​(∂x∂f​−i∂y∂f​),∂zˉ∂f​:=21​(∂x∂f​+i∂y∂f​).

在这两个记号下，fff 的增量写成

f(z0+Δz)−f(z0)=∂f∂z(z0) Δz+∂f∂zˉ(z0) Δz‾+o(Δz).f(z_0 + \Delta z) - f(z_0) = \frac{\partial f}{\partial z}(z_0)\,\Delta z + \frac{\partial f}{\partial \bar z}(z_0)\,\overline{\Delta z} + o(\Delta z).f(z0​+Δz)−f(z0​)=∂z∂f​(z0​)Δz+∂zˉ∂f​(z0​)Δz+o(Δz).

两个系数由增量唯一决定：若 AΔz+BΔz‾=aΔz+bΔz‾+o(Δz)A\Delta z + B\overline{\Delta z} = a\Delta z + b\overline{\Delta z} + o(\Delta z)AΔz+BΔz=aΔz+bΔz+o(Δz)，分别取 Δz=t\Delta z = tΔz=t（ttt 为实数）与 Δz=it\Delta z = itΔz=it，令 t→0t \to 0t→0 即得 A=aA = aA=a、B=bB = bB=b。

说明

⭐ ∂/∂z\partial/\partial z∂/∂z、∂/∂zˉ\partial/\partial \bar z∂/∂zˉ 叫 Wirtinger 导数。它们不是差商极限：zˉ\bar zzˉ 沿不同方向的行为不一样，差商没有极限。它们只是实偏导的一对线性组合，是记账工具。

⭐ 记忆法（书里脚注）：把 x=(z+zˉ)/2x = (z + \bar z)/2x=(z+zˉ)/2、y=−i(z−zˉ)/2y = -i(z - \bar z)/2y=−i(z−zˉ)/2 代进 f(x,y)f(x, y)f(x,y)，形式上把 zzz、zˉ\bar zzˉ 当成独立变量用链式法则求偏导，就得到上面两式。⚠ 这只帮助记忆 —— 严格定义是右边的组合，因为 zzz 与 zˉ\bar zzˉ 作为 R2\mathbb{R}^2R2 上的两个坐标并不独立。

⭐ 真正好用的是它的判据性质：fff 复可微   ⟺  \iff⟺ ∂f/∂zˉ(z0)=0\partial f/\partial \bar z(z_0) = 0∂f/∂zˉ(z0​)=0。也就是「fff 能否只含 zzz 不含 zˉ\bar zzˉ」，变成可以逐项验算的事情。

📌 形式上有 ∂z/∂z=∂zˉ/∂zˉ=1\partial z/\partial z = \partial \bar z/\partial \bar z = 1∂z/∂z=∂zˉ/∂zˉ=1，∂z/∂zˉ=∂zˉ/∂z=0\partial z/\partial \bar z = \partial \bar z/\partial z = 0∂z/∂zˉ=∂zˉ/∂z=0 —— 就像两组独立的坐标。
