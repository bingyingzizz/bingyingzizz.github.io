# singular value decomposition　`thm.svd`
English entry · root `../`
[in graph](../#n=thm.svd)　·　[Chinese page (authoritative)](./thm.svd.md)

⭐ Division of labour with the spectral theorem: the spectral theorem handles **square and self-adjoint** (similarity classification);

SVD handles **arbitrary shapes** (equivalence classification).

The former requires $m = n$ and $A^{\ast} = A$; the latter requires nothing.

⭐ Uses (the most important theorem in numerical linear algebra): low-rank approximation (Eckart–Young: truncating to the first $k$ singular values gives the best low-rank approximation), principal component analysis, pseudoinverse, condition number.
