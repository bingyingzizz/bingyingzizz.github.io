AB5 与 AB3*/AB4* 的关系

AB 公理之间的蕴含关系

prop.ab5-implications · 同调代数 · AB 公理 · Grothendieck

又称AB5 与 AB3*·AB 公理关系·Proposition 5.2.7

陈述

  1. Grothendieck 范畴自动满足 AB3\（有所有极限）—— 即 AB5 加上生成元，就免费得到 AB3\；
  2. 除零范畴 {0}\{0\}{0} 外，没有范畴能同时满足 AB5 与 AB5\*；
  3. 拓扑斯上的 Ab(T)\mathbf{Ab}(\mathcal{T})Ab(T) 满足 AB5 与 AB3\，但一般并不满足 AB6 或 AB4\。

说明

第 1 条为什么值得单说：AB3 与 AB3* 是对偶的两条（一个有所有余极限、一个有所有极限），一般不能互相推出。「有生成元 + 滤过余极限正合」这两条合起来却把对偶那一条也带出来了 —— 这是 Grothendieck 范畴理论里最不平凡的一条「免费午餐」。

第 2 条的意思：AB5（滤过余极限正合）与 AB5*（滤过极限正合）是互相排斥的，只能一边倒。零范畴是唯一例外（它什么都没有，两边都满足）。

第 3 条是「为什么凝聚态数学要用 CondAb 而不是随便一个拓扑斯」的答案：Ab(T)\mathbf{Ab}(\mathcal{T})Ab(T) 只有 AB5 与 AB3，做一般的同调代数够用；但 CondAb\mathrm{CondAb}CondAb 额外满足 AB6 与 AB4\ —— 即「滤过余极限与积交换」「积正合」。有了这两条才能像在 Ab\mathbf{Ab}Ab 里一样自由地交换极限与余极限。

三条各自的理由。

  • 第 1 条：用 Freyd 的特殊伴随函子定理。一个余完备范畴若有小的余生成集且余良幂（每个对象只有一个小集合那么多的商），则它完备。Grothendieck 范畴 A\mathcal{A}A：余完备 ✓（AB5）；余良幂与小的余生成集都来自生成元 UUU —— 一个商由它「在 UUU 上的点」决定，于是 UUU 的商构成一个集合，而它们的积就是余生成元。SAFT 于是给出所有极限存在 ✓。
  • 第 2 条：这是 Roos 的经典结果。思路：AB5 让 N\mathbb{N}N 形状的余极限行为良好、AB5\* 让 N\mathbb{N}N 形状的逆极限行为良好；两者同时成立时会逼出一条 Milnor 型的正合列（∏\prod∏ 与 ⨁\bigoplus⨁ 的比较），在阿贝尔范畴里只能对零对象成立 ✓。
  • 第 3 条：前半 —— Ab(T)\mathbf{Ab}(\mathcal{T})Ab(T) 是拓扑斯上的层范畴，是 Grothendieck 范畴，故 AB5 + AB3\（第 1 条）✓；后半 —— 「AB6 与 AB4\ 一般不成立」在一般拓扑斯上有反例（阿贝尔层的积一般不正合、滤过余极限一般不与积交换），这两条不能白拿 ✓。∎

⭐ 所以 CondAb\mathrm{CondAb}CondAb 的 AB6 / AB4\* 是额外的收获，来自 CHaus\mathbf{CHaus}CHaus 这个 site 的具体形状（逐项归约到 Ab\mathbf{Ab}Ab），而不是任何拓扑斯都有的。
