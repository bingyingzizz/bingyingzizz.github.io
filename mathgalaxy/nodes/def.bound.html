陈述

设 (P,⪯)(P, \preceq )(P,⪯) 是偏序集，S⊆PS \subseteq PS⊆P，u,l,m∈Pu, l, m \in Pu,l,m∈P。

  • uuu 是 SSS 的上界：∀s∈S,s⪯u\forall s \in S, s \preceq u∀s∈S,s⪯u。
  • lll 是 SSS 的下界：∀s∈S,l⪯s\forall s \in S, l \preceq s∀s∈S,l⪯s。
  • uuu 是 SSS 的上确界（记 sup⁡S\sup SsupS）：uuu 是上界，且 u⪯u \precequ⪯ 每一个上界 —— 即最小的上界。
  • lll 是 SSS 的下确界（记 inf⁡S\inf SinfS）：lll 是下界，且每一个下界 ⪯l\preceq l⪯l —— 即最大的下界。
  • mmm 是 PPP 的极大元：∀x∈P(m⪯x→x=m)\forall x \in P ( m \preceq x \to x = m )∀x∈P(m⪯x→x=m)，即没有比 mmm 更大的元素。
  • mmm 是 PPP 的最大元：∀x∈P,x⪯m\forall x \in P, x \preceq m∀x∈P,x⪯m，即 mmm 比所有元素都大。

把 ⪯\preceq⪯ 换成 ⪰\succeq⪰，前四条里的「上 / 大 / 极大」就变成「下 / 小 / 极小」。

⚠ 极大元 ≠\ne= 最大元；sup⁡S\sup SsupS 不必属于 SSS（sup⁡(0,1)=1\sup (0, 1) = 1sup(0,1)=1）—— 这是两组容易混的东西。

偏序集里一般不保证 sup⁡\supsup 存在；R\mathbb{R}R 的特别之处正是保证它存在，那就是确界原理（见「R\mathbb{R}R 是完备有序域」）。

说明

例子：P={{1},{2}}P = \{ \{1\}, \{2\} \}P={{1},{2}} 按 ⊆\subseteq⊆ 排序。两个元素都是极大元（谁也包不住谁），但没有最大元。

在全序集里两者才重合。偏序集里「极大」只要求「上面没有别人」，不要求「下面有所有人」。

佐恩引理保证的是极大元，而不是最大元——这一点在应用时最容易出错。

在 R\mathbb{R}R 上 u=sup⁡Su = \sup Su=supS 有一个只用序的等价说法：∀ε>0,∃s∈S:s>u−ε\forall \varepsilon > 0, \exists s \in S : s > u - \varepsilon∀ε>0,∃s∈S:s>u−ε（任意近地逼近，但不必取到）。
