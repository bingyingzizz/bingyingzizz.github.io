# convex sets are star-shaped at every point　`thm.convex-star-shaped-every-point`
English entry · root `../`
[in graph](../#n=thm.convex-star-shaped-every-point)　·　[Chinese page (authoritative)](./thm.convex-star-shaped-every-point.md)

⚠ For the empty set, "for every $x_{0} \in C$" is a universal statement and holds vacuously; but the empty set itself is not star-shaped (it has no star point), see @@def.star-shaped@@. There is no contradiction: this item says "every point is a star point", not "there exists a star point".

📌 Hence "convex set $\Longrightarrow$ star-shaped set" holds for nonempty convex sets; written pointwise, the empty set is no longer a counterexample.
