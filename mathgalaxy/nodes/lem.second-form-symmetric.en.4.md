# Symmetry of the Second Fundamental Form　`lem.second-form-symmetric`
English entry · root `../`
[in graph](../#n=lem.second-form-symmetric)　·　[Chinese page (authoritative)](./lem.second-form-symmetric.md)

⚠ What is symmetric is the matrix $(c_{ij})$ and $(h_{ij})$ **relative to an orthonormal frame**; if one uses a non-orthogonal $\{r_{u}, r_{v}\}$, it is $h_{ij}$ that is symmetric, while $(h^{j}_{\ i}) = g^{jk}h_{ki}$ is generally not. The equation $\det(h-kg)=0$ uses exactly the $h_{ij}$ branch.
