说明

⭐ 三角函数的分析定义（而非几何定义）：由级数出发，一切恒等式与求导公式都可以算出来，而且自动对复数成立。

⭐ 与 exp⁡\expexp 的关系将在「Euler 公式」那一条里揭晓：把 exp⁡\expexp 的级数按 nnn 的奇偶拆开，就得到 cos⁡\coscos 与 sin⁡\sinsin。

⚠ 几何意义（单位圆、角度、弧度）是后来才接上的：级数先告诉我们 cos⁡\coscos 有零点、sin⁡\sinsin 有周期，几何图像才随之而来。
