# power object　`def.power-object`
English entry · root `../`
[in graph](../#n=def.power-object)　·　[Chinese page (authoritative)](./def.power-object.md)

⭐ **Why it is the second half of "cartesian closed"**: cartesian closed = finite products + power objects. @@prop.cg-cartesian-closed@@ here says exactly that "the compactly generated side has power objects, only the compact-open topology has to be $k$-ified once more".

⚠ **Do not confuse it with "internal Hom"**: when $\mathcal{C}$ is a general category, $Y^{X}$ is the object that **really exists** in $\mathcal{C}$; the internal Hom (@@def.internal-hom@@, the one in a topos) is built by first taking Hom sets and then using colimits or sheafification. In a cartesian closed category the two agree; in a general topos only the internal Hom exists.
