# long exact sequence of a pair　`thm.long-exact-pair`
English entry · root `../`
[in graph](../#n=thm.long-exact-pair)　·　[Chinese page (authoritative)](./thm.long-exact-pair.md)

**Connecting homomorphism.** Take $[c] \in H_{p}(X, A)$, where $c \in S_{p}(X)$ and $\bar\partial[c] = 0$, that is, $\partial c \in S_{p-1}(A)$. Set $\partial_{*}[c] := [\partial c] \in H_{p-1}(A)$.

Well-definedness follows from $\partial\partial c = 0$, so $\partial c$ is a cycle in $A$. If $c^{\prime} - c = \partial d + a$ ($d \in S_{p+1}(X)$, $a \in S_{p}(A)$), then $\partial c^{\prime} - \partial c = \partial a$ is a boundary in $A$, so the homology class is unchanged.

**Exactness.** Let $j_{*} : H_{p}(A) \to H_{p}(X)$ and $q_{*} : H_{p}(X) \to H_{p}(X, A)$ denote the induced maps.
