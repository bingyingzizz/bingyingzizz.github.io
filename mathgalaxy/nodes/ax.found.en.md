## Statement · **reviewed**
Every non-empty set has an "$\in$-minimal" element:

$$\forall A [ A \ne \emptyset \to \exists x ( x \in A \wedge  x \cap A = \emptyset ) ]$$

An equivalent form: $\in$ is a well-founded relation, so there is no infinite descending chain

$$x_0 \ni  x_1 \ni  x_2 \ni  \cdots$$
