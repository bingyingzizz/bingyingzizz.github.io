设 M∙M^{\bullet}M∙ 是 site C\mathcal{C}C 上的阿贝尔层复形，X∈CX \in \mathcal{C}X∈C。它在 XXX 上的第 nnn 个上同调群是

Hn(X,M∙):=RnΓ(X,M∙),H^{n}(X, M^{\bullet}) := R^{n}\Gamma(X, M^{\bullet}),Hn(X,M∙):=RnΓ(X,M∙),

其中 Γ(X,−)\Gamma(X, -)Γ(X,−) 是 XXX 处的截面函子。

说明

⭐ 一句话：层上同调就是截面函子的右导出函子。Γ(X,−)\Gamma(X,-)Γ(X,−) 左正合但不右正合（层化会捣乱），RnΓR^{n}\GammaRnΓ 正是补上断口的那半个。

为什么需要它：单看 H0(X,M)=Γ(X,M)=M(X)H^{0}(X, M) = \Gamma(X, M) = M(X)H0(X,M)=Γ(X,M)=M(X) 只有整体截面；H1H^{1}H1 起才开始记录「层粘不上去」的信息（H1H^{1}H1 分类层的主丛 / torsor）。
