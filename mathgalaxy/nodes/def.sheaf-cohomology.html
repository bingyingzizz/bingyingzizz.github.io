设 M∙M^{\bullet}M∙ 是景 C\mathcal{C}C 上的阿贝尔层复形，X∈CX \in \mathcal{C}X∈C。它在 XXX 上的第 nnn 个上同调群是

其中 Γ(X,−)\Gamma(X, -)Γ(X,−) 是 XXX 处的截面函子。

说明

⭐ 一句话：层上同调就是截面函子的右导出函子。Γ(X,−)\Gamma(X,-)Γ(X,−) 左正合但不右正合（层化会捣乱），RnΓR^{n}\GammaRnΓ 正是补上断口的那半个。

为什么需要它：单看 H0(X,M)=Γ(X,M)=M(X)H^{0}(X, M) = \Gamma(X, M) = M(X)H0(X,M)=Γ(X,M)=M(X) 只有整体截面；H1H^{1}H1 起才开始记录「层粘不上去」的信息（H1H^{1}H1 分类层的主丛 / torsor）。

📌 例：H0(X;Z)H^{0}(X;\mathbb{Z})H0(X;Z) 就是整体截面的群；H1(S1;Z)≅ZH^{1}(S^{1};\mathbb{Z}) \cong \mathbb{Z}H1(S1;Z)≅Z（与奇异同调一致，见 圆的 H¹）；层上同调在细层（如 C∞C^{\infty}C∞ 函数层）上高次为零。

  • 本页 ⟹ 层上同调是同伦不变量推出

    证明第 1 条。 常值系数下可以用 Čech 模型（在紧 Hausdorff 上它就算出真上同调，在一般情形也足够比较）。

    • 同伦 H:X×[0,1]→YH : X \times [0,1] \to YH:X×[0,1]→Y 把 YYY 的覆盖拉到 X×[0,1]X \times [0,1]X×[0,1] 上。

    用 [0,1][0,1][0,1] 的有限区间分解 [0,1]=⋃kIk[0,1] = \bigcup_{k} I_{k}[0,1]=⋃k​Ik​（相邻交叠也是区间）把它拆成有限段，于是对每个覆盖都能在 Čech 复形之间造出一个链同伦 f∗≃g∗f^{*} \simeq g^{*}f∗≃g∗ —— 这一步的核心是「[0,1][0,1][0,1] 的常值系数 Čech 上同调在正次数为零」（区间分解给出的增广 Čech 复形是可缩的）。

    • 链同伦在同调上诱导同一个映射，故 Hn(f)=Hn(g)H^{n}(f) = H^{n}(g)Hn(f)=Hn(g)。

    第 2 条。 设 ggg 是 fff 的同伦逆，即 fg≃idYf g \simeq \mathrm{id}_{Y}fg≃idY​、gf≃idXg f \simeq \mathrm{id}_{X}gf≃idX​。

    由第 1 条，Hn(fg)=Hn(idY)=idH^{n}(fg) = H^{n}(\mathrm{id}_{Y}) = \mathrm{id}Hn(fg)=Hn(idY​)=id，而 Hn(fg)=Hn(f)∘Hn(g)H^{n}(fg) = H^{n}(f) \circ H^{n}(g)Hn(fg)=Hn(f)∘Hn(g)（上同调是函子），同理另一边。

    于是 Hn(f)H^{n}(f)Hn(f) 与 Hn(g)H^{n}(g)Hn(g) 互逆，Hn(Y,M)≅Hn(X,M)H^{n}(Y, M) \cong H^{n}(X, M)Hn(Y,M)≅Hn(X,M)。

    ∎

  • 本页 ⟹ 紧 Hausdorff 上 Čech 就是上同调推出

    证明思路（经典的比较论证）。 两边都是 Γ(X,−)\Gamma(X, -)Γ(X,−) 的导出函子，差别只在「用哪种消解去算」。要证的其实是一件事： 紧 Hausdorff 空间的开覆盖的 Čech 项是 Γ(X,−)\Gamma(X, -)Γ(X,−)-零调的。 具体地，覆盖 X=(Xi)i\mathfrak{X} = (X_{i})_{i}X=(Xi​)i​ 的 Čech 复形每一项是 ∏iM(Xi)\prod_{i} M(X_{i})∏i​M(Xi​) 型的「有限多个可表对象上的取值」（紧性保证可以只取有限覆盖 —— 有限细化在覆盖的滤过系统里是共尾的），而这类对象正是「有截面   ⟹  \implies⟹ 零调」那一套（Z⋅hX\mathbb{Z}\cdot h_{X}Z⋅hX​ 投射，见「有截面的态射给出零调」）适用的形状。 于是 Cartan–Leray 谱序列 E2p,q=Hˇp(X,Hq(M))  ⟹  Hp+q(X,M)E^{p,q}_{2} = \check{H}^{p}(\mathfrak{X}, H^{q}(M)) \implies H^{p+q}(X, M)E2p,q​=Hˇp(X,Hq(M))⟹Hp+q(X,M) 里 q>0q > 0q>0 的整行消失，退化给出 Hˇn(X,M)≅Hn(X,M)\check{H}^{n}(X, M) \cong H^{n}(X, M)Hˇn(X,M)≅Hn(X,M)；

    再沿覆盖取余极限（上一条）即得对所有覆盖成立的结论。

    ∎

    骨架：比较论证是路线图；有限覆盖在滤过系统中共尾、有限覆盖的高阶 Čech 项零调性两步未逐步展开，细节见节点注。

    证明。 关键在于这两个函子本来是同一个函子。由 Z⋅X\mathbb{Z}\cdot XZ⋅X 的泛性质（它是自由对象：Hom⁡Z(Z⋅X,M)=Hom⁡(X,M)\operatorname{Hom}_{\mathbb{Z}}(\mathbb{Z}\cdot X, M) = \operatorname{Hom}(X, M)HomZ​(Z⋅X,M)=Hom(X,M)）✓，

    Hom⁡Z(Z⋅X, M)  =  Hom⁡T(X, M)  =  Γ(X,M)=M(X)✓\operatorname{Hom}_{\mathbb{Z}}\bigl(\mathbb{Z}\cdot X,\ M\bigr) \;=\; \operatorname{Hom}_{\mathcal{T}}\bigl(X,\ M\bigr) \;=\; \Gamma(X, M) = M(X) ✓HomZ​(Z⋅X, M)=HomT​(X, M)=Γ(X,M)=M(X)✓

    即「取截面」函子与「Hom⁡(Z⋅X,−)\operatorname{Hom}(\mathbb{Z}\cdot X, -)Hom(Z⋅X,−)」逐字相同 ✓。

    右导出函子只依赖函子本身，故两者的右导出函子在导出范畴里同构：R⁡Γ(X,−)≅RHom⁡(Z⋅X,−)\operatorname{R}\Gamma(X, -) \cong \operatorname{RHom}(\mathbb{Z}\cdot X, -)RΓ(X,−)≅RHom(Z⋅X,−) ✓；

  • 本页 ⟹ Stone 空间上的上同调为零推出

    证明。 SSS 紧 Hausdorff，所以可以用 Čech 上同调算（上一条）。而完全不连通 + 紧 Hausdorff 给出一条极强的细化性质：

    • 任何覆盖都有有限的、两两不交的闭开（clopen）细化。 取任一覆盖，用紧性抽出有限子覆盖；再由完全不连通，每个点有包含在某个覆盖成员里的闭开邻域；有限多个这样的闭开集两两求差，就得到一族两两不交的闭开集盖住 SSS（这是「零维 + 紧」的标准操作）。
    • 于是只需算两两不交的覆盖 X=(Sk)k=0r\mathfrak{X} = (S_{k})_{k=0}^{r}X=(Sk​)k=0r​ 的 Čech 复形：Sk∩Sl=∅S_{k} \cap S_{l} = \emptysetSk​∩Sl​=∅（k≠lk \ne lk=l），所以所有高阶交叠都是空集，Čech 复形只在 000 次有非零项，集中在 000 次。
    • 把覆盖换成细化不改变 Čech 上同调（上一条已证沿覆盖取余极限），而每个覆盖都细化到一个「集中在 000 次」的复形，故 Hˇn(S,M)=0\check{H}^{n}(S, M) = 0Hˇn(S,M)=0（n≠0n \ne 0n=0）。再用紧 Hausdorff 上 Čech = 层上同调即得。∎

  • 本页 ⟹ Stonean 上 Ext 的截面公式推出

  • 本页 ⟹ 单纯方法算层上同调推出

    证明。 分两步。

    • 超覆盖的每一项在 Γ(X,−)\Gamma(X, -)Γ(X,−) 下零调。 FnF_{n}Fn​ 是可表层的直和，而 Γ(X,hU)=Hom⁡(X,U)\Gamma(X, h_{U}) = \operatorname{Hom}(X, U)Γ(X,hU​)=Hom(X,U) 直接可算；

    ∎
