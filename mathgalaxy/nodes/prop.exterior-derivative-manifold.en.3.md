# Exterior Derivative on Manifolds　`prop.exterior-derivative-manifold`
English entry · root `../`
[in graph](../#n=prop.exterior-derivative-manifold)　·　[Chinese page (authoritative)](./prop.exterior-derivative-manifold.md)

1. on functions $\mathrm{d}f$ is the differential of $f$: $\mathrm{d}f_{p}(v) = v(f)$ for $v\in T_{p}M$;
2. $\mathrm{d}$ is $\mathbb{R}$-linear;
3. **anti-derivation**: for a $k$-form $\omega$, $\mathrm{d}(\omega\wedge\tau) = \mathrm{d}\omega\wedge\tau + (-1)^{k}\omega\wedge\mathrm{d}\tau$;
4. $\mathrm{d}^{2} = 0$.

Moreover, in any chart $(U,x)$ it equals the coordinate formula

$$\mathrm{d}\Bigl(\sum_{I}a_{I}\,\mathrm{d}x^{I}\Bigr) = \sum_{I}\mathrm{d}a_{I}\wedge\mathrm{d}x^{I},$$
