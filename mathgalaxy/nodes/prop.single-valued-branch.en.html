Statement

A single-valued branch of FFF is a continuous function f:D→Cf : D \to \mathbb{C}f:D→C such that f(z)∈F(z)f(z) \in F(z)f(z)∈F(z) for all z∈Dz \in Dz∈D; if FFF comes from analytic continuation, the branch is automatically holomorphic.

For the logarithm (F(z)={ w:ew=z }F(z) = \{\, w : e^{w} = z \,\}F(z)={w:ew=z}) the following three conditions are equivalent:

Hypotheses used in each direction (the branch criterion requires the region to avoid the origin; simple connectedness is only sufficient):

  • single-valued branch   ⟺  \iff⟺ continuous choice of a value at each point: this is a definitional unfolding; the equivalence of the three logarithmic conditions requires D⊂C∖{0}D\subset\mathbb C\setminus\{0\}D⊂C∖{0}, otherwise 1/z1/z1/z is undefined.

  • (3)   ⟹  \implies⟹ (2): use path connectedness of the region and vanishing of closed-loop integrals to make the path integral independent of the path, then differentiate using holomorphy of the integrand.
