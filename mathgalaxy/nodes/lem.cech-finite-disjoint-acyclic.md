# 有限不交覆盖的 Čech 零调　`lem.cech-finite-disjoint-acyclic`
引理：紧 Hausdorff 空间上有限不交覆盖的 Čech 高次为零
layer 18 · 引理 · 凝聚态上同调 · 凝聚态数学
[在星图里打开](../#n=lem.cech-finite-disjoint-acyclic)　·　[节点索引](../index.md)

设 $M$ 是凝聚态阿贝尔群，$S$ 是紧 Hausdorff 空间，且

$$S = \bigsqcup_{i=1}^{r} S_{i}$$

是一个**有限不交覆盖**（$S_{i}$ 两两不交、并为 $S$）。则

$$\check{H}^{n}(S, M) = 0 \qquad (n > 0).$$
