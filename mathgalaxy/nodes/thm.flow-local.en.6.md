# existence of a local flow　`thm.flow-local`
English entry · root `../`
[in graph](../#n=thm.flow-local)　·　[Chinese page (authoritative)](./thm.flow-local.md)

**The cost**: this map does not prove Picard–Lindelöf (a theorem from ODE courses); it only performs the reduction "turn a flow on a manifold into an autonomous system on $\mathbb{R}^{n}$". A similar trade-off appears in `prop.geodesic-existence` (existence and uniqueness of geodesics are treated the same way).

⚠ Uniqueness means "uniqueness as **the same curve**": reparametrizing gives a reparametrization of the same curve, not a second solution. $\varphi_{t}(q)$ already fixes the parameter as "the time of the flow", so there is no ambiguity here.
