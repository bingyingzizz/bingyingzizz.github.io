# Tensor Product of Modules　`def.tensor-module`
English entry · root `../`
[in graph](../#n=def.tensor-module)　·　[Chinese page (authoritative)](./def.tensor-module.md)

**Elements are not pure tensors**: a general element is a finite sum, so "whether $\sum m_{i} \otimes n_{i}$ is zero" cannot be checked term by term. A pure tensor can still be zero: $\mathbb{Z}/2 \otimes_{\mathbb{Z}} \mathbb{Z}/3 = 0$, because

$$1 \otimes 1 = (3 \cdot 1) \otimes 1 = 1 \otimes (3 \cdot 1) = 1 \otimes 0 = 0 .$$

⭐ **The construction is basis-free**: the universal property says that every object converting bilinear maps into linear ones is isomorphic to it, so another construction (for example a free module followed by a quotient) gives the same thing.
