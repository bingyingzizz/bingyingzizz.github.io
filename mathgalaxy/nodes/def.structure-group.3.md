## 陈述（续）
**同一根纤维、不同的结构群**：$F = \mathbb{R}^{k}$ 时，取 $G = \mathrm{GL}(k)$ 得到一般向量丛；取 $G = \mathrm{O}(k)$ 得到「带纤维度量的丛」（由 `prop.bundle-metric`，每个丛都能这样约化）；取 $G = \mathrm{SL}(k)$ 得到「带体积形式的丛」；取 $G = \mathrm{GL}(k,\mathbb{C}) \subset \mathrm{GL}(2k,\mathbb{R
})$ 得到复丛。
