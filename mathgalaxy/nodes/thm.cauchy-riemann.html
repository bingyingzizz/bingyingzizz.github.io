陈述

白话：f=u+ivf = u + ivf=u+iv 复可微，当且仅当它实可微、且两个偏导满足一对很具体的方程 —— 「二维的极限条件」被两个一维方程完全替代。

设 Ω\OmegaΩ 是平面区域，f=u+iv:Ω→Cf = u + iv: \Omega \to \mathbb{C}f=u+iv:Ω→C，z0∈Ωz_0 \in \Omegaz0​∈Ω。以下三条等价：

(i) fff 在 z0z_0z0​ 复可微；

(ii) fff 在 z0z_0z0​ 实可微，且

∂u∂x=∂v∂y,∂u∂y=−∂v∂x;\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \qquad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x};∂x∂u​=∂y∂v​,∂y∂u​=−∂x∂v​;

(iii) fff 在 z0z_0z0​ 实可微，且 ∂f∂zˉ(z0)=0\dfrac{\partial f}{\partial \bar z}(z_0) = 0∂zˉ∂f​(z0​)=0。

三者成立时 f′(z0)=∂f∂z(z0)=∂u∂x(z0)+i ∂v∂x(z0)f'(z_0) = \dfrac{\partial f}{\partial z}(z_0) = \dfrac{\partial u}{\partial x}(z_0) + i\,\dfrac{\partial v}{\partial x}(z_0)f′(z0​)=∂z∂f​(z0​)=∂x∂u​(z0​)+i∂x∂v​(z0​)。

说明

⭐ 三条其实是一条。Δz\Delta zΔz 与 Δz‾\overline{\Delta z}Δz 是 C\mathbb{C}C 作为实向量空间的一组基，增量中只许出现 Δz\Delta zΔz 才可能是「乘一个复数」；而 Δz\Delta zΔz 的系数正是 ux+ivxu_x + i v_xux​+ivx​。CR 方程就是把「Δz‾\overline{\Delta z}Δz 的系数为 000」写成分量形式。

⭐ 一个有用的副产品：fff 在 z0z_0z0​ 的 Jacobi 行列式 =uxvy−uyvx=ux2+vx2=∣f′(z0)∣2≥0= u_x v_y - u_y v_x = u_x^2 + v_x^2 = |f'(z_0)|^2 \ge 0=ux​vy​−uy​vx​=ux2​+vx2​=∣f′(z0​)∣2≥0。所以全纯映射在导数不为零处保向，这也是它「保角」的来源。

⚠ 单独验 CR 方程不够，还要 fff 实可微。反例：f(x+iy)=∣xy∣f(x + iy) = \sqrt{|xy|}f(x+iy)=∣xy∣​，在原点四个偏导全为 000（CR 成立），但差商沿 h=t(1+i)h = t(1+i)h=t(1+i) 趋于 1/(1+i)≠01/(1+i) \ne 01/(1+i)=0，故不复可微。这同时说明「偏导存在」远弱于「实可微」。

📌 于是全纯性有两条可操作的路：抽象地用差商（几何直觉好），或具体地验 CR（计算方便）。

  • 本页 ⟹ 保角性推出
    Cauchy–Riemann 方程   ⟹  \implies⟹ 保角性即全纯且导数非零

    (i) 全纯 + 导数非零推出保角。 设 γ1,γ2\gamma_1, \gamma_2γ1​,γ2​ 是过 z0z_0z0​ 的两条光滑曲线，切向量 γ1′(0),γ2′(0)\gamma_1'(0), \gamma_2'(0)γ1′​(0),γ2′​(0) 都非零。由复可微，

    (f∘γj)′(0)=f′(z0) γj′(0).(f \circ \gamma_j)'(0) = f'(z_0)\,\gamma_j'(0).(f∘γj​)′(0)=f′(z0​)γj′​(0).

    两式相除（f′(z0)≠0f'(z_0) \ne 0f′(z0​)=0）：

    (f∘γ1)′(0)(f∘γ2)′(0)=γ1′(0)γ2′(0).\frac{(f \circ \gamma_1)'(0)}{(f \circ \gamma_2)'(0)} = \frac{\gamma_1'(0)}{\gamma_2'(0)}.(f∘γ2​)′(0)(f∘γ1​)′(0)​=γ2′​(0)γ1′​(0)​.

    (iii) 反例。 f(z)=z2f(z) = z^2f(z)=z2 在 000 处：f′(0)=0f'(0) = 0f′(0)=0，取过 000 的两条射线 arg⁡z=0\arg z = 0argz=0 与 arg⁡z=π/4\arg z = \pi/4argz=π/4，像的辐角变成 000 与 π/2\pi/2π/2 —— 夹角从 π/4\pi/4π/4 变成 π/2\pi/2π/2，加倍。f(z)=zˉf(z) = \bar zf(z)=zˉ 保角但把定向翻过来（∂f/∂zˉ=1≠0\partial f/\partial \bar z = 1 \ne 0∂f/∂zˉ=1=0），所以不在「保向」含义的保角范围内。■\blacksquare■

  • 本页 ⟹ Cauchy–Green 恒等式推出
    拆实部虚部 + Green 公式   ⟹  \implies⟹ Cauchy–Green 恒等式

    第一步：拆成两条实线积分。 f=u+ivf = u + ivf=u+iv，dz=dx+i dy\mathrm{d}z = \mathrm{d}x + i\,\mathrm{d}ydz=dx+idy，于是

    ∫∂Ωf dz=∫∂Ω(u dx−v dy)+i∫∂Ω(v dx+u dy).\int_{\partial\Omega} f\,\mathrm{d}z = \int_{\partial\Omega}(u\,\mathrm{d}x - v\,\mathrm{d}y) + i\int_{\partial\Omega}(v\,\mathrm{d}x + u\,\mathrm{d}y).∫∂Ω​fdz=∫∂Ω​(udx−vdy)+i∫∂Ω​(vdx+udy).

    第二步：两条都套 Green 公式 ∮∂Ω(P dx+Q dy)=∬Ω(Qx−Py) dxdy\oint_{\partial\Omega}(P\,\mathrm{d}x + Q\,\mathrm{d}y) = \iint_\Omega (Q_x - P_y)\,\mathrm{d}x\mathrm{d}y∮∂Ω​(Pdx+Qdy)=∬Ω​(Qx​−Py​)dxdy（∂Ω\partial\Omega∂Ω 取正向）。

  • 本页 ⟹ Cauchy–Goursat 积分定理推出
    Cauchy–Green 恒等式   ⟹  \implies⟹ Cauchy 定理（导数连续的情形）

    已得的部分。 由 Cauchy–Green 恒等式，只要 fff 在 Ω‾\overline{\Omega}Ω 上 C1C^1C1 且全纯，就有 ∮∂Ωf=2i∬fzˉ=0\oint_{\partial\Omega} f = 2i\iint f_{\bar z} = 0∮∂Ω​f=2i∬fzˉ​=0。对简单闭曲线围成的区域，这就是 Cauchy 定理。

    推广到一般闭曲线。 若 γ\gammaγ 是分段光滑闭曲线、fff 在 γ\gammaγ 内部及 γ\gammaγ 上 C1C^1C1 且全纯，则 γ\gammaγ 围成的区域可以剖分成有限个简单闭曲线围成的区域（加辅助割线），逐个用上面的结论，割线上的积分两两抵消，仍得 ∮γf=0\oint_\gamma f = 0∮γ​f=0。

    推广到多连通。 把 γ0\gamma_0γ0​ 与内圈 γ1,⋯ ,γn\gamma_1, \cdots, \gamma_nγ1​,⋯,γn​ 用 nnn 条割线连起来，得到一条闭曲线的边界；在它上面积分为 000。每条割线被走两次、方向相反，抵消后正是 ∮γ0f−∑k∮γkf=0\oint_{\gamma_0} f - \sum_k \oint_{\gamma_k} f = 0∮γ0​​f−∑k​∮γk​​f=0。

    这一步到此为止的地方。 上面每一句都用了「f∈C1f \in C^1f∈C1」，因为 Green 公式要求 P,QP, QP,Q 在闭包上连续可微。全纯不蕴含 f′f'f′ 连续（此刻还不知道），所以这条路线只证出了「额外假设 f′f'f′ 连续」的版本。去掉这个假设要另起一条路 —— 见 Goursat 三角形引理那条边。■\blacksquare■

    全纯的定义 + 复偏导数   ⟹  \implies⟹ Cauchy–Riemann 方程
