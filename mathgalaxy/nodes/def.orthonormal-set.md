# 正交基　`def.orthonormal-set`
标准正交集、完备性与正交基
layer 11 · 定义 · Hilbert 空间 · 泛函分析
[在星图里打开](../#n=def.orthonormal-set)　·　[节点索引](../index.md)

设 $\{f_i\}_{i \in I} \subseteq H$。

- **正交**：$f_i \perp f_j$（$i \ne j$）；
- **标准正交**：正交 + $\|f_i\| = 1$；
- **完备**：$\overline{\operatorname{span}\{f_i\}} = H$；
- **正交基**：标准正交 + 完备。
