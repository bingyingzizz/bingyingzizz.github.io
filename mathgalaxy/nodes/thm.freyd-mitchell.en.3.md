# Freyd–Mitchell Embedding Theorem　`thm.freyd-mitchell`
English entry · root `../`
[in graph](../#n=thm.freyd-mitchell)　·　[Chinese page (authoritative)](./thm.freyd-mitchell.md)

⚠️ But it is **not** the usual tool for proving the snake lemma or the five lemma — those are big theorems whose standard proofs first build exactness tools inside an abelian category; using this to prove them is overkill. Those two have elementary universal-property / generalized-element proofs (see their nodes).

**Why smallness is required**: the proof has to **make** the objects of $\mathcal{C}$ into modules, using precisely the colimit construction over "the set of all $\hom$"; if the category is not small these "sets" do not exist and the construction fails.
