陈述

对 x>0x > 0x>0 定义

π(x):=∑p≤x1,θ(x):=∑p≤xlog⁡p,ψ(x):=∑pk≤xlog⁡p.\pi(x) := \sum_{p \le x} 1, \qquad \theta(x) := \sum_{p \le x} \log p, \qquad \psi(x) := \sum_{p^{k} \le x} \log p .π(x):=p≤x∑​1,θ(x):=p≤x∑​logp,ψ(x):=pk≤x∑​logp.

π\piπ 数素数个数，θ\thetaθ 按对数加权，ψ\psiψ（Чебышёв 函数）把所有素数幂一起数。

说明

为什么要有三个：π\piπ 是最想知道的，但它对求导/求和极不友好；ψ\psiψ 最好用 ——

ψ(x)=∑n≤xΛ(n),Λ(n)={log⁡p,n=pk,0,否则\psi(x) = \sum_{n \le x} \Lambda(n), \qquad \Lambda(n) = \begin{cases}\log p, & n = p^{k},\\ 0, & \text{否则}\end{cases}ψ(x)=n≤x∑​Λ(n),Λ(n)={logp,0,​n=pk,否则​

三者的关系是 θ≤ψ≤θ+O(xlog⁡x)\theta \le \psi \le \theta + O(\sqrt{x}\log x)θ≤ψ≤θ+O(x​logx) 与 π(x)∼θ(x)/log⁡x\pi(x) \sim \theta(x)/\log xπ(x)∼θ(x)/logx —— 所以「三者同阶」这句话本身就是定理。
