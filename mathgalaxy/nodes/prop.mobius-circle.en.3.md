# Möbius transformations preserve circles　`prop.mobius-circle`
English entry · root `../`
[in graph](../#n=prop.mobius-circle)　·　[Chinese page (authoritative)](./prop.mobius-circle.md)

More concretely: $T$ is a composite of three translations/rotations/dilations and $z \mapsto 1/z$; the first three obviously preserve circles, and $1/z$ sends the circle $|z - a| = r$ to a circle (compute that $w = 1/z$ satisfies $|1/w - a| = r$, which rearranges to an equation of the form $|w - \bar a/\sigma|^{2} = r^{2}/\sigma^{2}$, still a circle).

∎

⭐ **"A line counts as a circle" is not wordplay**: on the extended plane a line is a circle through $\infty$, and after unification the theorem is a single sentence — half the code and half the proof.
