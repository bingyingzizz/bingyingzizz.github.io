设 S⊆RS \subseteq \mathbb{R}S⊆R，x∈Rx \in \mathbb{R}x∈R。称 xxx 是 SSS 的聚点（也叫极限点），当且仅当 xxx 的每个去心邻域都与 SSS 相交：

∀ε>0, ∃s∈S: 0<∣s−x∣<ε\forall \varepsilon > 0,\ \exists s \in S :\ 0 < |s - x| < \varepsilon∀ε>0, ∃s∈S: 0<∣s−x∣<ε

等价的序列说法：存在 S∖{x}S \setminus \{x\}S∖{x} 中的数列 sn→xs_n \to xsn​→x。

把 SSS 换成一个数列的项集，就得到「xxx 是 {xn}\{x_n\}{xn​} 的聚点」=「{xn}\{x_n\}{xn​} 有子列收敛到 xxx」。

说明

⭐ 「有界数列必有聚点」就是 Bolzano–Weierstrass 定理 —— 它是实数完备性的六副面孔之一。

⚠ 聚点不必属于 SSS：全体有理数构成的集合 Q\mathbb{Q}Q 的聚点集是整个 R\mathbb{R}R（这正是 Q\mathbb{Q}Q 不完备的样子）。

⚠ 别与上确界混：sup⁡S\sup SsupS 面向「SSS 的上界」，聚点面向「SSS 的点任意接近谁」；sup⁡{1,1/2,1/3,…}=1\sup\{1, 1/2, 1/3, \ldots\} = 1sup{1,1/2,1/3,…}=1 同时也是那个集合唯一的聚点，而 sup⁡{1}=1\sup\{1\} = 1sup{1}=1 却不是聚点。
