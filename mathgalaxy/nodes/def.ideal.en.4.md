# ideal　`def.ideal`
English entry · root `../`
[in graph](../#n=def.ideal)　·　[Chinese page (authoritative)](./def.ideal.md)

The **principal ideal** $(a) := \{\, xa : x \in A \,\}$ (in a commutative ring, the set of all multiples of $a$). ⚠️ In a general ring this set is only a **left** ideal: for $A = M_2(\mathbb{R})$ and $a = E_{11}$, $E_{11}E_{12} = E_{12} \notin Aa$. In a general ring the correct definition of $(a)$ is "the smallest two-sided ideal containing $a$". $A/(a)$ is the ring obtained by "setting $a$ equal to $0$"; $\mathbb{Z}/(n) = \mathbb{Z}/n\mathbb{Z}$ is congruence modulo $n$.
