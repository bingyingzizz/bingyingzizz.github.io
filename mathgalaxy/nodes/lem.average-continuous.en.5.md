# the averaging operator is jointly continuous　`lem.average-continuous`
English entry · root `../`
[in graph](../#n=lem.average-continuous)　·　[Chinese page (authoritative)](./lem.average-continuous.md)

- If $|y - x_0| > r_0$, choose $\varepsilon = |y - x_0| - r_0 > 0$. For the same small perturbations, $|y - x| > r_0 + \varepsilon/2 > r$, hence $\chi_{B(x,r)}(y) = 0 = \chi_{B(x_0,r_0)}(y)$.

Thus $\chi_{B(x_k,r_k)} \to \chi_{B(x_0,r_0)}$ holds for almost every $y$.
