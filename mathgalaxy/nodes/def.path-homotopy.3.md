## English abstract · **draft** · machine-drafted, pending author review; Chinese is authoritative（续）
A path in $X$ is a continuous map $\alpha:[0,1]\to X$, with $\alpha(0)$ its start and $\alpha(1)$ its end. Two paths with the same endpoints $x_{0},x_{1}$ are path homotopic when some continuous $F:[0,1]\times[0,1]\to X$ interpolates between them while both endpoints stay fixed, written $\alpha\simeq_{p}\beta$. Fixing the endpoints is essential: $[0,1]$ is contractible, so without that condition every path would be homotopic to every other and nothing would be distinguished. Path homotopy classes are the elements that the fundamental group turns into a group.
