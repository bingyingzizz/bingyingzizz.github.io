# totally disconnected space　`def.totally-disconnected`
English entry · root `../`
[in graph](../#n=def.totally-disconnected)　·　[Chinese page (authoritative)](./def.totally-disconnected.md)

⭐ **In the compact Hausdorff world the three line up in a chain**: extremally disconnected $\implies$ totally disconnected; totally disconnected + compact Hausdorff $\iff$ **profinite**; extremally disconnected + compact Hausdorff $\implies$ **Stonean**.

**Examples**: the Cantor set $2^{\mathbb{N}}$ is totally disconnected but not extremally disconnected; $\beta\mathbb{N}$ (the Stone–Čech compactification of $\mathbb{N}$) is extremally disconnected; $\beta\mathbb{N} \setminus \mathbb{N}$ is an extreme example of it.
