又称可分扩张·不可分扩张

陈述

代数扩张 K/FK/FK/F 叫可分（separable），如果每个 α∈K\alpha \in Kα∈K 的极小多项式 mαm_{\alpha}mα​ 在 KKK 上没有重根（等价地：mαm_{\alpha}mα​ 与它的形式导数 mα′m_{\alpha}'mα′​ 互素）。

特征 0 的域上，一切代数扩张都自动可分。

说明

⭐ 为什么 char 0 自动可分：不可约的 mmm 若与 m′m'm′ 有公共因子，则因 deg⁡m′<deg⁡m\deg m' < \deg mdegm′<degm 只能 m′=0m' = 0m′=0；而 char 0 时 m′=0m' = 0m′=0 只可能是常多项式，与 mmm 不可约矛盾。char ppp 时才有真麻烦：xp−tx^{p} - txp−t 在 Fp(t)\mathbb{F}_{p}(t)Fp​(t) 上不可约，但 xp−t=(x−tp)px^{p} - t = (x - \sqrt[p]{t})^{p}xp−t=(x−pt​)p（在分裂域里）—— 一个根，重数 ppp。这叫不可分扩张。

⭐ 伽罗瓦理论为什么需要可分：伽罗瓦对应要数「自同构的个数」，而自同构只能把根送到不同的根。有重根时根的数量不够，∣Gal⁡∣|\operatorname{Gal}|∣Gal∣ 就掉到 [K:F][K:F][K:F] 以下，对应关系失效。

⚠ 所以标准教材的「伽罗瓦扩张」定义是有限 + 正规 + 可分三件套；char 0 下第三条自动满足，于是常被悄悄省掉 —— 那是在 char 0 的前提下省，不是普遍成立。
