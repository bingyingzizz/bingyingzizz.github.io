又称最小二乘

陈述

在做什么：Ax=bAx = bAx=b 可能无解（bbb 不在列空间里）。那就退一步：找一个 xxx 让 AxAxAx 离 bbb 最近 —— 这就是最小二乘。

设 A∈Mm×n(R)A \in M_{m\times n}(\mathbb{R})A∈Mm×n​(R) 列满秩、b∈Rmb \in \mathbb{R}^{m}b∈Rm。最小二乘解是使

∥Ax−b∥2\lVert Ax - b\rVert_{2}∥Ax−b∥2​

取最小的 xxx。它由法方程（normal equation）唯一确定：

ATA x=ATb.A^{T}A\, x = A^{T} b .ATAx=ATb.

由于列满秩时 ATAA^{T}AATA 正定（可逆），解为 x=(ATA)−1ATbx = (A^{T}A)^{-1}A^{T}bx=(ATA)−1ATb。

几何意义：Ax∗Ax^{}Ax∗ 是 bbb 在 AAA 的列空间上的正交投影，残差 b−Ax∗b - Ax^{}b−Ax∗ 与列空间正交。

说明

法方程就是「残差与列空间正交」：(b−Ax)⊥col⁡(A)(b - Ax) \perp \operatorname{col}(A)(b−Ax)⊥col(A)   ⟺  \iff⟺ AT(b−Ax)=0A^{T}(b - Ax) = 0AT(b−Ax)=0   ⟺  \iff⟺ ATAx=ATbA^{T}Ax = A^{T}bATAx=ATb。所以它不是一个技巧，而是投影的定义（正交投影）。

⭐ 它是正交投影的具体算法：把「往子空间投影」写成矩阵，就是 P=A(ATA)−1ATP = A(A^{T}A)^{-1}A^{T}P=A(ATA)−1AT。这个 PPP 幂等且对称（幂等 的注里说的「正交幂等」），正是那个投影算子。

⚠️ 不要真的去求 ATAA^{T}AATA 的逆（数学上对、数值上有害：条件数被平方）。实际用 QR 或 SVD：x=R−1QTbx = R^{-1}Q^{T}bx=R−1QTb（QR 分解 的注）。本图只记数学结论，不展开算法。

⚠️ 列不满秩时最小二乘解不唯一（有无穷多，都给出同样的残差），这时要用伪逆取「范数最小」的那一个（伪逆）。

推出 1

  • 本页 ⟹ 伪逆推出
    列满秩时最小二乘算子就是伪逆

    最小二乘解是 x=(ATA)−1ATbx = (A^{T}A)^{-1}A^{T}bx=(ATA)−1ATb，右端是 bbb 的线性函数，记它对应的矩阵为 ALS+:=(ATA)−1ATA^{+}_{LS} := (A^{T}A)^{-1}A^{T}ALS+​:=(ATA)−1AT。

    逐条验证 Penrose 四式（AAA 列满秩）：AALS+=A(ATA)−1ATA A^{+}_{LS} = A(A^{T}A)^{-1}A^{T}AALS+​=A(ATA)−1AT 是对称幂等（到列空间的正交投影）；ALS+A=IA^{+}_{LS}A = IALS+​A=I；于是 AA+A=AAA^{+}A = AAA+A=A、A+AA+=A+A^{+}AA^{+} = A^{+}A+AA+=A+ 与两条对称性都成立。伪逆的唯一性   ⟹  \implies⟹ A+=(ATA)−1ATA^{+} = (A^{T}A)^{-1}A^{T}A+=(ATA)−1AT。

    ⭐ 所以伪逆在列满秩时就是最小二乘算子：x=A+bx = A^{+}bx=A+b。

    ⚠ 这是刻画，不是构造：伪逆的一般定义（Penrose 四式 / SVD 构造）对任意矩阵成立，而这条边只覆盖列满秩这一情形；奇异与欠定情形（此时 AA+AA^{+}AA+ 投影到列空间、A+A^{+}A+ 仍唯一）要另作处理，本图由 SVD 那条边（dep.pinv-svd）覆盖。

  • QR 分解 ⟹ 本页推出
    A=QRA = QRA=QR   ⟹  \implies⟹ 最小二乘解法方程化成一个上三角方程

    设 A=QRA = QRA=QR（QTQ=InQ^{T}Q = I_{n}QTQ=In​、RRR 上三角且对角元为正，列满秩时唯一）。由 QTQ=IQ^{T}Q = IQTQ=I 得 ATA=RTRA^{T}A = R^{T}RATA=RTR、ATb=RTQTbA^{T}b = R^{T}Q^{T}bATb=RTQTb，于是法方程 ATA x=ATbA^{T}A\,x = A^{T}bATAx=ATb 变成

    RTR x=RTQTb    ⟺    Rx=QTb,R^{T}R\,x = R^{T}Q^{T}b \;\iff\; Rx = Q^{T}b,RTRx=RTQTb⟺Rx=QTb,

    （RRR 可逆   ⟹  \implies⟹ RTR^{T}RT 可逆），即解一个上三角方程，回代是 O(n2)O(n^{2})O(n2)。

    ⭐ 这条边说明：QR 不是「另一个算法」，它把最小二乘归约成回代 —— 而且顺带给出 x=R−1QTbx = R^{-1}Q^{T}bx=R−1QTb，与 (ATA)−1ATb(A^{T}A)^{-1}A^{T}b(ATA)−1ATb 逐字相等。

    ⚠ 反过来解不出来：RRR 可逆这一条依赖列满秩，QR 的存在性并不蕴含「最小二乘解唯一」。所以这只是单向的归约，不是等价。
