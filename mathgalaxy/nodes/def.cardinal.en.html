Statement

Equipotence partitions all sets into classes. The cardinality #A\#A#A of a set AAA is the equipotence class of AAA — it measures how large AAA is, without regard to what the elements of AAA are.

Compare two cardinals:

  • #A≤#B\#A \le \#B#A≤#B: there is an injection A→BA \to BA→B;
  • #A=#B\#A = \#B#A=#B: there is a bijection A→BA \to BA→B (equipotence);
  • #A<#B\#A < \#B#A<#B: #A≤#B\#A \le \#B#A≤#B but #A≠#B\#A \ne \#B#A=#B.

If #A≤#B\#A \le \#B#A≤#B and #B≤#A\#B \le \#A#B≤#A, then #A=#B\#A = \#B#A=#B (the Schröder–Bernstein theorem).

⭐ Notation: #N=ℵ0\#\mathbb{N} = \aleph_0#N=ℵ0​ (countably infinite), #R=2ℵ0\#\mathbb{R} = 2^{\aleph_0}#R=2ℵ0​, and ℵ0<2ℵ0\aleph_0 < 2^{\aleph_0}ℵ0​<2ℵ0​.

⚠ Strictly speaking, equipotence classes are not sets; the standard ZFC approach is to take ordinals first and then, using the well-ordering theorem (  ⟺  \iff⟺ AC), choose the least ordinal in each equipotence class as its representative. That ordinal is called the cardinal.

Only two facts are needed — #A≤#B\#A \le \#B#A≤#B via injections and #A=#B\#A = \#B#A=#B via bijections — and both work without choosing representatives.

⚠ Two arbitrary cardinals are not necessarily comparable; this is exactly the content of the cardinal comparability theorem (which uses AC).
