# 素数定理　`thm.prime-number-theorem`
$\pi(x) \sim x/\log x$
layer 13 · 定理 · 数论函数与素数分布 · 数论
[在星图里打开](../#n=thm.prime-number-theorem)　·　[节点索引](../index.md)

$$\lim_{x \to \infty} \frac{\pi(x)}{x / \log x} = 1 .$$

等价形式：$\theta(x) \sim x$、$\psi(x) \sim x$、$p_{n} \sim n\log n$（$p_{n}$ 是第 $n$ 个素数）。
