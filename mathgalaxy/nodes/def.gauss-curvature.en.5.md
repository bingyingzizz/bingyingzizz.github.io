# Gaussian Curvature　`def.gauss-curvature`
English entry · root `../`
[in graph](../#n=def.gauss-curvature)　·　[Chinese page (authoritative)](./def.gauss-curvature.md)

- Intrinsic: $R$ involves only $g$ and its first and second derivatives ($\Gamma$ contains first derivatives, $R$ contains $\partial\Gamma$), so knowing $I$ is enough to compute $K$;
- Extrinsic: $K = k_{1}k_{2} = \det(h_{ij})$, using the two principal curvatures.

Both routes give the same number — this is the content of the **Theorema Egregium**.

⚠️ $K$ is a quantity **at a point**, with no direct size relation to "the curvature of a curve": on a surface with $K = 1$ there can be curves of curvature $0$ (geodesics), and on a cylinder with $K = 0$ there can be curves of nonzero curvature.
