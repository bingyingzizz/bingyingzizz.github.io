设 ppp 是素数。则单位群 Fp×=(Z/pZ)×\mathbb{F}_{p}^{\times} = (\mathbb{Z}/p\mathbb{Z})^{\times}Fp×​=(Z/pZ)× 是 p−1p-1p−1 阶循环群；它的生成元叫模 ppp 的原根，共有 φ(p−1)\varphi(p-1)φ(p−1) 个。

说明

证明：关键是计数。对每个 d∣p−1d \mid p-1d∣p−1，设 ψ(d)\psi(d)ψ(d) 为 Fp×\mathbb{F}_{p}^{\times}Fp×​ 中阶恰为 ddd 的元素个数。由「阶整除 φ(p)=p−1\varphi(p) = p-1φ(p)=p−1」（thm.order-divides-phi）与「xd=1x^{d} = 1xd=1 至多有 ddd 个解」得

∑d∣p−1ψ(d)=p−1=∑d∣p−1φ(d).\sum_{d \mid p-1}\psi(d) = p - 1 = \sum_{d \mid p-1}\varphi(d) .d∣p−1∑​ψ(d)=p−1=d∣p−1∑​φ(d).

再证 ψ(d)≤φ(d)\psi(d) \le \varphi(d)ψ(d)≤φ(d)：若存在阶为 ddd 的元素 ggg，则阶为 ddd 的元素恰是 gtg^{t}gt（gcd⁡(t,d)=1\gcd(t,d) = 1gcd(t,d)=1），共 φ(d)\varphi(d)φ(d) 个；若不存在，则 ψ(d)=0\psi(d) = 0ψ(d)=0。两种情形都有 ψ(d)≤φ(d)\psi(d) \le \varphi(d)ψ(d)≤φ(d)，而总和相等，故每项都相等 —— 特别地 ψ(p−1)=φ(p−1)>0\psi(p-1) = \varphi(p-1) > 0ψ(p−1)=φ(p−1)>0。

所以原根存在，且个数是 φ(p−1)\varphi(p-1)φ(p−1)。这条证明只用到「多项式根的个数」与「∑d∣nφ(d)=n\sum_{d\mid n}\varphi(d) = n∑d∣n​φ(d)=n」两件事。
