## Notes · **draft**
⚠️ **The name is a historical misunderstanding**: "bounded" here does **not** mean "the function is bounded": a linear map bounded as a function $\iff$ it is the zero map (the zero map satisfies this for any $E \ne 0$). The real meaning is "sends bounded sets to bounded sets", which is equivalent to **continuity** (next entry). Do not be misled by the name when reading old books.

⚠️ The three sups are equal only when $E \ne 0$ (otherwise the sphere is empty and the sup is meaningless).
