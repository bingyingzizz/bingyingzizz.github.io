# L^p 是 Banach 空间　`thm.lp-banach`
定理（Riesz–Fischer）：$1 \le p < \infty$ 时 $L^p$ 完备
layer 21 · 定理 · L^p 空间 · 分析学
[在星图里打开](../#n=thm.lp-banach)　·　[节点索引](../index.md)

设 $1 \le p < \infty$。则 $L^p(X, \mathcal{M}, \mu)$ 关于范数 $\|\cdot\|_p$ 是**完备**的，即它是一个 **Banach 空间**。
