# criterion for a single-valued branch　`prop.single-valued-branch`
English entry · root `../`
[in graph](../#n=prop.single-valued-branch)　·　[Chinese page (authoritative)](./prop.single-valued-branch.md)

⭐ **Condition 3 is exactly "all winding numbers vanish"** (see `prop.winding-integral`): $\oint_{\gamma}\mathrm{d}z/z = 2\pi i\, n(\gamma, 0)$. So "does the logarithm have a single-valued branch" is translated into a statement about whether curves **wind around the origin** — in a simply connected region no closed curve can wind around an outside point, so it holds automatically.
