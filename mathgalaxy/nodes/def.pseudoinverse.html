又称伪逆

陈述

在做什么：奇异矩阵、长方矩阵都没有逆，但仍然有「最好用的那个替代品」。伪逆 A+A^{+}A+ 是唯一满足四条 Penrose 条件的矩阵。

AA+A=A,A+AA+=A+,A A^{+} A = A, \qquad A^{+} A A^{+} = A^{+} ,AA+A=A,A+AA+=A+,(AA+)∗=AA+,(A+A)∗=A+A.(AA^{+})^{*} = AA^{+}, \qquad (A^{+}A)^{*} = A^{+}A .(AA+)∗=AA+,(A+A)∗=A+A.

由 SVD 构造：若 A=UΣV∗A = U\Sigma V^{*}A=UΣV∗（奇异值分解），则

A+=VΣ+U∗,A^{+} = V\Sigma^{+}U^{*} ,A+=VΣ+U∗,

其中 Σ+\Sigma^{+}Σ+ 是把 Σ\SigmaΣ 的非零对角元取倒数、再转置。

当 AAA 可逆时 A+=A−1A^{+} = A^{-1}A+=A−1；若 AAA 列满秩，则 A+=(A∗A)−1A∗A^{+} = (A^{}A)^{-1}A^{}A+=(A∗A)−1A∗（最小二乘解 x=A+bx = A^{+}bx=A+b）。

说明

四条条件的含义：前两条说 AA+AA^{+}AA+ 与 A+AA^{+}AA+A 是幂等（投影，幂等），后两条说这两个投影自伴（正交投影）。所以 A+A^{+}A+ 干的事是：把 bbb 正交投影到列空间、再在核的方向上取零 —— 也就是「唯一的最小范数最小二乘解」。

⭐ 它是「解不唯一时挑一个」的规范办法：Ax=bAx = bAx=b 相容但解无穷多时，A+bA^{+}bA+b 给出其中范数最小的那个；Ax=bAx = bAx=b 不相容时，A+bA^{+}bA+b 给出残差最小的那个。所以它同时接管了「最小范数解」与「最小二乘解」两件事。

⚠️ 伪逆不满足 (AB)+=B+A+(AB)^{+} = B^{+}A^{+}(AB)+=B+A+（一般不成立，只有特殊情形才对）。这与逆矩阵的 (AB)−1=B−1A−1(AB)^{-1} = B^{-1}A^{-1}(AB)−1=B−1A−1 形成鲜明对照 —— 是本概念最容易记错的地方。

⚠️ 记号：A+A^{+}A+ 与 A†A^{\dagger}A† 都在用（后者在物理里常见）。本图用 A+A^{+}A+，以免与共轭转置 A∗A^{*}A∗ 混淆。

  • 最小二乘 ⟹ 本页推出
    列满秩时最小二乘算子就是伪逆

    最小二乘解是 x=(ATA)−1ATbx = (A^{T}A)^{-1}A^{T}bx=(ATA)−1ATb，右端是 bbb 的线性函数，记它对应的矩阵为 ALS+:=(ATA)−1ATA^{+}_{LS} := (A^{T}A)^{-1}A^{T}ALS+​:=(ATA)−1AT。

    逐条验证 Penrose 四式（AAA 列满秩）：AALS+=A(ATA)−1ATA A^{+}_{LS} = A(A^{T}A)^{-1}A^{T}AALS+​=A(ATA)−1AT 是对称幂等（到列空间的正交投影）；ALS+A=IA^{+}_{LS}A = IALS+​A=I；于是 AA+A=AAA^{+}A = AAA+A=A、A+AA+=A+A^{+}AA^{+} = A^{+}A+AA+=A+ 与两条对称性都成立。伪逆的唯一性   ⟹  \implies⟹ A+=(ATA)−1ATA^{+} = (A^{T}A)^{-1}A^{T}A+=(ATA)−1AT。

    ⭐ 所以伪逆在列满秩时就是最小二乘算子：x=A+bx = A^{+}bx=A+b。

    ⚠ 这是刻画，不是构造：伪逆的一般定义（Penrose 四式 / SVD 构造）对任意矩阵成立，而这条边只覆盖列满秩这一情形；奇异与欠定情形（此时 AA+AA^{+}AA+ 投影到列空间、A+A^{+}A+ 仍唯一）要另作处理，本图由 SVD 那条边（dep.pinv-svd）覆盖。
