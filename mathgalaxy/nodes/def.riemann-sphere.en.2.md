# Riemann sphere　`def.riemann-sphere`
English entry · root `../`
[in graph](../#n=def.riemann-sphere)　·　[Chinese page (authoritative)](./def.riemann-sphere.md)

**Stereographic projection** identifies the unit sphere $S^{2} \subset \mathbb{R}^{3}$ with $\widehat{\mathbb{C}}$: from the north pole $N = (0,0,1)$, project every point of the sphere except $N$ onto the equatorial plane $w = 0$. For $z = u + iv$,

$$(x, y, w) = \left(\frac{2u}{1 + |z|^{2}},\ \frac{2v}{1 + |z|^{2}},\ \frac{|z|^{2} - 1}{1 + |z|^{2}}\right).$$

Conversely $z = \dfrac{x + iy}{1 - w}$. The pole $N$ corresponds to $\infty$.
