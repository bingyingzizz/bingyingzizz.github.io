# Zeroth de Rham Cohomology　`thm.de-rham-h0`
English entry · root `../`
[in graph](../#n=thm.de-rham-h0)　·　[Chinese page (authoritative)](./thm.de-rham-h0.md)

In particular, $M$ is connected if and only if $\dim H^{0}_{\mathrm{dR}}(M) = 1$ (for $M \ne \emptyset$).

A $0$-form is just a smooth function; $\mathrm{d}f = 0$ is equivalent to $f$ being constant on each connected chart; and $B^{0} = 0$, so $H^{0} = Z^{0}$ with no quotient to take.

## Notes · **draft**
**Why $\mathbb{R}^{c}$ and not $\mathbb{Z}^{c}$**: the coefficients are real, $H^{0}$ is a real vector space, and a basis is given by the indicator functions of the connected components. So "$H^{0}$ counts components" counts **dimension**, not the number of elements.
