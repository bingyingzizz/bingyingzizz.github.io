陈述

设 AAA 是整环，a,b∈Aa, b \in Aa,b∈A 非零。

  • aaa 与 bbb 相伴（记 a∼ba \sim ba∼b），若 a=uba = uba=ub 对某个可逆元 uuu 成立。
  • 非零非单位的 ppp 叫不可约，若 p=abp = abp=ab 迫使 aaa 或 bbb 可逆（即 ppp 不能拆成两个非单位的乘积）。
  • 非零非单位的 ppp 叫素，若 p∣abp \mid abp∣ab   ⟹  \implies⟹ p∣ap \mid ap∣a 或 p∣bp \mid bp∣b。

说明

在整环里素   ⟹  \implies⟹ 不可约：若 p=abp = abp=ab 且 ppp 是素元，则 p∣ap \mid ap∣a 或 p∣bp \mid bp∣b，设 p∣ap \mid ap∣a、a=pca = pca=pc，则 pcb=ppcb = ppcb=p，约掉 ppp 得 cb=1cb = 1cb=1，故 bbb 可逆。

反之不然：Z[−5]\mathbb{Z}[\sqrt{-5}]Z[−5​] 里 222 不可约（范数论证：N(2)=4N(2) = 4N(2)=4，而 N(a+b−5)=a2+5b2N(a + b\sqrt{-5}) = a^{2} + 5b^{2}N(a+b−5​)=a2+5b2 取不到 222），但 2∣6=(1+−5)(1−−5)2 \mid 6 = (1+\sqrt{-5})(1-\sqrt{-5})2∣6=(1+−5​)(1−−5​) 而不整除任一因子 —— 所以 222 是「不可约而非素」。

「不可约 = 素」正是唯一分解整环的判别特征（见 def.ufd）：UFD 里两者重合，非 UFD 里必有分歧。
