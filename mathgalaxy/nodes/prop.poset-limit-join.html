偏序集里的极限是交

偏序集里：极限 = 下确界，余极限 = 上确界

又称偏序集的极限·极限就是交·Exercise 1.30

陈述

把偏序集 (P,⪯)(P, \preceq)(P,⪯) 看作范畴（对象是元素，x→y  ⟺  x⪯yx \to y \iff x \preceq yx→y⟺x⪯y）。则对任何图 D:I→PD : I \to PD:I→P：

lim⁡D=inf⁡D  (下确界),lim→⁡D=sup⁡D  (上确界),\lim D = \inf D \;(\text{下确界}), \qquad \varinjlim D = \sup D \;(\text{上确界}),limD=infD(下确界),lim​D=supD(上确界),

只要它们存在。

说明

证明。 把偏序集看成范畴时，Hom⁡(x,y)\operatorname{Hom}(x,y)Hom(x,y) 至多一个元素，「锥」c→Dc \to Dc→D 就退化成「c⪯D(i)c \preceq D(i)c⪯D(i) 对一切 iii」，即 ccc 是 DDD 的一个下界 ✓。

  • 泛锥 = 下界中最大的那一个 = inf⁡D\inf DinfD；「lim⁡D\lim DlimD 存在」正好就是「inf⁡D\inf DinfD 存在」✓。
  • 对偶地（把 ⪯\preceq⪯ 反向），余锥 = 上界，泛余锥 = 最小上界 = sup⁡D\sup DsupD ✓。
  • 特例：单点图 inf⁡=sup⁡=\inf = \sup = inf=sup= 该元素；空图给出终对象（最大元）与始对象（最小元）；两元素图给出积 inf⁡{x,y}\inf\{x,y\}inf{x,y} 与余积 sup⁡{x,y}\sup\{x,y\}sup{x,y}；拉回、推出分别是下确界、上确界（因为相容条件自动满足）；而等化子：f,gf, gf,g 若平行则 f=gf = gf=g（Hom 至多一个元素），此时等化子就是恒等 ✓。

因此完备格 === 有所有小极限的偏序集；有界格 ↔\leftrightarrow↔ 有有限极限与有限余极限 ✓。∎

⭐ 这条把整套范畴语言翻译成序语言，也是最好的入门例子：

  • 积 = 下确界 inf⁡{x,y}\inf\{x, y\}inf{x,y}；余积 = 上确界 sup⁡{x,y}\sup\{x, y\}sup{x,y}；
  • 终对象 = 最大元；始对象 = 最小元；
  • 拉回（纤维积）= 两个元素的下确界；推出 = 上确界；
  • 等化子：因为 Hom 至多一个元素，平行的 f,gf, gf,g 只有「相等」或「不平行」两种，所以等化子平凡。

由此立刻得到：完备格 = 有所有小极限与小余极限的偏序集；Q\mathbb{Q}Q 作为偏序集不完备（{q:q2<2}\{q : q^{2} < 2\}{q:q2<2} 没有上确界）—— 这与实数完备性那条是同一件事的两种说法。
