陈述

XXX 中的一条道路是连续映射 α:[0,1]→X\alpha : [0, 1] \to Xα:[0,1]→X；α(0)\alpha(0)α(0) 是起点，α(1)\alpha(1)α(1) 是终点。 起点与终点都是 x0x_{0}x0​ 的道路叫闭道路（也叫以 x0x_{0}x0​ 为基点的环路）。

设 α,β\alpha, \betaα,β 是有相同起点 x0x_{0}x0​、相同终点 x1x_{1}x1​ 的两条道路。称它们道路同伦， 如果存在连续 F:[0,1]×[0,1]→XF : [0, 1] \times [0, 1] \to XF:[0,1]×[0,1]→X 使

F(t,0)=α(t),F(t,1)=β(t),F(t, 0) = \alpha(t),\qquad F(t, 1) = \beta(t),F(t,0)=α(t),F(t,1)=β(t),F(0,s)=x0,F(1,s)=x1,F(0, s) = x_{0},\qquad F(1, s) = x_{1},F(0,s)=x0​,F(1,s)=x1​,

记 α≃pβ\alpha \simeq_{p} \betaα≃p​β。也就是 α≃β  (rel⁡{0,1})\alpha \simeq \beta \; (\operatorname{rel} \{0, 1\})α≃β(rel{0,1})。

α\alphaα 的道路同伦类记作 [α][\alpha][α]，即 { β:β≃pα }\{\, \beta : \beta \simeq_{p} \alpha \,\}{β:β≃p​α}。 闭道路的道路同伦类也叫同伦类（基于 x0x_{0}x0​）。

说明

为什么必须钉死端点：[0,1][0, 1][0,1] 是凸的、可缩的，所以任何两条道路都同伦（把 α\alphaα 沿直线缩到点再拉成 β\betaβ）。不钉端点的同伦把所有道路糊成一类，什么也分辨不出来；钉死端点之后才剩下「绕法」这个信息。

⚠️ 道路同伦只对有共同端点的道路有意义——否则 F(0,s)F(0, s)F(0,s) 与 F(1,s)F(1, s)F(1,s) 的条件本身写不出来。

同伦类是等价类：由 def.homotopy-maps 里说的三条性质，限制到「端点不动」的同伦上也照样成立。所以固定 x0,x1x_{0}, x_{1}x0​,x1​ 后，从 x0x_{0}x0​ 到 x1x_{1}x1​ 的道路被切成若干同伦类。

💡 直观：同伦类 = 「从 x0x_{0}x0​ 走到 x1x_{1}x1​ 的不同走法」，两走过去可以互相连续变形则算同一种。

Abstract draft

A path in XXX is a continuous map α:[0,1]→X\alpha:[0,1]\to Xα:[0,1]→X, with α(0)\alpha(0)α(0) its start and α(1)\alpha(1)α(1) its end. Two paths with the same endpoints x0,x1x_{0},x_{1}x0​,x1​ are path homotopic when some continuous F:[0,1]×[0,1]→XF:[0,1]\times[0,1]\to XF:[0,1]×[0,1]→X interpolates between them while both endpoints stay fixed, written α≃pβ\alpha\simeq_{p}\betaα≃p​β. Fixing the endpoints is essential: [0,1][0,1][0,1] is contractible, so without that condition every path would be homotopic to every other and nothing would be distinguished. Path homotopy classes are the elements that the fundamental group turns into a group.

  • 映射 → 本页定义引用
