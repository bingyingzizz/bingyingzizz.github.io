# first isomorphism theorem　`thm.first-iso`
English entry · root `../`
[in graph](../#n=thm.first-iso)　·　[Chinese page (authoritative)](./thm.first-iso.md)

$$A \big/ \ker f \;\cong\; \operatorname{im} f.$$

⭐ **The set-level prototype**: for any map $f : A \to B$, define on $A$ the relation $a \sim a' \iff f(a) = f(a')$; then $f$ induces a **bijection** $A/{\sim} \;\to\; \operatorname{im} f$ (see "quotient set and equivalence classes").

The group version adds just one sentence: **after quotienting by the kernel, what remains is a group**.

The first two steps (well defined, bijection) are the set-level content; only the third (homomorphism) is new.
