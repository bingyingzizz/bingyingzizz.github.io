# Paracompact Hausdorff Spaces Are Normal　`thm.paracompact-hausdorff-normal`
English entry · root `../`
[in graph](../#n=thm.paracompact-hausdorff-normal)　·　[Chinese page (authoritative)](./thm.paracompact-hausdorff-normal.md)

Take a locally finite open refinement $\mathcal{C}$ and set $W := \bigcup \{\, C \in \mathcal{C} : C \cap F \ne \emptyset \,\}$.

Then $F \subseteq W$. A point of $F$, say $y$, lies in some $C$. The case $C \subseteq X \setminus F$ is impossible because it contains $y$. Hence $C \subseteq G_{y}$, so $C$ is included in $W$.

On the other hand, each member included in $W$, say $C$, lies in some $G_{y}$, so $x \notin \overline{C}$.
