说明

⭐ 与实可微的唯一区别：hhh 是复数。实情形只要左右两个方向一致，复情形要求无穷多个方向（h=teiθh = t e^{i\theta}h=teiθ，θ\thetaθ 任意）全部一致 —— 要求极强，收益也极大：一次可微就无穷次可微。

⚠ 这个要求不是自动的。f(z)=zˉf(z) = \bar zf(z)=zˉ 处处不复可微：沿实轴取 h=th = th=t 得差商 111，沿虚轴取 h=ith = ith=it 得差商 −1-1−1。两个方向的极限不同。所以「实可微」远不足以推出「复可微」。

⭐ 复可微的等价写法是 Δf=A Δz+o(Δz)\Delta f = A\,\Delta z + o(\Delta z)Δf=AΔz+o(Δz) —— 增量只是 Δz\Delta zΔz 的线性函数，不许出现 Δz‾\overline{\Delta z}Δz。写成偏导的语言就是 ∂f/∂zˉ=0\partial f/\partial \bar z = 0∂f/∂zˉ=0（见 Cauchy–Riemann 方程那条）。

📌 全纯函数的和、积、商（分母不为零）、复合仍全纯，且求导公式与实情形形式相同 —— 因为这些只是「极限的四则运算」，没有用到 hhh 的实性。
