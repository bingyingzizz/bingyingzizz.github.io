# induced homomorphism　`prop.induced-homomorphism`
English entry · root `../`
[in graph](../#n=prop.induced-homomorphism)　·　[Chinese page (authoritative)](./prop.induced-homomorphism.md)

1. **Well defined**: $\alpha \simeq_{p} \beta \implies f \circ \alpha \simeq_{p} f \circ \beta$;
2. **Homomorphism**: $f_{*}([\alpha][\beta]) = f_{*}([\alpha])\,f_{*}([\beta])$;
3. **Functoriality**: $(1_{X})_{*} = \operatorname{id}$, and $(g \circ f)_{*} = g_{*} \circ f_{*}$;
4. **Homotopy invariance**: if $f \simeq g \; (\operatorname{rel} \{x_{0}\})$, then $f_{*} = g_{*}$.

Therefore $\pi_{1}$ is a **functor** from "based topological spaces" to "groups".
