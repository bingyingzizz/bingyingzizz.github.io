Statement

In plain words: a holomorphic function is not only infinitely differentiable, but each derivative can be written by the same boundary integral — one only raises the power in the denominator by one.

The setting is the same as for the Cauchy integral formula (fff holomorphic on an open set containing Ω‾\overline{\Omega}Ω, with ∂Ω\partial\Omega∂Ω a piecewise smooth simple closed curve, positively oriented). Then for n=0,1,2,⋯n = 0, 1, 2, \cdotsn=0,1,2,⋯ and z∈Ωz \in \Omegaz∈Ω,
