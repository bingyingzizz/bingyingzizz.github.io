# Generator　`def.generator`
English entry · root `../`
[in graph](../#n=def.generator)　·　[Chinese page (authoritative)](./def.generator.md)

is **faithful**. Equivalently: whenever $f \ne g : X \to Y$, there exist $a \in S$ and $g_{0} : a \to X$ with $f \circ g_{0} \ne g \circ g_{0}$. When $S = \{G\}$, one calls $G$ a **generator**.

## Notes · **draft**
Intuition: **the objects in $S$ "see" the difference between all morphisms** — for any two distinct morphisms there is always an arrow from $S$ that separates them.

Examples: $\mathbf{1}$ is a generator of $\mathbf{Set}$; $A$ is a generator of $A\text{-}\mathbf{Mod}$; $\mathcal{C}$ itself is a set of generators of the presheaf category $\widehat{\mathcal{C}}$.
