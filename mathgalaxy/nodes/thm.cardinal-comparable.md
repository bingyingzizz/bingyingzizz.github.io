# 基数可比定理　`thm.cardinal-comparable`
基数可比定理（需要选择公理）
layer 10 · 定理 · 基数与等势 · 集合论
[在星图里打开](../#n=thm.cardinal-comparable)　·　[节点索引](../index.md)

在**选择公理**下：对任意两个集合 $A$、$B$，必有 $|A| \le |B|$ 或 $|B| \le |A|$。

即任意两个基数都可以比较大小。
