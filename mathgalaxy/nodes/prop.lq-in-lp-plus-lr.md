# L^q 落在 L^p + L^r 里　`prop.lq-in-lp-plus-lr`
命题：$L^q \subseteq L^p + L^r$（$0 < p < q < r \le \infty$）
layer 26 · 命题 · L^p 空间 · 实变函数+数学分析
[在星图里打开](../#n=prop.lq-in-lp-plus-lr)　·　[节点索引](../index.md)

设 $0 < p < q < r \le \infty$。则

$$L^q \subseteq L^p + L^r$$

（右边理解为 $\{ g + h : g \in L^p,\ h \in L^r \}$。）

## 为什么成立（入边，证明在 proofs/）
- …另有入边，续页见 [nodes/prop.lq-in-lp-plus-lr.2.md](./prop.lq-in-lp-plus-lr.2.md)

refs: Folland, Real Analysis, Prop. 6.4

## 说明
⭐ 这条说的是：**中间的 $L^q$ 可以被两端的 $L^p$ 与 $L^r$ 分担** —— 「大的部分」交给小的指数管，「小的部分」交给大的指数管。
