# L^q 落在 L^p + L^r 里　`prop.lq-in-lp-plus-lr`
命题：$L^q \subseteq L^p + L^r$（$0 < p < q < r \le \infty$）
layer 18 · 命题 · L^p 空间 · 分析学

设 $0 < p < q < r \le \infty$。则

$$L^q \subseteq L^p + L^r$$

（右边理解为 $\{ g + h : g \in L^p,\ h \in L^r \}$。）
