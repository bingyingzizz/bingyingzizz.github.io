设 RRR 是含幺环，NNN 是左 RRR-模。函子 (−)⊗RN:Mod-R→Ab(-) \otimes_{R} N : \mathbf{Mod}\text{-}R \to \mathbf{Ab}(−)⊗R​N:Mod-R→Ab 是右正合的：每个短正合列

0⟶M1→  f  M→  g  M2⟶00 \longrightarrow M_{1} \xrightarrow{\;f\;} M \xrightarrow{\;g\;} M_{2} \longrightarrow 00⟶M1​f​Mg​M2​⟶0

给出正合列

M1⊗RN→  f⊗1  M⊗RN→  g⊗1  M2⊗RN⟶0.M_{1} \otimes_{R} N \xrightarrow{\;f \otimes 1\;} M \otimes_{R} N \xrightarrow{\;g \otimes 1\;} M_{2} \otimes_{R} N \longrightarrow 0 .M1​⊗R​Nf⊗1​M⊗R​Ng⊗1​M2​⊗R​N⟶0.

进一步，下列等价：(i) (−)⊗RN(-) \otimes_{R} N(−)⊗R​N 正合；(ii) 对每个单射 M1↣MM_{1} \rightarrowtail MM1​↣M，M1⊗N→M⊗NM_{1} \otimes N \to M \otimes NM1​⊗N→M⊗N 仍单射；(iii) NNN 是平坦的。

（右端那个 →0\to 0→0 永远正合；缺的只有左端的 000。）

说明

证明（伴随路线，最快）：由 thm.hom-tensor-adjunction-mod，(−)⊗RN⊣Hom⁡R(N,−)(-) \otimes_{R} N \dashv \operatorname{Hom}_{R}(N, -)(−)⊗R​N⊣HomR​(N,−)。左伴随保所有余极限，而余核是两项图的余极限，故 (−)⊗N(-) \otimes N(−)⊗N 保余核 —— 对加法函子来说「保余核」正是「把短正合列送成 M1⊗N→M⊗N→M2⊗N→0M_{1} \otimes N \to M \otimes N \to M_{2} \otimes N \to 0M1​⊗N→M⊗N→M2​⊗N→0 正合」✓。

直接算也行：ggg 满蕴含 g⊗1g \otimes 1g⊗1 满（每个 m2⊗nm_{2} \otimes nm2​⊗n 有原像 m⊗nm \otimes nm⊗n）；核：由 ker⁡g=im⁡f\ker g = \operatorname{im} fkerg=imf，满足 g(m)=0g(m) = 0g(m)=0 的 mmm 可写 f(m1)f(m_{1})f(m1​)，于是纯张量 m⊗n=(f⊗1)(m1⊗n)m \otimes n = (f \otimes 1)(m_{1} \otimes n)m⊗n=(f⊗1)(m1​⊗n)，一般元素按双加性拆开即得 ker⁡(g⊗1)⊆im⁡(f⊗1)\ker(g \otimes 1) \subseteq \operatorname{im}(f \otimes 1)ker(g⊗1)⊆im(f⊗1)；反向由 gf=0g f = 0gf=0 ✓。

⚠️ 左端会丢：0→Z→  2  Z→Z/2→00 \to \mathbb{Z} \xrightarrow{\;2\;} \mathbb{Z} \to \mathbb{Z}/2 \to 00→Z2​Z→Z/2→0 张量 N=Z/2N = \mathbb{Z}/2N=Z/2 之后，Z⊗Z/2→  2  Z⊗Z/2\mathbb{Z} \otimes \mathbb{Z}/2 \xrightarrow{\;2\;} \mathbb{Z} \otimes \mathbb{Z}/2Z⊗Z/22​Z⊗Z/2 是零映射，不再单射。

⭐ 于是「右正合」是白送的、左正合才是性质，而那个性质的名字就叫平坦。丢掉的左端不是凭空消失：它是 Tor⁡1R(M2,N)\operatorname{Tor}_{1}^{R}(M_{2}, N)Tor1R​(M2​,N)（见 prop.flat-equivalences）。

  • 本页 ⟹ 平坦的等价说法推出
    右正合 + 平坦的定义   ⟹  \implies⟹ 五条等价刻画

    1 与 2：右正合已由前一条给出，所以「正合」只差左端那一个单射 ✓。

    2 蕴含 3：取 MMM 的投射消解 P∙→MP_{\bullet} \to MP∙​→M。Tor⁡1R(M,N)=H1(P∙⊗N)\operatorname{Tor}_{1}^{R}(M, N) = H_{1}(P_{\bullet} \otimes N)Tor1R​(M,N)=H1​(P∙​⊗N)。若 NNN 平坦，P∙⊗NP_{\bullet} \otimes NP∙​⊗N 仍是正合列（每一项都自由、逐项张量后短正合列仍正合），故 H1=0H_{1} = 0H1​=0 ✓。

    3 蕴含 4：由 0→I→R→R/I→00 \to I \to R \to R/I \to 00→I→R→R/I→0 与 Tor⁡1R(R,N)=0\operatorname{Tor}_{1}^{R}(R, N) = 0Tor1R​(R,N)=0（RRR 自由）得长正合列

    0⟶Tor⁡1R(R/I,N)⟶I⊗N⟶N⟶⋯0 \longrightarrow \operatorname{Tor}_{1}^{R}(R/I, N) \longrightarrow I \otimes N \longrightarrow N \longrightarrow \cdots0⟶Tor1R​(R/I,N)⟶I⊗N⟶N⟶⋯

    故 Tor⁡1R(R/I,N)=0\operatorname{Tor}_{1}^{R}(R/I, N) = 0Tor1R​(R/I,N)=0 推出 I⊗N→NI \otimes N \to NI⊗N→N 单 ✓。

    4 蕴含 2：先化到 MMM 有限生成（(−)⊗N(-) \otimes N(−)⊗N 保滤过余极限，而单射在滤过余极限下封闭），再对生成元个数归纳，每一步把「子模含入」拆成「理想含入 + 短正合列」，用蛇引理拼回去 —— 完整论证见 thm.lambek ✓。

    5 只是把 1、2 换成有限表现模的说法（Rn→MR^{n} \to MRn→M 有限生成自由），等价性是显然的 ✓。∎

    第 4 条是唯一能真正动手算的判据：理想比子模少，乘法映射 I⊗N→NI \otimes N \to NI⊗N→N 又常能显式写出。

谁指向它（入边）

推出 1

  • 张量与内同态的伴随 ⟹ 本页推出
    左伴随保余极限   ⟹  \implies⟹ 张量右正合

    由伴随 (−)⊗RN⊣Hom⁡R(N,−)(-) \otimes_{R} N \dashv \operatorname{Hom}_{R}(N, -)(−)⊗R​N⊣HomR​(N,−)，左伴随保所有余极限。

    而余核是两项图的余极限：coker⁡(f)=colim(M1→fM)\operatorname{coker}(f) = \mathrm{colim}\bigl(M_{1} \xrightarrow{f} M\bigr)coker(f)=colim(M1​f​M)。故 (−)⊗N(-) \otimes N(−)⊗N 保余核 ✓。

    对一个加法函子，「保余核」与「把短正合列送成 M1⊗N→M⊗N→M2⊗N→0M_{1} \otimes N \to M \otimes N \to M_{2} \otimes N \to 0M1​⊗N→M⊗N→M2​⊗N→0 正合」是同一句话：ggg 满   ⟺  \iff⟺ coker⁡g=0\operatorname{coker} g = 0cokerg=0   ⟺  \iff⟺ coker⁡(g⊗1)=0\operatorname{coker}(g \otimes 1) = 0coker(g⊗1)=0   ⟺  \iff⟺ g⊗1g \otimes 1g⊗1 满；im⁡(f⊗1)=ker⁡(g⊗1)\operatorname{im}(f \otimes 1) = \ker(g \otimes 1)im(f⊗1)=ker(g⊗1) 由保余核直接给出 ✓。

    左端为什么没有：f⊗1f \otimes 1f⊗1 的单射性不能由伴随得到（左伴随保的是余极限，不是极限）。Z→2Z\mathbb{Z} \xrightarrow{2} \mathbb{Z}Z2​Z 张量 Z/2\mathbb{Z}/2Z/2 就是反例：映射变成零 ✓。∎

    这条把「右正合」与「平坦」切成两半：右正合是伴随白送的，左正合才是要研究的性质。
