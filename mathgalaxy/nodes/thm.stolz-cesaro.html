陈述

设 {xn}\{x_n\}{xn​}、{yn}\{y_n\}{yn​} 是实数列，yny_nyn​ 严格单调。

  • 0/00/00/0 型：若 xn→0x_n \to 0xn​→0、yn→0y_n \to 0yn​→0，且
lim⁡n→∞xn+1−xnyn+1−yn=L,\lim_{n \to \infty} \frac{x_{n+1} - x_n}{y_{n+1} - y_n} = L,n→∞lim​yn+1​−yn​xn+1​−xn​​=L,

则 xnyn→L\dfrac{x_n}{y_n} \to Lyn​xn​​→L。

  • ∗/∞*/\infty∗/∞ 型：若 yny_nyn​ 严格递增且 yn→+∞y_n \to +\inftyyn​→+∞，同样条件成立时 xnyn→L\dfrac{x_n}{y_n} \to Lyn​xn​​→L。

这里 LLL 可以是有限实数，也可以是 ±∞\pm\infty±∞（按扩展实数理解）。

说明

⭐ 它是离散版的 L'Hôpital 法则：把「导数之比」换成「差分之比」。0/00/00/0 型要求分子也趋于 000；∗/∞*/\infty∗/∞ 型不要求 xnx_nxn​ 收敛。

例：xn=1+12+⋯+1nx_n = 1 + \frac12 + \cdots + \frac1nxn​=1+21​+⋯+n1​、yn=log⁡ny_n = \log nyn​=logn。则 Δxn=1n+1\Delta x_n = \frac{1}{n+1}Δxn​=n+11​、Δyn=log⁡n+1n∼1n\Delta y_n = \log\frac{n+1}{n} \sim \frac1nΔyn​=lognn+1​∼n1​，差分之比 →1\to 1→1，故 Hn/log⁡n→1H_n/\log n \to 1Hn​/logn→1。

⚠ 单调性不能去掉：取 xn=(−1)nx_n = (-1)^nxn​=(−1)n、yn=(−1)ny_n = (-1)^nyn​=(−1)n，差分之比恒为 111，但 xn/yn=1x_n/y_n = 1xn​/yn​=1 平凡；再看 xn=(−1)nnx_n = (-1)^n\sqrt nxn​=(−1)nn​、yn=ny_n = \sqrt nyn​=n​，xn/ynx_n/y_nxn​/yn​ 不收敛。

⚠ 与 Cesàro 平均的关系：取 xnx_nxn​ 为部分和、yn=ny_n = nyn​=n，Stolz 就退化成「算术平均」那一条（见 Cesàro 平均收敛）。
