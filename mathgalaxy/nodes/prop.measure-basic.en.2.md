# basic properties of measures　`prop.measure-basic`
English entry · root `../`
[in graph](../#n=prop.measure-basic)　·　[Chinese page (authoritative)](./prop.measure-basic.md)

- **(a) Monotone**: $E \subseteq F \implies \mu(E) \le \mu(F)$
- **(b) Subadditive**: $\mu( \bigcup_j E_j ) \le \sum_j \mu(E_j)$ (disjointness not required)
- **(c) Continuous from below**: $E_1 \subseteq E_2 \subseteq \cdots \implies \mu( \bigcup_j E_j ) = \lim_{j\to\infty} \mu(E_j)$
- **(d) Continuous from above**: $\mu(E_1) < \infty, \quad  E_1 \supseteq E_2 \supseteq \cdots \implies \mu( \bigcap_j E_j ) = \lim_{j\to\infty} \mu(E_j)$
