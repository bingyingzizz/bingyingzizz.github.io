# resolution　`def.resolution`
English entry · root `../`
[in graph](../#n=def.resolution)　·　[Chinese page (authoritative)](./def.resolution.md)

Reversing the arrows (that is, taking the same definition with values in $\mathcal{A}^{\mathrm{op}}$) gives **left resolutions**; if every $L^{n}$ is a **projective** object it is called a **projective resolution**.

## Notes · **draft**
**Why "resolve".** Derived functors must be computed with **computable** complexes: on injective objects every additive functor has vanishing higher derived functors, so to compute $R^{n}F$ from an injective resolution one only needs to apply $F$ and then take homology — that is the whole point of a "resolution" ✓.
