# genus　`def.genus`
English entry · root `../`
[in graph](../#n=def.genus)　·　[Chinese page (authoritative)](./def.genus.md)

⭐ **Why not define it by the number of handles or by $\chi = 2-2g$**: Both definitions require the classification theorem first (every closed orientable surface is a connected sum of tori), and the classification theorem itself uses $g$, which would make the reasoning circular. The homological definition is **independent of classification**, so it is the only choice at this stage that avoids circularity.
