# 初等变换与初等矩阵　`def.elementary-matrix`
初等变换与初等矩阵

**初等行变换**指下列三种操作：

- 把第 $i$ 行与第 $j$ 行**互换**；
- 把第 $i$ 行乘以非零常数 $c$；
- 把第 $j$ 行的 $c$ 倍**加到**第 $i$ 行上。

对单位矩阵 $I_n$ 做一次上述操作得到的矩阵叫**初等矩阵**（记 $E$）。关键性质是：**对 $A$ 做一次初等行变换，等于在左边乘上相应的初等矩阵**，即把 $A$ 换成 $EA$。
