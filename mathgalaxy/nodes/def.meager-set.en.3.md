# meager and residual sets　`def.meager-set`
English entry · root `../`
[in graph](../#n=def.meager-set)　·　[Chinese page (authoritative)](./def.meager-set.md)

⭐ Usage: to say "almost every point satisfies $P$", prove that $\{x : \neg P(x)\}$ is meager. In infinite dimension this is often handier than measure theory (many function spaces have no natural measure but do have a Baire category).
