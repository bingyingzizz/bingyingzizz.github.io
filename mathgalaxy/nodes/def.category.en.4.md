# category　`def.category`
English entry · root `../`
[in graph](../#n=def.category)　·　[Chinese page (authoritative)](./def.category.md)

morphisms are the increasing maps from $m$ to $n$.

**The category of open sets** $\operatorname{Open}(X)$: given a topological space $(X, \tau)$, take $\mathcal{O} = \tau$,

$$M = \{ (u, v) : u \subseteq v \} \subseteq \tau \times \tau$$

that is, "from a smaller open set to an open set containing it".
