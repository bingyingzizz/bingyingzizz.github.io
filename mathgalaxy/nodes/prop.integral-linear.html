说明

⭐ 「区间可加」是 Riemann 积分最实用的一条：它把一个大区间上的问题切成两半 —— 这也是后面「反常积分」能定义的基础。

⚠ 两个可积函数的乘积也可积（振幅估计：ω(fg)≤Mω(g)+Nω(f)\omega(fg) \le M\omega(g) + N\omega(f)ω(fg)≤Mω(g)+Nω(f) 在每一段上），但商不一定，商要先保证分母不接近零。

⭐ 和与积的可积性都靠振幅判据：把 ω(f+g)≤ω(f)+ω(g)\omega(f + g) \le \omega(f) + \omega(g)ω(f+g)≤ω(f)+ω(g) 代进去即可。

  • 可积的振幅判据 ⟹ 本页推出
    振幅判据   ⟹  \implies⟹ 线性与区间可加

    振幅的次可加性：在同一区间 III 上，ω(f+g)≤ω(f)+ω(g)\omega(f + g) \le \omega(f) + \omega(g)ω(f+g)≤ω(f)+ω(g)，ω(cf)=∣c∣ ω(f)\omega(cf) = |c|\,\omega(f)ω(cf)=∣c∣ω(f)（因为 sup⁡(f+g)≤sup⁡f+sup⁡g\sup(f + g) \le \sup f + \sup gsup(f+g)≤supf+supg、inf⁡(f+g)≥inf⁡f+inf⁡g\inf(f + g) \ge \inf f + \inf ginf(f+g)≥inff+infg）。
