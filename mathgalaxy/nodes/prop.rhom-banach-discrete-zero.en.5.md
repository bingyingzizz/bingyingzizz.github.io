# Derived Hom from Finite-Dimensional Banach Spaces to Discrete Groups Vanishes　`prop.rhom-banach-discrete-zero`
English entry · root `../`
[in graph](../#n=prop.rhom-banach-discrete-zero)　·　[Chinese page (authoritative)](./prop.rhom-banach-discrete-zero.md)

⭐ **Use**: any Ext problem with a real vector space as source and a discrete group as target is immediately zero — one of the key components of the later step "locally compact abelian groups have only $\operatorname{Ext}^{0}, \operatorname{Ext}^{1}$".

**Proof.** Use the spectral sequence above (with $S$ Stonean); to show the limit vanishes it suffices to show every $E^{p,q}_{1}$ vanishes.
