# Taylor Formula in Several Variables　`thm.taylor-multi`
English entry · root `../`
[in graph](../#n=thm.taylor-multi)　·　[Chinese page (authoritative)](./thm.taylor-multi.md)

To get uniformity in all $h$, one must induct on $k$ and write the remainder as a sum over multi-indices, using the one-variable MVT once per layer (or iterating over the coordinates of $h$).
