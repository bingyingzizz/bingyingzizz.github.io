# Christoffel Symbols　`def.christoffel-symbol`
English entry · root `../`
[in graph](../#n=def.christoffel-symbol)　·　[Chinese page (authoritative)](./def.christoffel-symbol.md)

⚠️ In two dimensions there are only $2^{3} = 8$ symbols, but symmetry reduces the independent components to $6$ ($k$ fixed, $i \le j$); in flat coordinates they all vanish.

📌 Example: in polar coordinates $(r, \varphi)$, $g = \mathrm{d}r^{2} + r^{2}\mathrm{d}\varphi^{2}$, and only three symbols are non-zero: $\Gamma^{r}_{\varphi\varphi} = -r$, $\Gamma^{\varphi}_{r\varphi} = \Gamma^{\varphi}_{\varphi r} = 1/r$ (term-by-term computation in `ex.polar-christoffel`).
