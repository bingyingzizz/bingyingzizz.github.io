# Chebyshev estimate　`thm.chebyshev-estimate`
English entry · root `../`
[in graph](../#n=thm.chebyshev-estimate)　·　[Chinese page (authoritative)](./thm.chebyshev-estimate.md)

For $x \ge 16$, we have $\log x \le \sqrt{x}$, so $\sqrt{x} \le x/\log x$ and hence $\pi(x) \le (1 + 4\log 2)\,x/\log x < 6\,x/\log x$. For $2 \le x < 16$, we have $6x/\log x > 6$ and $\pi(x) \le 6$, so the conclusion holds immediately.
