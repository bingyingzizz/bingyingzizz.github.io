**Step 3. Almost-everywhere pointwise convergence.** The sphere $\partial B(x_0, r_0)$ has measure zero. Suppose $y \notin \partial B(x_0, r_0)$.

- If $|y - x_0| < r_0$, choose $\varepsilon = r_0 - |y - x_0| > 0$. When $|x - x_0| < \varepsilon/2$ and $|r - r_0| < \varepsilon/2$, we have $|y - x| \le |y - x_0| + |x - x_0| < r_0 - \varepsilon/2 < r$, hence $\chi_{B(x,r)}(y) = 1 = \chi_{B(x_0,r_0)}(y)$.
