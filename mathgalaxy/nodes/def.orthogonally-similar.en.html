def.orthogonally-similar

Machine-drafted and pending author review. The Chinese text is authoritative.

Statement

What it does: fills the cell between "similarity" and "congruence" — when a change of basis both preserves the structure (similarity) and preserves lengths (orthogonal/unitary), this is it. The spectral theorem says exactly that "a symmetric matrix is orthogonally similar to a diagonal matrix".

Let A,B∈Mn(R)A, B \in M_{n}(\mathbb{R})A,B∈Mn​(R). Call AAA and BBB orthogonally similar if there exists an orthogonal matrix QQQ such that

B=QTA Q=Q−1A Q.B = Q^{T} A\, Q = Q^{-1} A\, Q .B=QTAQ=Q−1AQ.

In the complex case replace QQQ by a unitary matrix UUU, obtaining unitary similarity B=U∗AU=U−1AUB = U^{*}AU = U^{-1}AUB=U∗AU=U−1AU.

Why this cell matters: orthogonal/unitary matrices satisfy P−1=PTP^{-1} = P^{T}P−1=PT (or P∗P^{*}P∗) at the same time, so

orthogonal similarity = similarity + congruence (the differences among the three are explained in the notes of def.orthogonally-similar)

It preserves both eigenvalues (a property of similarity) and the inner-product structure (a property of congruence) — so it is a stable similarity, with condition number 111.

Notes

⭐ Which matrices are orthogonally similar to a diagonal matrix: real symmetric matrices (thm.spectral-matrix); more generally, real normal matrices are orthogonally similar to a block diagonal matrix (1×11\times11×1 and 2×22\times22×2 blocks, because non-real eigenvalues occur in pairs).

But any matrix is unitarily similar to an upper triangular one (thm.schur-triangularization) — this is the complete answer to "how far can orthogonal similarity simplify a matrix".

⚠️ Keep the difference between the three notions firmly in mind: similarity P−1APP^{-1}APP−1AP (any invertible PPP, preserves eigenvalues); congruence PTAPP^{T}APPTAP (any invertible PPP, preserves inertia); orthogonal similarity QTAQQ^{T}AQQTAQ with Q−1=QTQ^{-1} = Q^{T}Q−1=QT (preserves both). Only in the third is "P−1P^{-1}P−1 and PTP^{T}PT the same thing".

⚠️ The entry def.similarity in this graph treats the most general similarity. Do not confuse "AAA is similar to a diagonal matrix" with "AAA is orthogonally similar to a diagonal matrix" — the former requires only enough eigenvectors, the latter requires them to be mutually perpendicular (this is normality, def.normal-matrix).
