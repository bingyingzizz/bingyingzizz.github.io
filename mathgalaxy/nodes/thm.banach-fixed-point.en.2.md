# Banach Fixed Point Theorem　`thm.banach-fixed-point`
English entry · root `../`
[in graph](../#n=thm.banach-fixed-point)　·　[Chinese page (authoritative)](./thm.banach-fixed-point.md)

- $T$ has a **unique** fixed point $x^{\ast} \in X$ (that is, $Tx^{\ast} = x^{\ast}$);
- for **every** initial value $x_0 \in X$, the iteration $x_{k+1} := T x_k$ converges to $x^{\ast}$;
- and one has the a priori and a posteriori error estimates

$$d(x_k, x^{\ast}) \le \frac{q^{k}}{1 - q}\, d(x_0, x_1), \qquad d(x_k, x^{\ast}) \le \frac{q}{1 - q}\, d(x_k, x_{k-1})$$

## Notes · **draft**
⭐ This is a rare **three-in-one** theorem in analysis: it gives existence, uniqueness, **and** an algorithm (the iteration) **with error estimates**.
