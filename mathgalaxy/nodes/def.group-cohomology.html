陈述

设 MMM 是 GGG-模。群 GGG 系数在 MMM 里的第 nnn 个上同调群是不变量函子的右导出函子：

Hn(G,M):=Rn(−)G(M),H^{n}(G, M) := R^{n}(-)^{G}(M),Hn(G,M):=Rn(−)G(M),

等价地

Hn(G,M)=Ext⁡R[G]n(R, M),H^{n}(G, M) = \operatorname{Ext}^{n}_{R[G]}\bigl(R,\ M\bigr),Hn(G,M)=ExtR[G]n​(R, M),

其中 RRR 带平凡 GGG-作用。特别地 H0(G,M)=MGH^{0}(G, M) = M^{G}H0(G,M)=MG 且 Hn(G,M)=0H^{n}(G, M) = 0Hn(G,M)=0（n<0n < 0n<0）。

说明

⭐ 一句话：H0H^{0}H0 只是「不动点」；HnH^{n}Hn（n≥1n \ge 1n≥1）量的是不变量函子断了多远，也就是 GGG 的作用有多不平凡。

两条算法：

  • 内射消解（定义本身）：取 MMM 的内射 R[G]R[G]R[G]-模消解 M↣I∙M \rightarrowtail I^{\bullet}M↣I∙，取不变量、取同调。最干净，但内射 R[G]R[G]R[G]-模看不见摸不着。
  • 标准（bar）消解（可算）：取 RRR 的自由 R[G]R[G]R[G]-模消解 B∙→RB_{\bullet} \to RB∙​→R，再取 Hom⁡R[G](B∙,M)\operatorname{Hom}_{R[G]}(B_{\bullet}, M)HomR[G]​(B∙​,M)，得到一个显式上链复形。这一条给出 HnH^{n}Hn 的具体公式，见「用标准消解计算群上同调」。

为什么等于 Ext⁡\operatorname{Ext}Ext：(−)G=Hom⁡R[G](R,−)(-)^{G} = \operatorname{Hom}_{R[G]}(R, -)(−)G=HomR[G]​(R,−)，而用 RRR 的内射消解算 RnHom⁡R[G](R,−)R^{n}\operatorname{Hom}_{R[G]}(R, -)RnHomR[G]​(R,−) 正是 Ext⁡R[G]n(R,−)\operatorname{Ext}^{n}_{R[G]}(R, -)ExtR[G]n​(R,−)。同一个右导出函子，只是换了名字。Hn=0H^{n} = 0Hn=0（n<0n < 0n<0）也正是「右导出函子」的直接后果。

两条立刻能用的：

  • 若 MMM 是 Q\mathbb{Q}Q-向量空间且 GGG 作用平凡，则 (−)G(-)^{G}(−)G 就是恒等函子（正合），于是 Hn(G,M)=0H^{n}(G, M) = 0Hn(G,M)=0（n≥1n \ge 1n≥1）。
  • 若 GGG 在 MMM 上作用平凡，则 H1(G,M)=Hom⁡(G,M)H^{1}(G, M) = \operatorname{Hom}(G, M)H1(G,M)=Hom(G,M)；一般情形要换成「交叉同态」，见后面两条。
