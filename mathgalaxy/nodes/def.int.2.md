## 陈述（续）
$$[a, b] + [c, d] := [a + c,\ b + d]$$
$$[a, b] \cdot [c, d] := [ac + bd,\ ad + bc]$$
$$[a, b] \le [c, d] :\iff a + d \le b + c$$

其中加法与序来自 $\mathbb{N}$ 的加法与序，乘法的写法是照着 $(a - b)(c - d) = ac + bd - (ad + bc)$ 抄的。
