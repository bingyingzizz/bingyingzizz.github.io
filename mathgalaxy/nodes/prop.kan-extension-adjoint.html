Kan 延拓与伴随的存在性

命题：p−1p^{-1}p−1 有左伴随   ⟺  \iff⟺ 沿 ppp 的 Kan 延拓都存在

又称Proposition 1.5.10·Prop 1.5.10

陈述

设 p:C→C′p : \mathcal{C} \to \mathcal{C}'p:C→C′ 是小范畴之间的函子，D\mathcal{D}D 是范畴。则预复合函子

p−1:Hom⁡(C′,D)⟶Hom⁡(C,D),G⟼G∘pp^{-1} : \operatorname{Hom}(\mathcal{C}', \mathcal{D}) \longrightarrow \operatorname{Hom}(\mathcal{C}, \mathcal{D}), \qquad G \longmapsto G \circ pp−1:Hom(C′,D)⟶Hom(C,D),G⟼G∘p

有左伴随 p!p_{!}p!​   ⟺  \iff⟺ 沿 ppp 的、取值在 D\mathcal{D}D 中的左 Kan 延拓总存在。

对偶地：p−1p^{-1}p−1 有右伴随 p∗p_{*}p∗​   ⟺  \iff⟺ 右 Kan 延拓总存在。

说明

证明。 两边逐字对照即可。 「p−1p^{-1}p−1 有左伴随 p!p_{!}p!​」说的是：对每个 F∈Hom⁡(C,D)F \in \operatorname{Hom}(\mathcal{C}, \mathcal{D})F∈Hom(C,D) 存在 p!F∈Hom⁡(C′,D)p_{!}F \in \operatorname{Hom}(\mathcal{C}', \mathcal{D})p!​F∈Hom(C′,D) 与自然同构

Hom⁡(p!F, G)  ≅  Hom⁡(F, p−1G)=Hom⁡(F, G∘p).\operatorname{Hom}\bigl(p_{!}F,\ G\bigr) \;\cong\; \operatorname{Hom}\bigl(F,\ p^{-1}G\bigr) = \operatorname{Hom}\bigl(F,\ G \circ p\bigr).Hom(p!​F, G)≅Hom(F, p−1G)=Hom(F, G∘p).

右边的数据正是「FFF 沿 ppp 的左 Kan 延拓」的定义（泛性质）✓：伴随的单位 ηF:F  ⟹  p!F∘p\eta_{F} : F \implies p_{!}F \circ pηF​:F⟹p!​F∘p 就是定义里的那条 α\alphaα，而同构本身给出 α\alphaα 的泛性质 ✓。 所以「每个 FFF 都有左 Kan 延拓」与「p−1p^{-1}p−1 有左伴随」是同一句话；对偶地把箭头反过来即得右 Kan 延拓那一条 ✓。∎

⭐ 读法：Kan 延拓不是新东西，它就是预复合函子的伴随。这一条把「到处都要用 Kan 延拓」与「到处都要用伴随」两套话合成了一套。

⚠️ 命题本身不保证存在，它只说「伴随」与「Kan 延拓」同生同死；存在性要另加条件（见「有余极限时 Kan 延拓总存在」）。
