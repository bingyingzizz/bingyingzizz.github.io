陈述

设 F:A→A′F : \mathcal{A} \to \mathcal{A}'F:A→A′ 是左正合加法函子。则 RFRFRF 是复合映射

K+(A)→ F K+(A′)⟶D+(A′)\mathbf{K}^{+}(\mathcal{A}) \xrightarrow{\ F\ } \mathbf{K}^{+}(\mathcal{A}') \longrightarrow \mathbf{D}^{+}(\mathcal{A}')K+(A) F ​K+(A′)⟶D+(A′)

沿局部化 K+(A)→D+(A)\mathbf{K}^{+}(\mathcal{A}) \to \mathbf{D}^{+}(\mathcal{A})K+(A)→D+(A) 的（左）Kan 延拓（对偶地：右正合函子的 LFLFLF 沿另一个局部化）。

说明

证明。 局部化（把拟同构变成同构）是预复合函子的左伴随 ✓，而左正合函子在拟同构上表现良好，于是「先取 FFF 再局部化」这个复合函子沿局部化的左 Kan 延拓存在且正是 RFRFRF ✓ —— 这就是导出函子的泛性刻画：它是 FFF 在导出范畴里的最优扩张 ✓。∎

⭐ 读法：「导出函子」不是新东西，它是局部化下的 Kan 延拓 —— 与「Kan 延拓就是伴随」配成一对。
