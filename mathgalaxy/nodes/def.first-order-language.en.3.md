# first-order logic　`def.first-order-language`
English entry · root `../`
[in graph](../#n=def.first-order-language)　·　[Chinese page (authoritative)](./def.first-order-language.md)

1. variables and constants are **terms**; if $f$ is an $n$-ary function symbol and $t_{1}, \ldots, t_{n}$ are terms, then $f(t_{1}, \ldots, t_{n})$ is a term;
2. if $R$ is an $n$-ary relation symbol and $t_{1}, \ldots, t_{n}$ are terms, then $R(t_{1}, \ldots, t_{n})$ is an **atomic formula**;
3. **formulas** are built from atomic formulas by repeated application of $\neg$, $\wedge$, $\vee$, $\to$, $\forall v_{i}$, $\exists v_{i}$.

Example: $\mathcal{L} = \{ \in \}$ (with $\in$ a binary relation symbol) is the **language of set theory** — all axioms of ZFC are written in this language.
