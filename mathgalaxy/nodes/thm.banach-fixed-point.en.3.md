# Banach Fixed Point Theorem　`thm.banach-fixed-point`
English entry · root `../`
[in graph](../#n=thm.banach-fixed-point)　·　[Chinese page (authoritative)](./thm.banach-fixed-point.md)

Most existence theorems only say "there is"; this one says "how to find it and how accurate it is".

⚠ Neither hypothesis can be dropped:
- drop **completeness**: $(0,1]$ is not complete and $T(x) = x/2$ is a contraction, but the fixed point $0$ is not in the space;

- drop $q < 1$: the map $x + 1/x$ in `def.contraction` is a counterexample.
