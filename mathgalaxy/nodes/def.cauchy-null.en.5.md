# Cauchy sequences and null sequences　`def.cauchy-null`
English entry · root `../`
[in graph](../#n=def.cauchy-null)　·　[Chinese page (authoritative)](./def.cauchy-null.md)

Two Cauchy sequences are **equivalent** (written $(x_n) \sim (y_n)$) if and only if $(x_n - y_n)$ is a null sequence.

($\sim$ is an equivalence relation: reflexivity and symmetry are immediate, transitivity follows from the triangle inequality.)

## Notes · **reviewed**
⭐ **Why divide by the null sequences**: the same real number has many approximating sequences — for instance $(1, 1, 1, \ldots)$ and $(1.1,\ 1.01,\ 1.001,\ \ldots)$ should both represent $1$, and their difference is a null sequence. Equivalence classes glue "different approximations of one and the same number" into a single object.
