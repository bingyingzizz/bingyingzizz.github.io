## 陈述（续）
$M$ 的一条投射消解的**增广**，即
$$\cdots \to P_{2} \xrightarrow{\ d_{2}\ } P
_{1} \xrightarrow{\ d_{1}\ } P_{0} \xrightar
row{\ \varepsilon\ } M \to 0$$
处处正合、每项 $P_{n}$ 投射。**删
除消解**（deleted resolution）是**去
掉增广**留下的链复形
$$P_{\bullet} : \quad \cdots \to P_{2} \xrig
htarrow{\ d_{2}\ } P_{1} \xrightarrow{\ d_{1
}\ } P_{0} \to 0 .$$
换句话说：把 $M$ 支在 $-1$ 次的那
条正合复形，删掉 $-1$ 次的那一
项，其余原样保留。
