设 p:Y→Xp : Y \to Xp:Y→X 是紧 Riemann 面之间的 ddd 次分支覆盖（分支覆盖），gX,gYg_{X}, g_{Y}gX​,gY​ 是两边的亏格（亏格），{eq}\{e_{q}\}{eq​} 是分歧指数（分歧指数）。记

R:=∑q∈Y(eq−1)R := \sum_{q \in Y} (e_{q} - 1)R:=q∈Y∑​(eq​−1)

（分歧除子的次数：按 eq−1e_q - 1eq​−1 计，不是分支点个数）。则

2gY−2=d (2gX−2)+R.2g_{Y} - 2 = d\,(2g_{X} - 2) + R .2gY​−2=d(2gX​−2)+R.

换成 Euler 示性数的写法更整齐（Euler 示性数与亏格）：

χ(Y)=d χ(X)−R.\chi(Y) = d\,\chi(X) - R .χ(Y)=dχ(X)−R.

说明

证明：核心是「把 XXX 的一个三角剖分沿 ppp 拉成 YYY 的一个有限 CW 剖分，再数 0,1,20,1,20,1,2 维胞腔」。

记号：B⊂XB \subset XB⊂X 是分支点集（有限），p−1(B)p^{-1}(B)p−1(B) 是分歧点集；对 r∈Xr \in Xr∈X 记 p−1(r)={q1,…,qmr}p^{-1}(r) = \{q_{1}, \ldots, q_{m_{r}}\}p−1(r)={q1​,…,qmr​​}，则 分歧指数 的求和恒等式给出

∑i=1mreqi=d,即mr=d−∑i(eqi−1).\sum_{i=1}^{m_{r}} e_{q_{i}} = d,\qquad\text{即}\qquad m_{r} = d - \sum_{i}(e_{q_{i}} - 1).i=1∑mr​​eqi​​=d,即mr​=d−i∑​(eqi​​−1).

特别地 r∉Br \notin Br∈/B 时 mr=dm_{r} = dmr​=d。

引理（适配三角剖分）：存在 XXX 的有限三角剖分 KKK，使 (i) BBB 中每个点都是 KKK 的顶点；(ii) 对 KKK 的每个开单纯形 σ\sigmaσ，p−1(σ)→σp^{-1}(\sigma) \to \sigmap−1(σ)→σ 是 ddd 重覆叠，且每个连通分支同胚地映到 σ\sigmaσ。

证明：对 XXX 的每点取「适配图卡」：x∉Bx \notin Bx∈/B 时取使 ppp 平凡化的图卡 UxU_{x}Ux​（p−1(Ux)≅Ux×{1,…,d}p^{-1}(U_{x}) \cong U_{x} \times \{1, \ldots, d\}p−1(Ux​)≅Ux​×{1,…,d}）；b∈Bb \in Bb∈B 时取以 bbb 为原点的图卡，使 ppp 呈 z↦zeqz \mapsto z^{e_{q}}z↦zeq​ 的形状。这些开集覆盖紧空间 XXX，取有限子覆盖。曲面论的标准事实：XXX 有有限三角剖分，且可取得从属于这个有限开覆盖、并把指定的有限点集 BBB 全部取为顶点（先给 XXX 任一三角剖分，再在 BBB 处做重心重分并把 BBB 细化成顶点，最后用 Lebesgue 数保证每个闭单纯形落在某个覆盖成员里）。于是每个开单纯形 σ\sigmaσ 落在某个适配图卡 UUU 里。若 UUU 无分支，ppp 在 UUU 上平凡，结论成立；若 UUU 是以 bbb 为原点的分歧图卡，则 σ\sigmaσ 不含 bbb（bbb 已是顶点，开单纯形不含顶点），而 U∖{b}U \setminus \{b\}U∖{b} 上的 ppp 是覆叠映射，σ\sigmaσ 单连通，故覆叠在 σ\sigmaσ 上平凡。

引理（拉回剖分与计数）：把 YYY 写成 XXX 的开单纯形的原像之并：000-胞腔 === 顶点原像，111-胞腔 === 开边的原像分支，222-胞腔 === 开面的原像分支。这是一个有限 CW 剖分，且

VY=d VX−R,EY=d EX,FY=d FX.V_{Y} = d\,V_{X} - R,\qquad E_{Y} = d\,E_{X},\qquad F_{Y} = d\,F_{X}.VY​=dVX​−R,EY​=dEX​,FY​=dFX​.

证明：111-胞腔与 222-胞腔部分由上一个引理直接给出（每个开边/开面有 ddd 个分支）。000-胞腔：对每个顶点 xxx，原像个数是 mxm_{x}mx​；对 x∉Bx \notin Bx∈/B 它是 ddd，对 x=b∈Bx = b \in Bx=b∈B 它是 d−∑q∣b(eq−1)d - \sum_{q|b}(e_{q} - 1)d−∑q∣b​(eq​−1)。求和

VY=∑x∈VXmx=d VX−∑b∈B∑q∣b(eq−1)=d VX−R,V_{Y} = \sum_{x \in V_{X}} m_{x} = d\,V_{X} - \sum_{b \in B}\sum_{q|b}(e_{q} - 1) = d\,V_{X} - R,VY​=x∈VX​∑​mx​=dVX​−b∈B∑​q∣b∑​(eq​−1)=dVX​−R,

因为只有分歧点使 eq>1e_{q} > 1eq​>1，非分歧点对 RRR 的贡献是 000，而 RRR 按定义就是全部分歧点求和。

「这是 CW 剖分」需要说明 2-胞腔的闭包是闭圆盘：在分歧点的模型 z↦zez \mapsto z^{e}z↦ze 下，eee 个扇区（2-胞腔）共享顶点 qqq，每个扇区的闭包是一个闭三角形，eee 个扇区拼成 qqq 的一个邻域圆盘；在非分歧点同理。于是每个 2-胞腔的闭包是闭圆盘，贴合映射连续，确实给出有限 CW 结构。

收尾：CW 剖分的 Euler 示性数按胞腔数计算，

χ(Y)=VY−EY+FY=d(VX−EX+FX)−R=d χ(X)−R.\chi(Y) = V_{Y} - E_{Y} + F_{Y} = d(V_{X} - E_{X} + F_{X}) - R = d\,\chi(X) - R.χ(Y)=VY​−EY​+FY​=d(VX​−EX​+FX​)−R=dχ(X)−R.

再用 Euler 示性数与亏格 把 χ(X)=2−2gX\chi(X) = 2 - 2g_{X}χ(X)=2−2gX​、χ(Y)=2−2gY\chi(Y) = 2 - 2g_{Y}χ(Y)=2−2gY​ 代入，即得 2gY−2=d(2gX−2)+R2g_{Y} - 2 = d(2g_{X} - 2) + R2gY​−2=d(2gX​−2)+R。∎

等号条件（gY=gXg_{Y} = g_{X}gY​=gX​ 到底什么时候成立）：由 2gY−2=d(2gX−2)+R2g_{Y} - 2 = d(2g_{X} - 2) + R2gY​−2=d(2gX​−2)+R，gY=gXg_{Y} = g_{X}gY​=gX​ 等价于

d (2gX−2)+R=2gX−2,即(d−1)(2gX−2)=−R.d\,(2g_{X} - 2) + R = 2g_{X} - 2,\qquad\text{即}\qquad (d - 1)(2g_{X} - 2) = -R.d(2gX​−2)+R=2gX​−2,即(d−1)(2gX​−2)=−R.

因为 d≥1d \ge 1d≥1、R≥0R \ge 0R≥0，分三种情形：

  • gX≥2g_{X} \ge 2gX​≥2：(d−1)(2gX−2)≥0(d - 1)(2g_{X} - 2) \ge 0(d−1)(2gX​−2)≥0，要等于 −R≤0-R \le 0−R≤0，只能 d=1d = 1d=1 且 R=0R = 0R=0（双全纯）。
  • gX=1g_{X} = 1gX​=1：0=−R0 = -R0=−R，故 R=0R = 0R=0；ddd 任意（环面的无分歧覆叠）。
  • gX=0g_{X} = 0gX​=0：等式变成 R=2d−2R = 2d - 2R=2d−2。d=2d = 2d=2 时 R=2R = 2R=2，例如两个 e=2e = 2e=2 的分支点；z2:P1→P1z^{2} : \mathbb{P}^{1} \to \mathbb{P}^{1}z2:P1→P1 正是这种情形（d=2d = 2d=2、两个分支点、R=2R = 2R=2），仍有 gY=gX=0g_{Y} = g_{X} = 0gY​=gX​=0。

⚠️ 不要把 RRR 和「分支点个数」混用：一个分支点 bbb 贡献的是 ∑q∣b(eq−1)=d−mb\sum_{q|b}(e_{q} - 1) = d - m_{b}∑q∣b​(eq​−1)=d−mb​，可以大于 111（例如 z3z^{3}z3 在 000 处 e=3e = 3e=3，贡献 222）。也不要把「gY=gXg_{Y} = g_{X}gY​=gX​」直接说成「d=1d = 1d=1 且无分歧」——gX=0g_{X} = 0gX​=0 的反例正是 z2z^{2}z2。
