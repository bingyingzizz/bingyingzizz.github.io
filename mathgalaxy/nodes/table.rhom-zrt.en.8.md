# Table of Derived Hom for Z, R and T　`table.rhom-zrt`
English entry · root `../`
[in graph](../#n=table.rhom-zrt)　·　[Chinese page (authoritative)](./table.rhom-zrt.md)

- First row (source $\mathbb{Z}$): $\operatorname{RHom}(\mathbb{Z}, N) = N$. A free source has no higher terms, leaving only degree zero.
- Second row, first column $0$: **Real vector space $\to$ discrete** vanishes in every degree by divisibility.
- Remaining entries of the second row: RHom between finite-dimensional real Banach spaces is concentrated in degree zero, with value $\operatorname{Hom}_{\mathbb{R}}(M, N)$. Here the spaces are $\operatorname{Hom}_{\mathbb{R}}(\mathbb{R}, \mathbb{R}) = \mathbb{R}$ and $\operatorname{Hom}_{\mathbb{R}}(\mathbb{R}, T)$.
