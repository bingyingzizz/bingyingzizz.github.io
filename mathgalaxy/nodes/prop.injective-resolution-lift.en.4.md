# Lifting Maps to Injective Resolutions　`prop.injective-resolution-lift`
English entry · root `../`
[in graph](../#n=prop.injective-resolution-lift)　·　[Chinese page (authoritative)](./prop.injective-resolution-lift.md)

To construct $F^{n+1}$ it suffices to fix its value on the **coboundary** $B^{n+1}_{I} = \operatorname{im}d^{n}_{I}$, since $B^{n+1}_{I}\hookrightarrow I^{n+1}$ is a monomorphism.

Key observation: when $n \ge 1$, $H^{n}(I^{\bullet}) = 0$, i.e. $Z^{n}_{I} = B^{n}_{I}$ — so the value of $F^{n}$ on $Z^{n}_{I}$ is already determined by the previous layer and lies in $Z^{n}_{J}$ (for $n \ge 1$ it equals $d^{n-1}_{J}F^{n-1}$; for $n = 0$ one uses instead the commutativity at the augmentation) ✓.
