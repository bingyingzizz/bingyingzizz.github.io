# Stokes' Formula on a Single Cube　`lem.single-cube-stokes`
English entry · root `../`
[in graph](../#n=lem.single-cube-stokes)　·　[Chinese page (authoritative)](./lem.single-cube-stokes.md)

Let $\eta$ be defined on an open set containing $I^{k} = [0,1]^{k}$ and be a $(k-1)$-form ($k\ge 1$). Then

$$\int_{I^{k}}\mathrm{d}\eta = \int_{\partial I^{k}}\eta ,$$

Here $I^{k}$ has the standard orientation, and $\partial I^{k}$ is interpreted according to the sign convention in `def.boundary-operator` as a $(k-1)$-chain.

When $k = 1$, this is the fundamental theorem of calculus: $\int_{0}^{1}F^{\prime}(t)\,\mathrm{d}t = F(1)-F(0)$.
