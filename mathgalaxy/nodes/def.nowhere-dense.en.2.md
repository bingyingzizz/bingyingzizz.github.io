# nowhere dense set　`def.nowhere-dense`
English entry · root `../`
[in graph](../#n=def.nowhere-dense)　·　[Chinese page (authoritative)](./def.nowhere-dense.md)

Examples: $\mathbb{Z} \subseteq \mathbb{R}$, $\{1/n\}$, the Cantor set.

⭐ The Cantor set is the most instructive example: it is **nowhere dense** yet **uncountable**. So "nowhere dense" and "small cardinality" are two different things.
