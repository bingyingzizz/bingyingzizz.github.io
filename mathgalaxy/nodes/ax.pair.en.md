## Statement · **reviewed**
Given any two sets, one may pack them into "the set whose only elements are these two":

$$\forall a \forall b \exists A \forall x [ x \in A \leftrightarrow  ( x = a \vee  x = b ) ]$$

By extensionality $A$ is unique; it is written { a, b } (the unordered pair). Taking $a = b$ gives the singleton { a }.
