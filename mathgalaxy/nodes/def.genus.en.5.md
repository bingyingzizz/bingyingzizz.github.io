# genus　`def.genus`
English entry · root `../`
[in graph](../#n=def.genus)　·　[Chinese page (authoritative)](./def.genus.md)

⚠ **This definition applies only to closed orientable surfaces**. For surfaces with boundary, use relative homology or first cap the boundary components. In the **nonorientable** case, $H_{1}$ has torsion (for the projective plane, $H_{1} \cong \mathbb{Z}/2$), and genus must be replaced by a different quantity (nonorientable genus $k$, $\chi = 2 - k$).

📌 The relation to the Euler characteristic, $\chi(M) = 2 - 2g(M)$, is also a **theorem** covered next. It is only recorded here.
