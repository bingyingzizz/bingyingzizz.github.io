# 合冲比较引理　`lem.schanuel`
合冲比较引理：两条短正合列的首项与核彼此互补

设 $M$ 是 $R$-模，另有两条短正合列

$$0 \to K \to P \xrightarrow{\ \pi\ } M \to 0, \qquad 0 \to K_{1} \to P_{1} \xrightarrow{\ \pi_{1}\ } M \to 0,$$

其中 $P, P_{1}$ 都**投射**。则

$$P_{1} \oplus K \;\cong\; P \oplus K_{1} .$$
