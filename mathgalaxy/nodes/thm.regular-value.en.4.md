# Regular Value Theorem　`thm.regular-value`
English entry · root `../`
[in graph](../#n=thm.regular-value)　·　[Chinese page (authoritative)](./thm.regular-value.md)

⚠ $c = 0$ is a critical value (the only critical point is the origin and $f(0) = 0$), yet $f^{-1}(0) = \{0\}$ happens to be a $0$-dimensional manifold — the preimage of a critical value **may** still be a manifold; the theorem simply does not guarantee it.

Deciding that a point is regular is much easier than deciding that it is critical, and that is the practical value of the theorem.

⭐ Together with `thm.sard` it gives the full picture: regular values are plentiful, their preimages are manifolds, critical values have measure zero — hence "almost every level set is a manifold".
