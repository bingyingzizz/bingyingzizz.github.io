Statement

What it does: the last rung at the top of the chain. It tightens normality by one notch using countability: every closed set is a countable intersection of open sets.

First, two notations: a set AAA is a GδG_{\delta}Gδ​ set if it is a countable intersection of open sets; it is an FσF_{\sigma}Fσ​ set if it is a countable union of closed sets.

A topological space XXX is perfectly normal if

  1. XXX is normal (正规空间);
  2. every closed set is a GδG_{\delta}Gδ​ set.

(Equivalently: every open set is an FσF_{\sigma}Fσ​ set, by taking complements.)
