又称带余除法

陈述

设 KKK 是域，f,g∈K[x]f, g \in K[x]f,g∈K[x]，g≠0g \ne 0g=0。则存在唯一的 q,r∈K[x]q, r \in K[x]q,r∈K[x] 使

f=q g+r,deg⁡r<deg⁡gf = q\,g + r, \qquad \deg r < \deg gf=qg+r,degr<degg

（rrr 叫余式，qqq 叫商；允许 r=0r = 0r=0。）

于是 K[x]K[x]K[x] 是欧几里得整环：存在「次数」这个满足 deg⁡r<deg⁡g\deg r < \deg gdegr<degg 的欧几里得函数。

说明

⭐ 「KKK 是域」这一条不可省：换成环 Z[x]\mathbb{Z}[x]Z[x] 就没有带余除法了（x2x^{2}x2 除以 2x+12x + 12x+1 商不出多项式）。它的作用是保证首项系数可逆，从而能消掉最高次项。

⭐ 这一步的后果极长：有带余除法就有辗转相除（求最大公因式）、就有 Bézout 等式（af+bg=gcd⁡af + bg = \gcdaf+bg=gcd）、就有「不可约   ⟹  \implies⟹ 素」、就推出唯一分解（thm.poly-ufd）。欧几里得整环是「什么都好」的一类环。

⚠ 唯一性用的是次数比较，不是「除法本身唯一」—— 除法过程中每步的选择都不唯一，但最终商与余式唯一。

推出 2

  • 本页 ⟹ 因式定理与根推出
    带余除法   ⟹  \implies⟹ 因式定理

    设 a∈Ka \in Ka∈K。把 fff 除以 x−ax - ax−a（首一，故带余除法适用）：

    f=q (x−a)+r,deg⁡r<1f = q\,(x - a) + r, \qquad \deg r < 1f=q(x−a)+r,degr<1

    即 r∈Kr \in Kr∈K 是常数。把 x=ax = ax=a 代入两边：f(a)=q(a)⋅0+r=rf(a) = q(a) \cdot 0 + r = rf(a)=q(a)⋅0+r=r。

    于是 f(a)=0  ⟺  r=0  ⟺  (x−a)∣ff(a) = 0 \iff r = 0 \iff (x - a) \mid ff(a)=0⟺r=0⟺(x−a)∣f。∎

    这条证明只有一行实质内容，但它给出了一个额外收获：余式就是函数值 —— 这也是多项式作为「函数」与作为「形式对象」之间的桥。

  • 本页 ⟹ K[x] 是唯一分解整环推出
    带余除法   ⟹  \implies⟹ 唯一分解

    记 R:=K[x]R := K[x]R:=K[x]，它是整环（deg⁡(fg)=deg⁡f+deg⁡g\deg(fg) = \deg f + \deg gdeg(fg)=degf+degg）。

    第一步：辗转相除与 Bézout 等式。 对 f,g≠0f, g \ne 0f,g=0 反复用带余除法（f=qg+rf = qg + rf=qg+r，deg⁡r<deg⁡g\deg r < \deg gdegr<degg），次数严格下降故必停：最后非零余式 ddd 满足 d∣fd \mid fd∣f、d∣gd \mid gd∣g，且存在 a,b∈Ra, b \in Ra,b∈R 使

    af+bg=da f + b g = daf+bg=d

    （把除法的每一步回代即得。）ddd 就是 gcd⁡(f,g)\gcd(f, g)gcd(f,g)（首一化之后唯一）。

    第二步：不可约   ⟹  \implies⟹ 素。 设 ppp 不可约、p∣fgp \mid fgp∣fg。若 p∤fp \nmid fp∤f，则 gcd⁡(p,f)=1\gcd(p, f) = 1gcd(p,f)=1，由 Bézout 有 ap+bf=1ap + bf = 1ap+bf=1；两边乘 ggg：apg+bfg=gapg + bfg = gapg+bfg=g。左端两项都被 ppp 整除（第一项显然，第二项因为 p∣fgp \mid fgp∣fg），故 p∣gp \mid gp∣g。

    第三步：存在性。 对 deg⁡f\deg fdegf 归纳：若 fff 不可约则已分解完；否则 f=ghf = ghf=gh 且 deg⁡g,deg⁡h<deg⁡f\deg g, \deg h < \deg fdegg,degh<degf，对两者归纳。

    第四步：唯一性。 设 p1⋯pr=q1⋯qsp_1 \cdots p_r = q_1 \cdots q_sp1​⋯pr​=q1​⋯qs​（都是不可约元，首一化后）。由 p1∣q1⋯qsp_1 \mid q_1 \cdots q_sp1​∣q1​⋯qs​ 与第二步，存在某个 jjj 使 p1∣qjp_1 \mid q_jp1​∣qj​；两者都不可约（从而相伴），约掉后对 r+sr + sr+s 归纳，得 r=sr = sr=s 且分解在顺序与单位之下相同。∎

    四步里只有第二步用了域的特殊性（本质上是带余除法给出的 Bézout 等式）；其余三步对任何整环都成立。这也是「欧几里得整环   ⟹  \implies⟹ UFD」这条链的标准证明。

    带余除法是 K[x]K[x]K[x] 里两个元素之间的运算，先要有这个环。

  • Euclid 整环 → 本页定义引用

    K[x]K[x]K[x] 的带余除法正是「N=deg⁡N = \degN=deg 的欧几里得函数」，这条定理是 Euclid 整环的一个实例。

类比 1

  • 整数的带余除法类比
    整数与多项式：同一个带余除法

    两边的证明结构一模一样：Z\mathbb{Z}Z 上按绝对值下降，K[x]K[x]K[x] 上按次数下降；结论都是「商 + 余，余比除数小」。

    差异只在「小」怎么量：Z\mathbb{Z}Z 是全序，K[x]K[x]K[x] 只用次数（系数任意）。这也说明为什么两者都叫 Euclid 整环 —— 有欧几里得函数就够了。

    后续也同步：Z\mathbb{Z}Z 有辗转相除就有 gcd，进而就是 UFD；K[x]K[x]K[x] 有完全相同的链条（thm.poly-ufd）。
