# Mayer–Vietoris sequence in homology　`thm.mv-homology`
English entry · root `../`
[in graph](../#n=thm.mv-homology)　·　[Chinese page (authoritative)](./thm.mv-homology.md)

**Surjectivity.** Take any cycle $z$. Since $z$ contains only finitely many simplices, choose $M$ so that each $\operatorname{Sd}^{M}(\sigma)$ is small as $\sigma$ ranges over the simplices of $z$. Then $\operatorname{Sd}^{M} z \in S^{\mathcal{U}}_{*}(X)$ and $\operatorname{Sd}^{M} z - z = \partial T_{M} z$, so $\iota_{*}[\operatorname{Sd}^{M} z] = [z]$.
