# Moving Frame　`def.moving-frame`
English entry · root `../`
[in graph](../#n=def.moving-frame)　·　[Chinese page (authoritative)](./def.moving-frame.md)

**The standard choice on a surface**: $e_{3} = n$, with $e_{1}, e_{2}$ unit tangent vector fields orthogonal to $n$. Then $\omega^{3} = \langle \mathrm{d}r, n\rangle = 0$: there is no normal increment on the surface.

⚠ $(e_{1}, e_{2})$ exists only locally and is not unique (one may rotate it). Every quantity to be written down must be expressed in a rotation-invariant form (such as $I = (\omega^{1})^{2}+(\omega^{2})^{2}$), otherwise it deforms as soon as the frame is changed.
