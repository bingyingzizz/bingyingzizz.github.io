## Notes · **draft**
⭐ This group is a set of **operational laws**: it says that "taking limits" commutes with the four arithmetic operations.

All computations in analysis rest on it.

⚠ Order preservation yields only $\le$, never $<$: for example $0 < 1/n$ holds for all $n$, yet the limit is $0 \le 0$.

**A strict inequality is smoothed away when passing to the limit**.
