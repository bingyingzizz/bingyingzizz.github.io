# Smooth Partition of Unity　`thm.smooth-partition-unity`
English entry · root `../`
[in graph](../#n=thm.smooth-partition-unity)　·　[Chinese page (authoritative)](./thm.smooth-partition-unity.md)

**Second countability is essential**: The long line is locally Euclidean and Hausdorff but is neither separable nor paracompact, so partitions of unity cannot in general be constructed on it. The technical hypotheses in the manifold definition matter.

**Continuous and smooth versions**: The continuous version only requires paracompactness (`prop.paracompact-partition-unity`). The smooth version uses bump functions to obtain smoothness. On manifolds, these are two regularity levels of the same construction.
