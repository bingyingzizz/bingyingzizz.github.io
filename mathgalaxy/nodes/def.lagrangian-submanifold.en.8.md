# Lagrangian Submanifold　`def.lagrangian-submanifold`
English entry · root `../`
[in graph](../#n=def.lagrangian-submanifold)　·　[Chinese page (authoritative)](./def.lagrangian-submanifold.md)

⚠️ **Closedness is not part of the definition**: $L$ need not be closed, compact, or embedded. It can be immersed or even multiply covered. The Bohr–Sommerfeld condition in physics uses Lagrangian submanifolds that may only be immersed.
⚠️ **The equivalence with being locally the graph associated with a function holds only when the projection $\pi:L\to Q$ (with $Q$ the zero section containing a Lagrangian subspace) is a local diffeomorphism** (exactness of $p\,\mathrm{d}q$). This is a local property, so generating functions exist only locally.
