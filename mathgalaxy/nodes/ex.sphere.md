# 球面 S²　`ex.sphere`
球面 $S^{2}$：闭曲面，亏格 0，$\chi = 2$
layer 25 · 例 · 曲面的地形 · 拓扑学
[在星图里打开](../#n=ex.sphere)　·　[节点索引](../index.md)

$$S^{2} := \{\, x \in \mathbb{R}^{3} : \lVert x \rVert = 1 \,\}$$

配子空间拓扑，是一个**闭曲面**（`def.closed-surface`）。它的亏格 $g = 0$，Euler 示性数 $\chi(S^{2}) = 2$。
