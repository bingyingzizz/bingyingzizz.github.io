# Tensor Product of Modules　`def.tensor-module`
English entry · root `../`
[in graph](../#n=def.tensor-module)　·　[Chinese page (authoritative)](./def.tensor-module.md)

$$(m + m_{1},\ n) - (m,\ n) - (m_{1},\ n), \qquad (m,\ n + n_{1}) - (m,\ n) - (m,\ n_{1}), \qquad (m r,\ n) - (m,\ r n)$$

($m, m_{1} \in M$, $n, n_{1} \in N$, $r \in R$). Define

$$M \otimes_{R} N := F / K, \qquad m \otimes n := [\,(m, n)\,].$$

Its elements are **finite sums** $\sum_{i} m_{i} \otimes n_{i}$ of pure tensors $m \otimes n$.

Thus the relations are the two additivity relations and one **balanced** relation $m r \otimes n = m \otimes r n$;

moreover, for every **balanced biadditive** map $B : M \times N \to P$ ($P$ an abelian group), there is a **unique** group homomorphism
