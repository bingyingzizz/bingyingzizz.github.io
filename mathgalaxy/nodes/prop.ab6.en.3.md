## Notes · **draft**
⚠️ **The key is "each $j$ has its own filtered category".** If all $j$ share the same $I$ (the diagonal), the assertion is **false** — then it holds only for $J$ **finite** (that is "filtered colimits commute with finite products", coming from filtered colimits being sifted colimits).
Counterexample: $I = (\mathbb{N}, \le)$, $M_{i,j} = \mathbb{Z}/p^{i}$, with transition maps "multiplication by $p$", so that $\varinjlim_{i} \mathbb{Z}/p^{i} = \mathbb{Z}[1/p]/\mathbb{Z}$.
