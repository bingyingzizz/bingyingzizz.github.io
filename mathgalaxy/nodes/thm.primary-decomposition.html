陈述

设 KKK 代数闭，T:V→VT : V \to VT:V→V，dim⁡V=n<∞\dim V = n < \inftydimV=n<∞。设

χT(x)=∏i=1r(x−λi)mi\chi_T(x) = \prod_{i=1}^{r} (x - \lambda_i)^{m_i}χT​(x)=i=1∏r​(x−λi​)mi​

（λi\lambda_iλi​ 互异、mi≥1m_i \ge 1mi​≥1）是特征多项式的分解。则

  • V=⨁i=1rViV = \bigoplus_{i=1}^{r} V_iV=⨁i=1r​Vi​，其中 Vi:=ker⁡(T−λiI)miV_i := \ker (T - \lambda_i I)^{m_i}Vi​:=ker(T−λi​I)mi​ 是广义特征子空间（也叫根子空间）；
  • dim⁡Vi=mi\dim V_i = m_idimVi​=mi​（代数重数），每个 ViV_iVi​ 都是 TTT-不变的，且 T∣ViT|_{V_i}T∣Vi​​ 只有一个特征值 λi\lambda_iλi​；
  • Eλi=ker⁡(T−λiI)⊆ViE_{\lambda_i} = \ker(T - \lambda_i I) \subseteq V_iEλi​​=ker(T−λi​I)⊆Vi​ 是它里面的「λi\lambda_iλi​ 那一层」。

说明

⭐ 这一步是 Jordan 分解的第一半：先把 VVV 按特征值拆成 rrr 块，每一块上只剩一个特征值。第二半是在每块里再把「T−λiIT - \lambda_i IT−λi​I 的幂零程度」拆成小块（那就是 Jordan 块）。

⭐ 它的代数版本：VVV 是 K[x]K[x]K[x]-模，χT\chi_TχT​ 是它上面的「零化多项式」；由 K[x]K[x]K[x] 的唯一分解，模按 χT\chi_TχT​ 的不可约因子拆开（中国剩余定理）—— 这就是「主分解」这个名字的来源。

⚠ 要求 KKK 代数闭：否则 χT\chi_TχT​ 分解不出一次因子，块也不按特征值分（要把「不可约因子」当成块）。

推出 1

  • 本页 ⟹ Jordan 标准形推出
    根子空间分解 + 幂零块   ⟹  \implies⟹ Jordan 标准形
    1. 由主分解，V=⨁iViV = \bigoplus_i V_iV=⨁i​Vi​，每个 ViV_iVi​ 是 TTT-不变的，且 T∣Vi=λiI+NiT|_{V_i} = \lambda_i I + N_iT∣Vi​​=λi​I+Ni​，其中
    Ni:=(T−λiI)∣ViN_i := (T - \lambda_i I)|_{V_i}Ni​:=(T−λi​I)∣Vi​​

    是幂零的（因为 Vi=ker⁡(T−λiI)miV_i = \ker (T - \lambda_i I)^{m_i}Vi​=ker(T−λi​I)mi​）。只要在每个 ViV_iVi​ 上把幂零算子化成标准形，拼起来就是 Jordan 形。

    1. 幂零算子的标准形：设 NNN 在有限维空间 WWW 上幂零。对 k=1,2,…k = 1, 2, \ldotsk=1,2,… 有链
    {0}⊆ker⁡N⊆ker⁡N2⊆⋯⊆ker⁡Ns=W\{0\} \subseteq \ker N \subseteq \ker N^{2} \subseteq \cdots \subseteq \ker N^{s} = W{0}⊆kerN⊆kerN2⊆⋯⊆kerNs=W

    归纳地：从最后一层 ker⁡Ns\ker N^{s}kerNs 里取一组基，映到商 ker⁡Ns/ker⁡Ns−1\ker N^{s}/\ker N^{s-1}kerNs/kerNs−1 上；在商里按同样办法取基并拉回，逐层拼出一组基，使 NNN 在其中表现为若干「上移位」块 NkN_kNk​（对角线为 000、上对角为 111）。

    1. 拼装：把每个 ViV_iVi​ 里得到的基拼成 VVV 的基。在这组基下 TTT 的矩阵：在第 iii 块上是 λiI+Ni\lambda_i I + N_iλi​I+Ni​，即若干 Jordan 块之并，各块的特征值为 λi\lambda_iλi​。

    TTT 可对角化   ⟺  \iff⟺ 每个 Ni=0N_i = 0Ni​=0   ⟺  \iff⟺ 每个 Vi=EλiV_i = E_{\lambda_i}Vi​=Eλi​​   ⟺  \iff⟺ 所有块是 1×11 \times 11×1。∎

    第 2 步（幂零算子的分层取基）是整条定理唯一的构造性部分；其余两半都是「把已知分解拼起来」。这也解释了为什么 Jordan 型的计算本质上只是「求若干核链」。

推出 1

  • K[x] 是唯一分解整环、极小多项式、根的个数不超过次数 ⟹ 本页推出
    唯一分解 + 极小多项式   ⟹  \implies⟹ 根子空间分解

    设 KKK 代数闭、χT=∏i=1r(x−λi)mi\chi_T = \prod_{i=1}^{r}(x - \lambda_i)^{m_i}χT​=∏i=1r​(x−λi​)mi​，λi\lambda_iλi​ 互异。

    1. 把 VVV 看成 K[x]K[x]K[x]-模：令 x⋅v:=T(v)x \cdot v := T(v)x⋅v:=T(v)。模的公理就是 TTT 的线性性 + T0=IT^{0} = IT0=I，逐步验证即可。于是 χT⋅V=0\chi_T \cdot V = 0χT​⋅V=0。
    2. 中国剩余定理：χT=∏i(x−λi)mi\chi_T = \prod_i (x - \lambda_i)^{m_i}χT​=∏i​(x−λi​)mi​ 中诸因子两两互素（互异一次因子的幂），故
    K[x]/(χT)  ≅  ∏iK[x]/((x−λi)mi)K[x]/(\chi_T) \;\cong\; \prod_i K[x]/((x - \lambda_i)^{m_i})K[x]/(χT​)≅i∏​K[x]/((x−λi​)mi​)
    1. 翻译回 VVV：对每个 iii 令 Vi:=ker⁡(T−λiI)miV_i := \ker (T - \lambda_i I)^{m_i}Vi​:=ker(T−λi​I)mi​。由互素性可取多项式 uiu_iui​ 使 ∑iui⋅χT(x−λi)mi=1\sum_i u_i \cdot \frac{\chi_T}{(x-\lambda_i)^{m_i}} = 1∑i​ui​⋅(x−λi​)mi​χT​​=1（Bézout），作用到 v∈Vv \in Vv∈V 上给出分解 v=∑iviv = \sum_i v_iv=∑i​vi​，vi∈Viv_i \in V_ivi​∈Vi​。直和性由「不同因子的核之交为零」得到。
    2. 维数：ViV_iVi​ 是 TTT-不变的，且 T∣ViT|_{V_i}T∣Vi​​ 只有一个特征值 λi\lambda_iλi​，故 χT∣Vi=(x−λi)dim⁡Vi\chi_{T|_{V_i}} = (x - \lambda_i)^{\dim V_i}χT∣Vi​​​=(x−λi​)dimVi​；两边取乘积并与 χT\chi_TχT​ 比较，得 dim⁡Vi=mi\dim V_i = m_idimVi​=mi​。
