prop.set-top-ab-complete · Set

Machine-drafted and pending author review. The Chinese text is authoritative.

Statement

Set\mathbf{Set}Set, Top\mathbf{Top}Top and Ab\mathbf{Ab}Ab all have all small limits and all small colimits.

The forgetful functor Top→Set\mathbf{Top} \to \mathbf{Set}Top→Set preserves all limits and all colimits; but Ab→Set\mathbf{Ab} \to \mathbf{Set}Ab→Set preserves all limits, but not coproducts.

Notes

Proof. Set\mathbf{Set}Set: small products and equalizers give all small limits ✓, disjoint unions and coequalizers give all small colimits ✓. Top\mathbf{Top}Top: the same constructions with the corresponding topologies (product topology, subspace/equalizer topology, disjoint-union topology, quotient topology) ✓. Ab\mathbf{Ab}Ab: build them using free abelian groups and quotient groups ✓.

The forgetful functor preserves limits because both topological and algebraic structure are defined "pointwise" ✓; but the underlying set of M⊕NM \oplus NM⊕N is not M⊔NM \sqcup NM⊔N, so Ab→Set\mathbf{Ab} \to \mathbf{Set}Ab→Set does not preserve coproducts ✓. ∎
