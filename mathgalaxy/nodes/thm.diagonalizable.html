又称可对角化判据

陈述

设 dim⁡V=n<∞\dim V = n < \inftydimV=n<∞，T:V→VT : V \to VT:V→V 线性，λ1,…,λm\lambda_1, \ldots, \lambda_mλ1​,…,λm​ 是它在 KKK 中互异的特征值。则下列命题等价：

(1) TTT 可对角化：存在基使 TTT 的矩阵是对角阵；

(2) V=Eλ1⊕⋯⊕EλmV = E_{\lambda_1} \oplus \cdots \oplus E_{\lambda_m}V=Eλ1​​⊕⋯⊕Eλm​​，即特征向量张成整个 VVV；

(3) ∑idim⁡Eλi=n\sum_i \dim E_{\lambda_i} = n∑i​dimEλi​​=n（几何重数之和达到 nnn）；

(4) 每个特征值的几何重数等于代数重数；

(5) 存在互异的 λi\lambda_iλi​ 使 TTT 满足 ∏i(T−λiI)=0\prod_i (T - \lambda_i I) = 0∏i​(T−λi​I)=0（即 TTT 被一个无重根的多项式零化）。

说明

⭐ 最常用的判据是 (3)/(4)：nnn 个线性无关的特征向量存在   ⟺  \iff⟺ 可对角化。注意「特征值个数 =n= n=n」不够（重根要按重数算）。

⭐ (5) 是最深刻的写法：它把「可对角化」翻译成极小多项式无重根（见「极小多项式整除特征多项式」）—— 这一条在谱定理与 Jordan 型的讨论里都要用。

⚠ 判据依赖 KKK：R\mathbb{R}R 上的旋转没有实特征值，当然不可对角化；但它到 C\mathbb{C}C 上就有特征值 ±i\pm i±i 且可对角化。所以「可对角化」永远相对于 KKK 说。

    自伴性 + 紧性   ⟹  \implies⟹ 谱定理（实对称）

    设 TTT 是有限维实内积空间上的自伴算子。

    1. 存在实特征值：单位球面 S:={v:∥v∥=1}S := \{v : \|v\| = 1\}S:={v:∥v∥=1} 是紧集，函数 f(v):=⟨Tv,v⟩f(v) := \langle Tv, v\ranglef(v):=⟨Tv,v⟩ 连续，故在某点 v0v_0v0​ 取到最大值 λ\lambdaλ（最值定理）。用 Lagrange 乘子（或直接对 v0v_0v0​ 附近扰动求导）可得 Tv0=λv0Tv_0 = \lambda v_0Tv0​=λv0​：即在约束 ∥v∥2=1\|v\|^{2} = 1∥v∥2=1 下 fff 的极值点满足 ∇f=λ∇(∥v∥2)\nabla f = \lambda \nabla(\|v\|^{2})∇f=λ∇(∥v∥2)，而两个梯度分别是 2Tv02Tv_02Tv0​ 与 2v02v_02v0​。于是 λ\lambdaλ 是特征值，且由 λ=⟨Tv0,v0⟩∈R\lambda = \langle Tv_0, v_0\rangle \in \mathbb{R}λ=⟨Tv0​,v0​⟩∈R 知它是实数。
    2. 特征子空间的不变性：U:=EλU := E_\lambdaU:=Eλ​ 是 TTT-不变的；由自伴性，U⊥U^{\perp}U⊥ 也是 TTT-不变的：若 w⊥Uw \perp Uw⊥U，则对 u∈Uu \in Uu∈U，⟨u,Tw⟩=⟨Tu,w⟩=⟨λu,w⟩=λ⟨u,w⟩=0\langle u, Tw\rangle = \langle Tu, w\rangle = \langle \lambda u, w\rangle = \lambda\langle u, w\rangle = 0⟨u,Tw⟩=⟨Tu,w⟩=⟨λu,w⟩=λ⟨u,w⟩=0，即 Tw⊥UTw \perp UTw⊥U。
    3. 归纳：T∣U⊥T|_{U^{\perp}}T∣U⊥​ 仍自伴，对 dim⁡U⊥<dim⁡V\dim U^{\perp} < \dim VdimU⊥<dimV 用归纳假设，得 U⊥=Eλ2⊕⋯U^{\perp} = E_{\lambda_2}\oplus\cdotsU⊥=Eλ2​​⊕⋯（两两正交）。于是 V=Eλ⊕U⊥V = E_{\lambda} \oplus U^{\perp}V=Eλ​⊕U⊥ 是所有特征子空间的正交直和。
    4. 在每个 EλiE_{\lambda_i}Eλi​​ 里取标准正交基（Gram–Schmidt），拼起来就是 VVV 的标准正交基，TTT 在其中是对角阵。∎

    第 1 步是分析输入（紧集上连续函数取最值），第 2 步是自伴性唯一被用到的地方。这也解释了为什么谱定理在实情形必须要求对称：没有自伴性，U⊥U^{\perp}U⊥ 不必不变，归纳断掉。

    特征子空间 + 极小多项式   ⟹  \implies⟹ 可对角化判据

    记 n=dim⁡Vn = \dim Vn=dimV、λ1,…,λm\lambda_1, \ldots, \lambda_mλ1​,…,λm​ 为（KKK 中）互异特征值。

    (1)   ⟹  \implies⟹ (2)：若 TTT 在某组基下是对角阵 diag⁡(λi1,…)\operatorname{diag}(\lambda_{i_1}, \ldots)diag(λi1​​,…)，则每个基向量都是特征向量，于是这组基（共 nnn 个）落在 ⋃iEλi\bigcup_i E_{\lambda_i}⋃i​Eλi​​ 中；又不同特征值的特征子空间之和是直和，故 V=⨁iEλiV = \bigoplus_i E_{\lambda_i}V=⨁i​Eλi​​。

    (2)   ⟹  \implies⟹ (3)：取维数即得 ∑idim⁡Eλi=n\sum_i \dim E_{\lambda_i} = n∑i​dimEλi​​=n。

    (3)   ⟹  \implies⟹ (1)：在每个 EλiE_{\lambda_i}Eλi​​ 里取一组基（共 ∑idim⁡Eλi=n\sum_i \dim E_{\lambda_i} = n∑i​dimEλi​​=n 个向量）。它们线性无关（直和），故是 VVV 的基；在这组基下 TTT 是对角阵。

    (4)   ⟺  \iff⟺ (3)：恒有 dim⁡Eλ≤mλ\dim E_{\lambda} \le m_\lambdadimEλ​≤mλ​（代数重数）与 ∑λmλ=n\sum_\lambda m_\lambda = n∑λ​mλ​=n。于是「和 =n= n=n」等价于「每个都取等号」，即几何重数 === 代数重数。

    (5)   ⟹  \implies⟹ (4)：设 ∏i(T−λiI)=0\prod_i (T - \lambda_i I) = 0∏i​(T−λi​I)=0 且 λi\lambda_iλi​ 互异，则 μT∣∏i(x−λi)\mu_T \mid \prod_i (x - \lambda_i)μT​∣∏i​(x−λi​)，故 μT\mu_TμT​ 无重根。“无重根”意味着极小多项式在每个特征值处的重数为 1，结合 μT\mu_TμT​ 与 χT\chi_TχT​ 同根、且代数重数 ≥\ge≥ 几何重数 ≥1\ge 1≥1，逐块比较即得几何重数 === 代数重数。

    (1)   ⟹  \implies⟹ (5)：可对角化时 μT=∏i(x−λi)\mu_T = \prod_i (x - \lambda_i)μT​=∏i​(x−λi​)（互异的一次因子之积），代入 TTT 得零。∎

    证明里真正有内容的是 (4)   ⟺  \iff⟺ (3)（几何重数 vs 代数重数）与最后一对（(5) 是无重根判据）。前三条只是把「对角化」翻译成「有 nnn 个无关特征向量」。
