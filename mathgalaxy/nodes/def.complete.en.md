## Statement · **draft**
A sequence $\{x_{n}\}$ is a **Cauchy sequence** if and only if

$$\forall\varepsilon > 0, \exists N : m, n \ge N \implies d(x_m, x_n) < \varepsilon$$

A metric space $(X, d)$ is **complete** if and only if every Cauchy sequence in $X$ converges in $X$:

$$\{x_n\}\ \text{Cauchy} \implies \exists x \in X : x_n \to x$$
