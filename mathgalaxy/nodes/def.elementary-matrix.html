又称初等变换与初等矩阵

陈述

初等行变换指下列三种操作：

  • 把第 iii 行与第 jjj 行互换；
  • 把第 iii 行乘以非零常数 ccc；
  • 把第 jjj 行的 ccc 倍加到第 iii 行上（要求 i≠ji \ne ji=j；i=ji = ji=j、c=−1c = -1c=−1 会得到不可逆的 diag⁡(0,1)\operatorname{diag}(0, 1)diag(0,1)）。

对单位矩阵 InI_nIn​ 做一次上述操作得到的矩阵叫初等矩阵（记 EEE）。关键性质是：对 AAA 做一次初等行变换，等于在左边乘上相应的初等矩阵，即把 AAA 换成 EAEAEA。

每个初等矩阵都可逆，且逆仍是初等矩阵（同类型的）：互换的逆是自己、乘 ccc 的逆是乘 c−1c^{-1}c−1、加 ccc 倍的逆是加 −c-c−c 倍。

说明

⭐ 「左乘 = 行变换」这条对应关系把操作变成了对象：于是「用消元法解方程组」就是「在左边乘一串初等矩阵」，可以写成等式 Ek⋯E1A=RE_k \cdots E_1 A = REk​⋯E1​A=R（RRR 是行简化阶梯形）。

⭐ 最重要的一条推论：AAA 可逆当且仅当它是有限多个初等矩阵之积（消元法把 AAA 化成 InI_nIn​，把这一串操作记录下来就是 A−1A^{-1}A−1 的显式分解）。

这也是「算逆矩阵」那套 [A∣I]→[I∣A−1][A \mid I] \to [I \mid A^{-1}][A∣I]→[I∣A−1] 手法的道理。

⚠ 初等列变换对应的是右乘。

行列混着做就成了等价变换（A↦PAQA \mapsto PAQA↦PAQ），它保持秩但不保持相似。
