# criterion for diagonalisability　`thm.diagonalizable`
English entry · root `../`
[in graph](../#n=thm.diagonalizable)　·　[Chinese page (authoritative)](./thm.diagonalizable.md)

⚠ The criterion depends on $K$: a rotation over $\mathbb{R}$ has no real eigenvalue, so of course it is not diagonalizable;

but over $\mathbb{C}$ it has eigenvalues $\pm i$ and is diagonalizable.

So "diagonalizable" is always relative to $K$.

**(1)–(4): the first three are only restatements, only the fourth uses the characteristic polynomial; (5) is a separate entry point.**
