设 MMM 是 GGG-模。令

Cn(G,M):=Hom⁡R[G](Bn, M)  ≅  { c:Gn→M }C^{n}(G, M) := \operatorname{Hom}_{R[G]}\bigl(B_{n},\ M\bigr) \;\cong\; \bigl\{\, c : G^{n} \to M \,\bigr\}Cn(G,M):=HomR[G]​(Bn​, M)≅{c:Gn→M}

（C0(G,M)=MC^{0}(G, M) = MC0(G,M)=M，约定 G0G^{0}G0 是单点集），微分

(δc)(g1,⋯ ,gn+1):=g1c(g2,⋯ ,gn+1)+∑i=1n(−1)ic(g1,⋯ ,gigi+1,⋯ ,gn+1)+(−1)n+1c(g1,⋯ ,gn).(\delta c)(g_{1}, \cdots, g_{n+1}) := g_{1} c(g_{2}, \cdots, g_{n+1}) + \sum_{i=1}^{n} (-1)^{i} c(g_{1}, \cdots, g_{i} g_{i+1}, \cdots, g_{n+1}) + (-1)^{n+1} c(g_{1}, \cdots, g_{n}) .(δc)(g1​,⋯,gn+1​):=g1​c(g2​,⋯,gn+1​)+i=1∑n​(−1)ic(g1​,⋯,gi​gi+1​,⋯,gn+1​)+(−1)n+1c(g1​,⋯,gn​).

则 Hn(G,M)≅Hn(C∙(G,M))H^{n}(G, M) \cong H^{n}\bigl(C^{\bullet}(G, M)\bigr)Hn(G,M)≅Hn(C∙(G,M)) 对一切 n≥0n \ge 0n≥0 成立。

说明

按 nnn 展开就是最有用的那几行：

  • n=0n = 0n=0：C0=MC^{0} = MC0=M、(δ0m)(g)=gm−m(\delta^{0} m)(g) = g m - m(δ0m)(g)=gm−m，故 H0=ker⁡δ0=MGH^{0} = \ker \delta^{0} = M^{G}H0=kerδ0=MG。
  • n=1n = 1n=1：Z1Z^{1}Z1 是交叉同态、B1B^{1}B1 是主交叉同态，见「一维上同调与交叉同态」。
  • n=2n = 2n=2：Z2Z^{2}Z2 是满足结合律条件的 222-上圈、B2B^{2}B2 是 222-上边界，见「二维上圈与上边界」与「二维上同调分类群扩张」。

⭐ 实用价值：这个复形是显式的 —— 每一项都是「GnG^{n}Gn 到 MMM 的任意函数」，δ\deltaδ 是纯组合公式，没有任何消解要挑。于是群上同调在原则上可以硬算；代价是 CnC^{n}Cn 巨大，实际计算要靠小消解或谱序列。

⚠️ 别把它当成「另一个群上同调」：它算出来的就是 Rn(−)GR^{n}(-)^{G}Rn(−)G，只是换了一条（等价但可算的）路。两条路给出同构，且这个同构是自然的。

  • 标准消解、群上同调 ⟹ 本页推出
    标准消解   ⟹  \implies⟹ 显式上链复形算出群上同调

    要证：Hn(G,M)=Hn(Hom⁡R[G](B∙,M))H^{n}(G, M) = H^{n}\bigl(\operatorname{Hom}_{R[G]}(B_{\bullet}, M)\bigr)Hn(G,M)=Hn(HomR[G]​(B∙​,M))。

    第一步：B∙B_{\bullet}B∙​ 是自由（因而投射）消解。 由「标准消解」那条，B∙→RB_{\bullet} \to RB∙​→R 正合、每项自由。自由   ⟹  \implies⟹ 投射，投射消解可以拿来算右导出函子。

    第二步：投射消解算 RnHom⁡R^{n}\operatorname{Hom}RnHom。 对左正合加法函子 F=Hom⁡R[G](R,−)F = \operatorname{Hom}_{R[G]}(R, -)F=HomR[G]​(R,−)，取 RRR 的投射消解 P∙→RP_{\bullet} \to RP∙​→R，则

    RnF(M)=Hn(Hom⁡R[G](P∙,M)).R^{n}F(M) = H^{n}\bigl(\operatorname{Hom}_{R[G]}(P_{\bullet}, M)\bigr).RnF(M)=Hn(HomR[G]​(P∙​,M)).

    为什么：Hom⁡R[G](P∙,M)\operatorname{Hom}_{R[G]}(P_{\bullet}, M)HomR[G]​(P∙​,M) 与「先取 MMM 的内射消解再取 Hom」给出同一族右导出函子（两者都是 δ\deltaδ-函子，且在 n=0n = 0n=0 处都与 Hom⁡R[G](R,M)=MG\operatorname{Hom}_{R[G]}(R, M) = M^{G}HomR[G]​(R,M)=MG 一致、都可擦除），由同调代数的唯一性比较即得。取 P∙=B∙P_{\bullet} = B_{\bullet}P∙​=B∙​ 即可。

    第三步：把 Hom 翻译成函数。 Hom⁡R[G](Bn,M)\operatorname{Hom}_{R[G]}(B_{n}, M)HomR[G]​(Bn​,M) 里的元素由 c(g1,⋯ ,gn):=f([1∣g1∣⋯∣gn])c(g_{1}, \cdots, g_{n}) := f\bigl([1|g_{1}|\cdots|g_{n}]\bigr)c(g1​,⋯,gn​):=f([1∣g1​∣⋯∣gn​]) 唯一确定：给定任意 ccc，令 f(g0[1∣g1∣⋯∣gn]):=g0 c(g1,⋯ ,gn)f\bigl(g_{0}[1|g_{1}|\cdots|g_{n}]\bigr) := g_{0}\, c(g_{1}, \cdots, g_{n})f(g0​[1∣g1​∣⋯∣gn​]):=g0​c(g1​,⋯,gn​) 即得 R[G]R[G]R[G]-线性映射（良定义因为 {[1∣g1∣⋯∣gn]}\{[1|g_{1}|\cdots|g_{n}]\}{[1∣g1​∣⋯∣gn​]} 是 R[G]R[G]R[G]-基）。于是 Cn(G,M)≅{c:Gn→M}C^{n}(G, M) \cong \{c : G^{n} \to M\}Cn(G,M)≅{c:Gn→M}。

    第四步：微分对上号。 由 dn[1∣g1∣⋯∣gn]=[g1∣⋯∣gn]+∑i=1n(−1)i[1∣⋯∣gigi+1∣⋯∣gn]+(−1)n+1[1∣⋯∣gn]d_{n}[1|g_{1}|\cdots|g_{n}] = [g_{1}|\cdots|g_{n}] + \sum_{i=1}^{n} (-1)^{i}[1|\cdots|g_{i}g_{i+1}|\cdots|g_{n}] + (-1)^{n+1}[1|\cdots|g_{n}]dn​[1∣g1​∣⋯∣gn​]=[g1​∣⋯∣gn​]+∑i=1n​(−1)i[1∣⋯∣gi​gi+1​∣⋯∣gn​]+(−1)n+1[1∣⋯∣gn​]（把 i=0i = 0i=0 那一项用 R[G]R[G]R[G]-线性搬到最左边：[g1∣⋯∣gn]=g1⋅[1∣g2∣⋯∣gn][g_{1}|\cdots|g_{n}] = g_{1}\cdot[1|g_{2}|\cdots|g_{n}][g1​∣⋯∣gn​]=g1​⋅[1∣g2​∣⋯∣gn​]），对 fff 取值并记 ccc 为对应的函数，逐项读出的就是

    (δc)(g1,⋯ ,gn+1)=g1c(g2,⋯ ,gn+1)+∑i=1n(−1)ic(⋯ ,gigi+1,⋯ )+(−1)n+1c(g1,⋯ ,gn).(\delta c)(g_{1}, \cdots, g_{n+1}) = g_{1}c(g_{2}, \cdots, g_{n+1}) + \sum_{i=1}^{n}(-1)^{i} c(\cdots, g_{i}g_{i+1}, \cdots) + (-1)^{n+1} c(g_{1}, \cdots, g_{n}).(δc)(g1​,⋯,gn+1​)=g1​c(g2​,⋯,gn+1​)+i=1∑n​(−1)ic(⋯,gi​gi+1​,⋯)+(−1)n+1c(g1​,⋯,gn​).

    三步合起来即得 Hn(G,M)≅Hn(C∙(G,M))H^{n}(G, M) \cong H^{n}(C^{\bullet}(G, M))Hn(G,M)≅Hn(C∙(G,M))，且同构是自然的。∎
