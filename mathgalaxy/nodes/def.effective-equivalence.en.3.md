# effective equivalence relation　`def.effective-equivalence`
English entry · root `../`
[in graph](../#n=def.effective-equivalence)　·　[Chinese page (authoritative)](./def.effective-equivalence.md)

Compare with sets: for any $f : X \to Y$ the kernel pair $X \times_{Y} X$ is always effective ($\overline{X} \cong \operatorname{im} f$); conversely, any equivalence relation $R \subseteq X \times X$ with $\overline{X} = X/R$ always returns $R$.

**In $\mathbf{Set}$ everything is effective**, but in a general category this has to be required separately.
