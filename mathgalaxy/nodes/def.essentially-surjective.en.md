## Statement · **draft**
A functor $F : \mathcal{C} \to \mathcal{C}'$ is **essentially surjective** if for every object of $\mathcal{C}'$, say $X'$, there is an object of $\mathcal{C}$, say $X$, with

$$F(X) \cong X'$$
