陈述

Joukowski 映射 w=12(z+1z)w = \dfrac{1}{2}\left(z + \dfrac{1}{z}\right)w=21​(z+z1​) 把

  1. 单位圆 ∣z∣=1|z| = 1∣z∣=1 映成线段 [−1,1][-1, 1][−1,1]（二重覆盖）；
  2. ∣z∣=r>1|z| = r > 1∣z∣=r>1 映成以 ±1\pm 1±1 为焦点的椭圆；
  3. D\mathbb{D}D 的外部映成 C∖[−1,1]\mathbb{C} \setminus [-1, 1]C∖[−1,1]；
  4. 过 z=1z = 1z=1 的圆（圆心稍偏）映成机翼剖面（Joukowski 翼型）。

说明

为什么：w=12(z+1/z)w = \tfrac12(z + 1/z)w=21​(z+1/z) 把 z=reiθz = r e^{i\theta}z=reiθ 送到

u=12(r+1r)cos⁡θ,v=12(r−1r)sin⁡θ,u = \tfrac12\left(r + \tfrac1r\right)\cos\theta,\qquad v = \tfrac12\left(r - \tfrac1r\right)\sin\theta,u=21​(r+r1​)cosθ,v=21​(r−r1​)sinθ,

这正是椭圆的参数方程（半轴 12(r±1/r)\tfrac12(r \pm 1/r)21​(r±1/r)）。r→1r \to 1r→1 时短轴趋于 000，椭圆退化成线段。∎

⭐ 为什么它在空气动力学里出名：保角映射把「绕机翼的流动」搬到「绕圆的流动」，而绕圆的流动有现成公式；再由 thm.riemann-mapping 保证这种搬运不改变「无旋、不可压、无粘」这些结构（Laplace 方程在共形映射下不变）。

⚠️ w=12(z+1/z)w = \tfrac12(z + 1/z)w=21​(z+1/z) 不是单叶：zzz 与 1/z1/z1/z 给同一个 www。要得到双全纯，必须限制在 D\mathbb{D}D 或 D\mathbb{D}D 的外部（含 ∞\infty∞）。
