基本性质：

  • tr⁡(A+B)=tr⁡A+tr⁡B\operatorname{tr}(A + B) = \operatorname{tr} A + \operatorname{tr} Btr(A+B)=trA+trB，tr⁡(cA)=ctr⁡A\operatorname{tr}(cA) = c\operatorname{tr} Atr(cA)=ctrA（线性）；
  • tr⁡(AB)=tr⁡(BA)\operatorname{tr}(AB) = \operatorname{tr}(BA)tr(AB)=tr(BA)，于是 tr⁡(P−1AP)=tr⁡A\operatorname{tr}(P^{-1}AP) = \operatorname{tr} Atr(P−1AP)=trA（相似不变）；
  • tr⁡(ABC)=tr⁡(BCA)\operatorname{tr}(ABC) = \operatorname{tr}(BCA)tr(ABC)=tr(BCA)（循环不变）。

说明

⭐ 迹是最便宜的不变量：O(n)O(n)O(n) 就算出来，却已经能区分不少矩阵（比行列式便宜得多）。

⭐ 它的深层含义：tr⁡\operatorname{tr}tr 是矩阵代数的唯一的（差常数倍）中心线性泛函，也是「KnK^{n}Kn-代数到 KKK 的迹型」—— 在 Galois 理论、特征类里都会再遇到。

⚠ 「相似不变」比「循环不变」弱：tr⁡(P−1AP)=tr⁡(AP−1P)=tr⁡A\operatorname{tr}(P^{-1}AP) = \operatorname{tr}(A P^{-1} P) = \operatorname{tr}Atr(P−1AP)=tr(AP−1P)=trA 只是循环不变的特例。反之迹相同不蕴含相似（(0100)\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}(00​10​) 与零矩阵迹都是 000 而不相似）。
