# continuity between metric spaces　`def.metric-continuity`
English entry · root `../`
[in graph](../#n=def.metric-continuity)　·　[Chinese page (authoritative)](./def.metric-continuity.md)

(open preimages are open $\implies$ $\varepsilon$–$\delta$) Given $x_0$ and $\varepsilon > 0$, $B_Y(f(x_0), \varepsilon)$ is open, so $f^{-1}(B_Y(f(x_0), \varepsilon))$ is open and contains $x_0$; choose $\delta > 0$ so that $B_X(x_0, \delta)$ lies in it, which is exactly the $\varepsilon$–$\delta$ statement. $\blacksquare$

📌 This is `def.continuous-map` (the topological version) written out for metric spaces: open sets in a metric space are generated by open balls, so “preimages are open” is equivalent to $\varepsilon$–$\delta$.
