陈述

设 f∈L+f \in L^+f∈L+。定义

∫fdμ:=sup⁡{∫φdμ:0≤φ≤f,φ 是简单函数}\int f d\mu := \sup \{ \int \varphi d\mu : 0 \le \varphi \le f, \varphi\text{ 是简单函数} \}∫fdμ:=sup{∫φdμ:0≤φ≤f,φ 是简单函数}

说明

直观：用简单函数从下面去顶 fff，取这些面积的上确界。这与 Jordan 测度「从外面盖、从里面填」的做法不同 —— 这里只从里面填。

为什么不再要求「外面的盖」：因为测度已经在对偶的那一侧（μ\muμ 本身是从外面用外测度定义的），简单函数的下确界只会把积分定义偏小。

⚠ 这个定义只对非负函数管用。对一般实值函数，先拆成正负部再相减（见「复函数的积分」）。
