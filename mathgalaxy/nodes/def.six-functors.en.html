Statement

In plain words: a 6-functor formalism = attach to every space six operations "base change, pushforward, duality", and require them to be compatible as in classical Poincaré / Serre duality. The goal is single: turn "cohomology" into "an inner product", so that cohomology classes can be paired and the result computed. Classical geometry (sheaves, ℓ\ellℓ-adic cohomology) and solid geometry each have such a system of six functors.

A 6-functor formalism consists of:

  • for every scheme XXX a closed symmetric monoidal triangulated category D(X)D(X)D(X) (the tensor product −⊗X−- \otimes_X -−⊗X​− has a right adjoint Hom⁡X\operatorname{Hom}_XHomX​);
  • for every map f:X→Yf : X \to Yf:X→Y a pullback f∗:D(Y)→D(X)f^* : D(Y) \to D(X)f∗:D(Y)→D(X), with right adjoint f∗f_*f∗​ (pushforward);
  • for every map f:X→Yf : X \to Yf:X→Y (satisfying suitable conditions) a proper-support pushforward f!:D(X)→D(Y)f_! : D(X) \to D(Y)f!​:D(X)→D(Y) (keeping only the part "whose support lies in the compact fibres of fff", analogous to integration being meaningful only on compact regions), with right adjoint f!f^!f! (duality).

That is six functors: ⊗, Hom⁡, f∗, f∗, f!, f!\otimes,\ \operatorname{Hom},\ f^*,\ f_*,\ f_!,\ f^!⊗, Hom, f∗, f∗​, f!​, f!. They should satisfy:

(i) fff proper   ⟹  f!=f∗\implies f_! = f_*⟹f!​=f∗​; (ii) fff étale   ⟹  f!=f∗\implies f^! = f^*⟹f!=f∗;

(iii) Verdier duality: f∗Hom⁡X(A,f!B)≅Hom⁡Y(f!A,B)f_* \operatorname{Hom}_X(A, f^!B) \cong \operatorname{Hom}_Y(f_!A, B)f∗​HomX​(A,f!B)≅HomY​(f!​A,B);

(iv) projection formula: f!(A⊗Xf∗B)≅f!A⊗YBf_!(A \otimes_X f^*B) \cong f_!A \otimes_Y Bf!​(A⊗X​f∗B)≅f!​A⊗Y​B;

(v) proper base change: in a pullback square g∗f!≅f!′g′∗g^* f_! \cong f'_! g'^*g∗f!​≅f!′​g′∗;

(vi) Poincaré duality: for smooth fff the map f!1Y⊗Xf∗B→f!Bf^!\mathbf{1}_Y \otimes_X f^*B \to f^!Bf!1Y​⊗X​f∗B→f!B is an isomorphism and f!1Yf^!\mathbf{1}_Yf!1Y​ is invertible.

Notes

⭐ The first four functors ⊗,Hom⁡,f∗,f∗\otimes, \operatorname{Hom}, f^*, f_*⊗,Hom,f∗,f∗​ are usually easy to construct; all the difficulty is in f!f_!f!​.

The classical example is ℓ\ellℓ-adic sheaves Det(X,Zℓ)D_{\mathrm{et}}(X, \mathbb{Z}_\ell)Det​(X,Zℓ​) and condensed/solid sheaves.

⭐ Once f!f_!f!​ exists, f!f^!f! is given by adjunction.

Conversely, f!f_!f!​ is determined by "open immersion + proper map + Nagata compactification": for f=fˉ∘jf = \bar f \circ jf=fˉ​∘j one has f!=fˉ∗j!f_! = \bar f_* j_!f!​=fˉ​∗​j!​.
