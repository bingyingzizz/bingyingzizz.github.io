# uniform convergence　`def.uniform-convergence`
English entry · root `../`
[in graph](../#n=def.uniform-convergence)　·　[Chinese page (authoritative)](./def.uniform-convergence.md)

⚠ Uniform convergence $\implies$ pointwise convergence, but not conversely ($f_n(x) = x^{n}$ on $[0, 1]$).

⭐ The three exchange theorems in this pack (preserving continuity, integrals, derivatives) all need only uniform convergence — and convergence of the kind $f_n(x) = x^{n}$ that "misses one point" is exactly what destroys continuity.
