陈述

在做什么：把曲率张量缩并一次得到 Ricci 曲率、再缩并一次得到数量曲率 —— 这两个更粗的量才是 Einstein 方程里出现的对象。

设 (M,g)(M,g)(M,g) 是黎曼流形，RRR 是曲率算子。Ricci 曲率是

Ric⁡(X,Y):=tr⁡(Z↦R(Z,X)Y)=∑k⟨R(ek,X)Y,ek⟩,\operatorname{Ric}(X,Y) := \operatorname{tr}\bigl(Z\mapsto R(Z,X)Y\bigr) = \sum_{k}\langle R(e_{k},X)Y,e_{k}\rangle ,Ric(X,Y):=tr(Z↦R(Z,X)Y)=k∑​⟨R(ek​,X)Y,ek​⟩,

其中 {ek}\{e_{k}\}{ek​} 是任意单位正交基（取迹与基无关，这正是 def.trace 的相似不变性）。分量写成

Rij:=R kijk=gkℓRkijℓ.R_{ij} := R^{k}_{\ kij} = g^{k\ell}R_{kij\ell} .Rij​:=R kijk​=gkℓRkijℓ​.

再缩并一次得数量曲率

S:=tr⁡gRic⁡=gijRij.S := \operatorname{tr}_{g}\operatorname{Ric} = g^{ij}R_{ij} .S:=trg​Ric=gijRij​.

二维时曲率只有一个独立分量，于是两者都被高斯曲率决定：

Rij=K gij,S=2K,R1221=Kdet⁡(gij).R_{ij} = K\,g_{ij},\qquad S = 2K,\qquad R_{1221} = K\det(g_{ij}).Rij​=Kgij​,S=2K,R1221​=Kdet(gij​).

说明

它是迹，所以比 RRR 粗：RRR 有 n2(n2−1)/12n^{2}(n^{2}-1)/12n2(n2−1)/12 个分量，RijR_{ij}Rij​ 有 n(n+1)/2n(n+1)/2n(n+1)/2 个，SSS 只有 111 个。二维：1=1=11 = 1 = 11=1=1（三者等价）；三维：6=6=16 = 6 = 16=6=1（Ricci 决定一切）；四维：20>10>120 > 10 > 120>10>1（Ricci 丢掉外尔部分）。

符号约定与检验：本图取 Ric⁡(X,Y)=tr⁡(Z↦R(Z,X)Y)\operatorname{Ric}(X,Y) = \operatorname{tr}\bigl(Z\mapsto R(Z,X)Y\bigr)Ric(X,Y)=tr(Z↦R(Z,X)Y)，于是单位球面 SnS^{n}Sn 给 Ric⁡=(n−1)g\operatorname{Ric} = (n-1)gRic=(n−1)g、S=n(n−1)S = n(n-1)S=n(n−1)，二维时 Ric⁡=Kg\operatorname{Ric} = KgRic=Kg（球面 K=1K = 1K=1，与 def.gauss-curvature 一致）。判断约定对不对就看这一条；把缩并的指标换一个位置会整体反号。

为什么对称：RijR_{ij}Rij​ 的对称性来自曲率张量的两对指标可交换（prop.curvature-tensor-symmetries 第 3 条）。所以 Ricci 是切丛上的对称双线性型，可以拿来做二次型 Ric⁡(v,v)\operatorname{Ric}(v,v)Ric(v,v)。

Einstein 张量：Gij=Rij−12SgijG_{ij} = R_{ij}-\frac{1}{2}Sg_{ij}Gij​=Rij​−21​Sgij​，由第二比安基 ∇iGij=0\nabla^{i}G_{ij} = 0∇iGij​=0（thm.bianchi-identity）。这就是「为什么是 Rij−12SgijR_{ij}-\frac{1}{2}Sg_{ij}Rij​−21​Sgij​ 而不是 RijR_{ij}Rij​」的唯一理由。

⚠️ 二维里三个记号容易混：KKK 是高斯曲率（一个数）、S=2KS = 2KS=2K 是数量曲率（内蕴）、HHH 是平均曲率（外在，依赖嵌入，且随法向变号）。只有 HHH 会变号。
