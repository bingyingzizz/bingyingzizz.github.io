## Statement · **draft**
**What it does**: the last rung at the top of the chain. It tightens normality by one notch using countability: every closed set is a countable intersection of open sets.

First, two notations: a set $A$ is a **$G_{\delta}$ set** if it is a **countable** intersection of open sets; it is an **$F_{\sigma}$ set** if it is a countable union of closed sets.
