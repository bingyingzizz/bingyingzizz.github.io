# Lagrangian Submanifold　`def.lagrangian-submanifold`
English entry · root `../`
[in graph](../#n=def.lagrangian-submanifold)　·　[Chinese page (authoritative)](./def.lagrangian-submanifold.md)

- $\omega|_{L} \equiv 0$ gives **only isotropy**. An isotropic submanifold can have dimension **far below** $n$ (even a line in a symplectic vector space is isotropic), so isotropy alone does not give maximality.
- $\dim L = n$ (**must be imposed separately**): Equivalently, require $T_{p}L = (T_{p}L)^{\perp}$ (pointwise maximality). For a nondegenerate form, $\dim W + \dim W^{\perp} = \dim V$, so ‘$W = W^{\perp}$’ **forces** the dimension to be half. This is what it means to be Lagrangian.
- **Directions of the equivalence**: Pointwise, $T_{p}L$ is a Lagrangian subspace $\iff$ $L$
