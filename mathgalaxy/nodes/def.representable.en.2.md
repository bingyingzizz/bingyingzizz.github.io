# representable functor　`def.representable`

## Abstract · **reviewed**
A functor $F : \mathcal{C} \to \mathbf{Set}$ is represented by an object $X$ together with $s \in F(X)$ when every $t \in F(Y)$ is $F(f)(s)$ for exactly one $f : X \to Y$; equivalently $F \cong \operatorname{Hom}_{\mathcal{C}}(X, -)$. All the data of $F$ is generated by the single element $s$. Equivalently $(X, s)$ is an initial object of the category of elements of $F$. Examples: $k[t]$ represents the forgetful functor on $k$-algebras, $\mathbb{Z}$ represents the constant functor on rings.
