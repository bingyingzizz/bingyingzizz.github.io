# Sign Convention for Boundaries　`prop.boundary-sign-convention`
English entry · root `../`
[in graph](../#n=prop.boundary-sign-convention)　·　[Chinese page (authoritative)](./prop.boundary-sign-convention.md)

The four edges are left, right, bottom and top; the right edge ($\alpha = 1$, outward normal $+e_{1}$) gets $+$, the left edge (outward normal $-e_{1}$) gets $-$, the bottom edge (outward normal $-e_{2}$) gets $+$, and the top edge (outward normal $+e_{2}$) gets $-$.

Checking one by one with "outward normal first", all four agree — and the directions of the four edges run exactly once around counterclockwise.
