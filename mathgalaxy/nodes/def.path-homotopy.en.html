Statement

Notes

Why the endpoints must be pinned: [0,1][0, 1][0,1] is convex and contractible, so any two paths are homotopic (shrink α\alphaα to a point along a straight line and then expand into β\betaβ). A homotopy that does not pin the endpoints collapses all paths into one class and detects nothing; only after pinning the endpoints does the information "how it winds" survive.

⚠️ Path homotopy makes sense only for paths with common endpoints — otherwise the conditions F(0,s)F(0, s)F(0,s) and F(1,s)F(1, s)F(1,s) cannot even be written down.

Homotopy classes are equivalence classes: the three properties in 映射同伦 restrict to homotopies that keep the endpoints fixed, so for fixed x0,x1x_{0}, x_{1}x0​,x1​ the paths from x0x_{0}x0​ to x1x_{1}x1​ split into homotopy classes.

💡 Intuition: a homotopy class is "a way of walking from x0x_{0}x0​ to x1x_{1}x1​"; two walks count as the same if they can be deformed continuously into each other.
