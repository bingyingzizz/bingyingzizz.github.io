# Inner Product of Class Functions　`def.character-inner-product`

## Statement · **stale**
Let $G$ be a finite group with $\operatorname{char}F\nmid|G|$. For functions $f_1,f_2:G\to F$ define $\langle f_1,f_2\rangle=\frac{1}{|G|}\sum_{g\in G}f_1(g)f_2(g^{-1})$. This is an $F$-bilinear form; on the space of class functions it gives the pairing used in character theory.
