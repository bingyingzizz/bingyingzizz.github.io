## Statement · **reviewed**
The subsets of a set form a set:

$$\forall A \exists P \forall x [ x \in P \leftrightarrow  x \subseteq A ]$$

It is written $\mathcal{P}(A)$ (or P(A)). It turns "all subsets of $A$" itself into a set — the power set is the basic device for building larger sets.
