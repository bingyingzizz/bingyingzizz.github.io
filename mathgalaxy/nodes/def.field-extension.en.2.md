# field extension　`def.field-extension`
English entry · root `../`
[in graph](../#n=def.field-extension)　·　[Chinese page (authoritative)](./def.field-extension.md)

It is a **finite extension** when $[K:F] < \infty$.

## Notes · **draft**
⭐ **“Extension” is not a new object but a change of viewpoint**: the same field $K$, once a subfield $F$ is specified, can be regarded as a vector space $K$ over $F$. Field theory thus immediately borrows the whole linear-algebra machine (basis, dimension, linear independence) — this is the opening move of all Galois theory.

⭐ **How to compute degrees**: $[\mathbb{C}:\mathbb{R}] = 2$ (basis $\{1, i\}$); $[\mathbb{Q}(\sqrt{2}):\mathbb{Q}] = 2$; $[\mathbb{F}_{p^{n}}:\mathbb{F}_{p}] = n$.
