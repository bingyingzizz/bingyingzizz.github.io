# L^p 范数　`def.lp-norm`
$L^p$ 范数与 $L^p$ 空间

固定测度空间 $(X, \mathcal{M}, \mu)$。对可测 $f$ 与 $0 < p < \infty$ 定义

$$\|f\|_p := \left[ \int |f|^p \, d\mu \right]^{1/p}$$

以及

$$L^p(X, \mathcal{M}, \mu) := \{\, f : X \to \mathbb{C} : f \text{ 可测},\ \|f\|_p < \infty \,\}$$
