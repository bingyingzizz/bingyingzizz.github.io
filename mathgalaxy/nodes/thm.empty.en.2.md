# the empty set exists　`thm.empty`
English entry · root `../`
[in graph](../#n=thm.empty)　·　[Chinese page (authoritative)](./thm.empty.md)

The point of this theorem is that **$\emptyset$ need not be taken as a primitive object**: the Axiom Scheme of Separation already produces it (from any set $A$, take $\{x \in A : x \ne x\}$). So in ZF the empty set is not an extra assumption.
