# topological abelian groups embed into condensed ones　`prop.abtop-to-abcond`
English entry · root `../`
[in graph](../#n=prop.abtop-to-abcond)　·　[Chinese page (authoritative)](./prop.abtop-to-abcond.md)

$$\underline{M} : S \longmapsto C(S, M),$$

namely the set of continuous maps from a compact Hausdorff space $S$ to $M$, with pointwise addition. Since $M$ is a topological abelian group, $C(S, M)$ is an abelian group under pointwise addition. This defines an abelian-group-valued presheaf. The sheaf condition is gluing continuous maps, which holds.
