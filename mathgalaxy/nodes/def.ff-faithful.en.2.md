# faithful, full and fully faithful functor　`def.ff-faithful`
English entry · root `../`
[in graph](../#n=def.ff-faithful)　·　[Chinese page (authoritative)](./def.ff-faithful.md)

- **faithful**: each such map is injective;
- **full**: each such map is surjective;
- **fully faithful**: each such map is bijective.

## Notes · **draft**
All three names concern the behaviour of $F$ on the **morphism level**, independently of the object level — a fully faithful functor may send two distinct objects to the same object (which is exactly what is allowed in an equivalence).

Faithfulness guarantees that "morphisms are not merged", fullness that "every morphism in the target comes from the source"; neither implies the other.
