陈述

在做什么：给实对称型配一对整数，把它的「形状」量化 —— 正方向有多少维、负方向有多少维。这对整数在合同下完全不变，所以它是实二次型的完备不变量。

设 AAA 是 nnn 阶实对称矩阵，β\betaβ 是它对应的对称双线性型。把 AAA 合同对角化后，对角元中正、负、零的个数分别记为 p,q,zp, q, zp,q,z（p+q+z=np + q + z = np+q+z=n）。称

  • ppp 为正惯性指数；
  • qqq 为负惯性指数；
  • p−qp - qp−q 为符号差（signature）。

三者由 AAA 唯一确定（不依赖所选的合同变换、不依赖对角化方式）—— 这就是惯性定理。

秩 =p+q= p + q=p+q；AAA 正定   ⟺  p=n\iff p = n⟺p=n；半正定   ⟺  q=0\iff q = 0⟺q=0；不定   ⟺  p≥1\iff p \ge 1⟺p≥1 且 q≥1q \ge 1q≥1。

说明

符号差的几何读法：q(x)=1q(x) = 1q(x)=1 的等值面拓扑类型由 (p,q)(p,q)(p,q) 决定 —— (n,0)(n,0)(n,0) 是椭球、(n−1,1)(n-1,1)(n−1,1) 是双叶双曲面、更一般地是 Rp\mathbb{R}^{p}Rp 上的椭球与 Rq\mathbb{R}^{q}Rq 上的双曲部分的积。所以「惯性指数 = 等值面的拓扑」。

⚠️ 符号差不是「行列式的符号」：2×22\times22×2 矩阵 diag⁡(1,−1)\operatorname{diag}(1,-1)diag(1,−1) 的符号差是 000 而行列式是 −1-1−1。符号差是 p−qp - qp−q，行列式是 ∏λi\prod\lambda_i∏λi​ —— 前者是「有多少个负方向」，后者是「负方向的个数奇偶」。

⭐ 在几何里它叫 index：伪黎曼度量 (M,g)(M, g)(M,g) 的「指标」就是每点切空间上 ggg 的负惯性指数（111   ⟹  \implies⟹ Lorentz 型，000   ⟹  \implies⟹ Riemann 型）。所以这个词在相对论/伪黎曼几何里天天出现。

⚠️ 惯性指数只在实对称（或 Hermite）情形有意义。复对称型在合同下只看秩（可以开方把 −1-1−1 吸收），没有 p,qp,qp,q 之分。
