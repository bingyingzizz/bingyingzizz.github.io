# homotopy invariance of the winding number　`thm.winding-homotopy`
English entry · root `../`
[in graph](../#n=thm.winding-homotopy)　·　[Chinese page (authoritative)](./thm.winding-homotopy.md)

⭐ **It is the first hinge between complex analysis and topology**: the winding number is a homotopy invariant, so "holomorphic $\implies$ the contour integral depends only on the homotopy class" — this is why Cauchy's theorem holds for **any** curve that can be contracted to a point, with no convexity of the region required. The complex-analytic proof of Brouwer's fixed-point theorem (`thm.brouwer-fixed-point`) applies this directly to $\gamma(t) = e^{2\pi i t}$.

⚠️ The homotopy must take place in $\mathbb{C}\setminus\{a\}$: if it were allowed to pass through $a$, the winding number would jump.
