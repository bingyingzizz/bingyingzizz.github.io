陈述

每个整数 n>1n > 1n>1 都能唯一地写成

n=p1e1p2e2⋯prer,n = p_{1}^{e_{1}} p_{2}^{e_{2}} \cdots p_{r}^{e_{r}},n=p1e1​​p2e2​​⋯prer​​,

其中 p1<p2<⋯<prp_{1} < p_{2} < \cdots < p_{r}p1​<p2​<⋯<pr​ 是素数，ei≥1e_{i} \ge 1ei​≥1。

说明

存在性：对 nnn 归纳 —— nnn 是素数则完事；否则 n=abn = abn=ab 且 1<a,b<n1 < a, b < n1<a,b<n，对 a,ba, ba,b 各用归纳假设再合并。

唯一性：用 Euclid 引理（p∣ab  ⟹  p∣ap \mid ab \implies p \mid ap∣ab⟹p∣a 或 p∣bp \mid bp∣b）。这是唯一分解整环（UFD）的标准论证。

代数里的抽象版本是「Z\mathbb{Z}Z 是唯一分解整环」：K[x]K[x]K[x] 也有（thm.poly-ufd），Z[−5]\mathbb{Z}[\sqrt{-5}]Z[−5​] 没有（6=2⋅3=(1+−5)(1−−5)6 = 2\cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5})6=2⋅3=(1+−5​)(1−−5​)）。层级：Euclid 整环   ⟹  \implies⟹ UFD   ⟹  \implies⟹ gcd 整环。

  • 整数的带余除法 ⟹ 本页推出
    唯一分解：归纳 + Euclid 引理

    存在性：对 nnn 归纳。nnn 素则 n=nn = nn=n；否则 n=abn = abn=ab、1<a,b<n1 < a, b < n1<a,b<n，由归纳假设 a,ba, ba,b 各有分解，乘起来即得 nnn 的分解（再按大小重排、合并同素因子）。

    唯一性：设 p1⋯pr=q1⋯qsp_{1}\cdots p_{r} = q_{1}\cdots q_{s}p1​⋯pr​=q1​⋯qs​。p1p_{1}p1​ 整除右边，由 Euclid 引理（p∣xy  ⟹  p∣xp \mid xy \implies p \mid xp∣xy⟹p∣x 或 p∣yp \mid yp∣y，对乘积归纳）得 p1=qjp_{1} = q_{j}p1​=qj​ 对某个 jjj；两边约掉 p1p_{1}p1​，对 r+sr + sr+s 归纳即得 r=sr = sr=s 且两边的素因子多重集相同。

    Euclid 引理本身来自带余除法：若 p∤ap \nmid ap∤a，则 gcd⁡(p,a)=1\gcd(p, a) = 1gcd(p,a)=1，由 Bézout 有 up+va=1up + va = 1up+va=1，两边乘 bbb 得 upb+vab=bupb + vab = bupb+vab=b —— 而 ppp 整除右边两项（p∣abp \mid abp∣ab 与 p∣upbp \mid upbp∣upb），故 p∣bp \mid bp∣b。
