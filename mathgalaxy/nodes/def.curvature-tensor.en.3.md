# Riemann Curvature Tensor　`def.curvature-tensor`
English entry · root `../`
[in graph](../#n=def.curvature-tensor)　·　[Chinese page (authoritative)](./def.curvature-tensor.md)

in coordinates, $R(\partial_{i},\partial_{j})\partial_{k} = R^{\ell}_{ijk}\partial_{\ell}$, where

$$R^{\ell}_{ijk} = \partial_{i}\Gamma^{\ell}_{jk}-\partial_{j}\Gamma^{\ell}_{ik}+\Gamma^{\ell}_{ip}\Gamma^{p}_{jk}-\Gamma^{\ell}_{jp}\Gamma^{p}_{ik},$$

and indices are lowered by $R_{ijk\ell} = g_{\ell p}R^{p}_{ijk}$. It satisfies

$$R_{ijk\ell} = -R_{jik\ell} = -R_{ij\ell k} = R_{k\ell ij},\qquad R_{ijk\ell}+R_{jki\ell}+R_{kij\ell} = 0$$
