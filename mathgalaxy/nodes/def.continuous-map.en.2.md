## Notes · **draft**
⭐ This definition is the **abstraction** of $\varepsilon$-$\delta$: in a metric space, "$f^{-1}(V)$ is open" and "$\varepsilon$ gives $\delta$" are literally equivalent — because open balls are $\varepsilon$-neighbourhoods.

So continuity is a topological property, independent of any particular metric.

⚠ Use **preimages**, not images: preimages preserve unions, intersections and complements; images do not.

This is the same pattern as the definition of a measurable function ($f^{-1}(E) \in \mathcal{M}$).
