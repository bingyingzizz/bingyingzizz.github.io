设 1≤p<∞1 \le p < \infty1≤p<∞。则对 f,g∈Lpf, g \in L^pf,g∈Lp：

∥f+g∥p≤∥f∥p+∥g∥p\|f + g\|_p \le \|f\|_p + \|g\|_p∥f+g∥p​≤∥f∥p​+∥g∥p​

说明

p=1p = 1p=1 就是积分的三角不等式，显然。

一般 ppp 的证明：

∫∣f+g∣p=∫∣f+g∣⋅∣f+g∣p−1≤∫(∣f∣+∣g∣)∣f+g∣p−1≤(∥f∥p+∥g∥p)∥∣f+g∣p−1∥q\int |f+g|^p = \int |f+g| \cdot |f+g|^{p-1} \le \int (|f| + |g|) |f+g|^{p-1} \le \left( \|f\|_p + \|g\|_p \right) \left\| |f+g|^{p-1} \right\|_q∫∣f+g∣p=∫∣f+g∣⋅∣f+g∣p−1≤∫(∣f∣+∣g∣)∣f+g∣p−1≤(∥f∥p​+∥g∥p​)​∣f+g∣p−1​q​

其中最后一步是对 ∣f∣⋅∣f+g∣p−1|f| \cdot |f+g|^{p-1}∣f∣⋅∣f+g∣p−1 与 ∣g∣⋅∣f+g∣p−1|g| \cdot |f+g|^{p-1}∣g∣⋅∣f+g∣p−1 各用一次 Hölder。再注意

∥∣f+g∣p−1∥q q=∫∣f+g∣(p−1)q=∫∣f+g∣p\left\| |f+g|^{p-1} \right\|_q^{\,q} = \int |f+g|^{(p-1)q} = \int |f+g|^p​∣f+g∣p−1​qq​=∫∣f+g∣(p−1)q=∫∣f+g∣p

两边约掉一个 ∥f+g∥pp/q\|f+g\|_p^{p/q}∥f+g∥pp/q​ 即得。∎

⭐ 有了它，∥⋅∥p\|\cdot\|_p∥⋅∥p​ 才真的成为范数 —— 这是下面「LpL^pLp 是 Banach 空间」的前提。

推出 1

  • Hölder 不等式 ⟹ 本页推出
    Hölder 不等式   ⟹  \implies⟹ Minkowski 不等式

    ① 拆开。 对 p>1p > 1p>1，

    ∣f+g∣p=∣f+g∣⋅∣f+g∣p−1≤(∣f∣+∣g∣)∣f+g∣p−1|f+g|^p = |f+g| \cdot |f+g|^{p-1} \le \left( |f| + |g| \right) |f+g|^{p-1}∣f+g∣p=∣f+g∣⋅∣f+g∣p−1≤(∣f∣+∣g∣)∣f+g∣p−1

    ② 两次 Hölder。 对 ∣f∣⋅∣f+g∣p−1|f| \cdot |f+g|^{p-1}∣f∣⋅∣f+g∣p−1 与 ∣g∣⋅∣f+g∣p−1|g| \cdot |f+g|^{p-1}∣g∣⋅∣f+g∣p−1 分别用 Hölder（指数 ppp 与 qqq，其中 1/p+1/q=11/p + 1/q = 11/p+1/q=1）：

    ∫∣f+g∣p≤(∥f∥p+∥g∥p)(∫∣f+g∣(p−1)q)1/q\int |f+g|^p \le \left( \|f\|_p + \|g\|_p \right) \left( \int |f+g|^{(p-1)q} \right)^{1/q}∫∣f+g∣p≤(∥f∥p​+∥g∥p​)(∫∣f+g∣(p−1)q)1/q

    ③ 认出右边的积分。 因为 (p−1)q=p(p-1)q = p(p−1)q=p，右边那个因子就是 ∥f+g∥p p/q\|f+g\|_p^{\,p/q}∥f+g∥pp/q​。于是

    ∥f+g∥pp≤(∥f∥p+∥g∥p)∥f+g∥p p/q\|f+g\|_p^p \le \left( \|f\|_p + \|g\|_p \right) \|f+g\|_p^{\,p/q}∥f+g∥pp​≤(∥f∥p​+∥g∥p​)∥f+g∥pp/q​

    ④ 约掉。 若 ∥f+g∥p=0\|f+g\|_p = 0∥f+g∥p​=0 结论平凡；否则两边除以 ∥f+g∥pp/q\|f+g\|_p^{p/q}∥f+g∥pp/q​，注意 p−p/q=1p - p/q = 1p−p/q=1，即得

    ∥f+g∥p≤∥f∥p+∥g∥p\|f+g\|_p \le \|f\|_p + \|g\|_p∥f+g∥p​≤∥f∥p​+∥g∥p​

    p=1p = 1p=1 时直接由逐点不等式 ∣f+g∣≤∣f∣+∣g∣|f+g| \le |f| + |g|∣f+g∣≤∣f∣+∣g∣ 积分得到。∎

    ⭐ 注意「约掉」那一步：正是 1/p+1/q=11/p + 1/q = 11/p+1/q=1 保证 p−p/q=1p - p/q = 1p−p/q=1，否则会留下一个顽固的指数。
