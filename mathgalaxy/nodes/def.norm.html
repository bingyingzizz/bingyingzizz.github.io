陈述

设 EEE 是 K\mathbb{K}K（K=R\mathbb{K} = \mathbb{R}K=R 或 C\mathbb{C}C）上的向量空间。函数 ∥⋅∥:E→[0,+∞)\|\cdot\| : E \to [0, +\infty)∥⋅∥:E→[0,+∞) 叫范数，若

  1. ∥x∥=0  ⟺  x=0\|x\| = 0 \iff x = 0∥x∥=0⟺x=0；
  2. ∥λx∥=∣λ∣ ∥x∥\|\lambda x\| = |\lambda|\,\|x\|∥λx∥=∣λ∣∥x∥；
  3. ∥x+y∥≤∥x∥+∥y∥\|x + y\| \le \|x\| + \|y\|∥x+y∥≤∥x∥+∥y∥。

带范数的空间叫赋范空间。只满足 2、3（允许非零元素有零范数）叫半范数。

说明

范数比距离多的是线性：它只记住「离原点多远」，距离由平移得到（见「范数诱导的距离」）。所以赋范空间是「有原点、有尺度、平移不变」的度量空间。

⚠️ 半范数不等于范数：商掉零范数子空间才成为范数（LpL^pLp 的构造里「∥f∥p=0\|f\|_p = 0∥f∥p​=0 只说明 f=0f = 0f=0 a.e.」就是这件事，见「LpL^pLp 范数」）。
