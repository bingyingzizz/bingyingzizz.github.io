# Newman's Tauberian lemma　`lem.newman-tauberian`
English entry · root `../`
[in graph](../#n=lem.newman-tauberian)　·　[Chinese page (authoritative)](./lem.newman-tauberian.md)

This is Newman's Tauberian lemma for the prime number theorem; it compresses the analytic core of "$\psi(x)\sim x$" into a single contour estimate, see `thm.prime-number-theorem`.

## Notes · **draft**
**The proof is on the incoming edge of this node** (Cauchy's integral formula + residues + the contour estimate from Cauchy–Goursat); this note records only two remarks on usage.
