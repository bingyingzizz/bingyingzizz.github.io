# An Object Induces a Topos Morphism　`prop.topos-morphism-from-object`
English entry · root `../`
[in graph](../#n=prop.topos-morphism-from-object)　·　[Chinese page (authoritative)](./prop.topos-morphism-from-object.md)

$\widehat{X}^{-1}(T) = T(X)$; for $\widehat{X}_{!}(E)$, when $Y \to X$ exists the value is $E$, and otherwise $\emptyset$; for $\widehat{X}_{*}(E)$, when $X \to Y$ exists the value is $E$, and otherwise $\{0\}$:

$$\widehat{X}^{-1}(T) = T(X), \qquad \bigl(\widehat{X}_{!}(E)\bigr)(Y) \in \{\, E,\ \emptyset\, \}, \qquad \bigl(\widehat{X}_{*}(E)\bigr)(Y) \in \{\, E,\ \{0\}\, \}.$$
