# C(K,E)　`def.ck-space`
$C(K,E)$ 与一致度量
layer 16 · 定义 · $C(K)$ 与 Stone–Weierstrass · 泛函分析
[在星图里打开](../#n=def.ck-space)　·　[节点索引](../index.md)

设 $K$ 紧 Hausdorff，$(E, d)$ 度量。在 $C(K, E)$ 上定义

$$\Delta(f, g) := \sup_{x \in K} d\bigl(f(x), g(x)\bigr) .$$

$E$ 赋范时它就是一致范数 $\|f\| = \sup_x \|f(x)\|$。
