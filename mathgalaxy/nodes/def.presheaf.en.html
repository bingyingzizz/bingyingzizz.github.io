Statement

A **(set-valued) presheaf** on a category C\mathcal{C}C is a functor

T:Cop⟶SetT : \mathcal{C}^{\mathrm{op}} \longrightarrow \mathbf{Set}T:Cop⟶Set

A **morphism** of presheaves is a natural transformation between them. Notation: for a morphism f:Y→Xf : Y \to Xf:Y→X, write f−1=T(f):T(X)→T(Y)f^{-1} = T(f) : T(X) \to T(Y)f−1=T(f):T(X)→T(Y); for s∈T(X)s \in T(X)s∈T(X), write s∣Y=f−1(s)s|_Y = f^{-1}(s)s∣Y​=f−1(s).

Notes

Plainly: **each object is assigned a piece of data, and each morphism is assigned a restriction**. Contravariance is what lets a smaller object receive more data — the further one goes into substructures, the more restrictions there are.

Examples:

  • On a poset: assign to each iii a set TiT_iTi​, and to i≤ji \le ji≤j the restriction Tj→TiT_j \to T_iTj​→Ti​ (dropping antisymmetry, the same works on a preorder).
  • On a topological space: Open⁡(X)\operatorname{Open}(X)Open(X) is the category of open sets (morphisms are inclusions); a presheaf assigns to each open set uuu a set T(u)T(u)T(u), and to u′⊆uu' \subseteq uu′⊆u a restriction T(u)→T(u′)T(u) \to T(u')T(u)→T(u′), s↦s∣u′s \mapsto s|_{u'}s↦s∣u′​.

The presheaf of continuous functions C0C^{0}C0, the presheaf of smooth functions C∞C^{\infty}C∞, the constant presheaf E‾\underline{E}E​ (E‾(u)=E\underline{E}(u) = EE​(u)=E, with restrictions the identity), and the presheaf of constant functions are all examples.

  • Fix X∈CX \in \mathcal{C}X∈C: hX:Y↦Hom⁡C(Y,X)h_{X} : Y \mapsto \operatorname{Hom}_{\mathcal{C}}(Y, X)hX​:Y↦HomC​(Y,X) is a presheaf, called a **representable presheaf**.
