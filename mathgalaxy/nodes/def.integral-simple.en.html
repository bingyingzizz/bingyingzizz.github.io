Notes

This is exactly "area === height of each layer ×\times× measure of each layer" — written in the same shape as a Riemann sum, only intervals are replaced by measurable sets.

One must check well-definedness: the same φ\varphiφ can be written in different standard forms (for instance by splitting some EjE_{j}Ej​ further), but finite additivity of μ\muμ gives the same result.

Convention 0⋅∞=00 \cdot \infty = 00⋅∞=0: this step is crucial — it makes the integral of "the function equal to 0 on a set of infinite measure" equal to 0, as intuition demands.
