陈述

对每个整数 n>1n > 1n>1，存在素数 ppp 使 n<p<2nn < p < 2nn<p<2n。

说明

Bertrand 猜想（1845）由 Чебышёв 证明（1850），所以也叫 Чебышёв 定理；后来 Erdős 在 1932 年给出一个只用二项式系数的漂亮初等证明（他当时 19 岁）。

初等证明的关键仍是 (2nn)\binom{2n}{n}(n2n​)：假设 n<p<2nn < p < 2nn<p<2n 无素数，则 (2nn)\binom{2n}{n}(n2n​) 的所有素因子都 ≤n\le n≤n，再用 vpv_{p}vp​ 的估计与 (2nn)≥4n/(2n+1)\binom{2n}{n} \ge 4^{n}/(2n+1)(n2n​)≥4n/(2n+1) 导出矛盾（中间的常数要靠「小于 2n/32n/32n/3 的素数乘积」估计）。

它是素数分布的第一个区间型结论：π(2n)−π(n)≥1\pi(2n) - \pi(n) \ge 1π(2n)−π(n)≥1。真命题但远弱于素数定理（后者说这个区间里有 ∼n/log⁡n\sim n/\log n∼n/logn 个素数）。

    Bertrand 假设：Чебышёв 估计的区间版

    要证：对 n>1n > 1n>1 存在素数 p∈(n,2n)p \in (n, 2n)p∈(n,2n)。

    反设没有这样的素数。取 N=(2nn)N = \binom{2n}{n}N=(n2n​)，则 NNN 的每个素因子 p≤np \le np≤n（因为 p>2np > 2np>2n 不可能，n<p<2nn < p < 2nn<p<2n 被假设排除，p=2np = 2np=2n 不是素数）。

    把 p≤np \le np≤n 的贡献拆成两段：

    • p≤2np \le \sqrt{2n}p≤2n​：由 vp(N)≤log⁡(2n)/log⁡pv_{p}(N) \le \log(2n)/\log pvp​(N)≤log(2n)/logp 得总贡献 ≤(2n)π(2n)≤(2n)2n\le (2n)^{\pi(\sqrt{2n})} \le (2n)^{\sqrt{2n}}≤(2n)π(2n​)≤(2n)2n​；
    • 2n<p≤2n/3\sqrt{2n} < p \le 2n/32n​<p≤2n/3：这样的 ppp 在 NNN 里最多出现一次（p2>2np^{2} > 2np2>2n），且 p≤2n/3p \le 2n/3p≤2n/3 的素数乘积可以用归纳假设的界估计；
    • 2n/3<p≤n2n/3 < p \le n2n/3<p≤n：若出现，则 p∣Np \mid Np∣N 而 ppp 只出现一次，且 2p>4n/3>n2p > 4n/3 > n2p>4n/3>n 使 (2nn)\binom{2n}{n}(n2n​) 中只有一个这样的因子 —— 这段要单独数。

    三段合起来给出 N≤4n/3⋅(多项式因子)N \le 4^{n/3}\cdot(\text{多项式因子})N≤4n/3⋅(多项式因子)，与 N≥4n/(2n+1)N \ge 4^{n}/(2n+1)N≥4n/(2n+1) 矛盾（对充分大的 nnn）；小 nnn 逐个验证（n=2,3,⋯n = 2,3,\cdotsn=2,3,⋯）。

    ⚠ 这是骨架：第三段的计数是 Erdős 证明里最需要小心的部分。完整证明见华罗庚《数论导引》第九章。
