# Abelian Sheaves Are Abelian Groups in a Topos　`thm.abelian-sheaf-equiv`
English entry · root `../`
[in graph](../#n=thm.abelian-sheaf-equiv)　·　[Chinese page (authoritative)](./thm.abelian-sheaf-equiv.md)

- $\leftarrow$: conversely, given an abelian sheaf $M$, its value at each $X$ automatically carries an abelian group structure, and the group structure in the category of sheaves is determined pointwise by these values (group objects in a presheaf category are pointwise groups) ✓.

The two directions are mutually inverse, since both "take values at every $X$" ✓. ∎
