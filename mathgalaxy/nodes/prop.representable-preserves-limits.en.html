Statement

If F:C→SetF : \mathcal{C} \to \mathbf{Set}F:C→Set is representable, so that F≅Hom⁡C(X,−)F \cong \operatorname{Hom}_{\mathcal{C}}(X, -)F≅HomC​(X,−), then FFF preserves all limits. For any diagram D:I→CD : I \to \mathcal{C}D:I→C (provided lim⁡D\lim DlimD exists), we have

Hom⁡C(X, lim⁡D)  ≅  lim⁡Hom⁡C(X, D(−)).\operatorname{Hom}_{\mathcal{C}}\bigl(X,\ \lim D\bigr) \;\cong\; \lim \operatorname{Hom}_{\mathcal{C}}\bigl(X,\ D(-)\bigr).HomC​(X, limD)≅limHomC​(X, D(−)).

Notes

Now F≅Hom⁡(X,−)F \cong \operatorname{Hom}(X,-)F≅Hom(X,−), and naturally isomorphic functors preserve the same limits, so FFF also preserves all limits.

Immediate consequences

  • The contravariant representable functor Hom⁡(−,X)\operatorname{Hom}(-, X)Hom(−,X) sends colimits to limits, by passing to the opposite category.
  • The fact that Hom⁡(X,−)\operatorname{Hom}(X, -)Hom(X,−) preserves finite limits means that XXX is compatible with all finite limits in this sense.

A functor is left exact if it preserves all finite limits. It is right exact if it preserves all finite colimits, and exact if it does both.
