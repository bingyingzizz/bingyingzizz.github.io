# adjoint operator　`def.operator-adjoint`
English entry · root `../`
[in graph](../#n=def.operator-adjoint)　·　[Chinese page (authoritative)](./def.operator-adjoint.md)

Properties: $(T + S)^{\ast} = T^{\ast} + S^{\ast}$, $(cT)^{\ast} = \bar{c}\,T^{\ast}$, $(TS)^{\ast} = S^{\ast}T^{\ast}$, $T^{\ast\ast} = T$.

⚠️ This is not the same as an **adjoint functor** in category theory: that is a relation between two functors, whereas here we have an operator on the same space.

## Notes · **draft**
⭐ The way it is defined is worth noting: $T^{\ast}$ is not constructed but **uniquely determined by an identity** (existence comes from Riesz representation: $w \mapsto \langle T\cdot, w\rangle$ is a bounded linear functional on $V$).
