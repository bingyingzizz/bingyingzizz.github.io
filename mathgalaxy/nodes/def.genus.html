def.genus · 定义 · 拓扑 · 曲面 · 同调

又称亏格·genus·洞的个数

陈述

设 MMM 是闭的（紧、无边界）可定向曲面。定义它的亏格为

g(M):=12rank⁡ZH1(M;Z).g(M) := \tfrac{1}{2} \operatorname{rank}_{\mathbb{Z}} H_{1}(M; \mathbb{Z}).g(M):=21​rankZ​H1​(M;Z).

即一阶整同调的自由秩的一半。

说明

⭐ 为什么除以 2：闭可定向曲面的 H1H_{1}H1​ 是自由阿贝尔群，且

H1(M;Z)≅Z2g,H_{1}(M; \mathbb{Z}) \cong \mathbb{Z}^{2g},H1​(M;Z)≅Z2g,

所以 rank 是 2g2g2g。环面是第一个例子：H1(T2)≅Z2H_{1}(T^{2}) \cong \mathbb{Z}^{2}H1​(T2)≅Z2，rank = 2，而亏格是 1。若直接把亏格定义成 rank，环面就成了「亏格 2」，连带 χ=2−2g\chi = 2 - 2gχ=2−2g 也会算错（环面 χ=0\chi = 0χ=0）。除以 2 才是那个「洞的个数」。

⭐ 为什么不用「环柄个数」或「χ=2−2g\chi = 2-2gχ=2−2g」来定义：那两条都要先有分类定理（每个闭可定向曲面都是若干环面的连通和），而分类定理本身要用 ggg —— 会成环。同调定义不依赖分类，所以它是这一层唯一干净的选择。

⭐ 由定义立刻能算的三个值：球面 g=0g = 0g=0（H1=0H_{1} = 0H1​=0）；环面 g=1g = 1g=1；ggg 个环面的连通和满足 g(M#N)=g(M)+g(N)g(M \# N) = g(M) + g(N)g(M#N)=g(M)+g(N)（连通和的 H1H_{1}H1​ 是两个加项直和的那一部分）。⚠ 最后这条是定理（要 Mayer–Vietoris），本图还没写成节点。

⚠ 这个定义只对闭可定向曲面上班：带边界的曲面要看相对同调或先补洞；不可定向的情形 H1H_{1}H1​ 有挠部（射影平面 H1≅Z/2H_{1} \cong \mathbb{Z}/2H1​≅Z/2），「亏格」得换成别的量（不可定向亏格 kkk，χ=2−k\chi = 2 - kχ=2−k）。

📌 与 Euler 示性数的关系 χ(M)=2−2g(M)\chi(M) = 2 - 2g(M)χ(M)=2−2g(M) 也是定理（下一刀），这里只记一句。

    两个「亏格」：可定向的 ggg 与不可定向的 kkk

    同一个中文词、两套数法（这正是这条命题存在的理由）：

    • 可定向侧：g=12rank⁡H1g = \tfrac{1}{2}\operatorname{rank} H_{1}g=21​rankH1​，χ=2−2g\chi = 2 - 2gχ=2−2g；

    ⚠ 斜率不同（−2-2−2 vs −1-1−1），所以同一个 χ\chiχ 在两族里不是同一个曲面：χ=0\chi = 0χ=0 既可能是环面（g=1g=1g=1）也可能是克莱因瓶（k=2k=2k=2）。
