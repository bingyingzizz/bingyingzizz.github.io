# Fiber Metric on a Vector Bundle　`prop.bundle-metric`
English entry · root `../`
[in graph](../#n=prop.bundle-metric)　·　[Chinese page (authoritative)](./prop.bundle-metric.md)

Let $\pi : E \to M$ be a smooth vector bundle of rank $k$. A **fibre metric** is an inner product on each fibre $E_{p}$, namely $\langle\cdot,\cdot\rangle_{p}$, such that for any two smooth sections $s, t \in \Gamma(E)$ the function

$$p \longmapsto \langle s(p), t(p)\rangle_{p}$$

is smooth. Then **every smooth vector bundle admits a fibre metric**.

Special case: for $E = TM$ a fibre metric is a Riemannian metric (`def.riemannian-metric`); for a line bundle $E$ it is a "everywhere positive-definite symmetric bilinear form".
