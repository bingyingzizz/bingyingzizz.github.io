Statement

Let ⪯\preceq⪯ be a binary relation on a set AAA. Then ⪯\preceq⪯ is a partial order on AAA if and only if:

  • Reflexive: ∀x∈A,x⪯x\forall x \in A, x \preceq x∀x∈A,x⪯x;
  • Antisymmetric: ∀x,y∈A(x⪯y∧y⪯x→x=y)\forall x, y \in A ( x \preceq y \wedge y \preceq x \to x = y )∀x,y∈A(x⪯y∧y⪯x→x=y);
  • Transitive: ∀x,y,z∈A(x⪯y∧y⪯z→x⪯z)\forall x, y, z \in A ( x \preceq y \wedge y \preceq z \to x \preceq z )∀x,y,z∈A(x⪯y∧y⪯z→x⪯z).

If in addition comparability ∀x,y∈A(x⪯y∨y⪯x)\forall x, y \in A ( x \preceq y \vee y \preceq x )∀x,y∈A(x⪯y∨y⪯x) holds, then ⪯\preceq⪯ is called a total order (linear order) on AAA, and (A,⪯)(A, \preceq )(A,⪯) is called a totally ordered set.

Call (A,⪯)(A, \preceq )(A,⪯) a partially ordered set (poset). Define the strict order from ⪯\preceq⪯ by: x≺y:  ⟺  x⪯y∧x≠yx \prec y :\iff x \preceq y \wedge x \ne yx≺y:⟺x⪯y∧x=y

Notes

Standard examples: ⟨P(S),⊆⟩\langle \mathcal{P}(S), \subseteq \rangle⟨P(S),⊆⟩ is a poset but not totally ordered; ⟨R,≤⟩\langle \mathbb{R}, \le \rangle⟨R,≤⟩ is totally ordered.

Antisymmetry says that the only way two elements can be mutually ≤\le≤ is by being equal, so a partial order can be seen as an abstraction of ≤\le≤.

Assumptions used in each direction (axiomatic definition and passage to the strict order):

  • A relation is a partial order   ⟺  \iff⟺ it satisfies reflexivity, antisymmetry and transitivity simultaneously, and a relation is a total order   ⟺  \iff⟺ it is a partial order plus comparability; both are unfoldings of the definition and need no axiom of choice.
  • Partial order   ⟹  \implies⟹ strict order: let x≺yx\prec yx≺y mean x⪯yx\preceq yx⪯y and x≠yx\ne yx=y; irreflexivity and transitivity follow; conversely, taking the reflexive closure of an irreflexive transitive relation yields a partial order, a finite-step logical deduction.
  • Antisymmetry cannot be dropped: the universal relation on a two-point set is reflexive and transitive but not a partial order; comparability is not automatic either — ordered by inclusion, the power set of a two-element set has two incomparable singletons.
  • Extending a partial order to a total order is a separate theorem, usually proved from the order extension principle; the definition of a total order here does not assert that such an extension exists, and its existence must not be counted as part of the definition.
