在做什么：沿曲线架一副跟着转的正交标架，把「弯」与「扭」各压缩成一个数 —— 这是曲线的活动标架法。

设 γ\gammaγ 是弧长参数化的 C3C^{3}C3 正则曲线，T:=γ′T := \gamma'T:=γ′。曲率定义为

κ(s):=∥T′(s)∥≥0.\kappa(s) := \lVert T'(s)\rVert \ge 0 .κ(s):=∥T′(s)∥≥0.

在 κ(s)>0\kappa(s)>0κ(s)>0 处定义主法向与副法向

N:=T′κ,B:=T×N,N := \frac{T'}{\kappa},\qquad B := T\times N ,N:=κT′​,B:=T×N,

三者两两正交且都是单位向量，(T,N,B)(T,N,B)(T,N,B) 叫 Frenet 标架（曲线的活动标架）。挠率定义为

τ(s):=−⟨B′(s),N(s)⟩.\tau(s) := -\langle B'(s),N(s)\rangle .τ(s):=−⟨B′(s),N(s)⟩.

(T,N)(T,N)(T,N) 张成的平面叫密切平面（BBB 是它的法向）：κ\kappaκ 量「切线转得多快」，τ\tauτ 量「曲线离开密切平面多快」。

说明

量纲与例子：κ\kappaκ 的量纲是长度的倒数。直线 κ=0\kappa = 0κ=0；半径 RRR 的圆 κ=1/R\kappa = 1/Rκ=1/R、τ=0\tau = 0τ=0；圆柱螺旋线的 κ\kappaκ 与 τ\tauτ 都是非零常数。

κ=0\kappa = 0κ=0 处定义不出来：NNN 要靠 T′T'T′ 定向，直线段上 TTT 是常向量。所以 Frenet 标架只在 κ>0\kappa>0κ>0 的区间上存在，跨过拐点时会跳 —— 这也解释了为什么曲线基本定理要假设 κ>0\kappa>0κ>0。

任意参数下的公式（链式法则直接算）：κ=∥γ′×γ′′∥/∥γ′∥3\kappa = \lVert\gamma'\times\gamma''\rVert/\lVert\gamma'\rVert^{3}κ=∥γ′×γ′′∥/∥γ′∥3，τ=⟨γ′×γ′′,γ′′′⟩/∥γ′×γ′′∥2\tau = \langle\gamma'\times\gamma'',\gamma'''\rangle/\lVert\gamma'\times\gamma''\rVert^{2}τ=⟨γ′×γ′′,γ′′′⟩/∥γ′×γ′′∥2（后者在 κ>0\kappa>0κ>0 处）。它们说明 κ,τ\kappa,\tauκ,τ 只依赖像集与定向。

符号约定：本图取 τ=−⟨B′,N⟩\tau = -\langle B',N\rangleτ=−⟨B′,N⟩，于是 Frenet 公式是 N′=−κT+τBN' = -\kappa T+\tau BN′=−κT+τB、B′=−τNB' = -\tau NB′=−τN（thm.frenet-serret）。若某本书取 τ=⟨B′,N⟩\tau = \langle B',N\rangleτ=⟨B′,N⟩，它的挠率与本图差一个符号 —— 抄公式前先对齐。

与曲面的活动标架同源：曲面用 (e1,e2,e3)(e_{1},e_{2},e_{3})(e1​,e2​,e3​)，曲线用 (T,N,B)(T,N,B)(T,N,B)，都是「沿参数走、标架随地转」；联络形式那一套（def.connection-form）在曲线情形退化成 ±κ ds\pm\kappa\,\mathrm{d}s±κds 与 ±τ ds\pm\tau\,\mathrm{d}s±τds。
