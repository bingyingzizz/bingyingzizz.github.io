# Bézout identity　`thm.bezout`
English entry · root `../`
[in graph](../#n=thm.bezout)　·　[Chinese page (authoritative)](./thm.bezout.md)

This is the only tool for solving the linear congruence $ax \equiv b \pmod n$: it has a solution $\iff$ $\gcd(a, n) \mid b$, and the solution set is one residue class modulo $n / \gcd(a, n)$.

$\mathbb{Z}[x]$ has no Bézout identity ($\gcd(2, x) = 1$, yet $2u + xv = 1$ has no solution), so "Bézout domain" is a separate name.
