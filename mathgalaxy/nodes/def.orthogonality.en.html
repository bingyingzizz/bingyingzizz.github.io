def.orthogonality

Machine-drafted and pending author review. The Chinese text is authoritative.

Statement

Let VVV be an inner product space.

  • u⊥vu \perp vu⊥v (one says uuu and vvv are orthogonal)   ⟺  ⟨u,v⟩=0\iff \langle u, v \rangle = 0⟺⟨u,v⟩=0;
  • S⊥TS \perp TS⊥T: every vector of SSS is orthogonal to every vector of TTT;
  • {v1,…,vk}\{v_1, \ldots, v_k\}{v1​,…,vk​} is called an orthonormal set exactly when ⟨vi,vj⟩=δij\langle v_i, v_j \rangle = \delta_{ij}⟨vi​,vj​⟩=δij​;
  • {vi}\{v_i\}{vi​} is an orthonormal basis exactly when it is both a basis and an orthonormal set.

Pythagoras' theorem: u⊥v  ⟹  ∥u+v∥2=∥u∥2+∥v∥2u \perp v \implies \|u + v\|^{2} = \|u\|^{2} + \|v\|^{2}u⊥v⟹∥u+v∥2=∥u∥2+∥v∥2.

Notes

⭐ The great advantage of an orthonormal basis is that the coordinates are inner products: if (e1,…,en)(e_1, \ldots, e_n)(e1​,…,en​) is orthonormal, then

v=∑i=1n⟨ei,v⟩ ei,∥v∥2=∑i=1n∣⟨ei,v⟩∣2v = \sum_{i=1}^{n} \langle e_i, v \rangle\, e_i, \qquad \|v\|^{2} = \sum_{i=1}^{n} |\langle e_i, v \rangle|^{2}v=i=1∑n​⟨ei​,v⟩ei​,∥v∥2=i=1∑n​∣⟨ei​,v⟩∣2

(the second identity is Parseval's identity.) For a general basis one must solve a linear system to find coordinates; for an orthonormal basis it suffices to compute nnn inner products — this is why Gram–Schmidt is worth the trouble.

⚠ An orthonormal set differs from an orthonormal "basis": the former requires only orthonormality, not spanning the whole space.

Which of the four items is a definition and which needs a property (this group looks like it consists entirely of "definitions", but in fact only the first is one):

  • u⊥v  ⟺  ⟨u,v⟩=0u \perp v \iff \langle u,v\rangle = 0u⊥v⟺⟨u,v⟩=0: this is a definition, with no content.
  • S⊥TS \perp TS⊥T: also a definition (pairwise orthogonality).
  • Orthonormal set   ⟺  \iff⟺ ⟨vi,vj⟩=δij\langle v_{i},v_{j}\rangle = \delta_{ij}⟨vi​,vj​⟩=δij​: still a definition, but note that it includes the case i=ji = ji=j, that is, every vector has unit length; saying only "pairwise orthogonal" is not enough (that is an orthogonal set, whose lengths may differ from 111).
  • Orthonormal basis   ⟺  \iff⟺ basis +++ orthonormal set: this item uses a nontrivial fact — an orthonormal set is automatically linearly independent (taking the inner product of ∑civi=0\sum c_{i}v_{i} = 0∑ci​vi​=0 with vjv_{j}vj​ gives cj=0c_{j} = 0cj​=0), so "orthonormal set + spanning" is indeed "basis + orthonormal". If one requires only "basis" and "pairwise orthogonal", one must additionally assume that there is no zero vector.

The hypothesis of Pythagoras' theorem: u⊥vu \perp vu⊥v suffices (no finite dimension, no completeness): ∥u+v∥2=∥u∥2+2Re⁡⟨u,v⟩+∥v∥2\lVert u+v\rVert^{2} = \lVert u\rVert^{2} + 2\operatorname{Re}\langle u,v\rangle + \lVert v\rVert^{2}∥u+v∥2=∥u∥2+2Re⟨u,v⟩+∥v∥2, and in the real case ⟨u,v⟩=0\langle u,v\rangle = 0⟨u,v⟩=0 can simply be cancelled; the complex case needs Re⁡⟨u,v⟩=0\operatorname{Re}\langle u,v\rangle = 0Re⟨u,v⟩=0 (in general ⟨u,v⟩\langle u,v\rangle⟨u,v⟩ is a complex number, and orthogonality only says that its real part vanishes — orthogonality itself is defined by ⟨u,v⟩=0\langle u,v\rangle = 0⟨u,v⟩=0, so there is no problem, but in the proof one cannot simply throw one term away).

⚠️ Two pairs of words that are easily confused: an orthogonal set (pairwise orthogonal, arbitrary lengths) versus an orthonormal set (additionally unit length); the orthogonal complement S⊥S^{\perp}S⊥ is "the vectors orthogonal to all of SSS"; it is a subspace and S∩S⊥={0}S \cap S^{\perp} = \{0\}S∩S⊥={0} (for a positive definite inner product), but for a general bilinear form this can fail (def.isotropic-subspace).
