# Implicit Function Theorem　`thm.implicit-function`

[in graph](../#n=thm.implicit-function)　·　[Chinese page (authoritative)](./thm.implicit-function.md)

That is the entire content of the name "implicit function" — it turns "implicitly determined by an equation" into "a function really exists".

⭐ It is the **inverse function theorem in disguise**: assemble $F$ into $\Phi(x, y) := (x, F(x, y))$; then $D\Phi$ is block upper triangular, $\det D\Phi = \det D_y F$, so invertibility is equivalent;

and the inverse of $\Phi$ must have the form $(x, y) \mapsto (x, h(x, y))$; setting $g(x) := h(x, 0)$ gives the desired implicit function.

The two theorems are two ways of saying the same thing.
