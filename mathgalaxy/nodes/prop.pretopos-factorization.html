陈述

设 C\mathcal{C}C 是预拓扑斯。则

  1. C\mathcal{C}C 是平衡的：既单又满的态射一定是同构；
  2. 每个态射都是严格的：im⁡f≅coim⁡f\operatorname{im} f \cong \operatorname{coim} fimf≅coimf；
  3. 每个态射都有唯一的满-单分解
f:X↠X‾↣Y,X‾:=X/R,R:=X×YXf : X \twoheadrightarrow \overline{X} \rightarrowtail Y, \qquad \overline{X} := X / R,\quad R := X \times_{Y} Xf:X↠X↣Y,X:=X/R,R:=X×Y​X

说明

这三条在 Set\mathbf{Set}Set 里都理所当然，但在一般范畴里都要证。它们合起来说：「预拓扑斯里的像 = 商」，与集合里「像就是按核对取商」完全一致。证明见边上那条推导。

    预拓扑斯   ⟹  \implies⟹ 满-单分解

    设 f:X→Yf : X \to Yf:X→Y。取核对 R:=X×YXR := X \times_{Y} XR:=X×Y​X，它是 XXX 上的等价关系。由预拓扑斯第 3 条，等价关系有效，所以可以取商

    X‾:=X/R=coker⁡(R⇉X)\overline{X} := X/R = \operatorname{coker}(R \rightrightarrows X)X:=X/R=coker(R⇉X)

    两条投影在 fff 下相等，故 fff 穿过商，得到分解

    f:X↠X‾→ l Yf : X \twoheadrightarrow \overline{X} \xrightarrow{\ l\ } Yf:X↠X l ​Y

    lll 是单态射。 设 g,h:Z→X‾g, h : Z \to \overline{X}g,h:Z→X 且 l∘g=l∘hl \circ g = l \circ hl∘g=l∘h。因为 X‾=X/R\overline{X} = X/RX=X/R，把 g,hg, hg,h 与商映射 π\piπ 一起拉回：考虑 VVV 使方块

    V⟶Z↓(g0,h0)↓(g,h)X×XX→ π×π X‾×X‾\begin{array}{ccc} V & \longrightarrow & Z \\ \downarrow\scriptstyle{(g_0,h_0)} & & \downarrow\scriptstyle{(g,h)} \\ X \times_{X} X & \xrightarrow{\ \pi \times \pi\ } & \overline{X} \times \overline{X} \end{array}V↓(g0​,h0​)X×X​X​⟶ π×π ​​Z↓(g,h)X×X​

    笛卡尔。由 l∘g=l∘hl \circ g = l \circ hl∘g=l∘h 得 l∘π∘g0=l∘π∘h0l \circ \pi \circ g_{0} = l \circ \pi \circ h_{0}l∘π∘g0​=l∘π∘h0​，即 f∘g0=f∘h0f \circ g_{0} = f \circ h_{0}f∘g0​=f∘h0​。于是 (g0,h0)(g_{0}, h_{0})(g0​,h0​) 的像整个落在 R=X×YXR = X \times_{Y} XR=X×Y​X 里 —— 换句话说 (g0,h0)(g_{0}, h_{0})(g0​,h0​) 穿过 RRR。

    再由 X‾=coker⁡(R⇉X)\overline{X} = \operatorname{coker}(R \rightrightarrows X)X=coker(R⇉X) 的泛性质（两条投影的余等化子），π∘g0=π∘h0\pi \circ g_{0} = \pi \circ h_{0}π∘g0​=π∘h0​，于是 g=hg = hg=h。所以 lll 是单态射。

    唯一性。 若 f=X→ π′ X′→ l′ Yf = X \xrightarrow{\ \pi'\ } X' \xrightarrow{\ l'\ } Yf=X π′ ​X′ l′ ​Y 是另一个满-单分解，则由 l′l'l′ 是单态射得 R=X×X′XR = X \times_{X'} XR=X×X′​X。记 π′\pi'π′ 为满态射，由第 4 条它是正则的，即 π′=coker⁡(X×X′X⇉X)\pi' = \operatorname{coker}(X \times_{X'} X \rightrightarrows X)π′=coker(X×X′​X⇉X)；把 X×X′X=RX \times_{X'} X = RX×X′​X=R 代进去得 π′\pi'π′ 与 π\piπ 是同一个余等化子。于是存在互逆的 X‾⇄X′\overline{X} \rightleftarrows X'X⇄X′，X′≅X‾X' \cong \overline{X}X′≅X。∎

    平衡性。 若 fff 既满又单，则 R=X×YX≅XR = X \times_{Y} X \cong XR=X×Y​X≅X（单态射的等价刻画），故 X‾≅X\overline{X} \cong XX≅X，f≅lf \cong lf≅l 是单态射；又 fff 已是单态射，故 fff 是同构。∎

    严格性。 上面的分解把 im⁡f\operatorname{im} fimf 与 coim⁡f\operatorname{coim} fcoimf 都算成了 X‾\overline{X}X，所以它们同构。∎

    整条证明只用了一个构造「取核对再取商」和一组事实「等价关系有效 + 满态射正则」。这正是预拓扑斯那四条公理想换来的东西。
