# 非局部紧情形的 RHom　`ex.nonlc-rhom`

- $\operatorname{RHom}_{\mathbb{Z}}(\mathbb{R}^{I}, \mathbb{Z}) = 0$；
- $\operatorname{RHom}_{\mathbb{Z}}(\mathbb{Z}^{I}, \mathbb{Z}) = \mathbb{Z} \cdot I$，集中在 0 次。
