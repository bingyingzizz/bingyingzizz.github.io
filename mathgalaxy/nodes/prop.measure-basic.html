说明

(a)：把 FFF 拆成 F=E∪(F∖E)F = E \cup (F \setminus E)F=E∪(F∖E) 用可数可加（把余下的位置补 ∅\emptyset∅）。

(b)：把 ⋃Ej\bigcup E_{j}⋃Ej​ 改成不交并：Fj=Ej∖(E1∪⋯∪E{j−1})F_{j} = E_{j} \setminus (E_{1} \cup \cdots \cup E_\{j-1\})Fj​=Ej​∖(E1​∪⋯∪E{​j−1})，则 μ(⋃Ej)=∑μ(Fj)≤∑μ(Ej)\mu (\bigcup E_{j}) = \sum \mu (F_{j}) \le \sum \mu (E_{j})μ(⋃Ej​)=∑μ(Fj​)≤∑μ(Ej​)。

(c)：令 Aj=Ej∖E{j−1}A_{j} = E_{j} \setminus E_\{j-1\}Aj​=Ej​∖E{​j−1}（E0=∅E_{0} = \emptysetE0​=∅），则 ⋃Ej\bigcup E_{j}⋃Ej​ 是 AjA_{j}Aj​ 的不交并，而 μ(En)=∑{j≤n}μ(Aj)\mu (E_{n}) = \sum _\{j\le n\} \mu (A_{j})μ(En​)=∑{​j≤n}μ(Aj​) —— 两边取极限即可。

(d)：「μ(E1)<∞\mu (E_{1}) < \inftyμ(E1​)<∞」不能省。 反例：X=NX = \mathbb{N}X=N，μ=\mu =μ= 计数测度，Ej={j,j+1E_{j} = \{j, j+1Ej​={j,j+1 …}，则每个 μ(Ej)=∞\mu (E_{j}) = \inftyμ(Ej​)=∞ 但交集为 ∅\emptyset∅、μ(∅)=0\mu (\emptyset ) = 0μ(∅)=0。

(c) 与 (d) 合起来说明：测度在集合的单调极限下连续 —— 这正与「单调类」这个词呼应。

    测度   ⟹  \implies⟹ 单调 / 次可加 / 上下连续

    设 μ\muμ 是测度。

    (a) 单调。 设 E⊆FE \subseteq FE⊆F。则 F=E∪(F∖E)F = E \cup (F \setminus E)F=E∪(F∖E)，两项不交，故 μ(F)=μ(E)+μ(F∖E)≥μ(E)\mu (F) = \mu (E) + \mu (F \setminus E) \ge \mu (E)μ(F)=μ(E)+μ(F∖E)≥μ(E)（取值非负）。

    (b) 次可加。 令 Fj=Ej∖(E1∪⋯∪E{j−1})F_{j} = E_{j} \setminus (E_{1} \cup \cdots \cup E_\{j-1\})Fj​=Ej​∖(E1​∪⋯∪E{​j−1})，则 FjF_{j}Fj​ 两两不交、⋃Fj=⋃Ej\bigcup F_{j} = \bigcup E_{j}⋃Fj​=⋃Ej​ 且 Fj⊆EjF_{j} \subseteq E_{j}Fj​⊆Ej​。由可数可加与 (a)，

    μ(⋃jEj)=μ(⋃jFj)=∑jμ(Fj)≤∑jμ(Ej)\mu(\bigcup_j E_j) = \mu(\bigcup_j F_j) = \sum_j \mu(F_j) \le \sum_j \mu(E_j)μ(j⋃​Ej​)=μ(j⋃​Fj​)=j∑​μ(Fj​)≤j∑​μ(Ej​)

    (c) 下连续。 设 E1⊆E2⊆⋯E_{1} \subseteq E_{2} \subseteq \cdotsE1​⊆E2​⊆⋯。令 A1=E1A_{1} = E_{1}A1​=E1​，Aj=Ej∖E{j−1}A_{j} = E_{j} \setminus E_\{j-1\}Aj​=Ej​∖E{​j−1}（j≥2j \ge 2j≥2），则 AjA_{j}Aj​ 两两不交且 ⋃Aj=⋃Ej\bigcup A_{j} = \bigcup E_{j}⋃Aj​=⋃Ej​。由可数可加，

    μ(⋃jEj)=∑jμ(Aj)=lim⁡n→∞∑j=1nμ(Aj)=lim⁡n→∞μ(En)\mu(\bigcup_j E_j) = \sum_j \mu(A_j) = \lim_{n\to\infty} \sum_{j=1}^{n} \mu(A_j) = \lim_{n\to\infty} \mu(E_n)μ(j⋃​Ej​)=j∑​μ(Aj​)=n→∞lim​j=1∑n​μ(Aj​)=n→∞lim​μ(En​)

    (d) 上连续。 设 E1⊇E2⊇⋯E_{1} \supseteq E_{2} \supseteq \cdotsE1​⊇E2​⊇⋯ 且 μ(E1)<∞\mu (E_{1}) < \inftyμ(E1​)<∞。令 Fj=E1∖EjF_{j} = E_{1} \setminus E_{j}Fj​=E1​∖Ej​，则 F1⊆F2⊆⋯F_{1} \subseteq F_{2} \subseteq \cdotsF1​⊆F2​⊆⋯ 且 ⋃Fj=E1∖⋂Ej\bigcup F_{j} = E_{1} \setminus \bigcap E_{j}⋃Fj​=E1​∖⋂Ej​。由 (c) 与 (a)，

    μ(E1)−μ(⋂jEj)=μ(E1∖⋂jEj)=lim⁡jμ(Fj)=lim⁡j(μ(E1)−μ(Ej))\mu(E_1) - \mu(\bigcap_j E_j) = \mu(E_1 \setminus \bigcap_j E_j) = \lim_j \mu(F_j) = \lim_j ( \mu(E_1) - \mu(E_j) )μ(E1​)−μ(j⋂​Ej​)=μ(E1​∖j⋂​Ej​)=jlim​μ(Fj​)=jlim​(μ(E1​)−μ(Ej​))

    因为 μ(E1)<∞\mu (E_{1}) < \inftyμ(E1​)<∞ 是个有限数，可以从两边同时减掉，得 μ(⋂Ej)=lim⁡μ(Ej)\mu (\bigcap E_{j}) = \lim \mu (E_{j})μ(⋂Ej​)=limμ(Ej​)。∎
