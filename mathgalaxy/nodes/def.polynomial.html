设 KKK 是域。KKK 上的一个一元多项式是形式表达式

f=a0+a1x+a2x2+⋯+anxn,ai∈Kf = a_0 + a_1 x + a_2 x^{2} + \cdots + a_n x^{n}, \qquad a_i \in Kf=a0​+a1​x+a2​x2+⋯+an​xn,ai​∈K

（只有有限多项系数非零）；xxx 叫未定元，aia_iai​ 叫系数。

若最高次非零系数是 an≠0a_n \ne 0an​=0，称 fff 的次数为 nnn，记 deg⁡f:=n\deg f := ndegf:=n。规定零多项式没有次数（或记 deg⁡0:=−∞\deg 0 := -\inftydeg0:=−∞），非零常数多项式的次数为 000。ana_nan​ 叫首项系数；an=1a_n = 1an​=1 时称 fff 是首一的。

两个多项式相等当且仅当各次系数全相等 —— 「多项式」与「多项式函数」是两件事（见注释）。

说明

⚠ 多项式 ≠\ne= 多项式函数：在 F2\mathbb{F}_2F2​ 上，x2+xx^{2} + xx2+x 与 000 作为函数处处相等（0,10, 10,1 代进去都得 000），但作为多项式不同（系数不同）。本图的「多项式」一律指形式对象（系数序列）。

⭐ 去掉「有限项」这个词就得到形式幂级数 K[[x]]K[[x]]K[[x]] —— 那是另一门学问（生成函数、形式群）。

⭐ 次数是这套理论的「尺子」：带余除法、根的个数、不可约性，全部按次数说话。
