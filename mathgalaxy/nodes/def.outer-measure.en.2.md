## Abstract · **reviewed**
An outer measure on a non-empty set $X$ is a function $\mu^* : \mathcal{P}(X) \to [0, +\infty]$ with $\mu^*(\emptyset) = 0$ that is monotone and countably subadditive. It is defined on every subset, and the price is exactly that subadditivity: it is not a measure. Carathéodory's idea is to single out the sets on which $\mu^*$ is additive, and there it becomes a genuine measure. Lebesgue's original construction, $\mu^*(A) = \inf \sum (b_n - a_n)$ over countable interval covers, is the prototypical example.
