Statement

An algebraic extension K/FK/FK/F is separable if for every α∈K\alpha \in Kα∈K the minimal polynomial mαm_{\alpha}mα​ has no repeated roots in KKK (equivalently: mαm_{\alpha}mα​ and its formal derivative mα′m_{\alpha}'mα′​ are coprime).

Over a field of characteristic 0 every algebraic extension is automatically separable.

Notes

⭐ Why characteristic 0 is automatic: if the irreducible mmm shared a factor with m′m'm′, then, since deg⁡m′<deg⁡m\deg m' < \deg mdegm′<degm, that factor would have to be m′=0m' = 0m′=0; but in characteristic 0 the derivative m′=0m' = 0m′=0 can only be zero, contradicting the irreducibility of mmm. Real trouble appears only in characteristic ppp: xp−tx^{p} - txp−t is irreducible over Fp(t)\mathbb{F}_{p}(t)Fp​(t), yet xp−t=(x−tp)px^{p} - t = (x - \sqrt[p]{t})^{p}xp−t=(x−pt​)p in the splitting field — one root, with multiplicity ppp. This is an inseparable extension.

⭐ Why Galois theory needs separability: the correspondence counts automorphisms, and an automorphism can only send a root to a different root. With repeated roots there are too few roots, so ∣Gal⁡∣|\operatorname{Gal}|∣Gal∣ drops below [K:F][K:F][K:F] and the correspondence fails.

⚠ Hence the standard definition of Galois extension is finite + normal + separable; in characteristic 0 the third condition is automatic and is often quietly dropped — dropped under the characteristic 0 hypothesis, not in general.
