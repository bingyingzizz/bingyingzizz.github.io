# spectral sequence　`def.spectral-sequence`
English entry · root `../`
[in graph](../#n=def.spectral-sequence)　·　[Chinese page (authoritative)](./def.spectral-sequence.md)

Hence on each $H^{n}$ there is a chain $H^{n} \supseteq \cdots \supseteq F^{p}H^{n} \supseteq F^{p+1}H^{n} \supseteq \cdots \supseteq 0$.

A spectral sequence says: **for sufficiently large $r$, the page $E_{r}$ stabilizes and equals exactly the associated graded pieces of this filtration**. So it is a tool for "approximating homology layer by layer from a filtered complex" — when computing $H^{n}$ directly is too hard, break $H^{n}$ into easily computable pieces.
