# Čech Cohomology Equals Sheaf Cohomology on Paracompact Spaces　`thm.paracompact-cech-equals-sheaf`
English entry · root `../`
[in graph](../#n=thm.paracompact-cech-equals-sheaf)　·　[Chinese page (authoritative)](./thm.paracompact-cech-equals-sheaf.md)

⭐ **Relation to the compact Hausdorff result**: Every compact Hausdorff space is paracompact, so this result includes `prop.chaus-cech-eq-h`. The **proofs** use different arguments. The compactness proof uses the cofinality of finite covers in the filtered system and the control of finite products by representable objects. The paracompactness proof uses local finiteness and the softness obtained from partitions of unity. The two arguments establish the same conclusion independently.
