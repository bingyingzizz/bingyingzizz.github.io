# Euler 示性数与亏格　`prop.eulerchar-genus`
闭可定向曲面：$\chi = 2 - 2g$
layer 25 · 命题 · 曲面的地形 · 拓扑学
[在星图里打开](../#n=prop.eulerchar-genus)　·　[节点索引](../index.md)

设 $S$ 是**闭可定向曲面**，亏格 $g = \tfrac{1}{2}\operatorname{rank} H_{1}(S;\mathbb{Z})$（`def.genus`）。则

$$\chi(S) = 2 - 2g .$$

于是 $\chi$ 与 $g$ 互相决定：$g = (2 - \chi)/2$。
