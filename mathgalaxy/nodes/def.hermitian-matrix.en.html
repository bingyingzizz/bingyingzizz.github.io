Statement

What it does: writes "self-adjoint" as a matrix condition. In the complex case it is called Hermitian, in the real case symmetric. Their hallmarks are: all eigenvalues real, and orthogonally diagonalizable.

Let A∈Mn(C)A \in M_{n}(\mathbb{C})A∈Mn​(C). Call AAA a Hermitian matrix (self-adjoint matrix) if

A∗=A.A^{*} = A .A∗=A.

A real square matrix satisfying AT=AA^{T} = AAT=A is called a symmetric matrix.

Key properties: (i) the diagonal entries are all real; (ii) the eigenvalues are all real; (iii) eigenvectors belonging to distinct eigenvalues are mutually orthogonal; (iv) there exists a unitary matrix UUU such that U∗AUU^{*}AUU∗AU is a real diagonal matrix (thm.spectral-matrix).

A real symmetric matrix is the special case of a Hermitian matrix where AAA takes real values; in that case (iv) can be written as QTAQQ^{T}AQQTAQ is diagonal, with QQQ orthogonal.
