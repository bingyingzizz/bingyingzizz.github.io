# Injective Dimension　`def.injective-dimension`
English entry · root `../`
[in graph](../#n=def.injective-dimension)　·　[Chinese page (authoritative)](./def.injective-dimension.md)

in which each $I^{k}$ is injective. The **injective dimension** of $M$, denoted $\operatorname{id}_{R} M$, is the least $n$ for which this holds (or $\infty$ if no such integer exists).

**Duality (note the precise formula)**: $\operatorname{id}_{R} M = \operatorname{fd}_{R^{\mathrm{op}}} \operatorname{Hom}_{\mathbb{Z}}(M,\, \mathbb{Q}/\mathbb{Z})$. This is the flat dimension on the **corresponding side** after taking the character dual (for fd, see `def.flat-dimension`).
