# Inverse Function Theorem　`thm.inverse-function`
English entry · root `../`
[in graph](../#n=thm.inverse-function)　·　[Chinese page (authoritative)](./thm.inverse-function.md)

For $f(x, y) = (e^{x}\cos y,\ e^{x}\sin y)$, $\det Df = e^{2x} \ne 0$ holds everywhere, yet $f$ is far from injective globally ($y$ has period $2\pi$).

⚠ The theorem guarantees only $C^{1}$;

but from $Dg = (Df \circ g)^{-1}$ it follows at once: $f$ smooth $\implies$ $g$ smooth ($Df\circ g$ smooth, and inversion is a smooth operation).

This is "$f$ is a diffeomorphism $\implies$ $f^{-1}$ is too".
