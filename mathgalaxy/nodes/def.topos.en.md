## Statement · **draft**
A category $\mathcal{T}$ is called a **topos** if

1. there is a **small** set of generators;
2. finite limits exist;
3. coproducts exist and are disjoint and universal (equivalently: all colimits exist);
4. equivalence relations are effective and universal.

## Notes · **draft**
The only difference from a pretopos is item 1: **a topos = a pretopos with a small set of generators**. So "a topos is a pretopos shrunk until a set can control it".
