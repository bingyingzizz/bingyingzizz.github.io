# CGWH 是 CG 的反射子范畴　`thm.cgwh-reflective`
紧生成的弱 Hausdorff 空间是反射子范畴
layer 17 · 定理 · 紧生成空间与弱 Hausdorff · 拓扑学

紧生成的**弱 Hausdorff** 空间构成的范畴 $\mathrm{CGWH}$ 是 $\mathrm{CG}$（紧生成空间）的**反射**子范畴。

反射是

$$h : X \longmapsto X/R,$$

其中 $R$ 是 $X$ 上**最小的闭等价关系**。
