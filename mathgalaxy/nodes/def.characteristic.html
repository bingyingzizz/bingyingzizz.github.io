域的特征：111 加多少次回到 000

又称域的特征

陈述

在做什么：给域配一个数，记「111 要加多少次才回到 000」。它决定了域里能不能做除法以外的「模 ppp 运算」，也决定素域是哪个。

设 KKK 是域。考虑唯一环同态

φ:Z→K,φ(n)=1+1+⋯+1⏟n.\varphi : \mathbb{Z} \to K, \qquad \varphi(n) = \underbrace{1 + 1 + \cdots + 1}_{n} .φ:Z→K,φ(n)=n1+1+⋯+1​​.

它的核是 Z\mathbb{Z}Z 的理想，故为 (0)(0)(0) 或 (p)(p)(p)（ppp 素数）。称

  • ker⁡φ=(p)\ker\varphi = (p)kerφ=(p) 的情形为特征 ppp，记 char⁡K=p\operatorname{char} K = pcharK=p；
  • ker⁡φ=(0)\ker\varphi = (0)kerφ=(0) 的情形为特征 000，记 char⁡K=0\operatorname{char} K = 0charK=0（此时 φ\varphiφ 单射，KKK 含一份 Q\mathbb{Q}Q）。

素域：KKK 的最小子域（叫素域）同构于 Fp=Z/pZ\mathbb{F}_{p} = \mathbb{Z}/p\mathbb{Z}Fp​=Z/pZ（特征 ppp）或 Q\mathbb{Q}Q（特征 000）。所以「特征」决定了域的最小地基。

关键性质：char⁡K=p\operatorname{char} K = pcharK=p 时，对一切 a∈Ka \in Ka∈K 有 pa=0pa = 0pa=0，且 (a+b)p=ap+bp(a + b)^{p} = a^{p} + b^{p}(a+b)p=ap+bp（Frobenius：二项式系数 (pk)\binom{p}{k}(kp​) 都被 ppp 整除）。

说明

⭐ 为什么必须是素数：若 111 加 nnn 次回到 000 而 n=abn = abn=ab 可分解，则 0=n⋅1=(a⋅1)(b⋅1)0 = n\cdot 1 = (a\cdot 1)(b\cdot 1)0=n⋅1=(a⋅1)(b⋅1)，域无零因子   ⟹  \implies⟹ a⋅1=0a \cdot 1 = 0a⋅1=0 或 b⋅1=0b\cdot 1 = 0b⋅1=0   ⟹  \implies⟹ nnn 不是最小的。

所以核只能是 (0)(0)(0) 或 (p)(p)(p)，不存在特征 444 的域。

⚠️ char⁡\operatorname{char}char 不是「元素个数」：Fpn\mathbb{F}_{p^{n}}Fpn​ 的特征是 ppp，不是 pnp^{n}pn。

特征只记「Z\mathbb{Z}Z 怎么映进来」，元数记 ∣K∣\lvert K\rvert∣K∣。

两者对有限域由 ∣K∣=pn\lvert K\rvert = p^{n}∣K∣=pn 联系（ppp 是特征），但特征本身是那个 ppp。

⚠️ 与 有限特征（有限特征族）无关：那是序论 / Tukey 引理里的概念（「有限特征族」），只是中文撞了「特征」两个字。名字里带「特征」的东西在图上还有特征值、特征子空间、特征多项式、特征类 —— 各自独立。

⭐ Frobenius 是特征 ppp 的标志性现象：x↦xpx \mapsto x^{p}x↦xp 是域同态（在有限域上还是自同构），而特征 000 里完全没有对应物。Fpn\mathbb{F}_{p^{n}}Fpn​ 的 Galois 群就是 Frobenius 生成的循环群。
