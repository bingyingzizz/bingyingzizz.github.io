# Differential Form: Coordinate Model on Euclidean Open Sets　`def.differential-form`
English entry · root `../`
[in graph](../#n=def.differential-form)　·　[Chinese page (authoritative)](./def.differential-form.md)

⚠️ **Direction**: forms travel **against** a map (pullback, `prop.pullback-forms`), while vector fields travel **with** it (pushforward: along a **diffeomorphism**, or when $F$-related). This is the fundamental reason forms are easier to use than vector fields.
