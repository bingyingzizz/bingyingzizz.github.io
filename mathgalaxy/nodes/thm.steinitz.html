又称Steinitz 交换引理

陈述

设 VVV 是 KKK-向量空间，S=(v1,…,vn)S = (v_1, \ldots, v_n)S=(v1​,…,vn​) 线性无关，T=(w1,…,wm)T = (w_1, \ldots, w_m)T=(w1​,…,wm​) 生成 VVV。则

  • n≤mn \le mn≤m；
  • 可以从 TTT 中删去 nnn 个向量、换入 SSS 的全部向量，得到的 mmm 个向量仍生成 VVV。特别地，VVV 有一组基，其元素取自 T∪ST \cup ST∪S 且含 SSS。

说明

⭐ 一句话：「无关的」永远不比「生成的」多。它是维数良定义的全部内容 —— 两句话（n≤mn \le mn≤m 与可交换）在证明里是一起归纳出来的。

⭐ 证明是对 nnn 归纳：把 v1v_1v1​ 用 TTT 表出（TTT 生成），其中必有一个系数非零（否则 v1=0v_1 = 0v1​=0 与无关矛盾），把它换成 v1v_1v1​ 仍生成；再对剩下的重复。

⚠ 有限性是前提：这一条只管有限的无关集与生成集。无限的情形要靠 Zorn 引理（「每个向量空间有基」那一条就是）。

它指向谁（出边）

推出 1

  • 本页 ⟹ 维数良定义推出
    交换引理   ⟹  \implies⟹ 维数良定义

    设 B\mathcal{B}B 与 B′\mathcal{B}'B′ 是 VVV 的两组基。

    1. 由 B\mathcal{B}B 是基，它线性无关；由 B′\mathcal{B}'B′ 是基，它生成 VVV。于是由交换引理（取 S=BS = \mathcal{B}S=B、T=B′T = \mathcal{B}'T=B′）得 ∣B∣≤∣B′∣|\mathcal{B}| \le |\mathcal{B}'|∣B∣≤∣B′∣。
    2. 交换两者的角色（S=B′S = \mathcal{B}'S=B′、T=BT = \mathcal{B}T=B）得 ∣B′∣≤∣B∣|\mathcal{B}'| \le |\mathcal{B}|∣B′∣≤∣B∣。
    3. 由 Bernstein 定理（或直接用两个方向的单射）得 ∣B∣=∣B′∣|\mathcal{B}| = |\mathcal{B}'|∣B∣=∣B′∣。

    于是映射 B↦∣B∣\mathcal{B} \mapsto |\mathcal{B}|B↦∣B∣ 不依赖基的选取，dim⁡KV:=∣B∣\dim_K V := |\mathcal{B}|dimK​V:=∣B∣ 是良定义的。∎

    ⚠ 上面第 1、2 步用的交换引理是有限版本；无限维时要用它的无限形式（或 Zorn 引理 + 基数算术），结论相同。

    这条边的意义是：「维数」不是定义出来的，是证出来的。图上把它单独立一个节点，就是为了留下这个证明 —— 而不是把它塞进 def.vs 的 notes 里一笔带过。

定义引用 1

  • 维数良定义 用到 本页定义引用

    维数的定义要用「基的势」这个词 —— 而「势是唯一的」正是 Steinitz 引理给出的。

推出 1

  • 向量空间的基 ⟹ 本页推出
    线性无关与生成的定义   ⟹  \implies⟹ 交换引理

    对 nnn 归纳。n=0n = 0n=0 平凡。

    归纳步。 设 S=(v1,…,vn)S = (v_1, \ldots, v_n)S=(v1​,…,vn​) 线性无关、T=(w1,…,wm)T = (w_1, \ldots, w_m)T=(w1​,…,wm​) 生成 VVV。

    1. 把 v1v_1v1​ 用 TTT 表出：v1=∑jajwjv_1 = \sum_j a_j w_jv1​=∑j​aj​wj​。由 v1≠0v_1 \ne 0v1​=0（无关集不含零向量），某个 aj≠0a_j \ne 0aj​=0；重排下标设 a1≠0a_1 \ne 0a1​=0。
    2. 于是 w1=a1−1(v1−∑j≥2ajwj)w_1 = a_1^{-1}\bigl( v_1 - \sum_{j \ge 2} a_j w_j \bigr)w1​=a1−1​(v1​−∑j≥2​aj​wj​) 可由 T′:=(v1,w2,…,wm)T' := (v_1, w_2, \ldots, w_m)T′:=(v1​,w2​,…,wm​) 表出，所以 T′T'T′ 仍生成 VVV（TTT 中每个元素都能用 T′T'T′ 表出，而 VVV 由 TTT 生成）。
    3. 对 S′:=(v2,…,vn)S' := (v_2, \ldots, v_n)S′:=(v2​,…,vn​) 与生成集 T′T'T′（n−1n - 1n−1 与 mmm 个元素）用归纳假设：得 n−1≤mn - 1 \le mn−1≤m，即 n≤m+1n \le m + 1n≤m+1，且可以从 T′T'T′ 中删 n−1n - 1n−1 个换入 S′S'S′ 仍生成。
    4. 合并第 2、3 步：从 TTT 中删去 w1w_1w1​ 与那 n−1n - 1n−1 个，换入 v1,…,vnv_1, \ldots, v_nv1​,…,vn​，仍生成 VVV。

    （归纳假设给出的其实是 n−1≤mn - 1 \le mn−1≤m，要得到 n≤mn \le mn≤m 需要一个更精细的归纳陈述：若 SSS 无关、TTT 生成，则 ∣S∣≤∣T∣|S| \le |T|∣S∣≤∣T∣ 且可交换。上面的第 3 步用 T′T'T′ 而非 TTT 正是为此 —— 交换掉 v1v_1v1​ 之后生成集的势没有变。）∎

    基的存在性：取 T=T = T= 一组有限生成集、S=∅S = \emptysetS=∅ 逐步扩，或直接对无关集用 Zorn 引理（无限维情形），即得「每个向量空间有基」。

    交换引理的全部技巧在第 2 步：用一个无关向量替换掉生成集里的一个向量，生成性不丢。这件事能反复做，正是「无关的可以往生成集里塞」的来源。
