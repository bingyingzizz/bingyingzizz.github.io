# the order divides the totient　`thm.order-divides-phi`
English entry · root `../`
[in graph](../#n=thm.order-divides-phi)　·　[Chinese page (authoritative)](./thm.order-divides-phi.md)

**This is the "reason" for Euler's theorem**: Euler's theorem is not about congruences but the translation of "the order of an element in a finite group divides the order of the group" to $G = (\mathbb{Z}/n\mathbb{Z})^{\times}$ (see `imp.nt-lagrange-euler`).

**Corollary**: $a$ is a primitive root $\iff$ $\operatorname{ord}_{n}(a) = \varphi(n)$ — that is, it generates the whole unit group.
