# Paracompact Space　`def.paracompact`
English entry · root `../`
[in graph](../#n=def.paracompact)　·　[Chinese page (authoritative)](./def.paracompact.md)

⚠ The converse fails completely: a normal space need not be paracompact — $[0, \omega_{1})$ (the set of all ordinals below the first uncountable ordinal) is normal and countably compact but not compact, and "countably compact $+$ paracompact $\implies$ compact", so it is not paracompact.
