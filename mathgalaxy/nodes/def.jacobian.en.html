Notes

⭐ The chain rule in matrix form is just matrix multiplication: Jg∘f(a)=Jg(f(a)) Jf(a)J_{g \circ f}(a) = J_g(f(a))\, J_f(a)Jg∘f​(a)=Jg​(f(a))Jf​(a) (多元链式法则).

Composition of linear maps corresponds to matrix multiplication — the total differential is exactly the transport of this linear-algebra fact into calculus.

⭐ Three special cases are worth remembering:

  • n=1n = 1n=1: JJJ is a column, i.e. the tangent vector of a curve;
  • m=1m = 1m=1: JJJ is a row, i.e. (∇f)T(\nabla f)^{\mathsf{T}}(∇f)T;
  • m=nm = nm=n: det⁡Jf(a)\det J_f(a)detJf​(a) is the local volume scaling factor (this is the determinant factor in 流形上的换元公式).

⚠ Notational convention: some books write the Jacobian transposed (they store DfDfDf as a column vector).

The convention here is rows index the target coordinates and columns index the domain coordinates, so the chain rule is "multiply from left to right".
