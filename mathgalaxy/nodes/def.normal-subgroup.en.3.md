# normal subgroup　`def.normal-subgroup`
English entry · root `../`
[in graph](../#n=def.normal-subgroup)　·　[Chinese page (authoritative)](./def.normal-subgroup.md)

**Cosets are an equivalence relation.** Define $a \sim b \iff a^{-1} b \in H$; then the equivalence classes are precisely the left cosets, and all left cosets partition $G$ — this is the quotient set used for the quotient group below.

**Notation**: $H \le G$ denotes a subgroup, $H \trianglelefteq G$ a normal subgroup ($\trianglelefteq$ is read “is normal in”).
