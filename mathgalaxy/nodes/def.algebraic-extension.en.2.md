# algebraic extension　`def.algebraic-extension`
English entry · root `../`
[in graph](../#n=def.algebraic-extension)　·　[Chinese page (authoritative)](./def.algebraic-extension.md)

A finite extension is always algebraic: if $[K:F] = n < \infty$, take $0 \ne \alpha \in K$; then $1, \alpha, \ldots, \alpha^{n}$ — that is, $n+1$ vectors — are **linearly dependent** in the $n$-dimensional space, which gives a nonzero polynomial with root $\alpha$.

## Notes · **draft**
⭐ **The converse fails**: $\overline{\mathbb{Q}}/\mathbb{Q}$ (the algebraic closure of $\mathbb{Q}$) is algebraic but of **infinite** degree. So “algebraic” and “finite” are two different things — a distinction that matters in Galois theory (the fundamental theorem holds only for **finite** Galois extensions).
