# representable functor　`def.representable`
English entry · root `../`
[in graph](../#n=def.representable)　·　[Chinese page (authoritative)](./def.representable.md)

**(i) Universal element.** An object $X \in \mathcal{C}$ together with an element $s \in F(X)$ is called **universal** for $F$ if

$$\forall Y \in \mathcal{C},\ \forall t \in F(Y),\ \exists! \, f : X \to Y,\qquad F(f)(s) = t$$

One then also says that $F$ is **represented** by $(X, s)$.

**(ii) Representable.** If $F \cong \operatorname{Hom}_{\mathcal{C}}(X, -)$, one says that $F$ is **represented** by $X$, and $X$ is called a **representing object** of $F$.
