# Christoffel Symbols　`def.christoffel-symbol`
English entry · root `../`
[in graph](../#n=def.christoffel-symbol)　·　[Chinese page (authoritative)](./def.christoffel-symbol.md)

For a coordinate frame $[\partial_{i},\partial_{j}] = 0$, the right-hand side retains only two derivative terms and the left-hand side is $2\Gamma^{\ell}_{ij}g_{\ell k}$; solving gives the formula above. **The derivation uses only $g_{ij}$ and its first derivatives** — this is the first intrinsic quantity.
