陈述

设 φ:G→G′\varphi : G \to G'φ:G→G′ 是群同态。则 φ\varphiφ 诱导出同构

G/ker⁡φ  ≅  im⁡φ,gker⁡φ  ⟼  φ(g).G \big/ \ker\varphi \;\cong\; \operatorname{im}\varphi, \qquad g \ker\varphi \;\longmapsto\; \varphi(g).G/kerφ≅imφ,gkerφ⟼φ(g).

特别地：满同态的像就是商群（φ\varphiφ 满时 G/ker⁡φ≅G′G/\ker\varphi \cong G'G/kerφ≅G′）。

说明

证明的三步。 记 K=ker⁡φK = \ker\varphiK=kerφ。

  • 良定义：若 gK=g′KgK = g'KgK=g′K，则 g′=gkg' = gkg′=gk（某个 k∈Kk \in Kk∈K），于是 φ(g′)=φ(g)φ(k)=φ(g)e′=φ(g)\varphi(g') = \varphi(g)\varphi(k) = \varphi(g)e' = \varphi(g)φ(g′)=φ(g)φ(k)=φ(g)e′=φ(g) —— 同一陪集里的元素被送到同一个值。
  • 同态：φ‾((gK)(g′K))=φ‾(gg′K)=φ(gg′)=φ(g)φ(g′)=φ‾(gK) φ‾(g′K)\overline{\varphi}\bigl((gK)(g'K)\bigr) = \overline{\varphi}(gg'K) = \varphi(gg') = \varphi(g)\varphi(g') = \overline{\varphi}(gK)\,\overline{\varphi}(g'K)φ​((gK)(g′K))=φ​(gg′K)=φ(gg′)=φ(g)φ(g′)=φ​(gK)φ​(g′K)。
  • 双射：单，因为 φ‾(gK)=e′\overline{\varphi}(gK) = e'φ​(gK)=e′ 意味着 φ(g)=e′\varphi(g) = e'φ(g)=e′，即 g∈Kg \in Kg∈K，于是 gK=KgK = KgK=K；满，因为像本来就是 φ(G)\varphi(G)φ(G)。∎

⭐ 它其实是「集合 + 运算 + 公理」这套格式的通用定理，不是群的专利。 同一个证明逐字照搬，只要把「同态」换成对应的东西：

A/ker⁡f  ≅  im⁡f.A \big/ \ker f \;\cong\; \operatorname{im} f.A/kerf≅imf.

⭐ 集合层面的原型：对任何映射 f:A→Bf : A \to Bf:A→B，在 AAA 上令 a∼a′  ⟺  f(a)=f(a′)a \sim a' \iff f(a) = f(a')a∼a′⟺f(a)=f(a′)，则 fff 诱导双射 A/∼  →  im⁡fA/{\sim} \;\to\; \operatorname{im} fA/∼→imf（见「商集与等价类」）。群版比它多出来的只有一句话：商掉核之后，剩下的是一个群。前两步（良定义、双射）就是集合版的内容，第三步（同态）才是新的。

它回答了什么问题。 「同态把群送到哪里去了」这个问题，答案只有两部分：核（被压掉的部分）与像（留下来的部分），二者由一个同构精确地锁在一起。于是研究同态 = 研究正规子群，这就是把群论变成「子群格」的原因。

Abstract reviewed

For a group homomorphism φ:G→G′\varphi : G \to G'φ:G→G′, the assignment gker⁡φ↦φ(g)g\ker\varphi \mapsto \varphi(g)gkerφ↦φ(g) is an isomorphism G/ker⁡φ≅im⁡φG/\ker\varphi \cong \operatorname{im}\varphiG/kerφ≅imφ; in particular a surjective homomorphism has the quotient as image. The proof is three steps: well-definedness, multiplicativity, bijectivity. The same proof works verbatim for any "set + operations + axioms" structure, A/ker⁡f≅im⁡fA/\ker f \cong \operatorname{im} fA/kerf≅imf, and the set-level prototype is that every map induces a bijection from the quotient by a∼a′  ⟺  f(a)=f(a′)a \sim a' \iff f(a) = f(a')a∼a′⟺f(a)=f(a′) onto its image.

Statement reviewed

Let φ:G→G′\varphi : G \to G'φ:G→G′ be a group homomorphism. Then φ\varphiφ induces an isomorphism

G/ker⁡φ  ≅  im⁡φ,gker⁡φ  ⟼  φ(g).G \big/ \ker\varphi \;\cong\; \operatorname{im}\varphi, \qquad g \ker\varphi \;\longmapsto\; \varphi(g).G/kerφ≅imφ,gkerφ⟼φ(g).

In particular: the image of a surjective homomorphism is the quotient group (G/ker⁡φ≅G′G/\ker\varphi \cong G'G/kerφ≅G′ when φ\varphiφ is surjective).

Notes reviewed

The three steps of the proof. Write K=ker⁡φK = \ker\varphiK=kerφ.

  • Well defined: if gK=g′KgK = g'KgK=g′K then g′=gkg' = gkg′=gk for some k∈Kk \in Kk∈K, hence φ(g′)=φ(g)φ(k)=φ(g)e′=φ(g)\varphi(g') = \varphi(g)\varphi(k) = \varphi(g)e' = \varphi(g)φ(g′)=φ(g)φ(k)=φ(g)e′=φ(g) — elements of the same coset are sent to the same value.
  • Homomorphism: φ‾((gK)(g′K))=φ‾(gg′K)=φ(gg′)=φ(g)φ(g′)=φ‾(gK) φ‾(g′K)\overline{\varphi}\bigl((gK)(g'K)\bigr) = \overline{\varphi}(gg'K) = \varphi(gg') = \varphi(g)\varphi(g') = \overline{\varphi}(gK)\,\overline{\varphi}(g'K)φ​((gK)(g′K))=φ​(gg′K)=φ(gg′)=φ(g)φ(g′)=φ​(gK)φ​(g′K).
  • Bijection: injective, because φ‾(gK)=e′\overline{\varphi}(gK) = e'φ​(gK)=e′ means φ(g)=e′\varphi(g) = e'φ(g)=e′, i.e. g∈Kg \in Kg∈K, so gK=KgK = KgK=K; surjective, because the image is φ(G)\varphi(G)φ(G) by construction. ∎

⭐ It is really a theorem about the format "set + operations + axioms", not a privilege of groups. The same proof carries over verbatim, provided one replaces "homomorphism" by the corresponding notion:

A/ker⁡f  ≅  im⁡f.A \big/ \ker f \;\cong\; \operatorname{im} f.A/kerf≅imf.

⭐ The set-level prototype: for any map f:A→Bf : A \to Bf:A→B, put a∼a′  ⟺  f(a)=f(a′)a \sim a' \iff f(a) = f(a')a∼a′⟺f(a)=f(a′) on AAA; then fff induces a bijection A/∼  →  im⁡fA/{\sim} \;\to\; \operatorname{im} fA/∼→imf (see "quotient set and equivalence classes"). The group version adds exactly one sentence: after dividing by the kernel, what remains is a group. The first two steps (well defined, bijection) are the set-level content; only the third (homomorphism) is new.

What question does it answer? "Where does a homomorphism send a group?" has a two-part answer: the kernel (what is collapsed) and the image (what survives), locked together by a single isomorphism. So studying homomorphisms is studying normal subgroups — which is why group theory turns into the study of the lattice of subgroups.
