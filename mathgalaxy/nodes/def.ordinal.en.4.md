# ordinal　`def.ordinal`
English entry · root `../`
[in graph](../#n=def.ordinal)　·　[Chinese page (authoritative)](./def.ordinal.md)

**Why not take order types as the objects** — this is the most important step in this pack: an order type is an isomorphism class, and there are more order types of well-orders than fit into any set, so they cannot be collected (see "the ordinals do not form a set"). Ordinals avoid this: each order type is given a **concrete representative**, namely a transitive well-ordered set. Comparing order types then becomes comparing $\in$, which can be done outright.

**$\alpha \in \beta$ and $\alpha < \beta$ are the same thing**: on ordinals, $\in$ is the order. Writing $\alpha < \beta$ really uses $\in$ underneath.
