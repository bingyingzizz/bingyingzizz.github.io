## Statement · **draft**
Let $\mu^{*}$ be an outer measure on $X$. A set $A \subseteq X$ is called **$\mu^{*}$-measurable** iff $A$ splits every set “cleanly into two pieces”:

$$\mu^*(E) = \mu^*(E \cap A) + \mu^*(E \cap A^c)\quad  \forall E \subseteq X$$
