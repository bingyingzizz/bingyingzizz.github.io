陈述

C\mathcal{C}C 上全体预层以自然变换为态射，组成范畴

C^:=Hom⁡(Cop,Set)\widehat{\mathcal{C}} := \operatorname{Hom}(\mathcal{C}^{\mathrm{op}}, \mathbf{Set})C:=Hom(Cop,Set)

说明

它是函子范畴，所以极限与余极限逐点算 —— 后面所有关于 C^\widehat{\mathcal{C}}C 的构造都从这里出发。

几个小例子：∅^=1\widehat{\emptyset} = \mathbf{1}∅​=1（空范畴到 Set\mathbf{Set}Set 的唯一函子）；1^≃Set\widehat{\mathbf{1}} \simeq \mathbf{Set}1≃Set（选一个对象、一个集合）；

GGG 是幺半群时 G^≃G-Set\widehat{G} \simeq G\text{-}\mathbf{Set}G≃G-Set（带 GGG 作用的集合，且映射与 GGG 中每个元素的平移相容）。

它指向谁（出边）

推出 2

  • 本页 ⟹ 可表函子保所有极限推出

    证明。 先证 hX=Hom⁡(X,−)h^{X} = \operatorname{Hom}(X, -)hX=Hom(X,−) 保极限。取 D:I→CD : I \to \mathcal{C}D:I→C，链式：

    Hom⁡C(X, lim⁡D)  ≅  Hom⁡CI({0}‾, hX∘D)  ≅  lim⁡(hX∘D).\operatorname{Hom}_{\mathcal{C}}\bigl(X,\ \lim D\bigr) \;\cong\; \operatorname{Hom}_{\mathcal{C}^{I}}\bigl(\underline{\{0\}},\ h^{X} \circ D\bigr) \;\cong\; \lim \bigl(h^{X} \circ D\bigr).HomC​(X, limD)≅HomCI​({0}​, hX∘D)≅lim(hX∘D).

    第一式是极限的定义（lim⁡D\lim DlimD 表示锥函子：Hom⁡(ΔY,D)≅Hom⁡(Y,lim⁡D)\operatorname{Hom}(\Delta Y, D) \cong \operatorname{Hom}(Y, \lim D)Hom(ΔY,D)≅Hom(Y,limD)，取 Y=XY = XY=X）；

    第二式是「函子范畴里的极限逐点算」。

    这里 {0}‾\underline{\{0\}}{0}​ 是 SetI\mathbf{Set}^{I}SetI 的终对象（取值恒为单点的常函子）；hX∘Dh^{X}\circ DhX∘D 也取值在 Set\mathbf{Set}Set，故 Hom⁡SetI\operatorname{Hom}_{\mathbf{Set}^{I}}HomSetI​ 合法。

    ∎

  • 本页 ⟹ 切片范畴是拉回推出

    证明。 需要证 C/T→C×C^C^/T\mathcal{C}/T \to \mathcal{C}\times_{\widehat{\mathcal{C}}}\widehat{\mathcal{C}}/TC/T→C×C​C/T 是等价。

    • 对象：C/T\mathcal{C}/TC/T 的对象是 p:X→Tp : X \to Tp:X→T（X∈CX\in\mathcal{C}X∈C）；由 Yoneda，Hom⁡(hX,T)≅T(X)\operatorname{Hom}(h_{X}, T) \cong T(X)Hom(hX​,T)≅T(X)，所以 ppp 与一个态射 hX→Th_{X}\to ThX​→T 一一对应 —— 而右边拉回的对象的正是「X∈CX \in \mathcal{C}X∈C 连同 hX→Th_{X}\to ThX​→T」✓。
    • 态射：C/T\mathcal{C}/TC/T 中 p→p′p \to p'p→p′ 是交换三角（X→X′X\to X'X→X′ 与 TTT 上的相容性）；把 Yoneda 嵌入作用上去得到 hX→hX′h_{X}\to h_{X'}hX​→hX′​ 与 hX→Th_{X}\to ThX​→T 的相容对，右边正是一对这样的数据。

    由 Yoneda 嵌入全忠实（Hom⁡(hX,hX′)≅Hom⁡(X,X′)\operatorname{Hom}(h_{X},h_{X'}) \cong \operatorname{Hom}(X,X')Hom(hX​,hX′​)≅Hom(X,X′)），这个对应在 Hom 上是双射 ✓。

    • 函子性 / 等价：对应在复合下保持（Yoneda 是函子）✓ 于是得到一个范畴等价，即原方块笛卡尔 ✓。
    • 特例：取 T=hXT = h_{X}T=hX​，得 C/X≃C^/hX\mathcal{C}/X \simeq \widehat{\mathcal{C}}/h_{X}C/X≃C/hX​ —— 在 C\mathcal{C}C 里沿 XXX 切片与在预层范畴里沿 hXh_{X}hX​ 切片是同一件事 ✓。∎
