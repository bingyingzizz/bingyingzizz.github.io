# orthogonality　`def.orthogonality`
English entry · root `../`
[in graph](../#n=def.orthogonality)　·　[Chinese page (authoritative)](./def.orthogonality.md)

$$v = \sum_{i=1}^{n} \langle e_i, v \rangle\, e_i, \qquad \|v\|^{2} = \sum_{i=1}^{n} |\langle e_i, v \rangle|^{2}$$

(the second identity is **Parseval's identity**.) For a general basis one must solve a linear system to find coordinates; for an orthonormal basis it suffices to compute $n$ inner products — this is why Gram–Schmidt is worth the trouble.

⚠ An orthonormal set differs from an orthonormal "basis": the former requires only orthonormality, not spanning the whole space.
