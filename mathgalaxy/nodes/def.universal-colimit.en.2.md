# Universal Colimits and Disjoint Coproducts　`def.universal-colimit`

2. A regular epimorphism $f : X \to Y$ is called **universal** if for every $Y' \to Y$ the pullback $f \times_{Y} Y'$ is still a regular epimorphism;
3. A coproduct $X = \coprod_{i \in I} X_{i}$ is called **disjoint** if (a) every $X_{i} \to X$ is a monomorphism and (b) for $i \ne j$, $X_{i} \times_{X} X_{j}$ is an initial object.

An effective equivalence relation is called **universal** if its quotient map is a universal regular epimorphism.
