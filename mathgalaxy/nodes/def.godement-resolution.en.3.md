## Notes · **draft**
**Construction**: $\mathcal{C}^{0}(\mathcal{F})(U)=\prod_{x\in U}\mathcal{F}_{x}$ records sections pointwise as elements of stalks; the restriction maps are projections, so sections over any open set extend (flabbiness). $\mathcal{C}^{q}$ takes the alternating version of the $q$-fold "stalk product", with the Čech-type alternating differential.
