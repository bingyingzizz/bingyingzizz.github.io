**(ii) Order axioms**: $\le$ is a total order compatible with the operations:
$$a \le b \implies a + c \le b + c, \qquad a \le b,\ 0 \le c \implies ac \le bc$$

**(iii) Completeness (least upper bound principle)**: **every nonempty subset of $\mathbb{R}$ that is bounded above has a least upper bound**.

Moreover the embedded image of $\mathbb{Q}$ is **dense** in $\mathbb{R}$.
