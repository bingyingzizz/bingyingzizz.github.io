# ℓ^p ⊆ ℓ^q　`prop.ell-p-inclusion`
命题（只有衰减的场合）：$\ell^p \subseteq \ell^q$（$0 < p < q \le \infty$）
layer 18 · 命题 · L^p 空间 · 分析学

设 $0 < p < q \le \infty$，$A$ 是任意指标集。则

$$\ell^p(A) \subseteq \ell^q(A), \qquad \|f\|_q \le \|f\|_p$$
