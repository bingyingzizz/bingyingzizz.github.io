## 陈述（续）
是模同态。又设
$$\cdots \to P_{1} \xrightarrow{\ d_{1}\ } P
_{0} \xrightarrow{\ \varepsilon_{P}\ } M \to 
0, \qquad \cdots \to Q_{1} \xrightarrow{\ e_{
1}\ } Q_{0} \xrightarrow{\ \varepsilon_{Q}\ }
 N \to 0$$
是两条**投射消解**。则：
1. 存在**链映射** $\varphi : P_{\bullet} \to Q_{
\bullet}$ 提升 $f$：即 $\varepsilon_{Q}\varphi_{0
} = f\varepsilon_{P}$，且 $\varphi_{n-1}d_{n} = e
_{n}\varphi_{n}$ 对一切 $n \ge 1$；
2. 任意两
个提升 $\varphi, \psi$ **链同伦**：存在 $s_{
n} : P_{n} \to Q_{n+1}$ 使
$$\varphi_{n} - \psi
_{n} = e_{n+1}s_{n} + s_{n-1}d_{n},$$
其中约定 $s
_{-1} = 0$，并把 $e_{0}$ 读作 $\varepsilon_{Q}$
、$d_{0}$ 读作 $\varepsilon_{P}$。
