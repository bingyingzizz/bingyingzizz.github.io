陈述

在做什么：给形式配一个导数，把 kkk-形式送到 (k+1)(k+1)(k+1)-形式，并满足 d2=0\mathrm{d}^{2} = 0d2=0 —— 这一步把微积分写成不依赖坐标的样子。

设 ω=∑IaI dxI\omega = \sum_{I}a_{I}\,\mathrm{d}x^{I}ω=∑I​aI​dxI 是 UUU 上的 kkk-形式，其中 dxI:=dxi1∧⋯∧dxik\mathrm{d}x^{I} := \mathrm{d}x^{i_{1}}\wedge\cdots\wedge\mathrm{d}x^{i_{k}}dxI:=dxi1​∧⋯∧dxik​。外微分定义为

dω:=∑IdaI∧dxI=∑I∑j=1n∂aI∂xj dxj∧dxI.\mathrm{d}\omega := \sum_{I}\mathrm{d}a_{I}\wedge\mathrm{d}x^{I} = \sum_{I}\sum_{j=1}^{n}\frac{\partial a_{I}}{\partial x^{j}}\,\mathrm{d}x^{j}\wedge\mathrm{d}x^{I}.dω:=I∑​daI​∧dxI=I∑​j=1∑n​∂xj∂aI​​dxj∧dxI.

对函数（000-形式）它就是全微分 df=∑j∂jf dxj\mathrm{d}f = \sum_{j}\partial_{j}f\,\mathrm{d}x^{j}df=∑j​∂j​fdxj。基本性质：

  1. R\mathbb{R}R-线性：d(aω+bη)=a dω+b dη\mathrm{d}(a\omega+b\eta) = a\,\mathrm{d}\omega+b\,\mathrm{d}\etad(aω+bη)=adω+bdη；
  2. 分次 Leibniz 律：ω\omegaω 是 kkk-形式时 d(ω∧η)=dω∧η+(−1)kω∧dη\mathrm{d}(\omega\wedge\eta) = \mathrm{d}\omega\wedge\eta+(-1)^{k}\omega\wedge\mathrm{d}\etad(ω∧η)=dω∧η+(−1)kω∧dη；
  3. d2=0\mathrm{d}^{2} = 0d2=0：混合偏导可交换的直接推论；
  4. 与坐标选取无关（等价说法：与拉回交换，见 prop.pullback-forms）。

dω=0\mathrm{d}\omega = 0dω=0 的 ω\omegaω 叫闭形式，ω=dη\omega = \mathrm{d}\etaω=dη 的叫恰当形式。由 d2=0\mathrm{d}^{2}=0d2=0，恰当必闭；反之不成立（R2∖{0}\mathbb{R}^{2}\setminus\{0\}R2∖{0} 上的 x dy−y dxx2+y2\frac{x\,\mathrm{d}y-y\,\mathrm{d}x}{x^{2}+y^{2}}x2+y2xdy−ydx​ 闭而不恰当）。

说明

d\mathrm{d}d 是什么代数对象：外代数上的反导子 —— 次数 +1+1+1、分次 Leibniz、平方为零。这三条唯一确定它，所以不必背公式，记住这三条即可。

d2=0\mathrm{d}^{2}=0d2=0 与结构方程同源：曲面的结构方程也是 d2=0\mathrm{d}^{2}=0d2=0 的读数（thm.structure-equations）。形式语言的好处是把「混合偏导可交换」与「标架可积」写成同一条等式。

三个经典算子的统一（n=3n=3n=3）：d\mathrm{d}d 在 000-形式上给出梯度（作为 111-形式）、在 111-形式上给出旋度（作为 222-形式）、在 222-形式上给出散度（作为 333-形式）。于是 d2=0\mathrm{d}^{2}=0d2=0 就是「旋度的散度为零」与「梯度的旋度为零」。

⚠️ 不能对向量场取 d\mathrm{d}d：d\mathrm{d}d 只作用在形式上。对向量场求导要额外的结构（联络，def.affine-connection），得到的是协变导数而不是外微分。

⚠️ 同一个 d\mathrm{d}d 也用来记全微分、弧长元素、积分测度，这是记号的历史包袱。本图里 dω\mathrm{d}\omegadω 一律指外微分，ds\mathrm{d}sds、dA\mathrm{d}AdA 各有所指（def.arc-length、def.area-element）。
