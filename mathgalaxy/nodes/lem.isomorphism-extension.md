# 同构延拓　`lem.isomorphism-extension`
同构延拓：把基域同构延到单代数扩张

设 $\sigma:F\to F'$ 是域同构，$p\in F[x]$ 不可约，$p^{\sigma}\in F'[x]$ 是系数逐项取 $\sigma$ 的像所得多项式。若 $\alpha$ 是 $p$ 在 $F$ 的扩域中的根，$\alpha'$ 是 $p^{\sigma}$ 在 $F'$ 的扩域中的根，则 $\sigma$ 唯一地延拓为域

## 说明
这是把基域上的同构搬到单代数扩张上的最小引理：$p$ 与 $p^{\sigma}$ 不可约且次数相同，于是两个单扩张作为「模掉同一个不可约多项式」的商域同构。
