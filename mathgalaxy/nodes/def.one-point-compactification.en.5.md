⚠️ **Relation to "locally compact Hausdorff implies completely regular"**: that proof uses exactly "$X^{*}$ is compact Hausdorff $\implies$ normal $\implies$ one can build a Urysohn function on $X^{*}$ and pull it back". The one-point compactification is the standard interface that transfers the good properties of compact spaces to $X$.
