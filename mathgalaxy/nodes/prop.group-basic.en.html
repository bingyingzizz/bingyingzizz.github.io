Statement

Let GGG be a group and a,b,c∈Ga, b, c \in Ga,b,c∈G. Then:

(i) Cancellation: ab=ac  ⟹  b=cab = ac \implies b = cab=ac⟹b=c, ba=ca  ⟹  b=cba = ca \implies b = cba=ca⟹b=c;

(ii) Inverse formulas: (ab)−1=b−1a−1(ab)^{-1} = b^{-1}a^{-1}(ab)−1=b−1a−1, (a−1)−1=a(a^{-1})^{-1} = a(a−1)−1=a, e−1=ee^{-1} = ee−1=e;

(iii) For m,n∈Zm, n \in \mathbb{Z}m,n∈Z: aman=am+na^{m}a^{n} = a^{m+n}aman=am+n, (am)n=amn(a^{m})^{n} = a^{mn}(am)n=amn, a0=ea^{0} = ea0=e.

Notes

⭐ Cancellation is the watershed between groups and monoids: (N,⋅)(\mathbb{N}, \cdot)(N,⋅) is a monoid, but 0⋅2=0⋅30 \cdot 2 = 0 \cdot 30⋅2=0⋅3 cannot cancel 000 — what is missing is precisely inverses.

⚠ In a nonabelian group the order in (ab)−1=b−1a−1(ab)^{-1} = b^{-1}a^{-1}(ab)−1=b−1a−1 must be reversed: (ab)(b−1a−1)=a(bb−1)a−1=aa−1=e(ab)(b^{-1}a^{-1}) = a(bb^{-1})a^{-1} = aa^{-1} = e(ab)(b−1a−1)=a(bb−1)a−1=aa−1=e.

⭐ (iii) is the group version of group power;

the proof is again "induct on nonnegative integers, then pass to negative exponents using inverses".
