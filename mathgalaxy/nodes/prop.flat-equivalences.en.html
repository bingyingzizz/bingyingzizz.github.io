Statement

Let RRR be a commutative ring with unit and NNN an RRR-module. The following are equivalent:

  1. NNN is flat, i.e. (−)⊗RN(-) \otimes_{R} N(−)⊗R​N is exact;
  2. for every injection M1↣MM_{1} \rightarrowtail MM1​↣M, the map M1⊗RN→M⊗RNM_{1} \otimes_{R} N \to M \otimes_{R} NM1​⊗R​N→M⊗R​N is injective;
  3. for every RRR-module MMM, Tor⁡1R(M,N)=0\operatorname{Tor}_{1}^{R}(M, N) = 0Tor1R​(M,N)=0;
  4. for every ideal I⊆RI \subseteq RI⊆R, the multiplication map I⊗RN→NI \otimes_{R} N \to NI⊗R​N→N, a⊗n↦ana \otimes n \mapsto a na⊗n↦an, is injective (equivalently I⊗RN≅INI \otimes_{R} N \cong I NI⊗R​N≅IN);
  5. for every short exact sequence 0→K→Rn→M→00 \to K \to R^{n} \to M \to 00→K→Rn→M→0 with finitely presented modules, the tensored sequence 0→K⊗N→Nn→M⊗N→00 \to K \otimes N \to N^{n} \to M \otimes N \to 00→K⊗N→Nn→M⊗N→0 is still exact.

Notes

1 and 2 are the same sentence (right exactness is free). 2 and 3: take a projective resolution of MMM; Tor⁡1\operatorname{Tor}_{1}Tor1​ measures exactly the injectivity lost after tensoring.

3 implies 4: from 0→I→R→R/I→00 \to I \to R \to R/I \to 00→I→R→R/I→0 and Tor⁡1R(R,N)=0\operatorname{Tor}_{1}^{R}(R, N) = 0Tor1R​(R,N)=0 one gets the long exact sequence

0⟶Tor⁡1R(R/I,N)⟶I⊗N⟶N,0 \longrightarrow \operatorname{Tor}_{1}^{R}(R/I, N) \longrightarrow I \otimes N \longrightarrow N,0⟶Tor1R​(R/I,N)⟶I⊗N⟶N,

so Tor⁡1R(R/I,N)=0\operatorname{Tor}_{1}^{R}(R/I, N) = 0Tor1R​(R/I,N)=0 forces I⊗N→NI \otimes N \to NI⊗N→N injective ✓.

4 implies 1: it suffices to test on injections; first reduce to MMM finitely generated ((−)⊗N(-)\otimes N(−)⊗N preserves filtered colimits), then induct on the number of generators, using the ideal case at each step — the full argument is in 只需有限生成理想 ✓.

⭐ Only condition 4 is computable: ideals are usually far fewer than submodules, and the multiplication map I⊗N→NI \otimes N \to NI⊗N→N can often be written explicitly. Over a PID ideals are principal, so the criterion is almost automatic (the source of "torsion-free implies flat").

Hypotheses used in each direction (the five formulations differ only in "how large a module tests flatness"):

  • (1)   ⟺  \iff⟺ (2): unfolding the definition. (1) says (−)⊗N(-)\otimes N(−)⊗N is exact; exact = preserves kernels, and preserving kernels for injections is (2).
  • (2)   ⟹  \implies⟹ (3): this step needs the long exact sequence. From the long exact sequence for Tor⁡\operatorname{Tor}Tor, Tor⁡1R(M,N)=0\operatorname{Tor}_{1}^{R}(M,N) = 0Tor1R​(M,N)=0 is equivalent to "tensoring every short exact sequence 0→M1→M→M/M1→00 \to M_{1} \to M \to M/M_{1} \to 00→M1​→M→M/M1​→0 stays exact"; (2) gives only injectivity, and surjectivity needs one extra argument.
  • (3)   ⟹  \implies⟹ (2): the reverse is almost free (Tor⁡1=0\operatorname{Tor}_{1} = 0Tor1​=0 returns injectivity directly), the cheapest step of the five.
  • (1)   ⟹  \implies⟹ (4): only ideals are used. I↪RI \hookrightarrow RI↪R is an injection, so apply (2).
  • (4)   ⟹  \implies⟹ (1): the only direction with real cost, using the algebraic version of a Baire-type argument: first shrink the test objects to finitely presented modules (this uses "flat = preserves kernels after tensoring with finitely presented modules"), then ascend to arbitrary modules. Without this step flatness could only be tested on "all modules", which is unusable in practice.
  • (5)   ⟹  \implies⟹ (2): no extra hypothesis ((5) is the truncation of (2) to finitely presented modules; check KKK term by term).

In one sentence: the watershed is (4) — testing on ideals suffices, which is why flatness is computable (and why over a Noetherian ring only finitely generated ideals need testing).
