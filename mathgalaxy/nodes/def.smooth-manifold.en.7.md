# Smooth Manifold　`def.smooth-manifold`
English entry · root `../`
[in graph](../#n=def.smooth-manifold)　·　[Chinese page (authoritative)](./def.smooth-manifold.md)

⚠ **A smooth structure is not part of the topology**: the same topological space can carry inequivalent smooth structures (Milnor's exotic 7-sphere; $\mathbb{R}^{4}$ carries uncountably many pairwise inequivalent smooth structures). So a "smooth manifold" is a topological space **plus** structure, not a property of the space.

**Interface with existing content**: the implicit function theorem gives that level sets in $\mathbb{R}^{n}$ are manifolds (`thm.regular-level-set`); conversely, every manifold embeds into some $\mathbb{R}^{N}$ (Whitney), but $N$ may be much larger than $n$, so the abstract definition is not superfluous.
