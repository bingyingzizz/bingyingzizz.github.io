# algebraic closure　`def.algebraic-closure`
English entry · root `../`
[in graph](../#n=def.algebraic-closure)　·　[Chinese page (authoritative)](./def.algebraic-closure.md)

⭐ Existence uses Zorn, but first one must pass to a set: all algebraic extensions form a proper class and cannot be ordered directly. Give the candidate field a cardinal bound $\le \max(|K|, \aleph_0)$ first (each algebraic element is a root of some nonzero polynomial in $K[x]$, while $K[x]$ has only $\max(|K|,\aleph_0)$ elements and each polynomial has finitely many roots, so the total number of algebraic elements is at most this bound), keep only algebraic extensions within the bound, and apply Zorn to those; a maximal element must be algebraically closed (otherwise add one more root and extend).
