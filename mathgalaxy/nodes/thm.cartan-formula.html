又称Cartan 公式

陈述

白话：Lie 导数可以拆成「先缩再外微分」加「先外微分再缩」两部分 —— 一条公式把三个算子捆在一起，代价为零。

设 X∈X(M)X \in \mathfrak{X}(M)X∈X(M)、ω∈Ωk(M)\omega \in \Omega^{k}(M)ω∈Ωk(M)（k≥0k \ge 0k≥0）。则

LXω=d(ιXω)+ιX(dω),\mathcal{L}_{X}\omega = \mathrm{d}\bigl(\iota_{X}\omega\bigr) + \iota_{X}\bigl(\mathrm{d}\omega\bigr),LX​ω=d(ιX​ω)+ιX​(dω),

等价地，作为 Ω∙(M)\Omega^{\bullet}(M)Ω∙(M) 上的算子

LX=d ιX+ιX d,\mathcal{L}_{X} = \mathrm{d}\,\iota_{X} + \iota_{X}\,\mathrm{d},LX​=dιX​+ιX​d,

其中 LX\mathcal{L}_{X}LX​ 是 Lie 导数（def.lie-derivative）、ιX\iota_{X}ιX​ 是内乘（def.interior-product）、d\mathrm{d}d 是外微分（def.exterior-derivative），并规定 ιX\iota_{X}ιX​ 作用在函数上为 000。

推论：

  1. LXd=dLX\mathcal{L}_{X}\mathrm{d} = \mathrm{d}\mathcal{L}_{X}LX​d=dLX​（因为 d2=0\mathrm{d}^{2} = 0d2=0）；
  2. 在闭形式上有 LXω=dιXω\mathcal{L}_{X}\omega = \mathrm{d}\iota_{X}\omegaLX​ω=dιX​ω，即 LXω\mathcal{L}_{X}\omegaLX​ω 恰当；
  3. LX\mathcal{L}_{X}LX​ 保持闭形式空间与恰当形式空间。

说明

证明的形状（写在边上）：两边都是「与 d\mathrm{d}d 交换的次数 000 的导子」，所以只要在函数上验一遍 —— 这是 Cartan 公式三行证完的原因。注意「与 d\mathrm{d}d 交换」在左边用了「流拉回与外微分交换」，在右边用了 d2=0\mathrm{d}^{2} = 0d2=0。

它是「同伦算子」的原型：dιX+ιXd=LX\mathrm{d}\iota_{X} + \iota_{X}\mathrm{d} = \mathcal{L}_{X}dιX​+ιX​d=LX​ 的形状与 Poincaré 引理的 dK+Kd=id⁡\mathrm{d}K + K\mathrm{d} = \operatorname{id}dK+Kd=id（lem.poincare-lemma）完全一样 —— 都把「求导」拆成两条链映射之和。差别在于 LX\mathcal{L}_{X}LX​ 不必是 id⁡\operatorname{id}id：给定 LX\mathcal{L}_{X}LX​ 后想解 ιXω=η\iota_{X}\omega = \etaιX​ω=η，就是一个「同伦方程」。

为什么物理里爱用它：LX\mathcal{L}_{X}LX​ 是沿流的变化率，dιX\mathrm{d}\iota_{X}dιX​ 与 ιXd\iota_{X}\mathrm{d}ιX​d 分掉了「恰当部分」与「闭部分」。像「场的对称性」这类陈述（LXF=0\mathcal{L}_{X}F = 0LX​F=0）以及规范变换的存在性，都从这条公式出发。

两个边界情形：k=0k = 0k=0 时 ιXf=0\iota_{X}f = 0ιX​f=0，故 LXf=ιXdf=df(X)=Xf\mathcal{L}_{X}f = \iota_{X}\mathrm{d}f = \mathrm{d}f(X) = XfLX​f=ιX​df=df(X)=Xf，与 def.lie-derivative 的第一条一致；k=nk = nk=n 时 dω=0\mathrm{d}\omega = 0dω=0，故 LXω=dιXω\mathcal{L}_{X}\omega = \mathrm{d}\iota_{X}\omegaLX​ω=dιX​ω 恰当 —— 这是「体积沿流的变率等于散度乘体积」那条公式的起点。

⚠️ 符号约定：本图的 ιX\iota_{X}ιX​ 用「塞进第一个槽」的约定，故 (LXω)(Y)=Xω(Y)−ω([X,Y])(\mathcal{L}_{X}\omega)(Y) = X\omega(Y) - \omega([X,Y])(LX​ω)(Y)=Xω(Y)−ω([X,Y])；若有人把内乘定义成「塞进最后一个槽」，那 Cartan 公式要补一个 (−1)k(-1)^{k}(−1)k。抄公式前先看对方的内乘约定。

    记 D:=d ιX+ιX dD := \mathrm{d}\,\iota_{X} + \iota_{X}\,\mathrm{d}D:=dιX​+ιX​d，要证 D=LXD = \mathcal{L}_{X}D=LX​ 作用在 Ω∙(M)\Omega^{\bullet}(M)Ω∙(M) 上。分四步。

    (1) 两者都保次数。 d\mathrm{d}d 次数 +1+1+1、ιX\iota_{X}ιX​ 次数 −1-1−1，故 DDD 次数 000；LX\mathcal{L}_{X}LX​ 由拉回定义，而拉回保次数。

    且 D(dgi)=d(Dgi)D(\mathrm{d}g_{i}) = \mathrm{d}(Dg_{i})D(dgi​)=d(Dgi​)（第 3 步），于是每一步都由 D∣C∞(M)D|_{C^{\infty}(M)}D∣C∞(M)​ 决定。由 (4)，DDD 与 LX\mathcal{L}_{X}LX​ 在所有函数上相同，故处处相同。∎

定义引用 3

  • Lie 导数 → 本页定义引用

    公式左边就是 Lie 导数；证明的收尾用「它是与 d\mathrm{d}d 交换的次数 000 导子」这条性质。

  • 内乘 → 本页定义引用

    公式右边两项都含内乘；它与 d\mathrm{d}d 都是反导子，复合出来才是导子 —— 这是证明能三行收束的技术核心。

  • 外微分 → 本页定义引用

    「dιX+ιXd\mathrm{d}\iota_{X} + \iota_{X}\mathrm{d}dιX​+ιX​d 与 d\mathrm{d}d 交换」这一步用了 d2=0\mathrm{d}^{2} = 0d2=0；没有它，右边那个组合连类型都对不上。
