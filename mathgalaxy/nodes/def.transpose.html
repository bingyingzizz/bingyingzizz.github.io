陈述

在做什么：把矩阵沿主对角线翻过来。看起来只是个记号操作，但它正是对偶空间上诱导的映射在矩阵语言里的样子。

设 A=(aij)∈Mm×n(K)A = (a_{ij}) \in M_{m\times n}(K)A=(aij​)∈Mm×n​(K)。转置 AT∈Mn×m(K)A^{T} \in M_{n\times m}(K)AT∈Mn×m​(K) 由 (AT)ij:=aji(A^{T})_{ij} := a_{ji}(AT)ij​:=aji​ 定义。

基本性质：(A+B)T=AT+BT(A+B)^{T} = A^{T} + B^{T}(A+B)T=AT+BT、(cA)T=cAT(cA)^{T} = cA^{T}(cA)T=cAT、(AT)T=A(A^{T})^{T} = A(AT)T=A，以及最要紧的一条

(AB)T=BTAT(AB)^{T} = B^{T} A^{T}(AB)T=BTAT

（乘法换序。）若 AAA 可逆，则 ATA^{T}AT 可逆且 (A−1)T=(AT)−1(A^{-1})^{T} = (A^{T})^{-1}(A−1)T=(AT)−1。

说明

为什么乘法要换序：转置不是「重新排一下」，它是对偶。

线性映射 T:V→WT : V \to WT:V→W 诱导对偶映射 T∗:W∗→V∗T^{} : W^{} \to V^{}T∗:W∗→V∗（方向反过来），而 T∗T^{}T∗ 的矩阵恰好是 TTT 的矩阵的转置。

方向既然反了，复合的次序自然也要反 —— (AB)T=BTAT(AB)^{T} = B^{T}A^{T}(AB)T=BTAT 说的就是这件事。

与配对的相容性：把向量当列，则 yTAxy^{T}AxyTAx 是一个数，且等于 (ATy)Tx(A^{T}y)^{T}x(ATy)Tx —— 「把 AAA 从一边搬到另一边」全靠这条，它是后面「伴随算子」「对称矩阵」全部内容的起点。

⚠️ 转置依赖基的选取（需要用对偶基），而下一节的共轭转置（A∗A^{*}A∗）在标准正交基下才等于「伴随算子的矩阵」。把两者混同是初学最常见的事故。

⚠️ 别把 (AB)T=BTAT(AB)^{T} = B^{T}A^{T}(AB)T=BTAT 记成 ATBTA^{T}B^{T}ATBT：只有当 A,BA, BA,B 都是方阵且碰巧可交换时才可能对，一般不成立。
