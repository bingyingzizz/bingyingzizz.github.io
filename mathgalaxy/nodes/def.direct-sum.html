直和与补空间

直和 V=U⊕WV = U \oplus WV=U⊕W 与补空间

陈述

设 U,W⊆VU, W \subseteq VU,W⊆V 是子空间。称 VVV 是 UUU 与 WWW 的（内部）直和，记

V=U⊕WV = U \oplus WV=U⊕W

当且仅当

  • U+W=VU + W = VU+W=V（每个向量都能写成 u+wu + wu+w），
  • U∩W={0}U \cap W = \{0\}U∩W={0}（写法唯一）。

此时每个 v∈Vv \in Vv∈V 都唯一地写成 v=u+wv = u + wv=u+w；映射 (u,w)↦u+w(u, w) \mapsto u + w(u,w)↦u+w 是线性同构 U×W≅VU \times W \cong VU×W≅V。称 WWW 是 UUU 在 VVV 中的补空间。

说明

⭐ 直和的两条 = 「存在性」+「唯一性」，与基的定义（生成 + 无关）是同一个模式。这也解释了为什么一条都不能少：U+W=VU + W = VU+W=V 管存在、U∩W=0U \cap W = 0U∩W=0 管唯一。

⭐ 补空间总是存在（有限维或一般情形都可以用 Zorn 引理把 UUU 的基扩成 VVV 的基，取新增向量张成 WWW），但不唯一（R2\mathbb{R}^{2}R2 里 xxx 轴的补空间可以是任意另一条过原点的直线）。

⚠ 与「商空间」的分工：V/UV/UV/U 是压掉 UUU，U⊕WU \oplus WU⊕W 是拆开 VVV。有补空间时 V/U≅WV/U \cong WV/U≅W（由第一同构定理），但一般情形没有这种拆法。
