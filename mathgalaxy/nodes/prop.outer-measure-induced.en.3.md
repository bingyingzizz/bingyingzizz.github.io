# outer measure induced by a premeasure　`prop.outer-measure-induced`
English entry · root `../`
[in graph](../#n=prop.outer-measure-induced)　·　[Chinese page (authoritative)](./prop.outer-measure-induced.md)

Why require $X \in \mathcal{E}$: to guarantee that $A \subseteq X$ always has a cover, so that the infimum is not taken over the empty set.

⚠ This step uses only $\rho (\emptyset ) = 0$, **not additivity** — so in general $\mu^{*}$ does not recover $\rho$. Recovering it is precisely Carathéodory's job.
