又称函数·实值函数·复值函数·多元函数·function

陈述

设 f:X→Yf : X \to Yf:X→Y 是映射。若它的取值落在数集里 —— 即 Y⊆RY \subseteq \mathbb{R}Y⊆R 或 Y⊆CY \subseteq \mathbb{C}Y⊆C —— 就叫 fff 是一个函数。

按中学课本的说法是「数集到数集的映射」；本图把定义域那一边放宽：XXX 可以是任意集合（测度空间、拓扑空间、甚至另一个函数空间）。

说明

⭐ 为什么要和「映射」分开：「映射」是集合层面最一般的说法（几何体之间、群之间、函子之间都用它）；「函数」专指取值在数集的那些 —— 只有输出是数，才谈得上加减乘、大小、取极限、求导、求积分。图里出现「函数」的地方几乎都在用这些结构。

常用叫法：Y=RY = \mathbb{R}Y=R 的叫实值函数，Y=CY = \mathbb{C}Y=C 的叫复值函数，Rn→R\mathbb{R}^{n} \to \mathbb{R}Rn→R 的叫多元函数。

⚠️ 中学课本的定义是「数集到数集的映射」。本图只要求陪域是数集：f:X→Rf : X \to \mathbb{R}f:X→R 里 XXX 完全可以是一般的集合 —— 否则「可测函数」「连续函数」「LpL^{p}Lp 里的函数」都得另起名字，反而更绕。定义域也要求是数集的话，那些全都不是函数了。
