# Hamiltonian Vector Field　`def.hamiltonian-vector-field`
English entry · root `../`
[in graph](../#n=def.hamiltonian-vector-field)　·　[Chinese page (authoritative)](./def.hamiltonian-vector-field.md)

⚠️ **Hamiltonian vector field $\ne$ arbitrary vector field**: It is the gradient of $H$ rotated by 90°.

The criterion is that $\iota_{X}\omega$ is **closed** (that is, $d(\iota_X\omega)=0$).

The nonclosed case is called a ‘locally Hamiltonian vector field,’ and the closed case a ‘symplectic vector field.’ Most books do not distinguish the two (since they coincide when $H^{1}(M) = 0$).

⚠️ A vector field on a symplectic manifold need not arise from some $H$ ($\iota_{X}\omega$ must be exact). Thus symplectic vector fields form a broader class than Hamiltonian vector fields.
