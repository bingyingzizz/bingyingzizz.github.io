Statement

Let RRR be a ring with identity, MMM a right RRR-module and NNN a left RRR-module. Take the free abelian group F:=Z(M×N)F := \mathbb{Z}^{(M \times N)}F:=Z(M×N) with basis M×NM \times NM×N, and let K⊆FK \subseteq FK⊆F be the subgroup generated by all elements of the form

M⊗RN:=F/K,m⊗n:=[ (m,n) ].M \otimes_{R} N := F / K, \qquad m \otimes n := [\,(m, n)\,].M⊗R​N:=F/K,m⊗n:=[(m,n)].

Its elements are finite sums ∑imi⊗ni\sum_{i} m_{i} \otimes n_{i}∑i​mi​⊗ni​ of pure tensors m⊗nm \otimes nm⊗n.

Thus the relations are the two additivity relations and one balanced relation mr⊗n=m⊗rnm r \otimes n = m \otimes r nmr⊗n=m⊗rn;

moreover, for every balanced biadditive map B:M×N→PB : M \times N \to PB:M×N→P (PPP an abelian group), there is a unique group homomorphism

B~:M⊗RN⟶P,B~(m⊗n)=B(m,n).\widetilde{B} : M \otimes_{R} N \longrightarrow P, \qquad \widetilde{B}(m \otimes n) = B(m, n).B:M⊗R​N⟶P,B(m⊗n)=B(m,n).

If RRR is commutative, r⋅(m⊗n):=(mr)⊗nr \cdot (m \otimes n) := (m r) \otimes nr⋅(m⊗n):=(mr)⊗n makes M⊗RNM \otimes_{R} NM⊗R​N an RRR-module.

Notes

How to read it: each of the three relations does one job — the first two say that ⊗\otimes⊗ is additive in each variable separately, and the third mr⊗n=m⊗rnm r \otimes n = m \otimes r nmr⊗n=m⊗rn says "the action of RRR can be moved from one side to the other". Over a commutative ring the third reads rm⊗n=m⊗rnr m \otimes n = m \otimes r nrm⊗n=m⊗rn, which is the most familiar form.

Elements are not pure tensors: a general element is a finite sum, so "whether ∑mi⊗ni\sum m_{i} \otimes n_{i}∑mi​⊗ni​ is zero" cannot be checked term by term. A pure tensor can still be zero: Z/2⊗ZZ/3=0\mathbb{Z}/2 \otimes_{\mathbb{Z}} \mathbb{Z}/3 = 0Z/2⊗Z​Z/3=0, because

1⊗1=(3⋅1)⊗1=1⊗(3⋅1)=1⊗0=0.1 \otimes 1 = (3 \cdot 1) \otimes 1 = 1 \otimes (3 \cdot 1) = 1 \otimes 0 = 0 .1⊗1=(3⋅1)⊗1=1⊗(3⋅1)=1⊗0=0.

⭐ The construction is basis-free: the universal property says that every object converting bilinear maps into linear ones is isomorphic to it, so another construction (for example a free module followed by a quotient) gives the same thing.
