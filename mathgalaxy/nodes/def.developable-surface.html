又称可展曲面

陈述

在做什么：刻画「纸能卷、不能拉」的那些曲面 —— 把一张纸弯成的正是可展曲面。几何上就是高斯曲率恒为零。

称正则曲面 Σ\SigmaΣ 为可展曲面（developable surface），若它局部等距于平面：每点有邻域与平面某开集之间可建立保长度的对应。

等价刻画（见 可展的判据）：

  1. 高斯曲率恒为零：K≡0K \equiv 0K≡0；
  2. Σ\SigmaΣ 是直纹面且沿每条母线切平面不变（法向量与母线参数无关）；
  3. 高斯映射像是一条曲线（秩 ≤1\le 1≤1）。

局部只有三类：柱面（母线平行）、锥面（母线交于一点）、切线面（母线是某条空间曲线的切线）。

说明

为什么「纸能卷不能拉」就是 K≡0K \equiv 0K≡0：纸不可拉伸   ⟹  \implies⟹ 弯曲时第一基本形式不变   ⟹  \implies⟹ 等距；由 Gauss 绝妙定理（绝妙定理）KKK 只依赖第一基本形式   ⟹  \implies⟹ KKK 不变。平面 K=0K = 0K=0，所以纸弯成的曲面必须 K=0K = 0K=0；反过来 K=0K = 0K=0 也能摊平（这就是「可展」名字的来历）。

⭐ 三类从哪来：把直纹面写成 X=a(u)+v b(u)X = a(u) + v\,b(u)X=a(u)+vb(u)，「切平面沿母线不变」等价于 det⁡(a′,b,b′)=0\det(a', b, b') = 0det(a′,b,b′)=0。于是 b′=0b' = 0b′=0 得柱面；存在定点 qqq 与函数 λ\lambdaλ 使 a=q+λba = q + \lambda ba=q+λb（母线全过 qqq）得锥面 —— 注意这不是「a′∥ba' \parallel ba′∥b」：圆锥 a=b=(cos⁡u,sin⁡u,1)a = b = (\cos u, \sin u, 1)a=b=(cosu,sinu,1) 时 a′=b′a' = b'a′=b′ 与 bbb 并不平行；其余得切线面。⚠️ 这是局部分类，全局还有拼接与自交问题。

⚠️ K≡0K \equiv 0K≡0 时一定写成直纹面吗：不。若允许成片的平坦点（两主曲率同时为零），曲面仍可展（就是平面），但不一定能写成「沿母线切平面不变」的参数式。严格定义应取「局部等距于平面」，那一半恒成立。
