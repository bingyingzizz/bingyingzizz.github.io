# Hermitian and Symmetric Matrices　`def.hermitian-matrix`

[in graph](../#n=def.hermitian-matrix)　·　[Chinese page (authoritative)](./def.hermitian-matrix.md)

A real symmetric matrix is the special case of a Hermitian matrix where $A$ takes real values; in that case (iv) can be written as $Q^{T}AQ$ is diagonal, with $Q$ orthogonal.

## Notes · **draft**
**Why the eigenvalues are real**: take an eigenvector $x \ne 0$ with $Ax = \lambda x$; then $\lambda\langle x, x\rangle = \langle Ax, x\rangle = \langle x, Ax\rangle = \overline{\lambda}\langle x, x\rangle$ — the second step uses self-adjointness.

Hence $\lambda = \overline{\lambda}$.
