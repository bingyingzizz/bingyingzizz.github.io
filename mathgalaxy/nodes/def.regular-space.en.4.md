# Regular Space　`def.regular-space`
English entry · root `../`
[in graph](../#n=def.regular-space)　·　[Chinese page (authoritative)](./def.regular-space.md)

⚠️ **Regular does not imply normal**: the Sorgenfrey plane is regular but not normal. So "regular" is not a weaker version of "normal" on the same axis — they separate **differently shaped** objects (point/closed set vs closed set/closed set).

⭐ Relation to `thm.paracompact-hausdorff-normal`: "step 1" of that theorem proves "paracompact Hausdorff $\implies$ regular", using precisely the form $\overline{U} \subseteq W$ of $T_{3}$.
