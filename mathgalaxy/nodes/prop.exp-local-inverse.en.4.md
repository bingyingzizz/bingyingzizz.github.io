# local inverse of the exponential　`prop.exp-local-inverse`
English entry · root `../`
[in graph](../#n=prop.exp-local-inverse)　·　[Chinese page (authoritative)](./prop.exp-local-inverse.md)

⭐ **Local versus global**: a local inverse always exists, but a **global** $\log$ does not (going once around the origin adds $2\pi$ to the argument). Whether the pieces glue into a global function is exactly the question answered by `prop.single-valued-branch`, and the answer is that the winding number must be $0$.

⚠ Number of sheets: $e^{z}$ maps each horizontal strip $\{a < \operatorname{Im} z < a + 2\pi\}$ biholomorphically onto $\mathbb{C}\setminus\{0\}$, so the logarithm has infinitely many branches, any two differing by $2\pi i k$.
