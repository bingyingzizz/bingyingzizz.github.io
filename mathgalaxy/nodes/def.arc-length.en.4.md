# Arc Length　`def.arc-length`
English entry · root `../`
[in graph](../#n=def.arc-length)　·　[Chinese page (authoritative)](./def.arc-length.md)

**Notation discipline**: a dot means differentiation with respect to **arc length** ($\dot\gamma = T$, $\ddot\gamma = \kappa N$), while a prime means differentiation with respect to an **arbitrary** parameter. Mixing them produces a missing factor of $\lVert\gamma'\rVert$ — the most common copying error in curve theory.

⚠️ Arc length uses only the **inner product**, no other structure of the ambient space, so it carries over verbatim to Riemannian manifolds: replace $\lVert\gamma'\rVert$ by $\sqrt{g(\dot\gamma,\dot\gamma)}$ to get the length in `def.riemannian-metric`.
