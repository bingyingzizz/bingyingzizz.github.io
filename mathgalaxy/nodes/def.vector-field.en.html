Statement

What it says: at each point choose a tangent vector, and choose it smoothly as the point varies — that is a vector field. Its real identity is "the operator that takes directional derivatives of smooth functions".

Let MMM be a smooth manifold. A vector field on MMM is a map X:M→TMX : M \to TMX:M→TM such that π∘X=id⁡M\pi \circ X = \operatorname{id}_{M}π∘X=idM​ (each point is assigned a tangent vector at that point). If XXX is smooth as a map M→TMM \to TMM→TM, call it a smooth vector field; the set of all of them is denoted X(M)\mathfrak{X}(M)X(M).

Notes

"Smooth" is the only delicate point: merely "choose a tangent vector at each point" is a set-theoretic choice and can be extremely pathological. Smoothness pins it down to nnn smooth functions in local coordinates, so all of calculus carries over — this is also the use of the equivalence "vector field = derivation".

X(M)\mathfrak{X}(M)X(M) is a C∞(M)C^{\infty}(M)C∞(M)-module: X+YX + YX+Y and fXfXfX (with fff smooth) are again vector fields. So vector fields are not objects to be "added pointwise into numbers" but elements of a module — on the same level as "df\mathrm{d}fdf is a 111-form".

A nowhere-vanishing vector field need not exist: locally always, globally not. On S2S^{2}S2 none exists (hairy ball theorem); on S1S^{1}S1, S3S^{3}S3 and the torus they do. "Whether zeros exist" is the origin of the Poincaré–Hopf theorem and characteristic classes; this map only mentions it.

Coordinate change: expanding in two local coordinate systems, the components satisfy Xyi=∑j∂yi∂xjXxjX_{y}^{i} = \sum_{j}\frac{\partial y^{i}}{\partial x^{j}}X_{x}^{j}Xyi​=∑j​∂xj∂yi​Xxj​ — the XiX^{i}Xi on the two sides belong to different coordinate systems and must be written separately (for y=2xy = 2xy=2x and X=∂xX = \partial_{x}X=∂x​, the xxx component is 111 and the yyy component is 222, so using one symbol would produce the absurd 1=21 = 21=2). This is the same transformation law as for tangent vectors (contravariant). This is what "XXX is a tensor field of type (1,0)(1,0)(1,0)" means (张量场).

On support: write supp⁡X\operatorname{supp} XsuppX for the closure of "where XXX is nonzero". The partition-of-unity argument needs exactly "support contained in a chart", so this is the same notation supp⁡\operatorname{supp}supp as in 单位分解 (光滑单位分解).

Relation to integral curves: a vector field gives the first-order ODE γ˙=X(γ)\dot\gamma = X(\gamma)γ˙​=X(γ), whose solutions are integral curves; local solutions always exist, while global ones need not extend.
