在做什么：同调群 Hn=Zn/BnH^{n} = Z^{n}/B^{n}Hn=Zn/Bn 的元素。它是同调代数里真正被搬运、被比较的对象 —— 定理说得再好，最后总是落在一句「这两个上同调类相等」。

设 KKK 是复形。对闭链 z∈Zn(K)z \in Z^{n}(K)z∈Zn(K)，它在商里的像

[z]:=z+Bn(K)∈Hn(K)[z] := z + B^{n}(K) \in H^{n}(K)[z]:=z+Bn(K)∈Hn(K)

[z]=0  ⟺  z 是上边缘.[z] = 0 \iff z \ \text{是上边缘} .[z]=0⟺z 是上边缘.

所以「Hn=0H^{n} = 0Hn=0」这句话的完整意思是：每个闭链都恰当（每个上同调类都是零类）。

说明

⭐ 类 ≠\ne= 代表：同一个上同调类有无穷多个代表（差任意上边缘）。所有关于类的运算都必须先验证「换代表不改变结果」—— 这就是同调代数里每一次「良定义性」检查的来源。模掉 BnB^{n}Bn 的唯一目的就是让这种检查变成一句话。

几何含义：de Rham 情形下 [ω]∈HdRk(M)[\omega] \in H^{k}_{dR}(M)[ω]∈HdRk​(M) 是「ω\omegaω 的积分只依赖同调类」的那一半 —— Stokes 定理说 ∫cω\int_{c} \omega∫c​ω 在 ω↦ω+dη\omega \mapsto \omega + d\etaω↦ω+dη 与 c↦c+∂bc \mapsto c + \partial bc↦c+∂b 下都不变，于是它其实是上同调类与同调类的配对 Hk×Hk→RH^{k} \times H_{k} \to \mathbb{R}Hk×Hk​→R。

这条配对是 de Rham 定理的骨架。
