说明

两者都积性（不是完全积性）：nnn 的因数由各素因子的指数独立选取，于是 τ\tauτ 与 σ\sigmaσ 在互素的两个数上相乘。

σ(n)=2n\sigma(n) = 2nσ(n)=2n 的 nnn 叫完全数（6=1+2+36 = 1+2+36=1+2+3、282828、496496496）；σ(n)<2n\sigma(n) < 2nσ(n)<2n 叫亏数、>2n> 2n>2n 叫盈数。奇完全数是否存在仍未解决 —— 这是数论里最老的未解问题之一。

「τ\tauτ 的平均阶是 log⁡n\log nlogn」等价于「调和级数发散」：∑n≤xτ(n)=xlog⁡x+O(x)\sum_{n \le x} \tau(n) = x\log x + O(x)∑n≤x​τ(n)=xlogx+O(x)，这就是 Dirichlet 的除数问题。
