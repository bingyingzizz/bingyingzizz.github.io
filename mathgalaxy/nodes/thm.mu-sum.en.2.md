# sum of the Möbius function over divisors　`thm.mu-sum`
English entry · root `../`
[in graph](../#n=thm.mu-sum)　·　[Chinese page (authoritative)](./thm.mu-sum.md)

$$\sum_{d\mid n}\mu(d) = \sum_{S \subseteq \{1,\cdots,r\}} (-1)^{\#S} = (1 - 1)^{r} = 0 .$$

This is the binomial expansion. This identity is the **only** use of $\mu$ here. It turns summation into projection onto $n = 1$.
