# simplicial approximation　`thm.simplicial-approximation`
English entry · root `../`
[in graph](../#n=thm.simplicial-approximation)　·　[Chinese page (authoritative)](./thm.simplicial-approximation.md)

The stars of a collection of vertices in $L$ have nonempty intersection if and only if the vertices span a simplex ($\bigcap \operatorname{st}(w_{i})$ is precisely the interior of the simplex with vertex set $\{w_{i}\}$, and if it is nonempty, that simplex exists). Thus $\{g(v_{0}), \ldots, g(v_{p})\}$ span a simplex of $L$, and $g$ is simplicial.
