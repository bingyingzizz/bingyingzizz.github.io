ℝ 是完备度量空间

定理：(R,∣x−y∣)(\mathbb{R}, |x - y|)(R,∣x−y∣) 是完备度量空间

陈述

在 R\mathbb{R}R 上取距离 d(x,y):=∣x−y∣d(x, y) := |x - y|d(x,y):=∣x−y∣。则 (R,d)(\mathbb{R}, d)(R,d) 是完备度量空间：其中每个 Cauchy 列都收敛。

这正是 Cauchy 收敛准则用距离空间的语言重写一遍 —— 一句话：R\mathbb{R}R 是完备的。

说明

⭐ 这是两条线的接口：一边是「R\mathbb{R}R 是完备有序域」（确界原理），另一边是「XXX 是完备度量空间」（每个 Cauchy 列收敛）。在 R\mathbb{R}R 上两者重合，但它们来源不同：前者是序性质，后者是度量性质。

⭐ 顺着这条边往外走，就是完备化：任何度量空间都能嵌进一个完备度量空间（拿 Cauchy 列取商），而 R\mathbb{R}R 的构造正是它的原型 —— 把 Q\mathbb{Q}Q 完备化就是 R\mathbb{R}R。

⚠ 一般度量空间里「完备」与「紧」是两回事：R\mathbb{R}R 完备但不紧。

    Cauchy 准则   ⟹  \implies⟹ R\mathbb{R}R 完备

    把 Cauchy 准则的结论逐字翻译成距离空间的语言：R\mathbb{R}R 中的 Cauchy 列（即 ∀ε>0,∃N,∀m,n≥N:d(xm,xn)<ε\forall \varepsilon > 0, \exists N, \forall m, n \ge N : d(x_m, x_n) < \varepsilon∀ε>0,∃N,∀m,n≥N:d(xm​,xn​)<ε）都收敛，这恰恰就是「(R,d)(\mathbb{R}, d)(R,d) 完备」的定义。故不需要新的论证。∎

    这条边的作用是把两套语言对上：序那一侧的「确界原理」与度量那一侧的「完备」在 R\mathbb{R}R 上说的是同一件事。
