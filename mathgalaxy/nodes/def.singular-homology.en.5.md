# singular homology groups　`def.singular-homology`
English entry · root `../`
[in graph](../#n=def.singular-homology)　·　[Chinese page (authoritative)](./def.singular-homology.md)

⭐ **Why allow such a flood of singular simplices**: this way **every continuous map** can act, so no triangulation and no niceness hypothesis is needed, and the theory is defined for **every** topological space (indeed every pair of spaces).

The cost is that $S_{p}(X)$ is usually enormous (countability requires extra hypotheses), so direct computation is almost impossible — practical computations rely on long exact sequences (`thm.long-exact-pair`), Mayer–Vietoris (`thm.mv-homology`), and "singular $=$ simplicial" (`thm.simplicial-approximation`).
