# First Fundamental Form　`def.first-fundamental-form`
English entry · root `../`
[in graph](../#n=def.first-fundamental-form)　·　[Chinese page (authoritative)](./def.first-fundamental-form.md)

⚠️ **"Orientation compatible" cannot be dropped**: $\omega^{1}\wedge\omega^{2}$ equals $\sqrt{EG-F^{2}}\,\mathrm{d}u\,\mathrm{d}v$ only when the coframe is compatible with the parameter orientation. Counterexample: on the plane $r(u,v) = (u,v,0)$ take the orthonormal unit coframe $\omega^{1} = \mathrm{d}u$, $\omega^{2} = -\mathrm{d}v$; then $\omega^{1}\wedge\omega^{2} = -\mathrm{d}u\wedge\mathrm{d}v$, so the sign is reversed. Area itself is a **density** and requires $\lvert\omega^{1}\wedge\omega^{2}\rvert$ (see the edge on the area element).
