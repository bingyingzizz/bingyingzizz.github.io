# Grothendieck universe axiom　`ax.grothendieck-universe`
English entry · root `../`
[in graph](../#n=ax.grothendieck-universe)　·　[Chinese page (authoritative)](./ax.grothendieck-universe.md)

⭐ A common equivalent form: **strongly inaccessible cardinals are unbounded** — for every ordinal $\alpha$ there is a strongly inaccessible cardinal $\kappa > \alpha$, and then $V_{\kappa}$ itself is a universe.

## Notes · **draft**
It is **not in ZFC**. Taking a strongly inaccessible cardinal $\kappa$, $V_{\kappa} \models \mathrm{ZFC}$, so this axiom implies $\mathrm{Con}(\mathrm{ZFC})$; by Gödel's second incompleteness theorem, ZFC cannot prove it if consistent. So any theorem using it must list it as a hypothesis, not assume it silently.
