The nilpotent elements form an ideal: for any $h$, if $hf$ is invertible then $f$ has a left inverse, and in finite dimension $f$ is invertible, a contradiction; hence $hf$ is a non-unit and nilpotent; the same holds for $fh$.
Thus the nilpotent elements form a two-sided ideal; every nonzero element of the quotient ring is invertible, so the quotient is a division ring. This makes the ring local, with maximal ideal exactly the nilpotent elements.
