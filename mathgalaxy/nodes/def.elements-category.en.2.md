# category of elements　`def.elements-category`
English entry · root `../`
[in graph](../#n=def.elements-category)　·　[Chinese page (authoritative)](./def.elements-category.md)

One calls $(X, s)$ a **universal element** of $F$ if it is an initial object of $\operatorname{el}(F)$.

## Notes · **draft**
This explains the word "**universal**" once and for all: **universal = an initial (or terminal) object in some auxiliary category**. Thus "universal cone", "universal factorization" and "universal element" are three applications of the same slogan.

Examples: $\mathbb{Z}$ is the initial object of the category of rings, so it is "universal among all rings"; the universal cone on the empty diagram is the terminal object; a limit is the terminal object of the category of cones.
