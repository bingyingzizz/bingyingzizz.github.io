# pointwise limit of uniformly bounded operators　`cor.ubp-pointwise-limit`
English entry · root `../`
[in graph](../#n=cor.ubp-pointwise-limit)　·　[Chinese page (authoritative)](./cor.ubp-pointwise-limit.md)

**Uniform boundedness.** Apply the uniform boundedness principle to the family $\{u_n\} \subseteq B(E, F)$ ($E$ complete, $F$ normed): $C := \sup_n \|u_n\| < \infty$.

**Norm bound.** For any $x$,

$$\|u x\| = \lim_n \|u_n x\| = \liminf_n \|u_n x\| \le \liminf_n \bigl( \|u_n\| \, \|x\| \bigr) = \bigl( \liminf_n \|u_n\| \bigr) \|x\| ,$$

so $u$ is bounded with $\|u\| \le \liminf_n \|u_n\|$. $\blacksquare$
