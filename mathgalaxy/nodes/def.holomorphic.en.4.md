# Holomorphic Function　`def.holomorphic`
English entry · root `../`
[in graph](../#n=def.holomorphic)　·　[Chinese page (authoritative)](./def.holomorphic.md)

⭐ An equivalent formulation of complex differentiability is $\Delta f = A\,\Delta z + o(\Delta z)$ — the increment is **only** a linear function of $\Delta z$, and $\overline{\Delta z}$ may not appear.

In partial-derivative language this is $\partial f/\partial \bar z = 0$ (see the Cauchy–Riemann equations).

📌 Sums, products, quotients (with nonzero denominator) and composites of holomorphic functions are holomorphic, with the same derivative formulas as in the real case — because these are only the arithmetic of limits and never use the realness of $h$.
