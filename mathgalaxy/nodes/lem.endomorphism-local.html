Statement draft

Let VVV be a finite-dimensional indecomposable representation. Then End⁡A(V)\operatorname{End}_A(V)EndA​(V) is a local ring whose maximal ideal is exactly the set of nilpotent endomorphisms.

Notes draft

By cor.indecomposable-endomorphism, every f∈End⁡A(V)f\in\operatorname{End}_A(V)f∈EndA​(V) is either an automorphism or nilpotent; in particular, the non-units are exactly the nilpotent elements. The nilpotent elements are closed under addition (no commutativity is assumed): let f,gf,gf,g be nilpotent. If f+gf+gf+g is invertible, set u=(f+g)−1gu=(f+g)^{-1}gu=(f+g)−1g. If uuu is invertible, then g=(f+g)ug=(f+g)ug=(f+g)u is invertible, contradicting that ggg is nilpotent; so uuu is a non-unit, and by the corollary uuu is nilpotent. Then id⁡−u\operatorname{id}-uid−u is invertible, and (f+g)−1f=id⁡−u(f+g)^{-1}f=\operatorname{id}-u(f+g)−1f=id−u, so f=(f+g)(id⁡−u)f=(f+g)(\operatorname{id}-u)f=(f+g)(id−u) is invertible, contradicting that fff is a non-unit. Therefore f+gf+gf+g is a non-unit, and the corollary makes it nilpotent. The nilpotent elements form an ideal: for any hhh, if hfhfhf is invertible then fff has a left inverse, and in finite dimension fff is invertible, a contradiction; hence hfhfhf is a non-unit and nilpotent; the same holds for fhfhfh. Thus the nilpotent elements form a two-sided ideal; every nonzero element of the quotient ring is invertible, so the quotient is a division ring. This makes the ring local, with maximal ideal exactly the nilpotent elements.
