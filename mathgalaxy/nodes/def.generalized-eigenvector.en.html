Statement

What it does: when eigenvectors are not enough (geometric multiplicity < algebraic multiplicity), one steps back: instead of requiring T(v)=λvT(v) = \lambda vT(v)=λv, one only requires that repeated application be killed by λ\lambdaλ after finitely many steps. This makes up the dimension.

Notes

Why this makes up the dimension: T−λIT - \lambda IT−λI is zero on VλV_{\lambda}Vλ​, but on GλG_{\lambda}Gλ​ it is nilpotent (def.nilpotent).

Nilpotent operators have a very simple structure (a chain), so restricting TTT to GλG_{\lambda}Gλ​ gives "λI\lambda IλI + a nilpotent operator" — this is precisely a Jordan block.

Meaning of the order: k=1k = 1k=1 is an ordinary eigenvector; k=2k = 2k=2 means T(v)=λv+uT(v) = \lambda v + uT(v)=λv+u (uuu is an eigenvector) — this is the second term of a Jordan chain. So "generalized eigenvector" = "a point on a Jordan chain".
