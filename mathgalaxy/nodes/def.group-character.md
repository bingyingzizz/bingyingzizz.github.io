# 群特征标　`def.group-character`
群特征标
layer 25 · 定义 · 群与代数表示 · 抽象代数
[在星图里打开](../#n=def.group-character)　·　[节点索引](../index.md)

设 $(V,\rho)$ 是有限群 $G$ 的有限维表示。其特征标是 $\chi_\rho:G\to F$，$\chi_\rho(g)=\operatorname{tr}\rho(g)$。它满足 $\chi_\rho(1)=\dim V$，且在共轭类上为常数。
