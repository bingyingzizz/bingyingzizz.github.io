# lifting theorem　`thm.lifting`
English entry · root `../`
[in graph](../#n=thm.lifting)　·　[Chinese page (authoritative)](./thm.lifting.md)

**(2) Homotopy lifting.** For any homotopy $F : [0, 1] \times [0, 1] \to B$ with $F(0, 0) = b_{0}$, there exists a **unique**
lift $\tilde{F} : [0, 1] \times [0, 1] \to E$ such that $\tilde{F}(0, 0) = e_{0}$ and $p \circ \tilde{F} = F$.
If $F$ is a path homotopy relative to its endpoints, then both endpoints of $\tilde{F}$ are also fixed for every $s$.

## Notes · **draft**
**Proof outline.** Use a Lebesgue number to subdivide the path or homotopy into pieces, each lying in an evenly covered open set, and lift the pieces uniquely in succession. See the edge `imp.lifting-proof` for the full proof.
