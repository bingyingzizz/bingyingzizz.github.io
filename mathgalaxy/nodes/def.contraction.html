设 (X,d)(X, d)(X,d) 是度量空间，T:X→XT : X \to XT:X→X。TTT 叫压缩映射，当且仅当存在常数 q∈[0,1)q \in [0, 1)q∈[0,1) 使

最小的这样的 qqq 叫 TTT 的压缩系数。（q=1q = 1q=1 时叫非扩张映射，那时结论会变。）

说明

⚠ 关键是 q<1q < 1q<1 必须一致成立，而不是「每点附近小于 111」。反例：f(x)=x+1/xf(x) = x + 1/xf(x)=x+1/x 在 [1,∞)[1, \infty)[1,∞) 上满足 ∣f′(x)∣=1−1/x2<1|f'(x)| = 1 - 1/x^{2} < 1∣f′(x)∣=1−1/x2<1 处处成立，但它不是压缩映射，也没有不动点（f(x)=xf(x) = xf(x)=x 无解）。「每点局部收缩」与「整体一致收缩」的差别就是这条定理的生死线。

⭐ 压缩   ⟹  \implies⟹ 一致连续（def.uniform-continuity），比连续强得多；而且 Lipschitz 常数就是 qqq。

⭐ 压缩映射是唯一一类「存在性证明顺带给出算法与误差估计」的定理（见 thm.banach-fixed-point）—— 这是它在分析里地位极高的原因：逆映射定理、隐函数定理、常微分方程的 Picard–Lindelöf 定理、Bellman 方程，全都把它当引擎。
