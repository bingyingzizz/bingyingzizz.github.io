## Notes · **draft**
⚠ Values are allowed to be $\infty$, deliberately: integration is first defined for functions with values in $[0, +\infty ]$, and the convergence theorems (supremum / limits) are closed within all of $L^{+}$, so one need not keep asking whether an integral is finite.

“Integrable” (finite integral) is a condition added separately later, see the definition of $L^{1}$.
