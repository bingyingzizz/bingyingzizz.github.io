# Connection Form　`def.connection-form`
English entry · root `../`
[in graph](../#n=def.connection-form)　·　[Chinese page (authoritative)](./def.connection-form.md)

Expand $\mathrm{d}e_{i}$ in the frame, writing the coefficients as $\omega^{j}_{\ i}$:

$$\mathrm{d}e_{i} = \sum_{j=1}^{3}\omega^{j}_{\ i}\,e_{j},\qquad \omega^{j}_{\ i} = \langle \mathrm{d}e_{i}, e_{j}\rangle .$$

These nine $1$-forms are called **connection forms** ($\Gamma$-forms). The matrix $(\omega^{i}_{\ j})$ is skew-symmetric (see `prop.connection-antisymmetric`), so only three are independent: $\omega^{1}_{\ 2}, \omega^{1}_{\ 3}, \omega^{2}_{\ 3}$.
