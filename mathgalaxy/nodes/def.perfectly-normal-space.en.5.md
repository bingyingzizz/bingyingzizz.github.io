# Perfectly Normal Space　`def.perfectly-normal-space`
English entry · root `../`
[in graph](../#n=def.perfectly-normal-space)　·　[Chinese page (authoritative)](./def.perfectly-normal-space.md)

⚠️ **$T_{6} \implies T_{5}$ is not free**: one must use "countable intersection of open sets" to write the closed set as a zero set (Urysohn's lemma plus a $2^{-n}$ weighted series), then separate on a subspace by $f/(f+g)$ — details are in the edge "perfectly normal $\implies$ completely normal" in this file.

⚠️ **Convention**: the definition of perfect normality already includes normality, hence automatically $T_{1}$, and one need not add $T_{1}$.
