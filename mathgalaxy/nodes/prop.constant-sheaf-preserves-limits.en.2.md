# The Constant Sheaf Functor Preserves Limits　`prop.constant-sheaf-preserves-limits`
English entry · root `../`
[in graph](../#n=prop.constant-sheaf-preserves-limits)　·　[Chinese page (authoritative)](./prop.constant-sheaf-preserves-limits.md)

1. if $E = \varprojlim_{i} E_{i}$ is a limit in sets, then $\Delta E = \varprojlim_{i}\Delta E_{i}$;
2. the constant-sheaf functor $\underline{(-)}$ preserves **finite** limits: if $E = \varprojlim_{i} E_{i}$ is a finite limit, then $\underline{E} = \varprojlim_{i}\underline{E_{i}}$.
