Statement

A real-valued measurable fff is integrable iff ∫f+<∞\int f^+ < \infty∫f+<∞ and ∫f−<∞\int f^- < \infty∫f−<∞. Equivalently, fff is integrable iff the integral of ∣f∣|f|∣f∣ is finite:

A complex-valued measurable fff is integrable iff ∫∣f∣dμ<∞\int |f| d\mu < \infty∫∣f∣dμ<∞. The set of all integrable functions is denoted L1L^1L1.

Notes

⭐ Integrable   ⟺  \iff⟺ absolutely integrable: this is where the Lebesgue integral finally becomes convenient — because ∣f∣∈L+|f| \in L^{+}∣f∣∈L+, every theorem for the non-negative case applies directly.

(Compare the Riemann improper integral: there ∫f\int f∫f may converge while ∫∣f∣\int|f|∫∣f∣ diverges; this is called conditional convergence.)

⚠ Strictly speaking, the elements of L1L^{1}L1 are equivalence classes of functions (equal a.e. counts as the same), so "∫∣f∣=0  ⟹  f=0\int |f| = 0 \implies f = 0∫∣f∣=0⟹f=0" must be read a.e. This is the key step that later makes Lp spaces normed spaces.

Among the three equivalences, "∫∣f∣<∞\int|f| < \infty∫∣f∣<∞" is the most useful, but it presupposes f±f^{\pm}f±:

  • fff is integrable   ⟺  \iff⟺ ∫f+<∞\int f^{+} < \infty∫f+<∞ and ∫f−<∞\int f^{-} < \infty∫f−<∞: this is the definition (split fff into positive and negative parts, each a non-negative measurable function, and use the non-negative case).
  •   ⟺  \iff⟺ ∫∣f∣<∞\int \lvert f\rvert < \infty∫∣f∣<∞: one step (∣f∣=f++f−\lvert f\rvert = f^{+} + f^{-}∣f∣=f++f−), and it uses additivity of the non-negative integral. ⚠️ "∫f\int f∫f is finite" and integrability are not the same thing: if ∫f\int f∫f is a finite real number, then f±f^{\pm}f± are finite and fff is necessarily integrable; the danger is ∫f+=∫f−=+∞\int f^{+} = \int f^{-} = +\infty∫f+=∫f−=+∞, where ∫f\int f∫f is undefined (not 000) — which of course does not count as integrable. This is exactly why integrability requires absolute integrability.
  • fff measurable with ∣f∣≤g\lvert f\rvert \le g∣f∣≤g and ggg integrable   ⟹  \implies⟹ fff is integrable: this step needs monotonicity (积分的保序与估计).

⚠️ Necessary hypotheses: fff must be measurable (an unmeasurable function has no integral to speak of). The difference from Riemann integrability: Riemann requires boundedness plus a null set of discontinuities (可积 ⟺ 不连续点零测), whereas Lebesgue integrability does not require boundedness (1/x1/\sqrt{x}1/x​ is Lebesgue integrable on (0,1](0,1](0,1]); conversely, a bounded Riemann integrable function is Lebesgue integrable (Riemann 可积蕴含 Lebesgue 可积).
