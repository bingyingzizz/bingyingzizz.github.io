## Statement · **draft**
Let $\mathcal{T}$ be a topos and $S$ a set of **generators** for it. Then

$$\bigl\{\ \mathbb{Z}\cdot X \ :\ X \in S\ \bigr\}$$

is a set of generators for $\mathcal{T}(\mathbf{Ab})$.
