# an exact factor degenerates the spectral sequence　`prop.derived-functor-exact-factor`
English entry · root `../`
[in graph](../#n=prop.derived-functor-exact-factor)　·　[Chinese page (authoritative)](./prop.derived-functor-exact-factor.md)

Dually, if $G$ is exact, then $G\bigl(R^{n}F(K)\bigr) \cong R^{n}(G \circ F)(K)$.

## Notes · **draft**
**Proof.** The higher derived functors of an exact functor vanish, so $R^{q}F = 0$ ($q > 0$) ✓.

In the Grothendieck spectral sequence $E^{p,q}_{2} = R^{p}G(R^{q}F(K)) \implies R^{p+q}(G\circ F)(K)$, the $E_{2}$ page has only the $q = 0$ row left ✓, so the spectral sequence degenerates and $R^{n}(G\circ F)(K) \cong R^{n}G(F(K))$ ✓.

Dually, interchange $F,G$ (the other case uses that $G$ is exact $\implies$ $R^{p}G = 0$) ✓.
