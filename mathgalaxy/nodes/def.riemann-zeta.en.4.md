# Riemann zeta function　`def.riemann-zeta`
English entry · root `../`
[in graph](../#n=def.riemann-zeta)　·　[Chinese page (authoritative)](./def.riemann-zeta.md)

📌 **The value at $s = 2$**: $\zeta(2) = \pi^{2}/6$ (Euler); values at even integers are given by Bernoulli numbers, while at odd integers all that is known to this day is that $\zeta(3)$ is irrational (Apéry).

⚠ **The Riemann hypothesis** (unresolved): all non-trivial zeros lie on $\operatorname{Re}s = 1/2$. This library **does not** record it as a theorem; it notes here only what it asks — 📌 its value is that the location of the zeros of $\zeta$ is **equivalent** to an estimate for the error term in the distribution of primes, see `thm.prime-number-theorem`.
