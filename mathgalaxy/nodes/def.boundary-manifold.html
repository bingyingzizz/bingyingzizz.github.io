在做什么：把一个方向上砍掉一边，让「闭区间」「闭圆盘」这类带边的对象也成了流形 —— 有了它，「边界」才能有自己的维度、自己的积分、自己的 (n−1)(n-1)(n−1) 维几何。

记半空间

Hn:={x∈Rn:xn≤0},∂Hn={x∈Rn:xn=0}.\mathbb{H}^{n} := \{x\in\mathbb{R}^{n} : x^{n}\le 0\},\qquad \partial\mathbb{H}^{n} = \{x\in\mathbb{R}^{n} : x^{n} = 0\}.Hn:={x∈Rn:xn≤0},∂Hn={x∈Rn:xn=0}.

nnn 维带边流形是一个 Hausdorff、第二可数拓扑空间 MMM，带一族卡 (U,φ)(U,\varphi)(U,φ)：每个 U⊆MU\subseteq MU⊆M 开，φ:U→φ(U)\varphi : U\to\varphi(U)φ:U→φ(U) 是同胚，φ(U)\varphi(U)φ(U) 是 Hn\mathbb{H}^{n}Hn 的开子集，且任意两张卡的转移映射 ψ∘φ−1\psi\circ\varphi^{-1}ψ∘φ−1 光滑。

p∈Mp\in Mp∈M 叫内点，如果存在一张卡使 φ(p)n<0\varphi(p)^{n}<0φ(p)n<0；否则叫边界点。这两类与卡的选取无关。全部边界点记 ∂M\partial M∂M，全部内点记 Int⁡M\operatorname{Int}MIntM。

说明

「内点 / 边界点」为什么与卡无关：设某张卡给 φ(p)n<0\varphi(p)^{n}<0φ(p)n<0、另一张给 ψ(p)n=0\psi(p)^{n} = 0ψ(p)n=0。则 h:=ψ∘φ−1h := \psi\circ\varphi^{-1}h:=ψ∘φ−1 是开集之间的微分同胚，把点 φ(p)∈{xn<0}\varphi(p)\in\{x^{n}<0\}φ(p)∈{xn<0} 送到 {xn=0}\{x^{n} = 0\}{xn=0} 上。但 φ(p)\varphi(p)φ(p) 有一个整个含在 {xn<0}\{x^{n}<0\}{xn<0} 里的开球邻域，其像必含在 {xn=0}\{x^{n} = 0\}{xn=0} 里 —— 而后者没有内点，矛盾。所以「是不是边界点」属于 MMM，不属于坐标。

为什么用半空间而不是球：半空间白送一张坐标（x1,…,xn−1x^{1},\ldots,x^{n-1}x1,…,xn−1 沿边、xnx^{n}xn 指向内部），「边界」在坐标里就是一条方程 xn=0x^{n} = 0xn=0，要证的东西一步到位。球模型还得额外证明球面那块是流形，白干一遍。

边界不是「拓扑边界」：∂M\partial M∂M 是内蕴的一层 (n−1)(n-1)(n−1) 维皮，与有没有谁来包着 MMM 无关；拓扑意义上的边界要靠 MMM 先嵌在某个空间里才谈得上。两者只在嵌入的情形下碰头。

⚠️ 定向的约定（只在用到时交代）：∂M\partial M∂M 的诱导定向取「外法向在前」—— 若 (v1,…,vn−1)(v_{1},\ldots,v_{n-1})(v1​,…,vn−1​) 是 Tp∂MT_{p}\partial MTp​∂M 的基，它为正，当且仅当 (N,v1,…,vn−1)(N,v_{1},\ldots,v_{n-1})(N,v1​,…,vn−1​) 是 TpMT_{p}MTp​M 的正向基，NNN 是外单位法向。取 Hn\mathbb{H}^{n}Hn 的标准坐标时，这条等价于「用 x1,…,xn−1x^{1},\ldots,x^{n-1}x1,…,xn−1 的次序当定向，但与诱导定向差 (−1)n−1(-1)^{n-1}(−1)n−1」。这个符号在 prop.boundary-sign-convention 里会再出现一次，两处必须一致。

⚠️ 边界的边界是空的：∂(∂M)=∅\partial(\partial M) = \emptyset∂(∂M)=∅，因为 ∂M\partial M∂M 是无边流形（它的卡值域落在 Rn−1\mathbb{R}^{n-1}Rn−1 的开集里）。这一条让 Stokes 型公式能反复用而不会冒出「边界的边界」那一项。
