# Codazzi–Mainardi Equations　`thm.codazzi-mainardi`
English entry · root `../`
[in graph](../#n=thm.codazzi-mainardi)　·　[Chinese page (authoritative)](./thm.codazzi-mainardi.md)

In the frame version one only reads the $\omega^{1}\wedge\omega^{2}$ coefficient of $\mathrm{d}\omega^{i}_{\ 3}$, without touching Christoffel symbols.

⚠️ This simple shape holds only in codimension $1$ (surfaces in $\mathbb{R}^{3}$); in higher codimension the right-hand side acquires an extra normal-bundle curvature term. Only the codimension-one case inside $\mathbb{R}^{3}$ is used here.
