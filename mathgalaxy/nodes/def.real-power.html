说明

⭐ 思路一句话：用有理指数从下面逼近。有理指数靠 n 次方根定义，实数指数靠确界定义 —— 一层一层往上搭，每一步都不引入新的神秘对象。

⭐ 良定义要检查两件事：集合 {aq:q<x}\{a^{q} : q < x\}{aq:q<x} 非空（取 q<xq < xq<x，有理数稠密）且有上界（a>1a > 1a>1 时取 q<x+1q < x+1q<x+1，则 aq<ax+1a^{q} < a^{x+1}aq<ax+1）；上确界于是存在。

⭐ 与 exp / log 是同一件事：ax=exp⁡(xlog⁡a)a^{x} = \exp(x \log a)ax=exp(xloga)。但那条路要先有幂级数，这里只用确界 —— 所以 lem.young-inequality 里的 aλb1−λa^{\lambda}b^{1-\lambda}aλb1−λ（λ\lambdaλ 是实数）在这条定义下是有意义的。

⚠ 有理指数的指数律（ar+s=arasa^{r+s} = a^{r}a^{s}ar+s=aras 等）要对表示做消去，繁琐但不难；实数指数的指数律要用「上确界与加法相容」，是 prop.order-rules 与确界性质的练习。
