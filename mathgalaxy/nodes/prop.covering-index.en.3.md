## Notes · **draft**
⚠️⚠️ **This is a bijection of sets, not a group isomorphism.** The coset set $\pi_{1}(B)/p_{*}\pi_{1}(E)$ carries no group structure in general; from this alone one cannot get the **group** information $\pi_{1}(S^{1}) \cong \mathbb{Z}$ — only that $\pi_{1}(S^{1})$ and $\mathbb{Z}$ have the same cardinality. To get the isomorphism one must define **degree** and prove that it is a homomorphism; see `thm.pi1-circle`.
