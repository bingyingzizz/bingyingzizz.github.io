# Banach 代数　`def.banach-algebra`
Banach 代数

结合代数 $\mathcal{A}$ 配范数 $\|\cdot\|$ 叫 **Banach 代数**，若

1. $(\mathcal{A}, \|\cdot\|)$ 是 Banach 空间；
2. 乘法次可乘：$\|xy\| \le \|x\|\,\|y\|$。

若还有单位元且 $\|1\| = 1$，叫**含单位 Banach 代数**。
