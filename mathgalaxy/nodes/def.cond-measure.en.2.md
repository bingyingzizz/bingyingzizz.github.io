# integer-valued measures　`def.cond-measure`
English entry · root `../`
[in graph](../#n=def.cond-measure)　·　[Chinese page (authoritative)](./def.cond-measure.md)

Let $S$ be a profinite set (compact Hausdorff totally disconnected space), and denote the set of all $\mathbb{Z}$-linear homomorphisms on $C(S, \mathbb{Z})$ by

$$M(S, \mathbb{Z}) := \operatorname{Hom}_{\mathbb{Z}}\bigl(C(S, \mathbb{Z}),\ \mathbb{Z}\bigr).$$

More generally, for any abelian group $A$ write

$$M(S, A) := \operatorname{Hom}_{\mathbb{Z}}\bigl(C(S, \mathbb{Z}),\ A\bigr),$$

in particular $M(S, \mathbb{R})$ and $M(S, \mathbb{R}/\mathbb{Z})$ ($\mathbb{R}$-valued and $\mathbb{R}/\mathbb{Z}$-valued measures).
