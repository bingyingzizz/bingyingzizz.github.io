定理：简单闭多边形的补集恰有两个连通分量

又称Jordan polygon theorem·多边形 Jordan 定理

陈述

设 PPP 是 R2\mathbb{R}^{2}R2 中的简单闭多边形（有限条线段首尾相接、无自交点），KKK 是它围成的多边形区域。则 R2∖P\mathbb{R}^{2}\setminus PR2∖P 恰有两个连通分量：有界的那一个等于 int⁡K\operatorname{int}KintK，无界的那一个是 R2∖K\mathbb{R}^{2}\setminus KR2∖K；两者都以 PPP 为边界。

说明

证明结构：先证补集里有「射线交点奇偶」这个二值不变量（第一、二步），再用对角线引理 简单多边形的对角线 归纳出三角剖分（第三步），最后用三角剖分把补集分成两个开集、证明它们互不相通（第四至七步）。

约定。PPP 是简单闭多边形，KKK 是 PPP 围成的多边形区域（射线奇偶 Φ=1\Phi=1Φ=1 的一侧加上边界，见下），int⁡K\operatorname{int}KintK 是它的内部。结论：R2∖P\mathbb{R}^{2}\setminus PR2∖P 恰有两个连通分量，一个是 int⁡K\operatorname{int}KintK（有界），另一个是 R2∖K\mathbb{R}^{2}\setminus KR2∖K（无界），两者都以 PPP 为边界。

第一步：Φ\PhiΦ 良定义且局部常值。 把顶点按 yyy 坐标分组，相邻两组之间是一个开条带。在每个条带里，PPP 与它的交是一族互不相交的线段，每条都从条带下边界贯到上边界（否则会在条带内部出现顶点），所以它们是图 x=x1(y)<⋯<xj(y)x = x_1(y) < \cdots < x_j(y)x=x1​(y)<⋯<xj​(y)。对条带内的点 (x,y)(x,y)(x,y)，定义 Φ(x,y)=#{i:xi(y)<x} mod 2\Phi(x,y) = \#\{i : x_i(y) < x\} \bmod 2Φ(x,y)=#{i:xi​(y)<x}mod2。xix_ixi​ 连续，所以 Φ\PhiΦ 在条带内局部常值；yyy 穿过分界高度时，两侧的墙数之差是偶数（穿过一个顶点时两条边同时出现或同时消失），故 Φ\PhiΦ 在 R2∖P\mathbb{R}^{2}\setminus PR2∖P 上整体良定义、局部常值。

第二步：Φ\PhiΦ 取到两个值。 在 PPP 外取一个足够远的点，向左的射线不碰 PPP，Φ=0\Phi = 0Φ=0；取一条边的中点 mmm 与它的外法向 ν\nuν，点 m+ενm + \varepsilon\num+εν 在 PPP 外且紧邻这条边——沿该边的方向扰动可见它的左侧墙数恰与另一侧差 1，故 Φ=1\Phi = 1Φ=1。于是 Φ\PhiΦ 是满射到 {0,1}\{0,1\}{0,1}。

第三步：三角剖分（输入：简单多边形的对角线）。 对顶点数归纳：n=3n = 3n=3 时 KKK 本身就是一个三角形。n≥4n \ge 4n≥4 时由 简单多边形的对角线 取一条对角线，把 PPP 分成两个顶点数更少的简单多边形，分别归纳。结果：K=T1∪⋯∪Tn−2K = T_1 \cup \cdots \cup T_{n-2}K=T1​∪⋯∪Tn−2​，TiT_iTi​ 是闭三角形，两两内部不交，交集是公共边或公共顶点，且 ∂K=P\partial K = P∂K=P。

第四步：A:=K∖PA := K \setminus PA:=K∖P 道路连通。

（4a）对偶图连通，对顶点数 nnn 归纳。n=3n=3n=3 时剖分只有一个三角形，对偶图是单点。n≥4n\ge4n≥4 时，第三步用的是 简单多边形的对角线 给出的对角线 [a,b][a,b][a,b]，它把 PPP 分成 P1,P2P_1,P_2P1​,P2​（顶点数 n1,n2n_1,n_2n1​,n2​，n1+n2=n+2n_1+n_2=n+2n1​+n2​=n+2，各自都小于 nnn），PPP 的剖分就是两个子剖分之并。由归纳假设，两个子剖分的对偶图 Γ1,Γ2\Gamma_1,\Gamma_2Γ1​,Γ2​ 都连通。[a,b][a,b][a,b] 是 P1P_1P1​ 的边、也是 P2P_2P2​ 的边；在每个子剖分里含边 [a,b][a,b][a,b] 的三角形恰好一个——剖分覆盖整个子多边形、各三角形内部互不相交，故 [a,b][a,b][a,b] 的相对内部只落在一个三角形里，而含它的三角形必以 [a,b][a,b][a,b] 为一条边——记作 T1,T2T_1,T_2T1​,T2​。[a,b][a,b][a,b] 是内部对角线，T1,T2T_1,T_2T1​,T2​ 在 Γ\GammaΓ 里相邻，故 Γ=Γ1∪Γ2∪{T1T2}\Gamma=\Gamma_1\cup\Gamma_2\cup\{T_1T_2\}Γ=Γ1​∪Γ2​∪{T1​T2​} 连通。

（4b）AAA 道路连通。 AAA 是全部三角形挖掉 PPP 后的并（PPP 只落在三角形的落在 PPP 上的那些边上）。每一块 Ti∖PT_i \setminus PTi​∖P 道路连通：它是凸三角形去掉若干边的剩余部分，去掉的边都在它的边界上。相邻两块沿一条内部对角线相接，该对角线的相对内部既在 AAA 里又在两块的交里，所以可以就地把两块接起来。对偶图连通，故沿对偶图的路径可把任意两块接起来，从而 AAA 道路连通。

第五步：B:=R2∖KB := \mathbb{R}^{2}\setminus KB:=R2∖K 连通。 令 GGG 为剖分的 111-骨架（全部边之并）。R2∖G\mathbb{R}^{2}\setminus GR2∖G 的面就是 n−2n-2n−2 个三角形内部与唯一的外部面 EEE；每个三角形内部是它自己的一个（有界）面，EEE 是无界面。B=EB = EB=E：一方面 EEE 里的点不在任何三角形闭包里故不在 KKK 里，另一方面 KKK 外的点不在 GGG 上、也不在任何三角形内部，只能落在 EEE。开集的分量都是道路连通的（R2\mathbb{R}^{2}R2 局部道路连通），故 E=BE = BE=B 道路连通、且无界。

第六步：合起来恰两个分量。 AAA 与 BBB 都是开集、都非空、且 R2∖P=A⊔B\mathbb{R}^{2}\setminus P = A \sqcup BR2∖P=A⊔B：PPP 上的点被挖掉；不在 PPP 上的点要么在某三角形内部或内部边上（属于 KKK，即 AAA），要么不在 KKK 里（属于 BBB）。若有一条道路从 AAA 连到 BBB，它的像连通且含于两个不相交开集之并，只能落在其中一个里，矛盾。所以 AAA、BBB 就是全部两个分量：一个是有界的 int⁡K\operatorname{int}KintK 那一侧，一个是无界的 R2∖K\mathbb{R}^{2}\setminus KR2∖K。

第七步：边界。 A,BA,BA,B 都开，故 ∂A⊆P\partial A \subseteq P∂A⊆P、∂B⊆P\partial B \subseteq P∂B⊆P；反过来，PPP 上任一点 xxx 的任意小邻域里既有 AAA 的点（xxx 在 ∂K\partial K∂K 上）又有 BBB 的点，故 P⊆∂A∩∂BP \subseteq \partial A \cap \partial BP⊆∂A∩∂B。两边合起来 ∂A=∂B=P\partial A = \partial B = P∂A=∂B=P。

依赖声明：唯一的外部输入是 简单多边形的对角线（对角线引理；证明用旋转射线论证，含「转到边界边」那一支）；本条的第四至七步只用到「存在三角剖分」这一件事。
