## Statement · **draft**
A **path** in $X$ is a continuous map $\alpha : [0, 1] \to X$; $\alpha(0)$ is its **starting point** and $\alpha(1)$ its **end point**.
A path whose start and end are both $x_{0}$ is a **closed path** (also called a loop based at $x_{0}$).

Let $\alpha, \beta$ be two paths with the same start $x_{0}$ and the same end $x_{1}$. They are **path homotopic** if there is a continuous $F : [0, 1] \times [0, 1] \to X$ such that

$$F(t, 0) = \alpha(t),\qquad F(t, 1) = \beta(t),$$

$$F(0, s) = x_{0},\qquad F(1, s) = x_{1},$$
