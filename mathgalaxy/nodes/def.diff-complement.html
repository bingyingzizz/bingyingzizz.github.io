设 AAA、BBB、XXX 是集合且 A,B⊆XA, B \subseteq XA,B⊆X：

  • 差集：A∖B:={x∈A:x∉B}A \setminus B := \{ x \in A : x \notin B \}A∖B:={x∈A:x∈/B}；
  • 补集（相对于 XXX）：Ac:=X∖AA^{c} := X \setminus AAc:=X∖A；
  • 对称差：A△B:=(A∖B)∪(B∖A)A \triangle B := (A \setminus B) \cup (B \setminus A)A△B:=(A∖B)∪(B∖A)。

基本恒等式：

A∖B=A∩Bc,(Ac)c=A,(⋃iAi)c=⋂iAicA \setminus B = A \cap B^{c}, \qquad (A^{c})^{c} = A, \qquad (\bigcup_i A_i)^{c} = \bigcap_i A_i^{c}A∖B=A∩Bc,(Ac)c=A,(i⋃​Ai​)c=i⋂​Aic​

最后一条就是 De Morgan 律。

说明

⭐ De Morgan 律是「用差 + 可数并推出可数交」的全部依据：⋂nAn=A1∖⋃n≥2(A1∖An)\bigcap_n A_n = A_1 \setminus \bigcup_{n \ge 2} (A_1 \setminus A_n)⋂n​An​=A1​∖⋃n≥2​(A1​∖An​) —— σ\sigmaσ-环只要求对差与可数并封闭，可数交就自动有了。

⚠ 补集必须相对于某个全集 XXX 才有意义，这也正是 σ\sigmaσ-代数要含 XXX 的原因：不含 XXX 就只剩 σ\sigmaσ-环，补运算落不到里面。
