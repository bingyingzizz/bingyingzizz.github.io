⭐ 为什么那个集合是理想：它非空（代数）、对加法与乘 F[x]F[x]F[x] 中任意多项式封闭（代入 α\alphaα 后仍是 000）。F[x]F[x]F[x] 是主理想整环，所以它 =(mα)= (m_{\alpha})=(mα​)；再取首一代表就得唯一性。

⭐ 极小多项式是「α\alphaα 满足的最低条件」：它不可约（若 m=ghm = ghm=gh 且次数都更小，则 g(α)h(α)=0g(\alpha)h(\alpha) = 0g(α)h(α)=0，域里无零因子，故其中一个已 000，与极小性矛盾）。于是

F[x]/(mα)  ≅  F(α),[F(α):F]=deg⁡mα.F[x]/(m_{\alpha}) \;\cong\; F(\alpha), \qquad [F(\alpha):F] = \deg m_{\alpha}.F[x]/(mα​)≅F(α),[F(α):F]=degmα​.

这条同构是整条链的引擎：「造扩域」与「模掉多项式」是同一件事。

⭐ 例子：α=2\alpha = \sqrt{2}α=2​ 在 Q\mathbb{Q}Q 上：m=x2−2m = x^{2} - 2m=x2−2，次数 2；α=23\alpha = \sqrt[3]{2}α=32​：m=x3−2m = x^{3} - 2m=x3−2，次数 3；π\piπ、eee 在 Q\mathbb{Q}Q 上超越（Hermite / Lindemann，本图未收）。
