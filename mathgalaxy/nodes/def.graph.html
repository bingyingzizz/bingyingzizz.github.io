陈述

一个图是一个四元组

(V,E,s,t)( V, E, s, t )(V,E,s,t)

其中 VVV 与 EEE 是集合，s,t:E→Vs, t : E \to Vs,t:E→V 是函数 —— 分别叫起点映射与终点映射。VVV 的元素叫顶点，EEE 的元素叫边。

说明

这里的「图」是有向多重图：不要求 s(e)≠t(e)s(e) \ne t(e)s(e)=t(e)（允许自环），也不要求两条边的端点不同（允许平行边）。所以它比日常说的「图的图形」宽 —— 它只是一份「哪些边从哪连到哪」的数据。

四元组是嵌套的有序对，所以编码方式不是无关紧要的。(x,y):={{x},{x,y}}(x, y) := \{ \{x\}, \{x,y\} \}(x,y):={{x},{x,y}} 满足有序对公理

(a,b)=(c,d)  ⟺  a=c∧b=d(a, b) = (c, d) \iff a = c \wedge b = d(a,b)=(c,d)⟺a=c∧b=d

而换成 {x,{x,y}}\{ x, \{x,y\} \}{x,{x,y}} 就必须拿这条公理逐条去验，不能想当然。

它指向谁（出边）
