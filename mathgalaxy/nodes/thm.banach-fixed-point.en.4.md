# Banach Fixed Point Theorem　`thm.banach-fixed-point`
English entry · root `../`
[in graph](../#n=thm.banach-fixed-point)　·　[Chinese page (authoritative)](./thm.banach-fixed-point.md)

⭐ The standard trick for using it (the next two big theorems both use it): rewrite "solve the equation $f(x) = y$" as "find a fixed point of $\Phi_y$", where $\Phi_y(x) := x - f(x) + y$ is a contraction on a small ball — so "a solution exists" becomes "the ball is complete + the map is a contraction".
