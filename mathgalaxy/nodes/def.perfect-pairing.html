陈述

设 X,YX, YX,Y 是 K\mathbb{K}K 上的赋范空间，⟨⋅,⋅⟩:X×Y→K\langle\cdot,\cdot\rangle : X \times Y \to \mathbb{K}⟨⋅,⋅⟩:X×Y→K 是双线性映射（K=C\mathbb{K} = \mathbb{C}K=C 时对第二变元共轭线性）。称它是完美配对，若

  1. 非退化：⟨x,y⟩=0\langle x, y\rangle = 0⟨x,y⟩=0 对一切 yyy 成立   ⟹  x=0\implies x = 0⟹x=0；⟨x,y⟩=0\langle x, y\rangle = 0⟨x,y⟩=0 对一切 xxx 成立   ⟹  y=0\implies y = 0⟹y=0；
  2. 有界：∣⟨x,y⟩∣≤∥x∥ ∥y∥|\langle x, y\rangle| \le \|x\|\,\|y\|∣⟨x,y⟩∣≤∥x∥∥y∥；
  3. 两侧都定范：∥x∥=sup⁡∥y∥≤1∣⟨x,y⟩∣\|x\| = \sup_{\|y\| \le 1} |\langle x, y\rangle|∥x∥=sup∥y∥≤1​∣⟨x,y⟩∣，∥y∥=sup⁡∥x∥≤1∣⟨x,y⟩∣\|y\| = \sup_{\|x\| \le 1} |\langle x, y\rangle|∥y∥=sup∥x∥≤1​∣⟨x,y⟩∣。

说明

三条合起来等价于：x↦⟨x,⋅⟩x \mapsto \langle x, \cdot\ranglex↦⟨x,⋅⟩ 与 y↦⟨⋅,y⟩y \mapsto \langle \cdot, y\rangley↦⟨⋅,y⟩ 都是等距嵌入 X↪Y∗X \hookrightarrow Y^X↪Y∗、Y↪X∗Y \hookrightarrow X^Y↪X∗。

例子：Hilbert 空间 HHH 与自身、配对 ⟨x,y⟩\langle x, y\rangle⟨x,y⟩；LpL^pLp 与 LqL^qLq（1/p+1/q=11/p + 1/q = 11/p+1/q=1）、配对 ∫fg\int f g∫fg（Hölder 给有界，定范由 g=∣f∣p−1sgn⁡fg = |f|^{p-1}\operatorname{sgn} fg=∣f∣p−1sgnf 的共轭指数构造给出）。

⚠ 完美配对不保证满射：X=ℓ1X = \ell^1X=ℓ1、Y=c0Y = c_0Y=c0​、⟨x,y⟩=∑xnyn\langle x, y\rangle = \sum x_n y_n⟨x,y⟩=∑xn​yn​ 满足三条：Y∗=(c0)∗≅ℓ1Y^ = (c_0)^ \cong \ell^1Y∗=(c0​)∗≅ℓ1，故 T:X→Y∗T : X \to Y^T:X→Y∗ 是等距同构（满）；但 X∗=(ℓ1)∗≅ℓ∞X^ = (\ell^1)^ \cong \ell^\inftyX∗=(ℓ1)∗≅ℓ∞，S:Y=c0→X∗S : Y = c_0 \to X^S:Y=c0​→X∗ 只是等距嵌入（包含），不满。所以「完美」是「无废坐标 + 范数可由配对读出」，不是「互为对偶」。

⭐ 把 Riesz 表示定理的两种版本放在同一框架下：Hilbert 版与 LpL^pLp 版都在说「这对配对里映射是满的」——见 Riesz 表示的配对版。

📌 有限维时三条自动给出 X≅Y∗X \cong Y^*X≅Y∗（维数相同 + 单射即满射）。
