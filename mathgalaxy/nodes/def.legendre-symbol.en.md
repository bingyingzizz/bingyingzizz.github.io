## Statement · **draft**
Let $p$ be an odd prime and $p \nmid a$. Define

$\left(\frac{a}{p}\right)$ taking only the values $\pm 1$:

- $a$ **is a quadratic residue mod $p$** (that is, $a \equiv x^{2} \pmod p$ has a solution $x \not\equiv 0$), in which case the symbol takes the value $1$;
- $a$ **is a quadratic non-residue**, in which case the symbol takes the value $-1$.
