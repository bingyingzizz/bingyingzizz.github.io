## Notes · **draft**
⭐ This is the pointwise version of "star-shaped set": $C$ is star-shaped iff there exists $x_{0}$ such that $C$ is star-shaped with respect to $x_{0}$ (see @@def.star-shaped@@).

⚠ The empty set is not star-shaped with respect to any point ($x_{0} \in C$ already fails). A convex set is star-shaped at each of its points (see @@thm.convex-star-shaped-every-point@@).

💡 Examples: a cross in the plane is star-shaped about its centre but not convex; the unit disk is star-shaped about every interior point.
