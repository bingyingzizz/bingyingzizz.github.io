# 单纯同调群　`def.simplicial-homology`
单纯同调群 $H_{p}(K) = Z_{p} / B_{p}$
layer 18 · 定义 · 同调群 · 拓扑学
[在星图里打开](../#n=def.simplicial-homology)　·　[节点索引](../index.md)
