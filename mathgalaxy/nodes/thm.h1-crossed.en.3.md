# First Cohomology and Crossed Homomorphisms　`thm.h1-crossed`
English entry · root `../`
[in graph](../#n=thm.h1-crossed)　·　[Chinese page (authoritative)](./thm.h1-crossed.md)

$$\delta c(g_{1}, g_{2}) = g_{1} c(g_{2}) - c(g_{1} g_{2}) + c(g_{1}),$$

so $\delta c = 0 \iff c(g_{1}g_{2}) = c(g_{1}) + g_{1}c(g_{2})$, i.e. $Z^{1}$ is exactly the crossed homomorphisms.

Also $C^{0} = M$ and $(\delta^{0}m)(g) = g m - m$, hence $\operatorname{im}\delta^{0} = B^{1}$.

Thus $H^{1} = \ker\delta^{1}/\operatorname{im}\delta^{0} = Z^{1}/B^{1}$.
