## Notes · **draft**
**It yields three good properties at once**: second countable $\implies$ separable (choose one point from each nonempty basic element; the result is a countable dense set); second countable $\implies$ Lindelöf (every open cover has a countable subcover, by filtering basic elements);

second countable $\implies$ first countable (at each point, filter the countably many basic elements containing it).

With regularity it also yields normality — this is the first step of the Urysohn metrization theorem.
