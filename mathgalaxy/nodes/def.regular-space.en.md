## Statement · **draft**
**What this is**: the $T_{3}$ property **together with $T_{1}$**. Only after adding $T_{1}$ does it automatically become $T_{2}$ — this is the real purpose of the name "regular".

A topological space $X$ is a **regular space** if

1. $X$ is **$T_{3}$**: a point and a closed set not containing it can be separated by disjoint open sets (`def.t3-space`);
2. $X$ is **$T_{1}$**: singletons are closed (`def.t1-space`).
