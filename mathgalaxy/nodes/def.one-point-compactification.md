# 一点紧化　`def.one-point-compactification`
一点紧化：只补一个无穷远点
layer 16 · 定义 · 拓扑空间 · 拓扑学
[在星图里打开](../#n=def.one-point-compactification)　·　[节点索引](../index.md)

**在做什么**：最省的一点补法 —— 加**一个**点 $\infty$，让每个跑向无穷的序列都收敛到它。$\mathbb{R}^{n}$ 变成 $S^{n}$、$\mathbb{C}$ 变成 Riemann 球面，都是这个构造。
