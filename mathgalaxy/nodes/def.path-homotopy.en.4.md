# path homotopy　`def.path-homotopy`
English entry · root `../`
[in graph](../#n=def.path-homotopy)　·　[Chinese page (authoritative)](./def.path-homotopy.md)

written $\alpha \simeq_{p} \beta$. Equivalently, $\alpha \simeq \beta \; (\operatorname{rel} \{0, 1\})$.

The **path homotopy class** of $\alpha$ is written $[\alpha]$, i.e. $\{\, \beta : \beta \simeq_{p} \alpha \,\}$.
A path homotopy class of closed paths is also called a **homotopy class** (based at $x_{0}$).
