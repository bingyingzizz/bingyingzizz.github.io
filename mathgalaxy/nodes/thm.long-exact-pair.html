又称对的长正合列

陈述

一个拓扑对就是一个子空间对 A⊆XA \subseteq XA⊆X。由于 AAA 里的奇异单纯形自动也是 XXX 里的，S∗(A)⊆S∗(X)S_{}(A) \subseteq S_{}(X)S∗​(A)⊆S∗​(X) 是子复形；定义相对链群与相对同调群

Sp(X,A):=Sp(X)/Sp(A),S_{p}(X, A) := S_{p}(X) \big/ S_{p}(A),Sp​(X,A):=Sp​(X)/Sp​(A),Hp(X,A):=ker⁡∂ˉ/im⁡∂ˉ.H_{p}(X, A) := \ker\bar\partial \big/ \operatorname{im}\bar\partial.Hp​(X,A):=ker∂ˉ/im∂ˉ.

则存在长正合列（每个 ⋅\cdot⋅ 处都是 im⁡=ker⁡\operatorname{im} = \kerim=ker）

⋯→Hp(A)→Hp(X)→Hp(X,A)\cdots \to H_{p}(A) \to H_{p}(X) \to H_{p}(X, A)⋯→Hp​(A)→Hp​(X)→Hp​(X,A)→ ∂∗ Hp−1(A)→⋯\xrightarrow{\ \partial_{*}\ } H_{p-1}(A) \to \cdots ∂∗​ ​Hp−1​(A)→⋯

其中 ∂∗\partial_{*}∂∗​ 叫连接同态。序列对一切子空间对成立，不需要 AAA 是闭的、开的好子空间，也不需要任何「余纤维化」条件。

说明

连接同态怎么定义：取 [c]∈Hp(X,A)[c] \in H_{p}(X, A)[c]∈Hp​(X,A)，代表元 c∈Sp(X)c \in S_{p}(X)c∈Sp​(X) 满足「相对闭」的条件 ∂ˉ[c]=0\bar\partial[c] = 0∂ˉ[c]=0，即 ∂c∈Sp−1(A)\partial c \in S_{p-1}(A)∂c∈Sp−1​(A)。令

∂∗[c]:=[∂c]∈Hp−1(A).\partial_{*}[c] := [\partial c] \in H_{p-1}(A).∂∗​[c]:=[∂c]∈Hp−1​(A).

要验证三件事：∂c\partial c∂c 确实是闭链（∂∂c=0\partial\partial c = 0∂∂c=0）；换代表元不改变类；在三个位置 Hp(X),Hp(X,A),Hp−1(A)H_{p}(X), H_{p}(X,A), H_{p-1}(A)Hp​(X),Hp​(X,A),Hp−1​(A) 上分别验证正合性。

⚠️ 本图的证明是骨架：上面只写「短正合列 +++ 追图」的构造，不逐行写三轮正合性验证——那是标准的图追踪，写全要一整页。结构是完整的，细节请查 refs。

为什么同调有这条而同伦没有这么方便：πn\pi_{n}πn​ 的长正合列需要纤维化条件（空间得好）；同调的这条只要 A⊆XA \subseteq XA⊆X 是任意子空间。这是「链的复形」比「同伦群」好用的核心区别之一。

💡 用法：把大空间的同调拆成「小空间 +++ 相对部分」，用已知的算未知的（thm.mv-homology 就是这么来的）。

    0→S∗(U∩V)→S∗(U)⊕S∗(V)0 \to S_{*}(U \cap V) \to S_{*}(U) \oplus S_{*}(V)0→S∗​(U∩V)→S∗​(U)⊕S∗​(V)→S∗(U)+S∗(V)→0,\to S_{*}(U) + S_{*}(V) \to 0,→S∗​(U)+S∗​(V)→0,

    其中第一个映射是 a↦(a,−a)a \mapsto (a, -a)a↦(a,−a)，第二个是 (a,b)↦a+b(a, b) \mapsto a + b(a,b)↦a+b。单射性：aaa 在 UUU 与 VVV 里同时为零说明 a=0a = 0a=0；正合性：a+b=0a + b = 0a+b=0 时 a=−ba = -ba=−b 落在两边，故来自 U∩VU \cap VU∩V。再由 thm.long-exact-pair 的追图，得一条三项一片的长正合列：Hp(U∩V)→Hp(U)⊕Hp(V)→Hp(S∗(U)+S∗(V))→∂∗Hp−1(U∩V)H_{p}(U \cap V) \to H_{p}(U) \oplus H_{p}(V) \to H_{p}(S_{}(U) + S_{}(V)) \xrightarrow{\partial_{*}} H_{p-1}(U \cap V)Hp​(U∩V)→Hp​(U)⊕Hp​(V)→Hp​(S∗​(U)+S∗​(V))∂∗​​Hp−1​(U∩V)。

    合起来：把第一步的序列里 Hp(S∗(U)+S∗(V))H_{p}(S_{}(U)+S_{}(V))Hp​(S∗​(U)+S∗​(V)) 换成 Hp(X)H_{p}(X)Hp​(X)，就是 Mayer–Vietoris。∎

    追图给 ∂∗\partial_{*}∂∗​：对 [c]∈Hp(X,A)[c] \in H_{p}(X, A)[c]∈Hp​(X,A)，取代表 c∈Sp(X)c \in S_{p}(X)c∈Sp​(X)。「ccc 是相对闭链」的意思是 ∂ˉ[c]=0\bar\partial[c] = 0∂ˉ[c]=0，即 ∂c∈Sp−1(A)\partial c \in S_{p-1}(A)∂c∈Sp−1​(A) —— 这正好让 ∂c\partial c∂c 可以被看成 Hp−1(A)H_{p-1}(A)Hp−1​(A) 的元素。令
