Statement

Let T:V→WT : V \to WT:V→W be a linear map. Then

T‾:V/ker⁡T⟶im⁡T,v+ker⁡T⟼T(v)\overline{T} : V / \ker T \longrightarrow \operatorname{im} T, \qquad v + \ker T \longmapsto T(v)T:V/kerT⟶imT,v+kerT⟼T(v)

is a well-defined **linear isomorphism**. In particular

V/ker⁡T≅im⁡TV / \ker T \cong \operatorname{im} TV/kerT≅imT

Notes

⭐ This is the third appearance of the same template on the graph: the set version A/ ⁣∼A/\!\simA/∼, the group version G/N≅im⁡φG/N \cong \operatorname{im}\varphiG/N≅imφ, and the vector-space version V/ker⁡T≅im⁡TV/\ker T \cong \operatorname{im} TV/kerT≅imT.

The proof is verbatim the same in all three — **kill the kernel, and what remains is the image**.

⭐ One particularly useful branch: if TTT is surjective, then W≅V/ker⁡TW \cong V / \ker TW≅V/kerT;

if TTT is injective, then V≅im⁡TV \cong \operatorname{im} TV≅imT.

⚠ The well-definedness step cannot be skipped: v+ker⁡T=v′+ker⁡Tv + \ker T = v' + \ker Tv+kerT=v′+kerT says v−v′∈ker⁡Tv - v' \in \ker Tv−v′∈kerT, hence T(v)=T(v′)T(v) = T(v')T(v)=T(v′) — precisely the sentence "T‾\overline{T}T depends only on the coset".
