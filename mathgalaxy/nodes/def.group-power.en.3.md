# group power　`def.group-power`
English entry · root `../`
[in graph](../#n=def.group-power)　·　[Chinese page (authoritative)](./def.group-power.md)

**Keep it separate from integer powers in a ring.** Integer powers in a unital ring (see the real-analysis cluster's "integer powers") use the multiplicative identity $1$ of the ring as $a^{0}$, and $a^{-n}$ is defined only when $a$ is invertible; the present entry assumes only a group structure, with $e$ the group identity. The notation is the same but the carrier is different — use whichever the context calls for, and do not substitute one for the other.
