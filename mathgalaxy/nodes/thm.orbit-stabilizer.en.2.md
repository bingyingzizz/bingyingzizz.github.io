## Notes · **draft**
⭐ This theorem is the hub of the whole pack: it converts "**counting the size of an orbit**", a geometric/combinatorial matter, into "**computing an index**", a group-theoretic one.

The class equation, Sylow and Burnside's lemma are all direct corollaries.

⭐ One-line mnemonic: **orbit size $\times$ stabilizer size = group size**.

⚠ Only the quantity $[G : \operatorname{Stab}(x)]$ is used, so the theorem holds for **infinite groups** as well (then it must be read as "the orbit is in bijection with the coset set $G/G_x$").
