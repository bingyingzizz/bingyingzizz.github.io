So an outer measure is not a measure — it is too large even to be additive on $\mathcal{P}(X)$. Carathéodory's idea is to single out the sets that "behave well" (the next definition); on those the outer measure does become a genuine measure.

What Lebesgue first constructed was an outer measure: $\mu^{*}(A) = \inf\{ \sum (b_{n} - a_{n}) : A \subseteq \bigcup (a_{n}, b_{n}) \}$.
