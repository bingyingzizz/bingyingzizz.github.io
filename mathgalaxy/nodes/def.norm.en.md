## Statement · **draft**
Let $E$ be a vector space over $\mathbb{K}$ ($\mathbb{K} = \mathbb{R}$ or $\mathbb{C}$). A function $\|\cdot\| : E \to [0, +\infty)$ is called a **norm** if

1. $\|x\| = 0 \iff x = 0$;
2. $\|\lambda x\| = |\lambda|\,\|x\|$;
3. $\|x + y\| \le \|x\| + \|y\|$.

A space equipped with a norm is a **normed space**. One satisfying only 2 and 3 (allowing nonzero elements to have zero norm) is a **seminorm**.
