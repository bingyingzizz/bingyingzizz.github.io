## Statement · **draft**
Let $\Gamma$ be a set of first-order formulas. If **every finite subset** of $\Gamma$ has a model, then $\Gamma$ itself has a model.

Equivalently: if $\Gamma \vDash \varphi$, then there is a **finite** $\Gamma_{0} \subseteq \Gamma$ with $\Gamma_{0} \vDash \varphi$.
