# outer measure　`def.outer-measure`
English entry · root `../`
[in graph](../#n=def.outer-measure)　·　[Chinese page (authoritative)](./def.outer-measure.md)

- $\mu^{*}(\emptyset) = 0$: **normalisation**, there only so that $0 \le \mu^{*}$ below is meaningful (otherwise the constant $+\infty$ would satisfy the other two).
- **Monotonicity**: **almost free**, but deriving it uses countable subadditivity: $B = A \cup (B \setminus A)$ $\implies$ $\mu^{*}(B) \le \mu^{*}(A) + \mu^{*}(B\setminus A)$; monotonicity is usually listed as an axiom to save that step, and in a concrete construction (Carath\u00E9odory) it is verified directly.
- **Countable subadditivity**: **this is the real condition**, the only one with content \u2014 it ties "the size of one set" to "countable operations". \u2
