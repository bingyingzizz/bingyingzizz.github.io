陈述

标准 ppp-单纯形是

Δp:={(t0,…,tp)∈Rp+1:∑iti=1, ti≥0}.\Delta^{p} := \left\{ (t_{0}, \ldots, t_{p}) \in \mathbb{R}^{p+1} : \sum_{i} t_{i} = 1,\ t_{i} \ge 0 \right\}.Δp:={(t0​,…,tp​)∈Rp+1:i∑​ti​=1, ti​≥0}.

它的 p+1p + 1p+1 个顶点是 vi:=(0,…,1,…,0)v_{i} := (0, \ldots, 1, \ldots, 0)vi​:=(0,…,1,…,0)（第 iii 位为 111）。Δp\Delta^{p}Δp 是这些顶点的凸包，是 Rp+1\mathbb{R}^{p+1}Rp+1 里的紧凸集。

对 i=0,1,…,pi = 0, 1, \ldots, pi=0,1,…,p，面映射 di:Δp−1→Δpd_{i} : \Delta^{p-1} \to \Delta^{p}di​:Δp−1→Δp 在第 iii 位插一个 000：

di(t0,…,tp−1):=(t0,…,ti−1,0,ti,…,tp−1).d_{i}(t_{0}, \ldots, t_{p-1}) := (t_{0}, \ldots, t_{i-1}, 0, t_{i}, \ldots, t_{p-1}).di​(t0​,…,tp−1​):=(t0​,…,ti−1​,0,ti​,…,tp−1​).

它的像是「跳过第 iii 个顶点」的那个 (p−1)(p-1)(p−1)-面；这些像的并就是边界 ∂Δp\partial\Delta^{p}∂Δp。 （p=0p = 0p=0 时 Δ0\Delta^{0}Δ0 是单点，d0d_{0}d0​ 把它放进 Δ1\Delta^{1}Δ1 的一个端点。）

说明

面映射的恒等式（后面 ∂2=0\partial^{2} = 0∂2=0 全靠它）：对 i<ji < ji<j 有

dj∘di=di∘dj−1:Δp−2→Δp.d_{j} \circ d_{i} = d_{i} \circ d_{j-1} : \Delta^{p-2} \to \Delta^{p}.dj​∘di​=di​∘dj−1​:Δp−2→Δp.

两边都是「在 p−2p-2p−2 个分量里把 000 插进第 iii、第 jjj 位」，只是先后顺序不同。

为什么用 Δp\Delta^{p}Δp 而不是 [0,1]p[0, 1]^{p}[0,1]p：单纯形的每个面只需一个下标（「跳过第 iii 个顶点」），所以边界的符号是整齐的 (−1)i(-1)^{i}(−1)i；而方块的边界要区分「xi=0x_{i} = 0xi​=0」与「xi=1x_{i} = 1xi​=1」两类面，符号公式更长。⚠️ 两种模型给出的同调群同构，但边界公式不同，不能混写（本图 def.singular-cube 用的是方块模型）。

凸性是要用到的：Δp\Delta^{p}Δp 凸，所以任意两点之间的线段都在里面，于是「Δp\Delta^{p}Δp 里任何闭链都能缩成一点」；这是单纯逼近与「奇异单纯形内部无洞」的几何基础。
