# Yoneda embedding　`prop.yoneda-embedding`
English entry · root `../`
[in graph](../#n=prop.yoneda-embedding)　·　[Chinese page (authoritative)](./prop.yoneda-embedding.md)

Once $\mathcal{C}$ is embedded in $\widehat{\mathcal{C}}$, questions inside $\mathcal{C}$ can be solved in a category that **has all limits and colimits** — this is the standard way of "completing" a category.
