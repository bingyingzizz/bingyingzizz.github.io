# linear map　`def.linear-map`
English entry · root `../`
[in graph](../#n=def.linear-map)　·　[Chinese page (authoritative)](./def.linear-map.md)

⭐ That $\operatorname{Hom}_K(V, W)$ is itself a vector space is special to linear algebra: in a general category the morphism set between two objects has no addition (as in $\mathbf{Set}$), whereas the category of vector spaces is an **additive category** — the morphism sets carry an addition of their own, an extra structure absent from general categories.

⚠ The point of linearity is that **only the addition and scalar multiplication of $K$ matter**: the translation $v \mapsto v + v_0$ (with $v_0 \ne 0$) is not linear ($0$ does not map to $0$), but it "differs from a linear map by a translation" — that is an affine map.
