Abstract

A metric space is a pair (X,d)(X, d)(X,d) with d:X×X→[0,+∞)d : X \times X \to [0, +\infty)d:X×X→[0,+∞) satisfying d(x,y)=0  ⟺  x=yd(x,y) = 0 \iff x = yd(x,y)=0⟺x=y, symmetry and the triangle inequality; open balls B(x,r)={y:d(x,y)<r}B(x,r) = \{y : d(x,y) < r\}B(x,r)={y:d(x,y)<r} generate a topology, and they form a base for it. The point of the definition here is the split that follows: compactness and closedness use only the open sets, while completeness and total boundedness use ddd. Completeness is genuinely not topological — R\mathbb{R}R and (0,1)(0,1)(0,1) are homeomorphic but only the first is complete.

Notes

The open balls form a base for this topology. Every metric space is first countable and normal (hence Hausdorff).

The properties that follow fall into two classes: compactness / closedness depend only on the open sets and are topological; completeness / total boundedness use ddd and are metric. This dividing line is the point of the whole cluster.

⚠ Completeness is not a topological property: R\mathbb{R}R and the open interval (0, 1) are homeomorphic, yet only the first is complete.Only one of the three axioms is "hard" (they are usually listed side by side, but they carry very different weight):

  • Non-degeneracy d(x,y)=0  ⟺  x=yd(x,y)=0 \iff x=yd(x,y)=0⟺x=y: read it as two halves. "x=y  ⟹  d(x,y)=0x=y \implies d(x,y)=0x=y⟹d(x,y)=0" is nearly free (often built into how ddd is given); "d(x,y)=0  ⟹  x=yd(x,y)=0 \implies x=yd(x,y)=0⟹x=y" is the half with content (weakening it gives a pseudometric).
  • Symmetry: can be dropped — what is left is a quasi-metric (e.g. a "one-way shortest path"); the topology is still definable, but balls are asymmetric (the ball for ddd and the ball for the reversed quasi-metric differ).
  • Triangle inequality: the only indispensable one. Without it the open balls no longer form a base for a topology — the concrete failure is that an intersection stops containing a ball, which is precisely what the definition of "open" uses.

⚠ "ddd takes values in [0,+∞)[0,+\infty)[0,+∞) rather than [0,+∞][0,+\infty][0,+∞]": allowing +∞+\infty+∞ wrecks the notion of a connected component (the discrete metric d≡+∞d \equiv +\inftyd≡+∞ misbehaves), so the standard definition takes finite values; if a map between metric spaces needs +∞+\infty+∞, say so explicitly.
