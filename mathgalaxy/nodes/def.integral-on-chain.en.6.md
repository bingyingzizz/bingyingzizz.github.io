# Integration over a Chain　`def.integral-on-chain`
English entry · root `../`
[in graph](../#n=def.integral-on-chain)　·　[Chinese page (authoritative)](./def.integral-on-chain.md)

**⚠️ Degrees must match**: a $k$-form only pairs with a $k$-chain. Pulling back a $j$-form along a $k$-cube ($j<k$) is still meaningful, but that is a $j$-form on a $k$-dimensional region and cannot be integrated; for $j>k$ the pullback is simply zero. So "pairing of chains and forms" is defined only in equal degrees.

**⚠️ Degenerate cubes**: if $c$ has less than full rank, $c^{\ast}\omega$ may be zero (for instance if $c$ is constant), and the integral is then automatically zero. The definition needs no patch for the degenerate case.
