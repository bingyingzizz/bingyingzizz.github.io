# the adic spectrum　`def.adic-spectrum`
English entry · root `../`
[in graph](../#n=def.adic-spectrum)　·　[Chinese page (authoritative)](./def.adic-spectrum.md)

$\operatorname{Spa}$ takes **equivalence classes** of valuations (so the same point is not counted twice because of a different ruler).

Intuition: $|x|$ is "the distance from $x$ to $0$", and $|x| \le 1$ means "$x$ is bounded";

the $p$-adic absolute value $|p^{n}u| = p^{-n}$ ($u$ coprime to $p$) is the standard example.

Let $(A, A^+)$ be a discrete Huber pair. The **adic spectrum**

$$\operatorname{Spa}(A, A^+) := \bigl\{\, |\cdot| : A \to \Gamma \cup \{0\} \ \big|\ |A^+| \le 1 \,\bigr\} \big/ \sim$$
