## Statement · **draft**
In $\mathbf{Set}$, $X \mapsto X \times Y$ **$\dashv$** $Z \mapsto \mathbf{Set}(Y, Z)$:

## Notes · **draft**
**Proof.** Given $f : X \times Y \to Z$, set $\widehat{f}(x)(y) = f(x, y)$ ✓; conversely, given $g$ set $f(x,y) = g(x)(y)$ ✓ — the two directions are mutually inverse and natural ✓, so $\mathbf{Set}(X \times Y, Z) \cong \mathbf{Set}\bigl(X, \mathbf{Set}(Y, Z)\bigr)$ ✓.
