# Paracompact Space　`def.paracompact`
English entry · root `../`
[in graph](../#n=def.paracompact)　·　[Chinese page (authoritative)](./def.paracompact.md)

⭐ **What it buys**: partitions of unity (hence smoothing, integration and Stokes on manifolds, and extension theorems), and the local finiteness that sheaf theory needs so that "Čech cohomology equals sheaf cohomology" holds in detail. Manifolds are second countable by definition, hence automatically paracompact — which is why analysis never worries about it.
