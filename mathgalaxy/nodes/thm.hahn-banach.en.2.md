# Hahn–Banach　`thm.hahn-banach`
English entry · root `../`
[in graph](../#n=thm.hahn-banach)　·　[Chinese page (authoritative)](./thm.hahn-banach.md)

**Norm-preserving extension (corollary)**: let $X$ be a normed space, $M \subseteq X$ a subspace, $\varphi \in M^{*}$. Then there exists $\Phi \in X^{*}$ such that $\Phi|_M = \varphi$ and $\|\Phi\| = \|\varphi\|$.

## Notes · **draft**
**Step 1: the one-dimensional extension lemma.** Let $x_0 \notin M$, $N = M \oplus \mathbb{R}x_0$. Defining, on $N$, a map $g(m + t x_0) = f(m) + t c$ that preserves $g \le p$ is equivalent to having, for every $m \in M$,

$f(m) + c \le p(m + x_0), \qquad f(m) - c \le p(m - x_0).$
