# Weierstrass product theorem　`thm.weierstrass-product`
English entry · root `../`
[in graph](../#n=thm.weierstrass-product)　·　[Chinese page (authoritative)](./thm.weierstrass-product.md)

**Lemma 1 (estimate for elementary factors).** If $|z|\le \frac{1}{2}$, then $|1 - E_{p}(z)| \le 4|z|^{p+1}$. To prove this, observe that when $|z|<1$, we have $\log E_{p}(z) = -\sum_{k>p} z^{k}/k$, so $|\log E_{p}(z)| \le \sum_{k>p}\frac{|z|^{k}}{k} \le \frac{|z|^{p+1}}{(p+1)(1-|z|)} \le 2|z|^{p+1};$. Also, $|1-e^{w}|\le 2|w|$ ($|w|\le 1$). Taking $w = \log E_{p}(z)$ gives the result (when $p=0$, we obtain $1-E_{0}(z) = z$ directly).
