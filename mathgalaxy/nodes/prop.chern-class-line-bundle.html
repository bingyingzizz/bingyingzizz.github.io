陈述

在做什么：秩 111 时整台装置退化成一个可算的公式 —— 这是陈类唯一能「手算」的情形，也是分裂原理把它化归到的情形。

设 L→BL \to BL→B 是复线丛，∇\nabla∇ 是联络，Ω\OmegaΩ 是它的曲率 222-形式（线丛的曲率就是 dθ\mathrm{d}\thetadθ，因为 End⁡L≅C\operatorname{End}L \cong \mathbb{C}EndL≅C 可交换）。则

c1(L)=[ i2π Ω ]∈H2(B;Z),cj(L)=0 (j≥2).c_{1}(L) = \Bigl[\, \frac{i}{2\pi}\,\Omega \,\Bigr] \in H^{2}(B; \mathbb{Z}) , \qquad c_{j}(L) = 0 \ (j \ge 2) .c1​(L)=[2πi​Ω]∈H2(B;Z),cj​(L)=0 (j≥2).

推论（陈数）：若 BBB 是闭合可定向曲面 Σ\SigmaΣ，则

∫Σc1(L)=i2π∫ΣΩ  ∈  Z.\int_{\Sigma} c_{1}(L) = \frac{i}{2\pi}\int_{\Sigma}\Omega \;\in\; \mathbb{Z} .∫Σ​c1​(L)=2πi​∫Σ​Ω∈Z.

说明

为什么秩 111 特别简单：gl(1,C)=C\mathfrak{gl}(1,\mathbb{C}) = \mathbb{C}gl(1,C)=C 交换，于是「共轭不变」这个条件自动满足 —— 任何多项式都不变，不用挑。所以线丛的示性类只有一条（c1c_{1}c1​），后面的全为零。

这个整数是什么：i2π∫ΣΩ\frac{i}{2\pi}\int_{\Sigma}\Omega2πi​∫Σ​Ω 就是绕数 / 第一陈数，物理里叫「磁通量的量子化」。它在 Σ=S2\Sigma = S^{2}Σ=S2 上取遍 Z\mathbb{Z}Z —— 这就是复线丛在 S2S^{2}S2 上由 Z\mathbb{Z}Z 分类（Hopf 丛是生成元，丛的分类 的注里说过）的解析根子。

⚠️ 不能省 cj(L)=0c_{j}(L)=0cj​(L)=0（j≥2j\ge2j≥2）：它保证线丛的示性类只有一个自由度。⚠️ 但也别误推「c1=0c_1=0c1​=0 就平凡」：c1=0c_1=0c1​=0 只说明该丛在 H2H^2H2 层面看不出；平坦线丛就是一例（c1=0c_1=0c1​=0 但可以非平凡）。

⚠️ 曲率的符号约定：Ω=dθ\Omega = \mathrm{d}\thetaΩ=dθ 与 Ω=−dθ\Omega = -\mathrm{d}\thetaΩ=−dθ 两种约定都在用，差一个整体符号；c1c_{1}c1​ 的符号会跟着变。本图取 Ω=dθ\Omega = \mathrm{d}\thetaΩ=dθ（与 联络形式 一致）。
