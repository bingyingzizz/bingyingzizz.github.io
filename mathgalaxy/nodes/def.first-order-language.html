陈述

一阶语言 L\mathcal{L}L 由一张符号表给定，符号分两类：

  • 逻辑符号（所有一阶语言共用）：可数多个变元 v0,v1,v2,…v_{0}, v_{1}, v_{2}, \ldotsv0​,v1​,v2​,…；连接词 ¬\neg¬；量词 ∀\forall∀；等号 ===；括号。
  • 非逻辑符号（每个语言自己的）：常元符号、nnn 元函数符号、nnn 元关系符号，每一种都带一个确定的元数 nnn。

由符号表，用三条语法规则生成全部的项与公式：

  1. 变元、常元符号是项；若 fff 是 nnn 元函数符号而 t1,…,tnt_{1}, \ldots, t_{n}t1​,…,tn​ 是项，则 f(t1,…,tn)f(t_{1}, \ldots, t_{n})f(t1​,…,tn​) 是项；
  2. 若 RRR 是 nnn 元关系符号而 t1,…,tnt_{1}, \ldots, t_{n}t1​,…,tn​ 是项，则 R(t1,…,tn)R(t_{1}, \ldots, t_{n})R(t1​,…,tn​) 是原子公式；
  3. 公式由原子公式出发，经 ¬\neg¬、∧\wedge∧、∨\vee∨、→\to→、∀vi\forall v_{i}∀vi​、∃vi\exists v_{i}∃vi​ 反复组合而成。

例：L={∈}\mathcal{L} = \{ \in \}L={∈}（∈\in∈ 是一个二元关系符号）就是集合论的语言 —— ZFC 的全部公理都写在这门语言里。

说明

⭐⭐ 这是星图里唯一的「原始层」对象。 别的东西都是「由更下面的东西造出来」的，一阶语言不是 —— 它是写公理用的那门语言，比 ZFC 本身更原始。所以它跟 ZF 公理同在最底下的几层，不往上连依赖边：真要连，「公式」就得先在 ZFC 内部由集合造出来，而那要用 ZFC 的公理，可公理模式本身又需要公式 —— 直接成环。

⭐ 在 ZFC 内部也能把它形式化：把符号编码成集合、把公式编码成有限序列，「φ\varphiφ 是公式」于是成为 ZFC 里的一条性质。那是元数学的进一步工作，本图不展开。（这个方向正是 Gödel 不完备定理的入口。）

⚠ 语言与结构要分开：L={∈}\mathcal{L} = \{ \in \}L={∈} 只规定了有哪些符号，还没说变元往哪里跑 —— 那是满足关系要说的事。
