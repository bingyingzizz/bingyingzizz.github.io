# category of modules　`def.module-category`
English entry · root `../`
[in graph](../#n=def.module-category)　·　[Chinese page (authoritative)](./def.module-category.md)

**Freyd–Mitchell**: every small abelian category embeds fully faithfully and exactly into some $A\text{-}\mathbf{Mod}$, so “chasing elements in a module category” is a legitimate generalization.
