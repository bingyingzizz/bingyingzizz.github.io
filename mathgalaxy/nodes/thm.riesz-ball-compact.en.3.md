# the closed unit ball is compact iff finite dimensional　`thm.riesz-ball-compact`
English entry · root `../`
[in graph](../#n=thm.riesz-ball-compact)　·　[Chinese page (authoritative)](./thm.riesz-ball-compact.md)

⭐ This is one half of "finite-dimensional if and only if locally compact": finite-dimensional normed spaces are locally compact, while infinite-dimensional ones are **never** locally compact. It is also the precise version of "bounded closed sets are compact" holding only in finite dimension — Heine–Borel fails in infinite dimension.
