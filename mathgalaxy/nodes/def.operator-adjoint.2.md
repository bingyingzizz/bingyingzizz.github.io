## 陈述（续）
性质：$(T + S)^{\ast} = T^{\ast} + S^{\ast}$、$(cT)^{\ast} = \bar{c}\,T^{\ast}$、$(TS)^{\ast} = S^{\ast}T^{\ast}$、$T^{\ast\ast} = T$。

⚠️ 与范畴论的**伴随函子**（`def.adjoint`）不是一回事：那是两个函子之间的关系，这里是同一个空间上的算子。
