# standard conformal maps　`prop.standard-maps`
English entry · root `../`
[in graph](../#n=prop.standard-maps)　·　[Chinese page (authoritative)](./prop.standard-maps.md)

**Why these maps are right**: $z^{k}$ opens an angle by a factor $k$ ($k = \pi/\alpha$); $e^{z}$ rolls a horizontal strip into an angle; $\log$ conversely flattens a slit plane into a strip; fractional linear maps preserve circles (`prop.mobius-circle`), so they interchange half-planes and discs.

⚠️ Each map must **specify which branch** is taken: $z^{\pi/\alpha}$ and $\log$ are multivalued, and the formulas above mean the principal branch (or a fixed branch).
