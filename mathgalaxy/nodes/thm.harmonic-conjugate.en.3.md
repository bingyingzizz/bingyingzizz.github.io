# harmonic conjugate　`thm.harmonic-conjugate`
English entry · root `../`
[in graph](../#n=thm.harmonic-conjugate)　·　[Chinese page (authoritative)](./thm.harmonic-conjugate.md)

$\Omega$ simply connected $\implies$ there exists $v$ with $\mathrm{d}v = \omega$, that is, $v_x = -u_y$ and $v_y = u_x$; these two equations are exactly the Cauchy–Riemann equations for $(u, v)$, so $f = u + iv$ is holomorphic.

⭐ Uniqueness: if $\operatorname{Re} f_1 = \operatorname{Re} f_2 = u$, then $g = f_1 - f_2$ is purely imaginary and holomorphic; writing $g = iy$ with $y$ real-valued, Cauchy–Riemann gives $y_x = y_y = 0$, so $y$ is constant.
