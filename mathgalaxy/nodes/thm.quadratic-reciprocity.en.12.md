# law of quadratic reciprocity　`thm.quadratic-reciprocity`

For fixed $x$, $\{y : 1 \le y \le Q,\ qx - py > 0\} = \{y : y < qx/p\}$ has exactly $\min(Q, \lfloor qx/p \rfloor)$ elements. Since $qx/p \le qP/p = \frac{q(p-1)}{2p} < \frac{q}{2}$, we have $\lfloor qx/p \rfloor \le \frac{q-1}{2} = Q$, and this count is $\lfloor qx/p \rfloor$.
