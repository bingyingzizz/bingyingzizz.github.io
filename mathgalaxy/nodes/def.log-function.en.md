## Statement · **draft**
$\exp$ is strictly increasing on $\mathbb{R}$ (because $(\exp x)' = \exp x > 0$), with image $(0, +\infty)$. Define $\log : (0, +\infty) \to \mathbb{R}$ as its inverse:

$$\log := (\exp|_{\mathbb{R}})^{-1}, \qquad e := \exp 1 = \sum_{n=0}^{\infty} \frac{1}{n!}$$

Hence

$$\log(xy) = \log x + \log y, \qquad \frac{d}{dx}\log x = \frac{1}{x}$$
