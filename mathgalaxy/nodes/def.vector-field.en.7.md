**On support**: write $\operatorname{supp} X$ for the closure of "where $X$ is nonzero". The partition-of-unity argument needs exactly "support contained in a chart", so this is the same notation $\operatorname{supp}$ as in `def.partition-of-unity` (`thm.smooth-partition-unity`).

**Relation to integral curves**: a vector field gives the first-order ODE $\dot\gamma = X(\gamma)$, whose solutions are integral curves; local solutions always exist, while global ones need not extend. This map only uses local existence; flows and one-parameter groups are not yet in the map.
