每个 σ∈Sn\sigma \in S_nσ∈Sn​ 都能写成对换（两个点的交换）之积，且所用对换个数的奇偶性与分解方式无关。据此定义符号

sgn⁡(σ):=(−1)k(σ=k 个对换之积)\operatorname{sgn}(\sigma) := (-1)^{k} \quad (\sigma = \text{$k$ 个对换之积})sgn(σ):=(−1)k(σ=k 个对换之积)

等价公式（不含分解的任意性）

sgn⁡(σ)=∏1≤i<j≤nσ(j)−σ(i)j−i∈{±1}\operatorname{sgn}(\sigma) = \prod_{1 \le i < j \le n} \frac{\sigma(j) - \sigma(i)}{j - i} \in \{\pm 1\}sgn(σ)=1≤i<j≤n∏​j−iσ(j)−σ(i)​∈{±1}

sgn⁡:Sn→{±1}\operatorname{sgn} : S_n \to \{\pm 1\}sgn:Sn​→{±1} 是群同态（n≥2n \ge 2n≥2 时满）。其核

An:=ker⁡sgn⁡={ σ∈Sn:sgn⁡(σ)=1 }A_n := \ker \operatorname{sgn} = \{\, \sigma \in S_n : \operatorname{sgn}(\sigma) = 1 \,\}An​:=kersgn={σ∈Sn​:sgn(σ)=1}

说明

⭐ 符号是 SnS_nSn​ 到 {±1}\{\pm 1\}{±1} 的唯一非平凡同态（n≥3n \ge 3n≥3），所以 AnA_nAn​ 是 SnS_nSn​ 的唯一指数 222 子群 —— 这个唯一性是后面「SnS_nSn​ 不单」以及 Galois 理论里「二次子扩张唯一」的来源。

⭐ 乘积公式为什么干净：每一项 σ(j)−σ(i)j−i\frac{\sigma(j)-\sigma(i)}{j-i}j−iσ(j)−σ(i)​ 的分母固定、分子只是把同一批差重新排列，故乘积的符号只取决于 σ\sigmaσ 引起的排列的奇偶性。这也顺手证明了「奇偶性与分解无关」。

⚠ 边界：n=1n = 1n=1 时 A1=S1A_1 = S_1A1​=S1​ 是平凡群，∣An∣=n!/2|A_n| = n!/2∣An​∣=n!/2 不适用。n=2n = 2n=2 时 A2={e}A_2 = \{e\}A2​={e}。

⭐ 单性的跳变：A4A_4A4​ 不单（有正规子群 V4={e,(12)(34),(13)(24),(14)(23)}V_4 = \{e, (12)(34), (13)(24), (14)(23)\}V4​={e,(12)(34),(13)(24),(14)(23)}），而 A5A_5A5​ 单且非阿贝尔。这个跳变正是 SnS_nSn​ 可解性的分界线（prop.sn-solvable）。
