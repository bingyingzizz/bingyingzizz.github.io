设 a,b∈Za, b \in \mathbb{Z}a,b∈Z。若存在 c∈Zc \in \mathbb{Z}c∈Z 使 b=acb = acb=ac，就说 aaa 整除 bbb，记 a∣ba \mid ba∣b；否则记 a∤ba \nmid ba∤b。

基本性质：a∣b  ⟹  a∣bca \mid b \implies a \mid bca∣b⟹a∣bc；a∣ba \mid ba∣b 且 b∣cb \mid cb∣c   ⟹  \implies⟹ a∣ca \mid ca∣c；a∣ba \mid ba∣b 且 a∣ca \mid ca∣c   ⟹  \implies⟹ a∣(mb+nc)a \mid (mb + nc)a∣(mb+nc) 对一切 m,n∈Zm, n \in \mathbb{Z}m,n∈Z；若 a,b≠0a, b \ne 0a,b=0，则 a∣ba \mid ba∣b 且 b∣ab \mid ab∣a   ⟺  \iff⟺ a=±ba = \pm ba=±b。

说明

整除在 Z\mathbb{Z}Z 上不是偏序：反称性只在正整数上成立（2∣−22 \mid -22∣−2 与 −2∣2-2 \mid 2−2∣2 同时成立而 2≠−22 \ne -22=−2）。

它和理想是同一件事的两种写法：a∣b  ⟺  (b)⊆(a)a \mid b \iff (b) \subseteq (a)a∣b⟺(b)⊆(a) —— 整除把理想序反过来写。

约定 0∣00 \mid 00∣0 成立（取 ccc 任意），而 0∣b0 \mid b0∣b 只当 b=0b = 0b=0；所以讨论公因数时总要排除全为零的情形。

定义引用 4

  • 整数的带余除法 用到 本页定义引用

    带余除法的陈述里直接用了「整除」：b≠0b \ne 0b=0，r<∣b∣r < |b|r<∣b∣，而 a−qb=ra - qb = ra−qb=r 就是「bbb 除 aaa 的余数」。

  • 最大公因数 用到 本页定义引用

    最大公因数的定义是「同时整除 aaa 与 bbb 的最大正整数」—— 没有整除就没有公因数。

  • 素数 用到 本页定义引用

    素数的定义是「正因数只有 111 与 ppp」，这本身就是用整除写的。

  • 同余 用到 本页定义引用

    同余的定义只用一件事：n∣(a−b)n \mid (a-b)n∣(a−b)。
