陈述

范畴 C\mathcal{C}C 里的对象 000 叫零对象，如果它既是终对象又是始对象。

一族对象 (Mi)i∈I(M_{i})_{i \in I}(Mi​)i∈I​ 的双积（biproduct）是「积与余积恰好重合」的对象，记 ⨁i∈IMi\bigoplus_{i \in I} M_{i}⨁i∈I​Mi​；代数里就叫直和。

说明

零对象给出零态射：任意 X→YX \to YX→Y 都可以经 X→0→YX \to 0 \to YX→0→Y 分解，得到的态射记 0X,Y0_{X,Y}0X,Y​。所有「f=0f = 0f=0」「f≠0f \ne 0f=0」的说法都靠它。

双积为什么会重合：在预加性范畴里，积与余积只要存在就自动一致（两个泛性质能互相满足），所以可以只谈一个。M⊕NM \oplus NM⊕N 的元素形式上写成 f+gf + gf+g（从 MMM 与 NNN 各来一条）。

⚠️ 零对象在不一定有的范畴里可能不存在（如 Set\mathbf{Set}Set：空集是始对象，但终对象是单点集，两者不同）。Ab\mathbf{Ab}Ab、A-ModA\text{-}\mathbf{Mod}A-Mod 里当然是同一个 {0}\{0\}{0}。

Statement draft

An object of a category C\mathcal{C}C, say 000, is a zero object if it is both terminal and initial.

The biproduct of a family (Mi)i∈I(M_{i})_{i \in I}(Mi​)i∈I​ is the object where product and coproduct coincide, written ⨁i∈IMi\bigoplus_{i \in I} M_{i}⨁i∈I​Mi​; in algebra it is called the direct sum.

Notes draft

The zero object gives the zero morphism: any X→YX \to YX→Y factors through X→0→YX \to 0 \to YX→0→Y, and the resulting morphism is written 0X,Y0_{X,Y}0X,Y​. Every statement of the form “f=0f = 0f=0” or “f≠0f \ne 0f=0” relies on it.

Why the biproduct coincides: in a preadditive category, product and coproduct automatically agree whenever they exist (the two universal properties satisfy each other), so one may speak of just one. An element of M⊕NM \oplus NM⊕N is formally written f+gf + gf+g (one summand from MMM and one from NNN).

⚠️ A zero object may fail to exist when the category is not assumed to have one (e.g. Set\mathbf{Set}Set: the empty set is initial, but the terminal object is a one-point set, so they differ). In Ab\mathbf{Ab}Ab and A-ModA\text{-}\mathbf{Mod}A-Mod it is of course the same {0}\{0\}{0}.
