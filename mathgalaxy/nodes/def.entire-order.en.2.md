# order and type of an entire function　`def.entire-order`
English entry · root `../`
[in graph](../#n=def.entire-order)　·　[Chinese page (authoritative)](./def.entire-order.md)

Examples: a polynomial has order $0$; $e^{z}$ has order $1$ and type $1$; $e^{z^{2}}$ has order $2$; $\cos z$ has order $1$.

## Notes · **draft**
**Why use $\log\log$**: the growth of an entire function is “exponential in scale”, and measuring $\log M(r)$ directly distinguishes only “polynomial vs exponential”; a second $\log$ is needed to separate $e^{z}$ ($\log M \sim r$) from $e^{z^{2}}$ ($\log M \sim r^{2}$). This is the origin of the scale “order”.
