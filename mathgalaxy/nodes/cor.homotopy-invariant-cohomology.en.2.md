# Sheaf Cohomology Is a Homotopy Invariant　`cor.homotopy-invariant-cohomology`
English entry · root `../`
[in graph](../#n=cor.homotopy-invariant-cohomology)　·　[Chinese page (authoritative)](./cor.homotopy-invariant-cohomology.md)

1. If $f \simeq g : X \to Y$ are **homotopic** continuous maps, then $f$ and $g$ induce the same map on cohomology;
2. If $f : X \to Y$ is a **homotopy equivalence**, then $H^{n}(Y, M) \cong H^{n}(X, M)$.
