# Laplace expansion　`prop.det-laplace`
English entry · root `../`
[in graph](../#n=prop.det-laplace)　·　[Chinese page (authoritative)](./prop.det-laplace.md)

⭐ Another common corollary (for $K = \mathbb{R}$, $A \in \mathbb{R}^{n \times n}$, viewing $A$ as $n$ row vectors): **the determinant is linear in each row**, so the behaviour of det under elementary row operations can be listed one by one (swapping rows changes the sign, adding a multiple leaves it unchanged, multiplying by $c$ multiplies it by $c$).

Gaussian elimination computes determinants precisely through these three rules.
