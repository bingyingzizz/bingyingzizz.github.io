陈述

设 f∈K[x]f \in K[x]f∈K[x] 是非零多项式，deg⁡f=n\deg f = ndegf=n。则 fff 在 KKK 中至多有 nnn 个根（互不相同的根）。

更精确地（用重数）：存在 a1,…,am∈Ka_1, \ldots, a_m \in Ka1​,…,am​∈K（互异）与正整数 e1,…,eme_1, \ldots, e_me1​,…,em​ 使

f=(x−a1)e1⋯(x−am)em h,h(ai)≠0 for all if = (x - a_1)^{e_1} \cdots (x - a_m)^{e_m}\, h, \qquad h(a_i) \ne 0 \ \text{for all } if=(x−a1​)e1​⋯(x−am​)em​h,h(ai​)=0 for all i

此时 e1+⋯+em≤ne_1 + \cdots + e_m \le ne1​+⋯+em​≤n（eie_iei​ 叫根 aia_iai​ 的重数）。

说明

⭐ 证明就是反复用因式定理：每取一个根就除一次 (x−a)(x - a)(x−a)，次数降 1，降不到负，所以最多 nnn 次。

⭐ 这个「小」命题的用处出乎意料地大：有限域上的多项式恒等式判定（两个次数 <n< n<n 的多项式若在 nnn 个点上相等则恒等）—— 插值法、纠错码（Reed–Solomon）都靠它。

⚠ 只在整环里成立：在 Z/8\mathbb{Z}/8Z/8 上，x2−1x^{2} - 1x2−1 有四个根 1,3,5,71, 3, 5, 71,3,5,7（因为 Z/8\mathbb{Z}/8Z/8 有零因子）。K[x]K[x]K[x] 是整环是关键。

  • 因式定理与根 ⟹ 本页推出
    因式定理   ⟹  \implies⟹ 根的个数不超过次数

    对 n=deg⁡fn = \deg fn=degf 归纳，同时证明「可提出重数」的精确形式。

    存在性：若 fff 在 KKK 中没有根，取 m=0m = 0m=0、h=fh = fh=f 即可。否则取一个根 a1a_1a1​，由因式定理 f=(x−a1)f1f = (x - a_1) f_1f=(x−a1​)f1​，其中 deg⁡f1=n−1\deg f_1 = n - 1degf1​=n−1。对 f1f_1f1​ 归纳，得 f1=(x−a2)e2⋯hf_1 = (x - a_2)^{e_2} \cdots hf1​=(x−a2​)e2​⋯h；再把 a1a_1a1​ 的重数补足（若 f1f_1f1​ 也以 a1a_1a1​ 为根则继续除）。

    次数估计：每一步除法都让次数降 1，而左边总次数是 nnn，所以 e1+⋯+em≤ne_1 + \cdots + e_m \le ne1​+⋯+em​≤n。特别地互异根的个数 m≤nm \le nm≤n。∎

    归纳的写法要注意：重数是一步步除出来的，不是先取互异根再数次数 —— 后者会漏掉「同一个根出现多次」的情形。
