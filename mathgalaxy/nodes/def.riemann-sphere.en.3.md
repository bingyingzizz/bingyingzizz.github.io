## Notes · **draft**
**Why it is worth adding a single point**: many statements (fractional linear maps send circles to circles, the Riemann mapping theorem, cross-ratios) need case distinctions when the plane is only $\mathbb{C}$; after adding $\infty$, a single case remains — a line is a circle through $\infty$, and $1/z$ is a rational map defined everywhere on $\mathbb{C}$.
