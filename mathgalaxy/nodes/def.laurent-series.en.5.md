# Laurent Series　`def.laurent-series`
English entry · root `../`
[in graph](../#n=def.laurent-series)　·　[Chinese page (authoritative)](./def.laurent-series.md)

a principal part with only finitely many terms corresponds to a **pole** (the order = the absolute value of the **largest negative power** in the principal part: if it starts from $(z - a)^{-m}$ one says order $m$ — **not** the number of nonzero terms; $z^{-3}$ has only one term yet is a pole of order three);

an infinite principal part corresponds to an essential singularity.

So the trichotomy of isolated singularities is, in essence, a classification by the shape of the principal part.
