# integral formula for the winding number　`prop.winding-integral`
English entry · root `../`
[in graph](../#n=prop.winding-integral)　·　[Chinese page (authoritative)](./prop.winding-integral.md)

Take $t = 1$: since $\gamma(1) = \gamma(0)$, we have $e^{\varphi(1)} = 1$, hence $\varphi(1) \in 2\pi i \mathbb{Z}$. Now $\varphi(1) = \oint_{\gamma} \mathrm{d}z/z$, so the integral divided by $2\pi i$ is an integer; it varies continuously with $a$, hence is exactly the winding number (integer-valued + continuous $\implies$ locally constant).
