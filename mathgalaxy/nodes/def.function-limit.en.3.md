# limit of a function　`def.function-limit`
English entry · root `../`
[in graph](../#n=def.function-limit)　·　[Chinese page (authoritative)](./def.function-limit.md)

⚠ **Puncturing** is essential: the point $x = x_0$ does not participate in the limit, so whether $f$ is defined at $x_0$, and with what value, does not affect the limit.

For the same reason, "the limit exists and equals $f(x_0)$" can serve as the definition of **continuity**.

⚠ A limit, if it exists, is unique — the proof is the same as in the sequence case (split $\varepsilon$ between the two points).
