# Riemann Integrable Function　`def.riemann-integrable`
English entry · root `../`
[in graph](../#n=def.riemann-integrable)　·　[Chinese page (authoritative)](./def.riemann-integrable.md)

The equivalence of the two definitions is not free — it needs a proof, and that proof is `thm.riemann-criterion`.

⚠ For functions taking values in $\mathbb{C}$, integrability is defined by integrability of the real and imaginary parts;

the vector-valued case is analogous.

⚠ Boundedness is a **prerequisite** for integrability: an unbounded function is not Riemann integrable (it may be Lebesgue integrable, provided $\int |f| < \infty$).
