# Limits as Adjunctions　`prop.limit-adjoint`
English entry · root `../`
[in graph](../#n=prop.limit-adjoint)　·　[Chinese page (authoritative)](./prop.limit-adjoint.md)

$$\operatorname{Hom}_{\mathcal{C}^{I}}(\Delta X, D) \;\cong\; \operatorname{Hom}_{\mathcal{C}}(X, \lim D)$$

The left side is the set of cones, the right side the set of morphisms into the limit. Comparing with the definition of an adjunction word by word, both sides are the same sentence.

So “does this category have limits” asks “does $\Delta$ have an adjoint” — nearly every later construction of an adjunction reduces to constructing some limit.
