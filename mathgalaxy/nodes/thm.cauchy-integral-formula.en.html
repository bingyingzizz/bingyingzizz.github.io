Statement

In plain words: the value of a holomorphic function at an interior point is completely determined by its values on the boundary — every interior point "listens" to the boundary.

Let Ω\OmegaΩ be a bounded region whose boundary ∂Ω\partial\Omega∂Ω is a piecewise smooth simple closed curve, oriented positively, and fff holomorphic on an open set containing Ω‾\overline{\Omega}Ω. Then for every z∈Ωz \in \Omegaz∈Ω,

f(z)=12πi∮∂Ωf(ζ)ζ−z dζ.f(z) = \frac{1}{2\pi i}\oint_{\partial\Omega} \frac{f(\zeta)}{\zeta - z}\,\mathrm{d}\zeta.f(z)=2πi1​∮∂Ω​ζ−zf(ζ)​dζ.

More generally, if γ\gammaγ is a simple closed curve in the region and fff is holomorphic inside γ\gammaγ and on γ\gammaγ, then the formula holds for every point zzz inside γ\gammaγ (for a general closed curve, write Ind⁡(γ,z)f(z)=12πi∮γf(ζ)ζ−z dζ\operatorname{Ind}(\gamma, z)f(z) = \frac{1}{2\pi i}\oint_\gamma \frac{f(\zeta)}{\zeta - z}\,\mathrm{d}\zetaInd(γ,z)f(z)=2πi1​∮γ​ζ−zf(ζ)​dζ).
