又称单位根·分圆多项式·n 次单位根·roots of unity

陈述

设 n≥1n \ge 1n≥1。多项式 xn−1x^{n} - 1xn−1 在 C\mathbb{C}C 中的根叫 nnn 次单位根：

μn:={ ζ∈C:ζn=1 }={ e2πik/n:k=0,1,…,n−1 }.\mu_{n} := \{\, \zeta \in \mathbb{C} : \zeta^{n} = 1 \,\} = \{\, e^{2\pi i k/n} : k = 0, 1, \ldots, n-1 \,\}.μn​:={ζ∈C:ζn=1}={e2πik/n:k=0,1,…,n−1}.

它在乘法下构成一个 nnn 阶循环群。其中本原的那些（阶恰为 nnn）有 φ(n)\varphi(n)φ(n) 个，以它们为根的首一多项式

Φn(x):=∏ζ 本原(x−ζ)\Phi_{n}(x) := \prod_{\zeta \text{ 本原}} (x - \zeta)Φn​(x):=∏ζ 本原​(x−ζ)

叫第 nnn 个分圆多项式，它整系数、不可约（Gauss），且 xn−1=∏d∣nΦd(x)x^{n} - 1 = \prod_{d \mid n} \Phi_{d}(x)xn−1=∏d∣n​Φd​(x)。

说明

⭐ 它为什么在 Galois 那条线上：用根式解方程时，最后一步是「开 nnn 次方」，而开方在域里的样子正是「添加一个 nnn 次单位根之后，xn−ax^{n} - axn−a 的根可以写成 an⋅ζk\sqrt[n]{a}\cdot\zeta^{k}na​⋅ζk」。所以根式可解   ⟹  \implies⟹ 可解那个方向必须先把 μn\mu_{n}μn​ 加进来（根式可解 与 伽罗瓦群可解 的路线里提到过）。

⭐ Φn\Phi_{n}Φn​ 的伽罗瓦群是 (Z/n)×(\mathbb{Z}/n)^{\times}(Z/n)×（每个 σ\sigmaσ 由 ζ↦ζk\zeta \mapsto \zeta^{k}ζ↦ζk 决定，kkk 与 nnn 互素）—— 这是「伽罗瓦群可以是任何有限阿贝尔群」的第一次亮相（Kronecker–Weber 的起点）。

⭐ μn⊆Q\mu_{n} \subseteq \mathbb{Q}μn​⊆Q 只有 n=1,2n = 1, 2n=1,2：n≥3n \ge 3n≥3 时 ζ\zetaζ 不是有理数。所以「添加单位根」是真的扩张，不是形式上的。

⚠ 本图没有「分圆域 Q(ζn)\mathbb{Q}(\zeta_{n})Q(ζn​)」节点：那是这条线的下一步（它的伽罗瓦群与分圆多项式一起构成一个完整例子），留作后续。
