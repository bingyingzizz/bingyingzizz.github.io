# Skyscraper Sheaves Are Injective　`prop.skyscraper-injective`
English entry · root `../`
[in graph](../#n=prop.skyscraper-injective)　·　[Chinese page (authoritative)](./prop.skyscraper-injective.md)

Injectivity must be tested as: for every injective sheaf map $\mathcal{G} \rightarrowtail \mathcal{H}$, the map $\operatorname{Hom}(\mathcal{H}, i_{x,*}A) \to \operatorname{Hom}(\mathcal{G}, i_{x,*}A)$ is surjective.

Using the isomorphism above, this is equivalent to

$$\operatorname{Hom}_{\mathbf{Ab}}(\mathcal{H}_{x},\ A) \longrightarrow \operatorname{Hom}_{\mathbf{Ab}}(\mathcal{G}_{x},\ A)$$
