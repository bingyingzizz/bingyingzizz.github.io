ex.connected-lc-ext · Ext · Ex 8.18

Statement

Let MMM be a connected locally compact Hausdorff abelian group and NNN a discrete abelian group. Then Ext⁡Zn(M,N)=0\operatorname{Ext}^{n}_{\mathbb{Z}}(M, N) = 0ExtZn​(M,N)=0, for all n≠1n \ne 1n=1.

Notes

Difference from the main theorem: the main theorem (only Ext⁡0,Ext⁡1\operatorname{Ext}^{0}, \operatorname{Ext}^{1}Ext0,Ext1 remain between locally compact groups) requires both source and target to be locally compact; this item narrows the hypotheses to "source connected + target discrete", and even Ext⁡0\operatorname{Ext}^{0}Ext0 disappears from the conclusion — because a continuous homomorphism from a connected group to a discrete group must be trivial (a connected image inside a discrete topology is a single point).

Idea of proof: a connected locally compact abelian group splits as "compact connected part ⊕\oplus⊕ real vector space"; for the real vector space part use "real vector spaces →\to→ discrete are all zero", and for the compact connected part use compact-group techniques.

⭐ This is a key component of the "NNN discrete" branch of the main theorem.
