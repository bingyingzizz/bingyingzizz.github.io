又称拉格朗日括号

陈述

在做什么：比 Poisson 括号更早（Lagrange 1808，Poisson 1809）的版本，本质是「Poisson 括号矩阵的逆」。它衡量的是「两族曲线之间的面积」，所以在正则变换理论里更自然。

设 (q,p)(q, p)(q,p) 是 Darboux 坐标，u=(u1,…,u2n)u = (u_{1}, \ldots, u_{2n})u=(u1​,…,u2n​)、v=(v1,…,v2n)v = (v_{1}, \ldots, v_{2n})v=(v1​,…,v2n​) 是两组坐标函数。Lagrange 括号定义为

[u,v]q,p:=∑i=1n(∂qi∂u∂pi∂v−∂pi∂u∂qi∂v).[u, v]_{q,p} := \sum_{i=1}^{n}\Bigl(\frac{\partial q_{i}}{\partial u}\frac{\partial p_{i}}{\partial v} - \frac{\partial p_{i}}{\partial u}\frac{\partial q_{i}}{\partial v}\Bigr) .[u,v]q,p​:=i=1∑n​(∂u∂qi​​∂v∂pi​​−∂u∂pi​​∂v∂qi​​).

与 Poisson 括号的关系：把 Poisson 括号矩阵 ({ui,uj})\bigl(\{u_{i}, u_{j}\}\bigr)({ui​,uj​}) 记为 PPP，Lagrange 括号矩阵记为 LLL，则

L⋅P=I,L \cdot P = I ,L⋅P=I,

即 L=P−1L = P^{-1}L=P−1 —— 两者互为逆矩阵。

正则性的判据：变换 (q,p)↦(Q,P)(q, p) \mapsto (Q, P)(q,p)↦(Q,P) 是正则变换（辛同胚）  ⟺  \iff⟺ 对每个 i,ji, ji,j 有 [Qi,Qj]=[Pi,Pj]=0[Q_{i}, Q_{j}] = [P_{i}, P_{j}] = 0[Qi​,Qj​]=[Pi​,Pj​]=0 且 [Qi,Pj]=δij[Q_{i}, P_{j}] = \delta_{ij}[Qi​,Pj​]=δij​。

说明

为什么历史上先有 Lagrange 括号：变分法与正则变换的研究（Lagrange 的《分析力学》）先出现，那时还没有「辛流形」这个概念。

Poisson 后来才发现「对偶的那个括号」满足优美的 Jacobi 恒等式，于是成了现代形式化的主角。

两个括号记的是同一份信息（互为逆），只是 Lagrange 的那个不满足 Jacobi，所以现在只当工具用。

⭐ 几何意义：Lagrange 括号量的是「uuu、vvv 的等值曲线族在相空间里围出的面积」。所以它天然是「面积」的语言，而 Poisson 括号是「流」的语言 —— 这就是为什么正则变换的条件用 Lagrange 括号写更直观（它直接说「面积不变」）。

⚠️ L=P−1L = P^{-1}L=P−1 只在同一个坐标系下比较时成立：写这两个矩阵必须用同一组 (u,v)(u, v)(u,v) 作基，否则无可比性。这条是最容易记错的地方。

⚠️ 符号：有书把 Lagrange 括号写成 {u,v}\{u,v\}{u,v}（与 Poisson 撞），也有写 [u,v]q,p[u,v]_{q,p}[u,v]q,p​ 的。本图用后者，下标标明参照坐标。
