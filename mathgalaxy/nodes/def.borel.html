陈述

设 XXX 是拓扑空间。XXX 上的 BorelσBorel \sigmaBorelσ代数是由全体开集生成的 σ\sigmaσ代数：

BX:=M({U⊆X:U 是开集})\mathfrak{B}_X := \mathcal{M}(\{ U \subseteq X : U\text{ 是开集} \})BX​:=M({U⊆X:U 是开集})

BX\mathfrak{B}_XBX​ 中的集合称为 Borel 集：开集、闭集、可数个开集之交（GδG_\deltaGδ​）、可数个闭集之并（FσF_\sigmaFσ​）等都属于 BX\mathfrak{B}_XBX​。

说明

开集族本身一般只是拓扑，不是 σ\sigmaσ代数 —— 取它生成的 σ\sigmaσ代数才得到 Borel 集全体。

R\mathbb{R}R 上 BR\mathfrak{B}_\mathbb{R}BR​ 也可以由半开区间 {(a,b]:a<b}\{ (a, b] : a < b \}{(a,b]:a<b} 生成（或 { [a, b) }）。这些形式在构造测度时更好用，因为半开区间的「不交并」算起来干净。
