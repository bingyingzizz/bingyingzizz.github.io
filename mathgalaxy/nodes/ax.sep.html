ax.sep · ZFC · 子集 · 公理模式

又称分离·子集公理·specification·comprehension·separation

陈述

对每个公式 φ(x,p)\varphi (x, p)φ(x,p)（其中 BBB 不出现），下面是一条公理：

∀p∀A∃B∀x[x∈B↔(x∈A∧φ(x,p))]\forall p \forall A \exists B \forall x [ x \in B \leftrightarrow ( x \in A \wedge \varphi(x, p) ) ]∀p∀A∃B∀x[x∈B↔(x∈A∧φ(x,p))]

由外延公理，这样的 BBB 唯一，记作 B={x∈A:φ(x,p)}B = \{ x \in A : \varphi (x, p) \}B={x∈A:φ(x,p)}。俗称「子集公理」。

说明

它是公理模式而不是单条公理：每取一个公式 φ\varphiφ 就得到一条公理，ZFC 因此有无穷多条公理。

限制 x∈Ax \in Ax∈A 是关键——不能写成 {x:x∉x}\{ x : x \notin x \}{x:x∈/x}，否则就是罗素悖论。

它指向谁（出边）

推出 3

  • 本页 ⟹ 空集存在推出
    分离公理模式   ⟹  \implies⟹ 空集存在

    取任意集合 aaa（一阶逻辑的论域非空，故这样的 aaa 存在；在 ZF 中也可由无穷公理提供）。

    取公式 φ(x):≡(x≠x)\varphi (x) :\equiv ( x \ne x )φ(x):≡(x=x)，它是矛盾式。分离公理模式给出集合

    B={x∈a:x≠x}B = \{ x \in a : x \ne x \}B={x∈a:x=x}

    对任意 xxx，x∈B↔(x∈a∧x≠x)x \in B \leftrightarrow ( x \in a \wedge x \ne x )x∈B↔(x∈a∧x=x) 恒为假，故 BBB 不含任何元素。 由外延公理，这样的 BBB 唯一，记作 ∅\emptyset∅。∎

    严格地说，「论域非空」是一阶逻辑的约定，不属于 ZF 公理。若不喜欢这个约定，也可以先由无穷公理取出一个集合再分离。

  • 本页 ⟹ 自然数集存在推出
    无穷公理 + 幂集公理 + 分离公理模式   ⟹  ω\implies \omega⟹ω 存在
    1. 由无穷公理取一个归纳集 III。称 J⊆IJ \subseteq IJ⊆I 是归纳的，若 ∅∈J\emptyset \in J∅∈J 且 ∀x(x∈J→x∪{x}∈J)\forall x (x \in J \to x \cup \{x\} \in J)∀x(x∈J→x∪{x}∈J)。
    2. 由幂集公理，P(I)\mathcal{P}(I)P(I) 是集合；再用分离公理模式取
    S={J∈P(I):J 是归纳集}S = \{ J \in \mathcal{P}(I) : J\text{ 是归纳集} \}S={J∈P(I):J 是归纳集}

    SSS 非空（I∈SI \in SI∈S）。

    1. 再对 P(I)\mathcal{P}(I)P(I) 用一次分离公理模式，令
    ω={x∈I:∀J(J∈S→x∈J)}\omega = \{ x \in I : \forall J ( J \in S \to x \in J ) \}ω={x∈I:∀J(J∈S→x∈J)}

    即 ω\omegaω 是所有归纳子集的交。

    1. ω\omegaω 是归纳集：∅\emptyset∅ 属于每个 J∈SJ \in SJ∈S，故 ∅∈ω\emptyset \in \omega∅∈ω；若 x∈ωx \in \omegax∈ω，则 xxx 属于每个 J∈SJ \in SJ∈S，从而 x∪{x}x \cup \{x\}x∪{x} 属于每个 J∈SJ \in SJ∈S，故 x∪{x}∈ωx \cup \{x\} \in \omegax∪{x}∈ω。
    2. ω\omegaω 含于一切归纳集：若 KKK 是归纳集，则 K∩IK \cap IK∩I 也是归纳集且 K∩I∈SK \cap I \in SK∩I∈S，由 ω\omegaω 的定义 ω⊆K∩I⊆K\omega \subseteq K \cap I \subseteq Kω⊆K∩I⊆K。

    故 ω\omegaω 是最小归纳集，即自然数集。∎

  • 本页 ⟹ 笛卡尔积存在推出
    幂集 + 配对 + 并集 + 分离公理模式   ⟹  A×B\implies A \times B⟹A×B 存在

    任给 AAA、BBB。

    1. 由配对公理与并集公理，A∪BA \cup BA∪B 是集合。
    2. 对任意 a∈Aa \in Aa∈A、b∈Bb \in Bb∈B，Kuratowski 有序对 (a,b)={{a},{a,b}}(a, b) = \{\{a\}, \{a, b\}\}(a,b)={{a},{a,b}}。其中 {a}⊆A∪B\{a\} \subseteq A \cup B{a}⊆A∪B，{a,b}⊆A∪B\{a, b\} \subseteq A \cup B{a,b}⊆A∪B，所以 {a},{a,b}∈P(A∪B)\{a\}, \{a, b\} \in \mathcal{P}(A \cup B){a},{a,b}∈P(A∪B)，进而 (a,b)∈P(P(A∪B))(a, b) \in \mathcal{P}(\mathcal{P}(A \cup B))(a,b)∈P(P(A∪B))。
    3. 由幂集公理，P(P(A∪B))\mathcal{P}(\mathcal{P}(A \cup B))P(P(A∪B)) 是集合。用分离公理模式取
    C={z∈P(P(A∪B)):∃a∈A,∃b∈B,z=(a,b)}C = \{ z \in \mathcal{P}(\mathcal{P}(A \cup B)) : \exists a \in A, \exists b \in B, z = (a, b) \}C={z∈P(P(A∪B)):∃a∈A,∃b∈B,z=(a,b)}

    则 CCC 恰是 A×BA \times BA×B：一方面每个 (a, b) 都在 P(P(A∪B))\mathcal{P}(\mathcal{P}(A \cup B))P(P(A∪B)) 中，另一方面 zzz 是不在 AAA、BBB 中任意点处取到的有序对时不会被选进来。∎

    这个证明展示了一个典型套路：先用幂集「造一个足够大的容器」，再用分离公理模式「筛出真正想要的东西」。

类比 1

  • 有限特征类比
    「不描述整体，只给一个筛子」

    两者都不回答「这个集合里有什么」，只回答「怎么判断一个东西在不在里面」。

    • 分离公理模式：x∈B  ⟺  (x∈A∧φ(x))x \in B \iff (x \in A \wedge \varphi (x))x∈B⟺(x∈A∧φ(x)) —— 给的是判定条件，不是元素清单。
    • 有限特征：X∈A  ⟺  XX \in \mathcal{A} \iff XX∈A⟺X 的每个有限子集属于 A\mathcal{A}A —— 同样是判定条件。

    为什么这个思路重要：集合常常是无穷的，没法列举； 但只要给出判定条件，「这个元素属不属于」就成了一个可回答的问题。 数学里绝大多数「定义」本质上都是这一类 —— 给条件，不给清单。

    💡 读一个新定义时，先问自己：它给的是构造还是判定条件？

推出 1

  • 替换公理模式 ⟹ 本页推出
    替换公理模式   ⟹  \implies⟹ 分离公理模式

    设 φ(x,p)\varphi (x, p)φ(x,p) 是不含 BBB 的公式，AAA 是任意集合。取公式

    ψ(x,y,p):≡(x=y∧φ(x,p))\psi(x, y, p) :\equiv ( x = y \wedge \varphi(x, p) )ψ(x,y,p):≡(x=y∧φ(x,p))

    对任意 xxx，至多只有一个 yyy 使 ψ(x,y,p)\psi (x, y, p)ψ(x,y,p) 成立（因为 x=yx = yx=y 已经确定了 yyy）。于是替换公理模式给出一个集合

    B={y:∃x∈A,ψ(x,y,p)}={x∈A:φ(x,p)}B = \{ y : \exists x \in A, \psi(x, y, p) \} = \{ x \in A : \varphi(x, p) \}B={y:∃x∈A,ψ(x,y,p)}={x∈A:φ(x,p)}

    这正是分离公理模式所要的 BBB（外延公理保证唯一）。∎

    所以 ZF 里其实只需要「替换 + 一个集合存在」就够了，教材仍保留分离公理是为了方便陈述与使用。

定义引用 2

  • 公式 → 本页定义引用

    分离公理模式写的是「对每个公式 φ(x,p)\varphi (x, p)φ(x,p)（其中 BBB 不出现），下面是一条公理」—— 它是公理模式而不是单条公理，正在于它要对每个公式都发一条。

  • 子集 → 本页定义引用

    分离公理模式给出的 B={x∈A:φ(x,p)}B = \{ x \in A : \varphi (x, p) \}B={x∈A:φ(x,p)} 恰好是 AAA 的一个子集——"只从 AAA 里挑元素"正是 ⊆\subseteq⊆ 的语义。
