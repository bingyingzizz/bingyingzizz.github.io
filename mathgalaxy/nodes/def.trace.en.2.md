# trace　`def.trace`
English entry · root `../`
[in graph](../#n=def.trace)　·　[Chinese page (authoritative)](./def.trace.md)

- $\operatorname{tr}(A + B) = \operatorname{tr} A + \operatorname{tr} B$, $\operatorname{tr}(cA) = c\operatorname{tr} A$ (linearity);
- $\operatorname{tr}(AB) = \operatorname{tr}(BA)$, hence $\operatorname{tr}(P^{-1}AP) = \operatorname{tr} A$ (**similarity invariance**);
- $\operatorname{tr}(ABC) = \operatorname{tr}(BCA)$ (**cyclic invariance**).

## Notes · **draft**
⭐ The trace is the **cheapest invariant**: $O(n)$ computes it, yet it already distinguishes many matrices (far cheaper than the determinant).
