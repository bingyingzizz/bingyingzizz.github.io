# exact couple　`def.exact-couple`
English entry · root `../`
[in graph](../#n=def.exact-couple)　·　[Chinese page (authoritative)](./def.exact-couple.md)

$$\ker i = \operatorname{im} k, \qquad \ker j = \operatorname{im} i, \qquad \ker k = \operatorname{im} j .$$

Then $d := j \circ k : E \to E$ satisfies $d^{2} = j (k j) k = 0$ (because $kj = 0$ follows from exactness). The **derived couple** is $(D^{\prime}, E^{\prime}, i^{\prime}, j^{\prime}, k^{\prime})$, where

$$D^{\prime} := \operatorname{im} i, \qquad E^{\prime} := H(E, d) = \ker d \big/ \operatorname{im} d ,$$

$$i^{\prime} := i|_{D^{\prime}}, \qquad j^{\prime}\bigl(i(x)\bigr) := \bigl[\,j(x)\,\bigr], \qquad k^{\prime}\bigl([e]\bigr) := k(e),$$

with brackets $[\,\cdot\,]$ denoting the class in $H(E, d)$.
