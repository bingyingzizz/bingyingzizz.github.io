Statement

In a site C\mathcal{C}C, an object XXX is quasi-compact if for every family (Xi→X)i∈I(X_{i} \to X)_{i \in I}(Xi​→X)i∈I​ generating a covering sieve there is a finite J⊆IJ \subseteq IJ⊆I such that the sieve generated by (Xi→X)i∈J(X_{i} \to X)_{i \in J}(Xi​→X)i∈J​ is also a covering sieve.

In a topos, an equivalent formulation: for every surjection ∐i∈IXi→X\coprod_{i \in I} X_{i} \to X∐i∈I​Xi​→X there is a finite J⊆IJ \subseteq IJ⊆I such that ∐i∈JXi→X\coprod_{i \in J} X_{i} \to X∐i∈J​Xi​→X is still a surjection.

Notes

This is the shape compactness keeps after the topology has been stripped away: every cover has a finite subcover. Compact Hausdorff spaces are exactly the quasi-compact objects in Cond\mathrm{Cond}Cond — the definition of condensed sets is built on it, so the name is worth remembering.
