# Rado theorem: every compact surface is triangulable　`thm.rado`
English entry · root `../`
[in graph](../#n=thm.rado)　·　[Chinese page (authoritative)](./thm.rado.md)

**Approach A (complex analysis).** An orientable compact surface $\rightarrow$ a complex structure (a Riemann surface) $\rightarrow$ existence of a nonconstant meromorphic function $\rightarrow$ the meromorphic function is a branched covering of $\mathbb{CP}^{1}$ $\rightarrow$ pull back and subdivide a triangulation of $\mathbb{CP}^{1}$ (use the branch values as vertices and subdivide into sectors near the branch points using the local model $z\mapsto z^{m}$) $\rightarrow$ obtain a finite triangulation.
