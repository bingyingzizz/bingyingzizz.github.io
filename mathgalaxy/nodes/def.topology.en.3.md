## Notes · **draft**
The three axioms abstract the properties of open intervals on the real line: a union of arbitrarily many open sets is open, but only **finitely** many open sets are guaranteed to have an open intersection ($\bigcap_n (-1/n, 1/n) = \{0\}$ is not open).

The advantage of this language is that **only the question "which sets count as open" remains**, so distances, metrics and coordinates can all be thrown away — continuity, compactness, connectedness and limits can still be expressed.

A set can carry several different topologies;

they are compared as "finer / coarser", not by size.
