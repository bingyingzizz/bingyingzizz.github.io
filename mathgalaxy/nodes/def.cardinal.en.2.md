# cardinality　`def.cardinal`
English entry · root `../`
[in graph](../#n=def.cardinal)　·　[Chinese page (authoritative)](./def.cardinal.md)

If $\#A \le \#B$ and $\#B \le \#A$, then $\#A = \#B$ (the Schröder–Bernstein theorem).

## Notes · **draft**
⭐ Notation: $\#\mathbb{N} = \aleph_0$ (countably infinite), $\#\mathbb{R} = 2^{\aleph_0}$, and $\aleph_0 < 2^{\aleph_0}$.

⚠ Strictly speaking, equipotence classes are not sets; the standard ZFC approach is to take **ordinals** first and then, using the well-ordering theorem ($\iff$ AC), choose the least ordinal in each equipotence class as its representative. That ordinal is called the cardinal.

> Only two facts are needed — $\#A \le \#B$ via injections and $\#A = \#B$ via bijections — and both work without choosing representatives.
