# Schröder–Bernstein 定理　`thm.schroder-bernstein`
Schröder–Bernstein 定理
layer 7 · 定理 · 基数与等势 · 集合论

若存在单射 $f : A \to B$ 与单射 $g : B \to A$，则存在**双射** $A \to B$，即

$$|A| \le |B| \ \text{且}\ |B| \le |A| \implies |A| = |B|$$
