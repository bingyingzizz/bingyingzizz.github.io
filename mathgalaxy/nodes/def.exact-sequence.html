又称正合列·exact sequence·短正合列·Definition 5.2.3

陈述

设

⋯⟶Mn−1→ dn−1 Mn→ dn Mn+1⟶⋯\cdots \longrightarrow M^{n-1} \xrightarrow{\ d^{n-1}\ } M^{n} \xrightarrow{\ d^{n}\ } M^{n+1} \longrightarrow \cdots⋯⟶Mn−1 dn−1 ​Mn dn ​Mn+1⟶⋯

是阿贝尔范畴中的复形（dn∘dn−1=0d^{n} \circ d^{n-1} = 0dn∘dn−1=0）。称它在 MnM^{n}Mn 处正合，如果

im⁡(dn−1)=ker⁡(dn).\operatorname{im}(d^{n-1}) = \ker(d^{n}).im(dn−1)=ker(dn).

处处正合的复形叫正合列。特别地，短正合列

0⟶M′→ f M→ g M′′⟶00 \longrightarrow M' \xrightarrow{\ f\ } M \xrightarrow{\ g\ } M'' \longrightarrow 00⟶M′ f ​M g ​M′′⟶0

意思是：fff 是单态射、ggg 是满态射，且 im⁡(f)=ker⁡(g)\operatorname{im}(f) = \ker(g)im(f)=ker(g)。

说明

一句话：正合 = 「进来的东西恰好就是出去会被杀掉的核」—— 没有多、没有少。im⁡⊆ker⁡\operatorname{im} \subseteq \kerim⊆ker 是复形条件自动给的（d∘d=0d \circ d = 0d∘d=0），正合要求的只是反方向的包含。

两端的 000 在做什么：左端的 0→M′0 \to M'0→M′ 表示 ker⁡(f)=0\ker(f) = 0ker(f)=0，即 fff 单；右端的 M′′→0M'' \to 0M′′→0 表示 im⁡(g)=M′′\operatorname{im}(g) = M''im(g)=M′′，即 ggg 满。于是「短正合列」把单、满、正合三件事打包成一条。

同构的另一种写法：短正合列等价于「M′M'M′ 是 MMM 的子对象、且 M′′≅M/M′M'' \cong M/M'M′′≅M/M′」。这就是把「扩张」讲清楚的最短方式。

📌 与「分裂短正合列」相对照：一般正合列不保证可以写成直和；能写成 M≅M′⊕M′′M \cong M' \oplus M''M≅M′⊕M′′ 的那些是特殊情形。
