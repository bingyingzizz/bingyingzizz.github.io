陈述

设

⋯⟶Mn−1→ dn−1 Mn→ dn Mn+1⟶⋯\cdots \longrightarrow M^{n-1} \xrightarrow{\ d^{n-1}\ } M^{n} \xrightarrow{\ d^{n}\ } M^{n+1} \longrightarrow \cdots⋯⟶Mn−1 dn−1 ​Mn dn ​Mn+1⟶⋯

是阿贝尔范畴中的复形（dn∘dn−1=0d^{n} \circ d^{n-1} = 0dn∘dn−1=0）。称它在 MnM^{n}Mn 处正合，如果

im⁡(dn−1)=ker⁡(dn).\operatorname{im}(d^{n-1}) = \ker(d^{n}).im(dn−1)=ker(dn).

处处正合的复形叫正合列。特别地，短正合列

0⟶M′→ f M→ g M′′⟶00 \longrightarrow M' \xrightarrow{\ f\ } M \xrightarrow{\ g\ } M'' \longrightarrow 00⟶M′ f ​M g ​M′′⟶0

意思是：fff 是单态射、ggg 是满态射，且 im⁡(f)=ker⁡(g)\operatorname{im}(f) = \ker(g)im(f)=ker(g)。

说明

一句话：正合 = 「进来的东西恰好就是出去会被杀掉的核」—— 没有多、没有少。im⁡⊆ker⁡\operatorname{im} \subseteq \kerim⊆ker 是复形条件自动给的（d∘d=0d \circ d = 0d∘d=0），正合要求的只是反方向的包含。

两端的 000 在做什么：左端的 0→M′0 \to M'0→M′ 表示 ker⁡(f)=0\ker(f) = 0ker(f)=0，即 fff 单；右端的 M′′→0M'' \to 0M′′→0 表示 im⁡(g)=M′′\operatorname{im}(g) = M''im(g)=M′′，即 ggg 满。于是「短正合列」把单、满、正合三件事打包成一条。

同构的另一种写法：短正合列等价于「M′M'M′ 是 MMM 的子对象、且 M′′≅M/M′M'' \cong M/M'M′′≅M/M′」。这就是把「扩张」讲清楚的最短方式。

📌 与「分裂短正合列」相对照：一般正合列不保证可以写成直和；能写成 M≅M′⊕M′′M \cong M' \oplus M''M≅M′⊕M′′ 的那些是特殊情形。

  • 本页 ⟹ 正合就是逐点正合推出

    证明。 三句话逐条对照定义即可：「在 M′M'M′ 处正合」读作 ker⁡i=0\ker i = 0keri=0（即 iii 单）；「在 MMM 处正合」读作 im⁡i=ker⁡p\operatorname{im} i = \ker pimi=kerp；

    「在 M′′M''M′′ 处正合」读作 coker⁡p=0\operatorname{coker} p = 0cokerp=0（即 ppp 满）✓。

    把这几条组合起来正是左/右/短正合的定义 ✓。

    ∎

  • 本页 ⟹ 正合列构成子范畴推出

    证明。 ① 是（全）子范畴。 正合性是列本身的性质，与比较映射无关，所以「对象是左正合列」在恒等与复合下当然封闭 —— 它其实是 C3\mathcal{C}^{3}C3 的全子范畴 ✓。 ② 对有限双积封闭。 阿贝尔范畴里核与像都与有限双积交换：

    ker⁡(f1⊕f2)=ker⁡f1⊕ker⁡f2,im⁡(f1⊕f2)=im⁡f1⊕im⁡f2✓\ker(f_{1}\oplus f_{2}) = \ker f_{1}\oplus\ker f_{2}, \qquad \operatorname{im}(f_{1}\oplus f_{2}) = \operatorname{im}f_{1}\oplus\operatorname{im}f_{2} ✓ker(f1​⊕f2​)=kerf1​⊕kerf2​,im(f1​⊕f2​)=imf1​⊕imf2​✓

    （两者分别是有限极限与有限余极限，逐分量计算即可。）于是两条左正合列的双积仍左正合：

    im⁡(d1n−1⊕d2n−1)=im⁡d1n−1⊕im⁡d2n−1=ker⁡d1n⊕ker⁡d2n=ker⁡(d1n⊕d2n)✓\operatorname{im}(d^{n-1}_{1}\oplus d^{n-1}_{2}) = \operatorname{im}d^{n-1}_{1}\oplus\operatorname{im}d^{n-1}_{2} = \ker d^{n}_{1}\oplus\ker d^{n}_{2} = \ker(d^{n}_{1}\oplus d^{n}_{2}) ✓im(d1n−1​⊕d2n−1​)=imd1n−1​⊕imd2n−1​=kerd1n​⊕kerd2n​=ker(d1n​⊕d2n​)✓

    右正合对偶。短正合列再补一句：0→M′→M→M′′→00 \to M' \to M \to M'' \to 00→M′→M→M′′→0 正合   ⟺  \iff⟺ 左端映射单、右端映射满、且 im⁡=ker⁡\operatorname{im} = \kerim=ker —— 这三条都被逐分量保持 ✓。零对象（三条零列）显然正合，充当双积的单位元 ✓。 于是这三族对象各自是 C3\mathcal{C}^{3}C3 的加法子范畴 ✓。∎
