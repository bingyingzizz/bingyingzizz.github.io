可解性对子群与商群封闭

定理：可解性在子群、商群与扩张下的行为

陈述

设 GGG 是群。

（a）子群：若 GGG 可解、H≤GH \le GH≤G，则 HHH 可解。

（b）商群：若 GGG 可解、N⊴GN \trianglelefteq GN⊴G，则 G/NG/NG/N 可解。

（c）扩张：若 N⊴GN \trianglelefteq GN⊴G，NNN 可解且 G/NG/NG/N 可解，则 GGG 可解。

（(a)(b) 说的是「可解性向下传」，(c) 说的是「可解性沿正规扩张向上传」。）

说明

⭐ (c) 是这三条里最有用的：判 GGG 可解时，只要找到一条正规子群把 GGG 夹在中间，两头分别可解即可 —— 这就是把大群拆小的标准手法。

⚠ (a)(b) 的逆都不成立，反例很小：

  • 子群可解推不出群可解：Z/2≤A5\mathbb{Z}/2 \le A_5Z/2≤A5​ 可解，A5A_5A5​ 不可解；
  • 商群可解推不出群可解：S5/A5≅Z/2S_5 / A_5 \cong \mathbb{Z}/2S5​/A5​≅Z/2 可解，S5S_5S5​ 不可解。

所以「可解」不是「局部性质」，必须靠 (c) 那样的两头夹才往上传。

⭐ 用导出列看这三条几乎是一句话：H(k)≤G(k)H^{(k)} \le G^{(k)}H(k)≤G(k)；π(G(k))=(G/N)(k)\pi(G^{(k)}) = (G/N)^{(k)}π(G(k))=(G/N)(k)。证明全文在边上。

⭐ 立刻得到一个常用判据：GGG 可解   ⟺  \iff⟺ 存在正规链使商循环（而不只是阿贝尔）—— 因为阿贝尔群还能再细分成循环因子。

    导出列的三条函子性   ⟹  \implies⟹ 封闭性

    先记两个初等事实：若 φ:G→G′\varphi : G \to G'φ:G→G′ 是满同态，则 φ(G(k))=(G′)(k)\varphi(G^{(k)}) = (G')^{(k)}φ(G(k))=(G′)(k)（换位子被送到换位子，且满射保证反向也成立）。

    （a） 设 GGG 可解，G(n)={e}G^{(n)} = \{e\}G(n)={e}。因 H≤GH \le GH≤G 蕴含 H(k)≤G(k)H^{(k)} \le G^{(k)}H(k)≤G(k)（对 kkk 归纳：[H,H]≤[G,G][H,H] \le [G,G][H,H]≤[G,G]，再逐层），故 H(n)≤G(n)={e}H^{(n)} \le G^{(n)} = \{e\}H(n)≤G(n)={e}，即 H(n)={e}H^{(n)} = \{e\}H(n)={e}。

    （b） 设 π:G→G/N\pi : G \to G/Nπ:G→G/N 是自然满同态。由上面的事实

    (G/N)(n)=π(G(n))=π({e})={e},(G/N)^{(n)} = \pi(G^{(n)}) = \pi(\{e\}) = \{e\},(G/N)(n)=π(G(n))=π({e})={e},

    故 G/NG/NG/N 可解。

    （c） 设 NNN 可解、G/NG/NG/N 可解。取 nnn 使 (G/N)(n)={e}(G/N)^{(n)} = \{e\}(G/N)(n)={e}，即 π(G(n))={e}\pi(G^{(n)}) = \{e\}π(G(n))={e}，也就是 G(n)≤NG^{(n)} \le NG(n)≤N。再取 mmm 使 N(m)={e}N^{(m)} = \{e\}N(m)={e}。于是
