# long exact sequence of a pair　`thm.long-exact-pair`

**(b) $\operatorname{im} q_{*} = \ker \partial_{*}$.** If $[c] = q_{*}[z]$ and $z$ is a cycle in $X$, then $\partial c = \partial z = 0$, so $\partial_{*}[c] = 0$. Conversely, suppose $\partial_{*}[c] = 0$, so $\partial c = \partial a$ for some $a \in S_{p-1}(A)$. Set $z := c - a$. Then $\partial z = 0$ and $q(z) = q(c)$, so $[c] = q_{*}[z]$.
