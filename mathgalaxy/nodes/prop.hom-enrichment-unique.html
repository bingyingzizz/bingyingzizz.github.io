又称预加性结构唯一·Exercise 5.2

陈述

设 C\mathcal{C}C 是加法范畴。则使复合双线性、并与直和结构相容的 Hom⁡C(M,N)\operatorname{Hom}_{\mathcal{C}}(M,N)HomC​(M,N) 的阿贝尔群结构是唯一的。

说明

证明。 记 ΔM:M→M⊕M\Delta_{M} : M \to M \oplus MΔM​:M→M⊕M 是由积的泛性给出的「对角线」（pkΔM=1Mp_{k}\Delta_{M} = 1_{M}pk​ΔM​=1M​）、∇N:N⊕N→N\nabla_{N} : N \oplus N \to N∇N​:N⊕N→N 是由余积的泛性给出的「余对角线」（∇Nik=1N\nabla_{N}i_{k} = 1_{N}∇N​ik​=1N​）、f⊕g:M⊕M→N⊕Nf \oplus g : M \oplus M \to N \oplus Nf⊕g:M⊕M→N⊕N 是由四个角 pk(f⊕g)il=δkl (f 或 g)p_{k}(f\oplus g)i_{l} = \delta_{kl}\,(f \text{ 或 } g)pk​(f⊕g)il​=δkl​(f 或 g) 刻画的映射。这三个映射只用到直和的对象、投影与含入，与任何群结构无关 ✓。 关键公式：

f+g=∇N∘(f⊕g)∘ΔM.f + g = \nabla_{N}\circ (f \oplus g)\circ \Delta_{M}.f+g=∇N​∘(f⊕g)∘ΔM​.

验证：由 pk(f⊕g)=(第k分量)pkp_{k}(f\oplus g) = (\text{第} k \text{分量})p_{k}pk​(f⊕g)=(第k分量)pk​ 得 (f⊕g)ΔM(f\oplus g)\Delta_{M}(f⊕g)ΔM​ 的两个分量恰是 fff 与 ggg，即 (f⊕g)ΔM=i1f+i2g(f\oplus g)\Delta_{M} = i_{1}f + i_{2}g(f⊕g)ΔM​=i1​f+i2​g；再作用 ∇N\nabla_{N}∇N​，用 ∇Nik=1N\nabla_{N}i_{k} = 1_{N}∇N​ik​=1N​ 得 f+gf + gf+g ✓。（这一步的计算用到了群结构，但公式右边本身不依赖它。） 唯一性：既然「fff 与 ggg 的和」等于一个只由范畴结构与直和写出的表达式，任何使复合双线性的群结构都必须满足同一公式，故与它逐对一致 ✓。∎

⭐ 一句话：加法范畴里的「加」不是额外数据，而是双积结构逼出来的。 这也是为什么「加法函子」可以只要求「保双积」——见「加法函子的刻画」。
