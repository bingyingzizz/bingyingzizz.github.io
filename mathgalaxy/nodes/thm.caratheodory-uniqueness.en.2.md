# uniqueness of the Carathéodory extension　`thm.caratheodory-uniqueness`
English entry · root `../`
[in graph](../#n=thm.caratheodory-uniqueness)　·　[Chinese page (authoritative)](./thm.caratheodory-uniqueness.md)

## Statement · **draft**
Let $\mu _{0}$ be a premeasure on a **ring** $\mathfrak{A}$ (Carathéodory uniqueness already holds for rings; the case where $\mathfrak{A}$ is an algebra is a special case), and $\mu := \mu^{*}|_\mathcal{M}$ the extension obtained from it by Carathéodory. If $\nu$ is a measure on $\mathcal{M}(\mathfrak{A})$ that is **another** extension of $\mu _{0}$, then

$$\nu(E) \le \mu(E)\quad  \forall E \in \mathcal{M}(\mathfrak{A})$$

and equality holds when $\mu(E) < \infty$; moreover, if $\mu$ is $\sigma$-finite, then $\nu = \mu$.
