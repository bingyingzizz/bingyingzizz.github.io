def.prime · 数论 · 素数

又称质数·素元素

陈述

大于 111 的整数 ppp 叫素数，若它的正因数只有 111 与 ppp 本身。大于 111 且不是素数的整数叫合数。

说明

真正用来做证明的性质不是「只有两个因数」，而是 Euclid 引理：p∣ab  ⟹  p∣ap \mid ab \implies p \mid ap∣ab⟹p∣a 或 p∣bp \mid bp∣b。

这两条在 Z\mathbb{Z}Z 里等价，但在一般整环里不等价：Z[−5]\mathbb{Z}[\sqrt{-5}]Z[−5​] 里 2∣(1+−5)(1−−5)=62 \mid (1+\sqrt{-5})(1-\sqrt{-5}) = 62∣(1+−5​)(1−−5​)=6 而 222 不整除任一因子 —— 元素「不可约」却不「素」。环论把后者抽象成素元素，前者是不可约元素。

111 不是素数：否则唯一分解就不唯一了（6=2⋅3=1⋅2⋅36 = 2\cdot 3 = 1\cdot 2\cdot 36=2⋅3=1⋅2⋅3）。
