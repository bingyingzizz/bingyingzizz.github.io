# entire and meromorphic functions　`def.entire-meromorphic`
English entry · root `../`
[in graph](../#n=def.entire-meromorphic)　·　[Chinese page (authoritative)](./def.entire-meromorphic.md)

⭐ Examples: $1/\sin z$ (poles at $k\pi$), $\tan z$, and the $\Gamma$ function (poles at $0, -1, -2, \ldots$).

⚠ An essential singularity **does not count** as meromorphic: the behaviour of $e^{1/z}$ near $0$ is not a pole, so $e^{1/z}$ is not meromorphic on a region containing $0$. Meromorphic requires every bad point to be a pole.

⚠ "Isolated" cannot be dropped either: if the singularities have an accumulation point, it is not a pole.
