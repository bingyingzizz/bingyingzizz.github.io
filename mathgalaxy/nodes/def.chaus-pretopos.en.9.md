# Compact Hausdorff Spaces Form a Pretopos　`def.chaus-pretopos`
English entry · root `../`
[in graph](../#n=def.chaus-pretopos)　·　[Chinese page (authoritative)](./def.chaus-pretopos.md)

⚠️ **$\mathbf{CHaus}$ is not a topos**: it lacks a **small generator + arbitrary colimits** (arbitrary colimits need reflection, and there is no representable small generator/subobject classifier). So it is only a **pretopos** — this example illustrates exactly the usefulness of the notion "pretopos": it captures the layer where "one can form quotients and equivalence relations".
