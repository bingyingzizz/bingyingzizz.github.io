设 f:A→Bf : \mathcal{A} \to \mathcal{B}f:A→B 是解析环之间的映射（即凝聚态环映射，且每个 B[S]\mathcal{B}[S]B[S] 作为 AAA-模落在 Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​ 里）。则：

(i) 复合函子 Mod⁡Acond→−⊗ABMod⁡Bcond→−⊗BBMod⁡Bcond\operatorname{Mod}^{\mathrm{cond}}_{A} \xrightarrow{-\otimes_{A} B} \operatorname{Mod}^{\mathrm{cond}}_{B} \xrightarrow{-\otimes_{\mathcal{B}}\mathcal{B}} \operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}}ModAcond​−⊗A​B​ModBcond​−⊗B​B​ModBcond​ 穿过 Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​，记作

M⟼M⊗AB:Mod⁡Acond⟶Mod⁡Bcond.M \longmapsto M \otimes_{\mathcal{A}} \mathcal{B} : \operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}} \longrightarrow \operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}}.M⟼M⊗A​B:ModAcond​⟶ModBcond​.

(ii) 导出版本 C↦C⊗ALBC \mapsto C \otimes^{L}_{\mathcal{A}} \mathcal{B}C↦C⊗AL​B 是它的左导出。

说明

⭐ 这条让 Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​ 对 A\mathcal{A}A 函子化：换解析环就是做 base change。

⭐ 证明很短：由映射的定义，B[S]\mathcal{B}[S]B[S] 已经在 Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​ 里，而它们是紧投射生成元，所以整个 Mod⁡Bcond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}}ModBcond​ 都落进去。

Statement draft

Let f:A→Bf : \mathcal{A} \to \mathcal{B}f:A→B be a map between analytic rings (that is, a map of condensed rings such that each B[S]\mathcal{B}[S]B[S] lies in Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​ as an AAA-module). Then:

(i) the composite functor Mod⁡Acond→−⊗ABMod⁡Bcond→−⊗BBMod⁡Bcond\operatorname{Mod}^{\mathrm{cond}}_{A} \xrightarrow{-\otimes_{A} B} \operatorname{Mod}^{\mathrm{cond}}_{B} \xrightarrow{-\otimes_{\mathcal{B}}\mathcal{B}} \operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}}ModAcond​−⊗A​B​ModBcond​−⊗B​B​ModBcond​ factors through Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​, written

M⟼M⊗AB:Mod⁡Acond⟶Mod⁡Bcond.M \longmapsto M \otimes_{\mathcal{A}} \mathcal{B} : \operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}} \longrightarrow \operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}}.M⟼M⊗A​B:ModAcond​⟶ModBcond​.

(ii) the derived version C↦C⊗ALBC \mapsto C \otimes^{L}_{\mathcal{A}} \mathcal{B}C↦C⊗AL​B is its left derived functor.

Notes draft

⭐ This makes Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​ functorial in A\mathcal{A}A: changing the analytic ring is base change.

⭐ The proof is short: by the definition of the map, B[S]\mathcal{B}[S]B[S] already lies in Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​, and these are compact projective generators, so all of Mod⁡Bcond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}}ModBcond​ lands inside.

    解析环映射   ⟹  \implies⟹ base change

    (i) 由映射 f:A→Bf : \mathcal{A} \to \mathcal{B}f:A→B 的定义，每个 B[S]\mathcal{B}[S]B[S] 作为 AAA-模都在 Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​ 里；

    而这些 B[S]\mathcal{B}[S]B[S] 是 Mod⁡Bcond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}}ModBcond​ 的紧投射生成元，故整个 Mod⁡Bcond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}}ModBcond​ 都落进 Mod⁡Acond\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}}ModAcond​。

    (ii) 检验 C∈D(Mod⁡Bcond)C \in D(\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{B}})C∈D(ModBcond​) 作为 AAA-模是否在 D(Mod⁡Acond)D(\operatorname{Mod}^{\mathrm{cond}}_{\mathcal{A}})D(ModAcond​) 里：由 (ii) 的判据只需看上同调，归约到 (i)。

    得到的函子保余极限、把 A[S]A[S]A[S] 送到 B[S]\mathcal{B}[S]B[S]，故是左导出。

    ■\blacksquare■
