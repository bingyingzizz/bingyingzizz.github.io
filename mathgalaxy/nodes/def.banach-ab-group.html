陈述

Banach 阿贝尔群是半范数阿贝尔群 MMM，且满足

  • ∥s∥=0  ⟹  s=0\|s\| = 0 \implies s = 0∥s∥=0⟹s=0（分离性，即半范数其实是范数）；
  • MMM 对范数导出的度量完备。

任一半范数阿贝尔群 MMM 都有 Banach 化：先 Hausdorff 化、再完备化，

M⟼M/M0^,M0={ s:∥s∥=0 }.M \longmapsto \widehat{M/M_{0}},\qquad M_{0} = \{\, s : \|s\| = 0 \,\}.M⟼M/M0​​,M0​={s:∥s∥=0}.

说明

在凝聚态世界里长什么样。Banach 阿贝尔群 MMM 上，截面 Hom⁡(Z[S],M)\operatorname{Hom}(\mathbb{Z}[S], M)Hom(Z[S],M) 可以配一个「上确界半范数」，于是 MMM 作为一个凝聚态阿贝尔群本身带着范数信息。§8.2 的所有定量陈述都是在这个半范数上做的。

⚠️ 这里说的是阿贝尔群带范数，不是「向量空间」。每个实 Banach 空间当然是 Banach 阿贝尔群（忘掉标量乘法），但反过来不然 —— 第 8 章的很多定理只用到群结构。

⭐ 「Hausdorff 化 + 完备化」这两步是反射：它把半范数阿贝尔群的范畴投到 Banach 阿贝尔群的子范畴上，且让 KKK-有界正合这种定量性质不增不减地传过去。
