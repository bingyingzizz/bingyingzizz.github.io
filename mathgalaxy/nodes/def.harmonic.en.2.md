# harmonic function　`def.harmonic`

holds everywhere on $\Omega$, then $u$ is called a **harmonic function** on $\Omega$.

Equivalent characterization (local): $u$ is the real part of some holomorphic function (always possible on a disk, and also on simply connected regions, see the node on "harmonic conjugates").

## Notes · **draft**
⭐ The real and imaginary parts of a holomorphic function are harmonic: by the Cauchy–Riemann equations $u_x = v_y$, $u_y = -v_x$, one gets

$$\Delta u = (u_x)_x + (u_y)_y = (v_y)_x + (-v_x)_y = v_{xy} - v_{yx} = 0,$$

the last step using equality of mixed partials ($v$ is sufficiently smooth).
