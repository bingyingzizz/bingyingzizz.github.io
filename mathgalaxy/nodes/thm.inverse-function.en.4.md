⭐ The theorem also shows that $f$ is an **open map** (it sends the open set $V$ to the open set $W$) — this is **free** in both finite dimensions and Banach spaces (the inverse function theorem itself gives a local homeomorphism, and a local homeomorphism automatically sends open sets to open sets). ⚠ Do not confuse this with the **open mapping theorem** of functional analysis: that one says a surjective bounded linear operator is open, a different notion sharing the name with "a nonconstant holomorphic function is open".
