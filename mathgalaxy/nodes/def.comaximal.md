# 互素理想　`def.comaximal`
互素理想：$I + J = A$
layer 10 · 定义 · 整环与分解 · 抽象代数
[在星图里打开](../#n=def.comaximal)　·　[节点索引](../index.md)

环 $A$ 的两个理想 $I, J$ 叫**互素**，若

$$I + J = A .$$

一族理想 $\{I_{1}, \cdots, I_{k}\}$ 叫**两两互素**，若 $i \ne j$ 时 $I_{i} + I_{j} = A$。
