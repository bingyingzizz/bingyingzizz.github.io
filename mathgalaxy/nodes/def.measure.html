设 M\mathcal{M}M 是 XXX 上的 σ\sigmaσ代数。函数 μ:M→[0,+∞]\mu : \mathcal{M} \to [0, +\infty]μ:M→[0,+∞] 是一个测度，当且仅当

  • (i)　μ(∅)=0\mu(\emptyset) = 0μ(∅)=0
  • (ii) 可数可加：若 {Ej}\{E_{j}\}{Ej​} 是 M\mathcal{M}M 中两两不交的集合列，则
μ(⋃j=1∞Ej)=∑j=1∞μ(Ej)\mu( \bigcup_{j=1}^{\infty} E_j ) = \sum_{j=1}^{\infty} \mu(E_j)μ(j=1⋃∞​Ej​)=j=1∑∞​μ(Ej​)

(X,M,μ)(X, \mathcal{M}, \mu )(X,M,μ) 称为测度空间。

说明

(i) 看起来多余（由 (ii) 取 Ej=∅E_{j} = \emptysetEj​=∅ 立刻得到），写出来是为了排除「恒取 ∞\infty∞」这种没有意义的解，同时保证 (ii) 中的级数不是 ∞−∞\infty - \infty∞−∞。

可数可加是本定义唯一有实质内容的要求：它把「大小」从有限可加提升到可数可加，代价是允许取值为 ∞\infty∞。

⚠ 允许 μ(E)=+∞\mu (E) = +\inftyμ(E)=+∞ 是必要的：R\mathbb{R}R 的 Lebesgue 测度就是 ∞\infty∞。
