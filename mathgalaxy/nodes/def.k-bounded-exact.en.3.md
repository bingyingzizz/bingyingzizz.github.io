# K-bounded exact　`def.k-bounded-exact`
English entry · root `../`
[in graph](../#n=def.k-bounded-exact)　·　[Chinese page (authoritative)](./def.k-bounded-exact.md)

**Why this stronger condition is needed.** In Banach and seminormed settings, knowing that a cycle is a boundary is insufficient because errors can accumulate when taking limits. The $K$-bounded exactness condition gives **control over countable constructions**, allowing later constructions involving geometrically decaying Cauchy sequences to converge.

**What the $\varepsilon$ term does**: The norm comparisons allow a margin so that $\le$ still holds after taking limits. In practice, $\varepsilon$ can be arbitrarily small.
