# filtered colimits are exact　`prop.filtered-exact`
English entry · root `../`
[in graph](../#n=prop.filtered-exact)　·　[Chinese page (authoritative)](./prop.filtered-exact.md)

$$\varinjlim_{i} (X_{i} \times Y_{i}) \;\cong\; \bigl(\varinjlim_{i} X_{i}\bigr) \times \bigl(\varinjlim_{i} Y_{i}\bigr)$$

The method is to take representatives on both sides and compare: an element of the filtered colimit $\mathbf{Set}$ is exactly an element at some index, so "one representative on each side" can be lifted to "a pair at the same index".
