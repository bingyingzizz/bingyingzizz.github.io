# Refinement of the Embedding Theorem　`prop.mitchell-exactness`

[in graph](../#n=prop.mitchell-exactness)　·　[Chinese page (authoritative)](./prop.mitchell-exactness.md)

⭐ **Why the "reflection" direction is the useful half**: in module categories there are ready-made tools for deciding projectivity (direct summands, vanishing of $\operatorname{Ext}^{1}$, Baer-type criteria), whereas in an abstract small abelian category one has almost no handle. Reflection turns "a hard problem in $\mathcal{C}$" into "an easy problem in a module category".
