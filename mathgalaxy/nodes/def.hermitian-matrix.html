Hermite 矩阵与对称矩阵：等于自己的伴随

def.hermitian-matrix · 定义 · 线性代数 · Hermite 矩阵 · 对称矩阵 · 自伴

又称埃尔米特矩阵·厄米矩阵

陈述

在做什么：把「自伴」写成矩阵条件。复情形叫 Hermite，实情形叫对称。它们的特征是特征值全实、可正交对角化。

设 A∈Mn(C)A \in M_{n}(\mathbb{C})A∈Mn​(C)。称 AAA 是 Hermite 矩阵（自伴矩阵），若

A∗=A.A^{*} = A .A∗=A.

实方阵满足 AT=AA^{T} = AAT=A 时叫对称矩阵。

关键性质：(i) 对角元全实；(ii) 特征值全是实数；(iii) 属于不同特征值的特征向量互相正交；(iv) 存在酉矩阵 UUU 使 U∗AUU^{*}AUU∗AU 为实对角阵（谱定理（矩阵版））。

实对称矩阵是 Hermite 矩阵在 AAA 取实值时的特例，此时 (iv) 可写成 QTAQQ^{T}AQQTAQ 为对角阵，QQQ 正交。

说明

为什么特征值是实的：取特征向量 x≠0x \ne 0x=0 使 Ax=λxAx = \lambda xAx=λx，则 λ⟨x,x⟩=⟨Ax,x⟩=⟨x,Ax⟩=λ‾⟨x,x⟩\lambda\langle x, x\rangle = \langle Ax, x\rangle = \langle x, Ax\rangle = \overline{\lambda}\langle x, x\rangleλ⟨x,x⟩=⟨Ax,x⟩=⟨x,Ax⟩=λ⟨x,x⟩ —— 第二步用的就是自伴。

于是 λ=λ‾\lambda = \overline{\lambda}λ=λ。

为什么不同特征值的特征向量正交：若 Ax=λxAx = \lambda xAx=λx、Ay=μyAy = \mu yAy=μy，则 λ⟨x,y⟩=⟨Ax,y⟩=⟨x,Ay⟩=μ⟨x,y⟩\lambda\langle x,y\rangle = \langle Ax,y\rangle = \langle x,Ay\rangle = \mu\langle x,y\rangleλ⟨x,y⟩=⟨Ax,y⟩=⟨x,Ay⟩=μ⟨x,y⟩，而 λ≠μ\lambda \ne \muλ=μ   ⟹  \implies⟹ ⟨x,y⟩=0\langle x,y\rangle = 0⟨x,y⟩=0。

这两行是整章的核心计算，谱定理全靠它起头。

它和二次型的关系：对称矩阵与二次型一一对应（q(x)=xTAxq(x) = x^{T}Axq(x)=xTAx，二次型）；Hermite 矩阵与 Hermite 型一一对应。「正定」就是这条对应下「q>0q > 0q>0」（正定矩阵）。

⚠️ 别把「Hermite」与「对称」当两件无关的事：实对称 ⊂\subset⊂ Hermite。而复对称（AT=AA^{T} = AAT=A 而 A∗≠AA^{} \ne AA∗=A）既不是 Hermite 也没有实特征值 —— 复数域上要用 A∗A^{}A∗，不是 ATA^{T}AT。

定义引用 4

  • 正规矩阵 用到 本页定义引用

    Hermite 是正规的特例（A∗=AA^{*} = AA∗=A   ⟹  \implies⟹ 两个乘积都是 A2A^{2}A2），包含关系写进正文。

  • 正定矩阵 用到 本页定义引用

    正定只对 Hermite（实对称）矩阵定义 —— 否则 x∗Axx^{*}Axx∗Ax 不是实的，「>0>0>0」没有意义。

  • Rayleigh 商 用到 本页定义引用

    Rayleigh 商只对 Hermite（实对称）矩阵有实值、有极值意义。

  • Courant–Fischer 极小极大原理 用到 本页定义引用

    定理要求 AAA 是 Hermite（实对称）—— 否则特征值不是实的，不等式无从谈起。

    Hermite 的定义 A∗=AA^{*} = AA∗=A 就是一个共轭转置条件。
