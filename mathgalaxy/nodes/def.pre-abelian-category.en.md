## Statement · **draft**
A **pre-abelian category** is an additive category in which every morphism has a **kernel** and a **cokernel** (for the definitions see @@def.kernel-cokernel@@).

Equivalently: a pre-abelian category is an additive category in which all finite limits and all finite colimits exist.
