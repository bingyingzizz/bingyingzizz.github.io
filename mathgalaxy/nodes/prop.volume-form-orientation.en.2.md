# Orientation and Volume Forms　`prop.volume-form-orientation`
English entry · root `../`
[in graph](../#n=prop.volume-form-orientation)　·　[Chinese page (authoritative)](./prop.volume-form-orientation.md)

Let $M$ be an $n$-dimensional smooth manifold. Then $M$ is orientable if and only if there is an everywhere nonzero $n$-form

$$\omega \in \Omega^{n}(M),\qquad \omega_{p} \ne 0\ \ \bigl(\forall p \in M\bigr).$$

More precisely: two everywhere nonzero $n$-forms $\omega, \omega_{1}$ necessarily satisfy $\omega_{1} = f\,\omega$ with $f$ an everywhere nonzero smooth function; they give the **same orientation** if and only if $f > 0$ everywhere.
