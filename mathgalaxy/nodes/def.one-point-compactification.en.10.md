⚠️ **So "the one-point compactification always exists" must be read carefully**: $X^{*}$ always exists as a compact space; but it is **Hausdorff** only when $X$ is locally compact Hausdorff. Many textbooks state only the former, so beginners conclude that "every space can be compactified" — **false**: those admitting a Hausdorff compactification are exactly the locally compact Hausdorff spaces.
