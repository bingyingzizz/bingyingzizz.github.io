Statement

Call A⊆XA \subseteq XA⊆X a meager set (set of the first category) if AAA is a countable union of nowhere dense sets; a set that is not meager is of the second category. Call AAA residual if AcA^cAc is meager.

Notes

"Category" is a third notion of size, neither cardinality nor measure: Q\mathbb{Q}Q is countable and dense yet meager (each singleton is nowhere dense); the Cantor set is uncountable and of measure zero yet meager (it is itself nowhere dense); [0,1]∖Q[0,1] \setminus \mathbb{Q}[0,1]∖Q is of the second category and residual in the subspace [0,1][0,1][0,1] (it is not residual in R\mathbb{R}R: its complement contains the interval (1,2)(1,2)(1,2), which is not meager).

⚠️ Second category ≠\ne= dense: [0,1]∪{2}[0,1] \cup \{2\}[0,1]∪{2} is also of the second category.

⭐ Usage: to say "almost every point satisfies PPP", prove that {x:¬P(x)}\{x : \neg P(x)\}{x:¬P(x)} is meager. In infinite dimension this is often handier than measure theory (many function spaces have no natural measure but do have a Baire category).
