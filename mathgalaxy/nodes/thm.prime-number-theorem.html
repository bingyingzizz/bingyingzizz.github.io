引理 1（ψ\psiψ 与 θ\thetaθ 的关系）：

ψ(x)=∑k≥1θ(x1/k).\psi(x) = \sum_{k \ge 1} \theta\big(x^{1/k}\big).ψ(x)=k≥1∑​θ(x1/k).

证明：按 n=pkn = p^{k}n=pk 的 kkk 分组，pk≤x  ⟺  p≤x1/kp^{k} \le x \iff p \le x^{1/k}pk≤x⟺p≤x1/k，每组贡献 log⁡p\log plogp，求和即 θ(x1/k)\theta(x^{1/k})θ(x1/k)；k>log⁡2xk > \log_{2} xk>log2​x 时 x1/k<2x^{1/k} < 2x1/k<2，对应项为 000。∎

引理 2（ψ∼x  ⟺  θ∼x\psi \sim x \iff \theta \sim xψ∼x⟺θ∼x）：由引理 1，

0≤ψ(x)−θ(x)=∑k=2⌊log⁡2x⌋θ(x1/k)≤∑k=2⌊log⁡2x⌋x1/klog⁡x≤(log⁡2x) x log⁡x=o(x).0 \le \psi(x) - \theta(x) = \sum_{k=2}^{\lfloor \log_{2} x \rfloor} \theta\big(x^{1/k}\big) \le \sum_{k=2}^{\lfloor \log_{2} x \rfloor} x^{1/k}\log x \le (\log_{2} x)\,\sqrt{x}\,\log x = o(x).0≤ψ(x)−θ(x)=k=2∑⌊log2​x⌋​θ(x1/k)≤k=2∑⌊log2​x⌋​x1/klogx≤(log2​x)x​logx=o(x).

引理 3（Abel 变换）：

θ(x)=π(x)log⁡x−∫2xπ(t)t dt,π(x)=θ(x)log⁡x+∫2xθ(t)tlog⁡2t dt.\theta(x) = \pi(x)\log x - \int_{2}^{x} \frac{\pi(t)}{t}\,\mathrm{d}t,\qquad \pi(x) = \frac{\theta(x)}{\log x} + \int_{2}^{x} \frac{\theta(t)}{t\log^{2} t}\,\mathrm{d}t.θ(x)=π(x)logx−∫2x​tπ(t)​dt,π(x)=logxθ(x)​+∫2x​tlog2tθ(t)​dt.

证明：对 Stieltjes 积分 ∑p≤xf(p)=π(x)f(x)−∫2xπ(t) df(t)\sum_{p \le x} f(p) = \pi(x)f(x) - \int_{2}^{x} \pi(t)\,\mathrm{d}f(t)∑p≤x​f(p)=π(x)f(x)−∫2x​π(t)df(t) 分别取 f=log⁡f = \logf=log 与 f=1/log⁡f = 1/\logf=1/log，分部积分即得。∎

引理 4（θ∼x  ⟺  π∼x/log⁡x\theta \sim x \iff \pi \sim x/\log xθ∼x⟺π∼x/logx）：

  • 若 θ(x)∼x\theta(x) \sim xθ(x)∼x：由引理 3 第二式，π(x)=x(1+o(1))log⁡x+∫2xt(1+o(1))tlog⁡2t dt\pi(x) = \frac{x(1+o(1))}{\log x} + \int_{2}^{x}\frac{t(1+o(1))}{t\log^{2}t}\,\mathrm{d}tπ(x)=logxx(1+o(1))​+∫2x​tlog2tt(1+o(1))​dt。主项是 x/log⁡xx/\log xx/logx；积分 ∫2xdtlog⁡2t=o(xlog⁡x)\int_{2}^{x}\frac{\mathrm{d}t}{\log^{2} t} = o\big(\frac{x}{\log x}\big)∫2x​log2tdt​=o(logxx​)（因为 log⁡2t\log^{2} tlog2t 增长比 log⁡t\log tlogt 快），故 π(x)∼x/log⁡x\pi(x) \sim x/\log xπ(x)∼x/logx。
  • 若 π(x)∼x/log⁡x\pi(x) \sim x/\log xπ(x)∼x/logx：由引理 3 第一式，θ(x)=π(x)log⁡x−∫2xπ(t)t dt=x+o(x)−∫2x(1+o(1)) dtlog⁡t\theta(x) = \pi(x)\log x - \int_{2}^{x}\frac{\pi(t)}{t}\,\mathrm{d}t = x + o(x) - \int_{2}^{x}\frac{(1+o(1))\,\mathrm{d}t}{\log t}θ(x)=π(x)logx−∫2x​tπ(t)​dt=x+o(x)−∫2x​logt(1+o(1))dt​。而 ∫2xdtlog⁡t=o(x)\int_{2}^{x}\frac{\mathrm{d}t}{\log t} = o(x)∫2x​logtdt​=o(x)（对数积分 li⁡(x)=O(x/log⁡x)\operatorname{li}(x) = O(x/\log x)li(x)=O(x/logx)），故 θ(x)∼x\theta(x) \sim xθ(x)∼x。∎

于是素数定理 π(x)∼x/log⁡x\pi(x) \sim x/\log xπ(x)∼x/logx 与 ψ(x)∼x\psi(x) \sim xψ(x)∼x 等价（引理 2 + 引理 4）。

⚠️ 缺的正是命题 A 与命题 B 的证明：命题 A 需要 ζ\zetaζ 的解析延拓（Euler–Maclaurin 或 Abel 求和）、ζ(1+it)≠0\zeta(1+it) \ne 0ζ(1+it)=0 的经典论证（3+4cos⁡θ+cos⁡2θ≥03 + 4\cos\theta + \cos 2\theta \ge 03+4cosθ+cos2θ≥0 推出 ζ(1+it)≠0\zeta(1+it) \ne 0ζ(1+it)=0）；命题 B 是 Ingham/Newman 的 Tauber 定理，需要围道积分与增长估计。两者都不在「中等档」的篇幅内，本图不硬编——这就是本节点保留 skeleton 的原因。

⭐ Riemann 假设（ζ\zetaζ 的非平凡零点全在 Re⁡s=1/2\operatorname{Re} s = 1/2Res=1/2）下，ψ(x)=x+O(xlog⁡2x)\psi(x) = x + O(\sqrt{x}\log^{2}x)ψ(x)=x+O(x​log2x)、π(x)=li⁡(x)+O(xlog⁡x)\pi(x) = \operatorname{li}(x) + O(\sqrt{x}\log x)π(x)=li(x)+O(x​logx)；至今未解。

    素数定理：ζ\zetaζ 在 Re⁡ s=1\operatorname{Re}\,s = 1Res=1 上无零点

    ① ζ\zetaζ 的解析延拓。 对 Re⁡ s>1\operatorname{Re}\,s > 1Res>1，ζ(s)=∑n≥1n−s=∏p(1−p−s)−1\zeta(s) = \sum_{n\ge1} n^{-s} = \prod_{p}(1 - p^{-s})^{-1}ζ(s)=∑n≥1​n−s=∏p​(1−p−s)−1（Euler 乘积，靠唯一分解）。

    它在 s=1s = 1s=1 有单极点、留数 111，并可延拓为 C\mathbb{C}C 上的亚纯函数。

    ② 关键一步：Re⁡ s=1\operatorname{Re}\,s = 1Res=1 上无零点。 用 3+4cos⁡θ+cos⁡2θ≥03 + 4\cos\theta + \cos 2\theta \ge 03+4cosθ+cos2θ≥0 配上 Euler 乘积的对数导数，得 ζ(1+it)≠0\zeta(1 + it) \ne 0ζ(1+it)=0。这一步是全部难点，也是「素数不会太集中在一条线上」的本质。
