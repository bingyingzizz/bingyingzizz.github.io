# Pullback Between Manifolds　`prop.pullback-form-manifold`
English entry · root `../`
[in graph](../#n=prop.pullback-form-manifold)　·　[Chinese page (authoritative)](./prop.pullback-form-manifold.md)

1. $F^{\ast}$ is $\mathbb{R}$-linear; on functions $F^{\ast}f = f\circ F$;
2. **it preserves the wedge product**: $F^{\ast}(\omega\wedge\eta) = F^{\ast}\omega\wedge F^{\ast}\eta$;
3. **it commutes with $\mathrm{d}$**: $\mathrm{d}(F^{\ast}\omega) = F^{\ast}(\mathrm{d}\omega)$;
4. **it preserves composition**: $(G\circ F)^{\ast} = F^{\ast}\circ G^{\ast}$ and $(\operatorname{id})^{\ast} = \operatorname{id}$.

Thus $F^{\ast} : \Omega^{\bullet}(N)\to\Omega^{\bullet}(M)$ is a homomorphism of **differential graded algebras**.
