# Euler criterion　`thm.euler-criterion`
English entry · root `../`
[in graph](../#n=thm.euler-criterion)　·　[Chinese page (authoritative)](./thm.euler-criterion.md)

- If $k$ is even, $a = (g^{k/2})^{2}$ is a residue, and $a^{(p-1)/2} = g^{k(p-1)/2} = (g^{p-1})^{k/2} = 1$;
- If $k$ is odd, $a$ is not a residue (the squares in a cyclic group are exactly the even powers), and $a^{(p-1)/2} = g^{(p-1)/2} = -1$ (because its square is $1$ rather than $1$ itself — an element of order $2$ can only be $-1$).

In general, the equation $x^{(p-1)/2} \equiv 1$ has exactly $(p-1)/2$ solutions (degree bound), exactly as many as the number of quadratic residues; the two sets coincide.
