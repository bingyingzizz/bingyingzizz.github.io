# Inverse Function Theorem in Banach Spaces　`thm.inverse-function-banach`
English entry · root `../`
[in graph](../#n=thm.inverse-function-banach)　·　[Chinese page (authoritative)](./thm.inverse-function-banach.md)

- **Mean value inequality**: $\|f(x) - f(y)\| \le \sup_{[x,y]} \|Df\| \cdot \|x - y\|$ (`thm.mean-value-multi`) makes $\Phi_y$ a contraction.

⚠ This is **the form used in functional analysis and condensed mathematics**. Their objects include $C(S)$, $L^{p}$, Fréchet spaces, and groups of continuous functions on compact Hausdorff spaces. The finite-dimensional theorem is insufficient (for example, in the local isomorphism argument for $C(S, M)$ in Section 8.2).
