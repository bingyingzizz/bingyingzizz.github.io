# Connection Form　`def.connection-form`
English entry · root `../`
[in graph](../#n=def.connection-form)　·　[Chinese page (authoritative)](./def.connection-form.md)

- $\omega^{1}_{\ 2}$: the **intrinsic** part — the Levi-Civita connection of the surface, from which the Gauss curvature is computed;
- $\omega^{1}_{\ 3}, \omega^{2}_{\ 3}$: the **extrinsic** part — the second fundamental form is computed from them.

## Notes · **draft**
**Origin of the name**: $\omega^{j}_{\ i}$ describes "how the frame rotates when one walks in a direction". It is not an artificially invented exterior form: at each point it is a $3\times3$ skew-symmetric matrix over $\mathbb{R}^{3}$ ($3$ degrees of freedom), and evaluating it along directions gives a $1$-form.
