def.congruence · 数论 · 同余

又称同余关系·模 n 同余

陈述

设 n≥1n \ge 1n≥1。称 aaa 与 bbb 模 nnn 同余，记 a≡b(modn)a \equiv b \pmod na≡b(modn)，若 n∣(a−b)n \mid (a - b)n∣(a−b)。

同余是 Z\mathbb{Z}Z 上的等价关系，且与加法、乘法相容：由 a≡ba \equiv ba≡b、c≡dc \equiv dc≡d 可得 a+c≡b+da + c \equiv b + da+c≡b+d 与 ac≡bdac \equiv bdac≡bd。

说明

「等价关系 + 与运算相容」正是同余关系的一般定义，商掉它得到商环 Z/nZ\mathbb{Z}/n\mathbb{Z}Z/nZ。

n=0n = 0n=0 时约定 a≡b(mod0)  ⟺  a=ba \equiv b \pmod 0 \iff a = ba≡b(mod0)⟺a=b：模 000 的同余就是相等。

同余把「整除」问题化成了「有限环里的等式」，这是初等数论最核心的一步：后面对 Z/nZ\mathbb{Z}/n\mathbb{Z}Z/nZ 用 Lagrange 定理，就得到 Euler 定理与 Fermat 小定理。
