又称Lie 导数

陈述

白话：Lie 导数就是「沿 XXX 的流把张量拖回来，再对时间求导」—— 它量的是张量在流下的变化率；对函数它是方向导数，对向量场它就是 Lie 括号。

设 X∈X(M)X \in \mathfrak{X}(M)X∈X(M)，φt\varphi_{t}φt​ 是它的（局部）流（def.flow）。对张量场 TTT（def.tensor-field）定义 Lie 导数

(LXT)p:=ddt∣t=0(φt∗T)p,(\mathcal{L}_{X}T)_{p} := \left.\frac{\mathrm{d}}{\mathrm{d}t}\right|_{t=0}\bigl(\varphi_{t}^{\ast}T\bigr)_{p},(LX​T)p​:=dtd​​t=0​(φt∗​T)p​,

其中 φt∗\varphi_{t}^{\ast}φt∗​ 是「沿微分同胚的拉回」：函数与形式用拉回，向量场则用 dφ−t\mathrm{d}\varphi_{-t}dφ−t​ 推过去（向量场没有拉回，只有推前）。逐类写出：

  • 函数：LXf=Xf\mathcal{L}_{X}f = XfLX​f=Xf；
  • 向量场：LXY=[X,Y]\mathcal{L}_{X}Y = [X,Y]LX​Y=[X,Y]（def.lie-bracket）；
  • 111-形式：(LXω)(Y)=X(ω(Y))−ω([X,Y])(\mathcal{L}_{X}\omega)(Y) = X\bigl(\omega(Y)\bigr) - \omega\bigl([X,Y]\bigr)(LX​ω)(Y)=X(ω(Y))−ω([X,Y])；
  • 张量积：LX(T⊗S)=(LXT)⊗S+T⊗(LXS)\mathcal{L}_{X}(T\otimes S) = (\mathcal{L}_{X}T)\otimes S + T\otimes(\mathcal{L}_{X}S)LX​(T⊗S)=(LX​T)⊗S+T⊗(LX​S)，且 LX\mathcal{L}_{X}LX​ 与缩并交换。

于是 LX\mathcal{L}_{X}LX​ 是张量代数上次数 000 的导子，并满足

L[X,Y]=[LX,LY]\mathcal{L}_{[X,Y]} = [\mathcal{L}_{X},\mathcal{L}_{Y}]L[X,Y]​=[LX​,LY​]

（括号给出导子的交换子）。

说明

三类的统一：函数与形式的拉回是 ω↦φt∗ω\omega \mapsto \varphi_{t}^{\ast}\omegaω↦φt∗​ω，向量场没有拉回（要用推前 dφt\mathrm{d}\varphi_{t}dφt​），所以定义里得按类型选方向。但结果是统一的：LX\mathcal{L}_{X}LX​ 是张量代数上的导子，作用在函数上是 XXX，作用在向量场上就是括号 —— 两条都是从同一个「拖回来求导」算出来的。

为什么 LX\mathcal{L}_{X}LX​ 对 XXX 不是 C∞C^{\infty}C∞-线性的：LfXT≠f LXT\mathcal{L}_{fX}T \ne f\,\mathcal{L}_{X}TLfX​T=fLX​T（例如 LfXY=f[X,Y]−(Yf)X\mathcal{L}_{fX}Y = f[X,Y] - (Yf)XLfX​Y=f[X,Y]−(Yf)X）。所以 X↦LXX \mapsto \mathcal{L}_{X}X↦LX​ 不是张量，而是 Lie 代数同态 X(M)→Der⁡(Ω∙M)\mathfrak{X}(M) \to \operatorname{Der}(\Omega^{\bullet}M)X(M)→Der(Ω∙M) —— 这与 def.lie-bracket 的 notes 里「括号不是张量」是同一条性质。

与协变导数的区别：∇XT\nabla_{X}T∇X​T 需要额外结构（连络，def.affine-connection），但对函数两者给出同样的东西（都是 XfXfXf），对向量场不同（∇XY\nabla_{X}Y∇X​Y 与 [X,Y][X,Y][X,Y] 差一个「形变」项）。Lie 导数是流形的内在运算 —— 不需要度量、不需要连络，这是它比 ∇\nabla∇ 更「免费」的地方。

分量公式（111-形式）：

LXω=∑j(∑iXi∂iωj+∑iωi ∂jXi)dxj.\mathcal{L}_{X}\omega = \sum_{j}\Bigl(\sum_{i}X^{i}\partial_{i}\omega_{j} + \sum_{i}\omega_{i}\,\partial_{j}X^{i}\Bigr)\mathrm{d}x^{j}.LX​ω=j∑​(i∑​Xi∂i​ωj​+i∑​ωi​∂j​Xi)dxj.

第二项是「dxj\mathrm{d}x^{j}dxj 随流变形」的修正；少了它就得到「对 XXX 是 C∞C^{\infty}C∞-线性」的假结论。

流的定义域不完整时也成立：φt\varphi_{t}φt​ 只需在 ppp 附近、∣t∣<ε|t| < \varepsilon∣t∣<ε 有定义（thm.flow-local 就够），因为 Lie 导数只用 t=0t = 0t=0 处的导数。

定义引用 2

  • 流 → 本页定义引用

    Lie 导数的定义是「沿流拉回再对 ttt 求导」；流只需局部存在（thm.flow-local），所以这个定义对任意向量场都有意义。

  • 张量场 → 本页定义引用

    Lie 导数作用在张量场上；三类的具体写法（函数 / 向量场 / 形式）都是张量场的特例，统一在「次数 000 的导子」这个描述下。
