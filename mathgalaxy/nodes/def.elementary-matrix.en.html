Statement

An elementary row operation is one of the following three operations:

  • swap row iii and row jjj;
  • multiply row iii by a nonzero constant ccc;
  • take row jjj, multiply it by ccc, and add the result to row iii (with i≠ji \ne ji=j; taking i=ji = ji=j and c=−1c = -1c=−1 would give the non-invertible diag⁡(0,1)\operatorname{diag}(0, 1)diag(0,1)).

The matrix obtained by applying one such operation to the identity matrix InI_nIn​ is called an elementary matrix (written EEE). The key property is: performing one elementary row operation on AAA is the same as multiplying on the left by the corresponding elementary matrix, that is, replacing AAA by EAEAEA.

Every elementary matrix is invertible, and its inverse is again an elementary matrix of the same type: a swap is its own inverse, multiplying by ccc has inverse multiplying by c−1c^{-1}c−1, and adding ccc times a row has inverse adding −c-c−c times it.

Notes

⭐ The correspondence "left multiplication = row operation" turns operations into objects: thus "solving a system by elimination" becomes "multiplying on the left by a string of elementary matrices", and can be written as the identity Ek⋯E1A=RE_k \cdots E_1 A = REk​⋯E1​A=R (RRR is the reduced row-echelon form).

⭐ The most important consequence: AAA is invertible if and only if it is a product of finitely many elementary matrices (elimination reduces AAA to InI_nIn​, and recording the string of operations gives an explicit factorization of A−1A^{-1}A−1).

This is also the reason behind the [A∣I]→[I∣A−1][A \mid I] \to [I \mid A^{-1}][A∣I]→[I∣A−1] trick for computing inverses.

⚠ Elementary column operations correspond to right multiplication.

Mixing rows and columns gives equivalence transformations (A↦PAQA \mapsto PAQA↦PAQ), which preserve rank but not similarity.
