Abstract

For a topos T\mathcal{T}T, the category T(Ab)\mathcal{T}(\mathbf{Ab})T(Ab) of abelian group objects in sheaves is a Grothendieck category: abelian, with a small set of generators, all colimits, and filtered colimits exact. Abelianness is checked componentwise in the presheaf category and transported along the exact sheafification reflection; limits and colimits exist by that reflection; and if SSS generates T\mathcal{T}T then {Z⋅X:X∈S}\{\mathbb{Z}\cdot X : X \in S\}{Z⋅X:X∈S} generates T(Ab)\mathcal{T}(\mathbf{Ab})T(Ab). Those generators are moreover projective.

Statement

If T\mathcal{T}T is a topos, then the category T(Ab)\mathcal{T}(\mathbf{Ab})T(Ab) of abelian sheaves on T\mathcal{T}T is a Grothendieck category: it has a small set of generators, has all colimits, and filtered colimits are exact.

Notes

The proof has three parts:

  • Abelian: first verify componentwise in the presheaf category C^(Ab)\widehat{\mathcal{C}}(\mathbf{Ab})C(Ab) (there one simply has pointwise abelian groups) — concretely, for an arbitrary morphism uuu verify coker⁡(ker⁡u)≅ker⁡(coker⁡u)\operatorname{coker}(\ker u) \cong \ker(\operatorname{coker} u)coker(keru)≅ker(cokeru); then transport these identities back to the sheaf category along the exact reflection (sheafification). The same argument gives exactness of filtered colimits.
  • All limits and colimits exist: because the sheaf category is a reflective subcategory of the presheaf category.
  • Small set of generators: if SSS is a small set of generators of T\mathcal{T}T, then {Z⋅X:X∈S}\{\mathbb{Z}\cdot X : X \in S\}{Z⋅X:X∈S} generates T(Ab)\mathcal{T}(\mathbf{Ab})T(Ab) — their coproduct is a generator.

One more fact along the way: Z⋅X\mathbb{Z}\cdot XZ⋅X is projective in T(Ab)\mathcal{T}(\mathbf{Ab})T(Ab) (look at presheaves first: M↦Hom⁡Z(Z⋅hX,M)≅M(X)M \mapsto \operatorname{Hom}_{\mathbb{Z}}(\mathbb{Z}\cdot h_{X}, M) \cong M(X)M↦HomZ​(Z⋅hX​,M)≅M(X) is exact on presheaves).
