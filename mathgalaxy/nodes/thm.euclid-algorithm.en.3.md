# Euclidean algorithm　`thm.euclid-algorithm`
English entry · root `../`
[in graph](../#n=thm.euclid-algorithm)　·　[Chinese page (authoritative)](./thm.euclid-algorithm.md)

Complexity: the remainders decrease at least as fast as Fibonacci numbers, so the number of steps is $O(\log \min(|a|, |b|))$ — the worst input is precisely a pair of consecutive Fibonacci numbers (Lamé's theorem).

The same holds in $K[x]$ (with degree in place of absolute value), so "$\mathbb{Z}$ and $K[x]$ are both Euclidean domains" is one and the same statement.
