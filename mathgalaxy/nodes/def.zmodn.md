# 剩余类环　`def.zmodn`
剩余类环：把同余类收成一个元素
layer 12 · 定义 · 整除与同余 · 数论
[在星图里打开](../#n=def.zmodn)　·　[节点索引](../index.md)

记 $\mathbb{Z}/n\mathbb{Z} = \{[0], [1], \cdots, [n-1]\}$，其中 $[a]$ 是 $a$ 所在的同余类，运算由代表元定义：

$$[a] + [b] := [a + b], \qquad [a]\,[b] := [ab] .$$

它是一个有单位元的交换环，叫**剩余类环**（模 $n$ 的整数环）。
