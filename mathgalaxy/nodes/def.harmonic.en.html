Statement

In words: a real-valued function with continuous second partials satisfying Δu=0\Delta u = 0Δu=0. Loosely: a function that is "nowhere more convex or more concave than its surroundings".

Let Ω⊂R2≅C\Omega \subset \mathbb{R}^2 \cong \mathbb{C}Ω⊂R2≅C be a region and u:Ω→Ru: \Omega \to \mathbb{R}u:Ω→R of class C2C^2C2. If

Δu:=∂2u∂x2+∂2u∂y2=0\Delta u := \frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = 0Δu:=∂x2∂2u​+∂y2∂2u​=0

holds everywhere on Ω\OmegaΩ, then uuu is called a harmonic function on Ω\OmegaΩ.

Equivalent characterization (local): uuu is the real part of some holomorphic function (always possible on a disk, and also on simply connected regions, see the node on "harmonic conjugates").

Notes

⭐ The real and imaginary parts of a holomorphic function are harmonic: by the Cauchy–Riemann equations ux=vyu_x = v_yux​=vy​, uy=−vxu_y = -v_xuy​=−vx​, one gets

Δu=(ux)x+(uy)y=(vy)x+(−vx)y=vxy−vyx=0,\Delta u = (u_x)_x + (u_y)_y = (v_y)_x + (-v_x)_y = v_{xy} - v_{yx} = 0,Δu=(ux​)x​+(uy​)y​=(vy​)x​+(−vx​)y​=vxy​−vyx​=0,

the last step using equality of mixed partials (vvv is sufficiently smooth).

⭐ Examples: Re⁡zn\operatorname{Re} z^nRezn, x2−y2x^2 - y^2x2−y2, ln⁡∣z∣\ln|z|ln∣z∣ (on C×\mathbb{C}^{\times}C×), excos⁡ye^{x}\cos yexcosy.

⚠ Counterexamples: ∣z∣2=x2+y2|z|^2 = x^2 + y^2∣z∣2=x2+y2 is not harmonic, Δ(x2+y2)=4\Delta(x^2 + y^2) = 4Δ(x2+y2)=4; nor is x3x^3x3, since Δx3=6x\Delta x^3 = 6xΔx3=6x.

⚠ The definition only asks for C2C^2C2, but harmonic functions are automatically C∞C^{\infty}C∞ and real analytic — a direct consequence of "being the real part of a holomorphic function".

📌 Harmonic functions lack the rigidity of holomorphic ones: the product of two harmonic functions is in general neither harmonic nor holomorphic; only u+vu + vu+v and cucucu are.
