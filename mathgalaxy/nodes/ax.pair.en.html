Statement

Given any two sets, one may pack them into "the set whose only elements are these two":

∀a∀b∃A∀x[x∈A↔(x=a∨x=b)]\forall a \forall b \exists A \forall x [ x \in A \leftrightarrow ( x = a \vee x = b ) ]∀a∀b∃A∀x[x∈A↔(x=a∨x=b)]

By extensionality AAA is unique; it is written { a, b } (the unordered pair). Taking a=ba = ba=b gives the singleton { a }.
