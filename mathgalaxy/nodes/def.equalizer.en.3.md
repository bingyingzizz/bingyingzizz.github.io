# equalizer and coequalizer　`def.equalizer`
English entry · root `../`
[in graph](../#n=def.equalizer)　·　[Chinese page (authoritative)](./def.equalizer.md)

In $\mathbf{Ab}$, $\ker(f,g) = \ker(f - g)$ — the equaliser of two maps degenerates to the kernel of **one** map, which is exactly where the name “kernel” comes from.
