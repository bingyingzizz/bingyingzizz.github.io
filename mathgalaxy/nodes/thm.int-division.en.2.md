# division with remainder for integers　`thm.int-division`
English entry · root `../`
[in graph](../#n=thm.int-division)　·　[Chinese page (authoritative)](./thm.int-division.md)

Existence uses the well-ordering of $\mathbb{Z}$: fix $b > 0$; the set $\{\, a - qb : q \in \mathbb{Z},\ a - qb \ge 0 \,\}$ is nonempty (Archimedean property), and its least element is $r$; if $r \ge b$ then $r - b$ is smaller, a contradiction.

The corresponding theorem on $K[x]$ is `thm.division-algorithm`: the same proof structure, only "degree" is replaced by "absolute value" — both are Euclidean domains.
