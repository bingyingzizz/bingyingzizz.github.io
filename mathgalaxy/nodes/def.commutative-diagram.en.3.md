# diagram and commutative diagram　`def.commutative-diagram`
English entry · root `../`
[in graph](../#n=def.commutative-diagram)　·　[Chinese page (authoritative)](./def.commutative-diagram.md)

**In general only the “shape” is given.** When $I$ is not a preorder, $D$ can only be called a $I$-shaped diagram: a functor is **not required** to send parallel $f \ne g : i \rightrightarrows j$ to equal arrows.

The most typical non-commuting diagram is the **parallel pair** $\bullet \rightrightarrows \bullet$, whose limit and colimit are exactly the **equaliser** and **coequaliser**;

the classical commuting square corresponds to the preorder $\{A \le B \le D,\ A \le C \le D\}$.
