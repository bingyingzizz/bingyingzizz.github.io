命题：连续、单调   ⟹  \implies⟹ 可积；Dirichlet 函数不可积

陈述

设 fff 在 [a,b][a, b][a,b] 上有界。

  • fff 连续   ⟹  \implies⟹ fff 可积；
  • fff 单调   ⟹  \implies⟹ fff 可积；
  • fff 有界且只有有限个不连续点   ⟹  \implies⟹ fff 可积。

反之不成立。Dirichlet 函数（xxx 有理时取 111、无理时取 000）有界但不可积。

说明

⭐ 三条都是「振幅和可以任意小」的直接应用。

⭐ Dirichlet 函数为什么不可积：任何分割的每个小区间里都同时含有理数与无理数（稠密性），所以 Mi=1M_i = 1Mi​=1、mi=0m_i = 0mi​=0，于是 U−L=∑Δxi=b−aU - L = \sum \Delta x_i = b - aU−L=∑Δxi​=b−a 对每个分割成立，振幅和永远不趋于零。

⚠ 但它在 Lebesgue 意义下可积，且积分为 000（有理数集是零测集）。同一条函数，两个积分理论给出不同答案 —— 差别不在函数，在于「怎么切」。

    振幅判据 + 一致连续   ⟹  \implies⟹ 可积性三例

    ① 连续   ⟹  \implies⟹ 可积。 设 fff 在 [a,b][a, b][a,b] 上连续，令 M:=sup⁡∣f∣M := \sup |f|M:=sup∣f∣。由 Cantor 定理，fff 在 [a,b][a, b][a,b] 上一致连续：对 ε>0\varepsilon > 0ε>0 取 δ>0\delta > 0δ>0，使 ∣x−y∣<δ|x - y| < \delta∣x−y∣<δ 时 ∣f(x)−f(y)∣<εb−a|f(x) - f(y)| < \dfrac{\varepsilon}{b - a}∣f(x)−f(y)∣<b−aε​。

    （这是裂项：中间的 f(xi)f(x_i)f(xi​) 全部抵消。）

    ③ 有限个不连续点   ⟹  \implies⟹ 可积。 把 [a,b][a, b][a,b] 分成有限段，每段内部连续、端点处或为不连续点；对每一段用 ①，再把分割在端点处接起来即可。

    ④ Dirichlet 函数不可积。 任取分割 PPP：每个小区间同时含有理数与无理数（稠密性），故 Mi=1M_i = 1Mi​=1、mi=0m_i = 0mi​=0，振幅和 U−L=∑Δxi=b−aU - L = \sum \Delta x_i = b - aU−L=∑Δxi​=b−a 与 PPP 无关，永远不小于 ε=b−a\varepsilon = b - aε=b−a。由振幅判据不可积。∎
