# site 的层范畴的好性质　`prop.site-properties`
Grothendieck 拓扑下的层范畴
layer 19 · 命题 · 层与拓扑 · 范畴论
[在星图里打开](../#n=prop.site-properties)　·　[节点索引](../index.md)

若 $\mathcal{C}$ 是 site，则层范畴 $\widehat{\mathcal{C}}$ 中所有极限与余极限存在，并且：

1. 余极限是**万有**的；
2. **滤过余极限正合**；
3. 满态射都是**正则的**且**万有**的；
4. 余积是**不交**的；
5. 等价关系是**有效的**且**万有**的。
