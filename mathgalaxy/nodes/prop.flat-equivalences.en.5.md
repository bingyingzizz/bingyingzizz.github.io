# Equivalent Characterizations of Flatness　`prop.flat-equivalences`
English entry · root `../`
[in graph](../#n=prop.flat-equivalences)　·　[Chinese page (authoritative)](./prop.flat-equivalences.md)

**4 implies 1**: it suffices to test on injections; first reduce to $M$ finitely generated ($(-)\otimes N$ preserves filtered colimits), then induct on the number of generators, using the ideal case at each step — the full argument is in `thm.lambek` ✓.

⭐ **Only condition 4 is computable**: ideals are usually far fewer than submodules, and the multiplication map $I \otimes N \to N$ can often be written explicitly. Over a PID ideals are principal, so the criterion is almost automatic (the source of "torsion-free implies flat").
