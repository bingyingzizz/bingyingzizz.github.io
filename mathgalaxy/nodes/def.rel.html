又称二元关系·binary relation·关系

陈述

设 AAA、BBB 是集合。

关系 RRR 由有序对组成；R⊆A×BR \subseteq A \times BR⊆A×B 表示 RRR 是 AAA 到 BBB 的关系。

  • 定义域 dom⁡R={a:∃b(a,b)∈R}\operatorname{dom} R = \{ a : \exists b (a, b) \in R \}domR={a:∃b(a,b)∈R}；
  • 值域 ran⁡R={b:∃a(a,b)∈R}\operatorname{ran} R = \{ b : \exists a (a, b) \in R \}ranR={b:∃a(a,b)∈R}；
  • 逆 R−1={(b,a):(a,b)∈R}R^{-1} = \{ (b, a) : (a, b) \in R \}R−1={(b,a):(a,b)∈R}。

说明

在 ZFC 里关系就是一个集合（由有序对组成），没有额外的原始概念 —— 所以「⪯\preceq⪯ 是 AAA 上的关系」这句话本身是有内容的：它说的是一族有序对。

常见的两类关系：等价关系（自反、对称、传递）与偏序（自反、反对称、传递）——后者另开一条节点。

它指向谁（出边）

定义引用 3

  • 商集与等价类 用到 本页定义引用

    商集是拿等价关系做出来的 —— 先有关系，才谈得上等价类。

  • 映射 用到 本页定义引用

    函数是特殊的关系：只多要求「每个输入的输出唯一」。

  • 偏序集 用到 本页定义引用

    偏序 ⪯\preceq⪯ 是 AAA 上的二元关系——先有关系，才有「自反、反对称、传递」这三条。

谁指向它（入边）

定义引用 2

  • 有序对 → 本页定义引用

    关系被定义为「有序对的集合」，函数是特殊的关系，因此整个定义都建立在有序对之上。

  • 子集 → 本页定义引用

    关系是 A×BA \times BA×B 的子集，定义域 dom⁡R\operatorname{dom} RdomR 与值域 ran⁡R\operatorname{ran} RranR 也都是子集。
