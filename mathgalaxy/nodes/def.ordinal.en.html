Statement

A set α\alphaα is an ordinal (a von Neumann ordinal) iff:

  1. α\alphaα is transitive: ∀x∈α,  x⊆α\forall x \in \alpha,\; x \subseteq \alpha∀x∈α,x⊆α (an element of an element is again an element);
  2. ∈\in∈ well-orders α\alphaα: restricted to α\alphaα, ∈\in∈ makes α\alphaα a well-ordered set — that is, for any x,y∈αx, y \in \alphax,y∈α exactly one of x∈yx \in yx∈y, x=yx = yx=y, y∈xy \in xy∈x holds, and every non-empty subset of α\alphaα has an ∈\in∈-least element.

By transitivity, every element of α\alphaα is itself an ordinal. Notes

The format is still "set + relation + axioms": ordinals are not objects out of nowhere — a transitive set together with the ready-made relation ∈\in∈ determines an ordinal. To decide whether a set is an ordinal, check these two clauses.

Why not take order types as the objects — this is the most important step in this pack: an order type is an isomorphism class, and there are more order types of well-orders than fit into any set, so they cannot be collected (see "the ordinals do not form a set"). Ordinals avoid this: each order type is given a concrete representative, namely a transitive well-ordered set. Comparing order types then becomes comparing ∈\in∈, which can be done outright.

α∈β\alpha \in \betaα∈β and α<β\alpha < \betaα<β are the same thing: on ordinals, ∈\in∈ is the order. Writing α<β\alpha < \betaα<β really uses ∈\in∈ underneath.

Ordinals are not just "a generalization of N\mathbb{N}N". The ordinals after ω\omegaω get longer and longer, but their size (cardinality) can stay at ℵ0\aleph_0ℵ0​ — for ordinals, "longer" and "larger" are two different things.

Which assumptions each direction uses (the definition of an ordinal needs no Choice; the existence of a representative for each order type is a separate construction):

  • being a von Neumann ordinal   ⟺  \iff⟺ transitive and well-ordered by membership: both directions are unfolding the definition, with no compactness, no Choice and no metric; the convention α<β  ⟺  α∈β\alpha<\beta\iff\alpha\in\betaα<β⟺α∈β is also a notational definition.
  • elements of an ordinal are ordinals: inherit the well-order and use transitivity of membership on the ambient set to show the element is transitive; a general transitive set does not by itself have transitive elements.
  • well-ordered set   ⟹  \implies⟹ existence of a unique ordinal of the same order type: build it by well-founded recursion and collect the image with Replacement; this is not an unfolding of the definition, and it does not need the Choice that well-orders an arbitrary set.
  • transitivity cannot be dropped: the members of {{∅}}\{\{\emptyset\}\}{{∅}} are well-ordered by membership as a single point, yet the set is not transitive; the well-order condition cannot be dropped either: {0,1,{1}}\{0,1,\{1\}\}{0,1,{1}} is transitive, but 000 and {1}\{1\}{1} are incomparable under membership.
