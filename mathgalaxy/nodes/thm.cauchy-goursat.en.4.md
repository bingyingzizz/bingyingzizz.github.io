# Cauchy–Goursat Theorem　`thm.cauchy-goursat`
English entry · root `../`
[in graph](../#n=thm.cauchy-goursat)　·　[Chinese page (authoritative)](./thm.cauchy-goursat.md)

⭐ Immediate corollary: a holomorphic function on a simply connected region **has a primitive** (take $F(z) = \int_{z_0}^{z} f\,\mathrm{d}z$, which is path-independent by Cauchy's theorem, and then $F' = f$).

There is no **clean** counterpart in real analysis: $F(x) = \log|x|$ is indeed a primitive of $1/x$ on $\mathbb{R} \setminus \{0\}$ — the difference is that $\mathbb{R} \setminus \{0\}$ is **disconnected**, so "path independence" fails there (the integral around $0$ is nonzero).

⚠ The "Goursat" in the name: Cauchy's original 1825 proof required $f'$ to be continuous (via Green's formula);
