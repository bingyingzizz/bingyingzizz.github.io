白话：∂/∂z\partial/\partial z∂/∂z 与 ∂/∂zˉ\partial/\partial \bar z∂/∂zˉ 和普通偏导数一样服从线性法则、乘积法则、链式法则，而且两者互为共轭。

设 f,g:Ω→Cf, g: \Omega \to \mathbb{C}f,g:Ω→C 实可微。则

(1) 坐标：∂z∂z=∂zˉ∂zˉ=1\dfrac{\partial z}{\partial z} = \dfrac{\partial \bar z}{\partial \bar z} = 1∂z∂z​=∂zˉ∂zˉ​=1，∂z∂zˉ=∂zˉ∂z=0\dfrac{\partial z}{\partial \bar z} = \dfrac{\partial \bar z}{\partial z} = 0∂zˉ∂z​=∂z∂zˉ​=0；

(2) 复线性：α,β∈C\alpha, \beta \in \mathbb{C}α,β∈C 时 ∂(αf+βg)∂z=α∂f∂z+β∂g∂z\dfrac{\partial (\alpha f + \beta g)}{\partial z} = \alpha\dfrac{\partial f}{\partial z} + \beta\dfrac{\partial g}{\partial z}∂z∂(αf+βg)​=α∂z∂f​+β∂z∂g​，∂/∂zˉ\partial/\partial \bar z∂/∂zˉ 同理；

(3) 共轭：(∂f∂z)‾=∂fˉ∂zˉ\overline{\left( \dfrac{\partial f}{\partial z} \right)} = \dfrac{\partial \bar f}{\partial \bar z}(∂z∂f​)​=∂zˉ∂fˉ​​，(∂f∂zˉ)‾=∂fˉ∂z\overline{\left( \dfrac{\partial f}{\partial \bar z} \right)} = \dfrac{\partial \bar f}{\partial z}(∂zˉ∂f​)​=∂z∂fˉ​​；

(4) 乘积：∂(fg)∂z=∂f∂z g+f ∂g∂z\dfrac{\partial (fg)}{\partial z} = \dfrac{\partial f}{\partial z}\,g + f\,\dfrac{\partial g}{\partial z}∂z∂(fg)​=∂z∂f​g+f∂z∂g​，∂/∂zˉ\partial/\partial \bar z∂/∂zˉ 同理；

(5) 复合：若 f:Ω→Df: \Omega \to Df:Ω→D、g:D→Cg: D \to \mathbb{C}g:D→C 都实可微，则

∂(g∘f)∂z=(∂g∂w∘f)∂f∂z+(∂g∂wˉ∘f)(∂f∂zˉ)‾.\frac{\partial (g \circ f)}{\partial z} = \left( \frac{\partial g}{\partial w} \circ f \right)\frac{\partial f}{\partial z} + \left( \frac{\partial g}{\partial \bar w} \circ f \right)\overline{\left( \frac{\partial f}{\partial \bar z} \right)}.∂z∂(g∘f)​=(∂w∂g​∘f)∂z∂f​+(∂wˉ∂g​∘f)(∂zˉ∂f​)​.

说明

⭐ (5) 的第二项不是笔误：ggg 的增量里有 Δw\Delta wΔw 与 Δw‾\overline{\Delta w}Δw 两块，而 Δw‾=fz‾ Δz‾+fzˉ‾ Δz\overline{\Delta w} = \overline{f_z}\,\overline{\Delta z} + \overline{f_{\bar z}}\,\Delta zΔw=fz​​Δz+fzˉ​​Δz —— 共轭把两类项互换了，所以 gwˉg_{\bar w}gwˉ​ 那一块乘的是 fzˉ‾\overline{f_{\bar z}}fzˉ​​。

⭐ 全纯时 fzˉ=0f_{\bar z} = 0fzˉ​=0、gwˉ=0g_{\bar w} = 0gwˉ​=0，(5) 就退化成熟悉的 (g∘f)′=(g′∘f) f′(g \circ f)' = (g' \circ f)\,f'(g∘f)′=(g′∘f)f′ —— 只剩第一项。

⭐ 反过来这也解释了为什么「全纯 ∘\circ∘ 实可微」一般不全纯：此时 gwˉ≠0g_{\bar w} \ne 0gwˉ​=0，第二项活着，而它偏偏带着 fzˉ‾\overline{f_{\bar z}}fzˉ​​ 这个 Δz‾\overline{\Delta z}Δz 的系数。

📌 这五条都是把实偏导的对应法则照抄过来再重新组合，没有新的分析内容 —— 但它们让「验算一个表达式全不全纯」变成纯代数操作。

    (5) 复合。 这一步真要算。设 w=f(z)w = f(z)w=f(z)，由 ggg 的实可微性

    g(w0+Δw)−g(w0)=∂g∂w Δw+∂g∂wˉ Δw‾+o(Δw).g(w_0 + \Delta w) - g(w_0) = \frac{\partial g}{\partial w}\,\Delta w + \frac{\partial g}{\partial \bar w}\,\overline{\Delta w} + o(\Delta w).g(w0​+Δw)−g(w0​)=∂w∂g​Δw+∂wˉ∂g​Δw+o(Δw).

    又 Δw=fzΔz+fzˉΔz‾+o(Δz)\Delta w = f_z \Delta z + f_{\bar z}\overline{\Delta z} + o(\Delta z)Δw=fz​Δz+fzˉ​Δz+o(Δz)，取共轭得 Δw‾=fz‾ Δz‾+fzˉ‾ Δz+o(Δz)\overline{\Delta w} = \overline{f_z}\,\overline{\Delta z} + \overline{f_{\bar z}}\,\Delta z + o(\Delta z)Δw=fz​​Δz+fzˉ​​Δz+o(Δz)。代回去，按 Δz\Delta zΔz 与 Δz‾\overline{\Delta z}Δz 归并：

    Δ(g∘f)=(gwfz+gwˉfzˉ‾)Δz+(gwfzˉ+gwˉfz‾)Δz‾+o(Δz).\Delta (g \circ f) = \left( g_w f_z + g_{\bar w}\overline{f_{\bar z}} \right)\Delta z + \left( g_w f_{\bar z} + g_{\bar w}\overline{f_z} \right)\overline{\Delta z} + o(\Delta z).Δ(g∘f)=(gw​fz​+gwˉ​fzˉ​​)Δz+(gw​fzˉ​+gwˉ​fz​​)Δz+o(Δz).
