# criterion for a single-valued branch　`prop.single-valued-branch`
English entry · root `../`
[in graph](../#n=prop.single-valued-branch)　·　[Chinese page (authoritative)](./prop.single-valued-branch.md)

**Proof (3 $\implies$ 2 $\implies$ 1)**: condition 3 says that the integral along a curve depends only on the endpoints, so we may define $f(z) := \int_{z_{0}}^{z} \mathrm{d}\zeta/\zeta$, which satisfies $f' = 1/z$; next check $(z e^{-f(z)})' = e^{-f} - z e^{-f}/z = 0$, so $z e^{-f}$ is constant, and adjusting the constant gives $e^{f} = z$.
