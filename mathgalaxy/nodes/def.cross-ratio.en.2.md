# cross ratio　`def.cross-ratio`
English entry · root `../`
[in graph](../#n=def.cross-ratio)　·　[Chinese page (authoritative)](./def.cross-ratio.md)

$(Tz_{1}, Tz_{2}; Tz_{3}, Tz_{4}) = (z_{1}, z_{2}; z_{3}, z_{4})$

— the cross-ratio is a **complete invariant** under fractional linear transformations.

## Notes · **draft**
**Why it is invariant**: a fractional linear map $T(z) = (az+b)/(cz+d)$ can be written as a composite of four-point cross-ratios. A direct check: each difference $Tz_{i} - Tz_{j} = \dfrac{(ad - bc)(z_{i} - z_{j})}{(cz_{i} + d)(cz_{j} + d)}$; substituting into the numerator and denominator of the cross-ratio, $(ad-bc)$ cancels **pairwise** with the factors $(cz_{k}+d)$, leaving the original cross-ratio.
