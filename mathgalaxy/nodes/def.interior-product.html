又称内乘

陈述

白话：把一个向量场塞进形式的第一个槽，次数降一 —— 这就是内乘。它是 Cartan 公式里与外微分配对的那一半。

设 X∈X(M)X \in \mathfrak{X}(M)X∈X(M)、ω∈Ωk(M)\omega \in \Omega^{k}(M)ω∈Ωk(M)（k≥1k \ge 1k≥1）。内乘（也叫内积）ιXω∈Ωk−1(M)\iota_{X}\omega \in \Omega^{k-1}(M)ιX​ω∈Ωk−1(M) 逐点定义为

(ιXω)p(v2,…,vk):=ωp(Xp,v2,…,vk);(\iota_{X}\omega)_{p}(v_{2},\ldots,v_{k}) := \omega_{p}\bigl(X_{p},v_{2},\ldots,v_{k}\bigr);(ιX​ω)p​(v2​,…,vk​):=ωp​(Xp​,v2​,…,vk​);

对函数规定 ιXf:=0\iota_{X}f := 0ιX​f:=0。性质（ω\omegaω 是 kkk-形式、η\etaη 是 ℓ\ellℓ-形式、f,gf, gf,g 光滑）：

  1. 反导子：ιX(ω∧η)=(ιXω)∧η+(−1)k ω∧(ιXη)\iota_{X}(\omega\wedge\eta) = (\iota_{X}\omega)\wedge\eta + (-1)^{k}\,\omega\wedge(\iota_{X}\eta)ιX​(ω∧η)=(ιX​ω)∧η+(−1)kω∧(ιX​η)；

名字叫内积（interior product），但它与内积空间里的 ⟨⋅,⋅⟩\langle\cdot,\cdot\rangle⟨⋅,⋅⟩ 不是一回事：前者吃「一个向量 +++ 一个形式」吐一个低一阶的形式，后者吃「两个向量」吐一个数。

说明

为什么它是「逐点」的而 Lie 导数是「整体」的：内乘只用 XpX_{p}Xp​ 就能算出 (ιXω)p(\iota_{X}\omega)_{p}(ιX​ω)p​，所以它是张量运算（对 XXX 也 C∞C^{\infty}C∞-线性），不需要解任何方程；Lie 导数（def.lie-derivative）要对流求导，只对向量场有定义、且对 XXX 只 R\mathbb{R}R-线性。这条区别在 Cartan 公式（thm.cartan-formula）里正好互补：dιX\mathrm{d}\iota_{X}dιX​ 是「先缩再导」，ιXd\iota_{X}\mathrm{d}ιX​d 是「先导再缩」。

ιX2=0\iota_{X}^{2} = 0ιX2​=0 的理由：缩两次等于同一个槽被塞进两个向量，而形式是交错的，把两次缩并交换次序会出 −-− 号，于是 (ιX2ω)(v3,…)=ω(X,X,v3,…)=0(\iota_{X}^{2}\omega)(v_{3},\ldots) = \omega(X,X,v_{3},\ldots) = 0(ιX2​ω)(v3​,…)=ω(X,X,v3​,…)=0（交错性 + 同一向量自配为零）。

物理记号里它就是「缩一个指标」：电磁场 F=12Fij dxi∧dxjF = \frac{1}{2}F_{ij}\,\mathrm{d}x^{i}\wedge\mathrm{d}x^{j}F=21​Fij​dxi∧dxj 与 ιEF\iota_{E}FιE​F 给出「电场方向上的磁场通量」这类量；Maxwell 方程组里 dF=0\mathrm{d}F = 0dF=0、d⋆F=J\mathrm{d}\star F = Jd⋆F=J，其中 ⋆\star⋆ 依赖度量，而 ι\iotaι 与 d\mathrm{d}d 是纯组合的。

与缩并（def.tensor-contraction）的关系：ιXω\iota_{X}\omegaιX​ω 就是把 XXX 塞进第一个槽再缩并 —— 它是张量缩并在交错张量上的特例，只是塞进去的向量不必是基向量。

与楔积的搭配：dιX+ιXd\mathrm{d}\iota_{X} + \iota_{X}\mathrm{d}dιX​+ιX​d 这个组合之所以自然，是因为 d\mathrm{d}d 是 +1+1+1 次反导子、ιX\iota_{X}ιX​ 是 −1-1−1 次反导子，两个反导子复合出「次数 000 的导子」—— 与 Lie 导数同一个类型。Cartan 公式的证明就是拿这个类型去比对。

  • 微分形式 → 本页定义引用

    内乘的定义是「把 XpX_{p}Xp​ 塞进交错多重线性映射的第一个槽」；形式是交错的，所以塞两个向量必然为零（ιX2=0\iota_{X}^{2} = 0ιX2​=0）。

  • 向量场 → 本页定义引用

    内乘吃一个向量场与一个形式；它对向量场 C∞C^{\infty}C∞-线性（可逐点算），这一点与 Lie 导数形成对照。
