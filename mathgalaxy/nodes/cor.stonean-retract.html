陈述

Stonean 空间恰好是自由紧 Hausdorff 空间的收缩核：存在连续映射 r:X→Ar : X \to Ar:X→A 使 r∣A=1Ar|_{A} = 1_{A}r∣A​=1A​（这样的 AAA 叫 XXX 的收缩核）。

说明

这条把 Gleason 定理翻译成了一句「具体拓扑」的话：投射性 = 收缩核。与模论里「投射模 = 自由模的直和项」完全平行 —— 两者都是「投射 = 从自由对象上切一块下来」。

证明（把 Gleason 与「CHaus\mathbf{CHaus}CHaus 里每个对象都是自由的商」拼起来）。

  • (  ⟹  )(\implies)(⟹)：设 AAA 是 Stonean。取自由紧 Hausdorff 空间 FFF 与满射 p:F↠Ap : F\twoheadrightarrow Ap:F↠A（「CHaus\mathbf{CHaus}CHaus 里每个对象都是自由的商」）。Stonean   ⟹  \implies⟹ 由 Gleason 定理 AAA 是 CHaus\mathbf{CHaus}CHaus 里的投射对象，于是满射 p:F→Ap : F\to Ap:F→A 有截面 s:A→Fs : A\to Fs:A→F，即 p∘s=idAp\circ s = \mathrm{id}_{A}p∘s=idA​ —— 这正是「AAA 是 FFF 的收缩核」（取 r:=pr := pr:=p）✓。
  • (⟸)(\Longleftarrow)(⟸)：若 AAA 是自由对象 FFF 的收缩核（r:F→Ar: F\to Ar:F→A，r∣A=idr|_A = \mathrm{id}r∣A​=id），则由投射对象的收缩核仍投射（标准事实：投射对象的直和项/收缩核还是投射的），AAA 在 CHaus\mathbf{CHaus}CHaus 里投射；再由 Gleason 定理，AAA 是 Stonean ✓。∎

⭐ 这条是「Stonean = 自由紧 Hausdorff 的收缩核」的完整论证，也是后面「Z[S]\mathbb{Z}[S]Z[S] 投射」的来源（SSS 的收缩核给出截面，截面给出 Z[S]\mathbb{Z}[S]Z[S] 的投射性）。
