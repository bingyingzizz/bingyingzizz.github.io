# interior product　`def.interior-product`
English entry · root `../`
[in graph](../#n=def.interior-product)　·　[Chinese page (authoritative)](./def.interior-product.md)

1. **antiderivation**: $\iota_{X}(\omega\wedge\eta) = (\iota_{X}\omega)\wedge\eta + (-1)^{k}\,\omega\wedge(\iota_{X}\eta)$;
2. $\iota_{X}^{2} = 0$;
3. **$C^{\infty}(M)$-linear**: $\iota_{fX+gY} = f\,\iota_{X} + g\,\iota_{Y}$;
4. **coordinate formula**: $\iota_{\partial_{i}}\mathrm{d}x^{j} = \delta^{j}_{\ i}$, and
$$\iota_{\partial_{i}}\bigl(\mathrm{d}x^{j_{1}}\wedge\cdots\wedge\mathrm{d}x^{j_{k}}\bigr) = \sum_{r=1}^{k}(-1)^{r-1}\delta^{j_{r}}_{\ \ i}\ \mathrm{d}x^{j_{1}}\wedge\cdots\widehat{\mathrm{d}x^{j_{r}}}\cdots\wedge\mathrm{d}x^{j_{k}}.$$
