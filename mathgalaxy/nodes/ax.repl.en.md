## Statement · **reviewed**
If a formula defines a "functional relation", the image of any set is again a set. For every formula $\varphi (x, y, p)$ (in which $B$ does not occur):

$$\forall p [ \forall x\forall y\forall z ( \varphi(x,y,p) \wedge  \varphi(x,z,p) \to y = z ) \to \forall A \exists B \forall y ( y \in B \leftrightarrow  \exists x \in A, \varphi(x,y,p) ) ]$$

It guarantees that "replacement" never leaves the set-theoretic universe: the image $B$ is a set too.
