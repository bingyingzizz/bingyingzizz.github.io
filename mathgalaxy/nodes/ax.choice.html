陈述

任意一族非空集合都可以「同时」各挑出一个元素。写成选择函数的形式：

∀F[(∀X∈F,X≠∅)→∃f(f 是函数∧dom⁡f=F∧∀X∈F,f(X)∈X)]\forall F [ ( \forall X \in F, X \ne \emptyset ) \to \exists f ( f\text{ 是函数} \wedge \operatorname{dom} f = F \wedge \forall X \in F, f(X) \in X ) ]∀F[(∀X∈F,X=∅)→∃f(f 是函数∧domf=F∧∀X∈F,f(X)∈X)]

另一种常见形式（两两不交形式）：若 FFF 是两两不交的非空集合族，则存在集合 CCC，使对每个 X∈FX \in FX∈F 都有 ∣C∩X∣=1|C \cap X| = 1∣C∩X∣=1。

选择函数 fff 就是「同时挑元素」的工具；AC 断言这种同时挑选永远做得到。

说明

AC 与 ZF 独立：Gödel (1938) 证明 Con(ZF)→Con(ZF+AC)Con(ZF) \to Con(ZF + AC)Con(ZF)→Con(ZF+AC)，Cohen (1963) 证明 Con(ZF)→Con(ZF+¬AC)Con(ZF) \to Con(ZF + \neg AC)Con(ZF)→Con(ZF+¬AC)。

它是本星系里大量命题的枢纽——佐恩引理、良序定理、Hausdorff 极大原理、Tukey 引理都与它等价。

有限个非空集合可以逐个挑选，这正是 AC 只在无穷情形才显出力量的原因。

    ② 链的严格上界：对链 C⊆PC \subseteq PC⊆P 记

    S(C)={p∈P:∀c∈C,p≻c}S(C) = \{ p \in P : \forall c \in C, p \succ c \}S(C)={p∈P:∀c∈C,p≻c}

    p(α)=φ(S({p(β):β<α})) 只要S({p(β):β<α})≠∅; 一旦S 为空就停p(\alpha) = \varphi( S(\{ p(\beta) : \beta < \alpha \}) )\quad \text{ 只要} S(\{ p(\beta) : \beta < \alpha \}) \ne \emptyset;\text{ 一旦} S\text{ 为空就停}p(α)=φ(S({p(β):β<α})) 只要S({p(β):β<α})=∅; 一旦S 为空就停

    ⑤ 停下来就给极大元：令 C={p(β):β<α0}C = \{ p(\beta ) : \beta < \alpha _{0} \}C={p(β):β<α0​}，它是 PPP 的一个链（而且是严格递增的），由题设存在上界 u∈Pu \in Pu∈P。

    ⑥ uuu 是极大元：若存在 v∈Pv \in Pv∈P 使 u≺vu \prec vu≺v，则由 u⪰cu \succeq cu⪰c（∀c∈C\forall c \in C∀c∈C）与传递性得 v≻cv \succ cv≻c（∀c∈C\forall c \in C∀c∈C），即 v∈S(C)v \in S(C)v∈S(C) —— 与 S(C)=∅S(C) = \emptysetS(C)=∅ 矛盾。故 uuu 是 PPP 的极大元。∎

等价 1

  • 本页 ⟺ 良序定理等价
    选择公理   ⟺  \iff⟺ 良序定理
    选择公理 ⇒ 良序定理（路线 1⟹4）

    设 XXX 是集合。X=∅X = \emptysetX=∅ 时平凡，以下设 X≠∅X \ne \emptysetX=∅。

    1. 由 AC，非空子集族 P(X)∖{∅}\mathcal{P}(X) \setminus \{\emptyset \}P(X)∖{∅} 上有选择函数 φ\varphiφ，即 φ(A)∈A\varphi (A) \in Aφ(A)∈A 对每个非空 A⊆XA \subseteq XA⊆X 成立。
    2. 用超限递归往下取元素：对序数 α\alphaα，只要余集非空就令
    x(α)=φ(X∖{x(β):β<α})x(\alpha) = \varphi( X \setminus \{ x(\beta) : \beta < \alpha \} )x(α)=φ(X∖{x(β):β<α})

    一旦余集为空就停止。

    1. 过程一定会停：取 XXX 的 Hartogs 数 ℵ(X)\aleph (X)ℵ(X)，即最小的不能单射进 XXX 的序数（见「Hartogs 定理」——它在 ZF 里就能证，不需要 AC）。若对一切 α<ℵ(X)\alpha < \aleph (X)α<ℵ(X) 过程都没停，则 α↦x(α)\alpha \mapsto x(\alpha )α↦x(α) 就是 ℵ(X)\aleph (X)ℵ(X) 到 XXX 的单射，与 ℵ(X)\aleph (X)ℵ(X) 的定义矛盾。故存在序数 γ\gammaγ 使 x:γ→Xx : \gamma \to Xx:γ→X 是双射。
    2. 把 γ\gammaγ 上的序经 xxx 搬到 XXX 上：
    a⪯b:  ⟺  x−1(a)≤x−1(b)a \preceq b :\iff x^{-1}(a) \le x^{-1}(b)a⪯b:⟺x−1(a)≤x−1(b)

    因为序数在 ∈\in∈／≤\le≤ 下是良序的，XXX 上这个序也是良序。∎

    良序定理 ⇒ 选择公理（路线 4⟹1）

    设 FFF 是一族非空集合（即 ∅∉F\emptyset \notin F∅∈/F）。

    1. 由良序定理，取 U=⋃FU = \bigcup FU=⋃F 的一个良序 ⪯\preceq⪯。
    2. 对每个 X∈FX \in FX∈F：X≠∅X \ne \emptysetX=∅ 且 X⊆UX \subseteq UX⊆U，所以 XXX 是 UUU 的非空子集，有 ⪯\preceq⪯最小元 m(X)。
    3. 定义 f(X)=m(X)f(X) = m(X)f(X)=m(X)（XXX 唯一确定 m(X)，故这是一个函数）。则 dom⁡f=F\operatorname{dom} f = Fdomf=F 且 f(X)∈Xf(X) \in Xf(X)∈X 对一切 X∈FX \in FX∈F 成立，即 fff 是 FFF 的选择函数。

    由 FFF 的任意性，AC 成立。∎
