# quasi-isomorphism　`def.quasi-iso`
English entry · root `../`
[in graph](../#n=def.quasi-iso)　·　[Chinese page (authoritative)](./def.quasi-iso.md)

A quasi-isomorphism is a map that "is not an isomorphism in $\mathbf{K}(\mathcal{C})$, but is indistinguishable on homology" — formally inverting quasi-isomorphisms gives the **derived category**.
