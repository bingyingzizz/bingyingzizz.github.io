thm.int-ring · 定理 · 整数 · 环

又称ℤ 是交换整环

陈述

在 Z=(N×N)/∼\mathbb{Z} = (\mathbb{N} \times \mathbb{N})/{\sim}Z=(N×N)/∼ 上取 def.int 定义的运算与序。则：

(i) 两个运算良定义（与代表元的选取无关）；

(ii) (Z,+,⋅)(\mathbb{Z}, +, \cdot)(Z,+,⋅) 是含幺交换环；

(iii) Z\mathbb{Z}Z 无零因子（是整环）：xy=0  ⟹  x=0xy = 0 \implies x = 0xy=0⟹x=0 或 y=0y = 0y=0；

(iv) ≤\le≤ 是全序，且与运算相容：x≤y  ⟹  x+z≤y+zx \le y \implies x + z \le y + zx≤y⟹x+z≤y+z，x≤y, 0≤z  ⟹  xz≤yzx \le y,\ 0 \le z \implies xz \le yzx≤y, 0≤z⟹xz≤yz；

(v) n↦[n,0]n \mapsto [n, 0]n↦[n,0] 是 N\mathbb{N}N 到 Z\mathbb{Z}Z 的单射，保持加法、乘法与序。

说明

⭐ 每一项都是「搬到代表元上，用 N\mathbb{N}N 的运算律」。N\mathbb{N}N 里没有减法，所以 Z\mathbb{Z}Z 的加法写成 [a,b]+[c,d]=[a+c,b+d][a,b] + [c,d] = [a+c, b+d][a,b]+[c,d]=[a+c,b+d] —— 代表元里的 +++ 就是 thm.nat-arith-laws 的那个 +++。

⭐ 无零因子是最有意思的一条：设 x=[a,b]x = [a,b]x=[a,b]、y=[c,d]y = [c,d]y=[c,d] 都为正，即 a>ba > ba>b、c>dc > dc>d，写 a=b+pa = b + pa=b+p、c=d+qc = d + qc=d+q（p,q≥1p, q \ge 1p,q≥1）。则 xy=[ac+bd, ad+bc]xy = [ac + bd,\ ad + bc]xy=[ac+bd, ad+bc]，而

(ac+bd)−(ad+bc)=pq>0,(ac + bd) - (ad + bc) = pq > 0,(ac+bd)−(ad+bc)=pq>0,

故 xy>0xy > 0xy>0，不可能为 000。符号相反时乘积为负，同理。

⚠ 这一步做完，def.rat 里「于是 Q\mathbb{Q}Q 是一个有序域」才有依据 —— 有理数的分母取自 Z∖{0}\mathbb{Z} \setminus \{0\}Z∖{0}，而「000 不能作分母」的前提正是「整环里 bd=0bd = 0bd=0 只有平凡解」。

  • 本页 ⟹ ℚ 是有序域推出
    商构造 + Z\mathbb{Z}Z 是整环   ⟹  \implies⟹ Q\mathbb{Q}Q 是有序域

    良定义。 设 a/b=a′/b′a/b = a'/b'a/b=a′/b′、c/d=c′/d′c/d = c'/d'c/d=c′/d′（即 ab′=a′bab' = a'bab′=a′b、cd′=c′dcd' = c'dcd′=c′d，且分母非零）。加法：要证 (ad+bc)(b′d′)=(a′d′+b′c′)(bd)(ad + bc)(b'd') = (a'd' + b'c')(bd)(ad+bc)(b′d′)=(a′d′+b′c′)(bd)，把 ab′=a′bab' = a'bab′=a′b 乘 dd′dd'dd′、cd′=c′dcd' = c'dcd′=c′d 乘 bb′bb'bb′，相加即得。乘法同理（用 acb′d′=a′c′bdac b'd' = a'c' bdacb′d′=a′c′bd）。

    域公理。 全部搬到代表元上，就是 Z\mathbb{Z}Z 的环公理（thm.int-ring）；加法逆元 −a/b=(−a)/b-a/b = (-a)/b−a/b=(−a)/b。

    乘法逆元。 a/b≠0a/b \ne 0a/b=0 即 a≠0a \ne 0a=0，此时 (a/b)(b/a)=ab/ba=1(a/b)(b/a) = ab/ba = 1(a/b)(b/a)=ab/ba=1（交换性用上了；ba≠0b a \ne 0ba=0 用到 Z\mathbb{Z}Z 无零因子）。

    序。 把每个元素写成 b>0b > 0b>0 的 a/ba/ba/b（分母取相反数即可）。定义 a/b≤c/d:  ⟺  ad≤bca/b \le c/d :\iff ad \le bca/b≤c/d:⟺ad≤bc。良定义：换代表元时两边同乘正元 b′d′>0b'd' > 0b′d′>0，由 thm.int-ring 的序相容性不等号不变。全序与两条相容性逐项验证（加法直接；乘法用 bd>0bd > 0bd>0 时同乘正数保序）。

    嵌入。 n↦n/1n \mapsto n/1n↦n/1，保持运算与序。■\blacksquare■

推出 1

  • 整数 ℤ、自然数的运算律 ⟹ 本页推出
    商构造 + N\mathbb{N}N 的运算律   ⟹  \implies⟹ Z\mathbb{Z}Z 是整环

    良定义。 若 [a,b]=[a′,b′][a,b] = [a',b'][a,b]=[a′,b′]、[c,d]=[c′,d′][c,d] = [c',d'][c,d]=[c′,d′]（即 a+b′=a′+ba + b' = a' + ba+b′=a′+b、c+d′=c′+dc + d' = c' + dc+d′=c′+d），则把两式相加并重排得 (a+c)+(b′+d′)=(a′+c′)+(b+d)(a+c) + (b'+d') = (a'+c') + (b+d)(a+c)+(b′+d′)=(a′+c′)+(b+d)，即加法良定义。乘法要长一点：由 a+b′=a′+ba + b' = a' + ba+b′=a′+b 两边乘 c+d′c + d'c+d′、c+d′=c′+dc + d' = c' + dc+d′=c′+d 两边乘 a′+ba' + ba′+b，再比较两个展开式，用 N\mathbb{N}N 的分配律与消去律得 ac+bd+a′d′+b′c′=a′c′+b′d′+ad+bcac + bd + a'd' + b'c' = a'c' + b'd' + ad + bcac+bd+a′d′+b′c′=a′c′+b′d′+ad+bc，即 [ac+bd, ad+bc]=[a′c′+b′d′, a′d′+b′c′][ac+bd,\ ad+bc] = [a'c'+b'd',\ a'd'+b'c'][ac+bd, ad+bc]=[a′c′+b′d′, a′d′+b′c′]。

    环公理。 逐条搬到代表元：结合、交换、分配都变成 N\mathbb{N}N 的对应等式（thm.nat-arith-laws）。零元是 [0,0][0,0][0,0]，幺元是 [1,0][1,0][1,0]，加法逆元是 −[a,b]=[b,a]-[a,b] = [b,a]−[a,b]=[b,a]（因 [a,b]+[b,a]=[a+b, a+b]=0[a,b] + [b,a] = [a+b,\ a+b] = 0[a,b]+[b,a]=[a+b, a+b]=0）。

    序。 [a,b]≤[c,d]:  ⟺  a+d≤b+c[a,b] \le [c,d] :\iff a + d \le b + c[a,b]≤[c,d]:⟺a+d≤b+c 与代表元无关（同上，两边加同一个量）；全序由 N\mathbb{N}N 的全序（三分）得到；相容性逐项验证。

    无零因子。 见节点说明里的 pq>0p q > 0pq>0 论证：两个正元的积为正，故 xy=0xy = 0xy=0 迫使某个因子为 000。

    嵌入。 n↦[n,0]n \mapsto [n,0]n↦[n,0] 显然单射，且 [m,0]+[n,0]=[m+n,0][m,0] + [n,0] = [m+n,0][m,0]+[n,0]=[m+n,0]、[m,0][n,0]=[mn,0][m,0][n,0] = [mn,0][m,0][n,0]=[mn,0]、[m,0]≤[n,0]  ⟺  m≤n[m,0] \le [n,0] \iff m \le n[m,0]≤[n,0]⟺m≤n。■\blacksquare■
