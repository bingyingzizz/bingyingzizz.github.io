English entry · root `../`
[in graph](../#n=def.etale-sheaf)　·　[Chinese page (authoritative)](./def.etale-sheaf.md)

is "forgetting the étale structure", **not** an equivalence. In one sentence: étale sheaves are always Zariski sheaves, but not conversely.

⚠️ **The technical condition cannot be dropped**: the "small étale site" must be a set (not so large that no set can contain it), so one usually takes "affine étale $X$-schemes of locally finite presentation"; different references choose slightly differently, but the resulting topos is the same. This point is not pursued here.
