# Differential of a Smooth Map　`def.differential-map`
English entry · root `../`
[in graph](../#n=def.differential-map)　·　[Chinese page (authoritative)](./def.differential-map.md)

**The derivation viewpoint is leaner**: as a derivation, $\mathrm{d}F_{p}(v)$ is $\bigl(\mathrm{d}F_{p}(v)\bigr)(f) = v(f \circ F)$ — one composition, no curves mentioned. Both routes give the same linear map.

**Why it is not called "the derivative"**: in $\mathbb{R}^{n}$, $\mathrm{d}F_{p}$ is a matrix directly tied to difference quotients; on a manifold there is no subtraction, and $\mathrm{d}F_{p}$ is merely a linear map **between tangent spaces**.
