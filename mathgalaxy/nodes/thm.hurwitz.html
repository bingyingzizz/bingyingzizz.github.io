陈述

白话：一列都没有零点的全纯函数，如果在内闭一致收敛，那么极限函数要么恒等于零，要么也没有零点。

设 Ω\OmegaΩ 是区域，fkf_kfk​ 在 Ω\OmegaΩ 上全纯，且在 Ω\OmegaΩ 的每个紧子集上一致收敛到 fff。若每个 fkf_kfk​ 在 Ω\OmegaΩ 上无零点，则极限 fff 或者恒等于零，或者在 Ω\OmegaΩ 上处处不为零。

等价的说法：若 fff 不恒为零而 f(z0)=0f(z_0) = 0f(z0​)=0，则对每个充分大的 kkk，fkf_kfk​ 在 z0z_0z0​ 的任意小邻域内都有零点。

说明

⭐ 「恒为零」这个例外不能删：fk(z)=1/kf_k(z) = 1/kfk​(z)=1/k 在单位圆盘上处处无零点、内闭一致收敛到 000。

⚠ 需要的是「在每个紧集上一致收敛」（内闭一致），不是逐点收敛。逐点收敛时结论不成立。

⭐ 证明用一个紧的小圆盘 + Rouché：若 fff 在 z0z_0z0​ 有零点，取 rrr 使 fff 在 D(z0,r)‾\overline{D(z_0, r)}D(z0​,r)​ 内只有这一个零点，则 m=min⁡∣z−z0∣=r∣f∣>0m = \min_{|z - z_0| = r}|f| > 0m=min∣z−z0​∣=r​∣f∣>0；fkf_kfk​ 一致收敛保证在圆周上 ∣fk−f∣<m≤∣f∣|f_k - f| < m \le |f|∣fk​−f∣<m≤∣f∣，Rouché 就把 fff 的零点「搬」到 fkf_kfk​ 身上，矛盾。

📌 与 Morera 定理互补：Morera 管「极限全纯」，Hurwitz 管「极限的零点从哪来」。两者一起说明：全纯函数的一些离散性质在一致极限下是封闭的。

    Rouché 定理   ⟹  \implies⟹ Hurwitz 定理

    设 fff 不恒为零，且 f(z0)=0f(z_0) = 0f(z0​)=0。只需在这个零点处导出矛盾。

    第一步：挖一个只含这个零点的小圆盘。 不恒为零的全纯函数零点是孤立的，取 r>0r > 0r>0 使 D(z0,r)‾⊂Ω\overline{D(z_0, r)} \subset \OmegaD(z0​,r)​⊂Ω，且 fff 在 D(z0,r)‾\overline{D(z_0, r)}D(z0​,r)​ 内只有 z0z_0z0​ 一个零点。令

    m:=min⁡∣z−z0∣=r∣f(z)∣>0m := \min_{|z - z_0| = r} |f(z)| > 0m:=∣z−z0​∣=rmin​∣f(z)∣>0

    （圆周上无零点，连续函数在紧集上有正的最小值）。

    第二步：一致收敛让扰动变小。 在紧集 D(z0,r)‾\overline{D(z_0, r)}D(z0​,r)​ 上 fk⇉ff_k \rightrightarrows ffk​⇉f，故当 kkk 充分大时，对圆周上每一点

    ∣fk(z)−f(z)∣≤∥fk−f∥∞<m≤∣f(z)∣.|f_k(z) - f(z)| \le \|f_k - f\|_{\infty} < m \le |f(z)|.∣fk​(z)−f(z)∣≤∥fk​−f∥∞​<m≤∣f(z)∣.

    第三步：用 Rouché。 在圆周 ∣z−z0∣=r|z - z_0| = r∣z−z0​∣=r 上以 fff 为主项、以 fk−ff_k - ffk​−f 为扰动，Rouché 定理说 fff 与 f+(fk−f)=fkf + (f_k - f) = f_kf+(fk​−f)=fk​ 在这条圆周内部的零点数相同。
