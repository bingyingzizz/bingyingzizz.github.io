# retract　`cor.stonean-retract`
English entry · root `../`
[in graph](../#n=cor.stonean-retract)　·　[Chinese page (authoritative)](./cor.stonean-retract.md)

By **Gleason's theorem**, Stonean $\implies$ $A$ is a **projective object** of $\mathbf{CHaus}$, so the surjection $p : F\to A$ has a **section** $s : A\to F$, i.e. $p\circ s = \mathrm{id}_{A}$ — which is exactly "$A$ is a retract of $F$" (take $r := p$) ✓.
- **$(\Longleftarrow)$**: if $A$ is a retract of a free object $F$ ($r: F\to A$, $r|_A = \mathrm{id}$), then, since **a retract of a projective object is projective** (standard fact: a direct summand/retract of a projective object is projective), $A$ is projective in $\mathbf{CHaus}$;

and by Gleason's theorem again, $A$ is Stonean ✓.
