陈述

设 f:X→Yf : X \to Yf:X→Y 是映射。

  • 对 A⊆XA \subseteq XA⊆X，AAA 的像是 f(A):={ f(x):x∈A }⊆Yf(A) := \{\, f(x) : x \in A \,\} \subseteq Yf(A):={f(x):x∈A}⊆Y；
  • 对 B⊆YB \subseteq YB⊆Y，BBB 的原像是 f−1(B):={ x∈X:f(x)∈B }⊆Xf^{-1}(B) := \{\, x \in X : f(x) \in B \,\} \subseteq Xf−1(B):={x∈X:f(x)∈B}⊆X。

说明

⭐ 原像对并、交、补全部保持，而且不需要任何额外假设：

f−1(⋃iBi)=⋃if−1(Bi),f−1(⋂iBi)=⋂if−1(Bi),f−1(Bc)=(f−1(B))cf^{-1}\Bigl(\bigcup_{i} B_{i}\Bigr) = \bigcup_{i} f^{-1}(B_{i}), \qquad f^{-1}\Bigl(\bigcap_{i} B_{i}\Bigr) = \bigcap_{i} f^{-1}(B_{i}), \qquad f^{-1}(B^{c}) = \bigl(f^{-1}(B)\bigr)^{c}f−1(i⋃​Bi​)=i⋃​f−1(Bi​),f−1(i⋂​Bi​)=i⋂​f−1(Bi​),f−1(Bc)=(f−1(B))c

像没有这些性质：f(A∩A′)⊆f(A)∩f(A′)f(A \cap A') \subseteq f(A) \cap f(A')f(A∩A′)⊆f(A)∩f(A′) 一般只是包含，取等要 fff 单射。这正是「连续」（每个开集的原像是开集）与「可测」（每个可测集的原像可测）都用原像、不用像来定义的原因。
