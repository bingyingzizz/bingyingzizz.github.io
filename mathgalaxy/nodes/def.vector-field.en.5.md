# Vector Field　`def.vector-field`
English entry · root `../`
[in graph](../#n=def.vector-field)　·　[Chinese page (authoritative)](./def.vector-field.md)

**A nowhere-vanishing vector field need not exist**: locally always, globally not. On $S^{2}$ none exists (hairy ball theorem); on $S^{1}$, $S^{3}$ and the torus they do. "Whether zeros exist" is the origin of the Poincaré–Hopf theorem and characteristic classes; this map only mentions it.
