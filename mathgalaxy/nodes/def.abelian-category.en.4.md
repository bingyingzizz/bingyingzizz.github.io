## Statement · **reviewed**
- A **preadditive category** (an $\mathbf{Ab}$-category) is a category in which every $\operatorname{Hom}$ set carries an abelian group structure and composition is bilinear;
- A **zero object** is an object with $\operatorname{End}(M) = 1$ (that is, $1_{M} = 0_{M}$); an object $M$ is the **direct sum** $M = M_{1} \oplus M_{2}$ of $M_{1}, M_{2}$ if there are $p_{k} : M \to M_{k}$, $i_{k} : M_{k} \to M$ with $p_{1} i_{1} = 1$, $p_{2} i_{2} = 1$, $i_{1} p_{1} + i_{2} p_{2} = 1_{M}$;
