# 勒贝格数　`def.lebesgue-number`
勒贝格数：紧度量空间上开覆盖的一致尺度
layer 17 · 定义 · 度量空间 · 拓扑学
[在星图里打开](../#n=def.lebesgue-number)　·　[节点索引](../index.md)

**要解决什么问题**：紧性只保证「每个开覆盖有有限子覆盖」，但**没说每个点周围能有多小**。连续性的 $\varepsilon$-论证需要「存在一个统一的尺度 $\delta$，使任何直径小于 $\delta$ 的集合都落在某个覆盖成员里」—— 这就是勒贝格数。
