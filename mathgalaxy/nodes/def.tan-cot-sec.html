陈述

在 sin⁡,cos⁡\sin,\cossin,cos 已经定义的区间上，令

tan⁡x:=sin⁡xcos⁡x (cos⁡x≠0),cot⁡x:=cos⁡xsin⁡x (sin⁡x≠0),\tan x := \frac{\sin x}{\cos x}\ (\cos x \ne 0), \qquad \cot x := \frac{\cos x}{\sin x}\ (\sin x \ne 0),tanx:=cosxsinx​ (cosx=0),cotx:=sinxcosx​ (sinx=0),sec⁡x:=1cos⁡x,csc⁡x:=1sin⁡x.\sec x := \frac{1}{\cos x}, \qquad \csc x := \frac{1}{\sin x}.secx:=cosx1​,cscx:=sinx1​.

定义域相应去掉分母为零的点（例如 tan⁡\tantan 在 x=π/2+kπx = \pi/2 + k\pix=π/2+kπ 处无定义）。

说明

⭐ 它们不是新函数：全部由 sin⁡,cos⁡\sin,\cossin,cos 的商/倒数给出，所以导数和恒等式都能从 sin⁡,cos⁡\sin,\cossin,cos 推 —— tan⁡′=sec⁡2\tan' = \sec^{2}tan′=sec2、(sec⁡)′=sec⁡tan⁡(\sec)' = \sec\tan(sec)′=sectan。此前本图只有 正弦与余弦（只造 sin⁡,cos⁡\sin,\cossin,cos），搜「正切」0 命中。

⭐ 基本恒等式（把 sin⁡2+cos⁡2=1\sin^{2} + \cos^{2} = 1sin2+cos2=1 分别除以 cos⁡2\cos^{2}cos2、sin⁡2\sin^{2}sin2：前者给 1+tan⁡2=sec⁡21 + \tan^{2} = \sec^{2}1+tan2=sec2，后者给 1+cot⁡2=csc⁡21 + \cot^{2} = \csc^{2}1+cot2=csc2，都在分母非零处成立）：

1+tan⁡2x=sec⁡2x,1+cot⁡2x=csc⁡2x.1 + \tan^{2} x = \sec^{2} x, \qquad 1 + \cot^{2} x = \csc^{2} x .1+tan2x=sec2x,1+cot2x=csc2x.

⚠ 定义域是真事：tan⁡\tantan 在 π/2\pi/2π/2 处发散（竖直渐近线），这不是「画不出来」，是函数在那里没定义。所以 tan⁡\tantan 在 (−π/2,π/2)(-\pi/2, \pi/2)(−π/2,π/2) 上才是双射 —— 反函数只在这样的区间上取（见 反三角函数）。

📌 名字的来历：sec⁡\secsec 是 secant（割线），csc⁡\csccsc 是 cosecant；中文「正割/余割」与「正弦/余弦」同源的配对约定，与「正/余」在 sin⁡(π/2−x)=cos⁡x\sin(\pi/2 - x) = \cos xsin(π/2−x)=cosx 意义下的互换一致。
