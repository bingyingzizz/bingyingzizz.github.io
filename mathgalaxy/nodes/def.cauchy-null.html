陈述

设 (xn)(x_n)(xn​) 是有理数列（即函数 ω→Q\omega \to \mathbb{Q}ω→Q），∣x∣|x|∣x∣ 是 Q\mathbb{Q}Q 上的绝对值，ε\varepsilonε 一律取正有理数（此时还不需要实数）。

(xn)(x_n)(xn​) 是 Cauchy 列：

∀ε>0, ∃N, ∀m,n≥N:∣xm−xn∣<ε\forall \varepsilon > 0,\ \exists N,\ \forall m, n \ge N : |x_m - x_n| < \varepsilon∀ε>0, ∃N, ∀m,n≥N:∣xm​−xn​∣<ε

(xn)(x_n)(xn​) 是零列：

∀ε>0, ∃N, ∀n≥N:∣xn∣<ε\forall \varepsilon > 0,\ \exists N,\ \forall n \ge N : |x_n| < \varepsilon∀ε>0, ∃N, ∀n≥N:∣xn​∣<ε

两个 Cauchy 列等价（记作 (xn)∼(yn)(x_n) \sim (y_n)(xn​)∼(yn​)）当且仅当 (xn−yn)(x_n - y_n)(xn​−yn​) 是零列。

（∼\sim∼ 是等价关系：自反、对称显然，传递由三角不等式。）

说明

⭐ 为什么要「模去零列」：同一个实数有很多种逼近方式 —— 比如 (1,1,1,…)(1, 1, 1, \ldots)(1,1,1,…) 与 (1.1, 1.01, 1.001, …)(1.1,\ 1.01,\ 1.001,\ \ldots)(1.1, 1.01, 1.001, …) 都该代表 111，而它们的差是零列。等价类把「同一个数的不同逼近」粘成一件事。

⚠ 这里只用 Q\mathbb{Q}Q 的序与绝对值（ε\varepsilonε 取正有理数、绝对值是 Q\mathbb{Q}Q 上的），所以不构成循环：这一步在造出 R\mathbb{R}R 之前完全说得通。度量空间里那套「距离、Cauchy 列、完备」的语言，正是从这里的做法抽出来的。

三条后面要用的事实：

  • Cauchy 列有界；
  • Cauchy 列的和、差、积仍是 Cauchy 列；
  • 不是零列的 Cauchy 列，从某一项起 ∣xn∣≥δ|x_n| \ge \delta∣xn​∣≥δ（某个正有理数 δ\deltaδ）—— 于是它的倒数（去掉前面有限项）也是 Cauchy 列。第三条是「乘法有逆元」的全部依据。

Abstract reviewed

Over Q\mathbb{Q}Q alone — ε\varepsilonε ranges over positive rationals, so no reals are presupposed — a rational sequence (xn)(x_n)(xn​) is Cauchy when ∀ε>0 ∃N ∀m,n≥N:∣xm−xn∣<ε\forall \varepsilon > 0\, \exists N\, \forall m,n \ge N : |x_m - x_n| < \varepsilon∀ε>0∃N∀m,n≥N:∣xm​−xn​∣<ε, is null when ∀ε>0 ∃N ∀n≥N:∣xn∣<ε\forall \varepsilon > 0\, \exists N\, \forall n \ge N : |x_n| < \varepsilon∀ε>0∃N∀n≥N:∣xn​∣<ε, and two Cauchy sequences are equivalent when their difference is null. The quotient by this relation is how R\mathbb{R}R is built: it glues together the many ways of approximating one number. Three facts are used later: Cauchy sequences are bounded, sums and products of Cauchy sequences are Cauchy, and a non-null Cauchy sequence satisfies ∣xn∣≥δ>0|x_n| \ge \delta > 0∣xn​∣≥δ>0 from some point on, so its reciprocal is Cauchy again.

Statement reviewed

Let (xn)(x_n)(xn​) be a sequence of rational numbers (that is, a function ω→Q\omega \to \mathbb{Q}ω→Q), let ∣x∣|x|∣x∣ be the absolute value on Q\mathbb{Q}Q, and let ε\varepsilonε always range over positive rationals (no real numbers are needed yet).

(xn)(x_n)(xn​) is a Cauchy sequence:

∀ε>0, ∃N, ∀m,n≥N:∣xm−xn∣<ε\forall \varepsilon > 0,\ \exists N,\ \forall m, n \ge N : |x_m - x_n| < \varepsilon∀ε>0, ∃N, ∀m,n≥N:∣xm​−xn​∣<ε

(xn)(x_n)(xn​) is a null sequence:

∀ε>0, ∃N, ∀n≥N:∣xn∣<ε\forall \varepsilon > 0,\ \exists N,\ \forall n \ge N : |x_n| < \varepsilon∀ε>0, ∃N, ∀n≥N:∣xn​∣<ε

Two Cauchy sequences are equivalent:

Two Cauchy sequences are equivalent (written (xn)∼(yn)(x_n) \sim (y_n)(xn​)∼(yn​)) if and only if (xn−yn)(x_n - y_n)(xn​−yn​) is a null sequence.

(∼\sim∼ is an equivalence relation: reflexivity and symmetry are immediate, transitivity follows from the triangle inequality.)

Notes reviewed

⭐ Why divide by the null sequences: the same real number has many approximating sequences — for instance (1,1,1,…)(1, 1, 1, \ldots)(1,1,1,…) and (1.1, 1.01, 1.001, …)(1.1,\ 1.01,\ 1.001,\ \ldots)(1.1, 1.01, 1.001, …) should both represent 111, and their difference is a null sequence. Equivalence classes glue "different approximations of one and the same number" into a single object.

⚠ Here we use only the order and the absolute value of Q\mathbb{Q}Q (ε\varepsilonε ranges over positive rationals, and the absolute value is the one on Q\mathbb{Q}Q), so there is no circularity: this step makes perfect sense before R\mathbb{R}R is constructed. The language of "distance, Cauchy sequence, completeness" in metric spaces is exactly what was abstracted out of this construction.

Three facts needed later:

  • a Cauchy sequence is bounded;
  • sum, difference and product of Cauchy sequences are again Cauchy;
  • a Cauchy sequence that is not a null sequence satisfies ∣xn∣≥δ|x_n| \ge \delta∣xn​∣≥δ from some index on (for some positive rational δ\deltaδ) — hence its reciprocal, after discarding finitely many terms, is again Cauchy. The third fact is the entire basis for "multiplication has inverses".
