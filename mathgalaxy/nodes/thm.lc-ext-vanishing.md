# 局部紧阿贝尔群高次 Ext 消失　`thm.lc-ext-vanishing`
$\operatorname{Ext}^{n}_{\mathbb{Z}}(M, N) = 0$（$n \ne 0, 1$）
layer 17 · 定理 · 凝聚态上同调 · 凝聚态数学+同调代数

设 $M, N$ 是**局部紧 Hausdorff 阿贝尔群**。则对一切 $n \ne 0, 1$

$$\operatorname{Ext}^{n}_{\mathbb{Z}}(M, N) = 0.$$
