陈述

在交换环范畴里，沿 A→BA \to BA→B、A→CA \to CA→C 的纤维余积（推出）是 B⊗ACB \otimes_{A} CB⊗A​C。

说明

证明（验证推出的泛性质）。 记 D:=B⊗ACD := B\otimes_{A} CD:=B⊗A​C，β:B→D\beta : B\to Dβ:B→D、γ:C→D\gamma : C\to Dγ:C→D 为 b↦b⊗1b\mapsto b\otimes 1b↦b⊗1、c↦1⊗cc\mapsto 1\otimes cc↦1⊗c。

  • 方块交换：β(a⋅1B)=a⊗1=1⊗a⋅1=γ(a⋅1C)\beta(a\cdot 1_{B}) = a\otimes 1 = 1\otimes a\cdot 1 = \gamma(a\cdot 1_{C})β(a⋅1B​)=a⊗1=1⊗a⋅1=γ(a⋅1C​)，即 β∘(A→B)=γ∘(A→C)\beta\circ(A\to B) = \gamma\circ(A\to C)β∘(A→B)=γ∘(A→C) ✓；
  • 泛性质：任给交换环 EEE 与同态 f:B→Ef : B\to Ef:B→E、g:C→Eg : C\to Eg:C→E 使 f∣A=g∣Af|_{A} = g|_{A}f∣A​=g∣A​，定义
φ(∑kbk⊗ck):=∑kf(bk) g(ck)∈E.\varphi\Bigl(\sum_{k} b_{k}\otimes c_{k}\Bigr) := \sum_{k} f(b_{k})\,g(c_{k}) \in E .φ(k∑​bk​⊗ck​):=k∑​f(bk​)g(ck​)∈E.

它是良定义的：⊗\otimes⊗ 的双线性关系逐条被 f,gf,gf,g 的乘法性与 f∣A=g∣Af|_{A}=g|_{A}f∣A​=g∣A​ 满足（例如 ab⊗c−b⊗ac↦f(ab)g(c)−f(b)g(ac)=f(a)f(b)g(c)−f(b)g(a)g(c)=0ab\otimes c - b\otimes ac \mapsto f(ab)g(c)-f(b)g(ac) = f(a)f(b)g(c) - f(b)g(a)g(c) = 0ab⊗c−b⊗ac↦f(ab)g(c)−f(b)g(ac)=f(a)f(b)g(c)−f(b)g(a)g(c)=0）✓；由交换性 φ\varphiφ 是环同态 ✓；且 φβ=f\varphi\beta = fφβ=f、φγ=g\varphi\gamma = gφγ=g ✓。

  • 唯一性：DDD 由 β(B)∪γ(C)\beta(B)\cup\gamma(C)β(B)∪γ(C) 生成（b⊗c=β(b)γ(c)b\otimes c = \beta(b)\gamma(c)b⊗c=β(b)γ(c)），故在两个生成块上定死就唯一 ✓。

于是 DDD 满足推出的泛性质，即 B⊗AC=B∐ACB\otimes_{A}C = B\coprod_{A} CB⊗A​C=B∐A​C。∎ ⚠️ 交换性是必需的：非交换环上，B⊗ACB\otimes_{A}CB⊗A​C 一般不是环（乘法在张量积上不下降）—— 那时纤维余积要用自由积 / 余等化子另造。
