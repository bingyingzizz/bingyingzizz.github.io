# First Fundamental Form　`def.first-fundamental-form`
English entry · root `../`
[in graph](../#n=def.first-fundamental-form)　·　[Chinese page (authoritative)](./def.first-fundamental-form.md)

Relative to parameters $(u,v)$ it is written $I = E\,\mathrm{d}u^{2}+2F\,\mathrm{d}u\,\mathrm{d}v+G\,\mathrm{d}v^{2}$, where $E = \langle r_{u}, r_{u}\rangle$, $F = \langle r_{u}, r_{v}\rangle$, $G = \langle r_{v}, r_{v}\rangle$;

relative to an orthonormal coframe it is written

$$I = (\omega^{1})^{2}+(\omega^{2})^{2}.$$
