# Boolean ring　`def.boolean-ring`
English entry · root `../`
[in graph](../#n=def.boolean-ring)　·　[Chinese page (authoritative)](./def.boolean-ring.md)

Conversely, $a \,\triangle\, b = a + b$: ring addition is **symmetric difference**.

**Smallest example**: $\mathbb{F}_{2} = \{\, 0, 1 \,\}$. **Most general example**: for a set $I$, its power set $\mathcal{P}(I)$, with symmetric difference as addition and intersection as multiplication.
