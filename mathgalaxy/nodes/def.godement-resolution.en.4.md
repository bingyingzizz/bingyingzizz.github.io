# Godement resolution　`def.godement-resolution`
English entry · root `../`
[in graph](../#n=def.godement-resolution)　·　[Chinese page (authoritative)](./def.godement-resolution.md)

**Use (conditional on flabby acyclicity)**: if flabby sheaves are acyclic (Godement's theorem, not proved here), the Godement resolution computes sheaf cohomology: $H^{q}(X,\mathcal{F})\cong H^{q}(\Gamma(X,\mathcal{C}^{\bullet}(\mathcal{F})))$. This is the standard construction of a canonical acyclic resolution for an arbitrary sheaf, without injective sheaves.

⚠ This graph has @@def.acyclic-sheaf@@ and @@def.right-derived-functor@@, but **not** a node or proof of "flabby sheaves are acyclic" (step 3 of @@thm.soft-sheaf-acyclic@@ is precisely conditional on it). This node only defines the construction.
