## Statement · **reviewed**
There exists an "inductive set" — a set containing $\emptyset$ and closed under the successor operation:

$$\exists I [ \emptyset \in I \wedge  \forall x ( x \in I \to x \cup \{ x \} \in I ) ]$$

The axiom itself only asks that $I$ be **non-empty** and closed under successor; writing $\emptyset \in I$ is just for looks, since $\emptyset$ is a primitive object (see "the empty set"). This axiom asserts the existence of an infinite set, and is the only source from which the set of natural numbers $\omega$ is built.
