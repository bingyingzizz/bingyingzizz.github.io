Statement

Let μ\muμ be a measure on (X,M)(X, \mathcal{M})(X,M) and ν\nuν a signed measure. Then ν\nuν is absolutely continuous with respect to μ\muμ, written

ν≪μ,\nu \ll \mu, ν≪μ,

if and only if every μ\muμ-null set is ν\nuν-null:
