# 有限测度时方向反过来　`prop.lp-inclusion-finite`
命题（只有爆破的场合）：$\mu(X) < \infty$ 时 $L^p(\mu) \supseteq L^q(\mu)$

设 $\mu(X) < \infty$，$0 < p < q \le \infty$。则

$$L^q(\mu) \subseteq L^p(\mu), \qquad \|f\|_p \le \|f\|_q \, \mu(X)^{\,(1/p) - (1/q)}$$
