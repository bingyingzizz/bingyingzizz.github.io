陈述

在做什么：把「度量给的体积大小」写成能积分的量：带符号的叫体积形式（要定向），不带符号的叫密度（不要定向），同一串系数的两种读法。

设 (M,g)(M,g)(M,g) 是 nnn 维黎曼流形，卡 (U,x)(U,x)(U,x) 里记 gij=g(∂i,∂j)g_{ij} = g(\partial_{i},\partial_{j})gij​=g(∂i​,∂j​)。

体积密度（不需要定向）：

dμg:=det⁡(gij)  dx1⋯dxn,\mathrm{d}\mu_{g} := \sqrt{\det(g_{ij})}\;\mathrm{d}x^{1}\cdots\mathrm{d}x^{n},dμg​:=det(gij​)​dx1⋯dxn,

右边是 Lebesgue 测度乘一个正的光滑函数，所以它是一个密度：换卡不变（绝对值那一半在开方里，见 prop.volume-density-well-defined），拼接后给出 MMM 上唯一的 Radon 测度 μg\mu_{g}μg​。

体积形式（需要先取定一个定向）：在每张保向卡里令

dV:=det⁡(gij)  dx1∧⋯∧dxn.\mathrm{d}V := \sqrt{\det(g_{ij})}\;\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}.dV:=det(gij​)​dx1∧⋯∧dxn.

等价地，它逐点由「在正向标准正交基上取 111」刻画：dVp(e1,…,en)=1\mathrm{d}V_{p}(e_{1},\ldots,e_{n}) = 1dVp​(e1​,…,en​)=1，其中 (e1,…,en)(e_{1},\ldots,e_{n})(e1​,…,en​) 是 TpMT_{p}MTp​M 的任意一组正向标准正交基 —— 交错性加上「换一组这样的基只差行列式为 111 的变换」保证这刻画与基的选取无关。翻转定向，dV\mathrm{d}VdV 变号。

体积：vol⁡g(M):=μg(M)\operatorname{vol}_{g}(M) := \mu_{g}(M)volg​(M):=μg​(M)；MMM 紧且已定向时它等于 ∫MdV\int_{M}\mathrm{d}V∫M​dV，并且 dμg=∣dV∣\mathrm{d}\mu_{g} = |\mathrm{d}V|dμg​=∣dV∣。

说明

为什么系数是 det⁡g\sqrt{\det g}detg​：dx1∧⋯∧dxn\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}dx1∧⋯∧dxn 在基 (∂1,…,∂n)(\partial_{1},\ldots,\partial_{n})(∂1​,…,∂n​) 上取 111，但 ∂i\partial_{i}∂i​ 一般不是正交基。设 ∂i=∑jAijej\partial_{i} = \sum_{j}A_{ij}e_{j}∂i​=∑j​Aij​ej​（eje_{j}ej​ 为标准正交基），则 g=ATAg = A^{\mathsf T}Ag=ATA，于是 det⁡g=∣det⁡A∣\sqrt{\det g} = |\det A|detg​=∣detA∣；保向时 det⁡A>0\det A>0detA>0，而 dV(∂1,…,∂n)=det⁡A\mathrm{d}V(\partial_{1},\ldots,\partial_{n}) = \det AdV(∂1​,…,∂n​)=detA，与「在正交基上取 111」相容。面积（体积）放大率就是行列式，这是 det⁡(gij)\sqrt{\det(g_{ij})}det(gij​)​ 的全部来历。

两个结构各管一头：度量管「多大」（det⁡g\sqrt{\det g}detg​ 这个标量），定向管「正负」（dx1∧⋯\mathrm{d}x^{1}\wedge\cdotsdx1∧⋯ 的次序）。所以 dV\mathrm{d}VdV 属于「度量 +++ 定向」，缺一个都定义不出来；而 dμg\mathrm{d}\mu_{g}dμg​ 只要度量，这是它俩唯一但关键的差别。

存在性：可定向流形上存在处处非零的 nnn-形式 ω\omegaω（可定向即「能被转移映射 Jacobi 行列式处处为正的卡族覆盖」，二维情形见 def.orientable-surface）。把 ω\omegaω 除以它在正向标准正交基上的取值，就得到满足 dV(e1,…,en)=1\mathrm{d}V(e_{1},\ldots,e_{n}) = 1dV(e1​,…,en​)=1 的那个形式 —— 所以「可定向 +++ 度量」恰好给出一个体积形式，且只差一个定向的符号。

二维时它就是 def.area-element：那里写 dA=det⁡(gij) du∧dv\mathrm{d}A = \sqrt{\det(g_{ij})}\,\mathrm{d}u\wedge\mathrm{d}vdA=det(gij​)​du∧dv，与这里逐字相同；「面积元是密度、不是形式」那句话说的就是 dμg\mathrm{d}\mu_{g}dμg​ 那一面。

例子：Rn\mathbb{R}^{n}Rn 标准度量与标准定向给出 dV=dx1∧⋯∧dxn\mathrm{d}V = \mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}dV=dx1∧⋯∧dxn；半径 RRR 的 S2S^{2}S2 在球坐标 (θ,φ)(\theta,\varphi)(θ,φ) 下（取 ∂θ,∂φ\partial_{\theta},\partial_{\varphi}∂θ​,∂φ​ 为保向）给出 dV=R2sin⁡θ dθ∧dφ\mathrm{d}V = R^{2}\sin\theta\,\mathrm{d}\theta\wedge\mathrm{d}\varphidV=R2sinθdθ∧dφ。

⚠️ 记号分歧：很多书写 dV\mathrm{d}VdV 指密度（不带符号的测度）。本图把两者分开：dV\mathrm{d}VdV 是形式（带定向），dμg=∣dV∣\mathrm{d}\mu_{g} = |\mathrm{d}V|dμg​=∣dV∣ 是密度。抄公式前先看清对方用的是哪一种。

推出 1

  • 本页 ⟹ 密度与定向无关推出
    行列式的平方   ⟹  \implies⟹ 密度不依赖定向

    （1）局部变换。 设 yyy 是另一张卡，J:=∂x/∂yJ := \partial x/\partial yJ:=∂x/∂y。由 ∂yi=∑kJki ∂xk\partial_{y^{i}} = \sum_{k}J_{ki}\,\partial_{x^{k}}∂yi​=∑k​Jki​∂xk​ 与度量的双线性得 gy=JTgxJg^{y} = J^{\mathsf T}g^{x}Jgy=JTgxJ，取行列式：det⁡gy=(det⁡J)2det⁡gx\det g^{y} = (\det J)^{2}\det g^{x}detgy=(detJ)2detgx。两边开方（det⁡g>0\det g>0detg>0，因为 ggg 正定），

    det⁡gy=∣det⁡J∣ det⁡gx.\sqrt{\det g^{y}} = |\det J|\,\sqrt{\det g^{x}} .detgy​=∣detJ∣detgx​.

    （2）与体积元配平。 换元公式给出 dy1⋯dyn=∣det⁡(∂y/∂x)∣ dx1⋯dxn=∣det⁡J∣−1dx1⋯dxn\mathrm{d}y^{1}\cdots\mathrm{d}y^{n} = |\det(\partial y/\partial x)|\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n} = |\det J|^{-1}\mathrm{d}x^{1}\cdots\mathrm{d}x^{n}dy1⋯dyn=∣det(∂y/∂x)∣dx1⋯dxn=∣detJ∣−1dx1⋯dxn。两式相乘，∣det⁡J∣|\det J|∣detJ∣ 抵消，故

    det⁡gy dy1⋯dyn=det⁡gx dx1⋯dxn.\sqrt{\det g^{y}}\,\mathrm{d}y^{1}\cdots\mathrm{d}y^{n} = \sqrt{\det g^{x}}\,\mathrm{d}x^{1}\cdots\mathrm{d}x^{n} .detgy​dy1⋯dyn=detgx​dx1⋯dxn.

    关键：开方给出 ∣det⁡J∣|\det J|∣detJ∣ 而不是 det⁡J\det JdetJ —— 这一步就是「密度不换号」的全部来源。若换成 nnn-形式版，dx1∧⋯\mathrm{d}x^{1}\wedge\cdotsdx1∧⋯ 的变换因子是 det⁡J\det JdetJ（无绝对值），于是乘积只在保向时不变、反向时变号。

    （3）拼成整体。 局部密度在重叠处相等，故用从属于卡族的单位分解 {ρα}\{\rho_{\alpha}\}{ρα​} 定义 μg(f):=∑α∫Rn(ραf)∘xα−1 det⁡g dx\mu_{g}(f) := \sum_{\alpha}\int_{\mathbb{R}^{n}}(\rho_{\alpha}f)\circ x_{\alpha}^{-1}\,\sqrt{\det g}\ \mathrm{d}xμg​(f):=∑α​∫Rn​(ρα​f)∘xα−1​detg​ dx。每一项非负（f≥0f\ge 0f≥0 时）、和有限，且由 (2) 与卡选取无关；于是 μg\mu_{g}μg​ 是 MMM 上良定、正、可数可加的 Radon 测度。

    （4）与 dV\mathrm{d}VdV 对照。 有定向时 dV=det⁡g dx1∧⋯∧dxn\mathrm{d}V = \sqrt{\det g}\,\mathrm{d}x^{1}\wedge\cdots\wedge\mathrm{d}x^{n}dV=detg​dx1∧⋯∧dxn 与 dμg\mathrm{d}\mu_{g}dμg​ 逐卡同系数，只差「楔积（带符号）」与「Lebesgue（不带符号）」，故 μg=∣dV∣\mu_{g} = |\mathrm{d}V|μg​=∣dV∣，且紧流形上 ∫MdV=μg(M)=vol⁡g(M)\int_{M}\mathrm{d}V = \mu_{g}(M) = \operatorname{vol}_{g}(M)∫M​dV=μg​(M)=volg​(M)。∎
