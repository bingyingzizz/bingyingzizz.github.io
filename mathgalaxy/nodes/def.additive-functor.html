陈述

设 C,D\mathcal{C}, \mathcal{D}C,D 是两个预加性范畴。函子 F:C→DF : \mathcal{C} \to \mathcal{D}F:C→D 叫加法函子，如果对每对 M,N∈CM, N \in \mathcal{C}M,N∈C，映射

Hom⁡C(M,N)⟶Hom⁡D(F(M),F(N)),f⟼F(f)\operatorname{Hom}_{\mathcal{C}}(M, N) \longrightarrow \operatorname{Hom}_{\mathcal{D}}(F(M), F(N)), \qquad f \longmapsto F(f)HomC​(M,N)⟶HomD​(F(M),F(N)),f⟼F(f)

是阿贝尔群同态（即保加法、保 000）。

说明

等价说法：加法函子自动保有限直和（F(M⊕N)≅F(M)⊕F(N)F(M \oplus N) \cong F(M) \oplus F(N)F(M⊕N)≅F(M)⊕F(N)），而且 F(0)=0F(0) = 0F(0)=0。反过来，一个保有限直和的函子（在预加性范畴之间）也是加法的。

⭐ 为什么同调代数只谈加法函子：求导函子、Ext⁡\operatorname{Ext}Ext、HnH^{n}Hn 都是加法的。复形上的运算（d2=0d^{2}=0d2=0、取同调、映射锥）每一步都是加减法，非加法函子连复形都送不成复形。

例子：Hom⁡(X,−)\operatorname{Hom}(X, -)Hom(X,−) 是加法的（Hom⁡\operatorname{Hom}Hom 本身是阿贝尔群）；M⊗A−M \otimes_{A} -M⊗A​− 是加法的；遗忘函子 A-Mod→AbA\text{-}\mathbf{Mod} \to \mathbf{Ab}A-Mod→Ab 是加法的。

⚠️ 「加法」与「左正合/右正合」是两件事：加法只是保群结构，正合才是保核与余核。加法是前提，正合是进一步的条件。

推出 5

  • 本页 ⟹ 加法函子保导出三角推出

    证明。 导出三角的定义是「同构于某个映射锥三角」。逐条检查：

    • FFF 保映射锥：M(f)n=Kn+1⊕LnM(f)^{n} = K^{n+1} \oplus L^{n}M(f)n=Kn+1⊕Ln 而微分是分块矩阵 (−dn+10fndn)\begin{pmatrix} -d^{n+1} & 0 \\ f^{n} & d^{n} \end{pmatrix}(−dn+1fn​0dn​)。

    FFF 加法，故保有限双积（F(Kn+1⊕Ln)=FKn+1⊕FLnF(K^{n+1}\oplus L^{n}) = FK^{n+1}\oplus FL^{n}F(Kn+1⊕Ln)=FKn+1⊕FLn）✓，而分块矩阵的两个条件（与微分交换、左上取 −d-d−d）都是等式，逐项被 FFF 保持 ✓。

    于是 F(M(f))≅M(Ff)F(M(f)) \cong M(Ff)F(M(f))≅M(Ff) ✓。

    • FFF 保平移：F(K[1])=F(K)[1]F(K[1]) = F(K)[1]F(K[1])=F(K)[1]（逐项作用与指标无关）✓。
    • FFF 保同构与同伦类：FFF 是函子，把同构送到同构、把 K(C)\mathbf{K}(\mathcal{C})K(C) 的态射送到 K(C′)\mathbf{K}(\mathcal{C}')K(C′) 的态射 ✓。

    于是任何导出三角（≅\cong≅ 某个映射锥三角）被 FFF 送到 ≅\cong≅ FFF 的映射锥三角，仍是导出三角 ✓。 ⚠️ 这里必须用加法性：非加法函子不保双积，F(Kn+1⊕Ln)≠FKn+1⊕FLnF(K^{n+1}\oplus L^{n}) \ne FK^{n+1}\oplus FL^{n}F(Kn+1⊕Ln)=FKn+1⊕FLn，论证立刻断掉。∎

  • 本页 ⟹ 加法函子的刻画推出

    证明。 ① 加法   ⟹  \implies⟹ 保双积。 FFF 加法意味着每个 Hom⁡(M,N)→Hom⁡(FM,FN)\operatorname{Hom}(M,N) \to \operatorname{Hom}(FM,FN)Hom(M,N)→Hom(FM,FN) 是群同态。若 MMM 是 M1,M2M_{1},M_{2}M1​,M2​ 的双积，FFF 把三条等式送到

    F(pk)F(ik)=1,F(i1)F(p1)+F(i2)F(p2)=1F(M),F(p_{k})F(i_{k}) = 1, \qquad F(i_{1})F(p_{1}) + F(i_{2})F(p_{2}) = 1_{F(M)},F(pk​)F(ik​)=1,F(i1​)F(p1​)+F(i2​)F(p2​)=1F(M)​,

    这正是「F(M)F(M)F(M) 是 F(M1),F(M2)F(M_{1}), F(M_{2})F(M1​),F(M2​) 的双积」的定义 ✓；有限多支同理。零对象：1F(0)=F(10)=F(00)=0F(0)1_{F(0)} = F(1_{0}) = F(0_{0}) = 0_{F(0)}1F(0)​=F(10​)=F(00​)=0F(0)​（群同态把零元送到零元），故 F(0)F(0)F(0) 是零对象 ✓。 ② 保双积与零对象   ⟹  \implies⟹ 加法。 用上面的关键公式 f+g=∇N(f⊕g)ΔMf + g = \nabla_{N}(f\oplus g)\Delta_{M}f+g=∇N​(f⊕g)ΔM​。

    FFF 保积、保余积，故 F(ΔM)=ΔFMF(\Delta_{M}) = \Delta_{FM}F(ΔM​)=ΔFM​、F(∇N)=∇FNF(\nabla_{N}) = \nabla_{FN}F(∇N​)=∇FN​（这三个映射都由「与投影 / 含入复合是什么」唯一刻画，而 FFF 保投影与含入），且 F(f⊕g)=Ff⊕FgF(f \oplus g) = Ff \oplus FgF(f⊕g)=Ff⊕Fg（由四角刻画同样唯一）。

    于是

    F(f+g)=F(∇N)F(f⊕g)F(ΔM)=∇FN(Ff⊕Fg)ΔFM=Ff+Fg✓F(f+g) = F(\nabla_{N})F(f\oplus g)F(\Delta_{M}) = \nabla_{FN}(Ff\oplus Fg)\Delta_{FM} = Ff + Fg ✓F(f+g)=F(∇N​)F(f⊕g)F(ΔM​)=∇FN​(Ff⊕Fg)ΔFM​=Ff+Fg✓

    故 Hom⁡(M,N)→Hom⁡(FM,FN)\operatorname{Hom}(M,N) \to \operatorname{Hom}(FM,FN)Hom(M,N)→Hom(FM,FN) 保加法；它当然保零，所以是群同态，即 FFF 加法 ✓。 ③ 有限积 / 有限余积：加法范畴里有限积、有限余积、直和三者重合（见「直和就是积」），所以三个条件说的是同一件事；空积是终对象、空余积是始对象，都是零对象 ✓。∎

  • 本页 ⟹ 左正合性的判据推出

    证明。 (⟹)(\Longrightarrow)(⟹) 左正合就是保有限极限 ✓。

    保有限极限当然保有限积与核，于是：FFF 保双积   ⟹  \implies⟹ FFF 加法（见「加法函子的刻画」）✓；

    而左正合列 0→M′→M→M′′0 \to M' \to M \to M''0→M′→M→M′′ 本身就是一个有限极限图表，被 FFF 送到同样的图表，即仍是左正合列 ✓。 (⟸)(\Longleftarrow)(⟸) 设 FFF 加法且保左正合列。由「保有限积 + 保核   ⟹  \implies⟹ 保所有有限极限」，只需证这两条 ✓：

    • 保核：0→ker⁡f→ i M→ f N0 \to \ker f \xrightarrow{\ i\ } M \xrightarrow{\ f\ } N0→kerf i ​M f ​N 是左正合列 ✓，被送到左正合列 0→F(ker⁡f)→ Fi FM→ Ff FN0 \to F(\ker f) \xrightarrow{\ Fi\ } FM \xrightarrow{\ Ff\ } FN0→F(kerf) Fi ​FM Ff ​FN，这正是 F(ker⁡f)≅ker⁡(Ff)F(\ker f) \cong \ker(Ff)F(kerf)≅ker(Ff) ✓；
    • 保有限积：0→M→ i1 M⊕N→ p2 N0 \to M \xrightarrow{\ i_{1}\ } M \oplus N \xrightarrow{\ p_{2}\ } N0→M i1​ ​M⊕N p2​ ​N 也是左正合列（i1i_{1}i1​ 单、im⁡i1=ker⁡p2\operatorname{im}i_{1} = \ker p_{2}imi1​=kerp2​）✓，被送到左正合列 0→FM→F(M⊕N)→FN0 \to FM \to F(M\oplus N) \to FN0→FM→F(M⊕N)→FN；

    而 FFF 加法说明 FFF 保双积、Fi1Fi_{1}Fi1​ 就是第一个含入 ✓，于是 F(M⊕N)F(M \oplus N)F(M⊕N) 连同 Fi1,Fi2Fi_{1}, Fi_{2}Fi1​,Fi2​ 满足直和的三条等式（见「直和就是积」），即 F(M⊕N)≅FM⊕FNF(M\oplus N) \cong FM \oplus FNF(M⊕N)≅FM⊕FN ✓。 两条合起来：FFF 保有限积与核，从而保所有有限极限，即左正合 ✓。∎

  • 本页 ⟹ 张量函子的刻画推出

    证明（自由模上验、右正合推广）。 ① F(R)F(R)F(R) 是 RRR-模。 RRR 上的左乘给出 End⁡R-Mod(R)≅Rop\operatorname{End}_{R\text{-}\mathbf{Mod}}(R) \cong R^{\mathrm{op}}EndR-Mod​(R)≅Rop 的作用；

    FFF 把它送到 F(R)F(R)F(R) 的自同态，于是 F(R)F(R)F(R) 自动带上模结构 ✓（交换环上左右不分，可以就写 RRR）。 ② 自由模上成立。 对 M=R(I)=⨁i∈IRM = R^{(I)} = \bigoplus_{i \in I} RM=R(I)=⨁i∈I​R，保直和给出

    F(R(I))≅⨁iF(R)≅R(I)⊗RF(R)F\bigl(R^{(I)}\bigr) \cong \bigoplus_{i} F(R) \cong R^{(I)}\otimes_{R} F(R)F(R(I))≅i⨁​F(R)≅R(I)⊗R​F(R)

    FFF 右正合，保这个右正合列；而 M⊗R−M\otimes_{R}-M⊗R​− 也右正合，保同一个右正合列。

    ② 给出两端（R(I)R^{(I)}R(I) 与 R(J)R^{(J)}R(J) 处）的自然同构，于是两行比较、用「F(M)→M⊗F(R)F(M) \to M\otimes F(R)F(M)→M⊗F(R) 那个自然变换在两侧都是同构」以及五项（或三项）引理，中间也是同构 ✓。 说明：那个自然变换 τM:F(M)→M⊗RF(R)\tau_{M} : F(M) \to M\otimes_{R} F(R)τM​:F(M)→M⊗R​F(R) 的构造是「MMM 的元素沿 R→MR \to MR→M 送入、再作用 FFF」的一般化 —— 它在自由模上由 ② 给出、与生成元选取无关 ✓。∎
