# Zeroth de Rham Cohomology　`thm.de-rham-h0`
English entry · root `../`
[in graph](../#n=thm.de-rham-h0)　·　[Chinese page (authoritative)](./thm.de-rham-h0.md)

**Do not apply the Poincaré lemma to $H^{0}$**: the lemma says that for $k \ge 1$ and a contractible region one has $H^{k} = 0$. $H^{0}$ is never zero for a nonempty manifold, because it counts "how many global pieces there are", not "whether there is a local obstruction".
