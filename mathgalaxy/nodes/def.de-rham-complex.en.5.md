# de Rham Complex and Cohomology　`def.de-rham-complex`

**The de Rham theorem (stated only, not proved)**: $H^{k}_{\mathrm{dR}}(M) \cong H^{k}_{\mathrm{sing}}(M;\mathbb{R})$ — what is computed analytically (forms plus derivative) equals what is computed purely topologically (singular chains plus boundary).

This stitches differential geometry to algebraic topology and is the interface with the category/homology region of this graph.

**Finite dimension**: when $M$ is compact, each $H^{k}_{\mathrm{dR}}(M)$ is finite-dimensional and vanishes for $k > \dim M$. So cohomology is a finite set of numbers (Betti numbers). Not proved here.
