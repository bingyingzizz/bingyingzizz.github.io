# 记号表 · 积分与函数空间
根 `../`　·　索引 `notation.md`

- `\chi_{E}` χ_E　**特征函数**
- `L^{+}` L⁺　**非负可测函数全体**
- `\varphi` φ　**简单函数（$\varphi = \sum a_j \chi_{E_j}$）** — 一阶逻辑里是一阶公式
- `\psi` ψ　**与 $\varphi$ 配对的第二个函数**
- `\int \varphi \, d\mu` ∫　**积分**
- `L^{1}` L¹　**可积函数空间**
- `L^{p}, L^{q}`　**L^p 空间（$p, q$ 共轭指数）**
- `\int_a^b f` ∫　**Riemann / Lebesgue 积分** — 写成 $\int_a^b f$（不写 $dx$）时不强调变量；写成 $\int_a^b f(x)\,dx$ 时 $dx$ 前留一个细空格 `\,`。
- `U(f, P),\ L(f, P)` U／L　**（对分割的）上和 / 下和** — **只用于 Riemann 积分**：$P$ 是有限分割，$U$ 取每段的上确界、$L$ 取下确界。
- `\Delta x_i` Δxᵢ　**分割的小区间长度** — 与 $\Delta$ 的别的含义（对称差、增量）区分：带上标 $x_i$ 时专指分割点之差。
