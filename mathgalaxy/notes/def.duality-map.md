# 对偶配对 φ_g　`def.duality-map`　·　说明
根 `../`

由 **Hölder 不等式**，这个泛函是有界的，而且



$$\|\varphi_g\| \le \|g\|_q$$

（这里 $\|\varphi_g\|$ 是 $(L^p)^*$ 里的算子范数，即 $\sup\{|\varphi_g(f)| : \|f\|_p = 1\}$。）

⭐ 于是得到一个映射



$$L^q \longrightarrow (L^p)^*, \qquad g \mapsto \varphi_g$$

下面两条命题要证明它是一个**等距同构**（在 $1 < p < \infty$ 时）。
