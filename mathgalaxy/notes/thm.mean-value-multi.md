# 多元中值定理　`thm.mean-value-multi`　·　说明
根 `../`

⭐ 一维中值定理靠 Rolle，Rolle 靠「连续函数在闭区间取到最值」—— 而**多元没有这一条**（等号版本对 $\mathbb{R}^{m}$ 值函数是**假**的：$f(t) = (\cos t, \sin t)$ 绕一圈，$f(2\pi) - f(0) = 0$，但 $Df$ 处处非零、$\|Df\| = 1$）。

⭐ 所以多元真正好用的是**不等式版本**：它只需要「沿线段用一元中值定理 + 范数估计」，不需要任何最值存在性。后面压缩映射原理与逆映射定理用的全是它。

⚠ 标量情形（$f$ 值域是 $\mathbb{R}$）的等号版本要好小心：通常的证法是对 $\varphi(t) = f(a + th)$ 用一维 MVT，得到的是「存在 $\theta$ 使 $f(a+h) - f(a) = Df(a + \theta h)(h)$」—— 这里的 $\theta$ 依赖于 $h$，不能当成常数用。
