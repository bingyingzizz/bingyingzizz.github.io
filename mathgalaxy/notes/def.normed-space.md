# 赋范空间　`def.normed-space`　·　说明
根 `../`

⭐ 范数是「长度」的公理化。三条公理里**只有三角不等式不是逐点的** —— 它管的是「能不能绕路」，也正是它把范数与凸性绑在一起（单位球是凸的）。

⭐ 与内积的关系是单向的：内积 $\implies$ 范数（`def.induced-norm`），但范数来自内积**当且仅当**满足**平行四边形法则** $\|v+w\|^{2} + \|v-w\|^{2} = 2\|v\|^{2} + 2\|w\|^{2}$。所以「有长度」比「有夹角」弱。

⚠ 有限维时所有范数**等价**（诱导同一个拓扑、同一套收敛列）；无限维则不然 —— 这正是泛函分析开始变难的地方。

⭐ 本图在凝聚态那一片另有 `def.semi-normed-ab-group`（半范数阿贝尔群）：那里的系数不是向量空间而是拓扑阿贝尔群，所以只能要半范数。
