# 浸入 / 淹没 / 嵌入　`def.submersion-immersion`　·　说明
根 `../`

**各方向用到的假设**（秩的刻画是线性代数，标准形需要微积分定理）：
- 浸入 $\iff$ 导数单射、淹没 $\iff$ 导数满射是定义；相应满秩判据用有限维秩零度公式，不需要逆映射定理。
- 满秩 $\implies$ 局部包含或投影标准形：利用 $C^1$ 保证满秩在邻域稳定，再用秩定理；反向由标准形及链式法则立即恢复秩条件。
- 嵌入 $\iff$ 浸入且到像为同胚是定义，像必须取子空间拓扑；只验导数不能免费得到全局同胚。
- 浸入不保证嵌入：$t\mapsto(\sin 2t,\sin t)$ 处处导数非零却有自交；$t\mapsto t^3$ 是到像同胚但在零点不是浸入，说明同胚条件也不能代替导数条件。
