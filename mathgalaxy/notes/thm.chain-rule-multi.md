# 多元链式法则　`thm.chain-rule-multi`　·　说明
根 `../`

⭐ 整条定理就是一句话：**微分的链式法则是线性映射的复合**。矩阵形式只是选好基之后的写法 —— 所以「链式法则 = 矩阵乘法」不是巧合，而是定义使然。

⚠ 证明里有一个真陷阱：不能就此写下 $Dg(f(a + h)) = Dg(f(a)) + O(h)$。因为 $f(a + h) - f(a)$ 本身是 $O(\|h\|)$ 的量，$g$ 在 $f(a)$ 处的 $o(\|k\|)$（$k = f(a+h) - f(a)$）必须显式换成 $o(\|h\|)$，这一步要用 $\|k\| \le (\|Df(a)\| + 1)\|h\|$（$h$ 小的时候）。证明全文在边上。
