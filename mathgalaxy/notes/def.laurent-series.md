# Laurent 级数　`def.laurent-series`　·　说明
根 `../`

⭐ 两块各有各的收敛范围：正则部分在 $|z - a| < R$ 内收敛，主部在 $|z - a| > r$ 内收敛，交起来正好是**环域** —— 这就是为什么 Laurent 级数的自然舞台是环而不是圆盘。

⚠ 下面三分法都要求 $a$ 是**孤立奇点**（在某个穿孔圆盘 $0 < |z - a| < R$ 上全纯）；否则主部的形状不反映奇点类型 —— 例如 $|z| > 1$ 上的 Laurent 展开主部有无穷多项，而 $0$ 处 $f$ 全纯。主部为零对应可去奇点；

主部只有有限项对应**极点**（阶数 = 主部里**最大负幂**的绝对值：若从 $(z - a)^{-m}$ 起步就叫 $m$ 阶 —— **不是**非零项的个数，$z^{-3}$ 只有一项却是三阶极点）；

主部有无穷多项对应本性奇点。

所以孤立奇点的三分法，本质上是按主部的形状分的。

📌 书里先做「Laurent 分解」：环域上的全纯函数可以拆成「内圆盘上全纯的一项」加「外域（含无穷远）上全纯的一项」，再由这两项各自的展开合成 Laurent 级数。
