# 极小多项式　`def.minimal-poly`　·　说明
根 `../`

⭐ 极小多项式是**相似完全不变量**中最细的那一个（与特征多项式合起来）：Jordan 型完全由它们决定，而两个矩阵相似 $\iff$ 它们有相同的**不变因子**（等价于相同的 Jordan 型）。

⭐ $I_T$ 是理想这件事本身很重要：$p(T) = 0$、$q(T) = 0 \implies (p + q)(T) = 0$，且 $r\,p$ 也在里面 —— 于是 $T$ 在 $K[x]$ 上成了**模**（$x$ 作用 = $T$），后面 Jordan 型的证明全在这个模里做。

⚠ 极小多项式与特征多项式的根**相同**（差一个重数）：两者都等于「$T$ 的特征值全体」。
