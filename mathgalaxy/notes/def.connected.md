# 连通与连通分量　`def.connected`　·　说明
根 `../`

**四种说法，代价都在“取补”与“连续像”上**：

- 连通 $\iff$ **不能写成两个不交非空开集之并**：这是定义。
- 连通 $\iff$ **没有非平凡的闭开子集**：$(\implies)$ 用 $V = X \setminus U$ 闭；$(\Leftarrow)$ 一行。**这一步只用开闭集的对偶**。
- 连通 $\iff$ **每个连续映射 $X \to \{0,1\}$（离散两点）都是常值**：$(\implies)$ 像连通且 $\{0,1\}$ 不连通；$(\Leftarrow)$ 由前一条取特征函数。⚠️ 这一步把连通性翻译成「没有到两点的满射」，是内部语言里的标准形式。
- **连通分量的并是连通的（任意多个也成立）**：这一条要**不交并/并的连通性引理**（若两个连通集相交则并连通），而「任意多」的情形要对指标集做一次选择之外的形式论证（取含定点的族，避免 AC）。

⚠️ **连通 $\ne$ 道路连通**：道路连通 $\implies$ 连通，反之不成立（拓扑学家的正弦曲线）。两者的差距正是「$\pi_{0}$ 与道路 $\pi_{0}$」的差距。
