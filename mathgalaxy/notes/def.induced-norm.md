# 诱导范数与距离　`def.induced-norm`　·　说明
根 `../`

⭐ 于是**内积空间自动是度量空间**，可以谈收敛、完备、紧 —— 分析那一侧的全部工具都能进来。完备的内积空间叫 **Hilbert 空间**。

⭐ 反过来：范数未必来自内积。判据是**平行四边形律**

$$\|u + v\|^{2} + \|u - v\|^{2} = 2\|u\|^{2} + 2\|v\|^{2}$$

（$\ell^{p}$ 在 $p \ne 2$ 时不满足它，所以 $\ell^{p}$ 上的范数不来自任何内积 —— 这也是「$L^{2}$ 特别」的原因。）

⭐ 由内积恢复内积的公式是**极化恒等式**：$\langle u, v\rangle = \frac{1}{4}\bigl( \|u+v\|^{2} - \|u-v\|^{2} \bigr)$（实情形）。
