# 偏导数　`def.partial-derivative`　·　说明
根 `../`

⚠ 偏导数存在**什么也保证不了**：$f(x, y) = xy/(x^{2} + y^{2})$（原点补 $f(0,0) = 0$）在原点两个偏导都存在（都等于 $0$），但沿 $y = x$ 趋近时 $f \to 1/2 \ne f(0,0)$ —— 它连**连续**都不成立。

⭐ 病根是一个不对称：偏导存在是 $2n$ 个**一维**条件，而可微（`def.total-differential`）是**一个** $n$ 维条件。一维条件再多也堆不出 $n$ 维结论。

⭐ 反过来，$C^{1}$（偏导存在**且连续**）就足以推出可微 —— 这条是实践中最常用的充分条件，证明见 `def.total-differential` 的说明。

⭐ 在 $\mathbb{R}^n$ 这种「坐标里长出来的空间」上偏导是免费的；到了**流形**或 **Banach 空间**上，「坐标」本身要先花力气造出来，那时才有方向导数与可微性的讨论。
