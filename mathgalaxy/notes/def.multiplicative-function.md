# 积性函数　`def.multiplicative-function`　·　说明
根 `../`

为什么这个条件自然：由算术基本定理，$n$ 唯一分解成素数幂之积，而这些素数幂两两互素 —— 所以积性函数完全由它在素数幂 $p^{e}$ 上的值决定。这就把「$n$ 的全体」上的函数压成「每个素数一列」的数据。



完全积性更强：还要求 $f(p^{e}) = f(p)^{e}$。

$\mu$、$\varphi$、$\tau$、$\sigma$ 都只是**积性**，**没有一个是完全积性**：$\mu(4) = 0 \ne \mu(2)^{2} = 1$、$\varphi(4) = 2 \ne \varphi(2)^{2} = 1$。完全积性的典型例子是 $\mathrm{id}$ 与常函数 $1$（以及它们的乘积、Dirichlet 特征标）。



两个积性函数的**狄利克雷卷积**仍积性 —— 这是后面 Möbius 反演的代数背景。
