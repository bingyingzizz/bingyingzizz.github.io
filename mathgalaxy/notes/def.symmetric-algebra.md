# 对称代数　`def.symmetric-algebra`　·　说明
根 `../`

⭐ 三个「$V^{\otimes \bullet}$ 的商」构成一张完整的表：

- 全不商 $\implies$ **张量代数** $T^{\bullet}V$（非交换、自由）；
- 商掉 $vw - wv$ $\implies$ **对称代数** $\operatorname{Sym}^{\bullet}V \cong K[x_1, \ldots, x_n]$（交换）；
- 商掉 $vw + wv$ $\implies$ **外代数** $\bigwedge^{\bullet}V$（分次交换）。

⭐ «$\operatorname{Sym}^{\bullet}V \cong K[x_1,\ldots,x_n]$» 说明多项式环不是凭空造出来的 —— 它就是「$n$ 维空间的对称代数」。这解释了为什么多项式与多重线性型的关系这么紧（也回到 `def.polynomial-ring`）。

⭐ 二重线性型的分类（对称 / 交错）在代数层面的化身就是这两个商。
