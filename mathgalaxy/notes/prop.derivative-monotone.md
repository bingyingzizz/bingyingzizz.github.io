# 导数符号 ⟹ 单调性　`prop.derivative-monotone`　·　说明
根 `../`

⭐ 「$f' > 0 \implies$ 严格递增」的反命题**不成立**：$f(x) = x^{3}$ 严格递增而 $f'(0) = 0$。要得到严格单调，只能用 Lagrange 中值定理逐段验证（每一段上导数不恒为零即可），不能指望点点为正。

⚠ 「$f' \ge 0$ 处处成立」也推不出严格递增（常数函数）；反之那一半（递增 $\implies f' \ge 0$）是差商的极限，与中值定理无关。

⭐ 这是微积分里第一个「局部信息（导数）决定整体形状（单调）」的定理，也是求最值那套流程的理论依据。
