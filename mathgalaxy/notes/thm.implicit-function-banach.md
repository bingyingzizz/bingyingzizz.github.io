# 隐函数定理（Banach 版）　`thm.implicit-function-banach`　·　说明
根 `../`

⭐ 证明与有限维版本**逐字相同**：令 $\Phi(x, y) := (x, F_0(x, y))$，则 $D\Phi$ 是块上三角、$D\Phi$ 拓扑同构 $\iff$ $D_y F_0$ 拓扑同构，对 $\Phi$ 用 Banach 版逆映射定理（`thm.inverse-function-banach`）即可。

⭐ 这一步说明了为什么「逆映射」与「隐函数」在图上应当分开建节点却共用一个证明：它们在**范畴层面是同一件事**（$\Phi$ 是把隐函数问题打包成逆映射问题的函子式构造），只是包装不同。

⚠ 名字冲突提醒：本节点里的 $F_0$ 是为了不与 Banach 空间 $F$ 撞名而加的角标，含义与有限维版本的 $F$ 相同。
