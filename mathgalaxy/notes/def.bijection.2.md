# 单射 / 满射 / 双射　`def.bijection`　·　说明
根 `../`

**各方向用到的假设**（双射与双侧逆等价不需选择公理，满射的右逆另当别论）：
- 双射 $\iff$ 既单且满：定义展开，免费，满射始终针对指定陪域。
- 双射 $\implies$ 存在唯一双侧逆：满射给每个点的原像存在，单射给唯一；由逆关系构造函数，不需选择公理。
- 有双侧逆 $\implies$ 双射：用左逆推出单射、右逆推出满射，只需复合运算；只有单侧逆不够，例如 $n\mapsto n+1$ 在自然数上单射而不满。
- 任意满射都有右逆是选择公理的等价形式，不能与双射取逆混同；等势的自反、对称、传递分别用恒等映射、逆、复合，也不需选择公理。
