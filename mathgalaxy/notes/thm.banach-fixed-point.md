# 压缩映射原理　`thm.banach-fixed-point`　·　说明
根 `../`

⭐ 这是分析里罕见的**三合一**定理：它同时给出存在性、唯一性**和算法**（迭代）**与误差估计**。绝大多数存在性定理只说「有」，这一条说「怎么找、找多准」。

⚠ 两个前提都不能去：
- 去掉**完备性**：$(0,1]$ 不完备，$T(x) = x/2$ 是压缩，但不动点 $0$ 不在空间里；
- 去掉 $q < 1$：`def.contraction` 里的 $x + 1/x$ 就是反例。

⭐ 用它的标准套路（后面两条大定理都用）：把「解方程 $f(x) = y$」改写成「找 $\Phi_y$ 的不动点」，其中 $\Phi_y(x) := x - f(x) + y$ 在小球上是压缩 —— 于是「解存在」变成「球完备 + 压缩」。
