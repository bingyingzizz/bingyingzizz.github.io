# Čech 函子的性质　`prop.cech-properties`　·　说明
根 `../`

**各方向用到的假设**（集合值预层的加号构造）：
- 分离 $\iff$ 典范映射单：展开局部相等的定义，再用覆盖有公共细化；不是对任意余极限都成立。
- 层 $\implies$ 典范映射同构：相容族存在唯一粘合，属层条件的直接展开；反向利用加号构造总分离，从同构推出原预层分离，再还原粘合。
- 分离 $\implies$ 一次加号后为层：需覆盖的拉回及复合公理；任意预层一次加号只保证分离，不能直接宣称已是层。
- 左正合的代价是集合中滤过余极限与有限极限交换；固定覆盖的相容族函子保极限，但覆盖上的乘积可以是无限积，不能把它误称有限极限。
