# 关于圆的对称点　`def.symmetric-point`　·　说明
根 `../`

**为什么这样定义**：在圆内 $|z - a| < R$，对称点落在圆外 —— 这是个**反演**。它把「圆心」和「无穷远点」互相对应（$z = a$ 时 $z^{*} = \infty$），这正是 `prop.mobius-symmetry` 能让对称性在分式线性变换下保持的原因。

⭐ **计算式**（做题最常用）：

$$z^{*} = a + \frac{R^{2}}{\overline{z - a}}.$$

关于实轴的对称就是 $z^{*} = \bar z$；关于单位圆的对称是 $z^{*} = 1/\bar z$。

⚠️ 对称点不是「到圆心的距离相等」：那是对径点。对称是**反演**，距离乘积固定。
