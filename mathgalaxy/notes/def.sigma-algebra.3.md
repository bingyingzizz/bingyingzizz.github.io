# σ-代数　`def.sigma-algebra`　·　说明
根 `../`

- **含全集 $\iff$ 含空集**：由对补封闭即得（$\emptyset = X^{c}$）。所以写成「含 $\emptyset$」或「含 $X$」等价，**只要同时有对补封闭**。
- **对可数并封闭 $\iff$ 对可数交封闭**：**用两次 de Morgan**：$\bigcap_{n} A_{n} = \bigl(\bigcup_{n} A_{n}^{c}\bigr)^{c}$。所以「可数并对」与「可数交」两条只留一条即可 —— **但必须配「对补封闭」**，缺了它两条都推不出来。
- **「可数并」不能弱化成「有限并」**：只有有限并 + 对补 得到的是**代数**（Boolean algebra），不是 $\sigma$-代数。差别是实质的：有理数集在 $2^{\mathbb{R}}$ 的有限并代数里可以被包含，但 $\{q\}$ 的可数并（$= \mathbb{Q}$）就不一定 —— 而测度论的全部内容都要数可数并。
