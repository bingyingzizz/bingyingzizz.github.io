# 有限可加测度　`def.finitely-additive`　·　说明
根 `../`

它比预测度还弱：预测度是可数可加的（只是定义域是环），有限可加测度只要求有限可加。

⚠ 有限可加 $\ne$ 可数可加：在 $\mathbb{N}$ 上定义 $\mu (E) = 0$（$E$ 有限）、$\mu (E) = +\infty$（$E$ 无限），它是有限可加的，但对 $\bigcup _{n} \{n\} = \mathbb{N}$ 不满足可数可加。

历史上（Banach–Tarski 时代）确实认真考虑过只用有限可加性的「测度」，；问题不在构造长度（Lebesgue 测度本身就有限可加，$m((a,b]) = b - a$ 就是长度），而在于有限可加**不足以支撑可数极限定理**（MCT、DCT、Fubini 全都要塌）。
