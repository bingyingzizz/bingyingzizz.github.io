# 偏序集　`def.poset`　·　说明
根 `../`

典型例子：$\langle \mathcal{P}(S), \subseteq \rangle$ 是偏序集但不是全序集；$\langle \mathbb{R}, \le \rangle$ 是全序集。

反对称性是说：只允许「相等」这一种互相 $\le$ 的方式，所以偏序可以看成「$\le$ 的抽象」。



**各方向用到的假设**（公理定义与严格序转换）：
- 偏序 $\iff$ 自反、反对称、传递三条同时成立，以及全序 $\iff$ 偏序再加可比性，都是定义展开，不用选择公理。
- 偏序 $\implies$ 严格序：令 $x\prec y$ 表示 $x\preceq y$ 且 $x\ne y$，可证非自反及传递；反向从非自反传递关系取其自反闭包得到偏序，是有限步逻辑推导。
- 反对称不能省：两点集上的全关系自反且传递，却不是偏序；可比性也非自动，二元集的幂集按包含排序有两个不可比单点集。
- 偏序扩充成全序是另一个定理，通常用序扩张原理；本节点定义全序并不声称存在扩张，不能把其存在性算作定义。
