# 三点决定分式线性变换　`prop.mobius-three-points`　·　说明
根 `../`

**存在性**：上式对每个 $z$ 唯一确定一个 $w$（除非分母为零，此时 $w = \infty$），所以它定义了一个映射；它关于 $z$ 是一次的，故是分式线性变换。逐点代入即得 $Tz_{k} = w_{k}$。

**唯一性**：若 $T_{1}, T_{2}$ 都满足，则 $S := T_{1}^{-1}T_{2}$ 固定三个点。而固定三个点的分式线性变换只有恒等（由交比不变性：$Sz$ 与 $z$ 对同样的三点有相同的交比，故 $Sz = z$）。∎

⭐ **实用价值**：凡是「构造一个把某圆盘送到上半平面的变换」这类问题，只要挑三个边界点对好，变换就唯一确定了 —— 不用猜系数。

⚠️ 三对点必须在扩充平面上互异；允许 $\infty$ 作为目标点（例如把某点送到 $\infty$，那就是把它「挖掉」变成一个半平面）。
