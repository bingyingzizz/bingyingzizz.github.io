# 常秩定理　`cor.rank-theorem`　·　说明
根 `../`

⭐ 秩定理说「**常秩映射局部只有一种形状**」：一切常秩 $r$ 的映射在局部长得一模一样，唯一的「不变量」就是秩 $r$。这是微积分里的一条**分类定理**，也是「局部 $\to$ 标准形」这个套路的收官之作。

⭐ 三个推论一次拿到：
- $r = n = m$：$\psi \circ f \circ \varphi^{-1} = \mathrm{id}$ $\implies$ 局部同构，即**逆映射定理**；
- $r = n < m$：$x \mapsto (x, 0)$，即**浸入**标准形；
- $r = m < n$：$(x_1, \ldots, x_n) \mapsto (x_1, \ldots, x_m)$，即**淹没**（局部投影）标准形。

⚠ **常秩**这个前提不能去：$f(x) = x^{2}$（$\mathbb{R} \to \mathbb{R}$）在 $x \ne 0$ 处秩 $1$、在 $0$ 处秩 $0$，局部形状不是标准形（它是「折叠」）。

证明全文在边上（先对 $r$ 造坐标把 $f$ 的前 $r$ 个分量变成坐标，再用隐函数定理把剩下的分量消掉）。
