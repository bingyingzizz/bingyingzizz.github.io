# 逆映射定理　`thm.inverse-function`　·　说明
根 `../`

⭐ 定理的形状值得记：**局部可逆 $\iff$ $Df(a)$ 可逆**，而且「逆映射的导数 = 导数的逆」。

后半句完全是线性代数的操作 —— 一旦把 $f$ 局部看成「线性映射加高阶小量」，求逆自然落在 $Df$ 上。

⚠ 「局部」不能去掉。

$f(x, y) = (e^{x}\cos y,\ e^{x}\sin y)$ 的 $\det Df = e^{2x} \ne 0$ 处处成立，但 $f$ 整体远非单射（$y$ 有周期 $2\pi$）。

⚠ 定理只保证 $C^{1}$；

但由 $Dg = (Df \circ g)^{-1}$ 立即得：$f$ 光滑 $\implies$ $g$ 光滑（$Df\circ g$ 光滑、求逆是光滑运算）。

这就是「$f$ 是微分同胚 $\implies$ $f^{-1}$ 也是」。

⭐ 定理顺带说明了 $f$ 是**开映射**（把开集 $V$ 映成开集 $W$）—— 这一点在有限维与 Banach 空间里都是**免费**的（逆映射定理本身就给出局部同胚，局部同胚自然把开集映成开集）。⚠ 别和泛函分析的「**开映射定理**」搞混：那条讲的是满射有界线性算子是开映射，与本图的「非常数全纯函数是开映射」同名不同物。
