# 保圆性　`prop.mobius-circle`　·　说明
根 `../`

**证明**：由 `prop.cross-ratio-real`，四点共圆 $\iff$ 交比为实。而交比在分式线性变换下不变，故「共圆」这件事被保持 —— 于是圆（或直线）上的像仍在同一类里。更具体地：$T$ 是三个平移/旋转/伸缩与 $z \mapsto 1/z$ 的复合，前三种显然保圆，$1/z$ 把圆 $|z - a| = r$ 送到圆（算一下 $w = 1/z$ 满足 $|1/w - a| = r$，整理得 $|w - \bar a/\sigma|^{2} = r^{2}/\sigma^{2}$ 型方程，仍是圆）。∎

⭐ **「直线算圆」不是文字游戏**：在扩充平面上直线就是过 $\infty$ 的圆，统一之后定理只有一句，代码/证明都少一半。

⚠️ 保圆但**不保圆内**：「圆盘映成圆盘还是外部」要看定向。实系数（$ad - bc$ 与系数实性）的分式线性变换把上半平面映到上半或下半平面，要判方向就看一个测试点的像。
