# 预拓扑斯　`def.pretopos`　·　说明
根 `../`

- **① 有限极限存在**：**纯结构要求**，只保证能谈纤维积、等化子（于是能谈“关系”）。它不涉及余极限，也不涉及满/单。
- **② 有限余积不交且万有**：**这是真的条件，且不能省**。「不交」= 拉回 $A \times_{A\sqcup B} B \simeq \emptyset$ 的空白（要求有初始对象且它“真的空”）；「万有」= 余积在拉回下稳定。**只要求“有限余积存在”远不够** —— $\mathbf{Set}$ 的余积不交且万有，但 $\mathbf{Grp}$ 的余积（自由积）并不万有，于是 $\mathbf{Grp}$ 不是预拓扑斯。
- **③ 等价关系有效且万有**：**这一条保证“商”与“关系”对应**（有效 = 每个等价关系都是某个满态射的核对；万有 = 在拉回下保持）。⚠️ 缺了它，「商对象」与「等价关系」就对不上，第一同构定理无从谈起。
- **④ 满态射正则且万有**：**这一条最技术**（正则 = 是某个核对的第一分量）。⚠️ 它与 ③ 有重叠但**不互相蕴含**：③ 说的是等价关系$\to$满态射，④ 说的是满态射
