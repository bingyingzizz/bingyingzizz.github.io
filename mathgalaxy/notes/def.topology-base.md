# 基与子基　`def.topology-base`　·　说明
根 `../`

⭐ 基的用处：**只需在基上验证，就自动对一切开集成立**。

- 距离空间里：开球全体构成一组基；
- $\mathbb{R}$ 上：开区间构成一组基；半开区间 $\{ (a, b] \}$ 生成的是**另一拓扑**（上半极限拓扑）的基 —— 它们不是通常开集，所以**不是**通常拓扑的基（不过构造 Lebesgue–Stieltjes 测度时更好用）；

- 积拓扑、$\sigma$-代数的「柱集」也是同一套路：先定一组好用的集合，再取它生成的东西。

⚠ 基不是唯一的：同一个拓扑可以有很多组基。
