# 等距与正交变换　`def.isometry`　·　说明
根 `../`

⭐ 等距保持**全部几何**：长度、角度、正交性、体积（$|\det| = 1$）。所以「两个图形全等」在代数上就是「差一个正交变换」。

⭐ $O(n)$ 是紧李群（有界闭），$SO(n) := \{Q : \det Q = 1\}$ 是它的连通分支（含单位元的那个）—— 旋转群。

⚠ 「保持范数 $\implies$ 保持内积」的推导用**极化恒等式**：内积可以由范数恢复（$\langle u,v\rangle = \frac{1}{4}\sum_{k=0}^{3} i^{k}\|u + i^{k}v\|^{2}$）—— 这也是「范数未必来自内积」那一节的另一半。
