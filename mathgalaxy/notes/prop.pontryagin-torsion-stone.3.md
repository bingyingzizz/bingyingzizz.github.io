# 挠 与 Stonean，无挠 与 连通　`prop.pontryagin-torsion-stone`　·　说明
根 `../`

**各方向用到的假设**（原文 Stonean 应改读为 Stone，二者不可混同）：
- 挠 $\implies$ 对偶为 Stone：离散阿贝尔挠群是其有限生成有限子群的滤过并；对偶把它化为有限群的逆极限，故紧 Hausdorff 且全不连通。这用对偶和逆极限理论，不是定义。
- Stone 对偶 $\implies$ 挠：紧全不连通群有开子群邻域基，任意圆值特征标因圆群无小子群而有开核，故像有限；再用双对偶识别 $M$。
- 挠 $\implies$ Stonean（极不连通）并不成立：$M=\bigoplus_{n\ge1}\mathbb Z/2$ 的对偶是 Cantor 群 $\prod_{n\ge1}\mathbb Z/2$，它是 Stone 而非极不连通空间；原等价不能靠补假设说明当作已证事实。
- 无挠 $\iff$ 对偶连通：用紧阿贝尔群的连通性判据「无非平凡有限连续商」，及对偶把有限商与有限子群互换；不能只用一般空间的连续映射判据替代群同态判据。
