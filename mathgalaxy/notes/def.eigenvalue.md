# 特征值与特征向量　`def.eigenvalue`　·　说明
根 `../`

⭐ 一句话：**特征向量是「$T$ 只把它拉伸、不改变方向」的那些向量**，特征值是拉伸倍数。等价说法：$\lambda$ 是特征值 $\iff$ $T - \lambda I$ **不可逆** $\iff$ $\det(\lambda I - T) = 0$。

⭐ 特征子空间 $E_\lambda$ 是 $T$-不变的（而且 $T$ 在它上面就是「乘 $\lambda$」），不同特征值的特征子空间**线性无关**（和是直和）。

⚠ $\lambda$ 必须在 $K$ 里：实矩阵可能没有实特征值（旋转 $90^\circ$ 的特征值是 $\pm i$），此时要扩到 $\mathbb{C}$（或直接说「在 $K$ 上无特征值」）。
