# 马蹄引理　`lem.horseshoe`　·　说明
根 `../`

沿满射 $P_{n-1} \twoheadrightarrow \operatorname{im} d_{n-1}^{P}$ 用 $Q_{n}$ 的**投射性**抬升，即得 $\chi_{n}$ ✓。
**③ 增广。** $Q_{0}$ 投射、$p$ 满，故 $\eta$ 沿 $p$ 抬升为 $\sigma : Q_{0} \to M$（$p\sigma = \eta$）✓；令 $\varepsilon_{R}(x, y) := i\varepsilon(x) + \sigma(y)$。

要 $\varepsilon_{R}d_{0} = 0$，只需在 $\chi_{0} : Q_{0} \to P_{-1} = M_{1}$ 上补一个条件：由 $p\sigma e_{0} = \eta e_{0} = 0$ 知 $\sigma e_{0}$ 的像落在 $\ker p = \operatorname{im} i$ 里，写成 $i\theta$；

再用 $\varepsilon$ 满、$Q_{0}$ 投射把 $\theta : Q_{0} \to M_{1}$ 抬成 $\chi_{0}$，即 $\varepsilon\chi_{0} = -\theta$ ✓。
