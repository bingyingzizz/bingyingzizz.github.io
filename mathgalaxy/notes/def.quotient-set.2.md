# 商集与等价类　`def.quotient-set`　·　说明
根 `../`

**各方向用到的假设**（商的定义免费，等价类性质依赖等价关系公理）：
- $[a]=\{b:b\sim a\}$ 与商集为全体等价类是定义；$a\in[a]$ 用自反性，不用选择代表元。
- $a\sim b$ $\implies$ $[a]=[b]$：用对称性及传递性证明两边包含；反向由 $a\in[a]=[b]$ 得出，要用自反性。
- 等价关系 $\implies$ 等价类构成划分：用交集非空则类相等及自反性；划分 $\implies$ 同块关系为等价关系则逐条验证三公理，均不需选择公理。
- 等价关系假设不能省：在 $\mathbb Z$ 上取 $b\sim a$ 表示 $b\le a$，所得下闭射线相交却不相等。给每个非空等价类同时选代表元才可能需要选择公理，定义商集本身不需要。
