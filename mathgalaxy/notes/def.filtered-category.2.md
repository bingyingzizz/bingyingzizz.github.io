# 滤过范畴　`def.filtered-category`　·　说明
根 `../`

**各方向用到的假设**（有限图余锥与三条公理的有限组合）：
- 每个有限图有余锥 $\implies$ 三条：分别取空图、两个离散对象、一对平行箭头，只需展开余锥定义。
- 三条 $\implies$ 有限图余锥：先有限次取共同上界，再逐条余等化图中箭头造成的不相容；需有限归纳，无需 Zorn 或无限选择。
- 偏序看成范畴时，上界与非空 $\implies$ 滤过：平行箭头至多一条，第三条自动；一般范畴不能删第三条，非平凡群看成单对象范畴即反例。
- 非空条件不能删：空范畴真空满足后两条，却没有空图的余锥。换成共尾有向集的进一步定理还要小性约定及相应集合论构造，不属于这组定义等价。
