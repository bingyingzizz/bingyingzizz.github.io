# 谱定理（实对称）　`thm.spectral-theorem`　·　说明
根 `../`

⭐ 与 Jordan 型的区别：Jordan 只保证「相似」，谱定理保证「**酉/正交**相似」，代价是把条件收紧到自伴（正规）。这是有限维里两个不同的分类问题的答案。

⭐ 证明的两步：① 至少有一个（实）特征值（用最值定理：$|Tv|$ 或 $\langle Tv, v\rangle$ 在单位球面这个**紧**集上取极值）；② 对特征子空间的正交补归纳（不变性来自自伴：$T(U) \subseteq U \implies T(U^{\perp}) \subseteq U^{\perp}$）。

⭐ 无限维的推广是**Hilbert 空间上的谱定理**（自伴算子的谱测度 / 投影值测度）—— 那是泛函分析的内容，图上 `analysis.lp` 那一团的 $L^{2}$ 就是它的舞台。
