# 符号测度　`def.signed-measure`　·　说明
根 `../`

**各方向用到的假设**（公理与由正测度之差构造符号测度是不同层次）：
- 符号测度 $\iff$ 所列空集、单侧无穷及可数可加公理：按此处约定是定义展开，不用 Hahn 或 Jordan 分解定理。
- $\mu_1,\mu_2$ 至少一个有限 $\implies\mu_1-\mu_2$ 为符号测度：有限性排除未定义的无穷相减，可数可加性由正测度性质得；两者都无限时不能保证，例如无限计数测度减自身在全集上无定义。
- 广义可积 $f\implies\nu(E)=\int_E f\,d\mu$ 为符号测度：需正负部分积分至少一个有限，再用非负积分的单调收敛定理，不是定义展开。
- 反向“每个符号测度都是两个正测度之差”要用 Hahn–Jordan 分解；有限总值时不交分解的级数绝对收敛也可由可数可加性在子并集上的约束推出，不能用条件收敛级数替代。
