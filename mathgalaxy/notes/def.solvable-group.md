# 可解群　`def.solvable-group`　·　说明
根 `../`

⭐ 三个等价说法，用哪个都行：
- 存在**阿贝尔商**的正规链（定义）；
- **导出列**有限步终止（最好算）；
- 有合成列且**所有合成因子都是素数阶循环群**（最好判）。

⭐ 名字的来源与它真正的价值：Galois 理论的主定理把「多项式方程可用根式解」翻译成「它的 Galois 群可解」—— Abel–Ruffini 定理就从这里出来。这条线的另一半（域扩张）在批 7。

⚠ 「可解」**不是**「阿贝尔」：$S_3$ 与 $S_4$ 都可解但非阿贝尔。「可解」说的是「能被一串**阿贝尔商**逐层拆开」，即「离阿贝尔群有限步远」。

⭐ 单群 + 可解 $\implies$ 阿贝尔（因为合成列只能是一条 $\{e\} \trianglelefteq G$，因子 $G$ 单且必须阿贝尔）。所以**非阿贝尔单群一律不可解**，$A_5$ 是第一个例子。

⭐ 两类必会：阿贝尔群全部可解（一步链）；$p$-群全部可解（用类方程归纳，中心非平凡 $\implies$ 可对 $Z(G)$ 与 $G/Z(G)$ 归纳）。
