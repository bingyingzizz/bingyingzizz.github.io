# 映射　`def.function`　·　说明
根 `../`

在 ZFC 里「映射就是一种特殊的关系」：它只多了一条要求 —— 每个输入的输出**唯一**。

⚠ 两个容易混的地方：
- 「$f$ 是映射」不要求 $A$ 上处处有定义；要求了才写 $f : A \to B$（即 $\operatorname{dom} f = A$）。
- 像 $f(A)$ 一般只是 $B$ 的子集，满射才要求 $f(A) = B$。

⭐ **「映射」是最一般的说法**（集合到集合），不管是几何体之间的、群之间的、还是函子之间的。中文书里常把它和「函数」混着用，本图把两者分开：**取值在数集的才叫函数**。
