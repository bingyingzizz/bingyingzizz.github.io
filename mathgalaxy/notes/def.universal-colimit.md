# 万有关系　`def.universal-colimit`　·　说明
根 `../`

「万有」= **拉回之后还在**：不管把整个图沿什么映射拉回去，性质都保持。这三条是把「集合里那些显然的好性质」翻译成范畴语言的样板 —— 它们在 $\mathbf{Set}$ 里不出问题，但换一个范畴就未必，所以必须写下来。

**各方向用到的假设**（三类术语是不同的拉回稳定性要求）：
- 万有余极限 $\iff$ 任意基变换后仍为该图的余极限：定义展开免费，须所写拉回及余极限存在。
- 万有正则满态射 $\iff$ 所有拉回仍正则满：同为定义展开；仅取恒等基变换只得到正则满，不能反推万有。
- 不交余积 $\iff$ 注入为单态射且异项纤维积为始对象：定义展开；不自动蕴含余积万有。
- 集合中的稳定性需用集合余极限与拉回的具体构造；一般范畴不能照搬，例如群的余积虽为自由积，但群范畴余极限并不普遍万有。
