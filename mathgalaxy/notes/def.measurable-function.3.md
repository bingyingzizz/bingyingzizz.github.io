# 可测函数　`def.measurable-function`　·　说明
根 `../`

⚠️ **必须的假设是“靶空间带 Borel $\sigma$-代数”**：$\mathbb{R}$ 上的可测性永远是相对于某个 $\sigma$-代数说的；对 $\overline{\mathbb{R}}$（含 $\pm\infty$）也**不必**额外约定：$\{f = +\infty\} = \bigcap_n \{f > n\}$、$\{f = -\infty\} = \bigcap_n \{f \le -n\}$ 由水平集自动可测。
⚠️ **复合可测函数不必然可测**：$f$ 可测、$g$ Borel 可测 $\implies$ $g \circ f$ 可测；但 $g$ 只 Lebesgue 可测时不一定 —— 这是「Borel 可测」与「Lebesgue 可测」必须区分的原因。
