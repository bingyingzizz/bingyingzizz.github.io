# 面积元　`def.area-element`　·　说明
根 `../`

**为什么是 Gram 行列式**：二维平行四边形的面积 = 底乘高，平方之后就是两个向量的 Gram 矩阵的行列式（Lagrange 恒等式）。所以 $\mathrm{d}A$ 就是切映射把参数域面积放大多少倍的因子。

⚠️ **① 单射不能省**：$r$ 正则只保证秩 $2$，推不出单射。反例：圆柱面的参数化 $r(u,v) = (\cos u,\sin u,v)$、$D = (0,4\pi)\times(0,1)$ —— $u$ 绕了两圈，$\int_{D}\mathrm{d}A = 4\pi$，而像的几何面积只有 $2\pi$。所以一般只能把 $\int_{D}\mathrm{d}A$ 叫作像的**计重数面积**；要写等号**不需要**单射：只要重合部分**零测**（像上几乎处处重数为 $1$）等号就成立 —— 单射是**充分不必要**的条件。
