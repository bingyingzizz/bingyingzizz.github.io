# 基与子基　`def.topology-base`　·　说明
根 `../`

**各方向用到的假设**（生成一个拓扑与成为指定拓扑的基必须区别）：
- 是给定 $\mathcal T$ 的基 $\iff$ 每个 $\mathcal T$ 开集为基元并：这是定义展开；从此推出覆盖和局部交条件，用 $X$ 与两基元的交都开。
- 覆盖与局部交条件 $\implies$ 基元任意并构成一个拓扑：有限交用局部加细，其余公理直接核对，不用选择公理，可取全部满足条件的基元。
- 节点列出的两条件不能单独反推是给定 $\mathcal T$ 的基：还须 $\mathcal T$ 等于所生成拓扑。例如离散的两点空间取 $\mathcal B=\{X\}$，满足两条件却不能生成单点开集。
- 子基 $\iff$ 有限交全体为基：按约定是定义展开，有限交应含空交 $X$；通常实数拓扑的基元必须是通常开集，半开区间生成的是另一拓扑。
