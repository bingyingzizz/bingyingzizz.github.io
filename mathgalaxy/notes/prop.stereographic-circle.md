# 球极投影保圆且共形　`prop.stereographic-circle`　·　说明
根 `../`

**保圆性的算法**：球面上的圆是「平面与球面的交线」，即 $ax + by + cw = d$。把球极投影的公式代进去，整理成 $u, v, |z|^{2}$ 的一次式：

$$(d - c)|z|^{2} - 2au - 2bv = (d + c),$$

当 $c \ne d$ 时这是一个圆的方程；$c = d$ 时退化成直线 —— 正好对应「圆过不过北极」。∎

⭐ **保角性的意义**：它说明「在球面上看复分析」与「在平面上看」是同一门学问，只是换了度量。这也是为什么 $\widehat{\mathbb{C}}$ 上的共形结构可以定义成「$z \mapsto 1/z$ 也全纯」—— $1/z$ 正是「绕北极度旋转 180°」在平面上的样子。

⚠️ 定向：球面与平面的定向约定不同，不同教材对「保角还是反保角」的说法会差一个符号。本图只断言「保角（夹角不变）」，定向的事按各书约定。
