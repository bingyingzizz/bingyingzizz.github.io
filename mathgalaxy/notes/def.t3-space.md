# T3 空间　`def.t3-space`　·　说明
根 `../`

⚠️ **$T_{3}$ 推不出 $T_{1}$**（这是本图此前写错、用户当场纠正的那一点）：两个点以上的**不可分拓扑**（开集只有 $\emptyset$ 与 $X$）满足 $T_{3}$ —— 因为唯一的闭集是 $\emptyset$ 与 $X$，$x \notin F$ 时只能 $F = \emptyset$，取 $U = X$、$V = \emptyset$ 即可。而它的单点一般**不是**闭集，所以连 $T_{1}$ 都不是。因此 $T_{3} \implies T_{2}$ 是**假命题**；要「正则空间」（$T_{3} + T_{1}$）才推得出 $T_{2}$。

⭐ **等价形式「$\overline{U} \subseteq W$」是 $T_{3}$ 的真正用法**：它允许把开集**收缩**一点给旁边腾空间。所有「先造开覆盖、再收缩、再取有限子覆盖」的论证（紧性、仿紧性、单位分解）都靠这一手。对照 `prop.normal-locally-closed`（正规空间的同一手法）。
