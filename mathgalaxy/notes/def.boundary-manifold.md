# 带边流形　`def.boundary-manifold`　·　说明
根 `../`

**「内点 / 边界点」为什么与卡无关**：设某张卡给 $\varphi(p)^{n}<0$、另一张给 $\psi(p)^{n} = 0$。

则 $h := \psi\circ\varphi^{-1}$ 是开集之间的微分同胚，把点 $\varphi(p)\in\{x^{n}<0\}$ 送到 $\{x^{n} = 0\}$ 上。

但 $\varphi(p)$ 有一个整个含在 $\{x^{n}<0\}$ 里的开球邻域，其像必含在 $\{x^{n} = 0\}$ 里 —— 而后者没有内点，矛盾。

所以「是不是边界点」属于 $M$，不属于坐标。

**为什么用半空间而不是球**：半空间白送一张坐标（$x^{1},\ldots,x^{n-1}$ 沿边、$x^{n}$ 指向内部），「边界」在坐标里就是一条方程 $x^{n} = 0$，要证的东西一步到位。球模型还得额外证明球面那块是流形，白干一遍。
