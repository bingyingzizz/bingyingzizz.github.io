# 外测度　`def.outer-measure`　·　说明
根 `../`

- **外测度定义在 $\mathcal{P}(X)$ 上**（所有子集），而测度（`def.measure`）只定义在 $\sigma$-代数上 —— 这是外测度作为「构造工具」的全部意义：先在全部子集上给一个粗略的「大小」，再挑出那些「可加」的子集作为可测集。
- **单调 + 可数次可加 不蕴含「对可数并取值等于极限」**：外测度在递增并上只保证 $\mu^{*}(\bigcup A_{n}) \le \lim \mu^{*}(A_{n})$，等式要靠下连续性，而那需要可测性 —— 这正是 Carathéodory 条件要补的东西。

⚠️ 记号：$\mu^{*}$ 上的星号表示「在 $\mathcal{P}(X)$ 上」，不是「关于某个东西的对偶」。有些书用 $m^{*}$、$\nu^{*}$。
