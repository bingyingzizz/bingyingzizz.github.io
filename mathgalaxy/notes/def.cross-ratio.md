# 交比　`def.cross-ratio`　·　说明
根 `../`

**为什么它是不变量**：分式线性变换 $T(z) = (az+b)/(cz+d)$ 可以写成四个点的交比的
复合。直接验算：每个差 $Tz_{i} - Tz_{j} = \dfrac{(ad - bc)(z_{i} - z_{j})}{(cz_{i} + d)(cz_{j} + d)}$，
代进交比的分子分母后，$(ad-bc)$ 与那些 $(cz_{k}+d)$ **成对抵消**，只剩原交比。

⭐ **它是「四点几何」的坐标**：三角形有边长与角，四点就需要一个复数量来刻画 —— 交比取实值/取特定值，分别对应「共圆」与「调和分割」这两件经典的事。

⚠️ 交比的取值依赖**点的次序**：换两个位置会得到 $1/\lambda$、$1-\lambda$ 等六个值，它们是同一个「非调和比」的六种写法。写公式时先把次序钉死。
