# 外测度　`def.outer-measure`　·　说明
根 `../`

- $\mu^{*}(\emptyset) = 0$：**规范化**，只为让后面的 $0 \le \mu^{*}$ 有意义（否则常数 $+\infty$ 也满足后两条）。
- **单调**：**几乎是免费的**，但要用**可数次可加**来推：$B = A \cup (B \setminus A)$ $\implies$ $\mu^{*}(B) \le \mu^{*}(A) + \mu^{*}(B\setminus A)$，所以单调性本身常被列成公理以省去这步；在具体构造（Carathéodory 外测度）里它是直接验证的。
- **可数次可加**：**这才是真条件**，也是唯一有内容的 —— 它把「单点测度」与「可数运算」绑在一起。⚠️ 注意它是**不等式**：外测度**不**可加（对不交并可加才是测度，那是 Carathéodory 可测集上的额外结论）。
