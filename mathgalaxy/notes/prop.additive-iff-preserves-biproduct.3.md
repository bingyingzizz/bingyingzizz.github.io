# 加法函子的刻画　`prop.additive-iff-preserves-biproduct`　·　说明
根 `../`

- **加法** $\iff$ **保零对象与所有直和**：$(\implies)$ 加法函子保双积结构（核-余核对偶给出）；$(\Leftarrow)$ 要**用直和的投影/包含态射**把 $F(f+g) = F(f)+F(g)$ 拼出来 —— 这是四条里唯一需要动手的一步。
- **保所有直和** $\iff$ **保所有有限积**：**这一步完全依赖加法范畴的公理**（有限积自动是双积，于是"保积 = 保余积"）。⚠️ 在一般范畴里这一步是**假的**。
- **保双积**：与上一条同义（双积 = 既是积又是余积）。

⚠️ **「加法范畴」这个假设不能去掉**：$\mathbf{Set}$ 里「保有限积」的函子（如 $X \mapsto X \times X$）并不保余积，更谈不上加法。
⚠️ **「保直和」与「保余积」在加法范畴里才一致**：所以这条命题的准确读法是「在加法范畴之间，保积 = 保余积 = 加法」。
