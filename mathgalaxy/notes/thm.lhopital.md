# L'Hôpital 法则　`thm.lhopital`　·　说明
根 `../`

⭐ 它把「两个都趋于零的东西之比」换成了「导数之比」—— 唯一的依据就是 Cauchy 中值定理，而且是**逆命题式**的使用习惯：先算出导数之比好算，再宣布原比值相等。

⚠ 三个前提不要漏：**不定式**（$0/0$ 或 $\infty/\infty$；$\dfrac{0}{\infty}$ 之类直接是 $0$，用不上它）、$g' \ne 0$、右边那个极限**存在**。最后一个最要命：$\lim f'/g'$ 不存在时，右边不等于左边 —— 除了不能说，什么都不能说（典型：$f = x + \sin x$、$g = x$）。

⚠ 「$\infty/\infty$ 型」的证明比 $0/0$ 型麻烦一些（要先用 $g$ 的单调性做截断），但结论一样。
