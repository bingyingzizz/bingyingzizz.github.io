# 一致连续　`def.uniform-continuity`　·　说明
根 `../`

⭐ 一句话：连续是「每一点各自有一个 $\delta$」，一致连续是「有一个 $\delta$ 通吃全 $X$」。

⚠ 两者**不等价**：$f(x) = x^{2}$ 在 $\mathbb{R}$ 上连续，但取 $x = n$、$x' = n + 1/n$ 就有 $|f(x) - f(x')| = 2 + 1/n^{2} > 2$，无论 $\delta$ 多小都能撞上 —— 所以它不一致连续。$f(x) = 1/x$ 在 $(0, 1)$ 上同理。

⭐ 紧集上两者**重合**（Cantor 定理）—— 这就是为什么初等微积分里可以只谈连续却随手用一致连续的性质。

⭐ 一致连续是后面一切「把极限搬进积分 / 导数」的通行证：一致收敛的函数列才保连续、保积分。
