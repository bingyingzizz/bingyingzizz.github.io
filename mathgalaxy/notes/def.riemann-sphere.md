# 扩充复平面与球极投影　`def.riemann-sphere`　·　说明
根 `../`

**为什么值得单独定义一个点**：很多结论（分式线性变换把圆映成圆、Riemann 映射定理、交比）在「只是 $\mathbb{C}$」的时候都要分情形讨论，补上 $\infty$ 之后只剩一种情形 —— 直线就是过 $\infty$ 的圆，$1/z$ 就是 $\mathbb{C}$ 上无处不定义的有理映射。

**公式怎么来的**：过 $N$ 与球面上点 $(x,y,w)$ 的直线参数化为 $N + t((x,y,w) - N)$，令第三坐标为 $0$ 解出 $t$，即得 $2(x,y)/(1-w)$；再把 $|z|^{2}$ 与 $w$ 联立就得到上面的整齐形式（用 $x^{2}+y^{2}+w^{2}=1$ 化简）。

⚠️ 这里补的 $\infty$ 是**一个点**，不是 $+\infty$ 与 $-\infty$ 两个（那是一维实轴的做法，见 `def.extended-real`）。复数没有「符号」，所以只有一个无穷远点。
