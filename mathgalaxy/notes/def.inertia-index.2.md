# 惯性指数　`def.inertia-index`　·　说明
根 `../`

**各方向用到的假设**（实对称型的符号计数依赖惯性定理）：
- 已有合同对角形 $\implies$ 按正负零计数：这是定义展开；计数不依赖对角化方式则是 Sylvester 惯性定理，并非定义免费保证。
- 实对称矩阵 $\implies$ 可对角化并计数：有限维实谱定理足够；合同不变性还可用正定子空间的最大维数及维数交公式证明。
- $p=n$ $\iff$ 正定、$q=0$ $\iff$ 半正定：在合同对角形中逐项检查，再用可逆换元保持二次型取值。
- 固定维数下同一 $(p,q)$ $\implies$ 合同：把非零对角元用正实数平方根归一化；复对称型无正负之分，例如一维的 $[1]$ 与 $[-1]$ 在复数上合同。
