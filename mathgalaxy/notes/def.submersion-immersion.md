# 浸入 / 淹没 / 嵌入　`def.submersion-immersion`　·　说明
根 `../`

⭐ 三者都是「用 Jacobi 矩阵的秩说话」的条件。秩定理（`cor.rank-theorem`）说明它们分别是两种标准形：
- 浸入的局部标准形 $x \mapsto (x, 0)$（把 $\mathbb{R}^{n}$ 直接放进去，局部是一张「平的」子集）；
- 淹没的局部标准形 $x \mapsto (x_1, \ldots, x_m)$（局部是投影）。

⭐ 浸入是「局部嵌入」，允许自交：平面里的 $\infty$ 字形曲线（参数化 $t \mapsto (\sin 2t, \sin t)$）处处是浸入，但在自交点处不是单射，所以不是嵌入。

⚠ 「浸入 / 淹没」是**逐点的局部**性质（只需一点处秩满）；「嵌入」查的是**整体**性质（到像上的同胚）。把这两类混起来是初学流形时最主要的错误来源 —— 例如「$f$ 是单射浸入」并不自动是嵌入（像上拓扑可能更细）。
