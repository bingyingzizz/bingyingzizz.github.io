# 环　`def.ring`　·　说明
根 `../`

**各方向用到的假设**（这里是公理定义，交换与单位元是额外要求）：
- 环 $\iff$ 加法阿贝尔群、乘法结合、左右分配：本节点约定的定义展开，无需选择公理，亦不要求域或 PID。
- 交换环 $\implies$ 环、含幺环 $\implies$ 环：只忘掉附加结构；逆向均非免费，$M_2(\mathbb{R})$ 不交换，$2\mathbb{Z}$ 按通常乘法无单位元。
- 加上乘法交换 $\iff$ 交换环，加上单位元及本库的 $1\ne0$ 要求 $\iff$ 含幺环：仍是定义；这里的含幺环不自动要求乘法交换。
- 域 $\implies$ 交换含幺环：展开域公理即可；反向还要每个非零元可逆，$\mathbb{Z}$ 是反例。零环满足环公理，但不满足本节点含幺环的 $1\ne0$ 约定。
