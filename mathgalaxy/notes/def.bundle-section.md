# 丛的截面　`def.bundle-section`　·　说明
根 `../`

**三个最重要的例子**：$\Gamma(TM) = \mathfrak{X}(M)$（向量场）；$\Gamma(T^{\ast}M) = \Omega^{1}(M)$（$1$-形式）；

$E = M \times \mathbb{R}$ 时 $\Gamma(E) = C^{\infty}(M)$（函数）。

所以「函数是平凡线丛的截面」是这一族里最平凡的成员，却最能说明问题：截面是**带纤维结构的函数**。

**为什么强调是模**：$\Gamma(E)$ **本身就是实向量空间**（逐点加法、实数倍），但它更是 $C^{\infty}(M)$-**模** —— 系数乘法是光滑函数，不只是实数。所以「模」是比「向量空间」多出来的那一层结构。这条区别在「$\mathrm{d}$ 只作用在形式上、不作用在向量场上」那里又出现一次。

**「有没有处处非零的截面」是整体问题**：Möbius 带没有（走一圈翻号）；$TS^{2}$ 的截面必有零点（毛球定理）；一般线丛有处处非零截面，当且仅当它平凡。这是**障碍**类问题，与局部毫无关系 —— 与「局部总有非零截面」形成对照。
