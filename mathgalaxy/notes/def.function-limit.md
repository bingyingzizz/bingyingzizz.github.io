# 函数极限　`def.function-limit`　·　说明
根 `../`

⭐ 与**数列**极限的区别只有一处：这里自变量是连续地靠近的，所以要有一层额外的量词 $\delta$ 管住「多近才算够近」。$\varepsilon$-$\delta$ 语言的全部新意就在这个双层量词上。

⚠ **去心**是必须的：$x = x_0$ 那一点不参与极限，所以 $f$ 在 $x_0$ 处有没有定义、取值是多少，都不影响这个极限。也正因为如此，「极限存在且恰好等于 $f(x_0)$」才能拿来当**连续**的定义。

⚠ 极限若存在则唯一 —— 这一条与数列版证法相同（取两点各用一半 $\varepsilon$）。
