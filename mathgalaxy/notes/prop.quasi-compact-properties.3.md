# 拟紧的性质　`prop.quasi-compact-properties`　·　说明
根 `../`

**各方向用到的假设**（有限覆盖判据依赖站点覆盖与层覆盖的对应）：
- 第 1 条两个方向均需站点与其层范畴的覆盖比较，把可表示对象理解为层化后的表示预层；在次标准情形才可不写层化。这是覆盖比较，不能单靠改名证明。
- 第 2 条从有限拟紧覆盖推出拟紧：将任意覆盖拉回各块、分别取有限子族，再用覆盖的传递性；无限离散空间的单点覆盖说明“有限”不能删。
- 第 3 条正向：可表示层生成层范畴给出满覆盖，拟紧性抽有限支，有限余积把它们合成一个 $X$；最后一步用预标准拓扑下保有限余积。
- 第 3 条反向：$h_X\to F$ 满且 $h_X$ 拟紧时，拉回覆盖并取有限子族，再由满性下降覆盖。关键是该拓扑下可表示层拟紧；任意站点不能免费假定这一点，例如非拟紧拓扑空间的终层。
