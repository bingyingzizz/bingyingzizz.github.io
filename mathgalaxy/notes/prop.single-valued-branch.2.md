# 单值支的存在判据　`prop.single-valued-branch`　·　说明
根 `../`

**各方向用到的假设**（对数分支判据要求区域避开原点，单连通只是充分条件）：
- 单值支 $\iff$ 连续选择每点的值：这是定义展开；对数三条件的等价则要求 $D\subset\mathbb C\setminus\{0\}$，否则 $1/z$ 无定义。
- (1) $\implies$ (2) $\implies$ (3)：对 $e^f=z$ 求导得 $f'=1/z$，再用原函数的积分基本定理；不要求单连通。
- (3) $\implies$ (2)：用区域的道路连通性及闭路积分为零保证路径积分与路径无关，再由被积函数全纯求导。
- (2) $\implies$ (1)：$ze^{-f}$ 导数为零，由连通性为非零常数，调整一个常数即可；这是构造，不是定义展开。
- 单连通且避开零 $\implies$ (3) 用 Cauchy 积分定理；环域 $1<|z|<2$ 有积分 $2\pi i$ 的闭路而无对数分支。单连通非必要，例如右半平面删去一点仍可限制主值对数。
