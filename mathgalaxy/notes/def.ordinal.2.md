# 序数　`def.ordinal`　·　说明
根 `../`

**各方向用到的假设**（序数定义不需要选择公理，序型代表的存在另需构造）：
- 是 von Neumann 序数 $\iff$ 传递且被成员关系良序：两方向是定义展开，不用选择公理；对序数约定 $\alpha<\beta\iff\alpha\in\beta$ 也是记号定义。
- 序数的元素仍是序数：继承良序，并利用母集合上成员关系的传递性证明元素是传递集；不能仅凭一般传递集推出其元素也传递。
- 良序集 $\implies$ 存在唯一同序型序数：用良基递归构造及替代公理收集像，不是定义展开，也不需要把任意集合良序化的选择公理。
- 传递性不能删：$\{\{\emptyset\}\}$ 的成员关系是单点良序但该集合不传递；良序条件不能删：$\{0,1,\{1\}\}$ 是传递集，但 $0$ 与 $\{1\}$ 在成员关系下不可比。
