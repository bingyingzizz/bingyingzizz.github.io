# 单态射 / 满态射 / 同构　`def.mono`　·　说明
根 `../`

则 $f \circ (g \circ f) = (f \circ g) \circ f = 1_{Y} \circ f = f = f \circ 1_{X}$，由 $f$ 单态射得 $g \circ f = 1_{X}$，故 $f$ 是同构 ✓。

把箭头全部反向，得到对偶说法：$f$ 是同构 $\iff$ $f$ 是满态射且有**收缩**。

⚠️ 「单态射 $+$ 满态射」**不够**：环范畴里 $\mathbb{Z} \to \mathbb{Q}$ 既单又满，却不是同构 —— 还差一个截面（或收缩）。
