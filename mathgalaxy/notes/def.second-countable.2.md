# 第二可数空间　`def.second-countable`　·　说明
根 `../`

- **第二可数 $\implies$ 第一可数**：可数基本身在每个点给出可数局部基。**不需要额外假设**。
- **第二可数 $\implies$ 可分**：从每个基成员里挑一点，得到可数稠密集。⚠️ 这一步**用到可数选择**（若基成员为空则跳过，通常无碍）。
- **可分 $\not\implies$ 第二可数**：反例是 Sorgenfrey 直线（可分、第一可数，但不是第二可数）。
- **可分 + 可度量化 $\implies$ 第二可数**：这条才让「第二可数」在度量空间里等价于可分，**证明要用度量化**（取可数稠密集、半径 $1/n$ 的球）。

⚠️ 一句话：**第二可数是“全局可数”，第一可数是“局部可数”**；度量空间里两者都可分等价，一般拓扑里不行。
