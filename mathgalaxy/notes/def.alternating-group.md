# 符号与交错群　`def.alternating-group`　·　说明
根 `../`

⭐ 符号是 $S_n$ 到 $\{\pm 1\}$ 的**唯一**非平凡同态（$n \ge 3$），所以 $A_n$ 是 $S_n$ 的**唯一**指数 $2$ 子群 —— 这个唯一性是后面「$S_n$ 不单」以及 Galois 理论里「二次子扩张唯一」的来源。

⭐ 乘积公式为什么干净：每一项 $\frac{\sigma(j)-\sigma(i)}{j-i}$ 的分母固定、分子只是把同一批差重新排列，故乘积的符号只取决于 $\sigma$ 引起的排列的奇偶性。这也顺手证明了「奇偶性与分解无关」。

⚠ 边界：$n = 1$ 时 $A_1 = S_1$ 是平凡群，$|A_n| = n!/2$ 不适用。$n = 2$ 时 $A_2 = \{e\}$。

⭐ **单性的跳变**：$A_4$ 不单（有正规子群 $V_4 = \{e, (12)(34), (13)(24), (14)(23)\}$），而 $A_5$ **单**且非阿贝尔。这个跳变正是 $S_n$ 可解性的分界线（`prop.sn-solvable`）。
