# Stonean 上 Z[S] 的 RHom　`prop.rhom-zs-sections`　·　说明
根 `../`

**证明。** $S$ Stonean 时 $\mathbb{Z}[S]$ 是**投射**对象：极不连通性给出闭开集上的「截面型」投影性，$\mathbb{Z}[S]$ 是那些 $\mathbb{Z}[C]$（$C$ 闭开）的余极限，投影性沿余极限保持 ✓。于是
$$\operatorname{Hom}_{\mathbb{Z}}\bigl(\mathbb{Z}[S],\ -\bigr) = \Gamma(S, -) = \bigl(N \mapsto N(S)\bigr)$$
是**正合**函子，它的右导出函子集中在 $0$ 次、且 $R^{0} = \Gamma(S,-)$ ✓。因此 $\operatorname{RHom}(\mathbb{Z}[S], N)$ 就等于 $\operatorname{Hom}(\mathbb{Z}[S], N) = N(S)$（集中在 $0$ 次的复形）✓。∎

⭐ 与「Stonean 上凝聚态阿贝尔群零调」是同一件事的两种说法：**系数零调 $\iff$ 测试对象 $\mathbb{Z}[S]$ 投射**。
