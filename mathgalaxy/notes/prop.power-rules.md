# 指数律与幂的单调性　`prop.power-rules`　·　说明
根 `../`

⭐ 三条指数律都是「对 $n$ 归纳」，没有技巧。

真正有用的是**单调性**：$a > 1$ 时 $n \mapsto a^{n}$ 严格递增，所以 在**阿基米德有序域**（如 $\mathbb{R}$）里，$q^{n} \to 0$（$0 < q < 1$）可以写成 $q^{n} \le 1/(1+nh)$ 再夹逼（一般有序域不成立：$\mathbb{Q}(t)$ 里 $t$ 无穷大，$q = 1/2$ 的幂永远不小于 $1/t$） —— 几何级数收敛的证明就靠这一条。

⚠ 负指数那半边要先把 $a^{-n}$ 写成 $(a^{-1})^{n}$，再用**正指数**的结论；

交换性在这里是必需的（$(ab)^{-1} = b^{-1}a^{-1} = a^{-1}b^{-1}$ 只在交换时成立）。
