# 逆映射定理（Banach 版）　`thm.inverse-function-banach`　·　说明
根 `../`

⭐ 与有限维版本（`thm.inverse-function`）的差别**只有一处，但很关键**：有限维时「$Df(a)$ 可逆」自动蕴含「逆有界」（有限维空间上的线性映射自动有界，故可逆即有界逆）；**无限维时必须把它写进条件**。「拓扑线性同构」= 线性双射 + 逆连续，缺一不可。

⭐ 证明比有限维多两步，都是 Banach 空间特有的：
- **Neumann 级数**：$\|S\| < 1$ 时 $(I - S)^{-1} = \sum_{k \ge 0} S^{k}$（级数在算子范数下收敛，靠的是 $\mathcal{L}(E, F)$ 的完备性）。这一步把「接近恒等的算子」求逆，是化归 $Df(a) = I$ 的关键；
- **中值不等式**：$\|f(x) - f(y)\| \le \sup_{[x,y]} \|Df\| \cdot \|x - y\|$（`thm.mean-value-multi`），用来把 $\Phi_y$ 弄成压缩映射。

⚠ 这是**泛函分析 / 凝聚态数学真正用的形式**：那里的对象是 $C(S)$、$L^{p}$、Fréchet 空间、紧 Hausdorff 上的连续函数群，有限维版本不够用（例如 8.2 节里 $C(S, M)$ 的局部同构论证）。
