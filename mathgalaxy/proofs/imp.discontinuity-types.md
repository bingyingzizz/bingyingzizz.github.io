# imp.discontinuity-types

`def.limit-point` 聚点 + `def.continuous` 连续（ε-δ 判据） + `def.interior` 内部 → `prop.discontinuity-types` 间断点分类

**证明**（分类是穷尽的）。

在间断点 $x_0$ 处，每个单侧极限只有两种状态：存在且有限，或不存在 / 为无穷。

于是「两个单侧极限都有限」与「至少一个不满足」互斥且穷尽，前者再按两侧极限是否相等分成可去与跳跃两类 —— 三种情形互斥且已列出全部可能。
