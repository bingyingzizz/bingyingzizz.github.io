# 阶给出统一的 $p$，Jensen 给出零点密度
`e29.implication` · 推出 · strong 边 · 根 `../`

`thm.weierstrass-product` Weierstrass 乘积定理 + `prop.jensen` Jensen 公式 + `prop.single-valued-branch` 单值支的存在判据 + `thm.cauchy-inequality` Cauchy 不等式 + `lem.schwarz` Schwarz 引理 → `thm.hadamard-factorization` Hadamard 分解定理

**指数是多项式**：$\Phi = e^{h}$（`prop.single-valued-branch`），$\operatorname{Re} h = \log|\Phi| = O(r^{\rho+\varepsilon})$。对 $h$ 用 Borel–Carathéodory 不等式（由 Cauchy 不等式加实部控制），得 $|h(z)| = O(r^{\rho+\varepsilon})$，于是 $h$ 的 Taylor 系数在 $\deg > \rho$ 时全为零。
