# 让交比相等，就解出了唯一的三点映射
`e93.implication` · 推出 · strong 边 · 根 `../`

`def.cross-ratio` 交比 → `prop.mobius-three-points` 三点决定分式线性变换

设 $T$ 满足要求。由交比不变性，对任意 $z$

$$(z, z_{1}; z_{2}, z_{3}) = (Tz, w_{1}; w_{2}, w_{3}).$$

左端是 $z$ 的已知一次分式，右端是 $w = Tz$ 的一次分式。把右端当方程解出 $w$，得到的分式定义了 $T$（存在性）。

唯一性：若 $T_{1}, T_{2}$ 都行，则 $S = T_{1}^{-1}T_{2}$ 固定 $z_{1}, z_{2}, z_{3}$；但 $Sz$ 与 $z$ 对同样三点有相同交比，故 $Sz = z$，即 $S$ 是恒等。∎

> 「三点定变换」既给出存在性，也给了算法。
