# 绕数 = $\frac{1}{2\pi i}\oint \mathrm{d}z/(z-a)$
`e5.implication` · 推出 · strong 边 · 根 `../`

`def.winding-number` 绕数 + `def.contour-integral` 复围道积分 → `prop.winding-integral` 绕数的积分表示

平移使 $a = 0$。令 $\varphi(t) := \int_{0}^{t} \gamma'(s)/\gamma(s)\,\mathrm{d}s$。则

$$\frac{\mathrm{d}}{\mathrm{d}t}\left(\gamma(t)e^{-\varphi(t)}\right) = e^{-\varphi}\left(\gamma' - \varphi'\gamma\right) = 0,$$

故 $\gamma(t)e^{-\varphi(t)} \equiv \gamma(0)$，即 $e^{\varphi(t)} = \gamma(t)/\gamma(0)$。取 $t = 1$：$\gamma(1) = \gamma(0)$ 给出 $e^{\varphi(1)} = 1$，于是 $\varphi(1) \in 2\pi i\mathbb{Z}$。

$\varphi(1) = \oint_{\gamma}\mathrm{d}z/z$，而 $\varphi(1)/(2\pi i)$ 关于 $a$ 连续、取整数值、且在 $a$ 远离曲线时等于 $0$ —— 正是 `def.winding-number` 里那个「绕几圈」的整数。∎

> 几何量换成积分，是后面辐角原理能算零点个数的技术前提。
