# imp.weak-hausdorff-qseparated
`imp.weak-hausdorff-qseparated` · 推出 · strong 边 · 根 `../`

`def.weak-hausdorff` 弱 Hausdorff 空间 + `def.condensed-set` 凝聚态集 + `def.fibered-product` 纤维积 / 纤维余积 + `def.chaus` 紧 Hausdorff 空间范畴 → `lem.weak-hausdorff-qseparated` 弱 Hausdorff 推出 拟分离

**证明。** 不妨设 $X$ 紧生成（弱 Hausdorff 的 $k$-化不改变结论）。对 $i = 1, 2$，由拟紧性取紧 Hausdorff 空间 $S_{i}$ 与满态射 $S_{i} \twoheadrightarrow X_{i}$（「拟紧 $\iff$ 有从自由紧 Hausdorff 的满射」）。于是有满态射
$$S_{1} \times_{X} S_{2} \twoheadrightarrow X_{1} \times_{X} X_{2},$$
（纤维积保满射）。
