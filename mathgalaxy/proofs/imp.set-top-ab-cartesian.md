# imp.set-top-ab-cartesian
`imp.set-top-ab-cartesian` · 推出 · strong 边 · 根 `../`

`thm.arbitrary-product` 任意族笛卡尔积存在 → `prop.set-top-ab-complete` Set、Top、Ab 的完备性

在 $\mathbf{Set}$ 中，任意小族的积取任意族笛卡尔积（`thm.arbitrary-product`；有限族时由 `thm.product` 反复取二元积得到）；配合等化子即得所有小极限。这正是该命题中 $\mathbf{Set}$ 完备性论证的第一步。$\blacksquare$
