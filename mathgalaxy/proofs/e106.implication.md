# 把「平面与球面相交」翻译成 $u, v, |z|^{2}$ 的方程
`e106.implication` · 推出 · strong 边 · 根 `../`

`def.riemann-sphere` 扩充复平面与球极投影 → `prop.stereographic-circle` 球极投影保圆且共形

球面上的圆是某个平面与 $S^{2}$ 的交：$ax + by + cw = d$（$a, b, c, d \in \mathbb{R}$，且与球面确实相交）。

代入球极投影公式：$x = 2u/(1 + |z|^{2})$、$y = 2v/(1 + |z|^{2})$、$w = (|z|^{2} - 1)/(1 + |z|^{2})$，两边乘 $1 + |z|^{2}$ 得

$$2au + 2bv + c(|z|^{2} - 1) = d(1 + |z|^{2}).$$

整理得 $(c - d)|z|^{2} + 2au + 2bv + (c + d) = 0$。$c \ne d$ 时这是圆（配平方即可）；$c = d$ 时二次项消失，剩下一次方程 —— 直线。平面过北极 $N$ 恰好等价于 $c = d$（把 $N$ 的坐标代进平面方程即得）。

**保角**：球极投影的 Jacobi 在两个切向量上只差一个正纯量因子（算一下即知），故夹角不变。∎

> 「球面上的圆 $\to$ 平面上的圆或直线」就是保圆性的来源。
