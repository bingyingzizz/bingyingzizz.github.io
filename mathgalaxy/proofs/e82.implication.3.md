# $0$-链的边界恰好是「同一分支里两点之差」
`e82.implication` · 推出 · strong 边 · 根 `../`

`def.singular-homology` 奇异同调群 → `prop.h0-components` H₀ 与分支

故 $H_{0}(X) \cong \bigoplus_{\pi_{0}(X)} \mathbb{Z}$。

**约化版**：$\varepsilon(\sum n_{x} x) = \sum n_{x}$，且 $\varepsilon\partial_{1} = 0$ 说明 $B_{0} \subseteq \ker\varepsilon$。于是 $\tilde{H}_{0} = \ker\varepsilon / B_{0} \cong \bigoplus_{\pi_{0}(X)} \mathbb{Z} \big/ \mathbb{Z}\cdot(\text{对角})$，秩为 $\#\pi_{0}(X) - 1$。

特别地 $\tilde{H}_{0} = 0 \iff \#\pi_{0} = 1 \iff X$ 道路连通。

∎

> 整条论证只用到「$\partial$ 作用在一条道路上给出两端之差」这一个事实。
