# 对角线段 + 有限 ε-网 $\implies$ 一致收敛子列
`e10.implication` · 推出 · strong 边 · 根 `../`

`thm.bolzano-weierstrass` Bolzano–Weierstrass 定理 + `def.uniform-convergence` 一致收敛 → `thm.arzela-ascoli` Arzelà–Ascoli 定理

$$|g_{k}(x) - g_{l}(x)| \le |g_{k}(x) - g_{k}(x_{j})| + |g_{k}(x_{j}) - g_{l}(x_{j})| + |g_{l}(x_{j}) - g_{l}(x)| < 3\varepsilon.$$

故 $g_{k}$ 一致 Cauchy，收敛。∎

> 等度连续性把「逐点收敛」升级成「一致收敛」—— 这正是全纯族免费得到的东西。
