# 正规族 + 极值元 + 平方根技巧：映满圆盘
`e13.implication` · 推出 · strong 边 · 根 `../`

`thm.montel` Montel 定理 + `thm.hurwitz` Hurwitz 定理 + `lem.schwarz` Schwarz 引理 → `thm.riemann-mapping` Riemann 映射定理

**极值元存在**：Cauchy 不等式给出 $|\varphi'(z_{0})| \le 1/\operatorname{dist}(z_{0}, \partial\Omega)$，故 $s := \sup |\varphi'(z_{0})| < \infty$。取 $\varphi_{n}$ 逼近 $s$；族一致有界于 $\mathbb{D}$，**Montel**（`thm.montel`）给出内闭一致收敛子列，极限 $f$ 全纯、$f(z_{0}) = 0$、$|f'(z_{0})| = s$。

**极限仍单叶**：若 $f(z_{1}) = f(z_{2})$（$z_{1} \ne z_{2}$），考虑 $f - f(z_{1})$，它在 $z_{1}$ 处有零点；由 **Hurwitz**（`thm.hurwitz`），$\varphi_{n} - f(z_{1})$ 对大的 $n$ 也在 $z_{1}$ 附近有零点，结合 $\varphi_{n}(z_{2}) \to f(z_{2}) = f(z_{1})$ 得 $\varphi_{n}$ 取重值，矛盾。
