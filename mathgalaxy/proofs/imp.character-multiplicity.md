# 重数公式
`imp.character-multiplicity` · 推出 · strong 边 · 根 `../`

`thm.character-orthogonality` 不可约特征标的正交性 + `prop.character-operations` 特征标的运算 + `def.semisimple-representation` 半单表示 → `cor.character-multiplicity` 重数由特征标内积给出

由 $V$ 半单，$\chi_V=\sum_j n_j\chi_{V_j}$。
与 $\chi_{V_i}$ 作内积，并用正交性：$\langle\chi_V,\chi_{V_i}\rangle=\sum_j n_j\langle\chi_{V_j},\chi_{V_i}\rangle=n_i$。$\blacksquare$
