# Cauchy 准则 $\implies$ $\mathbb{R}$ 完备
`imp.cauchy-complete` · 推出 · strong 边 · 根 `../`

`thm.cauchy-criterion` Cauchy 收敛准则 → `thm.real-complete-metric` ℝ 是完备度量空间

把 Cauchy 准则的结论**逐字**翻译成距离空间的语言：$\mathbb{R}$ 中的 Cauchy 列（即 $\forall \varepsilon > 0, \exists N, \forall m, n \ge N : d(x_m, x_n) < \varepsilon$）都收敛，这恰恰就是「$(\mathbb{R}, d)$ 完备」的定义。故不需要新的论证。∎

> 这条边的作用是把两套语言对上：**序**那一侧的「确界原理」与**度量**那一侧的「完备」在 $\mathbb{R}$ 上说的是同一件事。
