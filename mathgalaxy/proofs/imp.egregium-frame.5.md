# imp.egregium-frame
`imp.egregium-frame` · 推出 · strong 边 · 根 `../`

`def.gauss-curvature` Gauss 曲率 + `def.curvature-tensor` Riemann 曲率张量 + `prop.christoffel-frame` 标架下的联络系数 → `thm.theorema-egregium` 绝妙定理

这时单位球面可以直接验算：取测地极坐标，$\omega^{1} = \mathrm{d}\rho$、$\omega^{2} = \sin\rho\,\mathrm{d}\theta$、$\omega^{1}_{2} = -\cos\rho\,\mathrm{d}\theta$，于是 $\mathrm{d}\omega^{1}_{2} = \sin\rho\,\mathrm{d}\rho\wedge\mathrm{d}\theta = +\omega^{1}\wedge\omega^{2}$，即 $K = 1$；

同时 $\omega^{1}_{3} = \omega^{1}$、$\omega^{2}_{3} = \omega^{2}$，$h_{ij} = \delta_{ij}$、$\det = 1$ ✓。

换另一支约定（$\omega^{i}_{j}$ 整体反号）时，证明里所有 $\omega^{i}_{j}$ 一起反号、$K$ 的符号随之统一反号，「$K$ 内蕴」这个结论不变。
