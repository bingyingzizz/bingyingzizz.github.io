# 一致等度连续 + 逐点全有界 $\implies$ 全有界
`imp.fa-ascoli` · 推出 · strong 边 · 根 `../`

故 $\Phi$ 是 $\mathcal{H}$ 的有限 $\varepsilon$-网，$\mathcal{H}$ 全有界。$\blacksquare$
