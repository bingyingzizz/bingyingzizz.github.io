# 正规族 + 极值元 + 平方根技巧：映满圆盘
`e14.implication` · 推出 · strong 边 · 根 `../`

`thm.montel` Montel 定理 + `thm.hurwitz` Hurwitz 定理 + `lem.schwarz` Schwarz 引理 + `prop.single-valued-branch` 单值支的存在判据 + `thm.cauchy-inequality` Cauchy 不等式 + `def.mobius` 分式线性变换 + `thm.weierstrass-convergence` Weierstrass 收敛性定理 → `thm.riemann-mapping` Riemann 映射定理

**满射**：若漏掉 $w_{1} \in \mathbb{D}$，令 $\psi_{0}$ 是 $\mathbb{D}$ 的自同构把 $w_{1}$ 送到 $0$，取 $\sqrt{\psi_{0} \circ f}$ 的分支 $h$（$0 \notin$ 像保证可取），再令 $\psi := \psi_{1} \circ h$ 把 $h(z_{0})$ 送回 $0$。

计算给出 $|\psi'(z_{0})| = |f'(z_{0})|\cdot\frac{1 + |w_{1}|}{2\sqrt{|w_{1}|}} > s$，与 $s$ 的极大性矛盾。

**唯一性**：若 $f, g$ 都满足条件，则 $g \circ f^{-1} : \mathbb{D} \to \mathbb{D}$ 固定 $0$、导数正实数，由 **Schwarz 引理**为恒等。∎

> 本图里最深的一条；证明的三根支柱（Montel / Hurwitz / Schwarz）都各自是独立节点。
