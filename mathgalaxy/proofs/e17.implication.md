# 法向—偏移参数化 + Borsuk–Ulam $\implies$ 同一个平面平分三块
`e17.implication` · 推出 · strong 边 · 根 `../`

`thm.borsuk-ulam` Borsuk–Ulam 定理（二维） → `thm.ham-sandwich` 火腿三明治定理

平面写作 $P(u, t) = \{\, x : \langle x, u\rangle = t \,\}$，$u \in S^{2}$，$t \in \mathbb{R}$。

**对固定 $u$**：$t \mapsto \operatorname{vol}(A_{i} \cap \{\langle x, u\rangle \le t\})$ 连续、单调、从 $0$ 到 $\operatorname{vol}(A_{i})$，故存在（不唯一时取最小的）$t_{i}(u)$ 使两侧体积相等。又 $t_{i}(-u) = -t_{i}(u)$：法向反向时「正侧」互换，而平分平面本身不变。

**取差**：$F(u) := (t_{1}(u) - t_{3}(u),\ t_{2}(u) - t_{3}(u))$ 连续，且 $F(-u) = -F(u)$（奇）。由 **Borsuk–Ulam**（`thm.borsuk-ulam`），存在 $u$ 使 $F(u) = F(-u) = -F(u)$，故 $F(u) = 0$，即 $t_{1}(u) = t_{2}(u) = t_{3}(u)$。同一个平面 $P(u, t_{1}(u))$ 平分三块。∎

> 整条链的终点：从「数零点」一路推到「切三明治」。
