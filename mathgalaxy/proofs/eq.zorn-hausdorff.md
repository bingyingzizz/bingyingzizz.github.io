**佐恩引理 ⇒ Hausdorff 极大原理（路线 2⟹3）**

设 $(P, \preceq )$ 是偏序集，$C_{0} \subseteq P$ 是链。令

$$\mathcal{C} = \{ C \subseteq P : C\text{ 是链} \}$$

按包含关系 $\subseteq$ 排序。给定 $C_{0}$ 时改用 $\mathcal{C}_{0} = \{ C \in \mathcal{C} : C \supseteq C_{0} \}$，它非空（$C_{0} \in \mathcal{C}_{0}$）。
