# 代数基本定理给出 $\mathbb{C}$ 上特征多项式的 $n$ 个根
`imp.derived-charpoly-splits` · 推出 · strong 边 · 根 `../`

`thm.fundamental-algebra` 代数基本定理 → `def.char-poly` 特征多项式

**顺带**：把两边的系数对比（Vieta），得 $\sum_j \lambda_j = \operatorname{tr}T$、$\prod_j \lambda_j = \det T$ —— 即「迹 = 特征值之和、行列式 = 特征值之积」，不必真的解出特征值。$\blacksquare$

> 只在 $K = \mathbb{C}$ 上成立：$\mathbb{R}$ 上特征多项式未必分裂（平面旋转没有实特征值），那里的 $n$ 个根只能在扩域里凑齐。
