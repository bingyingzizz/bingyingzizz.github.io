# 反证：奇映射的度既是奇数又必须是 0
`e16.implication` · 推出 · strong 边 · 根 `../`

`thm.brouwer-fixed-point` Brouwer 不动点定理（圆盘） → `thm.borsuk-ulam` Borsuk–Ulam 定理（二维）

设连续 $f : S^{2} \to \mathbb{R}^{2}$ 满足 $f(x) \ne f(-x)$ 处处成立。令

$$g(x) := \frac{f(x) - f(-x)}{|f(x) - f(-x)|} \in S^{1},$$

则 $g$ 连续且 $g(-x) = -g(x)$（奇映射）。

**第一步**：把 $g$ 限制到赤道 $S^{1} \subset S^{2}$，得连续奇映射 $\bar g : S^{1} \to S^{1}$。奇映射在 $S^{1}$ 上的**度**必为奇数：由 $\bar g(e^{i(t+\pi)}) = -\bar g(e^{it})$ 可提升为 $\theta(t + \pi) = \theta(t) + \pi + 2k\pi$，故 $\theta(t + 2\pi) = \theta(t) + 2\pi + 4k\pi$，度为 $1 + 2k$。

**第二步**：$\bar g$ 可延拓到上半球面（$g$ 本来就定义在整个 $S^{2}$ 上），而可延拓到圆盘上的映射度为 $0$（延拓给出同伦到常值）。
