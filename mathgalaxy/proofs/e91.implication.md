# 对称点是反演：$z^{*} = a + R^{2}/\overline{(z - a)}$
`e91.implication` · 推出 · strong 边 · 根 `../`

`def.mobius` 分式线性变换 + `prop.conformal-iff` 保角性 → `def.symmetric-point` 关于圆的对称点

由 `def.mobius`，$z \mapsto a + R^{2}/\overline{(z - a)}$ 是「平移 + 反演 + 伸缩」的复合，其中 $z \mapsto 1/\bar z$ 是共轭再取倒数，属于反全纯的分式映射。

**保角性的对照**：`prop.conformal-iff` 说全纯 + 导数非零 = 保角且保定向；而反演是**反全纯**的，保角但**反定向**。对称点正是在这个反全纯映射下与 $z$ 配对，所以「关于圆对称」与「关于直线镜像」是同一件事的两种外观（直线 = 过 $\infty$ 的圆）。

**验算**：$|z - a|\,|z^{*} - a| = |z - a| \cdot R^{2}/|z - a| = R^{2}$，且 $z^{*} - a$ 与 $z - a$ 同向（因为取了共轭再取倒数只改模长不改方向）。∎

> 对称 $\ne$ 到圆心等距；对称是反演，距离的**乘积**固定。
