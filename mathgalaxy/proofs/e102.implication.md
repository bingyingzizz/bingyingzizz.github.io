# 共轭到不动点上，读特征值的比
`e102.implication` · 推出 · strong 边 · 根 `../`

`def.mobius` 分式线性变换 + `prop.mobius-group` 分式线性变换成群 → `prop.mobius-classification` 分式线性变换的分类

**第一步：共轭。** 分式线性变换 $T$ 的不动点是二次方程 $cz^{2} + (d - a)z - b = 0$ 的根，所以有 0、1 或 2 个（重根时算一个）。

**第二步：标准形。** 若有两个不动点 $p, q$，取分式线性变换 $S$ 把 $p, q$ 送到 $0, \infty$，则 $S T S^{-1}$ 固定 $0$ 与 $\infty$，只能是 $w \mapsto \lambda w$。这时看 $|\lambda|$ 是 $1$、$> 1$ 还是其它，就分出椭圆/双曲。

**第三步：$\lambda$ 从哪来。** $T$ 对应的矩阵有特征值 $\lambda_{1}, \lambda_{2}$，而 $\lambda = \lambda_{1}/\lambda_{2}$。于是

$$\frac{\tau^{2}}{\Delta} = \frac{(\lambda_{1} + \lambda_{2})^{2}}{\lambda_{1}\lambda_{2}} = \lambda + \frac{1}{\lambda} + 2,$$
